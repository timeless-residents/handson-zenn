# Three.js Everyday Season 01 - Introduction

はじめまして！このドキュメントでは「Three.js Everyday SEASON 01」の最初のステップとして、Three.jsを使った3Dグラフィックスの世界へ足を踏み入れるための総合的な「導入」を行います。ここでは、ブラウザ上で動くインタラクティブな3D体験を作りたいというモチベーションから始まり、Three.jsを学ぶメリット、WebGLとの関係、そして実際に何をどのように学習していくかを、できるだけ丁寧に解説していきます。

本書のゴールは、JavaScriptの基本知識さえあれば**複雑な数学や低レベルなグラフィックスAPIの詳細を知らなくても** 3Dを活用したインタラクティブ表現ができるようになることです。まずはこの“introduction”を通じて、みなさんがThree.js学習に意欲を持ち、次のステップへスムーズに進めるようにするのが目的です。

本編が開始する前に、なぜThree.jsが便利なのか、どのような場面で役立つのか、そしてこのシリーズで何を学ぶのか――これらの疑問にしっかりと答えられるよう、かなり詳しく書き込んでいます。長文かつやや冗長に感じる部分もあるかもしれませんが、途中にはサンプルコードや小ネタ、開発のヒントも散りばめていますので、ぜひ気軽に読み進めてみてください。

## 1. Three.jsとは何か

### 1-1. WebGLの上位レイヤーとしてのThree.js

Three.jsは、WebGL（Web Graphics Library）のラッパ（wrapper）やフレームワークと呼ばれることがあります。WebGL自体はブラウザ上で動く低レベルな3DグラフィックスAPIであり、C++やOpenGLなどのネイティブなグラフィックスプログラミングに比べると抽象化されて使いやすくなっているとはいえ、直接触れるには依然として高い知識が要求されます。シェーダー言語や行列計算、頂点データの扱いなど、初心者が最初に直面するハードルは少なくありません。

しかし、Three.jsを使うとWebGLの複雑なAPIを直接意識する必要がほぼなくなります。オブジェクトやメッシュ、ライト、カメラといった概念を直感的に組み合わせるだけで、ブラウザ上に**リッチな3Dコンテンツ**を表示できるのです。この“直感的”というのが非常に重要で、JavaScriptのクラスやメソッドを呼び出してシーンを構築していくため、まるでゲームエンジンを扱っているかのような気軽さで3Dを扱えます。

### 1-2. Three.jsを学ぶメリット

- **シンプルな文法で始めやすい**  
  JavaScriptの基礎を理解していれば、`scene`, `camera`, `renderer`の3つを最小限に準備してスクリプトを数行書くだけで、すぐに3Dオブジェクトがブラウザに描画されます。

- **豊富な機能と拡張性**  
  パーティクルや物理シミュレーション、ポストプロセッシング、各種マテリアル設定、シェーダーのカスタマイズなども可能です。個人制作から大規模プロジェクトまで幅広く対応できます。

- **活発なコミュニティとサンプル**  
  GitHubのリポジトリや公式ドキュメントだけでなく、インターネット上には多くのブログ記事やチュートリアル、サンプルコードが存在します。困ったときに調べることで、多くのケースがすでに誰かによって解決されています。

- **3Dプログラミングの登竜門**  
  もし後にWebGLの低レベル部分やシェーダーをより深く学びたくなっても、Three.jsでの知見が大いに役立ちます。3D空間の基本概念や行列変換といった下地が、自然に身につくからです。

## 2. なぜブラウザで3D？

### 2-1. Web技術としての強み

- **マルチプラットフォーム対応**  
  ブラウザさえあれば、PCでもスマートフォンでもタブレットでも、同じURLにアクセスするだけで同一の3D体験を提供できます。ユーザーにアプリのインストールを強制することなく、即時に体験を共有できるのは大きな強みです。

- **更新や配布が容易**  
  従来の3Dコンテンツ（特にネイティブアプリ）と比べて、配布や更新が非常に容易です。コードをアップデートしてサーバーにデプロイすれば、ユーザーは新しいバージョンの3Dコンテンツを即座に体験できます。

- **UIとの連携がしやすい**  
  HTMLやCSS、JavaScriptといったWeb技術の既存のエコシステムを活用できるため、UIを作りこむのも比較的容易です。ボタンやフォームなどの要素を、Three.jsの3Dキャンバスとシームレスに組み合わせることができます。

### 2-2. インパクトのある表現

近年、Webサイトのデザインやユーザー体験において3D表現は大きなインパクトを持ちます。視覚的にもユニークで、ユーザーの印象に強く残るだけでなく、製品やコンセプトを直感的に理解してもらう手助けにもなります。

- **プレゼンテーションやプロモーション**  
  製品を3Dで閲覧できたり、インタラクティブに回転させて各部位を確認できるなど、静的な画像にはない説得力があります。

- **データ可視化**  
  大量のデータを3D空間にマッピングして可視化すると、2Dグラフでは見えてこないパターンや傾向をユーザーが発見しやすくなります。

- **ゲーミフィケーション**  
  シンプルなゲームやインタラクティブアニメーションをサイトに導入するだけでも、ユーザーの滞在時間やエンゲージメントを大幅に向上させることができます。

## 3. Three.js Everyday SEASON 01 で学ぶこと

このシリーズでは、**初学者から中級者向け**を対象に、Three.jsの基本から応用までを段階的に学習できるような構成を目指しています。特にSEASON 01は、これから3Dを学びたいという人が気軽に始められるよう、以下のようなステップに沿って内容を紹介します。

1. **環境構築とセットアップ**  
   Node.jsやローカルサーバーの準備など、最初の一歩からスタートします。CDN経由でもThree.jsを読み込めますが、開発効率を考えるとローカル環境のセットアップをおすすめするケースも多いです。

2. **基本概念（シーン、カメラ、レンダラー）**  
   Three.jsで最も重要な3つの要素「Scene」「Camera」「Renderer」について理解します。ここをしっかり押さえることで、3D空間にオブジェクトを追加し、カメラを設定し、実際に描画するプロセスが見えてきます。

3. **基本的なメッシュやライトの使い方**  
   BoxGeometryやSphereGeometryなどの基本ジオメトリを活用し、マテリアルを設定してメッシュを作成します。さらに、シーンを照らすためのライト（DirectionalLight、PointLight、AmbientLightなど）を追加して、ビジュアルの見え方を理解します。

5. **モデル読み込みとパーティクル表現**  
   glTFやOBJなどの3Dモデルを読み込み、シーンに配置する方法や、シェーダーを用いたパーティクル表現に触れます。これにより、より高度なビジュアルを作るための足がかりを得られます。

6. **実践的なユースケース**  
   小さなデモやサンプルを通じて、WebサイトやWebアプリケーションに3Dを組み込むときのポイント、パフォーマンス面の考慮などを紹介します。

## 4. Three.jsの基本構造

### 4-1. シーン（Scene）

3Dオブジェクトを配置する「空間」です。何もない真っ暗闇の空間をイメージしてもらうとよいでしょう。そこにメッシュを置き、ライトで照らし、カメラを配置するといった手順で、最終的にレンダラーがその空間をブラウザ上に描画します。

```js
// シーンの作成
const scene = new THREE.Scene();
```

### 4-2. カメラ（Camera）

ユーザーがシーンをどのような視点で見ているのかを決定します。Three.jsではパースペクティブカメラ（遠近感を表現する）やオルソカメラ（遠近感のない平行投影）などがよく使われます。

```js
// パースペクティブカメラ
const camera = new THREE.PerspectiveCamera(
  75, // 視野角
  window.innerWidth / window.innerHeight, // アスペクト比
  0.1, // ニアクリップ
  1000 // ファークリップ
);
camera.position.z = 5;
```

### 4-3. レンダラー（Renderer）

シーンとカメラをもとにブラウザ上に描画を行う役割を担います。WebGLRendererが典型的で、高度な制御が必要なときやパフォーマンス上の理由から他のレンダラーを使うこともありますが、基本的にはWebGLRendererを使っておけば問題ありません。

```js
// レンダラーの作成
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
```

### 4-4. メッシュ（Mesh）とジオメトリ（Geometry）、マテリアル（Material）

- **ジオメトリ**: 頂点情報、形状そのもの
- **マテリアル**: 色や質感
- **メッシュ**: ジオメトリとマテリアルを組み合わせた実体

```js
const geometry = new THREE.BoxGeometry(1, 1, 1); // 立方体
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
```

## 5. 簡単なサンプルコード解説

ここまでの要素を組み合わせると、最もシンプルなThree.jsのサンプルが書けます。以下は「緑色の立方体を回転させながら描画する」だけの基本サンプルです。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>Three.js Basic Sample</title>
  <style>
    body { margin: 0; }
    canvas { display: block; }
  </style>
</head>
<body>
  <script src="https://cdn.jsdelivr.net/npm/three@0.147.0/build/three.min.js"></script>
  <script>
    // シーン
    const scene = new THREE.Scene();

    // カメラ
    const camera = new THREE.PerspectiveCamera(
      75,
      window.innerWidth / window.innerHeight,
      0.1,
      1000
    );
    camera.position.z = 5;

    // レンダラー
    const renderer = new THREE.WebGLRenderer({ antialias: true });
    renderer.setSize(window.innerWidth, window.innerHeight);
    document.body.appendChild(renderer.domElement);

    // 立方体のメッシュを作成
    const geometry = new THREE.BoxGeometry(1, 1, 1);
    const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
    const cube = new THREE.Mesh(geometry, material);
    scene.add(cube);

    // アニメーションループ
    function animate() {
      requestAnimationFrame(animate);
      cube.rotation.x += 0.01; // X軸回転
      cube.rotation.y += 0.01; // Y軸回転
      renderer.render(scene, camera);
    }
    animate();
  </script>
</body>
</html>
```

このように、ほんの数十行のコードで簡単に3Dオブジェクトの描画とアニメーションを実現できます。初めて3Dを触る方にとっては、ここまでですでに大きな感動があるかもしれません。次に進むモチベーションにつなげていきましょう。

## 6. Three.jsを学ぶための前提知識

### 6-1. JavaScriptの基本文法

Three.jsはJavaScriptで動作します。したがって、**変数、関数、クラス、配列、オブジェクト**などの基本的なJavaScript文法は押さえておきたいところです。特に`this`の扱いやES6以降のモダンな文法（`let`, `const`, アロー関数、モジュールの仕組みなど）に慣れていない方は、簡単な文法解説の参考サイトをひととおり読むことをおすすめします。

### 6-2. HTMLとCSS

Three.jsの描画結果はキャンバス（`<canvas>`要素）上に表示されます。HTMLやCSSを組み合わせて、ブラウザ上にUIやテキスト要素を配置したり、Three.jsで作ったシーンを部分的にレイアウトに組み込んだりするケースも多々あります。その際、UIと3Dキャンバスの位置関係やレスポンシブ対応などは、通常のWeb制作と同じ知識が必要になります。

### 6-3. 基礎的な数学（行列、ベクトル、角度など）

Three.jsを使うだけなら、厳密な線形代数やベクトル・行列演算を理解しなくても最低限の3D表現は可能です。ただし、**3D空間の座標系の扱い**や**カメラの視野角**、**オブジェクトの回転**をコントロールする際には、少しだけ数学的な概念が登場します。たとえば、**オイラー角**や**クォータニオン**など、3D回転に特有の用語も出てくるでしょう。はじめは公式ドキュメントやチュートリアルを参考にしながら慣れていく形でOKです。

## 7. Three.jsプロジェクトを成功させるためのポイント

### 7-1. スケッチから始める

「大規模な3Dゲームを作りたい！」「めちゃくちゃリアルな3D世界を再現したい！」という壮大な構想を抱くことは素晴らしいですが、まずは**小さなスケッチやサンプルを作る**ところから始めるのが吉です。一つひとつの要素（メッシュ、カメラ、ライティング、アニメーションなど）を試しながら理解を深めることで、後の大きなプロジェクトでもトラブルシューティングがスムーズになります。

### 7-2. 定期的なブラウザテスト

Three.jsは比較的互換性が高いとはいえ、各ブラウザエンジンで微妙な挙動差がある可能性は否定できません。特にモバイルブラウザの場合、パフォーマンスのボトルネックや対応しているWebGLのバージョンが異なる場合があります。**開発過程で定期的に複数のブラウザ・デバイスでテスト**することで、予期せぬ問題を未然に発見できます。

### 7-3. スケーラビリティとパフォーマンス

- **テクスチャの最適化**: 大きなテクスチャファイルをそのまま読み込むと、メモリを大量に消費し、描画が遅くなる可能性があります。
- **モデルのポリゴン数**: 高精細な3Dモデルを多用すると、GPUの負荷が大きくなります。必要に応じてモデルを軽量化することも重要です。
- **フレームレート管理**: `requestAnimationFrame`でアニメーションする場合、1フレームあたりの処理が重いとカクつきを招きます。複雑な計算や大量のオブジェクトを扱う際は、パーティクルシステムの最適化やインスタンシングなどの技術を活用しましょう。

## 8. シェーダーへの入り口

Three.jsは、デフォルトで用意されたマテリアル（`MeshBasicMaterial`, `MeshStandardMaterial`, `MeshPhongMaterial`など）を使うだけでも多彩な表現が可能ですが、さらに踏み込んで**オリジナルシェーダー**を書くこともできます。これは少し高度なトピックではありますが、シリーズの後半や追加のチュートリアルで触れることで、より自由度の高いビジュアル表現を実現できるようになります。

- **ShaderMaterial**: 頂点シェーダーとフラグメントシェーダーを自前で定義できる
- **RawShaderMaterial**: Three.jsが提供する組み込みの変数やユニフォームを使わず、より低レベルに近い形でWebGLシェーダーを書ける

シェーダーを自作すると、普段の3D表現だけでは不可能な特殊効果やノイズ表現、ポストプロセッシングなど、より幅広いアーティスティックな表現が可能になります。最終的にはシェーダーを書くか書かないかで、表現力に大きな差が出てくるでしょう。

## 11. これからの3D表現の可能性

### 11-1. WebXRとの連携

WebGLやThree.jsは、WebXR（仮想現実・拡張現実をブラウザで体験できるAPI）とも関連が深いです。将来的にはVRヘッドセットやAR対応デバイスと組み合わせることで、没入感の高い3Dコンテンツをウェブ上で手軽に実現できるようになります。Three.jsでも、WebXRに対応したサンプルがすでにいくつか存在します。

### 11-2. メタバースやNFTとのシナジー

最近の技術トレンドであるメタバースやNFTと組み合わせ、ブラウザ上に**仮想空間**を構築し、そこに自分のアバターやデジタルアートを展示する――というような活用例も増えています。Three.jsは3D表現の基盤技術として最適であり、これからも活躍の場は広がっていくでしょう。

### 11-3. 教育や産業用途

- **教育**: 物理演習や天体シミュレーション、解剖学モデルなど、教育現場での3Dビジュアル化は年々重要度を増しています。
- **産業用途**: 工場のレイアウトシミュレーション、建築の3Dモデル確認、製品デザインのレビューなど、3Dが使われる現場は多岐にわたります。

ここまで読んで、「よし、やってみよう！」と思っていただければ幸いです。Three.jsが可能にする多彩な表現や機能を、ぜひ楽しみながら学んでいきましょう。次の章「Getting Started」では、環境構築や最初のプロジェクトセットアップについて詳しく解説していきます。

## 14. さらに踏み込むヒント（おまけ）

ここからは少しだけ先取りの情報や、Three.jsの学習で行き詰まったときに役立つヒントをいくつかお伝えします。余裕があれば参考にしてみてください。

1. **Scene Graph（シーングラフ）**  
   Three.jsはシーングラフ構造を持ち、それぞれのオブジェクトが階層的に管理されています。親オブジェクトを回転させると子オブジェクトも一緒に回転するといった特徴を把握しておくと、複雑なアニメーションやオブジェクト配置をスムーズに行えます。

2. **OrbitControlsなどのコントロールツール**  
   公式の`examples/jsm/controls/OrbitControls.js`などを使うと、マウスドラッグで視点を回転させたり、ホイールでズームしたりといった操作が簡単に実装できます。初期段階ではこういったツールを使うのがおすすめです。

3. **Helper系オブジェクトの活用**  
   Three.jsには、軸やライトの可視化に使えるヘルパー（`AxesHelper`, `CameraHelper`, `LightHelper`など）が多数あります。デバッグや学習段階では積極的に使いましょう。

4. **カメラの種類・特性**  
   パースペクティブカメラの他にも、オルソグラフィックカメラ（`OrthographicCamera`）があり、2Dライクな表現に重宝します。状況に応じてカメラを使い分けることで、思い通りの絵作りが可能です。

5. **Raycasterでオブジェクトをクリック検知**  
   インタラクティブな3Dシーンを作る際、ユーザーが3Dオブジェクトをクリックしたりタップしたりできるようにするには、`Raycaster`を使います。マウス座標をレイに変換して、シーンのメッシュとの交差判定を行う仕組みです。

6. **ライブラリと併用した高度な表現**  
   たとえば、物理演算を扱う`cannon.js`や`ammo.js`を組み合わせて、リアルな剛体シミュレーションを実装することも可能です。また、PostProcessingのライブラリを使えば、被写界深度やモーションブラーなどのエフェクトを簡単に適用できます。

## 15. プロジェクト導入に便利なサンプル：Three.js ショールームギャラリー

ここまで読み進めて、Three.jsを使って実際にどんなプロジェクトが作れるのか気になってきた方も多いでしょう。ここでは、**具体的な学習リソース**として、以下のオープンソースプロジェクトを紹介します。

- [GitHubリポジトリ: timeless-residents/handson-threejs](https://github.com/timeless-residents/handson-threejs)  
- [デモページ: https://timeless-residents.github.io/handson-threejs/](https://timeless-residents.github.io/handson-threejs/)

### 15-1. Three.js ショールームギャラリーとは？

- **複数のThree.jsシーンを展示するギャラリーサイト**  
  - 回転するキューブ、パーティクル、物理演算など、さまざまな例をカテゴリ別にまとめている。  
  - 検索バーやカテゴリタグを用いてシーンの絞り込みが可能。  
- **ソースコードがすべて公開されており、自由に改変できる**  
  - `npm run dev` でローカル開発サーバーを立ち上げ、すぐに学習・拡張が可能。  
- **複数のユースケースを横断しながら、Three.jsの使い方を体系的に把握できる**  
  - シーンごとに個別の設定や実装を分けており、徐々にステップアップしやすい構造。

### 15-2. セットアップ方法

以下は当該プロジェクト(`handson-threejs`)のREADMEにある手順の抜粋です。Three.jsに触れ始めたばかりの方が、**実際の運用例**として学習・改造してみるのに最適です。

#### 前提条件

- Node.js (バージョン14以上)
- npm または yarn

#### インストール

1. リポジトリをクローンします。

    ```sh
    git clone https://github.com/timeless-residents/handson-threejs.git
    ```

2. プロジェクトディレクトリに移動します。

    ```sh
    cd handson-threejs
    ```

3. 依存関係をインストールします。

    ```sh
    npm install
    ```
    または
    ```sh
    yarn install
    ```

#### 開発サーバーの起動

開発サーバーを起動して、プロジェクトをローカルで確認します。

```sh
npm run dev
```
または
```sh
yarn dev
```

ブラウザで `http://localhost:3000` を開いて、アプリケーションを確認します。

#### ビルド

プロジェクトを本番環境用にビルドします。

```sh
npm run build
```
または
```sh
yarn build
```

`dist` フォルダにビルドされたファイルが生成されます。

### 15-3. ディレクトリ構造と使い方

```
handson-threejs/
├── dist/                # ビルドされたファイル
├── src/                 # ソースコード
│   ├── gallery.js       # ギャラリーのメインスクリプト
│   └── ...              # その他のスクリプトやモジュール
├── index.html           # メインのHTMLファイル
├── styles/              # スタイルシート
│   └── main.css         # メインのスタイルシート
└── README.md            # このREADMEファイル
```

- **カテゴリタグ**をクリックして、特定のカテゴリのシーンだけを表示。
- **検索バー**にキーワードを入力して、シーンを検索。
- **シーンカード**をクリックすると詳細情報ページへ遷移し、Three.jsのコードが実際に動作する様子をチェックできる。

### 15-4. 自分のプロジェクトへの応用

1. **新しいシーン（Usecase）を追加**  
   `src/usecases` 配下に新たなフォルダを作成し、そこでシーンを定義。metadataを設定してギャラリーに表示できるようにする。
2. **既存のシーンコードを参考に改造**  
   キューブをパーティクルに変えてみたり、マテリアルを変更してみたり、ライトの位置や色を変えてみるなど、少しずつ手を動かして慣れるのがおすすめ。
3. **レイアウトやUIを変更**  
   `index.html` や `styles/main.css` を修正すれば、見た目やUIも簡単にカスタマイズできる。

### 15-5. 貢献方法

バグ報告や機能リクエストは、GitHub上の[Issues](https://github.com/timeless-residents/handson-threejs/issues)で受け付けているとのこと。Pull Requestも歓迎されているので、何か新しいシーンを作成してみたり、既存コードを改善してみたりしてコミュニティに貢献するのも学習を深める良い機会です。
