## 第 17 章：ServiceNow 認定資格：キャリアアップへの道

### 17.1 ServiceNow 認定資格の種類と概要

#### 概要と重要性

ServiceNow 認定資格は、ServiceNow プラットフォームに関する知識とスキルを証明する公式な資格です。ServiceNow のエコシステムは拡大を続けており、高度なスキルを持つ人材への需要は高まる一方です。認定資格を取得することで、あなたの市場価値を高め、キャリアアップの機会を広げることができます。企業側にとっても、認定資格を持つ人材は即戦力として期待でき、プロジェクトの成功率向上に貢献します。

#### Certified System Administrator (CSA)

**特徴と利点:** CSA は、ServiceNow プラットフォームの基本的な管理スキルを証明する最もポピュラーな資格です。インスタンスの設定、ユーザー管理、基本的なワークフローの管理など、ServiceNow プラットフォームの日常的な運用に必要なスキルを網羅しています。

**事前準備と前提条件:** 特に必須の前提条件はありませんが、ServiceNow の基本的な知識（テーブル、フォーム、リスト、モジュールなど）があるとスムーズに学習を進められます。ServiceNow Learn サイトの「System Administrator」ラーニングパスを受講することをお勧めします。

**基本的な使い方:**

- ServiceNow インスタンスへのログイン方法
- ユーザーとグループの作成と管理
- ロールの割り当てと権限管理
- 基本的なインシデント管理ワークフローの設定
- ナレッジベースの管理
- レポートの作成とカスタマイズ

**実践的なテクニック:**

- **ビジネスルールの活用:** 特定の条件が満たされた場合に自動的に実行されるスクリプトを作成します。例えば、優先度が高いインシデントがアサインされていない場合、担当グループのマネージャーに通知するビジネスルールを作成できます。

```javascript
(function executeRule(current, previous /*null when async*/) {
  // This example sends a notification if the priority is P1 and assignment group is empty.
  if (current.priority == 1 && current.assignment_group.nil()) {
    var gr = new GlideRecord("sys_user");
    gr.get("sys_id", "YOUR_MANAGER_SYS_ID"); // マネージャーのSys IDを指定
    var email = new GlideEmailOutbound();
    email.setSubject("High Priority Incident Needs Assignment");
    email.setBody(
      "Incident " + current.number + " needs immediate assignment!"
    );
    email.addAddress("to", gr.email, "Manager");
    email.send();
  }
})(current, previous);
```

- **クライアントスクリプトの活用:** フォーム上でリアルタイムに動作するスクリプトを作成します。例えば、インシデントの深刻度に応じて影響度の選択肢を動的に変更できます。

```javascript
function onChange(control, oldValue, newValue, isLoading, isTemplate) {
  if (isLoading || newValue === "") {
    return;
  }

  if (newValue == "critical") {
    g_form.clearOptions("impact");
    g_form.addOption("impact", "1", "High", true);
  } else {
    g_form.clearOptions("impact");
    g_form.addOption("impact", "2", "Medium", true);
    g_form.addOption("impact", "3", "Low");
  }
}
```

**応用例とユースケース:**

- **サービスカタログ:** エンドユーザーが IT サービスをリクエストするためのポータルを作成します。例えば、新しいソフトウェアのインストール、アカウント作成、パスワードリセットなどを自動化します。
- **変更管理:** 変更要求の承認プロセスを自動化し、変更によるリスクを最小限に抑えます。承認ワークフローを設定し、変更の計画、テスト、実装を追跡します。

**トラブルシューティング:**

- **ビジネスルールが期待通りに動作しない:** スクリプトログを確認し、エラーメッセージや変数の中身を確認します。
- **クライアントスクリプトが動作しない:** ブラウザの開発者ツールで JavaScript のエラーを確認します。

**まとめと次のステップ:**

CSA は ServiceNow の基礎を固める上で非常に重要な資格です。取得後は、より専門的な分野の資格取得を目指したり、実際のプロジェクトで経験を積むことをお勧めします。

#### Certified Application Developer (CAD)

**特徴と利点:** CAD は、ServiceNow プラットフォーム上でカスタムアプリケーションを開発するスキルを証明する資格です。スクリプト、ワークフロー、UI ポリシーなどを活用して、ビジネスニーズに合わせたアプリケーションを構築できます。

**事前準備と前提条件:** CSA 資格があると、よりスムーズに学習を進められます。JavaScript の基本的な知識も必要です。ServiceNow Learn サイトの「Application Developer」ラーニングパスを受講することをお勧めします。

**基本的な使い方:**

- ServiceNow Studio を使用したアプリケーション開発
- テーブルとフォームの設計
- クライアントスクリプトとサーバーサイドスクリプトの記述
- ワークフローの作成とカスタマイズ
- UI ポリシーと UI アクションの設定
- レポートとダッシュボードの作成

**実践的なテクニック:**

- **GlideRecord を使ったデータ操作:** データベースからデータを取得、更新、削除するためのスクリプトを記述します。

```javascript
var gr = new GlideRecord("incident");
gr.addQuery("category", "network");
gr.query();
while (gr.next()) {
  gs.log(
    "Incident Number: " +
      gr.number +
      ", Short Description: " +
      gr.short_description
  );
  // インシデントの解決日を更新
  gr.resolved_at = gs.nowDateTime();
  gr.update();
}
```

- **Flow Designer の活用:** コードを書かずに、ドラッグアンドドロップでワークフローを構築します。

**応用例とユースケース:**

- **人事管理アプリケーション:** 従業員の入社、異動、退職に関するプロセスを自動化するアプリケーションを開発します。
- **プロジェクト管理アプリケーション:** プロジェクトの進捗状況を追跡し、リソースを管理するためのアプリケーションを開発します。

**トラブルシューティング:**

- **GlideRecord のクエリが期待通りに動作しない:** クエリ条件を確認し、正しいフィールド名と値を使用していることを確認します。
- **Flow Designer でエラーが発生する:** エラーメッセージを確認し、必要な入力値が設定されているか、正しいアクションが選択されているかを確認します。

**まとめと次のステップ:**

CAD は、ServiceNow プラットフォーム上で独自のアプリケーションを開発したい場合に最適な資格です。取得後は、実際のプロジェクトでアプリケーション開発の経験を積むことをお勧めします。

#### Certified Implementation Specialist (CIS)

**特徴と利点:** CIS は、特定の ServiceNow 製品（ITSM、ITOM、HRSD など）の実装スキルを証明する資格です。顧客のビジネス要件を理解し、ServiceNow プラットフォームを最適に構成する能力が求められます。

**事前準備と前提条件:** 関連する ServiceNow 製品の知識と経験が必要です。ServiceNow Learn サイトの該当する製品のラーニングパスを受講することをお勧めします。

**基本的な使い方:**

- ServiceNow の実装方法論（SIM）の理解
- 顧客の要件定義と分析
- ServiceNow プラットフォームの構成とカスタマイズ
- データ移行と統合
- テストと検証
- トレーニングとドキュメント作成

**実践的なテクニック:**

- **Update Set の管理:** 変更を別のインスタンスに移行するための Update Set を作成、適用します。
- **Data Lookup Definition:** 外部データソースからデータを参照し、ServiceNow のレコードを自動的に入力します。

**応用例とユースケース:**

- **ITSM の実装:** インシデント管理、問題管理、変更管理などの ITSM プロセスを ServiceNow で実装します。
- **HRSD の実装:** 従業員からの問い合わせ対応、オンボーディング、オフボーディングなどの HR プロセスを ServiceNow で実装します。

**トラブルシューティング:**

- **データ移行で問題が発生する:** データ形式の不整合、マッピングの問題などを確認します。
- **Update Set の適用でエラーが発生する:** Update Set に含まれるレコードの競合、依存関係の問題などを確認します。

**まとめと次のステップ:**

CIS は、ServiceNow の実装プロジェクトで活躍したい場合に最適な資格です。取得後は、様々なプロジェクトに参加し、経験を積むことをお勧めします。

#### その他専門分野の認定資格

ServiceNow は、上記以外にも様々な専門分野の認定資格を提供しています。

- **Certified Application Specialist - Performance Analytics:** Performance Analytics の知識とスキルを証明する資格です。
- **Certified Application Specialist - Security Incident Response:** Security Incident Response の知識とスキルを証明する資格です。
- **Certified Application Specialist - Service Mapping:** Service Mapping の知識とスキルを証明する資格です。

これらの資格は、特定の分野に特化したスキルを証明し、キャリアの専門性を高めるのに役立ちます。

### 17.2 試験対策：学習方法とリソース

#### ServiceNow Learn サイトの活用

**概要と重要性:** ServiceNow Learn サイトは、ServiceNow 公式の学習プラットフォームであり、認定試験対策に不可欠なリソースです。様々なラーニングパス、コース、ドキュメントが提供されており、体系的に学習を進めることができます。

**特徴と利点:**

- 公式の情報源であるため、最新かつ正確な情報が得られる
- ハンズオンラボが用意されており、実践的なスキルを習得できる
- 認定試験の出題範囲に沿った内容で構成されている

**事前準備と前提条件:** 特にありません。ServiceNow アカウントを作成し、ログインするだけで、すべてのコンテンツにアクセスできます。

**基本的な使い方:**

1.  ServiceNow Learn サイトにアクセスします。
2.  目的の認定資格に対応するラーニングパスを選択します。
3.  ラーニングパスに含まれるコースを順番に受講します。
4.  各コースの最後に用意されているクイズやテストで理解度を確認します。
5.  ハンズオンラボで実践的なスキルを習得します。

**実践的なテクニック:**

- **ノートを取る:** 学習内容をノートにまとめ、後で復習できるようにします。
- **質問をする:** わからないことがあれば、コミュニティフォーラムで質問したり、インストラクターに質問したりします。
- **繰り返し学習する:** 1 回だけでなく、繰り返し学習することで、知識を定着させます。

**応用例とユースケース:**

- **認定試験対策:** 認定試験の出題範囲を網羅的に学習し、合格に必要な知識とスキルを習得します。
- **スキルアップ:** 既存のスキルを向上させ、新しいスキルを習得します。
- **プロジェクト支援:** プロジェクトに必要な知識とスキルを迅速に習得します。

**トラブルシューティング:**

- **コースが表示されない:** 適切なロールが付与されているか確認します。
- **ハンズオンラボが起動しない:** ブラウザのキャッシュをクリアしたり、別のブラウザで試したりします。

**まとめと次のステップ:**

ServiceNow Learn サイトは、認定試験対策だけでなく、ServiceNow の知識とスキルを向上させるための非常に強力なツールです。積極的に活用し、キャリアアップにつなげましょう。

#### 模擬試験の利用

**概要と重要性:** 模擬試験は、認定試験の形式や難易度を事前に体験し、自分の弱点を把握するための重要なツールです。本番の試験に向けて、時間配分や解答戦略を練習することができます。

**特徴と利点:**

- 本番の試験に近い形式で出題される
- 自分の弱点を把握できる
- 時間配分や解答戦略を練習できる

**事前準備と前提条件:** ServiceNow Learn サイトで基本的な知識を習得しておくことが望ましいです。

**基本的な使い方:**

1.  ServiceNow 認定試験の模擬試験を購入または入手します。
2.  試験時間内にすべての問題に解答します。
3.  採点し、正答率を確認します。
4.  間違えた問題について、解説を読み、理解を深めます。
5.  弱点を克服するために、ServiceNow Learn サイトで該当する箇所を復習します。
6.  繰り返し模擬試験を受け、正答率を向上させます。

**実践的なテクニック:**

- **時間配分:** 各問題にかけられる時間を計算し、時間内にすべての問題に解答できるように練習します。
- **解答戦略:** 難しい問題は後回しにし、確実に解答できる問題から解くようにします。
- **復習:** 間違えた問題だけでなく、正解した問題についても解説を読み、理解を深めます。

**応用例とユースケース:**

- **認定試験対策:** 認定試験の合格に必要な知識とスキルを習得します。
- **自己評価:** 自分の知識レベルを客観的に評価します。
- **学習計画:** 自分の弱点を克服するための学習計画を立てます。

**トラブルシューティング:**

- **模擬試験が見つからない:** ServiceNow Partner Portal で検索したり、認定トレーニングを提供している企業に問い合わせたりします。
- **模擬試験の結果が思わしくない:** 弱点を克服するために、ServiceNow Learn サイトで該当する箇所を復習したり、コミュニティフォーラムで質問したりします。

**まとめと次のステップ:**

模擬試験は、認定試験の合格を確実にするための重要なツールです。繰り返し模擬試験を受け、自分の弱点を克服し、自信を持って本番の試験に臨みましょう。

#### コミュニティフォーラムでの情報交換

**概要と重要性:** ServiceNow コミュニティフォーラムは、世界中の ServiceNow ユーザーが集まる活発なコミュニティです。質問、回答、ディスカッションを通じて、知識を共有し、問題を解決することができます。

**特徴と利点:**

- 経験豊富な ServiceNow ユーザーからアドバイスやヒントを得られる
- 他の受験生と情報交換できる
- ServiceNow に関する最新情報を入手できる

**事前準備と前提条件:** ServiceNow アカウントを作成し、ログインする必要があります。

**基本的な使い方:**

1.  ServiceNow コミュニティフォーラムにアクセスします。
2.  質問を投稿したり、他のユーザーの質問に回答したりします。
3.  ディスカッションに参加したり、ブログを読んだりします。
4.  興味のあるキーワードやトピックをフォローします。

**実践的なテクニック:**

- **質問の仕方:** 質問を投稿する前に、過去の投稿を検索し、同様の質問がないか確認します。質問を具体的に記述し、必要な情報をすべて提供します。
- **回答の仕方:** 質問に正確かつ丁寧に回答します。回答の根拠となる情報を提示します。

**応用例とユースケース:**

- **認定試験対策:** 試験範囲に関する質問をしたり、他の受験生と情報交換したりします。
- **問題解決:** ServiceNow に関する問題を解決するために、他のユーザーにアドバイスを求めます。
- **スキルアップ:** ServiceNow に関する最新情報を入手したり、新しいスキルを習得したりします。

**トラブルシューティング:**

- **質問しても回答が得られない:** 質問の内容が不明確であるか、過去に同様の質問が投稿されている可能性があります。質問の内容を修正したり、検索したりしてみましょう。
- **不適切な投稿を見つけた:** モデレーターに報告します。

**まとめと次のステップ:**

ServiceNow コミュニティフォーラムは、認定試験対策だけでなく、ServiceNow の知識とスキルを向上させるための非常に貴重なリソースです。積極的に参加し、他のユーザーと交流し、ServiceNow のエキスパートを目指しましょう。

### 17.3 キャリアパス：ServiceNow エンジニアとしての成長戦略

#### ServiceNow コンサルタント

**概要と重要性:** ServiceNow コンサルタントは、顧客のビジネスニーズを理解し、ServiceNow プラットフォームを活用して最適なソリューションを提供する専門家です。要件定義、設計、実装、テスト、トレーニングなど、ServiceNow プロジェクトの全フェーズに関わります。

**特徴と利点:**

- 様々な業界の顧客と接する機会がある
- 幅広い ServiceNow 製品の知識を習得できる
- 顧客のビジネスに貢献できる

**事前準備と前提条件:** CSA、CAD、CIS などの ServiceNow 認定資格があると有利です。コミュニケーション能力、問題解決能力、プレゼンテーション能力も重要です。

**基本的な使い方:**

- 顧客のビジネスニーズをヒアリングし、要件を定義します。
- ServiceNow プラットフォームの構成を設計します。
- ServiceNow プラットフォームを実装します。
- テストを実施し、品質を確保します。
- 顧客にトレーニングを提供します。
- プロジェクトのドキュメントを作成します。

**実践的なテクニック:**

- **要件定義:** 顧客のビジネスプロセスを理解し、具体的な要件に落とし込みます。
- **ソリューション設計:** ServiceNow の標準機能とカスタム開発を組み合わせ、最適なソリューションを設計します。
- **プロジェクト管理:** プロジェクトの進捗状況を管理し、期日内にプロジェクトを完了させます。

**応用例とユースケース:**

- **ITSM コンサルタント:** インシデント管理、問題管理、変更管理などの ITSM プロセスを ServiceNow で最適化します。
- **HRSD コンサルタント:** 従業員からの問い合わせ対応、オンボーディング、オフボーディングなどの HR プロセスを ServiceNow で最適化します。
- **ITOM コンサルタント:** サーバー、ネットワーク、アプリケーションなどの IT インフラを ServiceNow で管理します。

**トラブルシューティング:**

- **要件定義が曖昧な場合:** 顧客に追加のヒアリングを行い、要件を明確にします。
- **プロジェクトが遅延している場合:** 遅延の原因を分析し、対策を講じます。
- **顧客の満足度が低い場合:** 顧客の期待値を理解し、改善策を実施します。

**まとめと次のステップ:**

ServiceNow コンサルタントは、顧客のビジネスに貢献できるやりがいのある仕事です。様々なプロジェクトに参加し、経験を積むことで、より高度なコンサルタントを目指しましょう。

#### ServiceNow デベロッパー

**概要と重要性:** ServiceNow デベロッパーは、ServiceNow プラットフォーム上でカスタムアプリケーションを開発する専門家です。スクリプト、ワークフロー、UI ポリシーなどを活用して、ビジネスニーズに合わせたアプリケーションを構築します。

**特徴と利点:**

- 創造的な仕事ができる
- 技術的なスキルを向上させられる
- ビジネスに貢献できる

**事前準備と前提条件:** CAD などの ServiceNow 認定資格があると有利です。JavaScript、HTML、CSS などのプログラミングスキルも必要です。

**基本的な使い方:**

- ServiceNow Studio を使用してアプリケーションを開発します。
- テーブルとフォームを設計します。
- クライアントスクリプトとサーバーサイドスクリプトを記述します。
- ワークフローを作成およびカスタマイズします。
- UI ポリシーと UI アクションを設定します。
- レポートとダッシュボードを作成します。
- テストを実施し、品質を確保します。

**実践的なテクニック:**

- **スクリプトの最適化:** スクリプトの実行速度を向上させるために、効率的なコードを記述します。
- **ワークフローの設計:** 複雑なビジネスプロセスを、シンプルで効率的なワークフローで表現します。
- **UI の設計:** ユーザーが使いやすいように、直感的で分かりやすい UI を設計します。

**応用例とユースケース:**

- **カスタムアプリケーションの開発:** 顧客のビジネスニーズに合わせたカスタムアプリケーションを開発します。
- **既存アプリケーションの拡張:** ServiceNow の標準アプリケーションを拡張し、機能を追加します。
- **API 連携:** 外部システムと ServiceNow を連携させます。

**トラブルシューティング:**

- **スクリプトでエラーが発生する:** スクリプトログを確認し、エラーメッセージを分析します。
- **ワークフローが期待通りに動作しない:** ワークフローログを確認し、処理の流れを追跡します。
- **UI が表示されない:** ブラウザの開発者ツールでエラーを確認します。

**まとめと次のステップ:**

ServiceNow デベロッパーは、創造的な仕事ができる魅力的なキャリアです。様々なプロジェクトに参加し、経験を積むことで、より高度なデベロッパーを目指しましょう。

#### ServiceNow アーキテクト

**概要と重要性:** ServiceNow アーキテクトは、ServiceNow プラットフォーム全体の設計と実装を統括する専門家です。ビジネス要件、技術要件、セキュリティ要件などを考慮し、最適なアーキテクチャを設計します。

**特徴と利点:**

- ServiceNow プラットフォーム全体を把握できる
- 大規模なプロジェクトを主導できる
- 技術的なリーダーシップを発揮できる

**事前準備と前提条件:** CSA、CAD、CIS などの ServiceNow 認定資格に加えて、ServiceNow プラットフォームに関する深い知識と豊富な経験が必要です。IT アーキテクチャ、セキュリティ、ネットワークに関する知識も必要です。

**基本的な使い方:**

- ビジネス要件と技術要件を分析します。
- ServiceNow プラットフォームのアーキテクチャを設計します。
- セキュリティ要件を実装します。
- パフォーマンス要件を考慮します。
- ドキュメントを作成します。
- プロジェクトチームを指導します。

**実践的なテクニック:**

- **アーキテクチャ設計:** 可用性、拡張性、セキュリティ、パフォーマンスなどを考慮し、最適なアーキテクチャを設計します。
- **技術選定:** プロジェクトに最適な技術を選定します。
- **プロジェクト管理:** プロジェクトを成功させるために、プロジェクトチームを指導します。

**応用例とユースケース:**

- **エンタープライズアーキテクチャ:** ServiceNow をエンタープライズアーキテクチャの一部として設計します。
- **クラウドアーキテクチャ:** ServiceNow をクラウド環境に展開します。
- **セキュリティアーキテクチャ:** ServiceNow のセキュリティを強化します。

**トラブルシューティング:**

- **アーキテクチャ設計に問題がある場合:** 経験豊富なアーキテクトに相談し、設計を見直します。
- **プロジェクトが遅延している場合:** 遅延の原因を分析し、対策を講じます。
- **セキュリティ上の問題が発生した場合:** セキュリティ専門家と協力し、問題を解決します。

**まとめと次のステップ:**

ServiceNow アーキテクトは、ServiceNow プラットフォームの成功を左右する重要な役割です。技術的なリーダーシップを発揮し、大規模なプロジェクトを成功に導きましょう。
