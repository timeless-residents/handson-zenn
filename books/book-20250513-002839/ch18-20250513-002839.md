## 第 18 章：ServiceNow コミュニティ：情報交換と交流の場

ServiceNow のポテンシャルを最大限に引き出すためには、公式が提供する強力なコミュニティを活用することが不可欠です。この章では、ServiceNow Community Forums と Developer Program という、二つの主要なコミュニティプラットフォームについて、その活用方法を深く掘り下げて解説します。これらのプラットフォームは、単に疑問を解決する場所ではなく、最新情報を入手し、専門家と交流し、自身のスキルを向上させるための貴重なリソースです。

### 18.1 ServiceNow Community Forums の活用

#### 18.1.1 概要と重要性

ServiceNow Community Forums は、世界中の ServiceNow ユーザーが集まるオンラインプラットフォームです。初心者から経験豊富な開発者、管理者、エンドユーザーまで、幅広い層が参加し、知識や経験を共有しています。フォーラムを活用することで、ServiceNow に関する疑問の解決、ベストプラクティスの学習、最新情報の収集、そして他のユーザーとのネットワーク構築が可能になります。ServiceNow の活用において、このコミュニティは非常に重要な役割を果たします。

#### 18.1.2 特徴と利点

ServiceNow Community Forums には、以下のような特徴と利点があります。

- **広範なトピック**: IT サービス管理（ITSM）、IT 運用管理（ITOM）、IT ビジネス管理（ITBM）、カスタマーサービス管理（CSM）、人事サービスデリバリー（HRSD）、アプリ開発など、ServiceNow のあらゆる側面をカバーするトピックが議論されています。
- **豊富な情報**: 過去の投稿やドキュメントが豊富に蓄積されており、問題解決のヒントやアイデアを見つけることができます。
- **専門家のサポート**: ServiceNow のエキスパートや MVP（Most Valuable Professional）が活発に活動しており、質の高い回答やアドバイスを得ることができます。
- **迅速な回答**: 質問を投稿すると、多くの場合、数時間以内に回答が得られます。
- **グローバルなネットワーク**: 世界中の ServiceNow ユーザーと繋がり、情報交換や共同作業を行うことができます。
- **公式情報へのアクセス**: ServiceNow の公式情報やアップデートが定期的に投稿され、最新情報を常に把握することができます。

#### 18.1.3 事前準備と前提条件

ServiceNow Community Forums を利用するには、ServiceNow の Hi アカウントが必要です。Hi アカウントは、ServiceNow の顧客またはパートナーであれば無料で作成できます。

1.  **Hi アカウントの作成**: ServiceNow のサポートポータル（Hi ポータル）にアクセスし、新規アカウントを作成します。
2.  **プロフィールの設定**: Hi アカウントで Community Forums にログインし、プロフィールを設定します。興味のあるトピックや得意なスキルなどを記述することで、他のユーザーとの交流が円滑になります。
3.  **フォーラムのルール確認**: フォーラムのルール（英語）を必ず確認し、コミュニティの一員として適切な行動を心がけましょう。

#### 18.1.4 基本的な使い方

ServiceNow Community Forums の基本的な使い方は以下の通りです。

1.  **検索**: 質問やキーワードを入力して、過去の投稿を検索します。類似の質問や解決策が見つかる可能性があります。
2.  **質問の投稿**: 解決策が見つからない場合は、新しい質問を投稿します。質問の際には、以下の点に注意してください。

    - **明確なタイトル**: 質問の内容を的確に表すタイトルを付けます。
    - **詳細な説明**: 問題の詳細な説明、エラーメッセージ、関連するコードスニペットなどを記述します。
    - **ServiceNow バージョン**: 使用している ServiceNow のバージョンを明記します。
    - **適切なカテゴリ**: 質問に最適なカテゴリを選択します。
    - **コードの書式設定**: コードを投稿する際は、適切な書式設定（例：Markdown のコードブロック）を使用し、可読性を高めます。

    例：

    ````markdown
    # ServiceNow Community Forums 質問投稿例

    ## タイトル

    ビジネスルールの実行順序について

    ## 説明

    ビジネスルールの実行順序が期待通りに動作しません。インシデントレコードが作成された際に、以下の 2 つのビジネスルールが実行されます。

    1.  `BR_Priority`：優先度を`Critical`に設定
    2.  `BR_AssignmentGroup`：アサインメントグループを`Service Desk`に設定

    期待する動作は、`BR_Priority`が先に実行され、`BR_AssignmentGroup`が後に実行されることです。しかし、実際には`BR_AssignmentGroup`が先に実行され、優先度が`Critical`に設定される前にアサインメントグループが設定されてしまいます。

    ## コード

    ```javascript
    // BR_Priority (before insert, update)
    (function executeRule(current, previous /*null when async*/) {
      current.priority = "1"; // Critical
    })(current, previous);

    // BR_AssignmentGroup (before insert, update)
    (function executeRule(current, previous /*null when async*/) {
      current.assignment_group = "Service Desk";
    })(current, previous);
    ```

    ## ServiceNow バージョン

    Paris

    ## カテゴリ

    Platform
    ````

3.  **回答への参加**: 他のユーザーの質問に回答したり、ディスカッションに参加したりします。
4.  **評価**: 役に立つ回答には「いいね」や「正解」を付けます。これにより、他のユーザーが問題を解決する際に役立ちます。
5.  **フォロー**: 興味のあるトピックやユーザーをフォローすることで、最新情報を常に把握することができます。

#### 18.1.5 実践的なテクニック

- **キーワードの選定**: 検索の際には、関連性の高いキーワードを選定します。一般的な単語だけでなく、ServiceNow 固有の用語や略語も試してみましょう。
- **詳細な情報提供**: 質問を投稿する際には、できる限り詳細な情報を提供します。エラーメッセージ、ログ、スクリーンショットなどを添付することで、回答者が問題を特定しやすくなります。
- **丁寧な言葉遣い**: フォーラムは公共の場です。丁寧な言葉遣いを心がけ、他のユーザーを尊重しましょう。
- **解決策の共有**: 問題が解決したら、解決策をフォーラムに共有します。これにより、他のユーザーが同じ問題に遭遇した場合に役立ちます。
- **感謝の気持ち**: 回答してくれたユーザーには、感謝の気持ちを伝えましょう。

#### 18.1.6 応用例とユースケース

- **問題解決**: ServiceNow の特定の問題に関する解決策を探す。
- **ベストプラクティスの学習**: ServiceNow の最適な設定方法や運用方法を学ぶ。
- **新機能の理解**: ServiceNow の新しい機能やアップデートに関する情報を収集する。
- **スクリプトの共有**: ServiceNow のスクリプトやカスタムコンポーネントを共有する。
- **ジョブの機会**: ServiceNow の求人情報を探したり、自分のスキルをアピールしたりする。
- **コミュニティイベント**: ServiceNow のコミュニティイベントやウェビナーに関する情報を得る。

#### 18.1.7 トラブルシューティング

- **質問が回答されない**: 質問の内容が不明確であったり、情報が不足していたりする可能性があります。質問を修正し、より詳細な情報を提供してみましょう。
- **検索結果が多すぎる**: キーワードが一般的すぎる可能性があります。より具体的なキーワードを使用したり、検索条件を絞り込んだりしてみましょう。
- **フォーラムにアクセスできない**: Hi アカウントに問題がある可能性があります。ServiceNow のサポートに問い合わせて、アカウントの状態を確認してください。

#### 18.1.8 まとめと次のステップ

ServiceNow Community Forums は、ServiceNow の活用において非常に重要なリソースです。積極的に活用することで、問題解決、スキル向上、ネットワーク構築が可能になります。次のステップとして、実際にフォーラムにアクセスし、質問を投稿したり、ディスカッションに参加したりしてみましょう。

### 18.2 ServiceNow Developer Program への参加

#### 18.2.1 概要と重要性

ServiceNow Developer Program は、ServiceNow プラットフォームでの開発に関心のある開発者向けのプログラムです。このプログラムに参加することで、最新の API、SDK、ツール、トレーニングリソースにアクセスできるようになり、ServiceNow プラットフォームでの開発スキルを向上させることができます。また、他の開発者との交流や、コミュニティへの貢献を通じて、ServiceNow のエコシステムに貢献することもできます。

#### 18.2.2 特徴と利点

ServiceNow Developer Program には、以下のような特徴と利点があります。

- **無料の開発インスタンス**: ServiceNow の開発インスタンスを無料で利用できます。これにより、本番環境に影響を与えることなく、自由に開発やテストを行うことができます。
- **最新の API と SDK**: 最新の API、SDK、ツール、ドキュメントにアクセスできます。これにより、最新のテクノロジーを活用したアプリケーションを開発することができます。
- **豊富なトレーニングリソース**: オンラインコース、チュートリアル、ドキュメントなど、豊富なトレーニングリソースを利用できます。これにより、ServiceNow プラットフォームでの開発スキルを体系的に学ぶことができます。
- **イベントとウェビナー**: ServiceNow Developer Program が主催するイベントやウェビナーに参加できます。これにより、最新情報を入手したり、他の開発者と交流したりすることができます。
- **コミュニティへの貢献**: ServiceNow Developer Program のコミュニティに貢献することで、評価や報酬を得ることができます。例えば、サンプルコードを共有したり、ドキュメントを改善したり、フォーラムで質問に答えたりすることができます。
- **認定プログラム**: ServiceNow の認定プログラムに参加するための準備ができます。

#### 18.2.3 事前準備と前提条件

ServiceNow Developer Program に参加するには、ServiceNow の Hi アカウントが必要です。Hi アカウントは、ServiceNow の顧客またはパートナーであれば無料で作成できます。

1.  **Hi アカウントの作成**: ServiceNow のサポートポータル（Hi ポータル）にアクセスし、新規アカウントを作成します。
2.  **Developer Program への登録**: Hi アカウントで ServiceNow Developer Program のウェブサイトにアクセスし、登録します。
3.  **開発インスタンスの取得**: Developer Program に登録後、開発インスタンスをリクエストします。開発インスタンスは、数分でプロビジョニングされます。

#### 18.2.4 基本的な使い方

ServiceNow Developer Program の基本的な使い方は以下の通りです。

1.  **開発インスタンスへのログイン**: 開発インスタンスの URL、ユーザー名、パスワードを使用してログインします。
2.  **API と SDK の利用**: ServiceNow の API と SDK を利用して、アプリケーションを開発します。API ドキュメントやサンプルコードを参照しながら、必要な機能を実装します。
3.  **トレーニングリソースの活用**: ServiceNow Developer Program が提供するトレーニングリソースを活用して、開発スキルを向上させます。オンラインコースを受講したり、チュートリアルを試したり、ドキュメントを読んだりします。
4.  **イベントとウェビナーへの参加**: ServiceNow Developer Program が主催するイベントやウェビナーに参加して、最新情報を入手したり、他の開発者と交流したりします。
5.  **コミュニティへの貢献**: ServiceNow Developer Program のコミュニティに貢献することで、評価や報酬を得ることができます。サンプルコードを共有したり、ドキュメントを改善したり、フォーラムで質問に答えたりします。

    例：GlideRecord を使ったスクリプト例

    ```javascript
    // GlideRecordを使ったスクリプト例

    // インシデントテーブルから、優先度が高（1）のレコードを検索
    var gr = new GlideRecord("incident");
    gr.addQuery("priority", "1"); // 優先度が高
    gr.query();

    // 検索結果をログに出力
    while (gr.next()) {
      gs.info(
        "インシデント番号: " + gr.number + ", 概要: " + gr.short_description
      );
    }
    ```

#### 18.2.5 実践的なテクニック

- **API ドキュメントの活用**: ServiceNow の API ドキュメントは、API の使い方やパラメータの説明などが詳しく記載されています。API を利用する際には、必ず API ドキュメントを参照しましょう。
- **サンプルコードの利用**: ServiceNow Developer Program が提供するサンプルコードは、API の具体的な使い方を学ぶための良いリソースです。サンプルコードを参考に、自分のアプリケーションに必要な機能を実装してみましょう。
- **ベストプラクティスの学習**: ServiceNow の開発に関するベストプラクティスを学習することで、高品質なアプリケーションを開発することができます。ServiceNow Developer Program が提供するドキュメントやトレーニングリソースを参照しましょう。
- **テストの実施**: 開発したアプリケーションは、必ずテストを実施しましょう。単体テスト、結合テスト、システムテストなど、様々なテストを実施することで、バグを早期に発見し、修正することができます。
- **コードレビューの実施**: 開発したアプリケーションは、他の開発者にコードレビューしてもらいましょう。コードレビューを通じて、潜在的な問題を発見したり、コードの品質を向上させたりすることができます。

#### 18.2.6 応用例とユースケース

- **カスタムアプリケーションの開発**: ServiceNow プラットフォーム上で、カスタムアプリケーションを開発する。
- **インテグレーションの開発**: ServiceNow と他のシステムを連携させるためのインテグレーションを開発する。
- **ワークフローの自動化**: ServiceNow のワークフローエンジンを利用して、業務プロセスを自動化する。
- **モバイルアプリケーションの開発**: ServiceNow のモバイル SDK を利用して、モバイルアプリケーションを開発する。
- **機械学習の活用**: ServiceNow の機械学習機能を利用して、業務効率を改善する。

#### 18.2.7 トラブルシューティング

- **開発インスタンスにログインできない**: 開発インスタンスの URL、ユーザー名、パスワードが正しいか確認してください。また、開発インスタンスが有効になっているか確認してください。
- **API が動作しない**: API のドキュメントを再度確認し、API のパラメータが正しいか確認してください。また、API の実行に必要な権限があるか確認してください。
- **開発インスタンスが応答しない**: 開発インスタンスのリソースが不足している可能性があります。開発インスタンスのサイズを大きくしたり、不要なアプリケーションをアンインストールしたりしてみてください。

#### 18.2.8 まとめと次のステップ

ServiceNow Developer Program は、ServiceNow プラットフォームでの開発スキルを向上させるための貴重なリソースです。積極的に活用することで、最新の API、SDK、ツール、トレーニングリソースにアクセスできるようになり、ServiceNow のエコシステムに貢献することができます。次のステップとして、ServiceNow Developer Program に登録し、開発インスタンスを取得し、実際にアプリケーションを開発してみましょう。
