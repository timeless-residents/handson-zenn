# 第 6 章：スクリプトインクルード：再利用可能なコードの宝庫

## 6.1 スクリプトインクルードの作成と活用

### 概要と重要性

スクリプトインクルードは、ServiceNow プラットフォームにおいて、再利用可能なコードの部品を定義し、様々な場所から呼び出すことができる強力なメカニズムです。まるで、レゴブロックのように、必要な機能を組み合わせて、効率的にアプリケーションを構築できます。

特に、ビジネスロジックの重複を避け、メンテナンス性を向上させるために不可欠です。一度定義したスクリプトインクルードは、クライアントスクリプト、ビジネスルール、ワークフローなど、様々な場所で利用できるため、開発効率を飛躍的に向上させます。

### 特徴と利点

- **再利用性:** 同じコードを何度も書く必要がありません。
- **保守性:** コードが一箇所に集約されるため、修正や更新が容易です。
- **可読性:** コードが整理され、理解しやすくなります。
- **開発効率:** 共通の処理を迅速に実装できます。
- **テスト容易性:** 機能がモジュール化されるため、テストが容易です。

### 事前準備と前提条件

- ServiceNow インスタンスへのアクセス権（admin 権限が推奨）。
- 基本的な JavaScript の知識。
- ServiceNow のスクリプティングの基礎知識（ビジネスルール、クライアントスクリプトなど）。

### 基本的な使い方

1.  **スクリプトインクルードの作成:**

    - ServiceNow のナビゲータで「System Definition」>「Script Includes」に移動します。
    - 「New」ボタンをクリックして、新しいスクリプトインクルードを作成します。
    - 名前、API 名（クラス名）、説明を入力します。
    - 「Client callable」チェックボックスは、クライアントスクリプトから呼び出す場合にチェックします。
    - スクリプトフィールドに JavaScript コードを記述します。

    **例：シンプルな挨拶を返すスクリプトインクルード**

    ```javascript
    var GreetingUtil = Class.create();
    GreetingUtil.prototype = {
      initialize: function () {},
      getGreeting: function (name) {
        return "Hello, " + name + "!";
      },
      type: "GreetingUtil",
    };
    ```

2.  **クラスとメソッドの定義:**

    - スクリプトインクルードは、JavaScript のクラスとして定義されます。
    - `Class.create()`メソッドを使ってクラスを作成します。
    - `prototype`プロパティに、メソッドを定義します。
    - `initialize`メソッドはコンストラクタとして機能します。
    - `type`プロパティは、スクリプトインクルードの種類を定義します。これは必須ではありませんが、ベストプラクティスとして推奨されます。

3.  **クライアントスクリプト、ビジネスルール、ワークフローからの呼び出し:**

    - スクリプトインクルードは、`new`キーワードを使ってインスタンス化し、メソッドを呼び出します。

    **例：クライアントスクリプトから呼び出す場合**

    ```javascript
    function onClick() {
      var greetingUtil = new GreetingUtil(); // GreetingUtilはAPI名
      var name = g_form.getValue("name"); // 'name'はフィールド名
      var greeting = greetingUtil.getGreeting(name);
      alert(greeting);
    }
    ```

    **例：ビジネスルールから呼び出す場合**

    ```javascript
    (function executeRule(current, previous /*null when async*/) {
      var greetingUtil = new GreetingUtil();
      var name = current.getValue("caller_id.name"); // 'caller_id.name'は参照フィールド
      var greeting = greetingUtil.getGreeting(name);
      gs.info(greeting); // ログに出力
    })(current, previous);
    ```

4.  **名前空間とスコープ:**

    - スクリプトインクルード内で定義された変数や関数は、そのスクリプトインクルードのスコープ内に限定されます。
    - 名前空間の衝突を避けるため、クラス名やメソッド名は一意なものを選択しましょう。

### 実践的なテクニック

- **シングルトンパターン:** スクリプトインクルードのインスタンスを一度だけ作成し、それを再利用することで、パフォーマンスを向上させることができます。
- **パラメータの検証:** メソッドに渡されたパラメータを検証し、エラーを早期に検出することで、予期せぬ問題を回避できます。
- **ロギング:** スクリプトインクルードの動作を追跡するために、ログを適切に出力しましょう。`gs.info()`, `gs.warn()`, `gs.error()` などを活用します。

### 応用例とユースケース

- **承認処理の自動化:** 承認者の決定ロジックをスクリプトインクルードに定義し、ワークフローやビジネスルールから呼び出す。
- **データ変換:** 外部システムから取得したデータを、ServiceNow の形式に変換する処理をスクリプトインクルードに定義する。
- **セキュリティチェック:** ユーザーのロールや権限に基づいて、アクセス制御を行う処理をスクリプトインクルードに定義する。

### トラブルシューティング

- **スクリプトエラー:** スクリプトインクルードのコードにエラーがある場合、ServiceNow のログにエラーメッセージが出力されます。ログを確認し、エラーを修正しましょう。
- **スコープの問題:** クライアントスクリプトからスクリプトインクルードを呼び出す場合、「Client callable」チェックボックスがオンになっていることを確認してください。
- **パフォーマンスの問題:** スクリプトインクルードの処理が遅い場合、コードを見直し、最適化を行いましょう。不要な処理を削除したり、効率的なアルゴリズムを使用したりすることで、パフォーマンスを向上させることができます。

### まとめと次のステップ

スクリプトインクルードは、ServiceNow 開発における重要なツールです。この章で学んだことを活かし、積極的にスクリプトインクルードを活用して、効率的で保守性の高いアプリケーションを開発しましょう。

次のステップとして、ServiceNow の公式ドキュメントやコミュニティフォーラムを参照し、より高度なテクニックやユースケースを学ぶことをお勧めします。

## 6.2 一般的なスクリプトインクルードの実装例

### 概要と重要性

このセクションでは、ServiceNow 開発で頻繁に利用される、一般的なスクリプトインクルードの実装例を紹介します。これらの例は、様々なビジネス要件に対応するための基礎となり、開発の効率化に大きく貢献します。

### 特徴と利点

- **実践的なコード:** すぐに使えるコードスニペットを提供します。
- **汎用性:** 様々なシナリオに適用可能な設計です。
- **学習効果:** コードを読むことで、スクリプトインクルードの理解を深めることができます。

### 事前準備と前提条件

- 6.1 章の内容を理解していること。
- ServiceNow のスクリプトエディタの基本的な操作ができること。

### 基本的な使い方

各実装例を参考に、スクリプトインクルードを作成し、必要な場所に組み込んで利用します。

### 実践的なテクニック

- **例外処理:** 予期せぬエラーが発生した場合に備えて、`try...catch`ブロックを使用して例外処理を実装しましょう。
- **コメント:** コードの意図や処理内容を明確にするために、適切なコメントを記述しましょう。
- **テスト:** 作成したスクリプトインクルードが期待通りに動作するかをテストしましょう。

### 応用例とユースケース

以下に、具体的な実装例とユースケースを紹介します。

1.  **文字列操作:**

    - **機能:** 文字列の分割、結合、置換など、様々な文字列操作を提供します。
    - **コード例:**

    ```javascript
    var StringUtil = Class.create();
    StringUtil.prototype = {
      initialize: function () {},
      splitString: function (str, delimiter) {
        if (!str || !delimiter) {
          return [];
        }
        return str.split(delimiter);
      },
      joinString: function (arr, separator) {
        if (!arr || arr.length === 0) {
          return "";
        }
        return arr.join(separator);
      },
      replaceString: function (str, target, replacement) {
        if (!str || !target || !replacement) {
          return str;
        }
        return str.replace(new RegExp(target, "g"), replacement);
      },
      type: "StringUtil",
    };
    ```

    - **ユースケース:** CSV ファイルの解析、電話番号のフォーマット変換など。

2.  **日付操作:**

    - **機能:** 日付の加算、減算、フォーマット変換など、様々な日付操作を提供します。
    - **コード例:**

    ```javascript
    var DateUtil = Class.create();
    DateUtil.prototype = {
      initialize: function () {},
      addDays: function (date, days) {
        var dt = new GlideDateTime(date);
        dt.addDays(days);
        return dt.getValue();
      },
      formatDate: function (date, format) {
        var dt = new GlideDateTime(date);
        return dt.getDisplayValueInternal(); //インスタンスのタイムゾーンで表示される値
      },
      type: "DateUtil",
    };
    ```

    - **ユースケース:** 締め切り日の計算、イベントのリマインダー設定など。

3.  **数値計算:**

    - **機能:** 数値の計算、四捨五入、パーセント計算など、様々な数値計算を提供します。
    - **コード例:**

    ```javascript
    var NumberUtil = Class.create();
    NumberUtil.prototype = {
      initialize: function () {},
      roundNumber: function (number, decimals) {
        var factor = Math.pow(10, decimals);
        return Math.round(number * factor) / factor;
      },
      calculatePercentage: function (value, total) {
        if (total === 0) {
          return 0;
        }
        return (value / total) * 100;
      },
      type: "NumberUtil",
    };
    ```

    - **ユースケース:** 割引額の計算、KPI の算出など。

4.  **外部 API 呼び出し:**

    - **機能:** 外部 API を呼び出し、データを取得または送信します。
    - **コード例:**

    ```javascript
    var APIUtil = Class.create();
    APIUtil.prototype = {
      initialize: function () {},
      callAPI: function (url, method, payload) {
        try {
          var request = new sn_ws.RESTMessageV2();
          request.setHttpMethod(method);
          request.setEndpoint(url);
          if (payload) {
            request.setRequestBody(JSON.stringify(payload));
            request.setRequestHeader("Content-Type", "application/json");
          }
          var response = request.execute();
          var responseBody = response.getBody();
          var httpStatus = response.getStatusCode();

          if (httpStatus >= 200 && httpStatus < 300) {
            return JSON.parse(responseBody);
          } else {
            gs.error(
              "API call failed with status code: " +
                httpStatus +
                " - " +
                responseBody
            );
            return null;
          }
        } catch (ex) {
          var message = ex.getMessage();
          gs.error("Exception in APIUtil.callAPI: " + message);
          return null;
        }
      },
      type: "APIUtil",
    };
    ```

    - **ユースケース:** 天気情報の取得、株価情報の取得など。
    - **注意:** API キーや認証情報を安全に管理する必要があります。MID Server の設定も必要となる場合があります。

5.  **データ変換:**

    - **機能:** 異なる形式のデータを変換します。
    - **コード例:**

    ```javascript
    var DataConverter = Class.create();
    DataConverter.prototype = {
      initialize: function () {},
      convertJSONtoXML: function (json) {
        // JSON to XML 変換ロジック (例: XMLDocument を使用)
        // 簡易的な例として、JSON.stringify を使用
        return "<xml>" + JSON.stringify(json) + "</xml>";
      },
      type: "DataConverter",
    };
    ```

    - **ユースケース:** XML 形式のデータを JSON 形式に変換、またはその逆。

6.  **ロギング:**

    - **機能:** アプリケーションの動作を記録します。
    - **コード例:**

    ```javascript
    var LogUtil = Class.create();
    LogUtil.prototype = {
      initialize: function () {},
      logInfo: function (message) {
        gs.info(message);
      },
      logError: function (message) {
        gs.error(message);
      },
      type: "LogUtil",
    };
    ```

    - **ユースケース:** デバッグ、監査証跡の記録。

7.  **顧客情報検索:**

    - **機能:** 顧客情報を検索し、詳細情報を返します。
    - **コード例:**

    ```javascript
    var CustomerUtil = Class.create();
    CustomerUtil.prototype = {
      initialize: function () {},
      getCustomerInfo: function (customerId) {
        var gr = new GlideRecord("customer_table"); // customer_table は顧客テーブル名
        if (gr.get(customerId)) {
          return {
            name: gr.getValue("name"),
            email: gr.getValue("email"),
            phone: gr.getValue("phone"),
          };
        } else {
          return null;
        }
      },
      type: "CustomerUtil",
    };
    ```

    - **ユースケース:** 顧客情報表示、顧客サポート。

8.  **インシデント優先度計算:**

    - **機能:** インシデントの重要度、緊急度に基づいて、優先度を計算します。
    - **コード例:**

    ```javascript
    var IncidentPriorityUtil = Class.create();
    IncidentPriorityUtil.prototype = {
      initialize: function () {},
      calculatePriority: function (impact, urgency) {
        //重要度と緊急度から優先度を計算するロジック
        var priority = 4; // デフォルト値
        if (impact == 1 && urgency == 1) {
          priority = 1;
        } else if (impact <= 2 && urgency <= 2) {
          priority = 2;
        } else if (impact <= 3 && urgency <= 3) {
          priority = 3;
        }
        return priority;
      },
      type: "IncidentPriorityUtil",
    };
    ```

    - **ユースケース:** インシデント管理、SLA 管理。

### トラブルシューティング

- **API 呼び出しのエラー:** 外部 API のレスポンスを注意深く確認し、エラーの原因を特定しましょう。
- **データ変換のエラー:** データの形式が想定通りでない場合、エラーが発生することがあります。データの形式を確認し、適切な変換処理を実装しましょう。
- **ロギングの不足:** ログが不足していると、問題の特定が困難になることがあります。適切な場所にログを追加し、詳細な情報を記録しましょう。

このセクションでは、ServiceNow 開発で頻繁に利用される、一般的なスクリプトインクルードの実装例を紹介しました。これらの例を参考に、様々なビジネス要件に対応するスクリプトインクルードを作成し、開発の効率化に役立ててください。

次のステップとして、これらの例を基に、より複雑なロジックを実装したり、独自のスクリプトインクルードを作成したりすることに挑戦してみましょう。

## 6.3 高度なスクリプトインクルード：Ajax、非同期処理、イベントキュー

### 概要と重要性

このセクションでは、スクリプトインクルードの高度な活用方法として、Ajax による非同期処理、イベントキュー、System Scheduler による定期実行について解説します。これらの技術を活用することで、より洗練された、レスポンスの良いアプリケーションを開発できます。

### 特徴と利点

- **非同期処理:** ユーザーインターフェースの応答性を向上させます。
- **イベントキュー:** 処理の実行を遅延させ、システムの負荷を軽減します。
- **定期実行:** 定期的なタスクを自動化します。

### 事前準備と前提条件

- 6.1 章、6.2 章の内容を理解していること。
- ServiceNow の Ajax、イベントキュー、System Scheduler に関する知識。

### 基本的な使い方

各技術を理解し、スクリプトインクルードに組み込んで利用します。

### 実践的なテクニック

- **エラーハンドリング:** 非同期処理では、エラーが発生した場合の処理を適切に実装する必要があります。
- **パフォーマンス:** 非同期処理や定期実行は、システムの負荷に影響を与える可能性があります。パフォーマンスを考慮した設計を行いましょう。
- **セキュリティ:** Ajax 通信では、セキュリティに注意が必要です。クロスサイトスクリプティング（XSS）などの脆弱性対策を行いましょう。

### 応用例とユースケース

以下に、具体的な応用例とユースケースを紹介します。

1.  **GlideAjax によるクライアントスクリプトからの非同期呼び出し:**

    - **機能:** クライアントスクリプトからスクリプトインクルードを非同期で呼び出し、サーバー側の処理を実行します。
    - **コード例:**

      **スクリプトインクルード (Server-side):**

      ```javascript
      var MyAjax = Class.create();
      MyAjax.prototype = Object.extendsObject(AbstractAjaxProcessor, {
        getData: function () {
          var searchTerm = this.getParameter("sysparm_search_term");
          var results = [];
          var gr = new GlideRecord("incident");
          gr.addEncodedQuery("short_descriptionLIKE" + searchTerm);
          gr.setLimit(5);
          gr.query();
          while (gr.next()) {
            results.push({
              number: gr.getValue("number"),
              short_description: gr.getValue("short_description"),
            });
          }
          return JSON.stringify(results);
        },
        type: "MyAjax",
      });
      ```

      **クライアントスクリプト (Client-side):**

      ```javascript
      function searchIncidents() {
        var searchTerm = g_form.getValue("search_term"); // 'search_term' は入力フィールド名
        var ga = new GlideAjax("MyAjax"); // スクリプトインクルードのAPI名
        ga.addParam("sysparm_name", "getData"); // 呼び出すメソッド名
        ga.addParam("sysparm_search_term", searchTerm);
        ga.getXMLAnswer(processResponse); // レスポンスを処理する関数
      }

      function processResponse(response) {
        var results = JSON.parse(response);
        var output = "";
        for (var i = 0; i < results.length; i++) {
          output +=
            results[i].number + ": " + results[i].short_description + "\n";
        }
        alert(output);
      }
      ```

    - **ユースケース:** リアルタイムでのデータ検索、複雑な計算処理の実行。
    - **注意:** `g_form`オブジェクトはクライアントスクリプトでのみ利用可能です。

2.  **イベントキューによる非同期処理:**

    - **機能:** イベントキューにイベントを追加し、後で処理を実行します。
    - **コード例:**

      **イベントキューへのイベント追加:**

      ```javascript
      gs.eventQueue(
        "my.custom.event",
        current,
        gs.getUserID(),
        gs.getUserName()
      );
      ```

      **イベント処理スクリプトアクション:**

      ```javascript
      (function () {
        var event = new GlideRecord("sysevent");
        event.get(event_id);

        // イベントデータに基づいて処理を実行
        gs.info("Event " + event.name + " triggered for record " + event.parm1);
      })();
      ```

    - **ユースケース:** メール送信、通知送信、ログ記録など、時間のかかる処理の遅延実行。
    - **注意:** イベントキューは、システムの負荷を軽減する効果がありますが、イベントの処理が遅延する可能性があることに注意が必要です。

3.  **System Scheduler による定期実行:**

    - **機能:** 定期的なタスクを自動的に実行します。
    - **設定例:**

      - ServiceNow のナビゲータで「System Definition」>「Scheduled Jobs」に移動します。
      - 「New」ボタンをクリックして、新しい Scheduled Job を作成します。
      - 名前、説明、実行頻度、実行スクリプトを入力します。

    - **コード例:**

      ```javascript
      (function () {
        // 定期的に実行する処理
        gs.info("Scheduled job executed!");
      })();
      ```

    - **ユースケース:** データのエクスポート、バックアップ、定期的なレポート生成など。
    - **注意:** System Scheduler は、システムの負荷に影響を与える可能性があります。実行頻度や処理内容を適切に設定しましょう。

### トラブルシューティング

- **GlideAjax のエラー:** クライアントスクリプトとスクリプトインクルードの間の通信がうまくいかない場合、エラーが発生することがあります。コンソールログやサーバーログを確認し、エラーの原因を特定しましょう。
- **イベントキューのエラー:** イベントキューにイベントが追加されない、または処理されない場合、イベント名やパラメータが正しいかを確認しましょう。
- **System Scheduler のエラー:** Scheduled Job が実行されない場合、設定が正しいか、スクリプトにエラーがないかを確認しましょう。

次のステップとして、これらの技術を組み合わせたり、より複雑なロジックを実装したりすることに挑戦してみましょう。また、ServiceNow のパフォーマンス最適化に関するドキュメントを参照し、アプリケーションのパフォーマンスを向上させるための知識を深めることをお勧めします。
