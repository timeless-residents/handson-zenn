## 第2章：GNU COBOL徹底入門 - オープンソースCOBOLの活用

### 2.1 GNU COBOLのインストールと開発環境構築

**1. 概要と重要性**

GNU COBOLは、COBOL言語のオープンソース実装であり、レガシーシステムのモダナイゼーションや新規アプリケーション開発に活用できます。 このセクションでは、主要なOSにおけるGNU COBOLのインストール手順と、効率的な開発環境の構築方法を解説します。 環境構築は開発効率に直結するため、丁寧に設定を行いましょう。

**2. 基本的な使い方**

**Linux (Ubuntu/Debian)**

```bash
sudo apt update
sudo apt install open-cobol
```

**macOS (Homebrew)**

```bash
brew install gnu-cobol
```

**Windows (MinGW/MSYS2)**

1. MinGW/MSYS2をインストールします。 (https://www.msys2.org/ で入手できます)
2. MSYS2コンソールを開き、以下のコマンドを実行します。

```bash
pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-gmp mingw-w64-x86_64-open-cobol
```

**統合開発環境（IDE）の選定と設定**

* **Visual Studio Code:** 軽量で拡張性が高く、多くのプログラミング言語をサポートしています。
    *  拡張機能: `bitlang.cobol` (シンタックスハイライト、コード補完)
    *  `settings.json` の設定例:

        ```json
        {
            "files.associations": {
                "*.cbl": "cobol"
            },
            "editor.insertSpaces": true,
            "editor.tabSize": 4,
            "editor.detectIndentation": false
        }
        ```

* **Eclipse:** 高機能なIDEで、COBOL開発にも利用できます。
    * 必要なプラグイン: COBOL Development Tools
    * 設定: COBOLコンパイラへのパスを設定します。

**3. 実践的なテクニック**

*   インストール後に、`cobc --version` コマンドを実行して、GNU COBOLが正しくインストールされていることを確認します。
*   環境変数の設定: `COB_CONFIG_DIR` や `COB_LIBRARY_PATH` などを設定することで、コンパイルオプションやライブラリの検索パスをカスタマイズできます。
*   `.cobolrc` ファイル: GNU COBOL の設定ファイルを作成し、コンパイルオプションのデフォルト値を設定できます。

**4. 応用例とユースケース**

*   レガシーCOBOLシステムの移植: 古いCOBOLシステムを、最新の環境で動作させるためにGNU COBOLを利用します。
*   バッチ処理の開発: 大量のデータを処理するバッチ処理を、COBOLで効率的に開発します。

**5. トラブルシューティング**

*   コンパイルエラー: インストールパスや環境変数が正しく設定されているか確認してください。
*   リンクエラー: 必要なライブラリがインストールされているか確認してください。

**6. まとめと次のステップ**

このセクションでは、GNU COBOLのインストールと開発環境の構築について学びました。 次のセクションでは、COBOL言語の基本文法と拡張機能について解説します。

### 2.2 COBOL言語の基本文法と拡張機能

**1. 概要と重要性**

COBOLは、ビジネスアプリケーション開発に特化した言語です。 このセクションでは、COBOLの基本的な文法と、GNU COBOLの拡張機能について解説します。 モダンなコーディングスタイルを意識することで、可読性と保守性の高いコードを作成できます。

**2. 基本的な使い方**

COBOLプログラムは、以下の4つの部で構成されます。

*   **IDENTIFICATION DIVISION:** プログラム名、作成者などの情報を記述します。
*   **ENVIRONMENT DIVISION:** ハードウェア環境やファイル情報を記述します。
*   **DATA DIVISION:** プログラムで使用する変数を定義します。
*   **PROCEDURE DIVISION:** 処理ロジックを記述します。

**データ型:**

*   `PIC X(n)`: 文字型 (nは文字数)
*   `PIC 9(n)`: 数値型 (nは桁数)
*   `PIC S9(n)V9(m)`: 符号付き数値型 (nは整数部、mは小数部の桁数)

**制御構造:**

*   `IF ... THEN ... ELSE ... END-IF`
*   `PERFORM ... UNTIL ... END-PERFORM`
*   `EVALUATE ... WHEN ... OTHER ... END-EVALUATE`

**ファイル入出力:**

```cobol
SELECT ファイル名 ASSIGN TO "ファイルパス".
FD  ファイル名.
01  レコード名.
    05  フィールド名  PIC X(n).

OPEN INPUT ファイル名.
READ ファイル名 INTO レコード名.
CLOSE ファイル名.
```

**サブルーチン:**

```cobol
CALL "サブルーチン名" USING 引数1, 引数2.
```

**GNU COBOLの拡張機能:**

*   **オブジェクト指向COBOL:** クラス、オブジェクト、メソッドなどをサポートします。
*   **動的メモリ割り当て:** `ALLOCATE` と `FREE` ステートメントを使用して、実行時にメモリを割り当て/解放できます。

**3. 実践的なテクニック**

*   **COBOL 85標準:** できる限り標準に準拠したコードを作成することで、他のCOBOLコンパイラとの互換性を高めることができます。
*   **可読性の向上:** 意味のある変数名を使用し、適切なインデントを行うことで、コードの可読性を高めることができます。
*   **コメントの活用:** コードの意図や処理内容をコメントで説明することで、保守性を高めることができます。

**4. 応用例とユースケース**

*   **簡単な計算プログラム:**

    ```cobol
    IDENTIFICATION DIVISION.
    PROGRAM-ID. CALCULATOR.
    DATA DIVISION.
    WORKING-STORAGE SECTION.
    01  NUM1  PIC 9(5) VALUE 100.
    01  NUM2  PIC 9(5) VALUE 200.
    01  RESULT PIC 9(5).
    PROCEDURE DIVISION.
        ADD NUM1 TO NUM2 GIVING RESULT.
        DISPLAY "RESULT: " RESULT.
        STOP RUN.
    ```

*   **ファイル操作プログラム:**

    ```cobol
    IDENTIFICATION DIVISION.
    PROGRAM-ID. FILE-READER.
    ENVIRONMENT DIVISION.
    INPUT-OUTPUT SECTION.
    FILE-CONTROL.
        SELECT INPUT-FILE ASSIGN TO "input.txt"
               ORGANIZATION IS LINE SEQUENTIAL.
    DATA DIVISION.
    FILE SECTION.
    FD  INPUT-FILE.
    01  INPUT-RECORD PIC X(80).
    WORKING-STORAGE SECTION.
    01  EOF-FLAG PIC X(1) VALUE "N".
    PROCEDURE DIVISION.
        OPEN INPUT INPUT-FILE.
        PERFORM UNTIL EOF-FLAG = "Y"
            READ INPUT-FILE INTO INPUT-RECORD
                AT END MOVE "Y" TO EOF-FLAG
                NOT AT END DISPLAY INPUT-RECORD
            END-READ
        END-PERFORM.
        CLOSE INPUT-FILE.
        STOP RUN.
    ```

**5. トラブルシューティング**

*   コンパイルエラー: 文法エラーがないか確認してください。 スペルミスや、キーワードの記述ミスに注意が必要です。
*   実行時エラー: 変数の初期化、ファイルパスなどが正しく設定されているか確認してください。

### 2.3 COBOLアプリケーションのコンパイル、実行、デバッグ

**1. 概要と重要性**

COBOLアプリケーションを開発する上で、コンパイル、実行、デバッグは不可欠なプロセスです。 このセクションでは、GNU COBOLを用いたこれらの手順を詳細に解説します。 デバッグスキルを習得することで、効率的に問題解決を行うことができます。

**2. 基本的な使い方**

**コンパイル:**

```bash
cobc -x プログラム名.cbl
```

`-x` オプションは、実行可能ファイルを作成することを意味します。

**実行:**

```bash
./プログラム名
```

**デバッグ (GDB):**

1.  コンパイル時にデバッグ情報を付加します。

    ```bash
    cobc -g -x プログラム名.cbl
    ```

2.  GDBを起動します。

    ```bash
    gdb プログラム名
    ```

3.  ブレークポイントを設定します。

    ```gdb
    break 10  # 10行目にブレークポイントを設定
    ```

4.  プログラムを実行します。

    ```gdb
    run
    ```

5.  変数の値を表示します。

    ```gdb
    print 変数名
    ```

6.  ステップ実行します。

    ```gdb
    next
    ```

**ユニットテスト (COBOLUnit):**

COBOLUnit は、COBOL のユニットテストフレームワークです。

1. COBOLUnitをダウンロードし、インストールします。
2. テスト対象のCOBOLプログラムを作成します。
3. テストプログラムを作成します。
4. テストを実行します。

**3. 実践的なテクニック**

*   **Makefileの作成:** 複数のCOBOLプログラムをコンパイルする場合、Makefileを作成することで、コンパイル作業を自動化できます。
*   **デバッグオプションの活用:** `-debug` オプションを使用することで、実行時に詳細なデバッグ情報を出力できます。
*   **ロギングの導入:** プログラムの実行中に、ログファイルに情報を出力することで、問題発生時の原因究明を容易にすることができます。

**4. 応用例とユースケース**

*   **デバッグが必要なサンプルプログラム:**

    ```cobol
    IDENTIFICATION DIVISION.
    PROGRAM-ID. DEBUG-EXAMPLE.
    DATA DIVISION.
    WORKING-STORAGE SECTION.
    01  NUM1  PIC 9(5) VALUE 10.
    01  NUM2  PIC 9(5) VALUE 0.
    01  RESULT PIC 9(5).
    PROCEDURE DIVISION.
        IF NUM2 = 0 THEN
            DISPLAY "Error: Division by zero."
        ELSE
            DIVIDE NUM1 BY NUM2 GIVING RESULT
            DISPLAY "Result: " RESULT
        END-IF.
        STOP RUN.
    ```

    このプログラムは、0で除算する可能性があるため、デバッグが必要です。

**5. トラブルシューティング**

*   コンパイルエラー: コンパイラが出力するエラーメッセージをよく確認し、原因を特定してください。
*   実行時エラー: GDBを使用して、プログラムの実行状況を追跡し、エラーが発生した箇所を特定してください。
*   GDBの操作: GDBのコマンドを理解し、使いこなすことが重要です。

### 2.4 オープンソースライブラリとの連携

**1. 概要と重要性**

COBOLアプリケーションを現代的なシステムに統合するためには、オープンソースライブラリとの連携が不可欠です。 このセクションでは、JSON、XML、データベース、メッセージキューなどのライブラリとの連携方法を解説します。

**2. 基本的な使い方**

**JSON処理:**

GNU COBOLでJSONを処理するには、`libjansson`などのCライブラリをCOBOLから呼び出す必要があります。

1.  `libjansson` をインストールします。
2.  COBOLプログラムから、`CALL` ステートメントを使用して、`libjansson` の関数を呼び出します。

**XML処理:**

同様に、`libxml2` などのCライブラリをCOBOLから呼び出すことで、XMLを処理できます。

**データベースアクセス (MySQL, PostgreSQLなど):**

`libmysqlclient` や `libpq` などのCライブラリをCOBOLから呼び出すことで、データベースにアクセスできます。

**メッセージキュー (RabbitMQなど):**

`librabbitmq` などのCライブラリをCOBOLから呼び出すことで、メッセージキューと連携できます。

**3. 実践的なテクニック**

*   **C言語とのインターフェース:** COBOLからC言語の関数を呼び出すためには、`CALL` ステートメントを使用します。 引数の型や渡し方に注意が必要です。
*   **ライブラリのリンク:** コンパイル時に、必要なライブラリをリンクする必要があります。 `-l` オプションを使用します。
*   **エラー処理:** Cライブラリの関数呼び出し後には、エラーコードを確認し、適切にエラー処理を行う必要があります。

**4. 応用例とユースケース**

*   **JSON形式のデータを読み書きするプログラム:**

    ```cobol
    IDENTIFICATION DIVISION.
    PROGRAM-ID. JSON-EXAMPLE.
    DATA DIVISION.
    WORKING-STORAGE SECTION.
    01  JSON-STRING PIC X(200) VALUE '{"name": "John", "age": 30}'.
    01  NAME PIC X(20).
    01  AGE PIC 9(2).
    PROCEDURE DIVISION.
        DISPLAY "JSON String: " JSON-STRING.
        * ここにJSON解析のC言語関数呼び出しのコードが入ります
        * 例: CALL "parse_json" USING JSON-STRING, NAME, AGE.
        DISPLAY "Name: " NAME.
        DISPLAY "Age: " AGE.
        STOP RUN.
    ```

    このプログラムは、JSON形式の文字列を解析し、名前と年齢を表示します。 (C言語関数`parse_json`の実装は省略)

*   **データベースからデータを取得するプログラム:**

    ```cobol
    IDENTIFICATION DIVISION.
    PROGRAM-ID. DB-EXAMPLE.
    DATA DIVISION.
    WORKING-STORAGE SECTION.
    01  DB-HOST PIC X(20) VALUE "localhost".
    01  DB-USER PIC X(20) VALUE "user".
    01  DB-PASS PIC X(20) VALUE "password".
    01  DB-NAME PIC X(20) VALUE "database".
    01  SQL-QUERY PIC X(100) VALUE "SELECT * FROM users".
    01  RESULT-DATA PIC X(200).
    PROCEDURE DIVISION.
        * ここにデータベース接続とクエリ実行のC言語関数呼び出しのコードが入ります
        * 例: CALL "execute_query" USING DB-HOST, DB-USER, DB-PASS, DB-NAME, SQL-QUERY, RESULT-DATA.
        DISPLAY "Result Data: " RESULT-DATA.
        STOP RUN.
    ```

    このプログラムは、データベースに接続し、SQLクエリを実行して、結果を表示します。 (C言語関数`execute_query`の実装は省略)

**5. トラブルシューティング**

*   ライブラリが見つからない: ライブラリが正しくインストールされているか、リンクオプションが正しく設定されているか確認してください。
*   C言語関数呼び出しエラー: 引数の型や渡し方が正しいか確認してください。
