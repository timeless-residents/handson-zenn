# 第2章：HammerspoonとAppleScript連携の実践レシピ：基本編

この章では、HammerspoonとAppleScriptを連携させることで、Macの操作をどのように効率化できるのかを、具体的なレシピを通して解説します。キーバインドの拡張からウィンドウ操作、アプリケーション操作、クリップボード操作まで、日常業務で役立つ実践的なテクニックを習得しましょう。

## 2.1 キーバインド拡張：HammerspoonからAppleScriptを呼び出す

### 概要と重要性

Hammerspoonの強力なキーバインド機能とAppleScriptの自動化能力を組み合わせることで、キーボード操作だけで複雑なタスクを実行できるようになります。このセクションでは、HammerspoonからAppleScriptを実行するための基本的な設定と、その応用例を紹介します。

### 基本的な使い方

1. **キーバインドの設定とLua関数との連携**

Hammerspoonでは、`hs.hotkey.bind()` 関数を使ってキーバインドを定義します。この関数には、キーの組み合わせ、修飾キー、そしてキーが押されたときに実行するLua関数を指定します。

   ```lua
   -- 例：control + shift + A を押したときに my_applescript_function を実行
   hs.hotkey.bind({"ctrl", "shift"}, "a", function()
       my_applescript_function()
   end)
   ```

2. **AppleScriptを実行するLua関数の実装**

   `hs.osascript.applescript()` 関数を使うと、LuaからAppleScriptのコードを実行できます。この関数は、AppleScriptのコード文字列を引数として受け取り、実行結果を返します。

   ```lua
   local function my_applescript_function()
       local script = [[
           tell application "Finder"
               activate
               display alert "Hello from AppleScript!"
           end tell
       ]]
       local result = hs.osascript.applescript(script)
       if result.status == 0 then
           -- 成功した場合
           print("AppleScript executed successfully")
       else
           -- 失敗した場合
           print("AppleScript execution failed:", result.output)
       end
   end
   ```

### 実践的なテクニック

1. **実践例：特定のアプリのウィンドウを操作するショートカット**

   例えば、Google Chromeのウィンドウを最大化するショートカットを作成してみましょう。

    ```lua
    local function maximize_chrome_window()
      local script = [[
          tell application "Google Chrome"
              activate
              tell window 1
                  set bounds to {0, 0, (the screen's visible bounds's item 3), (the screen's visible bounds's item 4)}
              end tell
          end tell
      ]]
      hs.osascript.applescript(script)
    end

    hs.hotkey.bind({"ctrl", "shift"}, "c", maximize_chrome_window)
    ```
   この例では、`control + shift + c` を押すと、Google Chromeの最前面のウィンドウが最大化されます。

2. **実践例：クリップボードの内容を加工してペーストするショートカット**

   クリップボードの内容をHTMLエンコードしてペーストする例です。

    ```lua
    local function html_encode_and_paste()
        local text = hs.pasteboard.getContents()
        if text then
          local encodedText = text:gsub("&", "&amp;")
            :gsub("<", "&lt;")
            :gsub(">", "&gt;")
            :gsub('"', "&quot;")
          hs.pasteboard.setContents(encodedText)
          hs.eventtap.keyStroke("v", {"cmd"})
        end
    end

    hs.hotkey.bind({"ctrl", "shift"}, "v", html_encode_and_paste)
    ```
    この例では、`control + shift + v` を押すと、クリップボードの内容がHTMLエンコードされてペーストされます。

3. **パラメータの渡し方：HammerspoonからAppleScriptへの値渡し**

   `hs.osascript.applescript()` 関数に変数を含める場合は、Luaの文字列結合機能を使って値をAppleScriptに渡します。

    ```lua
     local function display_message(message)
         local script = [[
           tell application "Finder"
             display alert "]] .. message .. [["
           end tell
         ]]
         hs.osascript.applescript(script)
     end

    hs.hotkey.bind({"ctrl", "shift"}, "m", function()
        display_message("This is a message passed from Hammerspoon!")
    end)
    ```
    この例では、`control + shift + m` を押すと、Hammerspoonから渡されたメッセージがアラートとして表示されます。

### 応用例とユースケース

*   特定のテキストエディタで選択したテキストを、マークダウン形式に変換する
*   特定のWebサイトを開いて、特定の操作を自動化する
*   特定のフォルダを開いて、特定のファイルを選択する

### トラブルシューティング

*   AppleScriptのエラーは、`hs.osascript.applescript()` の戻り値の `output` フィールドに格納されています。エラーが発生した場合は、このフィールドを確認して原因を特定しましょう。
*   AppleScriptの構文エラーは、実行時にエラーとなります。AppleScript Editorで事前に動作確認をすることをおすすめします。
*   権限の問題でAppleScriptが実行できない場合は、Hammerspoonに「アクセシビリティ」権限を付与する必要があります。

## 2.2 ウィンドウ操作：複雑なウィンドウ配置を自動化する

### 概要と重要性

ウィンドウ操作は、日々の作業効率を大きく左右します。HammerspoonとAppleScriptを組み合わせることで、ウィンドウの位置、サイズ、配置を自動化し、作業効率を大幅に向上させることができます。

### 基本的な使い方

1. **ウィンドウの位置、サイズ、最大化/最小化の制御**

   AppleScriptを使って、特定のアプリケーションのウィンドウを操作する基本的なコードは以下の通りです。

   ```applescript
   tell application "Google Chrome"
      activate
      tell window 1
        set position to {100, 100}
        set size to {800, 600}
        -- 最大化
        set bounds to {0, 0, (the screen's visible bounds's item 3), (the screen's visible bounds's item 4)}
        --最小化
        --set miniaturized to true
      end tell
   end tell
   ```
   このコードをHammerspoonから実行するには、以下のようにします。

   ```lua
    local function set_chrome_window_position_and_size()
      local script = [[
           tell application "Google Chrome"
              activate
              tell window 1
                set position to {100, 100}
                set size to {800, 600}
              end tell
           end tell
       ]]
       hs.osascript.applescript(script)
   end

   hs.hotkey.bind({"ctrl", "shift"}, "p", set_chrome_window_position_and_size)
   ```
   `control + shift + p` を押すと、Google Chromeの最前面のウィンドウが、指定された位置とサイズに変更されます。

2. **複数のウィンドウを整列させるスクリプト**

   複数のアプリケーションのウィンドウを整列させる例です。

    ```applescript
    set appList to {"Google Chrome", "Finder", "iTerm2"}

    repeat with appName in appList
        tell application appName
            activate
            tell window 1
                if appName is "Google Chrome" then
                    set position to {0, 0}
                    set size to {800, 800}
                 else if appName is "Finder" then
                    set position to {800, 0}
                    set size to {600, 800}
                 else if appName is "iTerm2" then
                     set position to {0, 800}
                    set size to {800, 400}
                end if
            end tell
       end tell
    end repeat
    ```
    このAppleScriptをHammerspoonから実行することで、複数のアプリケーションのウィンドウを自動的に整列させることができます。

### 実践的なテクニック

1. **スクリーン分割を考慮したウィンドウ配置**

   画面を分割して、それぞれのウィンドウを特定の場所に配置するスクリプトです。画面のサイズを考慮してウィンドウを配置することで、作業効率を向上させます。

   ```lua
   local function arrange_windows()
      local screen = hs.screen.mainScreen()
      local screenFrame = screen:frame()
      local screenWidth = screenFrame.w
      local screenHeight = screenFrame.h

      local script = [[
           tell application "Google Chrome"
                activate
                tell window 1
                    set position to {0, 0}
                    set size to {]] .. screenWidth/2 .. [[, ]] .. screenHeight .. [[}
                end tell
            end tell
            tell application "Finder"
                activate
                tell window 1
                    set position to {]] .. screenWidth/2 .. [[, 0}
                    set size to {]] .. screenWidth/2 .. [[, ]] .. screenHeight .. [[}
                end tell
            end tell
       ]]
       hs.osascript.applescript(script)
   end

    hs.hotkey.bind({"ctrl", "shift"}, "r", arrange_windows)
   ```

2. **仮想デスクトップ間のウィンドウ移動**

   AppleScriptとHammerspoonを組み合わせて、特定のウィンドウを別の仮想デスクトップに移動させることは、直接的には難しいです。しかし、Hammerspoonの機能を使うことで、ウィンドウを他のデスクトップに移動させ、そのデスクトップにフォーカスを移動させることは可能です。
  
    ```lua
    local function move_window_to_desktop(desktopNumber)
        local focusedWindow = hs.window.focusedWindow()
        local currentDesktop = hs.desktop.currentDesktop()

      if not focusedWindow then return end

      if desktopNumber < 1 or desktopNumber > hs.desktop.count() then return end


        focusedWindow:moveToScreen(hs.screen.find(hs.desktop.screen(hs.desktop.at(desktopNumber)) ))

        hs.desktop.at(desktopNumber):focus()
      end

    hs.hotkey.bind({"ctrl","shift"}, "1", function() move_window_to_desktop(1) end)
    hs.hotkey.bind({"ctrl","shift"}, "2", function() move_window_to_desktop(2) end)
    hs.hotkey.bind({"ctrl","shift"}, "3", function() move_window_to_desktop(3) end)

    ```

### 応用例とユースケース

*   IDEとブラウザを並べて表示する
*   複数のテキストエディタのウィンドウを整列させる
*   特定のアプリを特定のディスプレイに移動させる

### トラブルシューティング

*   ウィンドウ操作がうまくいかない場合は、アプリケーションのプロセス名やウィンドウのタイトルが正しいかを確認しましょう。
*   ウィンドウの位置やサイズは、ディスプレイの解像度によって変わるため、環境に合わせて調整する必要があります。
*  仮想デスクトップの移動については、Hammerspoonの機能に依存するため、OSのバージョンによって挙動が異なる場合があります。

## 2.3 アプリケーション操作：繰り返し作業を効率化する

### 概要と重要性

アプリケーション操作の自動化は、繰り返しの多い作業を効率化する上で非常に重要です。このセクションでは、アプリケーションの起動と終了、メニュー操作、テキスト入力、ボタンクリックの自動化について解説します。

### 基本的な使い方

1. **アプリケーションの起動と終了**

   AppleScriptを使って、アプリケーションを起動または終了させる基本的なコードは以下の通りです。

   ```applescript
   -- アプリケーションを起動
   tell application "Google Chrome"
       activate
   end tell

   -- アプリケーションを終了
   tell application "Google Chrome"
       quit
   end tell
   ```

   これらのスクリプトをHammerspoonから実行するには、以下のようにします。

   ```lua
   local function launch_chrome()
       local script = [[
           tell application "Google Chrome"
               activate
           end tell
       ]]
       hs.osascript.applescript(script)
   end

   local function quit_chrome()
        local script = [[
           tell application "Google Chrome"
               quit
           end tell
       ]]
       hs.osascript.applescript(script)
   end
   hs.hotkey.bind({"ctrl", "shift"}, "l", launch_chrome)
   hs.hotkey.bind({"ctrl", "shift"}, "q", quit_chrome)
   ```
   `control + shift + l` でGoogle Chromeを起動、`control + shift + q` で終了させることができます。

2. **メニュー操作の自動化**

   AppleScriptを使って、アプリケーションのメニュー項目を操作することも可能です。例えば、Google Chromeで「履歴」メニューを開くスクリプトは以下のようになります。

   ```applescript
   tell application "Google Chrome"
        activate
       tell application "System Events"
            tell process "Google Chrome"
              click menu item "履歴" of menu 1 of menu bar 1
            end tell
        end tell
   end tell
   ```
    このAppleScriptをHammerspoonから実行することで、特定のアプリケーションのメニュー操作を自動化することができます。

### 実践的なテクニック

1. **テキスト入力とボタンクリックの自動化**

    アプリケーションのテキストフィールドにテキストを入力し、ボタンをクリックする自動化も可能です。
    ```applescript
        tell application "Safari"
            activate
           tell application "System Events"
               tell process "Safari"
                   --テキストフィールドにテキストを入力
                   set value of text field 1 of window 1 to "example.com"

                   --ボタンをクリック
                   click button "移動" of window 1
               end tell
           end tell
        end tell
    ```
   このスクリプトをHammerspoonから実行することで、指定のアプリケーションでテキスト入力とボタンクリックを自動化できます。

2. **特定のアプリを対象にした作業の自動化**

   特定のアプリに対して、複数の操作を組み合わせることで、より複雑な作業を自動化できます。

   ```lua
    local function open_new_mail()
      local script = [[
         tell application "Mail"
            activate
            tell application "System Events"
                tell process "Mail"
                    click menu item "新規メッセージ" of menu 1 of menu bar 1
               end tell
            end tell
          end tell
      ]]
       hs.osascript.applescript(script)
   end

  hs.hotkey.bind({"ctrl", "shift"}, "n", open_new_mail)
    ```
    `control + shift + n` でメールアプリで新規メールを作成するウィンドウを表示します。

### 応用例とユースケース

*   特定の開発環境を起動し、必要なファイルを自動的に開く
*   ブラウザで特定のページを開き、自動でログインする
*   特定のアプリケーションで、繰り返し行う作業をショートカットで実行する

### トラブルシューティング

*   アプリケーションのプロセス名、メニュー項目、ボタン名などは、アプリケーションのバージョンによって異なる場合があります。
*  UI要素を操作する場合は、System Eventsのプロセス名が正しいかを確認してください。
*  UI要素の識別には、Accessibility Inspectorが便利です。

## 2.4 クリップボード操作：テキスト処理を効率化する

### 概要と重要性

クリップボード操作の自動化は、テキスト処理を大幅に効率化できます。このセクションでは、クリップボードの内容の取得、加工、置換、フォーマット変換、そして日付や時刻の挿入について解説します。

### 基本的な使い方

1. **クリップボードの内容の取得と加工**

   Hammerspoonでは、`hs.pasteboard.getContents()` 関数を使ってクリップボードの内容を取得できます。取得した内容は、Luaの文字列操作関数を使って加工できます。

   ```lua
   local function get_clipboard_content()
      local content = hs.pasteboard.getContents()
      if content then
         print("クリップボードの内容:", content)
      else
        print("クリップボードにテキストがありません")
      end
   end

   hs.hotkey.bind({"ctrl", "shift"}, "g", get_clipboard_content)
   ```
   `control + shift + g` でクリップボードの内容をコンソールに出力します。

2. **テキストの置換、フォーマット変換**

   Luaの文字列操作関数を使って、テキストの置換やフォーマット変換を行います。例えば、クリップボードの内容に含まれる「foo」を「bar」に置換するスクリプトは以下のようになります。

    ```lua
     local function replace_foo_with_bar()
        local text = hs.pasteboard.getContents()
         if text then
           local newText = text:gsub("foo", "bar")
           hs.pasteboard.setContents(newText)
         end
    end

    hs.hotkey.bind({"ctrl", "shift"}, "r", replace_foo_with_bar)
    ```
    `control + shift + r` でクリップボードの内容の「foo」を「bar」に置換します。

### 実践的なテクニック

1. **日付や時刻の挿入**

   クリップボードの内容として、現在の日付や時刻を挿入することができます。

   ```lua
   local function insert_date_time()
      local dateString = os.date("%Y-%m-%d %H:%M:%S")
      hs.pasteboard.setContents(dateString)
      hs.eventtap.keyStroke("v", {"cmd"})
   end

   hs.hotkey.bind({"ctrl", "shift"}, "d", insert_date_time)
   ```
  `control + shift + d` で現在の日時をクリップボードにコピーし、ペーストします。

2. **実践例：特定のパターンに合致するテキストを変換する**

   クリップボードの内容から、URLを抽出して、マークダウン形式のリンクに変換する例です。

      ```lua
    local function convert_url_to_markdown()
        local text = hs.pasteboard.getContents()
        if text then
            local newText = text:gsub("(https?://%S+)", function(url)
                return "[" .. url .. "](" .. url .. ")"
            end)
            hs.pasteboard.setContents(newText)
        end
    end
   hs.hotkey.bind({"ctrl", "shift"}, "u", convert_url_to_markdown)
    ```
    `control + shift + u` でクリップボードにあるURLをマークダウン形式のリンクに変換します。

3.  **実践例：クリップボードからmarkdown形式で整形して貼り付ける**

    クリップボードからテキストを取得し、markdownの引用符（>）を各行頭に追加してペーストします。
    ```lua
      local function format_clipboard_as_markdown_quote()
          local text = hs.pasteboard.getContents()
          if text then
            local formattedText = "> " .. text:gsub("\n", "\n> ")
            hs.pasteboard.setContents(formattedText)
            hs.eventtap.keyStroke("v", {"cmd"})
          end
      end
      hs.hotkey.bind({"ctrl", "shift"}, "q", format_clipboard_as_markdown_quote)
    ```
    `control + shift + q` でクリップボードの内容をマークダウン形式の引用符で整形して貼り付けます。

### 応用例とユースケース

*   クリップボードの内容をHTMLエンコード/デコードする
*   クリップボードの内容をJSON形式に整形する
*   クリップボードの内容を特定のフォーマットに変換して貼り付ける

### トラブルシューティング

*   クリップボードにテキスト以外のデータが含まれている場合、エラーが発生する可能性があります。
*   テキストのエンコードによっては、文字化けが発生する場合があります。
*  テキストの加工には、Luaの正規表現を使いこなす必要がある場合があります。
