# 第3章：HammerspoonとAppleScript連携の実践レシピ：応用編

この章では、HammerspoonとAppleScriptを組み合わせた応用的なレシピを紹介します。前章で紹介した基本的な連携方法をベースに、より複雑なタスクを自動化し、あなたのMac環境をさらに便利にするための具体的な方法を解説します。

## 3.1 ファイルシステム操作：ファイルやフォルダの自動整理

### 3.1.1 概要と重要性
ファイルシステム操作は、日常的なPC作業において非常に重要な部分です。大量のファイルやフォルダを整理する作業は、手作業で行うと時間と労力がかかります。HammerspoonとAppleScriptを組み合わせることで、これらの作業を自動化し、効率を大幅に向上させることができます。特に、特定のルールに基づいてファイルを整理したい場合や、定期的に行う必要がある作業を自動化することで、生産性を向上させることができます。

### 3.1.2 基本的な使い方
HammerspoonからAppleScriptを利用してファイルシステムを操作するには、`hs.osascript`モジュールを使用します。AppleScriptの基本的な構文と、`tell application "Finder"`などの命令を理解しておく必要があります。

**基本的なAppleScriptの例:**

```applescript
-- ファイルの作成
set filePath to "~/Documents/test.txt"
do shell script "touch " & quoted form of filePath

-- ファイルの削除
set filePath to "~/Documents/test.txt"
do shell script "rm " & quoted form of filePath

-- ファイルの移動
set sourcePath to "~/Documents/test.txt"
set destinationPath to "~/Desktop/test.txt"
do shell script "mv " & quoted form of sourcePath & " " & quoted form of destinationPath

-- フォルダの作成
set folderPath to "~/Documents/testFolder"
do shell script "mkdir " & quoted form of folderPath
```

**Hammerspoonでの実行例:**

```lua
-- ファイルを作成するHammerspoon関数
local function create_file(filepath)
  hs.osascript.applescript([[
    set filePath to "]] .. filepath .. [["
    do shell script "touch " & quoted form of filePath
  ]])
end

-- Hammerspoonで関数を呼び出す例
create_file("~/Documents/test.txt")
```

### 3.1.3 実践的なテクニック

**ファイルの種類による操作:**
AppleScriptでは、ファイルの拡張子を取得し、それに応じて処理を分岐させることができます。例えば、特定の拡張子のファイルのみを移動したり、リネームしたりすることができます。

```applescript
-- ファイルの拡張子を取得する例
set filePath to "~/Documents/sample.txt"
tell application "Finder"
	set fileExtension to name extension of file filePath
	display dialog fileExtension
end tell

-- 特定の拡張子のファイルを移動する例
set folderPath to "~/Downloads"
tell application "Finder"
    set files to every file of folder folderPath
    repeat with aFile in files
        if name extension of aFile is "jpg" then
            move aFile to folder "~/Pictures/jpg"
        end if
    end repeat
end tell

```

**日付による操作:**
ファイルの作成日や更新日を取得して、それに応じてファイルを整理することも可能です。例えば、ダウンロードフォルダに溜まったファイルを、日付ごとにフォルダに整理することができます。

```applescript
-- ファイルの作成日を取得する例
set filePath to "~/Documents/sample.txt"
tell application "Finder"
	set fileCreationDate to creation date of file filePath
  set dateString to fileCreationDate as string
	display dialog dateString
end tell
```

### 3.1.4 応用例とユースケース

**実践例1：ダウンロードフォルダの自動整理:**
ダウンロードフォルダに溜まったファイルを、日付ごとにフォルダに整理するHammerspoonスクリプトです。

```lua
local function organize_downloads()
  hs.osascript.applescript([[
    set downloadsPath to path to downloads folder as string
    tell application "Finder"
      set theFiles to every file of folder downloadsPath
      repeat with aFile in theFiles
        try
            set fileDate to creation date of aFile
            set year to year of fileDate
            set month to month of fileDate
            set day to day of fileDate
            set folderName to year & "-" & (month as integer) & "-" & (day as integer)
            set targetFolder to (downloadsPath & folderName)

            if not (exists folder targetFolder) then
              make new folder at downloadsPath with properties {name:folderName}
            end if

            move aFile to folder targetFolder
        on error
            -- ファイル操作に失敗した場合のエラー処理
            display dialog "ファイルの移動に失敗しました: " & name of aFile
        end try
      end repeat
    end tell
  ]])
end

-- Hammerspoonのキーバインドで関数を実行
hs.hotkey.bind({"cmd", "shift"}, "o", function()
  organize_downloads()
end)
```

**実践例2：特定の形式のファイルをまとめてリネーム:**
例えば、PDFファイルに連番を振るなどの処理を自動化できます。

```lua
local function rename_pdfs()
  hs.osascript.applescript([[
    set targetFolder to "~/Documents/pdfs"
    tell application "Finder"
      set pdfFiles to every file of folder targetFolder whose name extension is "pdf"
      set i to 1
      repeat with aFile in pdfFiles
        set newFileName to "document_" & i & ".pdf"
        set name of aFile to newFileName
        set i to i + 1
      end repeat
    end tell
  ]])
end

hs.hotkey.bind({"cmd", "shift"}, "r", function()
  rename_pdfs()
end)
```

### 3.1.5 トラブルシューティング
- **権限の問題:**  AppleScriptがファイルやフォルダを操作するためには、適切な権限が必要です。エラーが発生する場合は、HammerspoonやAppleScriptの権限設定を確認してください。
- **ファイルの存在:**  指定したファイルやフォルダが存在しない場合、エラーが発生します。ファイルの存在チェックをスクリプトに追加することをおすすめします。
- **構文エラー:**  AppleScriptの構文エラーは、スクリプトの実行を妨げます。エラーメッセージをよく読んで、構文を修正する必要があります。

## 3.2 Webブラウザ操作：Webサイトの自動操作と情報収集

### 3.2.1 概要と重要性
Webブラウザ操作を自動化することで、Webサイトの情報を効率的に取得したり、繰り返し行う作業を自動化したりすることができます。例えば、Webサイトから最新のニュースを抽出したり、複数のWebサービスに自動でログインしたりすることが可能です。

### 3.2.2 基本的な使い方
Webブラウザの操作には、AppleScriptの`tell application "Safari"`や`tell application "Google Chrome"`などの命令を使用します。

**基本的なAppleScriptの例:**

```applescript
-- 特定のURLを開く
tell application "Safari"
  make new document at end with properties {URL:"https://www.example.com"}
end tell

-- タブを閉じる
tell application "Safari"
  close current tab of front window
end tell

-- 現在のタブのURLを取得する
tell application "Safari"
  get URL of current tab of front window
end tell

-- Webページのソースコードを取得する (Chromeの場合)
tell application "Google Chrome"
  set pageSource to execute javascript "document.documentElement.outerHTML" in active tab of front window
end tell
```

**Hammerspoonでの実行例:**

```lua
-- SafariでURLを開くHammerspoon関数
local function open_url_in_safari(url)
  hs.osascript.applescript([[
    tell application "Safari"
      make new document at end with properties {URL:" ]] .. url .. [["}
    end tell
  ]])
end

-- Hammerspoonで関数を呼び出す例
open_url_in_safari("https://www.example.com")
```

### 3.2.3 実践的なテクニック

**Webサイトの情報の取得（スクレイピング）:**
Webページのソースコードを取得し、必要な情報を抽出するには、正規表現や文字列操作が必要になります。Chromeの場合はJavaScriptを実行してDOMを操作できます。

```applescript
-- Webページのタイトルを取得する例 (Chrome)
tell application "Google Chrome"
  set pageTitle to execute javascript "document.title" in active tab of front window
end tell
```

**Webフォームへの自動入力:**
Webページの要素を特定して、自動でテキストを入力したり、ボタンをクリックしたりすることも可能です。

```applescript
-- Webフォームにテキストを入力する例 (Chrome)
tell application "Google Chrome"
  execute javascript "document.getElementById('username').value = 'test_user'" in active tab of front window
end tell

-- ボタンをクリックする例 (Chrome)
tell application "Google Chrome"
  execute javascript "document.getElementById('login_button').click()" in active tab of front window
end tell
```

### 3.2.4 応用例とユースケース

**実践例1：特定のサイトから最新ニュースを抽出する:**
指定したWebサイトから、最新のニュース記事のタイトルを抽出して表示する例です。

```lua
local function get_news()
  local url = "https://www.example-news.com"  -- 例としてニュースサイトのURLを記述
  local result = hs.http.get(url)
  if result.status_code == 200 then
      local html = result.body
      local titles = hs.regex.findAll('<h2 class="news-title">(.*?)</h2>', html)  -- 例としてニュースタイトルのHTMLタグを記述
      if titles then
          local message = ""
          for i, title in ipairs(titles) do
            message = message .. title .. "\n"
          end
          hs.alert.show(message)
      else
          hs.alert.show("ニュースが見つかりませんでした")
      end
  else
    hs.alert.show("Webサイトの読み込みに失敗しました")
  end
end

hs.hotkey.bind({"cmd", "shift"}, "n", function()
  get_news()
end)
```

**実践例2：複数のWebサービスに同時ログインする:**
複数のWebサイトのログインページを一度に開き、その後、別のスクリプトでログイン情報を自動入力する、という使い方も可能です。

```lua
local function login_to_multiple_services()
  local urls = {
    "https://www.example-service1.com/login",
    "https://www.example-service2.com/login",
    "https://www.example-service3.com/login"
  }

  for _, url in ipairs(urls) do
      hs.osascript.applescript([[
        tell application "Safari"
          make new document at end with properties {URL:" ]] .. url .. [["}
        end tell
      ]])
  end
end

hs.hotkey.bind({"cmd", "shift"}, "l", function()
  login_to_multiple_services()
end)
```

### 3.2.5 トラブルシューティング
- **Webページの構造:** WebページのHTML構造は、頻繁に変更される可能性があります。スクレイピング処理がうまく動かない場合は、HTML構造を再確認し、セレクタを修正する必要があります。
- **ログイン処理:** Webサイトによっては、セキュリティ上の理由から自動ログインをブロックしている場合があります。その場合は、別の方法を検討する必要があります。
- **JavaScriptエラー:** ChromeでのJavaScript実行時にエラーが発生する場合は、JavaScriptの構文を再度確認してください。

## 3.3 システム連携：macOSの様々な機能を自動化する

### 3.3.1 概要と重要性
macOSの様々な機能を自動化することで、より快適なPC環境を実現できます。通知センターの制御、ネットワーク接続の制御、スクリーンショットの自動化など、普段手作業で行っているタスクを自動化することで、作業効率を大幅に向上させることができます。

### 3.3.2 基本的な使い方
macOSのシステム機能を制御するには、AppleScriptの`tell application "System Events"`や`do shell script`などの命令を使用します。

**基本的なAppleScriptの例:**

```applescript
-- 通知センターを表示/非表示
tell application "System Events"
  if (exists process "Notification Center") then
    set visible of process "Notification Center" to not (visible of process "Notification Center")
  end if
end tell

-- Wi-Fiをオン/オフ
do shell script "networksetup -setairportpower en0 off"
do shell script "networksetup -setairportpower en0 on"

-- スクリーンショットを撮る
do shell script "screencapture -i ~/Desktop/screenshot.png"

-- カレンダーに予定を追加する（EventKit使用）
tell application "Calendar"
    tell calendar named "Home"
        make new event with properties {summary:"会議", start date:date "2024-05-01 10:00:00", end date:date "2024-05-01 11:00:00"}
    end tell
end tell
```

**Hammerspoonでの実行例:**

```lua
-- 通知センターを表示/非表示にするHammerspoon関数
local function toggle_notification_center()
  hs.osascript.applescript([[
    tell application "System Events"
        if (exists process "Notification Center") then
          set visible of process "Notification Center" to not (visible of process "Notification Center")
        end if
    end tell
  ]])
end

-- Hammerspoonで関数を呼び出す例
hs.hotkey.bind({"cmd", "shift"}, "t", function()
  toggle_notification_center()
end)
```

### 3.3.3 実践的なテクニック

**通知センターの制御:**
通知センターの表示/非表示を切り替えたり、通知をミュートしたりすることができます。

```applescript
-- 通知センターをミュートする (Do Not Disturbを有効にする)
tell application "System Events"
    set do not disturb to true
end tell
```

**ネットワーク接続の制御:**
Wi-FiやBluetoothのオン/オフを切り替えたり、特定のネットワークに接続したりすることができます。

```applescript
-- 特定のWi-Fiに接続する
do shell script "networksetup -setairportnetwork en0 \"MyNetwork\" \"MyPassword\""
```

**スクリーンショットの自動化:**
特定の領域のスクリーンショットを撮影して、指定した場所に保存することができます。

```applescript
-- スクリーンショットをデスクトップに保存する
do shell script "screencapture -x ~/Desktop/screenshot.png"
```

**実践例2：Wi-Fiのオンオフを自動化する:**
特定の場所（例えば、自宅や職場）に到着したときに自動的にWi-Fiをオンにしたり、離れたときにオフにするなど、ロケーションベースでWi-Fiを制御するスクリプトも可能です。（位置情報取得には別途実装が必要です）

- **コマンドの構文:** `do shell script`で使用するコマンドの構文は、OSのバージョンによって異なる場合があります。エラーが発生する場合は、コマンドの構文を再確認してください。

## 3.4 API連携：外部サービスとの連携でさらに便利に

### 3.4.1 概要と重要性
API連携を利用することで、外部のWebサービスと連携し、Hammerspoonの機能をさらに拡張することができます。天気予報API、TodoリストAPI、翻訳APIなど、様々なAPIを利用することで、自分の作業環境をカスタマイズすることができます。

### 3.4.2 基本的な使い方
HammerspoonからAPIを呼び出すには、`hs.http`モジュールを使用します。APIから返ってくるデータは、JSONやXML形式であることが多いため、`hs.json`モジュールや`hs.xml`モジュールを使用して解析する必要があります。

**基本的なHammerspoonの例:**

```lua
-- GETリクエストを送信する
local function get_data_from_api(url)
  local result = hs.http.get(url)
  if result.status_code == 200 then
    return result.body
  else
    return nil
  end
end

-- JSONデータを解析する
local function parse_json_data(json_string)
  return hs.json.decode(json_string)
end

-- XMLデータを解析する
local function parse_xml_data(xml_string)
  return hs.xml.parse(xml_string)
end
```

### 3.4.3 実践的なテクニック

**HTTPリクエストを使ったAPI呼び出し:**
`hs.http.get`や`hs.http.post`を使って、APIにリクエストを送信できます。APIによっては、リクエストヘッダーや認証情報が必要になる場合があります。

```lua
-- POSTリクエストを送信する例
local function post_data_to_api(url, data)
    local result = hs.http.post({url = url, body = data})
    if result.status_code == 200 then
      return result.body
    else
      return nil
    end
end
```

**JSONやXMLデータの解析:**
APIから返ってくるデータは、JSON形式またはXML形式であることが多いため、`hs.json`モジュールや`hs.xml`モジュールで解析する必要があります。

```lua
-- JSONデータを解析して特定の要素を取得する例
local function get_json_element(json_string, element_path)
  local json_data = hs.json.decode(json_string)
  local current = json_data
  for _, key in ipairs(element_path) do
    if current and current[key] then
      current = current[key]
    else
      return nil
    end
  end
  return current
end
```

**実践例2：Todoリストの項目をHammerspoonから追加する:**

```lua
local function add_todo_item(item_name)
    local api_token = "YOUR_API_TOKEN" -- 取得したAPIトークンを記述
    local todoist_api_url = "https://api.todoist.com/rest/v2/tasks"
    local post_data = hs.json.encode({content = item_name})
    local auth_header = "Bearer " .. api_token
    local headers = {["Authorization"] = auth_header, ["Content-Type"] = "application/json"}
    local result = hs.http.post({url=todoist_api_url, body=post_data, headers = headers})

    if result.status_code == 201 then
      hs.alert.show("Todo項目を追加しました: " .. item_name)
    else
      hs.alert.show("Todo項目追加に失敗しました。")

end


hs.hotkey.bind({"cmd", "shift"}, "a", function()
    hs.ui.textEntry("Todo項目を入力してください:", "", function(input)
        if input and input ~= "" then
            add_todo_item(input)
        end
    end)
end)
```

### 3.4.5 トラブルシューティング
- **APIキーやトークン:** APIを利用するには、APIキーやトークンが必要な場合があります。APIプロバイダのドキュメントを確認し、APIキーやトークンを正しく設定してください。
- **APIの制限:** APIによっては、利用回数やデータ量に制限がある場合があります。制限を超過すると、APIが利用できなくなるため注意してください。
- **データの形式:** APIから返ってくるデータの形式は、APIによって異なります。エラーが発生する場合は、APIのドキュメントを再度確認し、適切な方法でデータを解析してください。

## このチャプターの構成


### 3.1 ファイルシステム操作：ファイルやフォルダの自動整理
