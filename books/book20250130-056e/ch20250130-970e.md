# 第1章：Hammerspoon基礎 - Macを操るための第一歩

## はじめに

この章では、Macの自動化ツールとして非常に強力なHammerspoonの基礎について解説します。Hammerspoonは、Luaというスクリプト言語を用いてMacの様々な操作を自動化できるツールであり、その柔軟性と拡張性の高さから多くの開発者やパワーユーザーに愛用されています。この章を通じて、Hammerspoonの基本的な使い方を理解し、Macをより快適に、そして効率的に使えるようになることを目指します。

## 1. Hammerspoonとは？

### 1.1 概要と重要性

Hammerspoonは、Mac OS X用の無料のオープンソースツールです。このツールを使用することで、キーボードショートカット、ウィンドウ管理、アプリケーション操作など、Macの様々な側面をLuaスクリプトを通じてカスタマイズできます。つまり、プログラミングの知識を使って、自分の作業スタイルに合わせたMac環境を構築できるということです。

Hammerspoonの重要性は、そのカスタマイズの自由度にあります。例えば、特定のアプリケーションを特定の場所に常に表示させたり、特定のキーボードショートカットで複数の操作を一度に実行させたりといった、OS標準機能だけでは実現が難しい自動化が容易に実現可能です。

### 1.2 主要モジュール

Hammerspoonの中核をなす主要なモジュールをいくつか紹介します。これらのモジュールを理解することで、Hammerspoonの基本的な使い方を把握できます。

* **`hs.application`**: アプリケーションの操作を制御します。特定のアプリケーションを起動したり、フォーカスを切り替えたり、アプリケーションのウィンドウを操作したりできます。
* **`hs.hotkey`**: キーボードショートカットを定義します。特定のキーの組み合わせに、任意のLuaスクリプトを割り当てることができます。
* **`hs.eventtap`**: OSのイベントをフックします。マウスの動きやキーボードの入力を監視し、特定のイベントが発生したときにアクションを実行できます。
* **`hs.window`**: ウィンドウの操作を制御します。ウィンドウのサイズや位置を変更したり、特定のウィンドウを最前面に表示させたりできます。
* **`hs.task`**: コマンドラインツールを非同期で実行します。ターミナルコマンドをHammerspoonから呼び出して、その結果をスクリプト内で利用できます。
* **`hs.screen`**: スクリーンに関する情報を取得します。スクリーンサイズや解像度などを取得し、マルチディスプレイ環境での操作に役立ちます。
* **`hs.notify`**: 通知を表示します。HammerspoonのスクリプトからOSの通知センターに通知を送ることができます。
* **`hs.timer`**: 定期的な処理をスケジュールします。特定の時間間隔でスクリプトを実行したり、タイマーを作成したりできます。
* **`hs.menubar`**: メニューバーにカスタムメニューを追加します。メニューからスクリプトを実行したり、ステータスを表示したりできます。

これらのモジュールを組み合わせることで、非常に複雑な自動化スクリプトを作成できます。

### 1.3 Hammerspoonの設定と起動

Hammerspoonの基本的な使い方として、まずは設定と起動方法について解説します。

1. **インストール:** Hammerspoonの公式サイト ([https://www.hammerspoon.org/](https://www.hammerspoon.org/)) からダウンロードし、アプリケーションフォルダに移動します。
2. **起動:** Hammerspoonを初めて起動すると、アクセシビリティの許可を求められます。許可すると、メニューバーにHammerspoonのアイコンが表示されます。
3. **設定ファイル:** Hammerspoonの設定は、`~/.hammerspoon/init.lua` というファイルにLuaスクリプトとして記述します。このファイルがない場合は、新規作成します。
4. **設定の反映:** `init.lua` を編集した後は、メニューバーのHammerspoonアイコンをクリックし、「Reload Config」を選択して設定を反映させます。

## 2. 基本的な自動化スクリプト例

### 2.1 ウィンドウのリサイズと移動

`hs.window`モジュールを使用すると、ウィンドウの位置やサイズを制御できます。

**例：現在のウィンドウを画面左半分に配置**

```lua
local function moveWindowLeft()
  local win = hs.window.focusedWindow()
  if win then
    local screen = win:screen()
    local frame = screen:frame()
    local w = frame.w / 2
    win:setFrame({x = frame.x, y = frame.y, w = w, h = frame.h})
  end
end

hs.hotkey.bind({"cmd", "shift"}, "Left", moveWindowLeft)
```

**解説:**

*   `hs.window.focusedWindow()` で現在フォーカスされているウィンドウを取得します。
*   `win:screen()` でウィンドウが存在するスクリーンを取得します。
*   `screen:frame()` でスクリーンのフレーム（位置とサイズ）を取得します。
*   `win:setFrame()` でウィンドウのフレームを設定します。この例では、スクリーンの幅の半分になるようにウィンドウの幅を設定しています。
*   `hs.hotkey.bind()` でキーボードショートカット `cmd + shift + 左矢印` に関数 `moveWindowLeft` を割り当てます。

### 2.2 アプリケーションの起動と切り替え

`hs.application`モジュールを使用すると、アプリケーションの起動や切り替えができます。

**例：ターミナルを起動**

```lua
local function launchTerminal()
  hs.application.launchOrFocus("Terminal")
end

hs.hotkey.bind({"cmd", "ctrl"}, "t", launchTerminal)
```

**解説:**

*   `hs.application.launchOrFocus()` で、指定したアプリケーション (`Terminal`) を起動するか、既に起動している場合はフォーカスします。
*   `hs.hotkey.bind()` でキーボードショートカット `cmd + ctrl + t` に関数 `launchTerminal` を割り当てます。

**例：Chromeを最前面に表示**

```lua
local function bringChromeToFront()
  local app = hs.application.find("Google Chrome")
  if app then
    app:activate()
  end
end

hs.hotkey.bind({"cmd", "ctrl"}, "c", bringChromeToFront)
```

**解説:**

*   `hs.application.find()` で、指定した名前 (`Google Chrome`) のアプリケーションを探します。
*   `app:activate()` で、アプリケーションを最前面に表示します。
*   `hs.hotkey.bind()` でキーボードショートカット `cmd + ctrl + c` に関数 `bringChromeToFront` を割り当てます。

### 2.3 `hs.eventtap` でイベントを監視

`hs.eventtap` モジュールを使用すると、マウスのクリックやキーボードの入力を監視できます。

**例：マウスの右クリックを監視して通知を表示**

```lua
local function mouseEventCallback(event)
  if event:getType() == hs.eventtap.event.types.mouseDown then
    local btn = event:getButton()
    if btn == 2 then -- 2 is right click
      hs.notify.show("マウス右クリック", "右クリックが検出されました")
    end
  end
end

local mouseTap = hs.eventtap.new( { hs.eventtap.event.types.mouseDown }, mouseEventCallback )
mouseTap:start()
```

**解説:**

*   `hs.eventtap.new()` で、指定したイベント (`hs.eventtap.event.types.mouseDown` ) を監視するイベントタップを作成します。
*   `mouseEventCallback` 関数は、イベントが発生するたびに呼び出されます。
*   `event:getType()` でイベントのタイプを取得し、マウスダウンイベントの場合のみ処理を行います。
*   `event:getButton()` でクリックされたボタンを取得し、右クリック (button code 2) の場合のみ通知を表示します。
*   `mouseTap:start()` でイベントタップを開始します。

### 2.4 実践的なテクニック

**アプリケーション固有の設定:**

特定のアプリケーションに対してのみ有効になる設定を記述することも可能です。

```lua
-- 特定のアプリケーションのウィンドウサイズを調整
local function setupWindowLayout(appName)
  if hs.application.frontmostApplication():name() == appName then
    local win = hs.window.frontmostWindow()
    if win then
      local screen = win:screen()
      local frame = screen:frame()
       win:setFrame({x = frame.x + 200, y = frame.y + 100, w = frame.w - 400, h = frame.h - 200})
    end
  end
end


-- 1秒ごとに実行
hs.timer.doEvery(1, function()
  setupWindowLayout("Google Chrome")
end)
```

**解説:**

* `hs.application.frontmostApplication():name()` で最前面のアプリケーションの名前を取得し、指定したアプリケーション(`Google Chrome`)である場合のみ、ウィンドウの位置とサイズを調整します。
* `hs.timer.doEvery(1, ...)` で、1秒ごとに指定した関数を実行し、常に最前面のアプリケーションを監視し、設定を適用します。

### 2.5 応用例とユースケース

*   **ウィンドウ管理の効率化:**
    *   特定のアプリケーションを特定のスクリーンに常に表示させる。
    *   特定のアプリケーションのウィンドウを最大化または特定のサイズにリサイズするショートカットを作成する。
    *   複数のウィンドウをまとめて特定のレイアウトに配置するショートカットを作成する。
*   **開発効率の向上:**
    *   ターミナル、テキストエディタ、ブラウザをまとめて起動するショートカットを作成する。
    *   特定のディレクトリをFinderで開くショートカットを作成する。
    *   GitHubリポジトリをクローンして、ターミナルでそのディレクトリを開くショートカットを作成する。
*   **日常的な作業の効率化:**
    *   クリップボードの履歴を管理するツールを作成する。
    *   特定のWebサイトを素早く開くショートカットを作成する。
    *   スクリーンショットを撮って特定の場所に保存するショートカットを作成する。
*   **プレゼンテーションの効率化:**
    *   プレゼンテーション資料を常に最前面に表示するショートカットを作成する。
    *   プレゼンテーション中に不要なアプリケーションを非表示にするショートカットを作成する。

## 3. Tips & トラブルシューティング

### 3.1 設定ファイルの変更を反映させる

`init.lua` ファイルを変更した後は、必ずメニューバーの Hammerspoon アイコンをクリックし、「Reload Config」を選択して設定を反映させる必要があります。設定が反映されない場合は、この点をまず確認してください。

### 3.2 設定ファイルの記述ミス

Luaスクリプトの記述ミス（構文エラーやタイプミス）があると、Hammerspoonが正常に動作しません。

*   Hammerspoonのコンソール (`hs.console.open()`) を開き、エラーメッセージを確認します。
*   記述ミスを修正したら、設定を再度リロードしてください。

### 3.3 アクセシビリティの設定

Hammerspoonが正常に動作するためには、macOSのアクセシビリティ設定でHammerspoonを許可する必要があります。

*   システム環境設定の「セキュリティとプライバシー」で、「アクセシビリティ」を選択し、Hammerspoonにチェックが入っていることを確認してください。
*   チェックが入っていない場合は、チェックを入れて、Hammerspoonを再起動してください。

### 3.4 モジュールが見つからない場合

Hammerspoonのバージョンによっては、一部のモジュールが存在しない場合があります。

*   Hammerspoonの公式サイトのドキュメントを確認し、モジュールが存在するかどうかを確認してください。
*   最新のHammerspoonにアップデートすることを検討してください。

### 3.5 複雑な処理でエラーが発生する場合

複雑な処理を実行するスクリプトでは、エラーが発生する可能性があります。

*   エラーメッセージを丁寧に確認し、エラーの原因を特定してください。
*   エラーの原因が特定できない場合は、Hammerspoonのフォーラムやコミュニティで質問してみることをお勧めします。

### 3.6 CPU負荷の問題

過度に複雑な処理や頻繁なタイマー処理を実行すると、CPU負荷が高くなることがあります。

*   処理を簡略化したり、タイマーの間隔を調整したりするなど、CPU負荷を抑える工夫をしてください。
*   `hs.timer.doAfter` で遅延処理を行うことも有効です。

### 3.7 注意点

*   Hammerspoonは非常に強力なツールですが、設定を誤るとOSが不安定になる可能性があります。
*   `init.lua` を変更する前に、必ずバックアップを取っておくことをお勧めします。
*   公開されているスクリプトを使用する場合は、必ず内容を確認してから利用するようにしてください。
