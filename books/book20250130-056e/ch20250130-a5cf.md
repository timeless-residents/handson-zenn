### テキスト入力の効率化

#### 1. 概要と重要性

テキスト入力は、多くの業務において不可欠な作業です。しかし、同じようなフレーズを何度も入力したり、複雑な記号やフォーマットを扱うのは時間がかかり、ミスも発生しやすくなります。HammerspoonとClaudeを組み合わせることで、これらの課題を解決し、テキスト入力の効率を飛躍的に向上させることができます。

#### 2. 基本的な使い方

ここでは、Hammerspoonのホットキー機能と、Claudeのテキスト生成能力を利用した、基本的なテキスト入力自動化の例を紹介します。

```lua
-- Hammerspoon設定ファイル (init.lua)

-- Claude APIキーを設定（環境変数からも読み込めるように）
local claude_api_key = os.getenv("CLAUDE_API_KEY") or "YOUR_CLAUDE_API_KEY"

-- HTTPリクエスト関数
local function makeClaudeRequest(prompt)
  local url = "https://api.anthropic.com/v1/complete" -- Claude APIエンドポイント
  local headers = {
    ["Content-Type"] = "application/json",
    ["x-api-key"] = claude_api_key,
  }
  local data = {
      prompt = prompt,
      model = "claude-v1.3",
      max_tokens_to_sample = 200,
  }
  local json_data = hs.json.encode(data)
  local response = hs.http.post({url = url, headers = headers, body = json_data})
  if response.status_code == 200 then
    local json_response = hs.json.decode(response.body)
    return json_response.completion
  else
      hs.alert.show("Error: " .. response.status_code)
      hs.console.print("Error: " .. response.status_code .. " " .. response.body)
    return nil
  end
end

-- テキスト拡張ホットキーの設定例
hs.hotkey.bind({"cmd", "shift"}, "t", function()
  -- 入力プロンプトを設定
  local prompt = hs.dialog.textPrompt("Claudeに生成してほしいテキストの内容を入力してください:", "テキスト生成")
  if prompt then
    -- Claude APIを呼び出し
    local result = makeClaudeRequest(prompt)
    if result then
      -- 生成されたテキストをペースト
      hs.pasteboard.setContents(result)
      hs.eventtap.keyStroke("v", {"cmd"})
    end
  end
end)
```

このコード例では、`cmd + shift + t` のホットキーを押すと、プロンプト入力ダイアログが表示され、そこにテキストを入力すると、Claudeによって生成されたテキストがペーストされます。

**注意:** `YOUR_CLAUDE_API_KEY` を実際のAPIキーに置き換える必要があります。

local promptTemplate = "以下の文章を[length]文字以内で要約してください:\n[text]"

hs.hotkey.bind({"cmd", "shift"}, "s", function()
  local selectedText = hs.pasteboard.getContents()
  if selectedText then
    local length = hs.dialog.textPrompt("文字数上限を入力してください:", "要約")

        local prompt = string.gsub(promptTemplate, "[text]", selectedText)

          hs.pasteboard.setContents(result)
          hs.eventtap.keyStroke("v", {"cmd"})
        end
    end
  end

### タスク管理の自動化

#### 1. 概要と重要性

#### 2. 基本的な使い方

ここでは、HammerspoonとTodoistのようなタスク管理ツールと連携した、基本的なタスク管理自動化の例を紹介します。

**注意:** Todoist APIを使用するには、事前にAPIトークンを取得しておく必要があります。

```lua
-- Todoist APIトークンを設定
local todoist_api_token = os.getenv("TODOIST_API_TOKEN") or "YOUR_TODOIST_API_TOKEN"

-- Todoist APIリクエスト関数
local function makeTodoistRequest(method, endpoint, body)
    local url = "https://api.todoist.com/rest/v2/" .. endpoint
    local headers = {
        ["Authorization"] = "Bearer " .. todoist_api_token,
        ["Content-Type"] = "application/json",
    }
    local response
    if method == "POST" then
      response = hs.http.post({url = url, headers = headers, body = hs.json.encode(body)})
    elseif method == "GET" then
      response = hs.http.get({url = url, headers = headers})
    end
    if response.status_code == 200 or response.status_code == 201 then
      return hs.json.decode(response.body)
    else
      hs.alert.show("Error: " .. response.status_code)
      hs.console.print("Error: " .. response.status_code .. " " .. response.body)
      return nil
    end
end

-- タスク追加ホットキーの設定
hs.hotkey.bind({"cmd", "shift"}, "a", function()
    local taskContent = hs.dialog.textPrompt("追加するタスクを入力してください:", "タスク追加")
    if taskContent then
      local result = makeTodoistRequest("POST", "tasks", {content = taskContent})
      if result then
        hs.alert.show("タスクを追加しました: " .. result.content)
      end
    end
end)

-- 今日のタスクを表示
hs.hotkey.bind({"cmd", "shift"}, "d", function()
  local result = makeTodoistRequest("GET", "tasks")
  if result then
    local todayTasks = ""
    for i, task in ipairs(result) do
        if task.due and task.due.is_recurring == false then
            local dueDate = os.date("%Y-%m-%d", task.due.date)
            local today = os.date("%Y-%m-%d")
            if dueDate == today then
               todayTasks = todayTasks ..  (i) .. ": " .. task.content .. "\n"
            end
        end
    end
      hs.alert.show("今日のタスク: \n" .. todayTasks)
  end
end)

```

このコード例では、`cmd + shift + a` でタスクを追加し、`cmd + shift + d`で今日のタスクを表示します。

#### 2. 基本的な使い方

ここでは、HammerspoonとClaudeを使って、Webサイトの情報を抽出する基本的な例を紹介します。

```lua
-- Webページからテキストを取得する関数
local function getWebPageText(url)
  local response = hs.http.get(url)
  if response.status_code == 200 then
    local pageContent = response.body
    -- ここでは、簡易的にHTMLタグを除去
    local text = string.gsub(pageContent, "<[^>]*>", "")
    return text
  else
    hs.alert.show("Error: " .. response.status_code .. " " .. url)
    return nil
  end
end

-- 指定されたURLの情報を要約するホットキー
hs.hotkey.bind({"cmd", "shift"}, "w", function()
  local url = hs.dialog.textPrompt("要約するWebページのURLを入力してください:", "Webページ要約")
  if url then
    local text = getWebPageText(url)
    if text then
        local prompt = "以下の文章を要約してください:\n" .. text
        local result = makeClaudeRequest(prompt)
        if result then
          hs.pasteboard.setContents(result)
          hs.eventtap.keyStroke("v", {"cmd"})
        end
    end
  end
end)
```

このコード例では、`cmd + shift + w` のホットキーを押すと、URL入力ダイアログが表示され、そこにURLを入力すると、Webページのテキストが抽出され、Claudeによって要約されたテキストがペーストされます。
