## 第8章：フォームの作成と処理

Webサイトにおけるフォームは、顧客との重要なコミュニケーションツールであり、リードの獲得、顧客データの収集、サービスの提供など、様々な目的で利用されます。Sitecore Forms は、柔軟性と拡張性に優れたフォーム構築機能を提供し、マーケターがコーディングなしで高度なフォームを作成・管理できるようにします。さらに、Headless Forms を利用することで、フロントエンド技術との連携を強化し、より自由度の高いフォーム体験を実現できます。

### 8.1. Sitecore Forms の概要

**8.1.1. 概要と重要性**

Sitecore Forms は、Sitecore Experience Platform (XP) に統合されたドラッグ＆ドロップ式のフォームビルダーです。マーケターは、コーディングの知識がなくても直感的なインターフェースで、複雑なフォームを迅速に作成し、公開できます。フォームの重要性は、単なるデータ収集だけでなく、顧客とのエンゲージメントを深め、パーソナライズされた体験を提供する上で不可欠な役割を担う点にあります。

**8.1.2. 特徴と利点**

*   **ドラッグ＆ドロップインターフェース:** コーディング不要で直感的にフォームを作成可能。
*   **豊富なフォーム要素:** テキストボックス、ラジオボタン、ドロップダウンリストなど、多様な要素を標準で提供。
*   **カスタマイズ可能なテンプレート:** 企業のブランドイメージに合わせたフォームデザインを簡単に実現。
*   **フォーム送信アクション:** フォーム送信後の処理（メール送信、データベース保存など）を柔軟に設定可能。
*   **パーソナライゼーション:** 顧客の属性や行動に基づいて、フォームの内容を動的に変更可能。
*   **統合された分析機能:** フォームの利用状況やコンバージョン率を追跡し、改善点を特定可能。

**8.1.3. 事前準備と前提条件**

*   Sitecore XP がインストールされ、正常に動作していること。
*   Sitecore Forms モジュールがインストールされていること。
*   適切な権限を持つ Sitecore ユーザーアカウントを使用していること。

**8.1.4. 基本的な使い方**

1.  **フォームの作成:** Sitecore Content Editor で、`/sitecore/content/<サイト名>/Data/Forms` などの場所に新しいフォームアイテムを作成します。
2.  **フォーム要素の追加:** フォームエディターを開き、左側のツールボックスから必要なフォーム要素をドラッグ＆ドロップで追加します。
3.  **フォーム要素の設定:** 各フォーム要素を選択し、プロパティエディターでラベル、プレースホルダー、必須チェックなどの設定を行います。
4.  **レイアウトの調整:** フォーム要素の配置やサイズを調整し、視覚的に魅力的なフォームを作成します。
5.  **フォーム送信アクションの設定:** フォーム送信後の処理（メール送信、データベース保存など）を設定します。

**8.1.5. 実践的なテクニック**

*   **条件付き表示:** 顧客の入力に基づいて、特定のフォーム要素を表示または非表示にすることができます。例：特定の国を選択した場合のみ、都道府県の入力フィールドを表示する。
*   **バリデーションルールの設定:** 入力されたデータが正しい形式であることを確認するために、バリデーションルールを設定します。例：メールアドレスの形式チェック、電話番号の桁数チェック。
*   **カスタムバリデーション:** 標準のバリデーションルールでは対応できない場合、カスタムバリデーションルールを作成することができます。
*   **AJAX フォーム:** ページ全体をリロードせずにフォームを送信し、ユーザーエクスペリエンスを向上させることができます。

**8.1.6. 応用例とユースケース**

*   **お問い合わせフォーム:** 顧客からの問い合わせを受け付けるためのフォーム。
*   **資料請求フォーム:** 顧客に資料をダウンロードさせるためのフォーム。
*   **イベント登録フォーム:** イベントへの参加者を登録するためのフォーム。
*   **アンケートフォーム:** 顧客の意見やフィードバックを収集するためのフォーム。
*   **求人応募フォーム:** 求人への応募を受け付けるためのフォーム。

**8.1.7. トラブルシューティング**

*   **フォームが正しく表示されない:** Sitecore キャッシュをクリアし、ブラウザのキャッシュもクリアしてみてください。
*   **フォームが送信できない:** フォーム送信アクションの設定が正しいか確認してください。また、Sitecore ログにエラーメッセージがないか確認してください。
*   **メールが送信されない:** SMTP サーバーの設定が正しいか確認してください。

**8.1.8. まとめと次のステップ**

Sitecore Forms は、コーディングなしで高度なフォームを作成・管理できる強力なツールです。このセクションでは、Sitecore Forms の基本的な使い方と実践的なテクニックについて学びました。次のステップとして、Headless Forms を利用して、フロントエンド技術との連携を強化し、より自由度の高いフォーム体験を実現する方法を学びましょう。

### 8.2. Headless Forms の実装

**8.2.1. 概要と重要性**

Headless Forms は、Sitecore Forms の機能をヘッドレス環境で利用するための仕組みです。従来の Sitecore Forms は、Sitecore のプレゼンテーション層に依存していましたが、Headless Forms を利用することで、React、Angular、Vue.js などのフロントエンドフレームワークで自由にフォームをレンダリングし、Sitecore のコンテンツ管理機能と連携させることができます。この柔軟性により、開発者は高度にカスタマイズされたフォーム体験を構築できます。

**8.2.2. 特徴と利点**

*   **フロントエンド技術との自由な連携:** React、Angular、Vue.js など、任意のフロントエンドフレームワークでフォームをレンダリング可能。
*   **パフォーマンスの向上:** フロントエンドでフォームをレンダリングすることで、サーバー側の負荷を軽減し、パフォーマンスを向上。
*   **柔軟なカスタマイズ:** フロントエンド技術を活用することで、より高度なフォームデザインやインタラクションを実現。
*   **API ベースの連携:** Sitecore Headless Services を介して、フォームデータを送信し、処理結果を受け取ることが可能。
*   **将来性:** 最新のフロントエンド技術を活用し、将来的な技術の変化にも柔軟に対応可能。

**8.2.3. 事前準備と前提条件**

*   Sitecore XP がインストールされ、正常に動作していること。
*   Sitecore Headless Services がインストールされ、設定されていること。
*   Sitecore Forms モジュールがインストールされていること。
*   Next.js などのフロントエンドフレームワークのプロジェクトがセットアップされていること。
*   Sitecore Context API が正しく設定されていること。

**8.2.4. 基本的な使い方**

1.  **Sitecore でのフォーム作成:** Sitecore Forms を使用して、通常通りフォームを作成します。
2.  **API キーの設定:** Sitecore Headless Services 用の API キーを設定します。
3.  **Next.js コンポーネントの作成:** Next.js プロジェクトで、フォームをレンダリングするための React コンポーネントを作成します。`@sitecore-jss/sitecore-jss-nextjs` パッケージを利用して、Sitecore のデータを取得します。
4.  **フォームデータの送信:** フォームデータを Sitecore に送信するための API エンドポイントを作成します。`@sitecore-jss/sitecore-jss-formbuilder` パッケージを利用して、フォームデータを処理します。
5.  **フォームのレンダリング:** Next.js コンポーネントで、フォームをレンダリングします。`@sitecore-jss/sitecore-jss-formbuilder` パッケージを利用して、フォーム要素を動的にレンダリングします。

**8.2.5. 実践的なテクニック**

*   **フォーム要素のスタイリング:** CSS フレームワーク（Tailwind CSS、Bootstrap など）を使用して、フォーム要素をスタイリングします。
*   **フォームのバリデーション:** フロントエンドでフォームのバリデーションを行い、ユーザーにリアルタイムでエラーメッセージを表示します。
*   **フォームの送信状態の表示:** フォームの送信中、送信成功、送信失敗などの状態をユーザーに分かりやすく表示します。
*   **エラーハンドリング:** フォームデータの送信時にエラーが発生した場合、適切なエラーメッセージを表示し、ユーザーに再試行を促します。

**8.2.6. 応用例とユースケース**

*   **シングルページアプリケーション (SPA) でのフォーム:** React、Angular、Vue.js などの SPA で、Sitecore のコンテンツ管理機能を活用したフォームを構築します。
*   **モバイルアプリでのフォーム:** React Native などのモバイルアプリ開発フレームワークで、Sitecore のフォームを利用します。
*   **チャットボットでのフォーム:** チャットボットのインターフェースで、Sitecore のフォームを利用して、ユーザーとのインタラクションを向上させます。

**8.2.7. トラブルシューティング**

*   **フォームがレンダリングされない:** Sitecore Context API が正しく設定されているか確認してください。また、API キーが正しいか確認してください。
*   **フォームデータが送信できない:** API エンドポイントが正しく設定されているか確認してください。また、CORS (Cross-Origin Resource Sharing) の設定が正しいか確認してください。
*   **エラーメッセージが表示されない:** フロントエンドのバリデーションロジックが正しいか確認してください。

**8.2.8. まとめと次のステップ**

Headless Forms は、フロントエンド技術との連携を強化し、より自由度の高いフォーム体験を実現するための強力なツールです。このセクションでは、Headless Forms の基本的な使い方と実践的なテクニックについて学びました。次のステップとして、カスタムフォーム要素を作成し、より高度なフォームのカスタマイズに挑戦しましょう。

**コード例（Next.js コンポーネント）：**

```javascript
import { useSitecoreContext } from '@sitecore-jss/sitecore-jss-nextjs';
import { FormRenderer } from '@sitecore-jss/sitecore-jss-formbuilder';
import { useState } from 'react';

const MyForm = () => {
  const { sitecoreContext } = useSitecoreContext();
  const [formData, setFormData] = useState(null);

  if (!sitecoreContext?.route?.fields?.form) {
    return <div>フォームが見つかりません。</div>;
  }

  const formDefinition = sitecoreContext.route.fields.form.value;

  const handleSubmit = async (data) => {
    try {
      // フォームデータを Sitecore に送信する処理
      const response = await fetch('/api/submit-form', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify(data),
      });

      if (response.ok) {
        setFormData('送信が完了しました。');
      } else {
        setFormData('送信に失敗しました。');
      }
    } catch (error) {
      console.error('エラー:', error);
      setFormData('送信中にエラーが発生しました。');
    }
  };

  return (
    <div>
      {formData ? (
        <div>{formData}</div>
      ) : (
        <FormRenderer formDefinition={formDefinition} onSubmit={handleSubmit} />
      )}
    </div>
  );
};

export default MyForm;
```

**コード例（API エンドポイント - `/pages/api/submit-form.js`）：**

```javascript
import { FormBuilder } from '@sitecore-jss/sitecore-jss-formbuilder';

export default async function handler(req, res) {
  if (req.method === 'POST') {
    try {
      const formData = req.body;

      // ここで Sitecore にフォームデータを送信する処理を実装します
      // 例: Sitecore API を使用してデータを保存する

      console.log('受信したフォームデータ:', formData);

      res.status(200).json({ message: 'フォームデータを受信しました' });
    } catch (error) {
      console.error('エラー:', error);
      res.status(500).json({ message: 'フォームデータの処理中にエラーが発生しました' });
    }
  } else {
    res.status(405).json({ message: '許可されていないメソッドです' });
  }
}
```

### 8.3. カスタムフォーム要素の作成

**8.3.1. 概要と重要性**

Sitecore Forms は、標準で豊富なフォーム要素を提供していますが、特定の要件に合わせてカスタムフォーム要素を作成することも可能です。カスタムフォーム要素を作成することで、フォームの機能を拡張し、より高度なデータ収集やインタラクションを実現できます。例えば、地図連携、画像アップロード、署名入力などのカスタム要素を作成できます。

**8.3.2. 特徴と利点**

*   **特定の要件への対応:** 標準のフォーム要素では実現できない機能を実装可能。
*   **独自のデザイン:** 企業のブランドイメージに合わせたデザインのフォーム要素を作成可能。
*   **データの高度な制御:** 特定の形式のデータを入力させるためのカスタムバリデーションを実装可能。
*   **再利用性:** 作成したカスタムフォーム要素を複数のフォームで再利用可能。
*   **拡張性:** 必要に応じてカスタムフォーム要素の機能を拡張可能。

**8.3.3. 事前準備と前提条件**

*   Sitecore XP がインストールされ、正常に動作していること。
*   Sitecore Forms モジュールがインストールされていること。
*   React などのフロントエンドフレームワークの知識があること。
*   Sitecore Content Editor の操作に慣れていること。

**8.3.4. 基本的な使い方**

1.  **Sitecore でのカスタムフォーム要素の定義:** Sitecore Content Editor で、`/sitecore/templates/System/Forms/Controls` などの場所にカスタムフォーム要素のテンプレートを定義します。テンプレートには、カスタムフォーム要素に必要なフィールド（ラベル、説明、バリデーションルールなど）を定義します。
2.  **React コンポーネントの作成:** React でカスタムフォーム要素をレンダリングするためのコンポーネントを作成します。コンポーネントは、Sitecore から渡されるデータに基づいて、適切な HTML 要素をレンダリングし、ユーザーからの入力を処理します。
3.  **Sitecore でのカスタムフォーム要素の登録:** Sitecore で、作成したカスタムフォーム要素を登録します。登録する際には、カスタムフォーム要素のテンプレートと React コンポーネントを関連付けます。
4.  **フォームへのカスタムフォーム要素の追加:** Sitecore Forms エディターで、作成したカスタムフォーム要素をフォームに追加します。

**8.3.5. 実践的なテクニック**

*   **カスタムバリデーションの実装:** React コンポーネントで、カスタムバリデーションロジックを実装し、入力されたデータが正しい形式であることを確認します。
*   **エラーハンドリング:** バリデーションエラーが発生した場合、適切なエラーメッセージを表示し、ユーザーに再試行を促します。
*   **データのバインディング:** React コンポーネントで、ユーザーからの入力をフォームデータにバインドします。
*   **スタイリング:** CSS フレームワーク（Tailwind CSS、Bootstrap など）を使用して、カスタムフォーム要素をスタイリングします。

**8.3.6. 応用例とユースケース**

*   **地図連携フォーム要素:** Google Maps API などを利用して、地図上で場所を選択できるフォーム要素を作成します。
*   **画像アップロードフォーム要素:** 画像をアップロードできるフォーム要素を作成します。アップロードされた画像は、Sitecore Media Library に保存できます。
*   **署名入力フォーム要素:** デジタル署名を入力できるフォーム要素を作成します。
*   **評価 (Rating) フォーム要素:** 星の数や数値で評価を入力できるフォーム要素を作成します。

**8.3.7. トラブルシューティング**

*   **カスタムフォーム要素が表示されない:** Sitecore での登録が正しいか確認してください。また、React コンポーネントが正しくレンダリングされているか確認してください。
*   **バリデーションが機能しない:** React コンポーネントのバリデーションロジックが正しいか確認してください。
*   **データが保存されない:** フォームデータのバインディングが正しいか確認してください。

**8.3.8. まとめと次のステップ**

カスタムフォーム要素を作成することで、Sitecore Forms の機能を拡張し、より高度なフォームのカスタマイズを実現できます。このセクションでは、カスタムフォーム要素の基本的な使い方と実践的なテクニックについて学びました。次のステップとして、フォームデータを CRM システムに連携し、Sitecore Analytics を使用してフォームデータの分析を行いましょう。

**コード例（React コンポーネント）：**

```javascript
import React, { useState } from 'react';

const MyCustomField = ({ field }) => {
  const [value, setValue] = useState('');

  const handleChange = (event) => {
    setValue(event.target.value);
    // フォームデータの更新処理を実装
    field.setValue(event.target.value); // Sitecore Forms へのデータバインド
  };

  return (
    <div>
      <label htmlFor={field.id}>{field.label}</label>
      <input
        type="text"
        id={field.id}
        value={value}
        onChange={handleChange}
        placeholder={field.placeholder}
      />
      {field.errorMessage && <div className="error">{field.errorMessage}</div>}
    </div>
  );
};

export default MyCustomField;
```

**設定例（Sitecore テンプレート）：**

1.  `/sitecore/templates/System/Forms/Controls` にテンプレートを作成（例: `My Custom Field`）
2.  テンプレートに以下のフィールドを追加
    *   `Label` (Single-Line Text)
    *   `Placeholder` (Single-Line Text)
    *   `Validation` (Droplist - バリデーションルールを定義したアイテムへの参照)

### 8.4. フォームデータの連携と分析

**8.4.1. 概要と重要性**

フォームを通じて収集したデータは、マーケティング活動の改善や顧客理解の深化に役立ちます。Sitecore Forms で収集したデータを CRM (Customer Relationship Management) システムに連携することで、営業活動の効率化や顧客とのエンゲージメント向上に貢献できます。また、Sitecore Analytics を使用してフォームデータの分析を行うことで、フォームのパフォーマンスを評価し、改善点を特定できます。

**8.4.2. 特徴と利点**

*   **CRM 連携:** フォームデータを CRM システムに自動的に連携することで、営業担当者の負担を軽減し、リードの迅速なフォローアップを実現。
*   **顧客情報の統合:** フォームデータと CRM システムの顧客情報を統合することで、顧客プロファイルを充実させ、パーソナライズされたマーケティングを実現。
*   **Sitecore Analytics:** フォームの利用状況、コンバージョン率、エラー発生状況などを分析し、フォームの改善点を特定。
*   **A/B テスト:** フォームの異なるバージョンをテストし、コンバージョン率の高いデザインやコンテンツを特定。
*   **レポート作成:** フォームデータの分析結果をレポートとして出力し、マーケティング戦略の策定に役立てる。

**8.4.3. 事前準備と前提条件**

*   Sitecore XP がインストールされ、正常に動作していること。
*   Sitecore Forms モジュールがインストールされていること。
*   Sitecore Analytics が設定され、有効になっていること。
*   連携する CRM システムへのアクセス権があること。
*   Sitecore Connect やカスタム API などの連携ツールが設定されていること。

**8.4.4. 基本的な使い方**

1.  **CRM 連携の設定:** Sitecore Connect などの連携ツールを使用して、Sitecore Forms と CRM システム間のデータ連携を設定します。連携の設定には、データマッピング、トリガー条件、エラーハンドリングなどが含まれます。
2.  **Sitecore Analytics の設定:** Sitecore Analytics で、フォームのイベントを追跡するように設定します。追跡するイベントには、フォームの表示、フォームの送信、フォームのエラーなどがあります。
3.  **レポートの作成:** Sitecore Analytics で、フォームデータの分析結果をレポートとして作成します。レポートには、フォームの利用状況、コンバージョン率、エラー発生状況などが含まれます。
4.  **A/B テストの実施:** Sitecore で、フォームの異なるバージョンを作成し、A/B テストを実施します。A/B テストの結果を分析し、コンバージョン率の高いデザインやコンテンツを特定します。

**8.4.5. 実践的なテクニック**

*   **カスタムレポートの作成:** Sitecore Analytics で、標準のレポートでは提供されない情報を表示するためのカスタムレポートを作成します。
*   **セグメンテーション:** Sitecore Analytics で、フォームデータを特定の属性を持つ顧客グループにセグメント化し、セグメントごとの傾向を分析します。
*   **パーソナライゼーション:** フォームデータに基づいて、顧客にパーソナライズされたコンテンツを表示します。

**8.4.6. 応用例とユースケース**

*   **営業活動の効率化:** フォームから収集したリード情報を CRM システムに連携し、営業担当者に自動的に割り当てます。
*   **顧客とのエンゲージメント向上:** フォームデータに基づいて、顧客にパーソナライズされたメールを送信します。
*   **フォームの改善:** フォームの利用状況やコンバージョン率を分析し、フォームの改善点を特定します。

**8.4.7. トラブルシューティング**

*   **CRM にデータが連携されない:** Sitecore Connect などの連携ツールの設定が正しいか確認してください。また、連携先の CRM システムの API が正常に動作しているか確認してください。
*   **Sitecore Analytics でデータが追跡されない:** Sitecore Analytics の設定が正しいか確認してください。また、フォームのイベントが正しくトリガーされているか確認してください。
*   **レポートが正しく表示されない:** Sitecore Analytics のレポート設定が正しいか確認してください。

**8.4.8. まとめ**

フォームデータの連携と分析は、マーケティング活動の改善や顧客理解の深化に不可欠です。Sitecore Forms で収集したデータを CRM システムに連携し、Sitecore Analytics を使用してフォームデータの分析を行うことで、より効果的なマーケティング戦略を策定できます。
