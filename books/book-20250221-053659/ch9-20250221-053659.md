## 第9章：プレースホルダーとレイアウト

Sitecoreにおけるプレースホルダーとレイアウトは、コンテンツの表示を制御し、柔軟なページ構築を実現するための基盤となる要素です。この章では、これらの概念を深く理解し、実践的なスキルを身につけることを目指します。プレースホルダーの基本的な使い方から、レスポンシブなカスタムレイアウトの作成まで、具体的なコード例と詳細な解説を通して、Sitecore開発のスキルアップを支援します。

### 9.1. プレースホルダーの概念と利用

#### 概要と重要性

プレースホルダーは、Sitecoreにおけるコンテンツ配置の「場所」を定義するものです。テンプレートやレイアウト上に定義され、レンダリングされるコンポーネントを動的に配置するための枠組みを提供します。これにより、コンテンツ作成者は、事前に定義された範囲内で自由にコンテンツを配置し、ページの見た目を柔軟に調整できます。

#### 特徴と利点

*   **動的なコンテンツ配置:** コンテンツエディタは、プレースホルダーにコンポーネントをドラッグ＆ドロップすることで、ページのレイアウトをリアルタイムに調整できます。
*   **再利用性:** プレースホルダーは複数のテンプレートやレイアウトで再利用できます。
*   **柔軟性:** デフォルトのプレースホルダーだけでなく、カスタムプレースホルダーを作成することで、特定のコンポーネントのみを配置可能な領域を定義できます。
*   **拡張性:** プレースホルダーの設定を通じて、コンポーネントの表示順序や表示条件を制御できます。

#### 事前準備と前提条件

*   Sitecoreインスタンスへのアクセス権
*   Sitecore Content Editorの基本的な操作スキル
*   Reactコンポーネントの基本的な知識（Reactコンポーネントを利用する場合）

#### 基本的な使い方

1.  **プレースホルダーの定義 (Sitecore Content Editor):**
    *   `/sitecore/layout/Placeholder Settings`配下に新しいプレースホルダーアイテムを作成します。
    *   `Allowed Controls` フィールドで、このプレースホルダーに配置できるコンポーネントのリストを指定します。 空白の場合は、すべてのコンポーネントが許可されます。
    *   `Editable` チェックボックスをオンにすると、エクスペリエンスエディターで編集可能になります。

    ```xml
    <placeholder name="main-content" editable="true" allowedControls="{GUID-of-Component1},{GUID-of-Component2}" />
    ```

2.  **レイアウトへのプレースホルダーの追加 (React コンポーネント):**

    Reactコンポーネント内で `<Placeholder>` タグを使用してプレースホルダーを配置します。

    ```jsx
    import { Placeholder } from '@sitecore-jss/sitecore-jss-react';

    const MyLayout = () => {
      return (
        <div>
          <h1>My Awesome Layout</h1>
          <Placeholder name="main-content" rendering={rendering} />
        </div>
      );
    };

    export default MyLayout;
    ```

    `rendering` プロパティは、Sitecoreから渡される現在のレンダリングコンテキストです。

3.  **コンテンツアイテムへのレイアウトの適用 (Sitecore Content Editor):**
    *   コンテンツアイテムを選択し、Presentationタブを開きます。
    *   `Details`をクリックし、`Layout`フィールドで作成したレイアウトを選択します。
    *   エクスペリエンスエディターでコンテンツアイテムを開き、`main-content`プレースホルダーにコンポーネントをドラッグ＆ドロップします。

#### 実践的なテクニック

*   **条件付きプレースホルダー:** プレースホルダーの設定を利用して、特定の条件（例えば、ユーザーの役割、デバイスの種類）に基づいて異なるコンポーネントを表示できます。 これには、ルールエンジンを使用します。
*   **ネストされたプレースホルダー:** プレースホルダー内に別のプレースホルダーを配置することで、より複雑なレイアウト構造を構築できます。 例えば、サイドバーの中に複数のコンポーネントを配置するためのプレースホルダーを定義できます。
*   **プレースホルダー設定のテンプレート:** プレースホルダー設定のテンプレートを作成し、複数のプレースホルダーで共通の設定を再利用できます。

#### 応用例とユースケース

*   **ホームページのヒーローセクション:** ヒーローセクションにテキスト、画像、動画などのコンポーネントを動的に配置できるように、専用のプレースホルダーを定義します。
*   **ブログ記事のコンテンツエリア:** ブログ記事のコンテンツエリアに、テキスト、画像、埋め込みコンテンツ（動画、ソーシャルメディア投稿など）を自由に配置できるように、プレースホルダーを定義します。
*   **ランディングページのセクション:** ランディングページの各セクション（紹介、機能、料金、事例など）に、それぞれ専用のプレースホルダーを定義し、コンテンツの順序や内容を柔軟に調整できるようにします。

#### トラブルシューティング

*   **プレースホルダーが表示されない:**
    *   レイアウトにプレースホルダーが正しく定義されているか確認します。
    *   コンテンツアイテムに正しいレイアウトが適用されているか確認します。
    *   プレースホルダーの名前が、Reactコンポーネント内で使用されている名前と一致しているか確認します。
*   **特定のコンポーネントがプレースホルダーに配置できない:**
    *   プレースホルダーの設定 (`Allowed Controls`フィールド) で、そのコンポーネントが許可されているか確認します。
*   **エクスペリエンスエディターでプレースホルダーが編集できない:**
    *   プレースホルダーの設定 (`Editable`チェックボックス) がオンになっているか確認します。

#### まとめと次のステップ

プレースホルダーは、Sitecoreにおけるコンテンツの柔軟性と再利用性を高めるための強力なツールです。このセクションで学んだ知識を基に、様々なプレースホルダーを試して、実践的なスキルを向上させましょう。次のステップでは、レイアウトの設計と実装について詳しく解説します。

### 9.2. レイアウトの設計と実装

#### 概要と重要性

レイアウトは、Webページの全体的な構造とデザインを定義するものです。Sitecoreでは、レイアウトアイテムを作成し、そこにプレースホルダーを配置することで、ページの基本的な骨組みを構築します。適切なレイアウト設計は、ユーザーエクスペリエンスの向上、コンテンツの可読性の向上、そしてWebサイト全体の整合性の維持に不可欠です。

#### 特徴と利点

*   **Webサイト全体の統一感:** レイアウトを適切に設計することで、Webサイト全体のデザインと構造に統一感を持たせることができます。
*   **レスポンシブデザイン:** レスポンシブデザインに対応したレイアウトを作成することで、様々なデバイス（デスクトップ、タブレット、スマートフォン）で最適な表示を実現できます。
*   **再利用性:** 複数のページで共通のレイアウトを再利用できます。
*   **メンテナンス性:** レイアウトを変更するだけで、Webサイト全体の構造を簡単に変更できます。

#### 事前準備と前提条件

*   Sitecoreインスタンスへのアクセス権
*   Sitecore Content Editorの基本的な操作スキル
*   HTML, CSS, JavaScriptの基本的な知識
*   Reactコンポーネントの基本的な知識

#### 基本的な使い方

1.  **レイアウトアイテムの作成 (Sitecore Content Editor):**
    *   `/sitecore/layout/Layouts`配下に新しいレイアウトアイテムを作成します。 テンプレートは通常「Layout」を使用します。
    *   `Path`フィールドに、レイアウトを定義するReactコンポーネントまたはASP.NET MVCビューへのパスを指定します。

2.  **レイアウトの定義 (React コンポーネント):**

    Reactコンポーネント内で、ページの基本的なHTML構造を定義し、プレースホルダーを配置します。

    ```jsx
    import React from 'react';
    import { Placeholder } from '@sitecore-jss/sitecore-jss-react';

    const MyLayout = ({ rendering }) => {
      return (
        <div className="container">
          <header>
            <h1>My Awesome Website</h1>
          </header>
          <main>
            <Placeholder name="main-content" rendering={rendering} />
          </main>
          <footer>
            <p>© 2023 My Awesome Website</p>
          </footer>
        </div>
      );
    };

    export default MyLayout;
    ```

3.  **コンテンツアイテムへのレイアウトの適用 (Sitecore Content Editor):**
    *   コンテンツアイテムを選択し、Presentationタブを開きます。
    *   `Details`をクリックし、`Layout`フィールドで作成したレイアウトを選択します。

#### 実践的なテクニック

*   **レイアウトの継承:** 親レイアウトを継承することで、複数のレイアウトで共通の構造を再利用できます。例えば、Webサイト全体の共通ヘッダーとフッターを持つベースレイアウトを作成し、各ページのレイアウトがそれを継承するようにします。 Sitecoreの標準の値を使用することで実現できます。
*   **レスポンシブデザイン:** CSSメディアクエリを使用して、画面サイズに応じてレイアウトを調整します。
*   **レイアウトのバリエーション:** 複数のレイアウトを作成し、コンテンツアイテムの種類や目的に応じて異なるレイアウトを適用します。 例えば、ホームページ、ブログ記事、ランディングページなど、それぞれ専用のレイアウトを作成します。

#### 応用例とユースケース

*   **Webサイト全体の標準レイアウト:** Webサイト全体の標準レイアウトを作成し、共通ヘッダー、フッター、ナビゲーションメニューなどを定義します。
*   **ブログ記事のレイアウト:** ブログ記事専用のレイアウトを作成し、タイトル、著者、日付、コンテンツエリア、コメントセクションなどを配置します。
*   **ランディングページのレイアウト:** ランディングページ専用のレイアウトを作成し、ヒーローセクション、紹介、機能、料金、事例、CTA（Call to Action）などを配置します。

#### トラブルシューティング

*   **レイアウトが適用されない:**
    *   コンテンツアイテムに正しいレイアウトが適用されているか確認します。
    *   `Path`フィールドに正しいReactコンポーネントまたはASP.NET MVCビューへのパスが指定されているか確認します。
*   **レスポンシブデザインが正しく機能しない:**
    *   CSSメディアクエリが正しく定義されているか確認します。
    *   viewportの設定が正しく行われているか確認します。 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`

#### まとめと次のステップ

レイアウトは、Webサイトの構造とデザインを定義するための重要な要素です。このセクションで学んだ知識を基に、様々なレイアウトを試して、レスポンシブデザインに対応した魅力的なWebサイトを構築しましょう。次のステップでは、グリッドレイアウトとFlexboxレイアウトの活用について詳しく解説します。

### 9.3. グリッドレイアウトとFlexboxレイアウトの活用

#### 概要と重要性

グリッドレイアウトとFlexboxレイアウトは、Webページのレイアウトを柔軟かつ効率的に制御するためのCSSの強力なツールです。これらのレイアウトモデルを使用することで、複雑なレイアウトを簡単に作成し、レスポンシブデザインを実現できます。

#### 特徴と利点

*   **グリッドレイアウト:**
    *   2次元のレイアウトに適しており、行と列を組み合わせて、要素を配置できます。
    *   複雑なレイアウトを簡単に作成できます。
    *   レスポンシブデザインに対応しやすく、画面サイズに応じて要素の配置を柔軟に調整できます。
*   **Flexboxレイアウト:**
    *   1次元のレイアウトに適しており、要素を水平方向または垂直方向に配置できます。
    *   要素の配置、整列、サイズ調整を柔軟に行えます。
    *   レスポンシブデザインに対応しやすく、画面サイズに応じて要素の配置を柔軟に調整できます。

#### 事前準備と前提条件

*   Sitecoreインスタンスへのアクセス権
*   Sitecore Content Editorの基本的な操作スキル
*   HTML, CSS, JavaScriptの基本的な知識

#### 基本的な使い方

1.  **グリッドレイアウト:**

    ```css
    .grid-container {
      display: grid;
      grid-template-columns: repeat(3, 1fr); /* 3つの等幅の列 */
      grid-gap: 20px; /* 列と行の間の間隔 */
    }

    .grid-item {
      background-color: #f2f2f2;
      padding: 20px;
    }
    ```

    HTML:

    ```html
    <div class="grid-container">
      <div class="grid-item">Item 1</div>
      <div class="grid-item">Item 2</div>
      <div class="grid-item">Item 3</div>
      <div class="grid-item">Item 4</div>
      <div class="grid-item">Item 5</div>
      <div class="grid-item">Item 6</div>
    </div>
    ```

2.  **Flexboxレイアウト:**

    ```css
    .flex-container {
      display: flex;
      flex-direction: row; /* 要素を水平方向に配置 */
      justify-content: space-between; /* 要素を両端揃えに配置 */
      align-items: center; /* 要素を垂直方向の中央に配置 */
    }

    .flex-item {
      background-color: #f2f2f2;
      padding: 20px;
    }
    ```

    HTML:

    ```html
    <div class="flex-container">
      <div class="flex-item">Item 1</div>
      <div class="flex-item">Item 2</div>
      <div class="flex-item">Item 3</div>
    </div>
    ```

#### 実践的なテクニック

*   **レスポンシブデザイン:** メディアクエリを使用して、画面サイズに応じてグリッドレイアウトとFlexboxレイアウトを調整します。

    ```css
    /* 画面幅が768px以下の場合 */
    @media (max-width: 768px) {
      .grid-container {
        grid-template-columns: repeat(1, 1fr); /* 1つの列 */
      }

      .flex-container {
        flex-direction: column; /* 要素を垂直方向に配置 */
      }
    }
    ```

*   **グリッドレイアウトの応用:** `grid-template-areas`プロパティを使用すると、より複雑なレイアウトを視覚的に定義できます。
*   **Flexboxレイアウトの応用:** `flex-grow`、`flex-shrink`、`flex-basis`プロパティを使用すると、要素のサイズ調整をより柔軟に行えます。

#### 応用例とユースケース

*   **Webサイトのヘッダー:** Flexboxレイアウトを使用して、ロゴ、ナビゲーションメニュー、検索ボックスなどを水平方向に配置します。
*   **Webサイトのフッター:** Flexboxレイアウトを使用して、著作権表示、ソーシャルメディアアイコン、プライバシーポリシーへのリンクなどを水平方向に配置します。
*   **製品リスト:** グリッドレイアウトを使用して、製品をグリッド状に配置します。
*   **ブログ記事のレイアウト:** グリッドレイアウトを使用して、コンテンツエリア、サイドバー、関連する記事などを配置します。

#### トラブルシューティング

*   **レイアウトが正しく表示されない:**
    *   CSSが正しく適用されているか確認します。
    *   HTMLの構造が正しいか確認します。
    *   ブラウザの開発者ツールを使用して、CSSの競合やエラーがないか確認します。
*   **レスポンシブデザインが正しく機能しない:**
    *   メディアクエリが正しく定義されているか確認します。
    *   viewportの設定が正しく行われているか確認します。

#### まとめと次のステップ

グリッドレイアウトとFlexboxレイアウトは、Webページのレイアウトを柔軟かつ効率的に制御するための重要なツールです。このセクションで学んだ知識を基に、様々なレイアウトを試して、レスポンシブデザインに対応した魅力的なWebサイトを構築しましょう。次のステップでは、カスタムレイアウトの作成と適用について詳しく解説します。

### 9.4. カスタムレイアウトの作成と適用

#### 概要と重要性

Sitecoreにはデフォルトでいくつかのレイアウトが用意されていますが、Webサイトのデザインや機能要件に合わせて、独自のカスタムレイアウトを作成することも可能です。カスタムレイアウトを作成することで、より柔軟なコンテンツ表示が可能になり、ブランドイメージに合ったWebサイトを構築できます。

#### 特徴と利点

*   **デザインの自由度:** デフォルトのレイアウトにとらわれず、独自のレイアウトを作成できます。
*   **機能の拡張性:** レイアウトに独自の機能（例えば、JavaScriptによるインタラクション）を追加できます。
*   **ブランドイメージの強化:** ブランドイメージに合ったデザインのレイアウトを作成できます。

#### 事前準備と前提条件

*   Sitecoreインスタンスへのアクセス権
*   Sitecore Content Editorの基本的な操作スキル
*   HTML, CSS, JavaScriptの基本的な知識
*   Reactコンポーネントの基本的な知識

#### 基本的な使い方

1.  **レイアウトアイテムの作成 (Sitecore Content Editor):**
    *   `/sitecore/layout/Layouts`配下に新しいレイアウトアイテムを作成します。 テンプレートは通常「Layout」を使用します。
    *   `Path`フィールドに、レイアウトを定義するReactコンポーネントまたはASP.NET MVCビューへのパスを指定します。

2.  **レイアウトの定義 (React コンポーネント):**

    Reactコンポーネント内で、独自のHTML構造とCSSスタイルを定義し、プレースホルダーを配置します。

    ```jsx
    import React from 'react';
    import { Placeholder } from '@sitecore-jss/sitecore-jss-react';

    const MyCustomLayout = ({ rendering }) => {
      return (
        <div className="my-custom-layout">
          <header className="my-custom-header">
            <h1>My Custom Website</h1>
          </header>
          <main className="my-custom-main">
            <Placeholder name="main-content" rendering={rendering} />
          </main>
          <footer className="my-custom-footer">
            <p>© 2023 My Custom Website</p>
          </footer>
        </div>
      );
    };

    export default MyCustomLayout;
    ```

    CSS:

    ```css
    .my-custom-layout {
      font-family: sans-serif;
      color: #333;
    }

    .my-custom-header {
      background-color: #eee;
      padding: 20px;
      text-align: center;
    }

    .my-custom-main {
      padding: 20px;
    }

    .my-custom-footer {
      background-color: #eee;
      padding: 20px;
      text-align: center;
    }
    ```

3.  **コンテンツアイテムへのレイアウトの適用 (Sitecore Content Editor):**
    *   コンテンツアイテムを選択し、Presentationタブを開きます。
    *   `Details`をクリックし、`Layout`フィールドで作成したカスタムレイアウトを選択します。
    *   エクスペリエンスエディターでコンテンツアイテムを開き、カスタムレイアウトが適用されていることを確認します。

#### 実践的なテクニック

*   **レイアウトパラメータ:** レイアウトパラメータを使用すると、コンテンツエディタからレイアウトの表示方法を調整できます。 例えば、背景色、フォントサイズ、マージンなどをパラメータとして定義し、コンテンツエディタで値を変更できるようにします。
*   **コンポーネントパラメータ:** コンポーネントパラメータを使用すると、コンポーネントの表示方法をレイアウト内で調整できます。 例えば、画像のサイズ、テキストの色、ボタンのスタイルなどをパラメータとして定義し、レイアウト内で値を変更できるようにします。

#### 応用例とユースケース

*   **ブランドイメージに合わせたレイアウト:** ブランドカラー、フォント、ロゴなどを組み込んだカスタムレイアウトを作成し、ブランドイメージを強化します。
*   **特定のコンテンツタイプに合わせたレイアウト:** 特定のコンテンツタイプ（例えば、製品ページ、イベントページ、事例紹介ページ）専用のカスタムレイアウトを作成し、最適な情報表示を実現します。
*   **A/Bテスト用のレイアウト:** A/Bテスト用に複数のカスタムレイアウトを作成し、どのレイアウトが最も効果的か検証します。

#### トラブルシューティング

*   **カスタムレイアウトが適用されない:**
    *   コンテンツアイテムに正しいカスタムレイアウトが適用されているか確認します。
    *   `Path`フィールドに正しいReactコンポーネントまたはASP.NET MVCビューへのパスが指定されているか確認します。
*   **レイアウトのスタイルが正しく適用されない:**
    *   CSSが正しく適用されているか確認します。
    *   CSSの優先順位が正しく設定されているか確認します。
    *   ブラウザの開発者ツールを使用して、CSSの競合やエラーがないか確認します。
*   **レイアウトパラメータが正しく機能しない:**
    *   レイアウトパラメータが正しく定義されているか確認します。
    *   レイアウトパラメータの値が正しく設定されているか確認します。

#### まとめと次のステップ

カスタムレイアウトを作成することで、Sitecoreの柔軟性を最大限に活用し、Webサイトのデザインと機能を自由に制御できます。このセクションで学んだ知識を基に、様々なカスタムレイアウトを試して、ブランドイメージに合った魅力的なWebサイトを構築しましょう。

この章では、Sitecoreにおけるプレースホルダーとレイアウトの概念、基本的な使い方、実践的なテクニック、応用例、トラブルシューティングについて解説しました。これらの知識を基に、より高度なSitecore開発に挑戦し、素晴らしいWebサイトを構築してください。
