## 第2章: アニメーションとインタラクション - ユーザーを引き込む表現

3D空間にオブジェクトを表示するだけでは、静的で退屈な印象を与えてしまうかもしれません。アニメーションとインタラクションを加えることで、ユーザーはより深く3Dの世界に没入し、直感的に操作できるようになります。本章では、Three.jsでアニメーションとインタラクションを実装するための基本的なテクニックと、より高度な制御方法について解説します。

### 3.1 アニメーションの基本 - フレームレート、Tween.jsの活用

#### 概要と重要性

アニメーションは、オブジェクトを動かすことで視覚的な変化を生み出し、ユーザーの注意を引きつけ、情報伝達を効果的にする重要な要素です。スムーズなアニメーションは、ユーザーエクスペリエンスを向上させるだけでなく、3D空間のリアリティを高めることにも繋がります。

#### 特徴と利点

*   **視覚的な魅力の向上:** オブジェクトの動きは、静的なシーンよりもずっと魅力的です。
*   **情報伝達の強化:** アニメーションは、オブジェクトの状態変化や、空間的な関係性を視覚的に表現するのに役立ちます。
*   **インタラクションの自然さ:** ユーザーの操作に対するフィードバックとしてアニメーションを利用することで、より自然なインタラクションを実現できます。

#### 事前準備と前提条件

*   Three.jsの基本的な知識（シーン、カメラ、レンダラー、オブジェクトの追加など）
*   HTML、CSS、JavaScriptの基本的な知識

#### 基本的な使い方

**1. requestAnimationFrameによるアニメーションループ**

Three.jsでアニメーションを実現する最も基本的な方法は、`requestAnimationFrame`関数を使用することです。この関数は、ブラウザの描画サイクルに合わせて、指定された関数を呼び出します。これにより、滑らかで効率的なアニメーションループを作成できます。

```javascript
function animate() {
  requestAnimationFrame(animate);

  // ここにアニメーション処理を記述します。
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  renderer.render(scene, camera);
}

animate();
```

このコードは、毎フレームキューブを少しずつ回転させるアニメーションを作成します。`cube.rotation.x += 0.01;`と`cube.rotation.y += 0.01;`が回転の処理を担っており、`renderer.render(scene, camera);`がシーンを描画しています。

**2. Tween.jsによるスムーズなアニメーション**

`requestAnimationFrame`だけでも簡単なアニメーションは作成できますが、より複雑で自然な動きを実現するには、Tween.jsのようなアニメーションライブラリを使用するのがおすすめです。Tween.jsは、オブジェクトのプロパティ値を、指定された時間で、特定の方法（イージング関数）で変化させる機能を提供します。

まず、Tween.jsをプロジェクトに導入します。CDNを利用するか、npmなどでインストールできます。

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/tween.js/18.6.4/tween.umd.js"></script>
```

次に、Tween.jsを使用してアニメーションを作成します。

```javascript
import TWEEN from '@tweenjs/tween.js' // もし npm でインストールした場合

const target = { x: 0, y: 0, z: 0 };
const tween = new TWEEN.Tween(target)
  .to({ x: 5, y: 3, z: 10 }, 2000) // 2秒かけて目標値まで変化
  .easing(TWEEN.Easing.Quadratic.InOut) // イージング関数を指定
  .onUpdate(() => {
    cube.position.x = target.x;
    cube.position.y = target.y;
    cube.position.z = target.z;
  })
  .start();

function animate() {
  requestAnimationFrame(animate);

  TWEEN.update(); // Tween.jsのアニメーションを更新

  renderer.render(scene, camera);
}

animate();
```

このコードは、キューブの位置を2秒かけて(0,0,0)から(5,3,10)までスムーズに移動させるアニメーションを作成します。`easing`関数は、アニメーションの速度変化を制御します。`Quadratic.InOut`は、アニメーションの最初と最後に減速するイージングです。

**3. アニメーションの制御 (再生、停止、一時停止)**

Tween.jsでは、アニメーションの開始、停止、一時停止を簡単に制御できます。

```javascript
tween.start(); // アニメーションを開始
tween.stop();  // アニメーションを停止
```

アニメーションを一時停止させるには、アニメーションループ内で`TWEEN.update()`を呼び出さないようにします。再開するには、再度`TWEEN.update()`を呼び出すようにします。

#### 実践的なテクニック

*   **イージング関数の選択:** Tween.jsには様々なイージング関数が用意されています。アニメーションの目的に合わせて適切なイージング関数を選択することで、より自然で心地よい動きを実現できます。
*   **チェーンアニメーション:** 複数のTweenをチェーンさせることで、複雑なアニメーションシーケンスを作成できます。`.chain(nextTween)`メソッドを使用します。
*   **アニメーションのループ:** Tweenを繰り返すには、`.repeat(Infinity)`メソッドを使用します。

#### 応用例とユースケース

*   **ローディングアニメーション:** 3Dモデルのロード中に、回転するオブジェクトや、プログレスバーを表示するアニメーションを作成します。
*   **トランジションアニメーション:** シーンの切り替え時に、フェードイン/フェードアウトや、スライドイン/スライドアウトなどのアニメーションを使用します。
*   **インタラクティブなアニメーション:** ユーザーの操作に応じて、オブジェクトの色を変えたり、拡大縮小させたりするアニメーションを作成します。

#### トラブルシューティング

*   **アニメーションがカクカクする:** フレームレートが低い可能性があります。`requestAnimationFrame`を使用しているか確認し、必要に応じてパフォーマンスを最適化します。
*   **Tween.jsが動作しない:** Tween.jsが正しく導入されているか確認し、`TWEEN.update()`がアニメーションループ内で呼び出されているか確認します。
*   **イージングが期待通りに動作しない:** イージング関数の種類が適切でない可能性があります。別のイージング関数を試してみるか、カスタムイージング関数を作成します。

### 3.2 インタラクション - マウスイベント、キーボードイベントの処理

#### 概要と重要性

インタラクションは、ユーザーが3D空間と対話するための手段を提供します。マウスやキーボードの入力に基づいてオブジェクトを操作したり、視点を変更したりすることで、ユーザーはより積極的に3Dの世界に参加できるようになります。

#### 特徴と利点

*   **没入感の向上:** ユーザー自身が3D空間を操作することで、より深く世界に没入できます。
*   **操作性の向上:** 直感的な操作を提供することで、ユーザーエクスペリエンスを向上させることができます。
*   **情報伝達の強化:** ユーザーの操作に応じて情報を表示したり、オブジェクトの状態を変化させることで、インタラクティブな情報伝達を実現できます。

#### 事前準備と前提条件

*   HTML、CSS、JavaScriptの基本的な知識
*   Three.jsの基本的な知識（シーン、カメラ、レンダラー、オブジェクトの追加など）
*   イベントリスナーの基本的な知識

#### 基本的な使い方

**1. Raycasterによるオブジェクトの選択**

Raycasterは、マウスカーソルの位置から光線（Ray）を飛ばし、その光線と交差するオブジェクトを検出する機能を提供します。これを利用して、マウスでクリックされたオブジェクトを特定できます。

```javascript
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

window.addEventListener('click', (event) => {
  // マウス座標を正規化
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

  // Raycasterの光線を更新
  raycaster.setFromCamera(mouse, camera);

  // 光線と交差するオブジェクトを検出
  const intersects = raycaster.intersectObjects(scene.children);

  if (intersects.length > 0) {
    // 最初に交差したオブジェクト
    const selectedObject = intersects[0].object;
    console.log('クリックされたオブジェクト:', selectedObject);

    // オブジェクトに対する処理 (例: 色を変える)
    selectedObject.material.color.set(0xff0000);
  }
});
```

このコードは、クリックされたオブジェクトを特定し、その色を赤色に変更します。`raycaster.setFromCamera(mouse, camera);`でRaycasterの光線を設定し、`raycaster.intersectObjects(scene.children);`で光線と交差するオブジェクトを検出します。

**2. マウスドラッグによるオブジェクトの移動**

マウスドラッグによってオブジェクトを移動させるには、`mousedown`、`mousemove`、`mouseup`イベントを処理する必要があります。

```javascript
let isDragging = false;
let selectedObject = null;

window.addEventListener('mousedown', (event) => {
  // Raycasterでオブジェクトを選択
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObjects(scene.children);

  if (intersects.length > 0) {
    isDragging = true;
    selectedObject = intersects[0].object;
    // オフセットを計算（オブジェクトの中心からのずれ）
    const intersectsOffset = intersects[0].point;
    offset = new THREE.Vector3().copy(selectedObject.position).sub(intersectsOffset)
  }
});

window.addEventListener('mousemove', (event) => {
  if (isDragging && selectedObject) {
    // マウス座標を正規化
    mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
    mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

    // Raycasterの光線を更新
    raycaster.setFromCamera(mouse, camera);

    // 平面を作成し、光線と交差する点を計算
    const plane = new THREE.Plane(new THREE.Vector3(0, 1, 0), 0); // Y軸に沿った平面
    const intersectPoint = new THREE.Vector3();
    raycaster.ray.intersectPlane(plane, intersectPoint);

    // オブジェクトの位置を更新
    selectedObject.position.copy(intersectPoint.add(offset));
  }
});

window.addEventListener('mouseup', (event) => {
  isDragging = false;
  selectedObject = null;
});
```

このコードは、マウスドラッグによってオブジェクトをX-Z平面上で移動させます。`mousedown`イベントでオブジェクトを選択し、`mousemove`イベントでオブジェクトの位置を更新し、`mouseup`イベントでドラッグを終了します。

**3. キーボード入力によるカメラ制御**

キーボード入力によってカメラを制御するには、`keydown`と`keyup`イベントを処理する必要があります。

```javascript
const keys = {};

window.addEventListener('keydown', (event) => {
  keys[event.key] = true;
});

window.addEventListener('keyup', (event) => {
  keys[event.key] = false;
});

function updateCameraPosition() {
  const moveSpeed = 0.1; // 移動速度

  if (keys['w']) {
    camera.position.z -= moveSpeed;
  }
  if (keys['s']) {
    camera.position.z += moveSpeed;
  }
  if (keys['a']) {
    camera.position.x -= moveSpeed;
  }
  if (keys['d']) {
    camera.position.x += moveSpeed;
  }
  if (keys[' ']) {
    camera.position.y += moveSpeed; // スペースキーで上昇
  }
  if (keys['Shift']) {
    camera.position.y -= moveSpeed; // シフトキーで下降
  }
}

function animate() {
  requestAnimationFrame(animate);

  updateCameraPosition();

  renderer.render(scene, camera);
}

animate();
```

このコードは、W/A/S/Dキーでカメラを前後左右に移動させ、スペースキーで上昇、シフトキーで下降させます。`keydown`イベントで押されたキーを記録し、`keyup`イベントで離されたキーを記録します。`updateCameraPosition`関数で、押されているキーに基づいてカメラの位置を更新します。

#### 実践的なテクニック

*   **イベントリスナーの最適化:** イベントリスナーを大量に追加すると、パフォーマンスが低下する可能性があります。イベントデリゲーションを利用したり、不要なイベントリスナーを削除したりすることで、パフォーマンスを最適化できます。
*   **衝突判定:** Raycasterを使用してオブジェクト間の衝突を判定することができます。衝突時にオブジェクトの状態を変化させたり、特定の処理を実行したりすることができます。
*   **タッチイベントの処理:** スマートフォンやタブレットでインタラクションを実現するには、タッチイベントを処理する必要があります。`touchstart`、`touchmove`、`touchend`イベントを使用します。

#### 応用例とユースケース

*   **3Dモデルの操作:** マウスドラッグで3Dモデルを回転させたり、拡大縮小させたり、移動させたりすることができます。
*   **ゲーム開発:** キーボード入力やマウス操作でキャラクターを操作したり、アイテムを選択したり、UIを操作したりすることができます。
*   **インタラクティブな可視化:** ユーザーの操作に応じてデータを可視化したり、グラフを操作したりすることができます。

#### トラブルシューティング

*   **オブジェクトが選択できない:** Raycasterの光線がオブジェクトと交差していない可能性があります。カメラの位置や方向、オブジェクトの位置やサイズを確認します。
*   **オブジェクトが正しく移動しない:** マウス座標の計算や、オブジェクトの位置更新処理に誤りがある可能性があります。
*   **キーボード入力が認識されない:** イベントリスナーが正しく設定されていないか、キーコードが間違っている可能性があります。

#### まとめと次のステップ

### 3.3 カメラ制御 - OrbitControls, FlyControlsなどの利用

#### 概要と重要性

カメラ制御は、3D空間の視点を操作するための機能です。OrbitControlsやFlyControlsといったライブラリを使用することで、マウスやキーボードを使って直感的に視点を変更できるようになります。

#### 特徴と利点

*   **操作性の向上:** ユーザーは、視点を自由に操作することで、3D空間をより深く探索できます。
*   **視覚的な表現の多様性:** カメラの位置や角度を変化させることで、様々な視点から3D空間を表現できます。
*   **没入感の向上:** ユーザー自身が視点を操作することで、より深く3Dの世界に没入できます。

#### 事前準備と前提条件

*   HTML、CSS、JavaScriptの基本的な知識
*   Three.jsの基本的な知識（シーン、カメラ、レンダラー、オブジェクトの追加など）
*   OrbitControlsまたはFlyControlsライブラリの導入

#### 基本的な使い方

**1. OrbitControlsによるマウス操作での視点変更**

OrbitControlsは、マウスドラッグによってオブジェクトを中心に視点を回転させたり、マウスホイールでズームイン/ズームアウトしたりできるコントローラーです。

まず、OrbitControlsをプロジェクトに導入します。CDNを利用するか、npmなどでインストールできます。

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.132.2/examples/js/controls/OrbitControls.js"></script>
```

次に、OrbitControlsを作成し、アニメーションループ内で更新します。

```javascript
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js'; // もし npm でインストールした場合

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true; // ダンプニングを有効にする (慣性)
controls.dampingFactor = 0.05; // ダンプニングの強さ

function animate() {
  requestAnimationFrame(animate);

  controls.update(); // OrbitControlsを更新

  renderer.render(scene, camera);
}

animate();
```

このコードは、OrbitControlsを初期化し、アニメーションループ内で`controls.update()`を呼び出すことで、マウス操作で視点を変更できるようにします。`enableDamping`をtrueにすると、慣性が有効になり、より滑らかな操作感になります。

**2. FlyControlsによるFPS視点での操作**

FlyControlsは、FPS（First-Person Shooter）ゲームのような視点操作を実現するためのコントローラーです。キーボード入力で前後左右に移動し、マウスで視点の方向を変えます。

まず、FlyControlsをプロジェクトに導入します。CDNを利用するか、npmなどでインストールできます。

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.132.2/examples/js/controls/FlyControls.js"></script>
```

次に、FlyControlsを作成し、アニメーションループ内で更新します。

```javascript
import { FlyControls } from 'three/examples/jsm/controls/FlyControls.js'; // もし npm でインストールした場合

const controls = new FlyControls(camera, renderer.domElement);
controls.movementSpeed = 10; // 移動速度
controls.rollSpeed = Math.PI / 24; // 回転速度
controls.autoForward = false; // 自動前進を無効にする
controls.dragToLook = true; // マウスドラッグで視点変更
controls.enabled = true; // コントロールを有効にする

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta(); // 経過時間

  controls.update(delta); // FlyControlsを更新

  renderer.render(scene, camera);
}

animate();
```

このコードは、FlyControlsを初期化し、アニメーションループ内で`controls.update(delta)`を呼び出すことで、キーボードとマウスでFPS視点の操作を実現します。`clock.getDelta()`で経過時間を取得し、`controls.update()`に渡すことで、フレームレートに依存しない滑らかな動きを実現します。

**3. カスタムカメラ制御の実装**

OrbitControlsやFlyControls以外にも、独自のカメラ制御を実装することができます。例えば、キーボード入力でカメラの位置を移動させたり、マウスホイールでズームイン/ズームアウトさせたりすることができます。

```javascript
window.addEventListener('wheel', (event) => {
  // ズームイン/ズームアウト
  camera.position.z += event.deltaY * 0.01;
});
```

#### 実践的なテクニック

*   **コントローラーのパラメータ調整:** OrbitControlsやFlyControlsには様々なパラメータが用意されています。これらのパラメータを調整することで、操作感をカスタマイズすることができます。
*   **カメラの制約:** カメラの位置や角度に制約を設けることで、ユーザーが不自然な視点にならないようにすることができます。
*   **アニメーションとの連携:** カメラの動きをアニメーションと連携させることで、よりドラマチックな演出を実現できます。

#### 応用例とユースケース

*   **3Dモデルビューワー:** OrbitControlsを使用して、3Dモデルを自由に回転させたり、拡大縮小させたりできるビューワーを作成します。
*   **バーチャルツアー:** FlyControlsを使用して、3D空間を自由に歩き回れるバーチャルツアーを作成します。
*   **インタラクティブなプレゼンテーション:** カメラの動きをアニメーションと連携させて、ストーリーテリングを強化したインタラクティブなプレゼンテーションを作成します。

#### トラブルシューティング

*   **コントローラーが動作しない:** コントローラーが正しく初期化されているか、アニメーションループ内で`update()`が呼び出されているか確認します。
*   **操作感が悪い:** コントローラーのパラメータを調整したり、カメラの制約を設けたりすることで、操作感を改善することができます。
*   **カメラが予期せぬ動きをする:** カメラの動きが他のアニメーションやスクリプトと干渉している可能性があります。

#### まとめと次のステップ

このセクションでは、Three.jsでカメラ制御を実装するためのテクニックを学びました。OrbitControlsやFlyControlsといったライブラリの利用方法、そしてカスタムカメラ制御の実装方法について理解を深めました。次のステップでは、GUIを使用して、パラメータをリアルタイムに調整する方法を学びます。

### 3.4 GUI - dat.GUIによるパラメータ調整

#### 概要と重要性

GUI（Graphical User Interface）は、ユーザーが視覚的にパラメータを調整するためのインターフェースを提供します。dat.GUIのようなライブラリを使用することで、Three.jsオブジェクトのプロパティをGUIで制御し、リアルタイムにパラメータを調整することができます。

#### 特徴と利点

*   **直感的な操作:** スライダーやチェックボックスなどのGUI要素を使って、パラメータを直感的に調整できます。
*   **リアルタイムな反映:** パラメータの変更がリアルタイムに3D空間に反映されるため、視覚的に効果を確認しながら調整できます。
*   **実験と探索の促進:** 様々なパラメータを試すことで、より良い表現や効果を発見できます。

#### 事前準備と前提条件

*   HTML、CSS、JavaScriptの基本的な知識
*   Three.jsの基本的な知識（シーン、カメラ、レンダラー、オブジェクトの追加など）
*   dat.GUIライブラリの導入

#### 基本的な使い方

**1. dat.GUIの導入と基本的な使い方**

まず、dat.GUIをプロジェクトに導入します。CDNを利用するか、npmなどでインストールできます。

```html
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/dat-gui/0.7.9/dat.gui.min.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/dat-gui/0.7.9/dat.gui.min.js"></script>
```

次に、dat.GUIを作成し、パラメータを追加します。

```javascript
const gui = new dat.GUI();

const params = {
  rotationX: 0,
  rotationY: 0,
  color: '#ffffff',
  intensity: 1,
};

gui.add(params, 'rotationX', 0, Math.PI * 2).onChange((value) => {
  cube.rotation.x = value;
});

gui.add(params, 'rotationY', 0, Math.PI * 2).onChange((value) => {
  cube.rotation.y = value;
});

gui.addColor(params, 'color').onChange((value) => {
  cube.material.color.set(value);
});

gui.add(params, 'intensity', 0, 2).onChange((value) => {
  light.intensity = value;
});
```

このコードは、キューブの回転（X軸とY軸）、色、ライトの強度を制御するためのGUIを作成します。`gui.add()`でスライダーを追加し、`gui.addColor()`でカラーピッカーを追加します。`.onChange()`メソッドは、パラメータが変更されたときに実行されるコールバック関数を指定します。

**2. Three.jsオブジェクトのプロパティをGUIで制御**

上記の例のように、dat.GUIを使用してThree.jsオブジェクトの様々なプロパティを制御できます。位置、回転、スケール、色、透明度、材質など、様々なプロパティを調整することで、3D空間の見た目を細かく制御できます。

**3. GUIによるリアルタイムなパラメータ調整**

dat.GUIの最大の利点は、パラメータの変更がリアルタイムに3D空間に反映されることです。これにより、視覚的に効果を確認しながらパラメータを調整できます。

#### 実践的なテクニック

*   **フォルダの利用:** パラメータを整理するために、GUIにフォルダを作成することができます。`gui.addFolder()`メソッドを使用します。
*   **パラメータの保存と読み込み:** dat.GUIの状態をJSON形式で保存したり、読み込んだりすることができます。これにより、調整したパラメータを後で再利用したり、共有したりすることができます。
*   **GUIのスタイリング:** dat.GUIの見た目をカスタマイズするために、CSSを使用することができます。

#### 応用例とユースケース

*   **シェーダーのパラメータ調整:** カスタムシェーダーのパラメータをGUIで調整することで、様々な視覚効果を試すことができます。
*   **物理エンジンのパラメータ調整:** 物理エンジンのパラメータをGUIで調整することで、オブジェクトの動きや相互作用を制御できます。
*   **環境光の調整:** 環境光の色や強度をGUIで調整することで、シーン全体の雰囲気を変えることができます。

#### トラブルシューティング

*   **GUIが表示されない:** dat.GUIのCSSとJavaScriptが正しく導入されているか確認します。
*   **パラメータが反映されない:** `onChange()`メソッドで指定したコールバック関数が正しく実行されているか確認します。
*   **GUIが重い:** GUIに大量のパラメータを追加すると、パフォーマンスが低下する可能性があります。不要なパラメータを削除したり、GUIの更新頻度を調整したりすることで、パフォーマンスを最適化できます。
