## 第5章: 物理演算 - Cannon.jsによるリアルな挙動

### 5.1 Cannon.jsの導入 - 物理エンジンの基本

#### 概要と重要性

物理エンジンは、ゲームやシミュレーションにおいて、オブジェクトが現実世界のように相互作用するための重要な要素です。Cannon.jsは、JavaScriptで記述された軽量で強力な物理エンジンであり、Webブラウザ上でリアルな物理シミュレーションを実現できます。3Dモデリングツールで作られたオブジェクトに、重力、摩擦、衝突などの物理的な性質を与えることで、よりインタラクティブで没入感のある体験をWeb上に構築することが可能になります。

#### 特徴と利点

*   **軽量:** 非常に軽量なライブラリであり、Webアプリケーションへの組み込みが容易です。
*   **高性能:** Webブラウザ上で高速な物理シミュレーションを実現できます。
*   **柔軟性:** 多様な形状、制約、ジョイントをサポートし、複雑な物理シミュレーションを構築できます。
*   **オープンソース:** MITライセンスで公開されており、自由に使用、配布、改変できます。
*   **Three.jsとの連携:** Three.jsなどの3Dグラフィックスライブラリとの連携が容易です。

#### 事前準備と前提条件

*   基本的なJavaScriptの知識
*   HTML/CSSの基本的な知識
*   Three.jsなどの3Dグラフィックスライブラリの知識（推奨）
*   Node.jsとnpm（パッケージマネージャ）のインストール（開発環境構築のため）

#### 基本的な使い方

**1. Cannon.jsのインストールと設定**

プロジェクトディレクトリを作成し、npmを使用してCannon.jsをインストールします。

```bash
mkdir my-physics-project
cd my-physics-project
npm init -y  # package.jsonを作成
npm install cannon
```

または、CDNを使用することもできます。HTMLファイルに以下の行を追加してください。

```html
<script src="https://cdn.jsdelivr.net/npm/cannon@0.6.2/cannon.min.js"></script>
```

**2. World, Body, Shapeなどの基本的な要素**

Cannon.jsの物理シミュレーションは、`World`、`Body`、`Shape`という3つの基本的な要素で構成されます。

*   **World:** 物理シミュレーション空間全体を表します。重力、衝突検出などの設定を行います。
*   **Body:** シミュレーション内の物理オブジェクトを表します。質量、形状、位置、速度などの属性を持ちます。
*   **Shape:** Bodyの形状を定義します。Box、Sphere、Cylinderなどの基本的な形状や、より複雑な形状を使用できます。

**3. 物理シミュレーションの開始と停止**

以下のコードは、基本的な物理シミュレーションの初期化と実行の例です。

```javascript
// Cannon.jsの初期化
const world = new CANNON.World();
world.gravity.set(0, -9.82, 0); // 重力の設定

// 箱を作成
const boxShape = new CANNON.Box(new CANNON.Vec3(1, 1, 1));
const boxBody = new CANNON.Body({
  mass: 1, // 質量
  shape: boxShape,
});
boxBody.position.set(0, 5, 0); // 初期位置の設定
world.addBody(boxBody);

// 床を作成
const groundShape = new CANNON.Plane();
const groundBody = new CANNON.Body({
  mass: 0, // 静止させるため質量は0
  shape: groundShape,
});
groundBody.quaternion.setFromAxisAngle(new CANNON.Vec3(1, 0, 0), -Math.PI / 2); // 床を水平にする
world.addBody(groundBody);

// シミュレーションループ
const timeStep = 1 / 60; // タイムステップ
function updatePhysics() {
  world.step(timeStep);

  // 箱の位置を更新 (Three.jsのオブジェクトと連携する場合)
  // boxMesh.position.copy(boxBody.position);
  // boxMesh.quaternion.copy(boxBody.quaternion);

  requestAnimationFrame(updatePhysics);
}

updatePhysics();
```

このコードは、重力のある世界で、箱が落下し床と衝突するシミュレーションを行います。  `world.step(timeStep)` が物理シミュレーションを1ステップ進めます。 重要なのは、この処理を定期的に呼び出すことで、シミュレーションが進行していく点です。 一般的には、requestAnimationFrameを使って、ブラウザの描画更新に合わせて呼び出すのが良いでしょう。

#### 実践的なテクニック

*   **衝突検出:** `body.addEventListener("collide", function(event){ ... });` を使用して、衝突イベントをリッスンできます。
*   **マテリアル:** `CANNON.Material` を使用して、オブジェクトの材質（摩擦、反発など）を定義できます。
*   **ソルバー:** `world.solver.iterations` を調整して、シミュレーションの精度を向上させることができます（ただし、パフォーマンスに影響します）。

#### 応用例とユースケース

*   **ゲーム開発:** 落下、衝突、破壊などの物理的な挙動をゲームに組み込むことができます。
*   **シミュレーション:** ロボット、車両、流体などの挙動をシミュレーションできます。
*   **インタラクティブなWebサイト:** ユーザーがオブジェクトを操作できるインタラクティブなWebサイトを作成できます。
*   **VR/AR:** 仮想現実や拡張現実のコンテンツにリアルな物理演算を取り入れることができます。

#### トラブルシューティング

*   **オブジェクトが落下しない:** `Body` の `mass` が0になっている可能性があります。
*   **オブジェクトが不安定に振動する:** `world.solver.iterations` を増やすか、タイムステップ `timeStep` を小さくしてみてください。
*   **衝突判定が正確でない:** `Shape` の形状が複雑すぎる可能性があります。より単純な形状を使用するか、`world.broadphase` の設定を調整してください。
*   **パフォーマンスが低い:** シミュレーション内のオブジェクトの数を減らすか、`world.solver.iterations` を減らしてください。

### 5.2 剛体のシミュレーション - Box, Sphere, Cylinder

#### 概要と重要性

ゲームやシミュレーションの世界に登場するオブジェクトの形状は多種多様です。Cannon.jsでは、基本的な形状であるBox、Sphere、Cylinderを組み合わせて、複雑な形状のオブジェクトを表現することができます。また、これらの剛体の物理的な特性（重力、摩擦、反発）を調整することで、よりリアルな挙動を再現することが可能になります。

#### 特徴と利点

*   **多様な形状:** Box、Sphere、Cylinderなど、基本的な形状を簡単に作成できます。
*   **物理的な特性の設定:** 質量、摩擦、反発などの物理的な特性を細かく調整できます。
*   **衝突判定:** 異なる形状のオブジェクト同士の衝突判定を正確に行うことができます。
*   **パフォーマンス:** 基本的な形状を使用することで、複雑な形状よりも高いパフォーマンスを実現できます。

#### 事前準備と前提条件

*   Cannon.jsの基本的な知識（5.1を参照）

#### 基本的な使い方

**1. 基本的な形状の剛体を作成**

以下のコードは、Box、Sphere、Cylinderの剛体を作成する例です。

```javascript
// 箱を作成
const boxShape = new CANNON.Box(new CANNON.Vec3(1, 1, 1)); // 半径1の箱
const boxBody = new CANNON.Body({
  mass: 1,
  shape: boxShape,
  position: new CANNON.Vec3(0, 5, 0),
});
world.addBody(boxBody);

// 球を作成
const sphereShape = new CANNON.Sphere(1); // 半径1の球
const sphereBody = new CANNON.Body({
  mass: 1,
  shape: sphereShape,
  position: new CANNON.Vec3(3, 5, 0),
});
world.addBody(sphereBody);

// 円柱を作成
const cylinderShape = new CANNON.Cylinder(1, 1, 2, 12); // 上底半径1, 下底半径1, 高さ2, セグメント数12
const cylinderBody = new CANNON.Body({
  mass: 1,
  shape: cylinderShape,
  position: new CANNON.Vec3(-3, 5, 0),
  quaternion: new CANNON.Quaternion().setFromAxisAngle(new CANNON.Vec3(1, 0, 0), Math.PI / 2), // 縦向きにする
});
world.addBody(cylinderBody);
```

`CANNON.Box` のコンストラクタには、`Vec3` オブジェクトを渡します。 これは、箱の各軸方向の **半分の** 長さを表します。

`CANNON.Cylinder` のコンストラクタには、上底半径、下底半径、高さ、円周の分割数を渡します。

**2. 重力、摩擦、反発の設定**

以下のコードは、オブジェクトの重力、摩擦、反発を設定する例です。

```javascript
// マテリアルを作成
const physicsMaterial = new CANNON.Material({
  friction: 0.5, // 摩擦
  restitution: 0.3, // 反発
});

// Bodyにマテリアルを適用
boxBody.material = physicsMaterial;
sphereBody.material = physicsMaterial;
cylinderBody.material = physicsMaterial;

// 地面にもマテリアルを適用
groundBody.material = physicsMaterial;

// 2つのマテリアル間の相互作用を定義
const contactMaterial = new CANNON.ContactMaterial(groundBody.material, physicsMaterial, {
  friction: 0.5,
  restitution: 0.3,
});
world.addContactMaterial(contactMaterial);
```

`CANNON.ContactMaterial` は、2つのマテリアル間の相互作用を定義します。 これにより、異なるマテリアル同士の衝突時の挙動を細かく制御することができます。  `friction` は摩擦係数を、`restitution` は反発係数を表します。

**3. 衝突判定の実装**

以下のコードは、衝突判定を実装する例です。

```javascript
boxBody.addEventListener("collide", function(event) {
  console.log("Box collided with something!");
  // 衝突した相手のBodyを取得
  const otherBody = event.body;
  // 衝突した相手に応じて処理を行う
  if (otherBody === groundBody) {
    console.log("Box collided with the ground!");
  }
});
```

#### 実践的なテクニック

*   **複合形状:** `CANNON.Compound` を使用して、複数の形状を組み合わせた複合形状を作成できます。
*   **ローカル座標:** `CANNON.Compound` 内の形状は、ローカル座標で配置できます。
*   **動的と静的:** `Body` の `mass` を0に設定すると、静的なオブジェクトになります。

#### 応用例とユースケース

*   **ブロック崩しゲーム:** Boxを使用して、ブロックを表現できます。
*   **ビリヤードゲーム:** Sphereを使用して、ボールを表現できます。
*   **積み木ゲーム:** BoxやCylinderを使用して、積み木を表現できます。
*   **破壊シミュレーション:** 複数のBoxを組み合わせてオブジェクトを作成し、衝突によって破壊される様子をシミュレーションできます。

#### トラブルシューティング

*   **オブジェクトが期待通りに転がらない:** 摩擦係数が低すぎる可能性があります。
*   **オブジェクトが跳ね返りすぎる:** 反発係数が高すぎる可能性があります。
*   **複合形状の衝突判定が正しくない:** ローカル座標が正しく設定されているか確認してください。

### 5.3 ジョイント - オブジェクト同士の接続

#### 概要と重要性

現実世界では、複数のオブジェクトが互いに接続され、複雑な動きを実現しています。Cannon.jsのジョイントは、複数のBodyを接続し、特定の制約を与えるための機能です。これにより、ロボットアーム、ドア、サスペンションなど、多様なメカニズムをシミュレーションすることができます。

#### 特徴と利点

*   **多様なジョイント:** HingeConstraint、SpringConstraintなど、様々な種類のジョイントが用意されています。
*   **制約の設定:** ジョイントの種類に応じて、オブジェクトの動きに様々な制約を与えることができます。
*   **柔軟性:** 複数のジョイントを組み合わせることで、複雑なメカニズムを構築できます。
*   **制御:** ジョイントにモーターを設定することで、オブジェクトの動きを制御できます。

#### 事前準備と前提条件

*   Cannon.jsの基本的な知識（5.1を参照）
*   剛体のシミュレーションの知識（5.2を参照）

#### 基本的な使い方

**1. HingeConstraint, SpringConstraintなどのジョイント**

*   **HingeConstraint:** 蝶番のように、ある軸を中心に回転する動きを制約します。
*   **SpringConstraint:** バネのように、オブジェクト間の距離を一定に保つ力を発生させます。
*   **DistanceConstraint:** オブジェクト間の距離を一定に保ちます。
*   **LockConstraint:** 2つのボディの相対的な位置と回転を完全に固定します。

以下のコードは、HingeConstraintとSpringConstraintを作成する例です。

```javascript
// 2つのBoxを作成
const box1Shape = new CANNON.Box(new CANNON.Vec3(1, 1, 1));
const box1Body = new CANNON.Body({ mass: 1, shape: box1Shape });
box1Body.position.set(-3, 5, 0);
world.addBody(box1Body);

const box2Shape = new CANNON.Box(new CANNON.Vec3(1, 1, 1));
const box2Body = new CANNON.Body({ mass: 1, shape: box2Shape });
box2Body.position.set(-1, 5, 0);
world.addBody(box2Body);

// HingeConstraintを作成
const hingeConstraint = new CANNON.HingeConstraint(
  box1Body,
  box2Body,
  {
    pivotA: new CANNON.Vec3(1, 0, 0), // box1Bodyの回転軸の原点
    pivotB: new CANNON.Vec3(-1, 0, 0), // box2Bodyの回転軸の原点
    axisA: new CANNON.Vec3(0, 1, 0), // box1Bodyの回転軸の方向
    axisB: new CANNON.Vec3(0, 1, 0), // box2Bodyの回転軸の方向
  }
);
world.addConstraint(hingeConstraint);

// SpringConstraintを作成
const springConstraint = new CANNON.Spring(
  box1Body,
  box2Body,
  {
    restLength: 3, // バネの自然長
    stiffness: 100, // バネ定数
    damping: 10, // 減衰
    localAnchorA: new CANNON.Vec3(1,0,0),
    localAnchorB: new CANNON.Vec3(-1,0,0),
  }
);
world.addSpring(springConstraint);
```

`HingeConstraint` は、接続する2つのボディと、それぞれのボディにおける回転軸の位置（`pivotA`, `pivotB`）と方向（`axisA`, `axisB`）を指定します。

`SpringConstraint` は、接続する2つのボディと、バネの自然長（`restLength`）、バネ定数（`stiffness`）、減衰（`damping`）を指定します。 また、バネの両端のボディにおける接続点（`localAnchorA`, `localAnchorB`）を指定します。

**2. ロボットアームの制御**

以下のコードは、HingeConstraintを使用して、ロボットアームの関節を制御する例です。

```javascript
// ロボットアームの各関節にHingeConstraintを設定
// モーターを有効にし、目標速度と最大トルクを設定する
hingeConstraint.enableMotor();
hingeConstraint.setMotorSpeed(1); // 目標速度
hingeConstraint.setMaxMotorForce(10); // 最大トルク
```

`hingeConstraint.enableMotor()` でモーターを有効にし、`hingeConstraint.setMotorSpeed()` で目標速度を設定し、`hingeConstraint.setMaxMotorForce()` で最大トルクを設定します。 目標速度は、関節が回転しようとする速度を表します。 最大トルクは、関節が回転するために必要な力の最大値を表します。

#### 実践的なテクニック

*   **ジョイントの位置調整:** `pivotA` と `pivotB` を調整して、ジョイントの位置を正確に設定します。
*   **モーターの制御:** `setMotorSpeed` と `setMaxMotorForce` を動的に変更して、より複雑な動きを実現します。

*   **ロボットシミュレーション:** ロボットアームの動きをシミュレーションできます。

*   **ジョイントが正しく動作しない:** `pivotA`、`pivotB`、`axisA`、`axisB` が正しく設定されているか確認してください。

### 5.4 車両のシミュレーション - Wheel, Chassis

#### 概要と重要性

車両のシミュレーションは、ゲーム、シミュレーション、自動運転技術の開発など、様々な分野で重要な役割を果たします。Cannon.jsを使用すると、車両の基本的な構成要素であるWheel（車輪）とChassis（車体）を組み合わせ、アクセル、ブレーキ、ステアリングなどの制御機構を実装することで、リアルな車両の挙動をシミュレーションできます。

#### 特徴と利点

*   **柔軟な制御:** アクセル、ブレーキ、ステアリングを細かく制御できます。
*   **地形とのインタラクション:** 地形の形状に合わせて、車輪が適切に追従します。
*   **カスタマイズ性:** 車輪のサイズ、サスペンションの硬さ、摩擦係数などを調整できます。
*   **リアルな挙動:** 車両の質量、重心、慣性モーメントなどを考慮することで、よりリアルな挙動を再現できます。

#### 事前準備と前提条件

*   Cannon.jsの基本的な知識（5.1を参照）
*   剛体のシミュレーションの知識（5.2を参照）
*   ジョイントの知識（5.3を参照）

#### 基本的な使い方

**1. 車両の基本的な構成要素**

*   **Chassis (車体):** 車両の本体となるBoxまたはCompoundです。
*   **Wheel (車輪):** 車両の推進力と方向制御を担うSphereまたはCylinderです。
*   **WheelInfo:** 車輪の位置、半径、サスペンションの特性などを定義するオブジェクトです。
*   **Vehicle:** ChassisとWheelInfoを管理し、車両全体の挙動を制御するクラスです。

**2. アクセル、ブレーキ、ステアリングの制御**

以下のコードは、Cannon.jsで車両をシミュレーションする基本的な例です。

```javascript
// 車体の作成
const chassisShape = new CANNON.Box(new CANNON.Vec3(1.5, 0.5, 3));
const chassisBody = new CANNON.Body({ mass: 150, shape: chassisShape });
chassisBody.position.set(0, 2, 0); // 初期位置
chassisBody.angularDamping = 0.5;

// 車両の作成
const vehicle = new CANNON.Vehicle({
  chassisBody: chassisBody,
});

// 車輪のオプション
const wheelOptions = {
  radius: 0.7, // 車輪の半径
  directionLocal: new CANNON.Vec3(0, -1, 0), // 車輪の方向（ローカル座標）
  axleLocal: new CANNON.Vec3(-1, 0, 0), // 車軸の方向（ローカル座標）
  suspensionStiffness: 30, // サスペンションの硬さ
  suspensionRestLength: 0.3, // サスペンションの静止長
  frictionSlip: 5, // 摩擦スリップ
  dampingRelaxation: 2.3, // 減衰緩和
  dampingCompression: 4.4, // 減衰圧縮
  brake: 0, // 初期ブレーキ力
  steeringValue: 0, // 初期ステアリング角度
};

// 車輪の追加
const x = 1.25;
const y = 0.5;
const z = 2;

wheelOptions.isFrontWheel = true;
vehicle.addWheel({
  chassisConnectionPointLocal: new CANNON.Vec3(x, y, z), // 車体との接続点（ローカル座標）
  ...wheelOptions,
});
vehicle.addWheel({
  chassisConnectionPointLocal: new CANNON.Vec3(-x, y, z),
  ...wheelOptions,
});

wheelOptions.isFrontWheel = false;
vehicle.addWheel({
  chassisConnectionPointLocal: new CANNON.Vec3(x, y, -z),
  ...wheelOptions,
});
vehicle.addWheel({
  chassisConnectionPointLocal: new CANNON.Vec3(-x, y, -z),
  ...wheelOptions,
});

vehicle.addToWorld(world);

// アクセル、ブレーキ、ステアリングの制御
let accelerating = false;
let braking = false;
let steering = 0;

document.addEventListener('keydown', (event) => {
  switch (event.key) {
    case 'w': // アクセル
      accelerating = true;
      break;
    case 's': // ブレーキ
      braking = true;
      break;
    case 'a': // 左ステアリング
      steering = 0.5;
      break;
    case 'd': // 右ステアリング
      steering = -0.5;
      break;
  }
});

document.addEventListener('keyup', (event) => {
  switch (event.key) {
    case 'w':
      accelerating = false;
      break;
    case 's':
      braking = false;
      break;
    case 'a':
    case 'd':
      steering = 0;
      break;
  }
});

function updateVehicle(deltaTime) {
  const maxSteeringVal = 0.5;
  vehicle.setSteeringValue(steering * maxSteeringVal, 0);
  vehicle.setSteeringValue(steering * maxSteeringVal, 1);

  const engineForce = accelerating ? 1000 : 0;
  vehicle.applyEngineForce(engineForce, 0);
  vehicle.applyEngineForce(engineForce, 1);

  const brakeForce = braking ? 100 : 0;
  vehicle.setBrake(brakeForce, 0);
  vehicle.setBrake(brakeForce, 1);
  vehicle.setBrake(brakeForce, 2);
  vehicle.setBrake(brakeForce, 3);
}

// シミュレーションループ内でupdateVehicleを呼び出す
function updatePhysics() {
  world.step(timeStep);
  updateVehicle(timeStep);

  // ...
}
```

`CANNON.Vehicle` は、シャーシとなるボディ (`chassisBody`) を受け取って初期化されます。 次に、`addWheel` メソッドを使って車輪を追加します。 このメソッドは、車体との接続点 (`chassisConnectionPointLocal`)、車輪の方向 (`directionLocal`)、車軸の方向 (`axleLocal`)、サスペンションの特性 (`suspensionStiffness`, `suspensionRestLength`, `dampingRelaxation`, `dampingCompression`) などを指定する `WheelInfo` オブジェクトを受け取ります。

`vehicle.applyEngineForce()` でエンジンの力を加え、`vehicle.setBrake()` でブレーキ力を設定し、`vehicle.setSteeringValue()` でステアリング角度を設定します。 これらのメソッドを組み合わせて、車両の動きを制御します。

**3. 地形とのインタラクション**

地形を表現するために、`CANNON.Heightfield`を使用できます。これは、高さデータを基に地形を生成するShapeです。

```javascript
// 高さデータの作成
const matrix = [];
const sizeX = 64;
const sizeY = 64;
for (let i = 0; i < sizeX; i++) {
  matrix.push([]);
  for (let j = 0; j < sizeY; j++) {
    const height = Math.sin(i / sizeX * Math.PI * 2) * Math.cos(j / sizeY * Math.PI * 2) * 5;
    matrix[i].push(height);
  }
}

// Heightfieldの作成
const heightfieldShape = new CANNON.Heightfield(matrix, {
  elementSize: 2, // 高さデータの要素のサイズ
});
const heightfieldBody = new CANNON.Body({ mass: 0, shape: heightfieldShape });
heightfieldBody.position.set(-sizeX, -5, -sizeY); // 位置調整
heightfieldBody.quaternion.setFromAxisAngle(new CANNON.Vec3(1, 0, 0), -Math.PI / 2);
world.addBody(heightfieldBody);
```

`CANNON.Heightfield` は、高さデータ (`matrix`) と、高さデータの要素のサイズ (`elementSize`) を指定して初期化されます。  地形のBodyは通常、質量を0に設定して静的なオブジェクトにします。

#### 実践的なテクニック

*   **サスペンションの調整:** `suspensionStiffness`、`suspensionRestLength`、`dampingRelaxation`、`dampingCompression` を調整して、乗り心地を改善します。
*   **摩擦係数の調整:** `frictionSlip` を調整して、タイヤのグリップ力を調整します。
*   **車両の安定性:** 車両の重心を低くしたり、車輪の幅を広くしたりすることで、安定性を向上させることができます。

#### 応用例とユースケース

*   **レーシングゲーム:** アクセル、ブレーキ、ステアリングを駆使して、コースを走り抜けるゲームを開発できます。
*   **オフロードシミュレーション:** 複雑な地形を走破するシミュレーションを開発できます。
*   **自動運転シミュレーション:** 自動運転システムの開発やテストに使用できます。
*   **VR/ARドライブシミュレーター:** 仮想現実や拡張現実空間で、リアルな運転体験を提供できます。

#### トラブルシューティング

*   **車両がひっくり返る:** 車両の重心が高すぎる可能性があります。
*   **車輪が空回りする:** 摩擦係数が低すぎる可能性があります。
*   **サスペンションが硬すぎる/柔らかすぎる:** `suspensionStiffness` を調整してください。
*   **ステアリングが効きすぎる/効かない:** `maxSteeringVal` を調整してください。
