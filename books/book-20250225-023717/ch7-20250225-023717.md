## 第6章: テクスチャとマテリアルの高度な利用 - PBR, 環境マッピング

### 6.1 PBR (Physically Based Rendering) - 現実的な質感の表現

#### 概要と重要性

PBR（Physically Based Rendering: 物理ベースレンダリング）とは、現実世界の物理法則に基づいて光の相互作用をシミュレートし、よりリアルな質感を表現するレンダリング手法です。従来のレンダリング手法と比較して、光沢や反射がより自然になり、ライティング環境が変わっても見た目が大きく変わることが少なくなります。ゲーム、映像制作、建築ビジュアライゼーションなど、リアリティが求められるあらゆる分野で不可欠な技術となっています。

#### 特徴と利点

PBRの主な特徴は以下の通りです。

* **物理的な正確さ:** 光のエネルギー保存則や双方向反射率分布関数 (BRDF) などの物理法則に基づいているため、現実世界の質感を忠実に再現できます。
* **ライティングの安定性:**  異なるライティング環境下でも、一貫性のある質感を提供します。
* **直感的なパラメータ:**  Albedo、Metalness、Roughnessなど、物理的な意味を持つパラメータを使用するため、アーティストが直感的に質感を調整できます。

#### 事前準備と前提条件

* three.jsの基本的な知識 (シーン、カメラ、レンダラーの設定)
* テクスチャやマテリアルに関する基本的な知識

#### 基本的な使い方

three.jsでは、PBRを表現するために `MeshStandardMaterial` または `MeshPhysicalMaterial` を使用します。`MeshPhysicalMaterial` は、より高度なPBR表現（薄膜干渉、クリアコートなど）をサポートします。

```javascript
import * as THREE from 'three';

// シーン、カメラ、レンダラーの初期化 (省略)

// ジオメトリの作成
const geometry = new THREE.SphereGeometry(1, 32, 32);

// マテリアルの作成 (MeshStandardMaterial)
const material = new THREE.MeshStandardMaterial({
  color: 0xffffff, // Albedo (基本色)
  metalness: 0.5,  // 金属度 (0: 非金属, 1: 金属)
  roughness: 0.5,  // 粗さ (0: 鏡面, 1: 拡散)
  normalMap: normalTexture, // 法線マップ
});

// メッシュの作成
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// 環境光の追加
const ambientLight = new THREE.AmbientLight(0xffffff, 0.5);
scene.add(ambientLight);

// 平行光源の追加
const directionalLight = new THREE.DirectionalLight(0xffffff, 0.5);
directionalLight.position.set(1, 1, 1);
scene.add(directionalLight);

// レンダリングループ (省略)
```

#### 実践的なテクニック

**1. Albedo (基本色):** オブジェクトの基本色を設定します。テクスチャを使用することも可能です。

```javascript
material.map = albedoTexture; // Albedoテクスチャの設定
```

**2. Metalness (金属度):** オブジェクトが金属であるかどうかを0から1の範囲で指定します。0は非金属、1は完全な金属です。

```javascript
material.metalness = 0.8; // 金属度を80%に設定
material.metalnessMap = metalnessTexture; // Metalnessテクスチャの設定
```

**3. Roughness (粗さ):** オブジェクト表面の粗さを0から1の範囲で指定します。0は完全に滑らかな表面（鏡面反射）、1は完全に粗い表面（拡散反射）です。

```javascript
material.roughness = 0.2; // 粗さを20%に設定
material.roughnessMap = roughnessTexture; // Roughnessテクスチャの設定
```

**4. Normal Map (法線マップ):**  オブジェクト表面の微細な凹凸を表現します。これにより、より複雑なディテールを少ないポリゴン数で実現できます。

```javascript
material.normalMap = normalTexture; // 法線マップテクスチャの設定
material.normalScale = new THREE.Vector2(1, 1); // 法線マップのスケール調整
```

**5. IBL (Image Based Lighting):**  環境マップを使用して間接照明を表現します。これにより、よりリアルなライティング効果を得られます。

```javascript
const pmremGenerator = new THREE.PMREMGenerator(renderer);
const envMap = new THREE.CubeTextureLoader()
  .setPath('textures/cube/pisa/')
  .load([
    'px.png',
    'nx.png',
    'py.png',
    'ny.png',
    'pz.png',
    'nz.png',
  ], () => {
    const envMapEquireact = pmremGenerator.fromCubemap(envMap).texture;
    material.envMap = envMapEquireact;
    material.needsUpdate = true;

    pmremGenerator.dispose();
  });
```

#### 応用例とユースケース

* **ゲーム:** リアルなキャラクターや環境の表現
* **建築ビジュアライゼーション:** 高品質なレンダリングによるプレゼンテーション
* **製品デザイン:** 質感や素材感を忠実に再現した製品の3Dモデル

#### トラブルシューティング

* **オブジェクトが暗すぎる:** 環境光や平行光源の強度を調整してください。IBLを使用している場合は、環境マップの露出を調整してください。
* **質感が期待通りにならない:**  Metalness、Roughness、Normal Mapの設定を確認してください。テクスチャの解像度が十分であるか確認してください。
* **パフォーマンスの問題:**  高解像度のテクスチャの使用を避け、テクスチャ圧縮を検討してください。

#### まとめと次のステップ

PBRは、リアルな質感を表現するための強力なツールです。`MeshStandardMaterial` および `MeshPhysicalMaterial` を使用して、様々なパラメータを調整し、独自の質感を創造してください。IBLを利用することで、さらに高度なライティング効果を得ることができます。次のステップとして、環境マッピングについて学びましょう。

### 6.2 環境マッピング - 反射と屈折の表現

#### 概要と重要性

環境マッピングとは、周囲の環境をテクスチャとしてオブジェクトに適用し、反射や屈折を表現する技術です。これにより、オブジェクトに写り込みや透明感を加えることができ、よりリアルな表現が可能になります。特に、金属やガラスなどの表面を表現する際に非常に有効です。

#### 特徴と利点

* **リアルな反射と屈折:** 周囲の環境を反映することで、オブジェクトの存在感を高めます。
* **比較的低コスト:**  リアルタイムレンダリングにおいて、レイトレーシングよりも計算コストが低く、パフォーマンスを維持しやすいです。

#### 事前準備と前提条件

* three.jsの基本的な知識
* PBRに関する知識 (推奨)

#### 基本的な使い方

three.jsでは、環境マップを表現するために `CubeTexture` を使用します。これは、周囲の環境を6つの正方形のテクスチャとして表現したものです。

```javascript
import * as THREE from 'three';

// シーン、カメラ、レンダラーの初期化 (省略)

// キューブテクスチャの読み込み
const cubeTextureLoader = new THREE.CubeTextureLoader();
const envMap = cubeTextureLoader.load([
  'textures/cube/px.png',
  'textures/cube/nx.png',
  'textures/cube/py.png',
  'textures/cube/ny.png',
  'textures/cube/pz.png',
  'textures/cube/nz.png',
]);

// マテリアルの作成 (MeshStandardMaterial)
const material = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  metalness: 1.0, // 金属
  roughness: 0.0,  // 鏡面
  envMap: envMap, // 環境マップ
  envMapIntensity: 1.0, // 環境マップの強度
});

// メッシュの作成
const geometry = new THREE.SphereGeometry(1, 32, 32);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// レンダリングループ (省略)
```

#### 実践的なテクニック

**1. CubeTextureによる環境マップの作成:**  `CubeTextureLoader` を使用して、6つの画像ファイルからキューブテクスチャを読み込みます。

```javascript
const cubeTextureLoader = new THREE.CubeTextureLoader();
const envMap = cubeTextureLoader.load([
  'textures/cube/px.png',
  'textures/cube/nx.png',
  'textures/cube/py.png',
  'textures/cube/ny.png',
  'textures/cube/pz.png',
  'textures/cube/nz.png',
]);
```

**2. ReflectionとRefractionの表現:**  `MeshStandardMaterial` および `MeshPhysicalMaterial` の `envMap` プロパティにキューブテクスチャを設定することで、反射を表現できます。屈折を表現するには、`refractionRatio` プロパティを設定します。

```javascript
material.envMap = envMap; // 環境マップ
material.refractionRatio = 0.98; // 屈折率 (ガラスの場合、1.5程度)
```

**3. Dynamic Environment Map:**  シーン内のオブジェクトを動的に反映した環境マップを作成することも可能です。これには、`WebGLCubeRenderTarget` を使用します。ただし、これは計算コストが高いため、注意が必要です。

```javascript
const cubeRenderTarget = new THREE.WebGLCubeRenderTarget(256);
const cubeCamera = new THREE.CubeCamera(0.1, 1000, cubeRenderTarget);

// レンダリングループ内で、オブジェクトの位置に合わせてキューブカメラを更新し、レンダリングする
cubeCamera.update(renderer, scene);
material.envMap = cubeRenderTarget.texture;
```

#### 応用例とユースケース

* **車のシミュレーション:** 車体の反射をリアルに表現
* **ジュエリーの表現:**  宝石の輝きや屈折を再現
* **水面の表現:**  水面の反射や揺らぎを表現

#### トラブルシューティング

* **反射が不自然:** キューブテクスチャの画像が適切に設定されているか確認してください。環境マップの強さ（`envMapIntensity`）を調整してみてください。
* **パフォーマンスの問題:** ダイナミック環境マップを使用している場合、パフォーマンスが低下する可能性があります。必要に応じて、解像度を下げるか、更新頻度を調整してください。

#### まとめと次のステップ

環境マッピングは、オブジェクトにリアリティを与えるための重要なテクニックです。キューブテクスチャを使用し、反射や屈折を表現することで、より魅力的なシーンを作成できます。次のステップとして、テクスチャの生成と加工について学びましょう。

### 6.3 テクスチャの生成と加工 - Canvas, WebGLRenderer

#### 概要と重要性

three.jsでは、静的な画像テクスチャだけでなく、CanvasやWebGLRendererを使用して動的にテクスチャを生成したり、既存のテクスチャを加工したりすることができます。これにより、テクスチャをリアルタイムに変化させたり、特殊なエフェクトを作成したりすることが可能になります。

#### 特徴と利点

* **動的なテクスチャ:**  時間とともに変化するテクスチャを作成できます。
* **特殊効果:**  Blur、Sharpen、色調補正などのエフェクトをテクスチャに適用できます。
* **柔軟性:**  Canvas APIやWebGLRendererの機能を活用することで、様々なテクスチャを生成できます。

#### 事前準備と前提条件

* three.jsの基本的な知識
* Canvas APIに関する知識
* WebGLに関する知識 (推奨)

#### 基本的な使い方

**1. Canvasによるテクスチャの動的な生成:** Canvas要素を作成し、2Dレンダリングコンテキストを使用して描画を行います。その後、Canvasの内容をテクスチャとしてthree.jsにロードします。

```javascript
import * as THREE from 'three';

// シーン、カメラ、レンダラーの初期化 (省略)

// Canvas要素の作成
const canvas = document.createElement('canvas');
canvas.width = 256;
canvas.height = 256;
const ctx = canvas.getContext('2d');

// Canvasに描画
ctx.fillStyle = 'red';
ctx.fillRect(0, 0, canvas.width, canvas.height);
ctx.fillStyle = 'blue';
ctx.font = '48px sans-serif';
ctx.fillText('Hello, Three.js!', 10, 100);

// テクスチャの作成
const texture = new THREE.CanvasTexture(canvas);

// マテリアルの作成
const material = new THREE.MeshBasicMaterial({ map: texture });

// メッシュの作成
const geometry = new THREE.PlaneGeometry(2, 2);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// アニメーションループ内で、Canvasの内容を更新し、テクスチャを更新する
function animate() {
  requestAnimationFrame(animate);

  // Canvasの内容を更新
  ctx.fillStyle = 'rgba(255, 255, 255, 0.1)';
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = 'black';
  ctx.font = '48px sans-serif';
  ctx.fillText(Date.now(), 10, 100);

  // テクスチャを更新
  texture.needsUpdate = true;

  renderer.render(scene, camera);
}

animate();
```

**2. WebGLRendererによるテクスチャの書き出し:**  シーンをレンダリングし、その結果をテクスチャとして使用することができます。これには、`WebGLRenderTarget` を使用します。

```javascript
// レンダリングターゲットの作成
const renderTarget = new THREE.WebGLRenderTarget(256, 256);

// シーンをレンダリングターゲットにレンダリング
renderer.setRenderTarget(renderTarget);
renderer.render(scene, camera);
renderer.setRenderTarget(null); // 通常のレンダリングに戻す

// テクスチャの作成
const texture = renderTarget.texture;

// マテリアルの作成
const material = new THREE.MeshBasicMaterial({ map: texture });

// メッシュの作成
const geometry = new THREE.PlaneGeometry(2, 2);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);
```

#### 実践的なテクニック

**1. テクスチャの加工 (Blur, Sharpen, 色調補正):**  Canvas APIやWebGLShaderを使用して、テクスチャを加工することができます。例えば、Blurエフェクトを適用するには、ガウシアンぼかしフィルタを使用します。色調補正には、色空間変換やレベル補正などのテクニックを使用します。

**2.  Framebuffer Object (FBO) を利用したエフェクト:** WebGLRenderTargetは内部的にFramebuffer Objectを使用しています。これを利用することで、複数のテクスチャを組み合わせたり、複雑なエフェクトを適用したりすることができます。

#### 応用例とユースケース

* **パーティクルシステム:** パーティクルの色や形を動的に変化させる
* **インタラクティブなテクスチャ:**  ユーザーの操作に応じてテクスチャを変化させる
* **特殊効果:**  炎、煙、水などの自然現象を表現する

#### トラブルシューティング

* **テクスチャが更新されない:** `texture.needsUpdate = true;` を設定しているか確認してください。
* **パフォーマンスの問題:** Canvasの描画やWebGLRenderTargetへのレンダリングは計算コストが高い場合があります。必要に応じて、解像度を下げるか、更新頻度を調整してください。

#### まとめと次のステップ

テクスチャの生成と加工は、three.jsで高度な表現を実現するための重要なテクニックです。Canvas APIやWebGLRendererの機能を活用し、独自のテクスチャエフェクトを創造してください。次のステップとして、テクスチャ圧縮について学びましょう。

### 6.4 テクスチャ圧縮 - DDS, KTX, Basis Universal

#### 概要と重要性

テクスチャ圧縮とは、テクスチャデータのサイズを削減する技術です。テクスチャは、3Dグラフィックスにおいて最もメモリ消費量の多い要素の一つであり、圧縮によってロード時間、メモリ使用量、GPU負荷を大幅に削減することができます。モバイルデバイスやWebブラウザなど、リソースが限られた環境では特に重要です。

#### 特徴と利点

* **ロード時間の短縮:** テクスチャファイルのサイズが小さくなるため、ダウンロードやロードにかかる時間を短縮できます。
* **メモリ使用量の削減:** GPUメモリの使用量を削減し、より複雑なシーンをレンダリングできるようになります。
* **パフォーマンスの向上:** GPUのテクスチャサンプリングの効率が向上し、フレームレートを改善できます。
* **省電力化:** モバイルデバイスでは、メモリへのアクセス頻度を減らすことでバッテリー消費を抑えることができます。

#### 事前準備と前提条件

* three.jsの基本的な知識
* テクスチャに関する知識
* テクスチャ圧縮に関する基本的な知識

#### 基本的な使い方

three.jsでは、いくつかのテクスチャ圧縮形式をサポートしています。代表的なものとして、DDS、KTX、Basis Universalがあります。

**1. DDS (DirectDraw Surface):**  DirectXで使用される一般的なテクスチャ圧縮形式です。主にPC環境で使用されます。

```javascript
import * as THREE from 'three';
import { DDSLoader } from 'three/examples/jsm/loaders/DDSLoader.js';

// DDSLoaderのインスタンスを作成
const ddsLoader = new DDSLoader();

// DDSテクスチャの読み込み
ddsLoader.load('textures/compressed/example.dds', function (texture) {
  // マテリアルの作成
  const material = new THREE.MeshBasicMaterial({ map: texture });

  // メッシュの作成 (省略)
});
```

**2. KTX (Khronos Texture):**  OpenGLで使用されるテクスチャ圧縮形式です。クロスプラットフォームに対応しており、様々なプラットフォームで使用できます。

```javascript
import * as THREE from 'three';
import { KTX2Loader } from 'three/examples/jsm/loaders/KTX2Loader.js';

// KTX2Loaderのインスタンスを作成
const ktx2Loader = new KTX2Loader();
ktx2Loader.setTranscoderPath( '/examples/jsm/libs/basis/', 'basis_transcoder.js' );
ktx2Loader.detectSupport( renderer ); // Three.js r154 以降はrendererを渡す必要あり

// KTXテクスチャの読み込み
ktx2Loader.load('textures/compressed/example.ktx2', function (texture) {
  // マテリアルの作成
  const material = new THREE.MeshBasicMaterial({ map: texture });

  // メッシュの作成 (省略)
});
```

**3. Basis Universal:**  Googleが開発したクロスプラットフォーム対応のテクスチャ圧縮形式です。GPUに関わらず、ほぼ全ての環境で動作します。WebGL環境で最も推奨される形式です。

Basis Universalを使用するには、Basis Texture Tools (basisu) を使用してテクスチャを変換する必要があります。

#### 実践的なテクニック

**1. テクスチャ圧縮形式の選択:**  ターゲットプラットフォームに応じて適切なテクスチャ圧縮形式を選択する必要があります。WebGL環境では、Basis Universalが最も汎用性が高く推奨されます。PC環境では、DDSが適している場合があります。

**2. Mipmapの生成:**  Mipmapとは、異なる解像度のテクスチャを事前に生成しておくことで、遠くのオブジェクトに対して低解像度のテクスチャを使用し、パフォーマンスを向上させるテクニックです。テクスチャ圧縮と組み合わせて使用することで、より効果的なパフォーマンス改善が期待できます。

**3. テクスチャ圧縮ツールの利用:**  様々なテクスチャ圧縮ツールが存在します。これらのツールを使用することで、最適な圧縮設定を簡単に適用できます。

#### 応用例とユースケース

* **Webゲーム:**  ロード時間を短縮し、より快適なゲーム体験を提供する
* **モバイルアプリ:**  メモリ使用量を削減し、安定した動作を実現する
* **VR/ARアプリ:**  高解像度のテクスチャを使用しながら、高いフレームレートを維持する

#### トラブルシューティング

* **テクスチャが表示されない:**  ローダーが正しく設定されているか、テクスチャファイルのパスが正しいか確認してください。
* **テクスチャが破損している:** テクスチャファイルが正しく圧縮されているか確認してください。別の圧縮ツールを試してみてください。
* **パフォーマンスが改善されない:**  圧縮設定が適切であるか確認してください。Mipmapを生成してみてください。

#### まとめと次のステップ

テクスチャ圧縮は、3Dグラフィックスのパフォーマンスを最適化するために不可欠な技術です。DDS, KTX, Basis Universalなどの圧縮形式を理解し、ターゲットプラットフォームに応じて適切に選択することで、より快適な3D体験を提供することができます。この章で学んだ知識を活かし、自身のプロジェクトにテクスチャ圧縮を導入してみてください。
