## 第3章: モデルデータの活用 - glTF, FBX, OBJ

### 4.1 モデルデータの概要 - glTF, FBX, OBJの違いと特徴

**1. 概要と重要性**

3Dモデルは、Webアプリケーションにリアリティとインタラクティブ性をもたらす上で不可欠な要素です。キャラクター、オブジェクト、環境など、様々な要素を表現するために使用されます。Three.jsでは、glTF, FBX, OBJといった代表的なファイル形式を読み込み、表示することができます。それぞれの形式には特徴があり、用途に応じて使い分けることが重要です。

**2. 特徴と利点**

*   **glTF (GL Transmission Format):**
    *   **特徴:** JSONベースで、ランタイムでのロードと処理に最適化された形式です。アニメーション、マテリアル、テクスチャを効率的に格納できます。
    *   **利点:**
        *   軽量でロード時間が短い。
        *   Three.jsとの相性が良い。
        *   PBR (Physically Based Rendering) マテリアルをサポート。
        *   アニメーションのサポートが充実。
        *   オープンスタンダードで、幅広いツールでサポートされている。
*   **FBX (Filmbox):**
    *   **特徴:** Autodesk社が開発した、3Dモデリング、アニメーション、ゲーム開発で使用される一般的な形式です。豊富な機能と柔軟性を持っています。
    *   **利点:**
        *   様々な3Dソフトウェアでサポートされている。
        *   複雑なシーンやアニメーションを格納できる。
        *   バイナリ形式で、比較的ファイルサイズが小さい。
*   **OBJ (Object):**
    *   **特徴:** 最もシンプルな3Dモデル形式の一つで、頂点、面、テクスチャ座標をテキスト形式で記述します。
    *   **利点:**
        *   シンプルで理解しやすい。
        *   幅広い3Dソフトウェアでサポートされている。
        *   テキスト形式のため、手動で編集可能。
    *   **欠点:**
        * アニメーションをサポートしない。
        * マテリアルやテクスチャの情報は別途MTLファイルに記述する必要がある。

**3. 事前準備と前提条件**

*   Three.jsの基本的な知識が必要です。
*   テキストエディタ、IDE (Integrated Development Environment) を用意してください。
*   3Dモデルデータ (glTF, FBX, OBJファイル) を用意してください。
*   必要に応じて、3Dモデリングソフトウェア (Blenderなど) を用意してください。

**4. 基本的な使い方**

それぞれの形式を読み込むためのローダーを使用します。

```javascript
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { FBXLoader } from 'three/addons/loaders/FBXLoader.js';
import { OBJLoader } from 'three/addons/loaders/OBJLoader.js';

// glTFの読み込み
const gltfLoader = new GLTFLoader();
gltfLoader.load('path/to/model.gltf', (gltf) => {
  const model = gltf.scene;
  scene.add(model);
}, undefined, (error) => {
  console.error('An error happened', error);
});

// FBXの読み込み
const fbxLoader = new FBXLoader();
fbxLoader.load('path/to/model.fbx', (fbx) => {
  scene.add(fbx);
}, undefined, (error) => {
  console.error('An error happened', error);
});

// OBJの読み込み
const objLoader = new OBJLoader();
objLoader.load('path/to/model.obj', (obj) => {
  scene.add(obj);
}, undefined, (error) => {
  console.error('An error happened', error);
});
```

**5. 実践的なテクニック**

*   **モデルのスケール、回転、位置の調整:**

    ```javascript
    model.scale.set(0.5, 0.5, 0.5); // サイズを半分にする
    model.rotation.y = Math.PI / 2; // Y軸を中心に90度回転
    model.position.set(1, 0, 0); // X軸方向に1移動
    ```

*   **アニメーション付きglTFモデルの再生:**

    ```javascript
    const mixer = new THREE.AnimationMixer(model);
    gltf.animations.forEach((clip) => {
      mixer.clipAction(clip).play();
    });

    // アニメーションの更新 (renderループ内)
    function animate() {
      requestAnimationFrame(animate);
      mixer.update(deltaTime); // deltaTimeは経過時間
      renderer.render(scene, camera);
    }
    animate();
    ```

*   **FBXモデルのテクスチャの取り扱い:**

    FBXモデルにはテクスチャが埋め込まれている場合と、外部ファイルとして参照している場合があります。外部ファイルを参照している場合は、パスが正しいか確認してください。また、`THREE.TextureLoader`を使ってテクスチャを読み込み、マテリアルに設定することもできます。

    ```javascript
    const textureLoader = new THREE.TextureLoader();
    const texture = textureLoader.load('path/to/texture.png');
    model.traverse((child) => {
      if (child.isMesh) {
        child.material.map = texture;
        child.material.needsUpdate = true;
      }
    });
    ```

**6. 応用例とユースケース**

*   **製品の3Dビューワー:** Webサイト上で製品を3Dモデルで表示し、ユーザーが自由に視点を変更できるようにする。glTFは軽量でPBRマテリアルをサポートするため、高品質な表現が可能。
*   **バーチャル展示会:** オンライン上で展示会を開催し、3Dモデルの展示物をインタラクティブに閲覧できるようにする。アニメーション付きのモデルを使用することで、より魅力的な体験を提供できる。
*   **ゲーム開発:** Three.jsを使ってWebブラウザ上で動作するゲームを開発する。キャラクターやオブジェクトの3DモデルをglTFまたはFBX形式で読み込み、アニメーションを適用する。
*   **建築ビジュアライゼーション:** 建築物の完成予想図を3Dモデルで表示する。FBXは複雑な構造を扱うのに適しており、テクスチャやライティングを細かく調整することで、リアリティの高い表現が可能。

**7. トラブルシューティング**

*   **モデルが表示されない:**
    *   パスが正しいか確認してください。
    *   モデルがシーンに追加されているか確認してください。
    *   カメラの位置と視線が適切か確認してください。
    *   ライティングが適切か確認してください。
    *   モデルのスケールが小さすぎないか、大きすぎないか確認してください。
*   **テクスチャが表示されない:**
    *   テクスチャファイルのパスが正しいか確認してください。
    *   テクスチャがマテリアルに設定されているか確認してください。
    *   テクスチャのファイル形式がThree.jsでサポートされているか確認してください。
*   **アニメーションが再生されない:**
    *   `THREE.AnimationMixer`が正しく初期化されているか確認してください。
    *   アニメーションクリップが`mixer.clipAction(clip).play()`で再生されているか確認してください。
    *   `mixer.update(deltaTime)`がrenderループ内で呼び出されているか確認してください。
*   **FBX Loaderのエラー:**
    *   FBX LoaderのバージョンがThree.jsのバージョンと互換性があるか確認してください。
    *   FBXファイルが破損していないか確認してください。

**8. まとめと次のステップ**

この章では、Three.jsで3Dモデルデータを扱うための基本的な知識とテクニックを学びました。glTF, FBX, OBJといった形式の特徴を理解し、それぞれの形式に適したローダーを使用することで、様々な3DモデルをWebアプリケーションに組み込むことができます。

次のステップとしては、以下の内容を学ぶことをお勧めします。

*   **シェーダー:** より高度なマテリアル表現を実現するために、シェーダーの知識を深める。
*   **最適化:** 大規模な3Dモデルを効率的に表示するための最適化手法を学ぶ。
*   **インタラクション:** 3Dモデルとユーザーがインタラクションするための方法を学ぶ。
*   **物理エンジン:** 3Dモデルに物理的な挙動を与えるための物理エンジンの使い方を学ぶ。

### 4.2 glTFモデルの読み込みと表示 - GLTFLoaderの活用

**1. 概要と重要性**

glTF (GL Transmission Format) は、WebGLアプリケーションにおける3Dシーンの効率的な転送とロードのために設計された形式です。その軽量性とThree.jsとの親和性から、現代のWeb3D開発においてデファクトスタンダードとなっています。

**2. 特徴と利点**

*   **軽量性:** JSONベースで、バイナリデータとテクスチャを外部参照することで、ファイルサイズを最小限に抑えます。
*   **効率的なロード:** ランタイムでの解析とロードに最適化されています。
*   **PBR (Physically Based Rendering) マテリアル:** リアルな質感表現を可能にします。
*   **アニメーション:** スケルトンアニメーションやモーフターゲットアニメーションをサポートします。
*   **拡張性:** さまざまな拡張機能をサポートしており、特定のニーズに対応できます。

**3. 事前準備と前提条件**

*   Three.jsの基本的な知識
*   `three` npmパッケージのインストール (`npm install three`)
*   `GLTFLoader`のインポート

**4. 基本的な使い方**

```javascript
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

camera.position.z = 5;

const loader = new GLTFLoader();

loader.load(
  'path/to/your/model.gltf',
  function (gltf) {
    scene.add(gltf.scene);

    // optional: アクセサリの情報を記録 (アニメーションなど)
    // gltf.animations; // Array<THREE.AnimationClip>
    // gltf.scene;      // THREE.Group
    // gltf.scenes;     // Array<THREE.Group>
    // gltf.cameras;    // Array<THREE.Camera>
    // gltf.asset;      // Object

    renderer.render(scene, camera);
  },
  function (xhr) {
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  function (error) {
    console.error('An error happened', error);
  }
);

function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();
```

**5. 実践的なテクニック**

*   **モデルのスケール、回転、位置の調整:**

    ```javascript
    loader.load('path/to/model.gltf', (gltf) => {
      const model = gltf.scene;
      model.scale.set(0.5, 0.5, 0.5);
      model.rotation.y = Math.PI / 4;
      model.position.set(0, -1, 0);
      scene.add(model);
    });
    ```

*   **アニメーション付きglTFモデルの再生:**

    ```javascript
    loader.load('path/to/animated_model.gltf', (gltf) => {
      const model = gltf.scene;
      scene.add(model);

      const mixer = new THREE.AnimationMixer(model);
      const animations = gltf.animations;

      if (animations && animations.length) {
        animations.forEach((clip) => {
          mixer.clipAction(clip).play();
        });
      }

      function animate() {
        requestAnimationFrame(animate);
        mixer.update(0.01); // delta time
        renderer.render(scene, camera);
      }
      animate();
    });
    ```

*   **モデルの特定部分へのアクセス:**

    ```javascript
    loader.load('path/to/model.gltf', (gltf) => {
      const model = gltf.scene;

      // 名前でメッシュにアクセス
      const mesh = model.getObjectByName('MyMeshName');

      if (mesh) {
        // メッシュに対する操作
        mesh.material.color.setHex(0xff0000); // 赤色に変更
      }

      scene.add(model);
    });
    ```

**6. 応用例とユースケース**

*   **eコマース:** 製品のインタラクティブな3D表示。ユーザーは製品をあらゆる角度から確認できます。
*   **建築:** 建物のデザインやインテリアの仮想ウォークスルー。
*   **ゲーム:** 軽量で最適化されたキャラクターやオブジェクトの3Dモデル。
*   **教育:** 複雑な概念やオブジェクトを視覚的に表現。例えば、人体の3Dモデルをインタラクティブに表示。

**7. トラブルシューティング**

*   **モデルが表示されない:**
    *   ファイルパスが正しいことを確認。
    *   CORS (Cross-Origin Resource Sharing) の設定が適切であることを確認。
    *   ブラウザのデベロッパーツールでエラーメッセージを確認。
*   **テクスチャが表示されない:**
    *   テクスチャファイルがglTFファイルと同じディレクトリにあるか、正しいパスで参照されているか確認。
    *   テクスチャのフォーマットがブラウザでサポートされているか確認 (JPEG, PNG)。
*   **アニメーションが正常に再生されない:**
    *   `THREE.AnimationMixer`が正しく初期化されていることを確認。
    *   アニメーションクリップが正しく選択され、再生されていることを確認。
    *   delta timeが適切に設定されていることを確認。

**8. まとめと次のステップ**

`GLTFLoader`を使用することで、glTF形式の3DモデルをThree.jsアプリケーションに簡単にロードして表示できます。アニメーションやPBRマテリアルなどの高度な機能を活用することで、リッチな3Dエクスペリエンスを実現できます。

次のステップとしては、glTF形式のモデルを自分で作成したり、公開されているglTFモデルを探索して、さらに実践的な経験を積んでみてください。また、KHR_materials_transmission, KHR_materials_ior などのglTF拡張についても調べてみてください。

### 4.3 FBXモデルの読み込みと表示 - FBXLoaderの活用

**1. 概要と重要性**

FBX (Filmbox) は、Autodesk社が開発した、3Dモデル、アニメーション、シーン情報を格納するためのファイル形式です。多くの3Dモデリングソフトウェアでサポートされており、複雑なシーンやアニメーションをThree.jsで扱う場合に役立ちます。

**2. 特徴と利点**

*   **多様な情報:** 3Dモデル、マテリアル、テクスチャ、アニメーション、カメラ、ライトなどの情報を格納できます。
*   **互換性:** 多くの3Dソフトウェア (Maya, 3ds Max, Blenderなど) でサポートされています。
*   **バイナリ形式:** ファイルサイズを比較的小さく保てます。
*   **アニメーション:** スケルトンアニメーションやモーフターゲットアニメーションをサポートします。

**3. 事前準備と前提条件**

*   Three.jsの基本的な知識
*   `three` npmパッケージのインストール (`npm install three`)
*   `FBXLoader`のインポート

**4. 基本的な使い方**

```javascript
import * as THREE from 'three';
import { FBXLoader } from 'three/addons/loaders/FBXLoader.js';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

camera.position.z = 5;

const loader = new FBXLoader();

loader.load(
  'path/to/your/model.fbx',
  function (fbx) {
    scene.add(fbx);
    renderer.render(scene, camera);
  },
  function (xhr) {
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  function (error) {
    console.error('An error happened', error);
  }
);

function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();
```

**5. 実践的なテクニック**

*   **テクスチャの取り扱い:**

    FBXモデルにテクスチャが埋め込まれていない場合、別途テクスチャファイルを読み込んでマテリアルに設定する必要があります。

    ```javascript
    import { TextureLoader } from 'three';

    loader.load('path/to/model.fbx', (fbx) => {
      const textureLoader = new TextureLoader();
      const texture = textureLoader.load('path/to/texture.png');

      fbx.traverse((child) => {
        if (child.isMesh) {
          child.material.map = texture;
          child.material.needsUpdate = true; // マテリアルの更新を指示
        }
      });

      scene.add(fbx);
    });
    ```

*   **アニメーションの再生:**

    ```javascript
    loader.load('path/to/animated_model.fbx', (fbx) => {
      const mixer = new THREE.AnimationMixer(fbx);
      const animations = fbx.animations;

      if (animations && animations.length) {
        animations.forEach((clip) => {
          mixer.clipAction(clip).play();
        });
      }

      function animate() {
        requestAnimationFrame(animate);
        mixer.update(0.01); // delta time
        renderer.render(scene, camera);
      }
      animate();

      scene.add(fbx);
    });
    ```

*   **モデルの最適化:**

    FBXモデルは複雑なため、そのままWebで表示するとパフォーマンスが低下する可能性があります。以下の方法で最適化を試みてください。

    *   **ポリゴン数の削減:** 3Dモデリングソフトウェアでポリゴン数を減らす。
    *   **テクスチャの最適化:** テクスチャの解像度を下げる、または圧縮する。
    *   **不要なマテリアルの削除:** 使用されていないマテリアルを削除する。
    *   **`THREE.BufferGeometry`への変換:** メモリ効率が向上します。

**6. 応用例とユースケース**

*   **ゲーム開発:** 複雑なキャラクターモデルや背景モデルを使用するゲーム。
*   **建築ビジュアライゼーション:** 詳細な建築モデルやインテリアモデルを表示する。
*   **アニメーション:** Three.jsでアニメーション作品を作成する。
*   **バーチャルリアリティ/拡張現実:** 高度な3Dモデルを使用するVR/ARアプリケーション。

**7. トラブルシューティング**

*   **モデルが表示されない:**
    *   ファイルパスが正しいことを確認。
    *   FBXLoaderのバージョンがThree.jsのバージョンと互換性があるか確認。
    *   モデルのスケールが極端に小さくないか、または大きくないか確認。
*   **テクスチャが表示されない:**
    *   テクスチャファイルが正しいパスで参照されているか確認。
    *   テクスチャがマテリアルに正しく適用されているか確認。
*   **アニメーションが正常に再生されない:**
    *   `THREE.AnimationMixer`が正しく初期化されていることを確認。
    *   アニメーションクリップが正しく選択され、再生されていることを確認。

**8. まとめと次のステップ**

`FBXLoader`を使用することで、FBX形式の3DモデルをThree.jsアプリケーションにロードできます。複雑なシーンやアニメーションを扱う場合に適していますが、パフォーマンスに注意して最適化を行うようにしてください。

次のステップとしては、FBX形式のモデルを自分で作成したり、既存のFBXモデルをダウンロードして、Three.jsで表示する練習をしてみてください。アニメーションの制御やマテリアルの調整など、より高度なテクニックを学ぶこともお勧めです。

### 4.4 Blenderとの連携 - 3Dモデル作成からWeb表示まで

**1. 概要と重要性**

Blenderは、オープンソースで高機能な3Dモデリングソフトウェアです。モデリング、アニメーション、レンダリングなど、3D制作に必要な機能をすべて備えています。Blenderで作成した3DモデルをThree.jsで表示することで、Web上でインタラクティブな3Dコンテンツを制作できます。

**2. 特徴と利点**

*   **無料:** オープンソースソフトウェアなので、無料で利用できます。
*   **高機能:** プロレベルの3D制作に必要な機能をすべて備えています。
*   **活発なコミュニティ:** 豊富なチュートリアルやアドオンが利用できます。
*   **glTFエクスポート:** Three.jsとの連携に最適なglTF形式でエクスポートできます。

**3. 事前準備と前提条件**

*   Blenderのインストール
*   Three.jsの基本的な知識
*   テキストエディタ、IDE

**4. 基本的な使い方**

*   **Blenderでのモデル作成の基本:**

    *   **オブジェクトの追加:** `Shift + A`キーを押して、メッシュ、カーブ、サーフェス、メタボールなど、様々なオブジェクトを追加できます。
    *   **オブジェクトの編集:** オブジェクトを選択し、`Tab`キーを押して編集モードに切り替えます。頂点、辺、面を選択して、移動、回転、スケールなどの操作を行うことができます。
    *   **モディファイアーの使用:** モディファイアーは、オブジェクトに非破壊的な編集を加えるための機能です。サブディビジョンサーフェス、ベベル、ミラーなど、様々なモディファイアーを利用できます。
    *   **マテリアルの設定:** オブジェクトにマテリアルを設定することで、色、質感、反射などを表現できます。Blenderでは、CyclesレンダーエンジンまたはEeveeレンダーエンジンを使用して、リアルなマテリアルを作成できます。
    *   **UV展開:** オブジェクトにテクスチャを適用するために、UV展開を行う必要があります。UV展開とは、3Dオブジェクトの表面を2D平面に展開する作業です。
    *   **テクスチャの設定:** UV展開したオブジェクトにテクスチャを設定することで、よりリアルな質感を表現できます。

*   **BlenderからglTF形式でのエクスポート:**

    1.  Blenderで3Dモデルを作成し、必要なマテリアルとテクスチャを設定します。
    2.  `ファイル > エクスポート > glTF 2.0 (.glb/.gltf)`を選択します。
    3.  エクスポート設定を調整します。
        *   **形式:** glTF Binary (.glb) を推奨します (ファイルサイズが小さい)。
        *   **含める:**
            *   **選択オブジェクトのみ:** 選択したオブジェクトのみをエクスポートする場合にチェックします。
            *   **マテリアル:** マテリアルをエクスポートする場合にチェックします。
            *   **テクスチャ:** テクスチャをエクスポートする場合にチェックします。
            *   **アニメーション:** アニメーションをエクスポートする場合にチェックします。
        *   **トランスフォーム:**
            *   **Y軸を上:** Three.jsはY軸が上向きなので、通常はチェックします。
        *   **ジオメトリ:**
            *   **UVを適用:** UV展開したオブジェクトにテクスチャを適用する場合にチェックします。
    4.  `glTF 2.0をエクスポート`ボタンをクリックして、glTFファイルを保存します。

*   **Three.jsへのインポートと表示:**

    ```javascript
    import * as THREE from 'three';
    import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
    const renderer = new THREE.WebGLRenderer();
    renderer.setSize(window.innerWidth, window.innerHeight);
    document.body.appendChild(renderer.domElement);

    camera.position.z = 5;

    const loader = new GLTFLoader();

    loader.load(
      'path/to/your/model.glb', // エクスポートしたglTFファイルのパス
      function (gltf) {
        scene.add(gltf.scene);
        renderer.render(scene, camera);
      },
      function (xhr) {
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
      },
      function (error) {
        console.error('An error happened', error);
      }
    );

    function animate() {
      requestAnimationFrame(animate);
      renderer.render(scene, camera);
    }
    animate();
    ```

**5. 実践的なテクニック**

*   **PBR (Physically Based Rendering) マテリアルの設定:** BlenderでPBRマテリアルを設定することで、よりリアルな質感をThree.jsで表現できます。Principled BSDFシェーダーを使用し、ベースカラー、メタリック、ラフネス、スペキュラーなどのパラメータを調整します。
*   **アニメーションのリグ:** Blenderでキャラクターモデルにリグを設定することで、Three.jsでアニメーションを再生できます。アーマチュアを作成し、ボーンをキャラクターモデルにバインドします。
*   **カスタムプロパティ:** Blenderでカスタムプロパティを設定し、Three.jsでアクセスすることができます。これにより、Three.jsでモデルの動作を制御したり、インタラクションを追加したりすることができます。

**7. トラブルシューティング**

*   **BlenderからエクスポートしたモデルがThree.jsで正しく表示されない:**
    *   エクスポート設定が正しいか確認してください。特に、Y軸が上向きになっているか確認してください。
    *   スケールが極端に小さくないか、または大きくないか確認してください。
    *   マテリアルとテクスチャが正しくエクスポートされているか確認してください。
*   **アニメーションが再生されない:**
    *   アニメーションが正しくエクスポートされているか確認してください。
    *   `THREE.AnimationMixer`が正しく初期化されていることを確認。
    *   アニメーションクリップが正しく選択され、再生されていることを確認。
