## 付録: 用語集

この付録では、3Dグラフィックス、WebGL、Three.jsの学習と開発において頻繁に登場する用語を解説します。これらの用語を理解することで、公式ドキュメントの読解、エラーメッセージの解析、そして何よりスムーズな開発に役立つでしょう。初心者から上級者まで、幅広い読者層に向けて、それぞれの用語をわかりやすく、実践的に解説していきます。

### 19.1 3Dグラフィックス関連用語

#### 19.1.1 レンダリング (Rendering)

**概要と重要性:** 3Dモデルやシーンのデータを元に、2Dイメージを生成するプロセスのことです。最終的に画面に表示される画像を作り出す、3Dグラフィックスの中核となる部分です。レンダリング品質は、リアリティや美しさに直接影響します。

**特徴と利点:**

*   **リアルタイムレンダリング:** ゲームやインタラクティブなアプリケーションで使用され、高速な処理が求められます。
*   **オフラインレンダリング:** 映画やアニメーションで使用され、時間をかけて高品質な画像を生成します。

**事前準備と前提条件:** 3Dモデル、テクスチャ、ライティング、カメラ設定などが必要です。

**基本的な使い方:** レンダリングエンジンにシーンデータを入力し、出力画像の設定を行います。Three.jsでは`renderer.render(scene, camera)`が基本的なレンダリング命令です。

**実践的なテクニック:**

*   **シェーダーの最適化:** GPUの負荷を軽減し、パフォーマンスを向上させます。
*   **ライティングの調整:** シーンの雰囲気を大きく左右するため、光源の種類、色、強度などを細かく調整します。
*   **テクスチャの最適化:** 画像サイズ、圧縮形式などを調整し、メモリ使用量を削減します。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクター、背景、エフェクトなど、ゲーム内の全てのビジュアル要素をレンダリングします。
*   **建築ビジュアライゼーション:** 建物の設計段階で、完成後のイメージをリアルに再現します。
*   **映画製作:** 特殊効果、背景など、実写映像と組み合わせて使用されることが多いです。

**トラブルシューティング:**

*   **パフォーマンスが低い:** シェーダーの複雑さ、テクスチャサイズ、モデルのポリゴン数が原因であることが多いです。プロファイラを使用してボトルネックを特定し、最適化を行います。
*   **画像が正しく表示されない:** ライティング、マテリアルの設定、カメラの位置などが原因である可能性があります。各パラメータを丁寧に確認しましょう。

**まとめと次のステップ:** レンダリングは3Dグラフィックスの基礎であり、様々な技術が組み合わさって高品質な画像を生成します。より深く学ぶためには、シェーダー、ライティング、マテリアルなどの個々の要素を理解していくことが重要です。

#### 19.1.2 メッシュ (Mesh)

**概要と重要性:** 3Dオブジェクトの形状を定義する基本的な構成要素です。頂点、辺、面から構成され、これらの組み合わせによって様々な形状を表現できます。

**特徴と利点:**

*   **柔軟性:** 複雑な形状から単純な形状まで、あらゆるものを表現できます。
*   **効率性:** GPUによる高速な処理に適しています。

**事前準備と前提条件:** 頂点データ、面データ、法線ベクトルなどが必要です。

**基本的な使い方:** 頂点座標と面情報を定義し、メッシュオブジェクトを作成します。Three.jsでは`THREE.Mesh`クラスを使用します。

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 ); // 直方体のジオメトリを作成
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } ); // 緑色のマテリアルを作成
const cube = new THREE.Mesh( geometry, material ); // メッシュを作成
scene.add( cube ); // シーンに追加
```

**実践的なテクニック:**

*   **モデリングツール:** Blender、Maya、3ds Maxなどのモデリングツールを使用して、複雑なメッシュを作成します。
*   **プロシージャルモデリング:** コードによって自動的にメッシュを生成します。
*   **最適化:** ポリゴン数を削減し、パフォーマンスを向上させます。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクター、オブジェクト、背景など、ゲーム内の全ての3Dモデルはメッシュで構成されています。
*   **CAD/CAM:** 製品設計、製造などに使用される3Dモデルもメッシュで表現されます。
*   **3Dプリンティング:** メッシュデータを元に、物理的なオブジェクトを作成します。

**トラブルシューティング:**

*   **ポリゴン数が多すぎる:** パフォーマンスが低下する原因となります。不要なディテールを削除したり、LOD（Level of Detail）を使用するなどして、ポリゴン数を削減します。
*   **法線ベクトルが間違っている:** ライティングが正しく反映されず、不自然な表示になることがあります。法線ベクトルを再計算するか、モデリングツールで修正します。

**まとめと次のステップ:** メッシュは3Dグラフィックスの根幹をなす要素であり、その理解は3Dモデリング、レンダリングの基礎となります。様々なモデリングツールや技術を習得することで、より複雑で美しい3Dモデルを作成できるようになります。

#### 19.1.3 テクスチャ (Texture)

**概要と重要性:** 3Dオブジェクトの表面に貼り付ける画像のことです。オブジェクトの見た目を豊かにし、リアリティを高めるために不可欠です。

**特徴と利点:**

*   **詳細な表現:** 複雑な模様、色、質感を表現できます。
*   **効率性:** 少ないポリゴン数でも、ディテール感を出すことができます。

**事前準備と前提条件:** 画像ファイル（JPEG、PNGなど）が必要です。

**基本的な使い方:** テクスチャ画像をロードし、マテリアルに適用します。Three.jsでは`THREE.TextureLoader`クラスを使用します。

```javascript
const textureLoader = new THREE.TextureLoader();
const texture = textureLoader.load( 'textures/crate.gif' ); // テクスチャ画像をロード
const material = new THREE.MeshBasicMaterial( { map: texture } ); // マテリアルにテクスチャを適用
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );
```

**実践的なテクニック:**

*   **UVマッピング:** テクスチャを3Dオブジェクトの表面にどのように貼り付けるかを定義します。
*   **ミップマップ:** 遠くのオブジェクトのテクスチャをぼかして、パフォーマンスを向上させます。
*   **テクスチャアトラス:** 複数のテクスチャを1つの画像にまとめ、描画回数を減らします。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクターの服、建物の壁、地面など、あらゆるオブジェクトにテクスチャが使用されます。
*   **製品ビジュアライゼーション:** 製品の材質、色、質感をリアルに再現します。
*   **VR/AR:** 没入感を高めるために、高品質なテクスチャが重要です。

**トラブルシューティング:**

*   **テクスチャがぼやけている:** ミップマップの設定を確認します。
*   **テクスチャが歪んでいる:** UVマッピングの設定を確認します。
*   **テクスチャが表示されない:** 画像ファイルのパスが正しいか、ファイルが破損していないかを確認します。

**まとめと次のステップ:** テクスチャは3Dグラフィックスのリアリティを大きく向上させる重要な要素です。UVマッピング、ミップマップ、テクスチャアトラスなどの技術を習得することで、より高品質な3Dコンテンツを作成できます。

#### 19.1.4 シェーダー (Shader)

**概要と重要性:** GPU上で実行されるプログラムで、3Dオブジェクトの見た目を制御します。ライティング、テクスチャ、エフェクトなどを計算し、最終的なピクセル色を決定します。

**特徴と利点:**

*   **柔軟性:** 無限に近い表現力を持つ、高度なエフェクトを作成できます。
*   **パフォーマンス:** GPUによる並列処理により、高速な計算が可能です。

**事前準備と前提条件:** GLSL (OpenGL Shading Language) の知識が必要です。

**基本的な使い方:** バーテックスシェーダーとフラグメントシェーダーの2種類のシェーダーを記述し、マテリアルに適用します。

```javascript
const vertexShader = `
  void main() {
    gl_Position = projectionMatrix * modelViewMatrix * vec4( position, 1.0 );
  }
`;

const fragmentShader = `
  void main() {
    gl_FragColor = vec4( 1.0, 0.0, 0.0, 1.0 ); // 赤色
  }
`;

const material = new THREE.ShaderMaterial( {
  vertexShader: vertexShader,
  fragmentShader: fragmentShader
} );

const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );
```

**実践的なテクニック:**

*   **ライティングシェーダー:** Phongライティング、Blinn-Phongライティング、PBR（Physically Based Rendering）など、様々なライティングモデルを実装します。
*   **エフェクトシェーダー:** ブルーム、被写界深度、モーションブラーなど、ポストエフェクトを実装します。
*   **テクスチャシェーダー:** プロシージャルテクスチャ、ノイズテクスチャなどを生成します。

**応用例とユースケース:**

*   **ゲーム開発:** 高度なライティング、エフェクト、キャラクター表現などに使用されます。
*   **映画製作:** 特殊効果、コンポジットなどに使用されます。
*   **データ可視化:** 複雑なデータを視覚的に表現するために使用されます。

**トラブルシューティング:**

*   **シェーダーがコンパイルエラーになる:** GLSLの構文エラー、変数宣言の間違いなどが原因であることが多いです。エラーメッセージをよく確認し、修正します。
*   **シェーダーのパフォーマンスが低い:** 複雑な計算、大量のテクスチャアクセスなどが原因であることが多いです。最適化を行います。

**まとめと次のステップ:** シェーダーは3Dグラフィックスの表現力を飛躍的に向上させる強力なツールです。GLSLの知識を深め、様々なシェーダーテクニックを習得することで、独自の表現を実現できるようになります。

#### 19.1.5 法線 (Normal)

**概要と重要性:** 面の向きを示すベクトルです。ライティングの計算に使用され、オブジェクトの表面がどのように光を反射するかを決定します。

**特徴と利点:**

*   **ライティング:** 正確なライティングを計算するために不可欠です。
*   **シェーディング:** オブジェクトの表面の滑らかさを表現します。

**事前準備と前提条件:** 各頂点に対して、法線ベクトルが必要です。

**基本的な使い方:** 頂点座標から法線ベクトルを計算し、メッシュデータに含めます。

**実践的なテクニック:**

*   **スムージンググループ:** 隣接する面同士の法線ベクトルを平均化し、滑らかな表面を表現します。
*   **法線マップ:** テクスチャを使用して、表面のディテールを表現します。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクター、オブジェクト、背景など、ライティングが必要な全てのオブジェクトに使用されます。
*   **製品ビジュアライゼーション:** 製品の材質、表面の質感をリアルに再現します。

**トラブルシューティング:**

*   **ライティングが正しく反映されない:** 法線ベクトルの向きが間違っている可能性があります。法線ベクトルを再計算するか、モデリングツールで修正します。
*   **オブジェクトの表面がギザギザになる:** スムージンググループの設定を確認します。

**まとめと次のステップ:** 法線は3Dグラフィックスにおけるライティングの基礎となる重要な要素です。スムージンググループ、法線マップなどの技術を習得することで、よりリアルな3Dモデルを作成できます。

### 19.2 WebGL関連用語

#### 19.2.1 WebGLコンテキスト (WebGL Context)

**概要と重要性:** WebGLの描画を行うための環境です。WebGL APIを使用するためのエントリーポイントであり、描画に必要なリソース（バッファ、テクスチャ、シェーダーなど）を管理します。

**特徴と利点:**

*   **ハードウェアアクセラレーション:** GPUを活用した高速な描画が可能です。
*   **クロスプラットフォーム:** Webブラウザ上で動作するため、OSに依存しません。

**事前準備と前提条件:** HTML5の`<canvas>`要素が必要です。

**基本的な使い方:** `<canvas>`要素からWebGLコンテキストを取得します。

```javascript
const canvas = document.getElementById( 'myCanvas' );
const gl = canvas.getContext( 'webgl' ); // または 'webgl2'

if ( !gl ) {
  alert( 'WebGL is not supported.' );
}
```

**実践的なテクニック:**

*   **WebGL2:** より高度な機能が利用できるWebGLのバージョンです。
*   **エラーハンドリング:** WebGLの操作でエラーが発生した場合、原因を特定し、適切な処理を行います。

**応用例とユースケース:**

*   **ゲーム開発:** ブラウザ上で動作する3Dゲームを開発します。
*   **データ可視化:** Web上でインタラクティブな3Dグラフを表示します。
*   **CAD/CAM:** Webブラウザ上で3Dモデルを閲覧・編集します。

**トラブルシューティング:**

*   **WebGLが動作しない:** ブラウザがWebGLに対応しているか、ドライバが最新であるかを確認します。
*   **パフォーマンスが低い:** シェーダーの最適化、テクスチャサイズの削減などを行います。
*   **エラーが発生する:** WebGLのエラーコードを確認し、原因を特定します。

**まとめと次のステップ:** WebGLコンテキストはWebGLプログラミングの出発点です。WebGL APIを理解し、様々な描画処理を実装することで、Web上で高度な3Dグラフィックスを実現できます。

#### 19.2.2 バッファ (Buffer)

**概要と重要性:** 頂点データ、色データ、法線データなどをGPUに転送するためのメモリ領域です。WebGLは、このバッファに格納されたデータを使って描画を行います。

**特徴と利点:**

*   **高速アクセス:** GPUから高速にアクセスできます。
*   **効率的な描画:** 大量のデータを効率的に処理できます。

**事前準備と前提条件:** 頂点データ、色データ、法線データなどが必要です。

**基本的な使い方:** `gl.createBuffer()`でバッファオブジェクトを作成し、`gl.bindBuffer()`でバッファオブジェクトをバインドし、`gl.bufferData()`でデータをバッファオブジェクトに転送します。

```javascript
const vertices = [
  -0.5, -0.5, 0.0,
  0.5, -0.5, 0.0,
  0.0, 0.5, 0.0
];

const vertexBuffer = gl.createBuffer();
gl.bindBuffer( gl.ARRAY_BUFFER, vertexBuffer );
gl.bufferData( gl.ARRAY_BUFFER, new Float32Array( vertices ), gl.STATIC_DRAW );
```

**実践的なテクニック:**

*   **頂点バッファオブジェクト (VBO):** 頂点データを格納します。
*   **インデックスバッファオブジェクト (IBO):** 頂点を再利用し、メモリ使用量を削減します。
*   **動的バッファ:** 頻繁に更新されるデータを格納します。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクター、オブジェクト、背景など、ゲーム内の全ての3Dモデルのデータを格納します。
*   **データ可視化:** Web上でインタラクティブな3Dグラフを表示します。

**トラブルシューティング:**

*   **バッファにデータが正しく転送されない:** データ型、バッファサイズなどを確認します。
*   **パフォーマンスが低い:** バッファの更新頻度を削減します。

**まとめと次のステップ:** バッファはWebGLにおけるデータ管理の基本です。VBO、IBO、動的バッファなどの種類を理解し、適切に使用することで、効率的な描画を実現できます。

#### 19.2.3 シェーダープログラム (Shader Program)

**概要と重要性:** バーテックスシェーダーとフラグメントシェーダーを組み合わせたものです。GPU上で実行され、3Dオブジェクトの見た目を制御します。

**特徴と利点:**

*   **柔軟性:** 無限に近い表現力を持つ、高度なエフェクトを作成できます。
*   **パフォーマンス:** GPUによる並列処理により、高速な計算が可能です。

**事前準備と前提条件:** GLSLの知識が必要です。

**基本的な使い方:** バーテックスシェーダーとフラグメントシェーダーをコンパイルし、リンクしてシェーダープログラムを作成します。

```javascript
// バーテックスシェーダーとフラグメントシェーダーのソースコードは省略

const vertexShader = gl.createShader( gl.VERTEX_SHADER );
gl.shaderSource( vertexShader, vertexShaderSource );
gl.compileShader( vertexShader );

const fragmentShader = gl.createShader( gl.FRAGMENT_SHADER );
gl.shaderSource( fragmentShader, fragmentShaderSource );
gl.compileShader( fragmentShader );

const shaderProgram = gl.createProgram();
gl.attachShader( shaderProgram, vertexShader );
gl.attachShader( shaderProgram, fragmentShader );
gl.linkProgram( shaderProgram );
gl.useProgram( shaderProgram );
```

**実践的なテクニック:**

*   **ユニフォーム変数:** JavaScriptからシェーダーに値を渡します。
*   **アトリビュート変数:** バッファからシェーダーに値を渡します。
*   **varying変数:** バーテックスシェーダーからフラグメントシェーダーに値を渡します。

**応用例とユースケース:**

*   **ゲーム開発:** 高度なライティング、エフェクト、キャラクター表現などに使用されます。
*   **データ可視化:** 複雑なデータを視覚的に表現するために使用されます。

**トラブルシューティング:**

*   **シェーダーがコンパイルエラーになる:** GLSLの構文エラー、変数宣言の間違いなどが原因であることが多いです。エラーメッセージをよく確認し、修正します。
*   **シェーダープログラムがリンクエラーになる:** バーテックスシェーダーとフラグメントシェーダーの入出力が一致していない可能性があります。
*   **シェーダーのパフォーマンスが低い:** 複雑な計算、大量のテクスチャアクセスなどが原因であることが多いです。最適化を行います。

**まとめと次のステップ:** シェーダープログラムはWebGLにおける表現の中核をなす要素です。GLSLの知識を深め、様々なシェーダーテクニックを習得することで、独自の表現を実現できるようになります。

#### 19.2.4 Uniform変数

**概要と重要性:** JavaScriptのコードからWebGLのシェーダープログラムに値を渡すための仕組みです。ライトの色や位置、オブジェクトの変換行列など、フレームごとに変化する値をシェーダーに伝える際に使用します。

**特徴と利点:**

*   **動的な制御:** JavaScript側からシェーダーの挙動をリアルタイムに制御できます。
*   **グローバル変数:** シェーダープログラム全体で共有される変数です。

**事前準備と前提条件:** シェーダープログラムがコンパイル、リンクされている必要があります。GLSLの知識が必要です。

**基本的な使い方:**

1.  シェーダープログラム内で`uniform`キーワードを使って変数を宣言します。
    ```glsl
    // フラグメントシェーダーの例
    uniform vec3 u_lightColor; // ライトの色
    void main() {
      gl_FragColor = vec4(u_lightColor, 1.0);
    }
    ```
2.  JavaScript側で`gl.getUniformLocation()`を使ってUniform変数の場所（ロケーション）を取得します。
    ```javascript
    const lightColorLocation = gl.getUniformLocation(shaderProgram, "u_lightColor");
    ```
3.  適切な`gl.uniform...()`関数を使って値をUniform変数に設定します。例えば、`vec3`型のUniform変数には`gl.uniform3fv()`を使います。
    ```javascript
    const lightColor = [1.0, 0.8, 0.0]; // 黄色っぽいライト
    gl.uniform3fv(lightColorLocation, lightColor);
    ```

**実践的なテクニック:**

*   **複数のUniform変数:** 複数のUniform変数を組み合わせて、複雑なエフェクトを実現します。
*   **構造体Uniform:** 関連する複数の値をまとめてシェーダーに渡すことができます（WebGL2）。
*   **Uniformバッファオブジェクト(UBO):** 大量のUniform変数を効率的に更新できます（WebGL2）。

**応用例とユースケース:**

*   **ライティング:** ライトの色、強度、位置などをシェーダーに伝えます。
*   **変換行列:** オブジェクトの回転、拡大縮小、平行移動などの情報をシェーダーに伝えます。
*   **アニメーション:** 時間経過によって変化する値をシェーダーに伝えます。

**トラブルシューティング:**

*   **`gl.getUniformLocation()`が`null`を返す:** Uniform変数がシェーダープログラム内で宣言されていないか、名前が間違っている可能性があります。
*   **値が正しく反映されない:** Uniform変数の型と`gl.uniform...()`関数の種類が一致していない可能性があります。
*   **パフォーマンスが低い:** 大量のUniform変数を頻繁に更新するとパフォーマンスが低下する可能性があります。UBOの使用を検討してください（WebGL2）。

**まとめと次のステップ:** Uniform変数はWebGLにおいて、JavaScriptとシェーダープログラムを結びつける重要な役割を果たします。使いこなすことで、インタラクティブで動的な3Dグラフィックスを実現できます。

#### 19.2.5 Attribute変数

**概要と重要性:** WebGLにおいて、頂点データ（位置、色、法線など）をシェーダープログラムに渡すための仕組みです。各頂点に紐づいた情報をシェーダーに伝え、頂点ごとに異なる処理を行うことができます。

**特徴と利点:**

*   **頂点ごとのデータ:** 各頂点に固有の情報をシェーダーに渡すことができます。
*   **効率的な描画:** バッファオブジェクトと組み合わせて、大量の頂点データを効率的に処理できます。

**事前準備と前提条件:** シェーダープログラムがコンパイル、リンクされている必要があります。バッファオブジェクトに頂点データが格納されている必要があります。GLSLの知識が必要です。

**基本的な使い方:**

1.  シェーダープログラム内で`attribute`キーワードを使って変数を宣言します。
    ```glsl
    // バーテックスシェーダーの例
    attribute vec3 a_position; // 頂点の位置
    attribute vec3 a_color; // 頂点の色
    varying vec3 v_color; // フラグメントシェーダーに渡す色
    void main() {
      gl_Position = vec4(a_position, 1.0);
      v_color = a_color;
    }
    ```
2.  JavaScript側で`gl.getAttribLocation()`を使ってAttribute変数の場所（ロケーション）を取得します。
    ```javascript
    const positionLocation = gl.getAttribLocation(shaderProgram, "a_position");
    const colorLocation = gl.getAttribLocation(shaderProgram, "a_color");
    ```
3.  `gl.bindBuffer()`を使って頂点データを格納したバッファオブジェクトをバインドします。
    ```javascript
    gl.bindBuffer(gl.ARRAY_BUFFER, positionBuffer);
    ```
4.  `gl.vertexAttribPointer()`を使ってAttribute変数の場所、データの型、ストライド、オフセットなどを設定します。
    ```javascript
    gl.vertexAttribPointer(positionLocation, 3, gl.FLOAT, false, 0, 0);
    ```
5.  `gl.enableVertexAttribArray()`を使ってAttribute変数を有効にします。
    ```javascript
    gl.enableVertexAttribArray(positionLocation);
    gl.enableVertexAttribArray(colorLocation);
    ```

**実践的なテクニック:**

*   **インターリーブドバッファ:** 複数のAttribute変数のデータを1つのバッファオブジェクトにまとめて格納し、メモリ効率を向上させます。
*   **インスタンス描画:** 同じ形状のオブジェクトを大量に描画する際に、Attribute変数を使って各インスタンスの位置や色などの情報を個別に制御します。

**応用例とユースケース:**

*   **3Dモデルの描画:** 頂点の位置、法線、テクスチャ座標などをシェーダーに渡します。
*   **パーティクルシステム:** 各パーティクルの位置、速度、寿命などをAttribute変数を使って制御します。

**トラブルシューティング:**

*   **`gl.getAttribLocation()`が`-1`を返す:** Attribute変数がシェーダープログラム内で宣言されていないか、名前が間違っている可能性があります。
*   **形状が正しく描画されない:** `gl.vertexAttribPointer()`の設定が間違っている可能性があります。データの型、ストライド、オフセットなどを確認してください。
*   **パフォーマンスが低い:** 大量のAttribute変数を有効にするとパフォーマンスが低下する可能性があります。不要なAttribute変数は無効にしてください。

**まとめと次のステップ:** Attribute変数はWebGLにおいて、頂点データをシェーダープログラムに渡すための重要な仕組みです。使いこなすことで、複雑な3Dモデルやパーティクルシステムなどを効率的に描画できます。

### 19.3 Three.js関連用語

#### 19.3.1 シーン (Scene)

**概要と重要性:** Three.jsにおける3D空間のコンテナです。3Dオブジェクト、ライト、カメラなど、画面に表示されるすべての要素を格納します。

**特徴と利点:**

*   **階層構造:** オブジェクトを親子関係で管理できます。
*   **シーングラフ:** シーン内のオブジェクトの関係性をグラフ構造で表現します。

**事前準備と前提条件:** Three.jsライブラリが必要です。

**基本的な使い方:** `THREE.Scene`クラスを使用して、シーンオブジェクトを作成します。

```javascript
const scene = new THREE.Scene();
```

**実践的なテクニック:**

*   **シーンの最適化:** シーン内のオブジェクト数を削減したり、LOD（Level of Detail）を使用したりして、パフォーマンスを向上させます。
*   **シーングラフの活用:** 親オブジェクトを移動・回転させると、子オブジェクトも連動して移動・回転します。

**応用例とユースケース:**

*   **ゲーム開発:** ゲーム内の全ての3Dオブジェクトはシーンに追加されます。
*   **建築ビジュアライゼーション:** 建物の3Dモデルをシーンに配置し、様々な角度から見ることができます。

**トラブルシューティング:**

*   **オブジェクトが表示されない:** シーンにオブジェクトが追加されているか、カメラの位置が適切かを確認します。
*   **パフォーマンスが低い:** シーン内のオブジェクト数が多すぎる可能性があります。

**まとめと次のステップ:** シーンはThree.jsにおける3D空間の基盤です。シーングラフを理解し、シーンの最適化を行うことで、より複雑で大規模な3Dアプリケーションを開発できます。

#### 19.3.2 カメラ (Camera)

**概要と重要性:** 3D空間をどの視点から見るかを定義します。カメラの位置、向き、視野角などを設定することで、最終的に画面に表示される画像が決まります。

**特徴と利点:**

*   **視点制御:** ユーザーの操作に応じて、カメラを移動・回転させることができます。
*   **投影:** 3D空間を2D画面に投影します。

**事前準備と前提条件:** シーンオブジェクトが必要です。

**基本的な使い方:** `THREE.PerspectiveCamera`クラスまたは`THREE.OrthographicCamera`クラスを使用して、カメラオブジェクトを作成します。

```javascript
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 ); // 視野角75度、アスペクト比、nearクリップ、farクリップ
camera.position.z = 5; // カメラの位置
scene.add( camera );
```

**実践的なテクニック:**

*   **カメラコントロール:** OrbitControls、FlyControls、FirstPersonControlsなど、様々なカメラコントロールを使用できます。
*   **カメラアニメーション:** Tween.jsなどを使用して、カメラをアニメーションさせることができます。

**応用例とユースケース:**

*   **ゲーム開発:** プレイヤーの視点、三人称視点、固定視点など、ゲームの種類に応じてカメラを設定します。
*   **建築ビジュアライゼーション:** 建物の内部、外部を様々な角度から見ることができます。

**トラブルシューティング:**

*   **オブジェクトが表示されない:** カメラの位置、向き、視野角が適切かを確認します。
*   **オブジェクトがクリップされる:** nearクリップ、farクリップの設定を確認します。

**まとめと次のステップ:** カメラは3Dグラフィックスにおける視覚的な表現を決定する重要な要素です。カメラコントロール、カメラアニメーションなどの技術を習得することで、よりインタラクティブな3Dアプリケーションを開発できます。

#### 19.3.3 ジオメトリ (Geometry)

**概要と重要性:** 3Dオブジェクトの形状を定義します。頂点、面、法線ベクトルなどから構成されます。Three.jsには、様々な種類のジオメトリが用意されています。

**特徴と利点:**

*   **多様な形状:** 箱、球、円柱、円錐、平面など、様々な基本的な形状を作成できます。
*   **カスタム形状:** 独自の形状を定義することも可能です。

**事前準備と前提条件:** シーンオブジェクトが必要です。

**基本的な使い方:** `THREE.BoxGeometry`、`THREE.SphereGeometry`、`THREE.PlaneGeometry`などのクラスを使用して、ジオメトリオブジェクトを作成します。

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 ); // 直方体のジオメトリを作成
```

**実践的なテクニック:**

*   **BufferGeometry:** より高速な描画が可能なジオメトリです。
*   **ジオメトリの結合:** 複数のジオメトリを1つのジオメトリに結合することで、描画回数を削減できます。
*   **ジオメトリの編集:** 頂点座標を編集することで、形状を変形させることができます。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクター、オブジェクト、背景など、ゲーム内の全ての3Dモデルの形状を定義します。
*   **CAD/CAM:** 製品設計、製造などに使用される3Dモデルの形状を定義します。

**トラブルシューティング:**

*   **オブジェクトが表示されない:** ジオメトリが正しく定義されているか、マテリアルが適用されているかを確認します。
*   **オブジェクトの形状が歪んでいる:** 頂点座標、法線ベクトルが正しいかを確認します。

**まとめと次のステップ:** ジオメトリは3Dオブジェクトの形状を決定する基本的な要素です。BufferGeometry、ジオメトリの結合、ジオメトリの編集などの技術を習得することで、より複雑で美しい3Dモデルを作成できます。

#### 19.3.4 マテリアル (Material)

**概要と重要性:** 3Dオブジェクトの表面の質感や色を定義します。ライティング、テクスチャ、反射などの効果を表現するために使用されます。Three.jsには、様々な種類のマテリアルが用意されています。

**特徴と利点:**

*   **多様な表現:** 色、質感、反射、透明度など、様々な要素を制御できます。
*   **物理ベースレンダリング (PBR):** よりリアルな表現が可能です。

**事前準備と前提条件:** ジオメトリオブジェクトが必要です。

**基本的な使い方:** `THREE.MeshBasicMaterial`、`THREE.MeshLambertMaterial`、`THREE.MeshPhongMaterial`、`THREE.MeshStandardMaterial`などのクラスを使用して、マテリアルオブジェクトを作成します。

```javascript
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } ); // 緑色のマテリアルを作成
```

**実践的なテクニック:**

*   **テクスチャマッピング:** テクスチャ画像をマテリアルに適用し、表面のディテールを表現します。
*   **ノーマルマッピング:** 法線マップを使用して、表面の凹凸を表現します。
*   **環境マッピング:** 環境光を反射させ、リアルな金属のような表現を実現します。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクターの服、建物の壁、地面など、あらゆるオブジェクトの質感を定義します。
*   **製品ビジュアライゼーション:** 製品の材質、色、質感をリアルに再現します。

**トラブルシューティング:**

*   **オブジェクトの色が表示されない:** マテリアルの`color`プロパティが正しく設定されているかを確認します。
*   **テクスチャが表示されない:** テクスチャ画像のパスが正しいか、UVマッピングの設定を確認します。
*   **ライティングが正しく反映されない:** マテリアルの種類、ライティングの設定を確認します。

**まとめと次のステップ:** マテリアルは3Dオブジェクトの見た目を決定する重要な要素です。テクスチャマッピング、ノーマルマッピング、環境マッピングなどの技術を習得することで、よりリアルで美しい3Dコンテンツを作成できます。

#### 19.3.5 メッシュ (Mesh)

**概要と重要性:** ジオメトリとマテリアルを組み合わせて、3Dオブジェクトを作成します。シーンに追加することで、画面に表示されます。

**特徴と利点:**

*   **柔軟な表現:** 複雑な形状、リアルな質感を表現できます。
*   **パフォーマンス:** GPUによる高速な描画に適しています。

**事前準備と前提条件:** ジオメトリオブジェクト、マテリアルオブジェクトが必要です。

**基本的な使い方:** `THREE.Mesh`クラスを使用して、メッシュオブジェクトを作成します。

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 ); // 直方体のジオメトリを作成
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } ); // 緑色のマテリアルを作成
const cube = new THREE.Mesh( geometry, material ); // メッシュを作成
scene.add( cube ); // シーンに追加
```

**実践的なテクニック:**

*   **シャドウ:** オブジェクトに影を落とすことで、よりリアルな表現を実現します。
*   **LOD (Level of Detail):** オブジェクトの距離に応じて、詳細度を調整することで、パフォーマンスを向上させます。
*   **アニメーション:** オブジェクトをアニメーションさせることで、よりダイナミックな表現を実現します。

**応用例とユースケース:**

*   **ゲーム開発:** キャラクター、オブジェクト、背景など、ゲーム内の全ての3Dモデルはメッシュで構成されています。
*   **建築ビジュアライゼーション:** 建物の3Dモデルをシーンに配置し、様々な角度から見ることができます。

**トラブルシューティング:**

*   **オブジェクトが表示されない:** メッシュがシーンに追加されているか、カメラの位置が適切かを確認します。
*   **オブジェクトの形状が歪んでいる:** ジオメトリが正しく定義されているか、マテリアルが適用されているかを確認します。
*   **オブジェクトのパフォーマンスが低い:** ポリゴン数が多すぎる可能性があります。LODを使用したり、ポリゴン数を削減したりすることで、パフォーマンスを向上させることができます。

**まとめと次のステップ:** メッシュはThree.jsにおける3Dオブジェクトの基本的な要素です。シャドウ、LOD、アニメーションなどの技術を習得することで、より高度な3Dアプリケーションを開発できます。
