## 第4章: シェーダープログラミング - GLSLによる高度な表現

この章では、WebGLの力を最大限に引き出すためのシェーダープログラミングについて解説します。特にGLSL（OpenGL Shading Language）を用いて、Three.jsの標準機能では実現できない、より高度で視覚的に魅力的な表現を可能にする方法を探求します。シェーダーは、3Dグラフィックスの描画パイプラインをカスタマイズするための強力なツールであり、理解することで、パフォーマンスの最適化や独自の視覚効果の創造に大きく貢献できます。

### 5.1 シェーダーの基礎 - GLSLの文法と構造

#### 概要と重要性

シェーダーは、GPU上で実行される小さなプログラムです。3Dオブジェクトの頂点座標を変換したり、ピクセルの色を決定したりする役割を担います。標準的なレンダリングパイプラインでは実現できない表現を可能にし、ゲーム、インタラクティブアート、データ可視化など、幅広い分野で利用されています。

#### 特徴と利点

- **高度なカスタマイズ性:** 描画処理を細かく制御し、独自の視覚効果を生み出せる。
- **パフォーマンスの最適化:** GPUの並列処理能力を活用し、複雑な計算を高速に実行できる。
- **プラットフォームの独立性:** OpenGL ESをサポートする環境であれば、Webブラウザだけでなく、モバイルデバイスなどでも動作する。

#### 事前準備と前提条件

- Three.jsの基本的な知識 (シーン、カメラ、レンダラーの概念)
- JavaScriptの基礎知識
- GLSLの基本的な文法（これから説明します）

#### 基本的な使い方

GLSLはC言語に似た文法を持つ言語です。主な要素は以下の通りです。

*   **変数:** `float`, `vec3`, `mat4` など、さまざまなデータ型があります。
*   **関数:**  処理をまとめるために使用します。`void main()` がエントリーポイントになります。
*   **制御構造:** `if`, `for`, `while` など、条件分岐やループ処理を行います。
*   **プリプロセッサ:** `#define`, `#ifdef` など、コンパイル時にコードを制御するために使用します。

**頂点シェーダーとフラグメントシェーダーの違い**

WebGLのシェーダーは主に、**頂点シェーダー**と**フラグメントシェーダー**の2種類があります。

*   **頂点シェーダー:** モデルの頂点座標を処理し、クリップ空間への変換を行います。各頂点に対して一度実行されます。
*   **フラグメントシェーダー:** ラスタライズされたピクセル（フラグメント）の色を決定します。各ピクセルに対して実行されます。

```glsl
// 頂点シェーダーの例
#version 300 es
in vec3 position;
uniform mat4 modelViewMatrix;
uniform mat4 projectionMatrix;

void main() {
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}

// フラグメントシェーダーの例
#version 300 es
precision highp float;
out vec4 fragColor;

void main() {
    fragColor = vec4(1.0, 0.0, 0.0, 1.0); // 赤色
}
```

上記の例では、頂点シェーダーは頂点の位置を変換し、フラグメントシェーダーはピクセルの色を赤色に設定しています。

**GLSLの変数、関数、制御構造**

以下はGLSLの変数、関数、制御構造の例です。

```glsl
// 変数
float myFloat = 1.0;
vec3 myVector = vec3(0.5, 0.2, 0.8);
mat4 myMatrix = mat4(1.0);

// 関数
float calculateBrightness(vec3 color) {
  return (color.r + color.g + color.b) / 3.0;
}

// 制御構造
if (myFloat > 0.5) {
  // 処理
}

for (int i = 0; i < 10; i++) {
  // 処理
}
```

**シェーダーのコンパイルと実行**

Three.jsでシェーダーを使用するには、GLSLのコードを文字列としてJavaScriptに記述し、`THREE.ShaderMaterial`または`THREE.RawShaderMaterial`に渡します。Three.jsがコンパイルと実行を処理します。

```javascript
const vertexShader = `
  #version 300 es
  in vec3 position;
  uniform mat4 modelViewMatrix;
  uniform mat4 projectionMatrix;

  void main() {
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const fragmentShader = `
  #version 300 es
  precision highp float;
  out vec4 fragColor;

  void main() {
    fragColor = vec4(1.0, 0.0, 0.0, 1.0); // 赤色
  }
`;

const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader
});

const geometry = new THREE.BoxGeometry(1, 1, 1);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);
```

#### 実践的なテクニック

*   **varying変数:** 頂点シェーダーからフラグメントシェーダーへデータを渡すために使用します。頂点シェーダーで値を設定し、フラグメントシェーダーで受け取ります。値はピクセルごとに補間されます。
*   **uniform変数:** JavaScriptからシェーダーへデータを渡すために使用します。時間、マウス位置、テクスチャなど、さまざまなデータをシェーダーに渡すことができます。
*   **precision:**  シェーダーの精度を指定します。`highp`, `mediump`, `lowp` があります。モバイルデバイスでは、パフォーマンスを考慮して `mediump` や `lowp` を使用することがあります。

#### 応用例とユースケース

*   **カスタムライティング:** 標準のLambertやPhongライティングモデルを拡張し、独自のライティング効果を実装する。
*   **テクスチャマッピングの拡張:** テクスチャ座標を操作し、複雑なテクスチャ表現を実現する。
*   **プロシージャルテクスチャ:** 画像ファイルを使用せずに、数学的な関数を用いてテクスチャを生成する。

#### トラブルシューティング

*   **シェーダーのコンパイルエラー:** GLSLの文法エラーが原因であることが多いです。ブラウザの開発者ツールでエラーメッセージを確認し、修正してください。
*   **シェーダーが動作しない:** uniform変数の値が正しく設定されていない、varying変数が正しく定義されていないなどが原因として考えられます。
*   **パフォーマンスの問題:** シェーダーが複雑すぎる、精度が高すぎるなどが原因として考えられます。シェーダーの処理を最適化したり、精度を下げたりしてみてください。

#### まとめと次のステップ

このセクションでは、シェーダーの基本的な概念とGLSLの文法について学びました。次のセクションでは、これらの知識を応用して、Three.jsでカスタムマテリアルを作成する方法を解説します。

### 5.2 カスタムマテリアルの作成 - ShaderMaterial, RawShaderMaterial

#### 概要と重要性

Three.jsには、標準のマテリアル（`MeshBasicMaterial`, `MeshLambertMaterial`など）が用意されていますが、より高度な表現を実現するためには、シェーダーを使ってカスタムマテリアルを作成する必要があります。`ShaderMaterial`と`RawShaderMaterial`は、Three.jsでカスタムマテリアルを作成するための主要なクラスです。

#### 特徴と利点

- **柔軟性:** 描画処理を完全に制御できるため、標準マテリアルでは不可能な表現を実現できる。
- **パフォーマンス:** 複雑な処理をGPUにオフロードできるため、CPU負荷を軽減できる。
- **独自の視覚効果:** アニメーション、歪み、特殊なライティングなど、独自の視覚効果を創造できる。

#### 事前準備と前提条件

- シェーダーの基礎知識 (前セクション参照)
- Three.jsの基本的な知識 (シーン、カメラ、レンダラー、マテリアルの概念)

#### 基本的な使い方

**ShaderMaterialによるカスタムマテリアルの作成**

`THREE.ShaderMaterial`は、頂点シェーダーとフラグメントシェーダーを受け取り、マテリアルを作成します。

```javascript
const vertexShader = `
  #version 300 es
  in vec3 position;
  uniform mat4 modelViewMatrix;
  uniform mat4 projectionMatrix;

  void main() {
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const fragmentShader = `
  #version 300 es
  precision highp float;
  out vec4 fragColor;
  uniform vec3 color;

  void main() {
    fragColor = vec4(color, 1.0);
  }
`;

const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    color: { value: new THREE.Color(0xff0000) } // 赤色
  }
});

const geometry = new THREE.BoxGeometry(1, 1, 1);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);
```

上記の例では、uniform変数 `color` を使って、マテリアルの色を制御しています。

**RawShaderMaterialによるローレベルな制御**

`THREE.RawShaderMaterial`は、よりローレベルな制御を可能にするマテリアルです。WebGLの描画状態を直接設定できます。

```javascript
const material = new THREE.RawShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    color: { value: new THREE.Color(0xff0000) } // 赤色
  },
  side: THREE.DoubleSide, // 両面を描画
  transparent: true, // 透明度を有効にする
  depthTest: false // デプステストを無効にする
});
```

`RawShaderMaterial`は、高度なカスタマイズが必要な場合に有効ですが、Three.jsの標準的な機能との互換性が低い場合があるため、注意が必要です。

**Uniform変数の利用**

Uniform変数は、JavaScriptからシェーダーに値を渡すための重要な仕組みです。`uniforms`プロパティに、uniform変数の名前と初期値を設定します。

```javascript
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    time: { value: 0.0 },
    resolution: { value: new THREE.Vector2(window.innerWidth, window.innerHeight) }
  }
});

// アニメーションループでuniform変数の値を更新する
function animate() {
  requestAnimationFrame(animate);
  material.uniforms.time.value += 0.01;
  renderer.render(scene, camera);
}

animate();
```

#### 実践的なテクニック

*   **テクスチャの利用:** `THREE.TextureLoader`を使ってテクスチャをロードし、uniform変数としてシェーダーに渡すことができます。
*   **マウスインタラクション:** マウスの位置をuniform変数としてシェーダーに渡し、マウス操作に応じて視覚効果を変化させることができます。
*   **時間経過によるアニメーション:** 時間をuniform変数としてシェーダーに渡し、アニメーションを生成することができます。

#### 応用例とユースケース

*   **水の表現:** 波紋や屈折をシミュレートした水面を表現する。
*   **炎の表現:** ノイズ関数を使って、リアルな炎を表現する。
*   **溶岩の表現:** フラクタル地形と色変化を組み合わせて、溶岩を表現する。

#### トラブルシューティング

*   **uniform変数の値が更新されない:** `needsUpdate`プロパティを`true`に設定する必要がある場合があります。
*   **テクスチャが正しく表示されない:** テクスチャのフィルタリング設定やラップ設定を確認してください。

#### まとめと次のステップ

このセクションでは、`ShaderMaterial`と`RawShaderMaterial`を使って、カスタムマテリアルを作成する方法を学びました。次のセクションでは、レンダリング結果にポストエフェクトを適用する方法を解説します。

### 5.3 ポストエフェクト - RenderTarget, EffectComposer

#### 概要と重要性

ポストエフェクトは、3Dシーンのレンダリング結果に対して、追加的な視覚効果を適用する技術です。画面全体にフィルターをかけるイメージです。ブルーム、ブラー、グレースケールなど、さまざまな効果を適用することで、シーンの雰囲気を大きく変えることができます。

#### 特徴と利点

- **視覚的な魅力の向上:** シーンの見た目を劇的に改善できる。
- **柔軟性:** さまざまなポストエフェクトを組み合わせることで、独自の表現を作り出せる。
- **パフォーマンス:** リアルタイムに適用できる。

#### 事前準備と前提条件

- カスタムマテリアルの作成 (前セクション参照)
- Three.jsの基本的な知識 (シーン、カメラ、レンダラー、マテリアルの概念)

#### 基本的な使い方

**RenderTargetによるオフスクリーンレンダリング**

ポストエフェクトを適用するには、まずシーンを`THREE.WebGLRenderTarget`にレンダリングする必要があります。`WebGLRenderTarget`は、画面とは別の場所にシーンをレンダリングするためのオブジェクトです。

```javascript
const renderTarget = new THREE.WebGLRenderTarget(window.innerWidth, window.innerHeight);
```

**EffectComposerによるポストエフェクトの適用**

`THREE.EffectComposer`は、複数のポストエフェクトを連結して適用するためのクラスです。`EffectComposer`を使用するには、`three/examples/jsm/postprocessing/EffectComposer.js`をインポートする必要があります。また、適用したいエフェクトもそれぞれインポートする必要があります。

```javascript
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/examples/jsm/postprocessing/RenderPass.js';
import { BloomPass } from 'three/examples/jsm/postprocessing/BloomPass.js';
import { ShaderPass } from 'three/examples/jsm/postprocessing/ShaderPass.js';

const composer = new EffectComposer(renderer, renderTarget);

const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

const bloomPass = new BloomPass(1.0, 25, 4, 256); // intensity, kernelSize, sigma , blurStrength
composer.addPass(bloomPass);

// アニメーションループでEffectComposerを使ってレンダリングする
function animate() {
  requestAnimationFrame(animate);
  composer.render();
}

animate();
```

上記の例では、`RenderPass`でシーンをレンダリングし、`BloomPass`でブルーム効果を適用しています。

**複数のポストエフェクトの組み合わせ**

複数のポストエフェクトを組み合わせることで、より複雑な表現が可能になります。

```javascript
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/examples/jsm/postprocessing/RenderPass.js';
import { BloomPass } from 'three/examples/jsm/postprocessing/BloomPass.js';
import { ShaderPass } from 'three/examples/jsm/postprocessing/ShaderPass.js';
import { LuminosityHighPassShader } from 'three/examples/jsm/shaders/LuminosityHighPassShader.js';
import { FXAAShader } from 'three/examples/jsm/shaders/FXAAShader.js';

const composer = new EffectComposer(renderer, renderTarget);

const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// 高輝度部分のみを抽出するパス
const highLightPass = new ShaderPass( new LuminosityHighPassShader(), "tDiffuse" );
highLightPass.uniforms[ "luminosityThreshold" ].value = 0.5;  // 輝度の閾値
composer.addPass( highLightPass );

const bloomPass = new BloomPass(1.0, 25, 4, 256); // intensity, kernelSize, sigma , blurStrength
composer.addPass(bloomPass);

// FXAAでアンチエイリアスをかけるパス
const FXAApass = new ShaderPass( FXAAShader );
const pixelRatio = renderer.getPixelRatio();
FXAApass.material.uniforms[ 'resolution' ].value.x = 1 / ( window.innerWidth * pixelRatio );
FXAApass.material.uniforms[ 'resolution' ].value.y = 1 / ( window.innerHeight * pixelRatio );
composer.addPass( FXAApass );
```

**グレースケールの適用**

グレースケールを適用するには、カスタムシェーダーを使用します。

```javascript
const grayscaleShader = {
  uniforms: {
    tDiffuse: { value: null }
  },
  vertexShader: `
    varying vec2 vUv;

    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform sampler2D tDiffuse;
    varying vec2 vUv;

    void main() {
      vec4 color = texture2D(tDiffuse, vUv);
      float gray = dot(color.rgb, vec3(0.299, 0.587, 0.114));
      gl_FragColor = vec4(vec3(gray), color.a);
    }
  `
};

const grayscalePass = new ShaderPass(grayscaleShader);
composer.addPass(grayscalePass);
```

**ブラーの適用**

ブラーを適用するには、`THREE.ShaderPass`とブラーシェーダーを使用します。

```javascript
import { HorizontalBlurShader } from 'three/examples/jsm/shaders/HorizontalBlurShader.js';
import { VerticalBlurShader } from 'three/examples/jsm/shaders/VerticalBlurShader.js';

const hblurPass = new ShaderPass( HorizontalBlurShader );
hblurPass.uniforms[ 'h' ].value = 2 / ( window.innerWidth ); // 水平方向のぼかし幅
composer.addPass( hblurPass );

const vblurPass = new ShaderPass( VerticalBlurShader );
vblurPass.uniforms[ 'v' ].value = 2 / ( window.innerHeight ); // 垂直方向のぼかし幅
composer.addPass( vblurPass );
```

#### 実践的なテクニック

*   **ポストエフェクトの強度を調整する:** uniform変数を使って、ポストエフェクトの強度を調整することができます。
*   **ポストエフェクトを特定のオブジェクトのみに適用する:** stencil bufferを使って、特定のオブジェクトのみにポストエフェクトを適用することができます。
*   **パフォーマンスを最適化する:** ポストエフェクトは処理負荷が高い場合があるため、解像度を下げる、エフェクトの数を減らすなど、パフォーマンスを最適化する必要があります。

#### 応用例とユースケース

*   **映画のようなルック:** カラーグレーディングやビネット効果を適用して、映画のような雰囲気を出す。
*   **ゲームのエフェクト:** 爆発、炎、魔法など、ゲームならではのエフェクトを表現する。
*   **建築ビジュアライゼーション:** 現実感を高めるために、被写界深度やブルーム効果を適用する。

#### トラブルシューティング

*   **ポストエフェクトが適用されない:** `EffectComposer`の`render`メソッドが呼ばれていない、ポストエフェクトのパスが正しく追加されていないなどが原因として考えられます。
*   **パフォーマンスが低い:** ポストエフェクトの数が多い、解像度が高いなどが原因として考えられます。

#### まとめと次のステップ

このセクションでは、`RenderTarget`と`EffectComposer`を使って、ポストエフェクトを適用する方法を学びました。次のセクションでは、シェーダーを使って、ノイズ、フラクタル、パーティクルなどの高度な表現を実装する方法を解説します。

### 5.4 シェーダーによる高度な表現 - ノイズ、フラクタル、パーティクル

#### 概要と重要性

シェーダーを使うことで、ノイズ、フラクタル、パーティクルといった、より複雑で高度な表現が可能になります。これらの技術は、ゲーム、インタラクティブアート、データ可視化など、幅広い分野で利用されています。

#### 特徴と利点

- **リアリティの向上:** 自然界の複雑なパターンを再現できる。
- **ダイナミックな表現:** アニメーションやインタラクションによって、視覚効果を変化させられる。
- **効率的な処理:** GPUの並列処理能力を活用し、複雑な計算を高速に実行できる。

#### 事前準備と前提条件

- シェーダーの基礎知識 (5.1参照)
- カスタムマテリアルの作成 (5.2参照)
- Three.jsの基本的な知識 (シーン、カメラ、レンダラー、マテリアルの概念)

#### 基本的な使い方

**ノイズ関数 (Simplex Noise, Perlin Noise) の実装**

ノイズ関数は、ランダムに見える値を生成するための関数です。Simplex NoiseやPerlin Noiseは、自然な見た目のノイズを生成するためによく使われます。

```glsl
// Simplex Noiseの実装例 (GLSL)
// (このコードは例示であり、実際にはより最適化された実装が存在します)
vec3 permute(vec3 t) {
  return mod((34.0 * t + 1.0) * t, 289.0);
}

float snoise(vec3 v) {
  const vec4 C = vec4(0.138196601125976, 0.276393202251953, 4.1015625, 0.5);
  vec3 i  = floor(v + dot(v, vec3(C.y)));
  vec3 x0 = v -   i + dot(i, vec3(C.x));

  vec3 i1;
  i1.x = step( x0.y, x0.x );
  i1.y = step( x0.z, x0.y );
  i1.z = step( x0.x, x0.z );

  vec3 x1 = x0 - i1 + C.x;
  vec3 x2 = x0 - 1.0 + C.y;

  vec3 i = mod(i, 289.0);
  vec3 p = permute(permute(permute( i.z + vec3(0.0, i1.z, 1.0 )))
       + i.y + vec3(0.0, i1.y, 1.0 ));

  vec3 m = max(0.5 - vec3(dot(x0,x0), dot(x1,x1), dot(x2,x2)), 0.0);
  m = m*m * m*m;
  vec3 x = 2.0 * fract(p * C.w) - 1.0;
  vec3 h = abs(x) - 0.5;
  vec3 fl = floor(x + 0.5);
  vec3 s = sign(h);
  vec3 a = x - fl;
  return 127.5 * dot(m, s * (a * a * a * a - a * a)) - 1.0;
}
```

上記のコードは3D Simplex Noiseの一例です。GLSLでノイズ関数を実装するには、様々な実装方法があります。書籍やWebサイトで公開されているものを利用することも可能です。

**フラクタル地形の生成**

フラクタル地形は、自己相似性を持つ地形を生成するための技術です。ノイズ関数を繰り返し適用することで、複雑な地形を生成できます。

```glsl
// フラクタル地形を生成する例
float fractalNoise(vec3 position) {
  float total = 0.0;
  float frequency = 1.0;
  float amplitude = 1.0;
  float maxValue = 0.0;

  for (int i = 0; i < 4; i++) {
    total += snoise(position * frequency) * amplitude;
    maxValue += amplitude;
    amplitude *= 0.5;
    frequency *= 2.0;
  }

  return total / maxValue;
}
```

上記の例では、ノイズ関数を4回繰り返し適用し、振幅と周波数を調整しています。

**パーティクルシステムの実装**

パーティクルシステムは、多数の小さなオブジェクト（パーティクル）を生成し、アニメーションさせることで、煙、炎、水などの効果を表現するための技術です。

```javascript
// パーティクルシステムの例
const particleCount = 1000;
const positions = new Float32Array(particleCount * 3);
const velocities = new Float32Array(particleCount * 3);

for (let i = 0; i < particleCount; i++) {
  // ランダムな位置と速度を生成する
  positions[i * 3] = (Math.random() - 0.5) * 10;
  positions[i * 3 + 1] = (Math.random() - 0.5) * 10;
  positions[i * 3 + 2] = (Math.random() - 0.5) * 10;

  velocities[i * 3] = (Math.random() - 0.5) * 0.1;
  velocities[i * 3 + 1] = (Math.random() - 0.5) * 0.1;
  velocities[i * 3 + 2] = (Math.random() - 0.5) * 0.1;
}

const geometry = new THREE.BufferGeometry();
geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
geometry.setAttribute('velocity', new THREE.BufferAttribute(velocities, 3));

const material = new THREE.ShaderMaterial({
  vertexShader: `
    attribute vec3 velocity;
    uniform float time;
    uniform float gravity;

    void main() {
      vec3 newPosition = position + velocity * time;
      newPosition.y -= gravity * time * time * 0.5; // 重力

      gl_Position = projectionMatrix * modelViewMatrix * vec4(newPosition, 1.0);
      gl_PointSize = 5.0;
    }
  `,
  fragmentShader: `
    void main() {
      gl_FragColor = vec4(1.0, 1.0, 1.0, 1.0); // 白色
    }
  `,
  uniforms: {
    time: { value: 0.0 },
    gravity: { value: 0.1 }
  },
  blending: THREE.AdditiveBlending,
  depthTest: false,
  transparent: true
});

const particles = new THREE.Points(geometry, material);
scene.add(particles);

// アニメーションループでパーティクルを更新する
function animate() {
  requestAnimationFrame(animate);
  particles.material.uniforms.time.value += 0.01;
  renderer.render(scene, camera);
}

animate();
```
