## 付録: サンプルコード集

### 18.1 基本的なシーンの構築

**1. 概要と重要性**

3Dグラフィックスの旅は、まず基本的なシーンの構築から始まります。シーンは、オブジェクト、ライト、カメラなど、3D世界を構成するすべての要素の容器です。しっかりとしたシーン構築は、後続の作業の効率と品質に大きく影響します。見やすく整理されたシーン構造は、デバッグを容易にし、パフォーマンスを向上させ、複雑なプロジェクトを管理可能にします。

**2. 特徴と利点**

*   **整理された構造**: シーンを適切に構築することで、オブジェクトの親子関係やグループ化が容易になります。
*   **効率的なレンダリング**: ライトやカメラの設定を最適化することで、レンダリング時間を短縮し、パフォーマンスを向上させることができます。
*   **柔軟性**: シーンをモジュール化することで、コンポーネントの再利用が容易になり、プロジェクトの拡張性が向上します。
*   **デバッグの容易性**: 問題が発生した場合、シーン構造が整理されていると、原因の特定と修正が迅速に行えます。

**3. 事前準備と前提条件**

このセクションでは、WebGLまたはThree.jsを使用することを想定します。
*   **WebGL**: Webブラウザで3Dグラフィックスを表示するためのJavaScript API。
*   **Three.js**: WebGLを扱いやすくするためのJavaScriptライブラリ。

これらのライブラリを使用するために、HTMLファイルに読み込みます。

```html
<!DOCTYPE html>
<html>
<head>
  <title>基本的なシーンの構築</title>
  <style>
    body { margin: 0; }
    canvas { display: block; }
  </style>
</head>
<body>
  <script src="https://threejs.org/build/three.js"></script>
  <script>
    // ここにJavaScriptコードを記述します
  </script>
</body>
</html>
```

**4. 基本的な使い方**

基本的なシーンを構築する手順は以下の通りです。

1.  **シーンの作成**: `THREE.Scene` オブジェクトを作成します。

    ```javascript
    const scene = new THREE.Scene();
    ```

2.  **カメラの作成**: `THREE.PerspectiveCamera` または `THREE.OrthographicCamera` オブジェクトを作成します。`PerspectiveCamera` は遠近感を表現し、`OrthographicCamera` は平行投影を行います。

    ```javascript
    const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
    camera.position.z = 5; // カメラの位置を設定
    ```

3.  **レンダラーの作成**: `THREE.WebGLRenderer` オブジェクトを作成します。

    ```javascript
    const renderer = new THREE.WebGLRenderer();
    renderer.setSize(window.innerWidth, window.innerHeight);
    document.body.appendChild(renderer.domElement); // レンダラーをHTMLに追加
    ```

4.  **オブジェクトの作成**: `THREE.BoxGeometry`, `THREE.SphereGeometry`, `THREE.PlaneGeometry` などのジオメトリと `THREE.MeshBasicMaterial`, `THREE.MeshLambertMaterial`, `THREE.MeshPhongMaterial` などのマテリアルを使用して、3Dオブジェクトを作成します。

    ```javascript
    const geometry = new THREE.BoxGeometry();
    const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 }); // 緑色のマテリアル
    const cube = new THREE.Mesh(geometry, material);
    scene.add(cube); // シーンにオブジェクトを追加
    ```

5.  **ライトの追加**: `THREE.AmbientLight`, `THREE.DirectionalLight`, `THREE.PointLight` などのライトを追加します。

    ```javascript
    const light = new THREE.AmbientLight(0x404040); // ソフトなアンビエントライト
    scene.add(light);
    ```

6.  **レンダリングループ**: `requestAnimationFrame` を使用して、シーンを継続的にレンダリングします。

    ```javascript
    function animate() {
      requestAnimationFrame(animate);
      cube.rotation.x += 0.01; // キューブを回転させる
      cube.rotation.y += 0.01;
      renderer.render(scene, camera);
    }
    animate();
    ```

**5. 実践的なテクニック**

*   **オブジェクトの親子関係**: `add()` メソッドを使って、オブジェクトを別のオブジェクトの子として追加できます。これにより、親子関係を持つオブジェクトの移動や回転をまとめて制御できます。

    ```javascript
    const parent = new THREE.Group();
    scene.add(parent);
    parent.add(cube); // キューブをparentの子として追加
    parent.rotation.y += 0.01; // parentを回転させると、キューブも一緒に回転する
    ```

*   **シーングラフの可視化**: Three.jsエディタや他の3Dモデリングツールを使用して、シーングラフを視覚的に確認できます。
*   **パフォーマンス最適化**: 不要なオブジェクトを削除したり、複雑なジオメトリを簡略化することで、パフォーマンスを向上させることができます。

**6. 応用例とユースケース**

*   **ゲーム開発**: ゲームのレベルやキャラクターを表現するための基本的なシーンを構築します。
*   **インタラクティブなWebサイト**: 製品の3Dモデルを表示したり、バーチャルツアーを作成したりするために使用します。
*   **データ可視化**: 複雑なデータを3Dで表現し、視覚的に理解しやすくします。

**7. トラブルシューティング**

*   **オブジェクトが表示されない**: カメラの位置やオブジェクトの位置を確認し、ライトが適切に設定されているかを確認します。
*   **パフォーマンスが低い**: 複雑なジオメトリを簡略化したり、不要なオブジェクトを削除したりすることで、パフォーマンスを向上させることができます。
*   **エラーが発生する**: JavaScriptコンソールでエラーメッセージを確認し、コードに誤りがないか確認します。

**8. まとめと次のステップ**

### 18.2 アニメーションの実装

**1. 概要と重要性**

3Dシーンに命を吹き込むのがアニメーションです。アニメーションは、オブジェクトの動き、色の変化、形状の変形などを表現し、ユーザーエクスペリエンスを向上させます。効果的なアニメーションは、単に見た目を良くするだけでなく、情報伝達の手段としても機能します。

**2. 特徴と利点**

*   **視覚的な魅力**: アニメーションは、静的なシーンよりも視覚的に魅力的です。
*   **情報伝達**: アニメーションを使って、複雑なプロセスや関係性を視覚的に表現できます。
*   **インタラクションの強化**: アニメーションは、ユーザーの操作に対するフィードバックとして機能し、インタラクションをより自然にします。
*   **没入感の向上**: ユーザーを3D世界に引き込み、没入感を高めます。

**3. 事前準備と前提条件**

前のセクションで構築した基本的なシーンを再利用します。Three.jsが読み込まれていることを確認してください。

**4. 基本的な使い方**

アニメーションを実装する基本的な方法は以下の通りです。

1.  **アニメーションループ**: `requestAnimationFrame` を使用して、アニメーションループを作成します。

    ```javascript
    function animate() {
      requestAnimationFrame(animate);
      // ここにアニメーションのコードを記述します
      renderer.render(scene, camera);
    }
    animate();
    ```

2.  **オブジェクトのプロパティの変更**: アニメーションループ内で、オブジェクトの位置、回転、スケール、色などのプロパティを時間とともに変更します。

    ```javascript
    cube.rotation.x += 0.01; // キューブをX軸方向に回転させる
    cube.position.x += 0.005; // キューブをX軸方向に移動させる
    ```

3.  **イージング**: イージング関数を使用すると、アニメーションの速度を滑らかに変化させることができます。これにより、より自然なアニメーションを実現できます。

    ```javascript
    function lerp(a, b, t) {
      return a + (b - a) * t; // 線形補間
    }

    let targetPosition = 5; // 目標位置
    let currentPosition = cube.position.x;

    function animate() {
      requestAnimationFrame(animate);
      currentPosition = lerp(currentPosition, targetPosition, 0.05); // イージングを適用
      cube.position.x = currentPosition;
      renderer.render(scene, camera);
    }
    animate();
    ```

4. **Three.js Animation Mixer の使用**: 複雑なアニメーションには Three.js の `AnimationMixer` が便利です。これは、外部の3Dモデリングツールで作成されたアニメーションデータを読み込み、制御するための仕組みです。

    まず、アニメーションを含むモデル（例：GLTF形式）をロードします。

    ```javascript
    const loader = new THREE.GLTFLoader();
    loader.load( 'path/to/your/model.gltf', function ( gltf ) {

        scene.add( gltf.scene );
        const mixer = new THREE.AnimationMixer( gltf.scene );
        const clip = gltf.animations[ 0 ];
        const action = mixer.clipAction( clip );
        action.play();

        // アニメーションループ内でミキサーを更新
        function animate() {
            requestAnimationFrame( animate );
            mixer.update( 0.01 ); // delta time (秒)
            renderer.render( scene, camera );
        }
        animate();

    }, undefined, function ( error ) {
        console.error( error );
    } );
    ```

**5. 実践的なテクニック**

*   **キーフレームアニメーション**: 時間とオブジェクトのプロパティの値を対応付けたキーフレームを作成し、それらを補間することで、複雑なアニメーションを実現できます。
*   **シェーダーアニメーション**: シェーダーを使って、オブジェクトの形状やテクスチャを動的に変化させるアニメーションを実現できます。
*   **パーティクルシステム**: パーティクルシステムを使って、煙、炎、水などの自然現象をシミュレーションできます。

**6. 応用例とユースケース**

*   **UIアニメーション**: ボタンのホバー効果、画面遷移など、UI要素にアニメーションを追加することで、ユーザーエクスペリエンスを向上させることができます。
*   **インタラクティブなストーリーテリング**: ユーザーの選択に応じてストーリーが変化するインタラクティブなアニメーションを作成できます。
*   **製品デモンストレーション**: 製品の機能を視覚的に説明するためのアニメーションを作成できます。

**7. トラブルシューティング**

*   **アニメーションがカクカクする**: イージング関数を使用したり、キーフレームの数を増やしたりすることで、アニメーションを滑らかにすることができます。
*   **アニメーションが遅い**: 不要なオブジェクトを削除したり、アニメーションの複雑さを軽減したりすることで、パフォーマンスを向上させることができます。
*   **アニメーションが正しく再生されない**: アニメーションの開始時間、終了時間、再生速度などを確認します。

**8. まとめと次のステップ**

### 18.3 インタラクションの実装

**1. 概要と重要性**

3Dシーンにインタラクションを追加することで、ユーザーはオブジェクトを操作したり、環境に影響を与えたりできるようになります。インタラクションは、ユーザーエクスペリエンスを向上させ、没入感を高めるために不可欠です。

**2. 特徴と利点**

*   **ユーザーエンゲージメントの向上**: インタラクションは、ユーザーを3D世界に引き込み、エンゲージメントを高めます。
*   **情報探索**: インタラクションを通じて、ユーザーは3D世界を探索し、情報を発見できます。
*   **制御**: ユーザーはオブジェクトや環境を操作し、結果を直接観察できます。
*   **学習**: インタラクションを通じて、ユーザーは3D世界に関する知識を習得できます。

**3. 事前準備と前提条件**

前のセクションで作成したアニメーションを含むシーンを再利用します。Three.jsが読み込まれていることを確認してください。

**4. 基本的な使い方**

インタラクションを実装する基本的な方法は以下の通りです。

1.  **イベントリスナー**: `addEventListener` を使用して、マウスイベント（クリック、ホバー、ドラッグなど）やキーボードイベントをリッスンします。

    ```javascript
    document.addEventListener('mousedown', onMouseDown, false);

    function onMouseDown(event) {
      // マウスがクリックされたときの処理
    }
    ```

2.  **レイキャスティング**: レイキャスティングを使用して、マウスがクリックされた位置にある3Dオブジェクトを特定します。

    ```javascript
    const raycaster = new THREE.Raycaster();
    const mouse = new THREE.Vector2();

    function onMouseDown(event) {
      // マウスの座標を正規化
      mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
      mouse.y = - (event.clientY / window.innerHeight) * 2 + 1;

      // レイを生成
      raycaster.setFromCamera(mouse, camera);

      // レイと交差するオブジェクトを検出
      const intersects = raycaster.intersectObjects(scene.children);

      if (intersects.length > 0) {
        // 交差したオブジェクトに対する処理
        const selectedObject = intersects[0].object;
        selectedObject.material.color.set(0xff0000); // 赤色に変更
      }
    }
    ```

3.  **インタラクションの実装**: 特定されたオブジェクトに対して、アニメーションの開始、色の変更、オブジェクトの移動など、インタラクションを実装します。

**5. 実践的なテクニック**

*   **ドラッグ＆ドロップ**: オブジェクトをドラッグして別の場所に移動できるようにします。
*   **オブジェクトの選択**: クリックしたオブジェクトを選択状態にし、追加の操作を可能にします。
*   **カメラコントロール**: マウスやキーボードを使ってカメラを操作できるようにします。OrbitControls, FlyControlsといったライブラリを利用すると簡単に実装できます。

    ```javascript
    import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

    const controls = new OrbitControls( camera, renderer.domElement );
    controls.listenToKeyEvents( window ); // optional

    // アニメーションループ内でコントロールを更新
    function animate() {
        requestAnimationFrame( animate );
        controls.update();
        renderer.render( scene, camera );
    }
    animate();
    ```

*   **VR/ARインタラクション**: VR/ARデバイスのコントローラーを使用して、3Dオブジェクトを操作できるようにします。

**6. 応用例とユースケース**

*   **製品コンフィギュレーター**: 製品の色、素材、オプションなどを選択できるようにします。
*   **バーチャルショールーム**: 製品を3Dで展示し、インタラクティブに操作できるようにします。
*   **教育アプリケーション**: 3Dモデルを使って、科学、歴史、文化などをインタラクティブに学習できるようにします。

**7. トラブルシューティング**

*   **オブジェクトが選択できない**: レイキャスティングの設定やオブジェクトの衝突判定を確認します。
*   **インタラクションが遅い**: レイキャスティングのパフォーマンスを最適化したり、インタラクションの複雑さを軽減したりすることで、パフォーマンスを向上させることができます。
*   **予期しない動作が発生する**: イベントリスナーが正しく設定されているか、インタラクションのロジックに誤りがないか確認します。

### 18.4 モデルデータの読み込み

**1. 概要と重要性**

3Dモデルは、3Dシーンの見た目を大きく左右する重要な要素です。既存の3Dモデルデータを読み込むことで、手軽に複雑な形状やテクスチャをシーンに追加できます。

**2. 特徴と利点**

*   **効率的な開発**: 3Dモデルを自分で作成する手間を省き、開発時間を短縮できます。
*   **高品質なビジュアル**: プロのモデラーが作成した高品質な3Dモデルを利用できます。
*   **多様な表現**: さまざまな形式の3Dモデルを利用することで、多様な表現が可能です。

**3. 事前準備と前提条件**

前のセクションで作成したインタラクティブなシーンを再利用します。Three.jsが読み込まれていることを確認してください。3Dモデルデータ（例：GLTF, OBJ, FBX形式）を用意します。

**4. 基本的な使い方**

Three.jsでは、さまざまな形式の3Dモデルを読み込むためのローダーが提供されています。

1.  **ローダーの選択**: 3Dモデルの形式に応じて、適切なローダーを選択します。

    *   `THREE.GLTFLoader` (GLTF形式)
    *   `THREE.OBJLoader` (OBJ形式)
    *   `THREE.FBXLoader` (FBX形式)

2.  **ローダーの読み込み**: ローダーを使って、3Dモデルデータを読み込みます。

    ```javascript
    import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

    const loader = new GLTFLoader();

    loader.load('path/to/your/model.gltf', function (gltf) {
      scene.add(gltf.scene); // モデルをシーンに追加
    }, undefined, function (error) {
      console.error(error);
    });
    ```

3.  **モデルの調整**: 読み込んだモデルの位置、回転、スケールなどを調整します。

    ```javascript
    gltf.scene.position.set(0, 0, 0); // 位置を設定
    gltf.scene.rotation.set(0, Math.PI / 2, 0); // 回転を設定
    gltf.scene.scale.set(0.5, 0.5, 0.5); // スケールを設定
    ```

**5. 実践的なテクニック**

*   **モデルの最適化**: ポリゴン数を減らしたり、テクスチャの解像度を下げたりすることで、モデルのパフォーマンスを向上させることができます。
*   **マテリアルの変更**: モデルのマテリアルを変更して、見た目をカスタマイズできます。
*   **アニメーションの再生**: モデルにアニメーションが含まれている場合、`AnimationMixer` を使ってアニメーションを再生できます。

**6. 応用例とユースケース**

*   **製品ビジュアライゼーション**: 製品の3Dモデルを表示し、細部まで確認できるようにします。
*   **建築ビジュアライゼーション**: 建物の3Dモデルを表示し、内外観を自由に探索できるようにします。
*   **ゲーム開発**: ゲームのキャラクターや背景として3Dモデルを使用します。

**7. トラブルシューティング**

*   **モデルが読み込めない**: ファイルパスが正しいか、モデルデータが破損していないか確認します。
*   **モデルが小さすぎる/大きすぎる**: モデルのスケールを調整します。
*   **テクスチャが表示されない**: テクスチャのパスが正しいか、マテリアルの設定を確認します。

**8. まとめと次のステップ**

### 18.5 シェーダーの利用

**1. 概要と重要性**

シェーダーは、3Dオブジェクトの見た目を決定するプログラムです。WebGLではGLSL (OpenGL Shading Language) という言語を用いて記述します。シェーダーを使用することで、標準的なマテリアルでは表現できない高度なエフェクトや、独自のレンダリング手法を実装できます。

**2. 特徴と利点**

*   **高度な表現力**: シェーダーを使うことで、テクスチャ、ライティング、エフェクトなどを細かく制御できます。
*   **パフォーマンスの最適化**: 特定の処理をGPUにオフロードすることで、CPUの負荷を軽減し、パフォーマンスを向上させることができます。
*   **独自のレンダリング**: シェーダーを使って、独自のレンダリングパイプラインを構築できます。

**3. 事前準備と前提条件**

前のセクションで作成したシーンを再利用します。Three.jsが読み込まれていることを確認してください。GLSLの基本的な知識が必要です。

**4. 基本的な使い方**

シェーダーを使用する基本的な手順は以下の通りです。

1.  **シェーダーコードの記述**: バーテックスシェーダーとフラグメントシェーダーのコードを記述します。

    *   **バーテックスシェーダー**: 頂点の位置を計算するプログラム。
    *   **フラグメントシェーダー**: ピクセルの色を計算するプログラム。

    ```glsl
    // バーテックスシェーダー
    vertexShader = `
      void main() {
        gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
      }
    `;

    // フラグメントシェーダー
    fragmentShader = `
      void main() {
        gl_FragColor = vec4(1.0, 0.0, 0.0, 1.0); // 赤色
      }
    `;
    ```

2.  **シェーダーマテリアルの作成**: `THREE.ShaderMaterial` を作成し、バーテックスシェーダーとフラグメントシェーダーのコードを設定します。

    ```javascript
    const material = new THREE.ShaderMaterial({
      vertexShader: vertexShader,
      fragmentShader: fragmentShader
    });
    ```

3.  **オブジェクトへの適用**: 作成したマテリアルを3Dオブジェクトに適用します。

    ```javascript
    const geometry = new THREE.BoxGeometry();
    const mesh = new THREE.Mesh(geometry, material);
    scene.add(mesh);
    ```

4. **uniform変数の利用**: シェーダーに値を渡すには、uniform変数を使用します。JavaScriptからuniform変数の値を変更することで、シェーダーの効果を動的に制御できます。

   ```glsl
   // フラグメントシェーダー
   fragmentShader = `
     uniform vec3 uColor; // JavaScriptから渡される色

     void main() {
       gl_FragColor = vec4(uColor, 1.0);
     }
   `;
   ```

   ```javascript
   const material = new THREE.ShaderMaterial({
     vertexShader: vertexShader,
     fragmentShader: fragmentShader,
     uniforms: {
       uColor: { value: new THREE.Color(0xff0000) } // 初期値を赤に設定
     }
   });

   // アニメーションループ内でuniform変数の値を更新
   function animate() {
     requestAnimationFrame(animate);
     material.uniforms.uColor.value.setHSL(Math.sin(Date.now() * 0.001), 0.5, 0.5); // 色相を変化させる
     renderer.render(scene, camera);
   }
   animate();
   ```

**5. 実践的なテクニック**

*   **ライティング**: シェーダーを使って、独自のライティングモデルを実装できます。
*   **テクスチャ**: シェーダーを使って、テクスチャをサンプリングし、複雑なテクスチャエフェクトを作成できます。
*   **ポストエフェクト**: シーン全体のレンダリング結果にエフェクトを追加できます（ブルーム、ぼかし、色収差など）。

**6. 応用例とユースケース**

*   **水の表現**: シェーダーを使って、リアルな水面を表現できます。
*   **炎の表現**: シェーダーを使って、動的な炎を表現できます。
*   **トゥーンシェーディング**: シェーダーを使って、アニメのような表現を実現できます。

**7. トラブルシューティング**

*   **シェーダーがコンパイルできない**: GLSLの構文エラーを確認します。
*   **オブジェクトが真っ黒になる**: ライティングの設定や法線の向きを確認します。
*   **パフォーマンスが低い**: シェーダーの複雑さを軽減したり、GPUの負荷を減らすことで、パフォーマンスを向上させることができます。
