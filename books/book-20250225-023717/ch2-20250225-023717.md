## 第1章: Three.jsの基本要素 - 3Dオブジェクト、マテリアル、ライティング

Three.jsは、ブラウザ上で3Dグラフィックスを簡単に扱うためのJavaScriptライブラリです。この章では、Three.jsにおける3Dオブジェクト、マテリアル、ライティングという、3Dシーンを構成する上で不可欠な要素について、その基本から応用までを丁寧に解説します。これらの要素を理解し、自在に操ることで、あなたのWebサイトやアプリケーションに、没入感のある表現力豊かな3D空間を創造することができます。

### 2.1 ジオメトリ - 基本的な3D形状の作成とカスタマイズ

#### 概要と重要性

ジオメトリは、3Dオブジェクトの形状を定義するものです。立方体、球体、平面など、様々な形状のジオメトリを組み合わせたり、カスタマイズしたりすることで、複雑な3Dモデルを作成することができます。ジオメトリは、3Dグラフィックスの基礎であり、その理解は、より高度な表現を実現するために不可欠です。

#### 特徴と利点

Three.jsは、豊富な組み込みジオメトリを提供しており、手軽に3Dオブジェクトを作成することができます。また、`BufferGeometry`を使用することで、独自のジオメトリを定義することも可能です。

*   **組み込みジオメトリ:** 手軽に利用できる。
*   **カスタムジオメトリ:** 自由度の高い表現が可能。
*   **頂点、面、法線の編集:** より詳細な形状の制御が可能。

#### 事前準備と前提条件

*   HTMLファイル、JavaScriptファイルが用意されていること。
*   Three.jsライブラリが読み込まれていること。

```html
<!DOCTYPE html>
<html>
<head>
  <title>Three.js Geometry</title>
  <style>
    body { margin: 0; }
    canvas { display: block; }
  </style>
</head>
<body>
  <script src="https://cdn.jsdelivr.net/npm/three@0.155.0/build/three.min.js"></script>
  <script>
    // JavaScriptコードはここに記述します
  </script>
</body>
</html>
```

#### 基本的な使い方

まずは、基本的な組み込みジオメトリである`BoxGeometry`、`SphereGeometry`、`PlaneGeometry`の使い方を見ていきましょう。

**1. BoxGeometry (立方体)**

```javascript
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

const geometry = new THREE.BoxGeometry( 1, 1, 1 ); // 幅、高さ、奥行き
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } ); // 緑色
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );

camera.position.z = 5;

function animate() {
  requestAnimationFrame( animate );
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render( scene, camera );
}

animate();
```

**2. SphereGeometry (球体)**

```javascript
const geometry = new THREE.SphereGeometry( 1, 32, 32 ); // 半径、幅セグメント、高さセグメント
const material = new THREE.MeshBasicMaterial( {color: 0xff0000} ); // 赤色
const sphere = new THREE.Mesh( geometry, material );
scene.add( sphere );

camera.position.z = 5;

function animate() {
  requestAnimationFrame( animate );
  sphere.rotation.x += 0.01;
  sphere.rotation.y += 0.01;
  renderer.render( scene, camera );
}

animate();
```

**3. PlaneGeometry (平面)**

```javascript
const geometry = new THREE.PlaneGeometry( 5, 5 ); // 幅、高さ
const material = new THREE.MeshBasicMaterial( {color: 0x0000ff, side: THREE.DoubleSide} ); // 青色、両面表示
const plane = new THREE.Mesh( geometry, material );
scene.add( plane );

camera.position.z = 5;

function animate() {
  requestAnimationFrame( animate );
  plane.rotation.x += 0.01;
  plane.rotation.y += 0.01;
  renderer.render( scene, camera );
}

animate();
```

**4. カスタムジオメトリ (BufferGeometry)**

`BufferGeometry`を使用すると、頂点座標、法線、UV座標などを自由に定義して、オリジナルの形状を作成することができます。

```javascript
const geometry = new THREE.BufferGeometry();

// 頂点座標の定義
const vertices = new Float32Array( [
  -1.0, -1.0,  1.0, // v0
   1.0, -1.0,  1.0, // v1
   1.0,  1.0,  1.0, // v2

   1.0,  1.0,  1.0, // v2
  -1.0,  1.0,  1.0, // v3
  -1.0, -1.0,  1.0  // v0
] );

// 属性としてジオメトリに登録
geometry.setAttribute( 'position', new THREE.BufferAttribute( vertices, 3 ) );

const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } ); // 黄色
const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );

camera.position.z = 5;

function animate() {
  requestAnimationFrame( animate );
  mesh.rotation.x += 0.01;
  mesh.rotation.y += 0.01;
  renderer.render( scene, camera );
}

animate();
```

#### 実践的なテクニック

*   **ジオメトリの結合:** `THREE.BufferGeometryUtils.mergeBufferGeometries` を利用することで、複数のジオメトリを一つに結合し、パフォーマンスを向上させることができます。
*   **モディファイアの使用:** `THREE.BufferGeometry` の頂点情報を操作することで、形状をダイナミックに変化させることができます。例えば、波のような動きを表現するなどが可能です。

#### 応用例とユースケース

*   **ゲーム開発:** キャラクターや背景のモデル作成。
*   **データビジュアライゼーション:** 複雑なデータを3D形状で表現。
*   **建築設計:** 建物の3Dモデルを作成し、視覚的に確認。
*   **製品デザイン:** 製品のプロトタイプを3Dで作成し、様々な角度から検証。

#### トラブルシューティング

*   **形状が表示されない:** カメラの位置やライトの設定を確認してください。`side: THREE.DoubleSide` をマテリアルに設定することで、両面が表示されるようになります。
*   **パフォーマンスが悪い:** ジオメトリの頂点数を減らす、オブジェクトの数を減らす、カリングを適用するなどの対策を検討してください。

#### まとめと次のステップ

ジオメトリは、3Dオブジェクトの形状を定義する上で重要な要素です。様々な組み込みジオメトリを使いこなし、`BufferGeometry`を用いて独自の形状を作成することで、表現の幅を広げることができます。次は、マテリアルについて学び、オブジェクトに質感を与える方法を習得しましょう。

### 2.2 マテリアル - オブジェクトの見た目を定義する

#### 概要と重要性

マテリアルは、3Dオブジェクトの表面の質感や色、光の反射などを定義するものです。同じジオメトリでも、マテリアルを変えることで、全く異なる印象を与えることができます。マテリアルは、3Dシーンのリアリティを高め、視覚的な魅力を向上させるために不可欠な要素です。

#### 特徴と利点

Three.jsは、様々な種類のマテリアルを提供しており、シーンの目的に合わせて最適なマテリアルを選択することができます。

*   **多様なマテリアル:** `MeshBasicMaterial`, `MeshLambertMaterial`, `MeshPhongMaterial`, `MeshStandardMaterial`など、様々なライティングモデルに対応。
*   **テクスチャマッピング:** 画像やビデオをオブジェクトの表面に貼り付けることで、よりリアルな質感を表現。
*   **シェーダーマテリアル:** GLSL (OpenGL Shading Language) を使用して、高度なエフェクトや独自の表現を実現。

#### 事前準備と前提条件

*   ジオメトリが作成されていること。
*   Three.jsライブラリが読み込まれていること。

#### 基本的な使い方

**1. MeshBasicMaterial**

最もシンプルなマテリアルで、光の影響を受けません。指定された色でオブジェクトを描画します。

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } ); // 緑色
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );
```

**2. MeshLambertMaterial**

拡散反射光 (diffuse) のみを受け付けるマテリアルです。光沢のある表現には向きませんが、滑らかな印象を与えます。

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshLambertMaterial( { color: 0x00ff00 } ); // 緑色
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );

const light = new THREE.AmbientLight( 0xffffff ); // ソフトな白色光
scene.add( light );

const directionalLight = new THREE.DirectionalLight( 0xffffff, 0.5 ); // 白色光、強度0.5
directionalLight.position.set( 1, 1, 1 );
scene.add( directionalLight );
```

**3. MeshPhongMaterial**

拡散反射光に加え、鏡面反射光 (specular) も受け付けるマテリアルです。光沢のある表現に適しています。

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshPhongMaterial( { color: 0x00ff00, specular: 0xffffff, shininess: 30 } ); // 緑色、鏡面反射光の色、光沢の強さ
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );

const light = new THREE.AmbientLight( 0xffffff ); // ソフトな白色光
scene.add( light );

const directionalLight = new THREE.DirectionalLight( 0xffffff, 0.5 ); // 白色光、強度0.5
directionalLight.position.set( 1, 1, 1 );
scene.add( directionalLight );
```

**4. MeshStandardMaterial**

物理ベースレンダリング (PBR) に基づいたマテリアルです。よりリアルな質感を表現できます。`roughness` (粗さ) と `metalness` (金属度) のパラメータを調整することで、様々な質感を表現できます。

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshStandardMaterial( { color: 0x00ff00, roughness: 0.5, metalness: 0.5 } ); // 緑色、粗さ、金属度
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );

const light = new THREE.AmbientLight( 0xffffff ); // ソフトな白色光
scene.add( light );

const directionalLight = new THREE.DirectionalLight( 0xffffff, 0.5 ); // 白色光、強度0.5
directionalLight.position.set( 1, 1, 1 );
scene.add( directionalLight );
```

**5. テクスチャマッピング**

画像や動画をテクスチャとしてマテリアルに適用することで、より複雑でリアルな質感を表現できます。

```javascript
const textureLoader = new THREE.TextureLoader();
const texture = textureLoader.load( 'path/to/your/image.jpg' ); // 画像ファイルのパス

const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { map: texture } );
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );
```

**6. シェーダーマテリアルの利用 (ShaderMaterial, RawShaderMaterial)**

`ShaderMaterial`や`RawShaderMaterial`を使用すると、GLSLで記述されたカスタムシェーダーを適用できます。これにより、高度なエフェクトや独自の表現を実現できます。

```javascript
const vertexShader = `
  void main() {
    gl_Position = projectionMatrix * modelViewMatrix * vec4( position, 1.0 );
  }
`;

const fragmentShader = `
  void main() {
    gl_FragColor = vec4( 1.0, 0.0, 0.0, 1.0 ); // 赤色
  }
`;

const material = new THREE.ShaderMaterial( {
  vertexShader: vertexShader,
  fragmentShader: fragmentShader
} );

const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );
```

#### 実践的なテクニック

*   **環境マッピング:** 環境マップを使用すると、周囲の環境がオブジェクトに反射しているように見せることができます。
*   **法線マップ:** 法線マップを使用すると、オブジェクトの表面にディテールを追加し、よりリアルな凹凸を表現できます。
*   **マテリアルのアニメーション:** JavaScriptを使ってマテリアルのプロパティを時間とともに変化させることで、アニメーション効果を実現できます。

#### 応用例とユースケース

*   **製品ビジュアライゼーション:** 製品の素材感をリアルに表現。
*   **建築ビジュアライゼーション:** 建物の外観や内装の質感を詳細に表現。
*   **特殊効果:** 炎、水、煙などの特殊効果を表現。
*   **ゲーム開発:** キャラクターや背景の質感を高める。

#### トラブルシューティング

*   **テクスチャが表示されない:** 画像ファイルのパスが正しいか確認してください。また、テクスチャがロードされる前にマテリアルが作成されていないか確認してください。
*   **シェーダーがコンパイルされない:** シェーダーコードにエラーがないか確認してください。Three.jsのエラーメッセージを参考に修正してください。

#### まとめと次のステップ

マテリアルは、3Dオブジェクトの見た目を定義する上で非常に重要な要素です。様々な種類のマテリアルを使いこなし、テクスチャマッピングやシェーダーマテリアルを利用することで、より表現力豊かな3Dシーンを作成することができます。次は、ライティングについて学び、シーンに光を加えて立体感を表現する方法を習得しましょう。

### 2.3 ライティング - シーンに光を加えて立体感を表現する

#### 概要と重要性

ライティングは、3Dシーンに光を加え、オブジェクトの形状や質感を強調する上で不可欠な要素です。適切なライティングは、シーンのリアリティを高め、視覚的な魅力を向上させます。Three.jsでは、様々な種類のライトを提供しており、シーンの目的に合わせて最適なライトを選択し、設定することができます。

#### 特徴と利点

*   **多様なライト:** `AmbientLight`, `DirectionalLight`, `PointLight`, `SpotLight`など、様々な種類のライトを提供。
*   **シャドウの生成:** ライトからシャドウを生成することで、シーンの立体感を強調。
*   **ライティングの最適化:** パフォーマンスを考慮したライトの設定が可能。

#### 事前準備と前提条件

*   ジオメトリとマテリアルが設定されたオブジェクトが作成されていること。
*   Three.jsライブラリが読み込まれていること。

#### 基本的な使い方

**1. AmbientLight (環境光)**

シーン全体を均一に照らすライトです。影は生成されません。

```javascript
const light = new THREE.AmbientLight( 0xffffff ); // ソフトな白色光
scene.add( light );
```

**2. DirectionalLight (平行光)**

特定の方向から平行な光を照射するライトです。太陽光のような表現に適しています。

```javascript
const directionalLight = new THREE.DirectionalLight( 0xffffff, 0.5 ); // 白色光、強度0.5
directionalLight.position.set( 1, 1, 1 );
scene.add( directionalLight );
```

**3. PointLight (点光源)**

特定の点から全方向に光を放射するライトです。電球のような表現に適しています。

```javascript
const pointLight = new THREE.PointLight( 0xffffff, 1, 100 ); // 白色光、強度、距離
pointLight.position.set( 0, 0, 0 );
scene.add( pointLight );
```

**4. SpotLight (スポットライト)**

特定の点から円錐状に光を照射するライトです。懐中電灯のような表現に適しています。

```javascript
const spotLight = new THREE.SpotLight( 0xffffff, 1 ); // 白色光、強度
spotLight.position.set( 0, 5, 0 );
spotLight.target.position.set( 0, 0, 0 );
scene.add( spotLight );
scene.add( spotLight.target );

spotLight.angle = Math.PI / 6; // 照射角度
spotLight.penumbra = 0.2; // 減衰率
```

**5. シャドウの生成と最適化**

`DirectionalLight`, `PointLight`, `SpotLight` では、シャドウを生成することができます。シャドウを生成するには、以下の設定が必要です。

```javascript
// レンダラーの設定
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // シャドウの種類

// ライトの設定
directionalLight.castShadow = true; // シャドウを生成する
directionalLight.shadow.mapSize.width = 1024; // シャドウマップの解像度
directionalLight.shadow.mapSize.height = 1024;
directionalLight.shadow.camera.near = 0.5; // シャドウカメラのニアクリップ
directionalLight.shadow.camera.far = 500; // シャドウカメラのファークリップ

// オブジェクトの設定
cube.castShadow = true; // 影を落とす
plane.receiveShadow = true; // 影を受ける
```

シャドウの生成は、パフォーマンスに影響を与えるため、必要に応じて最適化が必要です。シャドウマップの解像度を下げる、シャドウを生成するオブジェクトの数を減らす、カリングを適用するなどの対策を検討してください。

#### 実践的なテクニック

*   **ライトのカラーミキシング:** 複数のライトを組み合わせ、色を調整することで、より複雑で美しいライティングを実現できます。
*   **ライトのアニメーション:** JavaScriptを使ってライトの位置や色を時間とともに変化させることで、アニメーション効果を実現できます。
*   **グローバルイルミネーション:** よりリアルなライティングを実現するために、グローバルイルミネーション (GI) を利用することができます。

#### 応用例とユースケース

*   **ゲーム開発:** ゲーム内の環境ライティングやキャラクターライティング。
*   **建築ビジュアライゼーション:** 建物の内部や外部のライティングをリアルに表現。
*   **製品ビジュアライゼーション:** 製品の質感を強調するためのライティング。
*   **映画制作:** 3Dアニメーションにおけるライティング。

#### トラブルシューティング

*   **シーンが暗すぎる、または明るすぎる:** ライトの強度や色を調整してください。
*   **シャドウが表示されない:** ライトの設定、オブジェクトの設定、レンダラーの設定を確認してください。シャドウマップの解像度が低すぎると、シャドウが粗くなることがあります。
*   **パフォーマンスが悪い:** シャドウの生成をオフにする、シャドウマップの解像度を下げる、ライトの数を減らすなどの対策を検討してください。

#### まとめと次のステップ

ライティングは、3Dシーンに立体感とリアリティを与える上で非常に重要な要素です。様々な種類のライトを使いこなし、シャドウを生成することで、より魅力的な3Dシーンを作成することができます。次は、シーンの構築と管理について学び、オブジェクトを配置し、階層化する方法を習得しましょう。

### 2.4 シーンの構築と管理 - オブジェクトの配置と階層化

#### 概要と重要性

シーンの構築と管理は、3Dシーンを構成する上で不可欠な要素です。オブジェクトを適切に配置し、親子関係を構築することで、複雑なシーンを効率的に管理することができます。また、シーンの最適化を行うことで、パフォーマンスを向上させることができます。

#### 特徴と利点

*   **オブジェクトの追加と削除:** シーンにオブジェクトを自由に追加したり、削除したりすることができます。
*   **オブジェクトの親子関係:** オブジェクト間に親子関係を構築することで、まとめて移動、回転、拡大縮小することができます。
*   **シーンの最適化:** オブジェクトのグルーピング、カリングなどのテクニックを用いて、パフォーマンスを向上させることができます。

#### 事前準備と前提条件

*   ジオメトリ、マテリアル、ライティングが設定されたオブジェクトが作成されていること。
*   Three.jsライブラリが読み込まれていること。

#### 基本的な使い方

**1. Three.jsシーンへのオブジェクトの追加と削除**

```javascript
const scene = new THREE.Scene();

// オブジェクトの作成
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const cube = new THREE.Mesh( geometry, material );

// シーンへの追加
scene.add( cube );

// シーンからの削除
scene.remove( cube );
```

**2. オブジェクトの親子関係 (階層構造)**

```javascript
const parent = new THREE.Object3D();
const child = new THREE.Mesh( new THREE.BoxGeometry( 0.5, 0.5, 0.5 ), new THREE.MeshBasicMaterial( { color: 0xff0000 } ) ); // 赤色

// 親オブジェクトへの追加
parent.add( child );

// シーンへの追加
scene.add( parent );

// 親オブジェクトを回転させると、子オブジェクトも一緒に回転する
parent.rotation.y = Math.PI / 4;
```

**3. シーンの最適化 (オブジェクトのグルーピング、カリング)**

*   **オブジェクトのグルーピング:** 複数のオブジェクトを`THREE.Group`にまとめて管理することで、パフォーマンスを向上させることができます。

```javascript
const group = new THREE.Group();

// オブジェクトの作成
const cube1 = new THREE.Mesh( new THREE.BoxGeometry( 1, 1, 1 ), new THREE.MeshBasicMaterial( { color: 0x00ff00 } ) );
const cube2 = new THREE.Mesh( new THREE.BoxGeometry( 1, 1, 1 ), new THREE.MeshBasicMaterial( { color: 0x0000ff } ) );

// グループへの追加
group.add( cube1 );
group.add( cube2 );

// シーンへの追加
scene.add( group );
```

*   **カリング:** 視錐台 (カメラから見える範囲) に入っていないオブジェクトのレンダリングをスキップすることで、パフォーマンスを向上させることができます。Three.jsは、自動的にフラスタムカリングを行います。

#### 実践的なテクニック

*   **シーングラフの設計:** シーンを構築する前に、オブジェクトの親子関係を考慮したシーングラフを設計することで、より効率的な管理が可能になります。
*   ** LOD (Level of Detail):** オブジェクトの距離に応じて、詳細度の異なるモデルを切り替えることで、パフォーマンスを向上させることができます。

#### 応用例とユースケース

*   **複雑なシーンの管理:** 多数のオブジェクトで構成されたシーンを効率的に管理。
*   **アニメーション:** オブジェクトの親子関係を利用して、複雑なアニメーションを作成。
*   **ゲーム開発:** ゲーム内のオブジェクトの管理と最適化。
*   **インタラクティブな3Dアプリケーション:** ユーザーの操作に応じて、オブジェクトを追加、削除、移動。

#### トラブルシューティング

*   **オブジェクトが表示されない:** オブジェクトの位置、スケール、回転を確認してください。また、カメラの位置や視野角も確認してください。
*   **パフォーマンスが悪い:** オブジェクトの数を減らす、ジオメトリの頂点数を減らす、テクスチャのサイズを小さくする、カリングを適用する、LODを実装するなどの対策を検討してください。

#### まとめと次のステップ

シーンの構築と管理は、3Dシーンを効率的に構成し、パフォーマンスを向上させる上で不可欠な要素です。オブジェクトの親子関係を理解し、シーンの最適化を行うことで、より複雑でインタラクティブな3Dアプリケーションを作成することができます。次のステップでは、アニメーションやインタラクションについて学び、3Dシーンをさらに魅力的にする方法を習得しましょう。
