## 14. 省電力化 - バッテリー駆動のための最適化

Arduinoをバッテリーで駆動させる場合、いかに消費電力を抑え、バッテリーを長持ちさせるかが重要になります。この章では、Arduinoの消費電力の測定方法から、省電力化のためのテクニック、バッテリーの選定と管理、電源回路の設計、そして具体的な実践例まで、バッテリー駆動のArduinoプロジェクトを成功させるためのノウハウを網羅的に解説します。

### 14.1. Arduinoの消費電力 - 各種モジュールの消費電力測定

#### 概要と重要性

Arduinoは、様々なモジュールを接続することで、多様な機能を実現できます。しかし、それぞれのモジュールは電力を消費するため、バッテリー駆動の場合、どのモジュールがどれだけ電力を消費しているのかを把握することが重要です。闇雲に省電力化に取り組むよりも、消費電力の大きい箇所を特定し、重点的に対策することで、効率的にバッテリー寿命を延ばすことができます。

#### 特徴と利点

* **消費電力の可視化:** モジュールごとの消費電力を把握することで、改善の優先順位をつけやすくなります。
* **無駄の排除:** 想定以上に電力を消費しているモジュールを見つけ、別のモジュールへの置き換えや、使用頻度の調整を検討できます。
* **バッテリー寿命の予測:** 各モジュールの消費電力から、バッテリーの推定寿命を算出できます。

#### 事前準備と前提条件

* **Arduino IDE:** 最新版のArduino IDEがインストールされていること。
* **マルチメーター:** 電流と電圧を測定できるマルチメーター。
* **USBシリアル変換モジュール(FTDIなど):** ArduinoをPCに接続してデータを取得するために使用。
* **ブレッドボード:** 回路を組むために使用。
* **ジャンパーワイヤー:** 回路を接続するために使用。
* **各種モジュール:** 消費電力を測定したいモジュール。例：LED、センサー、モーターなど。

#### 基本的な使い方

1. **マルチメーターによる電流測定:**

   * Arduinoとモジュールの間にマルチメーターを直列に接続します。
   * マルチメーターを電流測定モード（通常はmAまたはAレンジ）に設定します。
   * Arduinoにプログラムを書き込み、モジュールを動作させます。
   * マルチメーターの値を読み取り、消費電力を記録します。

   ```arduino
   // LEDを点灯させる簡単な例
   const int ledPin = 13;

   void setup() {
     pinMode(ledPin, OUTPUT);
   }

   void loop() {
     digitalWrite(ledPin, HIGH); // LED点灯
     delay(1000);               // 1秒間点灯
     digitalWrite(ledPin, LOW);  // LED消灯
     delay(1000);               // 1秒間消灯
   }
   ```

2. **シリアル通信による電流値の表示:**

   * 外部電源を使用し、ArduinoのAnalogピンを利用して電流を電圧に変換し、シリアル通信でPCに値を送信します。
   * シャント抵抗を回路に挿入し、その抵抗の両端の電圧を測定することで電流値を算出します（オームの法則：I = V/R）。
   * Arduino IDEのシリアルモニタで電流値を確認します。

   ```arduino
   // シャント抵抗を使い、電流値を測定する例
   const int analogPin = A0; // アナログピンA0
   const float shuntResistor = 1.0; // シャント抵抗の値 (Ω)
   const float vRef = 5.0;      // 基準電圧 (V)
   const int resolution = 1024; // アナログ-デジタル変換の解像度

   void setup() {
     Serial.begin(9600);
   }

   void loop() {
     int sensorValue = analogRead(analogPin);
     float voltage = sensorValue * vRef / resolution;
     float current = voltage / shuntResistor;

     Serial.print("Current: ");
     Serial.print(current);
     Serial.println(" A");

     delay(1000);
   }
   ```

#### 実践的なテクニック

* **ピーク電流の把握:** モーターやリレーなど、起動時に大きな電流を消費するモジュールは、ピーク電流を測定することが重要です。瞬間的な電流スパイクに対応できるバッテリー容量を選定する必要があります。
* **平均電流の計算:** 間欠動作をするモジュールの場合は、一定時間内の平均電流を計算します。これにより、バッテリーの推定寿命をより正確に予測できます。

#### 応用例とユースケース

* **環境モニタリングシステム:** 温度、湿度、気圧などを測定するセンサーを搭載したシステム。各センサーの消費電力を測定し、最も電力を消費するセンサーの使用頻度を減らすことで、バッテリー寿命を延ばします。
* **ウェアラブルデバイス:** 加速度センサーや心拍センサーなどを搭載したデバイス。各センサーの消費電力を測定し、スリープモードを積極的に活用することで、バッテリー寿命を向上させます。

#### トラブルシューティング

* **マルチメーターのレンジ設定:** 電流値が想定よりも低い場合、マルチメーターのレンジ設定が間違っている可能性があります。適切なレンジに設定し直してください。
* **シャント抵抗の精度:** シャント抵抗の精度が低いと、電流値の測定誤差が大きくなります。精度の高いシャント抵抗を使用してください。
* **配線ミス:** 回路の配線が間違っていると、正常に電流を測定できません。配線を再度確認してください。

### 14.2. 省電力化のためのテクニック - スリープモード、クロック制御

#### 概要と重要性

Arduinoの消費電力を削減する上で、スリープモードとクロック制御は非常に重要なテクニックです。特に、常時動作させる必要のないシステムにおいては、これらのテクニックを積極的に活用することで、大幅な省電力化が期待できます。

#### 特徴と利点

* **大幅な消費電力削減:** スリープモードでは、Arduinoの動作を一時停止させ、消費電力を大幅に削減できます。
* **柔軟な制御:** クロック制御によって、Arduinoの動作速度を調整し、必要な時だけ高いパフォーマンスを発揮させることができます。
* **バッテリー寿命の延長:** これらのテクニックを組み合わせることで、バッテリー寿命を最大限に延ばすことができます。

#### 事前準備と前提条件

* **Arduino IDE:** 最新版のArduino IDEがインストールされていること。
* **Arduinoの電源に関する知識:** Arduinoの電源供給方法、電圧、電流に関する基本的な知識が必要です。
* **LowPowerライブラリ:** Arduinoのスリープモードを簡単に利用できるライブラリ。

#### 基本的な使い方

1. **スリープモードの利用:**

   * `LowPower`ライブラリをインストールします（スケッチ > ライブラリをインクルード > ライブラリの管理... で検索）。
   * `LowPower.powerDown(SLEEP_FOREVER, ADC_OFF, BOD_OFF);` 関数を使用することで、Arduinoをディープスリープモードに移行させることができます。
   * ウェイクアップには、割り込みを使用します。

   ```arduino
   #include <LowPower.h>

   const int wakeUpPin = 2; // 割り込みに使用するピン

   void wakeUp() {
     // ウェイクアップ時の処理
     // ここに、ウェイクアップ後に実行するコードを記述します。
   }

   void setup() {
     Serial.begin(9600);
     pinMode(wakeUpPin, INPUT_PULLUP); // 内部プルアップ抵抗を有効にする
     attachInterrupt(digitalPinToInterrupt(wakeUpPin), wakeUp, FALLING); // 割り込み設定
   }

   void loop() {
     Serial.println("Going to sleep...");
     delay(1000);
     LowPower.powerDown(SLEEP_FOREVER, ADC_OFF, BOD_OFF); // ディープスリープモード
     Serial.println("Waking up..."); // ウェイクアップ後の処理
   }
   ```

2. **クロック制御:**

   * Arduinoの動作クロックを調整することで、消費電力を削減できます。
   * `clock_prescale_set` 関数を使用することで、クロック周波数を変更できます。

   ```arduino
   #include <avr/power.h>

   void setup() {
     Serial.begin(9600);
     // クロック周波数を1/8に設定 (8MHz -> 1MHz)
     clock_prescale_set(clock_div_8);
     Serial.println("Clock frequency reduced to 1MHz");
   }

   void loop() {
     // 何らかの処理
   }
   ```

#### 実践的なテクニック

* **割り込みによるウェイクアップ:** タイマー割り込みやピン変化割り込みなど、様々な割り込みを利用してArduinoをスリープモードから復帰させることができます。
* **ペリフェラルの停止:** 使用しないペリフェラル（ADC、タイマーなど）を停止させることで、消費電力を削減できます。
* **電圧の調整:** Arduinoに供給する電圧を調整することで、消費電力を削減できます。ただし、動作電圧範囲を超えないように注意が必要です。

#### 応用例とユースケース

* **センサーノード:** 一定時間ごとにセンサー値を読み取り、データを送信するセンサーノード。スリープモードを積極的に活用し、バッテリー寿命を大幅に延長します。
* **リモートコントロール:** ボタンが押された時だけ動作するリモートコントロール。通常時はスリープモードにして、ボタンが押された時に割り込みで復帰します。

#### トラブルシューティング

* **スリープモードからの復帰:** 割り込み設定が間違っていると、スリープモードから復帰できません。割り込み設定を再度確認してください。
* **クロック周波数の変更:** クロック周波数を変更すると、タイミングに依存する処理が正常に動作しなくなる可能性があります。動作確認を十分に行ってください。
* **消費電力削減効果:** スリープモードやクロック制御の効果は、システム構成や動作条件によって異なります。効果を測定し、最適な設定を見つける必要があります。

### 14.3. バッテリーの選定と管理 - リチウムイオン電池、充電回路

#### 概要と重要性

バッテリー駆動のArduinoプロジェクトにおいて、バッテリーの選定は非常に重要な要素です。適切なバッテリーを選定し、適切に管理することで、システムの安定動作を確保し、バッテリー寿命を最大限に延ばすことができます。特に、リチウムイオン電池は高エネルギー密度で小型軽量なため、多くのArduinoプロジェクトで使用されています。

#### 特徴と利点

* **バッテリーの選定:** プロジェクトの要件に最適なバッテリーを選定することで、システムの性能を最大限に引き出すことができます。
* **安全性の確保:** リチウムイオン電池は、取り扱いを誤ると発火や爆発の危険性があります。安全な使用方法を理解し、適切な保護回路を設けることが重要です。
* **バッテリー寿命の最適化:** 充電方法や放電深度などを適切に管理することで、バッテリー寿命を最大限に延ばすことができます。

#### 事前準備と前提条件

* **電気に関する知識:** 電圧、電流、容量、電力など、電気に関する基本的な知識が必要です。
* **リチウムイオン電池に関する知識:** リチウムイオン電池の特性、充電方法、放電方法、安全上の注意点などを理解する必要があります。
* **バッテリー充電器:** リチウムイオン電池を安全かつ効率的に充電できる充電器。

#### 基本的な使い方

1. **バッテリーの選定:**

   * **電圧:** Arduinoの動作電圧に適合するバッテリーを選びます（通常は5Vまたは3.3V）。
   * **容量:** プロジェクトの消費電力と使用時間に基づいて、必要なバッテリー容量を計算します。
   * **放電レート:** バッテリーが供給できる最大電流を確認します。モーターなど、大きな電流を必要とするモジュールを使用する場合は、放電レートの高いバッテリーを選びます。
   * **サイズと重量:** プロジェクトのサイズや重量の制約を考慮して、バッテリーを選びます。

2. **リチウムイオン電池の充電:**

   * **TP4056モジュール:** リチウムイオン電池の充電に一般的に使用されるモジュールです。
   * **定電圧/定電流 (CC/CV) 充電:** リチウムイオン電池の充電には、CC/CV充電方式が推奨されます。TP4056モジュールは、この方式に対応しています。
   * **過充電防止:** リチウムイオン電池を過充電すると、発火や爆発の危険性があります。TP4056モジュールには、過充電防止機能が搭載されています。
   * **過放電防止:** リチウムイオン電池を過放電すると、バッテリー寿命が著しく低下します。TP4056モジュールには、過放電防止機能が搭載されています。

   ```arduino
   // TP4056モジュールを使用したリチウムイオン電池の充電
   // (TP4056モジュールの配線は省略)

   void setup() {
     Serial.begin(9600);
     Serial.println("Charging Lithium Ion Battery...");
   }

   void loop() {
     // 充電状態の監視
     // (TP4056モジュールのステータスLEDなどを確認)

     delay(1000);
   }
   ```

3. **バッテリーの保護:**

   * **BMS (Battery Management System):** バッテリーの過充電、過放電、過電流などを防止する保護回路。リチウムイオン電池を使用する際は、BMSを必ず使用してください。

#### 実践的なテクニック

* **バッテリー残量監視:** バッテリーの電圧を監視し、残量を推定することで、システムが予期せぬ停止をすることを防ぎます。
* **充電制御:** 充電回路を制御し、バッテリーの充電状態を最適化することで、バッテリー寿命を延ばします。
* **温度監視:** バッテリーの温度を監視し、異常な高温や低温を検知した場合、充電を停止するなどの安全対策を講じます。

#### 応用例とユースケース

* **ソーラー充電システム:** ソーラーパネルで発電した電力をリチウムイオン電池に蓄電し、Arduinoを動作させるシステム。
* **無停電電源装置 (UPS):** 停電時にリチウムイオン電池から電力を供給し、Arduinoを継続して動作させるシステム。

#### トラブルシューティング

* **バッテリーが充電されない:** 充電回路の配線、電圧、電流などを確認してください。バッテリーが過放電状態になっている場合、専用の充電器が必要になる場合があります。
* **バッテリーの寿命が短い:** 充電方法、放電深度、温度などが適切でない可能性があります。バッテリーのデータシートを確認し、適切な使用方法を守ってください。
* **バッテリーが発熱する:** 過充電、過放電、過電流などが原因である可能性があります。直ちに充電を停止し、原因を調査してください。

### 14.4. 電源回路の設計 - レギュレーター、DC-DCコンバーター

#### 概要と重要性

Arduinoをバッテリーで駆動する場合、バッテリーの電圧をArduinoが動作可能な電圧に変換する必要があります。また、電圧の変動を安定化させることも重要です。そのため、レギュレーターやDC-DCコンバーターなどの電源回路を適切に設計する必要があります。

#### 特徴と利点

* **電圧変換:** バッテリーの電圧をArduinoが動作可能な電圧に変換できます。
* **電圧安定化:** 電圧の変動を抑え、Arduinoの安定動作を確保できます。
* **効率的な電力供給:** 無駄な電力消費を抑え、バッテリー寿命を延ばすことができます。

#### 事前準備と前提条件

* **電気回路に関する知識:** 電圧、電流、抵抗、コンデンサ、インダクタなど、電気回路に関する基本的な知識が必要です。
* **レギュレーター、DC-DCコンバーターに関する知識:** 各部品の特性、動作原理、使い方などを理解する必要があります。
* **回路図作成ツール:** 回路図を作成するためのソフトウェア（例：KiCad、Eagle）があると便利です。
* **ブレッドボード:** 回路を試作するために使用。
* **ジャンパーワイヤー:** 回路を接続するために使用。

#### 基本的な使い方

1. **レギュレーター:**

   * **リニアレギュレーター:** シンプルな回路で電圧を安定化できますが、効率が低いという欠点があります。入力電圧と出力電圧の差が大きいほど、発熱量が多くなります。
   * **LDOレギュレーター (Low Dropout Regulator):** 入力電圧と出力電圧の差が小さい場合でも、安定した電圧を出力できます。リニアレギュレーターよりも効率が高いです。
   * **7805:** 5Vのリニアレギュレーター。入手が容易で使いやすいですが、効率は高くありません。

   ```
   [バッテリー +] --[7805 IN]--[7805 OUT]--[Arduino Vin]
   [バッテリー -] --[7805 GND]--[Arduino GND]
   ```

2. **DC-DCコンバーター:**

   * **降圧型DC-DCコンバーター (Buck Converter):** 入力電圧よりも低い電圧を出力します。リニアレギュレーターよりも効率が高く、発熱も少ないです。
   * **昇圧型DC-DCコンバーター (Boost Converter):** 入力電圧よりも高い電圧を出力します。
   * **昇降圧型DC-DCコンバーター (Buck-Boost Converter):** 入力電圧よりも高いまたは低い電圧を出力できます。
   * **LM2596:** 降圧型DC-DCコンバーターモジュールとしてよく利用されます。

   ```
   [バッテリー +] --[LM2596 IN+]
   [バッテリー -] --[LM2596 IN-]
   [LM2596 OUT+]--[Arduino Vin]
   [LM2596 OUT-]--[Arduino GND]
   ```

#### 実践的なテクニック

* **効率の考慮:** バッテリー駆動の場合、電源回路の効率は非常に重要です。効率の高いDC-DCコンバーターを使用することで、バッテリー寿命を延ばすことができます。
* **リップルノイズの低減:** スイッチング電源であるDC-DCコンバーターは、出力にリップルノイズが発生する可能性があります。コンデンサを追加することで、リップルノイズを低減できます。
* **保護回路:** 過電流保護、過電圧保護、短絡保護などの保護回路を設けることで、Arduinoやバッテリーを保護できます。

#### 応用例とユースケース

* **ポータブル電源:** リチウムイオン電池とDC-DCコンバーターを組み合わせ、様々なデバイスに電力を供給できるポータブル電源を製作します。
* **無線センサーネットワーク:** 各センサーノードにバッテリーとDC-DCコンバーターを搭載し、無線でデータを収集するネットワークを構築します。

#### トラブルシューティング

* **電圧が出力されない:** 回路の配線、入力電圧、部品の故障などを確認してください。
* **電圧が不安定:** 入力電圧の変動、負荷の変動、部品の選定ミスなどが原因である可能性があります。
* **発熱が大きい:** 負荷が大きすぎる、効率が低いなどが原因である可能性があります。

#### まとめと次のステップ

### 14.5. 省電力化の実践例 - 間欠動作、イベントドリブン

#### 概要と重要性

これまでのセクションで学んだ知識を活かし、実際にArduinoプロジェクトで省電力化を実践してみましょう。間欠動作やイベントドリブンといったテクニックは、バッテリー駆動のシステムにおいて非常に有効です。

#### 特徴と利点

* **間欠動作:** 必要な時だけ動作させることで、大幅な消費電力削減が可能です。
* **イベントドリブン:** センサーの値が変化した時など、特定のイベントが発生した時だけ処理を実行することで、無駄な電力消費を抑えられます。
* **リアルな省電力効果:** 実際に動作するシステムで省電力化の効果を実感できます。

#### 事前準備と前提条件

* **これまでのセクションの知識:** Arduinoの消費電力、スリープモード、バッテリー、電源回路に関する知識が必要です。
* **具体的なプロジェクト:** 省電力化を試すArduinoプロジェクトが必要です（例：温度ロガー、人感センサーライト）。
* **必要な部品:** プロジェクトに必要なセンサー、アクチュエーター、バッテリー、電源回路などを準備します。

#### 基本的な使い方

1. **間欠動作の実装:**

   * **タイマー割り込み:** タイマー割り込みを利用して、一定時間ごとにArduinoをスリープモードから復帰させ、処理を実行します。
   * **LowPowerライブラリ:** `LowPower.powerDown`関数を使用し、Arduinoをスリープモードに移行させます。

   ```arduino
   #include <LowPower.h>

   const int wakeUpInterval = 8; // スリープする秒数 (最大8秒)

   void setup() {
     Serial.begin(9600);
     Serial.println("Starting intermittent operation...");
   }

   void loop() {
     // 何らかの処理 (例: センサー値の読み取り、データの送信)
     Serial.println("Performing task...");
     delay(1000);

     Serial.print("Sleeping for ");
     Serial.print(wakeUpInterval);
     Serial.println(" seconds...");
     LowPower.powerDown(SLEEP_8S, ADC_OFF, BOD_OFF); // 8秒間スリープ
     Serial.println("Waking up...");
   }
   ```

2. **イベントドリブンの実装:**

   * **ピン変化割り込み:** センサーの値が変化した時に割り込みを発生させ、処理を実行します。
   * **状態遷移:** センサーの値によって状態を遷移させ、必要な処理だけを実行します。

   ```arduino
   const int sensorPin = 2;   // センサーピン
   const int ledPin = 13;      // LEDピン

   volatile bool motionDetected = false;

   void sensorInterrupt() {
     motionDetected = true;
   }

   void setup() {
     Serial.begin(9600);
     pinMode(sensorPin, INPUT_PULLUP); // 内部プルアップ抵抗を有効にする
     pinMode(ledPin, OUTPUT);
     attachInterrupt(digitalPinToInterrupt(sensorPin), sensorInterrupt, FALLING); // 割り込み設定
   }

   void loop() {
     if (motionDetected) {
       Serial.println("Motion detected!");
       digitalWrite(ledPin, HIGH); // LED点灯
       delay(5000);               // 5秒間点灯
       digitalWrite(ledPin, LOW);  // LED消灯
       motionDetected = false;     // フラグをリセット
     }
     LowPower.powerDown(SLEEP_FOREVER, ADC_OFF, BOD_OFF); // スリープモード
   }
   ```

#### 実践的なテクニック

* **最適なスリープ時間:** プロジェクトの要件に合わせて、最適なスリープ時間を設定します。スリープ時間が長すぎると、必要な情報を取りこぼす可能性があります。
* **割り込みの最適化:** 割り込み処理をできるだけ短くすることで、消費電力を削減できます。
* **データロギング:** 省電力化の効果を検証するために、バッテリー電圧や消費電力を定期的に記録します。

#### 応用例とユースケース

* **動物追跡システム:** GPSモジュールを搭載した動物追跡システム。間欠動作とイベントドリブンを組み合わせることで、長期間の追跡を可能にします。
* **スマートホーム:** 人感センサーやドアセンサーを搭載したスマートホームシステム。必要な時だけデバイスを起動させ、消費電力を削減します。

#### トラブルシューティング

* **割り込みが動作しない:** 割り込み設定、ピンモード、配線などを確認してください。
* **スリープモードから復帰しない:** 割り込み要因が発生しているか確認してください。
* **バッテリーの寿命が期待通りに延びない:** 消費電力を再度測定し、ボトルネックとなっている箇所を特定してください。
