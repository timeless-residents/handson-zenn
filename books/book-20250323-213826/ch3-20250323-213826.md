## 3. Arduino プログラミングの基礎 - C++言語の基本と Arduino API

Arduino を使いこなすためには、C++言語の基礎と Arduino API の知識が不可欠です。この章では、変数、データ型、制御構造といった C++の基本から、ピンの入出力、タイマー、割り込みといった Arduino 特有の機能まで、段階的に解説していきます。最終的には、センサーデータの取得と処理を通じて、実践的なアプリケーション開発の基礎を習得することを目指します。

### 3.1. C++言語の基本 - 変数、データ型、制御構造

#### 概要と重要性

C++は、Arduino IDE で使用される主要なプログラミング言語です。変数、データ型、制御構造は、あらゆるプログラムの基礎となる要素であり、これらを理解することで、Arduino のプログラムを自由に記述し、制御できるようになります。

#### 特徴と利点

- **変数:** データを一時的に保存するための名前付きの記憶領域です。
- **データ型:** 変数に格納できるデータの種類（整数、浮動小数点数、文字など）を定義します。
- **制御構造:** プログラムの実行フローを制御するための構文（条件分岐、繰り返しなど）です。

#### 事前準備と前提条件

- Arduino IDE のインストール
- Arduino ボードの準備と PC への接続

#### 基本的な使い方

**1. 変数の宣言と初期化:**

```cpp
int sensorValue; // 整数の変数を宣言
sensorValue = 0;  // 変数に初期値を代入

// または、宣言と初期化を同時に行う
int ledPin = 13;  // LEDを接続するピン番号
```

**データ型:**

- `int`: 整数 (例: -32768 から 32767)
- `long`: 長い整数 (例: -2147483648 から 2147483647)
- `float`: 浮動小数点数 (例: 3.14, -2.5)
- `double`: 倍精度浮動小数点数
- `char`: 文字 (例: 'A', 'z')
- `boolean`: 真偽値 (true または false)

**2. 制御構造 (if 文、for 文、while 文):**

- **if 文:** 条件によって実行するコードを分岐します。

```cpp
if (sensorValue > 500) {
  // センサーの値が500より大きい場合に実行されるコード
  digitalWrite(ledPin, HIGH); // LEDを点灯
} else {
  // それ以外の場合に実行されるコード
  digitalWrite(ledPin, LOW);  // LEDを消灯
}
```

- **for 文:** 指定された回数だけコードを繰り返し実行します。

```cpp
for (int i = 0; i < 10; i++) {
  // iが0から9まで1ずつ増加しながら、以下のコードを10回繰り返す
  digitalWrite(ledPin, HIGH);
  delay(100);
  digitalWrite(ledPin, LOW);
  delay(100);
}
```

- **while 文:** 指定された条件が真である間、コードを繰り返し実行します。

```cpp
while (sensorValue < 800) {
  // センサーの値が800未満の間、以下のコードを繰り返す
  sensorValue = analogRead(A0); // アナログピンA0から値を読み取る
  delay(100);
}
```

#### 実践的なテクニック

- **変数のスコープ:** 変数が有効な範囲を理解することは、バグを防ぐために重要です。ローカル変数は、定義された関数内でのみ有効です。グローバル変数は、プログラム全体で有効です。
- **定数の利用:** 変化しない値を `const` キーワードで宣言すると、コードの可読性が向上し、予期せぬ変更を防ぐことができます。

```cpp
const int MAX_SENSOR_VALUE = 1023;
```

- **コメントの活用:** コードにコメントを追加することで、処理の内容を説明し、後でコードを理解しやすくします。

```cpp
// センサーの値が閾値を超えた場合にLEDを点灯する
if (sensorValue > 500) {
  digitalWrite(ledPin, HIGH); // LEDを点灯
}
```

#### 応用例とユースケース

- **温度監視システム:** 温度センサーから読み取った値を、指定された範囲を超えた場合にアラートを出す。
- **光センサーによる自動点灯:** 周囲の明るさに応じて LED を自動的に点灯または消灯する。
- **ボタンによる LED 制御:** ボタンを押すと LED の点灯/消灯を切り替える。

#### トラブルシューティング

- **変数が定義されていない:** 変数を使用する前に、必ず宣言してください。
- **データ型の不一致:** 代入する値と変数のデータ型が一致しているか確認してください。
- **無限ループ:** `while` 文の条件が常に真である場合、プログラムが停止しない可能性があります。条件を見直してください。

### 3.2. Arduino API の基本 - ピンの入出力、タイマー、割り込み

#### 概要と重要性

Arduino API は、Arduino ボードのハードウェア機能を C++言語から簡単に操作するための関数群です。ピンの入出力、タイマー、割り込みといった機能を理解することで、Arduino を様々な用途に活用することができます。

#### 特徴と利点

- **ピンの入出力:** デジタルピンやアナログピンを制御し、センサーやアクチュエータと接続することができます。
- **タイマー:** 特定の時間間隔で処理を実行したり、パルス幅変調（PWM）を生成したりすることができます。
- **割り込み:** 特定のイベントが発生した際に、プログラムの実行を一時中断して、特定の処理を実行することができます。

#### 事前準備と前提条件

- Arduino IDE のインストール
- Arduino ボードの準備と PC への接続
- LED、抵抗、ボタンなどの電子部品（必要に応じて）

#### 基本的な使い方

**1. ピンの入出力:**

- `pinMode(pin, mode)`: ピンのモードを設定します。`pin` はピン番号、`mode` は `INPUT`, `OUTPUT`, `INPUT_PULLUP` のいずれかです。
- `digitalWrite(pin, value)`: デジタルピンに HIGH または LOW の値を出力します。
- `digitalRead(pin)`: デジタルピンから HIGH または LOW の値を読み取ります。
- `analogRead(pin)`: アナログピンから 0 から 1023 の範囲の値を読み取ります。
- `analogWrite(pin, value)`: PWM 信号を生成して、アナログピンに 0 から 255 の範囲で出力します (PWM 対応ピンのみ)。

```cpp
// LEDを接続するピン番号
const int ledPin = 13;
// ボタンを接続するピン番号
const int buttonPin = 2;

void setup() {
  pinMode(ledPin, OUTPUT);  // LEDピンを出力に設定
  pinMode(buttonPin, INPUT_PULLUP); // ボタンピンを入力に設定（内部プルアップ抵抗を使用）
}

void loop() {
  // ボタンの状態を読み取る
  int buttonState = digitalRead(buttonPin);

  // ボタンが押された場合（LOWになる）
  if (buttonState == LOW) {
    digitalWrite(ledPin, HIGH); // LEDを点灯
  } else {
    digitalWrite(ledPin, LOW);  // LEDを消灯
  }

  delay(10); // 安定化のために少し待つ
}
```

**2. タイマー:**

Arduino には、`millis()`関数と`micros()`関数を使って経過時間を計測できます。一定時間ごとに処理を実行するには、これらの関数と `if` 文を組み合わせます。

```cpp
unsigned long previousMillis = 0; // 最後にLEDの状態を変えた時間
const long interval = 1000;      // LEDの状態を変える間隔 (ミリ秒)

void loop() {
  unsigned long currentMillis = millis();

  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;

    // LEDの状態を反転させる
    digitalWrite(ledPin, !digitalRead(ledPin));
  }
}
```

**3. 割り込み:**

割り込みを使用すると、特定のイベントが発生した際に、プログラムの実行を中断して、割り込み処理ルーチン（ISR）を実行することができます。Arduino の `attachInterrupt()` 関数を使って割り込みを設定します。

```cpp
// ボタンが接続されているピン
const int interruptPin = 2;
// LEDが接続されているピン
const int ledPin = 13;

// ボタンが押された回数をカウントする変数
volatile int buttonPressCount = 0;

// 割り込みサービスルーチン (ISR)
void buttonInterrupt() {
  buttonPressCount++;
}

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(interruptPin, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(interruptPin), buttonInterrupt, FALLING);
  Serial.begin(9600);
}

void loop() {
  // ボタンが押された回数をシリアルモニタに表示する
  Serial.print("Button pressed ");
  Serial.print(buttonPressCount);
  Serial.println(" times");
  delay(1000); // 1秒ごとに表示
}
```

#### 実践的なテクニック

- **ピン番号の定義:** `const int` を使用してピン番号を定義することで、コードの可読性を向上させることができます。
- **プルアップ抵抗の利用:** ボタンやスイッチを使用する場合、`INPUT_PULLUP` モードを使用することで、外付けのプルアップ抵抗を省略できます。
- **debounce 処理:** ボタンのチャタリングによる誤動作を防ぐために、debounce 処理を実装することが重要です。debounce 処理は、ボタンの状態が安定するまで待つことで実現できます。
- **割り込みの注意点:** 割り込み処理ルーチン（ISR）は、できるだけ短くシンプルに保つ必要があります。ISR 内で長時間処理を行うと、プログラムの応答性が低下する可能性があります。

#### 応用例とユースケース

- **光センサーによる自動点灯:** 周囲の明るさに応じて LED を自動的に点灯または消灯する。
- **超音波センサーによる距離計測:** 超音波センサーを使って距離を計測し、指定された距離に近づいた場合にアラートを出す。
- **ロータリーエンコーダによる制御:** ロータリーエンコーダの回転に応じて、LED の明るさやモーターの速度を制御する。
- **緊急停止ボタン:** ボタンが押されたら即座にモーターを停止させるなど、安全確保のために割り込みを使用する。

#### トラブルシューティング

- **ピンモードの設定ミス:** ピンモードが正しく設定されているか確認してください。
- **デジタルピンとアナログピンの混同:** デジタルピンにアナログ値を書き込もうとしたり、アナログピンにデジタル値を書き込もうとしたりすると、予期せぬ動作が発生する可能性があります。
- **割り込みの競合:** 複数の割り込みが同時に発生した場合、プログラムが不安定になる可能性があります。割り込みの優先順位を設定するか、割り込み処理ルーチンの実行時間を短縮してください。
- **debounce 処理の不足:** ボタンのチャタリングによって誤動作が発生する場合、debounce 処理を追加してください。

### 3.3. 関数とライブラリの活用 - コードの再利用と効率化

#### 概要と重要性

関数とライブラリは、コードの再利用性を高め、プログラムをより構造的にするための重要な要素です。関数は、特定の処理をまとめたもので、ライブラリは、複数の関数やクラスをまとめたものです。これらを活用することで、複雑なプログラムを効率的に開発することができます。

#### 特徴と利点

- **関数の再利用性:** 同じ処理を何度も記述する必要がなくなり、コードの量を減らすことができます。
- **プログラムの構造化:** 関数によってプログラムを論理的なブロックに分割することで、コードの可読性と保守性を向上させることができます。
- **ライブラリの利用:** 既存のライブラリを活用することで、高度な機能を簡単に実装することができます。
- **コードの共有と協調:** 関数とライブラリは、他の開発者と共有することができ、チームでの開発を効率化することができます。

#### 事前準備と前提条件

- Arduino IDE のインストール
- Arduino ボードの準備と PC への接続
- 必要なライブラリのインストール（例：LiquidCrystal）

#### 基本的な使い方

**1. 関数の定義と呼び出し:**

```cpp
// LEDを点滅させる関数
void blinkLed(int pin, int duration) {
  digitalWrite(pin, HIGH);
  delay(duration);
  digitalWrite(pin, LOW);
  delay(duration);
}

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  // LEDを1秒間隔で点滅させる
  blinkLed(13, 1000);
}
```

**2. 引数と戻り値:**

関数は、引数を受け取り、戻り値を返すことができます。

```cpp
// 2つの整数の合計を計算する関数

  return a + b;
}

void loop() {
  int result = add(5, 3);
  Serial.println(result); // シリアルモニタに8を表示

}
```

**3. ライブラリのインクルードと利用:**

Arduino IDE には、様々なライブラリが付属しています。これらのライブラリを使用するには、まず `#include` ディレクティブを使ってライブラリをインクルードする必要があります。

```cpp
#include <LiquidCrystal.h>

// LiquidCrystalオブジェクトを定義
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  // LCDの行数と列数を設定
  lcd.begin(16, 2);
  // LCDにメッセージを表示
  lcd.print("Hello, world!");
}

void loop() {
  // 現在のミリ秒数をLCDの2行目に表示
  lcd.setCursor(0, 1);
  lcd.print(millis() / 1000);
  delay(1000);
}
```

#### 実践的なテクニック

- **引数の型と数:** 関数に必要な引数の型と数を正確に定義しましょう。
- **戻り値の活用:** 関数の結果を戻り値として返すことで、処理の結果を他の場所で利用することができます。
- **ライブラリの選択:** 適切なライブラリを選択することで、開発時間を短縮することができます。

#### 応用例とユースケース

- **センサーデータの平均化:** 複数のセンサーから読み取った値を平均化する関数を作成する。
- **PWM 制御:** モーターの速度を PWM 制御する関数を作成する。

### 3.4. オブジェクト指向プログラミングの基礎 - クラスとオブジェクト

#### 概要と重要性

オブジェクト指向プログラミング（OOP）は、プログラムをオブジェクトと呼ばれる独立した部品の集合として捉えるプログラミングパラダイムです。クラスは、オブジェクトの設計図であり、オブジェクトは、クラスから生成された実体です。OOP を理解することで、より複雑なプログラムを効率的に開発し、保守性を高めることができます。

#### 特徴と利点

- **モジュール性:** オブジェクトは、独立したモジュールとして扱うことができるため、プログラムの構造を理解しやすくなります。
- **再利用性:** クラスを再利用することで、同じような機能を何度も記述する必要がなくなります。
- **拡張性:** 新しいクラスを作成したり、既存のクラスを拡張したりすることで、プログラムの機能を簡単に拡張することができます。
- **カプセル化:** データとメソッドをクラスの中に隠蔽することで、データの不正なアクセスを防ぐことができます。

#### 事前準備と前提条件

- Arduino IDE のインストール
- Arduino ボードの準備と PC への接続
- C++言語の基本的な知識（変数、データ型、制御構造、関数）

#### 基本的な使い方

**1. クラスの定義:**

```cpp
// LEDクラス
class Led {
  private:
    int pin;      // LEDが接続されているピン番号
    bool isOn;    // LEDの状態 (true: 点灯, false: 消灯)

  public:
    // コンストラクタ (オブジェクトの初期化)
    Led(int pinNumber) {
      pin = pinNumber;
      pinMode(pin, OUTPUT);
      isOn = false;  // 初期状態は消灯
    }

    // LEDを点灯させるメソッド
    void turnOn() {
      digitalWrite(pin, HIGH);
      isOn = true;
    }

    // LEDを消灯させるメソッド
    void turnOff() {
      digitalWrite(pin, LOW);
      isOn = false;
    }

    // LEDの状態を反転させるメソッド
    void toggle() {
      if (isOn) {
        turnOff();
      } else {
        turnOn();
      }
    }

    // LEDの状態を取得するメソッド
    bool getState() {
      return isOn;
    }
};
```

**2. オブジェクトの生成:**

```cpp
// Ledクラスのオブジェクトを生成
Led myLed(13); // 13番ピンに接続されたLEDオブジェクト
```

**3. メソッドの呼び出し:**

```cpp
void setup() {
}

void loop() {
  myLed.turnOn();   // LEDを点灯
  delay(1000);
  myLed.turnOff();  // LEDを消灯
  delay(1000);
  myLed.toggle(); //LEDの状態を反転させる
  delay(1000);
}
```

**4. 継承:**

既存のクラスを継承して、新しいクラスを作成することができます。継承によって、既存のクラスの機能を受け継ぎ、新しい機能を追加したり、既存の機能を変更したりすることができます。

```cpp
// 拡張されたLEDクラス(点滅機能付き)
class BlinkingLed : public Led {
  private:
    int blinkInterval;

  public:
    BlinkingLed(int pinNumber, int interval) : Led(pinNumber) {
      blinkInterval = interval;
    }

    void blink() {
      turnOn();
      delay(blinkInterval);
      turnOff();
      delay(blinkInterval);
    }
};

// BlinkingLedクラスのオブジェクトを生成
BlinkingLed blinkingLed(12, 500); // 12番ピンに接続されたLEDオブジェクト、500ms間隔で点滅

void loop() {
  blinkingLed.blink();
}
```

#### 実践的なテクニック

- **適切なクラス設計:** クラスは、現実世界のオブジェクトや概念をモデル化するように設計しましょう。
- **カプセル化の徹底:** データは `private` メンバ変数として宣言し、getter/setter メソッドを通じてアクセスするようにしましょう。
- **継承の活用:** 既存のクラスを継承して、新しいクラスを作成することで、コードの再利用性を高めることができます。
- **ポリモーフィズムの理解:** ポリモーフィズムとは、同じ名前のメソッドが、異なるクラスで異なる動作をすることです。ポリモーフィズムを活用することで、より柔軟なプログラムを作成することができます。

#### 応用例とユースケース

- **複数のセンサーを管理するクラス:** 複数のセンサーからデータを読み取り、平均値や最大値を計算するクラスを作成する。
- **モーターを制御するクラス:** モーターの速度や方向を制御するメソッドを持つクラスを作成する。
- **GUI ライブラリ:** ボタン、テキストボックス、ラベルなどの GUI 要素を管理するクラスを作成する。

#### トラブルシューティング

- **オブジェクトが生成できない:** クラスのコンストラクタが正しく定義されているか確認してください。
- **メソッドが呼び出せない:** メソッド名が正しいか、オブジェクトが正しい型であるか確認してください。
- **継承がうまくいかない:** 継承元のクラスのアクセス指定子（`public`, `private`, `protected`）が正しく設定されているか確認してください。

### 3.5. センサーデータの取得と処理 - 温度センサー、距離センサーなど

#### 概要と重要性

Arduino を使って様々なセンサーからデータを取得し、処理することは、IoT デバイス開発の基本です。温度センサー、距離センサー、光センサーなど、様々なセンサーからデータを取得し、適切な処理を行うことで、様々なアプリケーションを実現することができます。

#### 特徴と利点

- **現実世界のデータの取得:** センサーを使って、温度、湿度、距離、光、音など、現実世界の様々なデータを取得することができます。
- **データ処理:** 取得したデータを処理することで、必要な情報を取り出すことができます。例えば、温度センサーから取得した値を華氏から摂氏に変換したり、距離センサーから取得した値をスムージングしたりすることができます。
- **自動制御:** 取得したデータに基づいて、モーターや LED などのアクチュエータを制御することができます。例えば、温度センサーから取得した値が閾値を超えた場合に、ファンを回したり、LED を点灯させたりすることができます。

#### 事前準備と前提条件

- Arduino IDE のインストール
- Arduino ボードの準備と PC への接続
- 温度センサー、距離センサーなどの必要なセンサー
- ブレッドボード、ジャンパーワイヤー

#### 基本的な使い方

**1. 温度センサー（例：DHT11）:**

```cpp
#include <DHT.h>

#define DHTPIN 2     // DHT11のデータピン
#define DHTTYPE DHT11   // DHT11センサー

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  Serial.println("DHT11 Test Program");
  dht.begin();
}

void loop() {
  delay(2000); // 2秒ごとにデータを読み取る

  float h = dht.readHumidity();    // 湿度を読み取る
  float t = dht.readTemperature(); // 温度を読み取る (摂氏)

  if (isnan(h) || isnan(t)) {
    Serial.println("Failed to read from DHT sensor!");
    return;
  }

  Serial.print("Humidity: ");
  Serial.print(h);
  Serial.print(" %\t");
  Serial.print("Temperature: ");
  Serial.print(t);
  Serial.println(" *C");
}
```

**2. 距離センサー（例：超音波センサー HC-SR04）:**

```cpp
const int trigPin = 9;
const int echoPin = 10;

long duration;
int distance;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT); // Trigピンを出力に設定
  pinMode(echoPin, INPUT);   // Echoピンを入力に設定
}

void loop() {
  // 距離を測定
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  duration = pulseIn(echoPin, HIGH);
  distance = duration * 0.034 / 2; // 音速(340m/s)からcm単位に変換

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  delay(100);
}
```
