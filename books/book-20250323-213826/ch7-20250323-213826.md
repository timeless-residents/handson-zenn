## 7. 実践例 2：異常検知 - センサーデータから異常を予測するシステム

### 7.1. プロジェクト概要 - センサーデータによる異常検知

**概要と重要性**

現代社会において、様々な場所にセンサーが設置され、温度、湿度、振動、圧力など、多種多様なデータが収集されています。これらのセンサーデータは、工場の設備監視、建物の状態監視、環境モニタリングなど、様々な分野で活用されています。しかし、大量のデータの中に隠された異常を人間が手動で見つけ出すのは非常に困難です。そこで、機械学習を活用した異常検知システムが注目されています。

この章では、Arduino と各種センサーを用いてデータを収集し、機械学習モデルを用いて異常を検知するシステムを構築する実践的な例を紹介します。特に、製造業における設備故障の予知や、農業における異常気象の早期発見など、実務で役立つユースケースを想定して解説します。

**特徴と利点**

- **リアルタイム監視:** センサーデータをリアルタイムで分析し、異常を即座に検知できます。
- **予防保全:** 設備の故障や異常事態を予測し、事前に対応することで、ダウンタイムを削減できます。
- **コスト削減:** 人手による監視作業を削減し、効率的な運用を実現できます。
- **汎用性:** 様々なセンサーデータに対応でき、幅広い分野で応用できます。
- **自動化:** 異常検知プロセスを自動化し、ヒューマンエラーを防止できます。

**事前準備と前提条件**

- **ハードウェア:** Arduino Uno (または互換機)、温度センサー（DHT11、DHT22 など）、湿度センサー（DHT11、DHT22 など）、振動センサー、ブレッドボード、ジャンパーワイヤー
- **ソフトウェア:** Arduino IDE, Python (3.7 以降), Jupyter Notebook, scikit-learn, pandas, matplotlib
- **知識:** Arduino の基本的な使い方、Python の基本的なプログラミング、機械学習の基礎知識（教師あり学習、教師なし学習など）
- **その他:** PC (Windows, macOS, Linux), インターネット接続

**基本的な使い方**

この章では、以下のステップで異常検知システムを構築します。

1.  **センサーデータの収集:** Arduino を用いて各種センサーからデータを収集し、PC に送信します。
2.  **データの整形と前処理:** 収集したデータを Python で整形し、機械学習モデルに入力できる形式に変換します。
3.  **機械学習モデルの選択と学習:** 異常検知に適した機械学習モデル（例：Isolation Forest, One-Class SVM, Local Outlier Factor）を選択し、学習データを用いてモデルを学習させます。
4.  **異常検知の実装:** 学習済みモデルを用いて新しいデータに対する異常度を算出し、閾値に基づいて異常を判定します。
5.  **結果の可視化:** 異常検知の結果をグラフやダッシュボードで可視化します。

**実践的なテクニック**

- **データの前処理:** データの欠損値処理、外れ値処理、平滑化処理などを行うことで、モデルの精度を向上させることができます。
- **特徴量エンジニアリング:** センサーデータから有用な特徴量を抽出し、モデルに入力することで、検知精度を向上させることができます。
- **モデルの選択:** データの特性や要件に合わせて、適切な機械学習モデルを選択することが重要です。
- **閾値の設定:** 異常を判定するための閾値を適切に設定することが重要です。閾値を高く設定すると、見逃しが多くなり、低く設定すると誤検知が多くなります。
- **リアルタイム処理:** センサーデータをリアルタイムで処理し、異常を即座に検知するために、効率的なアルゴリズムとデータ構造を使用します。

**応用例とユースケース**

- **製造業:** 設備の振動や温度を監視し、故障を予知することで、ダウンタイムを削減します。
- **農業:** 温度、湿度、土壌水分などを監視し、異常気象や病害虫の発生を早期に発見することで、被害を最小限に抑えます。
- **エネルギー管理:** 電力使用量を監視し、異常な電力消費を検知することで、エネルギー効率を向上させます。
- **ヘルスケア:** 生体データを監視し、異常な心拍数や体温を検知することで、病気の早期発見に貢献します。
- **スマートシティ:** 交通量や騒音レベルを監視し、異常な交通渋滞や騒音を検知することで、都市の快適性を向上させます。

**トラブルシューティング**

- **データのノイズ:** センサーデータのノイズを除去するために、フィルタリング処理を行います。
- **モデルの精度:** モデルの精度が低い場合は、学習データを増やす、特徴量エンジニアリングを行う、モデルのパラメータを調整するなどの対策を検討します。
- **閾値の設定:** 閾値の設定が難しい場合は、ROC 曲線や Precision-Recall 曲線を用いて、適切な閾値を決定します。
- **ハードウェアの故障:** センサーや Arduino が故障した場合は、代替品と交換します。

**1. センサーデータの収集**

- **Arduino スケッチの作成:** 以下のコードは、DHT11/DHT22 から温度と湿度を読み取り、振動センサーから振動データを読み取り、シリアル通信で PC に送信する例です。

```arduino
#include <DHT.h>

#define DHTPIN 2     // DHTのデータピン
#define DHTTYPE DHT11   // DHTの種類 (DHT11, DHT22, DHT21)
#define VIBRATION_PIN A0 // 振動センサーのアナログピン

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  // 温度と湿度を読み取る
  float temperature = dht.readTemperature();
  float humidity = dht.readHumidity();

  // 振動データを読み取る
  int vibration = analogRead(VIBRATION_PIN);

  // データをシリアル通信で送信する
  Serial.print(temperature);
  Serial.print(",");
  Serial.print(humidity);
  Serial.print(",");
  Serial.println(vibration);

  delay(1000); // 1秒間隔でデータを送信
}
```

- **Arduino スケッチのアップロード:** Arduino IDE で上記のスケッチを開き、Arduino Uno にアップロードします。

**2. データの整形と前処理**

- **Python プログラムの作成:** 以下のコードは、シリアル通信で Arduino からデータを受信し、pandas の DataFrame に格納し、データを前処理する例です。

```python
import serial
import pandas as pd
from sklearn.preprocessing import MinMaxScaler
import time

# シリアルポートの設定
port = "COM3"  # Arduinoが接続されているシリアルポートを指定
baudrate = 9600
ser = serial.Serial(port, baudrate)
time.sleep(2) # Arduinoの初期化を待つ

# データの格納先
data = []

try:
    while True:
        # シリアル通信でデータを受信する
        line = ser.readline().decode('utf-8').rstrip()

        # データを分割
        values = line.split(',')

        # データが3つの場合のみ処理
        if len(values) == 3:
            try:
                temperature = float(values[0])
                humidity = float(values[1])
                vibration = int(values[2])

                # データをリストに追加
                data.append([temperature, humidity, vibration])
            except ValueError:
                print(f"Invalid data: {line}") # エラーハンドリング

        # データをDataFrameに変換 (最初の100件のみ)
        if len(data) >= 100:
            df = pd.DataFrame(data, columns=['temperature', 'humidity', 'vibration'])

            # 欠損値の処理 (平均値で補完)
            df = df.fillna(df.mean())

            # データの正規化 (MinMaxScalerを使用)
            scaler = MinMaxScaler()
            df[['temperature', 'humidity', 'vibration']] = scaler.fit_transform(df[['temperature', 'humidity', 'vibration']])

            print(df.head()) # 最初の5行を表示
            break # 最初の100件を処理したらループを抜ける
        else:
            print(f"Received data: {line}")


except KeyboardInterrupt:
    print("Exiting...")
finally:
    ser.close()
    print("Serial port closed.")
```

- **Python プログラムの実行:** Jupyter Notebook などで上記のプログラムを実行します。

**4. 異常検知の実装**

- **異常度の算出:** 学習済みモデルを用いて、新しいデータに対する異常度を算出します。
- **閾値の設定:** 異常と判定するための閾値を設定します。閾値は、データの特性や要件に合わせて調整する必要があります。ROC 曲線や Precision-Recall 曲線を用いて、適切な閾値を決定すると良いでしょう。
- **異常判定:** 異常度が閾値を超えた場合、異常と判定します。
- 以下のコードは、新しいデータに対する異常度を算出し、閾値に基づいて異常を判定する例です。

```python
import joblib
import serial
import pandas as pd
from sklearn.preprocessing import MinMaxScaler
import time

# 学習済みモデルのロード
model = joblib.load('isolation_forest_model.pkl')

# シリアルポートの設定
port = "COM3"  # Arduinoが接続されているシリアルポートを指定
baudrate = 9600
ser = serial.Serial(port, baudrate)
time.sleep(2) # Arduinoの初期化を待つ

# 閾値の設定 (要調整)
threshold = -0.15 # 例：異常度スコアが-0.15を下回る場合を異常と判定

# スケーラーのロード
scaler = MinMaxScaler()

try:
    while True:
        # シリアル通信でデータを受信する
        line = ser.readline().decode('utf-8').rstrip()

        # データを分割
        values = line.split(',')

        # データが3つの場合のみ処理
        if len(values) == 3:
            try:
                temperature = float(values[0])
                humidity = float(values[1])
                vibration = int(values[2])

                # データをDataFrameに変換
                new_data = pd.DataFrame([[temperature, humidity, vibration]], columns=['temperature', 'humidity', 'vibration'])

                # スケーリング
                new_data[['temperature', 'humidity', 'vibration']] = scaler.fit_transform(new_data[['temperature', 'humidity', 'vibration']])

                # 異常度を算出
                anomaly_score = model.decision_function(new_data[['temperature', 'humidity', 'vibration']])

                # 異常判定
                if anomaly_score < threshold:
                    print(f"Anomaly detected! Anomaly score: {anomaly_score[0]:.2f}")
                else:
                    print(f"Normal. Anomaly score: {anomaly_score[0]:.2f}")

            except ValueError:
                print(f"Invalid data: {line}")
        else:
            print(f"Received data: {line}")


except KeyboardInterrupt:
    print("Exiting...")
finally:
    ser.close()
    print("Serial port closed.")
```

**1. ノイズの原因特定:**

- **センサーの特性:** センサー自体が持つノイズ（例：電気的なノイズ、温度ドリフト）。

**2. ノイズ除去の手法:**

- **ハードウェア対策:**
  - **シールド:** シールド線を使用し、電磁波の影響を軽減します。
  - **フィルタ回路:** センサーの出力にローパスフィルタやバンドパスフィルタを挿入し、不要な周波数成分を除去します。
  - **絶縁:** グランドループを避けるため、電源と信号線を絶縁します。
- **ソフトウェア対策:** \* **移動平均フィルタ:** 過去のデータを用いて平均値を計算し、ノイズを平滑化します。
  ```python
  import numpy as np
  import pandas as pd

              def moving_average(data, window_size):
                  """移動平均フィルタを適用する関数"""
                  window = np.ones(int(window_size))/float(window_size)
                  return np.convolve(data, window, 'same')

              # 例：温度データの移動平均を計算
              #  df['temperature'] が温度データを含む pandas DataFrame
              window_size = 5 # ウィンドウサイズ
              df['temperature_smoothed'] = moving_average(df['temperature'], window_size)
              ```
          *   **メディアンフィルタ:** データの並び替えを行い、中央値を採用することで、外れ値の影響を軽減します。
               ```python
               from scipy.signal import medfilt

               # 例：振動データのメディアンフィルタを適用
               #  df['vibration'] が振動データを含む pandas DataFrame
               window_size = 3 # ウィンドウサイズ（奇数）
               df['vibration_smoothed'] = medfilt(df['vibration'], kernel_size=window_size)
               ```

          *   **カルマンフィルタ:** システムの状態を推定し、ノイズの影響を軽減します（より高度な手法）。
               ```python
               # PyKalmanを利用するにはインストールが必要です：pip install pykalman
               from pykalman import KalmanFilter
               import numpy as np

               # 例：カルマンフィルタを適用する
               # transition_matrix, observation_matrix, initial_state_mean, initial_state_covariance, observation_covariance, transition_covariance は適切な値に設定
               kf = KalmanFilter(transition_matrices = [[1]], observation_matrices = [[1]], initial_state_mean = 0, initial_state_covariance = 1, observation_covariance = 1, transition_covariance = 0.01)

               # 振動データのカルマンフィルタリング

               measurements = df['vibration'].values
               smoothed_state_means, smoothed_state_covariances = kf.filter(measurements)
               df['vibration_smoothed'] = smoothed_state_means
               ```

          *   **外れ値除去:** 統計的な手法（Zスコア、IQRなど）を用いて、異常な値を特定し、除去または修正します。
              ```python
              def remove_outliers(data, threshold=3):
                  """Zスコアに基づいて外れ値を除去する関数"""
                  mean = np.mean(data)
                  std = np.std(data)
                  z_scores = np.abs((data - mean) / std)
                  filtered_data = data[z_scores < threshold]
                  return filtered_data

              # 例：温度データの外れ値を除去
              #  df['temperature'] が温度データを含む pandas DataFrame
              df['temperature_filtered'] = remove_outliers(df['temperature'].values)
              ```
