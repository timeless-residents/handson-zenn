## 17. AI エージェントの実装 - 強化学習による制御

強化学習は、AI エージェントが試行錯誤を通じて最適な行動を学習する強力な手法です。本章では、強化学習の基礎から応用までを解説し、特に Arduino を使った具体的な実装例を通じて、その実践的な側面を深く掘り下げます。ロボット制御や自動運転といった具体的な応用例にも触れ、読者の皆さんが強化学習の可能性を最大限に引き出せるように、詳細かつ分かりやすく解説していきます。

### 17.1. 強化学習の概要 - 環境とのインタラクションによる学習

**1. 概要と重要性**

強化学習は、エージェントが環境とのインタラクションを通じて、報酬を最大化するように学習する機械学習の一分野です。教師あり学習や教師なし学習とは異なり、明示的な教師データは必要ありません。エージェントは、行動の結果として環境から得られる報酬に基づいて、最適な行動戦略（ポリシー）を学習します。

現実世界の多くの問題は、報酬という形で評価できるため、強化学習はロボット工学、ゲーム AI、自動運転、資源管理など、幅広い分野で応用されています。例えば、ロボットが特定のタスクを達成するために、試行錯誤を繰り返しながら最適な動作を学習したり、ゲーム AI が対戦相手を打ち負かすために、様々な戦略を学習したりできます。

**2. 特徴と利点**

強化学習の主な特徴は以下の通りです。

- **明示的な教師データが不要:** エージェントは、環境から得られる報酬に基づいて学習します。
- **試行錯誤による学習:** エージェントは、様々な行動を試し、その結果に基づいて学習します。
- **遅延報酬の扱い:** 行動の結果がすぐには現れず、時間差で報酬が発生する場合でも学習できます。
- **動的な環境への適応:** 環境が変化しても、継続的に学習し、最適な行動戦略を維持できます。

これらの特徴から、強化学習は以下のような利点を提供します。

- **複雑な問題への適用:** 複雑なルールや制約を持つ問題でも、エージェントが自律的に解決策を見つけ出すことができます。
- **最適化された戦略の発見:** 人間が設計するよりも、より効率的で効果的な行動戦略を学習できます。
- **環境変化への柔軟な対応:** 環境の変化に応じて、リアルタイムで行動戦略を適応させることができます。

**3. 事前準備と前提条件**

強化学習の実装には、以下の知識があると理解が深まります。

- **Python の基本的な知識:** 強化学習ライブラリの多くは Python で実装されています。
- **線形代数と確率の基礎知識:** 強化学習のアルゴリズムを理解する上で役立ちます。
- **強化学習の基本的な概念:** 報酬、状態、行動、ポリシーなどの用語を理解していることが望ましいです。

**4. 基本的な使い方**

強化学習の基本的な流れは以下の通りです。

1.  **環境の定義:** エージェントがインタラクションする環境を定義します。状態、行動、報酬関数などを決定します。
2.  **エージェントの設計:** 学習アルゴリズム（Q 学習、SARSA、DQN など）を選択し、エージェントを設計します。
3.  **学習の実行:** エージェントを環境とインタラクションさせ、学習を行います。
4.  **評価と改善:** 学習したポリシーを評価し、必要に応じてエージェントの設計や学習パラメータを調整します。

**5. 実践的なテクニック**

- **報酬関数の設計:** 適切な報酬関数を設計することが、強化学習の成功に不可欠です。報酬は、エージェントが目指すべき目標を明確に反映する必要があります。例えば、ロボットに特定の場所に移動させる場合、目標地点に近づくほど高い報酬を与えるように設計します。
- **探索と利用のバランス:** エージェントは、未知の行動を試す（探索）と、既に知っている最適な行動を取る（利用）のバランスを取る必要があります。探索を促進するために、ε-greedy 法やソフトマックス法などの手法が用いられます。
- **割引率の設定:** 未来の報酬をどれだけ重視するかを決定する割引率を設定します。割引率が高いほど、未来の報酬を重視し、長期的な視点での学習を促進します。
- **状態空間の削減:** 状態空間が大きすぎると、学習が困難になる場合があります。状態空間を削減するために、状態の集約や特徴抽出などの手法を用います。

**6. 応用例とユースケース**

- **ロボット制御:** ロボットアームの動作制御、自律移動ロボットの経路計画、ヒューマノイドロボットの歩行制御など。
- **ゲーム AI:** チェス、囲碁、将棋などのボードゲーム、ビデオゲームにおける敵キャラクターの制御など。
- **自動運転:** 車両の運転制御、経路計画、交通信号の最適化など。
- **資源管理:** エネルギー管理、在庫管理、広告配信の最適化など。

**7. トラブルシューティング**

- **学習が進まない:** 報酬関数が適切でない、学習率が低すぎる、状態空間が広すぎるなどの原因が考えられます。
- **過学習:** 学習データに過剰に適合し、未知の環境で性能が低下する現象です。正則化や早期打ち切りなどの手法で対応します。
- **発散:** 学習が不安定になり、報酬が振動したり、極端な値になったりする現象です。学習率の調整や報酬のクリッピングなどの手法で対応します。

**8. まとめと次のステップ**

強化学習は、エージェントが環境とのインタラクションを通じて最適な行動を学習する強力な手法です。本セクションでは、強化学習の基礎概念、特徴、利点、基本的な使い方、実践的なテクニック、応用例、トラブルシューティングについて解説しました。次のステップとして、具体的な強化学習アルゴリズム（Q 学習、SARSA、DQN など）を学習し、実際にコードを書いて実験してみることをお勧めします。

### 17.2. Q 学習、SARSA、Deep Q-Network（DQN）

**1. 概要と重要性**

Q 学習、SARSA、DQN は、代表的な強化学習アルゴリズムです。それぞれ異なる特徴を持ち、適用可能な問題も異なります。これらのアルゴリズムを理解することで、強化学習の適用範囲を広げることができます。

- **Q 学習:** オフポリシー型の強化学習アルゴリズムで、最適な行動価値関数を学習します。
- **SARSA:** オンポリシー型の強化学習アルゴリズムで、実際に行動するポリシーに従って行動価値関数を学習します。
- **DQN (Deep Q-Network):** Q 学習を深層学習と組み合わせたアルゴリズムで、高次元の状態空間を持つ問題に対応できます。

**2. 特徴と利点**

| アルゴリズム | 特徴                                               | 利点                                                           | 欠点                                                                 |
| :----------- | :------------------------------------------------- | :------------------------------------------------------------- | :------------------------------------------------------------------- |
| Q 学習       | オフポリシー型、行動価値関数を直接学習             | 最適な行動価値関数を学習できる、安定した学習                   | 行動ポリシーと学習ポリシーが異なるため、学習が不安定になる場合がある |
| SARSA        | オンポリシー型、実際に行動するポリシーに従って学習 | 安全な行動戦略を学習できる、Q 学習よりも安定した学習           | 最適な行動戦略を学習できない場合がある                               |
| DQN          | Q 学習 + 深層学習、高次元の状態空間に対応          | 高次元の状態空間を持つ問題に対応できる、複雑な環境でも学習可能 | 学習に時間がかかる、ハイパーパラメータの調整が難しい、過学習しやすい |

**3. 事前準備と前提条件**

- **Python の基本的な知識:** 強化学習ライブラリの多くは Python で実装されています。
- **NumPy の知識:** 数値計算ライブラリ NumPy の基本的な使い方を理解している必要があります。
- **PyTorch または TensorFlow の知識:** DQN の実装には、深層学習フレームワークの知識が必要です。
- **強化学習の基本的な概念:** 報酬、状態、行動、ポリシーなどの用語を理解していることが望ましいです。

**4. 基本的な使い方**

**Q 学習の実装例 (Python):**

```python
import numpy as np

# 環境の定義 (例: 迷路)
env = {
    0: {'A': 1, 'B': 4},
    1: {'A': 0, 'C': 2},
    2: {'B': 1, 'D': 3},
    3: {'C': 2, 'E': 5},
    4: {'A': 0, 'E': 5},
    5: {'D': 3, 'E': 4}
}

# パラメータ設定
alpha = 0.1  # 学習率
gamma = 0.9  # 割引率
epsilon = 0.1 # 探索率

# Q値の初期化
Q = np.zeros((len(env), len(env)))

# 学習
for episode in range(1000):
    state = np.random.choice(list(env.keys()))  # 初期状態をランダムに選択
    done = False

    while not done:
        # ε-greedy法による行動選択
        if np.random.uniform(0, 1) < epsilon:
            action = np.random.choice(list(env[state].keys()))  # ランダムな行動を選択
        else:
            possible_actions = list(env[state].keys())
            q_values = [Q[state, list(env.keys()).index(env[state][a])] for a in possible_actions]
            action = possible_actions[np.argmax(q_values)]

        # 行動の実行と報酬の獲得
        next_state = env[state][action]
        reward = 1 if next_state == 5 else 0  # ゴールに到達したら報酬1

        # Q値の更新
        Q[state, list(env.keys()).index(next_state)] = Q[state, list(env.keys()).index(next_state)] + alpha * (reward + gamma * np.max(Q[next_state, :]) - Q[state, list(env.keys()).index(next_state)])

        # 状態の更新
        state = next_state

        # 終了条件 (例: ゴールに到達)
        if state == 5:
            done = True

print("Q-Table:")
print(Q)
```

```python
# 環境の定義 (例: 迷路)
env = {

for episode in range(1000):

    if np.random.uniform(0, 1) < epsilon:
        action = np.random.choice(list(env[state].keys()))  # ランダムな行動を選択
    else:
        possible_actions = list(env[state].keys())
        q_values = [Q[state, list(env.keys()).index(env[state][a])] for a in possible_actions]
        action = possible_actions[np.argmax(q_values)]

    done = False

    while not done:
        # 行動の実行と報酬の獲得
        next_state = env[state][action]
        reward = 1 if next_state == 5 else 0  # ゴールに到達したら報酬1

        # ε-greedy法による次の行動選択
        if np.random.uniform(0, 1) < epsilon:
            next_action = np.random.choice(list(env[next_state].keys()))  # ランダムな行動を選択
        else:
            possible_actions = list(env[next_state].keys())
            q_values = [Q[next_state, list(env.keys()).index(env[next_state][a])] for a in possible_actions]
            next_action = possible_actions[np.argmax(q_values)]

        # Q値の更新
        Q[state, list(env.keys()).index(next_state)] = Q[state, list(env.keys()).index(next_state)] + alpha * (reward + gamma * Q[next_state, list(env.keys()).index(env[next_state][next_action])] - Q[state, list(env.keys()).index(next_state)])

        # 状態と行動の更新
        state = next_state
        action = next_action

        # 終了条件 (例: ゴールに到達)
        if state == 5:
            done = True

print("Q-Table:")
print(Q)
```

**DQN の実装例 (PyTorch):**

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
import random

# 環境の定義 (OpenAI Gymなどを使用)
# 例として、シンプルなCartPole環境を使用
import gym
env = gym.make('CartPole-v1')

# ハイパーパラメータ
learning_rate = 0.001
gamma = 0.99
epsilon_start = 1.0
epsilon_end = 0.01
epsilon_decay = 0.0005
batch_size = 32
memory_size = 10000
target_update_interval = 100
num_episodes = 500

# ニューラルネットワークの定義
class DQN(nn.Module):
    def __init__(self, input_dim, output_dim):
        super(DQN, self).__init__()
        self.fc1 = nn.Linear(input_dim, 128)
        self.fc2 = nn.Linear(128, 128)
        self.fc3 = nn.Linear(128, output_dim)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        x = self.fc3(x)
        return x

# リプレイメモリの定義
class ReplayMemory:
    def __init__(self, capacity):
        self.capacity = capacity
        self.memory = []
        self.position = 0

    def push(self, *args):
        if len(self.memory) < self.capacity:
            self.memory.append(None)
        self.memory[self.position] = Transition(*args)
        self.position = (self.position + 1) % self.capacity

    def sample(self, batch_size):
        return random.sample(self.memory, batch_size)

    def __len__(self):
        return len(self.memory)

# Transitionの定義
from collections import namedtuple
Transition = namedtuple('Transition',
                        ('state', 'action', 'reward', 'next_state', 'done'))


# モデルの初期化
input_dim = env.observation_space.shape[0]
output_dim = env.action_space.n
policy_net = DQN(input_dim, output_dim).to("cpu") #必要に応じて"cuda"に変更
target_net = DQN(input_dim, output_dim).to("cpu") #必要に応じて"cuda"に変更
target_net.load_state_dict(policy_net.state_dict())
target_net.eval()

optimizer = optim.Adam(policy_net.parameters(), lr=learning_rate)
memory = ReplayMemory(memory_size)

# ε-greedy法
def select_action(state, epsilon):
    if random.random() > epsilon:
        with torch.no_grad():
            return policy_net(state).max(1)[1].view(1, 1)
    else:
        return torch.tensor([[random.randrange(output_dim)]], device="cpu", dtype=torch.long) #必要に応じて"cuda"に変更

# 学習の実行
def optimize_model():
    if len(memory) < batch_size:
        return
    transitions = memory.sample(batch_size)
    batch = Transition(*zip(*transitions))

    state_batch = torch.cat(batch.state)
    action_batch = torch.cat(batch.action)
    reward_batch = torch.cat(batch.reward)
    next_state_batch = torch.cat(batch.next_state)
    done_mask = torch.tensor(batch.done, device="cpu", dtype=torch.bool) #必要に応じて"cuda"に変更

    q_values = policy_net(state_batch).gather(1, action_batch)

    next_state_values = torch.zeros(batch_size, device="cpu") #必要に応じて"cuda"に変更
    next_state_values[~done_mask] = target_net(next_state_batch[~done_mask]).max(1)[0].detach()

    expected_q_values = (next_state_values * gamma) + reward_batch

    loss = nn.functional.mse_loss(q_values, expected_q_values.unsqueeze(1))

    optimizer.zero_grad()
    loss.backward()
    for param in policy_net.parameters():
        param.grad.data.clamp_(-1, 1)
    optimizer.step()

# メインループ
epsilon = epsilon_start
for episode in range(num_episodes):
    state = env.reset()
    state = torch.tensor([state], dtype=torch.float32, device="cpu") #必要に応じて"cuda"に変更
    total_reward = 0
    for t in range(500):  # CartPoleの最大ステップ数は500
        action = select_action(state, epsilon)
        next_state, reward, done, _ = env.step(action.item())
        next_state = torch.tensor([next_state], dtype=torch.float32, device="cpu") #必要に応じて"cuda"に変更
        reward = torch.tensor([reward], dtype=torch.float32, device="cpu") #必要に応じて"cuda"に変更
        done = done

        memory.push(state, action, reward, next_state, done)
        state = next_state
        total_reward += reward.item()

        optimize_model()
        if done:
            break

    # ターゲットネットワークの更新
    if episode % target_update_interval == 0:
        target_net.load_state_dict(policy_net.state_dict())

    # εの減衰
    epsilon = epsilon_end + (epsilon_start - epsilon_end) * np.exp(-epsilon_decay * episode)

    print(f"Episode: {episode}, Total Reward: {total_reward}, Epsilon: {epsilon}")

print('Complete')
env.close()
```

**5. 実践的なテクニック**

- **ハイパーパラメータの調整:** 学習率、割引率、探索率などのハイパーパラメータは、問題によって最適な値が異なります。様々な値を試して、最適なパラメータを見つける必要があります。グリッドサーチやランダムサーチなどの手法が有効です。
- **リプレイメモリの利用:** DQN では、リプレイメモリを使って過去の経験を蓄積し、学習に利用します。リプレイメモリの容量やサンプリング方法を調整することで、学習の安定性や効率を向上させることができます。
- **ターゲットネットワークの利用:** DQN では、ターゲットネットワークを使って Q 値を安定させるために、一定間隔でポリシーネットワークのパラメータをコピーします。ターゲットネットワークの更新間隔を調整することで、学習の安定性を向上させることができます。
- **報酬の正規化:** 報酬のスケールが大きすぎると、学習が不安定になる場合があります。報酬を正規化することで、学習を安定させることができます。

### 17.3. Arduino での強化学習の実装 - 環境のモデル化、報酬関数の設計

**1. 概要と重要性**

Arduino は、手軽に扱えるマイコンボードであり、強化学習アルゴリズムを組み込むことで、物理的な環境とインタラクションする AI エージェントを開発できます。本セクションでは、Arduino で強化学習を実装するための環境モデルの構築、報酬関数の設計について解説します。

**2. 特徴と利点**

Arduino で強化学習を実装する主な特徴と利点は以下の通りです。

- **低コスト:** Arduino ボードは比較的安価であり、低コストで実験的な AI エージェントを開発できます。
- **物理的な環境とのインタラクション:** Arduino は、センサーやアクチュエータと接続できるため、物理的な環境とインタラクションする AI エージェントを開発できます。
- **リアルタイム制御:** Arduino は、リアルタイムで動作するため、リアルタイム制御が必要なアプリケーションに適しています。
- **教育的な価値:** Arduino は、プログラミングや電子回路の学習に役立ち、強化学習の概念を理解する上で役立ちます。

**3. 事前準備と前提条件**

- **Arduino の基本的な知識:** Arduino IDE の使い方、スケッチの書き方、デジタル入出力、アナログ入出力などの知識が必要です。
- **C++の基本的な知識:** Arduino のプログラミング言語は C++です。C++の基本的な構文、変数、関数、制御構造などの知識が必要です。
- **強化学習の基本的な概念:** 報酬、状態、行動、ポリシーなどの用語を理解していることが望ましいです。
- **必要なハードウェア:** Arduino ボード、センサー（例: 超音波センサー、温度センサー）、アクチュエータ（例: モーター、LED）など。

**4. 基本的な使い方**

**ステップ 1: 環境のモデル化**

Arduino で強化学習を実装するためには、まず環境をモデル化する必要があります。環境の状態、行動、報酬関数を定義します。

- **状態:** 環境の状態を表す変数を定義します。例えば、ロボットの位置、センサーの値、モーターの回転角度など。
- **行動:** エージェントが実行可能な行動を定義します。例えば、モーターの回転方向、LED の点灯/消灯など。
- **報酬関数:** エージェントの行動に対する報酬を定義します。報酬は、エージェントが目指すべき目標を明確に反映する必要があります。例えば、ロボットが目標地点に近づくほど高い報酬を与えるように設計します。

**ステップ 2: 強化学習アルゴリズムの実装**

Arduino に強化学習アルゴリズム（Q 学習、SARSA など）を実装します。Arduino のメモリ容量や処理能力は限られているため、シンプルなアルゴリズムを選択する必要があります。

**ステップ 3: 環境とのインタラクション**

Arduino をセンサーやアクチュエータと接続し、環境とインタラクションさせます。エージェントは、環境の状態を読み取り、行動を実行し、報酬を受け取ります。

**ステップ 4: 学習の実行**

エージェントを環境とインタラクションさせ、学習を実行します。学習の結果、エージェントは最適な行動戦略（ポリシー）を学習します。

**5. 実践的なテクニック**

- **状態の離散化:** 状態空間が連続的な場合、状態を離散化する必要があります。例えば、センサーの値がある範囲にある場合、その範囲を一つの状態として扱います。
- **報酬のスケール調整:** 報酬のスケールが大きすぎると、学習が不安定になる場合があります。報酬をスケール調整することで、学習を安定させることができます。
- **探索と利用のバランス:** エージェントは、未知の行動を試す（探索）と、既に知っている最適な行動を取る（利用）のバランスを取る必要があります。探索を促進するために、ε-greedy 法などの手法が用いられます。

**6. 応用例とユースケース**

- **ライントレースロボット:** ライントレースロボットに強化学習を実装することで、よりスムーズで効率的なライントレースを実現できます。
- **倒立振子:** 倒立振子に強化学習を実装することで、バランスを維持する制御を学習させることができます。
- **温度制御:** 温室の温度を一定に保つために、強化学習を実装することができます。

**7. トラブルシューティング**

- **メモリ不足:** Arduino のメモリ容量は限られているため、プログラムがメモリ不足になる場合があります。変数の数を減らす、配列のサイズを小さくするなどの対策が必要です。
- **処理速度の低下:** Arduino の処理能力は限られているため、複雑な計算を行うと処理速度が低下する場合があります。計算量を減らす、処理を最適化するなどの対策が必要です。
- **学習が進まない:** 報酬関数が適切でない、学習率が低すぎる、状態空間が広すぎる、探索が不十分などの原因が考えられます。

**8. まとめと次のステップ**

Arduino で強化学習を実装することで、低コストで物理的な環境とインタラクションする AI エージェントを開発できます。本セクションでは、Arduino で強化学習を実装するための環境モデルの構築、報酬関数の設計、実践的なテクニック、応用例、トラブルシューティングについて解説しました。次のステップとして、実際に Arduino を使って強化学習エージェントを開発し、実験してみることをお勧めします。

**Arduino での Q 学習の実装例:**

```c++
#include <EEPROM.h>

// 環境の定義
#define NUM_STATES 5 // 状態数
#define NUM_ACTIONS 2 // 行動数

// ピンの定義
#define LED_PIN 13

// パラメータ
const float learningRate = 0.1;
const float discountFactor = 0.9;
const float explorationRate = 0.1;

// Q値テーブル (EEPROMに保存)
float Q[NUM_STATES][NUM_ACTIONS];

// 状態の定義 (例: 距離センサーの値)
int currentState = 0;

// 関数のプロトタイプ宣言
int chooseAction(int state);
float calculateReward(int state);
void updateQValue(int state, int action, float reward, int nextState);
void loadQTableFromEEPROM();
void saveQTableToEEPROM();

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);

  // EEPROMからQ値をロード
  loadQTableFromEEPROM();

  // 初期状態の設定
  currentState = 0;
}

void loop() {
  // 行動を選択
  int action = chooseAction(currentState);

  // 行動を実行
  if (action == 0) {
    // LEDを点灯
    digitalWrite(LED_PIN, HIGH);
    Serial.println("Action: LED ON");
  } else {
    // LEDを消灯
    digitalWrite(LED_PIN, LOW);
    Serial.println("Action: LED OFF");
  }

  delay(1000); // 1秒待機

  // 次の状態を決定 (例: ランダムに変化)
  int nextState = random(NUM_STATES);

  // 報酬を計算
  float reward = calculateReward(currentState);

  // Q値を更新
  updateQValue(currentState, action, reward, nextState);

  // 状態を更新
  currentState = nextState;

  // EEPROMにQ値を保存 (一定間隔で)
  static unsigned long lastSaveTime = 0;
  if (millis() - lastSaveTime > 60000) { // 1分ごとに保存
    saveQTableToEEPROM();
    lastSaveTime = millis();
  }
}

// 行動を選択する関数 (ε-greedy法)
int chooseAction(int state) {
  if (random(100) < explorationRate * 100) {
    // 探索: ランダムな行動を選択
    return random(NUM_ACTIONS);
  } else {
    // 利用: 最も高いQ値を持つ行動を選択
    int bestAction = 0;
    for (int i = 1; i < NUM_ACTIONS; i++) {
      if (Q[state][i] > Q[state][bestAction]) {
        bestAction = i;
      }
    }
    return bestAction;
  }
}

// 報酬を計算する関数
float calculateReward(int state) {
  // 例: 状態が良いほど高い報酬を与える
  if (state == NUM_STATES - 1) {
    return 1.0; // 目標状態
  } else {
    return 0.0;
  }
}

// Q値を更新する関数
void updateQValue(int state, int action, float reward, int nextState) {
  // Q(s, a) = Q(s, a) + alpha * (reward + gamma * max(Q(s', a')) - Q(s, a))
  float maxNextQ = Q[nextState][0];
  for (int i = 1; i < NUM_ACTIONS; i++) {
    if (Q[nextState][i] > maxNextQ) {
      maxNextQ = Q[nextState][i];
    }
  }
  Q[state][action] = Q[state][action] + learningRate * (reward + discountFactor * maxNextQ - Q[state][action]);
}

// EEPROMからQ値をロードする関数
void loadQTableFromEEPROM() {
  for (int i = 0; i < NUM_STATES; i++) {
    for (int j = 0; j < NUM_ACTIONS; j++) {
      Q[i][j] = EEPROM.get(i * NUM_ACTIONS * sizeof(float) + j * sizeof(float), Q[i][j]);
    }
  }
  Serial.println("Q-Table loaded from EEPROM.");
}

// EEPROMにQ値を保存する関数
void saveQTableToEEPROM() {
  for (int i = 0; i < NUM_STATES; i++) {
    for (int j = 0; j < NUM_ACTIONS; j++) {
      EEPROM.put(i * NUM_ACTIONS * sizeof(float) + j * sizeof(float), Q[i][j]);
    }
  }
  Serial.println("Q-Table saved to EEPROM.");
}
```
