## 9. 実践例 4：自然言語処理 - テキストデータから感情を分析するシステム

### 9.1. プロジェクト概要 - テキストデータによる感情分析

#### 9.1.1. 概要と重要性

感情分析は、テキストデータから書き手の感情や意見を抽出する技術です。SNS の投稿、レビュー、アンケート回答など、あらゆるテキストデータから、ポジティブ、ネガティブ、ニュートラルといった感情を判別できます。

このプロジェクトでは、Arduino と WiFi モジュール、そして自然言語処理 API を利用して、テキストデータからリアルタイムで感情を分析するシステムを構築します。例えば、店舗のアンケート結果を自動的に分析し、顧客満足度を可視化したり、特定のキーワードに関する SNS の投稿を監視し、炎上リスクを早期に発見したりすることが可能になります。

#### 9.1.2. 特徴と利点

このシステムの主な特徴は以下の通りです。

- **リアルタイム分析:** テキストデータが入力されるとほぼ同時に感情分析結果を表示。
- **低コスト:** Arduino をベースにしているため、比較的低コストで構築可能。
- **カスタマイズ性:** Arduino スケッチを修正することで、様々な自然言語処理 API に対応可能。
- **IoT 連携:** WiFi モジュールを介してインターネットに接続し、クラウドサービスとの連携も容易。

感情分析システムの利点は、データに基づいた意思決定を支援できることです。例えば、製品開発における顧客のニーズ把握、マーケティング戦略の効果測定、リスク管理などに役立ちます。

#### 9.1.3. 事前準備と前提条件

このプロジェクトを進めるにあたって、以下の準備が必要です。

- **ハードウェア:**
  - Arduino Uno (または互換機)
  - WiFi モジュール (ESP8266 または ESP32)
  - LCD ディスプレイ (オプション、分析結果の表示用)
  - ジャンパーワイヤー
- **ソフトウェア:**
  - Arduino IDE
  - 自然言語処理 API のアカウント (例: Google Cloud Natural Language API, Microsoft Azure Text Analytics API)
- **前提知識:**
  - Arduino の基本的な使い方
  - C/C++のプログラミング基礎
  - 自然言語処理の基本的な概念

#### 9.1.4. 基本的な使い方

まずは、Arduino と WiFi モジュール、ディスプレイを接続し、Arduino IDE で基本的なプログラムを動作させることから始めます。

#### 9.3.4. 基本的な使い方

**Arduino スケッチの構成:**

```c++
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <ArduinoJson.h>
#include <LiquidCrystal_I2C.h> // LCDディスプレイ用

// WiFiの設定
const char* ssid = "YOUR_SSID";
const char* password = "YOUR_PASSWORD";

// 自然言語処理APIのエンドポイントとAPIキー (例: Google Cloud Natural Language API)
const char* host = "language.googleapis.com";
const int httpsPort = 443;
const char* apiKey = "YOUR_API_KEY";

// LCDディスプレイの設定
LiquidCrystal_I2C lcd(0x27, 16, 2); // I2Cアドレスとサイズ

WiFiClientSecure client;

void setup() {
  Serial.begin(115200);

  // LCDディスプレイ初期化
  lcd.init();
  lcd.backlight();
  lcd.print("Connecting...");

  // WiFi接続
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("");
  Serial.println("WiFi connected");
  lcd.clear();
  lcd.print("WiFi Connected!");
  delay(1000);
}

void loop() {
  // テキストデータの取得 (例: シリアルポートから)
  String text = Serial.readStringUntil('\n');
  text.trim(); // 空白文字を削除

  if (text.length() > 0) {
    Serial.print("Analyzing: ");
    Serial.println(text);
    lcd.clear();
    lcd.print("Analyzing...");

    // 自然言語処理APIにリクエストを送信し、感情分析の結果を取得
    String sentiment = analyzeSentiment(text);

    // 分析結果をシリアルポートとLCDディスプレイに出力
    Serial.print("Sentiment: ");
    Serial.println(sentiment);
    lcd.clear();
    lcd.print("Sentiment:");
    lcd.setCursor(0, 1);
    lcd.print(sentiment);
    delay(2000);
  }
}

// 自然言語処理APIにリクエストを送信する関数 (例: Google Cloud Natural Language API)
String analyzeSentiment(String text) {
  // JSONペイロードの作成
  String jsonPayload = "{\"document\":{\"type\":\"PLAIN_TEXT\",\"content\":\"" + text + "\"},\"encodingType\":\"UTF8\"}";

  // リクエストパスの作成
  String path = "/v1/documents:analyzeSentiment?key=" + String(apiKey);

  // HTTPSリクエストの送信
  if (!client.connect(host, httpsPort)) {
    Serial.println("connection failed");
    return "Error";
  }

  // リクエストヘッダーの送信
  client.println("POST " + path + " HTTP/1.1");
  client.println("Host: " + String(host));
  client.println("Content-Type: application/json");
  client.println("Content-Length: " + String(jsonPayload.length()));
  client.println("Connection: close");
  client.println();
  client.println(jsonPayload);

  // レスポンスの受信
  String response = "";
  while (client.available()) {
    String line = client.readStringUntil('\r');
    response += line;
  }

  // レスポンスの解析 (JSON形式)
  int bodyIndex = response.indexOf("{");
  String jsonResponse = response.substring(bodyIndex);

  // JSONの解析
  DynamicJsonDocument doc(1024);
  deserializeJson(doc, jsonResponse);

  // 感情の強さ (magnitude) と極性 (score) を取得
  float magnitude = doc["documentSentiment"]["magnitude"];
  float score = doc["documentSentiment"]["score"];

  // 感情の判定
  String sentiment;
  if (score > 0.2) {
    sentiment = "Positive";
  } else if (score < -0.2) {
    sentiment = "Negative";
  } else {
    sentiment = "Neutral";
  }

  Serial.print("Magnitude: ");
  Serial.println(magnitude);
  Serial.print("Score: ");
  Serial.println(score);

  return sentiment;
}
```

**注意点:**

- `YOUR_SSID`, `YOUR_PASSWORD`, `YOUR_API_KEY` は、ご自身の環境に合わせて変更してください。
- 使用する自然言語処理 API に合わせて、`analyzeSentiment` 関数を適切に修正してください。
- JSON の解析には、`ArduinoJson` ライブラリを使用しています。

#### 9.5.4. 基本的な使い方

**テキストデータのクリーニング:**

- **不要な文字の削除:** HTML タグ、URL、特殊文字など、感情分析に不要な文字を削除します。
- **大文字・小文字の統一:** 大文字と小文字を統一することで、単語の認識精度を向上させます。
- **スペルミス・誤字脱字の修正:** スペルミスや誤字脱字を修正することで、単語の認識精度を向上させます。
- **ストップワードの削除:** "a", "the", "is" など、一般的な単語（ストップワード）を削除することで、感情分析に重要な単語を強調することができます。

**分析精度の向上:**

- **感情分析 API の選択:** 使用する自然言語処理 API によって、分析精度が異なる場合があります。複数の API を試してみて、最適な API を選択してください。
- **学習データの追加:** 特定の分野のテキストデータを学習データとして追加することで、その分野の感情分析精度を向上させることができます。
- **パラメータ調整:** 自然言語処理 API のパラメータを調整することで、分析精度を向上させることができます。

#### 9.5.5. 実践的なテクニック

**テキストデータのクリーニングの実装例 (Arduino):**

```c++
String cleanText(String text) {
  // 不要な文字の削除
  text.replace("<[^>]*>", ""); // HTMLタグの削除
  text.replace("http[^\\s]*", ""); // URLの削除

  // 大文字を小文字に変換
  text.toLowerCase();

  // 特殊文字の削除 (例: !"#$%&'()*+,-./:;<=>?@[]^_`{|}~)
  String specialChars = "!\"#$%&'()*+,-./:;<=>?@[]^_`{|}~";
  for (int i = 0; i < specialChars.length(); i++) {
    text.replace(String(specialChars[i]), "");
  }

  return text;
}
```

**分析精度の向上 (感情極性の調整):**

`analyzeSentiment`関数で感情を判定する際、スコアの閾値を調整することで、より正確な感情分析を行うことができます。例えば、より慎重にポジティブ/ネガティブを判定したい場合は、閾値を大きくします。

```c++
  // 感情の判定
  String sentiment;
  if (score > 0.5) { // 閾値を0.5に調整
    sentiment = "Positive";
  } else if (score < -0.5) { // 閾値を-0.5に調整
    sentiment = "Negative";
  } else {
    sentiment = "Neutral";
  }
```

#### 9.5.6. 応用例とユースケース

- **レビュー分析:** オンラインストアのレビューを分析し、製品の改善点を見つけることができます。
- **カスタマーサポート:** カスタマーサポートの問い合わせ内容を分析し、顧客の不満を解消するための改善策を講じることができます。
- **従業員満足度調査:** 従業員アンケートを分析し、従業員の満足度を向上させるための施策を検討することができます。

#### 9.5.7. トラブルシューティング

- **クリーニング後のテキストデータが空になる:** クリーニング処理が過剰である可能性があります。不要なクリーニング処理を削除するか、クリーニング処理のパラメータを調整してください。
- **分析精度が向上しない:** 学習データの追加やパラメータ調整が不適切である可能性があります。他の方法を試すか、専門家のアドバイスを求めてください。
- **API のエラーレートが高い:** API の利用制限を超えていないか、API の障害が発生していないかなどを確認してください。
