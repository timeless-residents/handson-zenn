## 第4章：awkによるデータ抽出と加工

### 4.1 awkの基本構造

**概要と重要性**

awkは、テキストファイルを処理するための強力なプログラミング言語です。その強みは、データの抽出、加工、集計、レポート作成といった、テキストデータ処理に必要な機能を、簡潔な構文で実現できる点にあります。ログファイルの解析、CSVデータの整形、レポートの自動生成など、さまざまな場面で活躍します。

**特徴と利点**

*   **簡潔な構文:** 短いコードで複雑な処理を記述できます。
*   **柔軟なパターンマッチング:** 正規表現を使って柔軟なデータ抽出が可能です。
*   **強力なデータ加工機能:** 四則演算、文字列操作、配列など、豊富な機能が利用できます。
*   **レポート作成機能:** `printf`関数を使って、整形されたレポートを簡単に作成できます。

**事前準備と前提条件**

awkは、ほとんどのUnix系オペレーティングシステム（Linux, macOS, BSDなど）に標準でインストールされています。Windows環境で使用する場合は、Gawk (GNU Awk) などの実装をインストールする必要があります。

**基本的な使い方**

awkの基本的な構造は次のとおりです。

```bash
awk 'パターン { アクション }' 入力ファイル
```

*   **パターン:** 処理対象となるレコードを選択するための条件です。省略した場合、すべてのレコードが処理されます。
*   **アクション:** パターンに一致したレコードに対して実行される処理です。省略した場合、レコード全体が出力されます。
*   **入力ファイル:** 処理対象となるテキストファイルです。省略した場合、標準入力から読み込まれます。

**フィールドとレコード**

awkは、入力ファイルをレコード（通常は1行）に分割し、各レコードをフィールドに分割します。

*   `$1`, `$2`...：各フィールドを表します。`$1`は最初のフィールド、`$2`は2番目のフィールドを表します。
*   `$0`：レコード全体を表します。
*   `NR`：現在のレコード番号を表します。
*   `NF`：現在のレコードのフィールド数を表します。

例えば、次のコマンドは、`/etc/passwd`ファイルの各行の最初のフィールド（ユーザー名）を出力します。

```bash
awk -F: '{print $1}' /etc/passwd
```

`-F:`オプションは、フィールド区切り文字をコロン（:）に設定します。

**組み込み変数**

awkには、便利な組み込み変数が多数用意されています。

*   `FS`：フィールド区切り文字。デフォルトは空白文字。
*   `RS`：レコード区切り文字。デフォルトは改行文字。
*   `OFS`：出力フィールド区切り文字。デフォルトは空白文字。
*   `ORS`：出力レコード区切り文字。デフォルトは改行文字。

これらの変数を設定することで、入力ファイルの形式に合わせて、awkの動作をカスタマイズできます。

例えば、次のコマンドは、`/etc/passwd`ファイルの各行を、タブ区切りで出力します。

```bash
awk 'BEGIN { FS = ":"; OFS = "\t" } { print $1, $3, $4 }' /etc/passwd
```

`BEGIN`ブロックは、入力ファイルの読み込み前に一度だけ実行されます。ここでは、`FS`をコロン、`OFS`をタブに設定しています。

**実践的なテクニック**

*   **正規表現を使ったパターンマッチング:** `/パターン/`の形式で正規表現を使用できます。例えば、次のコマンドは、`error`という文字列を含む行を出力します。

    ```bash
    awk '/error/' logfile.txt
    ```

*   **条件文を使ったフィルタリング:** `if`文を使って、特定の条件を満たすレコードのみを処理できます。例えば、次のコマンドは、3番目のフィールドが100より大きいレコードを出力します。

    ```bash
    awk '{if ($3 > 100) print $0}' data.txt
    ```

*   **算術演算:** `+`, `-`, `*`, `/`, `%`などの算術演算子を使用できます。例えば、次のコマンドは、各行の最初のフィールドと2番目のフィールドの合計を出力します。

    ```bash
    awk '{print $1 + $2}' data.txt
    ```

**応用例とユースケース**

*   **ログファイルの解析:** 特定のエラーメッセージの抽出、特定のIPアドレスからのアクセス数の集計など。
*   **CSVデータの整形:** 不要なフィールドの削除、フィールドの順序の変更、データの変換など。
*   **レポートの自動生成:** データの集計結果を表形式で出力、特定の条件を満たすレコードの抽出とレポート作成など。

**トラブルシューティング**

*   **パターンが一致しない:** 正規表現の誤り、入力ファイルの形式との不一致などが考えられます。
*   **アクションが実行されない:** パターンの条件が厳しすぎる、アクションの構文エラーなどが考えられます。
*   **出力が期待通りでない:** フィールド区切り文字の設定ミス、`printf`関数のフォーマット指定の誤りなどが考えられます。

**まとめと次のステップ**

このセクションでは、awkの基本的な構造、フィールドとレコード、組み込み変数、実践的なテクニックについて学びました。次のセクションでは、awkを使ったデータ集計について詳しく解説します。

### 4.2 awkを使ったデータ集計

**概要と重要性**

awkは、テキストデータを集計するのに非常に適しています。数値の合計、平均、最大値、最小値などを簡単に計算できます。さらに、連想配列を使うことで、データのグルーピングやカウントも柔軟に行えます。

**特徴と利点**

*   **簡単な数値計算:** 変数を使って、数値の合計や平均などを簡単に計算できます。
*   **条件分岐:** `if`文を使って、条件に応じて異なる処理を実行できます。
*   **ループ処理:** `for`文や`while`文を使って、繰り返し処理を実行できます。
*   **連想配列:** キーと値のペアを格納できる連想配列を使って、データのグルーピングやカウントを効率的に行えます。

**事前準備と前提条件**

このセクションでは、awkの基本的な知識があることを前提としています。前のセクションをまだ読んでいない場合は、先にそちらを読むことをお勧めします。

**基本的な使い方**

*   **合計:** `sum += $1`のように、変数にフィールドの値を加算することで、合計を計算できます。
*   **平均:** 合計をレコード数で割ることで、平均を計算できます。
*   **最大値:** `if ($1 > max) max = $1`のように、条件文を使って最大値を更新できます。
*   **最小値:** `if ($1 < min) min = $1`のように、条件文を使って最小値を更新できます。

例えば、次のコマンドは、`data.txt`ファイルの各行の最初のフィールドの合計を出力します。

```bash
awk '{ sum += $1 } END { print "合計:", sum }' data.txt
```

`END`ブロックは、入力ファイルの読み込み後に一度だけ実行されます。ここでは、合計を出力しています。

**`if`文や `for` 文を使った条件分岐とループ**

awkでは、`if`文や`for`文を使って、条件分岐やループ処理を行うことができます。

*   **`if`文:** 特定の条件を満たす場合にのみ、処理を実行します。
    ```awk
    if (条件) {
        # 条件が真の場合に実行される処理
    } else {
        # 条件が偽の場合に実行される処理
    }
    ```
*   **`for`文:** 繰り返し処理を実行します。
    ```awk
    for (初期化; 条件; 増減) {
        # 繰り返し実行される処理
    }
    ```

例えば、次のコマンドは、`data.txt`ファイルの各行の最初のフィールドが100より大きい場合に、その値を出力します。

```bash
awk '{ if ($1 > 100) print $1 }' data.txt
```

また、次のコマンドは、1から10までの数字を順番に出力します。

```bash
awk 'BEGIN { for (i = 1; i <= 10; i++) print i }'
```

**連想配列を使ったデータの集計とグルーピング**

連想配列は、キーと値のペアを格納できる配列です。awkでは、連想配列を使って、データの集計やグルーピングを効率的に行うことができます。

```awk
配列名[キー] = 値
```

例えば、次のコマンドは、`access.log`ファイルから、各IPアドレスからのアクセス数を集計します。

```bash
awk '{ count[$1]++ } END { for (ip in count) print ip, count[ip] }' access.log
```

`count[$1]++`は、`$1`（IPアドレス）をキーとして、対応する値をインクリメントします。`END`ブロックでは、連想配列`count`の各要素をループ処理し、IPアドレスとアクセス数を出力します。

**実践的なテクニック**

*   **複数条件の組み合わせ:** `&&`（AND）、`||`（OR）、`!`（NOT）を使って、複数の条件を組み合わせることができます。例えば、次のコマンドは、最初のフィールドが100より大きく、2番目のフィールドが200より小さいレコードを出力します。

    ```bash
    awk '{ if ($1 > 100 && $2 < 200) print $0 }' data.txt
    ```

*   **文字列関数:** `length()`, `substr()`, `index()`, `split()`などの文字列関数を使って、文字列の長さを取得したり、部分文字列を抽出したり、文字列を分割したりすることができます。

    ```awk
    length(文字列)        # 文字列の長さを返す
    substr(文字列, 開始位置, 長さ)  # 文字列の部分文字列を返す
    index(文字列, 部分文字列)    # 部分文字列が最初に出現する位置を返す
    split(文字列, 配列, 区切り文字) # 文字列を区切り文字で分割し、配列に格納する
    ```

*   **ユーザー定義関数:** `function 関数名(引数) { ... }`の形式で、独自の関数を定義することができます。

**応用例とユースケース**

*   **Webサーバーのアクセスログ解析:** 特定のURLへのアクセス数の集計、特定の時間帯のアクセス数の集計、エラーコード別の件数集計など。
*   **販売データの集計:** 商品別の売上金額の集計、顧客別の購入履歴の集計、地域別の売上動向の分析など。
*   **アンケートデータの集計:** 各質問への回答数の集計、回答者の属性別の回答傾向の分析など。

**トラブルシューティング**

*   **数値計算がうまくいかない:** フィールドが数値として認識されていない、変数の初期化漏れなどが考えられます。`+0`することで文字列を数値に変換できる場合があります。
*   **連想配列のキーが意図しない値になる:** フィールド区切り文字の設定ミス、入力データの形式との不一致などが考えられます。
*   **集計結果が正しくない:** 条件分岐の誤り、ループ処理の誤り、変数の更新漏れなどが考えられます。

**まとめと次のステップ**

このセクションでは、awkを使ったデータ集計について学びました。次のセクションでは、awkを使ったレポート作成について詳しく解説します。

### 4.3 awkを使ったレポート作成

**概要と重要性**

awkは、データを抽出・集計するだけでなく、整形されたレポートを作成する機能も備えています。`printf`関数を使うことで、出力形式を細かく制御し、見やすいレポートを作成することができます。

**特徴と利点**

*   **`printf`関数によるフォーマット出力:** 数値、文字列、日付などを、指定された形式で出力できます。
*   **ヘッダーとフッターの追加:** レポートの先頭にヘッダー、末尾にフッターを追加できます。
*   **レポートの整形:** フィールドの幅、小数点以下の桁数などを指定し、見栄えの良いレポートを作成できます。

**事前準備と前提条件**

このセクションでは、awkの基本的な知識、およびデータ集計に関する知識があることを前提としています。

**`printf` 関数によるフォーマット出力**

`printf`関数は、C言語の`printf`関数とほぼ同じように動作します。

```awk
printf "フォーマット文字列", 引数1, 引数2, ...
```

*   **フォーマット文字列:** 出力形式を指定する文字列です。
*   **引数:** フォーマット文字列で指定された形式で出力される値です。

主なフォーマット指定子：

*   `%s`: 文字列
*   `%d`: 整数
*   `%f`: 浮動小数点数
*   `%e`: 指数表記の浮動小数点数
*   `%c`: 文字

フォーマット指定子には、幅や精度を指定することもできます。

*   `%10s`: 幅10文字の文字列
*   `%.2f`: 小数点以下2桁の浮動小数点数
*   `%03d`: 3桁の整数（0埋め）

例えば、次のコマンドは、`data.txt`ファイルの各行の最初のフィールドと2番目のフィールドを、それぞれ幅10文字の文字列として出力します。

```bash
awk '{ printf "%10s %10s\n", $1, $2 }' data.txt
```

`\n`は改行文字です。

**ヘッダーとフッターの追加**

`BEGIN`ブロックを使ってヘッダーを、`END`ブロックを使ってフッターを追加できます。

例えば、次のコマンドは、`data.txt`ファイルの各行の最初のフィールドと2番目のフィールドを出力するレポートに、ヘッダーとフッターを追加します。

```bash
awk '
BEGIN {
    printf "--------------------\n"
    printf "フィールド1  フィールド2\n"
    printf "--------------------\n"
}
{
    printf "%-10s %-10s\n", $1, $2
}
END {
    printf "--------------------\n"
    printf "レポート作成完了\n"
}
' data.txt
```

`-` は左寄せを指定します。

**レポートの整形と見栄えの改善**

*   **フィールドの幅を調整する:** `%Ns`や`%Nd`のように、フィールドの幅を指定することで、フィールドを整列させることができます。
*   **小数点以下の桁数を調整する:** `%.Nf`のように、小数点以下の桁数を指定することで、数値を統一された形式で表示できます。
*   **区切り線を追加する:** `printf "--------------------\n"`のように、区切り線を追加することで、レポートを見やすくすることができます。
*   **空白文字やタブ文字を適切に使う:** 空白文字やタブ文字を適切に使うことで、レポートの可読性を向上させることができます。

**実践的なテクニック**

*   **条件分岐を使ったレポートのカスタマイズ:** `if`文を使って、特定の条件に応じてレポートの内容を変更することができます。例えば、エラーが発生した場合に、エラーメッセージを強調表示するなどが可能です。

*   **連想配列を使った集計結果のレポート:** 連想配列を使って集計したデータを、表形式で出力することができます。

*   **外部コマンドとの連携:** `system()`関数を使って、外部コマンドを実行し、その結果をレポートに組み込むことができます。

    ```awk
    system("date") # 現在の日時を出力する
    ```

**応用例とユースケース**

*   **システム監視レポート:** CPU使用率、メモリ使用量、ディスク使用量などを定期的に監視し、レポートを作成する。
*   **Webサイトのアクセス解析レポート:** アクセス数、ページビュー数、滞在時間などを集計し、レポートを作成する。
*   **データベースのバックアップレポート:** バックアップの成功/失敗、バックアップサイズなどを記録し、レポートを作成する。

**トラブルシューティング**

*   **`printf`関数の出力が期待通りでない:** フォーマット文字列の誤り、引数の型との不一致などが考えられます。
*   **ヘッダーやフッターが表示されない:** `BEGIN`ブロックや`END`ブロックの記述ミスなどが考えられます。
*   **レポートの整形がうまくいかない:** フィールドの幅、小数点以下の桁数などの指定ミスなどが考えられます。
