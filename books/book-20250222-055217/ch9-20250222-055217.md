## 第9章：テキストデータの前処理：クリーニングと変換

自然言語処理（NLP）やテキストマイニングのプロジェクトにおいて、テキストデータの前処理は非常に重要なステップです。どんなに優れたアルゴリズムを使っても、入力データが汚れていたり、形式が統一されていなかったりすると、期待する結果は得られません。この章では、テキストデータを効果的にクリーニングし、分析に適した形式に変換するための基本と応用について解説します。初心者の方にも理解しやすいように、具体的なコード例を交えながら、段階的に説明を進めていきます。

### 9.1 データクリーニングの基本

テキストデータは、様々なソースから収集されるため、欠損値、重複、不正な文字などが含まれていることがよくあります。これらの問題を放置すると、分析結果に悪影響を及ぼす可能性があります。データクリーニングは、これらの問題を解決し、データの品質を高めるための重要なプロセスです。

#### 9.1.1 欠損値の処理：削除、補完

**概要と重要性:**

テキストデータにおける欠損値は、データ収集時のエラー、データの不完全性、または意図的な省略など、さまざまな原因で発生します。欠損値があると、分析結果の信頼性が低下するだけでなく、特定のアルゴリズムが正常に動作しないこともあります。そのため、欠損値を適切に処理することが重要です。

**特徴と利点:**

欠損値の処理方法としては、主に削除と補完の2つがあります。

*   **削除:** 欠損値を含む行または列を削除する方法です。単純ですが、データ量が大幅に減少する可能性があるため、注意が必要です。
*   **補完:** 欠損値を何らかの値で埋める方法です。代表的な方法としては、平均値、中央値、最頻値を使用する方法や、機械学習モデルを用いて予測する方法などがあります。

**事前準備と前提条件:**

*   Pythonのpandasライブラリをインストールしておく必要があります。

    ```bash
    pip install pandas
    ```

**基本的な使い方:**

```python
import pandas as pd
import numpy as np

# データの読み込み (例: CSVファイル)
data = pd.read_csv('sample_text_data.csv')

# 欠損値の確認
print(data.isnull().sum())

# 欠損値を含む行の削除
data_dropna = data.dropna()
print(f"欠損値削除後のデータサイズ: {len(data_dropna)}")

# 欠損値を特定の値で補完 (例: 空文字列で補完)
data_fillna = data.fillna('')
print(data_fillna.isnull().sum()) # 欠損値がなくなったことを確認

# 欠損値を平均値で補完（数値データの場合）
# data['column_name'].fillna(data['column_name'].mean(), inplace=True)

# 欠損値を最頻値で補完
most_frequent_value = data['column_name'].mode()[0]
data['column_name'].fillna(most_frequent_value, inplace=True)
```

**実践的なテクニック:**

*   欠損値の割合が高い列は、削除を検討する。
*   欠損値の種類（カテゴリカルデータか数値データか）に応じて、適切な補完方法を選択する。
*   欠損値補完によって、データの分布が大きく変わらないように注意する。

**応用例とユースケース:**

*   顧客レビューデータにおいて、特定の項目（例：年齢、性別）が欠損している場合に、平均値や最頻値で補完することで、顧客属性に基づいた分析が可能になる。
*   医療データにおいて、検査結果が欠損している場合に、過去のデータや類似症例のデータを用いて補完することで、診断の精度を高めることができる。

**トラブルシューティング:**

*   `ValueError: cannot convert float NaN to integer` というエラーが発生した場合、整数型の列に欠損値（NaN）が含まれている可能性があります。この場合、`fillna(0.0)`のように浮動小数点数で補完するか、列の型をfloat型に変更する必要があります。

**まとめと次のステップ:**

欠損値の処理は、データ分析の精度を向上させるために不可欠なステップです。欠損値の数や種類に応じて、削除または補完の適切な方法を選択しましょう。次のステップでは、重複データの削除について解説します。

#### 9.1.2 重複データの削除

**概要と重要性:**

重複データは、データ収集時のエラーや、複数のデータソースからのデータの統合時に発生することがあります。重複データがあると、分析結果に偏りが生じたり、誤った結論を導き出したりする可能性があります。そのため、重複データを削除して、データの正確性を高めることが重要です。

**特徴と利点:**

*   重複データを削除することで、データの偏りを解消し、分析結果の信頼性を高めることができます。
*   重複データを削除することで、データ容量を削減し、処理速度を向上させることができます。

**事前準備と前提条件:**

*   Pythonのpandasライブラリをインストールしておく必要があります。

    ```bash
    pip install pandas
    ```

**基本的な使い方:**

```python
import pandas as pd

# データの読み込み (例: CSVファイル)
data = pd.read_csv('sample_text_data.csv')

# 重複データの確認
print(f"重複データの数: {data.duplicated().sum()}")

# 重複データの削除
data_drop_duplicates = data.drop_duplicates()
print(f"重複削除後のデータサイズ: {len(data_drop_duplicates)}")

# 特定の列に基づいて重複を削除
data_drop_duplicates_subset = data.drop_duplicates(subset=['column1', 'column2'])
print(f"特定の列に基づいた重複削除後のデータサイズ: {len(data_drop_duplicates_subset)}")
```

**実践的なテクニック:**

*   `subset`引数を使用して、特定の列に基づいて重複を判定する。
*   `keep`引数を使用して、どの重複行を保持するか指定する（`first`: 最初の行を保持、`last`: 最後の行を保持、`False`: すべての重複行を削除）。

**応用例とユースケース:**

*   顧客データにおいて、同一人物のレコードが複数存在する場合に、重複データを削除することで、顧客数の正確な把握が可能になる。
*   ウェブサイトのアクセスログデータにおいて、同一ユーザーによる同一ページのアクセスが複数回記録されている場合に、重複データを削除することで、正確なアクセス数やユーザー行動の分析が可能になる。

**トラブルシューティング:**

*   重複データが削除されない場合、データの形式が完全に一致していない可能性があります。空白文字や大文字小文字の違いなどを確認し、必要に応じてデータをクリーニングする必要があります。

**まとめと次のステップ:**

重複データの削除は、データ分析の信頼性を高めるために重要なステップです。データの特性に応じて、適切な重複削除方法を選択しましょう。次のステップでは、不正な文字や記号の除去について解説します。

#### 9.1.3 不正な文字や記号の除去

**概要と重要性:**

テキストデータには、意図しない文字や記号が含まれていることがあります。例えば、HTMLタグ、特殊文字、制御文字などが挙げられます。これらの文字や記号は、テキストの解析を妨げたり、不要なノイズを発生させたりする可能性があります。そのため、これらの不正な文字や記号を除去し、テキストデータをクリーンに保つことが重要です。

**特徴と利点:**

*   不正な文字や記号を除去することで、テキストデータの品質が向上し、テキスト解析の精度を高めることができます。
*   不要なノイズを削減することで、モデルの学習効率を向上させることができます。

**事前準備と前提条件:**

*   Pythonのre（正規表現）ライブラリをインポートする必要があります。

    ```python
    import re
    ```

**基本的な使い方:**

```python
import re

text = "これはサンプルテキストです。<h1>HTMLタグ</h1>が含まれています。特殊文字: &amp;"

# HTMLタグの除去
text_no_html = re.sub(r'<[^>]*?>', '', text)
print(f"HTMLタグ除去後: {text_no_html}")

# 特殊文字の除去 (例: &amp; を & に置換)
text_no_special_chars = text_no_html.replace('&amp;', '&')
print(f"特殊文字除去後: {text_no_special_chars}")

# 正規表現による不要な記号の除去
text_cleaned = re.sub(r'[^\w\s]', '', text_no_special_chars) # \w は英数字とアンダースコア、\s は空白文字
print(f"記号除去後: {text_cleaned}")
```

**実践的なテクニック:**

*   正規表現を効果的に活用して、特定のパターンに一致する文字や記号を除去する。
*   `str.translate()` メソッドを使用して、文字の置換を行う。
*   文字コードの問題で表示されない文字を除去する。

**応用例とユースケース:**

*   ウェブサイトからスクレイピングしたテキストデータから、HTMLタグやJavaScriptコードを除去する。
*   SNSの投稿データから、URLやハッシュタグを除去する。
*   テキストデータに含まれる絵文字を除去する。

**トラブルシューティング:**

*   正規表現が期待通りに動作しない場合、正規表現のパターンが正しいか確認する。
*   文字コードの問題で、特定の文字が正しく処理されない場合、文字コードを変換する必要がある。

**まとめと次のステップ:**

不正な文字や記号の除去は、テキストデータを解析する前に必ず行うべき重要なステップです。正規表現などのツールを使いこなして、テキストデータをクリーンに保ちましょう。次のステップでは、テキストデータの変換について解説します。

### 9.2 テキストデータの変換

テキストデータは、そのままで分析に使うことが難しい場合があります。例えば、文字コードが異なっていたり、大文字と小文字が混在していたり、全角と半角が混在していたりする場合があります。これらの問題を解決するために、テキストデータを適切な形式に変換する必要があります。

#### 9.2.1 文字コードの変換：UTF-8, Shift-JIS, EUC-JP

**概要と重要性:**

文字コードは、文字をコンピュータで扱うための符号化方式です。異なる文字コードでエンコードされたテキストデータを扱う場合、文字化けが発生する可能性があります。そのため、文字コードを統一し、正しく表示・処理できるようにする必要があります。代表的な文字コードとしては、UTF-8、Shift-JIS、EUC-JPなどがあります。UTF-8は、Unicodeという文字集合を符号化するための方式の一つで、世界中の文字を扱うことができます。

**特徴と利点:**

*   文字コードを変換することで、文字化けを防ぎ、テキストデータを正しく表示・処理することができます。
*   UTF-8は、世界中の文字を扱うことができるため、多言語のテキストデータを扱う場合に適しています。

**事前準備と前提条件:**

*   Pythonで文字コードを変換するには、`codecs`モジュールや`io`モジュールを使用します。

**基本的な使い方:**

```python
import codecs

# Shift-JISでエンコードされたテキストファイルを読み込み、UTF-8に変換して書き出す
try:
    with codecs.open('shift_jis_file.txt', 'r', 'shift_jis') as f_in, \
         codecs.open('utf8_file.txt', 'w', 'utf-8') as f_out:
        for line in f_in:
            f_out.write(line)
    print("文字コード変換完了")

except UnicodeDecodeError as e:
    print(f"エラーが発生しました: {e}")
    print("ファイルがShift-JISでエンコードされていない可能性があります。正しいエンコーディングを指定してください。")
```

**実践的なテクニック:**

*   `chardet`ライブラリを使用して、テキストファイルの文字コードを自動判別する。

    ```bash
    pip install chardet
    ```

    ```python
    import chardet

    with open('unknown_encoding_file.txt', 'rb') as f:
        raw_data = f.read()
        result = chardet.detect(raw_data)
        encoding = result['encoding']
        print(f"ファイルのエンコーディング: {encoding}")

    # 判別したエンコーディングでファイルを読み込む
    with codecs.open('unknown_encoding_file.txt', 'r', encoding) as f:
        content = f.read()
        print(content)
    ```

**応用例とユースケース:**

*   異なる文字コードで保存された複数のテキストファイルを統合する場合に、文字コードを統一する。
*   ウェブサイトからスクレイピングしたテキストデータの文字コードが不明な場合に、`chardet`ライブラリで文字コードを判別し、UTF-8に変換する。

**トラブルシューティング:**

*   `UnicodeDecodeError`が発生した場合、ファイルの文字コードが指定した文字コードと異なっている可能性があります。`chardet`ライブラリで文字コードを判別し、正しい文字コードを指定してください。
*   文字コード変換後も文字化けが解消されない場合、フォントが対応していない可能性があります。フォントを変更するか、別の文字コードに変換する必要があります。

**まとめと次のステップ:**

文字コードの変換は、テキストデータを正しく扱うために重要なステップです。`codecs`モジュールや`chardet`ライブラリを使いこなして、文字コードを統一しましょう。次のステップでは、大文字と小文字の統一について解説します。

#### 9.2.2 大文字と小文字の統一

**概要と重要性:**

テキストデータにおいて、大文字と小文字が混在していると、同じ単語でも異なる単語として扱われてしまうことがあります。例えば、「apple」と「Apple」は、コンピュータにとっては異なる文字列です。そのため、大文字と小文字を統一し、テキストデータを正規化する必要があります。

**特徴と利点:**

*   大文字と小文字を統一することで、単語の出現頻度を正確にカウントすることができます。
*   検索や比較の精度を向上させることができます。
*   モデルの学習効率を向上させることができます。

**事前準備と前提条件:**

*   Pythonの`str`クラスのメソッドを使用します。

**基本的な使い方:**

```python
text = "This is a Sample Text."

# 小文字に変換
text_lower = text.lower()
print(f"小文字に変換後: {text_lower}")

# 大文字に変換
text_upper = text.upper()
print(f"大文字に変換後: {text_upper}")
```

**実践的なテクニック:**

*   テキストデータ全体を小文字に変換することが一般的ですが、特定のケースでは大文字に変換する方が適切な場合もあります。例えば、固有名詞を強調したい場合などです。

**応用例とユースケース:**

*   検索エンジンにおいて、検索キーワードの大文字小文字を区別せずに検索結果を表示する。
*   感情分析において、テキストデータの大文字小文字を統一することで、感情の極性を正確に分析する。

**トラブルシューティング:**

*   特定の文字（例：ドイツ語のウムラウトなど）が正しく小文字に変換されない場合、`locale`を設定する必要がある。

**まとめと次のステップ:**

大文字と小文字の統一は、テキストデータを正規化するための基本的なステップです。`str.lower()`メソッドや`str.upper()`メソッドを使いこなして、テキストデータを扱いやすい形式に変換しましょう。次のステップでは、全角と半角の統一について解説します。

#### 9.2.3 全角と半角の統一

**概要と重要性:**

日本語のテキストデータには、全角文字と半角文字が混在していることがあります。例えば、数字やアルファベット、記号などが全角で入力されている場合があります。全角文字と半角文字は、コンピュータにとっては異なる文字として扱われるため、全角と半角を統一し、テキストデータを正規化する必要があります。

**特徴と利点:**

*   全角と半角を統一することで、検索や比較の精度を向上させることができます。
*   テキストデータの表示幅を統一することができます。
*   モデルの学習効率を向上させることができます。

**事前準備と前提条件:**

*   Pythonの`unicodedata`ライブラリを使用します。

    ```python
    import unicodedata
    ```

**基本的な使い方:**

```python
import unicodedata

def normalize_text(text):
    """全角文字を半角文字に変換する関数"""
    normalized_text = unicodedata.normalize('NFKC', text)
    return normalized_text

text = "これは全角のサンプルテキストです。１２３４５ ＡＢＣＤＥ"

# 全角文字を半角文字に変換
text_normalized = normalize_text(text)
print(f"全角半角変換後: {text_normalized}")
```

**実践的なテクニック:**

*   `NFKC`は、Unicodeの正規化形式の一つで、互換分解と合成を行います。全角文字を半角文字に変換するだけでなく、一部の特殊文字を標準的な文字に変換することもできます。

**応用例とユースケース:**

*   住所データにおいて、全角と半角が混在している数字や記号を統一することで、住所の検索や照合の精度を向上させる。
*   商品名データにおいて、全角と半角が混在している英数字を統一することで、商品検索の精度を向上させる。

**トラブルシューティング:**

*   `unicodedata.normalize()` メソッドで変換できない文字がある場合、別の正規化形式を試すか、個別に文字を置換する必要があります。

**まとめと次のステップ:**

全角と半角の統一は、日本語のテキストデータを正規化するための重要なステップです。`unicodedata.normalize()` メソッドを使いこなして、テキストデータを扱いやすい形式に変換しましょう。次のステップでは、正規化とトークン化について解説します。

### 9.3 正規化とトークン化

テキストデータの前処理の最終段階として、正規化とトークン化があります。これらの処理を行うことで、テキストデータをより分析しやすい形にすることができます。

#### 9.3.1 正規化：表記の揺れを吸収する（例：数字の表記、日付の表記）

**概要と重要性:**

正規化とは、テキストデータにおける表記の揺れを吸収し、同じ意味を持つ表現を統一することです。例えば、数字の表記（例：1000, 1,000, 千）や日付の表記（例：2023/10/26, 2023年10月26日, Oct 26, 2023）は、様々な形式で表現される可能性があります。これらの表記の揺れを放置すると、分析結果にノイズが混入したり、正確な分析が難しくなったりする可能性があります。そのため、正規化を行い、テキストデータを一貫性のある形式に変換することが重要です。

**特徴と利点:**

*   表記の揺れを吸収することで、単語の出現頻度を正確にカウントすることができます。
*   検索や比較の精度を向上させることができます。
*   モデルの学習効率を向上させることができます。

**事前準備と前提条件:**

*   Pythonの`re`ライブラリや`dateutil`ライブラリを使用します。

    ```bash
    pip install python-dateutil
    ```

**基本的な使い方:**

```python
import re
from dateutil import parser

def normalize_number(text):
    """数字の表記を統一する関数"""
    text_normalized = re.sub(r'[,\.]', '', text)  # カンマとピリオドを削除
    text_normalized = re.sub(r'千', '000', text_normalized)  # 「千」を「000」に置換
    return text_normalized

def normalize_date(text):
    """日付の表記を統一する関数"""
    try:
        date = parser.parse(text)
        date_normalized = date.strftime('%Y-%m-%d')  # YYYY-MM-DD形式に変換
        return date_normalized
    except ValueError:
        return None  # パースできない場合はNoneを返す

text_number = "1,000円"
text_date = "2023年10月26日"

# 数字の表記を統一
number_normalized = normalize_number(text_number)
print(f"数字正規化後: {number_normalized}")

# 日付の表記を統一
date_normalized = normalize_date(text_date)
print(f"日付正規化後: {date_normalized}")
```

**実践的なテクニック:**

*   正規表現を駆使して、様々な表記の揺れに対応する。
*   `dateutil.parser`モジュールを使用して、様々な形式の日付をパースする。
*   辞書やルールベースの置換処理を用いて、特定の表現を統一する。

**応用例とユースケース:**

*   製品名データにおいて、スペースの有無や記号の有無などの表記の揺れを吸収する。
*   アンケートデータにおいて、回答者の記述した住所や電話番号の表記を統一する。
*   医療データにおいて、病名や症状名の表記を統一する。

**トラブルシューティング:**

*   正規表現が複雑になりすぎると、パフォーマンスが低下する可能性があります。正規表現のパターンを最適化するか、別の方法を検討する必要があります。
*   `dateutil.parser`モジュールが日付を正しくパースできない場合、日付の形式が不明確である可能性があります。日付の形式を特定し、適切なパース処理を実装する必要があります。

**まとめと次のステップ:**

正規化は、テキストデータの品質を向上させるために重要なステップです。正規表現や`dateutil`ライブラリを使いこなして、表記の揺れを吸収しましょう。次のステップでは、トークン化について解説します。

#### 9.3.2 トークン化：テキストを単語や句に分割する

**概要と重要性:**

トークン化とは、テキストを単語や句などの意味のある単位（トークン）に分割する処理です。トークン化は、テキストデータを分析するための基本的なステップであり、自然言語処理の様々なタスク（例：単語の出現頻度分析、テキスト分類、機械翻訳など）において必要不可欠です。

**特徴と利点:**

*   テキストを単語や句に分割することで、テキストデータを数値化し、機械学習モデルに入力することができます。
*   単語の出現頻度を分析することで、テキストデータの特徴を把握することができます。
*   テキストデータを細かく分割することで、より詳細な分析が可能になります。

**事前準備と前提条件:**

*   Pythonの`nltk`ライブラリや`spaCy`ライブラリを使用します。

    ```bash
    pip install nltk
    pip install spacy
    python -m spacy download en_core_web_sm # spaCyの英語モデルをダウンロード
    ```

**基本的な使い方:**

```python
import nltk
import spacy

text = "This is a sample sentence. Tokenization is important for NLP."

# nltkを使用したトークン化
nltk.download('punkt') # 必要なリソースをダウンロード
tokens_nltk = nltk.word_tokenize(text)
print(f"nltkによるトークン化: {tokens_nltk}")

# spaCyを使用したトークン化
nlp = spacy.load("en_core_web_sm")
doc = nlp(text)
tokens_spacy = [token.text for token in doc]
print(f"spaCyによるトークン化: {tokens_spacy}")
```

**実践的なテクニック:**

*   単語の区切り方（例：空白、句読点、ハイフンなど）を考慮して、適切なトークナイザーを選択する。
*   複合語（例：New York, hot dog）を1つのトークンとして扱うために、Nグラムトークン化を使用する。
*   ストップワード（例：a, the, is）を除去することで、ノイズを削減する。
*   ステミングやレンマタイズを行い、単語の活用形を統一する。

**応用例とユースケース:**

*   テキスト分類において、トークン化された単語を特徴量として、テキストをカテゴリーに分類する。
*   感情分析において、トークン化された単語の感情スコアを基に、テキスト全体の感情を分析する。
*   機械翻訳において、トークン化された単語を別の言語に翻訳する。

**トラブルシューティング:**

*   特定の単語が正しくトークン化されない場合、カスタムのトークナイザーを作成する必要がある。
*   トークン化の処理速度が遅い場合、より高速なトークナイザーを使用するか、処理を並列化する必要があります。

**まとめと次のステップ:**

トークン化は、テキストデータを分析するための基本的なステップです。`nltk`ライブラリや`spaCy`ライブラリを使いこなして、テキストを意味のある単位に分割しましょう。

この章では、テキストデータの前処理におけるクリーニングと変換について解説しました。これらの処理を行うことで、テキストデータを分析しやすい形にすることができます。次のステップでは、前処理済みのテキストデータを使用して、実際にテキスト分析を行ってみましょう。
