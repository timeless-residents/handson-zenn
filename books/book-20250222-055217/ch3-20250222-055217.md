## 第3章：sedによる高度なテキスト変換

### 3.1 sedスクリプトの作成と実行

#### 概要と重要性

sed（Stream EDitor）は、テキストストリームを処理するための強力なツールです。コマンドラインから簡単に使えるだけでなく、複数のコマンドをまとめたスクリプトを作成することで、より複雑なテキスト処理を自動化できます。このセクションでは、sedスクリプトの作成と実行方法を学び、効率的なテキスト処理の基盤を築きます。

#### 特徴と利点

- 複数行の複雑な処理を一度に実行可能
- 可読性と再利用性が向上
- コマンドラインが煩雑になるのを防ぐ
- テキスト処理の自動化を促進

#### 事前準備と前提条件

- Linux、macOS、Windows（WSL）などの環境
- sedコマンドが利用可能であること
- テキストエディタ（vim、nano、VSCodeなど）

#### 基本的な使い方

sedスクリプトは、テキストファイルにsedコマンドを記述したものです。`sed -f スクリプトファイル 入力ファイル` コマンドで実行します。

**例:**

1.  `my_script.sed` という名前のファイルを作成し、以下の内容を記述します。

```sed
# コメント: 各行の先頭に "Prefix: " を追加
s/^/Prefix: /
```

2.  `input.txt` という名前の入力ファイルを作成し、いくつかのテキスト行を記述します。

```text
This is the first line.
This is the second line.
```

3.  以下のコマンドを実行します。

```bash
sed -f my_script.sed input.txt
```

出力結果:

```text
Prefix: This is the first line.
Prefix: This is the second line.
```

#### sedスクリプトの構造：アドレス指定、コマンド、オプション

sedスクリプトの各行は、通常、アドレス指定、コマンド、オプションで構成されます。

-   **アドレス指定:** 処理対象の行を指定します。省略すると、すべての行が対象となります。例えば、`1,5` は1行目から5行目まで、`/pattern/` は `pattern` に一致する行を指します。
-   **コマンド:** 実行する処理を指定します。`s` (置換), `d` (削除), `i` (挿入), `a` (追加), `p` (表示) などがあります。
-   **オプション:** コマンドの動作を制御します。例えば、`s/old/new/g` の `g` は、行内のすべての `old` を `new` に置換することを意味します。

#### コメントの書き方： `#` を用いたスクリプトの説明

sedスクリプトには、`#` で始まるコメントを記述できます。コメントはスクリプトの動作には影響しませんが、スクリプトの内容を説明し、可読性を高めるために重要です。

**例:**

```sed
# 大文字の単語を小文字に変換する
s/\b[A-Z]+\b/\L&/g # \bは単語境界、\Lは小文字変換、&はマッチした文字列
```

#### 実践的なテクニック

-   **複数コマンドの組み合わせ:** 複数のsedコマンドを組み合わせて、複雑なテキスト処理を実現します。

```sed
# 1行目を削除し、各行の末尾に "END" を追加する
1d
s/$/ END/
```

-   **範囲指定:** アドレス指定で処理範囲を絞り込みます。

```sed
# 3行目から5行目までの行を削除する
3,5d
```

#### 応用例とユースケース

-   **設定ファイルの編集:** 設定ファイル内の特定の行を更新します。

```sed
# "port = 8080" を "port = 9000" に変更する
s/port = 8080/port = 9000/
```

-   **ログファイルのフィルタリング:** 特定のパターンに一致するログ行を抽出します。

```sed
# "ERROR" を含む行を抽出する
/ERROR/p
```

#### トラブルシューティング

-   **スクリプトが期待通りに動作しない:** コマンドの構文、アドレス指定、オプションなどを確認します。コメントを積極的に記述し、処理内容を明確にすることも重要です。
-   **特殊文字のエスケープ:** `.`、`*`、`$` などの特殊文字は、`\` でエスケープする必要があります。

#### まとめと次のステップ

sedスクリプトの作成と実行方法を理解することで、テキスト処理の自動化と効率化が可能になります。次のステップでは、sedコマンドの応用について学び、より高度なテキスト変換技術を習得しましょう。

### 3.2 sedコマンドの応用

#### 概要と重要性

sedコマンドは、単純な置換だけでなく、行の挿入、削除、ファイルの読み書き、条件分岐など、多様な機能を備えています。このセクションでは、これらの応用的なコマンドの使い方を習得し、テキスト処理の可能性を広げます。

#### 特徴と利点

-   テキストの構造を柔軟に変更可能
-   外部ファイルの内容を組み込むことが可能
-   条件に応じた処理を実現
-   複雑なテキスト変換を効率的に実行

#### 事前準備と前提条件

-   sedコマンドの基本的な使い方を理解していること
-   テキストエディタ

#### 行の挿入、削除、置換：`i`, `a`, `c`, `d`, `s` コマンドの高度な使い方

-   **`i` (insert):** 指定した行の前にテキストを挿入します。
-   **`a` (append):** 指定した行の後にテキストを追加します。
-   **`c` (change):** 指定した行をテキストで置換します。
-   **`d` (delete):** 指定した行を削除します。
-   **`s` (substitute):** 指定したパターンを別のテキストで置換します。

**例:**

```sed
# 2行目の前に "NEW LINE" を挿入する
2i NEW LINE

# 3行目の後に "APPENDED LINE" を追加する
3a APPENDED LINE

# 4行目を "REPLACED LINE" で置換する
4c REPLACED LINE

# "pattern" を含む行を削除する
/pattern/d

# "old" を "new" に置換する（行内のすべての "old" を置換）
s/old/new/g
```

`s`コマンドの高度な使い方として、後方参照があります。これは、正規表現でマッチした部分文字列を、置換後のテキストで再利用するテクニックです。

**例:**

```sed
# "<h1>タイトル</h1>" のようなHTMLタグから、タイトル部分を抽出する
s/<h1[^>]*>\(.*\)<\/h1>/\1/g  # \( ... \) で囲まれた部分が後方参照できる
```

この例では、`\(.*\)` で囲まれた部分（`<h1>` と `</h1>` の間のテキスト）が、`\1` で参照されます。

#### ファイルの読み込みと書き込み：`r`, `w` コマンドの使用例

-   **`r` (read):** 指定したファイルを読み込み、指定した行の後に挿入します。
-   **`w` (write):** 指定した行（または範囲）をファイルに書き込みます。

**例:**

```sed
# 5行目の後に "external.txt" の内容を挿入する
5r external.txt

# "pattern" を含む行を "output.txt" に書き込む
/pattern/w output.txt
```

`w` コマンドは、スクリプト実行時にファイルを新規作成または上書きします。既存ファイルへの追記は直接的にはできません。追記を実現するには、工夫が必要です。(GNU sedの場合）

```sed
# GNU sedを使用する場合、追記モードが利用可能
/pattern/w >> output.txt
```

#### ラベルと分岐：`:ラベル`, `b ラベル`, `t ラベル` を用いた条件分岐

-   **`:ラベル` (label):** スクリプト内の特定の位置にラベルを定義します。
-   **`b ラベル` (branch):** 指定したラベルに無条件にジャンプします。
-   **`t ラベル` (test):** 最後の `s` コマンドが成功した場合に、指定したラベルにジャンプします。

**例:**

```sed
:start
# "condition" を含む行を "processed.txt" に書き込む
/condition/w processed.txt
# "condition" を含む行を置換する
s/condition/processed/
# 置換が成功した場合、"end" ラベルにジャンプする
t end
# 置換が失敗した場合、次の行を処理する
b start
:end
```

この例では、`condition` を含む行を `processed.txt` に書き込み、`condition` を `processed` に置換します。置換が成功した場合、`end` ラベルにジャンプし、次の行の処理をスキップします。置換が失敗した場合、`start` ラベルに戻り、同じ行を再度処理します。（実際には無限ループになるので、条件を修正する必要があることに注意）

#### 実践的なテクニック

-   **複数ファイルの処理:** `sed`コマンドは、複数の入力ファイルを連続して処理できます。

```bash
sed -f my_script.sed file1.txt file2.txt file3.txt
```

-   **インプレース編集:** `-i` オプションを使用すると、入力ファイルを直接編集できます。

```bash
sed -i 's/old/new/g' input.txt  # input.txtが直接書き換えられる
```

**注意:** `-i` オプションを使用する際は、バックアップを作成することを推奨します。`sed -i.bak 's/old/new/g' input.txt` とすると、`input.txt.bak` というバックアップファイルが作成されます。

#### 応用例とユースケース

-   **HTMLファイルの構造変換:** HTMLファイル内の特定の要素を抽出したり、属性を変更したりします。

```sed
# <img> タグの src 属性を抽出する
s/.*src="\([^"]*\)".*/\1/p

# <h1> タグに class 属性を追加する
s/<h1 /<h1 class="title" /g
```

-   **CSVファイルのデータ操作:** CSVファイル内の特定の列を抽出したり、並べ替えたりします。

```sed
# 3列目を抽出する
s/\([^,]*,\)\{2\}\([^,]*\).*/\2/
```

#### トラブルシューティング

-   **ラベルが見つからない:** `b` または `t` コマンドで指定したラベルがスクリプト内に存在するか確認します。
-   **無限ループ:** `b` コマンドを誤って使用すると、無限ループが発生する可能性があります。条件分岐のロジックを見直します。
-   **ファイル書き込みエラー:** `w` コマンドで指定したファイルに書き込み権限があるか確認します。

#### まとめと次のステップ

sedコマンドの応用を学ぶことで、テキスト処理の幅が広がります。ファイルの読み書き、条件分岐などを組み合わせることで、より複雑なテキスト変換を効率的に実行できます。次のステップでは、sedを使った実践的なテキスト処理について学びます。

### 3.3 sedを使った実践的なテキスト処理

#### 概要と重要性

sedは、CSVファイルの操作、HTMLファイルの整形、ログファイルの解析など、さまざまな実用的なタスクに適用できます。このセクションでは、具体的なユースケースを通して、sedの実践的な使い方を学びます。

#### 特徴と利点

-   特定のデータ形式に特化した処理が可能
-   大量のデータを効率的に処理
-   シェルスクリプトとの連携が容易
-   複雑なテキスト処理を自動化

#### 事前準備と前提条件

-   sedコマンドの基本的な使い方を理解していること
-   CSVファイル、HTMLファイル、ログファイルなどのサンプルデータ
-   テキストエディタ

#### CSVファイルの操作：特定の列の抽出、置換、並べ替え

CSV（Comma Separated Values）ファイルは、データをカンマで区切って表現する一般的な形式です。sedを使って、CSVファイルの特定の列を抽出したり、置換したり、並べ替えたりできます。

**例:**

`data.csv`

```csv
id,name,age,city
1,Alice,25,Tokyo
2,Bob,30,London
3,Charlie,28,New York
```

-   **特定の列の抽出 (例: name 列):**

```bash
sed 's/^[^,]*,//; s/,.*//' data.csv | tail -n +2 # 1行目を削除
```

または、`awk`を使う方が、より直感的です。

```bash
awk -F, '{print $2}' data.csv | tail -n +2
```

-   **特定の列の置換 (例: age 列をすべて 0 に置換):**

```bash
sed 's/\([^,]*,[^,]*,[^,]*\),\([^,]*\),/\1,0,/' data.csv
```

-   **特定の列でソート (例: age 列でソート):**
sed だけではソートは難しいので、`sort`コマンドと組み合わせます。

```bash
# age列を先頭に出力し、sortでソート後、元の形式に戻す
sed '1s/.*/&,&/'; sed 's/\(.*\),\([^,]*\),\([^,]*\),\(.*\)/\3,\2,\4,\1/' data.csv | sort -t, -k1,1n | sed 's/\(.*\),\([^,]*\),\([^,]*\),\(.*\)/\4,\1,\2,\3/' | sed 's/&,.*//; 1d'
```
非常に複雑なので、このような場合は、`awk`や`python`などの他のツールを使う方が現実的です。

#### HTMLファイルの整形：タグの削除、属性の変更

sedを使って、HTMLファイルから特定のタグを削除したり、属性を変更したりできます。

**例:**

`index.html`

```html
<html>
<head>
<title>My Web Page</title>
</head>
<body>
<h1>Welcome</h1>
<p>This is my web page.</p>
<img src="image.jpg" alt="My Image">
</body>
</html>
```

-   **すべてのHTMLタグを削除する:**

```bash
sed 's/<[^>]*>//g' index.html
```

-   **特定の属性を変更する (例: img タグの alt 属性を "New Image" に変更):**

```bash
sed 's/<img src="\(.*\)" alt="\(.*\)">/<img src="\1" alt="New Image">/g' index.html
```

#### ログファイルの解析：エラーメッセージの抽出、集計

sedを使って、ログファイルから特定のエラーメッセージを抽出したり、集計したりできます。

**例:**

`access.log`

```log
2023-10-27 10:00:00 [INFO] User logged in
2023-10-27 10:00:01 [ERROR] Invalid username
2023-10-27 10:00:02 [INFO] Page loaded
2023-10-27 10:00:03 [ERROR] Database connection failed
```

-   **すべてのエラーメッセージを抽出する:**

```bash
sed -n '/\[ERROR\]/p' access.log
```

-   **エラーメッセージの種類を集計する:**

```bash
sed -n '/\[ERROR\]/p' access.log | sed 's/.*\[ERROR\] //g' | sort | uniq -c
```

この例では、まず `sed` でエラーメッセージを抽出し、次に `sed` でエラーメッセージの種類を抽出、`sort` でソートし、`uniq -c` で集計します。

#### 実践的なテクニック

-   **パイプライン処理:** 複数のsedコマンドをパイプラインで組み合わせることで、より複雑なテキスト処理を実現します。
-   **正規表現の活用:** 正規表現を駆使することで、複雑なパターンに一致するテキストを抽出したり、置換したりできます。
-   **スクリプトのモジュール化:** 複数のsedスクリプトを組み合わせて、より大規模なテキスト処理システムを構築します。

#### 応用例とユースケース

-   **Webサイトのクローリング:** Webサイトからテキストデータを抽出し、特定の情報を収集します。
-   **ソフトウェアのソースコード解析:** ソースコードから特定のパターンを検索したり、コードのスタイルを修正したりします。
-   **データベースのデータ変換:** データベースからエクスポートしたデータを、別の形式に変換します。

#### トラブルシューティング

-   **正規表現のエラー:** 正規表現の構文が正しいか確認します。複雑な正規表現は、テストツールを使ってデバッグすることを推奨します。
-   **文字コードの問題:** 入力ファイルの文字コードと、sedが使用する文字コードが一致しているか確認します。
-   **パフォーマンスの問題:** 大量のデータを処理する場合、sedのパフォーマンスが問題になることがあります。`awk`などの他のツールを検討することも有効です。
