# 第6章：テキストエディタの活用：Vim、Emacs

プログラミングやシステム管理において、テキストエディタは最も基本的であり、かつ強力なツールの一つです。本章では、長年にわたりエンジニアに愛用されているVimとEmacsという二つの高機能テキストエディタについて、その基本操作から高度な機能、実務での応用までを解説します。これらのエディタを使いこなせるようになれば、日々の作業効率が飛躍的に向上するでしょう。

## 6.1 Vimの基本操作

### 概要と重要性

Vim（Vi Improved）は、UNIX系OSで標準的に利用できるViエディタを拡張したテキストエディタです。キーボード操作だけで効率的にテキスト編集ができる点が特徴で、熟練すればマウスを使うよりも高速に作業できます。設定ファイルをカスタマイズすることで、自分好みの環境を構築できる柔軟性も魅力です。

### 特徴と利点

*   **軽量性**: 動作が軽快で、古いマシンでも快適に動作します。
*   **キーボード操作**: マウス操作に頼らず、キーボードだけで編集できます。
*   **拡張性**: プラグインによって機能を拡張できます。
*   **普遍性**: 多くの環境で利用でき、OSに依存しない操作が可能です。

### 事前準備と前提条件

Vimは多くのLinuxディストリビューションに標準でインストールされていますが、WindowsやmacOSでも利用できます。

*   **Linux**: `sudo apt install vim` (Debian/Ubuntu), `sudo yum install vim` (CentOS/RHEL), `sudo pacman -S vim` (Arch Linux)
*   **macOS**: `brew install vim` (Homebrew利用時)
*   **Windows**: Vim for Windows (https://www.vim.org/download.php#pc) からインストーラをダウンロードして実行

### 基本的な使い方

Vimには、主に以下の3つのモードがあります。

*   **ノーマルモード**: コマンドを実行するモード。カーソル移動やテキストの削除などを行います。
*   **インサートモード**: テキストを入力するモード。
*   **ビジュアルモード**: テキストを選択するモード。

**モードの切り替え**:

*   ノーマルモード -> インサートモード: `i` (カーソルの前に挿入), `a` (カーソルの後ろに挿入), `o` (カーソルのある行の下に新しい行を追加), `O` (カーソルのある行の上に新しい行を追加)
*   インサートモード -> ノーマルモード: `Esc` キー
*   ノーマルモード -> ビジュアルモード: `v` (文字単位), `V` (行単位), `Ctrl + v` (矩形選択)

**基本的な操作**:

*   **カーソル移動**: `h` (左), `j` (下), `k` (上), `l` (右)
*   **テキスト入力**: インサートモードで文字を入力
*   **削除**: `x` (カーソル位置の文字を削除), `dd` (カーソルのある行を削除), `dw` (カーソル位置から単語の終わりまでを削除)
*   **コピー＆ペースト**: `yy` (カーソルのある行をコピー), `p` (カーソルの後ろにペースト), `P` (カーソルの前にペースト)
*   **アンドゥ**: `u`
*   **リドゥ**: `Ctrl + r`
*   **保存**: `:w` (上書き保存)
*   **終了**: `:q` (変更がない場合), `:q!` (変更を破棄して終了), `:wq` (保存して終了)

### 実践的なテクニック

*   **行番号表示**: `:set number` または `:set nu`
*   **相対行番号表示**: `:set relativenumber` または `:set rnu`
*   **検索**: `/検索文字列` (Enterで検索開始、`n` で次の検索結果、`N` で前の検索結果)
*   **単語検索**: `*` (カーソル下の単語を検索)
*   **行頭に移動**: `0` (数字のゼロ)
*   **行末に移動**: `$`
*   **ファイル先頭に移動**: `gg`
*   **ファイル末尾に移動**: `G`
*   **指定行に移動**: `:行番号`

### 応用例とユースケース

*   **ログファイルの編集**: 大量のログファイルから特定のエラーメッセージを検索して修正する。
*   **設定ファイルの編集**: サーバーの設定ファイル（Apache, Nginxなど）を編集する。
*   **プログラミング**: コードの編集、コンパイル、デバッグをVim内で完結させる。

### Vimの設定ファイル：`.vimrc` のカスタマイズ

`.vimrc` ファイルは、Vimの動作をカスタマイズするための設定ファイルです。通常、ホームディレクトリ（`~/.vimrc`）に配置します。このファイルを編集することで、Vimの挙動を自分好みに変更できます。

**`.vimrc` の設定例**:

```vim
" 行番号を表示
set number

" インデントをスペース2つに設定
set tabstop=2
set shiftwidth=2
set expandtab

" シンタックスハイライトを有効化
syntax on

" ステータスラインを常に表示
set laststatus=2

" 検索時に大文字小文字を区別しない
set ignorecase
set smartcase

" バックスペースキーでインデントを削除可能にする
set backspace=indent,eol,start
```

### トラブルシューティング

*   **Vimが終了できない**: `:q!` で強制終了できます。
*   **設定が反映されない**: `.vimrc` を編集後、`:source ~/.vimrc` を実行するか、Vimを再起動してください。
*   **キーバインドがわからない**: `:help キーバインド名` でヘルプを参照できます。

### まとめと次のステップ

Vimの基本操作を習得することで、テキスト編集の効率が向上します。次のステップとして、正規表現を使った検索置換や、マクロの記録と再生などを学ぶと、さらに作業効率が向上するでしょう。

## 6.2 Vimの高度な機能

### 概要と重要性

Vimの真価は、その高度な機能にあります。正規表現を使った検索置換、マクロの記録と再生、プラグインによる機能拡張などを使いこなすことで、複雑なテキスト編集作業も効率的に行えます。

### 特徴と利点

*   **正規表現**: 複雑なパターンに合致する文字列を検索・置換できます。
*   **マクロ**: 一連の操作を記録し、繰り返し実行できます。
*   **プラグイン**: さまざまな機能を追加し、Vimを自分好みにカスタマイズできます。

### 事前準備と前提条件

Vimがインストールされていることを前提とします。プラグインの導入には、`vim-plug` や `Vundle` などのプラグインマネージャが必要です。ここでは、`vim-plug` のインストール方法を説明します。

**`vim-plug` のインストール**:

1.  https://github.com/junegunn/vim-plug から `plug.vim` をダウンロードします。
2.  Linux/macOS: `~/.vim/autoload` ディレクトリに、Windows: `vimfiles/autoload` ディレクトリに `plug.vim` を配置します。ディレクトリが存在しない場合は作成してください。

### 基本的な使い方

**正規表現を使った検索と置換**:

*   `:s/検索パターン/置換文字列/` : カーソルがある行で最初にマッチした文字列を置換
*   `:s/検索パターン/置換文字列/g` : カーソルがある行でマッチした全ての文字列を置換
*   `:%s/検索パターン/置換文字列/g` : ファイル全体でマッチした全ての文字列を置換
*   `:%s/検索パターン/置換文字列/gc` : ファイル全体でマッチした全ての文字列を置換（確認付き）

**正規表現の例**:

*   `\d`: 数字
*   `\s`: 空白文字
*   `\w`: 英数字
*   `.`: 任意の1文字
*   `*`: 直前の文字の0回以上の繰り返し
*   `+`: 直前の文字の1回以上の繰り返し
*   `?`: 直前の文字の0回または1回の出現

**マクロの記録と再生**:

1.  `q` + レジスタ名 (例: `qa`) : マクロの記録を開始します。レジスタ名は `a` から `z` までのアルファベットを使用できます。
2.  一連の操作を実行します。
3.  `q` : マクロの記録を終了します。
4.  `@` + レジスタ名 (例: `@a`) : 記録したマクロを再生します。
5.  `数字@` + レジスタ名 (例: `5@a`) : 記録したマクロを指定回数再生します。

**プラグインの導入と管理**:

1.  `.vimrc` にプラグインの設定を記述します。
2.  Vimを起動し、`:PlugInstall` コマンドを実行してプラグインをインストールします。

**`.vimrc` のプラグイン設定例 (vim-plug)**:

```vim
call plug#begin('~/.vim/plugged')

" プラグインの記述
Plug 'scrooloose/nerdtree' " ファイルツリー表示
Plug 'tpope/vim-fugitive' " Git連携
Plug 'vim-airline/vim-airline' " ステータスラインの改善
Plug 'morhetz/gruvbox'      " 配色テーマ

call plug#end()

" 配色テーマの設定 (プラグイン導入後に設定)
colorscheme gruvbox
```

### 実践的なテクニック

*   **複数のファイルを同時に編集**: `vim ファイル1 ファイル2 ファイル3...` で複数のファイルを開き、`:next` で次のファイル、`:prev` で前のファイルに移動できます。
*   **ウィンドウ分割**: `:split` (水平分割), `:vsplit` (垂直分割) でウィンドウを分割し、`Ctrl + w` + `方向キー` でウィンドウを移動できます。
*   **タブ**: `:tabnew` で新しいタブを作成し、`:tabnext` で次のタブ、`:tabprev` で前のタブに移動できます。

### 応用例とユースケース

*   **大規模なコードリファクタリング**: 正規表現を使って、関数名や変数名を一括置換する。
*   **定型的なコードの自動生成**: マクロを使って、繰り返し現れるコードパターンを自動生成する。
*   **開発環境の構築**: プラグインを使って、コード補完、構文チェック、デバッグなどの機能を追加する。

### トラブルシューティング

*   **正規表現が期待通りに動作しない**: 正規表現の構文が正しいか確認してください。Vimの正規表現はPerl互換ですが、一部異なる点があります。
*   **マクロが途中で停止する**: マクロの記録時にエラーが発生した場合、マクロが途中で停止することがあります。
*   **プラグインが正常に動作しない**: プラグインの依存関係が満たされているか、`.vimrc` の設定が正しいか確認してください。

### まとめと次のステップ

Vimの高度な機能を習得することで、テキスト編集の可能性が広がります。次のステップとして、LSP (Language Server Protocol) を導入して、より高度なコード補完や構文チェックを利用したり、独自のプラグインを作成してVimをさらにカスタマイズしたりすることも可能です。

## 6.3 Emacsの基本操作

### 概要と重要性

Emacsは、高機能で拡張性の高いテキストエディタです。Lispというプログラミング言語で拡張できる点が特徴で、テキスト編集だけでなく、メールの送受信、Webブラウジング、タスク管理など、さまざまな機能をEmacs内で実現できます。

### 特徴と利点

*   **高い拡張性**: Lispで機能を自由に拡張できます。
*   **豊富な機能**: テキスト編集以外にも、さまざまな機能を利用できます。
*   **カスタマイズ性**: 設定ファイルを編集することで、自分好みの環境を構築できます。
*   **安定性**: 長年の歴史があり、安定して動作します。

### 事前準備と前提条件

Emacsは、多くのLinuxディストリビューションに標準でインストールされていますが、WindowsやmacOSでも利用できます。

*   **Linux**: `sudo apt install emacs` (Debian/Ubuntu), `sudo yum install emacs` (CentOS/RHEL), `sudo pacman -S emacs` (Arch Linux)
*   **macOS**: `brew install emacs` (Homebrew利用時)
*   **Windows**: GNU Emacs for Windows (https://ftp.gnu.org/gnu/emacs/windows/) からインストーラをダウンロードして実行

### 基本的な使い方

Emacsでは、`Ctrl` キーと `Meta` キー（`Alt` キーまたは `Option` キー）を組み合わせたキーバインドを使用します。

*   `Ctrl + キー` : `C-キー` と表記します。
*   `Meta + キー` : `M-キー` と表記します。

**バッファとウィンドウの概念**:

*   **バッファ**: Emacsで編集するテキストデータのこと。ファイルの内容だけでなく、コマンドの出力やヘルプなどもバッファとして扱われます。
*   **ウィンドウ**: バッファを表示する領域のこと。1つのバッファを複数のウィンドウで表示したり、複数のバッファを異なるウィンドウで表示したりできます。

**基本的な操作**:

*   **カーソル移動**: `C-f` (右), `C-b` (左), `C-p` (上), `C-n` (下), `M-f` (1単語右), `M-b` (1単語左), `C-a` (行頭), `C-e` (行末), `M-<` (ファイル先頭), `M->` (ファイル末尾)
*   **テキスト入力**: 通常のキー入力
*   **削除**: `C-d` (カーソル位置の文字を削除), `M-d` (カーソル位置から単語の終わりまでを削除), `C-k` (カーソル位置から行末までを削除), `M-k` (カーソル位置から文末までを削除)
*   **コピー＆ペースト**: `M-w` (リージョンをコピー), `C-w` (リージョンを切り取り), `C-y` (ヤンク（ペースト）)
*   **アンドゥ**: `C-x u` または `C-_`
*   **リドゥ**: (アンドゥを取り消す)
*   **保存**: `C-x C-s` (保存)
*   **終了**: `C-x C-c` (Emacsを終了)
*   **ファイルを開く**: `C-x C-f` (ファイルを開く)
*   **バッファを切り替える**: `C-x b` (バッファ名を入力)
*   **ウィンドウを分割**: `C-x 2` (水平分割), `C-x 3` (垂直分割)
*   **ウィンドウを閉じる**: `C-x 0` (現在のウィンドウを閉じる), `C-x 1` (現在のウィンドウ以外を閉じる)
*   **ヘルプ**: `C-h t` (Emacsチュートリアル), `C-h i` (Infoマニュアル), `C-h k` (キーバインドの説明), `C-h f` (関数の説明)

### 実践的なテクニック

*   **ミニバッファ**: 画面下部に表示される入力領域。コマンドの実行やファイル名の入力などに使用します。
*   **補完**: `Tab` キーを押すことで、ファイル名やコマンド名を補完できます。
*   **マークとリージョン**: `C-Space` (または `C-@`) でマークを設定し、カーソルを移動することでリージョン（選択範囲）を作成できます。リージョンに対して、コピー、切り取り、置換などの操作を行えます。

### Emacsの設定ファイル：`.emacs` や `.emacs.d/init.el` のカスタマイズ

Emacsの設定ファイルは、通常、ホームディレクトリに `.emacs` ファイルとして配置するか、`.emacs.d` ディレクトリを作成し、その中に `init.el` ファイルとして配置します。`.emacs` ファイルが存在する場合は、`.emacs.d/init.el` は読み込まれません。Lispコードを記述することで、Emacsの挙動を自分好みに変更できます。

**`.emacs.d/init.el` の設定例**:

```lisp
;; 行番号を表示
(global-linum-mode t)

;; インデントをスペース2つに設定
(setq tab-width 2)
(setq indent-tabs-mode nil)

;; シンタックスハイライトを有効化
(global-font-lock-mode t)

;; ステータスバーの表示
(setq display-time-mode t)

;; キーバインドの変更例
(global-set-key (kbd "C-x C-b") 'ibuffer)

;; パッケージマネージャの設定
(require 'package)
(add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/") t)
(package-initialize)
```

### 応用例とユースケース

*   **プログラミング**: コードの編集、コンパイル、デバッグをEmacs内で完結させる。
*   **メールの送受信**: `wanderlust` や `mu4e` などのパッケージを使って、Emacs内でメールを処理する。
*   **Webブラウジング**: `emacs-w3m` などのパッケージを使って、Emacs内でWebページを閲覧する。
*   **タスク管理**: `Org-mode` を使って、タスクを整理し、スケジュールを管理する。

### トラブルシューティング

*   **キーバインドがわからない**: `C-h k` でキーバインドの説明を参照できます。
*   **設定が反映されない**: `.emacs` または `.emacs.d/init.el` を編集後、`M-x eval-buffer` を実行するか、Emacsを再起動してください。
*   **Lispのエラーが発生する**: Lispの構文が正しいか確認してください。EmacsのLispはCommon Lispとは異なり、Emacs Lispという方言です。

### まとめと次のステップ

Emacsの基本操作を習得することで、テキスト編集だけでなく、さまざまな作業をEmacs内で完結させることができます。次のステップとして、Org-modeによるテキスト整理とタスク管理や、LispによるEmacsの拡張などを学ぶと、さらにEmacsの可能性が広がります。

## 6.4 Emacsの高度な機能

### 概要と重要性

Emacsの真価は、その高度な機能と拡張性にあります。Org-modeによるテキスト整理とタスク管理、LispによるEmacsの拡張、パッケージの導入と管理などを使いこなすことで、Emacsを自分だけの強力なワークステーションとして活用できます。

### 特徴と利点

*   **Org-mode**: テキスト整理、タスク管理、スケジュール管理、ドキュメント作成など、さまざまな用途に利用できる強力なモードです。
*   **Lispによる拡張**: Emacsの機能を自由に拡張できます。独自のキーバインド、コマンド、モードなどを追加できます。
*   **パッケージ**: さまざまな機能を提供するパッケージを簡単に導入・管理できます。

### 事前準備と前提条件

Emacsがインストールされていることを前提とします。パッケージの導入には、`package.el` を使用します。通常、`.emacs.d/init.el` に以下の設定を追加します。

```lisp
(require 'package)
(add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/") t)
(package-initialize)
```

### 基本的な使い方

**Org-modeによるテキスト整理とタスク管理**:

*   **見出し**: `*` の数で階層構造を表します。例: `* 見出し1`, `** 見出し2`
*   **タスク**: `TODO` キーワードでタスクを定義します。例: `TODO プログラミング`, `DONE プログラミング`
*   **タイムスタンプ**: `<2023-10-27 金>` のように日付を入力できます。
*   **チェックボックス**: `[ ]` または `[X]` でチェックボックスを作成できます。
*   **リスト**: `- 項目1`, `1. 項目2` のようにリストを作成できます。
*   **テーブル**: `| 列1 | 列2 | 列3 |` のようにテーブルを作成できます。
*   **コードブロック**: `src` ブロックを使って、コードを記述できます。例: `#+BEGIN_SRC python\nprint("Hello, world!")\n#+END_SRC`
*   **エクスポート**: OrgファイルをHTML, PDF, LaTeXなどの形式にエクスポートできます。

**LispによるEmacsの拡張**:

Emacs Lispは、Emacsの機能を拡張するためのプログラミング言語です。`.emacs.d/init.el` にLispコードを記述することで、Emacsの挙動をカスタマイズできます。

**Lispの例**:

```lisp
;; キーバインドの変更
(global-set-key (kbd "C-c l") 'load-file)

;; 関数定義
(defun my-hello-world ()
  (interactive)
  (message "Hello, world!"))

;; コマンド登録
(defun my-insert-date ()
  (interactive)
  (insert (format-time-string "%Y-%m-%d")))
(global-set-key (kbd "C-c d") 'my-insert-date)
```

**パッケージの導入と管理**:

`package.el` を使うことで、Emacsのパッケージを簡単に導入・管理できます。

1.  `M-x package-list-packages` でパッケージの一覧を表示します。
2.  パッケージを選択し、`i` キーでインストール対象としてマークします。
3.  `x` キーでインストールを実行します。
4.  パッケージをアンインストールするには、`d` キーで削除対象としてマークし、`x` キーで実行します。

### 実践的なテクニック

*   **Org-modeによるプロジェクト管理**: Org-modeを使って、プロジェクトのタスク、スケジュール、ドキュメントなどを一元管理する。
*   **Lispによる自動化**: Lispを使って、繰り返し行う作業を自動化するスクリプトを作成する。
*   **パッケージによる開発環境の構築**: `lsp-mode` や `dap-mode` などのパッケージを使って、高度なコード補完、構文チェック、デバッグなどの機能を追加する。

### 応用例とユースケース

*   **ドキュメント作成**: Org-modeを使って、技術ドキュメントを作成し、HTMLやPDF形式で公開する。
*   **タスク管理**: Org-modeを使って、個人のタスクやプロジェクトのタスクを管理し、期限を設定する。
*   **システム管理**: Lispを使って、サーバーの状態を監視し、異常が発生した場合に自動的に通知するスクリプトを作成する。
*   **自動テスト**: EMacsからテストを実行し、結果を表示する。

### トラブルシューティング

*   **Org-modeの構文が正しくない**: Org-modeの構文ルールを確認してください。
*   **Lispのエラーが発生する**: Lispの構文が正しいか確認してください。Emacs Lispはデバッグが難しい場合があります。`*Messages*` バッファにエラーメッセージが表示されるので、参考にしてください。
*   **パッケージが正常に動作しない**: パッケージの依存関係が満たされているか、`.emacs.d/init.el` の設定が正しいか確認してください。

### まとめと次のステップ

Emacsの高度な機能を習得することで、テキストエディタを超えた、自分だけの強力なワークステーションを構築できます。次のステップとして、特定の分野に特化したパッケージを探求したり、独自のEmacsの設定をGitHubで公開したりすることも可能です。Emacsの世界は奥深く、探求し続けることで、さらなる効率化と創造性を実現できるでしょう。
