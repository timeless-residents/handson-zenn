## 第4章： 物体検出：車両、歩行者、標識の認識

### 4.1 物体検出アルゴリズムの基礎

#### 概要と重要性

物体検出は、画像や動画の中に存在する特定の物体（車両、歩行者、標識など）を識別し、その位置を特定する技術です。自動運転、監視システム、ロボット工学、小売分析など、多岐にわたる分野で重要な役割を果たしています。物体検出の精度と速度は、これらのアプリケーションの性能を大きく左右するため、適切なアルゴリズムを選択し、適切にチューニングすることが不可欠です。

#### 特徴と利点

代表的な物体検出アルゴリズムとして、YOLO (You Only Look Once)、SSD (Single Shot MultiBox Detector)、Faster R-CNNなどが挙げられます。それぞれのアルゴリズムは、異なるアーキテクチャを持ち、それぞれにメリットとデメリットがあります。

*   **YOLO:**  高速な推論速度が特徴で、リアルタイム処理に適しています。画像全体を一度に処理することで、背景知識を活用し、高速な物体検出を実現します。最新版であるYOLOv8は、v5よりもさらに高速かつ高精度になっています。
*   **SSD:** YOLOと同様にシングルショットの検出器であり、高速な推論速度を持ちます。YOLOよりも小さい物体や密集した物体に対する検出性能が高い傾向があります。
*   **Faster R-CNN:**  精度が高く、特に小さい物体の検出に強いですが、推論速度が比較的遅いという欠点があります。2段階の処理（Region Proposal Network (RPN) で候補領域を生成し、それを分類する）を行うことで、高精度な検出を実現します。

| アルゴリズム | 特徴                                  | メリット                                  | デメリット                                | 推奨用途                               |
| :---------- | :------------------------------------ | :-------------------------------------- | :-------------------------------------- | :------------------------------------- |
| YOLO        | シングルショット、高速                  | リアルタイム処理、高速推論                   | 小さい物体や密集した物体の検出が苦手           | リアルタイム監視、高速処理が必要な場面         |
| SSD         | シングルショット、高速、マルチスケール | YOLOより小さい物体の検出に強い、高速推論           | YOLOより精度が低い場合がある               | モバイルデバイス、組み込みシステム            |
| Faster R-CNN | 2段階検出、高精度                      | 小さい物体や密集した物体の検出に強い、高精度 | 推論速度が遅い、計算コストが高い             | 高精度な物体検出が必要な場面、オフライン処理     |

本章の実装例では、以下の環境を前提とします。

*   Python 3.7以上
*   PyTorch 1.10以上 (YOLOv5/v8で使用)
*   CUDA対応のGPU (推奨)
*   必要なPythonライブラリのインストール: `pip install torch torchvision opencv-python pyyaml tqdm`

**YOLOv5/v8:**

YOLOv5/v8は、Ultralytics社によって開発されたPyTorchベースの物体検出フレームワークです。

```python
import torch

# モデルのロード (YOLOv8)
model = torch.hub.load('ultralytics/yolov8', 'yolov8n')  # n: nano, s: small, m: medium, l: large, x: extra large

# 画像の推論
results = model('image.jpg')

results.print() # 推論結果をコンソールに表示
```

#### 実践的なテクニック

*   **Transfer Learning:** 事前学習済みのモデル（ImageNetなどで学習されたモデル）をファインチューニングすることで、少ないデータでも高い精度を達成できます。
*   **Data Augmentation:**  画像の回転、拡大縮小、色調変更などを施すことで、データセットを人工的に拡張し、モデルの汎化性能を向上させます。
*   **Anchor Boxの調整:**  YOLOやSSDでは、Anchor Boxのサイズやアスペクト比を調整することで、特定の物体に対する検出性能を向上させることができます。
*   **Non-Maximum Suppression (NMS):**  複数のバウンディングボックスが同じ物体を検出した場合、NMSを用いて最も信頼度の高いバウンディングボックスを選択します。

#### 応用例とユースケース

*   **自動運転:** 車両、歩行者、標識などの認識。
*   **監視システム:** 不審者の検出、異常行動の検知。
*   **小売分析:** 顧客の行動分析、商品の陳列状況の監視。
*   **医療画像診断:** 病変の検出、臓器のセグメンテーション。
*   **ドローン:** 災害状況の把握、インフラ点検。

#### トラブルシューティング

*   **CUDA Out of Memory Error:** バッチサイズを小さくする、モデルのサイズを小さくする、GPUメモリを解放するなどの対策が必要です。
*   **検出精度が低い:**  学習データの質を見直す、Data Augmentationを試す、モデルのアーキテクチャを変更するなどの対策が必要です。
*   **推論速度が遅い:** モデルを軽量化する (例: YOLOv5n)、GPUを使用する、TensorRTなどの最適化ツールを使用するなどの対策が必要です。

### 4.2 YOLOv5/v8による物体検出の実装

#### 概要と重要性

YOLOv5/v8は、高速かつ高精度な物体検出を実現するアルゴリズムです。PyTorchで実装されており、比較的容易に利用できるため、物体検出の入門として最適です。ここでは、YOLOv5/v8を使って、実際に物体検出を実装する方法をステップバイステップで解説します。

#### 特徴と利点

*   **高速な推論速度:** リアルタイム処理に適しています。
*   **高い検出精度:**  様々なデータセットで優れた性能を発揮します。
*   **使いやすさ:** PyTorchで実装されており、比較的容易に利用できます。
*   **豊富な事前学習済みモデル:**  様々な種類の物体を検出できる事前学習済みモデルが公開されています。
*   **活発なコミュニティ:**  Ultralytics社を中心とした活発なコミュニティがあり、情報交換やサポートが充実しています。

#### 事前準備と前提条件

*   4.1節と同じ環境が必要です。

#### 基本的な使い方

**1. YOLOv8のリポジトリをクローン:**

```bash
git clone https://github.com/ultralytics/ultralytics
cd ultralytics
pip install -r requirements.txt
```

**2. 事前学習済みモデルのダウンロード:**

YOLOv8には、nano (n), small (s), medium (m), large (l), extra large (x) の5つのサイズがあります。サイズが大きいほど精度が高くなりますが、推論速度は遅くなります。

```python
import torch

# モデルのロード (例: YOLOv8n)
model = torch.hub.load('ultralytics/yolov8', 'yolov8n')

# または、以下のように直接ロードすることもできます
model = torch.hub.load('.', 'yolov8n', source='local') # ローカルにダウンロード済の場合

# CUDAが利用可能であればGPUを使用
if torch.cuda.is_available():
    model.cuda()
```

**3. 画像の推論:**

```python
# 画像のパス
image_path = 'image.jpg'

# 推論の実行
results = model(image_path)

# 結果の表示
results.show()
```

**4. 推論結果の取得:**

`results`オブジェクトには、検出された物体の情報（バウンディングボックスの座標、クラス、信頼度）が含まれています。

```python
# バウンディングボックスの座標
boxes = results.xyxy[0]  # バウンディングボックスの座標 (xmin, ymin, xmax, ymax)

# 信頼度
confidences = results.confidence[0]

# クラス
classes = results.names  # クラス名
class_ids = results.cls[0]

# 結果の表示 (例: 最初の物体の情報)
if len(boxes) > 0:
    print(f'Bounding Box: {boxes[0]}')
    print(f'Confidence: {confidences[0]}')
    print(f'Class: {classes[int(class_ids[0])]}')
```

#### カスタムデータセットでのファインチューニング

**1. データセットの準備:**

*   画像ファイルを1つのディレクトリに格納します。
*   各画像に対応するアノテーションファイルを生成します。アノテーションファイルは、YOLO形式（クラスID, 正規化された中心座標, 正規化された幅, 正規化された高さ）で記述します。
*   データセットを学習用と検証用に分割します。
*   データセットの設定ファイル (YAML形式) を作成します。このファイルには、データセットのパス、クラス名などが記述されます。

例: `data.yaml`

```yaml
train: /path/to/train/images
val: /path/to/val/images
nc: 80  # クラス数 (COCOの場合80)
names: ['person', 'bicycle', 'car', ...]  # クラス名
```

**2. ファインチューニングの実行:**

```python
import torch

# モデルのロード
model = torch.hub.load('ultralytics/yolov8', 'yolov8n')

# データセットの設定ファイル
data_yaml = 'data.yaml'

# 学習の実行
results = model.train(data=data_yaml, epochs=10, imgsz=640)  # imgsz: 画像サイズ、epochs: 学習エポック数
```

#### 推論速度と精度のバランス調整

*   **モデルサイズの選択:**  YOLOv8には、nano (n), small (s), medium (m), large (l), extra large (x) の5つのサイズがあります。サイズが大きいほど精度が高くなりますが、推論速度は遅くなります。アプリケーションの要件に応じて、適切なサイズを選択する必要があります。
*   **バッチサイズの調整:**  バッチサイズを大きくすると、GPUの使用率が向上し、推論速度が向上します。しかし、GPUメモリが不足する場合は、バッチサイズを小さくする必要があります。
*   **画像サイズの調整:**  画像サイズを大きくすると、小さい物体の検出性能が向上します。しかし、推論速度は遅くなります。アプリケーションの要件に応じて、適切なサイズを選択する必要があります。
*   **FP16 (半精度浮動小数点数) の使用:**  FP16を使用すると、メモリ使用量を削減し、推論速度を向上させることができます。ただし、精度が若干低下する場合があります。
*   **TensorRTなどの最適化ツール:** TensorRTを使用すると、モデルを最適化し、推論速度を大幅に向上させることができます。

### 4.3 学習済みモデルの評価と改善

#### 概要と重要性

物体検出モデルを開発する上で、モデルの性能を客観的に評価し、改善することは非常に重要です。適切な評価指標を用いることで、モデルの弱点を特定し、改善策を講じることができます。ここでは、mAP (mean Average Precision) という代表的な評価指標を用いて、学習済みモデルを評価し、改善する方法を解説します。

#### 特徴と利点

*   **客観的な評価:**  mAPは、モデルの精度と検出漏れの両方を考慮した評価指標であり、モデルの性能を客観的に評価できます。
*   **モデルの比較:**  異なるモデルの性能を比較する際に、mAPを用いることで、公平な比較ができます。
*   **改善点の特定:**  mAPの詳細な分析を行うことで、モデルの弱点を特定し、改善策を講じることができます。
*   **学習の進捗状況の把握:**  学習中にmAPを監視することで、学習の進捗状況を把握し、早期に問題を発見できます。

#### 事前準備と前提条件

*   4.1, 4.2節と同じ環境が必要です。
*   評価用のデータセットが必要です (アノテーションデータを含む)。

#### mAP (mean Average Precision) による評価指標

**1. PrecisionとRecall:**

*   **Precision (適合率):**  モデルが検出した物体のうち、実際に正解である物体の割合。  Precision = TP / (TP + FP)
*   **Recall (再現率):**  実際に正解である物体のうち、モデルが検出できた物体の割合。 Recall = TP / (TP + FN)

    *   TP (True Positive): 正しく検出できた陽性サンプル
    *   FP (False Positive): 誤って陽性と判定した陰性サンプル
    *   FN (False Negative): 検出漏れとなった陽性サンプル

**2. Average Precision (AP):**

APは、Precision-Recallカーブの曲線下面積です。Precision-Recallカーブは、信頼度閾値を変化させたときのPrecisionとRecallの関係を表します。APは、クラスごとに計算されます。

**3. mean Average Precision (mAP):**

mAPは、全てのクラスのAPの平均値です。mAP@0.5は、IoU (Intersection over Union) の閾値を0.5としたときのmAPを表します。mAP@0.5:0.95は、IoUの閾値を0.5から0.95まで変化させたときのmAPの平均値を表します。

**4. YOLOv8でのmAPの計算:**

YOLOv8では、`val.py`スクリプトを使って、mAPを計算できます。

```bash
python val.py --data data.yaml --weights runs/train/exp/weights/best.pt --imgsz 640
```

このコマンドを実行すると、検証用データセットに対して、mAP@0.5, mAP@0.5:0.95などの評価指標が表示されます。

#### アノテーションデータの見直しと再学習

*   **アノテーションの誤りの修正:**  アノテーションデータに誤りがある場合、モデルの学習が阻害され、精度が低下します。アノテーションデータを見直し、誤りを修正することで、モデルの精度を向上させることができます。
*   **アノテーションの偏りの修正:**  アノテーションデータに偏りがある場合、モデルは特定の物体に対して過学習を起こし、汎化性能が低下します。アノテーションデータの偏りを修正することで、モデルの汎化性能を向上させることができます。
*   **十分なアノテーションデータの確保:**  十分なアノテーションデータがない場合、モデルは十分に学習できず、精度が低下します。アノテーションデータを増やすことで、モデルの精度を向上させることができます。

#### Data Augmentationによる汎化性能向上

Data Augmentationは、学習データを人工的に拡張する手法です。画像の回転、拡大縮小、色調変更などを施すことで、データセットを人工的に拡張し、モデルの汎化性能を向上させることができます。

**1. YOLOv8でのData Augmentation:**

YOLOv8では、`data.yaml`ファイルでData Augmentationの設定を行うことができます。

```yaml
train: /path/to/train/images
val: /path/to/val/images
nc: 80
names: ['person', 'bicycle', 'car', ...]

# Data Augmentation settings
augment:
  hsv_h: 0.015  # HSV color-space hue augmentation
  hsv_s: 0.7  # HSV color-space saturation augmentation
  hsv_v: 0.4  # HSV color-space value augmentation
  degrees: 0.0  # image rotation (+/- deg)
  translate: 0.1  # image translation (+/- fraction)
  scale: 0.5  # image scale (+/- gain)
  shear: 0.0  # image shear (+/- deg)
  perspective: 0.0  # image perspective (+/- fraction, only supported in YOLOv8)
  flipud: 0.0  # image flip up-down (probability)
  fliplr: 0.5  # image flip left-right (probability)
  mosaic: 1.0 # Enable mosaic augmentation
  mixup: 0.0 # Enable mixup augmentation
```

これらのパラメータを調整することで、Data Augmentationの効果を調整できます。
