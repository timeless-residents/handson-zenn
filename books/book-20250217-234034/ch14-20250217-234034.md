#### 14.1.4 基本的な使い方

ここでは、オープンソースのコンピュータビジョンライブラリであるOpenCVと、Pythonを用いて、簡単なドライブレコーダー映像解析の例を紹介します。

**例：衝突検出**

```python
import cv2

# 動画ファイルの読み込み
cap = cv2.VideoCapture('accident.mp4')

# 背景差分法による動き検出器の作成
fgbg = cv2.createBackgroundSubtractorMOG2()

while(1):
    ret, frame = cap.read()
    if not ret:
        break

    # 前景マスクの取得
    fgmask = fgbg.apply(frame)

    # マスク画像の二値化
    thresh = cv2.threshold(fgmask, 200, 255, cv2.THRESH_BINARY)[1]

    # ノイズ除去
    thresh = cv2.erode(thresh, None, iterations=2)
    thresh = cv2.dilate(thresh, None, iterations=2)

    # 輪郭抽出
    contours, hierarchy = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

    # 輪郭が存在する場合
    for c in contours:
        # 輪郭の面積が一定以上の場合
        if cv2.contourArea(c) > 500:
            # 衝突の可能性ありと判断
            (x, y, w, h) = cv2.boundingRect(c)
            cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 0, 255), 2)
            cv2.putText(frame, "Possible Collision", (x, y - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 0, 255), 2)

    # 結果の表示
    cv2.imshow('Collision Detection', frame)

    # qキーで終了
    if cv2.waitKey(30) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

このコードは、背景差分法を用いて映像内の動きを検出し、一定以上の大きさの動きがあった場合に「衝突の可能性あり」と判断します。これはあくまで基本的な例であり、実際にはより高度なアルゴリズムや機械学習モデルが必要になります。

#### 14.2.4 基本的な使い方

ここでは、YOLO (You Only Look Once) というオブジェクト検出アルゴリズムを用いて、危険運転の検出を行う例を紹介します。YOLOは、リアルタイム処理に適した高速なオブジェクト検出アルゴリズムです。

**例：前方不注意運転の検出**

```python
import cv2
import torch

# YOLOv5モデルのロード
model = torch.hub.load('ultralytics/yolov5', 'yolov5s')

# 動画ファイルの読み込み
cap = cv2.VideoCapture('distracted_driving.mp4')

while(1):
    ret, frame = cap.read()
    if not ret:
        break

    # YOLOによるオブジェクト検出
    results = model(frame)

    # 検出結果の表示
    for *xyxy, conf, cls in results.xyxy[0]:
        if int(cls) == 0: # person (運転手を想定)
            x1, y1, x2, y2 = map(int, xyxy)
            # 運転手の顔領域をクロップ
            face_region = frame[y1:y2, x1:x2]
            # ここで顔認識や視線推定を行い、前方不注意を判定
            # (詳細なコードは省略)
            cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 0, 255), 2)
            cv2.putText(frame, "Distracted Driving", (x1, y1 - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 0, 255), 2)

    # 結果の表示
    cv2.imshow('Distracted Driving Detection', frame)

    # qキーで終了
    if cv2.waitKey(30) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

このコードは、YOLOv5を用いて映像内の人物（運転手）を検出し、検出された人物の顔領域に対して顔認識や視線推定を行うことで、前方不注意運転を検出します。詳細な顔認識や視線推定のコードは省略していますが、既存のライブラリやAPIを活用することで実現可能です。

#### 14.3.4 基本的な使い方

# 動画ファイルの読み込み
cap = cv2.VideoCapture('traffic.mp4')

# 背景差分法による動き検出器の作成
fgbg = cv2.createBackgroundSubtractorMOG2()

# 交通量カウントの初期化
traffic_count = 0

while(1):
    ret, frame = cap.read()

    fgmask = fgbg.apply(frame)
