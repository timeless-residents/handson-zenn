## 第6章： 車線検出：安全運転支援への応用

### 6.1 Hough変換による車線検出

#### 6.1.1 概要と重要性

車線検出は、安全運転支援システム (ADAS) の根幹をなす技術の一つです。車両が自らの走行車線を正確に認識することで、車線逸脱警告 (LDW)、車線維持支援 (LKA)、自動運転といった高度な機能を実現できます。その中でも、Hough変換は古典的でありながら、計算コストが低く、リアルタイム処理に適しているため、依然として重要な手法です。本セクションでは、画像処理の基礎から、Hough変換を用いた車線検出の基本的な流れを解説し、パラメータチューニングによる精度向上を目指します。

#### 6.1.2 特徴と利点

Hough変換は、画像中の直線や円などの特定の形状を検出するアルゴリズムです。車線検出においては、車線を直線として近似することで、画像内の車線を効率的に検出できます。

**Hough変換の利点:**

*   **計算コストが低い:** 深層学習モデルと比較して、計算リソースの要求が少ないため、組み込みシステムにも実装しやすいです。
*   **リアルタイム処理に適している:** 高速な処理が可能であるため、リアルタイムでの車線検出に適しています。
*   **比較的ロバスト:** ノイズや小さな遮蔽物に対して、比較的強いです。

**Hough変換の欠点:**

*   **パラメータ調整が必要:** 検出精度はパラメータ設定に大きく依存します。
*   **曲線車線に弱い:** 車線を直線で近似するため、急なカーブや複雑な形状の車線には対応しづらいです。
*   **照明変化に弱い:** 画像の前処理が重要であり、照明条件の変化に影響を受けやすいです。

#### 6.1.4 基本的な使い方

Hough変換を用いた車線検出の基本的な流れは以下の通りです。

1.  **画像の前処理:** グレースケール変換、ガウシアンフィルタによる平滑化、エッジ検出 (Canny法) を行います。
2.  **Hough変換の適用:** エッジ画像に対してHough変換を適用し、直線候補を検出します。
3.  **車線候補のフィルタリング:** 検出された直線候補から、車線らしいもの (傾き、位置など) をフィルタリングします。
4.  **車線の描画:** フィルタリングされた直線候補を画像に描画します。

以下に、PythonとOpenCVを用いた基本的なコード例を示します。

```python
import cv2
import numpy as np

def detect_lanes_hough(image):
    """
    Hough変換を用いて車線を検出する関数
    """

    # 1. 画像の前処理
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0) # (5,5) はカーネルサイズ
    edges = cv2.Canny(blur, 50, 150) # 50, 150 は閾値

    # 2. Hough変換の適用
    lines = cv2.HoughLinesP(edges, 1, np.pi/180, 50, minLineLength=100, maxLineGap=50)

    # 3. 車線候補のフィルタリングと描画
    line_image = np.zeros_like(image)
    if lines is not None:
        for line in lines:
            x1, y1, x2, y2 = line[0]
            # 車線らしい傾きの線を抽出 (水平に近い線は除外)
            slope = (y2 - y1) / (x2 - x1 + 1e-5) # ゼロ除算対策
            if abs(slope) > 0.5:
                cv2.line(line_image, (x1, y1), (x2, y2), (0, 255, 0), 5) # 0, 255, 0 は色 (緑)、5 は線の太さ

    # 画像に車線を描画
    combo_image = cv2.addWeighted(image, 0.8, line_image, 1, 0)

    return combo_image

# 画像の読み込み
image = cv2.imread('lane_image.jpg') # 'lane_image.jpg' は画像ファイル名

# 車線検出の実行
lane_image = detect_lanes_hough(image)

# 結果の表示
cv2.imshow('Lane Detection with Hough Transform', lane_image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### 6.1.5 実践的なテクニック

Hough変換による車線検出の精度を向上させるためには、以下のテクニックが有効です。

*   **関心領域 (Region of Interest, ROI) の設定:** 車線が存在する可能性の高い領域のみを処理することで、ノイズの影響を軽減し、処理速度を向上させます。具体的には、画像の底辺から一定の高さまでの範囲をROIとして設定することが一般的です。
*   **パラメータチューニング:** HoughLinesP関数のパラメータ (rho, theta, threshold, minLineLength, maxLineGap) を適切に調整することで、検出精度を向上させることができます。
    *   `rho`: 距離分解能 (単位: ピクセル)。小さいほど精度が高くなるが、計算量が増加します。
    *   `theta`: 角度分解能 (単位: ラジアン)。小さいほど精度が高くなるが、計算量が増加します。
    *   `threshold`: 直線を検出するための最小投票数。大きいほど検出される直線が少なくなり、ノイズが減少します。
    *   `minLineLength`: 直線を構成する最小の線分の長さ。短い線分を除外することで、ノイズの影響を軽減できます。
    *   `maxLineGap`: 同じ直線上に存在する線分の最大の間隔。間隔の大きい線分を別の直線として扱うことで、車線の途切れを補完できます。
*   **色空間の変換:**  RGBではなく、HLSやHSV色空間を用いることで、照明変化に対するロバスト性を向上させることができます。特に、S (彩度) チャネルやV (明度) チャネルを利用することで、影の影響を軽減できます。
*   **Perspective Transform (射影変換):** カメラの視点による歪みを補正し、車線を平行な直線として扱うことで、Hough変換の精度を向上させることができます。

以下に、ROIを設定する例を示します。

```python
def region_of_interest(image, vertices):
    """
    画像から関心領域を抽出する関数
    """
    mask = np.zeros_like(image)
    cv2.fillPoly(mask, vertices, 255)
    masked_image = cv2.bitwise_and(image, mask)
    return masked_image

# 画像の高さと幅を取得
height = image.shape[0]
width = image.shape[1]

# 関心領域の頂点を定義
vertices = np.array([[(0, height), (width/2, height/2), (width, height)]], dtype=np.int32)

# 関心領域を抽出
roi_image = region_of_interest(edges, vertices) # edges は Cannyエッジ検出後の画像
```

#### 6.1.6 応用例とユースケース

Hough変換による車線検出は、以下のような応用例があります。

*   **車線逸脱警告 (LDW):** 車両が車線を逸脱した場合に、ドライバーに警告を発するシステム。
*   **車線維持支援 (LKA):** 車両が車線の中央を走行するように、ステアリングを自動的に制御するシステム。
*   **自動運転:** 高度な自動運転システムにおいて、車両の位置を特定し、安全な走行経路を計画するために利用されます。
*   **道路標識の認識:** 車線検出の結果を基に、道路標識の位置を特定し、内容を認識することができます。
*   **道路の維持管理:** 車線検出の結果を分析することで、道路の劣化状況を把握し、適切な維持管理計画を策定することができます。

#### 6.1.7 トラブルシューティング

*   **車線が検出されない:**
    *   画像の前処理が不適切である可能性があります。ガウシアンフィルタのカーネルサイズや、Cannyエッジ検出の閾値を調整してみてください。
    *   HoughLinesP関数のパラメータが不適切である可能性があります。特に、threshold, minLineLength, maxLineGapを調整してみてください。
    *   照明条件が悪い可能性があります。色空間を変換したり、画像の前処理を工夫してみてください。
*   **ノイズが多い:**
    *   関心領域 (ROI) を設定することで、ノイズの影響を軽減できます。
    *   HoughLinesP関数のthresholdを大きくすることで、ノイズを除去できます。
    *   画像の前処理を工夫することで、ノイズを軽減できます。
*   **曲線車線にうまく対応できない:**
    *   Hough変換以外のアルゴリズム (例: Deep Learning) を検討してみてください。
    *   短い線分を組み合わせて、曲線として近似する手法を検討してみてください。

### 6.2 Deep Learningによる車線検出

#### 6.2.1 概要と重要性

近年、Deep Learning技術の発展により、画像認識の分野で飛躍的な進歩が見られています。車線検出においても、CNN (Convolutional Neural Network) を用いることで、Hough変換では困難だった複雑な形状の車線や、悪条件下での検出が可能になりました。本セクションでは、CNNを用いた車線検出モデルの構築方法と、車線追従アルゴリズムの実装について解説します。

#### 6.2.4 CNNを用いた車線検出モデルの構築

ここでは、セマンティックセグメンテーションモデルの一種であるUNetをベースにした車線検出モデルを構築する例を紹介します。UNetは、医療画像解析で広く用いられているモデルであり、車線検出にも応用できます。

```python
import tensorflow as tf
from tensorflow.keras import layers

def unet_model(input_shape=(256, 512, 3), num_classes=2):
    """
    UNetモデルを構築する関数
    """

    inputs = tf.keras.Input(shape=input_shape)

    # Encoder
    conv1 = layers.Conv2D(64, 3, activation='relu', padding='same')(inputs)
    conv1 = layers.Conv2D(64, 3, activation='relu', padding='same')(conv1)
    pool1 = layers.MaxPooling2D(pool_size=(2, 2))(conv1)

    conv2 = layers.Conv2D(128, 3, activation='relu', padding='same')(pool1)
    conv2 = layers.Conv2D(128, 3, activation='relu', padding='same')(conv2)
    pool2 = layers.MaxPooling2D(pool_size=(2, 2))(conv2)

    # Bottleneck
    conv3 = layers.Conv2D(256, 3, activation='relu', padding='same')(pool2)
    conv3 = layers.Conv2D(256, 3, activation='relu', padding='same')(conv3)

    # Decoder
    up1 = layers.UpSampling2D(size=(2, 2))(conv3)
    merge1 = layers.concatenate([conv2, up1], axis=-1)
    conv4 = layers.Conv2D(128, 3, activation='relu', padding='same')(merge1)
    conv4 = layers.Conv2D(128, 3, activation='relu', padding='same')(conv4)

    up2 = layers.UpSampling2D(size=(2, 2))(conv4)
    merge2 = layers.concatenate([conv1, up2], axis=-1)
    conv5 = layers.Conv2D(64, 3, activation='relu', padding='same')(merge2)
    conv5 = layers.Conv2D(64, 3, activation='relu', padding='same')(conv5)

    # Output
    outputs = layers.Conv2D(num_classes, 1, activation='softmax')(conv5)  # softmax for segmentation

    model = tf.keras.Model(inputs=inputs, outputs=outputs)
    return model

# モデルの構築
model = unet_model()

# モデルのコンパイル
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])

# モデルの概要を表示
model.summary()
```

このコードでは、256x512のRGB画像をインプットとし、各ピクセルが車線であるか否かの2クラス分類を行うUNetモデルを定義しています。

#### 6.2.5 車線追従アルゴリズムの実装

車線検出モデルの出力 (セグメンテーションマップ) を基に、車線追従アルゴリズムを実装することができます。ここでは、簡単な例として、検出された車線の中央を走行するように、ステアリングを制御するアルゴリズムを紹介します。

```python
import numpy as np
import cv2

def lane_following(image, segmentation_map):
    """
    車線追従アルゴリズム
    """

    # 車線領域の抽出 (クラス1が車線と仮定)
    lane_mask = (segmentation_map == 1).astype(np.uint8)

    # 車線領域の重心を計算
    M = cv2.moments(lane_mask)
    if M["m00"] != 0:
        cX = int(M["m10"] / M["m00"])
        cY = int(M["m01"] / M["m00"])
    else:
        # 車線が検出されない場合
        return 0  # ステアリング操作なし

    # 画像の中心からのずれを計算
    deviation = cX - image.shape[1] / 2

    # ステアリング操作量を決定 (比例制御)
    steering_angle = deviation * 0.1  # 0.1 はゲイン

    return steering_angle
```

このコードでは、セグメンテーションマップから車線領域を抽出し、その重心を計算します。画像の中心からのずれを計算し、そのずれに比例したステアリング操作量を決定します。

### 6.3 車線逸脱警告システムの実装

#### 6.3.1 概要と重要性

車線逸脱警告 (Lane Departure Warning, LDW) システムは、車両が意図せずに車線を逸脱した場合に、ドライバーに警告を発するシステムです。居眠り運転や脇見運転などによる事故を未然に防ぐ効果が期待されています。本セクションでは、車線逸脱の定義と判定方法、および警告方法 (音声、視覚) について解説します。

#### 6.3.2 車線逸脱の定義と判定

車線逸脱は、一般的に、車両が車線を跨いで走行した場合、または車線境界線に接近しすぎた場合に定義されます。車線逸脱の判定には、車線検出の結果 (車線の位置、幅、角度) を用います。

以下に、車線逸脱を判定するアルゴリズムの例を示します。

```python
def is_lane_departure(lane_position, lane_width, deviation_threshold):
    """
    車線逸脱を判定する関数
    """

    # 車線の中央からのずれを計算
    deviation = abs(lane_position)

    # 車線の中央からのずれが閾値を超えた場合、車線逸脱と判定
    if deviation > lane_width / 2 * deviation_threshold: # deviation_threshold は例えば0.8
        return True
    else:
        return False
```

このコードでは、車線の中央からのずれが、車線幅の一定割合を超えた場合に、車線逸脱と判定します。`deviation_threshold` は、車線逸脱を判定するための閾値であり、車両の速度や道路状況に応じて調整する必要があります。

#### 6.3.3 警告方法 (音声、視覚)

車線逸脱が検出された場合、ドライバーに警告を発する必要があります。警告方法としては、音声による警告、視覚による警告、またはその組み合わせが考えられます。

*   **音声による警告:**
    *   ブザー音、警告音、または音声メッセージなどを用いて、ドライバーに警告を発します。
    *   音声メッセージを用いる場合、車線逸脱の方向 (右または左) を伝えることで、ドライバーが適切な操作を行えるように支援できます。
*   **視覚による警告:**
    *   ダッシュボード上の警告灯を点灯させたり、ヘッドアップディスプレイ (HUD) に警告情報を表示したりすることで、ドライバーに警告を発します。
    *   車線逸脱の方向を示す矢印を表示することで、ドライバーが適切な操作を行えるように支援できます。
    *   車線境界線を強調表示したり、色を変えたりすることで、ドライバーに注意を促すことができます。

以下に、OpenCVを用いて、車線逸脱を視覚的に警告する例を示します。

```python
import cv2

def visualize_lane_departure(image, lane_position, lane_width, is_departed):
    """
    車線逸脱を視覚的に警告する関数
    """

    # 車線逸脱した場合、車線境界線を赤色で強調表示
    if is_departed:
        # 車線位置から車線境界線の座標を計算 (簡略化のため、直線と仮定)
        left_lane_x = int(image.shape[1] / 2 + lane_position - lane_width / 2)
        right_lane_x = int(image.shape[1] / 2 + lane_position + lane_width / 2)

        # 車線境界線を赤色で描画
        cv2.line(image, (left_lane_x, image.shape[0]), (left_lane_x, 0), (0, 0, 255), 5) # 赤色、太さ5
        cv2.line(image, (right_lane_x, image.shape[0]), (right_lane_x, 0), (0, 0, 255), 5) # 赤色、太さ5

    return image
```

このコードでは、車線逸脱が検出された場合、車線境界線を赤色で強調表示します。

#### 6.3.4 実践的なテクニック

*   **状況に応じた警告レベルの調整:** 車両の速度、道路状況、ドライバーの状態などに応じて、警告レベルを調整することで、ドライバーに適切な警告を発することができます。例えば、高速道路では、低速道路よりも早めに警告を発するように設定します。また、ドライバーが疲労している場合や、居眠り運転をしている可能性がある場合には、より強い警告を発するように設定します。
*   **誤検出の抑制:** 車線変更時や、一時的な車線逸脱 (道路工事など) を誤検出しないように、フィルタリング処理や、状況判断アルゴリズムを導入します。
*   **ドライバーへのフィードバック:** 車線逸脱警告システムが正常に動作していることをドライバーに伝えるために、定期的にシステムの状態を表示したり、正常に警告が発せられた場合に、肯定的なフィードバック (例: 警告灯の点滅) を行います。
*   **ユーザーカスタマイズ:** 警告音の種類や音量、警告灯の明るさなどを、ユーザーがカスタマイズできるようにすることで、ドライバーの好みに合わせた警告を提供できます。

#### 6.3.5 応用例とユースケース

*   **トラックやバスなどの大型車両への搭載:** 大型車両は、死角が多く、運転操作が難しいため、車線逸脱警告システムの重要性が高まります。
*   **高齢者ドライバーへの支援:** 高齢者ドライバーは、認知機能や運動能力が低下しているため、車線逸脱警告システムによる支援が有効です。
*   **運転教習:** 車線逸脱警告システムを運転教習に活用することで、安全運転意識の向上を図ることができます。

#### 6.3.6 トラブルシューティング

*   **警告が頻繁に誤って発せられる:**
    *   車線逸脱の閾値が低すぎる可能性があります。閾値を高くしてみてください。
    *   車線検出の精度が低い可能性があります。車線検出アルゴリズムを見直してみてください。
    *   道路状況 (路面の状態、照明条件など) が悪い可能性があります。道路状況に適応できるようなロバストなアルゴリズムを開発してみてください。
*   **警告が遅すぎる:**
    *   車線逸脱の閾値が高すぎる可能性があります。閾値を低くしてみてください。
    *   車線検出の処理速度が遅い可能性があります。処理速度を向上させるために、アルゴリズムを最適化したり、より高性能なハードウェアを使用してみてください。
*   **警告音が聞こえにくい:**
    *   警告音の音量が小さすぎる可能性があります。音量を大きくしてみてください。
    *   周囲の騒音が大きい可能性があります。周囲の騒音に影響されないような、特徴的な警告音を使用してみてください。
