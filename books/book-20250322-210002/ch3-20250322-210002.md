## 第 3 章：RNN による音楽生成 - メロディとハーモニーの創造

音楽生成は、AI のクリエイティブな可能性を示す魅力的な分野です。この章では、リカレントニューラルネットワーク（RNN）を用いて、メロディとハーモニーを自動生成する方法を解説します。特に、長期的な依存関係の学習に優れた LSTM（Long Short-Term Memory）ネットワークに焦点を当て、Keras/TensorFlow を用いた実践的なコード例を交えながら、音楽生成の基礎から応用までを段階的に学びます。

### 3.1 RNN の基礎 - 時系列データの学習

#### 3.1.1 概要と重要性

RNN は、系列データ、つまり時間の流れに沿って変化するデータを扱うのに適したニューラルネットワークです。音楽はまさに時系列データであり、音符の順序、リズム、テンポなど、時間的な関係性が重要になります。RNN は、過去の情報を記憶し、それに基づいて未来を予測する能力を持っているため、音楽生成に非常に有効です。

#### 3.1.2 特徴と利点

RNN の最大の特徴は、**隠れ層が時間方向に接続されている**ことです。これにより、ネットワークは過去の入力情報を保持し、現在の入力処理に活用できます。これにより、音楽におけるフレーズの繰り返しやモチーフの展開といった、長期的な依存関係を学習することが可能になります。

#### 3.1.3 事前準備と前提条件

- **Python の基本的な知識:** 変数、関数、リスト、辞書などの基本的な構文を理解している必要があります。
- **ニューラルネットワークの基礎:** パーセプトロン、順伝播型ネットワークの仕組みを理解していると、RNN の理解が深まります。
- **Keras/TensorFlow のインストール:** `pip install tensorflow keras` コマンドでインストールできます。
- **MIDI ファイルの扱い:** MIDI ファイル（.mid）は、音楽データを記述するための標準的なフォーマットです。Python で MIDI ファイルを扱うためのライブラリ（例：`mido`）をインストールしておくと便利です。

#### 3.1.4 基本的な使い方

RNN の基本的な構造は、入力層、隠れ層、出力層から構成されます。音楽生成においては、通常、過去の音符の系列が入力となり、次の音符の予測が出力となります。

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense

# モデルの定義
model = Sequential()
model.add(SimpleRNN(units=128, input_shape=(None, 1)))  # Noneは可変長の系列に対応
model.add(Dense(units=1, activation='linear'))

# モデルのコンパイル
model.compile(optimizer='adam', loss='mse')

# データの準備 (例: sin波)
import numpy as np
data = np.sin(np.arange(1000) / 20)
data = data.reshape(-1, 1, 1) # (サンプル数, 時間ステップ数, 特徴量)

# 学習
model.fit(data[:-1], data[1:], epochs=10)

# 予測
predicted = model.predict(data[-10:])
print(predicted)
```

この例では、`SimpleRNN`という最も基本的な RNN 層を使用しています。`input_shape=(None, 1)`は、可変長の系列を受け付け、特徴量が 1 つ（例：音の高さ）であることを意味します。`Dense`層は、最終的な出力を生成するための全結合層です。

#### 3.1.5 実践的なテクニック

- **データの準備:** 音楽データを RNN に入力するためには、適切な形式に変換する必要があります。MIDI ファイルを解析し、音符の高さ（ピッチ）、音の長さ（デュレーション）、音の強さ（ベロシティ）などの情報を数値化します。
- **系列長の調整:** RNN は固定長の系列しか扱えないため、音楽データを適切な長さに分割する必要があります。短い系列はパディング（例えば 0 で埋める）し、長い系列は分割します。
- **埋め込み層の利用:** 音符を直接数値として扱うのではなく、埋め込み層（Embedding Layer）を利用することで、より効果的な学習が期待できます。埋め込み層は、音符を低次元のベクトル空間にマッピングし、音符間の関係性を学習します。

#### 3.1.6 応用例とユースケース

- **自動作曲:** RNN を用いて、既存の音楽スタイルを学習させ、新しい曲を生成することができます。
- **音楽の補完:** 未完成の楽曲に対して、RNN が適切なメロディやコード進行を提案することができます。
- **音楽教育:** RNN を用いて、音楽理論の学習を支援するツールを開発することができます。

#### 3.1.7 トラブルシューティング

- **勾配消失/爆発:** RNN の学習が進まない場合、勾配消失または勾配爆発が原因である可能性があります。勾配クリッピングや、より高度な RNN アーキテクチャ（LSTM、GRU）を使用することで、この問題を軽減できます。
- **過学習:** 学習データに過剰に適合してしまう場合、正則化（L1/L2 正則化、ドロップアウト）を適用することで、汎化性能を向上させることができます。

#### 3.1.8 まとめと次のステップ

RNN は、音楽生成の強力なツールですが、その性能を最大限に引き出すためには、適切なデータの前処理、モデルの選択、ハイパーパラメータの調整が不可欠です。次のセクションでは、RNN の中でも特に音楽生成に適した LSTM ネットワークについて詳しく解説します。

### 3.2 LSTM によるメロディ生成 - 長期的な依存関係の学習

#### 3.2.1 概要と重要性

LSTM（Long Short-Term Memory）は、RNN の一種であり、長期的な依存関係を効果的に学習できることが特徴です。従来の RNN では、系列が長くなるほど過去の情報が薄れてしまい、長期的な文脈を考慮した学習が難しくなるという問題（勾配消失問題）がありました。LSTM は、**セル状態**という特別な記憶機構を持つことで、この問題を克服し、音楽におけるフレーズの繰り返しやモチーフの展開といった、時間的に離れた要素間の関連性を捉えることが可能になります。

#### 3.2.2 特徴と利点

LSTM の主な特徴は以下の通りです。

- **セル状態:** 長期的な情報を保持するための記憶セル。情報の追加、削除を制御するゲート機構を備えています。
- **入力ゲート、出力ゲート、忘却ゲート:** これらのゲートは、セル状態への情報の流れを制御し、重要な情報を保持し、不要な情報を忘れる役割を果たします。

これらの機能により、LSTM は、従来の RNN よりもはるかに長い系列の情報を効果的に学習することができます。

#### 3.2.3 事前準備と前提条件

3.1 節と同様の事前準備に加えて、LSTM の内部構造（セル状態、ゲート機構）について理解しておくことが望ましいです。インターネット上には、LSTM の仕組みを解説する多くの資料がありますので、参考にしてください。

#### 3.2.4 基本的な使い方

Keras/TensorFlow で LSTM を使用するには、`LSTM`層を使用します。

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense

# モデルの定義
model = Sequential()
model.add(LSTM(units=128, input_shape=(None, 1)))  # Noneは可変長の系列に対応
model.add(Dense(units=1, activation='linear'))

# モデルのコンパイル
model.compile(optimizer='adam', loss='mse')

# データの準備 (例: sin波)
import numpy as np
data = np.sin(np.arange(1000) / 20)
data = data.reshape(-1, 1, 1) # (サンプル数, 時間ステップ数, 特徴量)

# 学習
model.fit(data[:-1], data[1:], epochs=10)

# 予測
predicted = model.predict(data[-10:])
print(predicted)
```

`SimpleRNN`層の代わりに`LSTM`層を使用するだけで、LSTM ネットワークを構築できます。`units`は、LSTM 層の隠れ状態の次元数を指定します。

#### 3.2.5 実践的なテクニック

- **多層 LSTM:** 複数の LSTM 層を積み重ねることで、より複雑な音楽構造を学習することができます。
- **双方向 LSTM:** 過去の情報だけでなく、未来の情報も考慮することで、より自然な音楽生成が可能になります。
- **Attention 機構の導入:** 注意機構（Attention Mechanism）を導入することで、入力系列の中で重要な部分に焦点を当て、より洗練された音楽生成を実現できます。

#### 3.2.6 応用例とユースケース

- **特定の作曲家のスタイル模倣:** バッハ、モーツァルトなどの作曲家の楽曲を学習させ、そのスタイルを模倣した曲を生成することができます。
- **インタラクティブな音楽生成:** ユーザーの入力（例えば、リズムパターンやコード進行）に基づいて、リアルタイムで音楽を生成することができます。
- **ゲーム音楽の自動生成:** ゲームの状況に応じて、適切な BGM を自動生成することができます。

#### 3.2.7 トラブルシューティング

- **学習時間の長さ:** LSTM は、従来の RNN よりも計算コストが高く、学習に時間がかかることがあります。GPU を利用したり、バッチサイズを調整したりすることで、学習時間を短縮できます。
- **パラメータの調整:** LSTM は、多くのハイパーパラメータ（層数、ユニット数、学習率など）を持ちます。これらのパラメータを適切に調整することで、性能を向上させることができます。

#### 3.2.8 まとめと次のステップ

LSTM は、長期的な依存関係を学習できる強力な RNN アーキテクチャであり、音楽生成において非常に有効です。次のセクションでは、Keras/TensorFlow を用いた LSTM によるメロディ生成の実装例を具体的に解説します。

### 3.3 実装例：Keras/TensorFlow による LSTM メロディ生成

#### 3.3.1 概要と重要性

このセクションでは、Keras/TensorFlow を用いて、実際に LSTM によるメロディ生成を行うためのコード例を示します。MIDI ファイルの読み込み、データの準備、モデルの構築、学習、生成、そして生成された MIDI ファイルの保存まで、一連のプロセスを段階的に解説します。

#### 3.3.2 事前準備と前提条件

- **Python の環境構築:** Python 3.7 以上が推奨されます。
- **必要なライブラリのインストール:** `pip install tensorflow keras mido pretty_midi`
- **MIDI ファイルの準備:** 学習に使用する MIDI ファイルをいくつか用意してください。

#### 3.3.3 コード例

以下は、LSTM によるメロディ生成の基本的なコード例です。

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Activation, Dropout
from tensorflow.keras.optimizers import RMSprop
import numpy as np
import glob
import pretty_midi

# 1. MIDIファイルの読み込みとデータの前処理
def load_midi_data(directory):
    notes = []
    for filename in glob.glob(directory + "/*.mid"):
        try:
            midi = pretty_midi.PrettyMIDI(filename)
            for instrument in midi.instruments:
                if not instrument.is_drum:
                    for note in instrument.notes:
                        notes.append(note.pitch)
        except Exception as e:
            print(f"Error processing {filename}: {e}")
    return notes

# 学習データを作成
def prepare_sequences(notes, sequence_length):
    pitchnames = sorted(set(item for item in notes))
    note_to_int = dict((note, number) for number, note in enumerate(pitchnames))

    network_input = []
    network_output = []

    for i in range(0, len(notes) - sequence_length, 1):
        sequence_in = notes[i:i + sequence_length]
        sequence_out = notes[i + sequence_length]
        network_input.append([note_to_int[char] for char in sequence_in])
        network_output.append(note_to_int[sequence_out])

    n_patterns = len(network_input)

    # 入力をLSTMで処理できる形に変形
    network_input = np.reshape(network_input, (n_patterns, sequence_length, 1))
    # 入力を正規化
    network_input = network_input / float(len(pitchnames))

    network_output = tf.keras.utils.to_categorical(network_output)

    return (network_input, network_output, pitchnames)

# 2. モデルの構築
def create_network(network_input, n_vocab):
    model = Sequential()
    model.add(LSTM(
        512,
        input_shape=(network_input.shape[1], network_input.shape[2]),
        return_sequences=True
    ))
    model.add(Dropout(0.3))
    model.add(LSTM(512, return_sequences=True))
    model.add(Dropout(0.3))
    model.add(LSTM(512))
    model.add(Dense(256))
    model.add(Dropout(0.3))
    model.add(Dense(n_vocab))
    model.add(Activation('softmax'))
    model.compile(loss='categorical_crossentropy', optimizer='rmsprop')

    return model

# 3. 学習
def train(model, network_input, network_output, filepath="weights.hdf5"):
    filepath = filepath
    checkpoint = tf.keras.callbacks.ModelCheckpoint(
        filepath,
        monitor='loss',
        verbose=0,
        save_best_only=True,
        mode='min'
    )
    callbacks_list = [checkpoint]

    model.fit(network_input, network_output, epochs=200, batch_size=64, callbacks=callbacks_list)

# 4. 音楽生成
def generate_notes(model, network_input, pitchnames, n_vocab, sequence_length):
    #  開始シーケンスを選択
    start = np.random.randint(0, len(network_input)-1)

    int_to_note = dict((number, note) for number, note in enumerate(pitchnames))

    pattern = list(network_input[start])
    prediction_output = []

    # 500音符を生成
    for note_index in range(500):
        prediction_input = np.reshape(pattern, (1, len(pattern), 1))
        prediction_input = prediction_input / float(n_vocab)

        prediction = model.predict(prediction_input, verbose=0)

        index = np.argmax(prediction)
        result = int_to_note[index]
        prediction_output.append(result)

        pattern.append(index / float(n_vocab))
        pattern = pattern[1:len(pattern)]

    return prediction_output

# 5. MIDIファイルとして保存
def create_midi(prediction_output, filename = 'output.mid'):
    offset = 0
    output_notes = []

    # 音符の生成
    for pattern in prediction_output:
        note = pretty_midi.Note(
            velocity=100,
            pitch=pattern,
            start=offset,
            end=offset + 0.5
        )
        output_notes.append(note)
        offset += 0.5

    # pretty_midiオブジェクトの生成
    pm = pretty_midi.PrettyMIDI()
    instrument = pretty_midi.Instrument(program=0)
    instrument.notes = output_notes
    pm.instruments.append(instrument)

    # MIDIファイルの書き出し
    pm.write(filename)

# メイン処理
if __name__ == '__main__':
    midi_directory = "midi_songs"  # MIDIファイルが保存されているディレクトリを指定
    sequence_length = 100
    weights_filepath = "weights.hdf5" # 学習済み重みの保存場所

    notes = load_midi_data(midi_directory)
    print(f"Loaded {len(notes)} notes")

    network_input, network_output, pitchnames = prepare_sequences(notes, sequence_length)
    n_vocab = len(set(notes))

    model = create_network(network_input, n_vocab)

    # 学習済み重みをロードする場合
    try:
        model.load_weights(weights_filepath)
        print("Loaded weights from disk")
    except:
        print("No weights found, training from scratch")
        train(model, network_input, network_output, weights_filepath)


    prediction_output = generate_notes(model, network_input, pitchnames, n_vocab, sequence_length)
    create_midi(prediction_output, filename='output.mid')

    print("Generated MIDI file: output.mid")
```

#### 3.3.4 コードの説明

1.  **MIDI ファイルの読み込みとデータの前処理:**
    - `load_midi_data`関数は、指定されたディレクトリ内の MIDI ファイルを読み込み、音符のピッチ情報をリストとして返します。
    - `prepare_sequences`関数は、音符の系列を LSTM に入力できる形式に変換します。具体的には、音符を数値に変換し、入力シーケンスと出力シーケンスを作成します。また、入力データを正規化し、出力データを one-hot ベクトルに変換します。
2.  **モデルの構築:**
    - `create_network`関数は、LSTM ネットワークを構築します。この例では、3 つの LSTM 層と、2 つの Dense 層を使用しています。活性化関数は`softmax`を使用し、出力層の次元数は音符の種類数に合わせます。
3.  **学習:**
    - `train`関数は、LSTM ネットワークを学習させます。`ModelCheckpoint`コールバックを使用して、学習中に最も良い重みを保存します。
4.  **音楽生成:**
    - `generate_notes`関数は、学習済みの LSTM ネットワークを用いて、新しい音符の系列を生成します。まず、ランダムな開始シーケンスを選択し、そのシーケンスを入力として LSTM ネットワークに与えます。LSTM ネットワークは、次の音符を予測し、その音符を生成された系列に追加します。このプロセスを繰り返すことで、新しい音符の系列を生成します。
5.  **MIDI ファイルとして保存:**
    - `create_midi`関数は、生成された音符の系列を MIDI ファイルとして保存します。

#### 3.3.5 実践的なテクニック

- **より多くの MIDI ファイルで学習:** より多くの MIDI ファイルで学習させることで、より多様な音楽スタイルを学習させることができます。
- **ハイパーパラメータの調整:** LSTM 層のユニット数、学習率、バッチサイズなどを調整することで、性能を向上させることができます。
- **より高度なモデルの構築:** Attention 機構や VAE（Variational Autoencoder）などのより高度な技術を導入することで、より洗練された音楽生成を実現できます。

#### 3.3.6 トラブルシューティング

- **メモリ不足:** MIDI ファイルの数が多い場合、メモリ不足になることがあります。その場合は、バッチサイズを小さくしたり、MIDI ファイルを分割したりすることで、メモリ使用量を削減できます。
- **学習が進まない:** 学習率が低すぎる、または高すぎる場合、学習が進まないことがあります。適切な学習率を見つけるためには、grid search や random search などの手法を用いると良いでしょう。

#### 3.3.7 まとめと次のステップ

このセクションでは、Keras/TensorFlow を用いて、LSTM によるメロディ生成を行うためのコード例を示しました。このコードを基に、様々なパラメータを調整したり、新しい技術を導入したりすることで、独自の音楽生成システムを開発することができます。次のセクションでは、ハーモニー生成への応用について解説します。

### 3.4 ハーモニー生成への応用 - コード進行の自動生成

#### 3.4.1 概要と重要性

メロディ生成に加えて、ハーモニー生成も音楽生成の重要な要素です。ハーモニーは、メロディを支え、楽曲に深みと色彩を与える役割を果たします。このセクションでは、LSTM を用いて、コード進行を自動生成する方法を解説します。コード進行は、音楽の骨格を形成し、楽曲全体の雰囲気や感情を大きく左右するため、自動生成されたコード進行を基に、独自の楽曲を制作することができます。

#### 3.4.2 特徴と利点

LSTM を用いてコード進行を生成する利点は、以下の通りです。

- **音楽理論の学習:** LSTM は、既存の楽曲のコード進行を学習することで、音楽理論に基づいた自然なコード進行を生成することができます。
- **多様なコード進行の生成:** LSTM は、ランダムな要素を取り入れることで、既存の楽曲にはない、新しいコード進行を生成することができます。
- **メロディとの調和:** LSTM は、生成されたメロディに合わせて、最適なコード進行を生成することができます。

#### 3.4.3 事前準備と前提条件

- **音楽理論の基礎知識:** コード、スケール、キーなどの音楽理論の基礎知識があると、コード進行の生成をより深く理解することができます。
- **コード進行の表現方法:** コード進行を LSTM に入力するためには、適切な表現方法を選択する必要があります。例えば、数字表記（I-IV-V-I など）や、MIDI ノートナンバーを使用することができます。

#### 3.4.4 基本的な使い方

コード進行の生成も、メロディ生成と同様に、LSTM ネットワークを使用します。ただし、入力データと出力データの表現方法が異なります。

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Embedding
import numpy as np

# 1. コード進行のデータを準備
# 例: ["C", "G", "Am", "F"] を数値に変換
# ここでは簡易的にインデックスを使用
chord_vocab = ["C", "G", "Am", "F"]
chord_to_index = {chord: i for i, chord in enumerate(chord_vocab)}
index_to_chord = {i: chord for i, chord in enumerate(chord_vocab)}

# コード進行のシーケンス (例)
chord_sequences = [
    ["C", "G", "Am", "F"],
    ["Am", "F", "C", "G"],
    ["F", "C", "G", "C"]
]

sequence_length = 3 # シーケンス長を設定

# 入力と出力のシーケンスを作成
X, y = [], []
for sequence in chord_sequences:
    for i in range(len(sequence) - sequence_length):
        input_sequence = sequence[i:i + sequence_length]
        output_chord = sequence[i + sequence_length]

        input_indices = [chord_to_index[chord] for chord in input_sequence]
        output_index = chord_to_index[output_chord]

        X.append(input_indices)
        y.append(output_index)

# データの整形
X = np.array(X)
y = np.array(y)
y = tf.keras.utils.to_categorical(y, num_classes=len(chord_vocab)) # One-hot encoding

# 2. モデルを構築
model = Sequential()
model.add(Embedding(len(chord_vocab), 16, input_length=sequence_length)) # 埋め込み層
model.add(LSTM(32))
model.add(Dense(len(chord_vocab), activation='softmax'))

model.compile(loss='categorical_crossentropy', optimizer='adam')

# 3. モデルを学習
model.fit(X, y, epochs=100, verbose=0)

# 4. コード進行を生成
def generate_chord_sequence(model, seed_sequence, sequence_length, num_chords_to_generate):
    generated_sequence = seed_sequence.copy()

    for _ in range(num_chords_to_generate):
        # 入力を整形
        input_sequence = np.array([chord_to_index[chord] for chord in generated_sequence[-sequence_length:]])
        input_sequence = np.reshape(input_sequence, (1, sequence_length))

        # 次のコードを予測
        predicted_probabilities = model.predict(input_sequence, verbose=0)[0]
        predicted_index = np.argmax(predicted_probabilities)
        predicted_chord = index_to_chord[predicted_index]

        # 生成されたシーケンスに追加
        generated_sequence.append(predicted_chord)

    return generated_sequence

# 最初のコードシーケンス
seed_sequence = ["C", "G", "Am"]
num_chords_to_generate = 10 # 生成するコード数

generated_chords = generate_chord_sequence(model, seed_sequence, sequence_length, num_chords_to_generate)
print("Generated Chord Sequence:", generated_chords)
```

この例では、コード進行を文字列として扱い、`chord_to_index`という辞書を使って数値に変換しています。また、`Embedding`層を使って、コードを低次元のベクトル空間にマッピングしています。

#### 3.4.5 実践的なテクニック

- **VAE（Variational Autoencoder）の導入:** VAE を導入することで、より多様なコード進行を生成することができます。VAE は、潜在空間と呼ばれる低次元の空間にコード進行を圧縮し、そこから新しいコード進行を生成します。
- **音楽理論に基づいた制約:** 生成されるコード進行が、音楽理論に基づいたものであるように、制約を設けることができます。例えば、特定のキーに属するコードのみを使用したり、特定のコード進行のルール（例えば、ドミナントモーション）に従うようにすることができます。
- **メロディとの連携:** 生成されたコード進行に合わせて、メロディを生成することができます。このためには、メロディとコード進行を同時に学習する、joint model を使用することができます。

#### 3.4.6 応用例とユースケース

- **作曲支援ツール:** 自動生成されたコード進行を基に、作曲家が楽曲を制作するのを支援するツールを開発することができます。
- **音楽教育:** LSTM を用いて、コード進行の学習を支援するツールを開発することができます。
- **音楽ゲーム:** 自動生成されたコード進行に合わせて、プレイヤーが演奏する音楽ゲームを開発することができます。

#### 3.4.7 トラブルシューティング

- **単調なコード進行:** 生成されるコード進行が単調になる場合、学習データが不足しているか、モデルの表現力が不足している可能性があります。より多くの学習データを使用したり、より複雑なモデルを試したりすることで、改善することができます。
- **音楽理論に反するコード進行:** 生成されるコード進行が、音楽理論に反する場合、音楽理論に基づいた制約を設けることで、改善することができます。
