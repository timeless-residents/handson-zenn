## 第 2 章：AI 作曲の基礎 - 機械学習モデルの選択とデータ準備

### 2.1 AI 作曲のワークフロー - データ収集、モデル学習、生成、評価

**概要と重要性:**

AI 作曲は、機械学習の力を借りて音楽を生成する分野です。このプロセスは、まるで料理のように、素材（データ）を準備し、レシピ（モデル）を選び、調理（生成）し、味見（評価）する一連の流れで構成されます。このワークフローを理解することは、AI 作曲を成功させるための最初の、そして最も重要なステップです。

**特徴と利点:**

AI 作曲のワークフローを体系的に行うことで、以下の利点が得られます。

- **効率的な開発:** 各段階を明確にすることで、開発プロセスを効率化できます。
- **問題の特定:** 問題が発生した場合、どの段階で問題が起きているのかを特定しやすくなります。
- **再現性の確保:** 同じワークフローを繰り返すことで、再現性の高い結果を得られます。
- **改善の余地:** 各段階を評価することで、改善点を見つけやすくなります。

**事前準備と前提条件:**

- プログラミングの基礎知識（Python 推奨）
- 機械学習の基本的な概念（教師あり学習、教師なし学習）
- 音楽理論の基礎知識（音階、コード、リズム）
- MIDI ファイルの扱いに関する基礎知識

**基本的な使い方:**

AI 作曲のワークフローは、以下の 4 つの主要な段階で構成されます。

1.  **データ収集:** 既存の楽曲データや自分で作成した楽曲データを集めます。質の高いデータは、質の高い AI 作曲結果に繋がります。
2.  **モデル学習:** 集めたデータを基に、機械学習モデルを学習させます。この段階で、モデルは音楽のパターンや構造を学習します。
3.  **生成:** 学習済みのモデルを使って、新しい音楽を生成します。モデルに様々なパラメータを与えることで、異なるスタイルの音楽を生成できます。
4.  **評価:** 生成された音楽を評価し、改善点を見つけます。評価は、音楽理論の知識や個人の好みに基づいて行われます。

**実践的なテクニック:**

- **データ収集:** 様々なジャンルの音楽データを収集し、データセットを構築します。データセットの多様性は、モデルの汎化能力を高めます。
- **モデル学習:** モデルのパラメータを調整し、より良い音楽を生成できるようにします。ハイパーパラメータの調整は、モデルの性能を大きく左右します。
- **生成:** モデルに様々な制約を与えることで、特定のスタイルの音楽を生成できます。例えば、特定のコード進行やリズムパターンを指定することができます。
- **評価:** 生成された音楽を音楽理論に基づいて分析し、改善点を見つけます。例えば、コード進行の不自然さやリズムの単調さを修正することができます。

**応用例とユースケース:**

- **ゲーム音楽の自動生成:** ゲームの雰囲気に合わせた BGM を自動生成します。
- **音楽療法:** 患者の感情に合わせた音楽を生成し、精神的なケアを行います。
- **作曲支援:** 作曲家がアイデアを得るためのツールとして活用します。
- **広告音楽の作成:** 商品のイメージに合わせた短い音楽を自動生成します。

**トラブルシューティング:**

- **学習データが不足している:** より多くのデータを収集するか、データ拡張を行います。
- **モデルが過学習している:** 正則化を適用するか、モデルの複雑さを減らします。
- **生成される音楽が単調:** データセットの多様性を増やすか、モデルの学習方法を改善します。
- **生成される音楽が音楽的に不自然:** 音楽理論の知識を取り入れた損失関数を使用するか、音楽理論に基づいた制約を生成時に加えます。

**まとめと次のステップ:**

AI 作曲のワークフローは、データ収集、モデル学習、生成、評価という 4 つの段階で構成されます。各段階を理解し、実践的なテクニックを適用することで、より質の高い音楽を生成できます。次のステップでは、代表的な機械学習モデルについて詳しく解説します。

### 2.2 代表的な機械学習モデル - RNN、LSTM、Transformer

**概要と重要性:**

AI 作曲の中核となるのは、機械学習モデルです。特に、RNN（Recurrent Neural Network）、LSTM（Long Short-Term Memory）、Transformer は、音楽のような時系列データを扱うのに適しており、AI 作曲で広く利用されています。これらのモデルの特性を理解し、適切なモデルを選択することが、AI 作曲の成功に不可欠です。

**特徴と利点:**

- **RNN:** 時系列データを扱う基本的なモデルで、過去の情報を考慮しながら現在の状態を予測します。構造が単純で実装が容易ですが、長期的な依存関係を捉えるのが苦手です。
- **LSTM:** RNN の改良版で、長期的な依存関係を捉えることができます。音楽のような複雑な構造を持つデータを扱うのに適しています。
- **Transformer:** 注意機構（Attention Mechanism）を用いて、系列データ全体の文脈を考慮することができます。並列処理が可能で、学習速度が速いという利点があります。近年、音楽生成においても高い性能を発揮しています。

**事前準備と前提条件:**

- 機械学習の基本的な知識（ニューラルネットワーク、勾配降下法）
- Python のライブラリ（TensorFlow, PyTorch）の使用経験

**基本的な使い方:**

これらのモデルは、通常、音楽データを数値表現に変換したものを入力として学習します。例えば、MIDI データを音符の ID や音の強さ、演奏時間などの数値に変換し、モデルに入力します。モデルは、過去の音符の系列から次の音符を予測するように学習します。

**RNN の例 (PyTorch):**

```python
import torch
import torch.nn as nn

class RNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(RNN, self).__init__()
        self.hidden_size = hidden_size
        self.rnn = nn.RNN(input_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, output_size)

    def forward(self, x, hidden):
        out, hidden = self.rnn(x, hidden)
        out = self.fc(out[:, -1, :]) # 最後のタイムステップの出力を使用
        return out, hidden

    def init_hidden(self, batch_size):
        return torch.zeros(1, batch_size, self.hidden_size)

# 使用例
input_size = 128 # MIDIノートの数
hidden_size = 256
output_size = 128
model = RNN(input_size, hidden_size, output_size)

# データの準備（例：ランダムな入力）
batch_size = 32
sequence_length = 100
input_data = torch.randn(batch_size, sequence_length, input_size)
hidden = model.init_hidden(batch_size)

# 順伝播
output, hidden = model(input_data, hidden)
print(output.shape)  # 出力の形状を確認 (batch_size, output_size)
```

from transformers import AutoTokenizer, AutoModelForCausalLM

# モデルとトークナイザーのロード

**実践的なテクニック:**

- **埋め込み層 (Embedding Layer) の利用:** 音符の ID を直接モデルに入力するのではなく、埋め込み層を使ってより表現力の高いベクトルに変換します。
- **Attention 機構の活用:** Transformer モデルを使用する際に、Attention 機構を可視化することで、モデルがどの部分に注目しているかを理解することができます。
- **アンサンブル学習:** 複数のモデルを組み合わせることで、よりロバストな音楽生成を実現します。

**応用例とユースケース:**

- **作曲支援:** 作曲家がアイデアを得るためのツールとして、特定のコード進行やリズムパターンを生成します。
- **自動編曲:** 与えられたメロディーに対して、自動的に伴奏を生成します。
- **音楽スタイルの変換:** ある音楽スタイルから別の音楽スタイルに変換します。例えば、クラシック音楽をジャズ音楽に変換することができます。

**トラブルシューティング:**

- **学習が収束しない:** 学習率を調整するか、optimizer を変更します。
- **生成される音楽が不自然:** 学習データを増やすか、モデルの構造を改善します。
- **GPU メモリが不足する:** バッチサイズを小さくするか、より小さなモデルを使用します。

**まとめと次のステップ:**

RNN、LSTM、Transformer は、AI 作曲で広く利用されている代表的な機械学習モデルです。それぞれのモデルの特性を理解し、適切なモデルを選択することが、AI 作曲の成功に不可欠です。次のステップでは、音楽データの準備と前処理について詳しく解説します。

### 2.3 MIDI データの準備と前処理 - 音楽データの構造化

**概要と重要性:**

AI 作曲において、機械学習モデルに与える音楽データの形式は、モデルの学習効率と生成される音楽の質に大きな影響を与えます。MIDI（Musical Instrument Digital Interface）データは、音楽情報を数値で表現するための標準的な形式であり、AI 作曲におけるデータ形式として広く利用されています。MIDI データを適切に準備し、前処理することは、AI 作曲の成功に不可欠なステップです。

**特徴と利点:**

- **汎用性:** 多くの音楽ソフトウェアや楽器で利用できる標準的な形式です。
- **情報量:** 音符の高さ、音の強さ、演奏時間、楽器の種類など、音楽に関する様々な情報を含んでいます。
- **加工の容易さ:** 数値データとして扱えるため、プログラムで簡単に加工できます。

**事前準備と前提条件:**

- MIDI ファイルの基本的な知識
- Python のライブラリ（mido, music21 など）の使用経験

**基本的な使い方:**

MIDI ファイルは、イベントと呼ばれるデータ列で構成されています。各イベントは、特定の時点における音楽的なアクションを表します。例えば、"Note On"イベントは音符の発音を、"Note Off"イベントは音符の消音を表します。

**MIDI ファイルの構造:**

MIDI ファイルは通常、ヘッダとトラックで構成されます。

- **ヘッダ:** MIDI ファイルの形式、トラック数、時間分解能などの情報を含みます。
- **トラック:** 音楽データそのものを含みます。通常、1 つのトラックが 1 つの楽器パートを表します。

**MIDI データの解析 (mido):**

```python
import mido

# MIDIファイルの読み込み
midi = mido.MidiFile('example.mid')

# トラックの情報を表示
print(f"MIDIファイルには {len(midi.tracks)} 個のトラックがあります。")

# 各トラックのメッセージを解析
for i, track in enumerate(midi.tracks):
    print(f"Track {i}:")
    for msg in track:
        print(msg)
```

**実践的なテクニック:**

- **データの正規化:** 音の強さ（ベロシティ）や演奏時間などの値を 0 から 1 の範囲に正規化することで、モデルの学習を安定させることができます。
- **音符の量子化:** 演奏時間の微妙なずれを修正するために、音符の開始時間と終了時間を一定の間隔に量子化します。
- **音楽理論に基づいたデータの拡張:** コード進行やスケールなどの音楽理論に基づいた情報を MIDI データに追加することで、モデルが音楽的な構造を学習しやすくなります。
- **休符の表現:** 休符を特別な音符として表現することで、モデルが音楽的なフレーズを学習しやすくなります。

**応用例とユースケース:**

- **MIDI データからの音楽スタイルの抽出:** MIDI データからコード進行やリズムパターンなどの特徴を抽出し、音楽スタイルの分類や生成に利用します。
- **MIDI データからの自動採譜:** MIDI データから楽譜を自動的に生成します。
- **MIDI データを用いた音楽教育:** MIDI データを使って、音楽理論や演奏技術を学習します。

**トラブルシューティング:**

- **MIDI ファイルが読み込めない:** MIDI ファイルの形式が正しいか確認します。
- **MIDI データの解釈が難しい:** MIDI ファイルの仕様書を参照するか、専門家に相談します。
- **データの前処理に時間がかかる:** より効率的なアルゴリズムを使用するか、並列処理を行います。

**まとめと次のステップ:**

MIDI データは、AI 作曲における重要なデータ形式です。MIDI データを適切に準備し、前処理することで、モデルの学習効率と生成される音楽の質を向上させることができます。次のステップでは、Python による MIDI データ解析の実装例について詳しく解説します。

### 2.4 実装例：Python による MIDI データ解析

**概要と重要性:**

このセクションでは、Python のライブラリ `mido` を使用して MIDI データを解析する具体的な実装例を紹介します。実際にコードを動かすことで、MIDI データの構造と扱い方をより深く理解することができます。

**特徴と利点:**

- **実践的なコード:** 実際に動作するコードを通して、MIDI データの解析方法を学ぶことができます。
- **段階的な説明:** コードの各部分について、丁寧に解説します。
- **応用可能なテクニック:** 紹介するテクニックは、様々な AI 作曲プロジェクトに応用できます。

**事前準備と前提条件:**

まずは、MIDI ファイルを読み込み、基本的な情報を表示するコードを見てみましょう。

**MIDI メッセージの解析:**

MIDI メッセージは、様々な種類があります。代表的なメッセージの種類とその意味は以下の通りです。

- `Note On`: 音符の発音
- `Note Off`: 音符の消音
- `Control Change`: コントロールチェンジ（音量、パン、エクスプレッションなど）
- `Program Change`: 楽器の変更
- `Pitch Wheel`: ピッチベンド

各メッセージには、それぞれ固有の属性があります。例えば、`Note On`メッセージには、`note`（音符の高さ）、`velocity`（音の強さ）、`channel`（チャンネル）などの属性があります。

```python
import mido

midi = mido.MidiFile('example.mid')

for i, track in enumerate(midi.tracks):
    print(f"Track {i}: {track.name}")
    for msg in track:
        if msg.type == 'note_on':
            print(f"  Note On: 音符={msg.note}, 強さ={msg.velocity}, チャンネル={msg.channel}, 時間={msg.time}") # 時間は前のメッセージからの経過時間
        elif msg.type == 'note_off':
            print(f"  Note Off: 音符={msg.note}, 強さ={msg.velocity}, チャンネル={msg.channel}, 時間={msg.time}")
        elif msg.type == 'control_change':
            print(f"  Control Change: コントロール={msg.control}, 値={msg.value}, チャンネル={msg.channel}, 時間={msg.time}")
        elif msg.type == 'program_change':
            print(f"  Program Change: プログラム={msg.program}, チャンネル={msg.channel}, 時間={msg.time}")
```

**実践的なテクニック:**

- **音符の抽出:** MIDI データから音符の系列を抽出し、機械学習モデルの学習データとして利用します。
- **コード進行の解析:** MIDI データからコード進行を解析し、音楽スタイルの分類や生成に利用します。
- **リズムパターンの解析:** MIDI データからリズムパターンを解析し、音楽のリズム感を学習します。

**音符の抽出例:**

```python
import mido

def extract_notes(midi_file):
    """MIDIファイルから音符のリストを抽出する関数"""
    midi = mido.MidiFile(midi_file)
    notes = []
    time = 0
    for track in midi.tracks:
        for msg in track:
            time += msg.time # 経過時間を加算

            if msg.type == 'note_on' and msg.velocity > 0: # velocity > 0 で Note On を判定
                notes.append({'note': msg.note, 'time': time, 'duration': 0}) # 音符情報を追加
            elif msg.type == 'note_off' or (msg.type == 'note_on' and msg.velocity == 0): # velocity == 0 も Note Off
                # 対応する Note On を探す
                for note in reversed(notes):
                    if note['note'] == msg.note and note['duration'] == 0:
                        note['duration'] = time - note['time'] # 音符の長さを計算
                        break
    return notes

# 音符の抽出
notes = extract_notes('example.mid')

# 音符の情報を表示
for note in notes:
    print(f"音符={note['note']}, 開始時間={note['time']}, 長さ={note['duration']}")
```

**応用例とユースケース:**

- **音楽ゲームの譜面データ生成:** MIDI データから音楽ゲームの譜面データを自動的に生成します。
- **自動伴奏生成:** 与えられたメロディーに対して、MIDI データを使って自動的に伴奏を生成します。
- **音楽教育ツール:** MIDI データを使って、音楽理論や演奏技術を学習するためのツールを開発します。

**トラブルシューティング:**

- **`mido` ライブラリがインストールできない:** `pip` のバージョンが古い可能性があります。`pip install --upgrade pip` で `pip` を更新してから、再度 `pip install mido` を実行してください。
- **MIDI ファイルが正しく読み込めない:** MIDI ファイルの形式が正しいか確認してください。また、`mido` が対応していない形式の MIDI ファイルである可能性もあります。
- **音符の抽出結果が正しくない:** MIDI ファイルに誤った情報が含まれている可能性があります。また、音符の抽出アルゴリズムに誤りがある可能性もあります。
