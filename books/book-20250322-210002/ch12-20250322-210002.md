## 第 12 章：MIDI データセットの作成と管理 - 音楽データの宝庫を築く

音楽 AI の世界に足を踏み入れたなら、MIDI データセットの重要性は避けて通れません。優れた音楽 AI モデルを育てるには、高品質な学習データが不可欠です。この章では、MIDI データセットの作成から管理まで、実践的な知識とテクニックを余すことなく伝授します。初心者から上級者まで、あらゆるレベルの読者にとって有益な情報を提供することを目指します。

### 12.1 MIDI データセットの重要性 - 学習データの質が AI の質を決定

#### 12.1.1 概要と重要性

音楽 AI、特に作曲支援、自動編曲、スタイル変換などのタスクにおいて、MIDI データセットは文字通り「血液」と言えるでしょう。AI モデルは、大量の MIDI データから音楽の構造、パターン、スタイルを学習し、それに基づいて新しい音楽を生成したり、既存の音楽を分析したりします。

しかし、学習データの質が低いと、AI モデルは期待通りのパフォーマンスを発揮できません。ノイズが多いデータ、不正確なデータ、偏ったデータは、AI モデルの学習を妨げ、創造性や汎化性能を著しく低下させる可能性があります。

#### 12.1.2 特徴と利点

高品質な MIDI データセットは、以下のような特徴と利点をもたらします。

- **高い精度:** 正確な音符情報、タイミング情報、ベロシティ情報が含まれている。
- **多様性:** さまざまなジャンル、スタイル、楽器構成の音楽が含まれている。
- **網羅性:** 音楽の構造、パターン、スタイルを学習するために十分なデータ量がある。
- **汎用性:** さまざまな AI モデル、タスク、アプリケーションに適用可能。
- **再現性:** 学習プロセスを再現可能にするために、データの取得方法、クリーニング方法、オーギュメンテーション方法が明確に記録されている。

#### 12.1.3 事前準備と前提条件

このセクションの内容を実践するには、以下の準備が必要です。

- **MIDI の基礎知識:** 音符、ベロシティ、デュレーションなどの MIDI の基本的な概念を理解していること。
- **プログラミングスキル:** Python などのプログラミング言語を使って、MIDI データを操作できること（必須ではありませんが、あると便利です）。
- **MIDI 編集ソフト:** MuseScore, REAPER, Logic Pro X などの MIDI 編集ソフトを使用できること（データの確認や修正に役立ちます）。
- **Python ライブラリ:** `mido`, `pretty_midi`などの Python ライブラリをインストールしておくこと（MIDI データの読み書き、解析に必要です）。
- `pip install mido pretty_midi`

#### 12.1.4 基本的な使い方

Python で MIDI データを読み込む基本的な例を示します。

```python
import mido

# MIDIファイルの読み込み
mid = mido.MidiFile('example.mid')

# トラックごとのメッセージを表示
for i, track in enumerate(mid.tracks):
    print(f"Track {i}: {track.name}")
    for msg in track:
        print(msg)
```

このコードは、`example.mid`という MIDI ファイルを読み込み、各トラックに含まれる MIDI メッセージを表示します。`mido`ライブラリを使うことで、MIDI ファイルを簡単に操作できます。

#### 12.1.5 実践的なテクニック

高品質な MIDI データセットを作成するために、以下のテクニックを実践しましょう。

- **メタデータの重要性:** 曲名、作曲者、ジャンル、テンポなどのメタデータを整理し、データセットに含める。
- **データの形式統一:** MIDI ファイルの形式（SMF0, SMF1）や解像度を統一する。
- **バージョンの管理:** データセットの変更履歴を記録し、バージョン管理システム（Git など）を利用する。

#### 12.1.6 応用例とユースケース

高品質な MIDI データセットは、以下のような応用例やユースケースで活用できます。

- **作曲支援 AI:** ユーザーが入力したメロディやコード進行に基づいて、自動的に伴奏を生成する。
- **自動編曲 AI:** 既存の楽曲を、異なるジャンルやスタイルに編曲する。
- **音楽スタイル変換 AI:** あるアーティストのスタイルを学習し、別のアーティストの楽曲に適用する。
- **音楽教育:** MIDI データを使って、音楽理論や作曲技法を教えるための教材を作成する。

#### 12.1.7 トラブルシューティング

MIDI データの処理でよく遭遇するトラブルとその解決策を紹介します。

- **文字化け:** MIDI ファイルが Unicode でエンコードされていない場合、文字化けが発生することがあります。`encoding='utf-8'`などのパラメータを指定してファイルを読み込んでみてください。
- **ライブラリのエラー:** ライブラリのバージョンが古い場合、エラーが発生することがあります。最新バージョンにアップデートしてみてください。
- **MIDI ファイル形式:** 対応していない MIDI ファイル形式の場合、読み込みエラーが発生することがあります。MIDI 編集ソフトで SMF0 または SMF1 形式で保存し直してみてください。

### 12.2 MIDI データ収集 - 公開データセット、スクレイピング、自作

#### 12.2.4 基本的な使い方

**スクレイピング:**

以下のコードは、特定のウェブサイトから MIDI ファイルをダウンロードする例です。

```python
import requests
from bs4 import BeautifulSoup
import os

url = 'http://example.com/midi-files'  # 例：MIDIファイルが置いてあるウェブサイトのURL
response = requests.get(url)
soup = BeautifulSoup(response.content, 'html.parser')

# MIDIファイルのリンクを抽出
midi_links = [a['href'] for a in soup.find_all('a', href=True) if a['href'].endswith('.mid')]

# MIDIファイルをダウンロード
for link in midi_links:
    midi_url = url + '/' + link if not link.startswith('http') else link  # 絶対URLでない場合に備える
    midi_response = requests.get(midi_url)

    # ファイル名を取得
    file_name = os.path.basename(link)

    # ファイルを保存
    with open(file_name, 'wb') as f:
        f.write(midi_response.content)

    print(f"Downloaded: {file_name}")
```

### 12.3 MIDI データクリーニング - ノイズ除去、エラー修正

#### 12.3.1 概要と重要性

MIDI データセットの質を向上させるために、データクリーニングは不可欠なプロセスです。収集した MIDI データには、ノイズやエラーが含まれていることが多く、そのまま学習データとして使用すると、AI モデルの精度を低下させる可能性があります。

#### 12.3.2 特徴と利点

- **精度の向上:** ノイズやエラーを除去することで、MIDI データの精度を高めることができます。
- **効率の向上:** データクリーニングを行うことで、AI モデルの学習効率を向上させることができます。
- **汎化性能の向上:** クリーニングされたデータセットを使用することで、AI モデルの汎化性能を向上させることができます。

#### 12.3.3 事前準備と前提条件

- **MIDI 編集ソフト:** MuseScore, REAPER, Logic Pro X などの MIDI 編集ソフトを使用できること（データの確認や修正に役立ちます）。
- **Python ライブラリ:** `mido`, `pretty_midi`などの Python ライブラリをインストールしておくこと（MIDI データの読み書き、解析に必要です）。
- **音楽理論の知識:** 音楽理論の知識があると、エラーの特定や修正が容易になります。

#### 12.3.4 基本的な使い方

MIDI データをクリーニングする基本的な例を示します。

```python
import mido

def clean_midi(input_file, output_file):
    """
    MIDIファイルをクリーニングする関数。
    内容：
    - ベロシティが0のノートオンメッセージを削除
    - デュレーションが極端に短いノートを削除
    """
    mid = mido.MidiFile(input_file)

    for track in mid.tracks:
        messages_to_remove = []
        for i, msg in enumerate(track):
            if msg.type == 'note_on' and msg.velocity == 0:
                # ベロシティが0のノートオンメッセージはノートオフと同じ意味なので削除
                messages_to_remove.append(msg)
            elif msg.type == 'note_on':
                # 極端に短いノートを削除（例：1ティック未満）
                next_msg = track[i+1] if i+1 < len(track) else None
                if next_msg and next_msg.type == 'note_off' and next_msg.note == msg.note and next_msg.time <= 1:
                    messages_to_remove.append(msg)
                    messages_to_remove.append(next_msg)

        for msg in messages_to_remove:
            track.remove(msg)

    mid.save(output_file)

# 例：
clean_midi('input.mid', 'output.mid')
```

#### 12.3.5 実践的なテクニック

- **ベロシティの正規化:** ベロシティの値を 0 から 127 の範囲に正規化する。
- **デュレーションの調整:** 音符のデュレーションを適切な長さに調整する。
- **タイミングの修正:** 音符のタイミングを修正し、リズム感を改善する。
- **不要なメッセージの削除:** コントロールチェンジメッセージ、システムエクスクルーシブメッセージなど、不要なメッセージを削除する。
- **音域の制限:** 学習対象の楽器の音域に合わせて、音域外の音符を削除する。

#### 12.3.6 応用例とユースケース

- **自動作曲 AI:** クリーニングされた MIDI データを使って、より自然で美しい音楽を生成する。
- **音楽スタイル変換 AI:** クリーニングされた MIDI データを使って、より正確なスタイル変換を行う。
- **音楽教育:** クリーニングされた MIDI データを使って、より効果的な音楽教材を作成する。

#### 12.3.7 トラブルシューティング

- **データの損失:** クリーニング処理によって、重要なデータが失われる可能性があります。クリーニング処理を行う前に、必ずバックアップを作成してください。
- **処理速度の低下:** 大量の MIDI データをクリーニングする場合、処理に時間がかかることがあります。処理を高速化するために、並列処理などの技術を活用しましょう。
- **MIDI ファイルの破損:** クリーニング処理によって、MIDI ファイルが破損する可能性があります。処理後に、必ず MIDI ファイルが正常に読み込めることを確認してください。

### 12.4 データオーギュメンテーション - データ量を増やして汎化性能向上

#### 12.4.1 概要と重要性

データオーギュメンテーションは、既存のデータセットを加工・変形して、データ量を人工的に増やすテクニックです。MIDI データセットの場合、ピッチのシフト、テンポの変更、音符の追加・削除など、様々な方法でデータを増やすことができます。データオーギュメンテーションは、AI モデルの汎化性能を向上させるために非常に有効な手段です。

#### 12.4.2 特徴と利点

- **データ量の増加:** 既存のデータセットから、何倍ものデータを作成することができます。
- **汎化性能の向上:** 多様なデータで学習することで、AI モデルの汎化性能を向上させることができます。
- **過学習の抑制:** データ量を増やすことで、AI モデルの過学習を抑制することができます。
- **コスト削減:** 新しいデータを収集するよりも、低コストでデータ量を増やすことができます。

#### 12.4.3 事前準備と前提条件

- **Python ライブラリ:** `mido`, `pretty_midi`などの Python ライブラリをインストールしておくこと（MIDI データの読み書き、解析に必要です）。
- **音楽理論の知識:** 音楽理論の知識があると、自然な音楽的な変形を行うことができます。
- **実験環境:** オーギュメンテーションの効果を検証するために、実験環境を用意することが望ましいです。

#### 12.4.4 基本的な使い方

MIDI データをオーギュメントする基本的な例を示します。

```python
import mido
import random

def augment_midi(input_file, output_file, pitch_shift=0, tempo_scale=1.0):
    """
    MIDIファイルをオーギュメントする関数。
    内容：
    - ピッチシフト
    - テンポの変更
    """
    mid = mido.MidiFile(input_file)

    for track in mid.tracks:
        for msg in track:
            if msg.type == 'note_on' or msg.type == 'note_off':
                msg.note += pitch_shift
                if msg.note < 0:
                    msg.note = 0
                elif msg.note > 127:
                    msg.note = 127
            elif msg.type == 'set_tempo':
                msg.tempo = int(msg.tempo * tempo_scale)

    mid.save(output_file)

# 例：
# ランダムなピッチシフト（-5から+5半音）
pitch_shift = random.randint(-5, 5)
# ランダムなテンポスケール（0.8から1.2倍）
tempo_scale = random.uniform(0.8, 1.2)

augment_midi('input.mid', 'output.mid', pitch_shift=pitch_shift, tempo_scale=tempo_scale)
```

#### 12.4.5 実践的なテクニック

- **ピッチシフト:** 音符のピッチを一定量シフトさせる。
- **テンポの変更:** 楽曲のテンポを一定量変更する。
- **音符の追加・削除:** ランダムに音符を追加したり、削除したりする。
- **楽器の変更:** 音色を変更する。
