## 11. ファイル入出力：タートルでデータを永続化する

タートルグラフィックスで描いた美しい絵や、タートルを使ったゲームのスコア。せっかく作ったものを、プログラムを終了するたびに失ってしまうのはもったいないですよね。そこで重要なのが、ファイル入出力の技術です。ファイルにデータを保存しておけば、いつでも再利用できます。本章では、タートルグラフィックスと組み合わせて、テキストファイル、CSVファイル、JSONファイルという3種類のファイル形式を扱い、データを永続化する方法を解説します。

### 11.1 テキストファイルの読み書き：スコアの保存、設定ファイルの読み込み

#### 11.1.1 概要と重要性

テキストファイルは、人間が読める形式でデータを保存できる最も基本的なファイル形式です。設定ファイルやログファイル、単純なデータリストなど、さまざまな用途に利用できます。タートルグラフィックスでは、例えばゲームのハイスコアや、タートルの初期位置、色などを保存するために使用できます。

#### 11.1.2 特徴と利点

*   **可読性:** テキストエディタで簡単に内容を確認・編集できます。
*   **汎用性:** ほとんどの環境で利用可能です。
*   **単純さ:** 構造がシンプルで扱いやすいです。

#### 11.1.3 事前準備と前提条件

Pythonの基本的な構文とタートルグラフィックスの基本的な使い方が理解できていることが前提となります。

#### 11.1.4 基本的な使い方

**書き込み (スコアの保存):**

```python
def save_score(score, filename="score.txt"):
  """スコアをテキストファイルに保存する"""
  try:
    with open(filename, "w") as f:  # "w": 書き込みモード
      f.write(str(score))
    print(f"スコア {score} を {filename} に保存しました。")
  except IOError as e:
    print(f"エラー: ファイル {filename} への書き込みに失敗しました: {e}")

# 例:
score = 100
save_score(score)  # score.txtに保存
```

**読み込み (ハイスコアの読み込み):**

```python
def load_score(filename="score.txt"):
  """テキストファイルからスコアを読み込む"""
  try:
    with open(filename, "r") as f:  # "r": 読み込みモード
      score = int(f.read())
    print(f"{filename} からスコア {score} を読み込みました。")
    return score
  except FileNotFoundError:
    print(f"エラー: ファイル {filename} が見つかりません。")
    return 0  # ファイルがない場合は0を返す
  except ValueError:
    print(f"エラー: ファイル {filename} の内容が不正です (数値ではありません)。")
    return 0  # ファイルの内容が数値でない場合は0を返す
  except IOError as e:
    print(f"エラー: ファイル {filename} の読み込みに失敗しました: {e}")
    return 0

# 例:
highscore = load_score()
print(f"ハイスコア: {highscore}")
```

`with open(...) as f:` は、ファイルを開いて、処理が終わったら自動的にファイルを閉じる構文です。これにより、ファイルが開きっぱなしになることを防ぎ、安全にファイルを操作できます。 `"w"` は書き込みモード、 `"r"` は読み込みモードを指定します。

#### 11.1.5 実践的なテクニック

*   **複数行の書き込み:** リストや辞書の内容を書き込む場合は、改行文字 (`\n`) を使って区切ると、読みやすい形式で保存できます。
*   **エンコーディングの指定:** 日本語などの文字を含むファイルを扱う場合は、`encoding="utf-8"` などを指定して、文字化けを防ぎます。

```python
def save_settings(settings, filename="settings.txt"):
  """設定をテキストファイルに保存する (1行に1設定)"""
  try:
    with open(filename, "w", encoding="utf-8") as f:
      for key, value in settings.items():
        f.write(f"{key}:{value}\n")  # キーと値をコロンで区切り、改行
    print(f"設定を {filename} に保存しました。")
  except IOError as e:
    print(f"エラー: ファイル {filename} への書き込みに失敗しました: {e}")

def load_settings(filename="settings.txt"):
  """テキストファイルから設定を読み込む (1行に1設定)"""
  settings = {}
  try:
    with open(filename, "r", encoding="utf-8") as f:
      for line in f:
        key, value = line.strip().split(":", 1)  # コロンで区切る (最大1回)
        settings[key] = value
    print(f"設定を {filename} から読み込みました。")
    return settings
  except FileNotFoundError:
    print(f"エラー: ファイル {filename} が見つかりません。")
    return {}
  except ValueError:
    print(f"エラー: ファイル {filename} の内容が不正です (キーと値の形式ではありません)。")
    return {}
  except IOError as e:
    print(f"エラー: ファイル {filename} の読み込みに失敗しました: {e}")
    return {}

# 例:
settings = {"turtle_color": "red", "screen_size": "800x600", "difficulty": "hard"}
save_settings(settings)
loaded_settings = load_settings()
print(f"読み込まれた設定: {loaded_settings}")
```

#### 11.1.6 応用例とユースケース

*   **ゲームの設定保存:** プレイヤーの好み（色、音量、操作方法など）を保存する。
*   **ログファイルの記録:** プログラムの実行状況を記録し、デバッグに役立てる。
*   **タートルの軌跡の保存:** タートルの移動履歴を保存し、後で再生する。

#### 11.1.7 トラブルシューティング

*   **FileNotFoundError:** ファイルが存在しない場合は、ファイル名が正しいか、ファイルが正しい場所に保存されているかを確認してください。
*   **PermissionError:** ファイルへのアクセス権がない場合は、プログラムを実行するユーザーに適切な権限を与えてください。
*   **エンコーディングエラー:** 文字化けが発生する場合は、ファイルのエンコーディングを正しく指定してください (UTF-8 が推奨)。

#### 11.1.8 まとめと次のステップ

テキストファイルは、シンプルながらも非常に強力なデータ保存方法です。ハイスコアや設定など、簡単なデータの永続化に最適です。次は、より構造的なデータを扱うのに適したCSVファイルについて学びましょう。

### 11.2 CSVファイルの読み書き：データの保存、分析

#### 11.2.1 概要と重要性

CSV (Comma Separated Values) ファイルは、表形式のデータを保存するために広く使われるファイル形式です。各行がレコードを表し、各レコード内のフィールドはカンマで区切られます。スプレッドシートソフト（Excelなど）との互換性が高く、データのインポート/エクスポートによく利用されます。タートルグラフィックスでは、例えば複数のタートルの位置情報を保存したり、シミュレーションの結果を保存したりするのに役立ちます。

#### 11.2.2 特徴と利点

*   **構造化されたデータ:** 表形式でデータを保存できるため、整理しやすいです。
*   **互換性:** スプレッドシートソフトで簡単に開くことができます。
*   **扱いやすさ:** Pythonのcsvモジュールを使うことで、簡単に読み書きできます。

#### 11.2.3 事前準備と前提条件

Pythonのcsvモジュールを使用します。`import csv` でインポートしておきましょう。

#### 11.2.4 基本的な使い方

**書き込み (タートルの位置情報の保存):**

```python
import csv

def save_turtle_positions(positions, filename="turtle_positions.csv"):
  """タートルの位置情報をCSVファイルに保存する"""
  try:
    with open(filename, "w", newline="") as f:
      writer = csv.writer(f)
      writer.writerow(["x", "y"])  # ヘッダー行
      writer.writerows(positions)  # 複数の行を一度に書き込む
    print(f"タートルの位置情報を {filename} に保存しました。")
  except IOError as e:
    print(f"エラー: ファイル {filename} への書き込みに失敗しました: {e}")

# 例:
turtle_positions = [(100, 50), (-50, 0), (0, 100)]
save_turtle_positions(turtle_positions)
```

**読み込み (タートルの位置情報の読み込み):**

```python
import csv

def load_turtle_positions(filename="turtle_positions.csv"):
  """CSVファイルからタートルの位置情報を読み込む"""
  positions = []
  try:
    with open(filename, "r") as f:
      reader = csv.reader(f)
      next(reader)  # ヘッダー行をスキップ
      for row in reader:
        x = int(row[0])
        y = int(row[1])
        positions.append((x, y))
    print(f"タートルの位置情報を {filename} から読み込みました。")
    return positions
  except FileNotFoundError:
    print(f"エラー: ファイル {filename} が見つかりません。")
    return []
  except ValueError:
    print(f"エラー: ファイル {filename} の内容が不正です (数値ではありません)。")
    return []
  except IOError as e:
    print(f"エラー: ファイル {filename} の読み込みに失敗しました: {e}")
    return []

# 例:
loaded_positions = load_turtle_positions()
print(f"読み込まれたタートルの位置情報: {loaded_positions}")
```

`csv.writer()` でCSVライターオブジェクトを作成し、`writerow()` で1行ずつ書き込みます。`writerows()` を使うと、複数の行をまとめて書き込むことができます。`csv.reader()` でCSVリーダーオブジェクトを作成し、`for` ループで1行ずつ読み込みます。`next(reader)` は、ヘッダー行をスキップするために使います。`newline=""` は、改行コードの処理を調整するために指定します (特にWindows環境で重要)。

#### 11.2.5 実践的なテクニック

*   **区切り文字の指定:** デフォルトではカンマが区切り文字ですが、`delimiter=";"` のように指定することで、セミコロンなどの別の文字を区切り文字として使用できます。
*   **引用符の扱い:** 文字列にカンマが含まれる場合は、引用符で囲む必要があります。`quotechar='"'` と `quoting=csv.QUOTE_MINIMAL` を指定することで、引用符の扱いを制御できます。
*   **辞書形式での読み書き:** `csv.DictReader` と `csv.DictWriter` を使うと、ヘッダー行に基づいて、辞書形式でデータを読み書きできます。

```python
import csv

def save_turtle_data(turtle_data, filename="turtle_data.csv"):
    """タートルのデータをCSVファイルに辞書形式で保存する"""
    fieldnames = ["name", "x", "y", "color"]
    try:
        with open(filename, "w", newline="") as csvfile:
            writer = csv.DictWriter(csvfile, fieldnames=fieldnames)
            writer.writeheader()  # ヘッダー行の書き込み
            writer.writerows(turtle_data)
        print(f"タートルのデータを {filename} に保存しました。")
    except IOError as e:
        print(f"エラー: ファイル {filename} への書き込みに失敗しました: {e}")

def load_turtle_data(filename="turtle_data.csv"):
    """CSVファイルからタートルのデータを辞書形式で読み込む"""
    turtle_data = []
    try:
        with open(filename, "r", newline="") as csvfile:
            reader = csv.DictReader(csvfile)
            for row in reader:
                turtle_data.append(row)
        print(f"タートルのデータを {filename} から読み込みました。")
        return turtle_data
    except FileNotFoundError:
        print(f"エラー: ファイル {filename} が見つかりません。")
        return []
    except IOError as e:
        print(f"エラー: ファイル {filename} の読み込みに失敗しました: {e}")
        return []

# 例:
turtle_data = [
    {"name": "turtle1", "x": 100, "y": 50, "color": "red"},
    {"name": "turtle2", "x": -50, "y": 0, "color": "blue"},
    {"name": "turtle3", "x": 0, "y": 100, "color": "green"}
]

save_turtle_data(turtle_data)
loaded_turtle_data = load_turtle_data()
print(f"読み込まれたタートルのデータ: {loaded_turtle_data}")

```

#### 11.2.6 応用例とユースケース

*   **シミュレーション結果の保存:** タートルを使ったシミュレーションの結果（位置、速度、色など）を保存し、後で分析する。
*   **データの可視化:** 保存したデータをスプレッドシートソフトで開き、グラフを作成して可視化する。
*   **データの交換:** 異なるプログラム間でデータを交換する。

#### 11.2.7 トラブルシューティング

*   **UnicodeDecodeError:** エンコーディングの問題が発生した場合は、`encoding="utf-8"` などを指定してください。
*   **ValueError:** ファイルの内容が数値として解釈できない場合は、データ型を確認してください。
*   **フィールド数の不一致:** 書き込み時にフィールド数が一致しない場合は、ヘッダー行を確認してください。

#### 11.2.8 まとめと次のステップ

CSVファイルは、表形式のデータを効率的に保存・管理できる便利なファイル形式です。タートルグラフィックスと組み合わせることで、シミュレーション結果やタートルの情報を簡単に保存・分析できます。次は、より複雑な構造を持つデータを扱うのに適したJSONファイルについて学びましょう。

### 11.3 JSONファイルの読み書き：設定ファイルの保存、APIデータの保存

#### 11.3.1 概要と重要性

JSON (JavaScript Object Notation) ファイルは、構造化されたデータを表現するための軽量なファイル形式です。キーと値のペアを持つ辞書や、リストなどのデータ構造を表現できます。設定ファイルやAPIからのレスポンスなど、複雑なデータを扱うのに適しています。タートルグラフィックスでは、例えば複数のタートルの詳細な情報（名前、位置、色、形など）をまとめて保存したり、ゲームの設定を保存したりするのに役立ちます。

#### 11.3.2 特徴と利点

*   **構造化されたデータ:** 複雑なデータ構造を表現できます。
*   **可読性:** 人間が読める形式で、構造がわかりやすいです。
*   **汎用性:** 多くのプログラミング言語でサポートされています。
*   **柔軟性:** データ構造を自由に変更できます。

#### 11.3.3 事前準備と前提条件

Pythonのjsonモジュールを使用します。`import json` でインポートしておきましょう。

#### 11.3.4 基本的な使い方

**書き込み (タートルの詳細情報の保存):**

```python
import json

def save_turtle_details(turtle_data, filename="turtle_details.json"):
  """タートルの詳細情報をJSONファイルに保存する"""
  try:
    with open(filename, "w") as f:
      json.dump(turtle_data, f, indent=4)  # インデント付きで書き込む
    print(f"タートルの詳細情報を {filename} に保存しました。")
  except IOError as e:
    print(f"エラー: ファイル {filename} への書き込みに失敗しました: {e}")

# 例:
turtle_data = {
  "turtle1": {"x": 100, "y": 50, "color": "red", "shape": "turtle"},
  "turtle2": {"x": -50, "y": 0, "color": "blue", "shape": "arrow"},
  "turtle3": {"x": 0, "y": 100, "color": "green", "shape": "circle"}
}

save_turtle_details(turtle_data)
```

**読み込み (タートルの詳細情報の読み込み):**

```python
import json

def load_turtle_details(filename="turtle_details.json"):
  """JSONファイルからタートルの詳細情報を読み込む"""
  try:
    with open(filename, "r") as f:
      turtle_data = json.load(f)
    print(f"タートルの詳細情報を {filename} から読み込みました。")
    return turtle_data
  except FileNotFoundError:
    print(f"エラー: ファイル {filename} が見つかりません。")
    return {}
  except json.JSONDecodeError:
    print(f"エラー: ファイル {filename} の内容が不正です (JSON形式ではありません)。")
    return {}
  except IOError as e:
    print(f"エラー: ファイル {filename} の読み込みに失敗しました: {e}")
    return {}

# 例:
loaded_turtle_data = load_turtle_details()
print(f"読み込まれたタートルの詳細情報: {loaded_turtle_data}")
```

`json.dump()` でJSON形式で書き込みます。`indent=4` を指定すると、見やすいようにインデントを付けて書き込むことができます。`json.load()` でJSON形式のデータを読み込みます。

#### 11.3.5 実践的なテクニック

*   **複雑なデータ構造の保存:** リスト、辞書、ネストされたデータ構造など、複雑なデータをJSON形式で保存できます。
*   **カスタムオブジェクトのシリアライズ:**  自作のクラスのオブジェクトをJSON形式で保存するには、`default` 引数を使ってシリアライズ処理をカスタマイズする必要があります。
*   **読み込み時のエラー処理:** `try-except` ブロックを使って、JSONファイルの形式が不正な場合のエラーを適切に処理します。

```python
import json
import turtle

class ColorfulTurtle:
    def __init__(self, name, color, shape="turtle"):
        self.name = name
        self.color = color
        self.shape = shape

    def to_dict(self):
        return {"name": self.name, "color": self.color, "shape": self.shape}

def save_turtle_objects(turtles, filename="turtle_objects.json"):
    """タートルオブジェクトをJSONファイルに保存する"""
    try:
        with open(filename, "w") as f:
            turtle_list = [t.to_dict() for t in turtles]
            json.dump(turtle_list, f, indent=4)
        print(f"タートルオブジェクトを {filename} に保存しました。")
    except IOError as e:
        print(f"エラー: ファイル {filename} への書き込みに失敗しました: {e}")


def load_turtle_objects(filename="turtle_objects.json"):
    """JSONファイルからタートルオブジェクトを読み込む"""
    turtle_objects = []
    try:
        with open(filename, "r") as f:
            turtle_data = json.load(f)
            for data in turtle_data:
                new_turtle = ColorfulTurtle(data["name"], data["color"], data["shape"])
                turtle_objects.append(new_turtle)
        print(f"タートルオブジェクトを {filename} から読み込みました。")
        return turtle_objects
    except FileNotFoundError:
        print(f"エラー: ファイル {filename} が見つかりません。")
        return []
    except json.JSONDecodeError:
        print(f"エラー: ファイル {filename} の内容が不正です (JSON形式ではありません)。")
        return []
    except IOError as e:
        print(f"エラー: ファイル {filename} の読み込みに失敗しました: {e}")
        return []

# 例:
t1 = ColorfulTurtle("Leo", "red")
t2 = ColorfulTurtle("Mike", "blue", "circle")
t3 = ColorfulTurtle("Don", "purple", "arrow")

save_turtle_objects([t1, t2, t3])
loaded_turtles = load_turtle_objects()

if loaded_turtles:
    for turtle in loaded_turtles:
        print(f"Name: {turtle.name}, Color: {turtle.color}, Shape: {turtle.shape}")
```

#### 11.3.6 応用例とユースケース

*   **ゲームの設定保存:** ゲームの難易度、サウンド設定、キー割り当てなど、複雑な設定を保存する。
*   **APIデータの保存:** Web APIから取得したデータを保存し、後で分析や処理を行う。
*   **タートルグラフィックスのシーンの保存:** 複数のタートルの情報や背景色、その他の描画設定をまとめて保存し、後で再現する。

#### 11.3.7 トラブルシューティング

*   **JSONDecodeError:** JSONファイルの形式が不正な場合は、JSON Validatorなどのツールを使って、構文エラーをチェックしてください。
*   **UnicodeEncodeError:** 日本語などの文字を含むデータを書き込む際にエラーが発生する場合は、`ensure_ascii=False` を指定してください。
*   **TypeError:** 保存できないオブジェクトをJSON形式で保存しようとした場合は、`default` 引数を使ってシリアライズ処理をカスタマイズしてください。

#### 11.3.8 まとめと次のステップ

JSONファイルは、複雑な構造を持つデータを柔軟に保存・管理できる強力なファイル形式です。タートルグラフィックスと組み合わせることで、ゲームの設定やタートルの詳細な情報を簡単に保存・再現できます。

本章では、テキストファイル、CSVファイル、JSONファイルの3種類のファイル形式について学びました。それぞれのファイル形式には、得意なことと苦手なことがあります。データの種類や用途に合わせて、適切なファイル形式を選択することが重要です。

次のステップとしては、データベースとの連携について学ぶことをお勧めします。データベースを使うと、大量のデータを効率的に管理・検索することができます。
