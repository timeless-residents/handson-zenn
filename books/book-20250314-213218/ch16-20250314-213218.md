# 16. 実践プロジェクト：Python Turtleを使ったデータビジュアライゼーションツール

データに隠れたパターンや傾向を視覚的に表現するため、Pythonの標準ライブラリである`turtle`を利用したデータビジュアライゼーションツールを作成します。このプロジェクトは、初心者から上級者まで、データ分析や教育目的で役立つ内容となっています。

---

## 1. プロジェクト概要

### 1.1 目的と重要性

- **データビジュアライゼーションの必要性:**  
  膨大なデータから意味を抽出するために、視覚的なアプローチが非常に効果的です。  
- **Python Turtleの利点:**  
  アニメーションを伴う動的な描画が可能で、変化や関係性を直感的に理解しやすくなります。

### 1.2 ツールの特徴

- **視覚的アニメーション:** Turtleの動作を活かし、データ変化の流れをアニメーションで表現。
- **多様なグラフ形式:** 折れ線グラフ、散布図、棒グラフ、円グラフなど複数のチャートを生成。
- **柔軟なカスタマイズ:** 色、形状、描画速度などをユーザが自由に設定可能。
- **モジュール性:** 各機能を独立モジュールとして実装するため、保守性と拡張性が高い。

## 3. モジュール設計と実装

### 3.1 `data_loader.py`

- **目的:**  
  CSVやJSON形式のファイルからデータを読み込み、データフレームとして扱う。
- **主な機能:**  
  - `load_data()`: ファイル形式（CSV/JSON）に応じたデータ読み込み
  - `get_columns()`: カラム名の取得
  - `get_data_range()`: 指定カラムの最小値・最大値の取得（スケーリングに利用）

```python
import pandas as pd

class DataLoader:
    def __init__(self, file_path):
        self.file_path = file_path
        self.data = None

    def load_data(self):
        try:
            if self.file_path.endswith('.csv'):
                self.data = pd.read_csv(self.file_path)
            elif self.file_path.endswith('.json'):
                self.data = pd.read_json(self.file_path)
            else:
                raise ValueError("Unsupported file format. Only CSV and JSON are supported.")
            return self.data
        except FileNotFoundError:
            print(f"Error: File not found at {self.file_path}")
            return None
        except Exception as e:
            print(f"Error: {e}")
            return None

    def get_columns(self):
        if self.data is not None:
            return list(self.data.columns)
        else:
            return []
    
    def get_data_range(self, column):
        if self.data is not None and column in self.data.columns:
            return self.data[column].min(), self.data[column].max()
        return None, None
```

*解説:*  
データファイルの形式に合わせたエラー処理と読み込み機能を提供します。ファイルパスや形式に注意してください。

### 3.2 `turtle_utils.py`

- **目的:**  
  Turtleグラフィックスの描画ウィンドウ設定、基本的な描画補助（座標系の描画、データ値の座標変換、テキスト出力）を実装。
- **主な機能:**  
  - `setup_screen()`: ウィンドウの初期設定
  - `create_turtle()`: Turtleオブジェクトの生成と初期設定
  - `draw_coordinate_system()`: 座標軸と目盛りの描画
  - `map_data_to_coords()`: データ値を画面座標に線形変換
  - `write_text()`: 指定位置へのテキスト描画

```python
import turtle
import math

class TurtleUtils:
    @staticmethod
    def setup_screen(width=800, height=600, title="Turtle Data Visualization"):
        screen = turtle.Screen()
        screen.setup(width, height)
        screen.title(title)
        screen.tracer(0)  # 描画のアニメーションを一時停止
        return screen
    
    @staticmethod
    def create_turtle(shape="classic", color="black", speed=0):
        t = turtle.Turtle()
        t.shape(shape)
        t.color(color)
        t.speed(speed)
        t.penup()
        return t
    
    @staticmethod
    def draw_coordinate_system(t, width, height, padding=50, x_ticks=5, y_ticks=5):
        original_pos = t.position()
        original_pensize = t.pensize()
        t.pensize(2)
        t.penup()
        x_axis_length = width - 2 * padding
        y_axis_length = height - 2 * padding

        # X軸の描画
        t.goto(-x_axis_length/2, -y_axis_length/2)
        t.pendown()
        t.goto(x_axis_length/2, -y_axis_length/2)
        t.goto(x_axis_length/2 - 10, -y_axis_length/2 - 5)
        t.goto(x_axis_length/2, -y_axis_length/2)
        t.goto(x_axis_length/2 - 10, -y_axis_length/2 + 5)
        
        # Y軸の描画
        t.penup()
        t.goto(-x_axis_length/2, -y_axis_length/2)
        t.pendown()
        t.goto(-x_axis_length/2, y_axis_length/2)
        t.goto(-x_axis_length/2 - 5, y_axis_length/2 - 10)
        t.goto(-x_axis_length/2, y_axis_length/2)
        t.goto(-x_axis_length/2 + 5, y_axis_length/2 - 10)
        
        # X軸の目盛り
        tick_spacing_x = x_axis_length / (x_ticks + 1)
        for i in range(1, x_ticks + 1):
            x = -x_axis_length/2 + i * tick_spacing_x
            t.penup()
            t.goto(x, -y_axis_length/2 - 5)
            t.pendown()
            t.goto(x, -y_axis_length/2 + 5)
        
        # Y軸の目盛り
        tick_spacing_y = y_axis_length / (y_ticks + 1)
        for i in range(1, y_ticks + 1):
            y = -y_axis_length/2 + i * tick_spacing_y
            t.penup()
            t.goto(-x_axis_length/2 - 5, y)
            t.pendown()
            t.goto(-x_axis_length/2 + 5, y)
        
        t.penup()
        t.goto(original_pos)
        t.pensize(original_pensize)
        
        return (-x_axis_length/2, -y_axis_length/2, x_axis_length, y_axis_length)
    
    @staticmethod
    def map_data_to_coords(value, data_min, data_max, coord_min, coord_max):
        if data_max == data_min:
            return (coord_max + coord_min) / 2
        return coord_min + (value - data_min) * (coord_max - coord_min) / (data_max - data_min)
    
    @staticmethod
    def write_text(t, text, x, y, align="center", font=("Arial", 10, "normal")):
        t.penup()
        t.goto(x, y)
        t.write(text, align=align, font=font)
```

*解説:*  
描画の高速化のため、`screen.tracer(0)`でアニメーションを一時停止し、描画後に`screen.update()`で反映する手法を採用しています。

### 3.3 `turtle_graph_generator.py`

- **目的:**  
  データフレームをもとに、各種グラフ（折れ線グラフ、散布図、棒グラフ、円グラフ）をTurtleで描画する。
- **主な機能:**  
  - `setup()`: Turtle画面の初期設定（ウィンドウ設定、座標系描画）
  - `generate_line_chart()`: 折れ線グラフの描画  
  - `generate_scatter_plot()`: 散布図の描画  
  - `generate_bar_chart()`: 棒グラフの描画（カテゴリデータの集計）
  - `generate_pie_chart()`: 円グラフの描画（各カテゴリの割合表示）

```python
import turtle
import pandas as pd
import math
import time
from turtle_utils import TurtleUtils

class TurtleGraphGenerator:
    def __init__(self, data: pd.DataFrame):
        self.data = data
        self.screen = None
        self.t = None
        self.coords = None
        self.width = 800
        self.height = 600
        self.padding = 50
        self.animation_speed = 5  # 1（最遅）～10（最速）
    
    def setup(self, title="Turtle Data Visualization"):
        self.screen = TurtleUtils.setup_screen(self.width, self.height, title)
        self.t = TurtleUtils.create_turtle()
        self.coords = TurtleUtils.draw_coordinate_system(self.t, self.width, self.height, self.padding)
        self.screen.update()
    
    def generate_line_chart(self, x_column, y_column, title="Line Chart"):
        try:
            if self.screen is None:
                self.setup(title)
            
            x_data = self.data[x_column]
            y_data = self.data[y_column]
            x_min, x_max = x_data.min(), x_data.max()
            y_min, y_max = y_data.min(), y_data.max()
            
            x_range = x_max - x_min
            y_range = y_max - y_min
            x_min -= x_range * 0.05
            x_max += x_range * 0.05
            y_min -= y_range * 0.05
            y_max += y_range * 0.05
            
            TurtleUtils.write_text(self.t, title, 0, self.height/2 - 30, font=("Arial", 16, "bold"))
            TurtleUtils.write_text(self.t, x_column, 0, -self.height/2 + 20)
            self.t.goto(-self.width/2 + 20, 0)
            self.t.left(90)
            TurtleUtils.write_text(self.t, y_column, -self.width/2 + 20, 0)
            self.t.right(90)
            
            self.t.penup()
            self.t.pensize(2)
            self.t.color("blue")
            self.screen.tracer(self.animation_speed)
            
            x_coord = TurtleUtils.map_data_to_coords(x_data.iloc[0], x_min, x_max, 
                                                     self.coords[0], self.coords[0] + self.coords[2])
            y_coord = TurtleUtils.map_data_to_coords(y_data.iloc[0], y_min, y_max, 
                                                     self.coords[1], self.coords[1] + self.coords[3])
            self.t.goto(x_coord, y_coord)
            self.t.pendown()
            
            for i in range(1, len(x_data)):
                x_coord = TurtleUtils.map_data_to_coords(x_data.iloc[i], x_min, x_max, 
                                                         self.coords[0], self.coords[0] + self.coords[2])
                y_coord = TurtleUtils.map_data_to_coords(y_data.iloc[i], y_min, y_max, 
                                                         self.coords[1], self.coords[1] + self.coords[3])
                self.t.goto(x_coord, y_coord)
            
            self.screen.tracer(0)
            self.screen.update()
            turtle.done()
            
        except KeyError:
            print("Error: One or more specified columns do not exist in the data.")
        except Exception as e:
            print(f"An error occurred: {e}")
    
    def generate_scatter_plot(self, x_column, y_column, title="Scatter Plot"):
        try:
            if self.screen is None:
                self.setup(title)
            
            x_data = self.data[x_column]
            y_data = self.data[y_column]
            x_min, x_max = x_data.min(), x_data.max()
            y_min, y_max = y_data.min(), y_data.max()
            
            x_range = x_max - x_min
            y_range = y_max - y_min
            x_min -= x_range * 0.05
            x_max += x_range * 0.05
            y_min -= y_range * 0.05
            y_max += y_range * 0.05
            
            TurtleUtils.write_text(self.t, title, 0, self.height/2 - 30, font=("Arial", 16, "bold"))
            TurtleUtils.write_text(self.t, x_column, 0, -self.height/2 + 20)
            self.t.goto(-self.width/2 + 20, 0)
            self.t.left(90)
            TurtleUtils.write_text(self.t, y_column, -self.width/2 + 20, 0)
            self.t.right(90)
            
            self.screen.tracer(self.animation_speed)
            self.t.penup()
            self.t.color("red")
            
            for i in range(len(x_data)):
                x_coord = TurtleUtils.map_data_to_coords(x_data.iloc[i], x_min, x_max, 
                                                         self.coords[0], self.coords[0] + self.coords[2])
                y_coord = TurtleUtils.map_data_to_coords(y_data.iloc[i], y_min, y_max, 
                                                         self.coords[1], self.coords[1] + self.coords[3])
                self.t.goto(x_coord, y_coord)
                self.t.dot(8)
            
            self.screen.tracer(0)
            self.screen.update()
            turtle.done()
            
        except KeyError:
            print("Error: One or more specified columns do not exist in the data.")
        except Exception as e:
            print(f"An error occurred: {e}")
    
    def generate_bar_chart(self, x_column, y_column, title="Bar Chart"):
        try:
            if self.screen is None:
                self.setup(title)
            
            x_data = self.data[x_column]
            y_data = self.data[y_column]
            
            categories = x_data.unique() if len(x_data.unique()) <= 20 else x_data.iloc[:20].unique()
            y_min, y_max = 0, y_data.max() * 1.1
            
            TurtleUtils.write_text(self.t, title, 0, self.height/2 - 30, font=("Arial", 16, "bold"))
            TurtleUtils.write_text(self.t, x_column, 0, -self.height/2 + 20)
            self.t.goto(-self.width/2 + 20, 0)
            self.t.left(90)
            TurtleUtils.write_text(self.t, y_column, -self.width/2 + 20, 0)
            self.t.right(90)
            
            bar_area_width = self.coords[2] * 0.8
            bar_width = bar_area_width / len(categories)
            bar_spacing = bar_width * 0.2
            bar_width = bar_width * 0.8
            
            self.screen.tracer(self.animation_speed)
            self.t.penup()
            self.t.color("green")
            
            for i, category in enumerate(categories):
                category_data = self.data[self.data[x_column] == category]
                if len(category_data) == 0:
                    continue
                
                value = category_data[y_column].mean()
                bar_height = TurtleUtils.map_data_to_coords(value, 0, y_max, 
                                                            self.coords[1], self.coords[1] + self.coords[3])
                
                bar_x = self.coords[0] + (i + 0.5) * (bar_width + bar_spacing)
                
                self.t.penup()
                self.t.goto(bar_x, self.coords[1])
                self.t.pendown()
                self.t.begin_fill()
                self.t.goto(bar_x, bar_height)
                self.t.goto(bar_x + bar_width, bar_height)
                self.t.goto(bar_x + bar_width, self.coords[1])
                self.t.goto(bar_x, self.coords[1])
                self.t.end_fill()
                
                TurtleUtils.write_text(self.t, str(category), 
                                         bar_x + bar_width/2, self.coords[1] - 20, 
                                         font=("Arial", 8, "normal"))
            
            self.screen.tracer(0)
            self.screen.update()
            turtle.done()
            
        except KeyError:
            print("Error: One or more specified columns do not exist in the data.")
        except Exception as e:
            print(f"An error occurred: {e}")
    
    def generate_pie_chart(self, label_column, value_column, title="Pie Chart"):
        try:
            if self.screen is None:
                self.setup(title)
            
            labels = self.data[label_column].unique()
            values = []
            for label in labels:
                label_data = self.data[self.data[label_column] == label]
                values.append(label_data[value_column].sum())
            
            total = sum(values)
            TurtleUtils.write_text(self.t, title, 0, self.height/2 - 30, font=("Arial", 16, "bold"))
            
            radius = min(self.width, self.height) * 0.3
            self.t.penup()
            self.t.goto(0, 0)
            
            colors = ["red", "green", "blue", "yellow", "purple", "orange", "pink", "cyan", "magenta", "brown"]
            self.screen.tracer(self.animation_speed)
            
            start_angle = 0
            for i, (label, value) in enumerate(zip(labels, values)):
                slice_angle = (value / total) * 360
                self.t.fillcolor(colors[i % len(colors)])
                
                self.t.penup()
                self.t.goto(0, 0)
                self.t.setheading(start_angle)
                self.t.pendown()
                self.t.begin_fill()
                self.t.forward(radius)
                self.t.left(90)
                
                arc_length = 2 * math.pi * radius * (slice_angle / 360)
                steps = max(int(arc_length / 5), 1)
                step_angle = slice_angle / steps
                for _ in range(steps):
                    self.t.forward(arc_length / steps)
                    self.t.left(step_angle)
                self.t.goto(0, 0)
                self.t.end_fill()
                
                label_angle = start_angle + slice_angle / 2
                label_x = (radius * 1.2) * math.cos(math.radians(label_angle))
                label_y = (radius * 1.2) * math.sin(math.radians(label_angle))
                percentage = (value / total) * 100
                label_text = f"{label}: {percentage:.1f}%"
                TurtleUtils.write_text(self.t, label_text, label_x, label_y, font=("Arial", 8, "normal"))
                
                start_angle += slice_angle
            
            self.screen.tracer(0)
            self.screen.update()
            turtle.done()
            
        except KeyError:
            print("Error: One or more specified columns do not exist in the data.")
        except Exception as e:
            print(f"An error occurred: {e}")
```

*解説:*  
各グラフ描画メソッドは、必要な場合に画面・Turtleオブジェクトを初期化し、データのレンジに応じた座標変換を行いながら描画します。描画の際はアニメーションを活用し、`tracer()`と`update()`を用いて効率的な描画を実現しています。

## 4. ツールの使い方と実行方法

### 4.1 基本的なフロー

1. **データの読み込み:**  
   `data_loader.py`を用いて、CSVやJSON形式のデータを読み込みます。

2. **グラフの種類選択と設定:**  
   - 折れ線グラフ、散布図、棒グラフ、円グラフなど、目的に応じたグラフタイプを選択。  
   - グラフタイトル、軸ラベル、アニメーション速度などを設定します。

3. **グラフ生成:**  
   `TurtleGraphGenerator`クラスの各メソッド（`generate_line_chart()`, `generate_scatter_plot()`など）を呼び出し、Turtleウィンドウ上で描画を開始します。

4. **結果の確認とトラブルシューティング:**  
   描画が表示されない場合は、`turtle.done()`の呼び出しやウィンドウ設定、データの整合性（指定カラムの存在など）を確認してください。

### 4.2 実行例

以下は、簡単なデータフレームを用いた実行例です。

```python
import pandas as pd
from turtle_graph_generator import TurtleGraphGenerator

# サンプルデータ作成
data = pd.DataFrame({'x': [1, 2, 3, 4, 5],
                     'y': [2, 4, 1, 3, 5]})

# グラフ生成オブジェクトの作成
graph_generator = TurtleGraphGenerator(data)

# 折れ線グラフの生成
graph_generator.generate_line_chart('x', 'y', title="Sample Line Chart")
```
