## 10. ネットワークプログラミング：タートルでオンラインゲーム

さあ、タートルグラフィックスの世界を飛び出し、ネットワークプログラミングの冒険に出かけましょう！この章では、タートルを使ってオンラインゲームを作るという、ちょっとワクワクするテーマに取り組みます。ネットワークの基本から、ゲームのクライアント・サーバー設計、そしてより効率的なWebソケットまで、段階的に解説していきます。初心者の方も、ネットワークプログラミングの経験者の方も、きっと新しい発見があるはずです。

### 10.1 ソケットプログラミングの基礎：クライアントとサーバー

#### 10.1.1 概要と重要性

ソケットプログラミングは、ネットワークを介して異なるコンピュータ間でデータをやり取りするための基本的な技術です。オンラインゲーム、チャットアプリケーション、ファイル共有など、ネットワークを利用するあらゆるアプリケーションの根幹をなしています。ソケットを理解することで、ネットワークの仕組みを深く理解し、自由自在にネットワークアプリケーションを開発できるようになります。

#### 10.1.2 特徴と利点

*   **柔軟性:** ソケットは、様々なプロトコル（TCP, UDPなど）に対応しており、用途に応じて最適なプロトコルを選択できます。
*   **汎用性:** 異なるOSやプログラミング言語間でも、ソケットを使って通信できます。
*   **直接制御:** ソケットAPIを使うことで、ネットワーク通信を細かく制御できます。

#### 10.1.3 事前準備と前提条件

*   **Pythonの基本的な知識:** 変数、関数、クラスなど、Pythonの基本的な文法を理解している必要があります。
*   **ターミナル（コマンドプロンプト）の操作:** Pythonスクリプトの実行や、ネットワーク関連のコマンドを実行するために使用します。
*   **インターネット接続:** クライアントとサーバーが通信するためには、インターネット接続が必要です。

#### 10.1.4 基本的な使い方

ソケットプログラミングでは、クライアントとサーバーという2つの役割があります。サーバーは、クライアントからの接続を待ち受け、クライアントはサーバーに接続してデータを送受信します。

**サーバー側のコード (server.py):**

```python
import socket

# ホストとポート番号を設定
HOST = '127.0.0.1'  # localhost (自分のPC)
PORT = 65432  # 1024以上のポート番号を選択

# ソケットを作成
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    # ソケットをホストとポートにバインド
    s.bind((HOST, PORT))
    # クライアントからの接続を待ち受け
    s.listen()
    print(f"Listening on {HOST}:{PORT}")

    # クライアントからの接続を受け入れる
    conn, addr = s.accept()
    with conn:
        print(f"Connected by {addr}")
        # クライアントからデータを受信し、送信
        while True:
            data = conn.recv(1024)
            if not data:
                break
            print(f"Received: {data.decode()}")
            conn.sendall(data) # 受信したデータをそのままクライアントに返す
```

**クライアント側のコード (client.py):**

```python
import socket

# ホストとポート番号を設定
HOST = '127.0.0.1'  # サーバーのホスト名またはIPアドレス
PORT = 65432  # サーバーと同じポート番号

# ソケットを作成し、サーバーに接続
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.connect((HOST, PORT))
    # サーバーにデータを送信
    message = "Hello, Server!"
    s.sendall(message.encode())
    # サーバーからデータを受信
    data = s.recv(1024)

print(f"Received: {data.decode()}")
```

**実行方法:**

1.  `server.py`をターミナルで実行します。
    ```bash
    python server.py
    ```
2.  別のターミナルで`client.py`を実行します。
    ```bash
    python client.py
    ```

クライアントが`Hello, Server!`というメッセージをサーバーに送信し、サーバーから同じメッセージが返ってくるはずです。

**解説:**

*   `socket.socket(socket.AF_INET, socket.SOCK_STREAM)`: ソケットを作成します。`AF_INET`はIPv4アドレス、`SOCK_STREAM`はTCPプロトコルを表します。
*   `s.bind((HOST, PORT))`: ソケットを特定のホストとポートにバインドします。
*   `s.listen()`: クライアントからの接続を待ち受けます。
*   `s.accept()`: クライアントからの接続を受け入れ、新しいソケットオブジェクトとクライアントのアドレスを返します。
*   `conn.recv(1024)`: クライアントから最大1024バイトのデータを受信します。
*   `conn.sendall(data)`: クライアントにデータを送信します。
*   `s.connect((HOST, PORT))`: サーバーのホストとポートに接続します。
*   `data.decode()`: 受信したバイト列を文字列にデコードします。
*   `message.encode()`: 文字列をバイト列にエンコードします。

#### 10.1.5 実践的なテクニック

*   **エラー処理:** ネットワーク通信は、様々な要因でエラーが発生する可能性があります。`try-except`ブロックを使って、エラーを適切に処理することが重要です。
*   **タイムアウト設定:** `socket.settimeout()`を使うことで、ソケットのタイムアウト時間を設定できます。これにより、応答のないクライアントやサーバーを検出し、処理を中断できます。
*   **ノンブロッキングソケット:** `socket.setblocking(False)`を使うことで、ソケットをノンブロッキングモードに設定できます。これにより、データの送受信がすぐに完了しない場合でも、プログラムがブロックされずに処理を続行できます。

**エラー処理の例:**

```python
import socket

HOST = '127.0.0.1'
PORT = 65432

try:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.connect((HOST, PORT))
        s.sendall(b"Hello, Server!")
        data = s.recv(1024)
    print(f"Received {data!r}")
except socket.error as e:
    print(f"Socket error: {e}")
except Exception as e:
    print(f"An unexpected error occurred: {e}")
```

#### 10.1.6 応用例とユースケース

*   **チャットアプリケーション:** 複数のクライアントがサーバーに接続し、メッセージを交換するチャットアプリケーションを開発できます。
*   **ファイル共有:** クライアントがサーバーからファイルをダウンロードしたり、サーバーにファイルをアップロードしたりするファイル共有アプリケーションを開発できます。
*   **リモートコントロール:** クライアントがサーバーをリモートで制御するアプリケーションを開発できます。

#### 10.1.7 トラブルシューティング

*   **接続エラー:** サーバーが起動していない、またはクライアントが間違ったホストやポートに接続しようとしている可能性があります。
*   **データの送受信エラー:** ネットワークが不安定である、またはデータのサイズが大きすぎる可能性があります。
*   **ファイアウォール:** ファイアウォールがソケットの通信をブロックしている可能性があります。

### 10.2 オンラインゲームの実装：クライアントとサーバーの連携

#### 10.2.1 概要と重要性

ソケットプログラミングの知識を応用して、いよいよオンラインゲームを実装していきます。ここでは、タートルグラフィックスを使って、簡単なオンラインゲームを作成し、クライアントとサーバーの連携について学びます。

#### 10.2.2 特徴と利点

*   **リアルタイム性:** 複数のプレイヤーがリアルタイムでゲームに参加できます。
*   **インタラクティブ性:** プレイヤー同士が互いに影響を与え合いながらゲームを進めることができます。
*   **拡張性:** 多くのプレイヤーが参加できるように、サーバーを拡張できます。

#### 10.2.3 事前準備と前提条件

#### 10.2.4 基本的な使い方

ここでは、タートルを使って、簡単なオンラインゲーム（例えば、お互いのタートルを追いかけるゲーム）を作成します。

**サーバー側のコード (game_server.py):**

```python
import socket
import threading
import json

HOST = '127.0.0.1'
PORT = 65432

# 接続中のクライアントを格納するリスト
clients = []
client_locks = {} #各クライアントの状態を保護するためのロック

def handle_client(conn, addr):
    print(f"Connected by {addr}")
    client_id = addr[1] # ポート番号をクライアントIDとする (簡易的な例)
    client_locks[client_id] = threading.Lock() #クライアントに対応するロックを作成

    try:
        while True:
            data = conn.recv(1024)
            if not data:
                break

            try:
                message = json.loads(data.decode())
                # 例：クライアントからの位置情報を更新
                with client_locks[client_id]: #クライアントの状態をロック
                    message['client_id'] = client_id #クライアントIDを付与
                    broadcast(message) # 全てのクライアントにブロードキャスト
            except json.JSONDecodeError:
                print(f"Invalid JSON received from {addr}")

    except Exception as e:
        print(f"Error with client {addr}: {e}")
    finally:
        print(f"Client {addr} disconnected")
        clients.remove(conn)
        del client_locks[client_id] #クライアントが切断されたらロックを削除
        conn.close()

def broadcast(message):
    for client in clients:
        try:
            client.sendall(json.dumps(message).encode())
        except Exception as e:
            print(f"Error broadcasting to client: {e}")

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.bind((HOST, PORT))
    s.listen()
    print(f"Listening on {HOST}:{PORT}")

    while True:
        conn, addr = s.accept()
        clients.append(conn)
        thread = threading.Thread(target=handle_client, args=(conn, addr))
        thread.start()
```

**クライアント側のコード (game_client.py):**

```python
import socket
import turtle
import threading
import json
import time

HOST = '127.0.0.1'
PORT = 65432

# タートルの初期設定
screen = turtle.Screen()
screen.setup(width=600, height=600)
screen.bgcolor("white")
screen.tracer(0)  # アニメーションをスムーズにする

player = turtle.Turtle()
player.shape("turtle")
player.color("blue")
player.penup()

other_players = {}  # 他のプレイヤーのタートルを格納する辞書

# キー入力による移動
def move_up():
    player.setheading(90)
    player.forward(10)
    send_position()

def move_down():
    player.setheading(270)
    player.forward(10)
    send_position()

def move_left():
    player.setheading(180)
    player.forward(10)
    send_position()

def move_right():
    player.setheading(0)
    player.forward(10)
    send_position()

screen.listen()
screen.onkeypress(move_up, "Up")
screen.onkeypress(move_down, "Down")
screen.onkeypress(move_left, "Left")
screen.onkeypress(move_right, "Right")

# サーバーに自分の位置情報を送信する関数
def send_position():
    position = {"x": player.xcor(), "y": player.ycor()}
    try:
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
            s.connect((HOST, PORT))
            s.sendall(json.dumps(position).encode())
    except Exception as e:
        print(f"Error sending position: {e}")

# サーバーから位置情報を受信する関数
def receive_position():
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.connect((HOST, PORT))
        while True:
            try:
                data = s.recv(1024)
                if not data:
                    break
                message = json.loads(data.decode())
                client_id = message['client_id']
                x = message['x']
                y = message['y']

                # 他のプレイヤーの位置を更新または作成
                if client_id not in other_players and client_id != s.getsockname()[1]: # 自分のタートルは表示しない
                    other_player = turtle.Turtle()
                    other_player.shape("turtle")
                    other_player.color("red")
                    other_player.penup()
                    other_players[client_id] = other_player

                if client_id in other_players and client_id != s.getsockname()[1]: #自分のタートルは更新しない
                    other_players[client_id].goto(x, y)

            except Exception as e:
                print(f"Error receiving position: {e}")
                break

# 受信スレッドを開始
receive_thread = threading.Thread(target=receive_position)
receive_thread.start()

# メインループ
while True:
    screen.update()
    time.sleep(0.01)  # CPU負荷を軽減
```

**実行方法:**

1.  `game_server.py`をターミナルで実行します。
    ```bash
    python game_server.py
    ```
2.  別のターミナルで`game_client.py`を実行します。
    ```bash
    python game_client.py
    ```
3.  複数のターミナルで`game_client.py`を実行すると、複数のプレイヤーが参加できるようになります。

**解説:**

*   **サーバー側:**
    *   `threading`: 複数のクライアントからの接続を同時に処理するために、スレッドを使用します。
    *   `json`: クライアントとサーバー間でデータをやり取りするために、JSON形式を使用します。

### 10.3 Webソケットの利用：より効率的なリアルタイム通信

#### 10.3.1 概要と重要性

Webソケットは、クライアントとサーバー間で双方向のリアルタイム通信を可能にする技術です。従来のHTTP通信とは異なり、一度接続を確立すると、データの送受信を効率的に行うことができます。オンラインゲーム、チャットアプリケーション、リアルタイムデータ配信など、リアルタイム性が求められるアプリケーションに最適です。

#### 10.3.2 特徴と利点

*   **双方向通信:** クライアントとサーバーが自由にデータを送受信できます。
*   **リアルタイム性:** HTTPポーリングやロングポーリングに比べて、遅延が少なく、リアルタイムな通信が可能です。
*   **効率性:** 一度接続を確立すると、HTTPヘッダーなどのオーバーヘッドが少なく、効率的にデータを送受信できます。
*   **ステートフル:** 接続が確立されている間、サーバーはクライアントの状態を保持できます。

#### 10.3.3 事前準備と前提条件

*   **HTTPの基本的な知識:** HTTPリクエスト、レスポンスなどの基本的な知識が必要です。
*   **Webサーバーの知識:** Apache, NginxなどのWebサーバーの基本的な知識が必要です。
*   **Webソケットライブラリ:** Pythonでは、`websockets`ライブラリを使用します。

    ```bash
    pip install websockets
    ```

#### 10.3.4 基本的な使い方

**サーバー側のコード (websocket_server.py):**

```python
import asyncio
import websockets
import json

connected_clients = set()

async def echo(websocket):
    connected_clients.add(websocket)
    try:
        async for message in websocket:
            # 受信したメッセージをJSONとしてパース
            try:
                data = json.loads(message)
                # クライアントIDを追加してブロードキャスト
                data['client_id'] = id(websocket)
                await broadcast(json.dumps(data))
            except json.JSONDecodeError:
                print("Received non-JSON message")

    except websockets.exceptions.ConnectionClosedError:
        print("Connection closed unexpectedly")
    finally:
        connected_clients.remove(websocket)

async def broadcast(message):
    for client in connected_clients:
        try:
            await client.send(message)
        except Exception as e:
            print(f"Error broadcasting message: {e}")

async def main():
    async with websockets.serve(echo, "localhost", 8765):
        print("WebSocket server started at ws://localhost:8765")
        await asyncio.Future()  # Run forever

if __name__ == "__main__":
    asyncio.run(main())
```

```python
        while True:
            screen.update()
            await asyncio.sleep(0.01)  # CPU負荷を軽減

asyncio.run(connect())
```

**実行方法:**

1.  `websocket_server.py`をターミナルで実行します。
    ```bash
    python websocket_server.py
    ```
2.  別のターミナルで`websocket_client.py`を実行します。
    ```bash
    python websocket_client.py
    ```
3.  複数のターミナルで`websocket_client.py`を実行すると、複数のプレイヤーが参加できるようになります。

**解説:**

*   **サーバー側:**
    *   `websockets.serve()`: Webソケットサーバーを起動します。
    *   `echo()`: クライアントからの接続を処理するコルーチンです。
    *   `websocket.send()`: クライアントにメッセージを送信します。
*   **クライアント側:**
    *   `websockets.connect()`: Webソケットサーバーに接続します。
    *   `websocket.send()`: サーバーにメッセージを送信します。
    *   `websocket.recv()`: サーバーからメッセージを受信します。

#### 10.3.5 実践的なテクニック

*   **メッセージのフォーマット:** JSON、Protocol Buffersなど、効率的なメッセージフォーマットを使用することで、ネットワークの負荷を軽減できます。
*   **認証:** Webソケット接続時に認証を行うことで、不正なアクセスを防ぐことができます。
*   **エラー処理:** Webソケット接続の切断や、メッセージの送受信エラーを適切に処理することが重要です。

#### 10.3.6 応用例とユースケース

*   **リアルタイムチャット:** 複数のユーザーがリアルタイムにメッセージを交換するチャットアプリケーションを開発できます。
*   **株価のリアルタイム配信:** 株価などのデータをリアルタイムに配信するアプリケーションを開発できます。
*   **IoTデバイスの制御:** IoTデバイスをリアルタイムに制御するアプリケーションを開発できます。

#### 10.3.7 トラブルシューティング

*   **接続エラー:** サーバーが起動していない、またはクライアントが間違ったURLに接続しようとしている可能性があります。
*   **メッセージの送受信エラー:** ネットワークが不安定である、またはメッセージのフォーマットが間違っている可能性があります。
*   **CORS (Cross-Origin Resource Sharing):** ブラウザのセキュリティポリシーにより、異なるオリジンからのWebソケット接続がブロックされる場合があります。
