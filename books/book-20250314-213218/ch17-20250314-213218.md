## 17. 実践プロジェクト：2Dゲームエンジン

この章では、2Dゲームエンジンを実際に構築するプロジェクトを通じて、ゲーム開発の基礎から応用までを体系的に学びます。ただコードを書き写すのではなく、なぜそのコードが必要なのか、どのように機能するのかを理解することを重視します。初心者の方でも理解できるように、丁寧に解説していきますのでご安心ください。上級者の方は、自身の知識の再確認や、新たな視点での発見があるかもしれません。

### 17.1 プロジェクトの概要：目的、機能、設計

#### 17.1.1 概要と重要性

このプロジェクトの目的は、シンプルな2Dゲームエンジンをゼロから構築することです。既存のゲームエンジン（Unity, Unreal Engineなど）は非常に強力ですが、内部構造が複雑で、初心者には学習コストが高いという側面があります。自作のエンジンを構築することで、ゲーム開発の根本的な仕組みを理解し、より自由な発想でゲームを作れるようになります。

このプロジェクトを通じて、以下の重要なスキルを習得できます。

*   **グラフィックス描画:** 画面にスプライトや図形を描画する方法
*   **ゲームループ:** ゲームの状態を更新し、描画を繰り返す基本的な仕組み
*   **入力処理:** キーボードやマウスなどの入力を受け付け、ゲームに反映させる方法
*   **衝突判定:** ゲームオブジェクト同士の衝突を検出し、適切な処理を行う方法
*   **サウンド再生:** 効果音やBGMを再生する方法
*   **リソース管理:** 画像や音声などのリソースを効率的に管理する方法

#### 17.1.2 特徴と利点

今回構築する2Dゲームエンジンの特徴は、シンプルさと拡張性の高さです。

*   **シンプル:** コード量が少なく、理解しやすい構造になっています。
*   **拡張性:** 機能をモジュール化することで、新しい機能を追加しやすくなっています。
*   **学習効果:** ゲーム開発の基礎を深く理解できます。
*   **カスタマイズ性:** 自分のアイデアを自由に反映できます。

既存のゲームエンジンと比較して、機能は限られていますが、その分、内部構造を深く理解できるため、将来的に既存のゲームエンジンを使いこなすための基礎力も養えます。

#### 17.1.3 事前準備と前提条件

このプロジェクトに取り組む前に、以下の準備が必要です。

*   **プログラミング言語:** C++ (または、慣れている他の言語。この例ではC++で記述します)
*   **開発環境:** Visual Studio, CLion, g++, etc. (C++がコンパイルできる環境)
*   **グラフィックスライブラリ:** SDL2 (または、SFML, OpenGL, DirectXなど。クロスプラットフォーム性と学習の容易さからSDL2を推奨します)

SDL2のインストールは、OSによって異なります。

*   **Windows:** SDL2の公式サイトから開発ライブラリをダウンロードし、Visual Studioの設定に含めます。
*   **macOS:** Homebrewを使って `brew install sdl2` でインストールできます。
*   **Linux:** 各ディストリビューションのパッケージマネージャを使ってインストールします。(例: `sudo apt-get install libsdl2-dev`)

C++の基本的な文法、ポインタ、クラスなどの知識があると、よりスムーズに進められます。しかし、分からなくても大丈夫です。コードを読み解きながら、必要に応じて調べていきましょう。

#### 17.1.4 基本的な設計

このエンジンは、以下の主要なモジュールで構成されます。

*   **Core:** エンジンの初期化、ゲームループ、イベント処理など、中核となる機能を提供します。
*   **Graphics:** スプライトの描画、テクスチャの管理など、グラフィックス関連の機能を提供します。
*   **Input:** キーボード、マウスなどの入力を処理します。
*   **Audio:** 効果音やBGMの再生を管理します。
*   **Physics:** 衝突判定、物理演算などを行います。(今回は簡単な衝突判定のみ実装します)
*   **GameObject:** ゲームに登場するオブジェクトの基底クラスです。

これらのモジュールを組み合わせることで、ゲームに必要な様々な機能を実現します。

#### 17.1.5 実践的なテクニック

設計段階で重要なのは、変更に強い構造にすることです。例えば、グラフィックスライブラリをSDL2からOpenGLに変更する可能性も考慮し、Graphicsモジュールを抽象化しておくことで、変更の影響範囲を最小限に抑えることができます。

また、設計段階で、どのようなゲームを作りたいかを具体的にイメージすることも重要です。作りたいゲームに必要な機能を洗い出し、それを実現するために必要なモジュールを設計することで、無駄のない効率的なエンジンを構築できます。

#### 17.1.6 応用例とユースケース

このエンジンは、以下のような2Dゲームの開発に利用できます。

*   **プラットフォーマーゲーム:** マリオのような横スクロールアクションゲーム
*   **シューティングゲーム:** スペースインベーダーのようなシューティングゲーム
*   **パズルゲーム:** テトリスのようなパズルゲーム
*   **RPG:** 簡単な戦闘システムを持つRPG

さらに、ゲーム開発だけでなく、教育用ツールやシミュレーションなど、様々な分野で応用できます。

#### 17.1.7 トラブルシューティング

*   **SDL2がリンクできない:** コンパイラの設定でSDL2のライブラリとヘッダーファイルのパスが正しく設定されているか確認してください。
*   **画面が真っ黒:** 描画処理が正しく実装されているか確認してください。また、ウィンドウの初期化処理が正しく行われているかも確認してください。
*   **ゲームがクラッシュする:** メモリリークや不正なポインタアクセスなどが原因である可能性があります。デバッガを使って原因を特定してください。

```cpp
#define ENGINE_H

#include <SDL.h>
#include "Graphics/TextureManager.h"
#include "Input/InputManager.h"

class Engine {
public:
    Engine();
    ~Engine();

    bool Init(const char* title, int width, int height);
    void Update();
    void Render();
    void Clean();
    bool Running() { return m_running; }

    static SDL_Renderer* GetRenderer() { return m_renderer; }

private:
    bool m_running;
    SDL_Window* m_window;
    SDL_Renderer* m_renderer;
    TextureManager* m_textureManager;
    InputManager* m_inputManager;
    AudioManager* m_audioManager;

```

```cpp
// Engine.cpp
#include "Core/Engine.h"
#include <iostream>

SDL_Renderer* Engine::m_renderer = nullptr; // static変数の初期化

Engine::Engine() : m_running(false), m_window(nullptr), m_renderer(nullptr), m_textureManager(nullptr), m_inputManager(nullptr), m_audioManager(nullptr) {}

Engine::~Engine() {
    Clean();
}

bool Engine::Init(const char* title, int width, int height) {
    if (SDL_Init(SDL_INIT_EVERYTHING) != 0) {
        std::cerr << "SDL_Init Error: " << SDL_GetError() << std::endl;
        return false;
    }

    m_window = SDL_CreateWindow(title, SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, width, height, SDL_WINDOW_SHOWN);
    if (m_window == nullptr) {
        std::cerr << "SDL_CreateWindow Error: " << SDL_GetError() << std::endl;
        return false;
    }

    m_renderer = SDL_CreateRenderer(m_window, -1, SDL_RENDERER_ACCELERATED | SDL_RENDERER_PRESENTVSYNC);
    if (m_renderer == nullptr) {
        std::cerr << "SDL_CreateRenderer Error: " << SDL_GetError() << std::endl;
        return false;
    }

    m_textureManager = new TextureManager();
    m_inputManager = new InputManager();
    m_audioManager = new AudioManager();

    m_running = true;
    return true;
}

void Engine::Update() {
    m_inputManager->Update(); // 入力更新

    if (m_inputManager->IsKeyDown(SDL_SCANCODE_ESCAPE)) {
        m_running = false;
    }
}

void Engine::Render() {
    SDL_RenderClear(m_renderer);
    // ここに描画処理を記述
    SDL_RenderPresent(m_renderer);
}

void Engine::Clean() {
    delete m_textureManager;
    delete m_inputManager;
    delete m_audioManager;

    SDL_DestroyRenderer(m_renderer);
    SDL_DestroyWindow(m_window);
    SDL_Quit();
    std::cout << "Game cleaned" << std::endl;
}
```

```cpp
// TextureManager.cpp
#include "Graphics/TextureManager.h"
#include "Core/Engine.h"
#include <iostream>

TextureManager::TextureManager() {}

TextureManager::~TextureManager() {
    for (auto& pair : m_textureMap) {
        SDL_DestroyTexture(pair.second);
    }
    m_textureMap.clear();
}


SDL_Texture* TextureManager::LoadTexture(const char* filename) {
    // キャッシュに存在するか確認
    auto it = m_textureMap.find(filename);
    if (it != m_textureMap.end()) {
        return it->second; // キャッシュから返す
    }

    SDL_Surface* surface = SDL_LoadBMP(filename);
    if (surface == nullptr) {
        std::cerr << "SDL_LoadBMP Error: " << SDL_GetError() << std::endl;
        return nullptr;
    }

    SDL_Texture* texture = SDL_CreateTextureFromSurface(Engine::GetRenderer(), surface);
    SDL_FreeSurface(surface); // Surfaceは不要になったら解放

    if (texture == nullptr) {
        std::cerr << "SDL_CreateTextureFromSurface Error: " << SDL_GetError() << std::endl;
        return nullptr;
    }

    m_textureMap[filename] = texture; // キャッシュに登録
    return texture;
}

void TextureManager::Draw(SDL_Texture* texture, SDL_Rect src, SDL_Rect dest) {
    SDL_RenderCopy(Engine::GetRenderer(), texture, &src, &dest);
}
```

```cpp
#ifndef AUDIO_MANAGER_H
#define AUDIO_MANAGER_H

#include <string>
#include <map>

class AudioManager {
public:

private:

#endif
```

```cpp
// AudioManager.cpp
#include "Audio/AudioManager.h"
#include <iostream>

AudioManager::AudioManager() {
    if (Mix_OpenAudio(MIX_DEFAULT_FREQUENCY, MIX_DEFAULT_FORMAT, 2, 2048) < 0) {
        std::cerr << "SDL_mixer Error: " << Mix_GetError() << std::endl;
    }
}

AudioManager::~AudioManager() {
    for (auto& pair : m_soundMap) {
        Mix_FreeChunk(pair.second);
    }
    m_soundMap.clear();
    Mix_Quit();
}

bool AudioManager::LoadSound(const char* filename, const std::string& id) {
    Mix_Chunk* sound = Mix_LoadWAV(filename);
    if (sound == nullptr) {
        std::cerr << "SDL_mixer LoadWAV Error: " << Mix_GetError() << std::endl;
        return false;
    }
    m_soundMap[id] = sound;
    return true;
}

void AudioManager::PlaySound(const std::string& id, int loops) {
    auto it = m_soundMap.find(id);
    if (it != m_soundMap.end()) {
        Mix_PlayChannel(-1, it->second, loops);
    } else {
        std::cerr << "Sound with id " << id << " not found." << std::endl;
    }
}
```

**7. メイン関数 (main.cpp)**

```cpp
// main.cpp
#include "Core/Engine.h"
#include "GameObject/GameObject.h"
#include <iostream>

int main(int argc, char* argv[]) {
    Engine* engine = new Engine();
    engine->Init("My Game Engine", 800, 600);

    GameObject* player = new GameObject("assets/player.bmp", 100, 100, 32, 32); // player.bmpを用意

    //AudioManagerの初期化とサウンド読み込み
    AudioManager* audioManager = new AudioManager();
    audioManager->LoadSound("assets/jump.wav", "jump"); // jump.wavを用意

    while (engine->Running()) {
        engine->Update();

        // 入力に応じてサウンドを再生
        if (InputManager::IsKeyDown(SDL_SCANCODE_SPACE)) {
            audioManager->PlaySound("jump");
        }

        player->Update();

        engine->Render();
        player->Draw(); // 描画

        SDL_Delay(16); // 60FPS
    }

    delete player;
    delete engine;
    delete audioManager;

    return 0;
}
```

*   **ゲームの企画:** どのようなゲームを作るか、事前に企画を立てておきましょう。
*   **発表資料の作成:** プレゼンテーション資料やデモンストレーション用のゲームを用意しましょう。
*   **発表練習:** スムーズに発表できるように、事前に練習しておきましょう。

#### 17.3.4 基本的な使い方

ここでは、簡単なシューティングゲームを作成する例を紹介します。

1.  **ゲームの企画:** 自機を操作して、敵を倒すシンプルなシューティングゲームを作成します。
2.  **ゲームオブジェクトの作成:** 自機、敵、弾丸などのゲームオブジェクトを作成します。
3.  **ゲームロジックの実装:** 自機の操作、敵の移動、弾丸の発射、衝突判定などのゲームロジックを実装します。
4.  **グラフィックスの作成:** 自機、敵、弾丸などのグラフィックスを作成します。
5.  **サウンドの作成:** 発射音、爆発音などのサウンドを作成します。
6.  **ゲームのテスト:** 実際にゲームをプレイして、バグがないか確認します。
7.  **成果発表:** 作成したゲームをプレゼンテーションし、デモンストレーションを行います。

#### 17.3.5 実践的なテクニック

*   **ゲームバランスの調整:** 難易度が高すぎたり、低すぎたりしないように、ゲームバランスを調整しましょう。
*   **UIの作成:** プレイしやすいように、UIを作成しましょう。
*   **演出の追加:** 効果音やエフェクトを追加して、ゲームを盛り上げましょう。

#### 17.3.6 応用例とユースケース

*   **ポートフォリオサイト:** 作成したゲームをポートフォリオサイトに掲載して、就職活動や転職活動に役立てましょう。
*   **ゲームジャム:** ゲームジャムに参加して、短期間でゲームを作成するスキルを磨きましょう。
*   **インディーゲーム開発:** 自分のアイデアを形にして、インディーゲームを開発しましょう。

#### 17.3.7 トラブルシューティング

*   **プレゼンテーションがうまくいかない:** 緊張せずに、自信を持って発表しましょう。
*   **デモンストレーション中にバグが発生する:** 慌てずに、冷静に対処しましょう。
*   **質問に答えられない:** 事前に想定される質問を準備しておきましょう。
