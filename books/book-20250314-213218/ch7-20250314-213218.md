## 7. データ可視化：タートルでグラフを描く

タートルグラフィックスは、プログラミングの学習において、視覚的に理解しやすい方法で基本的な概念を学ぶための強力なツールです。特に、データ可視化の分野では、タートルを使って棒グラフや折れ線グラフ、円グラフといった様々なグラフを描画することで、データの背後にあるパターンや傾向を直感的に把握することができます。本章では、タートルグラフィックスを使ってデータ可視化を行うための実践的な方法を解説します。

### 7.1 棒グラフ、折れ線グラフの描画：基本的なグラフの作成

#### 概要と重要性

棒グラフと折れ線グラフは、データの比較や時系列的な変化を視覚的に表現するための最も基本的なグラフです。タートルグラフィックスを使ってこれらのグラフを描画することで、データの値とグラフの形状の関係を直接的に理解することができます。

#### 特徴と利点

*   **直感的な理解:** タートルの動きを通じて、データの値がどのようにグラフの形状に反映されるかを視覚的に理解できます。
*   **カスタマイズ性:** 色、線の太さ、背景色など、様々な要素を自由にカスタマイズできます。
*   **学習効果:** プログラミングの基本的な構文（ループ、条件分岐など）を実践的に学ぶことができます。

#### 事前準備と前提条件

*   Pythonのインストール: Pythonがインストールされている必要があります。Python公式サイト (https://www.python.org/downloads/) からダウンロードしてインストールしてください。
*   turtleモジュールのインポート: Pythonの標準ライブラリに含まれているため、インストールは不要です。

#### 基本的な使い方

まず、`turtle`モジュールをインポートし、タートルオブジェクトを作成します。

```python
import turtle

# スクリーンオブジェクトを作成
screen = turtle.Screen()
screen.setup(width=800, height=600) # 画面サイズを設定
screen.bgcolor("white") # 背景色を設定
screen.title("棒グラフ") # ウィンドウタイトルを設定

# タートルオブジェクトを作成
pen = turtle.Turtle()
pen.speed(0) # 描画速度を最速に設定
pen.hideturtle() # タートルアイコンを非表示
```

次に、棒グラフを描画する関数を定義します。

```python
def draw_bar(height, label, color):
    pen.fillcolor(color)
    pen.begin_fill()
    pen.left(90)
    pen.forward(height)
    pen.write(label, align="center") # ラベルを追加
    pen.right(90)
    pen.forward(40)
    pen.right(90)
    pen.forward(height)
    pen.left(90)
    pen.end_fill()
```

最後に、データを用意して、`draw_bar`関数を呼び出して棒グラフを描画します。

```python
data = [
    ("A", 100, "red"),
    ("B", 150, "green"),
    ("C", 80, "blue"),
    ("D", 120, "orange")
]

x_start = -150 # グラフの開始位置を調整

pen.penup()
pen.goto(x_start, -100) # グラフの開始位置を設定
pen.pendown()

for label, value, color in data:
    draw_bar(value, label, color)

screen.mainloop() # 画面を維持
```

**解説:**

*   `screen = turtle.Screen()`: スクリーンオブジェクトを作成します。
*   `pen = turtle.Turtle()`: タートルオブジェクトを作成します。このオブジェクトが実際に画面に描画を行います。
*   `draw_bar(height, label, color)`: 棒グラフの1つの棒を描画する関数です。引数として、棒の高さ、ラベル、色を受け取ります。
*   `pen.fillcolor(color)`: 棒の色を設定します。
*   `pen.begin_fill()` と `pen.end_fill()`: 棒の塗りつぶしを開始および終了します。
*   `pen.left(90)` と `pen.right(90)`: タートルの向きを回転させます。
*   `pen.forward(height)`: タートルを指定された距離だけ前進させます。
*   `pen.write(label, align="center")`: 棒の上にラベルを表示します。
*   `data`: 棒グラフのデータです。各要素は、ラベル、値、色のタプルです。
*   `pen.penup()` と `pen.pendown()`: ペンの上げ下げを制御します。ペンが上がっているときは描画されません。
*   `pen.goto(x_start, -100)`: タートルの位置を指定された座標に移動させます。
*   `screen.mainloop()`: 画面を閉じないように維持します。

#### 実践的なテクニック

*   **軸の描画:** x軸とy軸を描画することで、グラフの見やすさを向上させることができます。
*   **ラベルのカスタマイズ:** ラベルのフォント、サイズ、色などを変更することで、グラフのデザインを調整できます。
*   **色のグラデーション:** 複数の色を組み合わせて、グラデーションを表現することができます。
*   **凡例の追加:** 複数のデータをグラフに表示する場合、凡例を追加することで、データの区別を容易にすることができます。

#### 応用例とユースケース

*   **売上データの可視化:** 月ごとの売上データを棒グラフで表示することで、売上の推移を把握することができます。
*   **アンケート結果の可視化:** アンケートの回答結果を棒グラフで表示することで、回答の傾向を分析することができます。
*   **気温の変化の可視化:** 日ごとの気温の変化を折れ線グラフで表示することで、気温の変動を把握することができます。

#### トラブルシューティング

*   **グラフが画面からはみ出す:** スクリーンのサイズを調整するか、タートルの開始位置を変更してください。
*   **ラベルが重なって読みにくい:** ラベルの位置を調整するか、フォントサイズを小さくしてください。
*   **色が思ったように表示されない:** カラーコードが正しいことを確認してください。

#### まとめと次のステップ

棒グラフと折れ線グラフは、データ可視化の基礎となる重要なグラフです。タートルグラフィックスを使ってこれらのグラフを描画することで、データの値とグラフの形状の関係を理解し、データの傾向を把握することができます。次のステップでは、円グラフや散布図といった、より複雑なグラフの描画方法について学びましょう。

### 7.2 円グラフ、散布図の描画：データの種類に合わせたグラフの選択

#### 概要と重要性

円グラフは、全体に対する各要素の割合を視覚的に表現するのに適しており、散布図は、2つの変数の関係性を分析するのに役立ちます。データの種類に合わせて適切なグラフを選択することで、データの持つ情報を効果的に伝えることができます。

#### 特徴と利点

*   **円グラフ:**
    *   割合の比較に最適
    *   視覚的に分かりやすい
    *   要素数が少ない場合に有効
*   **散布図:**
    *   2つの変数の関係性を把握できる
    *   相関関係の有無を判断できる
    *   外れ値を検出できる

#### 事前準備と前提条件

*   7.1節と同様に、Pythonとturtleモジュールが必要です。

#### 基本的な使い方

**円グラフの描画:**

円グラフを描画するためには、各要素の割合を計算し、それに基づいて円弧の角度を決定する必要があります。

```python
import turtle

screen = turtle.Screen()
screen.setup(width=600, height=600)
screen.bgcolor("white")
screen.title("円グラフ")

pen = turtle.Turtle()
pen.speed(0)
pen.hideturtle()

def draw_pie_chart(data):
    total = sum(data.values())
    start_angle = 0
    for label, value in data.items():
        angle = (value / total) * 360
        pen.fillcolor(get_color(label)) # 色を動的に決定
        pen.begin_fill()
        pen.goto(0, 0)
        pen.setheading(start_angle)
        pen.circle(100, angle)
        pen.goto(0, 0)
        pen.end_fill()
        start_angle += angle
        # 凡例を追加 (少し工夫が必要)
        x = 150 * math.cos(math.radians(start_angle - angle/2))
        y = 150 * math.sin(math.radians(start_angle - angle/2))
        pen.penup()
        pen.goto(x, y)
        pen.pendown()
        pen.write(f"{label} ({value})", align="center")


def get_color(label):
    # ラベルに基づいて色を決定する簡単な例
    colors = ["red", "green", "blue", "orange", "purple"]
    return colors[hash(label) % len(colors)]


import math

data = {
    "A": 30,
    "B": 20,
    "C": 25,
    "D": 15,
    "E": 10
}

draw_pie_chart(data)

screen.mainloop()
```

**解説:**

*   `data`: 円グラフのデータです。各キーはラベル、値は割合を表します。
*   `total`: データの合計値を計算します。
*   `angle`: 各要素の割合に基づいて、円弧の角度を計算します。
*   `pen.circle(100, angle)`: 指定された角度で円弧を描画します。
*   凡例の描画は、角度の中間地点を計算し、その位置にラベルを描画することで実現しています。

**散布図の描画:**

散布図を描画するためには、x座標とy座標のデータを用意し、それらを点としてプロットします。

```python
import turtle

screen = turtle.Screen()
screen.setup(width=600, height=600)
screen.bgcolor("white")
screen.title("散布図")

pen = turtle.Turtle()
pen.speed(0)
pen.hideturtle()

def draw_scatter_plot(data):
    # 軸の描画
    pen.penup()
    pen.goto(-200, 0)
    pen.pendown()
    pen.forward(400) # x軸
    pen.penup()
    pen.goto(0, -200)
    pen.pendown()
    pen.left(90)
    pen.forward(400) # y軸
    pen.right(90)

    for x, y, label in data:
        pen.penup()
        pen.goto(x, y)
        pen.pendown()
        pen.dot(5, "blue") # 点を描画
        # ラベルを付ける (オプション)
        # pen.write(label, align="left")

data = [
    (50, 80, "A"),
    (120, 30, "B"),
    (80, 150, "C"),
    (180, 100, "D")
]

draw_scatter_plot(data)

screen.mainloop()
```

**解説:**

*   `data`: 散布図のデータです。各要素は、x座標、y座標、ラベルのタプルです。
*   `pen.dot(5, "blue")`: 指定された直径と色の点でプロットします。

#### 実践的なテクニック

*   **円グラフ:**
    *   要素数の制限: 要素数が多すぎると、グラフが見にくくなるため、要素数を制限するか、他のグラフ形式を検討してください。
    *   ラベルの工夫: ラベルが重ならないように、位置を調整したり、フォントサイズを小さくしたりしてください。
    *   3D表現: 円グラフを3Dで表現することで、視覚的なインパクトを与えることができます。 (タートルでは難しいですが、概念として)
*   **散布図:**
    *   軸のスケール調整: データの範囲に合わせて、軸のスケールを調整してください。
    *   回帰直線の追加: データの相関関係を示すために、回帰直線を追加することができます。 (タートルで計算するのは大変ですが、概念として)
    *   色の使い分け: データの種類に応じて、色を使い分けることで、グラフの見やすさを向上させることができます。
    *   バブルチャート：点の大きさをデータの値に応じて変えることで、3つ目の変数を表現できます。 (タートルでは難しいですが、概念として)

#### 応用例とユースケース

*   **円グラフ:**
    *   市場シェアの可視化: 各企業の市場シェアを円グラフで表示することで、市場の構造を把握することができます。
    *   予算配分の可視化: 各費目の予算配分を円グラフで表示することで、予算の重点配分を理解することができます。
*   **散布図:**
    *   身長と体重の関係: 身長と体重のデータを散布図で表示することで、身長と体重の相関関係を分析することができます。
    *   広告費と売上の関係: 広告費と売上のデータを散布図で表示することで、広告費が売上に与える影響を分析することができます。

#### トラブルシューティング

*   **円グラフ:**
    *   割合が100%にならない: データに誤りがないか確認してください。
    *   ラベルが重なって読みにくい: ラベルの位置を調整するか、フォントサイズを小さくしてください。
*   **散布図:**
    *   点が画面からはみ出す: 軸のスケールを調整してください。
    *   点が密集して見にくい: 点のサイズを小さくするか、軸のスケールを調整してください。

#### まとめと次のステップ

円グラフと散布図は、データの種類に合わせて適切なグラフを選択することで、データの持つ情報を効果的に伝えることができます。次のステップでは、Web APIからデータを取得して、これらのグラフを描画する方法について学びましょう。

### 7.3 実践的なデータ可視化：Web APIからデータを取得してグラフを描く

#### 概要と重要性

現代のデータ可視化において、Web APIからリアルタイムにデータを取得し、それをグラフとして表示する能力は非常に重要です。これにより、最新の情報を反映した動的なグラフを作成し、状況の変化を迅速に把握することができます。

#### 特徴と利点

*   **リアルタイム性:** 最新のデータを反映したグラフを表示できます。
*   **自動化:** 定期的にデータを取得してグラフを更新することができます。
*   **多様なデータソース:** 様々なWeb APIからデータを取得できます。

#### 事前準備と前提条件

*   7.1節と同様に、Pythonとturtleモジュールが必要です。
*   `requests`モジュールのインストール: Web APIからデータを取得するために使用します。インストールするには、`pip install requests`を実行してください。
*   JSON形式のデータを取り扱うため、`json`モジュールも使用します（標準ライブラリに含まれます）。

#### 基本的な使い方

ここでは、例として、JSONPlaceholderというダミーAPIからデータを取得して、ユーザーごとの投稿数を棒グラフで表示する例を示します。

```python
import turtle
import requests
import json

screen = turtle.Screen()
screen.setup(width=800, height=600)
screen.bgcolor("white")
screen.title("Web APIから取得したデータによる棒グラフ")

pen = turtle.Turtle()
pen.speed(0)
pen.hideturtle()

def draw_bar(height, label, color):
    pen.fillcolor(color)
    pen.begin_fill()
    pen.left(90)
    pen.forward(height)
    pen.write(label, align="center")
    pen.right(90)
    pen.forward(40)
    pen.right(90)
    pen.forward(height)
    pen.left(90)
    pen.end_fill()

def get_user_post_counts():
    url = "https://jsonplaceholder.typicode.com/posts"
    response = requests.get(url)
    if response.status_code == 200:
        posts = json.loads(response.text)
        user_post_counts = {}
        for post in posts:
            user_id = post["userId"]
            if user_id in user_post_counts:
                user_post_counts[user_id] += 1
            else:
                user_post_counts[user_id] = 1
        return user_post_counts
    else:
        print("APIリクエストに失敗しました:", response.status_code)
        return None

user_post_counts = get_user_post_counts()

if user_post_counts:
    x_start = -150
    pen.penup()
    pen.goto(x_start, -100)
    pen.pendown()

    colors = ["red", "green", "blue", "orange", "purple", "pink", "brown", "gray", "cyan", "magenta"]
    i = 0
    for user_id, post_count in user_post_counts.items():
        color = colors[i % len(colors)]
        draw_bar(post_count * 10, f"User {user_id}", color) # データの値を調整
        i += 1

screen.mainloop()
```

**解説:**

*   `requests.get(url)`: 指定されたURLにHTTPリクエストを送信し、レスポンスを取得します。
*   `response.status_code`: レスポンスのステータスコードを確認します。200は成功を表します。
*   `json.loads(response.text)`: JSON形式のレスポンスをPythonのオブジェクトに変換します。
*   `get_user_post_counts()`: Web APIからデータを取得し、ユーザーごとの投稿数を集計する関数です。
*   `user_post_counts`: ユーザーごとの投稿数を格納した辞書です。
*   `draw_bar(post_count * 10, f"User {user_id}", color)`: ユーザーごとの投稿数を棒グラフで描画します。投稿数の値を調整することで、グラフのスケールを調整できます。

#### 実践的なテクニック

*   **APIキーの管理:** APIキーが必要な場合は、環境変数に格納するなど、安全に管理してください。
*   **エラー処理:** APIリクエストが失敗した場合のエラー処理を実装してください。
*   **データの整形:** APIから取得したデータを、グラフの描画に適した形式に整形してください。
*   **キャッシュ:** 同じデータを何度も取得しないように、キャッシュを利用してください。

#### 応用例とユースケース

*   **株価の可視化:** 株価APIから株価データを取得して、折れ線グラフで表示することで、株価の推移をリアルタイムに把握することができます。
*   **天気予報の可視化:** 天気予報APIから天気予報データを取得して、棒グラフや円グラフで表示することで、天気予報の情報を視覚的に理解することができます。
*   **ソーシャルメディアのトレンド可視化:** ソーシャルメディアAPIからトレンドデータを取得して、棒グラフやワードクラウドで表示することで、ソーシャルメディアのトレンドを把握することができます。

#### トラブルシューティング

*   **APIリクエストが失敗する:** APIキーが正しいか、APIの利用制限を超えていないか確認してください。
*   **データが正しく表示されない:** データの形式がグラフの描画に適しているか確認してください。
*   **グラフの更新が遅い:** キャッシュを利用するか、APIリクエストの頻度を減らしてください。

#### まとめと次のステップ

Web APIからデータを取得してグラフを描画することで、最新の情報を反映した動的なグラフを作成し、状況の変化を迅速に把握することができます。この技術は、データに基づいた意思決定を支援するための強力なツールとなります。次のステップでは、より高度なデータ可視化技術について学び、より複雑なデータを効果的に表現する方法を検討しましょう。例えば、対話的なグラフを作成したり、複数のグラフを組み合わせてダッシュボードを作成したりすることが考えられます。
