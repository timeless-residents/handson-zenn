# 第 2 章：環境構築：安全なテスト環境を構築する

安全なペネトレーションテストを行うためには、本番環境を危険に晒すことなく、様々な攻撃手法を試せるテスト環境の構築が不可欠です。この章では、仮想環境、脆弱性のある Web アプリケーション、プロキシサーバー、VPN といった、ペネトレーションテストに必須な要素を段階的に構築し、安全かつ効率的なテスト環境の構築方法を解説します。

### 仮想環境の構築 (VirtualBox, VMware)

**概要と重要性**

テスト環境と本番環境を分離することは、ペネトレーションテストにおける最も重要な原則の一つです。攻撃が成功した場合でも、本番環境への影響を最小限に抑え、データの損失やシステムの停止を防ぐことができます。仮想環境は、この分離を実現するための最も一般的な手段であり、VirtualBox や VMware などのソフトウェアを利用することで、物理的なリソースを共有しながら、複数の独立したオペレーティングシステムを実行できます。

**特徴と利点**

- **隔離性:** 仮想マシンはホスト OS から完全に隔離されており、相互に干渉しません。
- **柔軟性:** 異なる OS やソフトウェア構成を簡単に試すことができます。
- **可搬性:** 仮想マシンはファイルとして保存できるため、簡単にバックアップや移動が可能です。
- **スナップショット:** 特定の状態を保存し、いつでもその状態に戻すことができます。攻撃が成功した場合でも、すぐに元の状態に戻してテストを再開できます。

**事前準備と前提条件**

- VirtualBox または VMware Workstation Player (無償版あり)のインストール
- 十分なディスク容量とメモリ(8GB 以上推奨)
- オペレーティングシステムのインストールイメージ(ISO ファイル)

**基本的な使い方**

1.  VirtualBox または VMware を起動し、新しい仮想マシンを作成します。
2.  仮想マシンの名前、OS の種類、メモリサイズ、ハードディスクサイズなどを設定します。
3.  OS のインストールイメージ(ISO ファイル)を指定し、仮想マシンを起動します。
4.  OS のインストール手順に従って、OS を仮想マシンにインストールします。

**実践的なテクニック**

- **ネットワーク構成:** 仮想マシンを NAT (Network Address Translation)モードで設定すると、ホスト OS を経由してインターネットに接続できます。また、ブリッジアダプターモードで設定すると、仮想マシンはホスト OS と同じネットワークに直接接続できます。ペネトレーションテストでは、攻撃対象のネットワーク環境を再現するために、ネットワーク構成を適切に設定することが重要です。
- **スナップショットの活用:** テスト前にスナップショットを作成し、テスト後に元の状態に戻すことで、クリーンな状態でテストを繰り返すことができます。
- **セキュリティディストリビューションの利用:** Kali Linux や Parrot OS などのセキュリティディストリビューションには、ペネトレーションテストに必要なツールが予めインストールされています。これらのディストリビューションを仮想マシンにインストールすることで、すぐにテストを開始できます。

**Kali Linux, Parrot OS などのセキュリティディストリビューションの紹介**

- **Kali Linux:** Offensive Security によって開発された、最も有名なペネトレーションテストディストリビューションです。Metasploit Framework, Nmap, Wireshark など、豊富なツールがプリインストールされています。
- **Parrot OS:** Kali Linux と同様に、ペネトレーションテストやデジタルフォレンジックに特化したディストリビューションです。より軽量で、様々なデスクトップ環境が用意されています。
- **BlackArch:** Arch Linux をベースとした、ペネトレーションテスターやセキュリティ研究者向けのディストリビューションです。非常に多くのセキュリティツールが含まれています。

**Docker コンテナを利用した環境構築**

Docker コンテナは、仮想マシンよりも軽量で高速な仮想化技術です。Web アプリケーションのテスト環境や、特定のツールを隔離された環境で実行する場合に便利です。

**Docker のインストール**

Docker の公式ウェブサイトから、お使いの OS に合わせた Docker Desktop をダウンロードし、インストールしてください。

**Docker イメージの利用**

Docker Hub には、様々な Web アプリケーションやツールが Docker イメージとして公開されています。例えば、DVWA (Damn Vulnerable Web Application)の Docker イメージを利用することで、簡単に脆弱性のある Web アプリケーションのテスト環境を構築できます。

```bash
# DVWAのDockerイメージをダウンロード
docker pull vulnerables/web-dvwa

# Dockerコンテナを起動
docker run -d -p 80:80 --name dvwa --rm vulnerables/web-dvwa
```

このコマンドを実行すると、DVWA が 80 番ポートで起動します。ブラウザから`http://localhost`にアクセスすると、DVWA のログイン画面が表示されます。

**応用例とユースケース**

- **マルウェア解析:** マルウェアを仮想マシン上で実行し、その動作を監視することで、安全にマルウェア解析を行うことができます。
- **ネットワーク侵入テスト:** 仮想マシンを攻撃対象ネットワークの一部として構成し、ネットワーク侵入テストを行うことができます。
- **脆弱性評価:** 脆弱性スキャナを使用して、仮想マシン上のアプリケーションの脆弱性を評価することができます。

**トラブルシューティング**

- **ネットワーク接続の問題:** NAT モードでインターネットに接続できない場合は、ホスト OS のファイアウォール設定を確認してください。
- **パフォーマンスの問題:** 仮想マシンのメモリサイズを増やすか、ホスト OS 上の不要なプロセスを停止してください。
- **仮想マシンの起動エラー:** BIOS で仮想化支援機能(VT-x/AMD-V)が有効になっているか確認してください。

**まとめと次のステップ**

このセクションでは、仮想環境の構築方法について解説しました。次のセクションでは、脆弱性のある Web アプリケーションのセットアップについて解説します。

### Web アプリケーションのセットアップ

**概要と重要性**

脆弱性のある Web アプリケーションは、ペネトレーションテストの腕を磨くための最高の教材です。これらのアプリケーションは、意図的に様々な脆弱性が組み込まれており、攻撃者がどのようにシステムに侵入するかを学ぶことができます。

**特徴と利点**

- **安全な学習環境:** 本番環境を危険に晒すことなく、様々な攻撃手法を試すことができます。
- **実践的なスキル習得:** 実際の脆弱性に基づいた攻撃を経験することで、実践的なスキルを習得できます。
- **脆弱性の理解:** 脆弱性の根本原因を理解し、その対策を学ぶことができます。

**事前準備と前提条件**

- 仮想環境の構築 (VirtualBox または VMware)
- Web サーバー (Apache または Nginx) のインストール
- PHP, MySQL などの必要なソフトウェアのインストール

**Vulnerable Web Apps (DVWA, WebGoat, bWAPP) の導入**

- **DVWA (Damn Vulnerable Web Application):** PHP で書かれた、初心者向けの脆弱性のある Web アプリケーションです。SQL インジェクション、クロスサイトスクリプティング (XSS)、コマンドインジェクションなど、様々な脆弱性が含まれています。
- **WebGoat:** OWASP によって開発された、Java で書かれた脆弱性のある Web アプリケーションです。より高度な脆弱性が含まれており、上級者向けの教材として最適です。
- **bWAPP (Buggy Web Application):** PHP で書かれた、初心者から上級者まで対応できる脆弱性のある Web アプリケーションです。100 以上の異なる脆弱性が含まれており、幅広い攻撃手法を学ぶことができます。

**導入方法 (DVWA の例)**

1.  DVWA の公式サイトからソースコードをダウンロードします。
2.  Web サーバーのドキュメントルートにファイルを展開します。
3.  `config/config.inc.php`ファイルを編集し、データベース接続情報を設定します。
4.  ブラウザから DVWA にアクセスし、データベースを初期化します。

**ローカル環境での WordPress, Django などの CMS 構築**

WordPress や Django などの CMS (Content Management System)も、ペネトレーションテストの対象として重要です。これらの CMS には、脆弱性が存在する可能性があり、攻撃者がシステムに侵入する経路となることがあります。

**WordPress の構築**

1.  WordPress の公式サイトからソースコードをダウンロードします。
2.  Web サーバーのドキュメントルートにファイルを展開します。
3.  MySQL データベースを作成します。
4.  ブラウザから WordPress にアクセスし、インストールウィザードに従って設定を行います。

**Django の構築**

1.  Python と pip をインストールします。
2.  `pip install django`で Django をインストールします。
3.  `django-admin startproject myproject`で新しいプロジェクトを作成します。
4.  `python manage.py migrate`でデータベースを初期化します。
5.  `python manage.py runserver`で開発サーバーを起動します。

**脆弱性のある Web アプリケーションを利用する際の注意点**

- **本番環境で使用しない:** 脆弱性のある Web アプリケーションは、本番環境で使用しないでください。攻撃者がシステムに侵入する可能性があります。
- **最新バージョンを使用する:** 脆弱性が修正された最新バージョンを使用してください。
- **定期的なアップデート:** Web アプリケーションや関連ソフトウェアを定期的にアップデートしてください。
- **セキュリティ設定の確認:** Web アプリケーションのセキュリティ設定を確認し、適切な設定を行ってください。

**実践的なテクニック**

- **脆弱性の特定:** 脆弱性スキャナを使用して、Web アプリケーションの脆弱性を特定します。
- **攻撃の実行:** 脆弱性を利用して、Web アプリケーションに攻撃を実行します。
- **脆弱性の修正:** 脆弱性を修正し、Web アプリケーションのセキュリティを向上させます。
- **レポート作成:** 脆弱性の特定、攻撃の実行、脆弱性の修正結果をレポートにまとめます。

**応用例とユースケース**

- **Web アプリケーションの脆弱性診断:** Web アプリケーションの脆弱性を診断し、セキュリティリスクを評価します。
- **ペネトレーションテスト:** Web アプリケーションの脆弱性を利用して、システムに侵入できるかどうかをテストします。
- **セキュリティ教育:** Web アプリケーションの脆弱性を利用して、開発者や運用担当者にセキュリティ教育を行います。

**トラブルシューティング**

- **Web アプリケーションにアクセスできない:** Web サーバーの設定を確認してください。
- **データベース接続エラー:** データベース接続情報を確認してください。
- **脆弱性が悪用された:** Web アプリケーションを最新バージョンにアップデートし、セキュリティ設定を見直してください。

### プロキシサーバーの導入 (Burp Suite, OWASP ZAP)

**概要と重要性**

プロキシサーバーは、Web ブラウザと Web サーバーの間に入り、HTTP リクエスト/レスポンスを傍受、改ざん、分析するためのツールです。ペネトレーションテストにおいて、プロキシサーバーは Web アプリケーションの動作を理解し、脆弱性を特定するために不可欠です。

**特徴と利点**

- **HTTP リクエスト/レスポンスの傍受:** Web ブラウザと Web サーバーの間でやり取りされるすべての HTTP リクエスト/レスポンスを傍受できます。
- **HTTP リクエスト/レスポンスの改ざん:** リクエストの内容を改ざんし、Web アプリケーションの動作をテストできます。
- **脆弱性の特定:** 傍受したリクエスト/レスポンスを分析し、SQL インジェクション、XSS などの脆弱性を特定できます。

**事前準備と前提条件**

- Java Runtime Environment (JRE) のインストール
- Web ブラウザ (Firefox 推奨)
- Burp Suite または OWASP ZAP のインストール

**Burp Suite Community Edition と Professional Edition の違い**

- **Burp Suite Community Edition:** 無償版ですが、機能が制限されています。自動スキャン機能、脆弱性スキャナ、高度なリピーター機能などが利用できません。
- **Burp Suite Professional Edition:** 有償版ですが、すべての機能が利用できます。大規模な Web アプリケーションのペネトレーションテストに最適です。

**OWASP ZAP のインストールと基本的な使い方**

1.  OWASP ZAP の公式サイトからインストーラをダウンロードし、インストールします。
2.  OWASP ZAP を起動します。
3.  Web ブラウザのプロキシ設定を OWASP ZAP のプロキシポート (通常は 8080) に設定します。
4.  Web ブラウザで Web アプリケーションにアクセスすると、OWASP ZAP が HTTP リクエスト/レスポンスを傍受します。
5.  OWASP ZAP のインターフェースで、傍受したリクエスト/レスポンスを確認し、脆弱性を特定します。

**Burp Suite Community Edition のインストールと基本的な使い方**

1.  Burp Suite の公式サイトからインストーラをダウンロードし、インストールします。
2.  Burp Suite を起動します。
3.  Web ブラウザのプロキシ設定を Burp Suite のプロキシポート (通常は 8080) に設定します。
4.  Burp Suite のインターフェースで、Proxy -> Intercept タブを選択し、Intercept is on を確認します。
5.  Web ブラウザで Web アプリケーションにアクセスすると、Burp Suite が HTTP リクエスト/レスポンスを傍受します。
6.  Burp Suite のインターフェースで、リクエスト/レスポンスを確認し、必要に応じて改ざんし、Forward ボタンをクリックしてリクエストを送信します。

**プロキシ設定とブラウザの設定**

1.  Web ブラウザの設定画面を開きます。
2.  プロキシ設定を探し、手動プロキシ設定を選択します。
3.  HTTP プロキシと HTTPS プロキシに`localhost`または`127.0.0.1`と入力し、ポート番号に 8080 を入力します。
4.  プロキシ設定を保存します。

**実践的なテクニック**

- **リピーター機能:** 特定のリクエストを繰り返し送信し、Web アプリケーションの動作を詳細に分析します。
- **インターセプター機能:** リクエストを傍受し、内容を改ざんしてから送信します。SQL インジェクションや XSS のテストに有効です。
- **スパイダー機能:** Web アプリケーションのリンクを自動的にクロールし、Web サイトの構造を把握します。
- **自動スキャン機能 (Professional Edition のみ):** Web アプリケーションの脆弱性を自動的にスキャンします。

**応用例とユースケース**

- **SQL インジェクションのテスト:** リクエストに悪意のある SQL コードを注入し、データベースから情報を盗み出すことができるかどうかをテストします。
- **XSS のテスト:** リクエストに悪意のある JavaScript コードを注入し、Web サイトのユーザーのブラウザ上でコードを実行できるかどうかをテストします。
- **認証バイパスのテスト:** 認証をバイパスして、Web アプリケーションの管理機能にアクセスできるかどうかをテストします。

**トラブルシューティング**

- **プロキシサーバーがリクエストを傍受しない:** Web ブラウザのプロキシ設定が正しいか確認してください。
- **Web サイトにアクセスできない:** プロキシサーバーの設定を確認してください。
- **SSL/TLS 証明書のエラー:** プロキシサーバーの証明書を Web ブラウザにインストールしてください。

### VPN の利用と匿名化

**概要と重要性**

VPN (Virtual Private Network)は、インターネット接続を暗号化し、IP アドレスを隠蔽することで、プライバシーを保護するためのツールです。ペネトレーションテストにおいて、VPN は攻撃者の身元を隠し、追跡を困難にするために利用されます。

**特徴と利点**

- **IP アドレスの隠蔽:** 実際の IP アドレスを隠蔽し、VPN サーバーの IP アドレスを表示します。
- **通信の暗号化:** インターネット接続を暗号化し、通信内容を保護します。
- **地理的な制限の回避:** VPN サーバーの所在地に基づいて、地理的な制限を回避できます。

**事前準備と前提条件**

- VPN サービスの契約
- VPN クライアントソフトウェアのインストール

**VPN サービスの選定と設定**

- **有料 VPN サービス:** NordVPN, ExpressVPN, Surfshark など、多くの有料 VPN サービスがあります。これらのサービスは、高速な接続速度、多くのサーバーロケーション、高度なセキュリティ機能を提供します。
- **無料 VPN サービス:** 無料 VPN サービスもありますが、一般的に接続速度が遅く、セキュリティが低い場合があります。また、ログを収集して販売するなどのリスクもあります。

**VPN の設定**

1.  VPN クライアントソフトウェアを起動します。
2.  VPN サービスの認証情報を入力します。
3.  VPN サーバーのロケーションを選択します。
4.  VPN 接続を確立します。

**TOR ネットワークの利用と注意点**

TOR (The Onion Router)は、匿名性の高い通信を実現するためのネットワークです。TOR ネットワークは、世界中のボランティアによって運営されており、複数の暗号化レイヤーを通過することで、通信を追跡困難にします。

**TOR ブラウザの利用**

TOR ネットワークを利用するためには、TOR ブラウザをインストールする必要があります。TOR ブラウザは、Firefox をベースに開発されており、TOR ネットワークに接続するための設定が予め行われています。

**TOR ネットワークの利用と注意点**

- **匿名性の高さ:** TOR ネットワークは、IP アドレスを隠蔽し、通信を暗号化することで、高い匿名性を実現します。
- **接続速度の低下:** TOR ネットワークは、複数の暗号化レイヤーを通過するため、接続速度が低下します。
- **法的責任:** TOR ネットワークを利用して違法行為を行った場合、法的責任を問われる可能性があります。

**実践的なテクニック**

- **VPN と TOR の組み合わせ:** VPN と TOR を組み合わせて利用することで、さらに高い匿名性を実現できます。
- **DNS リークテスト:** VPN 接続後に、DNS リークテストを行い、IP アドレスが漏洩していないか確認します。
- **WebRTC リークテスト:** VPN 接続後に、WebRTC リークテストを行い、IP アドレスが漏洩していないか確認します。

**応用例とユースケース**

- **匿名での情報収集:** 匿名で Web サイトを閲覧したり、情報を収集したりすることができます。
- **検閲の回避:** 政府による検閲を回避し、自由にインターネットを利用することができます。
- **セキュリティ研究:** マルウェア解析や脆弱性調査などのセキュリティ研究を、匿名で行うことができます。

**トラブルシューティング**

- **VPN 接続が確立できない:** VPN サーバーの設定を確認してください。
- **インターネット接続が遅い:** VPN サーバーのロケーションを変更してください。
- **IP アドレスが漏洩している:** DNS リークテストや WebRTC リークテストを行い、IP アドレスが漏洩していないか確認してください。
