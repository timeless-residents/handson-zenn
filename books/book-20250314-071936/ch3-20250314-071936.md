## 第3章：Praatスクリプトで実現！音声パラメータ自動抽出の基礎

この章では、音声分析ソフトウェアPraatを用いて、音声パラメータを自動抽出するための基礎を解説します。基本周波数(F0)、フォルマント周波数、音声強度といった重要なパラメータを、Praatスクリプトを使って効率的に取得する方法を習得しましょう。音声分析の自動化は、研究、音声認識、音声合成、言語教育など、幅広い分野で役立ちます。

### 音声分析の「鍵」：重要な音声パラメータを理解する

#### 1. 概要と重要性

音声パラメータは、音声を特徴づける数値的な指標です。これらのパラメータを分析することで、話者の性別、年齢、感情、健康状態、発音の正確さなどを推測できます。特に、基本周波数(F0)、フォルマント周波数、音声強度は、音声分析における「3種の神器」とも言えるほど重要なパラメータです。これらのパラメータを理解し、適切に抽出・分析することで、音声データの背後にある情報を効果的に引き出すことができます。

#### 2. 特徴と利点

* **基本周波数(F0)**: 声の高さに対応し、話者の性別や感情、イントネーションを反映します。
* **フォルマント周波数**: 声道の共鳴特性を反映し、母音の識別や話者の個人性を識別する上で重要です。
* **音声強度**: 音の大きさに対応し、発話のエネルギーや強調を表します。

これらのパラメータを個別に、あるいは組み合わせて分析することで、音声の多様な側面を定量的に評価できます。自動抽出を行うことで、大量の音声データを効率的に処理し、客観的な分析結果を得ることができます。

#### 3. 事前準備と前提条件

* **Praatのインストール**: 公式ウェブサイト([http://www.fon.hum.uva.nl/praat/](http://www.fon.hum.uva.nl/praat/))から最新版をダウンロードし、インストールしてください。
* **音声データの準備**: 分析対象となる音声データ（.wav形式など）を用意してください。録音環境や音質によって分析結果が左右されるため、できるだけノイズの少ないクリアな音声データを使用することを推奨します。
* **基本的なPraatの操作**: Praatの基本的な操作（音声ファイルの読み込み、表示、再生など）を理解していることが望ましいです。PraatのGUIに触れて、基本的な操作に慣れておきましょう。

#### 4. 基本的な使い方

PraatのGUIから手動でパラメータを抽出することも可能ですが、大量のデータを処理する場合はスクリプトを使用するのが効率的です。まずは、簡単なスクリプトを作成し、基本的なパラメータ抽出の流れを理解しましょう。

#### 5. 実践的なテクニック

スクリプト内で、パラメータの抽出範囲やアルゴリズムの調整、エラー処理などを組み込むことで、より高度な分析が可能になります。例えば、無音区間を除外したり、特定の時間範囲のみを分析したり、外れ値を自動的に除去したりする処理を追加することができます。

#### 6. 応用例とユースケース

* **音声認識**: 音声認識エンジンの精度向上に向けて、特徴量としてF0やフォルマントを利用する。
* **音声合成**: 合成音声の自然性を高めるために、ターゲット話者のF0パターンやフォルマント周波数を模倣する。
* **言語教育**: 発音矯正ツールにおいて、学習者の発音と模範的な発音のF0パターンやフォルマント周波数を比較し、視覚的にフィードバックを提供する。
* **音声病理学**: 嗄声の客観的な評価指標として、F0の変動や音声強度の低下を定量的に分析する。
* **感情認識**: 発話におけるF0の変動パターンから、話者の感情状態（喜び、悲しみ、怒りなど）を推定する。
* **方言識別**: 特定の方言に特徴的なフォルマント周波数のパターンを抽出し、方言を識別する手がかりとする。
* **ストレス評価**: ストレス状態にある人の音声は、F0や音声強度が通常よりも変動しやすい傾向があるため、これらのパラメータを分析してストレスレベルを評価する。

#### 7. トラブルシューティング

* **パラメータが抽出できない**: 音声ファイルの形式がPraatでサポートされているか確認してください。また、音声データにノイズが多い場合、パラメータ抽出がうまくいかないことがあります。ノイズ除去処理を行うか、より高品質な音声データを準備してください。
* **抽出された値が異常**: ピッチトラッキングやLPC分析の設定が適切でない可能性があります。パラメータ設定を調整するか、他のアルゴリズムを試してみてください。
* **スクリプトが実行できない**: スクリプトに構文エラーがないか確認してください。また、必要なオブジェクトが存在するか、パスが正しいかなどを確認してください。PraatのError Logを確認することで、エラーの原因を特定できます。

### 基本周波数(F0)抽出：ピッチトラッキングアルゴリズムの概要

#### 1. 概要と重要性

基本周波数(F0)は、声の高さ（ピッチ）に対応するパラメータであり、声帯の振動数を示します。F0は、話者の性別や年齢、感情、イントネーションなどを反映するため、音声分析において非常に重要な指標となります。ピッチトラッキングとは、音声信号からF0を推定する技術のことです。

#### 2. 特徴と利点

* **性別識別**: 一般的に、男性よりも女性の方が高いF0を持ちます。
* **感情認識**: 喜びや興奮などの感情は、F0の上昇や変動の増加と関連があります。
* **イントネーション分析**: 発話におけるF0の変動パターンを分析することで、文の種類（疑問文、命令文など）や強調箇所を特定できます。

Praatには、様々なピッチトラッキングアルゴリズムが実装されており、音声データの特性や分析目的に応じて適切なアルゴリズムを選択できます。

#### 3. 事前準備と前提条件

* **音声データの準備**: 分析対象となる音声データ（.wav形式など）を用意してください。
* **Praatの起動**: Praatを起動し、音声ファイルを読み込んでください。
* **音声オブジェクトの選択**: Praat Objectsウィンドウで、読み込んだ音声オブジェクトを選択してください。

#### 4. 基本的な使い方

PraatスクリプトでF0を抽出する基本的なコードは以下の通りです。

```praat
# 音声ファイルの読み込み (例)
Read from file: "audio.wav"

# ピッチオブジェクトの作成
To Pitch: 0.0, 75, 600  # timeStep, minimum pitch, maximum pitch

# ピッチ値の取得
Get mean: 0, 0, "Hertz" # startTime, endTime, unit
```

このスクリプトは、以下の処理を行います。

1. `Read from file`：音声ファイルを読み込みます。ファイルパスは適宜変更してください。
2. `To Pitch`：ピッチオブジェクトを作成します。引数は、それぞれ`timeStep`(F0を算出する時間間隔)、`minimum pitch`(最小F0)、`maximum pitch`(最大F0)を表します。話者の性別や声域に合わせて、`minimum pitch`と`maximum pitch`を調整してください。一般的に、男性の場合は75-300 Hz、女性の場合は100-600 Hz程度が適切です。
3. `Get mean`：ピッチオブジェクトから、指定された時間範囲における平均F0を取得します。`startTime`と`endTime`はそれぞれ開始時刻と終了時刻を表し、0を指定すると音声ファイル全体を対象とします。`unit`はF0の単位（Hertz, Melなど）を指定します。

#### 5. 実践的なテクニック

* **パラメータの調整**: `To Pitch`コマンドのパラメータを調整することで、ピッチトラッキングの精度を向上させることができます。`timeStep`を小さくすると、より細かい時間単位でF0を算出できますが、計算量が増加します。
* **無音区間の除外**: 発話区間のみを分析対象とすることで、ノイズの影響を低減できます。VAD(Voice Activity Detection)アルゴリズムを用いて無音区間を検出し、スクリプトで除外することができます。
* **外れ値の除去**: ピッチトラッキングの結果に、明らかに異常な値が含まれる場合があります。これらの外れ値をスクリプトで自動的に除去することができます。例えば、F0の値が急激に変化した場合や、事前に設定した範囲外の値である場合に、外れ値として除去します。

```praat
# 外れ値除去の例 (平均値から標準偏差の3倍以上離れた値を外れ値とみなす)

pitch = selected("Pitch")
mean = Pitch_mean(pitch, 0, 0, "Hertz")
standardDeviation = Pitch_standardDeviation(pitch, 0, 0, "Hertz")

minimumF0 = mean - 3 * standardDeviation
maximumF0 = mean + 3 * standardDeviation

for i from 1 to Pitch_getNumberOfFrames (pitch)
  f0 = Pitch_getValueAtFrame (pitch, i, "Hertz")
  if f0 < minimumF0 or f0 > maximumF0
    Pitch_setValueAtFrame (pitch, i, 0) # 外れ値を0に設定
  endif
endfor
```

#### 6. 応用例とユースケース

* **音声病理学**: 嗄声の客観的な評価指標として、F0の変動やジッタ（F0の短時間変動）を定量的に分析する。
* **感情認識**: 発話におけるF0の変動パターンから、話者の感情状態（喜び、悲しみ、怒りなど）を推定する。

#### 7. トラブルシューティング

* **ピッチがうまく抽出できない**: 音声データにノイズが多い場合や、声が小さすぎる場合、ピッチトラッキングがうまくいかないことがあります。ノイズ除去処理を行うか、録音環境を改善してください。
* **Octave Jump**: ピッチトラッキングアルゴリズムが、正しいF0の整数倍（または1/整数倍）の値を誤ってF0として検出してしまう現象です。`minimum pitch`と`maximum pitch`を適切に設定することで、Octave Jumpを回避できます。また、他のピッチトラッキングアルゴリズムを試すことも有効です。Praatには、`To Pitch (ac)`という自己相関関数に基づくピッチトラッキングアルゴリズムも実装されています。

### フォルマント周波数抽出：線形予測分析(LPC)の基礎

#### 1. 概要と重要性

フォルマント周波数とは、声道（口や鼻腔）の共鳴周波数のことで、音声の音色を決定する重要なパラメータです。特に、第1フォルマント(F1)と第2フォルマント(F2)は、母音の識別において非常に重要な役割を果たします。フォルマント周波数を分析することで、話者の個人性や発音の正確さなどを評価できます。線形予測分析(LPC)は、音声信号から効率的にフォルマント周波数を推定するための代表的な手法です。

#### 2. 特徴と利点

* **母音の識別**: F1とF2の値に基づいて、母音を分類することができます。
* **話者識別の手がかり**: 声道の形状は個人によって異なるため、フォルマント周波数は話者識別の手がかりとなります。
* **発音評価**: 発音訓練において、学習者のフォルマント周波数と目標とするフォルマント周波数を比較し、発音の改善に役立てることができます。

#### 3. 事前準備と前提条件

* **音声データの準備**: 分析対象となる音声データ（.wav形式など）を用意してください。
* **Praatの起動**: Praatを起動し、音声ファイルを読み込んでください。
* **音声オブジェクトの選択**: Praat Objectsウィンドウで、読み込んだ音声オブジェクトを選択してください。

#### 4. 基本的な使い方

Praatスクリプトでフォルマント周波数を抽出する基本的なコードは以下の通りです。

```praat
# 音声ファイルの読み込み (例)
Read from file: "audio.wav"

# フォルマントオブジェクトの作成
To Formant (burg): 0.005, 5, 5500, 0.025, 50 # timeStep, maxNumber Of Formants, maximumFormant, windowLength, preEmphasis

# フォルマント値の取得
Get value at time: 1, 1, "Hertz", "Linear"  # formantNumber, time, unit, interpolation
```

このスクリプトは、以下の処理を行います。

1. `Read from file`：音声ファイルを読み込みます。ファイルパスは適宜変更してください。
2. `To Formant (burg)`：フォルマントオブジェクトを作成します。引数は、それぞれ`timeStep`(フォルマントを算出する時間間隔)、`maxNumber Of Formants`(抽出するフォルマントの最大数)、`maximumFormant`(最大フォルマント周波数)、`windowLength`(分析窓の長さ)、`preEmphasis`(プリエンファシス係数)を表します。`maximumFormant`は、分析対象となる音声の最高周波数成分よりも高く設定する必要があります。一般的に、男性の場合は5000 Hz、女性の場合は5500 Hz程度が適切です。`windowLength`は、分析窓の長さを秒単位で指定します。`preEmphasis`は、高周波数成分を強調するための係数です。
3. `Get value at time`：指定された時刻における指定されたフォルマント周波数を取得します。`formantNumber`は抽出するフォルマントの番号（1は第1フォルマント、2は第2フォルマントなど）、`time`は時刻、`unit`は単位（Hertz, Melなど）、`interpolation`は補間方法（Linear, Nearestなど）を指定します。

#### 5. 実践的なテクニック

* **パラメータの調整**: `To Formant (burg)`コマンドのパラメータを調整することで、フォルマント抽出の精度を向上させることができます。`windowLength`を長くすると、周波数分解能が向上しますが、時間分解能が低下します。
* **母音区間の抽出**: 母音区間のみを分析対象とすることで、より正確なフォルマント周波数を抽出できます。
* **LPC次数**: `To Formant (burg)`を使用する場合、LPC次数は自動的に決定されます。しかし、必要に応じて`To Formant (manual)`を使用して、LPC次数を手動で設定することも可能です。LPC次数は、分析対象となる音声の帯域幅と密接に関連しています。一般的に、帯域幅が広いほど、高いLPC次数が必要となります。
* **プリエンファシス**: 高周波数の減衰を補正するために、プリエンファシスを適用します。`preEmphasis`パラメータでプリエンファシスの強さを調整できます。適切なプリエンファシスの強さは、音声データによって異なります。

#### 6. 応用例とユースケース

* **言語教育**: 発音矯正ツールにおいて、学習者の発音と模範的な発音のフォルマント周波数を比較し、視覚的にフィードバックを提供する。
* **音声合成**: 合成音声の自然性を高めるために、ターゲット話者のフォルマント周波数を模倣する。
* **方言識別**: 特定の方言に特徴的なフォルマント周波数のパターンを抽出し、方言を識別する手がかりとする。

#### 7. トラブルシューティング

* **フォルマントがうまく抽出できない**: 音声データにノイズが多い場合や、発音が不明瞭な場合、フォルマント抽出がうまくいかないことがあります。ノイズ除去処理を行うか、より高品質な音声データを準備してください。
* **フォルマントの値が異常**: LPC分析の設定が適切でない可能性があります。パラメータ設定を調整するか、他の分析手法を試してみてください。
* **フォルマントトラッキングの問題**: フォルマント周波数は時間とともに変動するため、フォルマントトラッキングが必要となる場合があります。フォルマントトラッキングとは、時間的に連続したフォルマント周波数の変化を追跡する技術のことです。Praatには、自動フォルマントトラッキング機能は実装されていませんが、スクリプトを用いて、時間的に連続したフォルマント周波数を平滑化したり、外れ値を除去したりすることで、擬似的なフォルマントトラッキングを実現できます。

### 音声強度(Intensity)抽出：RMSエネルギーの計算

#### 1. 概要と重要性

音声強度(Intensity)は、音の大きさを表すパラメータであり、発話のエネルギーや強調を表します。音声強度は、RMS(Root Mean Square)エネルギーとして計算されることが一般的です。音声強度を分析することで、話者の発話意図や感情などを推測できます。

#### 2. 特徴と利点

* **強調箇所の特定**: 発話において強調された箇所は、通常、音声強度が高くなります。
* **発話速度の評価**: 発話速度が速いほど、音声強度が低下する傾向があります。
* **感情認識**: 怒りや興奮などの感情は、音声強度の上昇と関連があります。

#### 3. 事前準備と前提条件

* **音声データの準備**: 分析対象となる音声データ（.wav形式など）を用意してください。
* **Praatの起動**: Praatを起動し、音声ファイルを読み込んでください。
* **音声オブジェクトの選択**: Praat Objectsウィンドウで、読み込んだ音声オブジェクトを選択してください。

#### 4. 基本的な使い方

Praatスクリプトで音声強度を抽出する基本的なコードは以下の通りです。

```praat
# 音声ファイルの読み込み (例)
Read from file: "audio.wav"

# 強度オブジェクトの作成
To Intensity: 75, 0, yes # minimum pitch, time step, subtract mean

# 強度値の取得
Get mean: 0, 0 # startTime, endTime
```

このスクリプトは、以下の処理を行います。

1. `Read from file`：音声ファイルを読み込みます。ファイルパスは適宜変更してください。
2. `To Intensity`：強度オブジェクトを作成します。引数は、それぞれ`minimum pitch`(最小ピッチ)、`time step`(時間ステップ)、`subtract mean`(平均値を引くかどうか)を表します。`minimum pitch`は、F0がこの値以下の場合は無音とみなされます。`time step`は、強度を算出する時間間隔を指定します。
3. `Get mean`：強度オブジェクトから、指定された時間範囲における平均強度を取得します。`startTime`と`endTime`はそれぞれ開始時刻と終了時刻を表し、0を指定すると音声ファイル全体を対象とします。

#### 5. 実践的なテクニック

* **パラメータの調整**: `To Intensity`コマンドのパラメータを調整することで、強度抽出の精度を向上させることができます。`time step`を小さくすると、より細かい時間単位で強度を算出できますが、計算量が増加します。
* **正規化**: 音声強度を正規化することで、録音環境や話者の個人差による影響を低減できます。例えば、最大値を1とするように正規化したり、平均値を0、標準偏差を1とするように正規化したりすることができます。

```praat
# 強度の正規化 (最大値を1とする)

intensity = selected("Intensity")
maximumIntensity = Intensity_getMaximum (intensity, 0, 0, "dB")

for i from 1 to Intensity_getNumberOfFrames (intensity)
  currentIntensity = Intensity_getValueAtFrame (intensity, i, "dB")
  normalizedIntensity = currentIntensity / maximumIntensity
  Intensity_setValueAtFrame (intensity, i, normalizedIntensity)
endfor
```

* **平滑化**: 強度の時間的な変動を平滑化することで、ノイズの影響を低減できます。移動平均フィルタやメディアンフィルタなどを適用することができます。

#### 6. 応用例とユースケース

* **発話速度の評価**: 発話速度が速いほど、音声強度が低下する傾向があります。
* **感情認識**: 怒りや興奮などの感情は、音声強度の上昇と関連があります。
* **音声認識**: 音声認識において、音声強度を特徴量として利用することで、認識精度を向上させることができます。

#### 7. トラブルシューティング

* **強度がうまく抽出できない**: 音声データにノイズが多い場合や、声が小さすぎる場合、強度抽出がうまくいかないことがあります。ノイズ除去処理を行うか、録音環境を改善してください。
* **強度値が異常**: `minimum pitch`の設定が適切でない可能性があります。パラメータ設定を調整してください。
