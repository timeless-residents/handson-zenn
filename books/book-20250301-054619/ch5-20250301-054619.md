## 第5章：Whisperで音声認識：音声をテキストに変換する

音声認識技術は、私たちの生活やビジネスにおいてますます重要な役割を担っています。会議の議事録作成、顧客からの問い合わせ内容の記録、動画コンテンツの字幕生成など、その用途は多岐にわたります。そして、OpenAIが開発したWhisperは、その高性能さから、音声認識の分野に大きな変革をもたらしました。

この章では、Whisperの概要から、実際に音声ファイルをテキストに変換する方法、さらにリアルタイム音声認識の実装まで、段階的に解説していきます。初心者の方でも理解しやすいように、基本的な使い方から応用例、トラブルシューティングまで網羅し、実務で活用できる知識を身につけることを目指します。

### Whisperの概要とモデルサイズ

#### 概要と重要性

Whisperは、OpenAIによって開発された、最先端の音声認識システムです。大量の音声データで学習されており、多言語に対応し、ノイズの多い環境でも高い精度で音声をテキストに変換することができます。従来の音声認識システムと比較して、Whisperは汎用性が高く、特定の環境や言語に特化することなく、幅広い用途に適用可能です。

#### 特徴と利点

Whisperの主な特徴と利点は以下の通りです。

*   **高精度な音声認識:** 大量の学習データにより、ノイズの多い環境や異なるアクセントの音声でも高い精度で認識できます。
*   **多言語対応:** 多くの言語に対応しており、グローバルなビジネスシーンでも活用できます。
*   **オープンソース:** モデルとコードが公開されており、誰でも自由に利用、カスタマイズ、研究が可能です。
*   **様々なモデルサイズ:** 用途や計算リソースに応じて、複数のモデルサイズから選択できます。

#### 事前準備と前提条件

Whisperを使用するには、以下の環境が必要です。

*   **Python:** 3.7以上が推奨されます。
*   **pip:** Pythonのパッケージ管理システム。
*   **PyTorch:** 機械学習ライブラリ。WhisperはPyTorch上で動作します。
*   **CUDA (オプション):** NVIDIAのGPUを利用する場合に必要です。高速な処理が期待できます。

これらの環境を整えるために、以下の手順を実行します。

1.  **Pythonのインストール:** Python公式サイト([https://www.python.org/](https://www.python.org/))から最新版をダウンロードし、インストールします。インストール時には、"Add Python to PATH"にチェックを入れることを推奨します。
2.  **PyTorchのインストール:** PyTorchの公式サイト([https://pytorch.org/](https://pytorch.org/))にアクセスし、ご自身の環境に合わせたインストールコマンドを確認してください。例えば、CUDAを使用しない場合は、以下のコマンドを実行します。

    ```bash
    pip install torch torchvision torchaudio
    ```

    CUDAを使用する場合は、公式サイトの指示に従ってCUDA Toolkitをインストールし、適切なバージョンのPyTorchをインストールしてください。
3.  **Whisperのインストール:** 以下のコマンドでWhisperをインストールします。

    ```bash
    pip install -U openai-whisper
    ```

    このコマンドは、最新バージョンのWhisperをインストールします。

#### 基本的な使い方

Whisperをインストールしたら、早速音声ファイルをテキストに変換してみましょう。

1.  **コマンドラインからの実行:** 以下のコマンドを実行します。

    ```bash
    whisper audio.mp3 --model medium
    ```

    ここで、`audio.mp3`は音声ファイル名、`medium`は使用するモデルサイズです。モデルサイズについては後述します。
2.  **Pythonスクリプトからの実行:** 以下のPythonスクリプトを作成し、実行します。

    ```python
    import whisper

    model = whisper.load_model("medium")
    result = model.transcribe("audio.mp3")
    print(result["text"])
    ```

    このスクリプトは、音声ファイル`audio.mp3`を`medium`モデルでテキストに変換し、結果を表示します。

#### モデルサイズ

Whisperには、複数のモデルサイズが用意されています。モデルサイズによって、精度と処理速度が異なります。

*   `tiny`: 最も小さいモデル。高速だが、精度は低い。
*   `base`: 小型モデル。`tiny`より精度が高いが、処理速度は遅い。
*   `small`: 中型モデル。バランスの取れた性能。
*   `medium`: 大型モデル。高精度だが、処理速度は遅い。
*   `large`: 最も大きいモデル。最高精度だが、処理速度は非常に遅い。`large-v2`が最新版です。

モデルサイズは、`whisper.load_model()`関数やコマンドラインオプションで指定します。

```python
model = whisper.load_model("large-v2")
```

処理速度と精度のバランスを考慮し、用途に合ったモデルサイズを選択することが重要です。特にGPUがない環境では、`tiny`や`base`モデルの使用を検討してください。

#### 実践的なテクニック

*   **言語指定:** 音声ファイルの言語が分かっている場合は、`language`オプションで指定することで、認識精度を向上させることができます。

    ```python
    result = model.transcribe("audio.mp3", language="ja")
    ```

    ```bash
    whisper audio.mp3 --language ja --model medium
    ```

*   **初回プロンプト:** `initial_prompt`オプションで、認識のヒントとなるテキストを指定できます。例えば、特定の単語やフレーズが頻繁に出現する場合、それをプロンプトとして与えることで、認識精度を向上させることができます。

    ```python
    result = model.transcribe("audio.mp3", initial_prompt="この会議では、AI技術について議論します。")
    ```

    ```bash
    whisper audio.mp3 --initial_prompt "この会議では、AI技術について議論します。" --model medium
    ```

*   **複数ファイルの処理:** 複数の音声ファイルをまとめて処理することも可能です。

    ```python
    import os
    import whisper

    model = whisper.load_model("medium")

    for filename in os.listdir("audio_files"):
        if filename.endswith(".mp3"):
            audio_path = os.path.join("audio_files", filename)
            result = model.transcribe(audio_path)
            with open(filename.replace(".mp3", ".txt"), "w") as f:
                f.write(result["text"])
    ```

    このスクリプトは、`audio_files`ディレクトリ内のすべてのMP3ファイルをテキストに変換し、対応するテキストファイルを作成します。

#### 応用例とユースケース

*   **会議の議事録作成:** 会議の音声を録音し、Whisperでテキストに変換することで、議事録作成を効率化できます。
*   **動画コンテンツの字幕生成:** 動画の音声をテキストに変換し、字幕ファイルを作成できます。
*   **コールセンターの通話記録分析:** コールセンターの通話記録をテキストに変換し、顧客のニーズや問題点を分析できます。
*   **音声アシスタントの開発:** 音声入力をテキストに変換し、コマンドとして解釈することで、音声アシスタントを開発できます。
*   **教育分野での活用:** 講義や講演の音声をテキストに変換し、学習教材として活用できます。

#### トラブルシューティング

*   **CUDAエラー:** CUDAが正しくインストールされていない場合や、GPUドライバが古い場合に発生することがあります。CUDA ToolkitのバージョンとGPUドライバのバージョンが一致しているか確認してください。
*   **メモリ不足エラー:** `large`モデルなど、大きなモデルを使用する場合に発生することがあります。より小さなモデルを使用するか、GPUを搭載した環境で実行してください。
*   **認識精度が低い:** 音声ファイルの品質が低い場合や、ノイズが多い場合に発生することがあります。音声ファイルの品質を改善するか、`language`オプションや`initial_prompt`オプションを試してください。
*   **文字化け:** エンコーディングの問題で文字化けが発生することがあります。Pythonスクリプトでファイルを開く際に、`encoding="utf-8"`を指定してください。

    ```python
    with open(filename.replace(".mp3", ".txt"), "w", encoding="utf-8") as f:
        f.write(result["text"])
    ```

### 音声ファイルをテキストに変換する

#### 概要と重要性

音声ファイルをテキストに変換することは、多くの実務的な場面で不可欠です。例えば、インタビューの書き起こし、講演会の内容をまとめる、ポッドキャストのスクリプトを作成するなど、その用途は多岐にわたります。Whisperを使用することで、これらの作業を大幅に効率化できます。

#### 特徴と利点

*   **高精度な書き起こし:** Whisperは、様々な環境で録音された音声でも高い精度でテキストに変換できます。
*   **多言語対応:** 複数の言語の音声ファイルを処理できます。
*   **柔軟な出力形式:** テキストファイルとして出力できるため、様々な用途に活用できます。

#### 事前準備と前提条件

前のセクションで説明した環境構築が完了していることを前提とします。特に、Whisperが正しくインストールされていることを確認してください。

#### 基本的な使い方

音声ファイルをテキストに変換する基本的な方法は、前のセクションで既に説明しましたが、ここではより詳細な手順とオプションについて解説します。

1.  **コマンドラインからの実行:** 以下のコマンドを実行します。

    ```bash
    whisper audio.mp3 --model medium --output_format txt
    ```

    このコマンドは、`audio.mp3`を`medium`モデルでテキストに変換し、`audio.txt`というファイル名で出力します。`--output_format`オプションで、出力形式を指定できます。txt, vtt, srt, tsv, json, all などの形式に対応しています。

2.  **Pythonスクリプトからの実行:** 以下のPythonスクリプトを作成し、実行します。

    ```python
    import whisper

    model = whisper.load_model("medium")
    result = model.transcribe("audio.mp3", verbose=True) # 詳細な情報を表示
    print(result["text"])

    # 出力形式を指定する場合
    with open("audio.txt", "w", encoding="utf-8") as f:
        f.write(result["text"])
    ```

    `verbose=True`を指定すると、処理の詳細な情報が表示されます。これは、デバッグや性能評価に役立ちます。

#### 実践的なテクニック

*   **長い音声ファイルの処理:** 長い音声ファイルを処理する場合、Whisperは自動的に分割して処理します。しかし、分割のタイミングが不適切な場合、認識精度が低下することがあります。このような場合は、手動で分割し、それぞれのファイルを処理することを検討してください。

    ```python
    import whisper
    import librosa # 音声処理ライブラリ

    model = whisper.load_model("medium")
    audio, sr = librosa.load("audio.mp3", sr=None) # サンプルレートを保持

    segment_length = 30 # 30秒ごとに分割
    for i in range(0, len(audio), segment_length * sr):
        segment = audio[i:i + segment_length * sr]
        librosa.output.write_wav(f"segment_{i//(segment_length*sr)}.wav", segment, sr)
        result = model.transcribe(f"segment_{i//(segment_length*sr)}.wav")
        with open("output.txt", "a", encoding="utf-8") as f: #追記モード
            f.write(result["text"] + "\n")

    ```
    この例では `librosa` ライブラリを使用していますが、事前に `pip install librosa` でインストールしておく必要があります。

*   **ノイズ除去:** 音声ファイルにノイズが多い場合、事前にノイズ除去を行うことで、認識精度を向上させることができます。Audacityなどの音声編集ソフトを使用するか、Pythonの音声処理ライブラリ（例えば、`noisereduce`)を使用して、ノイズを除去してください。

    ```python
    import noisereduce as nr
    import soundfile as sf

    # ノイズリダクション
    data, rate = sf.read("noisy_audio.wav")
    reduced_noise = nr.reduce_noise(y=data, sr=rate)
    sf.write("clean_audio.wav", reduced_noise, rate)

    # Whisperで書き起こし
    model = whisper.load_model("medium")
    result = model.transcribe("clean_audio.wav")
    print(result["text"])
    ```
     この例では `noisereduce`と `soundfile` ライブラリを使用していますが、事前に `pip install noisereduce soundfile` でインストールしておく必要があります。

*   **特定箇所の書き起こし:** 音声ファイル全体ではなく、特定の箇所だけを書き起こしたい場合は、開始時間と終了時間を指定することができます。

    ```python
    import whisper
    import librosa

    model = whisper.load_model("medium")
    audio, sr = librosa.load("audio.mp3")
    start_time = 10  # 10秒から
    end_time = 20    # 20秒まで

    segment = audio[int(start_time * sr):int(end_time * sr)]
    librosa.output.write_wav("segment.wav", segment, sr)

    result = model.transcribe("segment.wav")
    print(result["text"])
    ```
    `librosa`ライブラリを利用して音声ファイルから特定区間を切り出し、Whisperで処理しています。

#### 応用例とユースケース

*   **インタビューの書き起こし:** インタビュー音声をテキストに変換し、記事やレポートの作成を支援します。
*   **講演会の内容まとめ:** 講演会の音声をテキストに変換し、内容の要約やキーワードの抽出を行います。
*   **ポッドキャストのスクリプト作成:** ポッドキャストの音声をテキストに変換し、スクリプトを作成します。

*   **顧客対応記録の分析:** 顧客との通話記録をテキストに変換し、顧客のニーズや不満点を分析します。

#### トラブルシューティング

*   **音声ファイルの形式がサポートされていない:** Whisperは、MP3, WAV, MP4, OGGなど、一般的な音声ファイル形式をサポートしています。もし、サポートされていない形式のファイルを使用している場合は、ffmpegなどのツールを使用して、変換してください。

*   **エラーメッセージが表示される:** エラーメッセージをよく読み、原因を特定してください。メモリ不足、ファイルが見つからない、権限がないなど、様々な原因が考えられます。
*   **書き起こし結果が不正確:** 音声ファイルの品質が低い場合や、ノイズが多い場合に発生することがあります。音声ファイルの品質を改善するか、ノイズ除去を行うことを検討してください。

### リアルタイム音声認識

#### 概要と重要性

リアルタイム音声認識は、マイクから入力された音声を即座にテキストに変換する技術です。会議での発言内容のリアルタイム字幕表示、音声操作によるアプリケーション制御、ライブストリーミングのリアルタイム字幕生成など、様々な用途で活用されています。

#### 特徴と利点

*   **即時性:** 入力された音声をリアルタイムでテキストに変換します。
*   **インタラクティブ性:** 音声による操作や制御が可能になります。
*   **アクセシビリティ:** 聴覚障碍者向けのリアルタイム字幕表示など、アクセシビリティ向上に貢献します。

#### 事前準備と前提条件

前のセクションで説明した環境構築が完了していることを前提とします。さらに、以下のライブラリが必要になります。

*   **PyAudio:** マイクからの音声入力を扱うためのライブラリ。

    ```bash
    pip install pyaudio
    ```

    PyAudioのインストールには、いくつかの依存関係がある場合があります。エラーが発生した場合は、PyAudioの公式サイト([https://people.csail.mit.edu/hubert/pyaudio/](https://people.csail.mit.edu/hubert/pyaudio/))を参照してください。

#### 基本的な使い方

以下のPythonスクリプトは、マイクから入力された音声をリアルタイムでテキストに変換し、表示する基本的な例です。

```python
import whisper
import pyaudio
import wave
import numpy as np

# パラメータ設定
CHUNK = 1024 # バッファサイズ
FORMAT = pyaudio.paInt16 # オーディオ形式
CHANNELS = 1 # モノラル
RATE = 16000 # サンプルレート
RECORD_SECONDS = 5 # 録音時間

# Whisperモデルのロード
model = whisper.load_model("small")

# PyAudioの設定
p = pyaudio.PyAudio()

stream = p.open(format=FORMAT,
                channels=CHANNELS,
                rate=RATE,
                input=True,
                frames_per_buffer=CHUNK)

print("* recording")

frames = []

for i in range(0, int(RATE / CHUNK * RECORD_SECONDS)):
    data = stream.read(CHUNK)
    frames.append(data)

print("* done recording")

stream.stop_stream()
stream.close()
p.terminate()

# 録音データをNumPy配列に変換
audio_data = np.frombuffer(b''.join(frames), dtype=np.int16)

# Whisperで文字起こし
result = model.transcribe(audio_data, language="ja")
print(result["text"])
```

このスクリプトは、5秒間マイクから音声を録音し、Whisperでテキストに変換して表示します。

**重要な注意点:**
このスクリプトは簡略化された例であり、リアルタイム性を実現するために、録音と文字起こしを同時に行う必要があります。さらに、Whisperは音声の入力形式として NumPy array を受け付けないため、一時ファイルとして音声データを保存する必要があります。

#### 実践的なテクニック

*   **連続的な音声認識:** 前述の例では、一定時間録音した後にテキストに変換していますが、リアルタイム性を高めるためには、録音と並行してテキストに変換する必要があります。

```python
import whisper
import pyaudio
import numpy as np
import io
import wave

# パラメータ設定
CHUNK = 1024 # バッファサイズ
FORMAT = pyaudio.paInt16 # オーディオ形式
CHANNELS = 1 # モノラル
RATE = 16000 # サンプルレート

# Whisperモデルのロード
model = whisper.load_model("small")

# PyAudioの設定
p = pyaudio.PyAudio()

stream = p.open(format=FORMAT,
                channels=CHANNELS,
                rate=RATE,
                input=True,
                frames_per_buffer=CHUNK)

print("* recording")

try:
    while True:
        data = stream.read(CHUNK)
        # NumPy配列に変換
        audio_data = np.frombuffer(data, dtype=np.int16)

        # Wave形式に変換するために BytesIO オブジェクトを使用
        wav_buffer = io.BytesIO()
        with wave.open(wav_buffer, 'wb') as wf:
            wf.setnchannels(CHANNELS)
            wf.setsampwidth(p.get_sample_size(FORMAT))
            wf.setframerate(RATE)
            wf.writeframes(audio_data)

        wav_buffer.seek(0)  # バッファの先頭に戻る

        # Whisperで文字起こし
        result = model.transcribe(wav_buffer, language="ja")
        print(result["text"])

except KeyboardInterrupt:
    print("* done recording")

stream.stop_stream()
stream.close()
p.terminate()
```

この例では、`KeyboardInterrupt`が発生するまで、継続的に音声を録音し、テキストに変換します。録音した音声データをBytesIOバッファに書き込み、それをWhisperで処理することで、一時ファイルを作成せずにリアルタイムに近い処理を実現しています。

*   **ノイズ抑制:** リアルタイム音声認識では、周囲のノイズが認識精度に大きく影響します。ノイズ抑制技術を組み合わせることで、より高精度な認識が可能になります。前述の`noisereduce`ライブラリなどを活用できます。ただし、リアルタイム性を損なわないように、処理負荷の低いノイズ抑制アルゴリズムを選択する必要があります。

*   **発話区間の検出:** 音声認識を開始・終了するタイミングを自動的に検出する技術を組み合わせることで、より自然なインタラクションを実現できます。VAD (Voice Activity Detection) と呼ばれる技術が用いられます。

#### 応用例とユースケース

*   **リアルタイム字幕生成:** 会議や講演会の音声をリアルタイムでテキストに変換し、字幕として表示します。
*   **音声操作によるアプリケーション制御:** 音声コマンドをリアルタイムで認識し、アプリケーションを操作します。
*   **音声入力によるテキスト作成:** 音声で文章を入力し、テキストエディタやチャットアプリケーションにリアルタイムで反映します。
*   **遠隔会議システム:** 遠隔会議システムにリアルタイム字幕表示機能を追加し、アクセシビリティを向上させます。
*   **ライブストリーミングのリアルタイム字幕生成:** ライブストリーミング配信にリアルタイム字幕を付与し、視聴者の理解を助けます。

#### トラブルシューティング

*   **マイクが認識されない:** PyAudioが正しくインストールされていない場合や、マイクの設定が誤っている場合に発生することがあります。PyAudioの公式サイトを参照し、環境設定を確認してください。
*   **音声認識が遅延する:** モデルサイズが大きい場合や、計算リソースが不足している場合に発生することがあります。より小さなモデルを使用するか、GPUを搭載した環境で実行してください。
*   **認識精度が低い:** 周囲のノイズが多い場合や、発音が不明瞭な場合に発生することがあります。ノイズ抑制技術を組み合わせるか、発音を改善してください。
*   **音声が途切れる:** ネットワーク環境が不安定な場合に発生することがあります。安定したネットワーク環境で実行してください。
