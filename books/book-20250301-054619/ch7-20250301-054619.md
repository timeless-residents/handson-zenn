## 第7章：Semantic Kernel入門：Microsoft発のAIオーケストレーションフレームワーク

### Semantic Kernelとは何か？

#### 概要と重要性

Semantic Kernel（以下、SK）は、Microsoftが開発したオープンソースのAIオーケストレーションフレームワークです。一言で表すと、「AIをあなたのアプリに組み込むための便利なツールキット」です。

従来のアプリケーション開発では、AIモデルを直接組み込むことは複雑で、専門的な知識が必要でした。SKは、この問題を解決するために、自然言語処理（NLP）や大規模言語モデル（LLM）などのAI機能を、よりシンプルで使いやすい形でアプリケーションに統合できるように設計されています。

SKの登場によって、開発者はAIモデルの選定、データの前処理、モデルの学習といった複雑なプロセスを意識することなく、AIの恩恵をアプリケーションに簡単に取り込めるようになりました。これは、開発期間の短縮、コスト削減、そしてより革新的なアプリケーションの創出につながります。

#### 特徴と利点

SKには、他のAI統合フレームワークと比較して、以下のような際立った特徴と利点があります。

*   **言語モデルとの高い親和性:** OpenAI、Azure OpenAI Service、Hugging Faceなどの主要な言語モデルプロバイダとの連携が容易です。
*   **プラグインアーキテクチャ:**  「スキル」と呼ばれる再利用可能なコンポーネントを簡単に作成、共有、利用できます。
*   **プランニング機能:**  複雑なタスクを複数のステップに分解し、自動的に実行する「プランナー」を備えています。
*   **柔軟な実行環境:** 様々なプログラミング言語（C#, Python, Javaなど）に対応しており、既存のアプリケーションに容易に統合できます。
*   **オープンソース:**  コミュニティによる活発な開発が行われており、継続的な機能追加や改善が期待できます。

これらの特徴により、SKは、AIを活用したアプリケーション開発の効率化、柔軟性向上、そして新たな可能性の開拓に貢献します。

#### 事前準備と前提条件

SKを使うためには、以下の準備が必要です。

1.  **開発環境のセットアップ:**
    *   Pythonの場合: Python 3.7以上がインストールされている必要があります。
    *   .NETの場合: .NET 6.0以上がインストールされている必要があります。
2.  **Semantic Kernelライブラリのインストール:**
    *   Pythonの場合: `pip install semantic-kernel`
    *   .NETの場合: `dotnet add package Microsoft.SemanticKernel`
3.  **APIキーの準備:**
    *   OpenAIやAzure OpenAI Serviceを使用する場合は、それぞれのAPIキーを取得します。Hugging Faceの場合は、環境変数にAPIキーを設定する必要がある場合があります。

APIキーは機密情報なので、ソースコードに直接埋め込まず、環境変数などを利用して安全に管理することを強く推奨します。

#### 基本的な使い方

まずはPythonでの簡単な例を見てみましょう。 OpenAIのAPIキーを使って、SKを初期化し、簡単な質問に答えてもらうコードです。

```python
import semantic_kernel as sk
from semantic_kernel.connectors.ai.open_ai import OpenAIChatCompletion

# カーネルの初期化
kernel = sk.Kernel()

# OpenAIの構成
api_key = "YOUR_OPENAI_API_KEY" # APIキーをここに入力 (環境変数から取得するのが理想)
org_id = "YOUR_OPENAI_ORG_ID" # Organization IDをここに入力 (必要な場合)

# OpenAI Chat Completion サービスの追加
kernel.add_chat_service("openai", OpenAIChatCompletion("gpt-3.5-turbo", api_key, org_id))

# 簡単な質問
ask = "現在の東京の天気は？"

# 実行
result = kernel.run_sync(ask)

# 結果の表示
print(result)
```

このコードは、OpenAIのGPT-3.5 Turboモデルを使って、ユーザーからの質問に答えるシンプルな例です。`kernel.run_sync()`メソッドは、同期的にスキルを実行し、結果を返します。非同期処理が必要な場合は、`kernel.run()`を使用します。

.NETの場合も同様の手順でSKを初期化し、AIモデルを利用できます。

#### 実践的なテクニック

SKを使いこなすための、いくつかの実践的なテクニックを紹介します。

*   **プロンプトエンジニアリング:**  LLMの出力を効果的に制御するために、プロンプトの書き方を工夫します。例えば、より具体的な指示を与えたり、出力形式を指定したりすることで、期待する結果を得やすくなります。
*   **コンテキストの利用:**  過去の会話履歴や外部情報をコンテキストとしてLLMに与えることで、より文脈に沿った回答を得ることができます。
*   **関数の定義:**  SKでは、PythonやC#の関数を「スキル」として定義し、LLMから呼び出すことができます。これにより、外部APIの呼び出しやデータ処理などをLLMに実行させることができます。
*   **メモリの利用:**  SKには、会話履歴や外部情報を保存するための「メモリ」が用意されています。メモリを利用することで、LLMは過去の情報を参照しながら、より適切な回答を生成できます。

これらのテクニックを組み合わせることで、より高度なAIアプリケーションを開発できます。

#### 応用例とユースケース

SKは、様々な分野で応用できます。以下に、いくつかの具体的なユースケースを紹介します。

*   **チャットボット:**  SKを使って、自然な会話ができるチャットボットを開発できます。コンテキストを保持し、過去の会話履歴を参照しながら、よりパーソナライズされた対応が可能です。
*   **ドキュメント要約:**  SKを使って、長いドキュメントを自動的に要約できます。重要なポイントを抽出し、簡潔な文章にまとめることで、情報収集の効率化に貢献します。
*   **コード生成:**  SKを使って、自然言語による指示から、自動的にコードを生成できます。プログラミングの知識がない人でも、簡単にアプリケーションを作成できます。
*   **ワークフロー自動化:**  SKを使って、複数のAIスキルを組み合わせ、複雑なワークフローを自動化できます。例えば、顧客からの問い合わせを分析し、適切な担当者に自動的に割り当てる、といった処理を自動化できます。
*   **ナレッジグラフ:** 企業の持つドキュメントやデータをベクトル化し、Semantic Kernel のメモリ機能と組み合わせることでナレッジグラフを構築できます。質問応答システムやドキュメント検索に応用できます。

これらのユースケースはほんの一例であり、SKの可能性は無限に広がっています。

#### トラブルシューティング

SKを使用する際に遭遇する可能性のある問題と、その解決策をいくつか紹介します。

*   **APIキーのエラー:**  APIキーが正しく設定されているか、APIキーの有効期限が切れていないかを確認します。
*   **パッケージのインストールエラー:**  必要なパッケージが正しくインストールされているかを確認します。バージョンが競合している場合は、仮想環境を利用して、依存関係を分離することを検討します。
*   **LLMからの応答がない:**  プロンプトが適切かどうかを確認します。より具体的な指示を与えたり、コンテキストを追加したりすることで、LLMが適切な応答を生成できるようになる可能性があります。また、LLMのAPI制限に達している可能性も考慮します。
*   **プランナーが期待通りに動作しない:**  プランナーの設定が正しいか、必要なスキルが定義されているかを確認します。プランナーのデバッグ機能を活用して、タスクの実行過程を詳しく調査することも有効です。

これらのトラブルシューティングを参考に、問題解決に役立ててください。

### Skills（スキル）の定義と利用

#### 概要と重要性

Semantic Kernelにおける「スキル（Skills）」とは、特定のタスクを実行するための再利用可能なコンポーネントのことです。スキルは、AIモデルとの対話、外部APIの呼び出し、データ処理など、様々な処理をカプセル化できます。

スキルを活用することで、開発者はAIアプリケーションの構築を効率化し、コードの再利用性を高めることができます。また、スキルを共有することで、他の開発者と協力して、より高度なAIアプリケーションを開発できます。

#### 特徴と利点

スキルには、以下のような特徴と利点があります。

*   **再利用性:** スキルは、複数のアプリケーションで再利用できます。これにより、開発者は同じコードを何度も書く必要がなくなり、開発効率が向上します。
*   **モジュール性:** スキルは、独立したモジュールとして開発できます。これにより、アプリケーションの保守性、テスト容易性が向上します。
*   **拡張性:** 新しいスキルを簡単に追加できます。これにより、アプリケーションの機能を柔軟に拡張できます。
*   **共有性:** スキルは、他の開発者と共有できます。これにより、コミュニティ全体でAI技術の発展を促進できます。
*   **可読性:** スキルを利用することで、AI関連の処理をアプリケーションの主要なロジックから分離できます。これにより、アプリケーション全体の可読性や保守性が向上します。

#### 事前準備と前提条件

スキルを定義し、利用するためには、以下の準備が必要です。

1.  **Semantic Kernelライブラリのインストール:**  まだインストールしていない場合は、Semantic Kernelライブラリをインストールします。
2.  **必要なAPIキーの準備:** スキル内で外部APIを呼び出す場合は、APIキーを取得し、安全に管理します。
3.  **開発環境の設定:** スキルを開発するための開発環境を設定します。IDEやテキストエディタなど、使い慣れたツールを使用できます。

#### 基本的な使い方

スキルは、主に以下の2つの方法で定義できます。

1.  **Semantic Functions:** LLMのプロンプトテンプレートと設定を記述したファイルを使って定義する方法。
2.  **Native Functions:** PythonやC#などのプログラミング言語で関数を記述し、それをスキルとして登録する方法。

まずはSemantic Functionsを使った簡単な例を見てみましょう。

*   **ディレクトリ構成:**

    ```
    MySkills/
    ├── SummarizeSkill/
    │   ├── Summarize.skprompt.txt
    │   └── config.json
    ```

*   **Summarize.skprompt.txt:**

    ```
    {{$input}}

    上記の内容を3文で要約してください。
    ```

*   **config.json:**

    ```json
    {
      "schema": 1,
      "description": "テキストを要約するスキル",
      "type": "completion",
      "completion": {
        "max_tokens": 2000,
        "temperature": 0.7,
        "top_p": 1.0,
        "presence_penalty": 0.0,
        "frequency_penalty": 0.0
      }
    }
    ```

次に、このスキルをロードして実行するPythonコードです。

```python
import semantic_kernel as sk
from semantic_kernel.connectors.ai.open_ai import OpenAIChatCompletion

# カーネルの初期化
kernel = sk.Kernel()

# OpenAIの構成
api_key = "YOUR_OPENAI_API_KEY" # APIキーをここに入力 (環境変数から取得するのが理想)
org_id = "YOUR_OPENAI_ORG_ID" # Organization IDをここに入力 (必要な場合)

# OpenAI Chat Completion サービスの追加
kernel.add_chat_service("openai", OpenAIChatCompletion("gpt-3.5-turbo", api_key, org_id))

# スキルのロード
skill_directory = "MySkills"
summarize_skill = kernel.import_semantic_skill_from_directory(skill_directory, "SummarizeSkill")

# 入力テキスト
input_text = """
Semantic Kernelは、AIアプリケーションを構築するための強力なツールです。
スキルを使うことで、開発者はAIの機能を簡単にアプリケーションに組み込むことができます。
プランナーは、複雑なタスクを自動的に実行するための機能を提供します。
"""

# スキルの実行
result = kernel.run_sync(summarize_skill["Summarize"], input_str=input_text)

# 結果の表示
print(result)
```

このコードは、`MySkills/SummarizeSkill`ディレクトリにあるスキルをロードし、`Summarize`関数を実行します。`input_text`は、LLMに渡される入力テキストです。

Native Functionsを使う場合は、PythonやC#で関数を定義し、`@sk_function`アノテーション（Pythonの場合）や`[SKFunction]`属性（C#の場合）を付与することで、スキルとして登録できます。

```python
import semantic_kernel as sk
from semantic_kernel.skill_definition import sk_function

class MySkills:
    @sk_function(
        description="2つの数値を足し算します",
        name="Add",
    )
    def add(self, number1: int, number2: int) -> int:
        """
        2つの数値を足し算します
        """
        return number1 + number2

# カーネルにスキルを登録
my_skills = MySkills()
kernel.import_skill(my_skills, "MySkills");

# スキルの実行
result = kernel.run_sync(kernel.skills["MySkills"]["Add"], number1=10, number2=20)

# 結果の表示
print(result) # -> 30
```

### Planners（プランナー）による自動タスク実行

#### 概要と重要性

Semantic Kernelの「プランナー（Planners）」は、ユーザーの目標を達成するために、適切なスキルを自動的に選択し、実行順序を決定する機能です。プランナーを使うことで、開発者は複雑なタスクを個別のスキルとして定義し、それらを組み合わせて自動的に実行するAIアプリケーションを構築できます。

プランナーは、AIアプリケーションの自動化、効率化、そして柔軟性向上に大きく貢献します。

#### 特徴と利点

プランナーには、以下のような特徴と利点があります。

*   **自動タスク実行:** ユーザーの目標を達成するために、必要なスキルを自動的に選択し、実行します。
*   **柔軟性:** 様々なスキルを組み合わせて、複雑なタスクを実行できます。
*   **適応性:** 環境の変化やユーザーの要求に応じて、計画を動的に変更できます。
*   **効率性:** 最適なスキルの実行順序を決定し、タスクを効率的に実行します。
*   **高度な抽象化:** 開発者は、タスク全体の流れを詳細に記述する必要がなく、個々のスキルの定義に集中できます。

#### 事前準備と前提条件

プランナーを使用するためには、以下の準備が必要です。

1.  **Semantic Kernelライブラリのインストール:** まだインストールしていない場合は、Semantic Kernelライブラリをインストールします。
2.  **必要なスキルの準備:** プランナーが使用するスキルを定義します。
3.  **プランナーの種類の選択:**  SKには、いくつかの種類のプランナーが用意されています。タスクの特性に応じて、適切なプランナーを選択します。

SKで利用可能な主なプランナーは以下の通りです。

*   **SequentialPlanner:** 定義されたスキルセットから、順番に実行するプランを生成します。シンプルなタスクに適しています。
*   **ActionPlanner:** ユーザーの目標を達成するために、最適なスキルを選択し、実行順序を決定します。
*   **StepwisePlanner:** 複雑なタスクを段階的に解決するために、ステップごとに計画を立て、実行します。

#### 基本的な使い方

ここでは、最も基本的なSequentialPlannerを使った例を紹介します。

まず、必要なスキルを定義します。ここでは、簡単なテキスト処理を行うスキルを2つ定義します。

```python
import semantic_kernel as sk
from semantic_kernel.connectors.ai.open_ai import OpenAIChatCompletion
from semantic_kernel.planning.sequential_planner import SequentialPlanner

# カーネルの初期化
kernel = sk.Kernel()

# OpenAIの構成
api_key = "YOUR_OPENAI_API_KEY" # APIキーをここに入力 (環境変数から取得するのが理想)
org_id = "YOUR_OPENAI_ORG_ID" # Organization IDをここに入力 (必要な場合)

# OpenAI Chat Completion サービスの追加
kernel.add_chat_service("openai", OpenAIChatCompletion("gpt-3.5-turbo", api_key, org_id))

# スキルのインポート (Semantic Functionsの例)
skill_directory = "MySkills"
text_skill = kernel.import_semantic_skill_from_directory(skill_directory, "TextSkill")

# もしくは Native Functionsでスキルを定義することも可能
# class MySkills:
#     @sk_function(
#         description="テキストを大文字に変換します",
#         name="ToUpperCase",
#     )
#     def to_upper_case(self, text: str) -> str:
#         """テキストを大文字に変換します"""
#         return text.upper()

# my_skills = MySkills()
# kernel.import_skill(my_skills, "MySkills");
```

次に、SequentialPlannerを使って、プランを生成し、実行します。

```python
# プランナーの作成
planner = SequentialPlanner(kernel)

# 目標の定義
goal = "テキストを大文字に変換して、句読点を追加してください。"

# プランの作成
plan = planner.create_plan(goal)

# プランの実行
result = kernel.run_sync(plan, input_str="hello world")

# 結果の表示
print(result)
```

このコードは、SequentialPlannerを使って、`goal`を達成するためのプランを生成し、実行します。プランナーは、利用可能なスキルの中から、`goal`を達成するために必要なスキルを選択し、実行順序を決定します。

#### 実践的なテクニック

プランナーを使いこなすための実践的なテクニックを紹介します。

*   **スキルの粒度:** スキルの粒度を適切に設定することで、プランナーの性能を向上させることができます。細かすぎるスキルは、プランナーの選択肢を増やし、計算コストを増加させる可能性があります。逆に、粗すぎるスキルは、プランナーの柔軟性を低下させる可能性があります。
*   **スキルの説明:** スキルの説明を丁寧に記述することで、プランナーが適切なスキルを選択できるようになります。
*   **プランナーのパラメータ調整:** プランナーのパラメータを調整することで、プランナーの性能を最適化できます。例えば、StepwisePlannerの場合、最大ステップ数や探索幅などのパラメータを調整できます。
*   **プランの検証:** プランナーが生成したプランを検証することで、プランの妥当性を確認できます。プランが期待通りでない場合は、スキルやプランナーの設定を見直す必要があります。

#### 応用例とユースケース

プランナーは、様々なAIアプリケーションで活用できます。以下に、いくつかの応用例とユースケースを紹介します。

*   **カスタマーサポート:** 顧客からの問い合わせ内容を分析し、適切な回答を自動的に生成するカスタマーサポートシステムを構築できます。
*   **コンテンツ生成:** ユーザーの要求に応じて、ブログ記事、メール、広告文など、様々な種類のコンテンツを自動的に生成できます。
*   **ワークフロー自動化:** 複数のAIスキルを組み合わせて、複雑なワークフローを自動化できます。例えば、請求書の処理、契約書の作成、プロジェクトの管理などを自動化できます。
*   **ロボット制御:** ロボットの動作を制御するために、プランナーを使用できます。例えば、ロボットに特定の場所まで移動させたり、特定のタスクを実行させたりできます。
*   **ゲームAI:** ゲームキャラクターの行動を制御するために、プランナーを使用できます。例えば、敵キャラクターに戦略的な行動を取らせたり、プレイヤーキャラクターに自然な行動を取らせたりできます。

#### トラブルシューティング

プランナーを使用する際に遭遇する可能性のある問題と、その解決策をいくつか紹介します。

*   **プランナーがプランを生成できない:** スキルの定義が不十分な可能性があります。スキルの説明を丁寧に記述したり、必要なスキルを追加したりすることで、プランナーがプランを生成できるようになる可能性があります。
*   **プランナーが生成したプランが期待通りでない:** スキルの粒度が適切でない可能性があります。スキルの粒度を調整したり、プランナーのパラメータを調整したりすることで、プランナーが期待通りのプランを生成できるようになる可能性があります。
*   **プランの実行に失敗する:** スキルの実行中にエラーが発生した可能性があります。スキルのログを確認したり、スキルのコードをデバッグしたりすることで、エラーの原因を特定できます。
