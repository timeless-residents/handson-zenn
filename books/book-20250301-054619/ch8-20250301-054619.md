## 第8章：OpenAI Function Calling：関数を呼び出すAI

### Function Callingの概要とメリット

#### 概要と重要性

OpenAI Function Callingは、OpenAIのAPIを通じて、言語モデルが外部の関数を呼び出す能力を提供する強力な機能です。従来の言語モデルは、テキストの生成や質問応答に特化していましたが、Function Callingの登場により、言語モデルは単なる情報提供者から、実際のアクションを実行できるインテリジェントなエージェントへと進化しました。

たとえば、ユーザーが「明日の東京の天気を教えて」と尋ねると、従来の言語モデルは天気予報のテキストを生成するだけでした。しかし、Function Callingを利用すれば、言語モデルは天気予報APIを呼び出し、最新の天気情報を取得してユーザーに提供できます。これは、ユーザーエクスペリエンスを向上させるだけでなく、言語モデルの活用範囲を大幅に広げる可能性を秘めています。

#### 特徴と利点

Function Callingの主な特徴と利点は以下の通りです。

*   **リアルタイムデータの活用:** 外部APIを通じて、最新の情報を取得し、動的な応答を生成できます。
*   **アクションの実行:** 単に情報を提供するだけでなく、メールの送信、予約の作成、タスクの実行など、具体的なアクションを実行できます。
*   **複雑なタスクの自動化:** 複数の関数を連携させることで、複雑なタスクを自動化できます。
*   **自然な対話の実現:** ユーザーの意図を理解し、適切な関数を呼び出すことで、より自然な対話を実現できます。
*   **カスタマイズ性:** 独自の関数を定義し、言語モデルの機能を拡張できます。

#### 事前準備と前提条件

Function Callingを利用するには、以下の準備が必要です。

*   **OpenAI APIキー:** OpenAIのAPIを利用するためのAPIキーを取得する必要があります。OpenAIのウェブサイトでアカウントを作成し、APIキーを発行してください。
*   **Python環境:** Pythonでコードを実行するための環境が必要です。Pythonのインストール方法については、Pythonの公式サイトを参照してください。
*   **OpenAI Pythonライブラリ:** OpenAIのAPIを利用するためのPythonライブラリをインストールする必要があります。以下のコマンドを実行してインストールしてください。

```bash
pip install openai
```

*   **外部APIの準備:** 呼び出す関数のAPIを準備する必要があります。例えば、天気予報API、翻訳APIなど、利用したいAPIのアカウント作成やAPIキーの取得を行ってください。

#### 基本的な使い方

Function Callingの基本的な使い方は以下の通りです。

1.  **関数の定義:** 呼び出す関数の情報を定義します。関数の名前、説明、引数などをJSON形式で記述します。
2.  **APIリクエストの送信:** OpenAIのAPIにリクエストを送信します。リクエストには、ユーザーの質問と関数の定義を含めます。
3.  **APIレスポンスの解析:** OpenAIのAPIからレスポンスを受け取ります。レスポンスには、呼び出すべき関数の名前と引数が含まれています。
4.  **関数の実行:** レスポンスに基づいて、関数を実行します。
5.  **結果の送信:** 関数の実行結果をOpenAIのAPIに送信します。
6.  **最終的なレスポンスの生成:** OpenAIのAPIから最終的なレスポンスを受け取ります。レスポンスには、関数の実行結果を反映したテキストが含まれています。

#### 実践的なテクニック

Function Callingを効果的に活用するための実践的なテクニックをいくつか紹介します。

*   **関数の説明を詳細に記述する:** 言語モデルが関数を適切に選択できるように、関数の説明をできるだけ詳細に記述することが重要です。関数の目的、入力、出力などを明確に記述してください。
*   **適切な引数を定義する:** 関数に必要な引数を正確に定義することが重要です。引数の名前、型、説明などを明確に記述してください。
*   **複数の関数を連携させる:** 複数の関数を連携させることで、より複雑なタスクを実行できます。たとえば、翻訳APIと要約APIを連携させて、外国語の記事を翻訳して要約することができます。
*   **エラーハンドリングを実装する:** 関数の実行中にエラーが発生した場合に、適切に処理する必要があります。エラーが発生した場合に、エラーメッセージをユーザーに表示したり、別の関数を呼び出したりすることができます。
*   **ユーザーに確認を求める:** 関数を実行する前に、ユーザーに確認を求めることで、意図しないアクションの実行を防ぐことができます。たとえば、メールを送信する前に、送信先と内容をユーザーに確認することができます。

#### 応用例とユースケース

Function Callingは、様々な分野で応用できます。以下にいくつかの具体的なユースケースを紹介します。

*   **旅行予約アシスタント:** ユーザーの希望に基づいて、航空券やホテルを検索し、予約することができます。
*   **パーソナルファイナンスアシスタント:** ユーザーの収入と支出を管理し、貯蓄目標を達成するためのアドバイスを提供することができます。
*   **スマートホームコントローラー:** ユーザーの音声コマンドに基づいて、照明、エアコン、テレビなどの家電製品を操作することができます。
*   **カスタマーサポートチャットボット:** ユーザーの質問に答え、問題を解決することができます。必要に応じて、人間のオペレーターに引き継ぐこともできます。
*   **コンテンツ生成ツール:** ユーザーの指示に基づいて、記事、ブログ投稿、ソーシャルメディアの投稿などを生成することができます。

#### トラブルシューティング

Function Callingを利用する際に発生する可能性のある問題とその解決策をいくつか紹介します。

*   **関数が選択されない:** 言語モデルが関数を選択しない場合、関数の説明が不十分である可能性があります。関数の説明をより詳細に記述してください。また、ユーザーの質問が不明確である場合もあります。ユーザーに質問を明確にするように促してください。
*   **関数が正しく実行されない:** 関数が正しく実行されない場合、関数の引数が間違っている可能性があります。引数の型や値を確認してください。また、外部APIがダウンしている可能性もあります。APIの状態を確認してください。
*   **API制限:** OpenAIのAPIには、利用制限があります。APIの利用制限を超えないように注意してください。

### 関数の定義と登録

#### 概要と重要性

Function Callingの成否は、いかに適切な関数を定義し、登録するかにかかっています。関数定義は、言語モデルがどの関数をいつ、どのように使用すべきかを理解するための設計図です。精度の高い関数定義は、AIの意思決定を助け、より効果的なアウトプットに繋がります。

#### 特徴と利点

*   **明確な指示:** 関数定義は、言語モデルに対し、外部ツールへのアクセス方法を明確に指示します。
*   **柔軟な設計:** 開発者は、特定のタスクに合わせて関数をカスタマイズできます。
*   **制御されたアクセス:** どの関数をどのモデルが利用できるかを制御できます。

#### 事前準備と前提条件

*   **実行可能な関数:** 定義する関数は、実際に動作するコードとして実装されている必要があります。
*   **APIエンドポイント:** 外部APIを利用する場合、アクセス可能なエンドポイントが必要です。
*   **認証情報:** APIへのアクセスに必要な認証情報（APIキーなど）を安全に管理する必要があります。

#### 基本的な使い方

関数の定義はJSON形式で行います。以下に、天気予報を取得する関数の定義例を示します。

```json
{
  "name": "get_current_weather",
  "description": "指定された場所の現在の天気を取得します。",
  "parameters": {
    "type": "object",
    "properties": {
      "location": {
        "type": "string",
        "description": "場所。例：東京都",
      },
      "unit": {
        "type": "string",
        "enum": ["celsius", "fahrenheit"],
        "description": "温度の単位",
      },
    },
    "required": ["location"],
  },
}
```

このJSONオブジェクトは、以下の情報を提供します。

*   `name`: 関数の名前。言語モデルがこの名前を使って関数を呼び出します。
*   `description`: 関数の説明。言語モデルが関数を選択する際に役立ちます。
*   `parameters`: 関数の引数。言語モデルが関数に渡す必要がある引数の情報を定義します。
    *   `type`: 引数の型（object、string、integerなど）。
    *   `properties`: 引数の詳細な情報。
        *   `location`: 場所の名前。
            *   `type`: string (文字列)
            *   `description`: 場所の説明。
        *   `unit`: 温度の単位。
            *   `type`: string (文字列)
            *   `enum`: 取りうる値のリスト（celsius または fahrenheit）。
            *   `description`: 単位の説明。
    *   `required`: 必須の引数のリスト。この例では、`location` が必須です。

#### 実践的なテクニック

*   **詳細な説明:** 関数の説明は、言語モデルが関数を適切に選択するために非常に重要です。関数が何を行い、どのような場合に役立つのかを明確に記述してください。
*   **適切な引数:** 必要な引数をすべて定義し、それぞれの引数の型と説明を明確に記述してください。`enum` を使用して、取りうる値を制限することで、言語モデルが正しい値を生成するのを助けることができます。
*   **複数の関数:** 複数の関数を定義することで、より複雑なタスクを実行できます。各関数は、特定のタスクに特化するように設計してください。
*   **JSON Schemaの活用:** JSON Schemaを使用して、関数の引数の構造を厳密に定義できます。これにより、言語モデルが正しい形式で引数を生成するのを助けることができます。

#### 応用例とユースケース

*   **メール送信関数:** メールアドレス、件名、本文を引数として受け取り、メールを送信する関数を定義できます。
*   **翻訳関数:** テキストと翻訳先の言語を引数として受け取り、テキストを翻訳する関数を定義できます。
*   **データベースクエリ関数:** SQLクエリを引数として受け取り、データベースからデータを取得する関数を定義できます。
*   **タスク管理関数:** タスクの追加、削除、更新を行う関数を定義できます。

#### トラブルシューティング

*   **関数が選択されない:** 言語モデルが関数を選択しない場合、関数の説明が不十分であるか、ユーザーの質問と関数の関連性が低い可能性があります。関数の説明を改善するか、ユーザーの質問をより明確にしてください。
*   **引数が無効:** 言語モデルが生成した引数が無効である場合、引数の型が間違っているか、`enum` で指定された値以外である可能性があります。引数の定義を確認し、言語モデルが正しい値を生成するように指示してください。

### Function Callingの実装例

#### 概要と重要性

Function Callingの実装は、実際にAIが関数を呼び出し、その結果を利用してタスクを完了させるプロセスです。このセクションでは、具体的なコード例を通じて、Function Callingの仕組みを理解し、実践的なスキルを習得します。

#### 特徴と利点

*   **実践的な理解:** コード例を通して、Function Callingの動作を具体的に理解できます。
*   **カスタマイズの基礎:** 提供されたコードをベースに、独自の関数やロジックを組み込むことができます。
*   **トラブルシューティングのヒント:** 実装中に発生する可能性のある問題とその解決策を学ぶことができます。

#### 事前準備と前提条件

*   **OpenAI APIキー:** OpenAI APIを利用するためのAPIキーが必要です。
*   **Python環境:** Python 3.7以降がインストールされている必要があります。
*   **必要なライブラリ:** `openai` ライブラリをインストールする必要があります。
    ```bash
    pip install openai requests
    ```
    加えて、天気予報APIを利用する場合は、`requests`ライブラリもインストールしておきましょう。

#### 基本的な使い方

以下は、OpenAI APIを用いてFunction Callingを実装する基本的な例です。この例では、天気予報を取得する関数を定義し、AIがその関数を呼び出すように指示します。

```python
import openai
import os
import json
import requests

# OpenAI APIキーを設定
openai.api_key = os.getenv("OPENAI_API_KEY")

# 天気予報APIキー(例)
WEATHER_API_KEY = os.getenv("WEATHER_API_KEY")

# 天気予報を取得する関数
def get_current_weather(location, unit="celsius"):
    """指定された場所の現在の天気を取得します。"""
    try:
        # OpenWeatherMap APIのエンドポイント
        url = f"http://api.openweathermap.org/data/2.5/weather?q={location}&appid={WEATHER_API_KEY}&units={unit}"
        response = requests.get(url)
        response.raise_for_status()  # HTTPエラーをチェック

        data = response.json()
        temperature = data["main"]["temp"]
        description = data["weather"][0]["description"]
        return f"{location}の現在の天気: {temperature}度、{description}"
    except requests.exceptions.RequestException as e:
        return f"天気情報の取得に失敗しました: {e}"
    except KeyError:
        return "天気情報の解析に失敗しました。APIのレスポンス形式が変更された可能性があります。"


# 関数定義
functions = [
    {
        "name": "get_current_weather",
        "description": "指定された場所の現在の天気を取得します。",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {
                    "type": "string",
                    "description": "場所。例：東京都",
                },
                "unit": {
                    "type": "string",
                    "enum": ["celsius", "fahrenheit"],
                    "description": "温度の単位",
                },
            },
            "required": ["location"],
        },
    }
]

# ユーザーの質問
messages = [
    {"role": "user", "content": "東京の現在の天気を教えて"},
]

# APIリクエストを送信
response = openai.ChatCompletion.create(
    model="gpt-3.5-turbo-0613",
    messages=messages,
    functions=functions,
    function_call="auto",  # "auto" で、モデルに関数を呼び出すかどうかを決定させる
)

# レスポンスを解析
response_message = response["choices"][0]["message"]

# 関数が呼び出された場合
if response_message.get("function_call"):
    function_name = response_message["function_call"]["name"]
    function_args = json.loads(response_message["function_call"]["arguments"])

    if function_name == "get_current_weather":
        location = function_args.get("location")
        unit = function_args.get("unit", "celsius")  # unitが指定されていない場合はデフォルト値を使用
        weather_info = get_current_weather(location, unit)

        # 関数の実行結果をAPIに送信
        messages.append(response_message)  # 以前の応答を追加
        messages.append(
            {
                "role": "function",
                "name": function_name,
                "content": weather_info,
            }
        )  # 関数の結果を追加
        second_response = openai.ChatCompletion.create(
            model="gpt-3.5-turbo-0613",
            messages=messages,
        )  # AIに最終的な回答を生成させる
        print(second_response["choices"][0]["message"]["content"])
else:
    print(response_message["content"])
```

このコードは、以下のステップを実行します。

1.  **関数の定義:** `get_current_weather` 関数を定義し、OpenAIに登録します。
2.  **APIリクエスト:** ユーザーの質問をOpenAI APIに送信します。`function_call="auto"` を設定することで、モデルに関数を呼び出すかどうかを決定させます。
3.  **レスポンスの解析:** APIからのレスポンスを解析し、関数が呼び出されたかどうかを確認します。
4.  **関数の実行:** 関数が呼び出された場合、引数を抽出し、関数を実行します。
5.  **結果の送信:** 関数の実行結果をOpenAI APIに送信し、最終的なレスポンスを生成させます。

#### 実践的なテクニック

*   **エラーハンドリング:** 関数が正しく実行されない場合、エラーハンドリングを実装することが重要です。エラーが発生した場合、エラーメッセージをユーザーに表示するか、別の関数を呼び出すことができます。
*   **ログ:** 関数呼び出しのログを記録することで、問題が発生した場合の原因を特定できます。
*   **検証:** 関数の引数を検証することで、不正なデータが関数に渡されるのを防ぐことができます。

#### 応用例とユースケース

*   **予定調整:** 複数の人の空き時間を確認し、最適な会議時間を提案する。
*   **旅行プラン作成:** ユーザーの希望に基づいて、旅行プランを作成する。
*   **商品検索:** ユーザーの検索クエリに基づいて、商品を検索する。

#### トラブルシューティング

*   **APIキーの確認:** OpenAI APIキーが正しく設定されているか確認してください。
*   **関数の定義:** 関数の定義が正しいJSON形式であるか確認してください。
*   **引数の型:** 関数の引数の型が正しいか確認してください。
*   **APIの制限:** OpenAI APIの利用制限を超えていないか確認してください。
*   **JSONDecodeError:** `json.loads` でエラーが発生する場合は、`response_message["function_call"]["arguments"]` の内容がJSON形式として正しくない可能性があります。ChatGPTのレスポンスを確認し、JSON形式で返答するようにプロンプトを調整してください。
