## 3. Immutable X APIの基本：アカウント作成とウォレット接続

この章では、Immutable X APIを利用するための最初のステップ、つまりアカウント作成とウォレット接続について詳しく解説します。Immutable Xは、Ethereumのスケーラビリティ問題を解決するために開発されたLayer2ソリューションであり、NFT（Non-Fungible Token）の取引を高速かつ低コストで実現します。本章を読み終えることで、Immutable XのAPIを使って、ユーザー登録からウォレット接続、そしてアカウント情報の取得までの一連の流れを理解し、実際に開発に組み込むことができるようになります。

### 3.1 アカウント作成：ユーザー登録と認証

#### 概要と重要性

Immutable Xを使うためには、まずアカウントを作成する必要があります。Immutable Xは、ユーザーの秘密鍵を直接管理せず、Starkキーという別の鍵ペアを用いてトランザクションに署名します。このStarkキーはImmutable X上で管理され、ユーザーは自身のウォレット（Metamaskなど）を使ってStarkキーを登録・認証します。

アカウント作成は、Immutable X上でNFTを取引したり、ゲームをプレイしたりするための最初の関門です。安全かつ確実なアカウント作成手順を理解することは、Immutable Xのエコシステムに参加するための基礎となります。

#### 特徴と利点

*   **安全性の向上:** Starkキーを使うことで、Ethereumの秘密鍵が直接Immutable Xにさらされるリスクを軽減します。
*   **利便性の向上:** アカウント作成は比較的手軽に行うことができ、Immutable Xの様々なサービスをすぐに利用開始できます。
*   **スケーラビリティ:** Immutable Xのアカウントシステムは、大量のユーザーに対応できるように設計されています。

#### 事前準備と前提条件

*   **Ethereumウォレット (Metamaskなど):** アカウント作成には、Ethereumウォレットが必要です。Metamaskをインストールし、EthereumメインネットまたはGoerliテストネットに接続しておいてください。
*   **Immutable X SDK (JavaScript/TypeScript):** Immutable XのJavaScript/TypeScript SDKをインストールします。`npm install @imtbl/imx-sdk` または `yarn add @imtbl/imx-sdk`
*   **APIキー (Optional):** 本番環境で使用する場合はAPIキーが必要です。Immutable Xの公式サイトで取得できます。テスト環境ではAPIキーは不要です。

#### 基本的な使い方

アカウント作成は、Immutable X SDKの`registerOffChain`関数を使って行います。この関数は、Ethereumウォレットで署名されたメッセージをImmutable Xに送信し、Starkキーを登録します。

以下は、JavaScript/TypeScriptでの基本的なアカウント作成のコード例です。

```typescript
import { ImmutableXClient, Config } from '@imtbl/imx-sdk';
import { ethers } from 'ethers';

async function registerAccount(provider: ethers.providers.Web3Provider) {
  // Immutable Xクライアントの初期化 (テスト環境)
  const client = await ImmutableXClient.build({
    publicApiUrl: Config.SANDBOX.apiURL,
    signer: provider.getSigner(),
    starkContractAddress: Config.SANDBOX.starkContractAddress,
    registrationContractAddress: Config.SANDBOX.registrationContractAddress
  });

  try {
    const registerResult = await client.registerOffChain();
    console.log('アカウント登録結果:', registerResult);
    return registerResult;
  } catch (error) {
    console.error('アカウント登録エラー:', error);
    throw error;
  }
}

// MetamaskからProviderを取得し、アカウント登録を実行する例
async function connectAndRegister() {
  if (window.ethereum) {
    try {
      await window.ethereum.request({ method: 'eth_requestAccounts' }); // Metamask接続許可のリクエスト
      const provider = new ethers.providers.Web3Provider(window.ethereum);
      await registerAccount(provider);
    } catch (error) {
      console.error('Metamask接続またはアカウント登録エラー:', error);
    }
  } else {
    console.error('Metamaskがインストールされていません');
  }
}

// 例：ボタンクリックなどでconnectAndRegister()を呼び出す
// document.getElementById('registerButton').addEventListener('click', connectAndRegister);
```

**コード解説:**

1.  **ImmutableXClientの初期化:** Immutable Xクライアントを初期化します。`Config.SANDBOX`はテスト環境の設定を示しています。本番環境では`Config.PRODUCTION`を使用します。`publicApiUrl`はImmutable XのAPIエンドポイント、`signer`はEthereumウォレットの署名者、`starkContractAddress`と`registrationContractAddress`はImmutable Xのコントラクトアドレスです。
2.  **registerOffChain関数の呼び出し:** `client.registerOffChain()`を呼び出すことで、アカウント登録処理が開始されます。この関数は、Ethereumウォレットで署名されたメッセージをImmutable Xに送信します。
3.  **Metamask接続のリクエスト:**  `window.ethereum.request({ method: 'eth_requestAccounts' })` は、ユーザーにMetamaskへの接続を許可してもらうためのリクエストです。ユーザーが許可すると、`provider`オブジェクトが作成され、Ethereumウォレットへのアクセスが可能になります。

#### 実践的なテクニック

*   **エラーハンドリング:** アカウント登録処理は、様々な理由で失敗する可能性があります。例えば、ネットワークの問題、ウォレットのロック、ユーザーが署名を拒否した場合などです。try-catchブロックを使って、エラーを適切に処理するようにしましょう。
*   **ローディング表示:** アカウント登録処理には時間がかかる場合があります。ローディング表示を実装することで、ユーザーエクスペリエンスを向上させることができます。
*   **アカウント登録状況の確認:** アカウント登録が完了したかどうかを確認するために、Immutable XのAPIを使ってアカウント情報を取得することができます。

#### 応用例とユースケース

*   **ゲーム:** ゲーム内でNFTを取引するために、ユーザーにImmutable Xアカウントを作成させます。
*   **マーケットプレイス:** NFTのマーケットプレイスで、Immutable Xを使ってNFTを売買するために、ユーザーにアカウントを作成させます。
*   **DAO (Decentralized Autonomous Organization):** DAOのメンバーシップをNFTとして表現し、Immutable Xを使ってメンバーシップを管理します。

#### トラブルシューティング

*   **"User is not registered"エラー:** このエラーは、EthereumウォレットがImmutable Xに登録されていない場合に発生します。`registerOffChain`関数を呼び出してアカウント登録を行ってください。
*   **"Signature verification failed"エラー:** このエラーは、署名が正しくない場合に発生します。ウォレットの接続を確認し、署名を再度試してください。
*   **トランザクションが遅い:** Immutable XはLayer2ソリューションなので、Ethereumメインネットよりもトランザクションが高速ですが、ネットワークの混雑状況によっては遅延が発生する場合があります。

### 3.2 ウォレット接続：Metamaskによる署名と認証

#### 概要と重要性

Immutable Xと連携するためには、ユーザーのウォレット（ここではMetamaskを例にとります）を接続し、トランザクションに署名する必要があります。ウォレット接続は、ユーザーがImmutable X上でNFTを取引したり、アプリケーションを利用したりする際に、自身の意思を証明するための重要なプロセスです。

#### 特徴と利点

*   **セキュリティ:** ユーザーは自身のウォレットの秘密鍵をImmutable Xに公開する必要はありません。署名によってトランザクションを承認することで、安全にImmutable Xを利用できます。
*   **利便性:** Metamaskなどのウォレットは、多くのユーザーが利用しており、Immutable Xとの連携も容易です。
*   **透明性:** 署名されたトランザクションは、ブロックチェーン上で公開され、誰でも検証することができます。

#### 事前準備と前提条件

*   **Metamask:** Metamaskがインストールされ、適切なネットワーク（Ethereumメインネット、Goerliテストネットなど）に接続されていること。
*   **Immutable X SDK:** Immutable X SDKがインストールされていること。
*   **Ethereumアカウント:** MetamaskにEthereumアカウントが作成されていること。

#### 基本的な使い方

ウォレット接続は、JavaScript/TypeScriptで以下の手順で行います。

1.  **Metamaskの接続確認:** `window.ethereum`オブジェクトの存在を確認し、Metamaskがブラウザにインストールされているかどうかを確認します。
2.  **アカウントへのアクセス要求:** `window.ethereum.request({ method: 'eth_requestAccounts' })`を使って、ユーザーにMetamaskへの接続を許可してもらうためのリクエストを送ります。
3.  **Providerの取得:** `ethers.providers.Web3Provider(window.ethereum)`を使って、Ethereum providerを取得します。
4.  **Signerの取得:**  `provider.getSigner()`を使って、署名者(Signer)を取得します。
5.  **Immutable Xクライアントの初期化:** 取得したSignerを使って、Immutable Xクライアントを初期化します。

以下は、JavaScript/TypeScriptでの基本的なウォレット接続のコード例です。

```typescript
import { ImmutableXClient, Config } from '@imtbl/imx-sdk';
import { ethers } from 'ethers';

async function connectWallet(): Promise<ImmutableXClient> {
  if (window.ethereum) {
    try {
      await window.ethereum.request({ method: 'eth_requestAccounts' }); // Metamask接続許可のリクエスト
      const provider = new ethers.providers.Web3Provider(window.ethereum);
      const signer = provider.getSigner();

      // Immutable Xクライアントの初期化 (テスト環境)
      const client = await ImmutableXClient.build({
        publicApiUrl: Config.SANDBOX.apiURL,
        signer: signer,
        starkContractAddress: Config.SANDBOX.starkContractAddress,
        registrationContractAddress: Config.SANDBOX.registrationContractAddress
      });

      return client;
    } catch (error) {
      console.error('Metamask接続エラー:', error);
      throw error;
    }
  } else {
    console.error('Metamaskがインストールされていません');
    throw new Error('Metamask not installed');
  }
}

// 例：ボタンクリックなどでconnectWallet()を呼び出し、ImmutableXClientを取得する
// document.getElementById('connectButton').addEventListener('click', async () => {
//   try {
//     const imxClient = await connectWallet();
//     console.log('Immutable Xクライアント:', imxClient);
//   } catch (error) {
//     console.error('Immutable Xクライアント初期化エラー:', error);
//   }
// });
```

**コード解説:**

1.  **Metamaskの存在確認:** `window.ethereum`が存在するかどうかを確認します。存在しない場合は、Metamaskがインストールされていないことを意味します。
2.  **アカウントへのアクセス要求:** `window.ethereum.request({ method: 'eth_requestAccounts' })`を使って、ユーザーにMetamaskへの接続を許可してもらうためのリクエストを送ります。
3.  **ProviderとSignerの取得:**  `ethers.providers.Web3Provider(window.ethereum)`でProviderを取得し、`provider.getSigner()`でSignerを取得します。Signerは、トランザクションに署名するために使用されます。
4.  **Immutable Xクライアントの初期化:** 取得したSignerを使って、Immutable Xクライアントを初期化します。

#### 実践的なテクニック

*   **ネットワークの切り替え:** ユーザーが誤ったネットワークに接続している場合、エラーが発生する可能性があります。`window.ethereum.request({ method: 'wallet_switchEthereumChain', params: [{ chainId: '0x5' }] })`を使って、正しいネットワーク（Goerliテストネットなど）に切り替えるように促すことができます。
*   **アカウントの変更検知:** ユーザーがMetamaskでアカウントを切り替えた場合、Immutable Xクライアントを再初期化する必要があります。`window.ethereum.on('accountsChanged', ...)`イベントをリッスンすることで、アカウントの変更を検知できます。

```typescript
window.ethereum.on('accountsChanged', async (accounts: string[]) => {
  if (accounts.length > 0) {
    console.log('アカウントが変更されました:', accounts[0]);
    // Immutable Xクライアントを再初期化する処理をここに記述
    try {
      const imxClient = await connectWallet();
      console.log('Immutable Xクライアントが再初期化されました:', imxClient);
    } catch (error) {
      console.error('Immutable Xクライアント再初期化エラー:', error);
    }
  } else {
    console.log('アカウントが切断されました');
  }
});
```

*   **チェーンIDの変更検知:** ユーザーがMetamaskで接続しているチェーンIDが変更された場合も、Immutable Xクライアントを再初期化する必要がある場合があります。`window.ethereum.on('chainChanged', ...)`イベントをリッスンすることで、チェーンIDの変更を検知できます。

#### 応用例とユースケース

*   **NFTの購入:** ユーザーがImmutable X上でNFTを購入する際に、Metamaskでトランザクションに署名します。
*   **ゲーム内のアイテム取引:** ゲーム内でImmutable Xを使ってアイテムを取引する際に、Metamaskでトランザクションに署名します。
*   **分散型取引所 (DEX):** Immutable Xを基盤としたDEXで、ユーザーがトークンを交換する際に、Metamaskでトランザクションに署名します。

#### トラブルシューティング

*   **"User rejected the request"エラー:** ユーザーがMetamaskの接続要求を拒否した場合に発生します。ユーザーに再度接続を促してください。
*   **"Provider not found"エラー:** Metamaskがインストールされていない、または有効になっていない場合に発生します。Metamaskがインストールされているかどうかを確認し、有効になっていることを確認してください。
*   **署名エラー:** トランザクションに署名する際にエラーが発生する場合があります。ネットワークの接続状況を確認し、Metamaskがロックされていないことを確認してください。

### 3.3 アカウント情報の取得：残高、取引履歴、NFT所有状況

#### 概要と重要性

アカウント作成とウォレット接続が完了したら、次はアカウント情報を取得します。アカウント情報には、残高、取引履歴、NFTの所有状況などが含まれます。これらの情報を取得することで、ユーザーのImmutable X上での活動状況を把握し、アプリケーションに表示したり、ユーザーに合わせたサービスを提供したりすることができます。

#### 特徴と利点

*   **ユーザー情報の把握:** アカウント情報を取得することで、ユーザーのImmutable X上での活動状況を把握することができます。
*   **パーソナライズされたサービス:** 取得したアカウント情報に基づいて、ユーザーに合わせたサービスを提供することができます。
*   **データ分析:** アカウント情報を分析することで、Immutable Xのエコシステムの動向を把握することができます。

#### 事前準備と前提条件

*   **Immutable Xクライアント:** Immutable Xクライアントが初期化されていること (ウォレット接続が完了していること)。
*   **Ethereumアドレス:** 情報を取得したいEthereumアドレス。

#### 基本的な使い方

Immutable X SDKを使って、アカウント情報を取得するには、以下のAPIを使用します。

*   **getBalance:** 指定されたトークンの残高を取得します。
*   **getTransactions:** 取引履歴を取得します。
*   **getAssets:** NFTの所有状況を取得します。

以下は、JavaScript/TypeScriptでの基本的なアカウント情報取得のコード例です。

```typescript
import { ImmutableXClient } from '@imtbl/imx-sdk';

async function getAccountInfo(client: ImmutableXClient, ethAddress: string) {
  try {
    // 残高の取得
    const balance = await client.getBalance({
      token: { type: 'ETH' }, // ETHの残高を取得する場合。ERC20トークンの場合はsymbolとcontractAddressを指定
      owner: ethAddress,
    });
    console.log('残高:', balance);

    // 取引履歴の取得
    const transactions = await client.getTransactions({
      pageSize: 10, // 取得するトランザクションの数
      orderBy: 'timestamp', // タイムスタンプでソート
      direction: 'desc', // 降順
      user: ethAddress,
    });
    console.log('取引履歴:', transactions.result);

    // NFT所有状況の取得
    const assets = await client.getAssets({
      pageSize: 10, // 取得するNFTの数
      orderBy: 'name', // 名前でソート
      direction: 'asc', // 昇順
      owner: ethAddress,
    });
    console.log('NFT所有状況:', assets.result);

    return { balance, transactions, assets };
  } catch (error) {
    console.error('アカウント情報取得エラー:', error);
    throw error;
  }
}

//   }

```

**コード解説:**

1.  **残高の取得:** `client.getBalance`を使って、指定されたトークンの残高を取得します。`token`パラメータで、取得したいトークンの種類を指定します。ETHの場合は`{ type: 'ETH' }`、ERC20トークンの場合は`{ symbol: 'USDC', contractAddress: '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48' }`のように指定します。`owner`パラメータで、残高を取得したいEthereumアドレスを指定します。
2.  **取引履歴の取得:** `client.getTransactions`を使って、取引履歴を取得します。`pageSize`パラメータで、取得するトランザクションの数を指定します。`orderBy`パラメータで、ソートの基準を指定します。`direction`パラメータで、ソートの方向を指定します。`user`パラメータで、取引履歴を取得したいEthereumアドレスを指定します。
3.  **NFT所有状況の取得:** `client.getAssets`を使って、NFTの所有状況を取得します。`pageSize`パラメータで、取得するNFTの数を指定します。`orderBy`パラメータで、ソートの基準を指定します。`direction`パラメータで、ソートの方向を指定します。`owner`パラメータで、NFT所有状況を取得したいEthereumアドレスを指定します。

#### 実践的なテクニック

*   **ページネーション:** 取引履歴やNFTの所有状況は、数が多くなる可能性があります。`getTransactions`や`getAssets` APIは、ページネーションに対応しています。`cursor`パラメータを使って、次のページのデータを取得することができます。
*   **フィルタリング:** `getTransactions`や`getAssets` APIは、様々なパラメータを使ってフィルタリングすることができます。例えば、特定のトークンに関する取引履歴のみを取得したり、特定のコレクションのNFTのみを取得したりすることができます。
*   **キャッシュ:** アカウント情報は、頻繁にアクセスされる可能性があります。キャッシュを導入することで、APIへのリクエスト数を減らし、パフォーマンスを向上させることができます。

#### 応用例とユースケース

*   **ウォレット:** ユーザーの残高、取引履歴、NFTの所有状況を表示するウォレットアプリケーションを開発します。
*   **ポートフォリオ:** ユーザーのImmutable X上での資産状況を表示するポートフォリオアプリケーションを開発します。
*   **ゲーム:** ユーザーが所有するNFTに基づいて、ゲーム内のキャラクターやアイテムをカスタマイズします。

#### トラブルシューティング

*   **APIレート制限:** Immutable X APIには、レート制限があります。レート制限を超えると、APIリクエストが拒否されます。APIリクエストの頻度を減らすか、レート制限を増やすための申請を行います。
*   **データの不整合:** APIから返されるデータが、期待されるデータと異なる場合があります。APIのドキュメントをよく確認し、正しいパラメータを指定しているかどうかを確認してください。
*   **エラーメッセージ:** APIから返されるエラーメッセージをよく確認し、エラーの原因を特定してください。

### 3.4 実装例：Reactを使ったアカウント情報表示

#### 概要と重要性

ここでは、Reactを使ってImmutable Xのアカウント情報を表示する具体的な実装例を紹介します。Reactは、UIを構築するための人気のJavaScriptライブラリであり、Immutable X APIとの連携も容易です。この実装例を参考に、自身のアプリケーションにアカウント情報表示機能を組み込むことができます。

#### 特徴と利点

*   **コンポーネントベース:** Reactはコンポーネントベースなので、UIを再利用可能な部品に分割することができます。
*   **宣言的なUI:** Reactは宣言的なUIなので、UIの状態をコードで記述し、Reactが自動的にUIを更新します。
*   **仮想DOM:** Reactは仮想DOMを使って、UIの変更を効率的に処理します。

#### 事前準備と前提条件

*   **Node.jsとnpm (または yarn):** Node.jsとnpm (または yarn)がインストールされていること。
*   **create-react-app:** create-react-appを使って、Reactプロジェクトを作成します。
*   **Immutable X SDK:** Immutable X SDKがインストールされていること。
*   **Ethereumウォレット:** Ethereumウォレット (Metamaskなど)がインストールされ、設定されていること。

#### 基本的な使い方

1.  **Reactプロジェクトの作成:** `npx create-react-app imx-account-info`を実行して、Reactプロジェクトを作成します。
2.  **Immutable X SDKのインストール:** `cd imx-account-info`を実行してプロジェクトディレクトリに移動し、`npm install @imtbl/imx-sdk ethers` または `yarn add @imtbl/imx-sdk ethers`を実行して、Immutable X SDKとethersをインストールします。
3.  **コンポーネントの作成:** アカウント情報を表示するためのReactコンポーネントを作成します。以下は、`src/components/AccountInfo.tsx`の例です。

```typescript jsx
import React, { useState, useEffect } from 'react';
import { ImmutableXClient, Config } from '@imtbl/imx-sdk';
import { ethers } from 'ethers';

interface AccountInfoProps {
  // 特にpropsは使用しない例
}

interface AccountData {
  balance: string;
  transactions: any[];
  assets: any[];
}

const AccountInfo: React.FC<AccountInfoProps> = () => {
  const [accountData, setAccountData] = useState<AccountData | null>(null);
  const [loading, setLoading] = useState<boolean>(false);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    const fetchAccountInfo = async () => {
      setLoading(true);
      setError(null);
      try {
        if (window.ethereum) {
          await window.ethereum.request({ method: 'eth_requestAccounts' });
          const provider = new ethers.providers.Web3Provider(window.ethereum);
          const signer = provider.getSigner();

          const client = await ImmutableXClient.build({
            publicApiUrl: Config.SANDBOX.apiURL,
            signer: signer,
            starkContractAddress: Config.SANDBOX.starkContractAddress,
            registrationContractAddress: Config.SANDBOX.registrationContractAddress
          });

          const ethAddress = await client.getAddress();

          const balance = await client.getBalance({
            token: { type: 'ETH' },
            owner: ethAddress,
          });

          const transactions = await client.getTransactions({
            pageSize: 5,
            orderBy: 'timestamp',
            direction: 'desc',
            user: ethAddress,
          });

          const assets = await client.getAssets({
            pageSize: 5,
            orderBy: 'name',
            direction: 'asc',
            owner: ethAddress,
          });

          setAccountData({
            balance: balance.balance,
            transactions: transactions.result,
            assets: assets.result,
          });
        } else {
          throw new Error('Metamask not installed');
        }
      } catch (err: any) {
        setError(err.message || 'Failed to fetch account info');
      } finally {
        setLoading(false);
      }
    };

    fetchAccountInfo();
  }, []);

  return (
    <div>
      <h2>Immutable X Account Info</h2>
      {loading && <p>Loading...</p>}
      {error && <p>Error: {error}</p>}
      {accountData && (
        <div>
          <p>Balance: {accountData.balance}</p>
          <h3>Transactions:</h3>
          <ul>
            {accountData.transactions.map((tx: any) => (
              <li key={tx.transaction_id}>
                Transaction ID: {tx.transaction_id}, Status: {tx.status}
              </li>
            ))}
          </ul>
          <h3>NFTs:</h3>
          <ul>
            {accountData.assets.map((asset: any) => (
              <li key={asset.token_id}>
                Name: {asset.name}, Token ID: {asset.token_id}
              </li>
            ))}
          </ul>
        </div>
      )}
    </div>
  );
};

export default AccountInfo;
```

4.  **コンポーネントの利用:** `src/App.tsx`で、作成した`AccountInfo`コンポーネントを利用します。

```typescript jsx
import React from 'react';
import AccountInfo from './components/AccountInfo';
import './App.css';

function App() {
  return (
    <div className="App">
      <header className="App-header">
        <h1>Immutable X Account Information</h1>
        <AccountInfo />
      </header>
    </div>
  );
}

export default App;
```

5.  **アプリケーションの実行:** `npm start` または `yarn start`を実行して、アプリケーションを実行します。

**コード解説:**

*   **useStateフック:** `useState`フックを使って、アカウント情報、ローディング状態、エラー状態を管理します。
*   **useEffectフック:** `useEffect`フックを使って、コンポーネントがマウントされたときにアカウント情報を取得します。
*   **Immutable X APIの呼び出し:** `ImmutableXClient`を使って、アカウント情報を取得します。
*   **UIの表示:** 取得したアカウント情報を、UIに表示します。

#### 実践的なテクニック

*   **エラーハンドリング:** アカウント情報取得時にエラーが発生した場合、エラーメッセージを表示するようにしましょう。
*   **ローディング表示:** アカウント情報取得中に、ローディング表示を表示することで、ユーザーエクスペリエンスを向上させることができます。
*   **スタイリング:** CSSを使って、UIをスタイリングしましょう。

#### 応用例とユースケース

*   **ウォレットアプリケーション:** ユーザーの残高、取引履歴、NFTの所有状況を表示するウォレットアプリケーションを開発します。
*   **ポートフォリオアプリケーション:** ユーザーのImmutable X上での資産状況を表示するポートフォリオアプリケーションを開発します。
*   **ゲーム:** ユーザーが所有するNFTに基づいて、ゲーム内のキャラクターやアイテムをカスタマイズします。

#### トラブルシューティング

*   **"TypeError: window.ethereum is undefined"エラー:** Metamaskがインストールされていない、または有効になっていない場合に発生します。Metamaskがインストールされているかどうかを確認し、有効になっていることを確認してください。
*   **APIレート制限:** Immutable X APIには、レート制限があります。レート制限を超えると、APIリクエストが拒否されます。APIリクエストの頻度を減らすか、レート制限を増やすための申請を行います。
