# 第6章: 数学マジック - Scratchでプログラムに命を吹き込む

Scratchを用いることで、プログラムに動き、インタラクティブ性、そして予測不可能な要素を手軽に加えることができます。数学的な考え方を基に、三角関数、ベクトル、座標変換、そして乱数と確率を活用し、見た目にも楽しいアニメーションやゲームの挙動を実現しましょう。

---

## 6.1 三角関数とベクトル - 複雑な動きを表現する

### 概要と重要性

* **三角関数:** Scratchの「sin」「cos」「tan」ブロック（演算ブロック内）を使い、角度に応じた計算ができます。たとえば、円運動や波の動きの表現に役立ちます。なお、Scratchでは角度は度数（°）で扱われるため、ラジアン変換は不要です。

* **ベクトル:** Scratch自体に専用のベクトルオブジェクトはありませんが、スプライトの座標 (x, y) や「向き」ブロックを活用することで、方向や速度をベクトル的に扱うことが可能です。

### 実践例：円運動するスプライト

以下は、円運動をさせるScratchの擬似スクリプト例です。変数「centerX」「centerY」「radius」「angle」を用意し、常に円周上の位置へスプライトを移動させます。

```scratch
// スクラッチ風のブロック疑似コード

// [緑の旗がクリックされたとき]
  set [centerX v] to (0)        // ステージ中央の場合（x座標）
  set [centerY v] to (0)        // ステージ中央の場合（y座標）
  set [radius v] to (150)       // 好きな半径（例:150ピクセル）
  set [angle v] to (0)

  // [ずっと]
    // x座標とy座標を計算してスプライトを移動
    set x to ((centerX) + (radius) * (cos (angle)))
    set y to ((centerY) + (radius) * (sin (angle)))
    change [angle v] by (5)      // 角度を5°ずつ増加
    wait (0.1) seconds
  end
```

このように、三角関数と変数を組み合わせることで、自然な円運動のアニメーションを作ることができます。

## 6.2 座標変換 - 2Dグラフィックスの基礎

### 概要と重要性

Scratchは主に2D環境ですが、スプライトの「位置を移動」「回転」「大きさを変える」といった変形を使って、さまざまな視覚効果を実現できます。これにより、キャラクターの移動、回転、拡大縮小などを直感的に表現可能です。

### 基本的な変換操作

* **平行移動:** 「○○に行く」や「x座標を○○にする」「y座標を○○にする」ブロックを使って、スプライトの位置を自由に操作できます。

* **回転:** 「向きを○○度にする」や「右に○○度回す」ブロックを用いて、スプライトを回転させることができます。

* **拡大縮小:** 「大きさを○○%にする」ブロックでスプライトのサイズを変更し、疑似的なズーム効果を演出できます。

### 実践例：スプライトの回転と拡大縮小

以下は、スプライトが回転しながら大きくなったり小さくなったりするシンプルな動きを表現する例です。

```scratch
// [緑の旗がクリックされたとき]
  set [angle v] to (0)
  set [size v] to (100)   // 初期サイズ100%

  // [ずっと]
    // 回転させる
    turn cw (5) degrees

    // 拡大縮小の切り替え（例: 100%～150%の間を行ったり来たり）
    if <(size) > (150)> then
      set [direction v] to (-1)
    end
    if <(size) < (100)> then
      set [direction v] to (1)
    end
    change [size v] by ((direction) * (2))
    set size to (size)
    
    wait (0.1) seconds
  end
```

この例では、スプライトが一定の角度で回転しながら、サイズが徐々に大きくなったり小さくなったりすることで、動的な変形効果を実現しています。

## 6.3 乱数と確率 - 予測不可能な世界を創り出す

### 概要と重要性

* **乱数:** Scratchには「乱数を取る」ブロックがあり、たとえば「1から100までの乱数を取る」といった具合に、ランダムな数値を簡単に生成できます。これにより、スプライトの位置や動き、見た目などに変化を加え、予測不可能な挙動を実現します。

* **確率:** 乱数を利用して、ある条件が一定の確率で発生するイベントを作ることができます。ゲーム内でのアイテムの出現や、敵の行動パターンにランダム性を加えるのに役立ちます。

### 実践例：ランダムに行動する敵キャラクター

以下は、敵キャラクターが一定の確率でランダムな動きをするScratch風の例です。乱数によって行動の発生を決定し、場合によっては攻撃や移動などを実行します。

```scratch
// [緑の旗がクリックされたとき]
  // 初期位置を設定（例: ステージ中央）
  go to x: (0) y: (0)

  // [ずっと]
    // 乱数を使って行動の確率を決定（例: 20%の確率で行動）
    if <(pick random (1) to (100)) < (20)> then
      // ランダムな行動を選ぶ
      set [action v] to (pick random (1) to (3))
      if <(action) = (1)> then
        // ランダムな方向へ移動
        point in direction (pick random (0) to (360))
        move (10) steps
      else
        if <(action) = (2)> then
          // 攻撃アクション（例: 「攻撃！」と話す）
          say [攻撃！] for (2) seconds
        else
          // 退却アクション（例: 後ろに少し移動）
          point in direction ((direction) + (180))
          move (5) steps
        end
      end
    end
    wait (0.2) seconds
  end
```

このように、Scratchの乱数ブロックを用いることで、スプライトの行動に多様性と予測不可能性を持たせることが可能です。
