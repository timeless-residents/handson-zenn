# 第12章: テキストベースプログラミングへの移行 - 未来へのステップ

Scratchでのブロックプログラミングは、プログラミングの概念を理解するための素晴らしい入り口でした。しかし、真に自由な発想を形にするには、テキストベースのプログラミング言語の習得が不可欠です。この章では、Python、JavaScript、そしてUnityという3つの主要な言語とプラットフォームを通して、Scratchからステップアップし、未来への扉を開くための知識とスキルを身につけていきます。

## 12.1 Python入門 - Scratchから次のレベルへ

### 12.1.1 概要と重要性

Pythonは、その読みやすさと汎用性の高さから、初心者にも優しいプログラミング言語として広く知られています。Web開発、データ分析、機械学習、自動化スクリプトなど、様々な分野で活用されており、習得することで可能性が大きく広がります。Scratchで培った論理的思考力を活かし、Pythonの世界へ飛び込みましょう。

### 12.1.2 特徴と利点

*   **可読性の高さ:** Pythonの文法は英語に近く、非常に読みやすいのが特徴です。これにより、コードの理解が容易になり、学習効率が向上します。
*   **豊富なライブラリ:** 機械学習、Webフレームワーク、データ分析など、様々な分野に対応した膨大なライブラリが利用可能です。これにより、複雑な処理も比較的簡単に実装できます。
*   **強力なコミュニティ:** 世界中に活発なPythonコミュニティが存在し、豊富なドキュメントやサンプルコードが提供されています。困ったときには、すぐに助けを求めることができます。
*   **多様な用途:** Web開発（Django, Flask）、データ分析（Pandas, NumPy）、機械学習（TensorFlow, PyTorch）、自動化スクリプトなど、幅広い分野で活用されています。

### 12.1.3 事前準備と前提条件

*   **Pythonのインストール:** Python公式サイト ([https://www.python.org/downloads/](https://www.python.org/downloads/)) から、ご自身のOSに合ったバージョンをダウンロードしてインストールしてください。3系（3.x.x）を推奨します。
*   **テキストエディタの準備:** コードを記述するためのテキストエディタが必要です。Visual Studio Code, Sublime Text, Atomなどが人気です。Visual Studio CodeはPython拡張機能が充実しているのでおすすめです。
*   **基本的なPCスキル:** ファイルの操作、フォルダの概念、ターミナル（コマンドプロンプト）の基本的な操作が必要です。
*   **Scratchの知識:** Scratchでプログラミングの基本的な概念（変数、条件分岐、繰り返しなど）を理解していることが望ましいです。

### 12.1.4 基本的な使い方

1.  **Hello, World!:**
    テキストエディタを開き、以下のコードを記述し、`hello.py`という名前で保存します。

    ```python
    print("Hello, World!")
    ```

    ターミナル（コマンドプロンプト）を開き、`hello.py`が保存されているディレクトリに移動し、以下のコマンドを実行します。

    ```bash
    python hello.py
    ```

    ターミナルに "Hello, World!" と表示されれば成功です。

2.  **変数:**

    ```python
    name = "太郎"
    age = 10
    print("こんにちは、" + name + "さん！" + age + "歳ですね。")
    print(f"こんにちは、{name}さん！{age}歳ですね。") # f-stringを使った書き方（推奨）
    ```

3.  **データ型:**

    *   **整数型 (int):** 1, 2, -3, 0
    *   **浮動小数点数型 (float):** 3.14, -2.5, 0.0
    *   **文字列型 (str):** "Hello", "Python", "123"
    *   **真偽値型 (bool):** True, False
    *   **リスト型 (list):** [1, 2, 3], ["a", "b", "c"]
    *   **辞書型 (dict):** {"name": "太郎", "age": 10}

4.  **条件分岐:**

    ```python
    age = 15
    if age >= 18:
        print("成人です。")
    else:
        print("未成年です。")
    ```

5.  **繰り返し:**

    ```python
    # forループ
    for i in range(5): # 0から4まで繰り返す
        print(i)

    # whileループ
    count = 0
    while count < 5:
        print(count)
        count += 1
    ```

6.  **関数:**

    ```python
    def greet(name):
        print("こんにちは、" + name + "さん！")

    greet("花子")
    ```

### 12.1.5 実践的なテクニック

*   **リスト内包表記:** より簡潔にリストを生成するテクニックです。

    ```python
    numbers = [1, 2, 3, 4, 5]
    squares = [x**2 for x in numbers] # [1, 4, 9, 16, 25]
    ```

*   **ラムダ式:** 無名関数を作成するテクニックです。

    ```python

    print(add(5, 3)) # 8
    ```

*   **モジュールのインポート:** `import`文を使って、外部のモジュールをインポートします。

    ```python

    ```

### 12.1.6 応用例とユースケース

*   **シンプルな電卓:** 四則演算を行う電卓プログラム。

    ```python
    def add(x, y):
        return x + y

    def subtract(x, y):
        return x - y

    def multiply(x, y):
        return x * y

    def divide(x, y):
        if y == 0:
            return "エラー: 0で割ることはできません。"
        return x / y

    print("計算の種類を選んでください。")
    print("1. 足し算")
    print("2. 引き算")
    print("3. 掛け算")
    print("4. 割り算")

    choice = input("選択肢(1/2/3/4): ")

    num1 = float(input("最初の数字を入力してください: "))
    num2 = float(input("2番目の数字を入力してください: "))

    if choice == '1':
        print(num1, "+", num2, "=", add(num1, num2))
    elif choice == '2':
        print(num1, "-", num2, "=", subtract(num1, num2))
    elif choice == '3':
        print(num1, "*", num2, "=", multiply(num1, num2))
    elif choice == '4':
        print(num1, "/", num2, "=", divide(num1, num2))
    else:
        print("無効な入力")
    ```

*   **ScratchのゲームをPythonで書き換える:**
    例えば、Scratchで作成したシンプルなシューティングゲームをPygameライブラリを使って書き換えることができます。Pygameは、ゲーム開発に必要な機能が豊富に用意されており、2Dゲームを簡単に作成できます。

    (Pygameでのシューティングゲームのサンプルコードは、スペースの都合上省略します。Pygameのドキュメントを参照してください。[https://www.pygame.org/docs/](https://www.pygame.org/docs/))

*   **Webスクレイピング:** `requests`と`BeautifulSoup`ライブラリを使って、Webサイトから情報を抽出する。

    ```python
    import requests
    from bs4 import BeautifulSoup

    url = "https://www.example.com"  # スクレイピングしたいURL
    response = requests.get(url)

    if response.status_code == 200:
        soup = BeautifulSoup(response.content, 'html.parser')
        title = soup.title.text
        print("ページのタイトル:", title)
    else:
        print("エラー:", response.status_code)
    ```

### 12.1.7 トラブルシューティング

*   **SyntaxError:** コードの文法が間違っている場合に発生します。エラーメッセージをよく読み、スペルミスや括弧の閉じ忘れなどを確認してください。
*   **IndentationError:** インデント（字下げ）が正しくない場合に発生します。Pythonではインデントが非常に重要なので、注意が必要です。
*   **NameError:** 定義されていない変数や関数を使用した場合に発生します。変数名や関数名が正しいか確認してください。
*   **TypeError:** データ型が間違っている場合に発生します。例えば、文字列と数値を足し算しようとした場合などです。

### 12.1.8 まとめと次のステップ

Pythonの基礎を理解し、簡単なプログラムを作成できるようになりました。次は、Pygameなどのゲーム開発ライブラリを使って、より複雑なゲームを作成したり、DjangoやFlaskなどのWebフレームワークを使って、Webアプリケーションを開発したりすることに挑戦してみましょう。

## 12.2 JavaScript入門 - Web開発の世界へ

### 12.2.1 概要と重要性

JavaScriptは、Webブラウザ上で動作するプログラミング言語であり、Webサイトにインタラクティブな要素を追加するために不可欠です。近年では、Node.jsという実行環境を使うことで、サーバーサイドの開発も可能になり、JavaScriptの活躍の場はますます広がっています。

### 12.2.2 特徴と利点

*   **Webブラウザで動作:** JavaScriptは、Webブラウザ上で直接実行されるため、特別な環境構築は不要です。
*   **DOM操作:** HTML要素をJavaScriptから操作することで、Webページの見た目や動作を動的に変更できます。
*   **豊富なフレームワーク:** React, Angular, Vue.jsなどのフレームワークを使うことで、大規模なWebアプリケーションを効率的に開発できます。
*   **サーバーサイド開発:** Node.jsを使うことで、JavaScriptを使ってサーバーサイドの開発も可能です。
*   **幅広い用途:** Webサイトのフロントエンド開発、Webアプリケーション開発、ゲーム開発、モバイルアプリ開発など、様々な分野で活用されています。

### 12.2.3 事前準備と前提条件

*   **Webブラウザ:** Google Chrome, Mozilla FirefoxなどのWebブラウザが必要です。
*   **テキストエディタ:** Visual Studio Code, Sublime Text, Atomなどが人気です。JavaScriptのシンタックスハイライトに対応しているエディタを選びましょう。
*   **HTML/CSSの基礎知識:** JavaScriptを学ぶ前に、HTMLとCSSの基本的な知識を習得しておくことをお勧めします。
*   **Scratchの知識:** Scratchでプログラミングの基本的な概念（変数、条件分岐、繰り返しなど）を理解していることが望ましいです。

### 12.2.4 基本的な使い方

    *   **真偽値型 (boolean):** true, false
    *   **配列型 (array):** [1, 2, 3], ["a", "b", "c"]

4.  **条件分岐:**

## 12.3 Unity入門 - 3Dゲーム開発への挑戦

### 12.3.1 概要と重要性

Unityは、2Dおよび3Dゲーム、インタラクティブなシミュレーション、ビジュアライゼーションを開発するための強力なクロスプラットフォームゲームエンジンです。初心者からプロの開発者まで幅広く利用されており、豊富なアセットストアやコミュニティサポートが魅力です。

### 12.3.2 特徴と利点

*   **クロスプラットフォーム:** Windows, macOS, iOS, Android, WebGLなど、様々なプラットフォームに対応しています。
*   **ビジュアルエディタ:** 直感的なビジュアルエディタを使って、ゲームオブジェクトの配置や設定を簡単に行えます。
*   **C#スクリプト:** C#を使って、ゲームのロジックを記述します。
*   **豊富なアセットストア:** キャラクター、背景、サウンドなどのアセットを購入・利用することで、開発効率を向上させることができます。
*   **強力なコミュニティ:** 世界中に活発なUnityコミュニティが存在し、豊富なドキュメントやチュートリアルが提供されています。

### 12.3.3 事前準備と前提条件

*   **Unity Hubのインストール:** Unity公式サイト ([https://unity.com/](https://unity.com/)) から、Unity Hubをダウンロードしてインストールしてください。Unity Hubは、Unityエディタのバージョン管理やプロジェクト管理を行うためのツールです。
*   **Unityエディタのインストール:** Unity Hubを使って、Unityエディタをインストールします。最新の推奨バージョンをインストールすることをお勧めします。
*   **Visual Studioのインストール (Windowsの場合):** C#スクリプトを記述するために、Visual Studioが必要です。Unityインストーラで自動的にインストールできます。
*   **C#の基礎知識:** C#の基本的な知識を習得しておくことをお勧めします。
*   **Scratchの知識:** Scratchでプログラミングの基本的な概念（変数、条件分岐、繰り返しなど）を理解していることが望ましいです。

### 12.3.4 基本的な使い方

1.  **新しいプロジェクトの作成:** Unity Hubを起動し、新しいプロジェクトを作成します。テンプレートを選択する画面では、2Dまたは3Dを選択します。
2.  **Unityエディタのインターフェース:**
    *   **Sceneビュー:** ゲームのシーンを視覚的に編集するためのビューです。
    *   **Gameビュー:** 実際にゲームを実行したときの画面を表示するビューです。
    *   **Hierarchyウィンドウ:** シーンに存在するゲームオブジェクトの階層構造を表示します。
    *   **Inspectorウィンドウ:** 選択したゲームオブジェクトのプロパティを表示・編集します。
    *   **Projectウィンドウ:** プロジェクトで使用するアセット（スクリプト、画像、モデルなど）を表示します。
    *   **Consoleウィンドウ:** エラーメッセージやデバッグ情報を表示します。

3.  **ゲームオブジェクトの作成:**
    Hierarchyウィンドウで右クリックし、Create > 3D Object > Cubeなどを選択して、ゲームオブジェクトを作成します。
4.  **コンポーネントの追加:**
    InspectorウィンドウでAdd Componentボタンをクリックし、コンポーネントを追加します。例えば、Rigidbodyコンポーネントを追加すると、物理演算が適用されます。
5.  **C#スクリプトの作成:**
    Projectウィンドウで右クリックし、Create > C# Scriptを選択して、C#スクリプトを作成します。スクリプトをダブルクリックすると、Visual Studioで開きます。

    ```csharp
    using UnityEngine;

    public class PlayerController : MonoBehaviour
    {
        public float speed = 5.0f;

        void Update()
        {
            float horizontalInput = Input.GetAxis("Horizontal");
            float verticalInput = Input.GetAxis("Vertical");

            Vector3 movement = new Vector3(horizontalInput, 0, verticalInput);
            transform.Translate(movement * speed * Time.deltaTime);
        }
    }
    ```

6.  **スクリプトのアタッチ:**
    作成したC#スクリプトを、Hierarchyウィンドウのゲームオブジェクトにドラッグ＆ドロップしてアタッチします。
7.  **ゲームの実行:**
    Unityエディタの上部にある再生ボタンをクリックして、ゲームを実行します。

### 12.3.5 実践的なテクニック

*   **プレハブ:** ゲームオブジェクトをテンプレート化し、再利用性を高める仕組みです。
*   **アニメーション:** アニメーションクリップを作成し、ゲームオブジェクトにアタッチすることで、動きを表現できます。
*   **UIシステム:** キャンバスを作成し、ボタンやテキストなどのUI要素を配置することで、ユーザーインターフェースを作成できます。
*   **物理演算:** RigidbodyコンポーネントやColliderコンポーネントを使って、物理演算をシミュレーションできます。

*   **ScratchのゲームをUnityで再現:**
    例えば、Scratchで作成したシンプルなプラットフォーマーゲームをUnityで再現することができます。Unityの2D機能を使うと、2Dゲームを簡単に作成できます。

    (Unityでのプラットフォーマーゲームのサンプルコードは、スペースの都合上省略します。Unityの公式チュートリアルを参照してください。[https://learn.unity.com/](https://learn.unity.com/))

*   **VR/AR開発:** UnityはVR/AR開発にも対応しています。VRヘッドセットやARデバイスを使って、没入感のある体験を開発できます。

### 12.3.7 トラブルシューティング

*   **スクリプトのエラー:** Visual Studioでエラーメッセージを確認し、コードの文法や論理に誤りがないか確認してください。
*   **ゲームオブジェクトの配置:** Sceneビューでゲームオブジェクトの位置やスケールを調整してください。
*   **コンポーネントの設定:** Inspectorウィンドウでコンポーネントのプロパティを適切に設定してください。
*   **Unityのドキュメント:** Unityの公式ドキュメントは、非常に充実しています。困ったときは、ドキュメントを参照してください。[https://docs.unity3d.com/ja/](https://docs.unity3d.com/ja/)

### 12.3.8 まとめと次のステップ

Unityの基礎を理解し、簡単な3Dゲームを作成できるようになりました。次は、Unityの公式チュートリアルや、オンラインのコースを受講して、より高度なゲーム開発に挑戦してみましょう。アセットストアを活用して、自分のゲームにオリジナルの要素を追加することもできます。
