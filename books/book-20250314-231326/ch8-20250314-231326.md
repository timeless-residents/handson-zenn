# 第8章: シミュレーションプログラミング - 現実世界をモデル化する

Scratchでは、複雑な数学的計算や大規模な並列処理は難しいものの、シンプルなルールや確率的な動作を使って現実世界の現象の「モデル」を作成することができます。ここでは、自然現象や社会システムのシミュレーション例を通して、シンプルながらも現実の一端を再現する方法を学びます。

---

## 8.1 自然現象のシミュレーション - 美しい物理法則

### 概要と重要性

自然現象のシミュレーションでは、目には見えにくい物理法則や微小な動きを、Scratchのクローンや変数、乱数ブロックを用いて表現します。たとえば、粒子の不規則な動き（ブラウン運動）や、複数の粒子が相互作用してパターンを作る様子を、シンプルなルールで再現できます。  
  
**特徴と利点**  
- **可視化:** 抽象的な自然現象を、画面上の動くスプライトで直感的に理解できます。  
- **予測:** ルールに基づくシミュレーションを通じ、どのような挙動が起こるかを予測できます。  
- **学習効果:** 自然界の法則（運動、衝突、反発など）を視覚的に体感できます。

### 実践例：ブラウン運動のシミュレーション

Scratchでは、複数の粒子（クローン）をランダムに動かすことで、ブラウン運動（微粒子の不規則な動き）をシンプルに再現できます。以下は、各粒子がランダムに動き、ステージの端に当たると反射する例です。

#### メインスクリプト（背景・管理用）
```scratch
// [緑の旗がクリックされたとき]
delete all clones  // 既存のクローンを削除
set [粒子数 v] to (20)  // 作成する粒子の数を設定
repeat (粒子数)
  create clone of [粒子 v]
end
```

#### 粒子スプライトのスクリプト
```scratch
// [このスプライトのクローンが作られたとき]
go to x: (pick random (-240) to (240)) y: (pick random (-180) to (180))
// [ずっと]
forever
  move (pick random (1) to (5)) steps
  // ランダムな左右の方向転換
  turn (pick random (-30) to (30)) degrees
  // ステージの端に当たったら自動で反射
  if on edge, bounce
  wait (0.1) seconds
end
```

この例では、各粒子が乱数によって動きの大きさや方向を変化させるため、自然界の微細な衝突や拡散の様子をシンプルに表現できます。

### 応用：反応拡散系のシンプルモデル

反応拡散系は、化学反応と物質の拡散によって複雑なパターンが生じる現象です。Scratchでは、グリッド状に配置した「セル」スプライトを使い、隣接するセル同士の状態を一定の確率で変化させることで、シンプルなパターン形成（チューリングパターン）を再現できます。  

【概念例】  
1. セル用のスプライトを用意し、背景のグリッドとして配置（もしくはクローンでグリッド状に配置）。  
2. 各セルは「反応中」か「安定状態」を表す変数（例：色や数値）を持つ。  
3. ずっとループ内で、隣接セルの状態を参照し、一定の確率で自分の状態を変更する。

※ 詳細な実装は、Scratchの処理能力に合わせてルールやグリッドサイズを調整してください。

## 8.2 社会システムのモデル化 - 未来を予測する

### 概要と重要性

社会システムのシミュレーションでは、経済や交通など、複数の要素が相互に影響し合う仕組みをシンプルなルールで表現します。Scratchでは、変数と乱数、クローンの管理機能を使い、個々の「エージェント」（例：車や株価の値）を動かして、システム全体の挙動をモデル化します。

### 経済シミュレーション：株価変動モデル

株価の変動は、ランダムウォークに近い動きをすることが多いため、変数を用いたランダムな増減で表現できます。さらに、ペンブロックを用いて、時系列グラフを描画することも可能です。

#### スクリプト例（株価グラフの描画）
```scratch
// [緑の旗がクリックされたとき]
clear  // ペンを消去
go to x: (-240) y: (0)  // グラフの開始位置
pen down
set [株価 v] to (100)  // 初期株価を設定

// [ずっと]
forever
  // ランダムな変動（-2〜+2の範囲で変動）
  change [株価 v] by (pick random (-2) to (2))
  // X方向に一定ステップずつ移動してプロット
  move (5) steps
  // Y座標は株価に応じて設定
  point in direction (90)  // 上方向にペンを進める
  go to x: (x position + 5) y: (株価)
  wait (0.1) seconds
end
```

この例では、株価が毎回ランダムに変動し、その結果をペンで線を引く形でグラフ化します。グラフを描くことで、時系列の変化が視覚的に理解できるようになります。

### 交通シミュレーション：渋滞モデル

交通シミュレーションでは、道路上を走る車の動きをクローンを使って表現します。各車両は、自身の速度や前の車との距離に応じて加速・減速を行い、道路上を移動します。

#### メインスクリプト（車の生成）
```scratch
// [緑の旗がクリックされたとき]
delete all clones  // 既存の車のクローンを削除
// ずっと
forever
  create clone of [車 v]
  wait (pick random (0.5) to (2)) seconds
end
```

#### 車スプライトのスクリプト
```scratch
// [このスプライトのクローンが作られたとき]
go to x: (-240) y: (固定の道路Y座標)  // 道路上に配置
set [速度 v] to (pick random (3) to (5))  // 初期速度を設定

// [ずっと]
forever
  // 前の車との距離チェック（簡易的に「他の車に触れているか」で判断）
  if <touching [車 v]?> then
    change [速度 v] by (-1)  // 接近している場合は減速
  else
    if <(速度) < (5)> then
      change [速度 v] by (1)  // 速度上限まで加速
    end
  end
  move (速度) steps
  // 画面右端に達したらクローンを削除
  if <x position > (240)> then
    delete this clone
  end
  wait (0.1) seconds
end
```

この例では、車が一定のルールに基づいて前の車との距離を考慮しながら移動することで、シンプルな渋滞の様子を再現します。

## 8.3 データ可視化 - シミュレーション結果をわかりやすく表現

### 概要と重要性

シミュレーションで得られたデータや結果を視覚化することで、パターンや傾向を直感的に理解できます。Scratchでは、ペンブロックやリスト、スプライトの位置・コスチューム変更を用いて、シンプルなグラフやチャートを作成できます。

### 折れ線グラフの描画例

たとえば、先ほどの株価変動シミュレーションでは、ペンブロックを使って時系列の折れ線グラフを描くことができます。  
  
【基本の流れ】  
1. 緑の旗がクリックされたときに画面をクリアし、描画開始位置に移動。  
2. ペンを下ろし、データ（例：株価）の変化に合わせてX軸方向に一定ステップずつ移動しながら、Y座標をデータ値に応じて設定。  
3. ループ内で変化をプロットし、グラフとして表示する。

### その他の可視化テクニック

- **棒グラフ:** リストに数値データを格納し、各項目ごとにスプライトの大きさや位置を変化させることで、棒グラフ風の表示が可能です。  
- **ヒートマップ風:** 背景のグリッド状に多数の小さなスプライト（またはクローン）を配置し、各セルの状態に応じて色（コスチューム）を変えることで、2次元のデータ分布を表現できます。  
- **アニメーション:** シミュレーションの時間経過に合わせてグラフや数値表示を更新することで、データの動的な変化をリアルタイムに観察できます。

### 応用例：複数のシミュレーション結果を同時に表示

たとえば、経済シミュレーションと交通シミュレーションの結果をそれぞれ別のスプライトや背景として表示し、ユーザーがタブやボタンで切り替えられるようにすることで、異なる現象の相互比較や全体像の把握が可能になります。
