## 7. RPA 開発実践：Excel 自動化

Excel は、多くの企業で業務の中核を担うツールです。RPA（Robotic Process Automation）と組み合わせることで、Excel で行われる反復作業を自動化し、業務効率を飛躍的に向上させることができます。本章では、RPA ツールを用いて Excel を自動化する実践的な方法を、初心者から上級者まで理解できるように解説します。

### 7.1 Excel ファイルの読み書き

#### 概要と重要性

Excel ファイルの読み書きは、RPA による Excel 自動化の基本中の基本です。データの入力、加工、集計など、様々な処理の起点となるため、確実な理解が求められます。RPA ツールは、CSV や XLSX など、様々なデータ形式をサポートしており、これらを適切に扱うことで、より広範な業務を自動化できます。

#### 特徴と利点

- **効率化:** 大量のデータを手作業で入力・編集する手間を削減。
- **正確性:** ヒューマンエラーを排除し、正確なデータ処理を実現。
- **柔軟性:** 様々なデータ形式に対応し、多様な業務プロセスに適用可能。
- **拡張性:** RPA の他の機能と組み合わせることで、より複雑な自動化を実現。

#### 事前準備と前提条件

- RPA ツール（例：Automation Anywhere、UiPath、Power Automate Desktop）のインストールと基本的な操作の理解。
- 対象となる Excel ファイルへのアクセス権。
- 必要な RPA ツールと Excel 間の接続設定。

#### 基本的な使い方

多くの RPA ツールは、Excel ファイルの読み書きを容易にするための専用のアクションやコマンドを提供しています。ここでは、Automation Anywhere を例に、基本的な操作を説明します。

**Excel ファイルの読み込み**

1.  Automation Anywhere のワークスペースで、新しい Bot を作成します。
2.  「アクション」パネルから「Excel」を検索し、「Excel を開く」アクションをドラッグ＆ドロップします。
3.  開く Excel ファイルのパスを指定します。
4.  「ワークシートを開く」アクションを追加し、操作対象のワークシートを選択します。
5.  「データを取得」アクションを追加し、読み込むセルの範囲を指定します。
6.  取得したデータは、変数に格納されます。

**Excel ファイルへの書き込み**

1.  「Excel を開く」アクションで Excel ファイルを開きます。
2.  「ワークシートを開く」アクションで操作対象のワークシートを選択します。
3.  「セルに書き込む」アクションを追加し、書き込むセルとデータを指定します。
4.  必要に応じて、複数のセルへの書き込みを繰り返します。
5.  「Excel を保存」アクションで変更を保存します。
6.  「Excel を閉じる」アクションで Excel ファイルを閉じます。

#### 実践的なテクニック

- **ループ処理:** 大量のデータを処理する場合、ループ処理を効果的に活用します。例えば、Excel ファイルの各行を順番に読み込み、特定の条件に合致するデータだけを別のシートに書き出す、といった処理を自動化できます。
- **条件分岐:** データの値に基づいて処理を分岐させることで、より複雑なロジックを実装できます。例えば、売上データが一定額を超えた場合に、アラートメールを送信する、といった処理を自動化できます。
- **エラーハンドリング:** Excel ファイルの形式が想定と異なる場合や、ファイルが見つからない場合など、エラーが発生した場合の処理を事前に定義しておくことで、RPA の安定性を高めることができます。

#### 応用例とユースケース

**大量データの集計と分析**

複数の Excel ファイルに分散している売上データを集計し、月次の売上レポートを作成する業務を自動化します。

```
# Automation Anywhereコード例

# Excelファイルを開く
Excel:Open File path:"C:\SalesData\MonthlySalesReport_{Year}_{Month}.xlsx" session:"Default"

# ワークシートを開く
Excel:Activate sheet name:"Sheet1" session:"Default"

# 最終行を取得
Excel:Get last row session:"Default" to Variable: "LastRow"

# ループ処理で各行を読み込む
Loop:Times {{LastRow}} times
  # 現在の行番号を計算
  Variable:Assign current row number to Variable:"CurrentRow" using formula "{{Loop:Index}}"

  # 各セルのデータを取得
  Excel:Get cell value column:"A" row:"{{CurrentRow}}" session:"Default" to Variable:"ProductID"
  Excel:Get cell value column:"B" row:"{{CurrentRow}}" session:"Default" to Variable:"ProductName"
  Excel:Get cell value column:"C" row:"{{CurrentRow}}" session:"Default" to Variable:"SalesAmount"

  # 売上データを集計
  Number:Increment Variable:"TotalSales" by {{SalesAmount}}

End Loop

# 集計結果をExcelに書き込む
Excel:Activate sheet name:"Summary" session:"Default"
Excel:Set cell value column:"B" row:"2" value:"{{TotalSales}}" session:"Default"

# Excelファイルを保存して閉じる
Excel:Save File session:"Default"
Excel:Close File session:"Default"
```

**顧客情報の登録**

Web フォームから入力された顧客情報を、Excel ファイルに自動的に登録する業務を自動化します。

#### トラブルシューティング

- **Excel ファイルが開けない:** ファイルパスが正しいか、アクセス権があるかを確認してください。また、Excel ファイルが破損していないかを確認してください。
- **データが正しく読み込まれない:** セルの範囲が正しいか、データ形式が想定通りかを確認してください。
- **書き込みに失敗する:** ファイルが ReadOnly になっていないか、書き込み先のセルがロックされていないかを確認してください。
- **RPA が途中で停止する:** エラーハンドリングを適切に設定し、エラー発生時の処理を定義してください。

#### まとめと次のステップ

Excel ファイルの読み書きは、RPA による Excel 自動化の基礎となります。様々なデータ形式に対応し、ループ処理や条件分岐を組み合わせることで、複雑な業務プロセスも自動化できます。次のステップでは、Excel のマクロ実行と VBA 連携について学び、さらに高度な自動化に挑戦しましょう。

### 7.2 マクロの実行と VBA 連携

#### 概要と重要性

Excel マクロは、VBA（Visual Basic for Applications）で記述されたプログラムであり、Excel の機能を拡張し、複雑な処理を自動化するために使用されます。RPA から Excel マクロを実行したり、VBA と連携したりすることで、RPA 単体では実現できない高度な自動化が可能になります。特に、既存のマクロを RPA に組み込むことで、既存の資産を有効活用しながら、自動化を推進できます。

#### 特徴と利点

- **高度な自動化:** VBA の豊富な機能を活用することで、複雑な処理を自動化できます。
- **既存資産の活用:** 既存のマクロを RPA に組み込むことで、開発コストを削減できます。
- **柔軟性:** RPA と VBA を組み合わせることで、より柔軟な自動化を実現できます。

#### 事前準備と前提条件

- Excel のマクロに関する基本的な知識。
- 対象となる Excel ファイルにマクロが含まれていること。
- RPA ツールから Excel マクロを実行するための設定。

#### 基本的な使い方

多くの RPA ツールは、Excel マクロを実行するための専用のアクションやコマンドを提供しています。ここでは、Automation Anywhere を例に、基本的な操作を説明します。

**Excel マクロの実行**

1.  Automation Anywhere のワークスペースで、新しい Bot を作成します。
2.  「アクション」パネルから「Excel」を検索し、「Excel を開く」アクションをドラッグ＆ドロップします。
3.  開く Excel ファイルのパスを指定します。（マクロを含むファイル）
4.  「マクロを実行」アクションを追加し、実行するマクロの名前を指定します。
5.  必要に応じて、マクロに引数を渡すことができます。
6.  「Excel を保存」アクションで変更を保存します。（必要な場合）
7.  「Excel を閉じる」アクションで Excel ファイルを閉じます。

**VBA 連携の例：Automation Anywhere から VBA コードを実行**

```
# Automation Anywhereコード例

# Excelファイルを開く
Excel:Open File path:"C:\MyExcelFile.xlsx" session:"Default"

# VBAスクリプトを実行
Excel:Run script script:'Sub MyMacro()\n  MsgBox "Hello from VBA!"\nEnd Sub' session:"Default"

# Excelファイルを閉じる
Excel:Close File session:"Default"
```

#### 実践的なテクニック

- **マクロの引数:** RPA からマクロに引数を渡すことで、処理内容を動的に変更できます。例えば、日付を引数として渡し、特定期間のデータを抽出するマクロを実行する、といった処理を自動化できます。
- **マクロの戻り値:** マクロの実行結果を RPA で取得することで、処理結果に基づいて後続の処理を分岐させることができます。例えば、データの抽出結果をマクロでチェックし、エラーが発生した場合に、アラートメールを送信する、といった処理を自動化できます。
- **エラーハンドリング:** マクロの実行中にエラーが発生した場合、RPA でエラーを検知し、適切な処理を行うように設定することで、RPA の安定性を高めることができます。

#### 応用例とユースケース

**財務レポート作成マクロの実行**

月次の財務レポートを作成するマクロを RPA から実行し、レポート作成作業を自動化します。

```
# Automation Anywhereコード例

# Excelファイルを開く
Excel:Open File path:"C:\FinancialReport.xlsm" session:"Default"

# マクロを実行
Excel:Run macro name:"CreateMonthlyReport" session:"Default" parameters:"{{Year}},{{Month}}"

# PDF形式で保存
Excel:Save as PDF file path:"C:\MonthlyReport_{Year}_{Month}.pdf" session:"Default"

# Excelファイルを閉じる
Excel:Close File session:"Default"
```

**Excel データの検証マクロの実行**

Excel シート内のデータに対して、複雑な検証を行うマクロを RPA から実行し、データの品質を保証します。

#### トラブルシューティング

- **マクロが実行されない:** マクロのセキュリティ設定が適切か、マクロが無効になっていないかを確認してください。
- **マクロの引数が正しく渡されない:** RPA から渡される引数の型と、マクロで期待される引数の型が一致しているかを確認してください。
- **VBA コードの実行エラー:** VBA コード自体にエラーがないかデバッグしてください。エラーメッセージを参考に、原因を特定し修正してください。

#### まとめと次のステップ

Excel マクロの実行と VBA 連携は、RPA による Excel 自動化の可能性を大きく広げます。既存のマクロを有効活用し、RPA と VBA を組み合わせることで、より高度な自動化を実現できます。次のステップでは、Excel データの可視化について学び、レポート作成を自動化する方法を習得しましょう。

### 7.3 Excel データの可視化

#### 概要と重要性

Excel データの可視化は、データを理解しやすくするための重要な手段です。グラフやダッシュボードを作成することで、データの傾向やパターンを視覚的に把握し、意思決定を支援することができます。RPA を活用することで、これらの可視化プロセスを自動化し、定期的なレポート作成作業を効率化できます。

#### 特徴と利点

- **視覚的な理解:** グラフやダッシュボードにより、データの傾向やパターンを容易に把握できます。
- **迅速な意思決定:** 可視化されたデータに基づいて、迅速かつ的確な意思決定を行うことができます。
- **効率的なレポート作成:** 定期的なレポート作成作業を自動化し、人的リソースを有効活用できます。

#### 事前準備と前提条件

- Excel のグラフ作成に関する基本的な知識。
- 対象となる Excel データ。
- RPA ツールから Excel のグラフ作成機能を操作するための設定。

#### 基本的な使い方

RPA ツールは、Excel のグラフ作成機能を制御するためのアクションを提供しています。ここでは、Automation Anywhere を例に、基本的な操作を説明します。

**Excel グラフの作成**

1.  Automation Anywhere のワークスペースで、新しい Bot を作成します。
2.  「アクション」パネルから「Excel」を検索し、「Excel を開く」アクションをドラッグ＆ドロップします。
3.  開く Excel ファイルのパスを指定します。
4.  「ワークシートを開く」アクションを追加し、グラフを作成する対象のワークシートを選択します。
5.  「グラフを作成」アクション（または、類似のアクション）を追加し、グラフの種類（棒グラフ、円グラフなど）、データの範囲、グラフのタイトルなどを指定します。　　　　※Automation Anywhere には標準でグラフを作成するアクションはないため、VBA 連携などで実現する必要がある
6.  「Excel を保存」アクションで変更を保存します。
7.  「Excel を閉じる」アクションで Excel ファイルを閉じます。

**VBA を使ったグラフ作成例**

```vba
Sub CreateChart()

    Dim cht As Chart
    Dim rng As Range

    ' データ範囲を設定
    Set rng = Range("A1:B10")  ' 例：A1からB10までの範囲をデータ範囲とする

    ' グラフを作成
    Set cht = Charts.Add

    With cht
        .ChartType = xlColumnClustered ' 棒グラフの種類を指定
        .SetSourceData Source:=rng ' データ範囲を設定
        .HasLegend = False ' 凡例を非表示
        .ChartTitle.Text = "Sample Chart" ' グラフタイトルを設定
        .Location Where:=xlLocationAsObject, Name:="Sheet1" 'グラフの配置場所をシート1に指定
    End With

End Sub
```

上記の VBA コードを RPA から実行することで、グラフを自動的に作成できます。

**ダッシュボードの作成**

ダッシュボードは、複数のグラフや表を組み合わせて、データの全体像を把握できるようにしたものです。RPA を使って、複数のグラフを自動的に作成し、それらをダッシュボードとして配置することができます。

#### 実践的なテクニック

- **グラフの種類の選択:** データの種類や目的に応じて、適切なグラフの種類を選択することが重要です。
  - **棒グラフ:** 複数の項目の値を比較する場合に適しています。
  - **円グラフ:** 全体に対する各項目の割合を示す場合に適しています。
  - **折れ線グラフ:** 時系列データの推移を示す場合に適しています。
- **グラフのカスタマイズ:** グラフのタイトル、軸ラベル、凡例などを適切に設定することで、グラフの見やすさを向上させることができます。
- **条件付き書式:** データの値に応じてセルの色やフォントを変更することで、特定の傾向を強調することができます。

#### 応用例とユースケース

**月次売上レポートの自動生成**

月次の売上データを集計し、グラフを作成して、レポートを自動的に生成する業務を自動化します。

```

# Excelファイルを開く
Excel:Open File path:"C:\SalesData\MonthlySales.xlsx" session:"Default"

# ワークシートを開く
Excel:Activate sheet name:"Data" session:"Default"

# VBAマクロを実行してグラフ作成
Excel:Run macro name:"CreateSalesReportChart" session:"Default"

# PDF形式で保存
Excel:Save as PDF file path:"C:\SalesReport_{Year}_{Month}.pdf" session:"Default"

# Excelファイルを閉じる
Excel:Close File session:"Default"
```

**在庫管理ダッシュボードの自動更新**

#### トラブルシューティング

- **グラフが正しく作成されない:** データの範囲が正しいか、グラフの種類が適切かを確認してください。
- **ダッシュボードの表示が崩れる:** グラフの配置やサイズが適切かを確認してください。
- **VBA エラーが発生する:** VBA コードの構文エラーや実行時エラーがないか確認してください。

#### まとめと次のステップ

Excel データの可視化は、データを理解し、意思決定を支援するための強力なツールです。RPA を活用することで、グラフ作成やダッシュボードの作成を自動化し、レポート作成作業を効率化できます。次のステップでは、RPA による Excel 自動化の応用的な活用方法について学び、さらに高度な業務プロセスを自動化する方法を習得しましょう。例えば、メール送信や他のシステムとの連携などを検討することで、自動化の範囲を広げることができます。
