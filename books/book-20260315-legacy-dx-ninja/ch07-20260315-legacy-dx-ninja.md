## 第7章：競技の中の記憶 ── チェス・スポーツ選手の知覚と記憶

### 7.1 チャンキング：専門家の記憶戦略

チェスの名人が初心者と根本的に異なるのは、「駒の配置を個別に覚える」のではなく、「意味のある塊（チャンク）として認識する」点だ。

心理学者デ・グルートの研究（1946年）は、チェスの名人が一瞬見ただけで盤面を完全に再現できることを示した。ただしそれは「意味のある対局中の配置」に限られ、ランダムに配置した駒では初心者と大差がなかった。

### 7.2 パターン認識としての記憶

スポーツ選手の「状況判断の速さ」も同じ原理で説明できる。サッカーの優れた選手は、フィールド全体を「パターン」として認識し、次の展開を予測する。個々の選手の位置を逐一記憶するのではなく、「3-4-3の崩れた配置」といった高次の概念で処理する。

忍者の場合も同様だ。敵陣の警備配置を「12人が東西南北に3人ずつ」と記憶するのではなく、「菱形配置の変則型」というパターンとして記憶する可能性がある。

### 7.3 競技記憶と生存記憶の違い

競技における記憶と生存における記憶の最大の違いは「失敗のコスト」だ。

チェスで一手を間違えれば負けるが、命は失わない。だから訓練を繰り返して「負けながら学ぶ」ことができる。忍者の訓練では、実際の任務でのミスは死を意味する。だから訓練環境でいかに本番に近い緊張感を作るかが重要だった。

```python
# 失敗コストの設計
class MemoryGame:
    def __init__(self, mode: str = 'competitive'):
        self.mode = mode
        self.lives = {
            'survival': 1,      # 忍者モード：一発アウト
            'competitive': 3,   # 競技モード：3ライフ
            'daily': float('inf')  # 日常モード：制限なし
        }[mode]
```

### 7.4 フロー状態と記憶の最適化

チクセントミハイのフロー理論によれば、能力と挑戦のバランスが取れたとき、人は「フロー状態」に入り、パフォーマンスが最大化される。

記憶トレーニングにおいても同じことが言える。難しすぎると不安になり、簡単すぎると退屈になる。この最適点を自動的に維持する難易度調整が、AIトレーナーの核心機能となる。
