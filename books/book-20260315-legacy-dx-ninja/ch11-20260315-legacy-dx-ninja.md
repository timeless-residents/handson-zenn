## 第11章：鮮明に残り、完全に復元される ── 忍者が目指した記憶の質

### 11.1 記憶の二つの次元：鮮明さと完全性

忍者の記憶術が目指したのは、二つの次元での最高品質だった。

**鮮明さ（Vividness）**：記憶の解像度。細部まで明確に見えるか。
**完全性（Completeness）**：記憶の網羅性。見たものをもれなく記憶しているか。

この二つはトレードオフの関係にあることが多い。完全に覚えようとすると一つ一つの解像度が下がり、鮮明に覚えようとすると覚えられる量が減る。忍者の訓練は、このバランスを状況に応じて使い分ける能力を磨いた。

### 11.2 想起可能性：覚えることより思い出すこと

記憶において、実は「覚えること」より「想起すること」の方が難しい。

「知っているのに思い出せない」状態（TOT: Tip of the Tongue現象）は、記憶の符号化には成功しているが、検索（Retrieval）に失敗している状態だ。

忍者の訓練では、「覚えたことを確実に報告できる」ことが求められた。想起の失敗は許されない。だから記憶の訓練と同時に、想起の訓練も行われた。

```python
# 想起品質の評価モデル
def evaluate_recall(
    original: dict,
    recalled: dict,
    time_elapsed: float  # 想起までの時間（秒）
) -> dict:
    """
    original: 元の視覚情報
    recalled: 想起した情報
    time_elapsed: 観察から想起までの時間
    """
    # 内容の正確性
    accuracy = calculate_overlap(original, recalled)
    
    # 時間減衰（忘却曲線）
    retention = math.exp(-time_elapsed / 3600)  # エビングハウス忘却曲線
    
    # 総合スコア
    score = accuracy * retention
    
    return {
        'accuracy': accuracy,
        'retention': retention,
        'final_score': score,
        'grade': 'A' if score > 0.9 else 'B' if score > 0.7 else 'C'
    }
```

### 11.3 感情的文脈の付加

店主が強調したのは「感情なしに記憶しない」という原則だ。

見た場面に、意識的に感情的な意味を付与する。「あの角に潜んでいた警備は怖かった」「あの部屋には財宝があって驚いた」——感情的文脈は記憶の固定化を強化する。

これは前章で説明した扁桃体と海馬の連携を意図的に利用する技術だ。

### 11.4 記憶の劣化と復元

記憶は固定された後も変化する。エビングハウスの忘却曲線が示すように、時間とともに劣化する。しかし適切なタイミングで「想起練習（Retrieval Practice）」を行うことで、記憶は強化される。

間隔反復（Spaced Repetition）と呼ばれるこの手法は、現代の学習ツール（Anki等）でも使われている。忍者の「定期的な復唱訓練」は、経験的にこの原理を発見していたと考えられる。

AIトレーナーの設計でも、間隔反復のアルゴリズムを組み込む。
