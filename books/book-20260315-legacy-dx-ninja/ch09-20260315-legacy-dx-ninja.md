## 第9章：網膜瞬間記憶とは何か ── 技法の解剖

### 9.1 アイコニックメモリの構造

視覚情報の処理は、脳の中で段階的に行われる。

```
光 → 網膜 → 視神経 → 一次視覚野(V1) → 
高次視覚野(V4/IT) → 海馬（記憶化）
```

アイコニックメモリは、この処理の最初の段階——網膜から一次視覚野への入力直後——に存在する、容量が大きく持続時間が極めて短い（0.25〜0.5秒）記憶バッファだ。

通常、このバッファの内容は処理される前に上書きされる。網膜瞬間記憶術は、このバッファの内容を意識的に「キャプチャ」して長期記憶に転送する技術と考えられる。

### 9.2 店主から学んだ五段階のプロセス

店主が教えてくれた具体的なプロセスを、現代の認知科学的フレームで整理すると以下のようになる。

**ステップ1：準備（Priming）**
見る前に「空の器」を作る。余計な思考を止め、視覚処理に意識を集中させる。瞑想の要素がある。

**ステップ2：全体受容（Global Reception）**
対象を一点に注目せず、視野全体を均等に「受け取る」。中心視ではなく周辺視を意識的に活用する。

**ステップ3：凍結（Freezing）**
見た瞬間にまぶたを閉じ（または視線を外し）、残像を意識的に「止める」。これが最も難しく、訓練を要するステップだ。

**ステップ4：走査（Scanning）**
凍結した残像を意識の中で「読む」。上から下、左から右へと系統的に走査する。

**ステップ5：符号化（Encoding）**
走査した内容に言語的・感情的ラベルを付けて長期記憶に転送する。

### 9.3 露出時間と記憶品質のトレードオフ

```python
import numpy as np

def memory_quality_model(exposure_ms: float, training_level: int) -> float:
    """
    exposure_ms: 露出時間（ミリ秒）
    training_level: 訓練レベル 0=初心者, 10=達人
    returns: 記憶品質 0.0〜1.0
    """
    # 初心者は2000ms必要、達人は200msで同品質
    base_threshold = 2000 - (training_level * 180)
    
    if exposure_ms >= base_threshold:
        return 1.0
    else:
        # 対数カーブで品質低下
        return np.log(exposure_ms / base_threshold * (np.e - 1) + 1)

# 訓練レベル別の必要露出時間
for level in [0, 3, 5, 8, 10]:
    threshold = 2000 - (level * 180)
    print(f"レベル{level}: 高品質記憶に必要な露出時間 {threshold}ms")
```


### 9.4 何を記憶するかの優先順位

無限に記憶できるわけではない。忍者は見た場面から「何が重要か」を瞬時に判断して優先的に記憶する訓練もしていた。

その優先順位は：
1. **動的な情報**（変化するもの：人の動き、警備の交代）
2. **数量情報**（何人、何本、何箱）
3. **位置関係**（どこに何がある）
4. **静的な構造**（建物の形、通路の配置）

現代のAIトレーナーでは、この優先順位の概念を採点ロジックに組み込む。
