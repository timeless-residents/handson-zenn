## 第12章：伊賀に伝わる具体的なトレーニング法

### 12.1 基礎訓練：蝋燭の炎を見る

店主が最初に教えてくれたのは、蝋燭の炎を使った基礎訓練だった。

暗い部屋で蝋燭を灯し、1分間凝視する。その後目を閉じて、残像をできる限り長く「保持」する。最初は数秒で消えるが、毎日繰り返すことで、数十秒〜数分保持できるようになるという。

これはアイコニックメモリの意図的な延長訓練だ。残像を保持する力を鍛えることで、より複雑な視覚情報の「凍結」が可能になる。

```python
# 基礎訓練のシミュレーション
class CandleTraining:
    def __init__(self):
        self.afterimage_duration = 3.0  # 初期値（秒）
    
    def daily_session(self, focus_seconds: int = 60) -> float:
        """
        毎日のセッション。訓練を続けるほど残像保持時間が延びる。
        returns: 今日の残像保持時間（秒）
        """
        # 上限は120秒、対数的に成長
        max_duration = 120.0
        growth_rate = 0.05
        
        self.afterimage_duration = min(
            max_duration,
            self.afterimage_duration * (1 + growth_rate)
        )
        return self.afterimage_duration
```

### 12.2 中級訓練：散らかった部屋の記憶

次の段階は、物が多く置かれた部屋を数秒間見て、すべてのオブジェクトを列挙する訓練だ。

ポイントは「見る前に準備する」こと。深呼吸をして意識を集中させ、「空の器」状態を作ってから見る。

最初は10個のオブジェクトを3秒で試みる。できたら15個、20個と増やし、同時に露出時間を2秒、1秒と短縮していく。

### 12.3 上級訓練：人物の記憶

物の記憶より人物の記憶の方が難しい。表情、服装、体格、特徴的な仕草——動的な情報が多く、固定した物と異なる。

忍者の人物記憶訓練では「特徴の3点記録」というアプローチを取る。どんな人物でも、最も目立つ3つの特徴を即座に抽出して記憶する。

1. 最も目立つ外見的特徴（傷、髪型、目の色など）
2. 体格・姿勢（身長、体型、歩き方）
3. 携帯品・服装の特徴

### 12.4 実戦訓練：街歩き記憶

最終段階は「街を歩きながら記憶する」実戦訓練だ。

商店街を歩き、後でどの店が何軒あったか、それぞれの店の前に何が置いてあったかを報告する。現代のバリエーションとして、店主は「電車に乗った時に同じ車両の乗客を覚える練習をしなさい」と言った。

このリアルワールドでの訓練を、AIトレーナーはどこまで補完できるか。次章からはシステム設計の議論に入る。

### 12.5 現代人への適用可能性

これらの訓練は、特別な才能がなくても成果が出るとされている。

店主の言葉が印象的だった。「才能の問題じゃない。訓練の問題。忍者になる人間は、子どもの頃から当たり前のようにこれをやっていた。当たり前になれば、できるようになる。」

この「当たり前にする」という訓練哲学は、AIを使った継続的トレーニングシステムの設計理念にそのまま活かせる。
