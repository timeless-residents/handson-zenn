## 第6章：生存のための記憶 ── アドレナリンと記憶定着の神経科学

### 6.1 三種類の記憶の動機

人間が何かを記憶する動機は大きく三種類に分けられる。生存のための記憶、競技・達成のための記憶、そして日常生活のための記憶だ。この三つは、神経科学的に全く異なるメカニズムで動いている。

### 6.2 扁桃体と海馬の連携

生存の脅威を感知した扁桃体は、海馬に「これは重要な記憶だ」というシグナルを送る。ノルエピネフリンの放出がこの連絡を媒介し、記憶の「書き込み強度」を高める。

これが「命がかかった記憶は忘れない」という現象の正体だ。戦場の兵士が何十年後も戦闘の細部を鮮明に覚えているのはPTSDの側面もあるが、アドレナリン増強記憶（EAM: Emotionally Aroused Memory）の典型例でもある。

### 6.3 コルチゾールの両面性

ストレスホルモンのコルチゾールは、短期的には記憶を強化するが、慢性化すると逆に海馬を萎縮させる。

忍者の訓練が短期的・集中的な緊張を繰り返す形をとっていたのは、この神経科学的なバランスを経験的に知っていたからかもしれない。

```python
# コルチゾールレベルと記憶効率の関係モデル
def memory_efficiency(cortisol_level: float) -> float:
    """
    cortisol_level: 0.0（無ストレス）〜 1.0（極限ストレス）
    returns: 記憶効率係数
    """
    # 逆U字型の関係（Yerkes-Dodson法則）
    optimal = 0.4
    if cortisol_level <= optimal:
        return cortisol_level / optimal
    else:
        return 1.0 - ((cortisol_level - optimal) / (1.0 - optimal)) * 0.8
```

### 6.4 トレーニングへの応用

この神経科学的知見から、最適なトレーニング環境の設計指針が得られる。

- **適度なプレッシャー**：完全に安全な環境では記憶効率が上がらない
- **短期集中**：長時間の慢性ストレスは避ける
- **成功体験の挿入**：達成感はドーパミンを放出し、記憶を強化する
- **即時フィードバック**：記憶の確認を遅らせるほど定着が弱まる

これらが後の実装章における難易度設計の根拠となる。
