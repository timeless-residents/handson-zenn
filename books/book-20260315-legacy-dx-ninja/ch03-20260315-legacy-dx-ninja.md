## 第3章：メモが死を招く時代 ── 文字を残さない技術

### 3.1 忘れることの危険、覚えることの必然

忍者の訓練において、「記憶する」ことは生存スキルの中核だった。しかしそれは単に「物事を記憶する」ということではない。「文字に頼らずに記憶する」という制約の中で、記憶の技術を極限まで高めるということだ。

現代人は記憶の補助ツールに囲まれている。スマートフォン、メモアプリ、カレンダー、クラウドストレージ。何かを覚えたければ、写真を撮ればいい。地図はGPSが教えてくれる。

忍者にはその選択肢がなかった。だから記憶する技術そのものを鍛えるしかなかった。

### 3.2 七方出：身体そのものが記録媒体

文字を持てないならば、情報を「身体に刻む」という発想が生まれる。

忍者の変装術「七方出」は、7つの身分（虚無僧、出家、山伏、商人、放下師、猿楽師、常の者）に完全になりきる技術だ。これは単なる衣装の着替えではない。その職業の人間の動作、話し方、知識、身体の癖まで含めて「身体で覚える」ことが求められた。

つまり、変装が必要な場所の情報（その土地の方言、地理、慣習）を、事前に完全に記憶しておく必要がある。

```
変装成功の条件:
  知識の記憶 × 身体動作の記憶 × 感情制御
     ↓
  完全なロールプレイング
     ↓
  発覚すれば即死
```

失敗が許されない一発本番の実装だ。

### 3.3 写し見の技術

店主が教えてくれた具体的な技法の一つが「写し見（うつしみ）」だ。

対象を見る際に、「写真を撮る」ように目を使う。焦点を一点に定めず、視野全体を均等に受け取る。まぶたを軽く閉じ、その残像を「保持」する。

「普通の人は見た後に解釈しようとする。でも写し見は解釈しない。ただ映像として保存する。意味を理解するのは後でいい。」

これは現代の認知科学における「ボトムアップ処理」と「トップダウン処理」の分離に近い。通常、人間の知覚は即座に意味付けを行う（トップダウン）。写し見は、その意味付けを意図的に遅らせ、生の視覚情報を先に固定する（ボトムアップ優先）。

### 3.4 記憶の圧縮技術：印（いん）

大量の情報を記憶するために忍者が使ったもう一つの技術が「印」を使った記憶の索引化だ。

特定の手の形（印を結ぶ）と記憶内容を関連付けることで、後から「印を結ぶ→記憶を想起する」というトリガーを作る。現代の記憶術で言えば「アンカリング」に近い。

```python
# 概念的なコード表現
class NinjaMemory:
    def __init__(self):
        self.anchors = {}  # 印 → 記憶のマッピング
    
    def encode(self, mudra: str, visual_data: bytes) -> None:
        """印と映像記憶を関連付けて保存"""
        self.anchors[mudra] = {
            'visual': visual_data,
            'timestamp': time.time(),
            'context': self._current_context()
        }
    
    def recall(self, mudra: str) -> bytes:
        """印を手がかりに記憶を想起"""
        return self.anchors.get(mudra, {}).get('visual')
```

### 3.5 忘れることを禁じた訓練

伊賀の訓練では、「忘れた」という言葉を使うことが許されなかったという。

「忘れた」は言い訳だ。忘れたから正確な情報を伝えられなかった、では済まされない。だから訓練の中でも、「記憶できなかった」という失敗をきちんと失敗として扱い、再度やり直す。

この「失敗を正面から受け入れる設計」が、次章のAIトレーニング設計にも反映される。ゲームのライフ制のように、「間違えたらやり直し」という緊張感が、記憶の定着を促進する。
