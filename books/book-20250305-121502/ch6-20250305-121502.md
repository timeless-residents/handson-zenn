# 6. ヘルスケア連携：Scriptableで健康データを可視化し、健康管理をサポート

近年、iOSのショートカットアプリを用いてヘルスケアデータ（歩数、睡眠時間、心拍数など）を取得し、Scriptableでウィジェットとして可視化する手法が注目されています。この章では、ショートカットとScriptableを組み合わせた健康管理アプリケーションの作成方法を解説します。以下の各セクションでは、実際にScriptableウィジェットでデータを表示する例や、DrawContextを使ったグラフ作成、他アプリとの連携方法など、実践的な知識とテクニックを紹介します。

---

## 6.1. ショートカットとScriptableによるヘルスケアデータの取得

**概要と重要性**

iOSのショートカットでは、ヘルスケアデータ（例：今日の歩数、睡眠時間など）をHealthアプリから取得することが可能です。これらのデータをショートカット内で処理し、Scriptableに引き渡すことで、ウィジェット上で最新の健康情報を表示できます。

**利用方法**

1. **ショートカットの作成:**  
   - 「健康」アクションを用いて、必要なデータ（歩数、睡眠時間など）を取得します。  
   - 取得したデータをJSON形式などにまとめ、Scriptableスクリプトの引数として渡します。

2. **Scriptableの受け取り:**  
   - Scriptableスクリプト内では、`args.queryParameters`（もしくは`args.plainTexts`）を用いて、ショートカットから渡されたデータを受け取ります。

**例（ショートカットからの引数例）**

> ショートカット側でJSONを作成し、Scriptableのスクリプトに渡すとします。  
> 例：`{"steps": 8532, "goal": 10000, "sleepHours": 7.5}`

---

## 6.2. Scriptableウィジェット：歩数計ウィジェットの作成

**概要と利点**

Scriptableでは、簡単なJavaScriptコードでウィジェットを作成可能です。歩数や目標達成率を表示するウィジェットは、ユーザーが日々の活動量をひと目で確認でき、モチベーション向上に役立ちます。

**コード例**

以下は、ショートカットから渡された歩数データを使い、今日の歩数と目標達成率を表示するウィジェットの例です。

```javascript
// Scriptableスクリプト例：StepCounterWidget.js

// ショートカットからのデータを受け取る（例：JSON形式）
let fm = FileManager.local();
let argsData = args.queryParameters; // URLクエリとして渡す場合
// または、ショートカットから直接テキスト引数を受け取る場合は: args.plainTexts[0]

// シンプルなJSONパース（エラーチェックは適宜追加）
let healthData = argsData ? JSON.parse(decodeURIComponent(argsData.data)) : { steps: 0, goal: 10000 };

let steps = healthData.steps || 0;
let goal = healthData.goal || 10000;
let percentage = Math.min((steps / goal) * 100, 100);

// ウィジェットの作成
let widget = new ListWidget();
widget.backgroundColor = new Color("#ffffff");

// タイトル
let title = widget.addText("今日の歩数");
title.font = Font.boldSystemFont(16);
title.centerAlignText();

// 歩数の表示
let stepText = widget.addText(`${steps} 歩`);
stepText.font = Font.systemFont(28);
stepText.centerAlignText();

// 目標達成率の表示
let percentText = widget.addText(`達成率: ${percentage.toFixed(1)}%`);
percentText.font = Font.systemFont(14);
percentText.centerAlignText();

if (!config.runsInWidget) {
  widget.presentMedium();
}
Script.setWidget(widget);
Script.complete();
```

**ポイント**

- ショートカットで取得した健康データをJSONにまとめ、URLエンコードしてScriptableへ渡します。  
- ウィジェットのレイアウトは`ListWidget`を用いてシンプルに作成しています。

## 6.3. Scriptableウィジェット：睡眠データウィジェットの作成

**概要と利点**

睡眠時間や睡眠の質を可視化することで、ユーザーは自分の睡眠習慣を客観的に把握できます。ショートカットから取得した睡眠データを用い、Scriptableでシンプルなウィジェットを作成する例を示します。

**コード例**

```javascript
// Scriptableスクリプト例：SleepWidget.js

// ショートカットからの睡眠データ（例：{"sleepHours": 7.5, "sleepQuality": "良好"}）
let argsData = args.queryParameters;
let sleepData = argsData ? JSON.parse(decodeURIComponent(argsData.data)) : { sleepHours: 0, sleepQuality: "未取得" };

let sleepHours = sleepData.sleepHours;
let sleepQuality = sleepData.sleepQuality;

// ウィジェットの作成
let widget = new ListWidget();
widget.backgroundColor = new Color("#f0f0f0");

// タイトル
let title = widget.addText("睡眠データ");
title.font = Font.boldSystemFont(16);
title.centerAlignText();

// 睡眠時間の表示
let sleepText = widget.addText(`睡眠時間: ${sleepHours} 時間`);
sleepText.font = Font.systemFont(20);
sleepText.centerAlignText();

// 睡眠の質の表示
let qualityText = widget.addText(`睡眠の質: ${sleepQuality}`);
qualityText.font = Font.systemFont(14);
qualityText.centerAlignText();

if (!config.runsInWidget) {
  widget.presentSmall();
}
Script.setWidget(widget);
Script.complete();
```

## 6.4. グラフの描画：DrawContextを用いたグラフ生成

**概要と利点**

Scriptableの`DrawContext`を使用すると、キャンバス上にグラフやチャートを描画し、ウィジェットに画像として表示できます。例えば、1週間分の歩数データを折れ線グラフで表示することで、データの傾向がひと目で分かるようになります。

**コード例（簡易折れ線グラフ）**

```javascript
// Scriptableスクリプト例：StepChart.js

// 例として、1週間分の歩数データ（曜日ごと）
let stepData = [
  { day: "月", steps: 8000 },
  { day: "火", steps: 9500 },
  { day: "水", steps: 7000 },
  { day: "木", steps: 11000 },
  { day: "金", steps: 8500 },
  { day: "土", steps: 12000 },
  { day: "日", steps: 9000 }
];

let dc = new DrawContext();
dc.size = new Size(300, 150);
dc.opaque = false;
dc.respectScreenScale = true;

// 背景描画
dc.setFillColor(new Color("#ffffff"));
dc.fillRect(new Rect(0, 0, 300, 150));

// グラフの枠線
dc.setStrokeColor(new Color("#cccccc"));
dc.setLineWidth(1);
dc.strokeRect(new Rect(40, 20, 240, 100));

// 最大値と最小値
let maxSteps = Math.max(...stepData.map(d => d.steps));
let minSteps = Math.min(...stepData.map(d => d.steps));

// グラフ描画
dc.setStrokeColor(new Color("#ff4500"));
dc.setLineWidth(2);

// 描画開始点
let startX = 40;
let endX = 280;
let graphWidth = endX - startX;
let pointGap = graphWidth / (stepData.length - 1);

for (let i = 0; i < stepData.length; i++) {
  let x = startX + (i * pointGap);
  // y座標は逆方向（上が最小）にする
  let y = 120 - ((stepData[i].steps - minSteps) / (maxSteps - minSteps)) * 100;
  if (i === 0) {
    dc.moveTo(new Point(x, y));
  } else {
    dc.addLine(new Point(x, y));
  }
}
dc.strokePath();

// ウィジェットに画像を追加
let widget = new ListWidget();
widget.backgroundColor = new Color("#ffffff");
let img = dc.getImage();
widget.addImage(img);

if (!config.runsInWidget) {
  widget.presentMedium();
}
Script.setWidget(widget);
Script.complete();
```

**ポイント**

- DrawContextを用いてキャンバス上に背景、枠線、データポイントを描画しています。  
- この手法により、より自由度の高いグラフ作成が可能となります。

## 6.5. 健康データの共有と他アプリとの連携

**概要と利点**

取得した健康データは、Scriptableウィジェット上で表示するだけでなく、他のアプリと連携することも可能です。たとえば、URLスキームを利用してメールやメッセージアプリへ送信したり、クリップボードにコピーすることで他のワークフローに組み込むことができます。

**具体例**

- **URLスキームの利用:**  
  Scriptableから特定のURL（例：カスタムプロトコル）を起動し、他のアプリにデータを渡す。

- **クリップボードへのコピー:**  
  `Pasteboard.copy()` を利用して、健康データのレポートをクリップボードに保存し、他アプリで貼り付け可能にする。

```javascript
// 例：健康データのレポートをクリップボードにコピー
let report = `今日の歩数: ${steps} 歩\n目標達成率: ${percentage.toFixed(1)}%`;
Pasteboard.copy(report);
console.log("健康レポートをクリップボードにコピーしました。");
```
