# 7. 株価ウィジェット：Scriptableでリアルタイムな株価情報をチェック

## 7.1. 株価APIの選定と利用：Finnhub APIを例に

**概要と重要性**

リアルタイムに近い株価データを取得するには、信頼性のある株価APIの利用が不可欠です。Scriptableでは、`Request`オブジェクトを利用してHTTPリクエストを行い、JSON形式でデータを取得できます。ここでは、Finnhub APIを例に、Apple（AAPL）の株価データを取得する方法を紹介します。  
※APIキーが必要なため、取得したキーを`YOUR_API_KEY`に設定してください。

```javascript
// Finnhub APIを利用して株価データを取得する例
let symbol = "AAPL";
let apiKey = "YOUR_API_KEY"; // ここに実際のAPIキーを入力
let url = `https://finnhub.io/api/v1/quote?symbol=${symbol}&token=${apiKey}`;

let req = new Request(url);
let stockData = await req.loadJSON();

// Finnhub APIのレスポンス例
// {
//   "c": 150.73,  // 現在値
//   "h": 151.20,  // 当日の最高値
//   "l": 149.50,  // 当日の最安値
//   "o": 150.00,  // 始値
//   "pc": 149.80, // 前日終値
//   "t": 1616605600 // タイムスタンプ
// }

console.log("現在値:", stockData.c);
```

**ポイント**

- Scriptableの`Request`を使うことで、シンプルに株価データを取得可能です。
- APIキーは適切に管理し、セキュリティに留意してください。

## 7.2. 銘柄コードの取得と設定：お気に入りの銘柄を登録

**概要と重要性**

株価ウィジェットで複数の銘柄情報を表示するには、ユーザーがお気に入りの銘柄を登録できる仕組みが必要です。Scriptableでは、`FileManager`を使ってJSON形式の設定ファイルを読み込み、ウィジェット内で利用できます。

**設定ファイルの例（config.json）**

```json
{
  "favorites": [
    {"name": "Apple", "code": "AAPL"},
    {"name": "Microsoft", "code": "MSFT"},
    {"name": "Sony", "code": "6758.T"}
  ]
}
```

**コード例：設定ファイルの読み込み**

```javascript
let fm = FileManager.iCloud();
let configPath = fm.joinPath(fm.documentsDirectory(), "config.json");

if (!fm.fileExists(configPath)) {
  // 設定ファイルが存在しない場合は、デフォルトの銘柄リストを作成
  let defaultConfig = {
    favorites: [
      {name: "Apple", code: "AAPL"},
      {name: "Microsoft", code: "MSFT"}
    ]
  };
  fm.writeString(configPath, JSON.stringify(defaultConfig));
}

let config = JSON.parse(fm.readString(configPath));
let favoriteStocks = config.favorites;
console.log(favoriteStocks);
```

**ポイント**

- ユーザーが編集可能な設定ファイルを用意することで、銘柄リストのカスタマイズが容易になります。
- iCloudを活用すれば、複数のデバイス間で設定の同期も可能です。

## 7.3. 株価データの解析と表示：現在値、前日比、高値、安値

**概要と重要性**

取得した株価データを解析し、ユーザーにとって見やすい形で表示することは、ウィジェットの利便性向上に直結します。ここでは、Finnhub APIから得たデータをもとに、現在値、前日比、高値、安値を計算し、ウィジェットに表示する例を示します。

**コード例：シンプルな株価ウィジェット**

```javascript
// 銘柄コードとAPIキーを設定
let symbol = "AAPL";
let apiKey = "YOUR_API_KEY";
let url = `https://finnhub.io/api/v1/quote?symbol=${symbol}&token=${apiKey}`;

let req = new Request(url);
let stockData = await req.loadJSON();

let currentPrice = stockData.c;
let previousClose = stockData.pc;
let highPrice = stockData.h;
let lowPrice = stockData.l;
let change = currentPrice - previousClose;
let changePercent = (change / previousClose) * 100;

// ウィジェットの作成
let widget = new ListWidget();
widget.backgroundColor = new Color("#ffffff");

// タイトル
let title = widget.addText(`${symbol} 株価`);
title.font = Font.boldSystemFont(16);
title.centerAlignText();

// 現在値の表示
let priceText = widget.addText(`現在値: ${currentPrice.toFixed(2)} USD`);
priceText.font = Font.systemFont(20);
priceText.centerAlignText();

// 前日比の表示（プラスなら緑、マイナスなら赤）
let changeText = widget.addText(`前日比: ${change.toFixed(2)} (${changePercent.toFixed(2)}%)`);
changeText.font = Font.systemFont(14);
changeText.textColor = change >= 0 ? new Color("#008000") : new Color("#FF0000");
changeText.centerAlignText();

// 高値・安値の表示
let rangeText = widget.addText(`高値: ${highPrice.toFixed(2)}  安値: ${lowPrice.toFixed(2)}`);
rangeText.font = Font.systemFont(12);
rangeText.centerAlignText();

if (!config.runsInWidget) {
  widget.presentMedium();
}

Script.setWidget(widget);
Script.complete();
```

**ポイント**

- 株価の変動を視覚的に分かりやすくするため、前日比の数値に応じてテキストの色を変更しています。
- 数値は適切にフォーマットし、読みやすさを向上させます。

## 7.4. 株価チャートの表示：過去の株価推移を視覚的に把握

**概要と重要性**

過去の株価データをグラフで表示することで、長期的なトレンドや変動パターンを直感的に理解できます。Scriptableの`DrawContext`を利用することで、ウィジェット上にシンプルな折れ線グラフを描画することが可能です。

**コード例：簡易折れ線グラフ**

```javascript
// 過去1週間の株価データの例（実際はAPIで取得したデータを利用）
let historicalData = [
  { day: "月", price: 148 },
  { day: "火", price: 150 },
  { day: "水", price: 149 },
  { day: "木", price: 151 },
  { day: "金", price: 150 },
  { day: "土", price: 152 },
  { day: "日", price: 151 }
];

let dc = new DrawContext();
dc.size = new Size(300, 150);
dc.opaque = false;
dc.respectScreenScale = true;

// 背景
dc.setFillColor(new Color("#ffffff"));
dc.fillRect(new Rect(0, 0, 300, 150));

// グラフ枠
dc.setStrokeColor(new Color("#cccccc"));
dc.setLineWidth(1);
dc.strokeRect(new Rect(40, 20, 240, 100));

// 最大値と最小値の算出
let prices = historicalData.map(d => d.price);
let maxPrice = Math.max(...prices);
let minPrice = Math.min(...prices);

// グラフ描画
dc.setStrokeColor(new Color("#1E90FF"));
dc.setLineWidth(2);

let startX = 40;
let endX = 280;
let graphWidth = endX - startX;
let pointGap = graphWidth / (historicalData.length - 1);

for (let i = 0; i < historicalData.length; i++) {
  let x = startX + (i * pointGap);
  let y = 120 - ((historicalData[i].price - minPrice) / (maxPrice - minPrice)) * 100;
  if (i === 0) {
    dc.moveTo(new Point(x, y));
  } else {
    dc.addLine(new Point(x, y));
  }
}
dc.strokePath();

// ウィジェット作成
let widgetChart = new ListWidget();
widgetChart.backgroundColor = new Color("#ffffff");
let chartImg = dc.getImage();
widgetChart.addImage(chartImg);

if (!config.runsInWidget) {
  widgetChart.presentMedium();
}
Script.setWidget(widgetChart);
Script.complete();
```

**ポイント**

- DrawContextを利用して、背景・枠線・データポイントを自由に描画できます。
- 実際のデータを利用する場合は、株価APIから取得した過去データを同様の形式に整形してください。

## 7.5. アラート機能：株価が指定した価格に達したら通知

**概要と重要性**

株価ウィジェットにアラート機能を実装することで、ユーザーは目標価格に達したときに自動的に通知を受け取ることができます。Scriptableでは、`Notification`クラスを利用してローカル通知を実現できます。

**コード例：株価アラート**

```javascript
// Finnhub APIを利用して株価をチェックし、目標価格に達したら通知する例
let symbolAlert = "AAPL";
let targetPrice = 170.0;
let apiKeyAlert = "YOUR_API_KEY";
let urlAlert = `https://finnhub.io/api/v1/quote?symbol=${symbolAlert}&token=${apiKeyAlert}`;

let reqAlert = new Request(urlAlert);
let dataAlert = await reqAlert.loadJSON();
let currentPriceAlert = dataAlert.c;

if (currentPriceAlert >= targetPrice) {
  let n = new Notification();
  n.title = `${symbolAlert}の株価アラート`;
  n.body = `現在値: ${currentPriceAlert.toFixed(2)} USD が目標価格 ${targetPrice.toFixed(2)} USD を達成しました！`;
  n.sound = "default";
  await n.schedule();
  console.log("アラート通知を送信しました。");
} else {
  console.log("目標価格に達していません。");
}
```

**ポイント**

- Notificationクラスでローカル通知を設定し、条件に応じたアラートを実現します。
- 複数のアラート条件や履歴管理など、さらなる拡張も可能です。
