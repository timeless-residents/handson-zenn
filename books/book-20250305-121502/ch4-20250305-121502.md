## 4. カレンダー連携：予定をスマートに管理・表示

この章では、Scriptableを使ってiOSカレンダーと連携し、予定を効率的に管理・表示する方法を解説します。会議、イベント、リマインダーなど、日々のスケジュールをScriptableのウィジェットに統合することで、情報へのアクセスを大幅に改善し、見逃しを防ぐことができます。初心者の方でも理解しやすいように、基本的な使い方から応用的なテクニックまで、段階的に説明していきます。

### 4.1. カレンダーAPIの利用：iOSカレンダーへのアクセスと操作

#### 概要と重要性

iOSのカレンダーAPIを利用することで、Scriptableからカレンダーイベントの読み込み、作成、更新、削除といった操作が可能になります。これにより、Scriptableウィジェットを単なる表示ツールから、インタラクティブなスケジュール管理ツールへと進化させることができます。

#### 特徴と利点

*   **柔軟なデータアクセス:** カレンダー内のイベント、リマインダー、アラームにアクセスできます。
*   **カスタマイズされた表示:** 取得したデータを加工し、自分にとって最も見やすい形でウィジェットに表示できます。
*   **イベント操作:** Scriptableから直接イベントの追加や編集が可能になります。
*   **自動化:** 定期的なイベントの自動登録や、特定の条件に基づいた通知など、様々な自動化処理を実現できます。

#### 事前準備と前提条件

*   **Scriptableアプリのインストール:** App StoreからScriptableアプリをダウンロードし、インストールしてください。
*   **カレンダーへのアクセス許可:** Scriptableにカレンダーへのアクセスを許可する必要があります。Scriptableアプリの設定画面から、カレンダーへのアクセスを許可してください。
*   **JavaScriptの基礎知識:** JavaScriptの基本的な構文や変数、関数などの知識があると、Scriptableのスクリプトを理解しやすくなります。

#### 基本的な使い方

Scriptableでカレンダーにアクセスするには、`Calendar`オブジェクトを使用します。

```javascript
// カレンダーオブジェクトを取得
let calendar = await Calendar.getDefault();

// 今日の日付のDateオブジェクトを作成
let today = new Date();

// 今日のイベントを取得
let events = await calendar.events(today, today);

// イベントの情報をログに出力
for (let event of events) {
  console.log(event.title);
  console.log(event.startDate);
  console.log(event.endDate);
}
```

このスクリプトは、デフォルトカレンダーから今日のイベントを取得し、イベントのタイトル、開始日時、終了日時をログに出力します。`Calendar.getDefault()`でデフォルトカレンダーを取得し、`calendar.events(startDate, endDate)`で指定された期間内のイベントを取得します。

#### 実践的なテクニック

**特定期間のイベントを取得する:**

```javascript
let startDate = new Date(); // 今日
let endDate = new Date();
endDate.setDate(startDate.getDate() + 7); // 7日後

let events = await calendar.events(startDate, endDate);

for (let event of events) {
  console.log(event.title);
}
```

この例では、今日から7日後までのイベントを取得しています。`endDate.setDate()`を使って終了日を計算しています。

**リマインダーを取得する:**

```javascript
let reminders = await Reminder.allDueToday();

for (let reminder of reminders) {
  console.log(reminder.title);
}
```

`Reminder.allDueToday()`で今日期限のリマインダーを取得できます。

**カレンダーを選択する:**

デフォルト以外のカレンダーを選択するには、`Calendar.forEvents()`または`Calendar.forReminders()`を使用します。

```javascript
let calendars = await Calendar.forEvents();
// または
// let calendars = await Calendar.forReminders();

// カレンダーのリストを表示
for (let calendar of calendars) {
  console.log(calendar.title);
}

// 特定のカレンダーを選択 (例: 最初のカレンダー)
let myCalendar = calendars[0];
let today = new Date();
let events = await myCalendar.events(today, today);
```

`Calendar.forEvents()`と`Calendar.forReminders()`は、それぞれイベントとリマインダーにアクセス可能なカレンダーのリストを返します。  リストから適切なカレンダーを選択し、そのカレンダーオブジェクトを使ってイベントやリマインダーを取得できます。

#### 応用例とユースケース

*   **会議開始前の通知:** 会議開始15分前に通知を表示するウィジェットを作成する。
*   **タスクリストの表示:** 今日締め切りのタスクをリスト表示するウィジェットを作成する。
*   **天気と予定の統合:** 天気予報とともに、その日の予定を表示するウィジェットを作成する。
*   **特定のプロジェクトに関する予定のフィルタリング:** プロジェクト名をキーワードに、関連する予定のみを表示するウィジェットを作成する。

#### トラブルシューティング

*   **カレンダーへのアクセス許可がない:** Scriptableアプリの設定で、カレンダーへのアクセス許可が有効になっていることを確認してください。
*   **イベントが取得できない:** 取得期間が正しく設定されているか確認してください。また、イベントがカレンダーに登録されていることを確認してください。
*   **スクリプトがエラーで停止する:** スクリプトのエラーメッセージを確認し、原因を特定してください。スペルミスや構文エラーなどが原因であることが多いです。`console.log()`を使って変数の値を確認すると、デバッグに役立ちます。

#### まとめと次のステップ

このセクションでは、ScriptableからiOSカレンダーにアクセスし、イベントやリマインダーを取得する方法を学びました。次のセクションでは、これらのデータをウィジェットに表示する方法について解説します。

### 4.2. 今日の予定を表示するウィジェット：会議、イベント、リマインダー…見逃し防止に

#### 概要と重要性

このセクションでは、前セクションで取得したカレンダーデータを基に、今日の予定をウィジェットに表示する方法を解説します。会議、イベント、リマインダーなど、重要な情報を一目で確認できるようにすることで、スケジュール管理を効率化し、見逃しを防ぎます。

#### 特徴と利点

*   **一目でわかる情報:** ウィジェットに予定を表示することで、ロック画面やホーム画面から簡単にスケジュールを確認できます。
*   **カスタマイズ可能な表示:** 予定のタイトル、時間、場所など、必要な情報だけを表示するようにカスタマイズできます。
*   **見逃し防止:** 重要な会議やイベントを忘れるリスクを軽減できます。
*   **タイムリーな情報更新:** 定期的にウィジェットを更新することで、常に最新のスケジュールを表示できます。

#### 事前準備と前提条件

*   **4.1の知識:** 前のセクションで説明したカレンダーAPIの基本的な使い方を理解している必要があります。
*   **ウィジェットの作成:** Scriptableでウィジェットを作成する基本的な手順を理解している必要があります。

#### 基本的な使い方

以下のスクリプトは、今日の予定をウィジェットに表示する基本的な例です。

```javascript
// カレンダーオブジェクトを取得
let calendar = await Calendar.getDefault();

// 今日の日付のDateオブジェクトを作成
let today = new Date();

// 今日のイベントを取得
let events = await calendar.events(today, today);

// ウィジェットを作成
let widget = new ListWidget();

// ヘッダーを追加
let header = widget.addText("今日の予定");
header.font = Font.boldSystemFont(16);

// イベントを表示
if (events.length > 0) {
  for (let event of events) {
    let time = formatDate(event.startDate);
    let title = event.title;
    let line = widget.addText(`${time} ${title}`);
  }
} else {
  widget.addText("予定はありません");
}

// ウィジェットを表示
Script.setWidget(widget);
Script.complete();

// 日付をフォーマットする関数
function formatDate(date) {
  let formatter = new DateFormatter();
  formatter.dateFormat = "HH:mm";
  return formatter.string(date);
}
```

このスクリプトは、今日のイベントを取得し、ウィジェットに「今日の予定」というヘッダーを表示します。イベントがある場合は、イベントの開始時間とタイトルをリスト表示します。イベントがない場合は、「予定はありません」と表示します。`formatDate()`関数は、Dateオブジェクトを`HH:mm`形式の文字列に変換します。

#### 実践的なテクニック

**イベントのソート:** イベントを時間順にソートして表示することで、より見やすくなります。

```javascript
events.sort((a, b) => a.startDate - b.startDate);
```

**色分け:** イベントの種類に応じて色を変えることで、視覚的に区別しやすくなります。

```javascript
let line = widget.addText(`${time} ${title}`);
if (event.title.includes("会議")) {
  line.textColor = Color.red();
}
```

**リマインダーの表示:** イベントだけでなく、リマインダーもウィジェットに表示できます。

```javascript
let reminders = await Reminder.allDueToday();

if (reminders.length > 0) {
  widget.addSpacer();
  widget.addText("リマインダー");
  for (let reminder of reminders) {
    let line = widget.addText(reminder.title);
    line.textColor = Color.blue();
  }
}
```

**アイコンの追加:** SFSymbolを使って、イベントの種類に応じたアイコンを表示できます。

```javascript
let sfSymbol = SFSymbol.named("calendar");
let icon = widget.addImage(sfSymbol.image);
```

#### 応用例とユースケース

*   **会議室の予約状況表示:** 会議室の予約状況をカレンダーから取得し、ウィジェットに表示する。
*   **プロジェクトの進捗状況表示:** プロジェクトのタスクをリマインダーとして登録し、ウィジェットに進捗状況を表示する。
*   **誕生日リマインダー:** 誕生日のイベントをカレンダーに登録し、ウィジェットに誕生日リマインダーを表示する。
*   **旅行プランの表示:** 旅行プランをカレンダーに登録し、ウィジェットにフライト情報やホテル予約を表示する。

#### トラブルシューティング

*   **ウィジェットが更新されない:** Scriptableアプリの設定で、ウィジェットの更新頻度を確認してください。また、iOSの設定で、ウィジェットのバックグラウンド更新が有効になっていることを確認してください。
*   **フォントサイズが小さすぎる/大きすぎる:** `Font`オブジェクトを使って、適切なフォントサイズを設定してください。
*   **文字が途中で途切れる:** `line.lineLimit = 0`を設定すると、テキストが複数行にわたって表示されます。

#### まとめと次のステップ

このセクションでは、今日の予定をウィジェットに表示する方法を学びました。次のセクションでは、予定をフィルタリングして、特定の条件に合致する予定だけを表示する方法について解説します。

### 4.3. 予定のフィルタリング：特定のカレンダー、キーワードで予定を絞り込む

#### 概要と重要性

カレンダーには、個人的な予定から仕事の会議まで、様々な種類のイベントが登録されています。全ての予定をウィジェットに表示すると、情報過多になり、必要な情報を見つけにくくなることがあります。このセクションでは、特定のカレンダーやキーワードで予定を絞り込み、ウィジェットに表示する情報を整理する方法を解説します。

#### 特徴と利点

*   **情報の整理:** 必要な情報だけを表示することで、ウィジェットの見やすさを向上させます。
*   **効率的な情報アクセス:** 特定のプロジェクトやタスクに関連する予定だけを抽出することで、情報へのアクセスを効率化します。
*   **パーソナライズされた表示:** 自分のニーズに合わせて、表示する情報をカスタマイズできます。
*   **集中力向上:** 不要な情報を排除することで、集中力を維持しやすくなります。

#### 事前準備と前提条件

*   **4.1と4.2の知識:** 前のセクションで説明したカレンダーAPIとウィジェット作成の基本的な使い方を理解している必要があります。
*   **フィルタリング条件の明確化:** どのような基準で予定を絞り込むかを明確にしておく必要があります (例: 特定のカレンダーの予定、特定のキーワードを含む予定)。

#### 基本的な使い方

**特定のカレンダーで絞り込む:**

```javascript
// イベントにアクセス可能なカレンダーを取得
let calendars = await Calendar.forEvents();

// 特定のカレンダーを選択 (例: "仕事"という名前のカレンダー)
let workCalendar = calendars.find(calendar => calendar.title === "仕事");

if (workCalendar) {
  let today = new Date();
  let events = await workCalendar.events(today, today);

  // ウィジェットを作成し、イベントを表示 (省略)
} else {
  console.log("指定されたカレンダーが見つかりません");
}
```

このスクリプトは、"仕事"という名前のカレンダーを選択し、そのカレンダーの今日のイベントを取得します。`calendars.find()`を使って、指定された名前のカレンダーを検索しています。

**キーワードで絞り込む:**

```javascript
// 取得したイベントのリスト
// let events = await calendar.events(today, today);

let keyword = "プロジェクトX";
let filteredEvents = events.filter(event => event.title.includes(keyword));

// フィルタリングされたイベントをウィジェットに表示 (省略)
```

このスクリプトは、イベントのタイトルに"プロジェクトX"というキーワードが含まれているイベントだけを抽出します。`events.filter()`を使って、指定された条件に合致するイベントをフィルタリングしています。

#### 実践的なテクニック

**複数のカレンダーを組み合わせる:** 複数のカレンダーからイベントを取得し、それらをまとめてウィジェットに表示できます。

```javascript
let calendar1 = await Calendar.withName("仕事");
let calendar2 = await Calendar.withName("個人");

let today = new Date();
let events1 = await calendar1.events(today, today);
let events2 = await calendar2.events(today, today);

let allEvents = events1.concat(events2);

// allEventsをウィジェットに表示 (省略)
```

**日付範囲を指定してフィルタリング:** 特定の期間に絞ってイベントをフィルタリングできます。

```javascript
let startDate = new Date(); // 今日
let endDate = new Date();
endDate.setDate(startDate.getDate() + 3); // 3日後

let events = await calendar.events(startDate, endDate);

// 期間内のイベントをウィジェットに表示 (省略)
```

**正規表現を使った高度なフィルタリング:** 正規表現を使うと、より複雑な条件でイベントをフィルタリングできます。

```javascript
let regex = /会議|ミーティング/; // 会議またはミーティングという単語を含むイベント
let filteredEvents = events.filter(event => regex.test(event.title));

// フィルタリングされたイベントをウィジェットに表示 (省略)
```

#### 応用例とユースケース

*   **特定のプロジェクトのタスク管理:** 特定のプロジェクトに関するリマインダーのみを表示するウィジェットを作成する。
*   **会議室の予約状況モニタリング:** 特定の会議室のカレンダーから、予約状況を表示するウィジェットを作成する。
*   **出張中の予定表示:** 出張に関するイベントのみを表示するウィジェットを作成する (例: "出張"というキーワードを含むイベント)。
*   **家族の誕生日リマインダー:** 家族のカレンダーから、誕生日のイベントのみを表示するウィジェットを作成する。

#### トラブルシューティング

*   **カレンダーが見つからない:** カレンダーの名前が正しいことを確認してください。大文字小文字も区別されます。
*   **フィルタリングが正しく機能しない:** フィルタリング条件が正しいことを確認してください。特に、正規表現を使用する場合は、構文が正しいことを確認してください。
*   **パフォーマンスの問題:** 多数のイベントをフィルタリングする場合、パフォーマンスが低下する可能性があります。フィルタリングの条件を最適化するか、表示するイベントの数を制限することを検討してください。

#### まとめと次のステップ

### 4.4. 予定の追加と編集：Scriptableからカレンダーに予定を追加・編集する

#### 概要と重要性

これまでのセクションでは、カレンダーから予定を読み込み、ウィジェットに表示する方法について説明しました。このセクションでは、Scriptableから直接カレンダーに予定を追加したり編集したりする方法を解説します。これにより、Scriptableをより強力なスケジュール管理ツールとして活用できるようになります。

#### 特徴と利点

*   **予定の迅速な追加:** 新しい予定を、iOSカレンダーアプリを開くことなく、Scriptableから直接追加できます。
*   **予定の効率的な編集:** 予定の詳細（タイトル、時間、場所など）をScriptableから簡単に編集できます。
*   **自動化された予定管理:** 特定の条件に基づいて、自動的に予定を追加・編集するスクリプトを作成できます。
*   **カスタムワークフローの構築:** Scriptableと他のアプリやサービスを連携させて、独自のスケジュール管理ワークフローを構築できます。

#### 事前準備と前提条件

*   **4.1〜4.3の知識:** 前のセクションで説明したカレンダーAPI、ウィジェット作成、フィルタリングの基本的な使い方を理解している必要があります。
*   **カレンダーへの書き込み許可:** Scriptableにカレンダーへの書き込みを許可する必要があります。Scriptableアプリの設定画面から、カレンダーへの書き込みアクセスを許可してください。
*   **UI.InputFieldの使用:** ユーザーから予定のタイトルや時間などの情報を入力してもらうために、`UI.InputField`を使用します。

#### 基本的な使い方

**新しい予定を追加する:**

```javascript
// カレンダーオブジェクトを取得
let calendar = await Calendar.getDefault();

// 予定の情報を入力してもらう
let alert = new Alert();
alert.title = "新しい予定";
alert.addTextField("タイトル");
alert.addTextField("開始時間 (HH:mm)");
alert.addTextField("終了時間 (HH:mm)");
alert.addAction("追加");
alert.addCancelAction("キャンセル");

let result = await alert.present();

if (result === 0) { // 「追加」ボタンが押された場合
  let title = alert.textFieldValues()[0];
  let startTime = alert.textFieldValues()[1];
  let endTime = alert.textFieldValues()[2];

  // 開始時間と終了時間のDateオブジェクトを作成
  let startDate = parseTime(startTime);
  let endDate = parseTime(endTime);

  // 新しいイベントを作成
  let newEvent = new CalendarEvent();
  newEvent.title = title;
  newEvent.startDate = startDate;
  newEvent.endDate = endDate;
  newEvent.calendar = calendar;

  // イベントをカレンダーに保存
  await CalendarEvent.create(newEvent);

  console.log("新しい予定を追加しました");
}

// 時刻文字列をDateオブジェクトに変換する関数
function parseTime(timeString) {
  let now = new Date();
  let [hours, minutes] = timeString.split(":");
  now.setHours(hours);
  now.setMinutes(minutes);
  now.setSeconds(0);
  now.setMilliseconds(0);
  return now;
}
```

このスクリプトは、`Alert`を使ってユーザーに予定の情報を入力してもらい、新しいイベントを作成してカレンダーに保存します。`UI.InputField`を使用してタイトル、開始時間、終了時間を入力してもらいます。`parseTime()`関数は、時刻文字列をDateオブジェクトに変換します。

**既存の予定を編集する:**

```javascript
// 編集する予定を選択
let today = new Date();
let events = await calendar.events(today, today);

if (events.length > 0) {
  let chooseAlert = new Alert();
  chooseAlert.title = "編集する予定を選択";
  for (let event of events) {
    chooseAlert.addAction(event.title);
  }
  chooseAlert.addCancelAction("キャンセル");

  let chosenEventIndex = await chooseAlert.present();

  if (chosenEventIndex >= 0 && chosenEventIndex < events.length) {
    let eventToEdit = events[chosenEventIndex];

    // 編集する情報を入力してもらう
    let editAlert = new Alert();
    editAlert.title = "予定を編集";
    editAlert.addTextField("タイトル", eventToEdit.title);
    editAlert.addTextField("開始時間 (HH:mm)", formatDate(eventToEdit.startDate));
    editAlert.addTextField("終了時間 (HH:mm)", formatDate(eventToEdit.endDate));
    editAlert.addAction("更新");
    editAlert.addCancelAction("キャンセル");

    let editResult = await editAlert.present();

    if (editResult === 0) { // 「更新」ボタンが押された場合
      eventToEdit.title = editAlert.textFieldValues()[0];
      eventToEdit.startDate = parseTime(editAlert.textFieldValues()[1]);
      eventToEdit.endDate = parseTime(editAlert.textFieldValues()[2]);

      // イベントを更新
      await CalendarEvent.modify(eventToEdit);

      console.log("予定を更新しました");
    }
  }
} else {
  console.log("今日の予定はありません");
}

// 日付をフォーマットする関数
function formatDate(date) {
  let formatter = new DateFormatter();
  formatter.dateFormat = "HH:mm";
  return formatter.string(date);
}
```

このスクリプトは、まず今日の予定のリストを表示し、ユーザーに編集する予定を選択してもらいます。次に、選択された予定の情報を`Alert`に表示し、ユーザーに変更を加えてもらいます。最後に、変更された情報を基にイベントを更新します。

#### 実践的なテクニック

**定期的なイベントの自動追加:** 特定の条件に基づいて、定期的なイベントを自動的に追加するスクリプトを作成できます。

```javascript
// 例: 毎週月曜日の午前9時に会議を追加する
let now = new Date();

if (dayOfWeek === 1 && now.getHours() === 9 && now.getMinutes() === 0) {
  let calendar = await Calendar.getDefault();
  let newEvent = new CalendarEvent();
  newEvent.title = "定例会議";
  newEvent.startDate = now;
  newEvent.endDate = new Date(now.getTime() + 60 * 60 * 1000); // 1時間後
  newEvent.calendar = calendar;
  await CalendarEvent.create(newEvent);

}
```

### 4.5. 週間予定表示ウィジェット：一週間の予定を俯瞰して把握

#### 概要と重要性

日々の予定を管理することも重要ですが、週全体の予定を俯瞰的に把握することも、効率的なスケジュール管理には不可欠です。このセクションでは、一週間の予定を一覧表示するウィジェットを作成する方法を解説します。これにより、週全体のスケジュールを把握し、より長期的な計画を立てやすくなります。

#### 特徴と利点

*   **週全体のスケジュールを把握:** 一週間の予定をまとめて確認できるため、週ごとのタスク配分や時間の使い方を計画しやすくなります。
*   **空き時間の可視化:** 予定の少ない日や時間帯を特定し、新しいタスクや活動を追加する余地を見つけやすくなります。
*   **会議の重複チェック:** 複数の会議やイベントが重複していないか、一目で確認できます。
*   **長期的な計画への貢献:** 週ごとのスケジュールを把握することで、より長期的な計画を立てやすくなります。

#### 事前準備と前提条件

*   **4.1〜4.4の知識:** 前のセクションで説明したカレンダーAPI、ウィジェット作成、フィルタリング、予定の追加・編集の基本的な使い方を理解している必要があります。
*   **日付計算の理解:** JavaScriptで日付を計算する基本的な方法（`Date`オブジェクトの操作）を理解している必要があります。

#### 基本的な使い方

以下のスクリプトは、一週間の予定をウィジェットに表示する基本的な例です。

```javascript
// カレンダーオブジェクトを取得
let calendar = await Calendar.getDefault();

// 今日の日付を取得
let today = new Date();

// 1週間後の日付を取得
let endDate = new Date(today.getTime() + 7 * 24 * 60 * 60 * 1000);

// 1週間のイベントを取得
let events = await calendar.events(today, endDate);

// ウィジェットを作成
let widget = new ListWidget();

// ヘッダーを追加
let header = widget.addText("週間予定");
header.font = Font.boldSystemFont(16);

// 日付ごとにイベントを表示
for (let i = 0; i < 7; i++) {
  let date = new Date(today.getTime() + i * 24 * 60 * 60 * 1000);
  let dateString = formatDate(date, "MM/dd (E)"); // 例: 03/08 (火)

  widget.addSpacer(5);
  let dateHeader = widget.addText(dateString);
  dateHeader.font = Font.boldSystemFont(12);

  let dailyEvents = events.filter(event => isSameDay(event.startDate, date));

  if (dailyEvents.length > 0) {
    for (let event of dailyEvents) {
      let time = formatDate(event.startDate, "HH:mm");
      let title = event.title;
      let line = widget.addText(`${time} ${title}`);
    }
  } else {
    widget.addText("予定はありません");
  }
}

// ウィジェットを表示
Script.setWidget(widget);
Script.complete();

// 日付をフォーマットする関数
function formatDate(date, format) {
  let formatter = new DateFormatter();
  formatter.dateFormat = format;
  return formatter.string(date);
}

// 2つの日付が同じ日かどうかを判定する関数
function isSameDay(date1, date2) {
  return date1.getFullYear() === date2.getFullYear() &&
         date1.getMonth() === date2.getMonth() &&
         date1.getDate() === date2.getDate();
}
```

このスクリプトは、今日から1週間分のイベントを取得し、日付ごとにイベントをリスト表示します。`formatDate()`関数は、日付を指定された形式の文字列に変換します。`isSameDay()`関数は、2つの日付が同じ日かどうかを判定します。

#### 実践的なテクニック

**イベントのグループ化:** 同じ時間帯のイベントをグループ化して表示することで、ウィジェットのスペースを節約できます。

**スクロール可能なウィジェット:** イベントの数が多い場合、スクロール可能なウィジェットを作成することで、すべてのイベントを表示できます (Scriptable 1.8以降の機能)。

**週の開始日を変更:** 週の開始日（日曜日または月曜日）を設定できるようにすることで、ユーザーの好みに合わせた表示が可能です。

#### 応用例とユースケース

*   **プロジェクトのガントチャート表示:** プロジェクトのタスクをカレンダーイベントとして登録し、ウィジェットにガントチャート風に表示する。
*   **シフト勤務のスケジュール表示:** シフト勤務のスケジュールをカレンダーに登録し、ウィジェットに週間の勤務表を表示する。
*   **習い事や子供の予定表示:** 家族の習い事や子供の予定をカレンダーに登録し、ウィジェットに週間の家族スケジュールを表示する。
*   **旅行プランの行程表示:** 旅行プランをカレンダーに登録し、ウィジェットに週間の旅行行程を表示する。

#### トラブルシューティング

*   **イベントが正しく表示されない:** イベントの開始日時が正しいことを確認してください。また、`isSameDay()`関数が正しく機能しているか確認してください。
*   **ウィジェットのパフォーマンスが低い:** イベントの数が多い場合、ウィジェットのパフォーマンスが低下する可能性があります。表示するイベントの数を制限するか、ウィジェットの更新頻度を調整することを検討してください。
*   **スクロールがうまく動作しない:** `ScrollView`オブジェクトの使用方法を確認してください。また、スクロール可能なコンテンツの高さが正しく設定されているか確認してください。
