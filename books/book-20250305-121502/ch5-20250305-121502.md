## 5. リマインダー連携：タスク管理をより効率的に

### 5.1. リマインダーAPIの利用：iOSリマインダーへのアクセスと操作

#### 概要と重要性

iOSのリマインダーアプリは、日々のタスク管理に欠かせないツールです。Scriptableを用いることで、このリマインダーアプリに直接アクセスし、タスクの追加、編集、完了といった操作を自動化できます。これにより、手動でのタスク管理から解放され、より効率的なワークフローを構築することが可能になります。例えば、会議の議事録から自動的にタスクを生成したり、日報の提出をリマインダーに登録したりといった応用が考えられます。

#### 特徴と利点

*   **自動化による効率化:** タスクの追加や編集を自動化することで、手動入力の手間を省き、時間を有効活用できます。
*   **柔軟なカスタマイズ:** ScriptableのJavaScriptの知識を活用することで、複雑な条件に基づいたタスク管理が可能になります。
*   **情報の一元管理:** iOSリマインダーアプリを基盤とすることで、他のアプリとの連携も容易になり、情報の一元管理を実現できます。
*   **クロスデバイス同期:** iCloud経由でiPhone, iPad, Macなど、すべてのAppleデバイスでリマインダーが同期されるため、どこからでもタスクを確認・管理できます。

#### 事前準備と前提条件

*   **Scriptableアプリのインストール:** App StoreからScriptableアプリをダウンロードし、インストールしてください。
*   **iOSのバージョン:** iOS 14以降のバージョンが必要です。古いバージョンではリマインダーAPIが利用できない場合があります。
*   **JavaScriptの基本的な知識:** ScriptableはJavaScriptで記述するため、基本的な文法や変数、関数などの知識が必要です。
*   **リマインダーへのアクセス許可:** Scriptableからリマインダーへのアクセスを許可する必要があります。これは、Scriptableスクリプトを実行する際に表示されるダイアログで許可することができます。初回実行時に必ず許可するようにしてください。

#### 基本的な使い方

まずは、Scriptableからリマインダーにアクセスし、リストを取得する基本的なコードを見てみましょう。

```javascript
// リマインダーアプリへのアクセスをリクエスト
let reminders = await Reminder.allLists();

// リストの名前をログに出力
for (let i = 0; i < reminders.length; i++) {
  log(reminders[i].name);
}
```

このコードを実行すると、あなたのリマインダーアプリに登録されているすべてのリストの名前がScriptableのログに表示されます。`Reminder.allLists()` は、リマインダーアプリに登録されているすべてのリストを配列として返します。

次に、特定のリストから未完了のタスクを取得するコードを見てみましょう。

```javascript
// 特定のリストの名前
let listName = "仕事";

// 特定のリストを取得
let list = await ReminderList.findOrCreate(listName);

// 未完了のタスクを取得
let incompleteReminders = await Reminder.incomplete(false, list);

// タスクのタイトルをログに出力
for (let i = 0; i < incompleteReminders.length; i++) {
  log(incompleteReminders[i].title);
}
```

このコードを実行すると、"仕事"という名前のリストに登録されている未完了のタスクのタイトルがScriptableのログに表示されます。`ReminderList.findOrCreate(listName)` は、指定された名前のリストが存在する場合はそのリストを返し、存在しない場合は新しいリストを作成します。 `Reminder.incomplete(false, list)` は、指定されたリストに含まれる未完了のタスクを配列として返します。 第1引数にはアラームの有無を指定でき、`false`を指定するとアラームなしのタスクも取得します。

#### 実践的なテクニック

リマインダーAPIを使いこなすための、より実践的なテクニックをいくつか紹介します。

*   **期限付きタスクの取得:** 特定の日付までに完了する必要があるタスクを取得することができます。

```javascript
// 特定の日付
let dueDate = new Date("2024-03-15");

// 期限付きのタスクを取得
let dueReminders = await Reminder.dueDateBetween(new Date(), dueDate);

// タスクのタイトルと期限をログに出力
for (let i = 0; i < dueReminders.length; i++) {
  log(dueReminders[i].title + ": " + dueReminders[i].dueDate);
}
```

*   **タスクの優先度の設定:** タスクに優先度を設定し、優先度の高いタスクを優先的に処理することができます。優先度は0から9までの数値で設定でき、0が最も高い優先度です。

```javascript
// 新しいタスクを作成
let newReminder = new Reminder("重要なタスク");

// 優先度を設定 (0が最も高い)
newReminder.priority = 0;

// リストを設定
newReminder.calendar = await ReminderList.findOrCreate("仕事");

// タスクを保存
await newReminder.save();
```

*   **タスクへのメモの追加:** タスクにメモを追加することで、詳細な情報を記録することができます。

```javascript
// タスクを取得
let reminder = await Reminder.find("タスクのタイトル");

// メモを追加
reminder.notes = "詳細な説明や参考資料へのリンクなどを記述";

// タスクを保存
await reminder.save();
```

#### 応用例とユースケース

*   **議事録からのタスク自動生成:** 会議の議事録を解析し、アクションアイテムを自動的にリマインダーに登録する。
*   **日報提出のリマインダー:** 毎日決まった時間に日報を提出するリマインダーを自動的に作成する。
*   **プロジェクト管理ツールとの連携:** プロジェクト管理ツールのタスクをリマインダーに同期し、進捗状況を把握する。
*   **買い物リストの自動作成:** 毎週末に購入する商品をリスト化し、リマインダーに登録する。

#### トラブルシューティング

*   **リマインダーへのアクセス許可がない:** Scriptableからリマインダーへのアクセスを許可する必要があります。設定アプリの「プライバシー」>「リマインダー」で、Scriptableがオンになっていることを確認してください。
*   **スクリプトがエラーで停止する:** Scriptableのログを確認し、エラーメッセージを参考に問題を解決してください。JavaScriptの構文エラーやAPIの使用方法の間違いなどが原因であることが多いです。
*   **タスクが正しく作成されない:** タスクのタイトルやリスト名が正しいことを確認してください。また、ネットワーク接続が安定していることを確認してください。

### 5.2. 未完了タスクを表示するウィジェット：タスク漏れを防止

#### 概要と重要性

Scriptableのウィジェット機能を使用することで、iOSのホーム画面に未完了タスクを表示するウィジェットを作成できます。これにより、リマインダーアプリを開かなくても、常にタスクを確認することができ、タスク漏れを防止することができます。特に、頻繁にタスクを確認する必要がある場合に非常に有効です。

#### 特徴と利点

*   **常にタスクを視覚的に確認:** ホーム画面にタスクを表示することで、常にタスクを意識することができます。
*   **リマインダーアプリを開く手間を省く:** ウィジェットから直接タスクを確認できるため、リマインダーアプリを開く手間を省くことができます。
*   **カスタマイズ可能な表示:** ウィジェットのサイズや表示するタスクの数などを自由にカスタマイズすることができます。
*   **タスクの優先度に応じた表示:** 優先度の高いタスクを強調表示するなど、視覚的にタスクの重要度を伝えることができます。

#### 事前準備と前提条件

*   **Scriptableアプリのインストール:** App StoreからScriptableアプリをダウンロードし、インストールしてください。
*   **iOS 14以降のバージョン:** ウィジェット機能はiOS 14以降で利用可能です。
*   **リマインダーへのアクセス許可:** Scriptableからリマインダーへのアクセスを許可する必要があります。
*   **ウィジェットの配置:** iOSのホーム画面にScriptableウィジェットを配置する方法を理解している必要があります。

#### 基本的な使い方

まずは、最もシンプルなウィジェットを作成し、未完了タスクを表示する基本的なコードを見てみましょう。

```javascript
// 特定のリストの名前
let listName = "仕事";

// 特定のリストを取得
let list = await ReminderList.findOrCreate(listName);

// 未完了のタスクを取得
let incompleteReminders = await Reminder.incomplete(false, list);

// ウィジェットを作成
let widget = new ListWidget();

// ウィジェットにタスクを追加
for (let i = 0; i < incompleteReminders.length; i++) {
  widget.addText(incompleteReminders[i].title);
}

// ウィジェットを表示
Script.setWidget(widget);
Script.complete();
```

このコードを実行すると、"仕事"という名前のリストに登録されている未完了のタスクが、Scriptableウィジェットとしてホーム画面に表示されます。

次に、ウィジェットのデザインを少し変更してみましょう。

```javascript
// 特定のリストの名前
let listName = "仕事";

// 特定のリストを取得
let list = await ReminderList.findOrCreate(listName);

// 未完了のタスクを取得
let incompleteReminders = await Reminder.incomplete(false, list);

// ウィジェットを作成
let widget = new ListWidget();

// 背景色を設定
widget.backgroundColor = new Color("#f0f0f0");

// ウィジェットにタスクを追加
for (let i = 0; i < incompleteReminders.length; i++) {
  let text = widget.addText(incompleteReminders[i].title);
  text.textColor = new Color("#333333");
  text.font = Font.mediumSystemFont(12);
  text.lineLimit = 1; // 1行で表示
}

// ウィジェットを表示
Script.setWidget(widget);
Script.complete();
```

このコードでは、ウィジェットの背景色をグレーに変更し、タスクのテキストの色を濃いグレーに、フォントサイズを12に設定しています。`text.lineLimit = 1;` で、タスクのタイトルが長すぎる場合に1行で表示するように制限しています。

#### 実践的なテクニック

ウィジェットをより便利にするための、実践的なテクニックをいくつか紹介します。

*   **タスクの数に応じてウィジェットのサイズを変更:** 表示するタスクの数に応じてウィジェットのサイズを自動的に変更することができます。
*   **タスクの優先度に応じて色を変える:** 優先度の高いタスクを赤色で表示するなど、色を変えることで視覚的に重要度を伝えることができます。
*   **タップでリマインダーアプリを開く:** ウィジェットをタップすると、リマインダーアプリが開くように設定することができます。

```javascript
// ウィジェットを作成
let widget = new ListWidget();

// タップ時のアクションを設定 (リマインダーアプリを開く)
widget.url = "x-apple-reminderkit://";

// ... (省略) ...

// ウィジェットを表示
Script.setWidget(widget);
Script.complete();
```

`widget.url = "x-apple-reminderkit://";` で、ウィジェットをタップした際にリマインダーアプリを開くように設定しています。

*   **ウィジェットのリフレッシュ間隔を設定:** ウィジェットのリフレッシュ間隔を設定することで、常に最新のタスクを表示することができます。

#### 応用例とユースケース

*   **プロジェクトごとのタスクを表示:** プロジェクトごとにリストを作成し、それぞれのリストのタスクを表示するウィジェットを作成する。
*   **今日締め切りのタスクを表示:** 今日締め切りのタスクのみを表示するウィジェットを作成する。
*   **買い物リストを表示:** 買い物リストを表示するウィジェットを作成し、買い忘れを防止する。
*   **ルーチンタスクを表示:** 毎日繰り返すルーチンタスクを表示するウィジェットを作成する。

#### トラブルシューティング

*   **ウィジェットに何も表示されない:** Scriptableからリマインダーへのアクセスが許可されているか確認してください。また、指定したリストに未完了のタスクが存在することを確認してください。
*   **ウィジェットが更新されない:** iOSの設定で、Scriptableのバックグラウンド更新が有効になっていることを確認してください。
*   **ウィジェットの表示が崩れる:** ウィジェットのサイズが適切かどうか確認してください。また、テキストのフォントサイズや行数制限などを調整してください。

### 5.3. リストの選択と表示：複数のリストを切り替えて表示

#### 概要と重要性

複数のリマインダーリストを使用している場合、ウィジェットで表示するリストを簡単に切り替えられると便利です。Scriptableを使うことで、ウィジェットをタップした際に表示するリストを選択できるメニューを表示したり、設定画面からリストを選択できるようにしたりすることができます。これにより、状況に応じて必要なリストのタスクを素早く確認できます。

#### 特徴と利点

*   **柔軟なリスト選択:** 複数のリストから表示するリストを簡単に選択できます。
*   **状況に応じたタスク表示:** 作業内容や場所に応じて、表示するリストを切り替えることができます。
*   **カスタマイズ可能な選択方法:** メニュー表示や設定画面など、好みに合わせた選択方法を実装できます。
*   **ウィジェットの省スペース化:** 複数のリストを個別のウィジェットとして配置する必要がなくなり、ホーム画面のスペースを有効活用できます。

#### 事前準備と前提条件

*   **Scriptableアプリのインストール:** App StoreからScriptableアプリをダウンロードし、インストールしてください。
*   **iOS 14以降のバージョン:** ウィジェット機能はiOS 14以降で利用可能です。
*   **リマインダーへのアクセス許可:** Scriptableからリマインダーへのアクセスを許可する必要があります。
*   **ウィジェットの配置:** iOSのホーム画面にScriptableウィジェットを配置する方法を理解している必要があります。
*   **UserDefaultsの使用:** Scriptableで永続的な設定を保存するために、`UserDefaults`の使い方を理解している必要があります。

#### 基本的な使い方

まずは、ウィジェットをタップした際に表示するリストを選択できるメニューを表示する基本的なコードを見てみましょう。

```javascript
// リストの名前を保存するキー
let listNameKey = "listName";

// UserDefaultsからリストの名前を取得
let listName = Keychain.read(listNameKey);

// リストの名前が保存されていない場合はデフォルト値を設定
if (!listName) {
  listName = "仕事";
}

// 特定のリストを取得
let list = await ReminderList.findOrCreate(listName);

// 未完了のタスクを取得
let incompleteReminders = await Reminder.incomplete(false, list);

// ウィジェットを作成
let widget = new ListWidget();

// ウィジェットにタスクを追加
for (let i = 0; i < incompleteReminders.length; i++) {
  widget.addText(incompleteReminders[i].title);
}

// タップ時のアクションを設定 (リスト選択メニューを表示)
widget.url = "scriptable:///run?scriptName=" + Script.name() + "&action=selectList";

// ウィジェットを表示
Script.setWidget(widget);
Script.complete();

// リスト選択メニューを表示する関数
if (args.queryParameters.action == "selectList") {
  // リストの名前を取得
  let reminders = await Reminder.allLists();
  let listNames = reminders.map(list => list.name);

  // メニューを表示
  let alert = new Alert();
  alert.title = "リストを選択";
  alert.addCancelAction("キャンセル");
  for (let name of listNames) {
    alert.addAction(name);
  }

  // 選択されたリストの名前を取得
  let selectedIndex = await alert.present();

  // キャンセルされた場合は何もしない
  if (selectedIndex == -1) {
    return;
  }

  // 選択されたリストの名前をUserDefaultsに保存
  Keychain.write(listNameKey, listNames[selectedIndex - 1]); //selectedIndexはキャンセル分ずれているので調整

  // ウィジェットをリフレッシュ
  await Script.run();
}
```

このコードでは、ウィジェットをタップするとリスト選択メニューが表示され、選択されたリストの名前が`UserDefaults`に保存されます。次にウィジェットが更新される際には、保存されたリストの名前を使用してタスクが表示されます。

#### 実践的なテクニック

*   **設定画面からリストを選択:** ウィジェットの設定画面からリストを選択できるようにすることで、より直感的な操作を実現できます。`Safari.open()` を使用して、設定用のWebページを開くことができます。
*   **リストのアイコンを表示:** リストごとに異なるアイコンを表示することで、視覚的にリストを区別しやすくすることができます。
*   **リストの並び順をカスタマイズ:** リストの並び順を優先度や使用頻度などに応じてカスタマイズすることができます。

#### 応用例とユースケース

*   **仕事用とプライベート用のリストを切り替え:** 仕事用とプライベート用のリストを切り替えて表示することで、ワークライフバランスをサポートする。
*   **プロジェクトごとのリストを切り替え:** 複数のプロジェクトを抱えている場合に、それぞれのプロジェクトのタスクを切り替えて表示する。
*   **買い物リストとTODOリストを切り替え:** 買い物リストとTODOリストを切り替えて表示することで、日々の生活を効率化する。
*   **家族共有リストと個人リストを切り替え:** 家族で共有しているリストと個人のリストを切り替えて表示する。

#### トラブルシューティング

*   **リスト選択メニューが表示されない:** `widget.url` が正しく設定されているか確認してください。また、Scriptableアプリが最新バージョンであることを確認してください。
*   **リストの選択が保存されない:** `UserDefaults` のキーが正しいことを確認してください。また、`Keychain.write()` で正しく書き込まれているか確認してください。
*   **ウィジェットが更新されない:** ウィジェットのリフレッシュ間隔が適切かどうか確認してください。

#### まとめと次のステップ

このセクションでは、Scriptableを使ってウィジェットで表示するリストを切り替える方法について学びました。次のセクションでは、Scriptableからタスクを完了にする方法について解説します。

### 5.4. タスクの完了処理：Scriptableからタスクを完了にする

#### 概要と重要性

ウィジェット上でタスクを確認できるだけでなく、タスクを完了にできるとさらに便利です。Scriptableを使うことで、ウィジェットに完了ボタンを追加し、それをタップすることでタスクを完了にすることができます。これにより、リマインダーアプリを開くことなく、タスクを完了させることができ、タスク管理の効率が大幅に向上します。

#### 特徴と利点

*   **ワンタップでタスク完了:** ウィジェット上でタスクを完了できるため、操作が簡単で迅速です。
*   **リマインダーアプリを開く手間を省く:** リマインダーアプリを開かずにタスクを完了できるため、時間を節約できます。
*   **ウィジェットのインタラクティブ性向上:** ウィジェットが単なる表示ツールではなく、操作可能なインターフェースになります。
*   **タスク管理のストレス軽減:** タスクを完了させるのが簡単になるため、タスク管理に対する心理的な負担を軽減できます。

#### 事前準備と前提条件

*   **Scriptableアプリのインストール:** App StoreからScriptableアプリをダウンロードし、インストールしてください。
*   **iOS 14以降のバージョン:** ウィジェット機能はiOS 14以降で利用可能です。
*   **リマインダーへのアクセス許可:** Scriptableからリマインダーへのアクセスを許可する必要があります。
*   **ウィジェットの配置:** iOSのホーム画面にScriptableウィジェットを配置する方法を理解している必要があります。
*   **タスクのID管理:** 完了するタスクを特定するために、タスクのIDを管理する必要があります。

#### 基本的な使い方

まずは、ウィジェットに完了ボタンを追加し、それをタップすることでタスクを完了にする基本的なコードを見てみましょう。

```javascript
// 特定のリストの名前
let listName = "仕事";

// 特定のリストを取得
let list = await ReminderList.findOrCreate(listName);

// 未完了のタスクを取得
let incompleteReminders = await Reminder.incomplete(false, list);

// ウィジェットを作成
let widget = new ListWidget();

// ウィジェットにタスクを追加
for (let i = 0; i < incompleteReminders.length; i++) {
  let reminder = incompleteReminders[i];

  let row = widget.addStack();
  row.layoutHorizontally();

  let title = row.addText(reminder.title);
  title.textColor = new Color("#333333");
  title.font = Font.mediumSystemFont(12);
  title.lineLimit = 1;

  row.addSpacer(); // スペースを追加

  // 完了ボタンを追加
  let completeButton = row.addImage(SFSymbol.named("checkmark.circle").image);
  completeButton.tintColor = Color.green();
  completeButton.url = "scriptable:///run?scriptName=" + Script.name() + "&action=complete&reminderId=" + reminder.identifier;
}

// ウィジェットを表示
Script.setWidget(widget);
Script.complete();

// タスクを完了にする関数
if (args.queryParameters.action == "complete") {
  // タスクのIDを取得
  let reminderId = args.queryParameters.reminderId;

  // タスクを取得
  let reminder = await Reminder.find(reminderId);

  // タスクを完了にする
  reminder.isComplete = true;
  await reminder.save();

  // ウィジェットをリフレッシュ
  await Script.run();
}
```

このコードでは、各タスクの横に完了ボタン（チェックマークのアイコン）が表示されます。完了ボタンをタップすると、`scriptable:///run` スキームを使って、Scriptableスクリプトが再度実行され、`action=complete` と `reminderId` が渡されます。スクリプトは、`reminderId` を使ってタスクを検索し、`isComplete` を `true` に設定してタスクを完了にします。

#### 実践的なテクニック

*   **完了ボタンのデザインをカスタマイズ:** 完了ボタンのアイコンや色を変更することで、ウィジェットのデザインに合わせて調整できます。
*   **完了アニメーションを追加:** タスクが完了した際に、アニメーションを表示することで、視覚的なフィードバックを提供できます。
*   **タスクの削除機能を追加:** 完了したタスクをウィジェットから削除する機能を追加することで、ウィジェットの表示を整理できます。

#### 応用例とユースケース

*   **ルーチンタスクの完了処理:** 毎日のルーチンタスクを完了にする機能を追加することで、習慣化をサポートする。
*   **プロジェクトタスクの完了処理:** プロジェクトのタスクを完了にする機能を追加することで、進捗管理を容易にする。

#### トラブルシューティング

### 5.5. リマインダーの通知設定：期限切れタスクを通知で知らせる

#### 概要と重要性

期限切れのタスクを見逃さないようにするために、通知を設定することは非常に重要です。Scriptableを使用することで、期限切れのタスクを定期的にチェックし、必要に応じて通知を送信することができます。これにより、タスクの遅延を防ぎ、スケジュール管理を徹底することができます。

#### 特徴と利点

*   **タスクの見逃し防止:** 期限切れのタスクを通知で知らせることで、タスクの見逃しを防ぎます。
*   **タイムリーなリマインド:** 期限が迫っているタスクを事前に通知することで、準備時間を確保できます。
*   **カスタマイズ可能な通知設定:** 通知のタイミングや内容を自由にカスタマイズできます。
*   **自動化による手間削減:** 定期的なタスクチェックを自動化することで、手動での確認作業を削減できます。

#### 事前準備と前提条件

*   **Scriptableアプリのインストール:** App StoreからScriptableアプリをダウンロードし、インストールしてください。
*   **iOSのバージョン:** iOS 14以降のバージョンが必要です。
*   **リマインダーへのアクセス許可:** Scriptableからリマインダーへのアクセスを許可する必要があります。
*   **通知の許可:** iOSの設定で、Scriptableからの通知を許可する必要があります。
*   **バックグラウンド実行:** Scriptableスクリプトをバックグラウンドで実行できるように設定する必要があります。

#### 基本的な使い方

まずは、期限切れのタスクをチェックし、通知を送信する基本的なコードを見てみましょう。

```javascript
// 通知を送信する関数
async function sendNotification(title, body) {
  let notification = new Notification();
  notification.title = title;
  notification.body = body;
  notification.sound = "default";
  await notification.schedule();
}

// 期限切れのタスクをチェックする関数
async function checkOverdueReminders() {
  // 現在の日時を取得
  let now = new Date();

  // すべてのリマインダーリストを取得
  let reminders = await Reminder.allDueToday();

  // 期限切れのタスクをチェック
  for (let i = 0; i < reminders.length; i++) {
    let reminder = reminders[i];

    // 期限が過ぎているか確認
    if (reminder.dueDate < now && !reminder.isComplete) {
      // 通知を送信
      await sendNotification("期限切れタスク", reminder.title + " の期限が過ぎました。");
    }
  }
}

// 関数を実行
await checkOverdueReminders();

// スクリプトを終了
Script.complete();
```

このコードでは、`checkOverdueReminders()` 関数が定期的に実行され、期限切れのタスクをチェックします。期限切れのタスクが見つかった場合は、`sendNotification()` 関数を使って通知を送信します。

このスクリプトを定期的に実行するには、Scriptableの設定で「バックグラウンド実行」を有効にし、iOSの「ショートカット」アプリを使って自動化を設定します。

1.  **ショートカットの作成:**
    *   ショートカットアプリを開き、「オートメーション」タブを選択します。
    *   「個人用オートメーションを作成」をタップします。
    *   トリガーとして「時刻」を選択し、タスクをチェックする時間 (例えば、毎日9:00) を設定します。
    *   「アクションを追加」をタップし、「Scriptable」と入力して「Scriptableを実行」を選択します。
    *   実行するScriptableスクリプトを選択します。
    *   「実行前に確認」をオフにします (自動で実行するため)。

#### 実践的なテクニック

*   **期限が迫っているタスクを事前に通知:** 期限の数時間前に通知を送信することで、準備時間を確保できます。
*   **タスクの優先度に応じて通知の重要度を変える:** 優先度の高いタスクは緊急度の高い通知を送信し、優先度の低いタスクは控えめな通知を送信する。
*   **通知の間隔を調整:** タスクの重要度や種類に応じて、通知の間隔を調整する。

#### 応用例とユースケース

*   **請求書の支払い期限のリマインド:** 請求書の支払い期限を通知で知らせることで、支払いの遅延を防ぐ。
*   **薬の服用時間のリマインド:** 薬の服用時間を通知で知らせることで、飲み忘れを防止する。
*   **会議のリマインド:** 会議の開始時間前に通知を送信することで、会議への参加を促す。

#### トラブルシューティング

*   **通知が送信されない:** iOSの設定で、Scriptableからの通知が許可されているか確認してください。また、バックグラウンド実行が有効になっているか確認してください。
*   **通知が重複して送信される:** ショートカットの設定で、トリガーが正しく設定されているか確認してください。
*   **通知の内容が正しくない:** Scriptableスクリプトで、タスクのタイトルや期限が正しく取得されているか確認してください。
