## 9. QRコード生成：必要な情報を瞬時に共有

QRコードは、現代の生活において、情報を迅速かつ効率的に共有するための不可欠なツールとなりました。Scriptableを使うことで、この強力なツールを自在に操り、様々な情報をQRコードとして生成し、活用できます。この章では、ScriptableでQRコードを生成する方法を、基本的な使い方から応用的なテクニックまで、ステップバイステップで解説します。

### 9.1. QRコードライブラリの利用：ScriptableでQRコードを生成

**1. 概要と重要性**

Scriptableは、標準でQRコード生成機能を提供していません。そこで、外部ライブラリを利用することで、QRコードの生成が可能になります。幸いなことに、Scriptableコミュニティは活発で、様々な便利なライブラリが公開されています。このセクションでは、最もポピュラーなライブラリの一つである、`QRCode.js` を利用する方法を紹介します。

**2. 特徴と利点**

`QRCode.js` は、軽量で扱いやすく、様々なカスタマイズオプションを提供します。エラー訂正レベルや色、サイズなどを変更できるため、用途に合わせたQRコードを作成できます。

**3. 事前準備と前提条件**

*   Scriptableアプリがインストールされていること。
*   JavaScriptの基本的な知識があること。
*   `QRCode.js` をダウンロードし、Scriptableのスクリプトフォルダに配置するか、オンラインでアクセスできるように準備すること。

    `QRCode.js` は、以下のリンクからダウンロードできます。

    *   [https://davidshimjs.github.io/qrcodejs/](https://davidshimjs.github.io/qrcodejs/)

**4. 基本的な使い方**

まず、`QRCode.js` をScriptableのスクリプトにインポートします。そして、`QRCode` オブジェクトを生成し、`makeCode()` メソッドを使ってQRコードを生成します。

```javascript
// QRCode.jsをインポート (ファイルパスは環境に合わせて変更)
const QRCode = importModule('qrcode');

// QRコードを生成するテキスト
const text = "Hello, Scriptable QR Code!";

// QRCodeオブジェクトを作成
const qrCode = new QRCode(0, QRCode.ErrorCorrectLevel.M); // Version 0 は自動設定
qrCode.addData(text);
qrCode.make();

// 生成されたQRコードの画像をUIImageとして取得
const uiImage = qrCode.createImage(3); // Scale factor of 3

// UIImageをプレビュー
QuickLook.present(uiImage);

// 画像をファイルに保存 (コメントアウトを外して使用)
//let fm = FileManager.iCloud();
//let filePath = fm.joinPath(fm.documentsDirectory(), "qr_code.png");
//fm.writeImage(filePath, uiImage);
//console.log("QR Code saved to: " + filePath);
```

このコードを実行すると、「Hello, Scriptable QR Code!」というテキストを含むQRコードが生成され、プレビューに表示されます。

**5. 実践的なテクニック**

*   **エラー訂正レベルの変更:** `QRCode.ErrorCorrectLevel` を変更することで、QRコードのエラー訂正能力を調整できます。 `L` (低)、 `M` (中)、 `Q` (高)、 `H` (最高) の4つのレベルがあります。
*   **サイズの調整:** `createImage()` メソッドに渡すスケールファクターを変更することで、QRコードのサイズを調整できます。
*   **背景色と前景色の変更:** `QRCode.js` は直接的な色の変更機能を提供していませんが、生成されたUIImageを加工することで色の変更が可能です。UIImageをCIImageに変換し、CIFilterを使って色を調整するテクニックがあります。

**6. 応用例とユースケース**

*   **Wi-Fiパスワードの共有:** Wi-FiのSSIDとパスワードをQRコード化して、簡単に共有できます。
*   **イベントへの招待:** イベントの詳細情報（日時、場所、参加方法など）をQRコード化して、招待状に印刷したり、SNSで共有したりできます。
*   **名刺への印刷:** 連絡先情報をQRコード化して名刺に印刷することで、相手に簡単に連絡先を登録してもらうことができます。
*   **店舗への誘導:** 店舗の場所や営業時間などをQRコード化して、チラシやWebサイトに掲載することで、顧客を誘導できます。

**7. トラブルシューティング**

*   **QRコードが読み取れない:** エラー訂正レベルが低すぎると、QRコードが汚れたり破損したりした場合に読み取れなくなることがあります。エラー訂正レベルを高くすることで、この問題を解決できます。
*   **QRコードのサイズが小さすぎる:** QRコードのサイズが小さすぎると、スマートフォンで読み取れないことがあります。スケールファクターを大きくすることで、QRコードのサイズを大きくできます。
*   **QRCode.jsが見つからない:** `importModule()` のパスが間違っている可能性があります。正しいパスを指定してください。

**8. まとめと次のステップ**

このセクションでは、`QRCode.js` を利用してScriptableでQRコードを生成する方法を学びました。次のセクションでは、テキストだけでなく、URLや連絡先など、様々なデータをQRコードに変換する方法を解説します。

### 9.2. テキスト、URL、連絡先…様々なデータをQRコードに変換

**1. 概要と重要性**

QRコードは、テキストだけでなく、URL、連絡先情報、位置情報など、様々なデータを格納できます。このセクションでは、Scriptableを使って、これらの様々なデータをQRコードに変換する方法を解説します。

**2. 特徴と利点**

様々なデータをQRコードに変換することで、情報をより効率的に共有できます。例えば、URLをQRコード化することで、ユーザーはURLを入力する手間を省き、Webサイトに直接アクセスできます。

**3. 事前準備と前提条件**

*   9.1 のセクションで説明した `QRCode.js` がScriptableにインポートされていること。
*   変換したいデータの形式を理解していること（URL、vCardなど）。

**4. 基本的な使い方**

9.1 のセクションで示したコードを基に、`text` 変数に格納するデータを変更します。

*   **URLのQRコード化:**

    ```javascript
    const text = "https://www.example.com";
    ```

*   **連絡先情報 (vCard) のQRコード化:**

    ```javascript
    const text = `BEGIN:VCARD
    VERSION:3.0
    N:Doe;John;;;
    FN:John Doe
    ORG:Example Corp.
    TEL;TYPE=WORK,VOICE:(123) 456-7890
    EMAIL:john.doe@example.com
    END:VCARD`;
    ```

    vCard形式は、改行を `\n` で表す必要があります。
*   **Wi-Fi設定のQRコード化:**

    ```javascript
    const text = `WIFI:S:<SSID>;T:<AUTHENTICATION>;P:<PASSWORD>;H:<HIDDEN>;;`;
    // 例：
    // const text = `WIFI:S:MyWiFiNetwork;T:WPA;P:MyWiFiPassword;H:false;;`;
    ```
    `<SSID>` はWi-FiのSSID、`<AUTHENTICATION>` は認証方式（WPA、WEP、なしの場合は"nopass"）、`<PASSWORD>` はパスワード、`<HIDDEN>` は非表示ネットワークかどうか（trueまたはfalse）を表します。

**5. 実践的なテクニック**

*   **URLエンコード:** URLに日本語が含まれる場合、URLエンコードする必要があります。JavaScriptの `encodeURIComponent()` 関数を使用できます。
*   **vCardの動的生成:** ユーザーインターフェースで入力された情報を基に、vCard形式の文字列を動的に生成できます。

**6. 応用例とユースケース**

*   **オンライン決済:** 決済URLをQRコード化して、ユーザーが簡単に支払いを行えるようにします。
*   **予約システム:** 予約確認画面にQRコードを表示し、ユーザーが簡単に予約情報を確認できるようにします。
*   **デジタルサイネージ:** 製品情報やキャンペーン情報をQRコード化して、ユーザーがスマートフォンで詳細情報を確認できるようにします。

**7. トラブルシューティング**

*   **vCardが正しく認識されない:** vCardの形式が間違っている可能性があります。vCardの仕様を確認し、正しい形式で記述してください。
*   **URLエンコードの問題:** URLエンコードが正しく行われていない可能性があります。`encodeURIComponent()` 関数を使用しているか確認してください。

**8. まとめと次のステップ**

このセクションでは、テキストだけでなく、URLや連絡先など、様々なデータをQRコードに変換する方法を学びました。次のセクションでは、生成したQRコードを保存する方法を解説します。

### 9.3. 生成したQRコードを保存：画像として保存したり、クリップボードにコピー

**1. 概要と重要性**

Scriptableで生成したQRコードは、画像として保存したり、クリップボードにコピーしたりできます。これにより、他のアプリやサービスでQRコードを簡単に利用できます。

**2. 特徴と利点**

QRコードを画像として保存することで、印刷物やWebサイトに埋め込むことができます。クリップボードにコピーすることで、メッセージアプリやメールに簡単に貼り付けることができます。

**3. 事前準備と前提条件**

*   9.1 のセクションで説明した `QRCode.js` を利用してQRコードを生成できること。
*   Scriptableのファイルシステムとクリップボードへのアクセス権限があること。

**4. 基本的な使い方**

*   **画像として保存:**

    9.1 のセクションで示したコードには、既に画像をファイルに保存するコードが含まれています。コメントアウトを外して使用してください。

    ```javascript
    let fm = FileManager.iCloud();
    let filePath = fm.joinPath(fm.documentsDirectory(), "qr_code.png");
    fm.writeImage(filePath, uiImage);
    console.log("QR Code saved to: " + filePath);
    ```
    保存先フォルダやファイル名は、必要に応じて変更してください。

*   **クリップボードにコピー:**

    ```javascript
    Pasteboard.copyImage(uiImage);
    console.log("QR Code copied to clipboard.");
    ```

    `Pasteboard.copyImage()` メソッドを使って、UIImageをクリップボードにコピーできます。

**5. 実践的なテクニック**

*   **ファイル名の自動生成:** 現在の日時を基にファイル名を自動生成することで、QRコードを整理しやすくなります。

    ```javascript
    let now = new Date();
    let fileName = "qr_code_" + now.toISOString().replace(/[-:]/g, '').substring(0, 15) + ".png";
    let filePath = fm.joinPath(fm.documentsDirectory(), fileName);
    ```
*   **iCloud Driveへの保存:** `FileManager.iCloud()` を使うことで、QRコードをiCloud Driveに保存できます。

**6. 応用例とユースケース**

*   **自動QRコード生成ツール:** 定期的にQRコードを生成し、iCloud Driveに保存するスクリプトを作成することで、自動QRコード生成ツールとして利用できます。
*   **ワークフローアプリとの連携:** 生成したQRコードをWorkflowアプリに渡し、印刷したり、SNSで共有したりできます。

**7. トラブルシューティング**

*   **ファイルへの書き込み権限がない:** Scriptableがファイルシステムへのアクセス権限を持っていない可能性があります。Scriptableの設定でファイルシステムへのアクセス権限を許可してください。
*   **クリップボードへのコピーができない:** iOSのバージョンによっては、クリップボードへのアクセスが制限されている場合があります。

**8. まとめと次のステップ**

このセクションでは、生成したQRコードを画像として保存したり、クリップボードにコピーしたりする方法を学びました。次のセクションでは、URLスキームと連携して、QRコードを読み取って特定のアプリを起動する方法を解説します。

### 9.4. URLスキームと連携：QRコードを読み取って特定のアプリを起動

**1. 概要と重要性**

URLスキームとは、特定のアプリを起動するための特別なURLのことです。QRコードにURLスキームを埋め込むことで、ユーザーがQRコードを読み取るだけで、特定のアプリを起動したり、特定の機能を実行したりできます。

**2. 特徴と利点**

URLスキームと連携することで、ユーザーエクスペリエンスを大幅に向上させることができます。例えば、地図アプリのURLスキームをQRコード化することで、ユーザーが場所情報を読み取るだけで、地図アプリが起動し、その場所が表示されます。

**3. 事前準備と前提条件**

*   QRコードを生成できること。
*   起動したいアプリのURLスキームを知っていること。
*   URLスキームを正しく理解していること。

**4. 基本的な使い方**

QRコードに埋め込むテキストを、起動したいアプリのURLスキームに設定します。

```javascript
// 起動したいアプリのURLスキーム
const urlScheme = "maps://?q=Tokyo"; // 例：地図アプリで東京を表示

// QRコードを生成するテキスト
const text = urlScheme;

// QRCodeオブジェクトを作成 (9.1 のセクションを参照)
const QRCode = importModule('qrcode');
const qrCode = new QRCode(0, QRCode.ErrorCorrectLevel.M);
qrCode.addData(text);
qrCode.make();

// 生成されたQRコードの画像をUIImageとして取得
const uiImage = qrCode.createImage(3);

// UIImageをプレビュー
QuickLook.present(uiImage);
```

このコードを実行し、生成されたQRコードをスマートフォンで読み取ると、地図アプリが起動し、東京が表示されます。（地図アプリがインストールされている必要があります）

**5. 実践的なテクニック**

*   **パラメータ付きのURLスキーム:** URLスキームにパラメータを追加することで、アプリの特定の機能を実行できます。例えば、特定の音楽を再生したり、特定の連絡先を編集したりできます。
*   **汎用的なURLスキーム:** `scriptable:///run`  URLスキームを使って、Scriptableスクリプトを実行できます。このURLスキームにスクリプト名やパラメータを渡すことで、QRコードを読み取るだけでScriptableスクリプトを実行できます。

    ```javascript
    // Scriptableスクリプトを実行するURLスキーム
    const urlScheme = "scriptable:///run?scriptName=MyScript&parameter=value";

    // MyScript.js ファイル
    // let parameter = args.plainTexts[0];
    // console.log("Parameter: " + parameter);
    // Script.complete();
    ```

**6. 応用例とユースケース**

*   **スマートホーム連携:** スマートホームデバイスの操作をURLスキームで実行し、QRコードを読み取るだけでスマートホームデバイスを操作できるようにします。
*   **店舗チェックイン:** 店舗のチェックインURLをQRコード化し、顧客がQRコードを読み取るだけでチェックインできるようにします。
*   **デジタルチケット:** デジタルチケットの情報をURLスキームで表現し、QRコードを読み取るだけでチケットを表示できるようにします。

**7. トラブルシューティング**

*   **アプリが起動しない:** URLスキームが間違っている可能性があります。起動したいアプリのURLスキームを確認してください。
*   **パラメータが正しく渡されない:** URLエンコードの問題や、アプリ側のパラメータ処理の問題が考えられます。

**8. まとめと次のステップ**

このセクションでは、URLスキームと連携して、QRコードを読み取って特定のアプリを起動する方法を学びました。次のセクションでは、動的なQRコード生成について解説します。

### 9.5. 動的なQRコード生成：時間によって内容が変わるQRコードを作成

**1. 概要と重要性**

動的なQRコードとは、時間や場所、ユーザーの状況などに応じて、内容が変化するQRコードのことです。Scriptableを使うことで、このような動的なQRコードを簡単に生成できます。

**2. 特徴と利点**

動的なQRコードは、常に最新の情報を提供できるため、ユーザーエクスペリエンスを大幅に向上させることができます。例えば、リアルタイムの交通状況や、現在地の天気予報などをQRコードで提供できます。

**3. 事前準備と前提条件**

*   QRコードを生成できること。
*   データを取得するためのAPIやWebサイトにアクセスできること。
*   JavaScriptの非同期処理の知識があること。

**4. 基本的な使い方**

まず、データを取得するためのAPIやWebサイトにアクセスし、必要なデータを取得します。次に、取得したデータをQRコードに埋め込みます。最後に、Scriptableのウィジェット機能を使って、定期的にQRコードを更新します。

```javascript
async function createDynamicQRCode() {
  // 天気APIからデータを取得
  const weatherApiUrl = "https://api.openweathermap.org/data/2.5/weather?q=Tokyo&appid=YOUR_API_KEY"; // 実際のAPIキーに置き換えてください
  const req = new Request(weatherApiUrl);
  const weatherData = await req.loadJSON();

  // 必要な情報を抽出
  const temperature = Math.round(weatherData.main.temp - 273.15); // ケルビンから摂氏に変換
  const condition = weatherData.weather[0].main;

  // QRコードに埋め込むテキスト
  const text = `現在の東京の天気: ${temperature}°C, ${condition}`;

  // QRCodeオブジェクトを作成 (9.1 のセクションを参照)
  const QRCode = importModule('qrcode');
  const qrCode = new QRCode(0, QRCode.ErrorCorrectLevel.M);
  qrCode.addData(text);
  qrCode.make();

  // 生成されたQRコードの画像をUIImageとして取得
  const uiImage = qrCode.createImage(3);

  return uiImage;
}

// メイン処理
async function main() {
  const qrCodeImage = await createDynamicQRCode();
  QuickLook.present(qrCodeImage);

  // ウィジェットに表示する場合
  let widget = new ListWidget();
  widget.backgroundImage = qrCodeImage;
  Script.setWidget(widget);
  widget.presentLarge();
  Script.complete();
}

main();
```

このコードは、OpenWeatherMap APIから東京の天気データを取得し、QRコードに埋め込みます。`YOUR_API_KEY`  は、OpenWeatherMap APIで取得したAPIキーに置き換えてください。

**5. 実践的なテクニック**

*   **ウィジェットのリフレッシュ:** `config.runsInWidget` を使用して、スクリプトがウィジェットとして実行されているかどうかを判断し、ウィジェットのリフレッシュレートを設定します。

    ```javascript
    if (config.runsInWidget) {
      widget.refreshAfterDate = new Date(Date.now() + 60 * 60 * 1000); // 1時間ごとにリフレッシュ
    }
    ```
*   **エラーハンドリング:** APIのレスポンスエラーやネットワークエラーが発生した場合に備えて、エラーハンドリング処理を追加します。

**6. 応用例とユースケース**

*   **リアルタイム交通情報:** リアルタイムの交通情報をQRコード化し、バス停や駅などに表示することで、ユーザーは常に最新の交通情報を確認できます。
*   **在庫状況:** 店舗の在庫状況をQRコード化し、商品棚に表示することで、顧客はスマートフォンで在庫状況を確認できます。
*   **イベント情報:** イベントのスケジュールや出演者情報をQRコード化し、イベント会場に表示することで、参加者は常に最新のイベント情報を確認できます。

**7. トラブルシューティング**

*   **APIアクセス制限:** APIのアクセス制限に達した場合、エラーが発生します。APIの利用制限を確認し、必要に応じて利用プランを変更してください。
*   **ウィジェットが更新されない:** ウィジェットのリフレッシュレートが適切に設定されていない可能性があります。`widget.refreshAfterDate` を確認してください。
