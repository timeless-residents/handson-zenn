## 8.1. ニュースAPIの選定と利用：News API と RSS フィード

**概要と重要性**

最新ニュースの収集には、News APIやRSSフィードを活用するのが有効です。Scriptableでは、`Request`オブジェクトを利用してこれらのエンドポイントにアクセスし、JSONまたはXML形式のデータを取得できます。  
たとえば、News API（※APIキーが必要）を用いる場合、以下のようなコードで日本国内のトップニュースを取得できます。

**コード例：News APIでのデータ取得**

```javascript
// News API を利用して日本のトップニュースを取得する例
let apiKey = "YOUR_NEWS_API_KEY"; // 取得したAPIキーを設定
let url = `https://newsapi.org/v2/top-headlines?country=jp&apiKey=${apiKey}`;

let req = new Request(url);
let newsData = await req.loadJSON();

// newsData.articles に記事の配列が格納されています
console.log(newsData.articles);
```

また、RSSフィードの場合は、XMLを解析するライブラリを使うか、シンプルに文字列操作で処理する方法もありますが、ここではNews APIを中心に解説します。

## 8.2. ニュースソースの登録と管理：お気に入りニュースサイトの設定

**概要と重要性**

ユーザーが関心のあるニュースソースを登録できる仕組みを作成することで、パーソナライズされたニュースフィードが実現できます。Scriptableでは、`FileManager`を利用してJSON形式の設定ファイルを管理し、複数のソース（例：ニュースカテゴリや特定サイト）を扱うことが可能です。

**設定ファイル例（config.json）**

```json
{
  "sources": [
    { "name": "NHKニュース", "url": "https://www3.nhk.or.jp/news/rss.xml", "category": "国内" },
    { "name": "Reuters", "url": "http://feeds.reuters.com/reuters/topNews", "category": "国際" }
  ],
  "defaultCategory": "国内"
}
```

**コード例：設定ファイルの読み込み**

```javascript
let fm = FileManager.iCloud();
let configPath = fm.joinPath(fm.documentsDirectory(), "news_config.json");

if (!fm.fileExists(configPath)) {
  // ファイルがなければ初期設定を保存
  let defaultConfig = {
    sources: [
      { name: "NHKニュース", url: "https://www3.nhk.or.jp/news/rss.xml", category: "国内" },
      { name: "Reuters", url: "http://feeds.reuters.com/reuters/topNews", category: "国際" }
    ],
    defaultCategory: "国内"
  };
  fm.writeString(configPath, JSON.stringify(defaultConfig));
}

let config = JSON.parse(fm.readString(configPath));
console.log(config);
```

## 8.3. ニュースタイトルの表示：最新ニュースの見出し一覧

**概要と重要性**

ニュースウィジェットの基本機能は、最新ニュースの見出しを一覧表示することです。取得した記事データからタイトルとURLなどの情報を抽出し、`ListWidget`を使ってウィジェット内に整然と表示します。

**コード例：ニュースタイトル一覧ウィジェット**

```javascript
// News API のデータをもとに、ニュースタイトル一覧ウィジェットを作成
let apiKey = "YOUR_NEWS_API_KEY";
let url = `https://newsapi.org/v2/top-headlines?country=jp&apiKey=${apiKey}`;

let req = new Request(url);
let newsData = await req.loadJSON();
let articles = newsData.articles;

// ウィジェット作成
let widget = new ListWidget();
widget.backgroundColor = new Color("#ffffff");

// ウィジェット上部にタイトルを表示
let header = widget.addText("最新ニュース");
header.font = Font.boldSystemFont(16);
header.centerAlignText();
widget.addSpacer(8);

// 各記事のタイトルをリスト表示（最大5件表示）
for (let i = 0; i < Math.min(articles.length, 5); i++) {
  let article = articles[i];
  let title = widget.addText(article.title);
  title.font = Font.systemFont(14);
  title.lineLimit = 2;
  title.url = article.url; // タップで記事URLを開く
  widget.addSpacer(4);
}

if (!config.runsInWidget) {
  widget.presentMedium();
}

Script.setWidget(widget);
Script.complete();
```

**ポイント**

- 各タイトルに`url`プロパティを設定することで、タップ時に自動的に記事を外部ブラウザで開くようになります。
- 表示件数やフォント、行数などは用途に合わせて調整可能です。

## 8.4. ニュース記事のURLを開く：タップで詳細記事へアクセス

**概要と重要性**

ウィジェット内で表示されたニュースタイトルをタップすると、対応する記事のURLを自動的に外部ブラウザで開く機能を実装します。Scriptableでは、各`Text`オブジェクトに`url`プロパティを設定するだけで実現でき、ユーザーはシームレスに詳細記事へアクセスできます。

**コード例：前述のウィジェット内で各タイトルに設定済み**

```javascript
// 例：タイトルに article.url を設定
let title = widget.addText(article.title);
title.font = Font.systemFont(14);
title.lineLimit = 2;
title.url = article.url; // タップで記事を開く
```

**ポイント**

- Scriptableのウィジェットはタップ操作をサポートしており、ユーザー体験を向上させるための簡単な設定でURL連携が可能です。

## 8.5. カテゴリ別の表示：興味のあるカテゴリに絞る

**概要と重要性**

ユーザーが興味のあるカテゴリ（例：国内、国際、経済、スポーツなど）に絞ってニュースを表示できるようにすることで、効率的な情報収集が実現します。設定ファイルで定義したニュースソースに基づいて、カテゴリフィルタリングを行い、ウィジェット上に該当するニュースのみを一覧表示する実装例を示します。

**コード例：カテゴリ別フィルタリング**

```javascript
// ここでは、configで設定した defaultCategory を利用し、「国内」ニュースのみ表示する例
let defaultCategory = config.defaultCategory; // 例: "国内"

// 複数のソースからRSSやNews APIで取得した記事データ（ここでは仮のデータを利用）
let allArticles = articles.filter(article => {
  // ここでは各記事の source.name を用いて、config.sources に登録されたカテゴリと照合する例
  // 実際には、各記事にカテゴリ情報を付与する仕組みが必要です。
  for (let source of config.sources) {
    if (article.source.name.includes(source.name) && source.category === defaultCategory) {
      return true;
    }
  }
  return false;
});

// ウィジェット作成（カテゴリ別ニュース表示）
let widgetCategory = new ListWidget();
widgetCategory.backgroundColor = new Color("#ffffff");

let headerCat = widgetCategory.addText(`${defaultCategory}ニュース`);
headerCat.font = Font.boldSystemFont(16);
headerCat.centerAlignText();
widgetCategory.addSpacer(8);

for (let i = 0; i < Math.min(allArticles.length, 5); i++) {
  let article = allArticles[i];
  let title = widgetCategory.addText(article.title);
  title.font = Font.systemFont(14);
  title.lineLimit = 2;
  title.url = article.url;
  widgetCategory.addSpacer(4);
}

if (!config.runsInWidget) {
  widgetCategory.presentMedium();
}

Script.setWidget(widgetCategory);
Script.complete();
```

**ポイント**

- 実際の運用では、各記事に対してカテゴリ情報をどう付与するかがポイントです。News APIの場合、記事の`source`や`category`（オプションの場合もあり）を利用するか、あらかじめソースごとにカテゴリを設定しておく方法が考えられます。
- ユーザーがカテゴリを切り替えられるように、URLパラメータやウィジェット設定と連携する工夫も可能です。
