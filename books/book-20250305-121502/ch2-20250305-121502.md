## 2. ウィジェット作成の基礎：情報表示を自由自在にカスタマイズ

Scriptableは、iOSデバイス上でJavaScriptを使ってカスタムウィジェットを作成できる強力なツールです。この章では、Scriptableウィジェットの作成に必要な基礎知識を、ステップバイステップで解説します。情報表示の自由度を高め、日々の生活や業務を効率化するための第一歩を踏み出しましょう。

### 2.1. Hello Worldウィジェット作成：Scriptableウィジェット開発の第一歩

#### 概要と重要性

プログラミングの世界では、何か新しいことを始める際に「Hello, World!」を表示するのが慣例です。Scriptableウィジェット開発も例外ではありません。このセクションでは、最もシンプルなウィジェットを作成し、Scriptable開発の基本的な流れを理解します。この小さな成功体験は、より複雑なウィジェット開発へのモチベーションを高めるでしょう。

#### 特徴と利点

*   **シンプルさ:** わずか数行のコードで動作するウィジェットを作成できます。
*   **即時性:** コードを記述したら、すぐにウィジェットとして表示できます。
*   **基礎の理解:** ScriptableのAPIとJavaScriptの基本を学ぶための足がかりとなります。

#### 事前準備と前提条件

*   iOSデバイス（iPhoneまたはiPad）
*   Scriptableアプリのインストール
*   JavaScriptの基本的な知識（変数、関数など）

#### 基本的な使い方

1.  **Scriptableアプリを開く:** ホーム画面からScriptableアプリを起動します。
2.  **新しいスクリプトを作成:** 画面右上の「＋」ボタンをタップして、新しいスクリプトを作成します。
3.  **コードを記述:** 以下のコードをエディタに記述します。

    ```javascript
    // ウィジェットを作成
    let widget = new ListWidget();

    // テキスト要素を作成
    let text = widget.addText("Hello, World!");

    // フォントサイズを設定
    text.font = Font.mediumSystemFont(20);

    // ウィジェットを表示
    Script.setWidget(widget);
    Script.complete();
    ```

4.  **スクリプトを保存:** 画面左上の「完了」ボタンをタップし、スクリプトに名前を付けて保存します（例：HelloWorld）。
5.  **ウィジェットをホーム画面に追加:** ホーム画面を長押しし、「＋」ボタンをタップしてウィジェット追加画面を開きます。
6.  **Scriptableウィジェットを選択:** リストからScriptableを探して選択します。
7.  **作成したスクリプトを選択:** ウィジェットのサイズを選び、「ウィジェットを追加」をタップします。ウィジェットの設定画面で、先ほど保存したスクリプト（HelloWorld）を選択します。

これで、ホーム画面に「Hello, World!」と表示されたウィジェットが表示されます。

#### 実践的なテクニック

*   **背景色を変更する:** `widget.backgroundColor = new Color("#FF0000");` でウィジェットの背景色を赤に変更できます。
*   **テキストの色を変更する:** `text.textColor = new Color("#FFFFFF");` でテキストの色を白に変更できます。
*   **テキストの配置を調整する:** `text.centerAlignText();` でテキストを中央に配置できます。

#### 応用例とユースケース

*   **日付と時刻を表示する:** 現在の日付と時刻を表示するウィジェットを作成できます。
*   **簡単な計算結果を表示する:** 簡単な計算を行い、その結果を表示するウィジェットを作成できます。

#### トラブルシューティング

*   **ウィジェットが表示されない:** スクリプトが正しく保存されているか、ウィジェットの設定画面で正しいスクリプトが選択されているかを確認してください。
*   **エラーメッセージが表示される:** スクリプトに構文エラーがないかを確認してください。Scriptableはエラーメッセージを表示してくれるので、それを参考に修正します。

#### まとめと次のステップ

このセクションでは、最も基本的なウィジェットを作成し、Scriptable開発の第一歩を踏み出しました。次は、ウィジェットのデザインについて学び、見やすく使いやすいウィジェットを作成する方法を習得しましょう。

### 2.2. ウィジェットのデザイン：色、フォント、レイアウト…見やすいウィジェットの作り方

#### 概要と重要性

ウィジェットは、常にユーザーの目に触れるものです。そのため、ウィジェットのデザインは非常に重要です。色、フォント、レイアウトを適切に選択することで、情報を効果的に伝え、ユーザーエクスペリエンスを向上させることができます。このセクションでは、見やすく使いやすいウィジェットを作成するためのデザイン原則とテクニックを学びます。

#### 特徴と利点

*   **視覚的な魅力:** 美しいウィジェットは、ユーザーの満足度を高めます。
*   **情報の明確性:** 見やすいウィジェットは、情報を迅速かつ正確に伝えます。
*   **ブランドイメージの向上:** 一貫性のあるデザインは、ブランドイメージを強化します。

#### 事前準備と前提条件

*   Scriptableアプリのインストール
*   基本的なウィジェット作成の知識（2.1節を参照）
*   デザインの基本的な知識（色の組み合わせ、フォントの選び方など）

#### 基本的な使い方

1.  **ウィジェットの背景色を設定する:**

    ```javascript
    let widget = new ListWidget();
    widget.backgroundColor = new Color("#F0F0F0"); // ライトグレー
    ```

2.  **テキストの色とフォントを設定する:**

    ```javascript
    let text = widget.addText("Hello, World!");
    text.textColor = new Color("#333333"); // ダークグレー
    text.font = Font.boldSystemFont(16);
    ```

3.  **ウィジェットのレイアウトを調整する:**

    ```javascript
    widget.addSpacer(10); // スペースを追加
    let image = widget.addImage(Image.fromURL("https://example.com/image.png")); // 画像を追加
    image.imageSize = new Size(50, 50); // 画像サイズを設定
    ```

#### 実践的なテクニック

*   **色の選択:** 色はウィジェットの印象を大きく左右します。コントラスト比に注意し、見やすい色の組み合わせを選びましょう。ColorhuntなどのWebサイトで、美しいカラーパレットを見つけることができます。
*   **フォントの選択:** フォントは可読性に影響します。システムフォント（San Francisco）は可読性が高く、おすすめです。太さやサイズを調整して、情報を強調したり、階層構造を表現したりできます。
*   **レイアウトの調整:** スペーサーやスタックを使用することで、ウィジェットのレイアウトを柔軟に調整できます。`widget.addStack()` で水平または垂直のスタックを作成し、その中に要素を追加できます。
*   **角丸の設定:** `widget.cornerRadius = 10;` でウィジェットの角を丸くすることができます。
*   **グラデーション背景:** `LinearGradient()` を使用して、美しいグラデーション背景を作成できます。

    ```javascript
    let gradient = new LinearGradient();
    gradient.colors = [new Color("#FFA07A"), new Color("#FFDAB9")]; // ライトコーラルとパパイヤホイップ
    gradient.locations = [0.0, 1.0];
    widget.backgroundGradient = gradient;
    ```

#### 応用例とユースケース

*   **天気ウィジェット:** 天気アイコン、気温、降水確率などを表示するウィジェット。天気アイコンは、SF Symbolsを使用すると簡単に表示できます。
*   **株価ウィジェット:** 株価、変動率、グラフなどを表示するウィジェット。株価データは、APIから取得できます。
*   **タスク管理ウィジェット:** 未完了のタスク、締め切り、優先度などを表示するウィジェット。タスクデータは、Remindersアプリから取得できます。

#### トラブルシューティング

*   **テキストが読みにくい:** 色のコントラスト比が低い可能性があります。背景色とテキストの色を変更して、コントラスト比を高めてください。
*   **ウィジェットがごちゃごちゃしている:** 要素間のスペースが足りない可能性があります。スペーサーを追加したり、パディングを設定したりして、要素間のスペースを確保してください。
*   **画像がぼやけている:** 画像の解像度が低い可能性があります。高解像度の画像を使用するか、`image.imageSize` で画像のサイズを調整してください。

### 2.3. データの取得と表示：JSON、API、Webサイトから情報を取得する

#### 概要と重要性

ウィジェットの真価は、動的な情報を表示できることにあります。JSONデータ、API、Webサイトから情報を取得し、ウィジェットに表示することで、常に最新の情報にアクセスできます。このセクションでは、Scriptableで外部データを取得し、ウィジェットに表示する方法を学びます。

#### 特徴と利点

*   **動的な情報表示:** 常に最新の情報にアクセスできます。
*   **多様なデータソース:** JSONデータ、API、Webサイトなど、様々なデータソースから情報を取得できます。
*   **自動更新:** 定期的にデータを取得し、ウィジェットを自動更新できます。

#### 事前準備と前提条件

*   Scriptableアプリのインストール
*   基本的なウィジェット作成の知識（2.1節と2.2節を参照）
*   JSONデータの基本的な知識
*   APIの基本的な知識

#### 基本的な使い方

1.  **JSONデータを取得する:**

    ```javascript
    let url = "https://jsonplaceholder.typicode.com/todos/1"; // サンプルJSON API
    let req = new Request(url);
    let json = await req.loadJSON();

    // JSONデータから情報を抽出
    let title = json.title;
    let completed = json.completed;
    ```

2.  **APIからデータを取得する:**

    APIを利用する場合は、APIキーが必要な場合があります。APIのドキュメントをよく読み、APIキーを取得してください。

    ```javascript
    let apiKey = "YOUR_API_KEY";
    let url = `https://api.openweathermap.org/data/2.5/weather?q=Tokyo&appid=${apiKey}`; // OpenWeatherMap API
    let req = new Request(url);
    let json = await req.loadJSON();

    // APIデータから情報を抽出
    let temperature = json.main.temp;
    let description = json.weather[0].description;
    ```

3.  **Webサイトからデータを取得する:**

    ```javascript
    let url = "https://www.apple.com/"; // AppleのWebサイト
    let req = new Request(url);
    let html = await req.loadString();

    // HTMLから特定の情報を抽出 (正規表現を使用)
    let titleRegex = /<title>(.*?)<\/title>/;
    let title = html.match(titleRegex)[1];
    ```

4.  **取得したデータをウィジェットに表示する:**

    ```javascript
    let widget = new ListWidget();
    let titleText = widget.addText(title);
    titleText.font = Font.mediumSystemFont(14);

    let tempText = widget.addText(`Temperature: ${temperature}`);
    tempText.font = Font.smallSystemFont(12);

    Script.setWidget(widget);
    Script.complete();
    ```

#### 実践的なテクニック

*   **エラーハンドリング:** データの取得に失敗した場合に備えて、エラーハンドリングを行いましょう。

    ```javascript
    try {
        let req = new Request(url);
        let json = await req.loadJSON();
        // データを処理
    } catch (error) {
        console.error("Error fetching data:", error);
        widget.addText("Error: Unable to fetch data");
    }
    ```

*   **キャッシュ:** 頻繁にアクセスするデータは、キャッシュすることでパフォーマンスを向上させることができます。

    ```javascript
    let fm = FileManager.iCloud(); // iCloud Driveを使用
    let cachePath = fm.joinPath(fm.documentsDirectory(), "weather_data.json");

    if (fm.fileExists(cachePath)) {
        let cacheDate = fm.modificationDate(cachePath);
        let now = new Date();
        let diff = now.getTime() - cacheDate.getTime();
        let minutes = Math.floor(diff / (1000 * 60));

        if (minutes < 10) { // 10分以内のキャッシュを使用
            let cacheData = JSON.parse(fm.readString(cachePath));
            // キャッシュデータを使用
        } else {
            // APIからデータを取得し、キャッシュを更新
        }
    } else {
        // APIからデータを取得し、キャッシュを作成
    }
    ```

*   **日付のフォーマット:** 取得した日付データを、見やすい形式にフォーマットすることができます。

    ```javascript
    let date = new Date();
    let formatter = new DateFormatter();
    formatter.dateFormat = "yyyy-MM-dd HH:mm";
    let formattedDate = formatter.string(date);
    ```

#### 応用例とユースケース

*   **ニュースウィジェット:** 最新のニュース記事のタイトル、概要、ソースなどを表示するウィジェット。
*   **為替レートウィジェット:** 最新の為替レートを表示するウィジェット。
*   **GitHubウィジェット:** GitHubのリポジトリのスター数、フォーク数、Issue数などを表示するウィジェット。

#### トラブルシューティング

*   **データを取得できない:** URLが正しいか、APIキーが有効か、インターネット接続があるかを確認してください。
*   **JSONデータがパースできない:** JSONデータの形式が正しいかを確認してください。JSONLintなどのWebサイトで、JSONデータの検証を行うことができます。
*   **Webサイトからデータを抽出できない:** 正規表現が正しいかを確認してください。正規表現のテストツールを使用すると、正規表現の動作を確認できます。

### 2.4. ウィジェットのリフレッシュ：自動更新を設定して常に最新情報を表示

#### 概要と重要性

ウィジェットの自動更新は、常に最新の情報を表示するために不可欠です。Scriptableでは、指定した間隔でウィジェットを自動更新するように設定できます。このセクションでは、ウィジェットの自動更新を設定する方法を学びます。

#### 特徴と利点

*   **常に最新の情報:** ユーザーは常に最新の情報にアクセスできます。
*   **手間いらず:** ユーザーが手動でウィジェットを更新する必要はありません。
*   **自動化:** 情報収集のプロセスを自動化できます。

#### 事前準備と前提条件

*   Scriptableアプリのインストール
*   基本的なウィジェット作成の知識（2.1節、2.2節、2.3節を参照）
*   ウィジェットが外部からデータを取得できる状態

#### 基本的な使い方

1.  **`widget.refreshAfterDate` を設定する:**

    ```javascript
    let widget = new ListWidget();
    // ... ウィジェットの内容を作成 ...

    // 次の更新日時を設定 (例: 1時間後)
    let nextUpdate = Date.now() + (60 * 60 * 1000);
    widget.refreshAfterDate = new Date(nextUpdate);

    Script.setWidget(widget);
    Script.complete();
    ```

2.  **`Script.setWidget` を呼び出す:**

    `Script.setWidget` を呼び出すことで、ウィジェットを更新します。

#### 実践的なテクニック

*   **更新間隔の調整:** 更新間隔は、ウィジェットの種類やデータの変動頻度に応じて調整してください。頻繁に変動するデータの場合は短い間隔で、そうでない場合は長い間隔で更新すると、バッテリー消費を抑えることができます。
*   **バッテリー消費の最適化:** 自動更新はバッテリーを消費する可能性があります。バッテリー消費を抑えるために、以下の点に注意してください。
    *   必要な場合にのみ自動更新を使用する。
    *   更新間隔を適切に設定する。
    *   データの取得量を最小限に抑える。
*   **更新タイミングの制御:** `widget.refreshAfterDate` は、あくまで推奨される更新日時です。システムは、バッテリー残量やネットワーク状況に応じて、更新を遅らせる場合があります。より厳密に更新タイミングを制御したい場合は、Pushcutなどの外部ツールを使用することを検討してください。

#### 応用例とユースケース

*   **天気ウィジェット:** 1時間ごとに天気情報を更新する。
*   **株価ウィジェット:** 15分ごとに株価情報を更新する。
*   **ニュースウィジェット:** 30分ごとにニュース記事を更新する。

#### トラブルシューティング

*   **ウィジェットが自動更新されない:**
    *   `widget.refreshAfterDate` が正しく設定されているかを確認してください。
    *   Scriptableアプリがバックグラウンドで実行されていることを確認してください。
    *   バッテリー節約モードが有効になっている場合は、自動更新が制限されることがあります。
*   **ウィジェットの更新頻度が高すぎる:**
    *   更新間隔を長くしてください。
    *   不要なデータの取得を避けてください。

### 2.5. ウィジェットタップ時のアクション：他のアプリを起動したり、URLを開いたり…

#### 概要と重要性

ウィジェットは、単に情報を表示するだけでなく、他のアプリを起動したり、特定のURLを開いたりするトリガーとしても機能します。ウィジェットをタップしたときに特定のアクションを実行することで、ユーザーエクスペリエンスを向上させ、ウィジェットの利便性を高めることができます。このセクションでは、ウィジェットタップ時のアクションを設定する方法を学びます。

#### 特徴と利点

*   **インタラクティブ性:** ウィジェットが単なる情報表示デバイスから、インタラクティブなツールへと進化します。
*   **効率的な操作:** ウィジェットから直接、関連するアプリやWebサイトを開くことができます。
*   **カスタマイズ性:** ウィジェットのタップアクションを自由にカスタマイズできます。

#### 事前準備と前提条件

*   Scriptableアプリのインストール
*   基本的なウィジェット作成の知識（2.1節、2.2節、2.3節、2.4節を参照）
*   起動したいアプリのURLスキーム、または開きたいWebサイトのURL

#### 基本的な使い方

1.  **`widget.url` を設定する:**

    ```javascript
    let widget = new ListWidget();
    // ... ウィジェットの内容を作成 ...

    // ウィジェットをタップしたときに開くURLを設定
    widget.url = "https://www.google.com/"; // GoogleのWebサイトを開く

    Script.setWidget(widget);
    Script.complete();
    ```

2.  **特定のアプリを起動する:**

    URLスキームを利用して、特定のアプリを起動することができます。URLスキームは、アプリによって異なります。例えば、リマインダーアプリを起動する場合は、`x-apple-reminderkit://` を使用します。

    ```javascript
    let widget = new ListWidget();
    // ... ウィジェットの内容を作成 ...

    // リマインダーアプリを起動
    widget.url = "x-apple-reminderkit://";

    Script.setWidget(widget);
    Script.complete();
    ```

#### 実践的なテクニック

*   **複数のタップ領域を設定する:**

    `widget.addText()` や `widget.addImage()` で追加した要素ごとに、個別のタップアクションを設定することができます。

    ```javascript
    let widget = new ListWidget();

    let titleText = widget.addText("Google");
    titleText.url = "https://www.google.com/";

    widget.addSpacer(5);

    let appleText = widget.addText("Apple");
    appleText.url = "https://www.apple.com/";

    Script.setWidget(widget);
    Script.complete();
    ```

*   **URLスキームの活用:**

    様々なアプリのURLスキームを調べて、ウィジェットから直接起動できるようにすることで、ウィジェットの利便性を高めることができます。URLスキームの一覧は、Web上で検索することができます。
*   **パラメータ付きURL:**

    URLにパラメータを付与することで、アプリを起動する際に特定の操作を実行させることができます。例えば、メモアプリを起動して、新しいメモを作成したり、特定のメモを開いたりすることができます。

#### 応用例とユースケース

*   **タスク管理ウィジェット:** タスクをタップすると、タスク管理アプリが起動し、そのタスクの詳細画面が開く。
*   **ニュースウィジェット:** ニュース記事のタイトルをタップすると、ブラウザが起動し、そのニュース記事の全文が表示される。
*   **音楽ウィジェット:** 曲名をタップすると、音楽アプリが起動し、その曲が再生される。

#### トラブルシューティング

*   **ウィジェットをタップしても何も起こらない:**
    *   `widget.url` が正しく設定されているかを確認してください。
    *   URLスキームが正しいかを確認してください。
    *   iOSのバージョンによっては、URLスキームが動作しない場合があります。
*   **アプリが起動しない:**
    *   URLスキームが正しいかを確認してください。
    *   アプリがインストールされているかを確認してください。

#### まとめと次のステップ

このセクションでは、ウィジェットタップ時のアクションを設定する方法を学びました。ウィジェットをタップしたときに特定のアクションを実行することで、ウィジェットの利便性を高め、ユーザーエクスペリエンスを向上させることができます。

この章で、Scriptableウィジェット作成の基礎を学びました。次の章では、より高度なウィジェットの作成方法を学び、Scriptableの可能性をさらに広げていきましょう。
