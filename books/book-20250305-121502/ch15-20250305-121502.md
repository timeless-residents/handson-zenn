# 15. 自動化レシピ集：実用的な Scriptable スクリプト例

この章では、Scriptable を使って iOS 上の日常作業を自動化するための具体的なスクリプト例を紹介します。ファイルの読み書き、Web API へのアクセス、ウィジェットの作成など、Scriptable の機能を活用することで、手間のかかるルーチンワークを効率化し、クリエイティブな作業に集中できる環境を構築できます。

## 15.1. 毎日のタスクを自動化：日報作成・TODO リスト整理

### 15.1.1. 概要と重要性

日々の業務報告や TODO リストの整理は、手作業だと時間がかかるうえミスも発生しがちです。Scriptable なら、iCloud 上のファイル操作機能を活用して、日報テンプレートの自動作成や TODO リストの整理を簡単に自動化できます。

### 15.1.2. 日報自動作成スクリプト

以下のスクリプトは、今日の日付に基づいた Markdown 形式の日報テンプレートを作成し、iCloud ドキュメントフォルダに保存します。

```javascript
// 日報自動作成 Scriptable スクリプト例

let fm = FileManager.iCloud();
let dir = fm.documentsDirectory();
let today = new Date();
let dateStr = today.toISOString().split("T")[0];  // "YYYY-MM-DD" の形式

let reportContent = `## ${dateStr} 日報

**本日の業務内容:**

* [ここに具体的な業務内容を記述]

**課題と改善点:**

* [ここに課題と改善点を記述]

**明日の予定:**

* [ここに明日の予定を記述]
`;

let filename = "daily_report_" + dateStr + ".md";
let filePath = fm.joinPath(dir, filename);
fm.writeString(filePath, reportContent);
console.log(`日報が ${filename} に作成されました。`);

if (!config.runsInWidget) {
  QuickLook.present(filePath);
}
```

### 15.1.3. TODO リスト自動整理スクリプト

次のスクリプトは、iCloud の「todo.txt」ファイルから完了タスク（"[x]" で始まる行）を抽出し、別ファイル（"done.txt"）に移動、未完了タスクは元ファイルに残す例です。

```javascript
// TODO リスト自動整理 Scriptable スクリプト例

let fm = FileManager.iCloud();
let dir = fm.documentsDirectory();
let todoPath = fm.joinPath(dir, "todo.txt");

if (!fm.fileExists(todoPath)) {
  console.log("todo.txt が存在しません。");
} else {
  let content = fm.readString(todoPath);
  let lines = content.split("\n");
  let doneTasks = [];
  let remainingTasks = [];
  
  for (let line of lines) {
    line = line.trim();
    if (line.startsWith("[x]")) {
      doneTasks.push(line);
    } else if (line.length > 0) {
      remainingTasks.push(line);
    }
  }
  
  // 完了したタスクを done.txt に追記
  let donePath = fm.joinPath(dir, "done.txt");
  let doneContent = fm.fileExists(donePath) ? fm.readString(donePath) + "\n" : "";
  doneContent += doneTasks.join("\n");
  fm.writeString(donePath, doneContent);
  
  // 未完了タスクを todo.txt に上書き保存
  fm.writeString(todoPath, remainingTasks.join("\n"));
  
  console.log("TODO リストが整理されました。完了タスクは done.txt に移動しました。");
}
```

### 15.1.4. 実践的なテクニック

- **定期実行:** Scriptable は iOS のショートカットから呼び出せるため、毎朝・毎晩の自動実行が可能です。
- **エラーハンドリング:** 作成したファイルの存在チェックやエラーメッセージの表示を適宜追加して、堅牢性を向上させましょう。

## 15.2. 情報収集の自動化：ニュースチェック・株価監視

### 15.2.1. 概要と重要性

最新情報は、ビジネスや投資判断に欠かせません。Scriptable を利用すれば、Web API からニュースや株価情報を取得し、ウィジェット表示やログ出力などで常に最新情報をチェックできます。

### 15.2.2. 株価監視スクリプト例

以下の例は、Finnhub API（※APIキーが必要）を利用して、Apple (AAPL) の株価を取得しコンソールに表示するものです。

```javascript
// 株価監視 Scriptable スクリプト例
let symbol = "AAPL";
let apiKey = "YOUR_API_KEY"; // Finnhub API のキーを設定
let url = `https://finnhub.io/api/v1/quote?symbol=${symbol}&token=${apiKey}`;

let req = new Request(url);
let data = await req.loadJSON();
let currentPrice = data.c;
console.log(`現在の ${symbol} の株価: ${currentPrice} USD`);
```

### 15.2.3. ニュース収集スクリプト例

News API（※APIキーが必要）を使って日本国内のトップニュースを取得し、最新の記事タイトルをコンソールに表示する例です。

```javascript
// ニュース収集 Scriptable スクリプト例
let newsApiKey = "YOUR_NEWS_API_KEY";
let newsUrl = `https://newsapi.org/v2/top-headlines?country=jp&apiKey=${newsApiKey}`;

let newsReq = new Request(newsUrl);
let newsData = await newsReq.loadJSON();
let articles = newsData.articles;

console.log("最新ニュースの見出し：");
for (let i = 0; i < Math.min(articles.length, 5); i++) {
  console.log("- " + articles[i].title);
}
```

### 15.2.4. 実践的なテクニック

- **定期実行:** iOS のショートカットと連携して、一定間隔で情報収集スクリプトを実行可能です。
- **閾値監視:** 株価が特定の数値を超えた場合にアラートを発するなど、条件分岐を追加できます。

## 15.3. 写真整理の自動化：アルバム作成・リサイズ

### 15.3.1. 概要と重要性

撮影した写真は時間とともに大量に溜まります。Scriptable の FileManager を使えば、iCloud ドキュメント内の画像ファイルを自動でリサイズしたり、日付別に整理したりすることが可能です。

### 15.3.2. 画像リサイズスクリプト例

以下は、Scriptable の DrawContext を利用して画像を 800×600 ピクセルにリサイズし、保存する例です。

```javascript
// 画像リサイズ Scriptable スクリプト例
let fm = FileManager.iCloud();
let dir = fm.documentsDirectory();
let imagePath = fm.joinPath(dir, "image.jpg");

if (fm.fileExists(imagePath)) {
  let img = await Image.fromFile(imagePath);
  let dc = new DrawContext();
  dc.size = new Size(800, 600);
  // 背景塗りつぶし（任意）
  dc.setFillColor(new Color("#ffffff"));
  dc.fillRect(new Rect(0, 0, 800, 600));
  // 画像を指定サイズで描画
  dc.drawImageInRect(img, new Rect(0, 0, 800, 600));
  let resizedImage = dc.getImage();
  let outputPath = fm.joinPath(dir, "resized_image.jpg");
  fm.writeImage(outputPath, resizedImage);
  console.log("画像が 800x600 にリサイズされました。");
} else {
  console.log("画像ファイルが見つかりません。");
}
```

### 15.3.3. 写真整理（更新日時による振り分け）スクリプト例

Exif 情報が直接利用できない場合は、ファイルの最終更新日時を基準に整理する方法です。

```javascript
// 写真整理 Scriptable スクリプト例
let fm = FileManager.iCloud();
let dir = fm.documentsDirectory();
let imagesDir = fm.joinPath(dir, "images");
let organizedDir = fm.joinPath(dir, "organized_photos");

// 整理先ディレクトリを作成
fm.createDirectory(organizedDir, true);

let files = fm.listContents(imagesDir);
for (let file of files) {
  if (file.toLowerCase().endsWith(".jpg") || file.toLowerCase().endsWith(".png")) {
    let filePath = fm.joinPath(imagesDir, file);
    let modDate = fm.modificationDate(filePath);
    let year = modDate.getFullYear();
    let month = ("0" + (modDate.getMonth() + 1)).slice(-2);
    let day = ("0" + modDate.getDate()).slice(-2);
    let targetDir = fm.joinPath(organizedDir, `${year}/${month}/${day}`);
    fm.createDirectory(targetDir, true);
    let newPath = fm.joinPath(targetDir, file);
    fm.move(filePath, newPath);
    console.log(`${file} を ${targetDir} に移動しました。`);
  }
}
```

### 15.3.4. 実践的なテクニック

- **高度な整理:** 顔認識や類似画像検出を組み合わせると、より高度な自動整理が実現できます（別途ライブラリ連携が必要）。
- **メタデータの活用:** Exif 以外のメタデータを利用する場合は、対応ライブラリとの連携を検討します。

## 15.4. リマインダー連携によるタスク管理自動化

### 15.4.1. 概要と重要性

定期的なタスクの登録は、作業の見落としを防ぎ、計画的な業務遂行に役立ちます。Scriptable は直接 Reminders への登録 API を持っていませんが、URL スキームや Shortcuts 経由で連携することが可能です。

### 15.4.2. URL スキームを使ったタスク登録例

以下は、Scriptable から Reminders アプリへタスク登録画面を開く例です。タスク名を URL エンコードして、Reminders の新規登録画面を起動します。

```javascript
// Reminders 新規登録画面を開く例
let taskTitle = "毎朝8時にコーヒーを飲む";
let encodedTitle = encodeURIComponent(taskTitle);
let url = "x-apple-reminders://new?title=" + encodedTitle;
Safari.open(url);
```

※この方法は Reminders アプリ側の動作に依存するため、事前に動作確認を行ってください。より高度な連携には、iOS ショートカットと組み合わせる方法がおすすめです。

### 15.4.3. 実践的なテクニック

- **ショートカット連携:** Scriptable の結果を Shortcuts 経由で Reminders に登録するなど、両者を組み合わせることで柔軟なタスク管理が可能です。
- **日付計算:** Scriptable の Date オブジェクトで動的に期日を計算し、タスク情報に組み込むと便利です。

## 15.5. Slack 連携：指定チャンネルへ定期的に通知を送信

### 15.5.1. 概要と重要性

Slack はチーム内の情報共有ツールとして広く使われています。Scriptable の Request オブジェクトを使えば、Webhook 経由で Slack へメッセージを自動送信でき、システム監視や日報、通知の自動化に非常に有用です。

### 15.5.2. Slack 通知スクリプト例

以下の例は、Slack の Webhook URL に対してメッセージを送信する Scriptable スクリプトです。

```javascript
// Slack 連携 Scriptable スクリプト例
let webhookUrl = "YOUR_SLACK_WEBHOOK_URL"; // 取得した Webhook URL を設定
let message = "これは Scriptable から自動送信されたメッセージです！";

let req = new Request(webhookUrl);
req.method = "POST";
req.headers = { "Content-Type": "application/json" };
req.body = JSON.stringify({ text: message });

let result = await req.loadString();
console.log("Slack 通知送信結果: " + result);
```

### 15.5.3. 実践的なテクニック

- **定期実行:** Scriptable のスクリプトは、iOS ショートカットやカレンダー連携で定期実行できるため、定期通知の自動化が容易です。
- **環境変数の活用:** セキュリティのため、Webhook URL などは外部管理（例えば、Keychain や環境変数）を検討しましょう。
- **メッセージフォーマット:** Slack のメッセージは JSON で自由にカスタマイズできるため、添付画像やリッチテキストを組み合わせた通知も実装可能です。
