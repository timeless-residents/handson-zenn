## 14. Siriショートカット連携：音声でScriptableを操作

### 14.1. Siriショートカットの設定：ScriptableスクリプトをSiriに登録

**概要と重要性**

SiriショートカットとScriptableを連携させることで、iPhoneやiPadの機能を音声でコントロールできるようになります。これにより、ボタン操作なしで、より自然な形でScriptableのスクリプトを実行し、日常の様々なタスクを自動化することが可能になります。朝の天気予報、リマインダーの追加、スマートホームデバイスの操作など、アイデア次第で様々な自動化を実現できます。

**特徴と利点**

*   **ハンズフリー操作:** 声だけでスクリプトを実行できるため、手が離せない状況でも便利です。
*   **カスタマイズ性:** Scriptableで作成したスクリプトを自由にSiriに登録できるため、自分だけの自動化を実現できます。
*   **直感的な操作:** 音声コマンドは、ボタン操作よりも直感的で覚えやすいことが多いです。
*   **アクセシビリティ:** 視覚障碍者の方など、画面操作が難しい方にも利用しやすいインターフェースを提供します。

**事前準備と前提条件**

*   **Scriptableアプリのインストール:** App StoreからScriptableアプリをインストールしてください。
*   **Siriの有効化:** iPhoneまたはiPadの設定アプリでSiriが有効になっていることを確認してください。
*   **Scriptableスクリプトの作成:** Siriから実行したいScriptableスクリプトを事前に作成しておく必要があります。 簡単な例として、現在時刻を表示するスクリプトを作成してみましょう。

```javascript
let now = new Date();
let formatter = new DateFormatter();
formatter.dateFormat = "yyyy-MM-dd HH:mm:ss";
let timeString = formatter.string(now);

let alert = new Alert();
alert.title = "現在時刻";
alert.message = timeString;
alert.addCancelAction("OK");
alert.presentAlert();
```

**基本的な使い方**

1.  **Scriptableでスクリプトを作成または準備します。** 上記の時刻表示スクリプトや、既存のスクリプトを利用できます。
2.  **Scriptableアプリを開き、Siriショートカットに登録したいスクリプトを選択します。**
3.  **スクリプトエディタ画面で、右上の共有ボタン（□に↑マーク）をタップします。**
4.  **共有シートから「Siriショートカットに追加」を選択します。** もし表示されない場合は、共有シートの一番下にある「アクションを編集」をタップし、「Siriショートカットに追加」をオンにしてください。
5.  **Siriショートカットの設定画面が表示されます。** ここで、このスクリプトを実行するための音声コマンドを登録します。（次のセクションで詳しく説明します）
6.  **画面下部の赤い録音ボタンをタップして、Siriに話しかける言葉を録音します。** 例えば、「スクリプト実行」のような簡単な言葉が良いでしょう。
7.  **録音を終えたら、「完了」をタップします。**

これで、ScriptableスクリプトがSiriに登録されました。

**実践的なテクニック**

*   **ショートカット名を変更する:** デフォルトでは、スクリプト名がショートカット名として使用されます。より覚えやすく、Siriに認識されやすい名前に変更することをおすすめします。Siriショートカットの設定画面で、ショートカット名をタップして変更できます。
*   **Siriからの応答をカスタマイズする:** Scriptableスクリプト内で、Siriに何を話させるかを制御できます。`Speech`オブジェクトを利用すると、スクリプトの実行結果を音声でフィードバックさせることができます。（4.4で詳しく説明します）
*   **ショートカットアプリでより複雑な処理を組み合わせる:** Scriptableで実行するスクリプトをSiriショートカットから呼び出すだけでなく、Siriショートカットアプリ自体で他のアクションを組み合わせることも可能です。例えば、Scriptableで取得した天気情報を元に、傘を持っていくかどうかをSiriに判断させることができます。

**応用例とユースケース**

*   **毎朝のニュースの読み上げ:** 特定のニュースサイトから記事をスクレイピングし、Siriに読み上げさせる。
*   **スマートホームデバイスの操作:** Philips Hueなどのスマート電球を音声で操作する。
*   **タスク管理:** Remember The MilkやTodoistなどのタスク管理サービスに、音声でタスクを追加する。
*   **睡眠記録:** 睡眠時間や起床時間を記録し、Googleスプレッドシートに自動的に書き込む。
*   **交通状況の確認:** 自宅から職場までの交通状況を確認し、所要時間をSiriに読み上げさせる。

**トラブルシューティング**

*   **Siriがスクリプトを認識しない:**
    *   録音した音声コマンドが、Siriに正しく認識されているか確認してください。
    *   周囲の騒音が大きいと、Siriが正しく認識できない場合があります。静かな場所で試してみてください。
    *   音声コマンドを別の言葉に変更してみるのも有効です。
*   **スクリプトがエラーで停止する:**
    *   Scriptableアプリでスクリプトを直接実行し、エラーがないか確認してください。
    *   Siriから実行する場合と、直接実行する場合で、動作が異なる場合があります。Siriから渡される引数などを考慮して、スクリプトを修正してください。
*   **Scriptableのアクセス許可:**
    *   Scriptableが、必要な情報（位置情報、連絡先など）にアクセスする許可を持っているか確認してください。設定アプリの「プライバシー」セクションで確認できます。

**まとめと次のステップ**

SiriショートカットとScriptableの連携は、日々のタスクを自動化するための強力なツールです。まずは簡単なスクリプトをSiriに登録し、音声で実行することから始めてみましょう。慣れてきたら、より複雑なスクリプトや、他のアプリとの連携に挑戦してみてください。次のセクションでは、Siriに話しかける言葉を登録する方法について詳しく解説します。

### 14.2. 音声コマンドの登録：Siriに話しかける言葉を登録

**概要と重要性**

Siriに登録する音声コマンドは、Scriptableスクリプトを実行するためのトリガーとなります。覚えやすく、Siriに認識されやすい言葉を選ぶことが重要です。また、複数のスクリプトをSiriに登録する場合、それぞれ異なる音声コマンドを設定する必要があります。

**特徴と利点**

*   **自由なカスタマイズ:** 自分の好きな言葉を音声コマンドとして登録できます。
*   **覚えやすさ:** よく使う言葉や、関連性の高い言葉を音声コマンドにすることで、覚えやすくなります。
*   **直感的な操作:** 音声コマンドは、ボタン操作よりも直感的で、自然な形でスクリプトを実行できます。

**事前準備と前提条件**

*   **Scriptableスクリプトの登録:** 前のセクションで説明したように、Siriに実行させたいScriptableスクリプトを事前に登録しておく必要があります。

**基本的な使い方**

1.  **Siriショートカットアプリを開きます。** (または設定アプリ -> Siriと検索 -> すべてのショートカット)
2.  **Siriに登録したScriptableスクリプトを選択します。**
3.  **「Siriに頼むときの言葉」と表示されている部分をタップします。**
4.  **画面下部の赤い録音ボタンをタップして、Siriに話しかける言葉を録音します。**
5.  **録音を終えたら、「完了」をタップします。**

**実践的なテクニック**

*   **短いフレーズを使う:** 長すぎるフレーズは、Siriに認識されにくい場合があります。できるだけ短いフレーズを使うように心がけましょう。
*   **明確な発音:** Siriに正しく認識してもらうために、明確な発音で録音しましょう。
*   **同音異義語に注意:** 同音異義語（例: 「雨」と「飴」）は、Siriが誤認識する可能性があります。文脈から判断できるように、複数の単語で構成されたフレーズを使うと、誤認識を防ぐことができます。
*   **エイリアスを設定する:** Siriショートカットアプリでは、同じスクリプトに対して複数の音声コマンド（エイリアス）を設定できます。これにより、異なる言い方でも同じスクリプトを実行できるようになります。
*   **絵文字を使用する:** 音声コマンドに絵文字を含めることはできませんが、ショートカットの名前には絵文字を含めることができます。絵文字を使うことで、ショートカットを視覚的に区別しやすくなります。

**応用例とユースケース**

*   **スマートホームの操作:**
    *   「電気をつけて」でリビングの照明を点灯。
    *   「エアコン暖房」でエアコンを暖房モードに設定。
*   **情報取得:**
    *   「今日の天気」で今日の天気予報を取得。
    *   「株価チェック」で指定した銘柄の株価を取得。
*   **タスク管理:**
    *   「買い物リスト追加」で買い物リストにアイテムを追加。
    *   「リマインダーセット」でリマインダーを設定。
*   **時間の記録**
    *   「作業開始」で作業開始時間を記録
    *   「休憩開始」で休憩時間を記録

**トラブルシューティング**

*   **Siriが音声コマンドを認識しない:**
    *   録音した音声コマンドが、Siriに正しく認識されているか確認してください。
    *   周囲の騒音が大きいと、Siriが正しく認識できない場合があります。静かな場所で試してみてください。
    *   音声コマンドを別の言葉に変更してみるのも有効です。
    *   Siriの設定で、言語が正しく設定されているか確認してください。
*   **Siriが間違ったスクリプトを実行する:**
    *   複数のスクリプトに同じ音声コマンドが登録されていないか確認してください。
    *   Siriショートカットアプリで、音声コマンドとスクリプトの紐付けが正しいか確認してください。

**まとめと次のステップ**

Siriに登録する音声コマンドは、Scriptableスクリプトを快適に利用するための重要な要素です。覚えやすく、Siriに認識されやすい言葉を選ぶように心がけましょう。次のセクションでは、SiriからScriptableに情報を渡す方法について解説します。

### 14.3. 変数の受け渡し：SiriからScriptableに情報を渡す

**概要と重要性**

SiriからScriptableに情報を渡すことで、スクリプトの動作をより柔軟に制御できるようになります。例えば、Siriに「〇〇を買い物リストに追加して」と話しかけた場合、「〇〇」の部分をScriptableに変数として渡すことができます。これにより、同じスクリプトでも、Siriに話しかける内容によって異なる動作をさせることが可能になります。

**特徴と利点**

*   **柔軟な制御:** Siriからの入力に基づいて、スクリプトの動作を動的に変更できます。
*   **再利用性:** 同じスクリプトを、異なる入力で使用できます。
*   **対話的な操作:** Siriとの対話を通じて、より複雑な処理を実行できます。

**事前準備と前提条件**

*   **Scriptableスクリプトの準備:** Siriから変数を受け取るように、Scriptableスクリプトを修正する必要があります。
*   **Siriショートカットの設定:** Siriショートカットアプリで、Scriptableスクリプトに値を渡すように設定する必要があります。

**基本的な使い方**

1.  **Scriptableスクリプトを修正します。** `args.plainTexts`または`args.numbers`を使用して、Siriから渡される引数を受け取ります。

```javascript
// Siriから渡されるテキストを受け取る
let inputText = args.plainTexts[0];

// もしテキストが渡されなかった場合は、デフォルト値を設定する
if (!inputText) {
  inputText = "デフォルトのテキスト";
}

let alert = new Alert();
alert.title = "Siriからの入力";
alert.message = inputText;
alert.addCancelAction("OK");
alert.presentAlert();
```

2.  **Siriショートカットアプリを開き、Scriptableスクリプトを選択します。**
3.  **「入力を受け取る」オプションが有効になっていることを確認します。** 有効になっていない場合は、オンにしてください。
4.  **「スクリプト」アクションの下にある「入力タイプ」で、Scriptableに渡したいデータの種類を選択します。** 例えば、テキストを渡したい場合は「テキスト」を選択します。
5.  **Siriに話しかける言葉に、変数として渡したい部分を含めます。** 例えば、「〇〇を買い物リストに追加して」という言葉を登録する場合、「〇〇」の部分が変数となります。 Siriショートカットアプリの画面では、この「〇〇」の部分が `<入力を求める>` のように表示されます。

**実践的なテクニック**

*   **複数の引数を受け取る:** `args.plainTexts`や`args.numbers`は配列なので、複数の引数を受け取ることができます。Siriショートカットアプリで、複数の入力をScriptableスクリプトに渡すように設定してください。
*   **引数の型変換:** Siriから渡される引数は、常に文字列型です。数値として扱いたい場合は、`Number()`関数を使って型変換する必要があります。
*   **デフォルト値を設定する:** Siriから引数が渡されなかった場合に備えて、デフォルト値を設定しておくことをおすすめします。
*   **条件分岐:** Siriから渡される引数に基づいて、スクリプトの動作を分岐させることができます。`if`文や`switch`文を使って、条件分岐を実装してください。
*   **辞書を使用する:** Siriから渡される引数を、辞書（オブジェクト）として受け取ることもできます。これにより、引数の名前を指定して、値を取得することができます。

**応用例とユースケース**

*   **タイマー設定:** 「〇〇分タイマー」で指定した時間でタイマーを設定する。
*   **メモの作成:** 「〇〇というメモを作成」で指定した内容のメモを作成する。
*   **検索:** 「〇〇を検索」で指定したキーワードでWeb検索を行う。
*   **地図の表示:** 「〇〇への経路を表示」で指定した場所への経路を地図アプリで表示する。
*   **翻訳:** 「〇〇を英語に翻訳」で指定したテキストを英語に翻訳する。

**トラブルシューティング**

*   **Scriptableが引数を受け取れない:**
    *   Siriショートカットアプリで、「入力を受け取る」オプションが有効になっているか確認してください。
    *   Scriptableスクリプトで、`args.plainTexts`や`args.numbers`を使って引数を受け取っているか確認してください。
    *   Siriショートカットアプリで、正しい入力タイプを選択しているか確認してください。
*   **引数の型が異なる:**
    *   Siriから渡される引数は常に文字列型なので、必要に応じて型変換を行ってください。
*   **Siriが変数部分を認識しない:**
    *   Siriに話しかける言葉に、変数として渡したい部分を明確に含めているか確認してください。
    *   Siriショートカットアプリで、変数部分が`<入力を求める>`のように表示されているか確認してください。

**まとめと次のステップ**

SiriからScriptableに情報を渡すことで、スクリプトの可能性を大きく広げることができます。様々な情報をSiriから受け取り、スクリプトの動作を柔軟に制御してみてください。次のセクションでは、音声による結果の読み上げについて解説します。

### 14.4. 音声による結果の読み上げ：Siriに結果を読み上げてもらう

**概要と重要性**

Scriptableで処理した結果をSiriに読み上げてもらうことで、視覚的に情報を見ることができない状況でも、結果を知ることができます。運転中や料理中など、手が離せない状況で特に便利です。

**特徴と利点**

*   **ハンズフリーでの情報取得:** 画面を見なくても、音声で結果を知ることができます。
*   **アクセシビリティ:** 視覚障碍者の方など、画面操作が難しい方にも利用しやすいインターフェースを提供します。
*   **自然な情報伝達:** 音声による情報伝達は、視覚的な情報伝達よりも自然で、理解しやすい場合があります。

**事前準備と前提条件**

*   **Scriptableスクリプトの準備:** Siriに読み上げさせたい結果を、文字列としてScriptableスクリプト内で生成する必要があります。

**基本的な使い方**

1.  **Scriptableスクリプト内で、`Speech`オブジェクトを作成します。**
2.  **`Speech`オブジェクトの`speak()`メソッドを使って、Siriに読み上げさせたい文字列を指定します。**

```javascript
let result = "今日の天気は晴れです。最高気温は25度、最低気温は15度です。";

let speech = Speech.create();
speech.speak(result);
```

3.  **Siriショートカットアプリで、Scriptableスクリプトを実行するアクションを追加します。**

**実践的なテクニック**

*   **言語と声の調整:** `Speech`オブジェクトのプロパティを使って、読み上げの言語や声の種類、速度などを調整できます。

```javascript
let speech = Speech.create();
speech.lang = "ja-JP"; // 日本語
speech.voice = "Kyoko"; // 声の種類
speech.rate = 0.5; // 読み上げ速度 (0.0 - 1.0)
speech.speak(result);
```

*   **エラーハンドリング:** `Speech`オブジェクトの`speak()`メソッドは、エラーが発生した場合に例外をスローします。`try-catch`ブロックを使って、エラーハンドリングを行いましょう。

```javascript
try {
  let speech = Speech.create();
  speech.speak(result);
} catch (error) {
  console.error("音声読み上げエラー:", error);
}
```

*   **長い文章の分割:** 長すぎる文章を一度に読み上げさせると、聞き取りにくくなる場合があります。文章を適切な長さに分割し、複数回に分けて読み上げさせることを検討してください。
*   **感情表現:** `Speech`オブジェクトでは、感情を込めた音声合成は直接サポートされていませんが、表現豊かな言葉選びや、間（ま）を置くことで、ある程度の感情表現を再現できます。
*   **テキストの整形:** 読み上げやすいように、テキストを整形することを意識しましょう。例えば、数字や記号は、読みやすいように言葉で表現したり、不要な情報を削除したりするなどの工夫が必要です。

**応用例とユースケース**

*   **毎朝のニュースの読み上げ:** 特定のニュースサイトから記事をスクレイピングし、Siriに読み上げさせる。
*   **交通状況の確認:** 自宅から職場までの交通状況を確認し、所要時間をSiriに読み上げさせる。
*   **リマインダーの読み上げ:** リマインダーの内容をSiriに読み上げさせる。
*   **メールの読み上げ:** 新着メールの件名や送信者をSiriに読み上げさせる。
*   **スマートホームの状態通知:** スマートホームデバイスの状態（例：照明のON/OFF、ドアの開閉状況）をSiriに読み上げさせる。

**トラブルシューティング**

*   **Siriが音声を読み上げない:**
    *   iPhoneまたはiPadの音量がミュートになっていないか確認してください。
    *   Scriptableアプリに、マイクへのアクセス許可が付与されているか確認してください。
    *   `Speech`オブジェクトの`speak()`メソッドが正しく呼び出されているか確認してください。
    *   エラーハンドリングを行い、エラーが発生していないか確認してください。
*   **音声が途切れる:**
    *   ネットワーク環境が不安定な場合、音声が途切れることがあります。安定したネットワーク環境で試してください。
    *   `Speech`オブジェクトの`rate`プロパティを調整し、読み上げ速度を遅くしてみてください。
*   **音声が聞き取りにくい:**
    *   `Speech`オブジェクトの`voice`プロパティを調整し、別の声の種類を試してみてください。
    *   読み上げさせるテキストを整形し、より聞き取りやすい表現に修正してください。

**まとめと次のステップ**

Scriptableで処理した結果をSiriに読み上げてもらうことで、より便利で快適な自動化を実現できます。様々な情報を音声で取得し、生活を豊かにしてみてください。次のセクションでは、ハンズフリー操作について解説します。

### 14.5. ハンズフリー操作：運転中や料理中でもScriptableを操作

**概要と重要性**

SiriショートカットとScriptableを組み合わせることで、運転中や料理中など、手が離せない状況でも、音声だけでiPhoneやiPadの操作が可能になります。これにより、安全性を確保しながら、様々なタスクを自動化することができます。

**特徴と利点**

*   **安全性:** 運転中や料理中など、画面操作が危険な状況でも、安全に操作できます。
*   **利便性:** 手が離せない状況でも、音声だけで様々なタスクを実行できます。
*   **効率性:** タスクを自動化することで、時間と労力を節約できます。

**事前準備と前提条件**

*   **Scriptableスクリプトの準備:** ハンズフリーで実行したいタスクを自動化するScriptableスクリプトを事前に作成しておく必要があります。
*   **Siriショートカットの設定:** Siriショートカットアプリで、ScriptableスクリプトをSiriに登録し、適切な音声コマンドを設定する必要があります。
*   **ハンズフリー環境の準備:** 運転中はBluetoothヘッドセット、料理中はスピーカーなど、ハンズフリーでSiriを利用できる環境を準備してください。

**実践的なテクニック**

*   **シンプルな音声コマンド:** 運転中や料理中は、周囲の騒音が大きい場合があるため、Siriに認識されやすい、シンプルな音声コマンドを使用するように心がけましょう。
*   **確認メッセージの活用:** スクリプトの実行前に、確認メッセージを表示し、誤操作を防ぐようにしましょう。

```javascript
let alert = new Alert();
alert.message = "本当に実行しますか？";
alert.addDestructiveAction("実行");
alert.addCancelAction("キャンセル");
let choice = await alert.presentAlert();

if (choice == 0) {
  // 実行
  // ...
} else {
  // キャンセル
}
```

*   **音声によるフィードバック:** スクリプトの実行結果をSiriに読み上げさせることで、操作が成功したかどうかを確認できます。

```javascript
let speech = Speech.create();
speech.speak("実行しました。");
```

*   **位置情報の活用:** 運転中は、位置情報を利用して、最寄りのガソリンスタンドや駐車場を検索するスクリプトを作成できます。
*   **タイマーの活用:** 料理中は、タイマーを設定するスクリプトを作成することで、料理の時間を管理できます。
*   **Siriの「Hey Siri」機能の活用:** iPhoneやiPadがロックされている状態でも、音声だけでSiriを起動できます。設定アプリの「Siriと検索」セクションで、「"Hey Siri"を聞き取る」オプションを有効にしてください。
*   **CarPlayとの連携:** CarPlayに対応した車載システムを使用している場合は、SiriショートカットをCarPlay経由で操作できます。

**応用例とユースケース**

*   **運転中:**
    *   ナビゲーションの開始
    *   音楽の再生
    *   メッセージの送信
    *   電話の発信
    *   最寄りのガソリンスタンドの検索
*   **料理中:**
    *   タイマーの設定
    *   レシピの読み上げ
    *   買い物リストの作成
    *   音楽の再生
    *   スマート家電の操作

**トラブルシューティング**

*   **Siriが音声コマンドを認識しない:**
    *   周囲の騒音が大きいと、Siriが正しく認識できない場合があります。静かな場所で試してみてください。
    *   音声コマンドを別の言葉に変更してみるのも有効です。
    *   Bluetoothヘッドセットやスピーカーの接続状態を確認してください。
*   **スクリプトがエラーで停止する:**
    *   Scriptableアプリでスクリプトを直接実行し、エラーがないか確認してください。
    *   Siriから実行する場合と、直接実行する場合で、動作が異なる場合があります。Siriから渡される引数などを考慮して、スクリプトを修正してください。
*   **CarPlayでSiriショートカットが動作しない:**
    *   iPhoneとCarPlayの接続が正しく行われているか確認してください。
    *   CarPlayの設定で、Siriが有効になっているか確認してください。
    *   Siriショートカットアプリで、CarPlayに対応したショートカットを作成しているか確認してください。

**まとめと次のステップ**

SiriショートカットとScriptableを組み合わせることで、ハンズフリーで様々なタスクを自動化できます。運転中や料理中など、手が離せない状況でも、安全に、そして快適にiPhoneやiPadを活用してみてください。この章で学んだことを活かし、あなたのライフスタイルに合わせた自動化を実現してください。
