## 第 11 章：LoRA を超えて - 地球観測 AI の最前線

### 11.1 Federated Learning - 分散環境での協調学習

#### 概要と重要性

地球観測データは、その性質上、様々な場所に分散して存在することが多いです。例えば、各地方自治体が管理するセンサーデータ、異なる研究機関が保有する衛星画像、個々の農家が収集するドローンデータなどがあります。これらのデータを集約して学習させることは、データの所有権、プライバシー、通信コストなどの問題から困難な場合があります。

そこで注目されるのが Federated Learning (FL) です。FL は、中央サーバーにデータを集約することなく、各クライアント（データ保有者）がローカルで学習を行い、その学習結果（モデルのパラメータ）のみを中央サーバーに集めて集約する技術です。これにより、データは各クライアントの管理下に置かれたまま、グローバルな視点での学習が可能になります。

#### 特徴と利点

- **プライバシー保護:** 生データを共有する必要がないため、プライバシーリスクを低減できます。
- **データ所有権の尊重:** 各クライアントはデータの所有権を維持できます。
- **通信コストの削減:** 大量のデータを転送する必要がないため、通信コストを削減できます。
- **モデルの汎化性能向上:** 分散された多様なデータで学習することで、モデルの汎化性能を向上させることができます。

#### 事前準備と前提条件

- **クライアント側の環境:** 各クライアントは、機械学習モデルを学習できる環境が必要です（Python、TensorFlow、PyTorch など）。
- **中央サーバーの環境:** 中央サーバーは、クライアントから送信されたモデルパラメータを集約し、更新されたモデルパラメータをクライアントに配布できる環境が必要です。
- **通信環境:** クライアントと中央サーバー間の安定した通信環境が必要です。
- **データの前処理:** 各クライアントは、ローカルデータを適切な形式に前処理する必要があります。

#### 基本的な使い方

FL の基本的な流れは以下の通りです。

1.  **初期モデルの配布:** 中央サーバーは、初期モデル（例えばランダムな重みを持つニューラルネットワーク）を各クライアントに配布します。
2.  **ローカル学習:** 各クライアントは、配布されたモデルを用いてローカルデータで学習を行います。
3.  **モデルパラメータの送信:** 各クライアントは、学習後のモデルパラメータを中央サーバーに送信します。
4.  **モデルパラメータの集約:** 中央サーバーは、受信したモデルパラメータを集約します。集約方法としては、単純な平均、重み付け平均などがあります。
5.  **グローバルモデルの更新:** 集約されたモデルパラメータを用いて、グローバルモデルを更新します。
6.  **グローバルモデルの配布:** 中央サーバーは、更新されたグローバルモデルを各クライアントに配布します。
7.  **繰り返し:** 2〜6 の手順を繰り返し行います。

**Python コード例 (PyTorch 使用):**

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms

# 1. 初期モデルの定義 (クライアント、サーバー共通)
class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 10, kernel_size=5)
        self.pool = nn.MaxPool2d(2, 2)
        self.conv2 = nn.Conv2d(10, 20, kernel_size=5)
        self.fc1 = nn.Linear(320, 50)
        self.fc2 = nn.Linear(50, 10)

    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool(torch.relu(self.conv2(x)))
        x = x.view(-1, 320)
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

# 2. ローカル学習 (クライアント側)
def train_local(model, data_loader, optimizer, epochs=1):
    model.train()
    for epoch in range(epochs):
        for batch_idx, (data, target) in enumerate(data_loader):
            optimizer.zero_grad()
            output = model(data)
            loss = nn.CrossEntropyLoss()(output, target)
            loss.backward()
            optimizer.step()
    return model.state_dict()

# 3. モデルパラメータの集約 (サーバー側)
def aggregate_model_parameters(client_params, num_clients):
    aggregated_params = {}
    for key in client_params[0].keys():
        aggregated_params[key] = torch.zeros_like(client_params[0][key])
        for i in range(num_clients):
            aggregated_params[key] += client_params[i][key]
        aggregated_params[key] /= num_clients
    return aggregated_params

# 例: MNISTデータセットを用いたFL
# 各クライアントはMNISTデータセットの一部を持つと仮定

# クライアント数
num_clients = 3

# データローダーの作成 (各クライアントで異なるデータ)
data_loaders = []
for i in range(num_clients):
    # 簡単のため、ここでは同じデータを使用
    transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.1307,), (0.3081,))])
    train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
    data_loader = torch.utils.data.DataLoader(train_dataset, batch_size=32, shuffle=True)
    data_loaders.append(data_loader)

# 初期モデルの作成
global_model = SimpleCNN()

# オプティマイザの作成 (各クライアントで同じ)
optimizers = [optim.SGD(global_model.parameters(), lr=0.01) for _ in range(num_clients)]

# FLの実行
num_rounds = 5
for round in range(num_rounds):
    client_params = []
    for i in range(num_clients):
        # ローカル学習
        local_model = SimpleCNN()
        local_model.load_state_dict(global_model.state_dict()) # グローバルモデルをコピー
        client_params.append(train_local(local_model, data_loaders[i], optimizers[i]))

    # モデルパラメータの集約
    aggregated_params = aggregate_model_parameters(client_params, num_clients)

    # グローバルモデルの更新
    global_model.load_state_dict(aggregated_params)

    print(f"Round {round+1} completed")

# 学習済みモデルの評価 (省略)
```

#### 実践的なテクニック

- **モデルパラメータの差分プライバシー:** モデルパラメータにノイズを加えることで、プライバシー保護を強化できます。
- **Secure Aggregation:** 暗号化技術を用いて、モデルパラメータを集約する際にプライバシーを保護できます。
- **クライアント選択:** 学習に参加するクライアントを適切に選択することで、学習効率を向上させることができます。
- **Non-IID データへの対応:** 各クライアントが持つデータが大きく異なる場合（Non-IID データ）、モデルの汎化性能が低下する可能性があります。この問題に対処するために、様々な手法が提案されています（例：FedProx, SCAFFOLD）。

#### 応用例とユースケース

- **農地のモニタリング:** 各農家が保有するドローンデータを用いて、農作物の生育状況をモニタリングする。
- **森林火災の予測:** 各地域の気象データや衛星画像を用いて、森林火災の発生リスクを予測する。
- **都市環境のモニタリング:** 各都市のセンサーデータや画像データを用いて、大気汚染、騒音、交通渋滞などをモニタリングする。

#### トラブルシューティング

- **学習が収束しない:** 学習率、バッチサイズ、モデル構造などを調整してみてください。Non-IID データの場合、特別な対応が必要となる場合があります。
- **通信エラー:** クライアントとサーバー間の通信環境を確認してください。
- **プライバシー侵害:** モデルパラメータの差分プライバシー、Secure Aggregation などの技術を用いて、プライバシー保護を強化してください。

#### まとめと次のステップ

FL は、分散された地球観測データを活用するための強力なツールです。今後は、より高度なプライバシー保護技術や、Non-IID データへの対応技術が発展していくと考えられます。次のステップとしては、実際の地球観測データを用いて FL を実装し、その効果を検証することをお勧めします。

### 11.2 Self-Supervised Learning - ラベルなしデータからの学習

#### 概要と重要性

地球観測データは膨大ですが、その全てにラベルが付与されているわけではありません。例えば、衛星画像は大量に存在しますが、その画像に写っている土地被覆（森林、水田、都市など）を一つ一つ手作業でラベル付けするのは非常に困難です。

Self-Supervised Learning (SSL) は、ラベルなしデータから自動的に学習を行う技術です。SSL では、データ自身から生成された擬似的なラベルを用いて学習を行います。例えば、画像の一部を隠して、隠された部分を予測するタスクを学習したり、画像を回転させて、回転角度を予測するタスクを学習したりします。

#### 特徴と利点

- **ラベルなしデータの活用:** 大量のラベルなしデータを活用して、モデルの汎化性能を向上させることができます。
- **特徴量抽出の自動化:** データから自動的に有用な特徴量を抽出することができます。
- **ドメイン適応:** ラベル付きデータが少ないドメインに、ラベルなしデータから学習したモデルを適応させることができます。

#### 事前準備と前提条件

- **ラベルなしデータ:** 大量のラベルなしの地球観測データが必要です。
- **学習環境:** SSL モデルを学習できる環境が必要です（Python、TensorFlow、PyTorch など）。
- **計算資源:** 大量のデータを学習するため、十分な計算資源（GPU など）が必要です。

#### 基本的な使い方

SSL の基本的な流れは以下の通りです。

1.  **事前学習 (Pre-training):** 大量のラベルなしデータを用いて、SSL モデルを事前学習します。
2.  **ファインチューニング (Fine-tuning):** 事前学習済みのモデルを、少量のラベル付きデータを用いてファインチューニングします。

**Python コード例 (PyTorch 使用):**

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from PIL import Image
import random

# 1. データ拡張の定義 (Self-Supervisedタスクに合わせて変更)
class RotationTransform:
    def __init__(self, angles):
        self.angles = angles

    def __call__(self, x):
        angle = random.choice(self.angles)
        return x.rotate(angle)

class RotatedDataset(torch.utils.data.Dataset):
    def __init__(self, dataset, rotation_transform):
        self.dataset = dataset
        self.rotation_transform = rotation_transform

    def __len__(self):
        return len(self.dataset)

    def __getitem__(self, idx):
        image, _ = self.dataset[idx] # 元のラベルは無視
        rotated_image = self.rotation_transform(Image.fromarray(image.numpy(), mode='L')) # DatasetがTensorを返すため一度PIL Imageに戻す
        angle = random.choice([0, 90, 180, 270]) # 回転角度
        rotated_image = transforms.ToTensor()(rotated_image) #再度Tensorに戻す

        # 回転角度をラベルとして返す
        angle_index = [0, 90, 180, 270].index(angle) # 角度をindexに変換

        return rotated_image, angle_index

# 2. モデルの定義 (SimpleCNNは上記FLの例と同じ)

# 3. 事前学習 (回転角度予測)
def pretrain(model, data_loader, optimizer, epochs=1):
    model.train()
    for epoch in range(epochs):
        for batch_idx, (data, target) in enumerate(data_loader):
            optimizer.zero_grad()
            output = model(data)
            loss = nn.CrossEntropyLoss()(output, target) # 回転角度を予測
            loss.backward()
            optimizer.step()
            if batch_idx % 100 == 0:
                print('Train Epoch: {} [{}/{} ({:.0f}%)]\tLoss: {:.6f}'.format(
                    epoch, batch_idx * len(data), len(data_loader.dataset),
                    100. * batch_idx / len(data_loader), loss.item()))


# 4. ファインチューニング
def finetune(model, data_loader, optimizer, epochs=1):
    model.train()
    for epoch in range(epochs):
        for batch_idx, (data, target) in enumerate(data_loader):
            optimizer.zero_grad()
            output = model(data)
            loss = nn.CrossEntropyLoss()(output, target) # 元のタスクのラベルを使用
            loss.backward()
            optimizer.step()
            if batch_idx % 100 == 0:
                print('Finetune Epoch: {} [{}/{} ({:.0f}%)]\tLoss: {:.6f}'.format(
                    epoch, batch_idx * len(data), len(data_loader.dataset),
                    100. * batch_idx / len(data_loader), loss.item()))

# 例: MNISTデータセットを用いたSSL
# 事前学習: 回転角度予測
# ファインチューニング: 手書き文字認識

# データセットの準備
transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.1307,), (0.3081,))])
train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_dataset = datasets.MNIST('./data', train=False, download=True, transform=transform)

# 事前学習用データセット (回転)
rotation_transform = RotationTransform(angles=[0, 90, 180, 270])
pretrain_dataset = RotatedDataset(train_dataset, rotation_transform)
pretrain_loader = torch.utils.data.DataLoader(pretrain_dataset, batch_size=32, shuffle=True)

# ファインチューニング用データセット
finetune_loader = torch.utils.data.DataLoader(train_dataset, batch_size=32, shuffle=True)
test_loader = torch.utils.data.DataLoader(test_dataset, batch_size=32, shuffle=False)

# モデルの作成
model = SimpleCNN()

# オプティマイザの作成
optimizer_pretrain = optim.Adam(model.parameters(), lr=0.001)
optimizer_finetune = optim.Adam(model.parameters(), lr=0.001)

# 事前学習
pretrain(model, pretrain_loader, optimizer_pretrain, epochs=2)

# ファインチューニング
finetune(model, finetune_loader, optimizer_finetune, epochs=1)

# 評価 (省略)
```

#### 実践的なテクニック

- **コントラスト学習:** 異なるデータ拡張を施した画像ペアを用いて、類似した画像の特徴表現を近づけ、異なる画像の特徴表現を遠ざけるように学習します。
- **Autoencoder:** 入力画像を圧縮し、それを復元するように学習します。
- **事前学習済みモデルの利用:** ImageNet などで事前学習されたモデルを、地球観測データにファインチューニングすることで、高い性能を発揮することができます。

#### 応用例とユースケース

- **土地被覆分類:** 大量の衛星画像を用いて、土地被覆を分類する。
- **異常検知:** 正常な地球観測データを用いて、異常な状態（森林火災、洪水など）を検知する。
- **解像度向上:** 低解像度の衛星画像から、高解像度の画像を生成する。

#### トラブルシューティング

- **学習が収束しない:** 事前学習タスクが適切でない可能性があります。データセットやタスクを見直してみてください。
- **過学習:** ラベルなしデータが偏っている可能性があります。データ拡張や正則化を試してみてください。

#### まとめと次のステップ

SSL は、ラベルなしの地球観測データを活用するための強力な技術です。今後は、より複雑なデータに対する SSL 手法や、ドメイン適応技術が発展していくと考えられます。次のステップとしては、実際の地球観測データを用いて SSL を実装し、その効果を検証することをお勧めします。特に、Transformer ベースのモデル（ViT など）は、地球観測データにおいて高い性能を発揮することが知られています。

### 11.3 Explainable AI (XAI) - モデルの解釈可能性向上

#### 概要と重要性

地球観測 AI モデルは、その複雑さから、なぜ特定の予測を行ったのか理解することが難しい場合があります。特に、人命に関わるような重要な意思決定（災害予測、農作物の収穫量予測など）においては、モデルの予測根拠を明確にすることが不可欠です。

Explainable AI (XAI) は、AI モデルの意思決定プロセスを人間が理解できるようにする技術です。XAI を用いることで、モデルの予測結果に対する信頼性を高め、モデルの改善点を見つけ出し、倫理的な問題（バイアスなど）を発見することができます。

#### 特徴と利点

- **モデルの信頼性向上:** モデルの予測根拠を理解することで、モデルに対する信頼性を高めることができます。
- **モデルの改善点発見:** モデルの弱点や改善点を発見することができます。
- **倫理的な問題の発見:** モデルのバイアスや差別的な振る舞いを発見することができます。
- **意思決定の支援:** モデルの予測結果を、意思決定者が理解しやすい形で提示することで、意思決定を支援することができます。

#### 事前準備と前提条件

- **学習済み AI モデル:** 解釈対象となる学習済みの地球観測 AI モデルが必要です。
- **XAI ライブラリ:** XAI 手法を実装するためのライブラリが必要です（SHAP、LIME など）。
- **解釈対象データ:** モデルの予測結果を解釈するためのデータが必要です。

#### 基本的な使い方

代表的な XAI 手法として、SHAP (SHapley Additive exPlanations) と LIME (Local Interpretable Model-agnostic Explanations) があります。

- **SHAP:** ゲーム理論におけるシャープレイ値を応用して、各特徴量が予測にどの程度貢献しているかを定量的に評価します。
- **LIME:** モデルの周辺で局所的に解釈可能な線形モデルを構築し、その線形モデルを用いて予測根拠を説明します。

**Python コード例 (SHAP 使用):**

```python
import shap
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms

# 前提: 学習済みのモデルとデータセットがあること
# (ここでは、11.1や11.2の例で学習したSimpleCNNモデルとMNISTデータセットを使用すると仮定)

# 1. 背景データ (background data) の準備
# SHAPでは、予測を説明するために、背景データと比較して、どの特徴量が予測に影響を与えたかを計算します。
# 背景データは、モデルが学習したデータ分布を代表するようなデータを選択する必要があります。
# ここでは、MNISTの学習データセットの一部を背景データとして使用します。

batch = next(iter(finetune_loader))
images, _ = batch
background = images[:100] # 100枚を背景データとする

# 2. explainerの作成
# DeepExplainerは、PyTorchモデルに対応したexplainerです。
# 背景データとモデルを引数として渡します。
explainer = shap.DeepExplainer(model, background)

# 3. 説明対象データの準備
test_images, _ = next(iter(test_loader)) # テストデータから説明対象の画像を取得

# 4. SHAP値の計算
# SHAP値を計算するには、explainerに説明対象データを渡します。
# SHAP値は、各特徴量が予測にどの程度貢献しているかを示す値です。
shap_values = explainer.shap_values(test_images[:5]) # 最初の5枚の画像についてSHAP値を計算

# 5. SHAP値の可視化
# SHAP値は、様々な方法で可視化することができます。
# force plotは、予測値を基準として、各特徴量が予測値を押し上げているか、押し下げているかを可視化します。
shap.initjs()
shap.force_plot(explainer.expected_value[0], shap_values[0][0], test_images[0].numpy().reshape(28*28), feature_names=[f'pixel_{i}' for i in range(28*28)])

# Summary plotは、全データに対する各特徴量の重要度を可視化します。
shap.summary_plot(shap_values, test_images[:5].numpy())
```

**Python コード例 (LIME 使用):**

```python
from lime import lime_image
from skimage.segmentation import mark_boundaries
import matplotlib.pyplot as plt

# 前提: 学習済みのモデルとデータセットがあること
# (ここでは、11.1や11.2の例で学習したSimpleCNNモデルとMNISTデータセットを使用すると仮定)

# LIME explainerの作成
explainer = lime_image.LimeImageExplainer()

# 説明対象データの準備
test_images, _ = next(iter(test_loader)) # テストデータから説明対象の画像を取得
image = test_images[0].numpy().transpose((1, 2, 0)) # (C, H, W) -> (H, W, C)

# LIMEによる説明
explanation = explainer.explain_instance(
    image.astype('double'),
    model.forward, # モデルの予測関数
    top_labels=5, # 上位5つのクラス
    hide_color=0,
    num_samples=1000 # サンプリング数
)

# 説明の可視化
temp, mask = explanation.get_image_and_mask(
    explanation.top_labels[0], positive_only=True, num_features=5, hide_rest=True
)
image_with_mask = mark_boundaries(temp / 2 + 0.5, mask)

plt.imshow(image_with_mask)
plt.show()
```

#### 実践的なテクニック

- **特徴量の重要度分析:** SHAP 値や LIME を用いて、モデルが重要な特徴量を特定します。
- **予測の解釈:** 特定の予測に対して、各特徴量がどのように影響を与えているかを分析します。
- **モデルのデバッグ:** 誤った予測の原因を特定し、モデルを改善します。
- **バイアス検出:** モデルが特定のグループに対して不当な予測を行っていないか確認します。

#### 応用例とユースケース

#### トラブルシューティング

### 11.4 Neural Architecture Search (NAS) - 最適なモデル構造の自動探索

#### 概要と重要性

ディープラーニングモデルの性能は、モデルのアーキテクチャに大きく依存します。しかし、最適なアーキテクチャを手動で見つけ出すには、専門的な知識と多くの試行錯誤が必要です。

Neural Architecture Search (NAS) は、AI を用いて最適なモデルアーキテクチャを自動的に探索する技術です。NAS を用いることで、人間が設計するよりも優れたアーキテクチャを発見したり、特定のタスクに特化したアーキテクチャを自動的に生成したりすることができます。

#### 特徴と利点

- **モデル設計の自動化:** モデルのアーキテクチャ設計を自動化することで、開発コストを削減できます。
- **性能向上:** 人間が設計するよりも優れたアーキテクチャを発見できる可能性があります。
- **専門知識の不要:** モデル設計に関する専門知識がなくても、高性能なモデルを開発できます。
- **タスク特化:** 特定のタスクに特化したアーキテクチャを自動的に生成できます。

#### 事前準備と前提条件

- **NAS フレームワーク:** NAS を実装するためのフレームワークが必要です（AutoKeras、NNI など）。
- **学習環境:** モデルを学習できる環境が必要です（Python、TensorFlow、PyTorch など）。
- **計算資源:** モデルを探索するため、十分な計算資源（GPU など）が必要です。
- **探索空間の定義:** 探索するアーキテクチャの範囲を定義する必要があります。

#### 基本的な使い方

NAS の基本的な流れは以下の通りです。

1.  **探索空間の定義:** 探索するアーキテクチャの範囲を定義します。例えば、畳み込み層の数、フィルタサイズ、活性化関数などを指定します。
2.  **探索アルゴリズムの選択:** 探索アルゴリズムを選択します。例えば、強化学習、進化戦略、勾配ベースの手法などがあります。
3.  **モデルの評価:** 探索されたアーキテクチャを持つモデルを学習し、その性能を評価します。
4.  **アーキテクチャの更新:** 評価結果に基づいて、探索アルゴリズムを用いて、より良いアーキテクチャを探索します。
5.  **繰り返し:** 3〜4 の手順を繰り返し行います。

**Python コード例 (AutoKeras 使用):**

```python
import autokeras as ak
import tensorflow as tf

# 前提: データセットの準備
# MNISTデータセットを使用すると仮定

(x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()
print(x_train.shape) # (60000, 28, 28)
print(y_train.shape) # (60000,)
print(x_test.shape) # (10000, 28, 28)
print(y_test.shape) # (10000,)

# 1. ImageClassifierの作成
# max_trials: 探索するアーキテクチャの数
clf = ak.ImageClassifier(max_trials=3, overwrite=True)

# 2. モデルの探索
# input_shape: 入力データの形状
# epochs: 学習エポック数
clf.fit(x_train, y_train, epochs=2)

# 3. モデルの評価
loss, accuracy = clf.evaluate(x_test, y_test)
print('Accuracy: %.2f' % (accuracy*100))

# 4. 最適なモデルの取得
model = clf.export_model()

# モデルの保存
model.save("model_autokeras.h5")
```

#### 実践的なテクニック

- **One-Shot NAS:** 複数のアーキテクチャを同時に学習し、その結果を用いて最適なアーキテクチャを探索します。
- **Cell-Based NAS:** モデルを構成する基本的な要素（セル）を探索し、それらを組み合わせてモデルを構築します。
- **Differential Architecture Search (DART):** モデルのアーキテクチャを連続的なパラメータで表現し、勾配ベースの手法で最適化します。

#### 応用例とユースケース

- **土地被覆分類:** 衛星画像から土地被覆を分類するための最適なモデルを探索する。
- **異常検知:** 地球観測データから異常な状態を検知するための最適なモデルを探索する。
- **解像度向上:** 低解像度の衛星画像から高解像度の画像を生成するための最適なモデルを探索する。

#### トラブルシューティング

- **計算コスト:** NAS は計算コストが高い場合があります。探索空間を絞ったり、計算資源を増やすなどの対策を検討してください。
- **過学習:** 探索されたアーキテクチャが過学習を起こす可能性があります。正則化を強化したり、データ拡張を試してみてください。
