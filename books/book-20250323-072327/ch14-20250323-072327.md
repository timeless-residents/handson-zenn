## 第 14 章：衛星画像データの法的側面 - ライセンス、著作権、規制

### 14.1 衛星データライセンスの種類と注意点

#### 14.1.1 概要と重要性

衛星画像データは、その取得コストや技術的な複雑さから、利用にあたっては様々な法的制約が存在します。ライセンス、著作権、そして関連法規制を理解することは、合法的に、かつ安心して衛星データを利用するための第一歩です。このセクションでは、様々な衛星データライセンスの種類と、それぞれの注意点について詳しく解説します。適切なライセンスを選択し、利用規約を遵守することで、予期せぬ法的トラブルを回避し、創造的なデータ活用を促進できます。

#### 14.1.2 特徴と利点

衛星データライセンスは、主にオープンデータライセンスと商用ライセンスの二種類に大別できます。

- **オープンデータライセンス:** 無償で利用できるライセンスで、多くの場合、学術研究や非営利目的での利用が許可されています。代表的なものに、CC BY（表示）、CC0（権利放棄）などがあります。

  - **利点:** 無償で利用可能、研究開発や教育用途に最適。
  - **注意点:** ライセンスの種類によって、クレジット表記の義務や改変の可否が異なります。商用利用が許可されていない場合もあります。

- **商用ライセンス:** 商業目的での利用を許可するライセンスで、データプロバイダから購入する必要があります。
  - **利点:** 商用サービスや製品への組み込みが可能。サポート体制が充実していることが多い。
  - **注意点:** ライセンス料が発生する。利用範囲（地域、期間、用途など）が制限されることがある。

#### 14.1.3 事前準備と前提条件

- 利用したい衛星データのプロバイダのウェブサイトを訪問し、ライセンスに関する情報を確認してください。
- ライセンスの種類（CC BY, CC0, 商用ライセンスなど）を特定してください。
- 利用規約を注意深く読み、利用条件を理解してください。
- 商用利用を検討している場合は、データプロバイダに見積もりを依頼してください。

#### 14.1.4 基本的な使い方

**オープンデータライセンスの例: Sentinel-2 (欧州宇宙機関)**

Sentinel-2 のデータは、原則として Copernicus Programme のライセンスに基づいて無償で利用できます。利用規約は以下の通りです。

- データの出所（"Copernicus Sentinel data [年]"）を明記する必要があります。
- 利用目的は基本的に自由ですが、違法な目的での利用は禁止されています。

**商用ライセンスの例: Maxar Technologies (WorldView シリーズ)**

WorldView シリーズのデータは、解像度が高く、様々な用途に利用できますが、商用ライセンスが必要です。ライセンスの種類は、利用目的、地域、期間などによって異なり、データプロバイダに見積もりを依頼する必要があります。

#### 14.1.5 実践的なテクニック

**ライセンス表示の自動化:**

Python のライブラリなどを用いて、衛星画像処理の過程でライセンス情報を自動的に付与するスクリプトを作成できます。

```python
def add_license_to_metadata(image_path, license_info):
  """画像ファイルのメタデータにライセンス情報を追加する関数"""
  # 画像ファイルを読み込む (例: rasterioを使用)
  import rasterio
  with rasterio.open(image_path, 'r+') as dst:
    # メタデータを更新
    profile = dst.profile
    profile.update(
        {
            'tiled': True,
            'blockxsize': 256,
            'blockysize': 256,
            'compress': 'lzw',
            'LICENSE': license_info
        }
    )
    # 新しいファイルに書き出す
    with rasterio.open(image_path.replace(".tif","_licensed.tif"), 'w', **profile) as dst2:
        dst2.write(dst.read())

# 例: Sentinel-2のライセンス情報を追加
license_info = "Copernicus Sentinel data 2023"
image_path = "path/to/your/sentinel2_image.tif"
add_license_to_metadata(image_path, license_info)
```

このコードは、`rasterio`ライブラリを使って TIFF ファイルのメタデータにライセンス情報を追加します。同様の手法を他の画像形式やライブラリにも適用できます。

#### 14.1.6 応用例とユースケース

- **農業モニタリング:** オープンデータの Sentinel-2 画像を用いて、作物の生育状況をモニタリングし、収穫量を予測する。結果を公表する際は、"Copernicus Sentinel data [年]"を明記する。
- **都市計画:** 商用ライセンスの WorldView 画像を用いて、高解像度の都市地図を作成し、都市開発の計画に役立てる。利用規約に従い、利用範囲や期間を遵守する。
- **災害対応:** 災害発生時に、オープンデータの Landsat 画像を用いて被災状況を把握し、救援活動を支援する。クレジット表記を忘れずに行う。

#### 14.1.7 トラブルシューティング

- **ライセンス違反:** 商用利用が許可されていないオープンデータ画像を商用サービスに組み込んだ場合、著作権侵害で訴えられる可能性があります。利用規約を再度確認し、必要であれば商用ライセンスを取得してください。
- **クレジット表記漏れ:** オープンデータ画像を利用した際に、クレジット表記を忘れると、ライセンス違反となる可能性があります。利用規約を再度確認し、適切なクレジット表記を行ってください。
- **ライセンスの解釈:** ライセンス条項の解釈に不明な点がある場合は、データプロバイダに問い合わせるか、法律の専門家に相談してください。

#### 14.1.8 まとめと次のステップ

### 14.2 衛星画像データの著作権

#### 14.2.1 概要と重要性

衛星画像データは、撮影という行為によって著作権が発生します。著作権は、著作者（通常はデータプロバイダ）の権利を保護し、無断複製や改変を禁止します。著作権に関する知識は、合法的に衛星画像データを利用し、知的財産権を尊重するために不可欠です。

#### 14.2.2 特徴と利点

- **著作権の帰属:** 衛星画像データの著作権は、通常、データプロバイダ（衛星の運用者またはデータ販売者）に帰属します。ただし、例外として、政府機関が撮影したデータや、オープンデータとして提供されているデータは、著作権が放棄されているか、緩やかな利用条件が適用されている場合があります。
- **二次利用の制限:** 著作権者は、複製、翻案、翻訳、送信などの二次利用を制限する権利を有します。二次利用を行う場合は、著作権者の許諾を得る必要があります。
- **クレジット表記の重要性:** 著作権表示は、著作権者の権利を明示し、利用者に適切な利用を促す役割を果たします。著作権表示は、通常、著作権マーク（©）、著作者名、発行年で構成されます。

#### 14.2.3 事前準備と前提条件

- 利用したい衛星画像データの著作権者を確認してください。
- 二次利用を検討している場合は、著作権者に許諾を求める手続きを確認してください。
- クレジット表記の方法をデータプロバイダのウェブサイトで確認してください。

#### 14.2.4 基本的な使い方

**著作権表示の例:**

"© [年] [データプロバイダ名]"

例: "© 2023 Maxar Technologies"

**クレジット表記の例:**

"Image: © [年] [データプロバイダ名], provided by [販売代理店名]"

例: "Image: © 2023 Maxar Technologies, provided by 株式会社〇〇"

#### 14.2.5 実践的なテクニック

**著作権表示の自動生成:**

衛星画像データのメタデータから著作権情報を抽出し、自動的に著作権表示を生成するスクリプトを作成できます。

```python
def generate_copyright_notice(image_path):
  """画像ファイルのメタデータから著作権情報を抽出し、著作権表示を生成する関数"""
  # 画像ファイルを読み込む (例: rasterioを使用)
  import rasterio
  with rasterio.open(image_path, 'r') as src:
    metadata = src.meta
    if 'COPYRIGHT' in metadata:
      copyright_info = metadata['COPYRIGHT']
      return f"© {copyright_info}"
    else:
      return "Copyright information not found in metadata."

# 例: 著作権表示を生成
image_path = "path/to/your/satellite_image.tif"
copyright_notice = generate_copyright_notice(image_path)
print(copyright_notice)
```

このコードは、`rasterio`ライブラリを使って TIFF ファイルのメタデータから著作権情報を抽出し、著作権表示を生成します。

#### 14.2.6 応用例とユースケース

- **ウェブサイトでの利用:** 衛星画像データをウェブサイトに掲載する場合は、著作権表示とクレジット表記を必ず行います。
- **プレゼンテーションでの利用:** 衛星画像データをプレゼンテーションで使用する場合は、スライドに著作権表示とクレジット表記を記載します。
- **出版物での利用:** 衛星画像データを書籍や論文などの出版物に掲載する場合は、著作権者の許諾を得る必要がある場合があります。出版社に確認してください。

#### 14.2.7 トラブルシューティング

- **著作権侵害:** 無断で衛星画像データを複製、改変、または頒布した場合、著作権侵害で訴えられる可能性があります。利用規約を再度確認し、必要であれば著作権者の許諾を得てください。
- **著作権表示の不備:** 著作権表示が不正確または不完全な場合、著作権侵害とみなされる可能性があります。著作権表示の方法を再度確認し、正確な情報を記載してください。
- **フェアユース:** 一定の条件下では、著作権者の許諾を得ずに著作物を利用できるフェアユース（公正な利用）が認められる場合があります。しかし、フェアユースの範囲は限定的であり、判断が難しい場合があります。法律の専門家に相談することをお勧めします。

### 14.3 地球観測データに関する法規制

#### 14.3.1 概要と重要性

衛星画像データは、個人情報保護法、地理空間情報活用推進基本法などの国内法規制に加え、国際的な取り決めにも影響を受けます。これらの法規制を理解し遵守することは、法的リスクを回避し、社会的な責任を果たす上で不可欠です。

#### 14.3.2 特徴と利点

- **個人情報保護法:** 衛星画像データに個人が特定できる情報が含まれる場合（例：高解像度画像に写り込んだ人物）、個人情報保護法が適用されます。個人情報を取得する場合は、本人の同意を得る必要があり、適切な管理措置を講じる必要があります。
- **地理空間情報活用推進基本法:** 地理空間情報の活用を推進するための基本法です。衛星画像データも地理空間情報の一部として扱われ、公共測量への利用や、地理空間情報の共有・連携に関する規定があります。
- **国際的な取り決め:** 衛星画像の撮影や利用に関しては、国際的な取り決めも存在します。特に、国家安全保障に関わるような機密性の高い地域を撮影する場合や、他国の主権を侵害するような利用を行う場合は、国際法に抵触する可能性があります。

#### 14.3.3 事前準備と前提条件

- 利用する衛星画像データに個人情報が含まれる可能性があるかどうかを確認してください。
- 地理空間情報活用推進基本法の内容を理解し、公共測量への利用や情報共有に関する規定を遵守してください。
- 国際的な取り決めについて知識を深め、他国の主権を侵害するような利用を避けてください。

#### 14.3.4 基本的な使い方

**個人情報保護への配慮:**

- 高解像度画像に写り込んだ人物の顔にぼかしを入れるなどの匿名化処理を行う。
- 個人情報が含まれる可能性があるデータを第三者に提供する場合は、本人の同意を得る。
- 個人情報保護に関する社内規定を整備し、従業員への教育を徹底する。

**地理空間情報活用推進基本法の遵守:**

- 公共測量に衛星画像データを利用する場合は、測量法の規定に従い、国土交通大臣の承認を得る。
- 地理空間情報を共有・連携する場合は、関係機関との間で適切な取り決めを行う。

**国際的な取り決めへの配慮:**

- 国家安全保障に関わるような機密性の高い地域を撮影する場合は、事前に関係機関に確認する。
- 他国の主権を侵害するような利用は避ける。

#### 14.3.5 実践的なテクニック

**匿名化処理の自動化:**

Python の画像処理ライブラリ（例：OpenCV）を用いて、衛星画像データに写り込んだ人物の顔を自動的に検出してぼかしを入れるスクリプトを作成できます。

```python
import cv2

def anonymize_faces(image_path):
  """画像ファイル内の顔を検出し、ぼかし処理を行う関数"""
  # 画像ファイルを読み込む
  img = cv2.imread(image_path)
  # Haar Cascade Classifierをロード
  face_cascade = cv2.CascadeClassifier('haarcascade_frontalface_default.xml')
  # グレースケールに変換
  gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
  # 顔を検出
  faces = face_cascade.detectMultiScale(gray, 1.1, 4)
  # 検出された顔にぼかしを適用
  for (x, y, w, h) in faces:
    roi = img[y:y+h, x:x+w]
    blur = cv2.GaussianBlur(roi, (99, 99), 0)
    img[y:y+h, x:x+w] = blur

  # 匿名化された画像を保存
  cv2.imwrite(image_path.replace(".jpg","_anonymized.jpg"), img)
  return image_path.replace(".jpg","_anonymized.jpg")

# 例: 顔を匿名化
image_path = "path/to/your/satellite_image.jpg"
anonymized_image_path = anonymize_faces(image_path)
print(f"匿名化された画像が保存されました: {anonymized_image_path}")
```

このコードは、OpenCV ライブラリを使って画像内の顔を検出し、ぼかし処理を行います。`haarcascade_frontalface_default.xml`は顔検出のための学習済みモデルファイルです。

#### 14.3.6 応用例とユースケース

- **防災・減災:** 災害発生時の被災状況を把握するために衛星画像データを利用する場合、個人情報が含まれないように注意し、被災者のプライバシーを保護する必要があります。
- **都市計画:** 都市開発の計画に衛星画像データを利用する場合、地理空間情報活用推進基本法を遵守し、関係機関との間で適切な情報共有を行う必要があります。
- **環境モニタリング:** 環境汚染の状況を把握するために衛星画像データを利用する場合、国際的な取り決めに抵触しないように注意し、他国の環境保全活動を妨げるような利用を避ける必要があります。

#### 14.3.7 トラブルシューティング

- **個人情報漏洩:** 衛星画像データから個人情報が漏洩した場合、個人情報保護法違反となる可能性があります。漏洩の原因を特定し、再発防止策を講じる必要があります。
- **測量法違反:** 公共測量に衛星画像データを利用する際に、測量法の規定に違反した場合、罰則が科せられる可能性があります。測量法の規定を再度確認し、必要な手続きを行ってください。
- **国際法違反:** 衛星画像の撮影や利用が国際法に違反した場合、外交問題に発展する可能性があります。事前に専門家に相談し、法的リスクを評価してください。
