## 第 5 章：LoRA を用いた衛星画像生成モデルの構築 - 実践編

衛星画像生成モデルの可能性は、都市計画、環境モニタリング、災害予測など、多岐にわたる分野で革新をもたらす鍵となります。しかし、高解像度の衛星画像を生成するためには、計算資源とデータセットの規模が大きな課題となります。そこで、本章では、LoRA (Low-Rank Adaptation) という手法を用いて、既存の巨大モデルを効率的にファインチューニングし、衛星画像生成モデルを構築する実践的な方法を解説します。

### 5.1 モデルアーキテクチャの選定 - UNet、GAN、Diffusion Models

衛星画像生成に適したモデルアーキテクチャはいくつか存在します。それぞれの特徴を理解し、目的と利用可能なリソースに応じて最適なものを選択することが重要です。

#### UNet の概要と実装（エンコーダー・デコーダー構造、スキップコネクション）

**1. 概要と重要性**

UNet は、特にセグメンテーションタスクで優れた性能を発揮するアーキテクチャです。衛星画像処理においては、土地被覆分類、道路抽出、建物検出など、ピクセル単位での分類が必要なタスクに最適です。エンコーダー・デコーダー構造とスキップコネクションが特徴で、細かいテクスチャ情報と大域的なコンテキストの両方を捉えることができます。

**2. 特徴と利点**

- **高精度なセグメンテーション:** ピクセルレベルでの正確な分類が可能。
- **効率的な学習:** 比較的少ないデータセットでも学習可能。
- **柔軟性:** アーキテクチャを調整することで、様々なタスクに対応可能。

**3. 事前準備と前提条件**

- Python 環境の構築
- TensorFlow または PyTorch のインストール
- 必要なライブラリのインストール（例：`pip install tensorflow scikit-image numpy matplotlib`）

**4. 基本的な使い方**

```python
import tensorflow as tf

def unet_model(input_size=(256, 256, 3)):
    inputs = tf.keras.layers.Input(input_size)

    # エンコーダー
    conv1 = tf.keras.layers.Conv2D(64, 3, activation='relu', padding='same')(inputs)
    conv1 = tf.keras.layers.Conv2D(64, 3, activation='relu', padding='same')(conv1)
    pool1 = tf.keras.layers.MaxPooling2D(pool_size=(2, 2))(conv1)

    conv2 = tf.keras.layers.Conv2D(128, 3, activation='relu', padding='same')(pool1)
    conv2 = tf.keras.layers.Conv2D(128, 3, activation='relu', padding='same')(conv2)
    pool2 = tf.keras.layers.MaxPooling2D(pool_size=(2, 2))(conv2)

    # ... (さらに深い層を追加)

    # デコーダー
    up7 = tf.keras.layers.Conv2DTranspose(128, 2, strides=(2, 2), padding='same')(conv2)
    merge7 = tf.keras.layers.concatenate([up7, conv2], axis=3)
    conv7 = tf.keras.layers.Conv2D(128, 3, activation='relu', padding='same')(merge7)
    conv7 = tf.keras.layers.Conv2D(128, 3, activation='relu', padding='same')(conv7)

    up8 = tf.keras.layers.Conv2DTranspose(64, 2, strides=(2, 2), padding='same')(conv7)
    merge8 = tf.keras.layers.concatenate([up8, conv1], axis=3)
    conv8 = tf.keras.layers.Conv2D(64, 3, activation='relu', padding='same')(merge8)
    conv8 = tf.keras.layers.Conv2D(64, 3, activation='relu', padding='same')(conv8)

    # 出力層
    outputs = tf.keras.layers.Conv2D(1, 1, activation='sigmoid')(conv8) # 例：二値分類の場合

    model = tf.keras.models.Model(inputs=inputs, outputs=outputs)
    return model

model = unet_model()
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.summary()
```

**5. 実践的なテクニック**

- **学習率の調整:** 学習の進行に合わせて学習率を調整します（例：ReduceLROnPlateau）。

- **教師なし学習:** ラベルなしデータでも学習可能。

    model = tf.keras.Sequential([
        tf.keras.layers.Flatten(input_shape=img_shape),
        tf.keras.layers.Dense(512),
        tf.keras.layers.LeakyReLU(alpha=0.2),
        tf.keras.layers.Dense(256),

    fake_loss = cross_entropy(tf.zeros_like(fake_output), fake_output)
    total_loss = real_loss + fake_loss
    return total_loss

### 5.2 LoRA の適用 - モデルの特定層に LoRA を組み込む

LoRA (Low-Rank Adaptation) は、事前学習済みの巨大モデルを効率的にファインチューニングするための手法です。モデル全体のパラメータを更新する代わりに、少数の追加パラメータ（LoRA レイヤー）を学習することで、計算資源を大幅に削減できます。

**1. 概要と重要性**

LoRA は、特に巨大な Transformer モデルを扱う場合に有効です。衛星画像生成モデルは、大規模なデータセットで学習された複雑なモデルであるため、LoRA を適用することで、限られた計算資源でも効率的にファインチューニングできます。

**2. 特徴と利点**

- **計算コストの削減:** 学習に必要な計算資源を大幅に削減。
- **メモリ使用量の削減:** モデル全体のパラメータを更新しないため、メモリ使用量を削減。
- **高速な学習:** 学習時間を短縮。
- **既存モデルの活用:** 事前学習済みの巨大モデルを再利用可能。

**3. 事前準備と前提条件**

- Python 環境の構築
- PyTorch のインストール
- Transformers ライブラリのインストール (`pip install transformers accelerate`)
- LoRA をサポートするライブラリのインストール (例：`pip install peft`)

### 5.3 損失関数の設計 - 目的とするタスクに合わせた損失関数

損失関数は、モデルの学習における「道しるべ」です。目的とするタスクに合わせて適切な損失関数を選択することで、モデルの性能を最大限に引き出すことができます。

**1. 概要と重要性**

衛星画像生成タスクは、セグメンテーション、超解像、生成など、様々な種類があります。それぞれのタスクに合わせて、適切な損失関数を選択することが重要です。

**2. 特徴と利点**

- **セグメンテーションタスク:** Dice 損失、IoU 損失など、ピクセル単位での分類精度を向上させる損失関数。
- **超解像タスク:** MSE 損失、PSNR など、画像の品質を評価する損失関数。
- **生成タスク:** Perceptual Loss、Style Loss など、生成された画像のリアリティやスタイルを評価する損失関数。

**3. 事前準備と前提条件**

- Python 環境の構築
- TensorFlow または PyTorch のインストール
- 必要なライブラリのインストール（例：`pip install tensorflow scikit-image numpy matplotlib`）
- 目的に合わせた損失関数の実装

**4. 基本的な使い方（損失関数の例）**

```python
import tensorflow as tf

# Dice損失
def dice_loss(y_true, y_pred, smooth=1e-6):
    intersection = tf.reduce_sum(y_true * y_pred, axis=(1, 2, 3))
    union = tf.reduce_sum(y_true, axis=(1, 2, 3)) + tf.reduce_sum(y_pred, axis=(1, 2, 3))
    dice = (2. * intersection + smooth) / (union + smooth)
    return 1 - tf.reduce_mean(dice)

# IoU損失
def iou_loss(y_true, y_pred, smooth=1e-6):
    intersection = tf.reduce_sum(y_true * y_pred, axis=(1, 2, 3))
    union = tf.reduce_sum(y_true, axis=(1, 2, 3)) + tf.reduce_sum(y_pred, axis=(1, 2, 3)) - intersection
    iou = (intersection + smooth) / (union + smooth)
    return 1 - tf.reduce_mean(iou)

# MSE損失
def mse_loss(y_true, y_pred):
    return tf.reduce_mean(tf.square(y_true - y_pred))

# Perceptual Loss (VGG特徴量を使用)
def perceptual_loss(y_true, y_pred, vgg_model):
    true_features = vgg_model(y_true)
    pred_features = vgg_model(y_pred)
    return tf.reduce_mean(tf.square(true_features - pred_features))

# Style Loss (Gram行列を使用)
def gram_matrix(x):
    channels = int(x.shape[-1])
    a = tf.reshape(x, [-1, channels])
    n = tf.shape(a)[0]
    gram = tf.matmul(a, a, transpose_a=True)
    return gram / tf.cast(n * channels, tf.float32)

def style_loss(y_true, y_pred, vgg_model):
    true_features = vgg_model(y_true)
    pred_features = vgg_model(y_pred)
    true_gram = gram_matrix(true_features)
    pred_gram = gram_matrix(pred_features)
    return tf.reduce_mean(tf.square(true_gram - pred_gram))
```

**5. 実践的なテクニック**

- **損失関数の組み合わせ:** 複数の損失関数を組み合わせて使用することで、より複雑なタスクに対応できます（例：Dice 損失とクロスエントロピー損失の組み合わせ）。
- **損失関数の重み付け:** 各損失関数の重要度に応じて重み付けを調整します。
- **カスタム損失関数の設計:** 特定のタスクに合わせて、独自の損失関数を設計します。

**6. 応用例とユースケース**

- **土地被覆分類:** Dice 損失とクロスエントロピー損失を組み合わせて、土地被覆分類の精度を向上させます。
- **超解像:** MSE 損失と Perceptual Loss を組み合わせて、高解像度画像のリアリティを向上させます。
- **スタイル変換:** Style Loss を使用して、衛星画像を特定のスタイルに変換します。

**7. トラブルシューティング**

- **学習が進まない:** 損失関数の重み付けを調整するか、異なる損失関数を試します。
- **生成される画像の品質が低い:** データセットを増やすか、プロンプトを改善します。
- **勾配消失:** 勾配クリッピングを適用するか、異なる活性化関数を使用します。
