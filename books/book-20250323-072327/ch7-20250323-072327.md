## 第 7 章：LoRA の応用 - 様々な地球観測タスクへの挑戦

地球観測衛星から得られるデータは、環境モニタリング、都市計画、災害対策など、様々な分野で活用されています。しかし、これらのデータを効果的に利用するには、高度な画像処理技術や機械学習モデルが必要となります。本章では、近年注目を集めている LoRA（Low-Rank Adaptation）という手法を用いて、地球観測タスクの精度向上と効率化を目指します。LoRA は、事前学習済みの大規模モデルを特定のタスクに適応させるための手法であり、少ないパラメータで高い性能を発揮できるという利点があります。

### 7.1 土地被覆分類 - 衛星画像から土地利用を分類する

#### 概要と重要性

土地被覆分類は、衛星画像から土地の利用状況を識別するタスクです。農地、森林、市街地、水域など、様々な土地被覆タイプを分類することで、環境変化のモニタリングや都市計画、農業管理などに役立てられます。

#### 特徴と利点

LoRA を土地被覆分類に適用する利点は、以下の通りです。

- **計算コストの削減:** 大規模なモデル全体を再学習する代わりに、LoRA は少数のパラメータのみを学習するため、計算コストを大幅に削減できます。
- **迅速な適応:** 新しい地域や異なるセンサーからのデータに対して、迅速にモデルを適応させることができます。
- **高い汎化性能:** 事前学習済みのモデルの知識を活用することで、限られたデータでも高い汎化性能を発揮できます。

#### 事前準備と前提条件

- **環境:** Python 3.8 以上、PyTorch 1.10 以上、transformers ライブラリ、rasterio ライブラリ。
- **データセット:** EuroSAT, BigEarthNet など、土地被覆分類のための公開データセットを使用します。独自のデータセットを使用する場合は、各画像に土地被覆タイプのアノテーションが必要です。
- **事前学習済みモデル:** ResNet, EfficientNet など、画像認識で優れた性能を発揮する事前学習済みモデルを用意します。Hugging Face Transformers ライブラリからダウンロードできます。

#### 基本的な使い方

1.  **データセットの準備:**
    EuroSAT データセットをダウンロードし、訓練データと検証データに分割します。

    ```python
    import os
    import rasterio
    import numpy as np
    from sklearn.model_selection import train_test_split

    data_dir = "path/to/eurosat/rgb"  # EuroSAT RGB画像のディレクトリ
    labels = [d for d in os.listdir(data_dir) if os.path.isdir(os.path.join(data_dir, d))]
    image_paths = []
    image_labels = []

    for label in labels:
        label_dir = os.path.join(data_dir, label)
        for image_file in os.listdir(label_dir):
            if image_file.endswith(".jpg"):
                image_paths.append(os.path.join(label_dir, image_file))
                image_labels.append(label)

    # ラベルを数値に変換
    unique_labels = sorted(list(set(image_labels)))
    label_to_id = {label: i for i, label in enumerate(unique_labels)}
    numeric_labels = [label_to_id[label] for label in image_labels]

    # データセットを訓練データと検証データに分割
    train_paths, val_paths, train_labels, val_labels = train_test_split(
        image_paths, numeric_labels, test_size=0.2, random_state=42
    )
    ```

2.  **モデルの構築:**
    ResNet をベースに、LoRA を適用した土地被覆分類モデルを構築します。

    ```python
    import torch
    import torch.nn as nn
    from torchvision import models, transforms
    from PIL import Image

    class LoRALinear(nn.Module):
        def __init__(self, in_features, out_features, r=8, alpha=1):
            super().__init__()
            self.lora_A = nn.Linear(in_features, r, bias=False)
            self.lora_B = nn.Linear(r, out_features, bias=False)
            nn.init.zeros_(self.lora_A.weight)
            nn.init.zeros_(self.lora_B.weight)
            self.scaling = alpha / r

        def forward(self, x):
            return x + self.lora_B(self.lora_A(x)) * self.scaling

    class LoRAResNet(nn.Module):
        def __init__(self, num_classes=10, r=8, alpha=1):
            super().__init__()
            self.resnet = models.resnet18(pretrained=True)
            # ResNetの最後の全結合層をLoRAで置き換える
            num_ftrs = self.resnet.fc.in_features
            self.resnet.fc = LoRALinear(num_ftrs, num_classes, r=r, alpha=alpha)

        def forward(self, x):
            return self.resnet(x)


    # モデルのインスタンス化
    model = LoRAResNet(num_classes=len(unique_labels))
    ```

3.  **学習の準備:**
    損失関数、最適化アルゴリズム、学習率などを設定します。

    ```python
    import torch.optim as optim

    # 損失関数
    criterion = nn.CrossEntropyLoss()

    # 最適化アルゴリズム
    optimizer = optim.Adam(model.parameters(), lr=0.001) # LoRAパラメータのみ学習される
    ```

4.  **学習の実行:**
    訓練データを用いてモデルを学習させます。

    ```python
    from torch.utils.data import Dataset, DataLoader
    from PIL import Image

    class CustomDataset(Dataset):
        def __init__(self, image_paths, labels, transform=None):
            self.image_paths = image_paths
            self.labels = labels
            self.transform = transform

        def __len__(self):
            return len(self.image_paths)

        def __getitem__(self, idx):
            image_path = self.image_paths[idx]
            image = Image.open(image_path).convert('RGB')
            label = self.labels[idx]

            if self.transform:
                image = self.transform(image)

            return image, label

    # データ変換
    data_transforms = transforms.Compose([
        transforms.Resize((224, 224)),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
    ])

    # データセットの作成
    train_dataset = CustomDataset(train_paths, train_labels, transform=data_transforms)
    val_dataset = CustomDataset(val_paths, val_labels, transform=data_transforms)

    # データローダーの作成
    train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)

    # 学習ループ
    num_epochs = 10
    device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")
    model.to(device)

    for epoch in range(num_epochs):
        model.train()
        running_loss = 0.0
        for inputs, labels in train_loader:
            inputs = inputs.to(device)
            labels = labels.to(device)

            optimizer.zero_grad()

            outputs = model(inputs)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()

            running_loss += loss.item()

        print(f"Epoch {epoch+1}/{num_epochs}, Loss: {running_loss/len(train_loader)}")

        # 検証ループ (オプション)
        model.eval()
        correct = 0
        total = 0
        with torch.no_grad():
            for inputs, labels in val_loader:
                inputs = inputs.to(device)
                labels = labels.to(device)
                outputs = model(inputs)
                _, predicted = torch.max(outputs.data, 1)
                total += labels.size(0)
                correct += (predicted == labels).sum().item()

        print(f"Validation Accuracy: {100 * correct / total}%")

    print("Finished Training")
    ```

#### 実践的なテクニック

- **データ拡張:** 画像の回転、反転、拡大縮小などのデータ拡張を適用することで、モデルの汎化性能を向上させることができます。
- **学習率の調整:** 学習率を適切に調整することで、学習の安定性と収束速度を向上させることができます。
- **LoRA のランク調整:** LoRA のランク（`r`パラメータ）を調整することで、モデルの表現能力と計算コストのバランスを取ることができます。ランクを高くすると表現能力は向上しますが、計算コストも増加します。

#### 応用例とユースケース

- **農地管理:** 衛星画像から農地の種類や作物の生育状況を分類し、施肥や灌漑の最適化に役立てることができます。
- **森林モニタリング:** 森林の伐採状況や森林火災の被害状況を把握し、森林保護に役立てることができます。
- **都市計画:** 市街地の拡大状況や土地利用の変化を把握し、都市計画に役立てることができます。

#### トラブルシューティング

- **メモリ不足:** 大規模なモデルや高解像度の画像を使用すると、メモリ不足になることがあります。バッチサイズを小さくしたり、画像の解像度を下げたりすることで、メモリ使用量を削減できます。
- **過学習:** 訓練データに過剰に適合してしまうと、未知のデータに対する汎化性能が低下します。データ拡張や正則化などの手法を用いることで、過学習を抑制できます。

#### まとめと次のステップ

LoRA を用いることで、計算コストを抑えつつ、土地被覆分類の精度を向上させることが可能です。今後は、より大規模なデータセットや複雑なモデルを用いて、LoRA の性能をさらに探求していくことが重要です。

### 7.2 変化検知 - 時系列衛星画像から変化を検出する

#### 概要と重要性

変化検知は、同一地域における異なる時点の衛星画像を比較し、その間に生じた変化を検出するタスクです。森林破壊、都市開発、災害発生など、様々な変化を把握することができます。

#### 特徴と利点

LoRA を変化検知に適用する利点は、以下の通りです。

- **少ないデータでの学習:** 変化検知タスクは、変化が生じた箇所のデータが少ないことが一般的です。LoRA を用いることで、少ないデータでも効果的な学習が可能です。
- **異なるセンサーへの対応:** 異なるセンサーで撮影された画像に対して、LoRA を用いることで、センサー間の差異を補正し、高精度な変化検知を実現できます。
- **計算資源の節約:** 大規模なモデル全体を再学習するのではなく、LoRA によって少数のパラメータを調整するため、計算資源を大幅に節約できます。

#### 事前準備と前提条件

- **環境:** Python 3.8 以上、PyTorch 1.10 以上、transformers ライブラリ、rasterio ライブラリ。
- **データセット:** Google Earth Engine (GEE) や Sentinel Hub などのプラットフォームから、時系列衛星画像データセットを収集します。変化が生じた箇所のアノテーションが必要です。
- **事前学習済みモデル:** ResNet, EfficientNet など、画像認識で優れた性能を発揮する事前学習済みモデルを用意します。Hugging Face Transformers ライブラリからダウンロードできます。

#### 基本的な使い方

1.  **データセットの準備:**
    変化前後の衛星画像ペアと、変化箇所のマスクデータを用意します。

    ```python
    import os
    import rasterio
    import numpy as np
    from PIL import Image
    from torch.utils.data import Dataset, DataLoader

    class ChangeDetectionDataset(Dataset):
        def __init__(self, image1_paths, image2_paths, mask_paths, transform=None):
            self.image1_paths = image1_paths
            self.image2_paths = image2_paths
            self.mask_paths = mask_paths
            self.transform = transform

        def __len__(self):
            return len(self.image1_paths)

        def __getitem__(self, idx):
            image1_path = self.image1_paths[idx]
            image2_path = self.image2_paths[idx]
            mask_path = self.mask_paths[idx]

            image1 = Image.open(image1_path).convert('RGB')
            image2 = Image.open(image2_path).convert('RGB')
            mask = Image.open(mask_path).convert('L') # グレースケール

            if self.transform:
                image1 = self.transform(image1)
                image2 = self.transform(image2)
                mask = self.transform(mask)

            return image1, image2, mask
    ```

2.  **モデルの構築:**
    Siamese Network をベースに、LoRA を適用した変化検知モデルを構築します。

    ```python
    import torch
    import torch.nn as nn
    from torchvision import models, transforms
    import torch.nn.functional as F

    class LoRALinear(nn.Module):
        def __init__(self, in_features, out_features, r=8, alpha=1):
            super().__init__()
            self.lora_A = nn.Linear(in_features, r, bias=False)
            self.lora_B = nn.Linear(r, out_features, bias=False)
            nn.init.zeros_(self.lora_A.weight)
            nn.init.zeros_(self.lora_B.weight)
            self.scaling = alpha / r

        def forward(self, x):
            return x + self.lora_B(self.lora_A(x)) * self.scaling

    class SiameseNetwork(nn.Module):
        def __init__(self, r=8, alpha=1):
            super(SiameseNetwork, self).__init__()
            self.resnet = models.resnet18(pretrained=True)
            # ResNetの最終層を削除
            self.resnet = nn.Sequential(*list(self.resnet.children())[:-1])

            # LoRAを適用
            self.fc1 = LoRALinear(512, 256, r=r, alpha=alpha)
            self.fc2 = LoRALinear(256, 128, r=r, alpha=alpha)
            self.fc3 = LoRALinear(128, 1, r=r, alpha=alpha) # 出力は変化の有無

        def forward_once(self, x):
            output = self.resnet(x)
            output = output.view(output.size()[0], -1) # Flatten
            return output

        def forward(self, input1, input2):
            output1 = self.forward_once(input1)
            output2 = self.forward_once(input2)

            # 特徴量間の距離を計算
            distance = F.pairwise_distance(output1, output2)

            # 全結合層で変化の有無を判定
            x = F.relu(self.fc1(distance.unsqueeze(1))) # distanceをunsqueezeして次元を合わせる
            x = F.relu(self.fc2(x))
            x = torch.sigmoid(self.fc3(x)) # 0-1の確率値を出力

            return x
    ```

#### 実践的なテクニック

- **データ拡張:** 画像の回転、反転、拡大縮小などのデータ拡張を適用することで、モデルの汎化性能を向上させることができます。特に、変化が生じた箇所を重点的に拡張すると効果的です。
- **バンドの組み合わせ:** 衛星画像の異なるバンドを組み合わせることで、変化の検出精度を向上させることができます。
- **時間窓の設定:** 変化を検出する時間窓を適切に設定することで、季節変動などのノイズを低減することができます。

#### 応用例とユースケース

- **森林破壊の監視:** 森林の伐採状況を定期的に監視し、違法伐採の早期発見に役立てることができます。
- **都市開発のモニタリング:** 都市の拡大状況や土地利用の変化を把握し、都市計画に役立てることができます。
- **災害後の被害状況把握:** 地震や洪水などの災害発生後、被害状況を迅速に把握し、救助活動や復旧計画に役立てることができます。

#### トラブルシューティング

- **偽陽性:** 変化していない箇所を誤って変化として検出してしまうことがあります。時間窓の設定やバンドの組み合わせを工夫することで、偽陽性を低減できます。
- **偽陰性:** 実際には変化している箇所を検出できないことがあります。データ拡張やモデルのアーキテクチャを改善することで、偽陰性を低減できます。

#### まとめと次のステップ

LoRA を用いることで、変化検知の精度向上と効率化を両立させることが可能です。今後は、より複雑な変化パターンを検出するために、Transformer などの高度なモデルを LoRA と組み合わせて利用していくことが期待されます。

### 7.3 超解像 - 低解像度画像を高品質化する

#### 概要と重要性

超解像は、低解像度（LR）画像から高解像度（HR）画像を生成するタスクです。衛星画像の解像度が低い場合でも、超解像技術を用いることで、より詳細な情報を取得し、分析の精度を向上させることができます。

#### 特徴と利点

LoRA を超解像に適用する利点は、以下の通りです。

- **計算コストの削減:** GAN のような複雑なモデルを超解像に用いる場合、学習コストが大きくなります。LoRA を用いることで、既存のモデルを効率的に適応させることができます。
- **メモリ効率:** 大規模なモデル全体を保存する必要がないため、メモリ使用量を削減できます。
- **高速な推論:** モデルのサイズが小さいため、高速な推論が可能です。

#### 事前準備と前提条件

- **環境:** Python 3.8 以上、PyTorch 1.10 以上、transformers ライブラリ、rasterio ライブラリ。
- **データセット:** Sentinel-2 や Landsat などの衛星画像データセットを使用します。LR 画像と HR 画像のペアが必要です。
- **事前学習済みモデル:** SRGAN, ESRGAN などの超解像モデルをベースに、LoRA を適用します。Hugging Face Transformers ライブラリで公開されているモデルを使用することも可能です。

#### 基本的な使い方

1.  **データセットの準備:**
    低解像度画像と高解像度画像のペアを用意します。

    ```python
    import os
    import rasterio
    import numpy as np
    from PIL import Image
    from torch.utils.data import Dataset, DataLoader

    class SRDataset(Dataset):
        def __init__(self, lr_paths, hr_paths, transform=None):
            self.lr_paths = lr_paths
            self.hr_paths = hr_paths
            self.transform = transform

        def __len__(self):
            return len(self.lr_paths)

        def __getitem__(self, idx):
            lr_path = self.lr_paths[idx]
            hr_path = self.hr_paths[idx]

            lr_image = Image.open(lr_path).convert('RGB')
            hr_image = Image.open(hr_path).convert('RGB')

            if self.transform:
                lr_image = self.transform(lr_image)
                hr_image = self.transform(hr_image)

            return lr_image, hr_image
    ```

2.  **モデルの構築:**
    SRGAN をベースに、LoRA を適用した超解像モデルを構築します。SRGAN の Discriminator 部分に LoRA を適用するのが効果的です。

    ```python
    import torch
    import torch.nn as nn
    from torchvision import models, transforms
    import torch.nn.functional as F

    # LoRAレイヤーの定義 (上記と同様)
    class LoRALinear(nn.Module):
        def __init__(self, in_features, out_features, r=8, alpha=1):
            super().__init__()
            self.lora_A = nn.Linear(in_features, r, bias=False)
            self.lora_B = nn.Linear(r, out_features, bias=False)
            nn.init.zeros_(self.lora_A.weight)
            nn.init.zeros_(self.lora_B.weight)
            self.scaling = alpha / r

        def forward(self, x):
            return x + self.lora_B(self.lora_A(x)) * self.scaling

    # SRGANのDiscriminator
    class Discriminator(nn.Module):
        def __init__(self, r=8, alpha=1):
            super(Discriminator, self).__init__()
            self.net = nn.Sequential(
                nn.Conv2d(3, 64, kernel_size=3, padding=1),
                nn.LeakyReLU(0.2),

                nn.Conv2d(64, 64, kernel_size=3, stride=2, padding=1),
                nn.BatchNorm2d(64),
                nn.LeakyReLU(0.2),

                nn.Conv2d(64, 128, kernel_size=3, padding=1),
                nn.BatchNorm2d(128),
                nn.LeakyReLU(0.2),

                nn.Conv2d(128, 128, kernel_size=3, stride=2, padding=1),
                nn.BatchNorm2d(128),
                nn.LeakyReLU(0.2),

                nn.Conv2d(128, 256, kernel_size=3, padding=1),
                nn.BatchNorm2d(256),
                nn.LeakyReLU(0.2),

                nn.Conv2d(256, 256, kernel_size=3, stride=2, padding=1),
                nn.BatchNorm2d(256),
                nn.LeakyReLU(0.2),

                nn.Conv2d(256, 512, kernel_size=3, padding=1),
                nn.BatchNorm2d(512),
                nn.LeakyReLU(0.2),

                nn.Conv2d(512, 512, kernel_size=3, stride=2, padding=1),
                nn.BatchNorm2d(512),
                nn.LeakyReLU(0.2),

                nn.AdaptiveAvgPool2d(1),
                nn.Flatten(),
                LoRALinear(512, 1, r=r, alpha=alpha)  # LoRAを適用
            )

        def forward(self, img):
            validity = self.net(img)
            return validity
    ```

3.  **学習の準備:**
    損失関数、最適化アルゴリズム、学習率などを設定します。SRGAN では、Generator と Discriminator の両方を学習する必要があります。

4.  **学習の実行:**
    訓練データを用いてモデルを学習させます。

5.  **評価:**
    検証データを用いてモデルの性能を評価します。PSNR, SSIM などの指標を用いて評価します。

#### 実践的なテクニック

- **敵対的損失:** SRGAN のように、敵対的損失を用いることで、より自然な画像を生成することができます。
- **知覚損失:** 知覚損失（Perceptual Loss）を用いることで、画像の質感や構造を保持することができます。
- **マルチスケール学習:** 異なる解像度の画像を用いて学習することで、モデルの汎化性能を向上させることができます。

#### 応用例とユースケース

- **古い航空写真の復元:** 解像度の低い古い航空写真を高解像度化し、過去の土地利用状況を分析することができます。
- **監視カメラの映像の高画質化:** 解像度の低い監視カメラの映像を高画質化し、犯罪捜査に役立てることができます。
- **医療画像の鮮明化:** 解像度の低い医療画像を鮮明化し、診断精度を向上させることができます。

#### トラブルシューティング

- **アーティファクト:** 生成された画像に、不自然な模様やノイズが発生することがあります。損失関数の重みやモデルのアーキテクチャを調整することで、アーティファクトを低減できます。
- **過剰な平滑化:** 生成された画像が、過剰に平滑化されてしまうことがあります。知覚損失を用いることで、画像のシャープネスを維持できます。

#### まとめと次のステップ

LoRA を用いることで、計算コストを抑えつつ、超解像の精度を向上させることが可能です。今後は、より複雑なモデルやデータセットを用いて、LoRA の性能をさらに探求していくことが重要です。

### 7.4 災害モニタリング - 災害状況を迅速に把握する

#### 概要と重要性

災害モニタリングは、災害発生前後の衛星画像を比較し、被害状況を迅速に把握するタスクです。洪水、地震、火災など、様々な災害に対して、被害範囲や被害程度を推定することができます。

#### 特徴と利点

LoRA を災害モニタリングに適用する利点は、以下の通りです。

- **緊急時対応:** 災害発生直後など、限られた時間で迅速にモデルを適応させる必要があります。LoRA を用いることで、迅速な適応が可能です。
- **異なる災害タイプへの対応:** 異なる災害タイプ（洪水、地震、火災など）に対して、LoRA を用いることで、柔軟に対応できます。
- **データの不足:** 災害発生直後は、十分なデータが得られないことがあります。LoRA を用いることで、少ないデータでも効果的な学習が可能です。

#### 事前準備と前提条件

- **環境:** Python 3.8 以上、PyTorch 1.10 以上、transformers ライブラリ、rasterio ライブラリ。
- **データセット:** 災害発生前後の衛星画像データセットを収集します。災害の種類や被害範囲のアノテーションが必要です。
- **事前学習済みモデル:** セマンティックセグメンテーションモデル（UNet, DeepLabv3+など）をベースに、LoRA を適用します。Hugging Face Transformers ライブラリで公開されているモデルを使用することも可能です。

#### 基本的な使い方

1.  **データセットの準備:**
    災害発生前後の衛星画像ペアと、被害箇所のマスクデータを用意します。

2.  **モデルの構築:**
    UNet をベースに、LoRA を適用したセマンティックセグメンテーションモデルを構築します。

3.  **学習の準備:**
    損失関数、最適化アルゴリズム、学習率などを設定します。

4.  **学習の実行:**
    訓練データを用いてモデルを学習させます。

5.  **評価:**
    検証データを用いてモデルの性能を評価します。IoU (Intersection over Union) などの指標を用いて評価します。

#### 実践的なテクニック

- **マルチモーダルデータ:** 衛星画像だけでなく、レーダーデータや DEM（数値標高モデル）などのマルチモーダルデータを組み合わせることで、被害状況の推定精度を向上させることができます。
- **Transfer Learning:** 過去の災害データを用いてモデルを事前学習し、新しい災害データに対して LoRA を適用することで、学習効率を向上させることができます。
- **アンサンブル学習:** 複数のモデルを組み合わせることで、推定精度の安定性を向上させることができます。

#### 応用例とユースケース

- **洪水の被害範囲推定:** 洪水発生前後の衛星画像を比較し、浸水範囲を推定することができます。
- **地震の建物被害推定:** 地震発生前後の衛星画像を比較し、建物の倒壊状況を推定することができます。
- **火災の焼失面積推定:** 火災発生前後の衛星画像を比較し、焼失面積を推定することができます。

#### トラブルシューティング

- **雲の影響:** 衛星画像に雲がかかっていると、地表面の状況を正確に把握できません。雲除去技術やレーダーデータを用いることで、雲の影響を低減できます。
- **影の影響:** 建物や地形の影の影響で、被害状況の推定が困難になることがあります。影の影響を補正する技術を用いることで、推定精度を向上させることができます。

#### まとめと次のステップ

LoRA を用いることで、災害モニタリングの迅速性と精度を向上させることが可能です。今後は、より高度なモデルやマルチモーダルデータを用いて、LoRA の性能をさらに探求していくことが重要です。また、推定結果を可視化し、関係機関に迅速に情報提供できるようなシステム構築も重要となります。

本章では、LoRA を地球観測タスクに適用する例をいくつか紹介しました。LoRA は、計算資源が限られた環境でも、既存のモデルを効率的に適応させることができる強力な手法です。ぜひ、本章で紹介したテクニックを参考に、LoRA を自身の地球観測タスクに適用してみてください。地球観測データと LoRA の組み合わせは、持続可能な社会の実現に貢献できる可能性を秘めています。
