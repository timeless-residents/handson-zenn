## 第 3 章：環境構築 - 開発環境と必要なツールを準備する

この章では、衛星データを用いた機械学習開発に必要な環境構築について解説します。ローカル環境、クラウド環境、そして Docker コンテナの利用方法について、具体的な手順とコード例を交えながら説明します。また、PyTorch や Transformers といった主要なライブラリのインストールから、衛星データのダウンロードと前処理まで、一連のワークフローを網羅的にカバーします。

### 3.1 開発環境の構築 - GPU 環境の準備（ローカル、クラウド）

GPU は、衛星画像のような大規模データを扱う機械学習において、計算速度を飛躍的に向上させるために不可欠です。ここでは、ローカル環境とクラウド環境、それぞれの構築方法を解説します。

#### 3.1.1 ローカル環境構築（CUDA、cuDNN のインストール、ドライバの注意点）

**概要と重要性:** ローカル環境は、インターネット接続に依存せず、自由にカスタマイズできる点が魅力です。特に、GPU を搭載した PC を用意することで、クラウド環境に匹敵する計算能力を手軽に利用できます。

**特徴と利点:**

- **コスト:** 一度環境を構築すれば、継続的な利用料金は発生しません。
- **カスタマイズ:** 環境を細かく制御でき、独自のライブラリやツールを自由にインストールできます。
- **オフライン:** インターネット接続がない環境でも開発可能です。

**事前準備と前提条件:**

- NVIDIA 製 GPU 搭載の PC
- 対応する NVIDIA ドライバ

**基本的な使い方:**

1.  **NVIDIA ドライバのインストール:**

    - NVIDIA の公式サイトから、GPU モデルに合った最新ドライバをダウンロードし、インストールします。
    - **注意点:** ドライバのバージョンは、CUDA や cuDNN のバージョンと互換性がある必要があります。互換性情報は NVIDIA のドキュメントで確認しましょう。

    ```bash
    # Ubuntuの場合
    sudo apt update
    sudo apt install nvidia-driver-<最新バージョン>
    ```

2.  **CUDA Toolkit のインストール:**

    - CUDA Toolkit は、NVIDIA GPU 上で動作するアプリケーションを開発するためのツールキットです。
    - NVIDIA の公式サイトから、OS と GPU に対応したバージョンをダウンロードし、インストールします。
    - **注意点:** CUDA Toolkit のインストールパスは、環境変数に設定する必要があります。

    ```bash
    # Ubuntuの場合
    wget https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2004/x86_64/cuda-ubuntu2004.pin
    sudo mv cuda-ubuntu2004.pin /etc/apt/preferences.d/cuda-repository-pin-600
    sudo apt-key adv --fetch-keys https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2004/x86_64/7fa2af80.pub
    sudo add-apt-repository "deb http://developer.download.nvidia.com/compute/cuda/repos/ubuntu2004/x86_64 /"
    sudo apt update
    sudo apt install cuda
    ```

    インストール後、環境変数を設定します。

    ```bash
    export CUDA_HOME=/usr/local/cuda
    export PATH=$CUDA_HOME/bin:$PATH
    export LD_LIBRARY_PATH=$CUDA_HOME/lib64:$LD_LIBRARY_PATH
    ```

    `.bashrc` や `.zshrc` などの設定ファイルに追記しておくと便利です。

3.  **cuDNN のインストール:**

    - cuDNN は、ディープラーニングの計算を高速化するためのライブラリです。
    - NVIDIA の公式サイトから、CUDA Toolkit のバージョンに対応した cuDNN をダウンロードし、解凍します。
    - 解凍したファイルを CUDA Toolkit のディレクトリにコピーします。

    ```bash
    # 例：CUDA 11.xの場合
    sudo cp cuda/include/cudnn*.h /usr/local/cuda/include
    sudo cp cuda/lib64/libcudnn* /usr/local/cuda/lib64
    sudo chmod a+r /usr/local/cuda/include/cudnn*.h /usr/local/cuda/lib64/libcudnn*
    ```

4.  **動作確認:**

    - CUDA が正しくインストールされているかを確認するため、以下のコマンドを実行します。

    ```bash
    nvcc --version
    ```

    CUDA のバージョン情報が表示されれば成功です。

**実践的なテクニック:**

- 複数の CUDA Toolkit をインストールし、切り替えて使用することも可能です。`update-alternatives`コマンドを使用すると便利です。
- Anaconda 環境を利用する場合、CUDA Toolkit を Anaconda 環境にインストールすることも可能です。

**応用例とユースケース:**

- ローカル環境でのモデル開発、学習、推論。
- 実験的なアルゴリズムの開発。
- オフライン環境でのデータ処理。

**トラブルシューティング:**

- **ドライバのバージョンが古い:** 最新のドライバにアップデートしてください。
- **CUDA Toolkit のインストールパスが間違っている:** 環境変数を正しく設定してください。
- **cuDNN のファイルが正しくコピーされていない:** ファイルのコピー先と権限を確認してください。
- **CUDA のバージョンと PyTorch のバージョンが合っていない:** PyTorch のインストール時に適切な CUDA バージョンを指定してください。（後述）

**まとめと次のステップ:**

ローカル環境の構築は、初期設定に手間がかかるものの、長期的に見るとコストパフォーマンスに優れています。次のステップでは、クラウド環境の構築について解説します。

#### 3.1.2 クラウド環境構築（Google Colab、AWS SageMaker、Azure Machine Learning）

**概要と重要性:** クラウド環境は、初期費用を抑え、必要な時に必要なリソースを利用できる点が魅力です。特に、GPU を搭載したインスタンスを簡単に利用できるため、大規模なデータ処理や複雑なモデルの学習に適しています。

**特徴と利点:**

- **スケーラビリティ:** 必要に応じてリソースを柔軟に拡張できます。
- **コスト:** 使った分だけ料金を支払う従量課金制です。
- **手軽さ:** 環境構築の手間が省けます。
- **共同作業:** チームでの共同作業に適しています。

**事前準備と前提条件:**

- Google アカウント (Google Colab)
- AWS アカウント (AWS SageMaker)
- Azure アカウント (Azure Machine Learning)

**基本的な使い方:**

1.  **Google Colab:**

    - Google アカウントでログインし、Google Colab のノートブックを作成します。
    - メニューから「ランタイム」→「ランタイムのタイプを変更」を選択し、「GPU」を選択します。
    - 以下のコードを実行し、GPU が認識されていることを確認します。

    ```python
    import torch
    print(torch.cuda.is_available())
    ```

    `True`と表示されれば成功です。

2.  **AWS SageMaker:**

    - AWS マネジメントコンソールから SageMaker Studio を開きます。
    - ノートブックインスタンスを作成し、必要なスペック（GPU インスタンスを選択）を設定します。
    - ノートブックを開き、同様に GPU が認識されていることを確認します。

3.  **Azure Machine Learning:**

    - Azure ポータルから Machine Learning ワークスペースを作成します。
    - コンピューティングインスタンスを作成し、必要なスペック（GPU インスタンスを選択）を設定します。
    - Jupyter Notebook を開き、同様に GPU が認識されていることを確認します。

**実践的なテクニック:**

- **Google Colab:** Google Drive と連携させることで、データの読み書きが容易になります。
- **AWS SageMaker:** Docker コンテナを利用することで、環境の再現性を高めることができます。
- **Azure Machine Learning:** パイプライン機能を利用することで、機械学習ワークフローを自動化できます。

**応用例とユースケース:**

- 大規模な衛星画像の解析。
- 深層学習モデルの学習。
- リアルタイムでの異常検知。

**トラブルシューティング:**

- **GPU が認識されない:** ランタイムタイプが GPU に設定されているか確認してください。
- **ストレージ容量が不足する:** Google Drive や S3 などの外部ストレージを利用してください。
- **インスタンスの料金が高い:** スポットインスタンスを利用したり、不要なインスタンスを停止したりすることでコストを削減できます。

**まとめと次のステップ:**

クラウド環境は、手軽に高性能な計算資源を利用できるため、開発効率を大幅に向上させることができます。次のステップでは、Docker コンテナの利用について解説します。

#### 3.1.3 Docker コンテナの利用

**概要と重要性:** Docker コンテナは、アプリケーションとその依存関係をまとめてパッケージングし、異なる環境でも同じように動作させるための技術です。開発環境の再現性を高め、チームでの共同作業を円滑に進めることができます。

**特徴と利点:**

- **再現性:** 開発環境を完全に再現できます。
- **移植性:** 異なる環境でも同じように動作します。
- **隔離性:** アプリケーション間の干渉を防ぎます。
- **軽量性:** 仮想マシンよりも軽量です。

**事前準備と前提条件:**

- Docker のインストール
- Docker Compose のインストール（任意）

**基本的な使い方:**

1.  **Dockerfile の作成:**

    - Dockerfile は、Docker イメージを構築するための設計図です。
    - ベースイメージ（例：Ubuntu、CentOS）を指定し、必要なライブラリやツールをインストールする手順を記述します。

    ```dockerfile
    FROM ubuntu:latest

    # 必要なパッケージをインストール
    RUN apt-get update && apt-get install -y \
        python3 \
        python3-pip \
        git \
        ...

    # PyTorchをインストール
    RUN pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu116

    # 作業ディレクトリを設定
    WORKDIR /app

    # ソースコードをコピー
    COPY . .

    # コマンドを実行
    CMD ["python3", "main.py"]
    ```

2.  **Docker イメージの構築:**

    - Dockerfile があるディレクトリで、以下のコマンドを実行します。

    ```bash
    docker build -t my-image .
    ```

    `-t`オプションは、イメージにタグ（名前）を付けるために使用します。

3.  **Docker コンテナの実行:**

    - 以下のコマンドを実行し、Docker コンテナを実行します。

    ```bash
    docker run -it --gpus all -v $(pwd):/app my-image
    ```

    `-it`オプションは、コンテナにインタラクティブに接続するために使用します。
    `--gpus all`オプションは、コンテナに GPU を割り当てるために使用します。
    `-v $(pwd):/app`オプションは、ホストの現在のディレクトリをコンテナ内の`/app`ディレクトリにマウントするために使用します。

**実践的なテクニック:**

- **Docker Compose:** 複数のコンテナをまとめて管理するためのツールです。
- **Docker Hub:** Docker イメージを共有するためのレジストリです。
- **`.dockerignore`:** Docker イメージに含めたくないファイルやディレクトリを指定するためのファイルです。

**応用例とユースケース:**

- 異なる OS やバージョンの環境でのアプリケーションの実行。
- 開発環境の標準化。
- CI/CD パイプラインへの組み込み。

**トラブルシューティング:**

- **イメージのビルドに失敗する:** Dockerfile の記述に誤りがないか確認してください。
- **コンテナの実行に失敗する:** 必要なポートが公開されているか、必要なファイルがマウントされているか確認してください。
- **GPU が認識されない:** `--gpus all`オプションが指定されているか確認してください。

**まとめと次のステップ:**

Docker コンテナは、開発環境の管理を効率化し、アプリケーションの移植性を高めるための強力なツールです。次のステップでは、必要なライブラリのインストールについて解説します。

### 3.2 必要なライブラリのインストール - PyTorch、Transformers、その他

衛星データを用いた機械学習には、PyTorch、Transformers といった主要なライブラリだけでなく、データ処理に必要な様々なライブラリが必要です。ここでは、これらのライブラリのインストール方法について解説します。

#### 3.2.1 PyTorch のインストール（CUDA バージョンの選択）

**概要と重要性:** PyTorch は、柔軟性と高速性を兼ね備えた、機械学習・深層学習のためのオープンソースフレームワークです。GPU を活用した高速な計算が可能で、衛星画像解析においても広く利用されています。

**特徴と利点:**

- **動的グラフ:** 柔軟なモデル構築が可能です。
- **GPU サポート:** 高速な計算が可能です。
- **豊富な機能:** 様々なモデルや最適化アルゴリズムが利用可能です。
- **活発なコミュニティ:** 情報共有やサポートが充実しています。

**事前準備と前提条件:**

- Python のインストール
- pip のインストール
- CUDA のインストール（GPU 環境の場合）

**基本的な使い方:**

- PyTorch の公式サイトにアクセスし、環境に合ったインストールコマンドを確認します。
- 以下の例は、CUDA 11.6 に対応した PyTorch をインストールする場合のコマンドです。

  ```bash
  pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu116
  ```

  **重要:** CUDA のバージョンと PyTorch のバージョンは必ず一致させる必要があります。一致しない場合、GPU が正常に認識されないことがあります。

- インストール後、以下のコードを実行し、PyTorch が正しくインストールされていることを確認します。
  ```python
  import torch
  print(torch.__version__)
  print(torch.cuda.is_available())
  ```
  PyTorch のバージョンと`True`が表示されれば成功です。

**実践的なテクニック:**

- Anaconda 環境を利用している場合は、Anaconda で PyTorch をインストールすることも可能です。
  ```bash
  conda install pytorch torchvision torchaudio cudatoolkit=11.6 -c pytorch
  ```
- 開発環境に合わせて、CPU 版の PyTorch をインストールすることも可能です。
  ```bash
  pip3 install torch torchvision torchaudio
  ```

**応用例とユースケース:**

- 衛星画像のセグメンテーション。
- 衛星画像の物体検出。
- 衛星画像の異常検知。

**トラブルシューティング:**

- **PyTorch のインストールに失敗する:** pip のバージョンが古い場合、アップデートしてください。
- **GPU が認識されない:** CUDA のバージョンと PyTorch のバージョンが一致しているか確認してください。
- **cuda error が発生する:** GPU のメモリが不足している可能性があります。バッチサイズを小さくしたり、より高性能な GPU を使用したりしてください。

**まとめと次のステップ:**

PyTorch は、衛星画像解析のための強力なツールです。次のステップでは、Transformers ライブラリのインストールについて解説します。

#### 3.2.2 Transformers ライブラリのインストール（Hugging Face）

**概要と重要性:** Transformers ライブラリは、Hugging Face 社が開発した、自然言語処理のためのオープンソースライブラリです。近年では、画像認識分野にも応用されており、衛星画像解析においても注目されています。特に、事前学習済みのモデルを活用することで、少ないデータでも高い精度を実現できます。

**特徴と利点:**

- **豊富な事前学習済みモデル:** 様々なタスクに対応した事前学習済みモデルが利用可能です。
- **簡単な API:** シンプルな API で、簡単にモデルを扱うことができます。
- **GPU サポート:** 高速な計算が可能です。
- **活発なコミュニティ:** 情報共有やサポートが充実しています。

**事前準備と前提条件:**

- PyTorch のインストール
- pip のインストール

**基本的な使い方:**

- 以下のコマンドを実行し、Transformers ライブラリをインストールします。

  ```bash
  pip3 install transformers
  ```

- インストール後、以下のコードを実行し、Transformers ライブラリが正しくインストールされていることを確認します。
  ```python
  from transformers import pipeline
  classifier = pipeline("sentiment-analysis")
  result = classifier("I love transformers!")
  print(result)
  ```
  `[{'label': 'POSITIVE', 'score': 0.999...}]`のような結果が表示されれば成功です。

**実践的なテクニック:**

- 事前学習済みのモデルをファインチューニングすることで、特定のタスクに最適化できます。
- Hugging Face Hub を利用することで、様々なモデルやデータセットを共有できます。

**応用例とユースケース:**

- 衛星画像のシーン分類。
- 衛星画像のキャプション生成。
- 衛星画像の検索。

**トラブルシューティング:**

- **Transformers ライブラリのインストールに失敗する:** pip のバージョンが古い場合、アップデートしてください。
- **モデルのダウンロードに失敗する:** インターネット接続を確認してください。
- **メモリ不足のエラーが発生する:** より小さなモデルを使用したり、バッチサイズを小さくしたりしてください。

**まとめと次のステップ:**

Transformers ライブラリは、衛星画像解析の可能性を広げるための強力なツールです。次のステップでは、その他必要なライブラリのインストールについて解説します。

### 3.3 データセットの準備 - 衛星データのダウンロードと前処理

衛星データは、様々な形式で提供されており、前処理が必要な場合が多いです。ここでは、衛星データのダウンロードから前処理まで、一連のワークフローを解説します。

#### 3.3.1 衛星データのダウンロード方法（API の利用、Web サイトからのダウンロード）

**概要と重要性:** 衛星データは、様々な機関や企業から提供されています。データの種類や利用条件は、提供元によって異なります。ここでは、代表的なデータソースとそのダウンロード方法について解説します。

**データソース:**

- **Landsat:** アメリカ地質調査所（USGS）が提供する、地球観測衛星のデータです。
- **Sentinel:** 欧州宇宙機関（ESA）が提供する、地球観測衛星のデータです。
- **MODIS:** NASA が提供する、地球観測衛星のデータです。
- **Planet:** Planet Labs 社が提供する、高分解能の地球観測衛星のデータです（商用）。

**ダウンロード方法:**

1.  **Web サイトからのダウンロード:**

    - USGS EarthExplorer、ESA Copernicus Open Access Hub などの Web サイトから、手動でデータをダウンロードします。
    - データの検索条件（地域、期間、センサーなど）を指定し、必要なデータをダウンロードします。

2.  **API の利用:**

    - USGS EarthExplorer API、ESA Copernicus Services API などの API を利用して、プログラムから自動でデータをダウンロードします。
    - API を利用することで、大量のデータを効率的にダウンロードできます。

    ```python
    # 例：sentinelsatライブラリを用いたSentinel-2データのダウンロード
    from sentinelsat import SentinelAPI, read_geojson, geojson_to_wkt
    from datetime import date

    api = SentinelAPI('YOUR_USER', 'YOUR_PASSWORD', 'https://scihub.copernicus.eu/dhus')

    footprint = geojson_to_wkt(read_geojson('area.geojson'))

    products = api.query(footprint,
                         date=('20230101', date(2023, 1, 31)),
                         platformname='Sentinel-2',
                         cloudcoverpercentage=(0, 30))

    api.download_all(products)
    ```

**実践的なテクニック:**

- データのダウンロードを自動化するために、スクリプトを作成すると便利です。
- ダウンロードしたデータを整理するために、フォルダ構造を設計すると便利です。

**応用例とユースケース:**

- 特定の地域の土地被覆変化の分析。
- 自然災害の被害状況の把握。
- 農作物の生育状況のモニタリング。

**トラブルシューティング:**

- **データのダウンロードに失敗する:** インターネット接続を確認してください。
- **API の認証に失敗する:** ユーザー名とパスワードが正しいか確認してください。
- **ダウンロードしたデータが破損している:** データの再ダウンロードを試してください。

**まとめと次のステップ:**

衛星データをダウンロードすることで、解析の準備が整いました。次のステップでは、衛星データの前処理について解説します。

#### 3.3.2 衛星データの前処理（幾何補正、放射補正、雲除去）

**概要と重要性:** 衛星データは、取得時のセンサーのずれや大気の影響などにより、歪みやノイズが含まれている場合があります。そのため、解析を行う前に、これらの歪みやノイズを除去する前処理が必要です。

**前処理の種類:**

- **幾何補正:** 衛星画像の歪みを修正し、正確な位置情報を持たせる処理です。
  - 基準となる地図データや他の衛星画像を用いて、画像の座標を補正します。
- **放射補正:** センサーの感度や大気の影響などにより、画像の色や明るさに生じたずれを修正する処理です。
  - 大気補正モデルや校正データを用いて、画像の輝度値を補正します。
- **雲除去:** 雲や雲の影を除去し、地表面の情報を抽出する処理です。
  - 雲マスクを作成し、雲領域を特定します。
  - 雲領域を周囲の画素値で補完したり、別の時期のデータで置き換えたりします。

**実践的なテクニック:**

- **幾何補正:** 基準となる地図データを用意します。
- **放射補正:** 適切な大気補正モデルを選択します。
- **雲除去:** 雲マスクの精度を高めます。

**コード例 (Rasterio と NumPy を用いた簡単な雲除去):**

```python
import rasterio
import numpy as np

def cloud_removal(image_path, cloud_threshold=0.8):
    """
    簡単な雲除去の例：指定された閾値以上の画素値を雲とみなし、NaNに置き換える
    """
    with rasterio.open(image_path) as src:
        image = src.read()
        profile = src.profile

    # 雲の閾値以上の画素値をNaNに置き換える
    image = np.where(image > cloud_threshold, np.nan, image)

    # NaNを適切に処理するために、データの型をfloatにする
    image = image.astype('float32')

    # 出力ファイル名を設定
    output_path = image_path.replace(".tif", "_cloud_removed.tif")

    # 書き込み
    with rasterio.open(output_path, 'w', **profile) as dst:
        dst.write(image)

    print(f"雲除去後の画像が {output_path} に保存されました。")

# 使用例
cloud_removal("input.tif")
```

**応用例とユースケース:**

- 高精度な土地被覆分類。
- 時系列的な植生変化の分析。
- 気候変動の影響評価。

**トラブルシューティング:**

- **幾何補正に失敗する:** 基準となる地図データが正しいか確認してください。
- **放射補正の効果が得られない:** 適切な大気補正モデルを選択してください。
- **雲除去の結果が不自然になる:** 雲マスクの精度を高めてください。

**まとめと次のステップ:**

衛星データの前処理を行うことで、解析の精度を高めることができます。次のステップでは、データ形式の変換について解説します。

#### 3.3.3 データ形式の変換（GeoTIFF、NetCDF など）

**概要と重要性:** 衛星データは、様々な形式で提供されています。解析を行うためには、データを扱いやすい形式に変換する必要があります。ここでは、代表的なデータ形式とその変換方法について解説します。

**データ形式:**

- **GeoTIFF:** 地理情報を持つ TIFF 形式の画像データです。
- **NetCDF:** 多次元配列データを格納するための形式です。
- **HDF5:** 大量の科学データを効率的に格納するための形式です。

**変換方法:**

- **GeoTIFF:** rasterio ライブラリを用いて読み書きできます。
- **NetCDF:** netCDF4 ライブラリを用いて読み書きできます。
- **HDF5:** h5py ライブラリを用いて読み書きできます。

**コード例 (GeoTIFF から NetCDF への変換):**

```python
import rasterio
import netCDF4
import numpy as np

def geotiff_to_netcdf(geotiff_path, netcdf_path):
    """
    GeoTIFFファイルをNetCDF形式に変換する
    """
    with rasterio.open(geotiff_path) as src:
        data = src.read()
        profile = src.profile

    # NetCDFファイルの作成
    with netCDF4.Dataset(netcdf_path, 'w', format='NETCDF4') as ncfile:
        # 次元定義
        ncfile.createDimension('band', data.shape[0])
        ncfile.createDimension('height', data.shape[1])
        ncfile.createDimension('width', data.shape[2])

        # 変数定義
        band = ncfile.createVariable('band', np.int32, ('band',))
        height = ncfile.createVariable('height', np.int32, ('height',))
        width = ncfile.createVariable('width', np.int32, ('width',))
        data_var = ncfile.createVariable('data', np.float32, ('band', 'height', 'width'))

        # データ書き込み
        data_var[:] = data

        # 属性情報
        data_var.description = "Satellite image data"
        data_var.units = "Reflectance"
        ncfile.title = "GeoTIFF to NetCDF Conversion"

    print(f"GeoTIFFファイルが {netcdf_path} に変換されました。")

# 使用例
geotiff_to_netcdf("input.tif", "output.nc")
```

**実践的なテクニック:**

- データの形式に合わせて、適切なライブラリを選択します。
- 大量のデータを扱う場合は、メモリの使用量に注意します。

**応用例とユースケース:**

- データの共有やアーカイブ。
- 異なるソフトウェア間でのデータのやり取り。
- 時系列データの解析。

**トラブルシューティング:**

- **データの変換に失敗する:** ライブラリのバージョンを確認してください。
- **メモリ不足のエラーが発生する:** データの分割処理を検討してください。
- **変換後のデータが破損している:** 変換元のデータが正しいか確認してください。
