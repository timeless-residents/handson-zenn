## 第 4 章：衛星画像データセットの作成 - アノテーションとデータ拡張

### 4.1 アノテーションツール - 効率的なアノテーション手法

**1. 概要と重要性**

衛星画像を用いた機械学習モデルの構築において、高品質なアノテーションデータセットは不可欠です。モデルの性能は、アノテーションの精度とデータセットの多様性に大きく依存します。このセクションでは、効率的なアノテーションを実現するためのツール、形式、注意点について解説します。適切なアノテーションは、時間とコストを削減し、より正確で信頼性の高いモデルの開発につながります。

**2. 特徴と利点**

アノテーションツールは、衛星画像上にオブジェクトや領域を定義するための様々な機能を提供します。以下に代表的なツールを紹介します。

- **QGIS:** オープンソースの GIS（地理情報システム）ソフトウェア。プラグインを用いることで、アノテーション機能を追加できます。

  - 利点: 無料で利用可能、豊富な GIS 機能、カスタマイズ性。
  - 注意点: 学習コストが高い、大規模なデータセットには不向きな場合がある。

- **Labelbox:** クラウドベースのアノテーションプラットフォーム。チームでの共同作業、アノテーション品質の管理、機械学習によるアノテーション支援機能を提供します。

  - 利点: チームでの共同作業に最適、高品質なアノテーション、機械学習による効率化。
  - 注意点: 有料サービス、インターネット環境が必要。

- **Roboflow:** ブラウザベースのアノテーションプラットフォーム。画像の前処理、アノテーション、データ拡張、モデルの学習までを統合的にサポートします。
  - 利点: 直感的な操作性、データ拡張機能、モデル学習との連携。
  - 注意点: 無料枠に制限がある、独自のデータ形式を使用。

アノテーション形式は、目的に応じて選択する必要があります。

- **ポリゴン:** 不規則な形状のオブジェクトを正確に表現できます。

  - 用途: 森林の境界、河川、建物の輪郭など。
  - 注意点: アノテーションに時間がかかる。

- **バウンディングボックス:** オブジェクトを囲む長方形で表現します。

  - 用途: 自動車、飛行機、太陽光パネルなど。
  - 注意点: オブジェクトの形状が複雑な場合、精度が低下する。

- **ピクセル単位:** 画像の各ピクセルにクラスラベルを付与します（セマンティックセグメンテーション）。
  - 用途: 土地被覆分類、道路抽出など。
  - 注意点: アノテーションに非常に時間がかかる、専門知識が必要。

**3. 事前準備と前提条件**

- **QGIS:** QGIS のインストールとプラグインの設定が必要です（例: QuickOSM, Shapefile などの操作）。
- **Labelbox/Roboflow:** アカウントの作成とプロジェクトの設定が必要です。
- アノテーション対象の衛星画像データ。
- アノテーション対象のクラス定義（例: 建物、道路、森林など）。
- アノテーションに関するガイドラインの作成（必須）。

**4. 基本的な使い方**

**QGIS の場合:**

1.  QGIS を起動し、衛星画像データを読み込みます。
2.  アノテーション用のシェープファイルを作成します（例: ポリゴン）。
3.  プラグイン（例: QuickOSM）を用いて、既存の地理情報を活用します。
4.  シェープファイル上で、オブジェクトをデジタイズします。
5.  属性テーブルにクラスラベルを付与します。

**Labelbox の場合:**

1.  Labelbox にログインし、プロジェクトを作成します。
2.  衛星画像データをアップロードします。
3.  アノテーションインターフェースで、オブジェクトを定義します（ポリゴン、バウンディングボックスなど）。
4.  アノテーション結果をエクスポートします。

**Roboflow の場合:**

1. Roboflow にログインし、プロジェクトを作成します。
2. 衛星画像データをアップロードします。
3. ブラウザ上でアノテーション作業を行います。
4. アノテーションデータセットをダウンロードします。YOLO, COCO, Pascal VOC などの形式でエクスポート可能です。

**5. 実践的なテクニック**

- **QGIS:** WMS/WCS サービスを利用して、最新の衛星画像や地図情報を取得し、アノテーションの参考にします。
- **Labelbox:** 事前学習済みの機械学習モデルを用いて、アノテーションを自動化します（Active Learning）。
- **Roboflow:** データ拡張機能を活用して、データセットのバリエーションを増やします。
- **共通:** アノテーション作業の前に、詳細なアノテーションガイドラインを作成し、アノテーター間で共有します。ガイドラインには、クラスの定義、境界の曖昧な場合の判断基準、例外事項などを明記します。
- **共通:** アノテーションの品質管理を徹底します。定期的にアノテーション結果をレビューし、誤りや不整合を修正します。複数人で同じデータをアノテーションし、結果を比較することで、品質を向上させることができます（ inter-annotator agreement）。

**6. 応用例とユースケース**

- **都市計画:** 建物の種類、道路の幅、緑地の面積などをアノテーションし、都市の現状分析や将来予測に役立てます。
- **農業:** 農作物の種類、生育状況、病害虫の発生状況などをアノテーションし、精密農業に役立てます。
- **環境モニタリング:** 森林の伐採、湿地の減少、海洋汚染などをアノテーションし、環境変化の監視に役立てます。

**7. トラブルシューティング**

- **アノテーションツールが重い:** 画像サイズを小さくする、PC のスペックを上げる、クラウドベースのツールを利用する。
- **アノテーションの品質が低い:** アノテーションガイドラインを見直す、アノテーターのトレーニングを行う、レビュー体制を強化する。
- **アノテーションデータが偏っている:** データセットの分割方法を見直す、データ拡張を行う、オーバーサンプリング/アンダーサンプリングを行う。
- **QGIS で日本語が文字化けする:** エンコーディングを UTF-8 に設定する。
- **Roboflow でアップロードに失敗する:** 画像形式を確認する（JPEG, PNG など）。画像サイズが大きすぎる場合はリサイズする。

**8. まとめと次のステップ**

このセクションでは、効率的なアノテーションを実現するためのツール、形式、注意点について解説しました。次のステップでは、アノテーションしたデータセットをさらに充実させるためのデータ拡張について学びます。高品質なアノテーションと多様なデータセットは、高性能な機械学習モデルを構築するための基盤となります。

### 4.2 データ拡張 - バリエーション豊かなデータセットを作る

**1. 概要と重要性**

データ拡張は、既存のデータセットから新しいデータを生成する技術です。衛星画像データセットは、収集に時間とコストがかかるため、データ拡張は特に重要です。データ拡張により、モデルの汎化性能を向上させ、オーバーフィッティングを防ぐことができます。

**2. 特徴と利点**

データ拡張には、様々な手法があります。

- **画像処理によるデータ拡張:** 回転、反転、ズーム、ノイズ付加など、画像処理技術を用いて新しい画像を生成します。

  - 利点: 実装が容易、計算コストが低い。
  - 注意点: 生成される画像が現実的でない場合がある。

- **GAN によるデータ拡張:** GAN（Generative Adversarial Network）を用いて、よりリアルな画像を生成します。
  - 利点: 高品質な画像を生成できる。
  - 注意点: 実装が難しい、計算コストが高い、学習に時間がかかる。

**3. 事前準備と前提条件**

- アノテーション済みの衛星画像データセット。
- Python のプログラミングスキル（画像処理ライブラリ、GAN フレームワーク）。
- 画像処理ライブラリ（例: OpenCV, scikit-image）。
- GAN フレームワーク（例: TensorFlow, PyTorch）。
- GPU 環境（GAN の学習に推奨）。

**4. 基本的な使い方**

**画像処理によるデータ拡張 (Python + OpenCV):**

```python
import cv2
import numpy as np
import os

def augment_image(image_path, output_dir, num_augmentations=3):
  """
  画像に対して回転、反転、ズーム、ノイズ付加を行い、データ拡張する関数。

  Args:
    image_path: 入力画像のパス。
    output_dir: 拡張後の画像を保存するディレクトリ。
    num_augmentations: 各画像に対して生成する拡張画像の数。
  """

  img = cv2.imread(image_path)
  if img is None:
    print(f"Error: Could not read image at {image_path}")
    return

  filename = os.path.basename(image_path)
  name, ext = os.path.splitext(filename)

  for i in range(num_augmentations):
    # 回転
    angle = np.random.uniform(-30, 30) # -30度から30度の範囲でランダムに回転
    M = cv2.getRotationMatrix2D((img.shape[1] / 2, img.shape[0] / 2), angle, 1)
    rotated_img = cv2.warpAffine(img, M, (img.shape[1], img.shape[0]))

    # 反転
    if np.random.rand() > 0.5:
      rotated_img = cv2.flip(rotated_img, 1) # 左右反転

    # ズーム (ランダムにクロップしてリサイズ)
    scale = np.random.uniform(0.8, 1.2) # 80%から120%の範囲でズーム
    width = int(img.shape[1] * scale)
    height = int(img.shape[0] * scale)
    x1 = int((img.shape[1] - width) / 2)
    y1 = int((img.shape[0] - height) / 2)
    cropped_img = rotated_img[y1:y1+height, x1:x1+width]
    resized_img = cv2.resize(cropped_img, (img.shape[1], img.shape[0])) # 元のサイズに戻す

    # ノイズ付加
    noise = np.random.normal(0, 20, resized_img.shape).astype(np.uint8) # 平均0、標準偏差20のガウシアンノイズ
    noisy_img = cv2.add(resized_img, noise)

    output_path = os.path.join(output_dir, f"{name}_augmented_{i}{ext}")
    cv2.imwrite(output_path, noisy_img)
    print(f"Saved augmented image to {output_path}")


# 使用例
image_path = "path/to/your/image.jpg"
output_dir = "path/to/output/directory"
os.makedirs(output_dir, exist_ok=True)
augment_image(image_path, output_dir)

```

**GAN によるデータ拡張 (TensorFlow + Keras):**

GAN の実装は複雑なため、ここでは概要のみを説明します。

1.  **Generator モデルの構築:** ランダムなノイズベクトルを入力として、画像を生成するモデルを構築します。
2.  **Discriminator モデルの構築:** 生成された画像と本物の画像を判別するモデルを構築します。
3.  **GAN モデルの学習:** Generator と Discriminator を交互に学習させ、Generator がよりリアルな画像を生成できるように訓練します。
4.  **生成された画像の利用:** 学習済みの Generator を用いて、新しい画像を生成し、データセットに追加します。

TensorFlow/Keras の公式ドキュメントやチュートリアルを参考に、詳細な実装を行ってください。 StyleGAN2 や BigGAN などの最新の GAN アーキテクチャを使用することで、より高品質な画像を生成できます。

**5. 実践的なテクニック**

- **データ拡張の組み合わせ:** 複数のデータ拡張手法を組み合わせることで、より多様なデータセットを生成できます。
- **データ拡張の強度の調整:** 回転角度、ズーム率、ノイズの強さなどを調整することで、生成される画像のバリエーションをコントロールできます。
- **ドメイン知識の活用:** 衛星画像の特性を考慮したデータ拡張を行います（例: 太陽光の角度、季節変動など）。
- **アノテーションデータの拡張:** 画像データだけでなく、アノテーションデータも拡張します（例: ポリゴンを回転、バウンディングボックスの位置をずらすなど）。
- **Mixup:** 2 つの画像とそのラベルを混ぜ合わせることで、新しいサンプルを作成します。この方法は、モデルのロバスト性を向上させ、オーバーフィッティングを軽減する効果があります。

**6. 応用例とユースケース**

- **農作物の生育状況予測:** 天候や土壌条件の異なる画像を GAN で生成し、様々な環境下での生育状況を予測します。
- **災害予測:** 過去の災害画像を元に、新たな災害画像を GAN で生成し、災害リスクの高い地域を特定します。
- **環境変化の予測:** 過去の衛星画像から、将来の森林面積や水資源の変化を予測します。

**7. トラブルシューティング**

- **データ拡張後の画像が不自然:** データ拡張の強度を弱める、GAN のアーキテクチャを見直す、学習データを増やす。
- **GAN の学習が不安定:** 学習率を調整する、バッチサイズを変更する、正則化手法を導入する。
- **データ拡張によってモデルの性能が低下:** データ拡張のやりすぎ、アノテーションの誤り、データセットの偏り。データ拡張を行う前後の性能を比較し、効果的なデータ拡張手法を選択することが重要です。

### 4.3 データセットの分割 - 学習データ、検証データ、テストデータ

**1. 概要と重要性**

機械学習モデルを訓練し、その性能を評価するためには、データセットを学習データ、検証データ、テストデータに適切に分割することが重要です。

- **学習データ:** モデルの訓練に使用します。
- **検証データ:** モデルのハイパーパラメータを調整するために使用します。
- **テストデータ:** モデルの最終的な性能を評価するために使用します。

**2. 特徴と利点**

データセットの分割方法には、いくつかの種類があります。

- **ランダム分割:** データをランダムに分割します。

  - 利点: 実装が容易。
  - 注意点: データセットに偏りがある場合、分割結果も偏る可能性があります。

- **層化抽出:** クラスの分布を考慮して分割します。
  - 利点: データセットに偏りがある場合でも、各データセットのクラス分布を均等にできます。
  - 注意点: クラスラベルが必要。

**3. 事前準備と前提条件**

- アノテーション済みの衛星画像データセット。
- Python のプログラミングスキル（データ操作ライブラリ）。
- データ操作ライブラリ（例: pandas, scikit-learn）。

**4. 基本的な使い方**

**ランダム分割 (Python + scikit-learn):**

```python
from sklearn.model_selection import train_test_split
import os
import random

def split_dataset_randomly(image_dir, test_size=0.2, val_size=0.1, random_state=42):
  """
  データセットをランダムに学習データ、検証データ、テストデータに分割する関数。

  Args:
    image_dir: 画像が格納されているディレクトリ。
    test_size: テストデータの割合。
    val_size: 検証データの割合（学習データに対する）。
    random_state: 乱数シード。
  """

  image_files = [os.path.join(image_dir, f) for f in os.listdir(image_dir) if os.path.isfile(os.path.join(image_dir, f))]
  random.shuffle(image_files) # Shuffle the list in place

  # まずは学習データとテストデータに分割
  train_val_files, test_files = train_test_split(image_files, test_size=test_size, random_state=random_state)

  # 次に学習データを学習データと検証データに分割
  train_files, val_files = train_test_split(train_val_files, test_size=val_size/(1-test_size), random_state=random_state) #検証データの割合を調整

  print(f"Number of training images: {len(train_files)}")
  print(f"Number of validation images: {len(val_files)}")
  print(f"Number of testing images: {len(test_files)}")

  return train_files, val_files, test_files

# 使用例
image_dir = "path/to/your/image/directory"
train_files, val_files, test_files = split_dataset_randomly(image_dir)

# 分割されたデータをそれぞれのディレクトリに移動する処理を追加
# 例えば、下記のようにtrain, val, testディレクトリを作成し、ファイルを移動する

def move_files(file_list, destination_dir):
  os.makedirs(destination_dir, exist_ok=True)
  for file_path in file_list:
      try:
        os.rename(file_path, os.path.join(destination_dir, os.path.basename(file_path))) # ファイルを移動
      except FileNotFoundError:
        print(f"Warning: File not found: {file_path}")

train_dir = "path/to/train/directory"
val_dir = "path/to/val/directory"
test_dir = "path/to/test/directory"

move_files(train_files, train_dir)
move_files(val_files, val_dir)
move_files(test_files, test_dir)
```

**層化抽出 (Python + scikit-learn):**

```python
from sklearn.model_selection import StratifiedShuffleSplit
import pandas as pd
import os

def split_dataset_stratified(image_dir, labels_csv, test_size=0.2, val_size=0.1, random_state=42):
  """
  データセットを層化抽出で学習データ、検証データ、テストデータに分割する関数。

  Args:
    image_dir: 画像が格納されているディレクトリ。
    labels_csv: 画像ファイル名とクラスラベルが記載されたCSVファイル。
    test_size: テストデータの割合。
    val_size: 検証データの割合（学習データに対する）。
    random_state: 乱数シード。
  """

  # CSVファイルを読み込み、画像ファイル名とクラスラベルの対応を作成
  df = pd.read_csv(labels_csv)
  df['image_path'] = df['image_id'].apply(lambda x: os.path.join(image_dir, x + ".jpg")) # ファイルパスを作成 (拡張子を適宜修正)

  # まずは学習データとテストデータに分割
  sss = StratifiedShuffleSplit(n_splits=1, test_size=test_size, random_state=random_state)
  for train_val_index, test_index in sss.split(df['image_path'], df['label']):
    train_val_df = df.iloc[train_val_index]
    test_df = df.iloc[test_index]

  # 次に学習データを学習データと検証データに分割
  sss = StratifiedShuffleSplit(n_splits=1, test_size=val_size/(1-test_size), random_state=random_state) # 検証データの割合を調整
  for train_index, val_index in sss.split(train_val_df['image_path'], train_val_df['label']):
    train_df = train_val_df.iloc[train_index]
    val_df = train_val_df.iloc[val_index]

  train_files = train_df['image_path'].tolist()
  val_files = val_df['image_path'].tolist()
  test_files = test_df['image_path'].tolist()

  print(f"Number of training images: {len(train_files)}")
  print(f"Number of validation images: {len(val_files)}")
  print(f"Number of testing images: {len(test_files)}")

  return train_files, val_files, test_files

# 使用例
image_dir = "path/to/your/image/directory"
```

**5. 実践的なテクニック**

- **データセットの偏りの確認:** クラスの分布、地理的な分布などを確認し、偏りがある場合は、層化抽出やデータ拡張などの対策を行います。 クラスの分布は、ヒストグラムを作成することで視覚的に確認できます。地理的な分布は、地図上にデータをプロットすることで確認できます。
- **データセットのバランス調整:** オーバーサンプリング (少数派のクラスのデータを増やす)、アンダーサンプリング (多数派のクラスのデータを減らす) などを行い、データセットのバランスを調整します。
- **クロスバリデーション:** データセットが小さい場合、クロスバリデーション (データを複数回分割して学習と評価を行う) を行うことで、モデルの汎化性能をより正確に評価できます。
- **地理的な偏りの考慮:** 衛星画像データは、地理的な偏りを持つ場合があります。例えば、特定の地域にデータが集中している場合、モデルはその地域に特化した性能を発揮する可能性があります。この問題を解決するために、地理的な情報を考慮した分割方法（例：特定の地域をテストデータとして分離する）を検討する必要があります。

**6. 応用例とユースケース**

- **土地被覆分類:** 各土地被覆クラス（森林、農地、都市など）の分布を考慮してデータセットを分割し、土地被覆分類モデルを訓練します。
- **災害予測:** 過去の災害発生地点と非発生地点のデータを分割し、災害予測モデルを訓練します。
- **農作物の収量予測:** 地域、品種、気象条件などの情報を考慮してデータセットを分割し、農作物の収量予測モデルを訓練します。

**7. トラブルシューティング**

- **学習データとテストデータの性能に大きな差がある:** データセットの分割方法を見直す、データ拡張を行う、モデルの正則化を強化する。
- **検証データの性能が低い:** ハイパーパラメータの調整範囲を見直す、データセットの分割方法を見直す。
- **オーバーサンプリング/アンダーサンプリングによってモデルの性能が低下:** オーバーサンプリング/アンダーサンプリングの割合を調整する、SMOTE などのより高度なサンプリング手法を試す。
