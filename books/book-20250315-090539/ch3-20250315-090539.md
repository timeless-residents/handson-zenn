## 第2章：Pillowの基礎：画像データの取り扱いと加工

Pillowは、Pythonで画像処理を行うための強力なライブラリです。この章では、Pillowの基本的な使い方から、実務で役立つ応用例までを網羅的に解説します。画像を読み込み、表示し、加工する一連の流れをマスターすることで、画像処理の可能性を広げましょう。

### 画像データの読み込みと表示：基礎の徹底

#### 概要と重要性

画像処理の第一歩は、画像データをプログラムに読み込み、適切に表示することです。Pillowを使用すると、様々な画像形式（JPEG, PNG, GIF, TIFFなど）を簡単に扱うことができます。このセクションでは、Pillowを使った画像データの読み込みと表示の基礎を徹底的に解説します。画像処理を行う上で、画像データの読み込みと表示は不可欠なスキルであり、これをマスターすることで、様々な画像処理の応用に進むことができます。

#### 特徴と利点

Pillowを使って画像データを読み込む利点は以下の通りです。

*   **多様な画像形式のサポート:** ほとんどの一般的な画像形式に対応しています。
*   **シンプルなAPI:** 直感的で使いやすいAPIを提供します。
*   **豊富な機能:** 画像の読み込みだけでなく、様々な画像処理機能を内包しています。
*   **クロスプラットフォーム:** Windows, macOS, Linuxなど、様々な環境で動作します。

#### 事前準備と前提条件

このセクションを進めるにあたって、以下の準備が必要です。

*   **Pythonのインストール:** Pythonがインストールされていることを確認してください (バージョン3.6以上を推奨)。
*   **Pillowのインストール:** ターミナルまたはコマンドプロンプトで以下のコマンドを実行して、Pillowをインストールします。

    ```bash
    pip install Pillow
    ```

    または、conda環境の場合は以下のコマンドを実行します。

    ```bash
    conda install -c anaconda pillow
    ```

*   **サンプル画像の準備:** 読み込みと表示のテストに使用するサンプル画像を準備してください。JPEG、PNGなど、一般的な形式の画像を用意することをおすすめします。

#### 基本的な使い方

1.  **画像の読み込み:**

    Pillowの`Image.open()`関数を使って画像を読み込みます。

    ```python
    from PIL import Image

    # 画像ファイルのパス
    image_path = "sample.jpg"

    # 画像を読み込む
    try:
        image = Image.open(image_path)
    except FileNotFoundError:
        print(f"エラー：画像ファイル '{image_path}' が見つかりません。")
        exit()
    except Exception as e:
        print(f"エラー：画像読み込み中にエラーが発生しました: {e}")
        exit()

    # 画像の情報を表示
    print(f"画像形式: {image.format}")
    print(f"画像サイズ: {image.size}")
    print(f"カラーモード: {image.mode}")
    ```

    このコードは、指定されたパスの画像を読み込み、その形式、サイズ、カラーモードを表示します。`try-except`ブロックを使用することで、ファイルが見つからない場合や、画像が破損している場合のエラーハンドリングを行っています。

2.  **画像の表示:**

    Pillowの`Image.show()`関数を使って画像を表示します。

    ```python
    # 画像を表示
    image.show()
    ```

    `Image.show()`関数は、OSに登録されたデフォルトの画像ビューアで画像を表示します。

    **注意点:** `Image.show()`関数は、一部の環境（特にリモートサーバー環境など）では動作しないことがあります。その場合は、`matplotlib`などのライブラリを使って画像を表示することを検討してください。

    ```python
    import matplotlib.pyplot as plt

    # 画像をmatplotlibで表示
    plt.imshow(image)
    plt.axis("off")  # 軸を非表示にする
    plt.show()
    ```

3.  **画像の保存:**

    Pillowの`Image.save()`関数を使って画像を保存します。

    ```python
    # 画像を保存
    image.save("output.png")
    ```

    保存形式はファイル拡張子によって自動的に決定されます。形式を指定したい場合は、`format`引数を使用します。

    ```python
    # JPEG形式で保存
    image.save("output.jpg", format="JPEG")
    ```

    JPEG形式で保存する場合、画質を指定するために`quality`引数を使用できます (0から100の範囲で、数値が大きいほど高画質)。

    ```python
    # 高画質でJPEG形式で保存
    image.save("output.jpg", format="JPEG", quality=95)
    ```

#### 実践的なテクニック

*   **画像サイズの取得:** `image.size`属性を使って、画像の幅と高さを取得できます。

    ```python
    width, height = image.size
    print(f"画像の幅: {width}")
    print(f"画像の高さ: {height}")
    ```

*   **特定の領域の切り出し:** `image.crop()`関数を使って、画像の一部を切り出すことができます。

    ```python
    # 切り出す領域の座標 (左上のx座標, 左上のy座標, 右下のx座標, 右下のy座標)
    crop_area = (100, 100, 300, 300)

    # 画像を切り出す
    cropped_image = image.crop(crop_area)

    # 切り出した画像を表示
    cropped_image.show()
    ```

*   **画像形式の変換:** `image.convert()`関数を使って、画像のカラーモードを変換できます。例えば、RGBA (Red, Green, Blue, Alpha) から RGB に変換することができます。

    ```python
    # RGBAからRGBに変換
    image = image.convert("RGB")

    # 変換後の画像を保存
    image.save("output.jpg")
    ```

#### 応用例とユースケース

*   **Webアプリケーションでの画像表示:** ユーザーがアップロードした画像をWebページに表示する際に、Pillowを使って画像のリサイズや形式変換を行うことができます。
*   **バッチ処理による画像変換:** 大量の画像をまとめてリサイズしたり、形式を変換したりするバッチ処理を自動化することができます。
*   **画像解析の前処理:** 画像解析を行う前に、Pillowを使って画像の前処理（ノイズ除去、コントラスト調整など）を行うことができます。

#### トラブルシューティング

*   **`FileNotFoundError`:** 指定した画像ファイルが見つからない場合のエラーです。パスが正しいか確認してください。
*   **`OSError: cannot identify image file`:** 画像ファイルが破損しているか、Pillowが対応していない形式である可能性があります。別の画像ファイルで試してみてください。
*   **`Image.show()`が動作しない:** 環境によっては、`Image.show()`関数が動作しない場合があります。`matplotlib`などのライブラリを使って画像を表示することを検討してください。
*   **JPEG保存時の画質劣化:** JPEG形式で画像を保存すると、画質が劣化する場合があります。`quality`引数を調整して、画質とファイルサイズのバランスを調整してください。

このセクションでは、Pillowを使った画像データの読み込みと表示の基礎を学びました。画像を読み込み、表示し、保存する基本的な操作をマスターすることで、様々な画像処理の応用に進むことができます。次のステップでは、画像の基本的な操作（リサイズ、トリミング、回転）について学びましょう。

### 画像の基本操作：リサイズ、トリミング、回転

#### 概要と重要性

画像のリサイズ、トリミング、回転は、画像処理における基本的な操作です。これらの操作をマスターすることで、画像の見た目を調整したり、特定の領域を強調したりすることができます。Pillowを使用すると、これらの操作を簡単に行うことができます。

#### 特徴と利点

Pillowを使って画像に対して基本的な操作を行う利点は以下の通りです。

*   **簡単な操作:** 直感的で使いやすいAPIで、リサイズ、トリミング、回転などの操作を簡単に行うことができます。
*   **高品質な処理:** Pillowは、高品質な画像処理を提供します。特にリサイズ処理においては、様々な補間方法を選択することができます。
*   **柔軟なカスタマイズ:** リサイズ、トリミング、回転のパラメータを細かく調整することができます。

#### 事前準備と前提条件

*   **Pillowのインストール:** Pillowがインストールされていることを確認してください (まだの場合は、`pip install Pillow`または`conda install -c anaconda pillow`でインストールします)。
*   **サンプル画像の準備:** リサイズ、トリミング、回転のテストに使用するサンプル画像を準備してください。

#### 基本的な使い方

1.  **リサイズ:**

    Pillowの`image.resize()`関数を使って、画像サイズを変更します。

    ```python
    from PIL import Image

    image_path = "sample.jpg"
    try:
        image = Image.open(image_path)
    except FileNotFoundError:
        print(f"エラー：画像ファイル '{image_path}' が見つかりません。")
        exit()
    except Exception as e:
        print(f"エラー：画像読み込み中にエラーが発生しました: {e}")
        exit()

    # 新しいサイズを指定 (幅, 高さ)
    new_size = (300, 200)

    # 画像をリサイズ
    resized_image = image.resize(new_size)

    # リサイズされた画像を表示
    resized_image.show()

    # リサイズされた画像を保存
    resized_image.save("resized_image.jpg")
    ```

    `image.resize()`関数は、新しいサイズをタプルで指定します。デフォルトでは、`PIL.Image.Resampling.NEAREST`補間方法が使用されます。より高品質なリサイズを行いたい場合は、`resample`引数に別の補間方法を指定します。

    *   `PIL.Image.Resampling.NEAREST`: 最近傍法 (最も高速だが、品質は低い)
    *   `PIL.Image.Resampling.BILINEAR`: バイリニア補間
    *   `PIL.Image.Resampling.BICUBIC`: バイキュービック補間 (より高品質)
    *   `PIL.Image.Resampling.LANCZOS`: Lanczos補間 (最高品質だが、最も遅い)

    ```python
    from PIL import Image, Image.Resampling

    # Lanczos補間を使用してリサイズ
    resized_image = image.resize(new_size, resample=Image.Resampling.LANCZOS)
    ```

2.  **トリミング:**

    Pillowの`image.crop()`関数を使って、画像の一部を切り抜きます。

    ```python
    # 切り出す領域の座標 (左上のx座標, 左上のy座標, 右下のx座標, 右下のy座標)
    crop_area = (100, 100, 400, 300)

    # 画像をトリミング
    cropped_image = image.crop(crop_area)

    # トリミングされた画像を表示
    cropped_image.show()

    # トリミングされた画像を保存
    cropped_image.save("cropped_image.jpg")
    ```

3.  **回転:**

    Pillowの`image.rotate()`関数を使って、画像を回転させます。

    ```python
    # 回転角度を度数で指定
    angle = 45

    # 画像を回転
    rotated_image = image.rotate(angle)

    # 回転された画像を表示
    rotated_image.show()

    # 回転された画像を保存
    rotated_image.save("rotated_image.jpg")
    ```

    `image.rotate()`関数は、反時計回りに画像を回転させます。デフォルトでは、回転によって生じた隙間は黒で塗りつぶされます。隙間を透明にしたい場合は、`expand`引数を`True`に設定します。

    ```python
    # 回転時に画像を拡大して隙間をなくす
    rotated_image = image.rotate(angle, expand=True)
    ```

    `fillcolor`引数で隙間の色を指定することもできます。

    ```python
    # 回転時の隙間を赤色で塗りつぶす
    rotated_image = image.rotate(angle, fillcolor=(255, 0, 0))
    ```

#### 実践的なテクニック

*   **アスペクト比を維持したリサイズ:** 画像のアスペクト比を維持したままリサイズするには、以下の関数を使用します。

    ```python
    def resize_with_aspect_ratio(image, width=None, height=None, resample=Image.Resampling.LANCZOS):
        """アスペクト比を維持したままリサイズする"""
        if width is None and height is None:
            return image

        original_width, original_height = image.size

        if width is None:
            width = int(height * original_width / original_height)
        elif height is None:
            height = int(width * original_height / original_width)

        return image.resize((width, height), resample=resample)
    ```

    この関数は、幅または高さのいずれかを指定すると、アスペクト比を維持したまま画像をリサイズします。

*   **特定のオブジェクトを中心としたトリミング:** 画像内の特定のオブジェクトを中心としてトリミングするには、オブジェクトの座標とサイズに基づいてトリミング領域を計算します。

*   **回転と同時にリサイズ:** `image.rotate()`関数と`image.resize()`関数を組み合わせて、回転と同時にリサイズを行うことができます。

#### 応用例とユースケース

*   **サムネイル画像の作成:** Webサイトやアプリケーションでサムネイル画像を表示する際に、Pillowを使って画像のリサイズやトリミングを行うことができます。
*   **SNS投稿用の画像加工:** SNSに投稿する画像を、規定のサイズやアスペクト比に調整するために、Pillowを使うことができます。
*   **画像編集アプリケーションの開発:** Pillowをベースにして、独自の画像編集アプリケーションを開発することができます。

#### トラブルシューティング

*   **リサイズ後の画像がぼやける:** リサイズ時に使用する補間方法を変更することで、画質を改善することができます。`PIL.Image.Resampling.LANCZOS`や`PIL.Image.Resampling.BICUBIC`などの高品質な補間方法を試してみてください。
*   **トリミング範囲が画像からはみ出る:** トリミング範囲が画像からはみ出ないように、座標を調整してください。
*   **回転後の画像が欠ける:** `expand`引数を`True`に設定することで、回転時に画像を拡大して欠けを防ぐことができます。

### 画像のカラー処理：グレースケール変換、色調調整

#### 概要と重要性

画像のカラー処理は、画像の色を操作することで、画像の印象を変えたり、特定の情報を強調したりするために重要です。Pillowを使用すると、グレースケール変換、色調調整、コントラスト調整など、様々なカラー処理を簡単に行うことができます。

#### 特徴と利点

Pillowを使って画像に対してカラー処理を行う利点は以下の通りです。

*   **豊富なカラーモード:** Pillowは、RGB、RGBA、グレースケールなど、様々なカラーモードに対応しています。
*   **多様なカラー処理関数:** グレースケール変換、色調調整、コントラスト調整など、多様なカラー処理関数を提供しています。
*   **簡単なカスタマイズ:** カラー処理のパラメータを細かく調整することができます。

#### 事前準備と前提条件

*   **Pillowのインストール:** Pillowがインストールされていることを確認してください (まだの場合は、`pip install Pillow`または`conda install -c anaconda pillow`でインストールします)。
*   **サンプル画像の準備:** カラー処理のテストに使用するサンプル画像を準備してください。

#### 基本的な使い方

1.  **グレースケール変換:**

    Pillowの`image.convert("L")`関数を使って、画像をグレースケールに変換します。

    ```python
    from PIL import Image

    image_path = "sample.jpg"
    try:
        image = Image.open(image_path)
    except FileNotFoundError:
        print(f"エラー：画像ファイル '{image_path}' が見つかりません。")
        exit()
    except Exception as e:
        print(f"エラー：画像読み込み中にエラーが発生しました: {e}")
        exit()

    # 画像をグレースケールに変換
    grayscale_image = image.convert("L")

    # グレースケール画像を保存
    grayscale_image.save("grayscale_image.jpg")
    ```

    `"L"`は、グレースケールモードを表します。

2.  **色調調整 (Brightness Enhancement):**
     Pillowには直接的な色調調整機能はありませんが、`PIL.ImageEnhance`モジュールを使用することで、明るさ、コントラスト、彩度などを調整することができます。ここでは、明るさの調整を例に示します。

   ```python
   from PIL import Image, ImageEnhance

   # 明るさの調整
   enhancer = ImageEnhance.Brightness(image)
   # 1.0が元の明るさ。1.5で1.5倍の明るさにする
   enhanced_image = enhancer.enhance(1.5)

   enhanced_image.save("brightness_enhanced.jpg")
   ```

3.  **コントラスト調整:**

    `PIL.ImageEnhance.Contrast`クラスを使って、画像のコントラストを調整します。

    ```python
    from PIL import Image, ImageEnhance

    # コントラストの調整
    enhancer = ImageEnhance.Contrast(image)
    # 1.0が元のコントラスト。1.2で1.2倍のコントラストにする
    enhanced_image = enhancer.enhance(1.2)

    # コントラスト調整後の画像を保存
    enhanced_image.save("contrast_enhanced.jpg")
    ```

4.  **彩度調整:**

    `PIL.ImageEnhance.Color`クラスを使って、画像の彩度を調整します。

    ```python
    from PIL import Image, ImageEnhance

    # 彩度の調整
    enhancer = ImageEnhance.Color(image)
    # 1.0が元の彩度。0.5で彩度を半分にする
    enhanced_image = enhancer.enhance(0.5)

    # 彩度調整後の画像を保存
    enhanced_image.save("color_enhanced.jpg")
    ```

5.  **シャープネス調整:**

    `PIL.ImageEnhance.Sharpness`クラスを使って、画像のシャープネスを調整します。

    ```python
    from PIL import Image, ImageEnhance

    # シャープネスの調整
    enhancer = ImageEnhance.Sharpness(image)
    # 1.0が元のシャープネス。2.0でシャープネスを強調する
    enhanced_image = enhancer.enhance(2.0)

    # シャープネス調整後の画像を保存
    enhanced_image.save("sharpness_enhanced.jpg")
    ```

#### 実践的なテクニック

*   **ヒストグラム平坦化:** 画像のコントラストを改善するために、ヒストグラム平坦化を行うことができます。NumPyと組み合わせて、ヒストグラムを計算し、累積分布関数を適用することで、ヒストグラム平坦化を実現できます。
*   **カラーバランス調整:** 特定の色を強調したり、抑えたりするために、カラーバランスを調整することができます。RGBチャンネルごとに異なる係数を適用することで、カラーバランスを調整することができます。
*   **トーンカーブ調整:** より高度な色調調整を行いたい場合は、トーンカーブを調整することができます。トーンカーブは、入力輝度値と出力輝度値の対応関係を表すグラフです。

#### 応用例とユースケース

*   **画像編集ソフトウェアの開発:** Pillowをベースにして、独自の画像編集ソフトウェアを開発することができます。
*   **医療画像の解析:** 医療画像のコントラストを調整したり、特定の組織を強調したりするために、Pillowを使うことができます。
*   **写真のレタッチ:** 写真の色調を調整したり、不要な色を取り除いたりするために、Pillowを使うことができます。

#### トラブルシューティング

*   **カラー処理後の画像の色がおかしい:** カラーモードが正しいか確認してください。また、カラー処理のパラメータが適切か確認してください。
*   **`PIL.ImageEnhance`が期待通りに動作しない:** 係数の値を適切に調整してください。また、画像のカラーモードが`PIL.ImageEnhance`が対応しているカラーモードであるか確認してください。
