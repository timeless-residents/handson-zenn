## 第4章：画像データの可視化：Matplotlibとの連携

画像データは、AIや機械学習の分野において非常に重要な役割を果たします。しかし、生のピクセルデータだけを見ても、その画像が持つ意味や特徴を理解するのは困難です。そこで、画像データを可視化し、直感的に理解を深めるための強力なツールがMatplotlibです。本章では、MatplotlibとPillowライブラリを連携させ、画像表示、ヒストグラム、スキャッタープロットといった基本的な可視化手法を解説します。初心者の方でも段階的に理解できるよう、具体的なコード例と詳細な解説を交えながら、実践的なテクニックを習得していきましょう。

### Matplotlibによる画像表示：Pillowとの統合

#### 概要と重要性

画像表示は、画像データの可視化における最初のステップです。画像の内容を直接確認することで、データの異常や特徴を把握し、その後の分析や処理の方向性を決定する上で非常に重要です。Matplotlibは、画像を表示するための基本的な機能を提供しており、Pillowライブラリと組み合わせることで、様々な画像形式に対応できます。

#### 特徴と利点

*   **幅広い画像形式のサポート:** Pillowライブラリを使用することで、JPEG、PNG、GIFなど、様々な画像形式をMatplotlibで扱うことができます。
*   **柔軟なカスタマイズ:** Matplotlibの豊富な機能を活用することで、画像の表示サイズ、色、軸などを細かく調整できます。
*   **簡単な操作:** シンプルなコードで画像を読み込み、表示できます。

#### 事前準備と前提条件

*   **Pythonのインストール:** Pythonがインストールされている必要があります。まだの場合は、[https://www.python.org/](https://www.python.org/) からダウンロードしてインストールしてください。
*   **ライブラリのインストール:** MatplotlibとPillowライブラリをインストールする必要があります。以下のコマンドをターミナルまたはコマンドプロンプトで実行してください。

    ```bash
    pip install matplotlib pillow
    ```

#### 基本的な使い方

まず、MatplotlibとPillowをインポートします。

```python
import matplotlib.pyplot as plt
from PIL import Image
```

次に、Pillowを使って画像を読み込みます。

```python
image_path = "sample.jpg"  # 表示したい画像ファイルのパスを指定
try:
    img = Image.open(image_path)
except FileNotFoundError:
    print(f"エラー: ファイル {image_path} が見つかりません。")
    exit()
except Exception as e:
    print(f"エラー: 画像ファイルの読み込みに失敗しました。詳細: {e}")
    exit()
```

`sample.jpg` は表示したい画像のファイル名に置き換えてください。 画像ファイルが存在しない場合はエラー処理を追加しています。

最後に、Matplotlibを使って画像を表示します。

```python
plt.imshow(img)
plt.axis("off")  # 軸を非表示にする
plt.title("Sample Image") # タイトルを追加
plt.show()
```

`plt.imshow()` 関数は、画像データを表示するための関数です。`plt.axis("off")` は、軸を非表示にするための関数です。`plt.show()` 関数は、画像を表示するための関数です。

#### 実践的なテクニック

*   **画像のサイズ調整:** `plt.figure()` 関数を使って、画像の表示サイズを調整できます。

    ```python
    plt.figure(figsize=(8, 6))  # 幅8インチ、高さ6インチの図を作成
    plt.imshow(img)
    plt.axis("off")
    plt.show()
    ```

*   **グレースケール表示:** カラー画像をグレースケールで表示するには、Pillowで画像をグレースケールに変換してからMatplotlibで表示します。

    ```python
    img_gray = img.convert("L")  # グレースケールに変換
    plt.imshow(img_gray, cmap="gray")  # cmap="gray" を指定してグレースケールで表示
    plt.axis("off")
    plt.show()
    ```

*   **画像のトリミング:**  Pillowを使って画像をトリミングできます。

    ```python
    width, height = img.size
    left = width / 4
    top = height / 4
    right = 3 * width / 4
    bottom = 3 * height / 4
    img_cropped = img.crop((left, top, right, bottom))
    plt.imshow(img_cropped)
    plt.axis("off")
    plt.show()
    ```

#### 応用例とユースケース

*   **画像認識モデルの出力結果の可視化:** 画像認識モデルの出力結果を、元の画像に重ねて表示することで、モデルがどこに注目しているかを確認できます。例えば、顔検出モデルの検出結果を、元の画像に矩形で表示することができます。
*   **医療画像の表示:** CTスキャンやMRIなどの医療画像をMatplotlibで表示し、病変の有無を確認することができます。
*   **衛星画像の表示:** 衛星画像をMatplotlibで表示し、土地利用の変化や森林破壊の状況を把握することができます。

#### トラブルシューティング

*   **画像が表示されない:** 画像ファイルのパスが正しいか確認してください。また、必要なライブラリがインストールされているか確認してください。
*   **画像の色がおかしい:** カラーモードが正しいか確認してください。グレースケール画像を表示する場合は、`cmap="gray"` を指定してください。
*   **メモリ不足:** 大きな画像を扱う場合、メモリ不足になることがあります。画像のサイズを縮小するか、より多くのメモリを搭載した環境で実行してください。

#### まとめと次のステップ

このセクションでは、MatplotlibとPillowを使って画像を表示する方法を学びました。画像のサイズ調整、グレースケール表示、トリミングなどのテクニックを習得しました。次のステップでは、ヒストグラムを描画して、画像データの分布を分析する方法を学びましょう。

### ヒストグラムの描画：画像データの分布分析

#### 概要と重要性

ヒストグラムは、画像データのピクセル値の分布を表すグラフです。ヒストグラムを分析することで、画像の明るさ、コントラスト、色の偏りなどを把握し、画像処理や機械学習の前処理に役立てることができます。例えば、ヒストグラムが特定の範囲に偏っている場合、画像のコントラストを調整することで、より鮮明な画像を得ることができます。

#### 特徴と利点

*   **データの分布を視覚的に把握:** ヒストグラムを見ることで、ピクセル値がどのように分布しているかを直感的に理解できます。
*   **画像処理の指針:** ヒストグラムの形状から、どのような画像処理を行うべきかの判断材料を得られます。
*   **異常検知:** 通常の画像と比較して、ヒストグラムが大きく異なる場合、画像の異常を検知できます。

#### 事前準備と前提条件

*   **MatplotlibとPillowのインストール:** 前のセクションと同様です。
*   **NumPyのインストール:** NumPyは、数値計算を行うためのライブラリです。ヒストグラムの描画に必要となるため、以下のコマンドでインストールしてください。

    ```bash
    pip install numpy
    ```

#### 基本的な使い方

まず、必要なライブラリをインポートします。

```python
import matplotlib.pyplot as plt
from PIL import Image
import numpy as np
```

次に、Pillowを使って画像を読み込みます。

```python
image_path = "sample.jpg"  # ヒストグラムを表示したい画像ファイルのパスを指定
try:
    img = Image.open(image_path)
except FileNotFoundError:
    print(f"エラー: ファイル {image_path} が見つかりません。")
    exit()
except Exception as e:
    print(f"エラー: 画像ファイルの読み込みに失敗しました。詳細: {e}")
    exit()
```

画像をNumPy配列に変換します。

```python
img_array = np.array(img)
```

Matplotlibを使ってヒストグラムを描画します。

```python
plt.hist(img_array.flatten(), bins=256, range=[0, 256])  # ピクセル値を平坦化してヒストグラムを描画
plt.title("Image Histogram")
plt.xlabel("Pixel Value")
plt.ylabel("Frequency")
plt.show()
```

`img_array.flatten()` は、NumPy配列を1次元に平坦化する関数です。`bins=256` は、ヒストグラムのビン数を256に設定するオプションです。`range=[0, 256]` は、ピクセル値の範囲を0から256に設定するオプションです。

#### 実践的なテクニック

*   **カラー画像のヒストグラム:** カラー画像のヒストグラムを描画するには、各チャンネル（赤、緑、青）ごとにヒストグラムを描画します。

    ```python
    plt.figure(figsize=(10, 6))

    colors = ("red", "green", "blue")
    for i, color in enumerate(colors):
        histogram, bin_edges = np.histogram(
            img_array[:, :, i].flatten(), bins=256, range=[0, 256]
        )
        plt.plot(bin_edges[:-1], histogram, color=color, label=color)

    plt.title("Color Image Histogram")
    plt.xlabel("Pixel Value")
    plt.ylabel("Frequency")
    plt.legend()
    plt.show()
    ```

*   **累積ヒストグラム:** 累積ヒストグラムを描画するには、`cumulative=True` オプションを指定します。

    ```python
    plt.hist(img_array.flatten(), bins=256, range=[0, 256], cumulative=True)
    plt.title("Cumulative Image Histogram")
    plt.xlabel("Pixel Value")
    plt.ylabel("Cumulative Frequency")
    plt.show()
    ```

*   **ヒストグラムの平坦化:** ヒストグラムの平坦化は、画像のコントラストを改善するためのテクニックです。Scikit-imageライブラリを使うと簡単に実装できます。

    ```python
    from skimage import exposure

    img_eq = exposure.equalize_hist(img_array)
    plt.imshow(img_eq)
    plt.axis("off")
    plt.title("Equalized Image")
    plt.show()

    plt.hist(img_eq.flatten(), bins=256, range=[0, 1]) # 0-1に正規化されているのでrangeも変更
    plt.title("Histogram of Equalized Image")
    plt.xlabel("Pixel Value")
    plt.ylabel("Frequency")
    plt.show()
    ```

    まず、`pip install scikit-image` で `scikit-image` ライブラリをインストールする必要があります。

#### 応用例とユースケース

*   **画像検索:** ヒストグラムを特徴量として使用し、類似した画像を検索することができます。
*   **画像セグメンテーション:** ヒストグラムの情報を使って、画像を複数の領域に分割することができます。
*   **画像品質評価:** ヒストグラムの形状から、画像の品質を評価することができます。例えば、ヒストグラムが偏っている場合、画像のコントラストが低い可能性があります。

#### トラブルシューティング

*   **ヒストグラムが表示されない:** 画像ファイルが正しく読み込まれているか確認してください。また、NumPyがインストールされているか確認してください。
*   **ヒストグラムの形状がおかしい:** 画像データの範囲が正しいか確認してください。グレースケール画像の場合、ピクセル値の範囲は0から255です。カラー画像の場合、各チャンネルのピクセル値の範囲は0から255です。
*   **ValueError: Image data of dtype float64 cannot be converted to uint8:** `skimage.exposure.equalize_hist` 関数は、0から1の範囲で正規化された画像を返します。Matplotlibで表示する前に、`img_as_ubyte` 関数を使って、画像を0から255の範囲に変換してください。

    ```python
    from skimage import exposure, img_as_ubyte

    img_eq = exposure.equalize_hist(img_array)
    img_eq_uint8 = img_as_ubyte(img_eq)  # 0-255に変換
    plt.imshow(img_eq_uint8, cmap='gray')
    plt.axis("off")
    plt.title("Equalized Image")
    plt.show()
    ```
    カラー画像の場合は`img_as_ubyte`を適用する必要はありません。

#### まとめと次のステップ

### スキャッタープロット：特徴量間の相関分析

#### 概要と重要性

スキャッタープロットは、2つの特徴量間の関係を視覚的に表現するためのグラフです。画像データの場合、例えば、隣接するピクセルの輝度値や、異なるチャンネルのピクセル値などの相関を分析することができます。特徴量間の相関を把握することで、画像データの冗長性を排除したり、より効果的な特徴量を設計したりすることができます。

#### 特徴と利点

*   **特徴量間の関係性を視覚的に把握:** スキャッタープロットを見ることで、2つの特徴量がどのような関係にあるかを直感的に理解できます。
*   **相関の強さを評価:** スキャッタープロットの点の分布から、相関の強さを評価できます。
*   **外れ値の検出:** スキャッタープロット上で、他の点から大きく離れた点を外れ値として検出できます。

#### 事前準備と前提条件

*   **Matplotlib、Pillow、NumPyのインストール:** 前のセクションと同様です。
*   **Pandasのインストール:** Pandasは、データ分析を支援するライブラリです。スキャッタープロットの描画に必要となるため、以下のコマンドでインストールしてください。

    ```bash
    pip install pandas
    ```

#### 基本的な使い方

まず、必要なライブラリをインポートします。

```python
import matplotlib.pyplot as plt
from PIL import Image
import numpy as np
import pandas as pd
```

次に、Pillowを使って画像を読み込みます。

```python
image_path = "sample.jpg"  # スキャッタープロットを描画したい画像ファイルのパスを指定
try:
    img = Image.open(image_path)
except FileNotFoundError:
    print(f"エラー: ファイル {image_path} が見つかりません。")
    exit()
except Exception as e:
    print(f"エラー: 画像ファイルの読み込みに失敗しました。詳細: {e}")
    exit()
```

画像をNumPy配列に変換します。

```python
img_array = np.array(img)
```

2つの特徴量を選択します。ここでは、赤チャンネルと緑チャンネルのピクセル値を例として使用します。

```python
red_channel = img_array[:, :, 0].flatten()
green_channel = img_array[:, :, 1].flatten()
```

PandasのDataFrameを作成します。

```python
df = pd.DataFrame({"red": red_channel, "green": green_channel})
```

Matplotlibを使ってスキャッタープロットを描画します。

```python
plt.scatter(df["red"], df["green"], alpha=0.5)  # alphaは透明度
plt.title("Red vs Green Channel")
plt.xlabel("Red Channel Value")
plt.ylabel("Green Channel Value")
plt.show()
```

`alpha=0.5` は、点の透明度を設定するオプションです。これにより、点が重なり合っている部分を視覚的に確認しやすくなります。

#### 実践的なテクニック

*   **異なるチャンネルの組み合わせ:** 赤チャンネルと青チャンネル、緑チャンネルと青チャンネルなど、異なるチャンネルの組み合わせでスキャッタープロットを描画することで、色の相関関係を分析できます。
*   **輝度と彩度の相関:** 画像をHSV (Hue, Saturation, Value) 色空間に変換し、輝度 (Value) と彩度 (Saturation) の相関をスキャッタープロットで分析することができます。

    ```python
    from matplotlib.colors import rgb_to_hsv

    img_hsv = rgb_to_hsv(img_array)
    hue_channel = img_hsv[:, :, 0].flatten()
    saturation_channel = img_hsv[:, :, 1].flatten()
    value_channel = img_hsv[:, :, 2].flatten()

    df_hsv = pd.DataFrame({"hue": hue_channel, "saturation": saturation_channel, "value": value_channel})

    plt.scatter(df_hsv["value"], df_hsv["saturation"], alpha=0.5)
    plt.title("Value vs Saturation")
    plt.xlabel("Value")
    plt.ylabel("Saturation")
    plt.show()
    ```

*   **局所的な特徴量の相関:** 画像を小さなパッチに分割し、各パッチの平均輝度や分散などの統計量を計算し、これらの統計量の相関をスキャッタープロットで分析することができます。例えば、隣接するパッチの平均輝度の相関を分析することで、画像のテクスチャを特徴付けることができます。

#### 応用例とユースケース

*   **画像圧縮:** スキャッタープロットで強い相関が確認された特徴量については、一方の特徴量だけを保持し、もう一方の特徴量を予測することで、画像データを圧縮することができます。
*   **異常検知:** 通常の画像と比較して、スキャッタープロットの形状が大きく異なる場合、画像の異常を検知できます。例えば、医療画像において、病変領域と正常領域のスキャッタープロットを比較することで、病変の有無を判断することができます。
*   **特徴量選択:** 機械学習モデルを構築する際に、スキャッタープロットで相関の低い特徴量を選択することで、モデルの性能を向上させることができます。

#### トラブルシューティング

*   **スキャッタープロットが表示されない:** 画像ファイルが正しく読み込まれているか確認してください。また、Pandasがインストールされているか確認してください。
*   **スキャッタープロットの点が密集していて見にくい:** `alpha` オプションを調整して、点の透明度を変更してみてください。また、点のサイズを小さくすることも有効です。
*   **メモリ不足:** 大きな画像を扱う場合、メモリ不足になることがあります。画像のサイズを縮小するか、より多くのメモリを搭載した環境で実行してください。
