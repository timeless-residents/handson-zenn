## 第4章：実践！シンプルなGUIアプリ開発：Hello, World! から一歩進んで

GUIアプリケーション開発の世界へようこそ！ この章では、"Hello, World!" を超えて、より実践的なGUIアプリケーション開発に挑戦します。 具体的には、シンプルなテキストエディタアプリの作成を通して、GUIデザイン、レイアウト、ウィジェット、そしてイベント処理といったGUI開発の基礎を習得します。 PyQt, Tkinter, Fletという3つの人気フレームワークを対象に、それぞれの特徴を比較しながら、あなたに合ったフレームワークを見つける手助けをします。

### 簡単なテキストエディタアプリの作成（PyQt/Tkinter/Flet）

#### 概要と重要性

テキストエディタは、プログラミング学習における定番の題材です。 GUIアプリケーションの基本的な要素が詰まっており、ファイル操作、テキストの表示・編集、イベント処理など、GUI開発に必要なスキルを幅広く学ぶことができます。 このセクションでは、PyQt、Tkinter、Fletを使って、シンプルなテキストエディタアプリを段階的に作成します。

#### 特徴と利点

* **PyQt:** QtフレームワークのPythonバインディング。豊富なウィジェットと強力なカスタマイズ性が特徴。大規模なアプリケーション開発に向いています。
* **Tkinter:** Python標準ライブラリに含まれるGUIツールキット。手軽にGUIアプリケーションを開発できるのが魅力。学習コストが低く、小規模なアプリケーションやプロトタイプ作成に適しています。
* **Flet:** Pythonで記述されたUIを、Flutterの柔軟性と美しさで高速に構築できる新しいフレームワーク。Web、モバイル、デスクトップ向けに単一のコードベースでデプロイできます。

#### 事前準備と前提条件

* Python 3.6以上がインストールされていること。
* 各フレームワークをインストール済みであること。

    * **PyQt:** `pip install PyQt6` (PyQt6を使用する場合) または `pip install PyQt5` (PyQt5を使用する場合)
    * **Tkinter:** Python標準ライブラリに含まれているため、通常はインストール不要。
    * **Flet:** `pip install flet`

#### 基本的な使い方

**1. PyQtでのテキストエディタアプリ**

```python
import sys
from PyQt6.QtWidgets import (QApplication, QMainWindow, QTextEdit,
                             QFileDialog, QMenuBar, QVBoxLayout, QWidget)
from PyQt6.QtGui import QAction
from PyQt6.QtCore import Qt

class TextEditor(QMainWindow):
    def __init__(self):
        super().__init__()

        self.setWindowTitle("Simple Text Editor")
        self.setGeometry(100, 100, 800, 600)

        self.text_edit = QTextEdit()
        self.setCentralWidget(self.text_edit)

        self.create_menu()

    def create_menu(self):
        menu_bar = QMenuBar()
        self.setMenuBar(menu_bar)

        file_menu = menu_bar.addMenu("File")

        open_action = QAction("Open", self)
        open_action.triggered.connect(self.open_file)
        file_menu.addAction(open_action)

        save_action = QAction("Save", self)
        save_action.triggered.connect(self.save_file)
        file_menu.addAction(save_action)

        exit_action = QAction("Exit", self)
        exit_action.triggered.connect(self.close)
        file_menu.addAction(exit_action)


    def open_file(self):
        file_name, _ = QFileDialog.getOpenFileName(self, "Open File", "", "Text Files (*.txt)")
        if file_name:
            with open(file_name, "r") as f:
                self.text_edit.setText(f.read())

    def save_file(self):
        file_name, _ = QFileDialog.getSaveFileName(self, "Save File", "", "Text Files (*.txt)")
        if file_name:
            with open(file_name, "w") as f:
                f.write(self.text_edit.toPlainText())


if __name__ == "__main__":
    app = QApplication(sys.argv)
    editor = TextEditor()
    editor.show()
    sys.exit(app.exec())
```

**解説:**

*   **`QMainWindow`:**  メインウィンドウとなるクラス。メニューバーやステータスバーなど、基本的なウィンドウの要素を提供します。
*   **`QTextEdit`:** 複数行のテキストを表示・編集するためのウィジェット。これがテキストエディタの中核となります。
*   **`QMenuBar`と`QAction`:** メニューバーとメニュー項目を作成します。 "Open"、"Save"、"Exit"などのアクションを定義し、それぞれの処理（`open_file`、`save_file`、`close`）と関連付けます。
*   **`QFileDialog`:** ファイルを開く/保存するためのダイアログを表示します。
*   **`open_file`と`save_file`:** ファイルの読み込みと保存の処理を実装します。

**2. Tkinterでのテキストエディタアプリ**

```python
import tkinter as tk
from tkinter import filedialog
from tkinter import messagebox

class TextEditor:
    def __init__(self, master):
        self.master = master
        master.title("Simple Text Editor")

        self.text_area = tk.Text(master, wrap=tk.WORD)
        self.text_area.pack(fill=tk.BOTH, expand=True)

        self.create_menu()

    def create_menu(self):
        menu_bar = tk.Menu(self.master)
        file_menu = tk.Menu(menu_bar, tearoff=0)
        file_menu.add_command(label="Open", command=self.open_file)
        file_menu.add_command(label="Save", command=self.save_file)
        file_menu.add_separator()
        file_menu.add_command(label="Exit", command=self.exit_editor)
        menu_bar.add_cascade(label="File", menu=file_menu)
        self.master.config(menu=menu_bar)

    def open_file(self):
        file_path = filedialog.askopenfilename(defaultextension=".txt",
                                              filetypes=[("Text Files", "*.txt"), ("All Files", "*.*")])
        if file_path:
            try:
                with open(file_path, "r") as file:
                    self.text_area.delete("1.0", tk.END)
                    self.text_area.insert(tk.END, file.read())
            except Exception as e:
                messagebox.showerror("Error", f"Could not open file:\n{e}")

    def save_file(self):
        file_path = filedialog.asksaveasfilename(defaultextension=".txt",
                                              filetypes=[("Text Files", "*.txt"), ("All Files", "*.*")])
        if file_path:
            try:
                with open(file_path, "w") as file:
                    file.write(self.text_area.get("1.0", tk.END))
            except Exception as e:
                messagebox.showerror("Error", f"Could not save file:\n{e}")

    def exit_editor(self):
        if messagebox.askokcancel("Quit", "Do you really want to quit?"):
            self.master.destroy()


root = tk.Tk()
editor = TextEditor(root)
root.mainloop()
```

**解説:**

*   **`tk.Tk`:**  Tkinterのルートウィンドウを作成します。
*   **`tk.Text`:** 複数行のテキストを表示・編集するためのウィジェット。PyQtの`QTextEdit`と同様の役割を果たします。`wrap=tk.WORD`は、単語単位で改行することを指定します。
*   **`tk.Menu`:** メニューバーとメニューを作成します。`tearoff=0`は、メニューをウィンドウから切り離せないようにします。
*   **`filedialog.askopenfilename`と`filedialog.asksaveasfilename`:** ファイルを開く/保存するためのダイアログを表示します。
*   **`messagebox.showerror`と`messagebox.askokcancel`:** エラーメッセージや確認ダイアログを表示します。

**3. Fletでのテキストエディタアプリ**

```python
import flet
from flet import IconButton, Page, Row, TextField, icons, Column, FilePicker, FilePickerResultEvent, FilePickerSaveFileEvent

def main(page: Page):
    page.title = "Flet Text Editor"
    page.vertical_alignment = "start"

    text_content = ""
    file_path = None

    txt_content = TextField(expand=True, multiline=True)

    def open_file_result(e: FilePickerResultEvent):
        nonlocal text_content, file_path
        if e.files:
            file_path = e.files[0].path
            with open(file_path, "r") as f:
                text_content = f.read()
            txt_content.value = text_content
        page.update()

    def save_file_result(e: FilePickerSaveFileEvent):
        nonlocal text_content, file_path
        if e.path:
            file_path = e.path
            text_content = txt_content.value
            with open(file_path, "w") as f:
                f.write(text_content)
        page.update()

    file_picker = FilePicker(on_result=open_file_result)
    save_file_picker = FilePicker(on_result=save_file_result)

    page.overlay.extend([file_picker, save_file_picker])

    page.add(
        Row(
            [
                IconButton(icons.FOLDER_OPEN, tooltip="Open file", on_click=lambda _: file_picker.pick_files(allow_multiple=False)),
                IconButton(icons.SAVE, tooltip="Save file", on_click=lambda _: save_file_picker.save_file(file_name="untitled.txt")),
            ],
            alignment="end",
        ),
        txt_content,
    )


flet.app(target=main)
```

**解説:**

*   **`flet.Page`:** Fletアプリケーションの基本となるクラス。
*   **`TextField`:** 複数行のテキストを表示・編集するためのウィジェット。`expand=True`で利用可能なスペースを最大限に利用し、`multiline=True`で複数行の入力を許可します。
*   **`FilePicker`:** ファイルを開く/保存するためのダイアログを表示します。Fletでは、ファイルピッカーは`page.overlay`に追加する必要があります。
*   **`IconButton`:** アイコン付きのボタンを作成します。`on_click`イベントで、ファイルピッカーを表示する処理を関連付けます。
*   **`open_file_result`と`save_file_result`:** ファイルの読み込みと保存の処理を実装します。`nonlocal`キーワードを使用して、外部のスコープの変数を変更します。

#### 実践的なテクニック

* **PyQt:** シグナルとスロットを使用して、イベント処理をより柔軟に実装できます。 カスタムウィジェットを作成することで、GUIをより細かく制御できます。
* **Tkinter:** `grid`レイアウトマネージャを使用すると、より複雑なレイアウトを作成できます。 イベントバインディングを使用して、キーボードショートカットやマウスイベントを処理できます。
* **Flet:** リアルタイムコラボレーション機能を活用して、複数ユーザーが同時にテキストを編集できるアプリケーションを開発できます。 Flet Cloudを使って、アプリケーションを簡単にデプロイできます。

#### 応用例とユースケース

* **PyQt:** 大規模なテキストエディタ（例：IDE）や、グラフィカルな設定ツールなど。
* **Tkinter:** 簡単なテキスト処理ツールや、スクリプトの実行結果を表示するGUIなど。
* **Flet:** リアルタイム共同編集可能なドキュメントエディタ、Webベースのテキストエディタなど。

#### トラブルシューティング

* **PyQt:** "ModuleNotFoundError: No module named 'PyQt5'" エラーが発生した場合、PyQt5が正しくインストールされているか確認してください。
* **Tkinter:** ウィジェットが正しく表示されない場合、レイアウトマネージャ（pack、grid、place）の設定を見直してください。
* **Flet:** アプリケーションが起動しない場合、Fletが正しくインストールされているか、およびPythonのバージョンがFletと互換性があるか確認してください。

### GUIのデザイン：レイアウトとウィジェット

#### 概要と重要性

GUIアプリケーションの見た目と使いやすさは、ユーザーエクスペリエンスを大きく左右します。 適切なレイアウトとウィジェットを選択し、効果的に配置することで、直感的で使いやすいアプリケーションを作成できます。

#### 特徴と利点

* **レイアウト:** ウィジェットの配置方法を決定します。 代表的なレイアウトマネージャとして、PyQtの`QVBoxLayout`、`QHBoxLayout`、`QGridLayout`、Tkinterの`pack`、`grid`、`place`、Fletの`Row`, `Column`などがあります。
* **ウィジェット:** ボタン、テキストボックス、ラベル、チェックボックスなど、GUIを構成する部品です。 フレームワークによって提供されるウィジェットの種類や機能が異なります。

#### 事前準備と前提条件

* 前セクションで作成したテキストエディタアプリのコードを参考に、GUIのデザインを変更してみましょう。

#### 基本的な使い方

**1. PyQtのレイアウトとウィジェット**

```python
from PyQt6.QtWidgets import (QApplication, QMainWindow, QTextEdit,
                             QPushButton, QVBoxLayout, QWidget, QHBoxLayout)
import sys

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Layout Example")

        # 中央のウィジェット
        central_widget = QWidget()
        self.setCentralWidget(central_widget)

        # レイアウトを作成
        main_layout = QVBoxLayout(central_widget) #QWidgetにレイアウトを設定
        top_layout = QHBoxLayout()

        # ウィジェットを作成
        self.text_edit = QTextEdit()
        button1 = QPushButton("Button 1")
        button2 = QPushButton("Button 2")

        # レイアウトにウィジェットを追加
        top_layout.addWidget(button1)
        top_layout.addWidget(button2)
        main_layout.addLayout(top_layout)
        main_layout.addWidget(self.text_edit)
```

**解説:**

*   **`QVBoxLayout`:** 垂直方向にウィジェットを配置します。
*   **`QHBoxLayout`:** 水平方向にウィジェットを配置します。
*   `top_layout`で水平方向にボタンを配置し、その上に`main_layout`でテキストエディタを配置する、というようにレイアウトを組み合わせることができます。

**2. Tkinterのレイアウトとウィジェット**

```python
import tkinter as tk

root = tk.Tk()
root.title("Layout Example")

# ウィジェットを作成
text_area = tk.Text(root)
button1 = tk.Button(root, text="Button 1")
button2 = tk.Button(root, text="Button 2")

# レイアウトマネージャでウィジェットを配置 (packを使用)
button1.pack(side=tk.LEFT)
button2.pack(side=tk.LEFT)
text_area.pack(fill=tk.BOTH, expand=True)

root.mainloop()
```

**解説:**

*   **`pack`:** ウィジェットを配置する最も基本的なレイアウトマネージャ。`side`オプションで配置する方向を指定します。`fill`と`expand`オプションで、利用可能なスペースをどのようにウィジェットに割り当てるかを制御します。

**3. Fletのレイアウトとウィジェット**

#### 実践的なテクニック

### イベント処理：ボタンクリック、テキスト入力など

#### 概要と重要性

イベント処理は、GUIアプリケーションのインタラクティブ性を実現するための重要な要素です。 ボタンクリック、テキスト入力、マウス操作など、ユーザーの操作に応じて適切な処理を実行することで、ユーザーエクスペリエンスを向上させることができます。

#### 特徴と利点

* **イベント:** ユーザーの操作やシステムの動作によって発生する信号です。
* **イベントハンドラ:** イベントが発生したときに実行される関数です。 イベントハンドラを適切に実装することで、GUIアプリケーションの動作を制御できます。

#### 事前準備と前提条件

* 前セクションで作成したGUIアプリケーションのコードを参考に、イベント処理を追加してみましょう。

#### 基本的な使い方

**1. PyQtのイベント処理**

```python
from PyQt6.QtWidgets import (QApplication, QMainWindow, QPushButton, QVBoxLayout, QWidget,
                             QMessageBox)
from PyQt6.QtCore import Qt
import sys

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Event Handling Example")

        central_widget = QWidget()
        self.setCentralWidget(central_widget)

        layout = QVBoxLayout(central_widget)

        self.button = QPushButton("Click Me")
        self.button.clicked.connect(self.button_clicked)  # シグナルとスロットの接続

        layout.addWidget(self.button)

    def button_clicked(self):
        QMessageBox.information(self, "Button Clicked", "You clicked the button!")


if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

**解説:**

*   **`clicked.connect`:** ボタンがクリックされたときに`button_clicked`関数を呼び出すように、シグナルとスロットを接続します。
*   **`button_clicked`:** ボタンがクリックされたときに実行される関数。`QMessageBox`を表示します。

**2. Tkinterのイベント処理**

```python
import tkinter as tk
from tkinter import messagebox

def button_clicked():
    messagebox.showinfo("Button Clicked", "You clicked the button!")

root = tk.Tk()
root.title("Event Handling Example")

button = tk.Button(root, text="Click Me", command=button_clicked)
button.pack()

root.mainloop()
```

**解説:**

*   **`command`:** ボタンがクリックされたときに`button_clicked`関数を呼び出すように指定します。
*   **`button_clicked`:** ボタンがクリックされたときに実行される関数。`messagebox`を表示します。

**3. Fletのイベント処理**

```python
import flet
from flet import IconButton, Page, Row, TextField, icons, Column, ElevatedButton
```

**解説:**

*   **`on_click`:** ボタンがクリックされたときに`button_clicked`関数を呼び出すように指定します。
*   **`button_clicked`:** ボタンがクリックされたときに実行される関数。ページにテキストを追加します。

#### 実践的なテクニック

* **PyQt:** カスタムシグナルを定義することで、より複雑なイベント処理を実装できます。 イベントフィルタを使用すると、特定のイベントをインターセプトして処理できます。
* **Tkinter:** `bind`メソッドを使用すると、キーボードイベントやマウスイベントなど、さまざまなイベントを処理できます。
* **Flet:** リアルタイムイベント処理を活用して、インタラクティブなUIを構築します。 非同期処理を使用して、UIの応答性を維持します。

#### 応用例とユースケース

* **フォームのバリデーション:** テキスト入力時に、入力された値が正しい形式であるか検証します。
* **アニメーション:** マウス操作に応じて、オブジェクトの位置や形状を変化させます。
* **ゲーム:** キーボード入力に応じて、キャラクターを移動させたり、攻撃させたりします。
