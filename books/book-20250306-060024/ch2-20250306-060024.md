# Chapter 1：リアルタイムチャット構築 - コア機能の実装

## WebSocket接続の確立とイベントハンドリング

### 概要と重要性

リアルタイムチャットアプリケーションの根幹をなすのが、クライアントとサーバー間の双方向通信を実現するWebSocketです。従来のHTTP通信とは異なり、WebSocketは一度接続を確立すると、サーバーとクライアントがいつでもメッセージを送り合うことができます。これにより、メッセージの送受信にかかる遅延を最小限に抑え、スムーズなリアルタイムコミュニケーションを可能にします。

WebSocket接続の確立とイベントハンドリングを適切に行うことは、チャットアプリケーションの応答性、スケーラビリティ、そして全体的なユーザーエクスペリエンスに大きく影響します。このセクションでは、WebSocketの基本から、接続確立、メッセージの送受信、エラー処理までを丁寧に解説します。

### 特徴と利点

*   **リアルタイム性:** サーバーからのプッシュ通知により、クライアントは常に最新の情報を取得できます。
*   **双方向通信:** クライアントとサーバーがいつでも自由にメッセージを交換できます。
*   **効率性:** HTTPポーリングなどの代替手段と比較して、ネットワークリソースの消費を抑えられます。
*   **拡張性:** 多数のクライアントを同時にサポートできるスケーラブルなアーキテクチャを構築できます。

### 事前準備と前提条件

このセクションでは、Node.jsと`ws`ライブラリを使用します。Node.jsがインストールされていること、そしてnpm（Node Package Manager）が利用可能であることを確認してください。

```bash
node -v
npm -v
```

プロジェクトディレクトリを作成し、`npm init -y`を実行して`package.json`ファイルを生成します。その後、`ws`ライブラリをインストールします。

```bash
mkdir realtime-chat
cd realtime-chat
npm init -y
npm install ws --save
```

### 基本的な使い方

まず、WebSocketサーバーを起動する基本的なコードを見てみましょう。

```javascript
// server.js
const WebSocket = require('ws');

const wss = new WebSocket.Server({ port: 8080 });

wss.on('connection', ws => {
  console.log('クライアントが接続しました');

  ws.on('message', message => {
    console.log(`受信したメッセージ: ${message}`);
    ws.send(`サーバーからの応答: ${message}`);
  });

  ws.on('close', () => {
    console.log('クライアントが切断しました');
  });

  ws.on('error', error => {
    console.error('WebSocketエラー:', error);
  });

  ws.send('サーバーに接続しました！');
});

console.log('WebSocketサーバーがポート8080で起動しました');
```

このコードは、ポート8080でWebSocketサーバーを起動し、クライアントからの接続を待ち受けます。クライアントが接続すると、以下のイベントハンドラが登録されます。

*   **message:** クライアントからメッセージを受信したときに実行されます。
*   **close:** クライアントが接続を閉じたときに実行されます。
*   **error:** WebSocket接続でエラーが発生したときに実行されます。

クライアントからメッセージを受信すると、コンソールにメッセージの内容を表示し、同じメッセージをクライアントに返信します。

次に、クライアント側のコードを見てみましょう。

```html
<!DOCTYPE html>
<html>
<head>
  <title>WebSocket Client</title>
</head>
<body>
  <h1>WebSocket Client</h1>
  <input type="text" id="messageInput" placeholder="メッセージを入力">
  <button onclick="sendMessage()">送信</button>
  <div id="messages"></div>

  <script>
    const ws = new WebSocket('ws://localhost:8080');

    ws.onopen = () => {
      console.log('サーバーに接続しました');
    };

    ws.onmessage = event => {
      const message = document.createElement('p');
      message.textContent = `サーバー: ${event.data}`;
      document.getElementById('messages').appendChild(message);
    };

    ws.onclose = () => {
      console.log('サーバーから切断されました');
    };

    ws.onerror = error => {
      console.error('WebSocketエラー:', error);
    };

    function sendMessage() {
      const messageInput = document.getElementById('messageInput');
      const message = messageInput.value;
      ws.send(message);
      messageInput.value = '';
    }
  </script>
</body>
</html>
```

このHTMLファイルは、WebSocketサーバーに接続し、メッセージを送受信するための簡単なインターフェースを提供します。ユーザーが入力したメッセージをサーバーに送信し、サーバーから受信したメッセージを画面に表示します。

これらのコードを実行するには、まず`server.js`をNode.jsで実行します。

```bash
node server.js
```

次に、HTMLファイルをブラウザで開きます。メッセージを入力して送信ボタンをクリックすると、サーバーにメッセージが送信され、サーバーから受信した応答が画面に表示されます。

### 実践的なテクニック

**メッセージのフォーマット:** 単純なテキストメッセージだけでなく、JSON形式のメッセージを送受信することで、より複雑なデータ構造を扱うことができます。

```javascript
// サーバー側
ws.on('message', message => {
  try {
    const data = JSON.parse(message);
    console.log('受信したデータ:', data);
    ws.send(JSON.stringify({ status: 'ok', message: 'メッセージを受信しました' }));
  } catch (error) {
    console.error('JSON解析エラー:', error);
    ws.send(JSON.stringify({ status: 'error', message: '無効なJSON形式です' }));
  }
});

// クライアント側
function sendMessage() {
  const messageInput = document.getElementById('messageInput');
  const message = messageInput.value;
  const data = { type: 'chat', text: message };
  ws.send(JSON.stringify(data));
  messageInput.value = '';
}
```

**Ping/Pongメカニズム:** WebSocket接続がアクティブであることを定期的に確認するために、Ping/Pongメカニズムを使用します。これにより、ネットワークの問題などで接続が切断された場合に、自動的に再接続を試みることができます。

```javascript
// サーバー側
function heartbeat() {
  this.isAlive = true;
}

wss.on('connection', ws => {
  ws.isAlive = true;
  ws.on('pong', heartbeat);

  const interval = setInterval(() => {
    wss.clients.forEach(ws => {
      if (ws.isAlive === false) return ws.terminate();

      ws.isAlive = false;
      ws.ping(() => {});
    });
  }, 30000); // 30秒ごとにPingを送信

  ws.on('close', () => {
    clearInterval(interval);
  });
});
```

**接続の維持:** ネットワーク環境が不安定な場合、WebSocket接続が頻繁に切断されることがあります。このような場合、クライアント側で自動的に再接続を試みる処理を実装することで、ユーザーエクスペリエンスを向上させることができます。

```javascript
// クライアント側
let ws;

function connect() {
  ws = new WebSocket('ws://localhost:8080');

  ws.onopen = () => {
    console.log('サーバーに再接続しました');
  };

  ws.onclose = () => {
    console.log('サーバーから切断されました。再接続を試みます...');
    setTimeout(connect, 3000); // 3秒後に再接続を試みる
  };
}

connect();
```

*   **株価表示:** 株価の変動をリアルタイムに表示するために使用されます。

*   **接続エラー:** サーバーのアドレスやポートが正しいか確認してください。ファイアウォールがWebSocket接続をブロックしていないか確認してください。

*   **パフォーマンスの問題:** WebSocketサーバーの負荷が高くなっていないか確認してください。必要に応じて、サーバーのスケールアップや負荷分散を検討してください。

## ユーザー認証と権限管理

### 概要と重要性

チャットアプリケーションにおいて、ユーザー認証と権限管理はセキュリティとプライバシーを確保するために不可欠です。ユーザー認証は、ユーザーが本人であることを確認するプロセスであり、権限管理は、ユーザーがアクセスできるリソースや実行できる操作を制御するプロセスです。

ユーザー認証と権限管理を適切に行うことで、不正アクセスやデータの漏洩を防ぎ、安全なチャット環境を提供することができます。このセクションでは、ユーザー認証の基本から、セッショントークンの管理、役割に基づいた権限管理までを解説します。

### 特徴と利点

*   **セキュリティ:** 不正アクセスやデータ漏洩のリスクを軽減します。
*   **プライバシー:** ユーザーのプライバシーを保護します。
*   **カスタマイズ:** ユーザーの役割や権限に基づいて、アクセスできる機能をカスタマイズできます。
*   **コンプライアンス:** 法令遵守を支援します。

### 事前準備と前提条件

このセクションでは、Node.jsとjsonwebtokenライブラリを使用します。jsonwebtokenライブラリをインストールします。

```bash
npm install jsonwebtoken --save
```

また、簡易的なユーザーデータベースとして、JSONファイルを使用します。`users.json`ファイルを作成し、以下の形式でユーザー情報を記述します。

```json
[
  { "id": "user1", "username": "alice", "password": "password123", "role": "admin" },
  { "id": "user2", "username": "bob", "password": "password456", "role": "user" }
]
```

### 基本的な使い方

まず、ユーザー認証を行うためのAPIエンドポイントを作成します。ここでは、簡略化のため、パスワードは平文で保存していますが、実際にはハッシュ化して保存する必要があります。

```javascript
// auth.js
const fs = require('fs');
const jwt = require('jsonwebtoken');
const secretKey = 'your-secret-key'; // 秘密鍵は安全な場所に保管してください

function authenticateUser(username, password) {
  const users = JSON.parse(fs.readFileSync('users.json', 'utf8'));
  const user = users.find(u => u.username === username && u.password === password);
  return user;
}

function generateToken(user) {
  const payload = {
    userId: user.id,
    username: user.username,
    role: user.role
  };
  const token = jwt.sign(payload, secretKey, { expiresIn: '1h' });
  return token;
}

module.exports = { authenticateUser, generateToken };
```

次に、WebSocketサーバーに認証処理を追加します。

```javascript
// server.js
const WebSocket = require('ws');
const { authenticateUser, generateToken } = require('./auth');

const wss = new WebSocket.Server({ port: 8080 });

wss.on('connection', (ws, req) => {
  const urlParams = new URLSearchParams(req.url.split('?')[1]);
  const token = urlParams.get('token');

  if (!token) {
    ws.close(1008, '認証が必要です'); // 1008: ポリシールール違反
    return;
  }

  try {
    const decoded = jwt.verify(token, 'your-secret-key');
    ws.user = decoded; // ユーザー情報をWebSocketオブジェクトに保存
    console.log(`ユーザー ${decoded.username} が接続しました`);
  } catch (err) {
    console.error('JWT検証エラー:', err);
    ws.close(1008, '認証に失敗しました');
    return;
  }

  ws.on('message', message => {
    console.log(`ユーザー ${ws.user.username} からのメッセージ: ${message}`);
    wss.clients.forEach(client => {
        if (client !== ws && client.readyState === WebSocket.OPEN) { // 送信者以外にメッセージを配信
            client.send(`${ws.user.username}: ${message}`);
        }
    });
  });

  ws.on('close', () => {
    console.log(`ユーザー ${ws.user.username} が切断しました`);
  });
});

// ログインAPI (簡易的な例)
const http = require('http');
const server = http.createServer((req, res) => {
    if (req.url === '/login' && req.method === 'POST') {
        let body = '';
        req.on('data', chunk => {
            body += chunk.toString();
        });
        req.on('end', () => {
            const { username, password } = JSON.parse(body);
            const user = authenticateUser(username, password);
            if (user) {
                const token = generateToken(user);
                res.writeHead(200, { 'Content-Type': 'application/json' });
                res.end(JSON.stringify({ token }));
            } else {
                res.writeHead(401, { 'Content-Type': 'application/json' });
                res.end(JSON.stringify({ message: '認証に失敗しました' }));
            }
        });
    } else {
        res.writeHead(404, { 'Content-Type': 'text/plain' });
        res.end('Not Found');
    }
});

server.listen(3000, () => {
    console.log('HTTPサーバーがポート3000で起動しました');
});

console.log('WebSocketサーバーがポート8080で起動しました');
```

このコードでは、クライアントが接続する際に、URLパラメータとしてトークンを渡す必要があります。サーバーは、トークンを検証し、有効なトークンであれば、ユーザー情報をWebSocketオブジェクトに保存します。

クライアント側のコードは、ログインAPIを呼び出し、取得したトークンをWebSocket接続時に使用するように変更します。

```html
<!DOCTYPE html>
<html>
<head>
  <title>WebSocket Client</title>
</head>
<body>
  <h1>WebSocket Client</h1>
  <div>
      <input type="text" id="username" placeholder="ユーザー名">
      <input type="password" id="password" placeholder="パスワード">
      <button onclick="login()">ログイン</button>
  </div>
  <input type="text" id="messageInput" placeholder="メッセージを入力">
  <button onclick="sendMessage()">送信</button>
  <div id="messages"></div>

  <script>

          const message = document.createElement('p');
          message.textContent = event.data;
          document.getElementById('messages').appendChild(message);
        };

        ws.onclose = () => {
          console.log('サーバーから切断されました');
        };

        ws.onerror = error => {
          console.error('WebSocketエラー:', error);
        };
    }

    function sendMessage() {
      const messageInput = document.getElementById('messageInput');
      const message = messageInput.value;
      ws.send(message);
      messageInput.value = '';
    }
  </script>
</body>

```

### 実践的なテクニック

**セッショントークンの管理:** セッショントークンをクライアント側に安全に保存するために、HTTPOnlyクッキーを使用することを検討してください。これにより、JavaScriptからトークンにアクセスできなくなり、XSS攻撃のリスクを軽減できます。

**役割に基づいた権限管理:** ユーザーの役割に基づいて、アクセスできるチャットルームや実行できる操作を制限することができます。例えば、管理者はすべてのチャットルームにアクセスでき、ユーザーは特定のチャットルームにのみアクセスできるといった具合です。

**リフレッシュトークン:** 短寿命のアクセストークンと、長寿命のリフレッシュトークンを組み合わせることで、セキュリティを向上させることができます。アクセストークンが期限切れになった場合、リフレッシュトークンを使用して新しいアクセストークンを取得します。

### 応用例とユースケース

*   **企業内チャット:** 従業員の役割に基づいて、アクセスできるチャットルームを制限します。
*   **オンラインゲーム:** プレイヤーの権限に基づいて、実行できる操作を制限します。
*   **カスタマーサポート:** 顧客のアクセス権限を管理し、担当者のみが顧客のチャット履歴にアクセスできるようにします。

### トラブルシューティング

*   **認証エラー:** 秘密鍵が一致しているか確認してください。トークンの有効期限が切れていないか確認してください。
*   **権限エラー:** ユーザーの役割が正しく設定されているか確認してください。権限のチェックが正しく実装されているか確認してください。

## チャットルーム機能の実装

### 概要と重要性

チャットルーム機能は、チャットアプリケーションの中核となる機能です。ユーザーはチャットルームに参加し、他の参加者とメッセージを交換することができます。チャットルーム機能の実装は、ユーザーエンゲージメントを高め、コミュニティを形成するために重要です。

このセクションでは、チャットルームの作成、参加、退出、メッセージの送受信といった基本的な機能の実装方法を解説します。また、チャット履歴の保存や、ユーザーの状態管理といった、より高度な機能についても触れます。

### 特徴と利点

*   **組織化:** ユーザーはテーマや目的に応じてチャットルームを選択し、参加することができます。
*   **コラボレーション:** 複数人で情報交換や共同作業を行うことができます。
*   **コミュニティ:** 共通の興味を持つユーザーが集まり、コミュニティを形成することができます。
*   **エンゲージメント:** ユーザーは他のユーザーと交流し、アプリケーションに継続的に関与することができます。

### 事前準備と前提条件

このセクションでは、前のセクションで作成したWebSocketサーバーとクライアントを使用します。また、チャットルームの情報を保存するために、簡易的なデータベースとして、インメモリのオブジェクトを使用します。

### 基本的な使い方

まず、チャットルームを管理するためのデータ構造を定義します。

```javascript
// rooms.js
const rooms = {};

function createRoom(roomId, roomName) {
  rooms[roomId] = {
    name: roomName,
    users: [],
    messages: []
  };
}

function joinRoom(roomId, userId) {
  if (rooms[roomId]) {
    rooms[roomId].users.push(userId);
  }
}

function leaveRoom(roomId, userId) {
  if (rooms[roomId]) {
    rooms[roomId].users = rooms[roomId].users.filter(id => id !== userId);
  }
}

function addMessage(roomId, message) {
  if (rooms[roomId]) {
    rooms[roomId].messages.push(message);
  }
}

function getRoom(roomId) {
    return rooms[roomId];
}

module.exports = { createRoom, joinRoom, leaveRoom, addMessage, getRoom, rooms }; // roomsオブジェクト自体もexport
```

次に、WebSocketサーバーにチャットルームの管理機能を追加します。

```javascript
// server.js
const WebSocket = require('ws');
const { authenticateUser, generateToken } = require('./auth');
const { createRoom, joinRoom, leaveRoom, addMessage, getRoom, rooms } = require('./rooms');

const wss = new WebSocket.Server({ port: 8080 });

wss.on('connection', (ws, req) => {
    const urlParams = new URLSearchParams(req.url.split('?')[1]);
    const token = urlParams.get('token');

    if (!token) {
      ws.close(1008, '認証が必要です'); // 1008: ポリシールール違反
      return;
    }

    try {
      const decoded = jwt.verify(token, 'your-secret-key');
      ws.user = decoded; // ユーザー情報をWebSocketオブジェクトに保存
      console.log(`ユーザー ${decoded.username} が接続しました`);
    } catch (err) {
      console.error('JWT検証エラー:', err);
      ws.close(1008, '認証に失敗しました');
      return;
    }

    // デフォルトのチャットルームに参加
    joinRoom('default', ws.user.userId);
    ws.roomId = 'default'; // ユーザーが現在参加しているチャットルームを記録

    ws.on('message', message => {
      console.log(`ユーザー ${ws.user.username} からのメッセージ: ${message}`);
      addMessage(ws.roomId, `${ws.user.username}: ${message}`); // メッセージをチャットルームに保存

      // 同じチャットルームのユーザーにメッセージを配信
      wss.clients.forEach(client => {
        if (client !== ws && client.readyState === WebSocket.OPEN && client.roomId === ws.roomId) {
          client.send(`${ws.user.username}: ${message}`);
        }
      });
    });

    ws.on('close', () => {
      console.log(`ユーザー ${ws.user.username} が切断しました`);
      leaveRoom(ws.roomId, ws.user.userId); // チャットルームから退出
    });

    // 接続時にチャットルームの履歴を送信
    const room = getRoom(ws.roomId);
    if (room) {
        room.messages.forEach(msg => {
            ws.send(`[履歴] ${msg}`);
        });
    }
  });

// ログインAPI (簡易的な例)
const http = require('http');
const server = http.createServer((req, res) => {
    if (req.url === '/login' && req.method === 'POST') {
        let body = '';
        req.on('data', chunk => {
            body += chunk.toString();
        });
        req.on('end', () => {
            const { username, password } = JSON.parse(body);
            const user = authenticateUser(username, password);
            if (user) {
                const token = generateToken(user);
                res.writeHead(200, { 'Content-Type': 'application/json' });
                res.end(JSON.stringify({ token }));
            } else {
                res.writeHead(401, { 'Content-Type': 'application/json' });
                res.end(JSON.stringify({ message: '認証に失敗しました' }));
            }
        });
    }  else if (req.url === '/rooms' && req.method === 'GET') {
        // チャットルーム一覧を提供するAPI
        const roomList = Object.keys(rooms).map(roomId => ({
            id: roomId,
            name: rooms[roomId].name
        }));
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify(roomList));
    }
    else {
        res.writeHead(404, { 'Content-Type': 'text/plain' });
        res.end('Not Found');
    }
});

server.listen(3000, () => {
```

### 実践的なテクニック

**チャット履歴の保存:** メッセージをデータベースに保存することで、チャット履歴を永続化することができます。

**ユーザーの状態管理:** ユーザーがオンラインかオフラインかを管理することで、ユーザーリストを表示したり、オンラインユーザーにのみメッセージを送信したりすることができます。

**メッセージの検索:** メッセージの内容を検索できるようにすることで、過去の会話を簡単に見つけることができます。

### 応用例とユースケース

*   **企業内チャット:** プロジェクトごとにチャットルームを作成し、プロジェクトメンバー間で情報共有を行います。
*   **オンラインゲーム:** ギルドごとにチャットルームを作成し、ギルドメンバー間でコミュニケーションを取ります。
*   **カスタマーサポート:** 顧客ごとにチャットルームを作成し、担当者が顧客とのやり取りを記録します。

### トラブルシューティング

*   **メッセージが配信されない:** チャットルームIDが一致しているか確認してください。ユーザーがチャットルームに参加しているか確認してください。
*   **チャット履歴が表示されない:** データベースにメッセージが保存されているか確認してください。チャット履歴の取得処理が正しく実装されているか確認してください。
