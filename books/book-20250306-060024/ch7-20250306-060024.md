## Chapter 6：高度なゲームロジック - 戦闘、スキル、AI

### 戦闘システムの設計

#### 概要と重要性

戦闘システムは、ゲームの中核をなす要素の一つです。プレイヤーが敵とどのように対峙し、どのように勝利を掴むかを定義します。洗練された戦闘システムは、単なるボタン連打ではなく、戦略性、緊張感、そして達成感を提供し、ゲームの没入感を飛躍的に向上させます。アクションゲームはもちろん、RPG、シミュレーションゲームなど、多くのジャンルで重要な役割を果たします。

#### 特徴と利点

優れた戦闘システムは、以下の特徴を持つことが望ましいです。

*   **戦略性:** 敵の弱点を突いたり、状況に応じて戦術を変えたりする要素がある。
*   **レスポンスの良さ:** プレイヤーの入力に対する反応が速く、操作感が快適。
*   **視覚的な魅力:** エフェクト、アニメーション、サウンドなどが効果的に組み合わさり、戦闘を盛り上げる。
*   **拡張性:** 新しい敵、スキル、アイテムなどを容易に追加できる構造になっている。
*   **バランス調整のしやすさ:** ダメージ計算、敵の強さなどを調整しやすく、ゲーム全体の難易度をコントロールできる。

#### 事前準備と前提条件

このセクションでは、基本的なゲーム開発の知識（プログラミング言語の基礎、ゲームエンジンの使い方など）があることを前提とします。具体的には、以下のような知識があると理解が深まります。

*   プログラミング言語（C#, C++, Luaなど）の基礎
*   ゲームエンジンの基本的な操作（Unity, Unreal Engineなど）
*   オブジェクト指向プログラミングの概念
*   基本的な数学の知識（ベクトル、行列など）

また、本章で使用するゲームエンジンはUnityを想定し、C#で記述します。Unreal Engineを利用する場合は、C++に置き換えてください。

**1. データ構造の定義:**

まず、キャラクター（プレイヤー、敵）のステータスを定義するクラスを作成します。

```csharp
public class Character
{
    public string Name { get; set; }
    public int MaxHealth { get; set; }
    public int CurrentHealth { get; set; }
    public int Attack { get; set; }
    public int Defense { get; set; }

    public Character(string name, int maxHealth, int attack, int defense)
    {
        Name = name;
        MaxHealth = maxHealth;
        CurrentHealth = maxHealth;
        Attack = attack;
        Defense = defense;
    }

    public bool IsAlive()
    {
        return CurrentHealth > 0;
    }

    public void TakeDamage(int damage)
    {
        CurrentHealth -= damage;
        if (CurrentHealth < 0)
        {
            CurrentHealth = 0;
        }
        Debug.Log($"{Name}は{damage}のダメージを受けた！");
    }
}
```

**2. 戦闘ロジックの実装:**

戦闘の基本的な流れを制御するクラスを作成します。

```csharp
public class BattleManager : MonoBehaviour
{
    public Character Player;
    public Character Enemy;

    void Start()
    {
        Player = new Character("主人公", 100, 20, 10);
        Enemy = new Character("敵", 80, 15, 5);

        StartCoroutine(BattleLoop());
    }

    IEnumerator BattleLoop()
    {
        while (Player.IsAlive() && Enemy.IsAlive())
        {
            // プレイヤーのターン
            yield return StartCoroutine(PlayerTurn());

            if (!Enemy.IsAlive())
            {
                Debug.Log("プレイヤーの勝利！");
                break;
            }

            // 敵のターン
            yield return StartCoroutine(EnemyTurn());

            if (!Player.IsAlive())
            {
                Debug.Log("敵の勝利！");
                break;
            }
        }
    }

    IEnumerator PlayerTurn()
    {
        Debug.Log("プレイヤーのターン");

        // 簡単な攻撃処理
        int damage = Mathf.Max(0, Player.Attack - Enemy.Defense);
        Enemy.TakeDamage(damage);
        Debug.Log($"{Player.Name}は{Enemy.Name}に{damage}のダメージを与えた！");

        yield return new WaitForSeconds(1.0f); // 演出のためのウェイト
    }

    IEnumerator EnemyTurn()
    {
        Debug.Log("敵のターン");

        // 簡単な攻撃処理
        int damage = Mathf.Max(0, Enemy.Attack - Player.Defense);
        Player.TakeDamage(damage);
        Debug.Log($"{Enemy.Name}は{Player.Name}に{damage}のダメージを与えた！");

        yield return new WaitForSeconds(1.0f); // 演出のためのウェイト
    }
}
```

### スキルの実装

#### 概要と重要性

スキルは、キャラクターの能力を拡張し、戦闘に多様性と戦略性をもたらす重要な要素です。攻撃スキル、回復スキル、補助スキルなど、様々な種類のスキルを実装することで、プレイヤーは自分だけのプレイスタイルを確立し、より深くゲームに没入することができます。

#### 特徴と利点

*   **多様なプレイスタイル:** スキルの組み合わせによって、様々な戦術や戦略が可能になる。
*   **キャラクターの成長:** スキルを習得、強化することで、キャラクターの成長を実感できる。
*   **戦略性の向上:** 敵の弱点や状況に応じてスキルを選択することで、戦闘を有利に進めることができる。
*   **視覚的な魅力:** スキル発動時のエフェクトやアニメーションは、戦闘をよりエキサイティングにする。
*   **ゲームプレイの変化:** 新しいスキルが追加されることで、ゲームプレイに新鮮さが保たれる。

**1. スキルのレベルアップ:**

スキルを使用するごとに経験値を獲得し、レベルアップすることで、効果を強化することができます。

```csharp
public class Skill : ScriptableObject
{
    public int Level { get; set; } = 1;
    public int MaxLevel { get; set; } = 5;
    public int Experience { get; set; } = 0;
    public int ExperienceToNextLevel { get; set; } = 100;

    public void AddExperience(int amount)
    {
        Experience += amount;
        while (Experience >= ExperienceToNextLevel && Level < MaxLevel)
        {
            LevelUp();
        }
    }

    private void LevelUp()
    {
        Level++;
        Experience -= ExperienceToNextLevel;
        ExperienceToNextLevel *= 2; // 必要経験値を増加
        Debug.Log($"{SkillName}がレベル{Level}になった！");

        // レベルアップ時の効果を定義 (例：ダメージ増加)
        Damage += 10;
    }
}
```

### 簡単なAIの実装

#### 概要と重要性

AI（人工知能）は、ゲームに登場する敵キャラクターやNPC（ノンプレイヤーキャラクター）に行動原理を与え、ゲーム世界に生命感とインタラクティブ性をもたらす重要な要素です。簡単なAIを実装することで、敵はプレイヤーを認識し、攻撃したり、逃げたり、アイテムを拾ったりするなど、様々な行動をとることができます。

#### 特徴と利点

*   **チャレンジの向上:** AIキャラクターの行動パターンを変化させることで、プレイヤーに常に新しい挑戦を提供できる。
*   **没入感の向上:** AIキャラクターの言動や行動によって、プレイヤーはゲーム世界に深く没入できる。
*   **ゲームプレイの多様化:** AIキャラクターの行動によって、ゲームプレイに予期せぬ展開が生まれる。
*   **ストーリーテリングの強化:** AIキャラクターの行動を通して、ストーリーを語ることができる。

**2. AIコントローラーの実装:**

AIの状態遷移と行動を制御するクラスを作成します。

```csharp
using UnityEngine;
using UnityEngine.AI; //NavMeshAgentを使うために必要

public class AIController : MonoBehaviour
{
    public AIState CurrentState = AIState.Idle;
    public float SightRange = 10f;
    public float AttackRange = 2f;
    public float PatrolSpeed = 1f;
    public float ChaseSpeed = 3f;
    public Transform[] PatrolPoints;
    private int currentPatrolIndex = 0;

    private GameObject player;
    private NavMeshAgent agent;

    void Start()
    {
        player = GameObject.FindGameObjectWithTag("Player"); // Playerタグを付けたオブジェクトを探す
        agent = GetComponent<NavMeshAgent>();
        if(agent == null){
            Debug.LogError("NavMeshAgentが見つかりません！");
            enabled = false;
        }
        if (PatrolPoints.Length > 0)
        {
            CurrentState = AIState.Patrol;
        }
        else
        {
            CurrentState = AIState.Idle;
        }

    }

    void Update()
    {
        switch (CurrentState)
        {
            case AIState.Idle:
                Idle();
                break;
            case AIState.Patrol:
                Patrol();
                break;
            case AIState.Chase:
                Chase();
                break;
            case AIState.Attack:
                Attack();
                break;
        }
    }

    void Idle()
    {
        // 何もしない
        if (CanSeePlayer())
        {
            CurrentState = AIState.Chase;
        }
    }

    void Patrol()
    {
        agent.speed = PatrolSpeed;
        if(PatrolPoints.Length == 0) {
            Debug.LogWarning("PatrolPointsが設定されていません！");
            CurrentState = AIState.Idle;
            return;
        }

        if (Vector3.Distance(transform.position, PatrolPoints[currentPatrolIndex].position) < 1f)
        {
            currentPatrolIndex = (currentPatrolIndex + 1) % PatrolPoints.Length; // 次の巡回地点へ
        }
        agent.SetDestination(PatrolPoints[currentPatrolIndex].position);

        if (CanSeePlayer())
        {
            CurrentState = AIState.Chase;
        }
    }

    bool CanSeePlayer()
    {
        if (player == null) return false;
        float distanceToPlayer = Vector3.Distance(transform.position, player.transform.position);
        if (distanceToPlayer <= SightRange)
        {
            // レイキャストで間に障害物がないか確認
            Vector3 directionToPlayer = (player.transform.position - transform.position).normalized;
            if (!Physics.Raycast(transform.position, directionToPlayer, distanceToPlayer))
            {
                return true; // プレイヤーを発見
            }
        }
        return false;
    }


    void Chase()
    {
        agent.speed = ChaseSpeed;
        if (player != null) {
            agent.SetDestination(player.transform.position);
        }

        float distanceToPlayer = Vector3.Distance(transform.position, player.transform.position);
        if (distanceToPlayer <= AttackRange)
        {
            CurrentState = AIState.Attack;
        }
        if (!CanSeePlayer())
        {
            CurrentState = AIState.Patrol; // 見失ったら巡回に戻る
        }
    }

    void Attack()
    {
        // 攻撃処理
        Debug.Log("攻撃！");
        // ここに攻撃のロジックを実装する
        if (player == null)
        {
            CurrentState = AIState.Idle;
            return;
        }
        float distanceToPlayer = Vector3.Distance(transform.position, player.transform.position);
        if (distanceToPlayer > AttackRange)
        {
            CurrentState = AIState.Chase;
        }
    }
}
```

**3. シーンへの配置と設定:**

*   Unityで敵キャラクターのGameObjectを作成します。
*   `AIController`スクリプトをGameObjectにアタッチします。
*   `NavMeshAgent`コンポーネントを追加します。
*   巡回地点となるGameObjectをいくつか作成し、`PatrolPoints`に設定します。
*   プレイヤーキャラクターに"Player"タグを付けます。

#### 実践的なテクニック

**1. 索敵範囲の設定:**

敵キャラクターの索敵範囲を設定することで、プレイヤーを認識する距離を調整することができます。

**2. 視線判定の実装:**

レイキャストを使って、敵キャラクターの視線がプレイヤーに届いているか判定することで、障害物を考慮した索敵を実現できます。

**3. 行動パターンの追加:**

状態を増やしたり、状態遷移の条件を複雑化したりすることで、より多様な行動パターンを実現できます。

#### 応用例とユースケース

*   **ステルスゲーム:** 敵AIに見つからないように、隠れて移動する。
*   **RTS:** 部隊を指揮し、敵のAIを打ち破る。
*   **パズルゲーム:** AIキャラクターの行動を予測し、パズルを解く。
*   **アドベンチャーゲーム:** AIキャラクターとの会話や協力を通して、ストーリーを進める。

#### トラブルシューティング

*   **敵キャラクターが動かない:** NavMeshAgentが正しく設定されているか、NavMeshが生成されているか確認する。
*   **敵キャラクターが意図しない方向に動く:** AIの状態遷移、移動速度、索敵範囲などを確認する。
*   **敵キャラクターが障害物に引っかかる:** NavMeshAgentのパラメータ（半径、高さなど）を調整する。
