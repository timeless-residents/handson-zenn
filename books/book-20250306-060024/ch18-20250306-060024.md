## Chapter 17：空間分割 - 大規模ワールドの実現

大規模なゲームワールドやシミュレーション環境を構築する際、パフォーマンスは常に重要な課題となります。特に、大量のオブジェクトが存在する場合、すべてのオブジェクトに対して当たり判定や可視性判定を行うのは非効率です。そこで役立つのが空間分割です。空間分割は、空間を階層的に分割し、オブジェクトを適切な領域に格納することで、検索範囲を絞り込み、パフォーマンスを大幅に向上させる技術です。

この章では、代表的な空間分割手法であるクアッドツリー、KDツリー、Rツリーについて、基本的な概念から実践的な応用までを解説します。これらの手法を理解し、適切に活用することで、大規模ワールドの実現に大きく貢献できるでしょう。

### クアッドツリー

#### 1. 概要と重要性

クアッドツリーは、2次元空間を再帰的に4分割していく空間分割手法です。各ノードは、空間内の矩形領域を表し、子ノードは親ノードの領域を4等分した矩形領域を表します。オブジェクトは、その位置する最小の矩形領域に対応するノードに格納されます。

クアッドツリーは、特に2次元ゲームや地理情報システム（GIS）などで広く利用されています。簡単な実装で高いパフォーマンスを発揮できるため、初心者にも扱いやすいのが特徴です。

#### 2. 特徴と利点

*   **単純な構造:** 実装が比較的容易であり、理解しやすい。
*   **動的な調整:** オブジェクトの移動や追加に合わせて、ツリー構造を動的に調整できる。
*   **高速な検索:** 特定の領域に存在するオブジェクトを高速に検索できる。
*   **メモリ効率:** オブジェクトの分布が均一でない場合でも、効率的にメモリを使用できる。

#### 3. 事前準備と前提条件

*   基本的なプログラミングスキル（C++, C#, Javaなど）
*   木構造に関する基本的な知識
*   2次元空間における座標系の理解

#### 4. 基本的な使い方

クアッドツリーの実装例を以下に示します（C#）。

```csharp
public class QuadTree
{
    private int _capacity; // ノードが保持できる最大オブジェクト数
    private Rectangle _boundary; // ノードの境界
    private List<GameObject> _objects; // ノードに格納されたオブジェクト

    private QuadTree _northWest;
    private QuadTree _northEast;
    private QuadTree _southWest;
    private QuadTree _southEast;

    public QuadTree(Rectangle boundary, int capacity = 4)
    {
        _capacity = capacity;
        _boundary = boundary;
        _objects = new List<GameObject>();
    }

    // オブジェクトを挿入
    public bool Insert(GameObject obj)
    {
        if (!_boundary.Contains(obj.Position))
        {
            return false; // オブジェクトが境界外にある場合
        }

        if (_objects.Count < _capacity && _northWest == null) // まだ分割されていない場合
        {
            _objects.Add(obj);
            return true;
        }
        else
        {
            if (_northWest == null)
            {
                Subdivide(); // 分割
            }

            // オブジェクトを適切な子ノードに挿入
            if (_northWest.Insert(obj)) return true;
            if (_northEast.Insert(obj)) return true;
            if (_southWest.Insert(obj)) return true;
            if (_southEast.Insert(obj)) return true;

            return false; // 全ての子ノードに挿入できなかった場合
        }
    }

    // ノードを4分割
    private void Subdivide()
    {
        float halfWidth = _boundary.Width / 2;
        float halfHeight = _boundary.Height / 2;
        float x = _boundary.X;
        float y = _boundary.Y;

        _northWest = new QuadTree(new Rectangle(x, y, halfWidth, halfHeight), _capacity);
        _northEast = new QuadTree(new Rectangle(x + halfWidth, y, halfWidth, halfHeight), _capacity);
        _southWest = new QuadTree(new Rectangle(x, y + halfHeight, halfWidth, halfHeight), _capacity);
        _southEast = new QuadTree(new Rectangle(x + halfWidth, y + halfHeight, halfWidth, halfHeight), _capacity);

        // 既存のオブジェクトを再配置
        foreach (var obj in _objects)
        {
            if (_northWest.Insert(obj)) continue;
            if (_northEast.Insert(obj)) continue;
            if (_southWest.Insert(obj)) continue;
            if (_southEast.Insert(obj)) continue;
        }

        _objects.Clear(); // 親ノードからは削除
    }

    // 特定の領域内のオブジェクトを検索
    public List<GameObject> Query(Rectangle range)
    {
        List<GameObject> foundObjects = new List<GameObject>();

        if (!_boundary.IntersectsWith(range))
        {
            return foundObjects; // 範囲が交差しない場合
        }

        foreach (var obj in _objects)
        {
            if (range.Contains(obj.Position))
            {
                foundObjects.Add(obj);
            }
        }

        if (_northWest != null)
        {
            foundObjects.AddRange(_northWest.Query(range));
            foundObjects.AddRange(_northEast.Query(range));
            foundObjects.AddRange(_southWest.Query(range));
            foundObjects.AddRange(_southEast.Query(range));
        }

        return foundObjects;
    }
}

public class GameObject
{
    public Vector2 Position { get; set; }
}

public struct Rectangle
{
    public float X { get; set; }
    public float Y { get; set; }
    public float Width { get; set; }
    public float Height { get; set; }

    public Rectangle(float x, float y, float width, float height)
    {
        X = x;
        Y = y;
        Width = width;
        Height = height;
    }

    public bool Contains(Vector2 point)
    {
        return point.X >= X && point.X <= X + Width && point.Y >= Y && point.Y <= Y + Height;
    }

     public bool IntersectsWith(Rectangle other)
    {
        return !(other.X > X + Width || other.X + other.Width < X || other.Y > Y + Height || other.Y + other.Height < Y);
    }
}

public struct Vector2
{
    public float X { get; set; }
    public float Y { get; set; }

    public Vector2(float x, float y)
    {
        X = x;
        Y = y;
    }
}
```

このコードは、オブジェクトを格納し、指定された矩形領域内のオブジェクトを検索する基本的なクアッドツリーの実装を示しています。`Insert`メソッドでオブジェクトを挿入し、`Query`メソッドでオブジェクトを検索します。

#### 5. 実践的なテクニック

*   **Capacityの調整:** 各ノードが保持できるオブジェクト数（`_capacity`）は、パフォーマンスに大きく影響します。適切な値を実験的に見つけることが重要です。一般的に、`_capacity`を小さくすると、ツリーの深さが深くなり、検索が高速になりますが、メモリ使用量が増加します。逆に、`_capacity`を大きくすると、ツリーの深さが浅くなり、メモリ使用量は減少しますが、検索が遅くなる可能性があります。
*   **境界の選択:** ワールド全体を包含する初期境界を適切に設定することが重要です。境界が小さすぎると、オブジェクトが挿入できなくなる可能性があります。
*   **動的な調整:** オブジェクトの移動に合わせて、ツリー構造を動的に調整することで、常に最適な状態を維持できます。ただし、頻繁な調整はパフォーマンスに影響を与える可能性があるため、注意が必要です。

#### 6. 応用例とユースケース

*   **2Dゲーム:** 敵キャラクターの当たり判定、弾丸と敵の当たり判定、可視範囲内のオブジェクトの描画などに利用できます。
*   **地理情報システム（GIS）:** 地図データの表示、特定の地域の検索、施設の検索などに利用できます。
*   **画像処理:** 画像の領域分割、特徴抽出などに利用できます。

#### 7. トラブルシューティング

*   **オブジェクトが挿入できない:** 境界が小さすぎる可能性があります。境界を広げるか、オブジェクトの位置を修正してください。
*   **検索が遅い:** `_capacity`が大きすぎる可能性があります。`_capacity`を小さくするか、ツリーの深さを深くすることを検討してください。
*   **メモリ使用量が多い:** `_capacity`が小さすぎる可能性があります。`_capacity`を大きくすることを検討してください。

#### 8. まとめと次のステップ

クアッドツリーは、2次元空間におけるオブジェクトの管理と検索に非常に有効な手法です。基本的な概念を理解し、実践的なテクニックを習得することで、大規模な2次元ワールドを効率的に構築できます。

次のステップとして、クアッドツリーのパフォーマンスをさらに向上させるための最適化手法や、3次元空間に対応したオクツリーについて学習することをお勧めします。

### KDツリー

#### 1. 概要と重要性

KDツリーは、k次元空間を軸に沿って再帰的に分割していく空間分割手法です。各ノードは、空間内の超矩形領域を表し、子ノードは親ノードの領域を、特定の軸に沿って2分割した超矩形領域を表します。分割軸は、通常、各ノードで交互に選択されます（例えば、X軸、Y軸、Z軸の順）。オブジェクトは、その位置する領域に対応するノードに格納されます。

KDツリーは、特に3次元ゲームや物理シミュレーションなどで広く利用されています。クアッドツリーよりも汎用性が高く、高次元空間にも対応できるのが特徴です。

#### 2. 特徴と利点

*   **高次元空間への対応:** 3次元以上の空間にも適用可能。
*   **軸に沿った分割:** 分割軸を交互に選択することで、偏った分布にも対応しやすい。
*   **高速な最近傍探索:** 特定の点に最も近いオブジェクトを高速に検索できる。
*   **動的な調整:** オブジェクトの移動や追加に合わせて、ツリー構造を動的に調整できる。

#### 3. 事前準備と前提条件

*   基本的なプログラミングスキル（C++, C#, Javaなど）
*   木構造に関する基本的な知識
*   k次元空間における座標系の理解

#### 4. 基本的な使い方

KDツリーの実装例を以下に示します（C#、3次元）。

```csharp
public class KDTree
{
    private int _k; // 次元数
    private KDNode _root;

    public KDTree(int k)
    {
        _k = k;
    }

    public void Insert(float[] point, object data)
    {
        _root = Insert(_root, point, data, 0);
    }

    private KDNode Insert(KDNode node, float[] point, object data, int depth)
    {
        if (node == null)
        {
            return new KDNode(point, data);
        }

        int cd = depth % _k; // 現在の分割軸

        if (point[cd] < node.Point[cd])
        {
            node.Left = Insert(node.Left, point, data, depth + 1);
        }
        else
        {
            node.Right = Insert(node.Right, point, data, depth + 1);
        }

        return node;
    }

    public object Nearest(float[] point)
    {
        return Nearest(_root, point, null, double.MaxValue, 0);
    }

    private object Nearest(KDNode node, float[] point, object best, double bestDistance, int depth)
    {
        if (node == null)
        {
            return best;
        }

        double distance = Distance(point, node.Point);

        if (distance < bestDistance)
        {
            bestDistance = distance;
            best = node.Data;
        }

        int cd = depth % _k;
        KDNode nearNode;
        KDNode farNode;

        if (point[cd] < node.Point[cd])
        {
            nearNode = node.Left;
            farNode = node.Right;
        }
        else
        {
            nearNode = node.Right;
            farNode = node.Left;
        }

        best = Nearest(nearNode, point, best, bestDistance, depth + 1);

        // 分割面を跨ぐ可能性を考慮
        if (Math.Abs(point[cd] - node.Point[cd]) < bestDistance)
        {
            best = Nearest(farNode, point, best, bestDistance, depth + 1);
        }

        return best;
    }


    private double Distance(float[] p1, float[] p2)
    {
        double sum = 0;
        for (int i = 0; i < _k; i++)
        {
            sum += Math.Pow(p1[i] - p2[i], 2);
        }
        return Math.Sqrt(sum);
    }
}

public class KDNode
{
    public float[] Point { get; set; }
    public object Data { get; set; }
    public KDNode Left { get; set; }
    public KDNode Right { get; set; }

    public KDNode(float[] point, object data)
    {
        Point = point;
        Data = data;
    }
}
```

このコードは、点を挿入し、指定された点に最も近いオブジェクトを検索する基本的なKDツリーの実装を示しています。`Insert`メソッドで点を挿入し、`Nearest`メソッドで最近傍探索を行います。

#### 5. 実践的なテクニック

*   **分割軸の選択:** 各ノードで分割軸を交互に選択するだけでなく、オブジェクトの分布に応じて最適な分割軸を選択することで、パフォーマンスを向上させることができます。例えば、分散が最も大きい軸を選択する方法があります。
*   **リーフノードの容量:** KDツリーを完全に分割するのではなく、リーフノードに複数のオブジェクトを格納することで、メモリ使用量を削減できます。
*   **近似最近傍探索:** 厳密な最近傍探索の代わりに、近似的な最近傍探索を行うことで、計算時間を短縮できます。例えば、バケット検索や優先度付き探索などが利用できます。

#### 6. 応用例とユースケース

*   **3Dゲーム:** 敵キャラクターのAI、パーティクルエフェクト、光線追跡などに利用できます。
*   **物理シミュレーション:** 衝突検出、近傍粒子探索などに利用できます。
*   **機械学習:** k-近傍法（k-NN）などのアルゴリズムに利用できます。
*   **データマイニング:** 大規模なデータセットからの類似データ検索に利用できます。

#### 7. トラブルシューティング

*   **メモリ使用量が多い:** KDツリーを完全に分割している可能性があります。リーフノードに複数のオブジェクトを格納するか、分割軸の選択方法を見直してください。
*   **最近傍探索が遅い:** 分割軸の選択が適切でない可能性があります。オブジェクトの分布に応じて最適な分割軸を選択してください。

#### 8. まとめと次のステップ

KDツリーは、k次元空間におけるオブジェクトの管理と検索に非常に有効な手法です。特に、最近傍探索において高いパフォーマンスを発揮します。

次のステップとして、KDツリーのバリアントであるBall Treeや、大規模なデータセットに対応するための手法について学習することをお勧めします。

### Rツリー

#### 1. 概要と重要性

Rツリーは、多次元空間におけるオブジェクト（特に領域）を効率的に管理するための木構造です。KDツリーが点を扱うのに適しているのに対し、Rツリーは矩形や多角形などの領域を扱うのに優れています。各ノードは、複数の子ノード（またはリーフノード）を持ち、それぞれのノードは、それらの子ノードを包含する最小の境界矩形（MBR: Minimum Bounding Rectangle）を持ちます。

Rツリーは、地理情報システム（GIS）、CADシステム、および空間データベースで広く使用されています。オーバーラップする可能性のある領域を効率的に管理できるため、複雑な空間データセットを扱うのに適しています。

#### 2. 特徴と利点

*   **領域の管理:** 点だけでなく、矩形や多角形などの領域を効率的に管理できる。
*   **オーバーラップへの対応:** オーバーラップする領域を効率的に扱うことができる。
*   **動的な更新:** オブジェクトの挿入、削除、更新に対応できる。
*   **範囲検索:** 特定の領域と交差するオブジェクトを高速に検索できる。

#### 3. 事前準備と前提条件

*   基本的なプログラミングスキル（C++, C#, Javaなど）
*   木構造に関する基本的な知識
*   多次元空間における領域の表現と計算の理解

#### 4. 基本的な使い方

Rツリーの実装例を以下に示します（C#）。

public class RTree
{
    private int _maxEntries; // ノードが保持できる最大エントリ数
    private RTreeNode _root;

    public RTree(int maxEntries = 9)
    {
        _maxEntries = maxEntries;
        _root = new RTreeNode(true); // ルートノードはリーフノードとして初期化
    }

    public void Insert(Rectangle rect, object data)
    {
        _root = Insert(_root, rect, data);
    }

    private RTreeNode Insert(RTreeNode node, Rectangle rect, object data)
    {
        if (node.IsLeaf)
        {
            node.Entries.Add(new RTreeEntry(rect, data));
            if (node.Entries.Count > _maxEntries)
            {
                return SplitNode(node); // ノードを分割
            }
            else
            {
                return node;
            }
        }
        else
        {
            // 最も拡張が少ない子ノードを選択
            RTreeNode bestChild = null;
            float minAreaIncrease = float.MaxValue;
            foreach (var entry in node.Entries)
            {
                float areaIncrease = CalculateAreaIncrease(entry.Rectangle, rect);
                if (areaIncrease < minAreaIncrease)
                {
                    minAreaIncrease = areaIncrease;
                    bestChild = entry.Child;
                }
            }

            bestChild = Insert(bestChild, rect, data);
            // 親ノードのMBRを更新
            UpdateMBR(node, rect);

            return node;
        }
    }

    {

        }

        {
            if (searchRect.IntersectsWith(entry.Rectangle))

                if (node.IsLeaf)

#### 5. 実践的なテクニック

*   **ノード分割戦略:** ノードがオーバーフローした場合、どのように分割するかは、Rツリーのパフォーマンスに大きな影響を与えます。代表的な分割戦略としては、Quadratic Split、Linear Split、Greene's Splitなどがあります。
*   **MBRの最適化:** 各ノードのMBRをできるだけ小さく保つことで、検索効率を向上させることができます。
*   **動的な調整:** オブジェクトの移動やサイズの変更に合わせて、ツリー構造を動的に調整することで、常に最適な状態を維持できます。

#### 6. 応用例とユースケース

*   **地理情報システム（GIS）:** 地図データのインデックス作成、空間クエリ処理などに利用できます。
*   **CADシステム:** 図面データの管理、干渉チェックなどに利用できます。
*   **空間データベース:** 空間データの検索、分析などに利用できます。
*   **衝突検出:** ゲームやシミュレーションにおけるオブジェクト間の衝突検出に利用できます。

#### 7. トラブルシューティング

*   **検索が遅い:** ノード分割戦略が適切でない可能性があります。別の分割戦略を試すか、MBRの最適化を検討してください。
*   **メモリ使用量が多い:** ノードが過剰に分割されている可能性があります。`_maxEntries`を大きくするか、分割戦略を見直してください。

#### 8. まとめと次のステップ

Rツリーは、多次元空間における領域の管理と検索に非常に有効な手法です。特に、GISやCADシステムなど、空間データを扱うアプリケーションにおいて重要な役割を果たします。

次のステップとして、RツリーのバリアントであるR+ツリーやR*ツリーについて学習することをお勧めします。これらのバリアントは、Rツリーのパフォーマンスをさらに向上させるための様々な最適化手法を取り入れています。

この章で紹介した空間分割手法は、大規模ワールドの実現に不可欠な技術です。それぞれの特徴を理解し、適切な手法を選択することで、パフォーマンスの高いアプリケーションを開発できるでしょう。
