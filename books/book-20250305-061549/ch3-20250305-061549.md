## 第3章: Stable Diffusionの基本操作：テキストから画像を生成する

Stable Diffusionは、テキストプロンプトから高品質な画像を生成できる強力なツールです。この章では、Stable Diffusionを使い始めるための基本操作を、Diffusersライブラリを用いて段階的に解説します。プロンプトの書き方から、画像生成のパラメータ調整まで、実践的なテクニックを習得し、あなたの創造性を解き放ちましょう。

### 3.1 Diffusersライブラリを使った基本的な画像生成

#### 3.1.1 概要と重要性

Diffusersは、Hugging Faceが開発した、拡散モデル（Diffusion Models）を簡単に利用できるPythonライブラリです。Stable Diffusionも拡散モデルの一種であり、Diffusersを利用することで、複雑な実装を気にすることなく、手軽に画像生成を始めることができます。このライブラリは、PyTorchやTensorFlowなどの主要な機械学習フレームワークに対応しており、学習済みのモデルを簡単にダウンロードして使用できます。

#### 3.1.2 特徴と利点

*   **簡単なセットアップ**: わずか数行のコードでStable Diffusionを起動し、画像生成を開始できます。
*   **多様なモデルのサポート**: Stable Diffusionだけでなく、様々な拡散モデルを試すことができます。
*   **高度なカスタマイズ**: 生成パイプラインを細かく制御し、独自の画像生成プロセスを構築できます。
*   **コミュニティ**: 活発なコミュニティによるサポートと、豊富なドキュメントが利用可能です。

#### 3.1.3 事前準備と前提条件

*   **Python**: 3.7以上のバージョンを推奨します。
*   **pip**: Pythonのパッケージマネージャが必要です。
*   **PyTorch**: GPUを使用する場合は、CUDA対応のPyTorchをインストールしてください。
*   **Diffusersライブラリ**: `pip install diffusers transformers accelerate`でインストールします。
*   **Hugging Face Hubアカウント**: モデルをダウンロードするために必要です。（無料アカウントでOK）

#### 3.1.4 基本的な使い方

まずは、Diffusersライブラリを使ってStable Diffusionで画像を生成する基本的なコードを見ていきましょう。

```python
from diffusers import StableDiffusionPipeline
from PIL import Image

# モデルIDを指定（Stable Diffusionの様々なバリエーションが存在します）
model_id = "runwayml/stable-diffusion-v1-5" # 公式モデル

# GPUが利用可能な場合は、CUDAを使用
device = "cuda"

# パイプラインの作成
pipe = StableDiffusionPipeline.from_pretrained(model_id).to(device)

# プロンプト
prompt = "A photo of a cat wearing a hat"

# 画像生成
image = pipe(prompt).images[0]

# 画像の保存
image.save("cat_with_hat.png")

# 画像の表示 (Jupyter Notebookなどで実行する場合)
# image
```

**コード解説:**

1.  `from diffusers import StableDiffusionPipeline`: DiffusersライブラリからStableDiffusionPipelineクラスをインポートします。
2.  `model_id = "runwayml/stable-diffusion-v1-5"`: 使用するStable DiffusionのモデルIDを指定します。ここでは、runwayml/stable-diffusion-v1-5という公式モデルを指定しています。別のモデルも指定できます。
3.  `device = "cuda"`: GPUを使用する場合は、デバイスを"cuda"に設定します。GPUがない場合は、"cpu"に設定します。
4.  `pipe = StableDiffusionPipeline.from_pretrained(model_id).to(device)`: 指定したモデルIDのStable Diffusionパイプラインを作成し、指定したデバイスにロードします。`.from_pretrained()`は、Hugging Face Hubから学習済みのモデルをダウンロードしてロードします。初回実行時はモデルのダウンロードに時間がかかります。
5.  `prompt = "A photo of a cat wearing a hat"`: 画像生成に使用するプロンプト（テキスト）を設定します。
6.  `image = pipe(prompt).images[0]`: パイプラインにプロンプトを渡して画像を生成します。`pipe()`メソッドは、生成された画像のリストを返します。ここでは、最初の画像（`images[0]`）を取得しています。
7.  `image.save("cat_with_hat.png")`: 生成された画像を"cat_with_hat.png"という名前で保存します。

#### 3.1.5 実践的なテクニック

**異なるモデルを試す:**

Stable Diffusionには、様々な派生モデルが存在します。例えば、Realistic VisionやDreamShaperなど、特定のスタイルに特化したモデルを試してみると、表現の幅が広がります。

```python
model_id = "Lykon/dreamshaper-xl-v2-turbo" # DreamShaper XL Turbo モデル
pipe = StableDiffusionPipeline.from_pretrained(model_id).to(device)
```

**複数の画像を生成する:**

同じプロンプトで複数の画像を生成することで、より良い結果を得られる可能性が高まります。

```python
num_images = 4
images = pipe([prompt] * num_images).images

for i, image in enumerate(images):
    image.save(f"cat_with_hat_{i}.png")
```

**シード値の固定:**

シード値を固定することで、同じプロンプトで実行した場合に、毎回同じ画像を生成できます。再現性を高めるために重要です。

```python
import torch

generator = torch.Generator(device=device).manual_seed(42) # 42は例。好きな数字を指定
image = pipe(prompt, generator=generator).images[0]
image.save("cat_with_hat_seed42.png")
```

#### 3.1.6 応用例とユースケース

*   **アート作品の生成**: テキストプロンプトで抽象的なアート作品や風景画を生成する。
*   **コンセプトアートの作成**: ゲームや映画のキャラクターや背景のコンセプトアートを生成する。
*   **広告素材の作成**: 商品やサービスのイメージをテキストプロンプトで生成する。
*   **ブログやSNSのアイキャッチ画像の作成**: 記事の内容に合わせた画像を自動生成する。
*   **デザインのプロトタイプ作成**: 製品デザインのアイデアを画像として可視化する。

#### 3.1.7 トラブルシューティング

*   **メモリ不足**: GPUのメモリが不足する場合は、バッチサイズを小さくしたり、よりメモリ効率の良いモデルを使用したりすることを検討してください。
*   **モデルのダウンロードエラー**: ネットワーク環境を確認し、Hugging Face Hubへのアクセスが正常に行われているか確認してください。
*   **期待通りの画像が生成されない**: プロンプトを修正したり、パラメータを調整したりすることで、改善されることがあります。

### 3.2 プロンプトの基本：キーワード、属性、スタイル

#### 3.2.1 概要と重要性

プロンプトは、Stable Diffusionにどのような画像を生成させたいかを指示するテキストです。プロンプトの質は、生成される画像の品質に大きく影響します。効果的なプロンプトを作成することで、あなたの想像力を最大限に引き出すことができます。

#### 3.2.2 特徴と利点

*   **表現の自由度**: プロンプトを工夫することで、様々なスタイルやテーマの画像を生成できます。
*   **創造性の刺激**: プロンプトを考える過程で、新たなアイデアや発見が生まれることがあります。
*   **高品質な画像生成**: 明確で詳細なプロンプトは、高品質な画像を生成するための鍵となります。

#### 3.2.3 事前準備と前提条件

*   **Stable Diffusionの環境構築**: 前のセクションで説明した環境が構築されている必要があります。
*   **創造的な思考**: どのような画像を生成したいか、具体的なイメージを持つことが重要です。
*   **英語の基礎知識**: Stable Diffusionは英語のプロンプトに最適化されています。

#### 3.2.4 基本的な使い方

基本的なプロンプトは、生成したい画像の主要な要素を記述します。

```python
prompt = "A beautiful landscape" # 美しい風景
```

より具体的な画像を生成するには、キーワード、属性、スタイルを追加します。

*   **キーワード**: 画像に含めるオブジェクトや要素を指定します。
    *   例: `cat`, `dog`, `mountain`, `ocean`
*   **属性**: オブジェクトの色、形、大きさ、状態などを指定します。
    *   例: `red`, `fluffy`, `giant`, `sleeping`
*   **スタイル**: 画像のスタイル（写真、絵画、アニメなど）やアーティストを指定します。
    *   例: `photorealistic`, `oil painting`, `anime style`, `by Van Gogh`

#### 3.2.5 実践的なテクニック

**キーワードの組み合わせ:**

複数のキーワードを組み合わせることで、より複雑なシーンを表現できます。

```python
prompt = "A cat wearing a hat in a forest" # 帽子を被った猫が森の中にいる
```

**属性の追加:**

属性を追加することで、オブジェクトの具体的な特徴を指定できます。

```python
prompt = "A fluffy white cat wearing a red hat in a dark forest" # ふわふわの白い猫が赤い帽子を被って暗い森の中にいる
```

**スタイルの指定:**

スタイルの指定により、画像の雰囲気を大きく変えることができます。

```python
prompt = "A fluffy white cat wearing a red hat in a dark forest, oil painting by Van Gogh" # ふわふわの白い猫が赤い帽子を被って暗い森の中にいる、ゴッホ風の油絵
```

**ネガティブプロンプト:**

ネガティブプロンプトを使用すると、画像に含めたくない要素を指定できます。これにより、より高品質な画像を生成できます。

```python
pipe = StableDiffusionPipeline.from_pretrained(model_id).to(device)

prompt = "A beautiful woman"
negative_prompt = "ugly, deformed, blurry"

image = pipe(prompt=prompt, negative_prompt=negative_prompt).images[0]
image.save("beautiful_woman_negative.png")
```

**プロンプトエンジニアリング:**

プロンプトエンジニアリングとは、特定のタスクに対して最適なプロンプトを見つけるための技術です。試行錯誤を繰り返すことで、より良いプロンプトを作成することができます。例えば、以下のようなテクニックがあります。

*   **形容詞の追加**: "beautiful", "stunning", "amazing"などの形容詞を追加することで、画像の品質を向上させることができます。
*   **具体的な指示**: "close-up", "full shot", "wide angle"などの指示を追加することで、構図を制御できます。
*   **詳細な描写**: シーンの細部まで具体的に描写することで、よりイメージに近い画像を生成できます。

#### 3.2.6 応用例とユースケース

*   **ファンタジー世界の創造**: "A majestic dragon flying over a crystal clear lake, epic fantasy art"のようなプロンプトで、ファンタジー世界を創造する。
*   **建築デザイン**: "A modern minimalist house with large windows overlooking the ocean, architectural rendering"のようなプロンプトで、建築デザインを生成する。
*   **ポートレート写真**: "A portrait of a young woman with long hair, natural light, professional photography"のようなプロンプトで、ポートレート写真を生成する。

#### 3.2.7 トラブルシューティング

*   **プロンプトが無視される**: プロンプトが短すぎるか、曖昧すぎる可能性があります。より詳細なプロンプトを試してください。
*   **意図しない画像が生成される**: ネガティブプロンプトを追加することで、意図しない要素を排除できます。
*   **文法的な誤り**: プロンプトの文法的な誤りも、画像の品質に影響する可能性があります。文法チェッカーなどを使用して確認してください。

### 3.3 画像生成のパラメータ調整：guidance scale, steps

#### 3.3.1 概要と重要性

Stable Diffusionには、画像の生成プロセスを制御するための様々なパラメータがあります。これらのパラメータを調整することで、生成される画像の品質、スタイル、詳細度などを細かく制御できます。特に、`guidance scale`と`steps`は、最も重要なパラメータであり、効果的な調整によって、あなたの意図した画像を生成することができます。

#### 3.3.2 特徴と利点

*   **微調整の自由度**: パラメータを調整することで、生成される画像を細かく制御できます。
*   **実験と発見**: 様々なパラメータの組み合わせを試すことで、新たな表現方法を発見できます。
*   **高品質な画像生成**: 最適なパラメータ設定を見つけることで、高品質な画像を生成できます。

#### 3.3.3 事前準備と前提条件

*   **Stable Diffusionの環境構築**: 前のセクションで説明した環境が構築されている必要があります。
*   **プロンプトの作成**: ある程度、プロンプトの作成に慣れている必要があります。
*   **実験精神**: 様々なパラメータを試すことを厭わない気持ちが重要です。

#### 3.3.4 基本的な使い方

`guidance scale`と`steps`は、StableDiffusionPipelineの`__call__`メソッドの引数として指定します。

```python
pipe = StableDiffusionPipeline.from_pretrained(model_id).to(device)

prompt = "A beautiful landscape"

# Guidance scale: プロンプトへの適合度を調整 (通常7.5が推奨)
guidance_scale = 7.5

# Steps: 生成プロセスを繰り返す回数を調整 (通常20-50が推奨)
num_inference_steps = 50

image = pipe(prompt, guidance_scale=guidance_scale, num_inference_steps=num_inference_steps).images[0]
image.save("landscape_gs7.5_steps50.png")
```

**`guidance scale`:**

`guidance scale`は、プロンプトへの適合度を調整するパラメータです。値が大きいほど、プロンプトに忠実な画像が生成されますが、過剰に大きくすると、画像が不自然になったり、アーティファクトが発生したりすることがあります。一般的には、7.5程度が推奨されますが、プロンプトやモデルによって最適な値が異なります。

*   **低い値 (例: 3)**: プロンプトの影響が弱まり、より自由な画像が生成されます。創造的な表現や抽象的なイメージを生成するのに適しています。
*   **高い値 (例: 15)**: プロンプトの影響が強まり、プロンプトに忠実な画像が生成されます。具体的なオブジェクトやシーンを生成するのに適しています。

**`steps`:**

`steps`は、画像の生成プロセスを繰り返す回数を調整するパラメータです。値が大きいほど、より詳細で高品質な画像が生成されますが、計算時間も長くなります。一般的には、20から50程度が推奨されますが、プロンプトやモデルによって最適な値が異なります。

*   **低い値 (例: 10)**: 生成時間が短縮されますが、画像の詳細度が低くなります。ラフなイメージやプロトタイプを作成するのに適しています。
*   **高い値 (例: 100)**: 生成時間が長くなりますが、画像の詳細度が高くなります。高品質な画像を生成するのに適しています。

#### 3.3.5 実践的なテクニック

**パラメータの組み合わせ:**

`guidance scale`と`steps`は、互いに影響しあうため、最適な組み合わせを見つけることが重要です。例えば、`guidance scale`が高い場合は、`steps`を低くしても、プロンプトに忠実な画像を生成できます。

**実験と記録:**

様々なパラメータの組み合わせを試し、結果を記録することで、どのような設定がどのような画像を生み出すかを理解することができます。

**パラメータスイープ:**

複数のパラメータを自動的に変更しながら画像を生成し、最適な設定を見つける方法です。

```python
import itertools

pipe = StableDiffusionPipeline.from_pretrained(model_id).to(device)
prompt = "A beautiful landscape"

guidance_scales = [5, 7.5, 10]
num_inference_steps_list = [20, 30, 40]

# パラメータの組み合わせを生成
param_combinations = list(itertools.product(guidance_scales, num_inference_steps_list))

for gs, steps in param_combinations:
    image = pipe(prompt, guidance_scale=gs, num_inference_steps=steps).images[0]
    image.save(f"landscape_gs{gs}_steps{steps}.png")
```

このコードは、`guidance_scales`と`num_inference_steps_list`に設定された値のすべての組み合わせで画像を生成し、ファイル名にパラメータの値を含めて保存します。結果を比較することで、最適な設定を見つけることができます。

#### 3.3.6 応用例とユースケース

*   **スタイルの微調整**: `guidance scale`を調整することで、画像のスタイルを微調整できます。例えば、写真のようなリアルな画像を生成したい場合は、`guidance scale`を高めに設定します。
*   **詳細度の向上**: `steps`を調整することで、画像の詳細度を向上させることができます。例えば、風景画のような複雑なシーンを生成したい場合は、`steps`を高めに設定します。
*   **計算時間の短縮**: `guidance scale`と`steps`を適切に調整することで、画像の品質を維持しつつ、計算時間を短縮することができます。

#### 3.3.7 トラブルシューティング

*   **画像が不自然になる**: `guidance scale`が高すぎる可能性があります。値を下げてみてください。
*   **画像がぼやける**: `steps`が低すぎる可能性があります。値を上げてみてください。
*   **生成時間が長すぎる**: `steps`が高すぎる可能性があります。値を下げてみてください。
