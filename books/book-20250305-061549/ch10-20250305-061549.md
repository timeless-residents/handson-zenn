## 第10章: Stable Diffusion WebUI (AUTOMATIC1111) の活用

Stable Diffusion WebUI、特にAUTOMATIC1111版は、Stable DiffusionをGUIで操作するための最も人気のあるインターフェースの一つです。この章では、WebUIのインストールから基本操作、便利な拡張機能の活用、カスタマイズまで、Stable Diffusionを最大限に活用するための方法を解説します。初心者から上級者まで、幅広いレベルの読者がStable Diffusionをより深く理解し、実践に役立てられるように、段階的な説明と具体的な例を交えて解説していきます。

### 10.1 WebUIのインストールと基本操作

#### 概要と重要性

AUTOMATIC1111版Stable Diffusion WebUIは、コマンドライン操作を必要とせず、GUIを通じてStable Diffusionの様々な機能を実行できる強力なツールです。直感的なインターフェースと豊富な機能を備えており、初心者でも容易にStable Diffusionの世界に入り込むことができます。また、拡張機能の導入やカスタマイズも容易であり、上級者にとっても手放せないツールとなっています。画像生成AIを本格的に利用していく上で、WebUIの習得は必要不可欠と言えるでしょう。

#### 特徴と利点

*   **直感的なGUI:** ブラウザベースのGUIで、プロンプトの入力、パラメータの設定、画像の生成などが容易に行えます。
*   **豊富な機能:** テキストから画像生成、画像から画像生成、画像修復、アップスケーリングなど、多彩な機能を搭載しています。
*   **強力な拡張性:** 多くの拡張機能が利用可能で、ControlNetやadetailerなど、特定のタスクに特化した機能を追加できます。
*   **活発なコミュニティ:** 活発なコミュニティがあり、情報交換や問題解決が容易に行えます。
*   **無料:** オープンソースソフトウェアとして公開されており、無料で利用できます。

#### 事前準備と前提条件

*   **Python:** Python 3.10以上がインストールされている必要があります。
*   **Git:** Gitがインストールされている必要があります。
*   **GPU:** NVIDIA製のGPU (CUDA) またはAMD製のGPU (ROCm/DirectML) を推奨します。CPUでも動作しますが、処理速度が大幅に低下します。GPUのVRAMが少ない場合は、後述する`--lowvram`オプションを使用することで、メモリ消費量を削減できます。
*   **VRAM:** 最低でも4GB以上のVRAMを推奨します。8GB以上あれば、より多くの機能を快適に利用できます。
*   **モデルデータ:** Stable Diffusionのモデルデータ（.ckptまたは.safetensorsファイル）が必要です。例えば、Stable Diffusion 1.5やStable Diffusion 2.1、またはHugging Faceで公開されている様々なモデルをダウンロードして利用できます。
    *   [Hugging Face](https://huggingface.co/models)

#### 基本的な使い方

1.  **WebUIのインストール:**

    ```bash
    git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui
    cd stable-diffusion-webui
    ```

2.  **起動スクリプトの実行:**

    *   Windowsの場合: `webui-user.bat` を実行します。
    *   Linux/macOSの場合: `webui.sh` を実行します。

    初回起動時には、必要なライブラリのインストールが行われます。これには時間がかかる場合があります。

3.  **モデルデータの配置:**

    ダウンロードしたモデルデータ（.ckptまたは.safetensorsファイル）を `stable-diffusion-webui/models/Stable-diffusion` フォルダに配置します。

4.  **Webブラウザでのアクセス:**

    WebUIの起動が完了すると、ブラウザで `http://localhost:7860` にアクセスできるようになります。

5.  **基本的な操作:**

    *   **txt2imgタブ:** テキストから画像を生成します。
    *   **img2imgタブ:** 画像を元に画像を生成します。
    *   **Prompt:** 生成したい画像のプロンプトを入力します。
    *   **Negative prompt:** 生成したくない要素のプロンプトを入力します。
    *   **Sampling method:** サンプリング方法を選択します。DPM++ 2M KarrasやEuler aなどが一般的です。
    *   **Sampling steps:** サンプリングステップ数を設定します。20-30程度が推奨されます。
    *   **Width/Height:** 生成する画像のサイズを設定します。512x512や768x768などが一般的です。
    *   **CFG Scale:** プロンプトへの適合度を設定します。7-12程度が推奨されます。
    *   **Seed:** 乱数のシード値を設定します。同じシード値を使用すると、同じ画像が生成されます。-1にするとランダムなシードが使用されます。
    *   **Generate:** 画像を生成します。

    例えば、「a beautiful girl in a futuristic city」というプロンプトで画像を生成するには、txt2imgタブのPrompt欄にこのテキストを入力し、Generateボタンをクリックします。Negative promptには、「ugly, deformed, bad anatomy」などを入力すると、生成される画像の品質を向上させることができます。

#### 実践的なテクニック

*   **プロンプトエンジニアリング:** プロンプトの書き方によって、生成される画像の品質が大きく変わります。具体的で詳細なプロンプトを書くことで、よりイメージに近い画像を生成できます。例えば、「a photo of a beautiful girl with long blonde hair, wearing a blue dress, standing in a futuristic city at night, neon lights, highly detailed, 8k」のように、具体的な要素を組み合わせることで、より高品質な画像を生成できます。
*   **ネガティブプロンプトの活用:** ネガティブプロンプトは、生成したくない要素を指定することで、画像の品質を向上させる効果があります。例えば、「ugly, deformed, bad anatomy, blurry, low quality」などを指定することで、より高品質な画像を生成できます。
*   **サンプリング方法の選択:** サンプリング方法によって、生成される画像のスタイルが異なります。DPM++ 2M Karrasは、高品質な画像を生成するのに適しており、Euler aは、高速に画像を生成するのに適しています。
*   **シード値の活用:** シード値を固定することで、同じプロンプトで同じ画像を生成できます。シード値を少しずつ変更することで、バリエーション豊かな画像を生成できます。

#### 応用例とユースケース

*   **キャラクターデザイン:** オリジナルのキャラクターをデザインするために、Stable Diffusionを活用できます。プロンプトにキャラクターの特徴や服装などを記述することで、様々なキャラクターを生成できます。
*   **風景画の生成:** 美しい風景画を生成するために、Stable Diffusionを活用できます。プロンプトに風景の特徴や時間帯などを記述することで、様々な風景画を生成できます。
*   **イラスト制作:** イラスト制作のアイデア出しや、ラフスケッチの作成にStable Diffusionを活用できます。
*   **ゲームアセットの生成:** ゲームで使用するテクスチャやモデルを生成するために、Stable Diffusionを活用できます。
*   **広告素材の生成:** 広告で使用するイメージ画像を生成するために、Stable Diffusionを活用できます。

#### トラブルシューティング

*   **メモリ不足エラー:** GPUのVRAMが不足している場合、メモリ不足エラーが発生する場合があります。この場合、`--lowvram`オプションを付けてWebUIを起動することで、メモリ消費量を削減できます。また、画像のサイズを小さくしたり、サンプリングステップ数を減らすことでも、メモリ消費量を削減できます。`--medvram`オプションも試す価値があります。

    ```bash
    # Windows
    webui-user.bat --lowvram

    # Linux/macOS
    ./webui.sh --lowvram
    ```

*   **CUDAエラー:** CUDAドライバのバージョンが古い場合、CUDAエラーが発生する場合があります。CUDAドライバを最新バージョンにアップデートしてください。
*   **起動エラー:** WebUIの起動時にエラーが発生する場合、依存関係が正しくインストールされていない可能性があります。WebUIのフォルダで、以下のコマンドを実行して、依存関係を再インストールしてみてください。

    ```bash
    pip install -r requirements.txt
    ```
    またはvenvを削除して再構築するのも有効です。

### 10.2 便利な拡張機能：ControlNet, adetailer, Latent Couple

#### 概要と重要性

Stable Diffusion WebUIの強力な点の1つは、その拡張性です。様々な拡張機能を導入することで、Stable Diffusionの機能を拡張し、より高度なタスクを実行できるようになります。このセクションでは、特に便利な拡張機能であるControlNet、adetailer、Latent Coupleについて解説します。

#### 特徴と利点

*   **ControlNet:** 画像の構造や構図を制御して画像を生成できます。例えば、ポーズを指定したり、線画を元に画像を生成したりできます。
*   **adetailer:** 生成された画像の顔や手などの細部を自動的に修正できます。
*   **Latent Couple:** 画像を複数の領域に分割し、それぞれの領域に対して異なるプロンプトを適用できます。

#### 事前準備と前提条件

*   **Stable Diffusion WebUI:** Stable Diffusion WebUIがインストールされている必要があります。
*   **各拡張機能のインストール:** 各拡張機能は、WebUIのExtensionsタブからインストールできます。URLを指定してインストールする方式が一般的です。
    *   ControlNet: `https://github.com/Mikubill/sd-webui-controlnet`
    *   adetailer: `https://github.com/Bing-Ling-Waffle/adetailer`
    *   Latent Couple: `https://github.com/djbielecki/stable-diffusion-webui-latent-couple`

    インストール後、WebUIを再起動する必要があります。ControlNetを使用する場合は、ControlNetモデルのダウンロードが必要です。ControlNetのWebUI画面からダウンロードできます。

#### 基本的な使い方

**1. ControlNet:**

ControlNetを使用すると、画像の構造や構図を制御して画像を生成できます。

*   **Control Type:** 画像の構造を制御するための種類を選択します。例えば、Canny edge detection (canny)は、画像のエッジを抽出して、そのエッジに沿って画像を生成します。Pose estimation (openpose)は、人物のポーズを検出し、そのポーズに沿って画像を生成します。
*   **Control Image:** 構造を制御するための画像を指定します。
*   **Preprocessor:** 画像の前処理方法を選択します。
*   **Model:** 使用するControlNetモデルを選択します。
*   **Control Weight:** ControlNetの効果の強さを設定します。
*   **Starting/Ending Control Step:** ControlNetを適用するステップ範囲を設定します。

例えば、人物のポーズを指定して画像を生成するには、Control TypeをPose estimation (openpose)に設定し、Control Imageに人物のポーズが描かれた画像を指定します。PreprocessorとModelを選択し、Generateボタンをクリックすると、指定したポーズに沿った人物画像が生成されます。

**2. adetailer:**

adetailerを使用すると、生成された画像の顔や手などの細部を自動的に修正できます。

*   **Enable Adetailer:** Adetailerを有効にします。
*   **Model:** 使用するadetailerモデルを選択します。FaceYOLOv3 が顔検出に利用できます。
*   **Confidence threshold:** 検出の信頼度を設定します。
*   **Mask blur:** マスクのぼかし度合いを設定します。
*   **Denoising strength:** ノイズ除去の強度を設定します。
*   **Inpaint at original resolution:** 元の解像度で修復を行うかどうかを設定します。

例えば、生成された画像の顔を修正するには、Enable Adetailerを有効にし、ModelにFaceYOLOv3を選択します。Denoising strengthを調整し、Generateボタンをクリックすると、顔が自動的に修正された画像が生成されます。

**3. Latent Couple:**

Latent Coupleを使用すると、画像を複数の領域に分割し、それぞれの領域に対して異なるプロンプトを適用できます。

*   **Enable Latent Couple:** Latent Coupleを有効にします。
*   **Grid Size:** 画像を分割するグリッドのサイズを設定します。
*   **Prompts:** 各領域に対するプロンプトを入力します。
*   **Negative Prompts:** 各領域に対するネガティブプロンプトを入力します。

例えば、画像を左半分と右半分に分割し、左半分に「a cat」、右半分に「a dog」というプロンプトを適用するには、Grid Sizeを1x2に設定し、Promptsに「a cat, a dog」と入力します。Generateボタンをクリックすると、左半分に猫、右半分に犬が描かれた画像が生成されます。

#### 実践的なテクニック

*   **ControlNetとプロンプトの組み合わせ:** ControlNetで大まかな構図を制御し、プロンプトで詳細な要素を指定することで、よりイメージに近い画像を生成できます。
*   **adetailerの設定調整:** adetailerの設定を調整することで、修正の度合いを調整できます。Denoising strengthを高くすると、より強く修正されますが、元の画像の特徴が失われる可能性があります。
*   **Latent Coupleによる複雑な構図の生成:** Latent Coupleを使用することで、複数の要素が組み合わさった複雑な構図の画像を生成できます。

#### 応用例とユースケース

*   **ControlNetによる建築デザイン:** ControlNetを使用することで、建物の設計図を元に、リアルな建築画像を生成できます。
*   **adetailerによるポートレート写真の修正:** adetailerを使用することで、ポートレート写真の顔の細部を修正し、より美しい写真に仕上げることができます。
*   **Latent Coupleによる風景写真の合成:** Latent Coupleを使用することで、複数の風景写真を合成し、オリジナルの風景写真を生成できます。

#### トラブルシューティング

*   **ControlNetモデルのエラー:** ControlNetモデルが正しくロードされていない場合、エラーが発生する場合があります。モデルが正しい場所に配置されているか確認してください。
*   **adetailerの過剰な修正:** adetailerの設定が高すぎる場合、過剰な修正が行われることがあります。Denoising strengthを調整してみてください。
*   **Latent Coupleのプロンプトの競合:** Latent Coupleで複数の領域に異なるプロンプトを適用する場合、プロンプトが競合することがあります。プロンプトを調整して、矛盾がないようにしてください。

### 10.3 WebUIのカスタマイズ：テーマ変更、スクリプトの追加

#### 概要と重要性

Stable Diffusion WebUIは、テーマ変更やスクリプトの追加など、様々な方法でカスタマイズできます。WebUIを自分好みにカスタマイズすることで、より快適にStable Diffusionを利用できます。

#### 特徴と利点

*   **テーマ変更:** WebUIの見た目を変更できます。
*   **スクリプトの追加:** WebUIの機能を拡張できます。
*   **オプション設定:** 起動オプションを設定することで、WebUIの動作を調整できます。

#### 事前準備と前提条件

*   **Stable Diffusion WebUI:** Stable Diffusion WebUIがインストールされている必要があります。
*   **テーマファイル:** テーマファイル（.cssファイル）が必要です。
*   **スクリプト:** スクリプト（.pyファイル）が必要です。

#### 基本的な使い方

**1. テーマ変更:**

WebUIの見た目を変更するには、テーマファイルをWebUIのthemesフォルダに配置し、WebUIの設定画面からテーマを選択します。

*   **テーマファイルの配置:** テーマファイルを `stable-diffusion-webui/themes` フォルダに配置します。
*   **設定画面での選択:** WebUIの設定画面（Settingsタブ）を開き、User interfaceセクションのThemesドロップダウンメニューから、配置したテーマを選択します。
*   **WebUIの再起動:** WebUIを再起動すると、選択したテーマが適用されます。

様々なテーマが公開されており、例えば、ダークテーマやミニマルなテーマなどがあります。GitHubなどで検索してみると良いでしょう。

**2. スクリプトの追加:**

WebUIの機能を拡張するには、スクリプトファイルをWebUIのscriptsフォルダに配置します。スクリプトは、WebUIのUIに追加の機能を提供したり、画像の生成処理を自動化したりできます。

*   **スクリプトファイルの配置:** スクリプトファイルを `stable-diffusion-webui/scripts` フォルダに配置します。
*   **WebUIの再起動:** WebUIを再起動すると、配置したスクリプトがWebUIのUIに追加されます。

スクリプトはPythonで記述する必要があります。例えば、画像を生成するたびに、特定のフォルダに画像を自動的に保存するスクリプトや、プロンプトを自動的に生成するスクリプトなどを作成できます。

**3. 起動オプションの設定:**

WebUIの起動オプションを設定することで、WebUIの動作を調整できます。起動オプションは、`webui-user.bat`（Windowsの場合）または`webui.sh`（Linux/macOSの場合）ファイルに記述します。

*   **オプションの記述:** 起動オプションを、`COMMANDLINE_ARGS` 変数に記述します。

    ```bash
    # webui-user.bat (Windows)
    set COMMANDLINE_ARGS=--xformers --medvram --autolaunch

    # webui.sh (Linux/macOS)
    COMMANDLINE_ARGS="--xformers --medvram --autolaunch"
    ```

よく使用される起動オプションには、以下のようなものがあります。

*   `--xformers`: xFormersを使用します。メモリ効率と処理速度を向上させることができます。
*   `--medvram`: 中程度のVRAMを使用します。VRAMが少ない場合に有効です。
*   `--lowvram`: 低VRAMモードを使用します。VRAMが非常に少ない場合に有効です。
*   `--autolaunch`: WebUIを起動時に自動的にブラウザで開きます。
*   `--listen`: ネットワーク経由でのアクセスを許可します。

#### 実践的なテクニック

*   **オリジナルのテーマの作成:** 自分でCSSを記述して、オリジナルのテーマを作成できます。
*   **便利なスクリプトの作成:** Pythonの知識を活用して、自分にとって便利なスクリプトを作成できます。
*   **起動オプションの組み合わせ:** 起動オプションを組み合わせることで、WebUIの動作を最適化できます。

#### 応用例とユースケース

*   **テーマ変更による作業効率の向上:** 自分の好みに合ったテーマを使用することで、作業効率を向上させることができます。
*   **スクリプトによる作業の自動化:** スクリプトを使用することで、繰り返し行う作業を自動化できます。
*   **起動オプションによるパフォーマンスの最適化:** 起動オプションを調整することで、WebUIのパフォーマンスを最適化できます。

#### トラブルシューティング

*   **テーマが適用されない:** テーマファイルが正しい場所に配置されているか、設定画面で正しいテーマが選択されているかを確認してください。また、ブラウザのキャッシュをクリアしてみてください。
*   **スクリプトが動作しない:** スクリプトにエラーがないか、正しい場所に配置されているかを確認してください。WebUIのコンソールにエラーメッセージが表示されている場合があります。
*   **起動オプションが有効にならない:** 起動オプションの記述が正しいかを確認してください。
