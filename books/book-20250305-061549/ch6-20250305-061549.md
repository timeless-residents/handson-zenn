## 第6章: イメージtoイメージ：既存の画像を加工・編集する

イメージtoイメージ（img2img）は、既存の画像をベースにして、AIの力で新たな画像を生成する技術です。単なる画像編集ツールとは異なり、プロンプト（指示文）に基づいて、画像のスタイル、構図、細部を大きく変化させることができます。この章では、img2imgの基本から応用までを、実践的なテクニックと具体的なユースケースを交えながら解説します。

### 6.1 img2imgの基本：strengthパラメータとノイズの調整

#### 6.1.1 概要と重要性

img2imgは、例えば「写真を油絵風に変換する」「風景写真をファンタジー風にする」「人物の服装を変える」といった、クリエイティブな表現を可能にします。この技術の核心は、元の画像が持つ情報をどれだけ保持し、どれだけAIに解釈を委ねるかをコントロールすることです。その鍵となるのが、`strength`パラメータとノイズの調整です。

#### 6.1.2 特徴と利点

*   **創造性の拡張:** 写真やイラストを、プロンプトと組み合わせることで、想像力を形にできます。
*   **効率的な画像生成:** ゼロから画像を生成するよりも、既存の画像を基にすることで、より短時間で目的の画像を得られます。
*   **多様な表現:** `strength`パラメータやノイズの調整によって、元の画像からの変化度合いを細かく制御できます。
*   **既存アセットの再利用:** 過去に作成した画像を再利用し、新しいコンテンツを生み出せます。

#### 6.1.3 事前準備と前提条件

*   **Stable Diffusion環境:** Stable Diffusion web UI (AUTOMATIC1111版など) がインストールされ、正常に動作していること。
*   **基本的なプロンプトの知識:** Stable Diffusionで画像を生成するためのプロンプトの書き方を理解していること。
*   **VRAM:** 使用するモデルや設定によっては、多くのVRAMを消費する可能性があります。推奨されるVRAM容量は、8GB以上です。
*   **画像編集ソフト:** 必要に応じて、画像のリサイズやクロップを行うために、GIMPやPhotoshopなどの画像編集ソフトがあると便利です。

#### 6.1.4 基本的な使い方

Stable Diffusion web UI で img2img タブを選択し、以下の手順で操作します。

1.  **画像のアップロード:** 加工したい画像をアップロードします。
2.  **プロンプトの入力:** 生成したい画像のイメージを記述します。
3.  **Negative promptの入力 (推奨):** 生成したくない要素を記述します。例えば、「blurry, artifacts」など。
4.  **`Denoising strength` (strengthパラメータ):** このパラメータがimg2imgの肝です。0に近いほど元の画像が保持され、1に近いほどAIが自由に画像を生成します。
5.  **その他のパラメータ:** `Sampling method` (Euler a, DPM++ 2M Karrasなど)、`Sampling steps`、`CFG Scale` などを調整します。これらのパラメータは、画像の品質やスタイルに影響します。
6.  **Generate:** 生成ボタンをクリックし、画像を生成します。

**例:**

*   **元の画像:** 風景写真
*   **プロンプト:** "a majestic mountain range, covered in snow, hyperrealistic painting, vibrant colors"
*   **`Denoising strength`:** 0.7

この設定で生成すると、風景写真が雪に覆われた山脈の絵画風の画像に変換されます。`Denoising strength`を0.3にすると、元の写真の要素がより強く残り、0.9にすると、より絵画的な表現になります。

#### 6.1.5 実践的なテクニック

*   **`strength`パラメータの調整:**

    *   **値を小さくする (0.3-0.5):** 元の画像の構造や構図を維持しつつ、テクスチャや色味を変化させたい場合に有効です。例えば、人物写真の服装だけを変えたい場合などに適しています。
    *   **値を大きくする (0.7-0.9):** 元の画像を大幅に変化させ、新しいイメージを生成したい場合に有効です。例えば、風景写真を全く異なるスタイルに変換する場合などに適しています。
    *   **中間的な値 (0.5-0.7):** 元の画像とAIの生成結果のバランスを取りたい場合に有効です。微調整を繰り返しながら、最適な値を見つけるのがおすすめです。

*   **ノイズの調整:**

    *   Stable Diffusion web UI には、アップロードした画像にノイズを加える機能が備わっています。このノイズは、AIが画像を生成する際のベースとなります。
    *   **ノイズの種類:** `Original` (元の画像そのまま), `Gaussian` (ガウシアンノイズ), `Uniform` (一様ノイズ) など、様々な種類のノイズを選択できます。
    *   **ノイズ量の調整:** ノイズの量を調整することで、生成される画像の細部やテクスチャに影響を与えられます。ノイズ量を増やすと、よりオリジナルから離れた画像が生成されやすくなります。

*   **リサイズモードの活用:**

    *   `Resize mode`パラメータで、画像のアップスケール時の挙動を制御できます。
    *   **`Just resize`:** 単純に画像をリサイズします。
    *   **`Crop and resize`:** 画像をクロップしてリサイズします。構図を維持したい場合に有効です。
    *   **`Resize and fill`:** 画像をリサイズし、余白を黒で埋めます。
    *   **`Just resize (latent upscale)`:** Latent空間でアップスケールします。高画質なアップスケールが可能です。

#### 6.1.6 応用例とユースケース

*   **写真のスタイル変換:** 写真を油絵風、水彩画風、アニメ風など、様々なスタイルに変換します。
*   **イラストの修正と加工:** イラストの線画を清書したり、色味を調整したり、背景を追加したりします。
*   **ゲームアセットの生成:** ゲームで使用するテクスチャや背景画像を生成します。
*   **製品デザインのプロトタイプ作成:** 製品のコンセプト画像を基に、様々なバリエーションのデザインを生成します。
*   **ポートレート写真の加工:** 服装の変更、髪型の変更、背景の変更などを行います。
*   **古い写真の修復:** 破損した古い写真を修復し、鮮明な状態に復元します。

#### 6.1.7 トラブルシューティング

*   **画像が大きく変化しすぎる:** `Denoising strength`を小さくしてみてください。プロンプトが強すぎる可能性もありますので、プロンプトを見直すのも有効です。
*   **画像がほとんど変化しない:** `Denoising strength`を大きくしてみてください。プロンプトが弱すぎる可能性もあります。
*   **意図しないアーティファクトが発生する:** Negative promptに "artifacts, blurry, deformed" などを追加してみてください。Sampling methodを変更するのも効果的な場合があります。
*   **VRAM不足:** より低い解像度で画像を生成するか、不要な拡張機能を停止してみてください。xFormersを有効にすると、VRAM消費量を削減できる場合があります。

#### 6.1.8 まとめと次のステップ

`strength`パラメータとノイズの調整は、img2imgの根幹をなす重要な要素です。これらのパラメータを理解し、使いこなすことで、思い通りの画像を生成できるようになります。次のステップでは、スケッチから画像を生成するControlNetの活用方法について解説します。

### 6.2 スケッチから画像を生成する：ControlNetの活用

#### 6.2.1 概要と重要性

ControlNetは、Stable Diffusionを高度に制御するための拡張機能です。特に、スケッチや線画といった入力画像をガイドとして、より正確に、より意図どおりの画像を生成する能力に優れています。例えば、手描きのラフスケッチから、高品質なイラストや写真を生成したり、建築図面をリアルなCG画像に変換したりできます。

#### 6.2.2 特徴と利点

*   **高度な制御:** スケッチ、線画、cannyエッジ、深度マップなど、様々な種類の入力画像をガイドとして使用できます。
*   **正確な構図の再現:** 元のスケッチの構図や形状を忠実に再現できます。
*   **創造性の拡張:** スケッチをベースに、プロンプトと組み合わせることで、多様な表現を生み出せます。
*   **特定のスタイルの維持:** 特定のアーティストのスタイルや、既存の画像のスタイルを模倣できます。

#### 6.2.3 事前準備と前提条件

*   **Stable Diffusion環境:** Stable Diffusion web UI (AUTOMATIC1111版など) がインストールされ、正常に動作していること。
*   **ControlNetのインストール:** Stable Diffusion web UI の `Extensions` タブから、ControlNetをインストールし、再起動します。
*   **ControlNetモデルのダウンロード:** ControlNetで使用するモデルをダウンロードします。代表的なモデルとして、`control_v11p_sd15_canny.pth` (cannyエッジ検出)、`control_v11p_sd15_lineart.pth` (線画抽出) などがあります。これらのモデルは、Hugging Faceなどのサイトからダウンロードできます。ダウンロードしたモデルは、`stable-diffusion-webui/extensions/sd-webui-controlnet/models` フォルダに配置します。
*   **基本的なプロンプトの知識:** Stable Diffusionで画像を生成するためのプロンプトの書き方を理解していること。
*   **VRAM:** ControlNetは、通常のStable Diffusionよりも多くのVRAMを消費する可能性があります。推奨されるVRAM容量は、12GB以上です。

#### 6.2.4 基本的な使い方

Stable Diffusion web UI で img2img タブを選択し、ControlNetセクションを表示します。

1.  **ControlNetの有効化:** `Enable` チェックボックスをオンにします。
2.  **入力画像のアップロード:** スケッチや線画などの入力画像をアップロードします。
3.  **Preprocessorの選択:** 入力画像の種類に応じて、適切なPreprocessorを選択します。例えば、スケッチの場合は `scribble_xdog`、線画の場合は `lineart_coarse` を選択します。
4.  **Modelの選択:** 使用するControlNetモデルを選択します。例えば、cannyエッジ検出の場合は `control_v11p_sd15_canny.pth`、線画抽出の場合は `control_v11p_sd15_lineart.pth` を選択します。
5.  **プロンプトの入力:** 生成したい画像のイメージを記述します。
6.  **Negative promptの入力 (推奨):** 生成したくない要素を記述します。
7.  **その他のパラメータ:** `Sampling method`、`Sampling steps`、`CFG Scale` などを調整します。
8.  **Generate:** 生成ボタンをクリックし、画像を生成します。

**例:**

*   **入力画像:** 手描きの椅子のスケッチ
*   **Preprocessor:** `scribble_xdog`
*   **Model:** `control_v11p_sd15_scribble.pth` (もしくは近いモデル)
*   **プロンプト:** "a modern chair, minimalist design, high quality render, photorealistic"

この設定で生成すると、手描きの椅子のスケッチを基に、モダンなデザインの椅子の高品質なCG画像が生成されます。

#### 6.2.5 実践的なテクニック

*   **PreprocessorとModelの組み合わせ:**

    *   Preprocessorは、入力画像をControlNetが理解できる形式に変換します。Modelは、変換された画像を基に、画像を生成します。
    *   PreprocessorとModelの組み合わせは、画像の種類と生成したい結果によって異なります。例えば、cannyエッジ検出を使用する場合は、`canny` Preprocessorと`control_v11p_sd15_canny.pth` Modelを組み合わせます。
    *   様々な組み合わせを試すことで、最適な設定を見つけることができます。

*   **Control Weightの調整:**

    *   `Control Weight`パラメータは、ControlNetの影響度を調整します。値を大きくすると、ControlNetの影響が強くなり、元のスケッチに忠実な画像が生成されます。値を小さくすると、ControlNetの影響が弱くなり、プロンプトに基づいた自由な画像が生成されます。

*   **Guidance Start/Endの調整:**

    *   `Guidance Start` と `Guidance End` パラメータは、ControlNetが適用されるステップの範囲を指定します。
    *   `Guidance Start` を0に設定し、`Guidance End` を1に設定すると、最初から最後までControlNetが適用されます。
    *   `Guidance Start` を0.2に設定し、`Guidance End` を0.8に設定すると、最初の20%と最後の20%のステップではControlNetが適用されず、中間60%のステップでのみ適用されます。
    *   これらのパラメータを調整することで、生成される画像の細部をコントロールできます。

*   **複数のControlNetの活用:**

    *   ControlNetは、複数のControlNetを同時に使用できます。例えば、cannyエッジ検出とdepthマップを同時に使用することで、より複雑な画像を生成できます。

#### 6.2.6 応用例とユースケース

*   **建築デザイン:** 手書きの建築スケッチやCAD図面から、リアルな建築CG画像を生成します。
*   **キャラクターデザイン:** ラフスケッチから、詳細なキャラクターイラストを生成します。
*   **風景デザイン:** 簡単な地形のスケッチから、壮大な風景画像を生成します。
*   **製品デザイン:** 製品のアイデアスケッチから、製品のプロトタイプ画像を生成します。
*   **コミック制作:** コマ割りと簡単な背景のスケッチから、完成度の高いコミックページを生成します。

#### 6.2.7 トラブルシューティング

*   **ControlNetが有効にならない:** ControlNet拡張機能が正しくインストールされているか確認してください。Stable Diffusion web UI を再起動すると、問題が解決する場合があります。
*   **画像がスケッチと似ても似つかない:** PreprocessorとModelの組み合わせが間違っている可能性があります。適切な組み合わせを選択してください。Control Weightを大きくするのも有効です。
*   **画像が崩れてしまう:** VRAMが不足している可能性があります。より低い解像度で画像を生成するか、不要な拡張機能を停止してみてください。
*   **線が太すぎる/細すぎる:** Preprocessorの設定を調整してみてください。例えば、cannyエッジ検出の場合は、thresholdの値を調整することで、線の太さを調整できます。

#### 6.2.8 まとめと次のステップ

ControlNetは、Stable Diffusionの表現力を飛躍的に向上させる強力なツールです。スケッチや線画をガイドとして使用することで、より正確に、より意図どおりの画像を生成できます。次のステップでは、ポーズ制御による画像生成について解説します。

### 6.3 ポーズ制御：OpenPoseの活用

#### 6.3.1 概要と重要性

OpenPoseは、画像や動画から人間の姿勢を推定するためのライブラリです。この技術をStable Diffusionと組み合わせることで、生成される画像の人物のポーズを細かく制御できます。例えば、「特定のポーズをとった人物のイラストを生成する」「写真の人物のポーズを別の人物に適用する」といったことが可能になります。

#### 6.3.2 特徴と利点

*   **正確なポーズ制御:** 人物のポーズを正確に指定し、画像を生成できます。
*   **多様なポーズの表現:** 立っている、座っている、走っているなど、様々なポーズを表現できます。
*   **アニメーション制作への応用:** ポーズを連続的に変化させることで、簡単なアニメーションを生成できます。
*   **写真の合成:** 複数の写真の人物のポーズを組み合わせ、新しい画像を生成できます。

#### 6.3.3 事前準備と前提条件

*   **Stable Diffusion環境:** Stable Diffusion web UI (AUTOMATIC1111版など) がインストールされ、正常に動作していること。
*   **ControlNetのインストール:** ControlNetがインストールされていること。（前述のセクション参照）
*   **ControlNetモデルのダウンロード:** ControlNetで使用するOpenPoseモデルをダウンロードします。代表的なモデルとして、`control_v11p_sd15_openpose.pth` があります。
*   **OpenPoseの知識 (必須ではないが推奨):** OpenPoseライブラリ自体についての深い知識は必須ではありませんが、OpenPoseがどのような情報を提供しているかを知っておくと、より効果的に活用できます。
*   **VRAM:** OpenPoseモデルは、ある程度のVRAMを消費します。推奨されるVRAM容量は、8GB以上です。

#### 6.3.4 基本的な使い方

Stable Diffusion web UI で img2img タブを選択し、ControlNetセクションを表示します。

1.  **ControlNetの有効化:** `Enable` チェックボックスをオンにします。
2.  **入力画像のアップロード:** ポーズを抽出したい画像、もしくは白い背景にポーズを描いた画像（棒人間のようなものでもOK）をアップロードします。
3.  **Preprocessorの選択:** `openpose` もしくは `openpose_full` を選択します。`openpose` は顔の情報を除いたポーズを抽出し、`openpose_full` は顔の情報も含めて抽出します。
4.  **Modelの選択:** `control_v11p_sd15_openpose.pth` を選択します。
5.  **プロンプトの入力:** 生成したい画像のイメージを記述します。人物の服装、髪型、背景などを指定します。
6.  **Negative promptの入力 (推奨):** 生成したくない要素を記述します。
7.  **その他のパラメータ:** `Sampling method`、`Sampling steps`、`CFG Scale` などを調整します。
8.  **Generate:** 生成ボタンをクリックし、画像を生成します。

**例:**

*   **入力画像:** 腕を上げた人物のシルエット画像
*   **Preprocessor:** `openpose`
*   **Model:** `control_v11p_sd15_openpose.pth`
*   **プロンプト:** "a woman wearing a red dress, standing in a park, smiling, photorealistic"

この設定で生成すると、腕を上げたポーズの女性が、赤いドレスを着て公園に立っている写真のような画像が生成されます。

#### 6.3.5 実践的なテクニック

*   **Preprocessorの選択:**

    *   `openpose`: 顔の情報を除いたポーズを抽出します。顔の表情や年齢をプロンプトで制御したい場合に有効です。
    *   `openpose_full`: 顔の情報も含めて抽出します。入力画像の顔の特徴をある程度維持したい場合に有効です。
    *   `openpose_faceonly`: 顔のポーズのみを抽出します。

*   **Control Weightの調整:**

    *   Control Weightを大きくすると、ポーズがより正確に再現されますが、プロンプトの自由度が低下する可能性があります。
    *   Control Weightを小さくすると、プロンプトの自由度が高まりますが、ポーズの正確性が低下する可能性があります。

*   **プロンプトの工夫:**

    *   プロンプトに「standing, sitting, running」などのポーズに関するキーワードを含めると、より意図したポーズの画像を生成しやすくなります。
    *   プロンプトに「looking at the camera, looking away」などの視線に関するキーワードを含めると、視線を制御できます。

*   **異なる画像のポーズの転用:**

    *   まず、ポーズを転用したい人物の画像をControlNetに入力し、OpenPoseでポーズを抽出します。
    *   次に、生成したい画像のプロンプトを入力します。
    *   このとき、プロンプトに「same pose as the input image」などのキーワードを含めると、より元の画像のポーズに近い画像を生成できます。

#### 6.3.6 応用例とユースケース

*   **キャラクターポーズの作成:** オリジナルキャラクターに様々なポーズをとらせたイラストを生成します。
*   **ダンス練習の支援:** 自分のダンス動画をOpenPoseで解析し、理想的なフォームとの比較を行います。
*   **広告デザイン:** 製品を持つポーズ、アピールするポーズなど、広告に適したポーズの人物画像を生成します。
*   **教育コンテンツの作成:** 教材で使用する人物のイラストを、OpenPoseでポーズを制御しながら生成します。
*   **バーチャルYouTuber (VTuber) のモーションキャプチャ:** OpenPoseを使ってリアルタイムにVTuberのモーションを制御します。(別途、OpenPoseの出力を受け取るソフトウェアが必要です。)

#### 6.3.7 トラブルシューティング

*   **ポーズが正確に再現されない:** Control Weightを大きくしてみてください。Preprocessorの選択が間違っている可能性もあります。
*   **人物の体が崩れてしまう:** VRAMが不足している可能性があります。より低い解像度で画像を生成するか、不要な拡張機能を停止してみてください。
*   **手足が不自然な形になる:** プロンプトに「anatomically correct」などのキーワードを追加してみてください。
*   **顔が認識されない:** `openpose_full` を試してください。それでも認識されない場合は、顔が隠れていたり、小さすぎる可能性があります。

#### 6.3.8 まとめと次のステップ

OpenPoseを活用することで、Stable Diffusionによる画像生成において、人物のポーズを精密にコントロールできるようになります。これにより、より意図した構図の画像を生成したり、アニメーション制作に応用したりすることが可能になります。次のステップでは、これまで学んだ技術を組み合わせて、より複雑な表現に挑戦してみましょう。

**最後に：**

この章で解説したimg2imgのテクニックは、AI画像生成の可能性を大きく広げるものです。`strength`パラメータの調整、ControlNetの活用、OpenPoseによるポーズ制御など、様々な方法を組み合わせることで、あなたの創造性を最大限に表現できるでしょう。ぜひ、色々な設定を試して、独自の表現方法を見つけてください。AI画像生成の世界は奥深く、常に新しい技術が登場しています。最新の情報をキャッチアップしながら、AIとの協働を楽しんでいきましょう。
