## 第9章: LoRA (Low-Rank Adaptation)：軽量な追加学習

### 9.1 LoRAの基本：少ないリソースでモデルをカスタマイズ

#### 概要と重要性

近年、大規模言語モデル（LLM）の性能は目覚ましい進化を遂げていますが、その学習には膨大な計算リソースとデータが必要となります。LoRA (Low-Rank Adaptation) は、大規模モデル全体を再学習することなく、特定のタスクやデータセットに適応させるための効率的な手法です。LoRAを使うことで、限られたリソースでもLLMの能力を最大限に引き出し、様々な課題に対応できるようになります。

#### 特徴と利点

LoRAの最大の特徴は、学習対象となるパラメータ数を大幅に削減できる点です。具体的には、既存のモデルの重みを固定したまま、低ランクの行列ペアを学習することで、アダプター層として機能させます。これにより、以下のような利点が得られます。

*   **省リソース**: モデル全体を再学習するよりも、はるかに少ない計算リソースとストレージで学習が可能。GPUメモリの制約がある環境でもLLMのカスタマイズが可能になります。
*   **高速な学習**: 学習対象パラメータが少ないため、学習時間が大幅に短縮されます。
*   **容易な切り替え**: 複数のLoRAモデルを容易に切り替えることができ、様々なタスクに対応できます。アダプター層を切り替えるだけで、元のモデルを複数の用途に使い分けることができます。
*   **元のモデルへの影響を最小限に**: LoRAは元のモデルの重みを変更しないため、元のモデルの汎用性を維持できます。
*   **移植性**: 学習済みのLoRAモデルは、元のモデルに容易に適用できます。

#### 事前準備と前提条件

LoRAを利用するには、以下の準備が必要です。

1.  **Python環境**: Python 3.7以上が推奨されます。
2.  **PyTorch**: 最新版のPyTorchをインストールしてください。 `pip install torch torchvision torchaudio`
3.  **Transformers**: Hugging FaceのTransformersライブラリをインストールします。`pip install transformers accelerate`
4.  **Diffusers**: 画像生成モデルでLoRAを利用する場合はDiffusersライブラリもインストールします。`pip install diffusers`
5.  **GPU**: 学習にはGPUの使用を推奨します。

#### 基本的な使い方

LoRAの基本的な使い方は、Hugging FaceのTransformersライブラリに統合されています。以下に、テキスト生成モデルをLoRAでファインチューニングする例を示します。

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, get_linear_schedule_with_warmup
from peft import LoraConfig, get_peft_model, prepare_model_for_int8_training, TaskType
from datasets import load_dataset
import torch
from torch.optim import AdamW
from tqdm import tqdm

# モデルとトークナイザーのロード
model_name = "gpt2"  # 例: GPT-2
model = AutoModelForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token

# データセットのロード
dataset_name = "wikitext" # 例：ウィキテキスト
dataset = load_dataset(dataset_name, 'wikitext-2-raw-v1')
train_dataset = dataset['train']

# データセットの前処理
def tokenize_function(examples):
    return tokenizer(examples["text"], truncation=True, max_length=128) #適切なmax_lengthを設定

tokenized_datasets = train_dataset.map(tokenize_function, batched=True, num_proc=4, remove_columns=["text"]) #num_procは環境に合わせて調整
tokenized_datasets = tokenized_datasets.filter(lambda example: example['input_ids'] is not None and len(example['input_ids']) > 0)

# LoRA設定
lora_config = LoraConfig(
    r=8,                         # LoRAランク
    lora_alpha=32,                 # スケーリング係数
    lora_dropout=0.05,              # ドロップアウト率
    bias="none",                   # バイアス項の扱い
    task_type=TaskType.CAUSAL_LM   # タスクの種類 (因果言語モデル)
)

# LoRAモデルの作成
model = get_peft_model(model, lora_config)
model.print_trainable_parameters() # 学習対象パラメータの確認

# 学習設定
optimizer = AdamW(model.parameters(), lr=5e-4)
model.train()
device = "cuda" if torch.cuda.is_available() else "cpu"
model.to(device)

# データローダーの作成
from torch.utils.data import DataLoader
train_dataloader = DataLoader(tokenized_datasets, shuffle=True, batch_size=4) # batch_sizeは環境に合わせて調整

# 学習ループ
num_epochs = 1 #エポック数
num_training_steps = num_epochs * len(train_dataloader)
lr_scheduler = get_linear_schedule_with_warmup(
    optimizer=optimizer,
    num_warmup_steps=0,
    num_training_steps=num_training_steps
)

progress_bar = tqdm(range(num_training_steps))

for epoch in range(num_epochs):
    for batch in train_dataloader:
        batch = {k: v.to(device) for k, v in batch.items()}
        outputs = model(**batch, labels=batch["input_ids"])
        loss = outputs.loss
        loss.backward()

        optimizer.step()
        lr_scheduler.step()
        optimizer.zero_grad()
        progress_bar.update(1)

# LoRAモデルの保存
model.save_pretrained("lora-gpt2-wikitext")

```

#### 実践的なテクニック

*   **LoRAランク (r) の調整**: LoRAランクは、学習するパラメータの数を決定する重要なパラメータです。ランクを大きくすると、表現力が高まりますが、計算コストも増加します。一般的には、8〜64程度の値が用いられます。タスクの複雑さやデータセットのサイズに応じて調整してください。
*   **LoRAアルファ (lora_alpha) の調整**: lora_alphaはLoRAランクをスケーリングするパラメータです。一般的に、lora_alphaを大きくすると、LoRAの影響が強くなります。`r`の値と組み合わせて調整してください。
*   **ドロップアウト率 (lora_dropout) の調整**: ドロップアウトは、過学習を抑制するためのテクニックです。適切なドロップアウト率を設定することで、汎化性能を向上させることができます。
*   **量子化**: `prepare_model_for_int8_training`関数を利用して、モデルを8bitに量子化することで、メモリ使用量を削減し、学習を高速化できます。
*   **PEFTライブラリの活用**: PEFT (Parameter-Efficient Fine-Tuning) ライブラリは、LoRAを含む様々なパラメータ効率の良いファインチューニング手法をサポートしています。このライブラリを活用することで、LoRAの学習をより簡単に行うことができます。

#### 応用例とユースケース

*   **テキスト生成**: 特定のスタイルやトーンでテキストを生成するように、LLMをカスタマイズできます。例えば、特定の作家の文体を模倣したり、特定のジャンルの記事を生成したりできます。
*   **質問応答**: 特定の知識ベースに基づいて質問に答えるように、LLMをカスタマイズできます。例えば、特定の製品に関する質問に答えたり、特定の法律に関する質問に答えたりできます。
*   **画像生成**: Stable Diffusionなどの画像生成モデルをLoRAでファインチューニングすることで、特定のスタイルやオブジェクトを生成するようにカスタマイズできます。例えば、特定のアーティストのスタイルで画像を生成したり、特定のキャラクターの画像を生成したりできます。
*   **翻訳**: 特定の分野に特化した翻訳モデルを構築できます。例えば、医療分野の論文を翻訳したり、法律分野の契約書を翻訳したりできます。
*   **コード生成**: 特定のプログラミング言語やフレームワークに特化したコード生成モデルを構築できます。例えば、Pythonの特定のライブラリを使用するコードを生成したり、Webアプリケーションのフロントエンドコードを生成したりできます。

#### トラブルシューティング

*   **メモリ不足**: GPUメモリが不足する場合は、バッチサイズを小さくしたり、量子化を利用したり、LoRAランクを小さくしたりすることを検討してください。
*   **学習が収束しない**: 学習率を調整したり、ウォームアップステップを追加したり、LoRAランクを調整したりすることを検討してください。
*   **過学習**: ドロップアウト率を上げたり、正則化項を追加したり、データ拡張を利用したりすることを検討してください。
*   **Transformersのバージョン**: PEFTライブラリのバージョンとTransformersライブラリのバージョンが互換性があるか確認してください。

### 9.2 LoRAの学習：データセットの準備、学習設定、パラメータ調整

#### 概要と重要性

LoRAの学習プロセスは、その効果を最大限に引き出す上で非常に重要です。適切なデータセットの準備、学習設定、パラメータ調整を行うことで、モデルの性能を向上させることができます。このセクションでは、LoRAの学習における重要な要素について詳しく解説します。

#### 特徴と利点

LoRAの学習プロセスを理解し、適切に設定することで、以下のような利点が得られます。

*   **高い精度**: 特定のタスクやデータセットに最適化されたLoRAモデルを構築できます。
*   **効率的な学習**: 適切なパラメータ設定により、学習時間を短縮できます。
*   **汎化性能の向上**: 過学習を抑制し、未知のデータに対する汎化性能を高めることができます。
*   **再現性の確保**: 実験結果を再現し、改善するための基盤を構築できます。

#### 事前準備と前提条件

*   **データセット**: 学習に使用するデータセットを用意します。データセットの形式は、タスクの種類によって異なります。テキスト生成タスクであれば、テキストデータのリスト、画像生成タスクであれば、画像のリストが必要になります。
*   **前処理スクリプト**: データセットをモデルに入力できる形式に変換するための前処理スクリプトを作成します。例えば、テキストデータをトークン化したり、画像をリサイズしたりする処理が必要です。
*   **評価指標**: モデルの性能を評価するための指標を定義します。例えば、テキスト生成タスクであれば、Perplexity、BLEUスコア、ROUGEスコアなどが用いられます。画像生成タスクであれば、FIDスコア、Inceptionスコアなどが用いられます。

#### 基本的な使い方

LoRAの学習は、通常、以下の手順で行われます。

1.  **データセットの準備**: 適切なデータセットを収集し、前処理を行います。
2.  **LoRAの設定**: LoRAランク、アルファ、ドロップアウト率などのパラメータを設定します。
3.  **学習ループ**: モデルにデータセットを入力し、損失関数を計算し、パラメータを更新します。
4.  **評価**: モデルの性能を評価指標に基づいて評価します。
5.  **パラメータ調整**: モデルの性能を向上させるために、LoRAのパラメータや学習設定を調整します。

#### 実践的なテクニック

*   **データセットの選定**: 学習に使用するデータセットは、モデルの性能に大きな影響を与えます。タスクの種類や目的に合ったデータセットを選定することが重要です。
*   **データ拡張**: データセットのサイズが小さい場合は、データ拡張を行うことで、モデルの汎化性能を向上させることができます。例えば、テキストデータをランダムに削除したり、画像を回転させたりする処理が有効です。
*   **ハイパーパラメータの最適化**: LoRAのパラメータや学習率、バッチサイズなどのハイパーパラメータを最適化することで、モデルの性能を向上させることができます。
*   **早期打ち切り**: 検証データセットの性能が向上しなくなった時点で学習を打ち切ることで、過学習を抑制することができます。
*   **学習率のスケジューリング**: 学習率を徐々に減少させることで、学習の安定性を向上させることができます。
*   **Weight & Biases**: Weight & Biasesのような実験管理ツールを使用すると、ハイパーパラメータの調整や実験結果の追跡が容易になります。

#### 応用例とユースケース

*   **特定ドメインの専門知識の注入**: 医療、法律、金融などの特定のドメインに特化したデータセットを使用してLoRAを学習させることで、その分野の専門知識をモデルに注入することができます。
*   **多様なタスクへの適応**: 複数のLoRAモデルを学習させることで、一つのLLMを様々なタスクに適応させることができます。
*   **パーソナライズされたモデルの構築**: ユーザーの行動履歴や好みに基づいてLoRAを学習させることで、パーソナライズされたモデルを構築することができます。

#### トラブルシューティング

*   **データセットの問題**: データセットに誤りや偏りがある場合は、モデルの性能が低下する可能性があります。データセットを注意深く確認し、必要に応じて修正してください。
*   **過学習**: 学習データに過剰に適合してしまうと、未知のデータに対する性能が低下する可能性があります。ドロップアウト率を上げたり、正則化項を追加したり、データ拡張を利用したりすることで、過学習を抑制することができます。
*   **勾配消失**: 勾配が消失してしまうと、学習が進まなくなる可能性があります。学習率を調整したり、活性化関数を変更したり、バッチ正規化を導入したりすることで、勾配消失を回避することができます。
*   **学習の不安定性**: 学習が不安定な場合は、学習率を小さくしたり、ウォームアップステップを追加したり、勾配クリッピングを導入したりすることで、学習の安定性を向上させることができます。

### 9.3 学習済みLoRAの利用：既存モデルへの適用とブレンド

#### 概要と重要性

学習済みのLoRAモデルを既存のモデルに適用したり、複数のLoRAモデルをブレンドしたりすることで、さらに柔軟なモデルのカスタマイズが可能になります。このセクションでは、学習済みLoRAモデルの利用方法について詳しく解説します。

#### 特徴と利点

学習済みLoRAモデルを利用することで、以下のような利点が得られます。

*   **迅速なカスタマイズ**: 新しいタスクやデータセットに対して、迅速にモデルを適応させることができます。
*   **知識の転移**: 既存のLoRAモデルから知識を転移させることで、学習に必要なデータ量を削減できます。
*   **多様な表現**: 複数のLoRAモデルをブレンドすることで、多様な表現を生成することができます。
*   **アンサンブル学習**: 複数のLoRAモデルを組み合わせることで、モデルのロバスト性を向上させることができます。

#### 事前準備と前提条件

*   **学習済みLoRAモデル**: 適用またはブレンドするLoRAモデルを用意します。
*   **元のモデル**: LoRAモデルを適用する元のモデルを用意します。
*   **Transformersライブラリ**: Transformersライブラリがインストールされていることを確認します。

#### 基本的な使い方

学習済みLoRAモデルの適用は、以下の手順で行います。

1.  **モデルとLoRAのロード**: 元のモデルと学習済みLoRAモデルをロードします。
2.  **LoRAの適用**: LoRAモデルを元のモデルに適用します。

```python
from peft import PeftModel

# モデルとLoRAのロード
model_name = "gpt2"
model = AutoModelForCausalLM.from_pretrained(model_name)
lora_model_path = "lora-gpt2-wikitext"
model = PeftModel.from_pretrained(model, lora_model_path)

# 推論の実行
tokenizer = AutoTokenizer.from_pretrained(model_name)
prompt = "The capital of France is"
inputs = tokenizer(prompt, return_tensors="pt").to("cuda")
outputs = model.generate(**inputs, max_length=50)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

複数のLoRAモデルをブレンドする場合は、それぞれのLoRAモデルの重みを調整することで、様々な表現を生成することができます。PEFTライブラリには`add_weighted_adapter`という便利なメソッドが用意されています。

```python
from peft import PeftModel

# モデルのロード
model_name = "bigscience/bloom-560m"
model = AutoModelForCausalLM.from_pretrained(model_name)

# 複数のLoRAアダプターのロード
lora_adapter_1 = "adapter_1"
lora_adapter_2 = "adapter_2"
model = PeftModel.from_pretrained(model, lora_adapter_1, adapter_name="adapter1")
model.load_adapter(lora_adapter_2, adapter_name="adapter2")

# アダプターのブレンド
model.add_weighted_adapter(["adapter1", "adapter2"], weights=[0.5, 0.5], adapter_name="blended")
model.set_adapter("blended")

# 推論
tokenizer = AutoTokenizer.from_pretrained(model_name)
prompt = "The capital of France is"
inputs = tokenizer(prompt, return_tensors="pt").to("cuda")
outputs = model.generate(**inputs, max_length=50)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

#### 実践的なテクニック

*   **LoRAの重みの調整**: 複数のLoRAモデルをブレンドする際に、それぞれのLoRAモデルの重みを調整することで、生成されるテキストのスタイルやトーンを制御することができます。
*   **LoRAのアンサンブル**: 複数のLoRAモデルをアンサンブルすることで、モデルのロバスト性を向上させることができます。例えば、複数のLoRAモデルの出力を平均したり、多数決で決定したりする方法があります。
*   **LoRAの階層化**: LoRAモデルを階層的に適用することで、より複雑なカスタマイズを行うことができます。例えば、まず大まかなスタイルをLoRAで調整し、その後、より細かい表現を別のLoRAで調整することができます。
*   **LoRAの蒸留**: 知識蒸留を利用して、複数のLoRAモデルの知識を一つのLoRAモデルに集約することができます。

#### 応用例とユースケース

*   **スタイル変換**: 特定の作家のスタイルを模倣したLoRAモデルと、別の作家のスタイルを模倣したLoRAモデルをブレンドすることで、二つのスタイルの融合したテキストを生成することができます。
*   **タスクの組み合わせ**: 質問応答タスクに特化したLoRAモデルと、テキスト要約タスクに特化したLoRAモデルをブレンドすることで、質問応答とテキスト要約の両方を行うことができるモデルを構築することができます。
*   **多様な表現の生成**: 複数の異なるデータセットで学習されたLoRAモデルをブレンドすることで、多様な表現を生成することができます。

#### トラブルシューティング

*   **メモリ不足**: 複数のLoRAモデルをロードすると、メモリが不足する可能性があります。その場合は、モデルを量子化したり、バッチサイズを小さくしたりすることを検討してください。
*   **性能の低下**: LoRAモデルを適用またはブレンドした際に、性能が低下する場合があります。その場合は、LoRAの重みを調整したり、学習率を調整したりすることを検討してください。
*   **互換性の問題**: LoRAモデルのバージョンと、元のモデルのバージョンが互換性がない場合があります。その場合は、それぞれのバージョンを一致させるか、互換性のあるバージョンを使用するようにしてください。
