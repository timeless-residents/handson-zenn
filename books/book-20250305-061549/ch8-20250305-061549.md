## 第8章: モデルのカスタマイズ：DreamBoothとTextual Inversion

Stable Diffusionのような画像生成AIモデルは、既に膨大なデータセットで学習されているため、多様な画像を生成することができます。しかし、特定のキャラクター、オブジェクト、スタイルなどを忠実に再現したい場合、既存のモデルでは限界があります。そこで、DreamBoothとTextual Inversionという、モデルをカスタマイズするための強力な手法が登場しました。この章では、これらの手法の基礎から応用までを丁寧に解説し、あなた自身の創造性を最大限に引き出すための知識とスキルを提供します。

### 8.1 DreamBooth：独自のキャラクターやオブジェクトを学習させる

#### 8.1.1 概要と重要性

DreamBoothは、Google Researchによって開発された、わずかな数の画像（通常3〜5枚程度）を使って、特定のキャラクターやオブジェクトを画像生成AIモデルに学習させるための手法です。これにより、例えばあなた自身のペットや、オリジナルキャラクターを様々なシチュエーションで生成できるようになります。既存のモデルに新しい概念を効率的に導入できるため、クリエイティブな表現の幅を大きく広げることができます。

#### 8.1.2 特徴と利点

*   **少ない画像で学習可能:** 数枚の画像で十分な学習効果を得られるため、データ収集のコストを大幅に削減できます。
*   **高い再現性:** 学習させたキャラクターやオブジェクトを、様々なスタイルやシチュエーションで忠実に再現できます。
*   **カスタマイズ性:** 学習プロセスを調整することで、生成される画像の多様性をコントロールできます。
*   **手軽な導入:** 比較的小規模な計算資源でも学習が可能です。

#### 8.1.3 事前準備と前提条件

*   **環境構築:** DreamBoothを使用するには、Stable Diffusionが動作する環境が必要です。Compute環境としてはGoogle ColaboratoryやクラウドGPUインスタンスなどが利用できます。
*   **Pythonと必要なライブラリ:** Python 3.7以上、PyTorch, Diffusers, Transformers, Accelerateなど、必要なライブラリをインストールする必要があります。
*   **学習データ:** 学習させたいキャラクターやオブジェクトの画像を用意します。画像はクリアで、対象がはっきりと写っている必要があります。
*   **インスタンスプロンプト:** 学習させる対象を識別するための固有のプロンプト（例: `sks dog`）を定義します。`sks`のような、既存の単語と被らないユニークなトークンを選びましょう。

#### 8.1.4 基本的な使い方

DreamBoothの基本的な学習手順は以下の通りです。

1.  **リポジトリのクローン:** DreamBoothの実装が含まれるリポジトリ（多くの場合、Diffusersのexamples/dreambooth）をクローンします。

    ```bash
    git clone https://github.com/huggingface/diffusers
    cd diffusers/examples/dreambooth
    ```

2.  **環境構築:** 必要なライブラリをインストールします。

    ```bash
    pip install -r requirements.txt
    pip install "accelerate >= 0.16.0" transformers ftfy bitsandbytes
    ```

3.  **学習データの準備:** 学習データを特定のディレクトリに配置します。

    ```bash
    mkdir data
    # dataディレクトリに画像を配置
    ```

4.  **学習スクリプトの実行:** `train_dreambooth.py`スクリプトを実行します。

    ```bash
    accelerate launch train_dreambooth.py \
    --pretrained_model_name_or_path="runwayml/stable-diffusion-v1-5" \
    --instance_data_dir="data" \
    --instance_prompt="sks dog" \
    --resolution=512 \
    --train_batch_size=1 \
    --gradient_accumulation_steps=1 \
    --max_train_steps=800 \
    --learning_rate=5e-6 \
    --scale_lr \
    --lr_scheduler="constant" \
    --lr_warmup_steps=0 \
    --output_dir="dreambooth-dog"
    ```

    各パラメータの意味は以下の通りです。

    *   `pretrained_model_name_or_path`: 事前学習済みモデルのパスまたは名前。
    *   `instance_data_dir`: 学習データのディレクトリ。
    *   `instance_prompt`: 学習対象を識別するプロンプト。
    *   `resolution`: 学習に使用する画像の解像度。
    *   `train_batch_size`: バッチサイズ。
    *   `gradient_accumulation_steps`: 勾配累積ステップ数。
    *   `max_train_steps`: 学習ステップの最大数。
    *   `learning_rate`: 学習率。
    *   `output_dir`: 学習結果の保存先ディレクトリ。

5.  **推論:** 学習済みのモデルを使って画像を生成します。

    ```python
    from diffusers import StableDiffusionPipeline

    model_id = "dreambooth-dog"
    pipe = StableDiffusionPipeline.from_pretrained(model_id)
    pipe.to("cuda")

    prompt = "a photo of sks dog in a park"
    image = pipe(prompt).images[0]
    image.save("dog_in_park.png")
    ```

#### 8.1.5 実践的なテクニック

*   **プロンプトの工夫:**  学習に使用したインスタンスプロンプト（`sks dog`など）を基本としつつ、詳細な説明を加えることで、生成される画像の品質を向上させることができます。例: `a high-quality photo of sks dog wearing a hat, sitting in a cafe`
*   **正則化:** 学習時に、正則化画像（学習対象とは異なる、関連する一般的な画像）を使用することで、過学習を抑制し、汎化性能を高めることができます。`--with_prior_preservation --prior_loss_weight=0.5` などのオプションを使用します。
*   **学習率の調整:** 学習率を適切に調整することで、学習の安定性と収束速度を改善できます。一般的に、低い学習率（例: 1e-6）から始めることが推奨されます。
*   **画像の前処理:** 学習に使用する画像を、適切な解像度に変更したり、ノイズを除去したりすることで、学習効果を高めることができます。

#### 8.1.6 応用例とユースケース

*   **キャラクターデザイン:** オリジナルキャラクターを学習させ、様々なポーズや衣装で生成することで、キャラクターデザインの効率を向上させることができます。
*   **商品写真:** 特定の商品を学習させ、様々な背景や照明で生成することで、商品写真のバリエーションを増やし、マーケティングに活用できます。
*   **アバター作成:** 自分の顔写真を学習させ、様々なスタイルでアバターを生成することで、SNSやゲームで使用できます。
*   **建築デザイン:** 特定の建築様式や建物を学習させ、新しい建築デザインを生成するためのアイデア出しに活用できます。

#### 8.1.7 トラブルシューティング

*   **過学習:** 学習データが少ない場合、モデルが学習データに過剰に適合し、汎化性能が低下することがあります。正則化を使用したり、学習データを増やしたりすることで、過学習を抑制できます。
*   **学習の不安定性:** 学習率が高すぎる場合、学習が不安定になることがあります。学習率を下げたり、バッチサイズを調整したりすることで、学習を安定させることができます。
*   **生成画像の品質低下:** 学習に使用する画像の品質が低い場合、生成される画像の品質も低下します。高品質な画像を使用したり、画像の前処理を行ったりすることで、生成画像の品質を向上させることができます。
*   **メモリ不足:** 大量の画像を使用したり、高い解像度で学習したりする場合、メモリ不足が発生することがあります。バッチサイズを減らしたり、勾配累積ステップ数を増やしたり、GPUメモリを増強したりすることで、メモリ不足を解消できます。

#### 8.1.8 まとめと次のステップ

DreamBoothは、少ない画像で特定のキャラクターやオブジェクトを学習させるための強力な手法です。このセクションでは、DreamBoothの基本的な使い方から、実践的なテクニック、応用例までを解説しました。次のステップとして、実際にDreamBoothを試してみて、様々なパラメータを調整し、自分にとって最適な設定を見つけることをお勧めします。また、正則化や画像の前処理など、より高度なテクニックを学ぶことで、生成される画像の品質をさらに向上させることができます。

### 8.2 Textual Inversion：新しいスタイルやコンセプトを学習させる

#### 8.2.1 概要と重要性

Textual Inversionは、DreamBoothと同様に、Stable Diffusionなどの画像生成AIモデルをカスタマイズするための手法ですが、こちらは主に新しいスタイルやコンセプトを学習させることに特化しています。例えば、特定の画家のスタイルや、特定のテクスチャ、抽象的な概念などを学習させ、プロンプトに組み込むことで、それらの要素を反映した画像を生成することができます。DreamBoothがオブジェクトの学習に強いのに対し、Textual Inversionはスタイルの学習に強みを発揮します。

#### 8.2.2 特徴と利点

*   **スタイルの再現:** 特定の画風やテクスチャなどを忠実に再現できます。
*   **コンセプトの導入:** 抽象的な概念（例: 憂鬱、幸福）を学習させ、画像に反映させることができます。
*   **柔軟性:** プロンプトに組み込むことで、様々な画像にスタイルやコンセプトを適用できます。
*   **軽量性:** 学習によって生成されるのは、モデル全体ではなく、特定のトークンに対応する埋め込みベクトルであるため、モデルのサイズが大きくなることはありません。

#### 8.2.3 事前準備と前提条件

*   **環境構築:** DreamBoothと同様に、Stable Diffusionが動作する環境が必要です。
*   **Pythonと必要なライブラリ:** Python 3.7以上、PyTorch, Diffusers, Transformers, Accelerateなど、必要なライブラリをインストールする必要があります。
*   **学習データ:** 学習させたいスタイルやコンセプトを表現する画像を収集します。画像の枚数は、スタイルやコンセプトの複雑さによって異なりますが、一般的には数十枚程度が推奨されます。
*   **初期化トークン:** 学習に使用するトークンを定義します。DreamBoothと同様に、既存の単語と被らないユニークなトークンを選びましょう。`[new-style]` のようにブラケットで囲むのが一般的です。

#### 8.2.4 基本的な使い方

Textual Inversionの基本的な学習手順は以下の通りです。

1.  **リポジトリのクローン:** Textual Inversionの実装が含まれるリポジトリ（多くの場合、Diffusersのexamples/textual_inversion）をクローンします。

    ```bash
    git clone https://github.com/huggingface/diffusers
    cd diffusers/examples/textual_inversion
    ```

2.  **環境構築:** 必要なライブラリをインストールします。

    ```bash
    pip install -r requirements.txt
    pip install "accelerate >= 0.16.0" transformers ftfy bitsandbytes
    ```

3.  **学習データの準備:** 学習データを特定のディレクトリに配置します。

    ```bash
    mkdir data
    # dataディレクトリに画像を配置
    ```

4.  **学習スクリプトの実行:** `textual_inversion.py`スクリプトを実行します。

    ```bash
    accelerate launch textual_inversion.py \
    --pretrained_model_name_or_path="runwayml/stable-diffusion-v1-5" \
    --train_data_dir="data" \
    --learnable_property="style" \
    --placeholder_token="[new-style]" \
    --initializer_token="art style" \
    --resolution=512 \
    --train_batch_size=1 \
    --max_train_steps=3000 \
    --learning_rate=5.0e-04 \
    --scale_lr \
    --output_dir="textual_inversion-style"
    ```

    各パラメータの意味は以下の通りです。

    *   `pretrained_model_name_or_path`: 事前学習済みモデルのパスまたは名前。
    *   `train_data_dir`: 学習データのディレクトリ。
    *   `learnable_property`: 学習対象のプロパティ（例: style, object）。
    *   `placeholder_token`: 学習に使用するトークン。
    *   `initializer_token`: 初期化に使用するトークン。`placeholder_token`の初期値を決定するために使われます。
    *   `resolution`: 学習に使用する画像の解像度。
    *   `train_batch_size`: バッチサイズ。
    *   `max_train_steps`: 学習ステップの最大数。
    *   `learning_rate`: 学習率。
    *   `output_dir`: 学習結果の保存先ディレクトリ。

5.  **推論:** 学習済みのトークンを使って画像を生成します。

    ```python
    from diffusers import StableDiffusionPipeline

    model_id = "runwayml/stable-diffusion-v1-5"
    pipe = StableDiffusionPipeline.from_pretrained(model_id)
    pipe.to("cuda")

    pipe.load_textual_inversion("textual_inversion-style/learned_embeds.bin")

    prompt = "a photo of a cat in [new-style]"
    image = pipe(prompt).images[0]
    image.save("cat_new_style.png")
    ```

#### 8.2.5 実践的なテクニック

*   **初期化トークンの選択:** `initializer_token`を適切に選択することで、学習の初期段階でのトークンの意味合いを制御し、学習の安定性を高めることができます。例えば、油絵のスタイルを学習させたい場合、`initializer_token`を`oil painting`に設定すると、より自然な学習が期待できます。
*   **学習ステップ数の調整:** 学習ステップ数を適切に調整することで、学習の精度と時間を最適化できます。一般的に、複雑なスタイルやコンセプトを学習させるには、より多くのステップ数が必要です。
*   **正則化:** DreamBoothと同様に、正則化画像を使用することで、過学習を抑制し、汎化性能を高めることができます。
*   **トークンの組み合わせ:** 複数の学習済みトークンを組み合わせることで、より複雑な表現を実現できます。例えば、特定の画家のスタイルと、特定のテクスチャを組み合わせることで、ユニークな画像を生成できます。

#### 8.2.6 応用例とユースケース

*   **アート制作:** 特定の画風やアーティストのスタイルを学習させ、自分の作品に適用することで、新しい表現を探求できます。
*   **テクスチャ生成:** 様々なテクスチャ（例: 木材、金属、布）を学習させ、ゲームやCG制作に利用できます。
*   **フォント生成:** 特定の書体を学習させ、新しいフォントをデザインできます。
*   **広告デザイン:** 特定のブランドイメージやコンセプトを学習させ、広告素材を制作できます。

#### 8.2.7 トラブルシューティング

*   **学習の収束:** 学習が収束しない場合、学習率を調整したり、学習ステップ数を増やしたり、初期化トークンを変更したりすることで、改善を試みることができます。
*   **トークンの意味の喪失:** 学習が進むにつれて、トークンが本来の意味から逸脱してしまうことがあります。正則化を使用したり、学習データを調整したりすることで、トークンの意味を維持することができます。
*   **生成画像のアーティファクト:** 学習データに偏りがある場合、生成画像にアーティファクト（不自然な模様やノイズ）が発生することがあります。学習データを多様化したり、画像の前処理を行ったりすることで、アーティファクトを軽減することができます。

Textual Inversionは、新しいスタイルやコンセプトを画像生成AIモデルに学習させるための強力な手法です。このセクションでは、Textual Inversionの基本的な使い方から、実践的なテクニック、応用例までを解説しました。次のステップとして、実際にTextual Inversionを試してみて、様々なスタイルやコンセプトを学習させ、自分の創造性を最大限に引き出すことをお勧めします。また、トークンの組み合わせや、他のカスタマイズ手法との組み合わせなど、より高度なテクニックを学ぶことで、表現の幅をさらに広げることができます。
