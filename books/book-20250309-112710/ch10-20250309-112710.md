## 第10章：Eleven Labs API連携！ - 英語学習を自動化する

英語学習は継続が重要ですが、モチベーション維持が難しいこともあります。そこで、Eleven Labs APIを活用して、英語学習を自動化し、より楽しく、効率的に学習を進めていきましょう。本章では、Eleven Labs APIの基礎から、Pythonを用いた自動化スクリプトの作成まで、実践的な内容を解説します。プログラミング初心者の方でも理解しやすいように、丁寧に解説を進めていきますので、ご安心ください。

### API連携の基礎 - プログラミング知識は不要

#### 概要と重要性

API (Application Programming Interface) は、ソフトウェア同士が情報をやり取りするための「共通言語」のようなものです。Eleven Labs APIを利用することで、プログラムからEleven Labsのテキスト読み上げ機能を呼び出し、自動的に音声ファイルを生成できます。これにより、例えば、ニュース記事を自動で読み上げたり、発音練習ツールを開発したりといった、様々な英語学習の自動化が可能になります。プログラミングの知識がなくても、APIの概念を理解すれば、API連携の可能性を広げることができます。

#### 特徴と利点

*   **自動化:** 定期的なタスク（例：毎日のニュース記事の読み上げ）を自動化できます。
*   **カスタマイズ:** テキスト読み上げの速度やピッチなどを細かく調整できます。
*   **多様な音声:** Eleven Labsは、多様な音声モデルを提供しており、好みの声を選択できます。
*   **学習効果の向上:** 飽きやすい作業を自動化することで、学習のモチベーションを維持できます。

#### 事前準備と前提条件

*   **APIキーの取得:** Eleven Labsのウェブサイトでアカウントを作成し、APIキーを取得する必要があります。無料プランでも利用可能ですが、利用制限があります。
*   **APIキーの保管:** 取得したAPIキーは、安全な場所に保管してください。GitHubなどのパブリックリポジトリに誤って公開しないように注意が必要です。
*   **HTTPリクエストの理解:** APIはHTTPリクエストを通じて情報をやり取りします。基本的なHTTPリクエスト（GET, POST）の概念を理解しておくと、API連携がスムーズに進みます。
*   **JSON形式の理解:** APIは、JSON形式でデータを送受信することが一般的です。JSONの構造を理解しておくと、APIからのレスポンスを解析しやすくなります。

#### 基本的な使い方

API連携は、HTTPリクエストを送信して、APIからレスポンスを受け取るという流れで行われます。

1.  **リクエストの作成:** どのような情報をAPIに送信するかを定義します（例：読み上げたいテキスト、音声モデルの種類）。
2.  **リクエストの送信:** 作成したリクエストをAPIのエンドポイントに送信します。
3.  **レスポンスの受信:** APIから結果（例：音声データ）が返ってきます。
4.  **レスポンスの処理:** 受け取ったレスポンスを解析し、必要な情報を抽出します。

#### 実践的なテクニック

API連携を効率的に行うためには、APIドキュメントをよく読み、提供されている機能を理解することが重要です。Eleven LabsのAPIドキュメントには、利用可能なエンドポイント、リクエストのパラメータ、レスポンスの形式などが詳しく記載されています。

#### 応用例とユースケース

*   **自動単語帳作成:** 新しい単語とその意味をAPIに送信し、発音を自動生成して単語帳に追加する。
*   **ポッドキャスト作成:** ニュース記事やブログ記事をAPIに送信し、音声ファイルを作成してポッドキャストとして配信する。
*   **ゲーム開発:** ゲームキャラクターのセリフをAPIで生成し、ゲームに組み込む。
*   **アクセシビリティ向上:** ウェブサイトのテキストをAPIで読み上げ、視覚障碍者向けのコンテンツを作成する。

#### トラブルシューティング

*   **APIキーのエラー:** APIキーが正しいか確認してください。また、APIキーの有効期限が切れていないか確認してください。
*   **リクエストのエラー:** リクエストのパラメータが正しいか確認してください。APIドキュメントを参考に、必要なパラメータがすべて含まれているか確認してください。
*   **レスポンスのエラー:** APIからのレスポンスコードを確認してください。4xx番台のエラーはクライアント側のエラー、5xx番台のエラーはサーバー側のエラーを示します。

### PythonでAPI連携 - 簡単なスクリプトで自動化

#### 概要と重要性

Pythonは、API連携に非常に適したプログラミング言語です。豊富なライブラリが提供されており、HTTPリクエストの送信やJSONデータの処理を簡単に行うことができます。このセクションでは、Pythonを使ってEleven Labs APIと連携し、テキストを音声に変換する簡単なスクリプトを作成します。

#### 特徴と利点

*   **シンプルで読みやすい構文:** Pythonは、初心者でも理解しやすい構文を持っています。
*   **豊富なライブラリ:** `requests`ライブラリを使用すると、HTTPリクエストを簡単に送信できます。
*   **クロスプラットフォーム:** Pythonは、Windows、macOS、Linuxなど、様々なOSで動作します。
*   **迅速な開発:** Pythonを使うことで、効率的にAPI連携のスクリプトを開発できます。

#### 事前準備と前提条件

*   **Pythonのインストール:** Pythonがインストールされていない場合は、Pythonの公式サイトからダウンロードしてインストールしてください。
*   **pipのインストール:** pipは、Pythonのパッケージ管理システムです。Pythonのインストール時に自動的にインストールされることが多いですが、もしインストールされていない場合は、以下のコマンドでインストールできます。

    ```bash
    python -m ensurepip --default-pip
    ```

*   **requestsライブラリのインストール:** `requests`ライブラリは、HTTPリクエストを送信するために使用します。以下のコマンドでインストールできます。

    ```bash
    pip install requests
    ```

*   **APIキーの準備:** Eleven Labs APIを使用するには、APIキーが必要です。Eleven Labsのウェブサイトでアカウントを作成し、APIキーを取得してください。

#### 基本的な使い方

以下は、PythonでEleven Labs APIを使ってテキストを音声に変換する基本的なスクリプトの例です。

```python
import requests
import json

# APIキーとエンドポイントの設定
ELEVEN_LABS_API_KEY = "YOUR_API_KEY"  # 取得したAPIキーに置き換えてください
VOICE_ID = "pNfQjXQZ5nuz2u6N5dZx" # RachelのVoice ID
API_URL = f"https://api.elevenlabs.io/v1/text-to-speech/{VOICE_ID}"

# ヘッダーの設定
headers = {
    "xi-api-key": ELEVEN_LABS_API_KEY,
    "Content-Type": "application/json"
}

# リクエストボディの設定
data = {
    "text": "Hello, world! This is a test of the Eleven Labs API.",
    "model_id": "eleven_monolingual_v1", # モノリンガルモデルを指定 (英語)
    "voice_settings": {
        "stability": 0.5,
        "similarity_boost": 0.5
    }
}

# APIリクエストの送信
try:
    response = requests.post(API_URL, headers=headers, data=json.dumps(data))
    response.raise_for_status()  # エラーが発生した場合、例外を発生させる
except requests.exceptions.RequestException as e:
    print(f"APIリクエストエラー: {e}")
    exit()


# 音声ファイルの保存
try:
    with open("output.mp3", "wb") as f:
        f.write(response.content)
    print("音声ファイルが保存されました: output.mp3")
except IOError as e:
    print(f"ファイル書き込みエラー: {e}")
    exit()
```

**スクリプトの説明:**

1.  **APIキーとエンドポイントの設定:** Eleven Labs APIのエンドポイントと、取得したAPIキーを設定します。
2.  **ヘッダーの設定:** APIリクエストに必要なヘッダーを設定します。`xi-api-key`には、APIキーを設定します。
3.  **リクエストボディの設定:** 読み上げたいテキスト、モデルID、音声設定などを設定します。`text`には、読み上げたいテキストを設定します。`model_id`には、使用する音声モデルのIDを設定します。`voice_settings`には、音声の安定性や類似性のブーストを設定します。
4.  **APIリクエストの送信:** `requests.post()`関数を使って、APIリクエストを送信します。`headers`には、設定したヘッダーを渡します。`data`には、リクエストボディをJSON形式に変換して渡します。
5.  **レスポンスの確認:** `response.raise_for_status()`を呼び出すことで、HTTPステータスコードが200番台でない場合に例外を発生させ、エラーを検知できます。
6.  **音声ファイルの保存:** APIからのレスポンス（音声データ）をファイルに保存します。

#### 実践的なテクニック

*   **進捗状況の表示:** 長いテキストを読み上げる場合に、進捗状況を表示すると、ユーザーエクスペリエンスが向上します。
*   **APIレート制限の考慮:** Eleven Labs APIには、レート制限があります。レート制限を超えないように、リクエストの頻度を調整してください。

#### 応用例とユースケース

*   **翻訳と読み上げ:** テキストを翻訳APIで翻訳し、Eleven Labs APIで読み上げる。

### スクリプト例：自動教材作成 - ニュース記事を毎日自動で読み上げ

#### 概要と重要性

毎日英語のニュース記事を読み上げることは、リスニング力向上に効果的です。しかし、毎日記事を探して読み上げるのは面倒です。このセクションでは、ニュース記事を自動的に取得し、Eleven Labs APIで読み上げるスクリプトを作成します。

#### 事前準備と前提条件

*   **Beautiful Soupライブラリのインストール:** ニュース記事をスクレイピングするために、`beautifulsoup4`ライブラリをインストールします。

    ```bash
    pip install beautifulsoup4
    ```

*   **requestsライブラリのインストール (再確認):** `requests`ライブラリは、HTTPリクエストを送信するために使用します。まだインストールしていない場合は、以下のコマンドでインストールできます。

    ```bash
    pip install requests
    ```
*   **APIキーの準備 (再確認):** Eleven Labs APIを使用するには、APIキーが必要です。Eleven Labsのウェブサイトでアカウントを作成し、APIキーを取得してください。

#### スクリプト例

以下は、BBC Newsから英語のニュース記事を取得し、Eleven Labs APIで読み上げるスクリプトの例です。

```python
import requests
from bs4 import BeautifulSoup
import json
import os
from datetime import date

# APIキーの設定
ELEVEN_LABS_API_KEY = os.environ.get("ELEVEN_LABS_API_KEY")
VOICE_ID = "pNfQjXQZ5nuz2u6N5dZx"  # RachelのVoice ID
API_URL = f"https://api.elevenlabs.io/v1/text-to-speech/{VOICE_ID}"

# ニュース記事のURL
NEWS_URL = "https://www.bbc.com/news/world"

# ヘッダーの設定
headers = {
    "xi-api-key": ELEVEN_LABS_API_KEY,
    "Content-Type": "application/json"
}

def get_news_article(url):
    """ニュース記事を取得する関数"""
    try:
        response = requests.get(url)
        response.raise_for_status()
    except requests.exceptions.RequestException as e:
        print(f"記事取得エラー: {e}")
        return None

    soup = BeautifulSoup(response.content, "html.parser")
    # ニュース記事の本文を抽出 (BBC Newsの構造に合わせて調整)
    article_body = ""
    for paragraph in soup.find_all('div', class_='e44qvlp0'): # class名は適宜変更
        article_body += paragraph.text + "\n"

    return article_body

def text_to_speech(text, filename):
    """テキストを音声に変換する関数"""
    data = {
        "text": text,
        "model_id": "eleven_monolingual_v1",  # モノリンガルモデルを指定 (英語)
        "voice_settings": {
            "stability": 0.5,
            "similarity_boost": 0.5
        }
    }
    try:
        response = requests.post(API_URL, headers=headers, data=json.dumps(data))
        response.raise_for_status()
    except requests.exceptions.RequestException as e:
        print(f"APIリクエストエラー: {e}")
        return False

    try:
        with open(filename, "wb") as f:
            f.write(response.content)
        print(f"音声ファイルが保存されました: {filename}")
        return True
    except IOError as e:
        print(f"ファイル書き込みエラー: {e}")
        return False

# メインの処理
if __name__ == "__main__":
    article = get_news_article(NEWS_URL)

    if article:
        today = date.today().strftime("%Y-%m-%d")
        filename = f"news_{today}.mp3"
        text_to_speech(article, filename)
    else:
        print("ニュース記事の取得に失敗しました。")
```

**スクリプトの説明:**

1.  **必要なライブラリのインポート:** `requests`, `beautifulsoup4`, `json`, `os`, `datetime`ライブラリをインポートします。
2.  **APIキーとエンドポイントの設定:** Eleven Labs APIのエンドポイントと、APIキーを設定します。APIキーは環境変数から取得するように変更しました。
3.  **ニュース記事のURLの設定:** 取得するニュース記事のURLを設定します。
4.  **`get_news_article()`関数:** ニュース記事のURLを受け取り、`requests`ライブラリでHTTPリクエストを送信し、`beautifulsoup4`ライブラリでHTMLを解析し、ニュース記事の本文を抽出します。
5.  **`text_to_speech()`関数:** テキストとファイル名を受け取り、Eleven Labs APIでテキストを音声に変換し、音声ファイルを保存します。
6.  **メインの処理:** `get_news_article()`関数でニュース記事を取得し、`text_to_speech()`関数で音声ファイルを作成します。

#### 実践的なテクニック

*   **記事の要約:** 長い記事の場合、全文を読み上げるのではなく、要約を作成して読み上げることで、時間を短縮できます。
*   **定期的な実行:** スクリプトをcronやタスクスケジューラで定期的に実行することで、毎日自動的にニュース記事を読み上げることができます。

*   **複数のニュースソース:** 複数のニュースソースから記事を取得して読み上げる。
*   **単語帳との連携:** ニュース記事に出現した新しい単語を抽出し、単語帳に追加する。

#### トラブルシューティング

*   **Webサイトの構造変更:** Webサイトの構造が変更された場合、`beautifulsoup4`ライブラリでHTMLを解析する部分を修正する必要があります。

### スクリプト例：発音練習ツール - 自分の発音をAIが評価

#### 概要と重要性

発音練習は、英語学習において重要な要素です。しかし、自分の発音が正しいかどうかを判断するのは難しい場合があります。このセクションでは、録音した自分の発音をAIが評価するツールを作成します。Eleven LabsのAPIだけでは発音評価はできないため、このセクションでは、Google Cloud Speech-to-Text APIと組み合わせて、発音練習ツールを作成する例を紹介します。

#### 事前準備と前提条件

*   **Google Cloud Platformアカウントの作成:** Google Cloud Speech-to-Text APIを使用するには、Google Cloud Platform (GCP) のアカウントを作成する必要があります。
*   **Google Cloud Speech-to-Text APIの有効化:** GCPのコンソールで、Google Cloud Speech-to-Text APIを有効にする必要があります。
*   **認証情報の設定:** GCPの認証情報（サービスアカウントキー）を作成し、環境変数に設定する必要があります。
*   **pydubライブラリのインストール:** 音声ファイルのフォーマット変換を行うために、`pydub`ライブラリをインストールします。

    ```bash
    pip install pydub
    ```

*   **google-cloud-speechライブラリのインストール:** Google Cloud Speech-to-Text APIを使用するために、`google-cloud-speech`ライブラリをインストールします。

    ```bash
    pip install google-cloud-speech
    ```

*   **APIキーの準備 (再確認):** Eleven Labs APIを使用するには、APIキーが必要です。Eleven Labsのウェブサイトでアカウントを作成し、APIキーを取得してください。

#### スクリプト例

以下は、録音した音声ファイルをGoogle Cloud Speech-to-Text APIでテキストに変換し、Eleven Labs APIで正しい発音を生成し、比較するスクリプトの例です。

```python
import os
from google.cloud import speech_v1 as speech
from pydub import AudioSegment
import io
import json
import requests

# 環境変数の設定
GOOGLE_APPLICATION_CREDENTIALS = os.environ.get("GOOGLE_APPLICATION_CREDENTIALS")
ELEVEN_LABS_API_KEY = os.environ.get("ELEVEN_LABS_API_KEY")
VOICE_ID = "pNfQjXQZ5nuz2u6N5dZx"  # RachelのVoice ID
API_URL = f"https://api.elevenlabs.io/v1/text-to-speech/{VOICE_ID}"

def transcribe_audio(audio_file):
    """音声ファイルをテキストに変換する関数"""
    client = speech.SpeechClient()

    # 音声ファイルを読み込む
    with io.open(audio_file, "rb") as audio_file:
        content = audio_file.read()

    audio = speech.RecognitionAudio(content=content)
    config = speech.RecognitionConfig(
        encoding=speech.RecognitionConfig.AudioEncoding.MP3, # 音声ファイルのエンコーディングに合わせて変更
        sample_rate_hertz=44100, # 音声ファイルのサンプルレートに合わせて変更
        language_code="en-US",  # 言語コード
    )

    # 音声認識を実行
    response = client.recognize(config=config, audio=audio)

    # 結果を返す
    for result in response.results:
        return result.alternatives[0].transcript
    return None

def text_to_speech(text, filename):
    """テキストを音声に変換する関数"""
    headers = {
        "xi-api-key": ELEVEN_LABS_API_KEY,
        "Content-Type": "application/json"
    }
    data = {
        "text": text,
        "model_id": "eleven_monolingual_v1",  # モノリンガルモデルを指定 (英語)
        "voice_settings": {
            "stability": 0.5,
            "similarity_boost": 0.5
        }
    }
    try:
        response = requests.post(API_URL, headers=headers, data=json.dumps(data))
        response.raise_for_status()
    except requests.exceptions.RequestException as e:
        print(f"APIリクエストエラー: {e}")
        return False

    try:
```
