## 第5章：地図データの取得と表示

### GeoJSONデータの基本

#### 概要と重要性

地図データを扱う上で、GeoJSONは非常に重要な役割を果たします。GeoJSONは、地理空間データを表現するための標準的なフォーマットであり、そのシンプルさと柔軟性から、Web地図アプリケーションや地理情報システム（GIS）で広く利用されています。このセクションでは、GeoJSONの基本的な構造と、なぜこれが重要なのかを解説します。

#### 特徴と利点

GeoJSONの最大の特徴は、JSON形式に基づいていることです。JSONは、人間にとってもコンピュータにとっても読み書きしやすいデータ形式であり、様々なプログラミング言語で容易に扱えます。GeoJSONの利点は以下の通りです。

*   **可読性と簡潔性：** JSON形式なので、データの構造が理解しやすい。
*   **汎用性：** 多くの地図ライブラリやGISソフトウェアでサポートされている。
*   **拡張性：** 独自のプロパティを追加して、データを拡張できる。
*   **軽量性：** テキストベースなので、バイナリ形式に比べて容量が小さい場合が多い。

#### 事前準備と前提条件

GeoJSONを扱う上で、特に必要な事前準備はありません。基本的なJSONの知識があれば、GeoJSONの構造を理解するのは容易です。また、テキストエディタや、JSONを扱えるプログラミング言語（Python, JavaScriptなど）があれば、GeoJSONデータを実際に操作できます。

#### 基本的な使い方

GeoJSONデータは、大きく分けて以下の要素で構成されています。

*   **`type`：** GeoJSONオブジェクトのタイプ（例：`FeatureCollection`, `Feature`, `Point`, `LineString`, `Polygon`）。
*   **`geometry`：** 地理的な形状を表すオブジェクト。`type`（例：`Point`, `LineString`, `Polygon`）と`coordinates`（座標の配列）を持つ。
*   **`properties`：** 地物の属性情報を格納するオブジェクト。キーと値のペアで表現される。
*   **`features`：** `Feature`オブジェクトの配列。`FeatureCollection`オブジェクトで使用される。

以下に、いくつかのGeoJSONの例を示します。

**例1：単一のポイント**

```json
{
  "type": "Feature",
  "geometry": {
    "type": "Point",
    "coordinates": [139.7673068, 35.6815515] // [経度, 緯度]
  },
  "properties": {
    "name": "東京駅"
  }
}
```

**例2：複数のポイント（FeatureCollection）**

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [139.7673068, 35.6815515]
      },
      "properties": {
        "name": "東京駅"
      }
    },
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [139.6917064, 35.6894875]
      },
      "properties": {
        "name": "新宿駅"
      }
    }
  ]
}
```

**例3：ポリゴン**

```json
{
  "type": "Feature",
  "geometry": {
    "type": "Polygon",
    "coordinates": [
      [
        [139.691667, 35.689444],
        [139.691667, 35.691667],
        [139.694444, 35.691667],
        [139.694444, 35.689444],
        [139.691667, 35.689444]
      ]
    ]
  },
  "properties": {
    "name": "新宿御苑の一部"
  }
}
```

#### 実践的なテクニック

*   **座標系の理解：** GeoJSONでは、通常、WGS84（経度、緯度）座標系が使用されます。地図ライブラリによっては、別の座標系に変換する必要がある場合があります。
*   **データの検証：** GeoJSONデータが正しい形式であるかどうかを検証するために、JSON ValidatorやGeoJSON Validatorなどのツールを使用できます。
*   **データの整形：** GeoJSON Lintなどのツールを使用すると、GeoJSONデータを読みやすく整形できます。

#### 応用例とユースケース

*   **Web地図アプリケーション：** Leaflet, Mapbox GL JS, OpenLayersなどの地図ライブラリを使用して、GeoJSONデータを地図上に表示できます。
*   **GISソフトウェア：** QGIS, ArcGISなどのGISソフトウェアで、GeoJSONデータを読み込み、編集、分析できます。
*   **データ分析：** GeoPandas（Python）などのライブラリを使用して、GeoJSONデータを操作し、空間的な分析を行うことができます。

#### トラブルシューティング

*   **座標の順序の間違い：** GeoJSONでは、座標は[経度, 緯度]の順序で指定します。これを[緯度, 経度]と間違えると、地図上に正しい位置に表示されません。
*   **JSONの構文エラー：** JSONの構文エラーがあると、GeoJSONデータを読み込めません。JSON Validatorを使用して、構文エラーをチェックしましょう。
*   **データのサイズ：** 大きなGeoJSONデータは、Web地図アプリケーションのパフォーマンスに影響を与える可能性があります。データを簡略化したり、タイル形式に変換することを検討しましょう。

### 地図データの取得方法：API, ファイル

#### 概要と重要性

地図データを取得する方法はいくつかあります。代表的なのは、APIを利用する方法と、ファイル（GeoJSONファイルなど）を直接読み込む方法です。どちらの方法を選択するかは、データの種類、データの更新頻度、アプリケーションの要件などによって異なります。

#### 特徴と利点

**APIを利用する方法**

*   **利点：**
    *   常に最新のデータを入手できる。
    *   必要なデータのみを取得できるため、データの量を削減できる。
    *   APIプロバイダーがデータのメンテナンスを行ってくれる。
*   **注意点：**
    *   APIの利用には、APIキーが必要な場合がある。
    *   APIの利用制限（リクエスト数など）がある場合がある。
    *   APIの仕様変更に対応する必要がある。

**ファイルを読み込む方法**

*   **利点：**
    *   オフライン環境でも地図データを利用できる。
    *   APIの利用制限を気にする必要がない。
    *   独自のデータを作成して利用できる。
*   **注意点：**
    *   データの更新を手動で行う必要がある。
    *   データの量が多くなる場合がある。
    *   ファイルの形式に対応したライブラリやツールが必要となる。

#### 事前準備と前提条件

*   **APIを利用する場合：** APIプロバイダーからAPIキーを取得する必要があります。また、APIのドキュメントを読んで、APIの使い方を理解しておく必要があります。
*   **ファイルを読み込む場合：** 必要な形式の地図データファイル（GeoJSONファイルなど）を用意する必要があります。

#### 基本的な使い方

**APIを利用する場合（例：Mapbox API）**

```javascript
// Mapbox APIのアクセストークンを設定
mapboxgl.accessToken = 'YOUR_MAPBOX_ACCESS_TOKEN';

// 地図の初期化
const map = new mapboxgl.Map({
  container: 'map', // 地図を表示する要素のID
  style: 'mapbox://styles/mapbox/streets-v11', // 地図のスタイル
  center: [139.7673068, 35.6815515], // 地図の中心座標
  zoom: 12 // 地図のズームレベル
});

// APIからGeoJSONデータを取得する例
fetch('https://api.mapbox.com/datasets/v1/YOUR_MAPBOX_USERNAME/YOUR_DATASET_ID/features?access_token=' + mapboxgl.accessToken)
  .then(response => response.json())
  .then(data => {
    // 取得したGeoJSONデータを地図に追加する
    map.addSource('my-data', {
      type: 'geojson',
      data: data
    });

    map.addLayer({
      id: 'my-layer',
      type: 'circle',
      source: 'my-data',
      paint: {
        'circle-radius': 5,
        'circle-color': 'red'
      }
    });
  });
```

**ファイルを読み込む場合（例：GeoJSONファイルを読み込む）**

```javascript
// GeoJSONファイルを読み込む
fetch('data.geojson') // data.geojsonはGeoJSONファイルのパス
  .then(response => response.json())
  .then(data => {
    // 取得したGeoJSONデータを地図に追加する
    map.addSource('my-data', {
      type: 'geojson',
      data: data
    });

    map.addLayer({
      id: 'my-layer',
      type: 'circle',
      source: 'my-data',
      paint: {
        'circle-radius': 5,
        'circle-color': 'red'
      }
    });
  });
```

#### 実践的なテクニック

*   **APIのキャッシュ：** APIから取得したデータをローカルストレージにキャッシュすることで、APIへのリクエスト回数を減らし、パフォーマンスを向上させることができます。
*   **データのフィルタリング：** APIから取得したデータの中から、必要なデータのみを抽出して表示することで、データの量を削減し、パフォーマンスを向上させることができます。
*   **データのフォーマット変換：** APIから取得したデータのフォーマットが、地図ライブラリでサポートされていない場合は、データを変換する必要があります。Turf.jsなどのライブラリを使用すると、データのフォーマット変換が容易に行えます。

#### 応用例とユースケース

*   **リアルタイム交通情報：** リアルタイム交通情報APIを利用して、地図上に交通状況を表示する。
*   **店舗検索：** 店舗情報APIとGeoJSONファイルを組み合わせて、地図上に店舗を表示し、検索機能を提供する。
*   **災害情報：** 災害情報APIを利用して、地図上に避難場所や災害発生状況を表示する。
*   **人流分析：** 人流データAPIを利用して、地図上に人の流れを可視化する。

#### トラブルシューティング

*   **APIキーのエラー：** APIキーが正しく設定されていない場合、APIへのアクセスが拒否されます。APIキーが正しいことを確認しましょう。
*   **CORSエラー：** 異なるオリジンからAPIにアクセスする場合、CORSエラーが発生する可能性があります。APIサーバー側でCORSの設定を行う必要があります。
*   **データの形式エラー：** APIから取得したデータの形式が、地図ライブラリでサポートされていない場合、エラーが発生する可能性があります。データの形式を確認し、必要に応じて変換しましょう。

#### まとめと次のステップ

### レイヤーの追加とスタイリング

#### 概要と重要性

地図データを入手したら、それを地図上に表示する必要があります。地図上にデータ(例えば、GeoJSON)を表示するためには、地図ライブラリのレイヤーという概念を利用します。レイヤーは、地図上に表示されるデータの集合であり、それぞれ異なるスタイルや表示方法を持つことができます。このセクションでは、地図にレイヤーを追加し、様々な方法でスタイリングする方法を解説します。

#### 特徴と利点

*   **柔軟性：** レイヤーごとに異なるデータを表示できるため、地図上に複数の情報を重ねて表示できます。
*   **カスタマイズ性：** レイヤーごとにスタイルを設定できるため、データの種類や重要度に応じて表示方法を変更できます。
*   **パフォーマンス：** レイヤーを適切に管理することで、地図の表示パフォーマンスを最適化できます。例えば、表示範囲外のレイヤーを非表示にすることで、描画処理の負荷を軽減できます。

#### 事前準備と前提条件

*   地図ライブラリ（Leaflet, Mapbox GL JS, OpenLayersなど）の基本的な使い方を理解していること。
*   GeoJSONデータなどの地図データが用意されていること。

#### 基本的な使い方

ここでは、Mapbox GL JSを例に、レイヤーの追加とスタイリングの基本的な使い方を説明します。

**例1：シンプルなポイントの表示**

```javascript
// Mapbox GL JSの初期化（前のセクションを参照）

// GeoJSONデータ
const geojson = {
  type: 'FeatureCollection',
  features: [
    {
      type: 'Feature',
      geometry: {
        type: 'Point',
        coordinates: [139.7673068, 35.6815515]
      },
      properties: {
        name: '東京駅'
      }
    }
  ]
};

// 地図にGeoJSONデータを追加
map.on('load', () => {
  map.addSource('points', {
    type: 'geojson',
    data: geojson
  });

  map.addLayer({
    id: 'points-layer',
    type: 'circle',
    source: 'points',
    paint: {
      'circle-radius': 10,
      'circle-color': 'red'
    }
  });
});
```

この例では、`map.addSource`でGeoJSONデータを地図のソースとして登録し、`map.addLayer`でそのソースを元に円（circle）のレイヤーを追加しています。`paint`プロパティで、円の半径（`circle-radius`）と色（`circle-color`）を指定しています。

**例2：異なる種類のデータの表示（ポイント、ライン、ポリゴン）**

```javascript
// 前の例と同様に、Mapbox GL JSの初期化とGeoJSONデータの準備が必要です

// ポイントのGeoJSONデータ
const pointData = {
  type: 'FeatureCollection',
  features: [
    {
      type: 'Feature',
      geometry: {
        type: 'Point',
        coordinates: [139.7673068, 35.6815515]
      },
      properties: {
        name: '東京駅'
      }
    }
  ]
};

// ラインのGeoJSONデータ
const lineData = {
  type: 'FeatureCollection',
  features: [
    {
      type: 'Feature',
      geometry: {
        type: 'LineString',
        coordinates: [
          [139.7673068, 35.6815515],
          [139.6917064, 35.6894875]
        ]
      },
      properties: {
        name: '東京駅 -> 新宿駅'
      }
    }
  ]
};

// ポリゴンのGeoJSONデータ
const polygonData = {
  type: 'FeatureCollection',
  features: [
    {
      type: 'Feature',
      geometry: {
        type: 'Polygon',
        coordinates: [
          [
            [139.691667, 35.689444],
            [139.691667, 35.691667],
            [139.694444, 35.691667],
            [139.694444, 35.689444],
            [139.691667, 35.689444]
          ]
        ]
      },
      properties: {
        name: '新宿御苑の一部'
      }
    }
  ]
};

map.on('load', () => {
  // ポイントのレイヤー
  map.addSource('points', { type: 'geojson', data: pointData });
  map.addLayer({ id: 'points-layer', type: 'circle', source: 'points', paint: { 'circle-radius': 10, 'circle-color': 'red' } });

  // ラインのレイヤー
  map.addSource('lines', { type: 'geojson', data: lineData });
  map.addLayer({ id: 'lines-layer', type: 'line', source: 'lines', paint: { 'line-color': 'blue', 'line-width': 3 } });

  // ポリゴンのレイヤー
  map.addSource('polygons', { type: 'geojson', data: polygonData });
  map.addLayer({ id: 'polygons-layer', type: 'fill', source: 'polygons', paint: { 'fill-color': 'green', 'fill-opacity': 0.5 } });
});
```

この例では、ポイント、ライン、ポリゴンのそれぞれに対して、異なるソースとレイヤーを追加しています。`type`プロパティで、レイヤーの種類（`circle`, `line`, `fill`）を指定しています。それぞれのレイヤーの種類に応じて、`paint`プロパティで様々なスタイルを設定できます。

#### 実践的なテクニック

*   **データの属性に応じたスタイリング：** GeoJSONデータの`properties`に基づいて、レイヤーのスタイルを動的に変更できます。例えば、人口密度に応じてポリゴンの色を変えることができます。

```javascript
// 例：人口密度に応じてポリゴンの色を変える
map.addLayer({
  id: 'population-layer',
  type: 'fill',
  source: 'polygons',
  paint: {
    'fill-color': [
      'interpolate',
      ['linear'],
      ['get', 'population'], // GeoJSONのpropertiesにある'population'の値を取得
      0, 'green', // 人口密度が0の場合、緑色
      1000, 'yellow', // 人口密度が1000の場合、黄色
      5000, 'red' // 人口密度が5000の場合、赤色
    ],
    'fill-opacity': 0.7
  }
});
```

*   **レイヤーの表示/非表示の切り替え：** ユーザーの操作に応じて、レイヤーの表示/非表示を切り替えることができます。これにより、地図上の情報を整理し、ユーザーエクスペリエンスを向上させることができます。

```javascript
// 例：チェックボックスの変更に応じてレイヤーの表示/非表示を切り替える
const checkbox = document.getElementById('population-checkbox');
checkbox.addEventListener('change', function() {
  if (this.checked) {
    map.setLayoutProperty('population-layer', 'visibility', 'visible');
  } else {
    map.setLayoutProperty('population-layer', 'visibility', 'none');
  }
});
```

*   **レイヤーのZオーダーの制御：** 複数のレイヤーが重なって表示される場合、Zオーダーを制御することで、どのレイヤーを前面に表示するかを指定できます。`map.moveLayer`を使用すると、レイヤーのZオーダーを変更できます。

```javascript
// 例：'population-layer'を最前面に移動する
map.moveLayer('population-layer');
```

#### 応用例とユースケース

*   **ハザードマップ：** 洪水や地震などの災害リスクを、ポリゴンやラインで地図上に表示します。リスクの度合いに応じて色を変えることで、視覚的に分かりやすく情報を伝えることができます。
*   **都市計画：** 土地利用の状況や建物の用途を、ポリゴンで地図上に表示します。用途に応じて色やパターンを変えることで、都市の構造を把握しやすくすることができます。
*   **観光マップ：** 観光スポットや宿泊施設の位置を、アイコンやマーカーで地図上に表示します。施設の種別に応じてアイコンを変えることで、ユーザーが目的の施設を見つけやすくすることができます。
*   **不動産情報：** 物件の位置や価格、間取りなどの情報を、地図上に表示します。価格に応じてマーカーの色を変えたり、間取り図を表示するポップアップを表示したりすることで、ユーザーが物件を比較検討しやすくすることができます。

#### トラブルシューティング

*   **レイヤーが表示されない：** 以下の原因が考えられます。
    *   GeoJSONデータの形式が正しくない。
    *   ソースが正しく登録されていない。
    *   レイヤーの`visibility`が`none`になっている。
    *   レイヤーのZオーダーが他のレイヤーの下になっている。
*   **スタイリングが適用されない：** 以下の原因が考えられます。
    *   `paint`プロパティの値が正しくない。
    *   データの属性名が間違っている。
    *   スタイルの優先順位が他のスタイルによって上書きされている。
*   **パフォーマンスが悪い：** 以下の原因が考えられます。
    *   GeoJSONデータのサイズが大きすぎる。
    *   レイヤーの数が多すぎる。
    *   複雑なスタイリングを使用している。
