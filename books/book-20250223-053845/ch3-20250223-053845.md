## 第3章：地図ライブラリ選定とMapbox GL JS導入

### 主要な地図ライブラリの比較検討：Mapbox, Google Maps, Leaflet

#### 概要と重要性

地図ライブラリは、Webアプリケーションやモバイルアプリケーションに地図機能を組み込むために不可欠なツールです。 どのライブラリを選ぶかは、プロジェクトの要件、予算、技術的な制約に大きく依存します。ここでは、主要な地図ライブラリであるMapbox GL JS, Google Maps, Leafletを比較検討し、それぞれの特徴を明らかにすることで、最適な選択を支援します。

#### 特徴と利点

**Mapbox GL JS**

*   **特徴:** ベクトルタイルベースの描画エンジンを採用しており、滑らかでインタラクティブな地図表示が可能です。 Mapbox Studioを利用することで、地図のスタイルを高度にカスタマイズできます。
*   **利点:** 高度なカスタマイズ性、高速なレンダリング、豊富なAPI、オフラインサポート。
*   **得意なユースケース:** データの可視化、インタラクティブな地図アプリケーション、独自の地図スタイルを必要とするプロジェクト。
*   **価格:** 従量課金制。使用量に応じて料金が発生します。無料枠も用意されています。

**Google Maps**

*   **特徴:** 世界中で広く利用されている地図サービスで、豊富な地理データと信頼性の高いAPIを提供します。
*   **利点:** 膨大なデータ量、強力な検索機能、ストリートビュー、多様なAPI（Places API, Directions APIなど）。
*   **得意なユースケース:** 場所の検索、経路検索、店舗検索、一般的な地図アプリケーション。
*   **価格:** 従量課金制。無料枠を超えると料金が発生します。

**Leaflet**

*   **特徴:** 軽量で使いやすいオープンソースの地図ライブラリです。
*   **利点:** シンプルなAPI、豊富なプラグイン、カスタマイズ性、無料で使用可能。
*   **得意なユースケース:** 小規模なプロジェクト、シンプルな地図表示、オープンソースコミュニティを活用したい場合。
*   **価格:** 無料 (オープンソース)。

**比較表**

| 特徴          | Mapbox GL JS                                  | Google Maps                                     | Leaflet                                        |
|---------------|------------------------------------------------|-------------------------------------------------|------------------------------------------------|
| データソース    | Mapbox提供のベクトルタイル, カスタムデータ対応 | Google提供のラスタタイル, ベクトルタイル (一部)   | 様々なデータソースに対応 (Tile Layer, GeoJSON)  |
| レンダリング    | ベクトルタイルベース (WebGL)                    | ラスタタイル, ベクトルタイル (一部)              | ラスタタイル, ベクトルタイル (プラグイン)          |
| カスタマイズ性  | 非常に高い (Mapbox Studio)                      | 高い (スタイル設定)                               | 高い (プラグイン, CSS)                           |
| オフラインサポート | 可能                                           | 一部可能 (キャッシュ)                             | 可能 (プラグイン)                                |
| API           | 豊富                                           | 非常に豊富                                        | シンプル                                         |
| 価格          | 従量課金制                                       | 従量課金制                                       | 無料 (オープンソース)                           |
| ライセンス      | 独自ライセンス                                   | 独自ライセンス                                   | BSDライセンス                                    |

#### 事前準備と前提条件

*   **Mapbox GL JS:** Mapboxアカウントの作成とAPIキーの取得が必要です。
*   **Google Maps:** Google Cloud Platformプロジェクトの作成とAPIキーの取得が必要です。
*   **Leaflet:** 特に準備は必要ありません。CDNまたはnpmでライブラリをインストールするだけです。

```html

  </style>

  <div id="map"></div>

	mapboxgl.accessToken = 'YOUR_MAPBOX_ACCESS_TOKEN';
    const map = new mapboxgl.Map({
      container: 'map', // container ID

  </script>
```

#### 実践的なテクニック

*   **Mapbox GL JS:** GeoJSONデータを使ったカスタムレイヤーの追加、Mapbox Studioでのスタイル編集、アニメーションの作成。
*   **Google Maps:** Places APIを使った場所検索、Directions APIを使った経路検索、カスタムマーカーの追加。
*   **Leaflet:** GeoJSONデータの表示、ポップアップの追加、カスタムコントロールの作成。

#### 応用例とユースケース

*   **Mapbox GL JS:** 不動産情報の地図表示、旅行プランニングアプリケーション、気象データの可視化。
*   **Google Maps:** 店舗検索サイト、ナビゲーションアプリケーション、配送ルート最適化。
*   **Leaflet:** サイクリングマップ、ハイキングマップ、地域情報サイト。

#### トラブルシューティング

*   **Mapbox GL JS:** APIキーのエラー、スタイルの読み込みエラー、パフォーマンスの問題。
*   **Google Maps:** APIキーのエラー、課金に関する問題、地図の表示エラー。
*   **Leaflet:** レイヤーの表示順序、プラグインの競合、データの読み込みエラー。

### Mapbox GL JSの導入と初期設定

#### 概要と重要性

Mapbox GL JSは、高性能なベクトルタイルベースの地図ライブラリであり、Webアプリケーションにインタラクティブな地図機能を実装するのに最適です。 導入と初期設定を正しく行うことで、スムーズな開発と最適なパフォーマンスを実現できます。

#### 特徴と利点

*   **高速なレンダリング:** ベクトルタイルを使用することで、地図の表示が非常に高速です。
*   **高いカスタマイズ性:** Mapbox Studioを使って、地図のスタイルを自由にカスタマイズできます。
*   **豊富なAPI:** 地図の操作、データの追加、インタラクションの実装など、多様なAPIが利用できます。
*   **オフラインサポート:** オフライン環境でも地図を表示できます。

#### 事前準備と前提条件

1.  **Mapboxアカウントの作成:** [Mapbox](https://www.mapbox.com/)の公式サイトでアカウントを作成します。
2.  **APIキーの取得:** Mapboxアカウントにログインし、[Account](https://account.mapbox.com/)ページからAPIキー（Access token）を取得します。

#### 基本的な使い方

**1. HTMLファイルの作成:**

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Mapbox GL JS</title>
  <meta name="viewport" content="initial-scale=1,maximum-scale=1,user-scalable=no">
  <link href="https://api.mapbox.com/mapbox-gl-js/v3.1.0/mapbox-gl.css" rel="stylesheet">
  <style>
    body { margin: 0; padding: 0; }
    #map { position: absolute; top: 0; bottom: 0; width: 100%; }
  </style>
</head>
<body>
  <div id="map"></div>
  <script src="https://api.mapbox.com/mapbox-gl-js/v3.1.0/mapbox-gl.js"></script>
  <script>
    mapboxgl.accessToken = 'YOUR_MAPBOX_ACCESS_TOKEN';
    const map = new mapboxgl.Map({
      container: 'map', // container ID
      style: 'mapbox://styles/mapbox/streets-v12', // style URL
      center: [139.767125, 35.681236], // starting position [lng, lat]
      zoom: 9 // starting zoom
    });
  </script>
</body>
</html>
```

**2. Mapbox GL JSの読み込み:**

`<head>`セクションにMapbox GL JSのCSSとJavaScriptファイルを読み込みます。 CDN（Content Delivery Network）を利用するのが簡単です。

```html
<link href="https://api.mapbox.com/mapbox-gl-js/v3.1.0/mapbox-gl.css" rel="stylesheet">
<script src="https://api.mapbox.com/mapbox-gl-js/v3.1.0/mapbox-gl.js"></script>
```

**3. 地図の表示:**

`<body>`セクションに地図を表示するための`<div>`要素を追加します。 また、JavaScriptでMapbox GL JSのAPIを使って地図を初期化します。

```html
<div id="map"></div>
<script>
  mapboxgl.accessToken = 'YOUR_MAPBOX_ACCESS_TOKEN'; // ここにあなたのAPIキーを入力
  const map = new mapboxgl.Map({
    container: 'map', // 地図を表示する要素のID
    style: 'mapbox://styles/mapbox/streets-v12', // 地図のスタイルURL
    center: [139.767125, 35.681236], // 地図の中心座標 [経度, 緯度]
    zoom: 9 // 地図の初期ズームレベル
  });
</script>
```

**解説:**

*   `mapboxgl.accessToken`: Mapbox APIを使用するためのAPIキーを設定します。
*   `mapboxgl.Map()`: Mapbox GL JSの地図オブジェクトを作成します。
    *   `container`: 地図を表示するHTML要素のIDを指定します。
    *   `style`: 地図のスタイルURLを指定します。 Mapboxが提供するデフォルトのスタイルや、自分で作成したカスタムスタイルを指定できます。
    *   `center`: 地図の中心座標を[経度, 緯度]の形式で指定します。
    *   `zoom`: 地図の初期ズームレベルを指定します。

#### 実践的なテクニック

**1. マーカーの追加:**

```javascript
const marker = new mapboxgl.Marker()
  .setLngLat([139.767125, 35.681236]) // マーカーの座標
  .addTo(map); // マーカーを地図に追加
```

**2. ポップアップの追加:**

```javascript
const popup = new mapboxgl.Popup({ offset: 25 })
  .setText('これはポップアップです。');

const marker = new mapboxgl.Marker()
  .setLngLat([139.767125, 35.681236])
  .setPopup(popup) // マーカーにポップアップを設定
  .addTo(map);
```

**3. GeoJSONデータの表示:**

```javascript
map.on('load', () => {
  map.addSource('places', {
    'type': 'geojson',
    'data': {
      'type': 'FeatureCollection',
      'features': [
        {
          'type': 'Feature',
          'properties': {
            'name': '東京タワー',
            'description': '東京のランドマーク'
          },
          'geometry': {
            'type': 'Point',
            'coordinates': [139.745433, 35.658581]
          }
        }
      ]
    }
  });

  map.addLayer({
    'id': 'places',
    'type': 'symbol',
    'source': 'places',
    'layout': {
      'icon-image': 'marker-15',
      'icon-allow-overlap': true
    }
  });

  // ポップアップの追加
  map.on('click', 'places', (e) => {
    const coordinates = e.features[0].geometry.coordinates.slice();
    const description = e.features[0].properties.description;
    const name = e.features[0].properties.name;

    new mapboxgl.Popup()
      .setLngLat(coordinates)
      .setHTML(`<b>${name}</b><br>${description}`)
      .addTo(map);
  });

  // カーソルスタイルの変更
  map.on('mouseenter', 'places', () => {
    map.getCanvas().style.cursor = 'pointer';
  });

  map.on('mouseleave', 'places', () => {
    map.getCanvas().style.cursor = '';
  });
});
```

#### 応用例とユースケース

*   **不動産情報の地図表示:** 物件の位置、価格、詳細情報を地図上に表示します。
*   **旅行プランニングアプリケーション:** 観光スポット、ホテル、レストランを地図上に表示し、経路検索機能を追加します。
*   **気象データの可視化:** 気温、降水量、風速などの気象データを地図上に重ねて表示します。

#### トラブルシューティング

*   **APIキーのエラー:** APIキーが正しく設定されているか確認してください。 また、APIキーの利用制限を超えていないか確認してください。
*   **スタイルの読み込みエラー:** スタイルURLが正しいか確認してください。 また、インターネット接続が正常であることを確認してください。
*   **パフォーマンスの問題:** 地図の表示が遅い場合は、ベクタータイルの最適化、レイヤー数の削減、レンダリング設定の調整などを検討してください。

### 地図スタイルのカスタマイズ：Mapbox Studio

#### 概要と重要性

Mapbox Studioは、Mapbox GL JSで使用する地図のスタイルをGUIで直感的にカスタマイズできるツールです。 Mapbox Studioを使うことで、色、フォント、アイコン、レイヤーの表示などを細かく調整し、独自の地図スタイルを作成できます。

#### 特徴と利点

*   **直感的なGUI:** コーディングなしで、GUI上で簡単にスタイルを編集できます。
*   **リアルタイムプレビュー:** スタイルを変更すると、リアルタイムで地図の表示が更新されます。
*   **豊富なスタイルプリセット:** Mapboxが提供する豊富なスタイルプリセットをベースに、独自のスタイルを作成できます。
*   **データのインポート:** GeoJSON, Shapefileなどの地理空間データをインポートし、地図に表示できます。

#### 事前準備と前提条件

1.  **Mapboxアカウントの作成:** [Mapbox](https://www.mapbox.com/)の公式サイトでアカウントを作成します。
2.  **Mapbox Studioへのアクセス:** Mapboxアカウントにログインし、[Mapbox Studio](https://studio.mapbox.com/)にアクセスします。

#### 基本的な使い方

**1. 新しいスタイルの作成:**

Mapbox Studioにログイン後、「New style」ボタンをクリックして、新しいスタイルを作成します。 ベースとなるスタイルプリセットを選択するか、空のスタイルから作成できます。

**2. スタイルの編集:**

スタイルエディタでは、以下の要素を編集できます。

*   **Layers:** 地図のレイヤー（道路、建物、水域など）の表示設定を調整します。
    *   Visibility: レイヤーの表示/非表示を切り替えます。
    *   Style: レイヤーの色、線幅、フォントなどを変更します。
    *   Filters: 特定の条件に合致するフィーチャーのみを表示します。
*   **Components:** 地図のコンポーネント（ラベル、アイコン、凡例など）の表示設定を調整します。
*   **Data:** 地図に表示するデータソース（GeoJSON, Vector Tilesなど）を管理します。
*   **Settings:** 地図の全体的な設定（背景色、フォントなど）を調整します。

**3. スタイルの保存と公開:**

スタイルを編集したら、「Publish」ボタンをクリックして、スタイルを保存し、公開します。 公開されたスタイルのURLは、Mapbox GL JSで使用できます。

#### 実践的なテクニック

**1. 色の変更:**

レイヤーの「Style」設定で、色を変更できます。 色を選択するだけでなく、色の透明度やブレンドモードも調整できます。

**2. フォントの変更:**

ラベルの「Text」設定で、フォントを変更できます。 フォントサイズ、フォントファミリー、フォントカラーなどを調整できます。

**3. アイコンの変更:**

ポイントデータの表示に使用するアイコンを変更できます。 Mapboxが提供するアイコンライブラリから選択するか、自分で作成したカスタムアイコンをアップロードできます。

**4. データのインポート:**

GeoJSON, Shapefileなどの地理空間データをインポートし、地図に表示できます。 インポートしたデータは、レイヤーとして追加され、スタイルを編集できます。

**5. フィルターの使用:**

フィルターを使用すると、特定の条件に合致するフィーチャーのみを表示できます。 例えば、特定の種類の道路のみを表示したり、特定の属性を持つ建物のみを表示したりできます。

#### 応用例とユースケース

*   **ブランドイメージに合わせた地図:** 会社のロゴやブランドカラーに合わせて、地図のスタイルをカスタマイズします。
*   **特定の目的に特化した地図:** 例えば、サイクリングマップ、ハイキングマップ、防災マップなどを作成します。
*   **データの可視化:** データの属性に合わせて、地図のスタイルを動的に変更し、データの傾向やパターンを可視化します。

#### トラブルシューティング

*   **スタイルの読み込みエラー:** スタイルURLが正しいか確認してください。 また、APIキーが正しく設定されているか確認してください。
*   **パフォーマンスの問題:** スタイルの複雑さによっては、地図の表示が遅くなることがあります。 レイヤー数の削減、スタイルの簡略化、データの最適化などを検討してください。
*   **Mapbox Studioの操作に関する問題:** Mapboxのドキュメントやチュートリアルを参照してください。 また、Mapboxのコミュニティフォーラムで質問することもできます。
