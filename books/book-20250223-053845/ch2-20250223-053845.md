## 第2章：開発環境の構築とReact Native基礎

### React Native開発環境の構築：Node.js, Expo CLI

#### 概要と重要性

React Nativeでアプリ開発を始めるにあたって、まず適切な開発環境を構築することが非常に重要です。環境構築が不十分だと、開発中に予期せぬエラーが発生したり、効率が著しく低下したりする可能性があります。このセクションでは、React Native開発に必要なNode.jsとExpo CLIを中心に、スムーズな開発環境の構築方法を解説します。

#### 特徴と利点

*   **Node.js:** JavaScriptの実行環境であり、React Nativeプロジェクトのビルドやパッケージ管理に不可欠です。npm (Node Package Manager) や yarnといったパッケージマネージャーを通じて、必要なライブラリやツールを簡単にインストールできます。

*   **Expo CLI:** React Native開発をより手軽にするためのツールキットです。デバイスへのプレビュー、ビルド、デプロイなどをコマンド一つで実行できます。特に、ネイティブコードを直接触る必要がないため、JavaScriptの知識だけでクロスプラットフォーム開発を始められます。

#### 事前準備と前提条件

*   **OS:** macOS, Windows, Linuxのいずれか
*   **エディタ:** Visual Studio Code, Sublime Text, Atomなど（お好みのもの）
*   **ターミナル:** コマンド操作を行うためのターミナル (macOS: Terminal, iTerm2; Windows: PowerShell, Git Bash)

#### 基本的な使い方

1.  **Node.jsのインストール:**
    Node.jsの公式サイト ([https://nodejs.org/](https://nodejs.org/)) から、LTS (Long Term Support) バージョンをダウンロードしてインストールします。インストール時に、npmも同時にインストールされることを確認してください。

    インストール後、ターミナルで以下のコマンドを実行し、バージョンを確認します。

    ```bash
    node -v
    npm -v
    ```

    バージョンが表示されれば、Node.jsとnpmのインストールは成功です。

2.  **Expo CLIのインストール:**
    ターミナルで以下のコマンドを実行し、Expo CLIをグローバルにインストールします。

    ```bash
    npm install -g expo-cli
    ```

    インストール後、以下のコマンドでバージョンを確認します。

    ```bash
    expo --version
    ```

    バージョンが表示されれば、Expo CLIのインストールは成功です。

3.  **プロジェクトの作成:**
    開発したいディレクトリに移動し、以下のコマンドを実行して新しいReact Nativeプロジェクトを作成します。

    ```bash
    expo init AwesomeProject
    ```

    いくつか質問が表示されるので、テンプレートを選択します。
    ここでは、最もシンプルな「blank」を選択します。

    ```
    Choose a template: (Use arrow keys)
    ❯ blank               a minimal template for clean app configuring
      blank (TypeScript)  a minimal template for clean app configuring with TypeScript
      tabs (TypeScript)   several example screens and tab navigation using TypeScript
      (Use arrow keys to move, type to filter)
    ```

    プロジェクトの作成が完了したら、作成されたディレクトリに移動します。

    ```bash
    cd AwesomeProject
    ```

4.  **プロジェクトの実行:**
    ターミナルで以下のコマンドを実行し、開発サーバーを起動します。

    ```bash
    expo start
    ```

    すると、ブラウザにExpo DevToolsが表示されます。

    *   **Androidエミュレーター/実機で実行:** Android Studioをインストールし、エミュレーターを起動するか、実機をUSB接続して、Expo DevToolsから「Run on Android device/emulator」を選択します。

    *   **iOSシミュレーター/実機で実行:** Xcodeをインストールし、シミュレーターを起動するか、実機をUSB接続して、Expo DevToolsから「Run on iOS simulator」を選択します。

    *   **Webブラウザで実行:** Expo DevToolsから「Run in web browser」を選択します。

    QRコードが表示された場合は、Expo Goアプリをインストールしたスマートフォンで読み込むことでも実行可能です。

#### 実践的なテクニック

*   **Expoアカウントの作成:** Expo CLIを使うには、Expoアカウントが必要です。`expo register`コマンドでアカウントを作成できます。
*   **Gitによるバージョン管理:** プロジェクトを作成したら、Gitリポジトリを作成し、変更をコミットすることを推奨します。
*   **`.gitignore`ファイルの作成:** `node_modules`など、バージョン管理する必要のないファイルを`.gitignore`ファイルに記述します。
*   **環境変数の利用:** 秘密鍵やAPIキーなどの機密情報は、環境変数として管理し、コードに直接記述しないようにします。`.env`ファイルを作成し、`react-native-dotenv`などのライブラリを利用して、環境変数を読み込むことができます。

#### 応用例とユースケース

*   **簡単なToDoアプリ:** リストの追加、削除、完了などの機能を実装したシンプルなToDoアプリは、React Nativeの基本を学ぶ上で非常に役立ちます。
*   **API連携アプリ:** 公開APIを利用して、天気予報アプリやニュースアプリなどを作成することで、API連携の基礎を学ぶことができます。

#### トラブルシューティング

*   **Node.jsのバージョンが古い:** React Nativeのバージョンによっては、Node.jsのバージョンが古いとエラーが発生することがあります。Node.jsを最新のLTSバージョンにアップデートしてください。
*   **Expo CLIのバージョンが古い:** Expo CLIを最新バージョンにアップデートしてください。`npm install -g expo-cli`でアップデートできます。
*   **依存関係のエラー:** `npm install`または`yarn install`で依存関係をインストールする際にエラーが発生した場合、`node_modules`ディレクトリを削除し、再度インストールしてみてください。
*   **ポートが競合している:** 開発サーバーが起動しない場合、他のプロセスがポートを占有している可能性があります。ポートを変更するか、占有しているプロセスを停止してください。

#### まとめと次のステップ

このセクションでは、React Native開発環境の構築として、Node.jsとExpo CLIのインストール、プロジェクトの作成、実行方法について解説しました。次のステップでは、React Nativeのコンポーネントの基本について学びます。

### React Nativeコンポーネントの基本

#### 概要と重要性

React Nativeアプリは、再利用可能なUI要素であるコンポーネントで構成されています。コンポーネントを理解し、適切に設計することは、効率的で保守性の高いアプリ開発に不可欠です。このセクションでは、React Nativeのコンポーネントの基本について解説します。

#### 特徴と利点

*   **再利用性:** コンポーネントは、複数の場所で再利用できます。これにより、コードの重複を減らし、開発効率を向上させることができます。
*   **モジュール性:** コンポーネントは、独立したモジュールとして機能します。これにより、コードの可読性と保守性を向上させることができます。
*   **UIの一貫性:** コンポーネントを使用することで、アプリ全体のUIの一貫性を保つことができます。

#### 事前準備と前提条件

*   React Native開発環境が構築済みであること（前のセクションを参照）
*   JavaScriptの基本的な知識（変数、関数、オブジェクトなど）
*   Reactの基本的な知識（JSX, Props, Stateなど）があるとより理解が深まります

#### 基本的な使い方

1.  **関数コンポーネント:**
    最もシンプルなコンポーネントの形式です。JavaScriptの関数として定義され、Propsを受け取り、JSXを返します。

    ```javascript
    import React from 'react';
    import { Text, View } from 'react-native';

    const Greeting = (props) => {
      return (
        <View>
          <Text>Hello {props.name}!</Text>
        </View>
      );
    };

    export default Greeting;
    ```

    このコンポーネントは、`name`というPropsを受け取り、`Hello {props.name}!`というテキストを表示します。

    親コンポーネントで以下のように使用します。

    ```javascript
    import React from 'react';
    import { View } from 'react-native';
    import Greeting from './Greeting';

    const App = () => {
      return (
        <View>
          <Greeting name="John" />
          <Greeting name="Jane" />
        </View>
      );
    };

    export default App;
    ```

2.  **クラスコンポーネント:**
    Reactのクラスとして定義されるコンポーネントです。Stateを持ち、ライフサイクルメソッドを使用できます。

    ```javascript
    import React, { Component } from 'react';
    import { Text, View } from 'react-native';

    class Counter extends Component {
      constructor(props) {
        super(props);
        this.state = {
          count: 0,
        };
      }

      increment = () => {
        this.setState({ count: this.state.count + 1 });
      };

      render() {
        return (
          <View>
            <Text>Count: {this.state.count}</Text>
            <Button title="Increment" onPress={this.increment} />
          </View>
        );
      }
    }

    export default Counter;
    ```

    このコンポーネントは、`count`というStateを持ち、ボタンを押すと`count`が増加します。

    **useStateフック:**
    関数コンポーネントでStateを扱うためのフックです。React 16.8から導入されました。

    ```javascript
    import React, { useState } from 'react';
    import { Text, View, Button } from 'react-native';

    const Counter = () => {
      const [count, setCount] = useState(0);

      return (
        <View>
          <Text>Count: {count}</Text>
          <Button title="Increment" onPress={() => setCount(count + 1)} />
        </View>
      );
    };

    export default Counter;
    ```

    このコンポーネントは、`count`というStateを持ち、ボタンを押すと`count`が増加します。`useState`フックを使用することで、関数コンポーネントでもStateを扱うことができます。

3.  **Props:**
    親コンポーネントから子コンポーネントにデータを渡すための仕組みです。Propsは読み取り専用であり、子コンポーネント内で変更することはできません。

4.  **State:**
    コンポーネントの状態を表すデータです。Stateはコンポーネント内で変更可能であり、変更されるとコンポーネントが再レンダリングされます。

5.  **ライフサイクルメソッド:**
    コンポーネントが生成、更新、破棄される際に実行されるメソッドです。クラスコンポーネントでのみ使用できます。`componentDidMount`, `componentDidUpdate`, `componentWillUnmount`などが代表的なライフサイクルメソッドです。

    **useEffectフック:**
    関数コンポーネントでライフサイクルメソッドの代替として使用できるフックです。React 16.8から導入されました。

    ```javascript
    import React, { useState, useEffect } from 'react';
    import { Text, View } from 'react-native';

    const MyComponent = () => {
      const [data, setData] = useState(null);

      useEffect(() => {
        // コンポーネントがマウントされた時に実行される処理
        console.log('Component mounted');

        // APIからデータを取得するなどの非同期処理を行う
        fetch('https://example.com/api/data')
          .then(response => response.json())
          .then(data => setData(data));

        // コンポーネントがアンマウントされる時に実行される処理（クリーンアップ）
        return () => {
          console.log('Component unmounted');
        };
      }, []); // 空の配列を渡すと、マウント時のみ実行される

      return (
        <View>
          {data ? <Text>Data: {data.message}</Text> : <Text>Loading...</Text>}
        </View>
      );
    };

    export default MyComponent;
    ```

#### 実践的なテクニック

*   **コンポーネントの分割:** 大きくて複雑なコンポーネントは、小さなコンポーネントに分割することで、可読性と保守性を向上させることができます。
*   **Propsの型チェック:** PropTypesライブラリを使用して、Propsの型をチェックすることで、予期せぬエラーを防止できます。TypeScriptを使用する場合は、型定義によってPropsの型をチェックできます。
*   **状態管理ライブラリ:** ReduxやMobXなどの状態管理ライブラリを使用することで、複雑な状態管理を効率的に行うことができます。

#### 応用例とユースケース

*   **ボタンコンポーネント:** クリックイベントを処理し、スタイルをカスタマイズ可能なボタンコンポーネント。
*   **リストアイテムコンポーネント:** リストの各アイテムを表示し、データをバインド可能なリストアイテムコンポーネント。
*   **フォームコンポーネント:** 入力フィールド、ラベル、バリデーションを備えたフォームコンポーネント。
*   **モーダルコンポーネント:** オーバーレイでコンテンツを表示するモーダルコンポーネント。

#### トラブルシューティング

*   **Propsが正しく渡されていない:** 親コンポーネントから子コンポーネントにPropsが正しく渡されているか確認してください。
*   **Stateが正しく更新されていない:** Stateが正しく更新されているか確認してください。`setState`メソッドを正しく使用しているか、関数コンポーネントの場合は`useState`フックを正しく使用しているか確認してください。
*   **無限ループが発生している:** `componentDidUpdate`や`useEffect`内でStateを更新する際に、無限ループが発生することがあります。条件を適切に設定し、無限ループを回避してください。

このセクションでは、React Nativeのコンポーネントの基本について解説しました。関数コンポーネント、クラスコンポーネント、Props, State, ライフサイクルメソッドなど、コンポーネントを構成する要素を理解することで、より効率的で保守性の高いアプリ開発を行うことができます。次のステップでは、スタイリングについて学びます。

### スタイリング：FlexboxレイアウトとStyleSheet

#### 概要と重要性

React Nativeでは、UIのレイアウトとスタイルを定義するために、FlexboxレイアウトとStyleSheetを使用します。これらの概念を理解することは、美しいUIを作成するために不可欠です。このセクションでは、FlexboxレイアウトとStyleSheetの基本について解説します。

#### 特徴と利点

*   **Flexboxレイアウト:** 様々なデバイスサイズに対応できる柔軟なレイアウトを実現できます。要素の配置、サイズ、間隔などを簡単に制御できます。
*   **StyleSheet:** スタイルをオブジェクトとして定義し、コンポーネントに適用できます。これにより、コードの可読性と保守性を向上させることができます。

#### 事前準備と前提条件

*   React Native開発環境が構築済みであること（前のセクションを参照）
*   React Nativeコンポーネントの基本的な知識（前のセクションを参照）
*   CSSの基本的な知識があるとより理解が深まります

#### 基本的な使い方

1.  **Flexboxレイアウト:**
    Flexboxは、要素の配置、サイズ、間隔などを制御するためのレイアウトモデルです。React Nativeでは、CSSのFlexboxとほぼ同じプロパティを使用できます。

    *   **`flexDirection`:** 要素の配置方向を指定します。`row` (水平方向), `column` (垂直方向), `row-reverse`, `column-reverse`などの値があります。
    *   **`justifyContent`:** 主軸方向の要素の配置を指定します。`flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`などの値があります。
    *   **`alignItems`:** 交差軸方向の要素の配置を指定します。`flex-start`, `flex-end`, `center`, `stretch`, `baseline`などの値があります。
    *   **`flex`:** 要素のサイズを相対的に指定します。数値が大きいほど、利用可能なスペースをより多く占有します。

    ```javascript
    import React from 'react';
    import { View, Text } from 'react-native';

    const FlexboxExample = () => {
      return (
        <View style={{
          flex: 1,
          flexDirection: 'column', // または 'row'
          justifyContent: 'center', // または 'flex-start', 'flex-end', 'space-around'など
          alignItems: 'center', // または 'flex-start', 'flex-end', 'stretch'など
        }}>
          <View style={{ width: 50, height: 50, backgroundColor: 'red' }} />
          <View style={{ width: 50, height: 50, backgroundColor: 'green' }} />
          <View style={{ width: 50, height: 50, backgroundColor: 'blue' }} />
        </View>
      );
    };

    export default FlexboxExample;
    ```

2.  **StyleSheet:**
    StyleSheetは、スタイルをオブジェクトとして定義し、コンポーネントに適用するためのAPIです。これにより、コードの可読性と保守性を向上させることができます。

    ```javascript
    import React from 'react';
    import { View, Text, StyleSheet } from 'react-native';

    const styles = StyleSheet.create({
      container: {
        flex: 1,
        justifyContent: 'center',
        alignItems: 'center',
      },
      text: {
        fontSize: 20,
        fontWeight: 'bold',
        color: 'blue',
      },
    });

    const StyleSheetExample = () => {
      return (
        <View style={styles.container}>
          <Text style={styles.text}>Hello, StyleSheet!</Text>
        </View>
      );
    };

    export default StyleSheetExample;
    ```

3.  **インラインスタイル:**
    StyleSheetを使用せずに、直接スタイルを記述することもできます。ただし、可読性と保守性が低下するため、StyleSheetの使用を推奨します。

    ```javascript
    import React from 'react';
    import { View, Text } from 'react-native';

    const InlineStyleExample = () => {
      return (
        <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
          <Text style={{ fontSize: 20, fontWeight: 'bold', color: 'blue' }}>Hello, Inline Style!</Text>
        </View>
      );
    };

    export default InlineStyleExample;
    ```

4.  **スタイルの継承:**
    StyleSheetで定義されたスタイルは、コンポーネント間で継承されません。親コンポーネントのスタイルを子コンポーネントに適用するには、Propsを使用するか、Context APIなどの状態管理ライブラリを使用する必要があります。

5. **レスポンシブデザイン:**
   画面サイズに応じてスタイルを切り替えることで、様々なデバイスに対応したUIを作成できます。`Dimensions` APIを使用して画面サイズを取得し、条件分岐によってスタイルを変更します。

   ```javascript
   import React from 'react';
   import { View, Text, StyleSheet, Dimensions } from 'react-native';

   const { width, height } = Dimensions.get('window');

   const styles = StyleSheet.create({
     container: {
       flex: 1,
       justifyContent: 'center',
       alignItems: 'center',
     },
     text: {
       fontSize: width > 600 ? 30 : 20, // 画面幅が600pxより大きい場合は30px、それ以外は20px
       fontWeight: 'bold',
       color: 'blue',
     },
   });

   const ResponsiveExample = () => {
     return (
       <View style={styles.container}>
         <Text style={styles.text}>Hello, Responsive!</Text>
       </View>
     );
   };

   export default ResponsiveExample;
   ```

#### 実践的なテクニック

*   **スタイルの再利用:** 複数のコンポーネントで共通のスタイルを使用する場合、StyleSheetを再利用することで、コードの重複を減らすことができます。
*   **テーマの適用:** アプリ全体で一貫したテーマを適用するために、Context APIやReduxなどの状態管理ライブラリを使用することができます。
*   **アニメーション:** `Animated` APIを使用して、コンポーネントのアニメーションを実装することができます。

#### 応用例とユースケース

*   **ボタンのスタイリング:** 背景色、文字色、ボーダーなどをカスタマイズしたボタンを作成する。
*   **フォームのスタイリング:** 入力フィールド、ラベル、エラーメッセージなどをスタイリングする。
*   **リストのスタイリング:** リストアイテム、区切り線などをスタイリングする。
*   **ナビゲーションバーのスタイリング:** 背景色、文字色、アイコンなどをスタイリングする。

#### トラブルシューティング

*   **スタイルが適用されない:** StyleSheetで定義したスタイルがコンポーネントに適用されない場合、StyleSheetの構文が正しいか、コンポーネントにStyleSheetが正しく適用されているか確認してください。
*   **レイアウトが崩れる:** Flexboxレイアウトを使用している場合、`flexDirection`, `justifyContent`, `alignItems`などのプロパティが正しく設定されているか確認してください。
*   **パフォーマンスが低下する:** インラインスタイルを多用すると、パフォーマンスが低下する可能性があります。StyleSheetの使用を推奨します。
