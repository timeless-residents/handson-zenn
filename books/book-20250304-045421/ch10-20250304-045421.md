## 1. 年号、出来事、人物の関連付けをフラッシュカードに活かす

### 概要と重要性

年号、出来事、人物を関連付けた情報は、歴史の全体像を把握するために不可欠です。たとえば、ある歴史的事件の前後関係や、中心となる人物との関係を理解することで、単なる暗記では得られない深い知識が身につきます。これらの情報をAnkiカードとして登録することで、反復学習しながら自分だけの歴史マップを作成できます。

### 基本的な使い方

以下は、CSV形式などで整理した歴史データ（例：年号、出来事、人物）を読み込み、Ankiカードとして自動登録するサンプルコードです。

```python
import csv
import requests

def add_history_card(year, event, person, deck="History", model="Basic"):
    # カードのFrontに年号と出来事、Backに人物情報を表示
    front = f"<strong>{year}</strong><br>{event}"
    back = f"<em>関係人物:</em> {person}"
    
    note = {
        "action": "addNote",
        "version": 6,
        "params": {
            "note": {
                "deckName": deck,
                "modelName": model,
                "fields": {
                    "Front": front,
                    "Back": back
                },
                "tags": ["歴史", "年表"]
            }
        }
    }
    response = requests.post("http://localhost:8765", json=note)
    return response.json()

# CSVファイル "history_data.csv" の例:
# 年号,出来事,人物
# 1185,鎌倉幕府成立,源頼朝・北条政子
# 1221,承久の乱,後鳥羽上皇・北条義時

with open("history_data.csv", newline="", encoding="utf-8") as csvfile:
    reader = csv.DictReader(csvfile)
    for row in reader:
        result = add_history_card(row["年号"], row["出来事"], row["人物"])
        print(result)
```

この例では、CSVから各行の歴史データを読み取り、年号と出来事をカードの「Front」に、関係人物を「Back」に表示するフラッシュカードをAnki Connectで追加しています。

## 2. 地図画像の自動表示を利用したカード作成

### 概要と重要性

歴史的な出来事が起こった場所を地図で確認することは、地理的背景の理解に役立ちます。Ankiカードに地図画像を埋め込むことで、視覚的に場所の情報を補強できます。HTMLの `<img>` タグを用いれば、Ankiカード内に地図画像を表示可能です。

### 基本的な使い方

以下は、地図画像のURLをカードに埋め込み、歴史的事件の場所と概要を表示する例です。

```python
import requests

def add_map_card(event_title, location, map_url, deck="History", model="Basic"):
    # Front: イベント名と場所、Back: 地図画像を表示
    front = f"<strong>{event_title}</strong><br><em>{location}</em>"
    back = f'<img src="{map_url}" alt="{event_title}の地図" style="max-width:100%;">'
    
    note = {
        "action": "addNote",
        "version": 6,
        "params": {
            "note": {
                "deckName": deck,
                "modelName": model,
                "fields": {
                    "Front": front,
                    "Back": back
                },
                "tags": ["歴史", "地図"]
            }
        }
    }
    response = requests.post("http://localhost:8765", json=note)
    return response.json()

# 例：関ヶ原の戦いに関するカード
event_title = "関ヶ原の戦い"
location = "岐阜県 関ケ原町"
map_url = "https://example.com/sekigahara_map.jpg"  # 地図画像のURL

result = add_map_card(event_title, location, map_url)
print(result)
```

このコードでは、イベント名と場所情報をFrontに、地図画像（URL経由）をBackに表示するカードを生成しています。画像のスタイルは、Ankiカードの表示領域に合わせて調整可能です。

## 3. タイムライン形式の学習カードの自動生成

### 概要と重要性

歴史は時間の流れの中で展開される物語です。タイムライン形式の情報は、各出来事の前後関係や変遷を視覚的に把握するのに有用です。Ankiカードとしてタイムラインを登録すれば、全体の流れを俯瞰しながら復習できます。

### 基本的な使い方

以下は、Markdown形式で記述したタイムラインの情報をAnkiカードに変換する例です。

```python
import requests

def add_timeline_card(title, timeline_markdown, deck="History", model="Basic"):
    # Markdown形式のタイムライン情報をHTMLに変換（必要に応じて）
    # ここではそのまま<pre>タグで整形して表示
    front = f"<strong>{title}</strong>"
    back = f"<pre>{timeline_markdown}</pre>"
    
    note = {
        "action": "addNote",
        "version": 6,
        "params": {
            "note": {
                "deckName": deck,
                "modelName": model,
                "fields": {
                    "Front": front,
                    "Back": back
                },
                "tags": ["歴史", "タイムライン"]
            }
        }
    }
    response = requests.post("http://localhost:8765", json=note)
    return response.json()

timeline_md = """
- **紀元前660年:** 神武天皇即位（伝説）
- **593年:** 聖徳太子が摂政に
- **794年:** 平安京遷都
- **1185年:** 鎌倉幕府成立
- **1603年:** 江戸幕府成立
- **1868年:** 明治維新
"""

result = add_timeline_card("日本史タイムライン", timeline_md)
print(result)
```

この例では、タイムライン情報をプレーンテキストとして登録しています。必要に応じてMarkdown→HTML変換ライブラリを活用して整形することも可能です。

## 4. イベントの前後関係の理解を深めるカードの自動生成

### 概要と重要性

歴史的出来事は因果関係をもって連鎖しています。ある事件の前後関係をカードとして整理することで、なぜその出来事が起こったのか、またその結果どのような変化があったのかを復習できます。

### 基本的な使い方

以下は、特定のイベントに対して前後の関連事項をカードにまとめる例です。

```python
import requests

def add_event_relationship_card(event, preceding, following, deck="History", model="Basic"):
    front = f"<strong>{event}</strong><br><em>前の出来事:</em> {preceding}"
    back = f"<em>後の出来事:</em> {following}"
    
    note = {
        "action": "addNote",
        "version": 6,
        "params": {
            "note": {
                "deckName": deck,
                "modelName": model,
                "fields": {
                    "Front": front,
                    "Back": back
                },
                "tags": ["歴史", "因果関係"]
            }
        }
    }
    response = requests.post("http://localhost:8765", json=note)
    return response.json()

event = "応仁の乱"
preceding = "足利義政の跡継ぎ問題・守護大名間の勢力争い"
following = "戦国時代の幕開けと室町幕府の衰退"

result = add_event_relationship_card(event, preceding, following)
print(result)
```

このカードは、イベント中心の因果関係を明示することで、歴史的流れの理解を深めるための一助となります。
