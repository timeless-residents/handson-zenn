## 12章: Webスクレイピングによるカード作成 - 最新情報をAnkiに反映

### Beautiful Soup, Seleniumを用いたスクレイピング

#### 概要と重要性

Ankiは、効率的な暗記学習を支援する強力なツールですが、常に最新の情報を取り込むことが重要です。Webスクレイピングは、インターネット上の情報を自動的に収集し、Ankiに取り込むための非常に有効な手段です。このセクションでは、PythonのBeautiful SoupとSeleniumという強力なライブラリを使用して、様々なWebサイトから情報をスクレイピングする方法を解説します。Beautiful Soupは静的なHTMLの解析に優れており、SeleniumはJavaScriptで動的に生成されるコンテンツのスクレイピングに役立ちます。

#### 特徴と利点

*   **Beautiful Soup:**
    *   HTML/XMLの解析に特化
    *   高速で軽量
    *   シンプルなAPIで扱いやすい
*   **Selenium:**
    *   ブラウザを自動操作し、JavaScriptを実行可能
    *   動的なコンテンツや認証が必要なサイトに対応
    *   多様なブラウザをサポート

これらのライブラリを組み合わせることで、静的なサイトから動的なWebアプリケーションまで、幅広いWebサイトから情報を抽出できます。

#### 事前準備と前提条件

*   **Python:** 3.6以上を推奨
*   **pip:** Pythonのパッケージ管理ツール
*   **Beautiful Soup:** `pip install beautifulsoup4` でインストール
*   **Selenium:** `pip install selenium` でインストール
*   **Webドライバ:** Google Chrome, FirefoxなどのWebドライバをダウンロードし、PATHを通す必要があります。（例：ChromeDriver）
*   **requests:** `pip install requests` (HTTPリクエストを扱う際に便利)

**ChromeDriver のインストールと設定例：**

1.  Chromeのバージョンを確認: Chromeブラウザのアドレスバーに `chrome://settings/help` と入力してバージョンを確認します。
2.  ChromeDriverのダウンロード: ChromeDriverの公式サイト([https://chromedriver.chromium.org/downloads](https://chromedriver.chromium.org/downloads))から、Chromeのバージョンに対応したChromeDriverをダウンロードします。
3.  ChromeDriverの配置: ダウンロードしたファイルを解凍し、`/usr/local/bin` (Linux/macOS) または `C:\Windows` (Windows) などのPATHが通ったディレクトリに配置します。

#### 基本的な使い方

**Beautiful Soup の例:**

```python
import requests
from bs4 import BeautifulSoup

url = "https://ja.wikipedia.org/wiki/Python"
response = requests.get(url)
response.raise_for_status() # エラーがあれば例外を発生
soup = BeautifulSoup(response.content, "html.parser")

# タイトルを取得
title = soup.find("h1", {"id": "firstHeading"}).text
print(f"タイトル: {title}")

# 段落を抽出
paragraphs = soup.find_all("p")
for p in paragraphs[:3]: #最初の3つの段落
    print(p.text)
```

**Selenium の例:**

```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

# Headless Chromeの設定（GUIなしで実行）
options = Options()
options.add_argument("--headless")

# WebDriverの起動（ChromeDriverのパスを明示的に指定することも可能）
driver = webdriver.Chrome(options=options)

try:
    url = "https://www.google.com"
    driver.get(url)

    # 検索ボックスに入力
    search_box = driver.find_element(By.NAME, "q")
    search_box.send_keys("Selenium")
    search_box.submit()

    # 検索結果が表示されるまで待機 (最大10秒)
    WebDriverWait(driver, 10).until(
        EC.presence_of_element_located((By.ID, "search"))
    )

    # 検索結果のタイトルを抽出
    results = driver.find_elements(By.CSS_SELECTOR, "div#search h3")
    for result in results[:3]:
        print(result.text)

except Exception as e:
    print(f"エラーが発生しました: {e}")

finally:
    driver.quit() # ブラウザを閉じる
```

**解説:**

*   **Beautiful Soup:**  `requests`でWebページを取得し、`BeautifulSoup`オブジェクトを作成。`find`や`find_all`メソッドで特定の要素を抽出します。
*   **Selenium:**  WebDriverを起動し、URLにアクセス。`find_element`や`find_elements`で要素を特定し、操作（入力、クリックなど）を行います。`WebDriverWait`で要素が表示されるまで待機することで、動的なコンテンツにも対応できます。

#### 実践的なテクニック

*   **CSSセレクタの活用:**  Beautiful SoupやSeleniumで要素を特定する際に、CSSセレクタを効果的に使用することで、複雑な構造のWebページでも目的の要素を正確に抽出できます。Chrome DevTools (F12キー) を利用して、要素のCSSセレクタを確認しましょう。
*   **XPath の活用:** CSSセレクタが難しい場合、XPathを使用することも可能です。XPathはXMLドキュメントの要素を特定するための言語で、より柔軟な指定ができます。
*   **JavaScriptの実行:** Seleniumでは、`execute_script`メソッドを使用してJavaScriptコードを実行できます。これにより、Webページ上の特定の操作を自動化したり、JavaScriptで生成される情報を抽出したりできます。
*   **Cookieの管理:**  ログインが必要なWebサイトをスクレイピングする場合、Cookieを適切に管理する必要があります。Seleniumの`get_cookies`メソッドでCookieを取得し、`add_cookie`メソッドで設定できます。
*   **User-Agentの設定:**  Webサイトによっては、スクレイピングをブロックするために、User-Agentをチェックしている場合があります。`requests`やSeleniumでUser-Agentを設定することで、スクレイピングを回避できる場合があります。

```python
# User-Agentの設定 (requests)
headers = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/58.0.3029.110 Safari/537.3'}
response = requests.get(url, headers=headers)

# User-Agentの設定 (Selenium)
options = Options()
options.add_argument("user-agent=Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/58.0.3029.110 Safari/537.3")
driver = webdriver.Chrome(options=options)
```

#### トラブルシューティング

*   **要素が見つからない:** CSSセレクタやXPathが間違っている可能性があります。Chrome DevToolsで要素を詳しく調べて、正しいセレクタやXPathを使用してください。また、Webページの構造が変更された可能性も考慮してください。
*   **スクレイピングがブロックされる:** Webサイトがスクレイピングを禁止している可能性があります。robots.txtを確認し、スクレイピングポリシーに従ってください。User-Agentの設定や、アクセス頻度を調整することで、ブロックを回避できる場合があります。
*   **文字化けが発生する:**  Webページのエンコーディングが正しく認識されていない可能性があります。`response.encoding` を確認し、適切なエンコーディングを設定してください。 `response.encoding = response.apparent_encoding` とすることで自動で判別させることができます。
*   **Seleniumでエラーが発生する:**  WebDriverのバージョンがChromeのバージョンと一致しているか確認してください。また、WebDriverのPATHが正しく設定されているか確認してください。
*   **タイムアウトが発生する:** Webページの読み込みに時間がかかっている可能性があります。`WebDriverWait`のタイムアウト時間を延長するか、ネットワーク環境を確認してください。

### スクレイピングデータの整形とAnkiへのインポート

#### 概要と重要性

Webスクレイピングによって取得したデータは、そのままではAnkiにインポートできないことがほとんどです。多くの場合、データを整形し、Ankiが認識できる形式に変換する必要があります。このセクションでは、スクレイピングしたデータをAnkiにインポートするための整形方法と、具体的なインポート手順を解説します。

#### 特徴と利点

*   **柔軟なデータ整形:** Pythonの文字列操作や正規表現を活用することで、様々な形式のデータをAnkiにインポートできる形式に変換できます。
*   **効率的なAnkiカード作成:** 自動的にデータを整形してAnkiカードを作成することで、手作業によるカード作成の手間を大幅に削減できます。
*   **エラーの削減:** データ整形時にエラーチェックを行うことで、Ankiに不正確なデータがインポートされるのを防ぎます。

#### 事前準備と前提条件

*   **Anki:** インストール済みであること
*   **スクレイピング済みデータ:** 前のセクションでスクレイピングしたデータ

#### 基本的な使い方

**データ整形:**

スクレイピングしたデータを整形する際には、以下の点に注意する必要があります。

1.  **不要な文字の削除:** HTMLタグ、空白、改行などの不要な文字を削除します。
2.  **データの分割:** スクレイピングしたデータを、Ankiカードの表と裏に分割します。
3.  **特殊文字のエスケープ:** Ankiが解釈できない特殊文字（タブ、改行など）をエスケープします。
4.  **データの結合:** 複数のデータを結合して、Ankiカードのフィールドを作成します。

```python
import re

def clean_text(text):
    """テキストからHTMLタグ、空白、改行などを削除する関数"""
    text = re.sub(r"<.*?>", "", text)  # HTMLタグを削除
    text = re.sub(r"\s+", " ", text)  # 複数の空白を1つにまとめる
    text = text.strip()  # 前後の空白を削除
    return text

def escape_anki_field(text):
    """Ankiフィールド内の特殊文字をエスケープする関数"""
    text = text.replace("\n", "<br>")  # 改行を<br>に置換
    text = text.replace("\t", "    ")  # タブをスペース4つに置換
    return text
```

**Ankiへのインポート:**

Ankiは、テキストファイル（UTF-8エンコーディング）またはCSVファイル（カンマ区切り）をインポートできます。テキストファイルの場合、各行がAnkiカードに対応し、フィールドはタブで区切られます。CSVファイルの場合、各行がAnkiカードに対応し、フィールドはカンマで区切られます。

```python
import csv

def create_anki_csv(data, filename="anki_cards.csv"):
    """データをAnkiにインポートできるCSVファイルを作成する関数"""
    with open(filename, "w", newline="", encoding="utf-8") as csvfile:
        writer = csv.writer(csvfile, delimiter=",", quotechar='"', quoting=csv.QUOTE_MINIMAL)
        for item in data:
            front = escape_anki_field(item["front"])
            back = escape_anki_field(item["back"])
            writer.writerow([front, back])

# 例:
data = [
    {"front": "Pythonとは？", "back": "高水準汎用プログラミング言語"},
    {"front": "Beautiful Soupとは？", "back": "HTML/XMLパーサー"}
]

create_anki_csv(data)
print("anki_cards.csv が作成されました。Ankiにインポートしてください。")
```

**Ankiへのインポート手順:**

1.  Ankiを起動します。
2.  「ファイル」メニューから「インポート」を選択します。
3.  作成したCSVファイルを選択します。
4.  インポート設定を確認し、「インポート」ボタンをクリックします。

### 定期的なスクレイピングによる自動更新

#### 概要と重要性

Web上の情報は常に変化するため、Ankiカードを最新の状態に保つためには、定期的なスクレイピングが必要です。このセクションでは、Pythonのスケジューラライブラリを使用して、スクレイピング処理を定期的に実行する方法を解説します。

#### 特徴と利点

*   **自動的な情報更新:** 定期的にスクレイピングを実行することで、Ankiカードを常に最新の状態に保つことができます。
*   **手間のかからないメンテナンス:** 手動でスクレイピングを実行する必要がないため、メンテナンスの手間を大幅に削減できます。
*   **時間効率の向上:** スクレイピング処理を自動化することで、学習に集中する時間を増やすことができます。

#### 事前準備と前提条件

*   **スクレイピング、データ整形、Ankiへのインポートのスクリプト:** 前のセクションで作成したスクリプト
*   **schedule ライブラリ:** `pip install schedule` でインストール

#### 基本的な使い方

**scheduleライブラリ:**

`schedule`ライブラリを使用すると、指定した間隔で関数を実行できます。

```python
import schedule
import time

def job():
    print("スクレイピング処理を実行します")
    # ここにスクレイピング、データ整形、Ankiへのインポートの処理を記述

# 毎日午前0時に実行
schedule.every().day.at("00:00").do(job)

# 10分ごとに実行
# schedule.every(10).minutes.do(job)

while True:
    schedule.run_pending()
    time.sleep(1)
```

**解説:**

*   `schedule.every().day.at("00:00").do(job)` は、毎日午前0時に `job` 関数を実行するようにスケジュールします。
*   `schedule.run_pending()` は、スケジュールされたジョブのうち、実行時間になったものを実行します。
*   `time.sleep(1)` は、1秒間待機します。

**AnkiConnectを使用した自動更新:**

AnkiConnectは、Ankiを外部プログラムから操作するためのAPIを提供します。これを使用すると、スクレイピングしたデータを直接Ankiにインポートしたり、既存のカードを更新したりできます。

1.  **AnkiConnectアドオンのインストール:** AnkiConnectアドオンをAnkiにインストールします。
2.  **Ankiの起動:** Ankiを起動し、AnkiConnectアドオンが有効になっていることを確認します。
3.  **Pythonスクリプト:** 以下のPythonスクリプトを使用して、Ankiを操作します。

```python
import json
import urllib.request

def invoke(action, version=6, params={}):
    """AnkiConnect APIを呼び出す関数"""
    requestJson = json.dumps({'action': action, 'version': version, 'params': params}).encode('utf-8')
    response = json.urlopen(urllib.request.Request('http://localhost:8765', requestJson)).read().decode('utf-8')
    return json.loads(response)

def update_card(card_id, front, back):
    """Ankiカードを更新する関数"""
    card = invoke('cardsInfo', params={'cards': [card_id]})[0]
    note_id = card['noteId']

    invoke(
        'updateNoteFields',
        params={
            'note': {
                'id': note_id,
                'fields': {
                    'Front': front,
                    'Back': back
                }
            }
        }
    )

# 例:
# update_card(1234567890, "更新された質問", "更新された答え")

def add_note(deck_name, model_name, front, back):
    """新しいAnkiノートを追加する関数"""
    invoke(
        "addNote",
        params={
            "note": {
                "deckName": deck_name,
                "modelName": model_name,
                "fields": {
                    "Front": front,
                    "Back": back,
                },
                "options": {
                    "allowDuplicate": False,
                    "duplicateScope": "deck",
                },
                "tags": [
                    "web_scraped"
                ]
            }
        }
    )


# 例:
# add_note("デフォルト", "基本", "新しい質問", "新しい答え")

def find_cards(query):
    """Ankiカードを検索する関数"""
    return invoke('findCards', params={'query': query})


# 例:
# card_ids = find_cards("deck:デフォルト tag:web_scraped")
# print(card_ids)
```

**AnkiConnectを使ったスクレイピングの自動化:**

1.  スクレイピングスクリプトを実行し、最新のデータを取得します。
2.  AnkiConnectを使用して、既存のカードを更新するか、新しいカードを追加します。
3.  `schedule`ライブラリを使用して、スクリプトを定期的に実行します。

*   **エラー処理:**  スクレイピング処理中にエラーが発生した場合に、プログラムが停止しないように、エラー処理を適切に行う必要があります。
*   **バックアップ:**  Ankiのデータを定期的にバックアップすることで、万が一の事態に備えることができます。

### Webサイトの変化に対応したスクレイピングロジックの構築

#### 概要と重要性

Webサイトの構造は予告なく変更されることがあり、スクレイピングロジックが突然機能しなくなることがあります。このセクションでは、Webサイトの変化に柔軟に対応できるスクレイピングロジックを構築するためのテクニックを解説します。

#### 特徴と利点

*   **ロバストなスクレイピング:** Webサイトの構造が変更されても、スクレイピング処理が停止する可能性を低減できます。
*   **メンテナンス性の向上:** スクレイピングロジックの変更が容易になるため、メンテナンスの手間を削減できます。
*   **信頼性の高いデータ収集:** 常に最新の情報を収集できるため、Ankiカードの信頼性を維持できます。

#### 事前準備と前提条件

*   **スクレイピングスクリプト:** これまで作成したスクレイピングスクリプト
*   **変更履歴の記録:** スクレイピング対象のWebサイトの過去のHTML構造の記録があると、変更点の特定に役立ちます。

#### 基本的な使い方

**CSSセレクタやXPathの柔軟な記述:**

CSSセレクタやXPathを記述する際に、特定の属性に依存しないように、より一般的な指定方法を使用します。

```python
# 悪い例:
# title = soup.find("h1", {"id": "firstHeading"}).text

# 良い例:
title = soup.find("h1").text # id属性に依存しない
```

**エラーハンドリングの徹底:**

要素が見つからない場合や、Webサイトの構造が変更された場合に備えて、try-exceptブロックを使用してエラーハンドリングを徹底します。

```python
try:
    title = soup.find("h1").text
except AttributeError:
    print("Error: タイトルが見つかりませんでした")
    title = "タイトル取得エラー"
```

**バックアップセレクタの利用:**

複数のCSSセレクタやXPathを定義しておき、最初のセレクタで要素が見つからなかった場合に、次のセレクタを試すようにします。

```python
selectors = [
    "h1#firstHeading",
    "h1.title",
    "h1"
]

title = None
for selector in selectors:
    element = soup.select_one(selector)
    if element:
        title = element.text
        break

if title:
    print(f"タイトル: {title}")
else:
    print("Error: タイトルが見つかりませんでした")
    title = "タイトル取得エラー"
```

**APIの利用:**

WebサイトがAPIを提供している場合は、スクレイピングではなくAPIを使用することを検討します。APIは、Webサイトの構造変更の影響を受けにくく、安定したデータ収集が可能です。

#### 実践的なテクニック

*   **Webサイトの変更監視:** Webサイトの変更を自動的に検知するツール（例：Versionista, ChangeTower）を利用することで、Webサイトの構造変更に迅速に対応できます。
*   **定期的なスクレイピングテスト:** 定期的にスクレイピングスクリプトを実行し、正常に動作することを確認します。
*   **スクレイピングルールのバージョン管理:** スクレイピングルール（CSSセレクタ、XPathなど）をバージョン管理システム（Gitなど）で管理することで、変更履歴を追跡し、問題が発生した場合にロールバックできます。
*   **機械学習の利用:** Webサイトの構造変化を予測するために、機械学習モデルを利用することを検討します。例えば、過去の変更履歴からパターンを学習し、将来の変更を予測することができます。

#### 応用例とユースケース

*   **オンラインショッピングサイトの価格監視:** オンラインショッピングサイトの価格を定期的にスクレイピングし、価格変動を検知した場合に通知を受け取るように設定します。
*   **不動産情報のスクレイピング:** 不動産情報サイトから物件情報を定期的にスクレイピングし、新しい物件が登録された場合に通知を受け取るように設定します。
*   **求人情報のスクレイピング:** 求人情報サイトから求人情報を定期的にスクレイピングし、希望する条件に合致する求人が掲載された場合に通知を受け取るように設定します。

#### トラブルシューティング

*   **スクレイピング処理が突然停止する:** Webサイトの構造が変更された可能性があります。Chrome DevToolsで要素を詳しく調べて、CSSセレクタやXPathを修正してください。
*   **データが正しく抽出されない:** Webサイトの構造が変更された可能性があります。抽出ロジックを見直してください。
*   **スクレイピングがブロックされる:** Webサイトがスクレイピングを禁止している可能性があります。robots.txtを確認し、スクレイピングポリシーに従ってください。User-Agentの設定や、アクセス頻度を調整することで、ブロックを回避できる場合があります。
