## 3章: AnkiConnect APIの基礎 - カード操作の第一歩

この章では、AnkiConnect APIを使ってAnkiのカードを操作するための基礎を学びます。AnkiConnect APIは、Ankiの機能を外部プログラムから利用するための強力なインターフェースです。このAPIを活用することで、Ankiの学習体験を自動化したり、他のアプリケーションと連携させたり、独自の学習システムを構築したりすることができます。

### APIの基本構造: リクエストとレスポンス

#### 概要と重要性

AnkiConnect APIは、JSON-RPC 2.0プロトコルに基づいたシンプルなリクエスト-レスポンス型のAPIです。クライアントはJSON形式のリクエストをAnkiConnectサーバーに送信し、サーバーは処理結果をJSON形式で返します。このシンプルさが、様々なプログラミング言語や環境での利用を容易にしています。APIの構造を理解することは、効率的なAnkiConnectプログラミングの第一歩です。

#### 特徴と利点

*   **JSONベース:** データ形式がJSONなので、多くのプログラミング言語で簡単に扱えます。
*   **HTTP経由:** HTTPプロトコルを使用するため、ファイアウォールやプロキシの設定に左右されにくいです。
*   **RESTfulではない:** RESTfulなAPIではありませんが、シンプルで予測可能な動作が可能です。
*   **バージョン管理:** AnkiConnect自体のバージョンアップにより、APIの仕様が変更されることがあります。常に最新のドキュメントを参照することが重要です。

#### 事前準備と前提条件

*   **Ankiのインストール:** 最新版のAnkiがインストールされている必要があります。
*   **AnkiConnectアドオンのインストール:** AnkiConnectアドオンをAnkiにインストールし、有効化する必要があります。アドオンはAnkiのAdd-onsメニューからインストールできます。（ツール -> アドオン -> アドオンをダウンロード）
*   **AnkiConnectの起動:** Ankiを起動すると、AnkiConnectが自動的に起動します。

#### 基本的な使い方

AnkiConnect APIとのやり取りは、HTTPリクエストを通じて行います。リクエストはJSON形式で、通常`Content-Type: application/json`ヘッダーを設定します。

**リクエストの例:**

```json
{
    "action": "version",
    "version": 6,
    "params": {}
}
```

*   `action`: 実行するAPIメソッドの名前。
*   `version`: 使用するAnkiConnect APIのバージョン。
*   `params`: メソッドに渡すパラメータ（辞書形式）。

**レスポンスの例:**

```json
{
    "result": 6,
    "error": null
}
```

*   `result`: APIメソッドの実行結果。
*   `error`: エラーが発生した場合、エラーメッセージが含まれます。成功時は`null`。

**Pythonでのリクエスト送信例:**

```python
import json
import urllib.request

def request(action, **params):
    return {'action': action, 'params': params, 'version': 6}

def invoke(action, **params):
    requestJson = json.dumps(request(action, **params)).encode('utf-8')
    try:
        response = json.load(urllib.request.urlopen(urllib.request.Request('http://localhost:8765', requestJson)))
    except Exception as e:
        print(e)
        return None
    if len(response) != 2:
        raise Exception('response has an unexpected number of fields')
    if 'error' not in response:
        raise Exception('response is missing required error field')
    if 'result' not in response:
        raise Exception('response is missing required result field')
    if response['error'] is not None:
        raise Exception(response['error'])
    return response['result']

# AnkiConnect APIのバージョンを取得
version = invoke('version')
print(f"AnkiConnect API version: {version}")

# デッキ一覧を取得
deck_names = invoke('deckNames')
print(f"Deck names: {deck_names}")
```

このコードは、AnkiConnect APIにリクエストを送信し、レスポンスを受け取るための基本的な関数`invoke`を定義しています。`version`アクションと`deckNames`アクションを呼び出し、AnkiConnectのバージョンとデッキの名前を取得しています。

#### 実践的なテクニック

*   **エラーハンドリング:** API呼び出しの結果は、必ず`error`フィールドを確認し、エラーが発生した場合は適切な処理を行うようにします。
*   **非同期処理:** 大量のデータを扱う場合は、API呼び出しを非同期で行うことで、Ankiの動作を妨げないようにします。
*   **APIドキュメントの参照:** AnkiConnectのAPIドキュメントは常に最新の情報を参照し、利用可能なメソッドやパラメータを確認するようにします。

#### 応用例とユースケース

*   **学習進捗の可視化:** Ankiの学習データを取得し、学習進捗をグラフで表示するダッシュボードを作成する。
*   **外部データとの連携:** 外部の辞書やデータベースからデータを取得し、Ankiのカードを自動生成する。
*   **カスタム学習システムの構築:** Ankiの学習アルゴリズムを応用し、独自の学習システムを構築する。

#### トラブルシューティング

*   **AnkiConnectが起動しない:** AnkiConnectアドオンが有効になっているか確認してください。Ankiを再起動することで解決することがあります。
*   **APIリクエストがタイムアウトする:** 大量のデータを扱う場合は、APIリクエストのタイムアウト時間を長く設定してください。
*   **エラーメッセージが理解できない:** AnkiConnectのAPIドキュメントを参照し、エラーメッセージの意味を確認してください。

*   **データ分析の基盤:** 取得したデータを分析することで、学習状況の把握や改善に役立てられます。

#### 事前準備と前提条件

*   **AnkiConnect APIの基本理解:** 前のセクションで説明したAPIの基本構造を理解している必要があります。

#### 基本的な使い方

AnkiConnect APIを使用してコレクションの情報を取得するには、様々なAPIメソッドを利用します。例えば、`deckNames`メソッドでデッキの名前一覧を取得できます。

**コレクション情報の取得例:**

```python
import json
import urllib.request

def request(action, **params):
    return {'action': action, 'params': params, 'version': 6}

def invoke(action, **params):
    requestJson = json.dumps(request(action, **params)).encode('utf-8')
    try:
        response = json.load(urllib.request.urlopen(urllib.request.Request('http://localhost:8765', requestJson)))
    except Exception as e:
        print(e)
        return None
    if len(response) != 2:
        raise Exception('response has an unexpected number of fields')
    if 'error' not in response:
        raise Exception('response is missing required error field')
    if 'result' not in response:
        raise Exception('response is missing required result field')
    if response['error'] is not None:
        raise Exception(response['error'])
    return response['result']

# デッキ一覧を取得
deck_names = invoke('deckNames')
print(f"Deck names: {deck_names}")

# デッキの統計情報を取得
deck_stats = invoke('deckStats', decks=deck_names)
print(f"Deck stats: {deck_stats}")

# カードの情報を取得 (例: カードID 1234567890123 の情報)
try:
    card_info = invoke('cardsInfo', cards=[1234567890123])
    print(f"Card info: {card_info}")
except Exception as e:
    print(f"Card info could not be retrieved: {e}")
```

このコードでは、`deckNames`メソッドでデッキの名前一覧を取得し、`deckStats`メソッドで各デッキの統計情報を取得しています。また、`cardsInfo`で特定のカードの情報を取得しています。存在しないカードIDを指定した場合、エラーが発生するので、try-exceptブロックで例外処理を行っています。

#### 実践的なテクニック

*   **データ構造の理解:** APIから返されるデータは、ネストされた辞書やリストで構成されています。データ構造を理解し、必要な情報にアクセスできるようにします。
*   **データのフィルタリング:** 大量のデータの中から、特定の条件に合致するデータのみを抽出します。
*   **データの変換:** 取得したデータを、使いやすい形式に変換します。例えば、日付を文字列からdatetimeオブジェクトに変換するなど。

#### 応用例とユースケース

*   **学習データの分析:** 学習履歴を分析し、苦手な分野を特定する。
*   **学習計画の最適化:** 学習状況に応じて、学習計画を自動的に調整する。
*   **カードの自動整理:** カードの復習間隔や正答率に応じて、デッキを自動的に整理する。

#### トラブルシューティング

*   **APIレスポンスが遅い:** 大量のデータを扱う場合は、APIレスポンスが遅くなることがあります。API呼び出しを非同期で行うか、データの取得範囲を絞ることを検討してください。
*   **APIレスポンスが空:** APIリクエストのパラメータが正しいか確認してください。また、AnkiConnectのAPIドキュメントを参照し、パラメータの仕様を確認してください。

#### 概要と重要性

Ankiのデッキは、学習するカードを整理するための基本的な単位です。AnkiConnect APIを使用してデッキを操作することで、Ankiの学習環境をプログラムから制御できます。

*   **デッキの自動作成:** 大量のカードを効率的に管理するために、デッキを自動的に作成できます。
*   **デッキの自動整理:** 学習状況に応じて、デッキを自動的に整理できます。
*   **デッキのリネーム:** デッキ名を一括で変更できます。

#### 事前準備と前提条件

*   **AnkiConnect APIの基本理解:** 前のセクションで説明したAPIの基本構造を理解している必要があります。
*   **Python環境の準備:** このセクションのコード例はPythonで記述されています。Pythonの実行環境を準備してください。

#### 基本的な使い方

AnkiConnect APIを使用してデッキを作成、削除、名前変更するには、対応するAPIメソッドを利用します。

**デッキ操作の例:**

```python
import json
import urllib.request

def request(action, **params):
    return {'action': action, 'params': params, 'version': 6}

def invoke(action, **params):
    requestJson = json.dumps(request(action, **params)).encode('utf-8')
    try:
        response = json.load(urllib.request.urlopen(urllib.request.Request('http://localhost:8765', requestJson)))
    except Exception as e:
        print(e)
        return None
    if len(response) != 2:
        raise Exception('response has an unexpected number of fields')
    if 'error' not in response:
        raise Exception('response is missing required error field')
    if 'result' not in response:
        raise Exception('response is missing required result field')
    if response['error'] is not None:
        raise Exception(response['error'])
    return response['result']

# 新しいデッキを作成
new_deck_name = "新しいデッキ"
try:
    invoke('createDeck', deck=new_deck_name)
    print(f"デッキ '{new_deck_name}' を作成しました。")
except Exception as e:
    print(f"デッキの作成に失敗しました: {e}")

# デッキの名前を変更
old_deck_name = "新しいデッキ"
new_deck_name = "リネーム後のデッキ"
try:
    invoke('renameDeck', oldName=old_deck_name, newName=new_deck_name)
    print(f"デッキ '{old_deck_name}' を '{new_deck_name}' に変更しました。")
except Exception as e:
    print(f"デッキの名前変更に失敗しました: {e}")

# デッキを削除
deck_to_delete = "リネーム後のデッキ"
try:
    invoke('deleteDecks', decks=[deck_to_delete], cardsToo=False) # cardsToo=Trueにするとカードも削除
    print(f"デッキ '{deck_to_delete}' を削除しました。")
except Exception as e:
    print(f"デッキの削除に失敗しました: {e}")

```

このコードでは、`createDeck`メソッドで新しいデッキを作成し、`renameDeck`メソッドでデッキの名前を変更し、`deleteDecks`メソッドでデッキを削除しています。`deleteDecks`の`cardsToo`パラメータを`True`にすると、デッキ内のカードも一緒に削除されます。

#### 実践的なテクニック

*   **デッキ名の命名規則:** デッキ名を階層構造にすることで、カードの整理が容易になります。例えば、"言語::英語::単語" のように、コロン（::）で区切って階層を表すことができます。
*   **デッキのバックアップ:** デッキを削除する前に、バックアップを作成することを推奨します。

#### 応用例とユースケース

*   **教材ごとのデッキ作成:** 新しい教材を学習する際に、教材ごとにデッキを自動的に作成する。
*   **復習間隔に応じたデッキ整理:** カードの復習間隔に応じて、デッキを自動的に整理する。
*   **共有デッキの作成:** 特定のテーマに関するカードを集めた共有デッキを作成する。

#### トラブルシューティング

*   **デッキの作成に失敗する:** デッキ名が既に存在するか確認してください。また、デッキ名に特殊文字が含まれていないか確認してください。
*   **デッキの削除に失敗する:** デッキが存在するか確認してください。また、デッキが他のデッキの子デッキになっていないか確認してください。

#### 概要と重要性

#### 基本的な使い方

AnkiConnect APIを使用してカードを検索、追加、編集、削除するには、対応するAPIメソッドを利用します。

**カード操作の例:**

```python
import json
import urllib.request

def request(action, **params):
    return {'action': action, 'params': params, 'version': 6}

def invoke(action, **params):
    requestJson = json.dumps(request(action, **params)).encode('utf-8')
    try:
        response = json.load(urllib.request.urlopen(urllib.request.Request('http://localhost:8765', requestJson)))
    except Exception as e:
        print(e)
        return None
    if len(response) != 2:
        raise Exception('response has an unexpected number of fields')
    if 'error' not in response:
        raise Exception('response is missing required error field')
    if 'result' not in response:
        raise Exception('response is missing required result field')
    if response['error'] is not None:
        raise Exception(response['error'])
    return response['result']

# カードを追加
note = {
    "deckName": "Default",
    "modelName": "Basic",
    "fields": {
        "Front": "質問",
        "Back": "答え"
    },
    "options": {
        "allowDuplicate": False,
        "duplicateScope": "deck"
    },
    "tags": [
        "AnkiConnect",
        "API"
    ]
}
try:
    note_id = invoke('addNote', note=note)
    print(f"カードを作成しました。Note ID: {note_id}")
except Exception as e:
    print(f"カードの作成に失敗しました: {e}")

# カードを検索
try:
    card_ids = invoke('findCards', query='deck:Default "質問"')
    print(f"カードが見つかりました。Card IDs: {card_ids}")

    # 検索結果が空でなければ最初のカードIDを取得
    if card_ids:
        card_id = card_ids[0]

        # カードの情報を取得
        card_info = invoke('cardsInfo', cards=[card_id])
        print(f"カードの情報: {card_info}")

        # カードを編集
        card_info[0]['fields']['Front']['value'] = "新しい質問"
        card_info[0]['fields']['Back']['value'] = "新しい答え"

        # Update the card using updateNoteFields
        fields_update = {
            'id': card_info[0]['noteId'], # Note IDが必要です
            'fields': {
                'Front': "新しい質問",
                'Back': "新しい答え"
            }
        }
        invoke('updateNoteFields', note=fields_update)

        print(f"カード {card_id} を編集しました。")

        # カードを削除
        #invoke('deleteCards', cards=[card_id])
        #print(f"カード {card_id} を削除しました。")

    else:
        print("検索条件に一致するカードは見つかりませんでした。")

except Exception as e:
    print(f"カードの検索または編集に失敗しました: {e}")


```

このコードでは、`addNote`メソッドで新しいカードを追加し、`findCards`メソッドでカードを検索しています。そして`cardsInfo`でカードの情報を取得し、`updateNoteFields`メソッドでカードの内容を編集しています。コメントアウトしている`deleteCards`メソッドでカードを削除できます。
