## 2章: 開発環境構築 - 準備を整える

この章では、Anki連携アプリケーション開発に必要な環境を構築します。AnkiConnectを介してAnkiのデータにアクセスし、Pythonを使って様々な処理を行うための基盤を整備します。Ankiの可能性を最大限に引き出すための第一歩として、丁寧に環境構築を進めていきましょう。

### Python環境構築 (Anaconda/venv)

**概要と重要性**

Pythonは、AnkiConnectと連携するアプリケーションを開発するための主要なプログラミング言語です。しかし、プロジェクトごとに必要なライブラリやバージョンが異なる場合がよくあります。そのため、プロジェクトごとに独立したPython環境を用意することが重要です。Anacondaまたはvenvを使うことで、プロジェクトごとに必要なライブラリを管理し、依存関係による問題を回避できます。

**特徴と利点**

*   **Anaconda:** データサイエンスに特化したディストリビューションであり、必要なライブラリが最初から多く含まれています。初心者にとって導入が容易で、環境管理ツールであるcondaを使って複数の環境を簡単に切り替えられます。

*   **venv:** Pythonに標準で付属している仮想環境構築ツールです。軽量でシンプルであり、AnacondaをインストールせずにPythonの標準機能だけで環境を構築できます。

**事前準備と前提条件**

*   **Anaconda:** Anacondaの公式サイト([https://www.anaconda.com/](https://www.anaconda.com/))からインストーラをダウンロードし、インストールしてください。
*   **venv:** Python 3.3以降がインストールされている必要があります。Pythonがインストールされていない場合は、Pythonの公式サイト([https://www.python.org/](https://www.python.org/))からインストールしてください。

**基本的な使い方**

**Anacondaの場合:**

1.  **環境の作成:**
    ```bash
    conda create -n ankiconnect_env python=3.9 # pythonのバージョンは任意
    ```
    このコマンドは、`ankiconnect_env`という名前の新しい環境を作成し、Python 3.9をインストールします。

2.  **環境の有効化:**
    ```bash
    conda activate ankiconnect_env
    ```
    このコマンドで、作成した環境を有効化します。ターミナルのプロンプトが `(ankiconnect_env)` のように変化したら成功です。

3.  **環境の無効化:**
    ```bash
    conda deactivate
    ```
    このコマンドで、環境を無効化します。

**venvの場合:**

1.  **仮想環境の作成:**
    ```bash
    python3 -m venv ankiconnect_env
    ```
    このコマンドは、現在のディレクトリに `ankiconnect_env` という名前の仮想環境を作成します。

2.  **仮想環境の有効化:**
    *   **Windows:**
        ```bash
        .\ankiconnect_env\Scripts\activate
        ```
    *   **macOS/Linux:**
        ```bash
        source ankiconnect_env/bin/activate
        ```
    環境が有効になると、ターミナルのプロンプトが `(ankiconnect_env)` のように変化します。

3.  **仮想環境の無効化:**
    ```bash
    deactivate
    ```

**実践的なテクニック**

*   **環境の依存関係を管理:** 環境を作成したら、`pip`または`conda`を使って必要なライブラリをインストールします。
    ```bash
    pip install requests pandas
    ```
    インストールしたライブラリとそのバージョンを記録するために、`requirements.txt`ファイルを作成することをおすすめします。
    ```bash
    pip freeze > requirements.txt
    ```
    他の環境で同じライブラリをインストールするには、以下のコマンドを実行します。
    ```bash
    pip install -r requirements.txt
    ```

*   **環境の共有:** 他の人と協力して開発する場合、環境を共有することが重要です。Anacondaの場合、環境をYAMLファイルとしてエクスポートできます。
    ```bash
    conda env export > environment.yml
    ```
    他の人は、このYAMLファイルから環境を再構築できます。
    ```bash
    conda env create -f environment.yml
    ```

**応用例とユースケース**

*   **複数のAnki連携アプリケーション開発:** 複数のAnki連携アプリケーションを開発する場合、それぞれのアプリケーションごとに独立した環境を作成することで、ライブラリのバージョン衝突を避けることができます。
*   **異なるバージョンのAnkiConnectに対応:** AnkiConnectのバージョンが異なる場合、それぞれのバージョンに対応した環境を作成することで、互換性の問題を回避できます。

**トラブルシューティング**

*   **`conda` コマンドが見つからない:** Anacondaが正しくインストールされているか確認してください。環境変数の設定が正しいかも確認してください。
*   **仮想環境が有効にならない:** コマンドを正しく入力しているか確認してください。特に、Windowsの場合は、パスが正しいか確認してください。
*   **ライブラリのインストールに失敗する:** インターネット接続が安定しているか確認してください。`pip`または`conda`のバージョンが最新であるか確認してください。

### AnkiConnectのインストールと設定

**概要と重要性**

AnkiConnectは、AnkiのAPIとして機能し、外部のアプリケーションからAnkiのデータにアクセスしたり、操作したりすることを可能にします。Anki連携アプリケーションを開発する上で、AnkiConnectは不可欠なコンポーネントです。AnkiConnectをインストールし、設定することで、PythonからAnkiのデータにアクセスし、カードの追加、編集、削除などの操作を行うことができます。

**特徴と利点**

*   **Ankiとの連携:** AnkiConnectは、Ankiと外部アプリケーション間の橋渡し役として機能します。
*   **豊富なAPI:** AnkiConnectは、Ankiの様々な機能にアクセスするための豊富なAPIを提供します。
*   **クロスプラットフォーム対応:** AnkiConnectは、Windows、macOS、Linuxなどの様々なプラットフォームで動作します。

**事前準備と前提条件**

*   Ankiがインストールされている必要があります。Ankiの公式サイト([https://apps.ankiweb.net/](https://apps.ankiweb.net/))からダウンロードし、インストールしてください。
*   前述のPython環境構築が完了している必要があります。

**基本的な使い方**

1.  **AnkiConnectアドオンのインストール:** Ankiを起動し、`ツール` -> `アドオン` -> `アドオンを入手` を選択します。
2.  表示されたダイアログに、AnkiConnectのアドオンコードを入力します。AnkiConnectのアドオンコードは **2055492159** です。
3.  `OK` をクリックすると、AnkiConnectアドオンがインストールされます。
4.  Ankiを再起動します。

**設定**

AnkiConnectの設定は、Ankiの `ツール` -> `アドオン` -> `AnkiConnect` -> `設定` から行えます。設定ファイルはJSON形式で記述されており、以下の項目を設定できます。

*   **port:** AnkiConnectがリッスンするポート番号。デフォルトは8765です。
*   **webBindAddress:** AnkiConnectがバインドするIPアドレス。デフォルトは127.0.0.1（ローカルホスト）です。
*   **apiKey:** AnkiConnectへのアクセスを認証するためのAPIキー。セキュリティのために設定することを推奨します。

```json
{
    "port": 8765,
    "webBindAddress": "127.0.0.1",
    "apiKey": "your_secret_api_key"
}
```

**実践的なテクニック**

*   **APIキーの設定:** セキュリティのために、必ずAPIキーを設定してください。APIキーを設定すると、AnkiConnectへのアクセスを認証する必要があります。
*   **ポート番号の変更:** デフォルトのポート番号である8765が他のアプリケーションで使用されている場合は、別のポート番号に変更してください。
*   **IPアドレスの変更:** リモートからAnkiConnectにアクセスする場合は、`webBindAddress` を 0.0.0.0 に設定してください。ただし、セキュリティ上のリスクがあるため、APIキーを必ず設定してください。

**応用例とユースケース**

*   **Ankiの自動化:** Pythonスクリプトを使って、Ankiのカードの追加、編集、削除などの操作を自動化できます。
*   **外部データソースとの連携:** 外部のデータソース（例えば、Webサイトやデータベース）からデータを取得し、Ankiのカードに自動的に追加できます。
*   **Ankiの学習支援ツール開発:** Ankiの学習データを分析し、学習効果を高めるためのツールを開発できます。

**Pythonコード例 (requestsライブラリを使用):**

```python
import requests
import json

def invoke(action, version=6, params={}):
    requestJson = json.dumps({'action': action, 'version': version, 'params': params})
    try:
        response = requests.post('http://127.0.0.1:8765', data=requestJson).json()
        if len(response) != 2:
            raise Exception('response has an unexpected number of fields')
        if 'error' not in response:
            raise Exception('response is missing required error field')
        if 'result' not in response:
            raise Exception('response is missing required result field')
        if response['error'] is not None:
            raise Exception(response['error'])
        return response['result']
    except Exception as e:
        print(f"Error: {e}")
        return None

# デッキの一覧を取得
deck_names = invoke('deckNames')
if deck_names:
    print("デッキの一覧:")
    for deck_name in deck_names:
        print(f"- {deck_name}")

# 新しいノートを作成 (基本的な例)
note = {
    "deckName": "Default", # デフォルトのデッキ名
    "modelName": "Basic",  # 基本的なノートタイプ
    "fields": {
        "Front": "これはAnkiConnectを使って追加されたカードの表側です。",
        "Back": "これはAnkiConnectを使って追加されたカードの裏側です。"
    },
    "options": {
        "allowDuplicate": False, # 重複を許可しない
        "duplicateScope": "deck"  # デッキ内での重複チェック
    },
    "tags": ["AnkiConnect", "Python"] # タグの追加
}

result = invoke("addNote", params={"note": note})

if result:
    print(f"ノートが追加されました。ノートID: {result}")
else:
    print("ノートの追加に失敗しました。")
```

**トラブルシューティング**

*   **AnkiConnectが起動しない:** Ankiが正しくインストールされているか確認してください。AnkiConnectアドオンが有効になっているか確認してください。
*   **AnkiConnectに接続できない:** ポート番号が正しいか確認してください。IPアドレスが正しいか確認してください。ファイアウォールがAnkiConnectへのアクセスをブロックしていないか確認してください。APIキーが設定されている場合は、APIキーを正しく指定しているか確認してください。
*   **エラーメッセージが表示される:** エラーメッセージをよく読んで、原因を特定してください。AnkiConnectのドキュメント([https://github.com/FooSoft/anki-connect](https://github.com/FooSoft/anki-connect))を参照してください。

```python
import pandas as pd
import requests
import json

def invoke(action, version=6, params={}):
  # (以前のinvoke関数)

  requestJson = json.dumps({'action': action, 'version': version, 'params': params})
  try:
      response = requests.post('http://127.0.0.1:8765', data=requestJson).json()
      if len(response) != 2:
          raise Exception('response has an unexpected number of fields')
      if 'error' not in response:
          raise Exception('response is missing required error field')
      if 'result' not in response:
          raise Exception('response is missing required result field')
      if response['error'] is not None:
          raise Exception(response['error'])
      return response['result']
  except Exception as e:
      print(f"Error: {e}")
      return None


# すべてのノートを取得 (非常に大規模なデッキでは注意)
all_notes = invoke("findNotes", params={"query": ""})

if all_notes:
    note_info_list = []
    for note_id in all_notes:
        note_info = invoke("notesInfo", params={"notes": [note_id]})
        if note_info:
            note_info_list.append(note_info[0]) # notesInfoはリストを返す

    # pandas DataFrameを作成
    df = pd.DataFrame(note_info_list)

    # CSVファイルに書き出し
    df.to_csv("anki_notes.csv", index=False)
    print("Ankiノートをanki_notes.csvにエクスポートしました。")
else:
    print("ノートの取得に失敗しました。")
```
