## 16章: AnkiConnectアドオンの開発 - 機能拡張で学習をさらに便利に

Ankiは強力なフラッシュカード学習ツールですが、その真価はアドオンによる拡張性にあります。AnkiConnectアドオンはその拡張性をさらに高め、Ankiを外部アプリケーションやスクリプトと連携させることを可能にします。この章では、AnkiConnectを利用したアドオン開発の基礎から応用までを解説し、あなたの学習体験をさらに向上させるための知識とスキルを提供します。

### アドオンの基本構造

**概要と重要性**

Ankiアドオンは、Ankiの機能を拡張するためのPythonスクリプトです。シンプルなものから複雑なものまで、様々なアドオンが存在し、あなたの学習ニーズに合わせてカスタマイズできます。アドオン開発の基本を理解することで、既存のアドオンを改良したり、自分だけのオリジナルアドオンを作成したりすることが可能になります。

**特徴と利点**

*   Ankiの機能を自由に拡張できる
*   学習プロセスを自動化できる
*   他のアプリケーションとの連携が可能になる
*   コミュニティに貢献できる

**事前準備と前提条件**

*   Ankiのインストール (最新版推奨)
*   Pythonの基本的な知識 (変数、関数、条件分岐など)
*   テキストエディタ (VS Code, Sublime Textなど)

**基本的な使い方**

Ankiアドオンの基本的な構造は、以下の通りです。

```python
# -*- coding: utf-8 -*-

from aqt import mw
from aqt.utils import showInfo

def test_function():
    showInfo("Hello, Anki addon!")

# メニューに追加
action = aqt.qt.QAction("Test Addon", mw)
action.triggered.connect(test_function)
mw.form.menuTools.addAction(action)
```

このコードは、Ankiのツールメニューに「Test Addon」という項目を追加し、クリックすると「Hello, Anki addon!」というメッセージを表示する簡単なアドオンです。

**構成要素の説明:**

*   `# -*- coding: utf-8 -*-`:  文字コードの指定。日本語など非ASCII文字を扱う場合に重要。
*   `from aqt import mw`:  Ankiのメインウィンドウへのアクセスを提供する`mw`オブジェクトをインポート。
*   `from aqt.utils import showInfo`:  メッセージボックスを表示する関数をインポート。
*   `def test_function():`:  アドオンが実行する処理を定義する関数。
*   `showInfo("Hello, Anki addon!")`:  メッセージボックスに文字列を表示する。
*   `action = aqt.qt.QAction("Test Addon", mw)`:  メニュー項目を作成。
*   `action.triggered.connect(test_function)`:  メニュー項目がクリックされたときの処理を`test_function`に接続。
*   `mw.form.menuTools.addAction(action)`:  メニュー項目をAnkiのツールメニューに追加。

**アドオンの配置:**

1.  Ankiを終了します。
2.  Ankiのデータフォルダを開きます (ツール -> アドオン -> ファイルを表示)。
3.  `addons21`フォルダ (Anki 2.1の場合) または `addons` フォルダ（古いバージョン）を作成します。
4.  上記のコードを `test_addon.py` という名前で保存し、`addons21` フォルダに配置します。
5.  Ankiを再起動します。

ツールメニューに「Test Addon」が表示され、クリックするとメッセージが表示されることを確認してください。

**実践的なテクニック**

*   AnkiのAPIドキュメントを参考に、様々な機能を利用する
*   他のアドオンのソースコードを参考に、実装方法を学ぶ
*   エラーメッセージを丁寧に読み、原因を特定する
*   print文やloggingモジュールを使って、デバッグを行う

**応用例とユースケース**

*   特定のノートタイプに対して、自動的にタグを付与する
*   外部のAPIからデータを取得し、カードに追加する
*   カードの統計情報を分析し、学習プランを最適化する

**トラブルシューティング**

*   アドオンが動作しない場合:
    *   Ankiのバージョンがアドオンに対応しているか確認する
    *   エラーメッセージを確認し、原因を特定する
    *   他のアドオンとの競合がないか確認する
*   文字化けが発生する場合:
    *   ファイルの文字コードがUTF-8になっているか確認する

### AnkiConnectとの連携

**概要と重要性**

AnkiConnectは、Ankiを外部のアプリケーションやスクリプトから操作するためのAPIを提供するアドオンです。AnkiConnectを利用することで、Python、JavaScript、その他の言語からAnkiのカードの追加、編集、削除など、様々な操作を行うことができます。

**特徴と利点**

*   Ankiを外部アプリケーションから操作できる
*   学習プロセスを自動化できる
*   Webアプリケーションやモバイルアプリケーションと連携できる

**事前準備と前提条件**

*   AnkiConnectアドオンのインストール (Ankiからインストール可能)
*   Pythonのrequestsライブラリのインストール (`pip install requests`)
*   JSONの基本的な知識

**基本的な使い方**

AnkiConnectへのリクエストは、JSON形式で行います。以下の例は、Pythonのrequestsライブラリを使って、Ankiに新しいカードを追加する例です。

```python
import requests
import json

def add_note(deck_name, model_name, fields, tags):
    url = 'http://127.0.0.1:8765'
    headers = {'Content-Type': 'application/json'}
    data = {
        "action": "addNote",
        "version": 6,
        "params": {
            "note": {
                "deckName": deck_name,
                "modelName": model_name,
                "fields": fields,
                "options": {
                    "allowDuplicate": False,
                    "duplicateScope": "deck"
                },
                "tags": tags
            }
        }
    }
    response = requests.post(url, data=json.dumps(data), headers=headers)
    return response.json()

# 例: 新しいカードを追加
result = add_note(
    deck_name="Default",
    model_name="Basic",
    fields={"Front": "What is the capital of France?", "Back": "Paris"},
    tags=["geography"]
)

print(result)

```

**コードの説明:**

1.  **`import requests` と `import json`**:  必要なライブラリをインポートします。`requests`はHTTPリクエストを送信するために、`json`はJSON形式のデータを扱うために使用します。
2.  **`def add_note(...)`**:  Ankiに新しいカードを追加する関数を定義します。
3.  **`url = 'http://127.0.0.1:8765'`**: AnkiConnectがリッスンしているURL。デフォルトは `http://127.0.0.1:8765` です。
4.  **`headers = {'Content-Type': 'application/json'}`**: HTTPリクエストのヘッダーを設定します。Content-Typeを`application/json`に設定することで、JSON形式のデータを送信することをサーバーに伝えます。
5.  **`data = {...}`**:  AnkiConnectに送信するJSONデータを定義します。
    *   `"action": "addNote"`:  実行するアクションを指定します。ここでは新しいカードを追加する`addNote`アクションを指定しています。
    *   `"version": 6`: AnkiConnectのAPIバージョンを指定します。
    *   `"params": {...}`:  アクションに必要なパラメータを指定します。
        *   `"note": {...}`:  追加するカードの情報を指定します。
            *   `"deckName": deck_name`:  カードを追加するデッキの名前。
            *   `"modelName": model_name`:  カードのモデル（ノートタイプ）の名前。
            *   `"fields": fields`:  カードのフィールドの内容。辞書形式で指定します。
            *   `"options": {...}`:  カードの追加オプション。
                *   `"allowDuplicate": False`:  重複を許可するかどうか。
                *   `"duplicateScope": "deck"`: 重複チェックの範囲。
            *   `"tags": tags`:  カードに付与するタグのリスト。
6.  **`response = requests.post(url, data=json.dumps(data), headers=headers)`**:  HTTP POSTリクエストをAnkiConnectに送信します。`json.dumps(data)`でPythonの辞書をJSON形式の文字列に変換します。
7.  **`return response.json()`**:  AnkiConnectからのレスポンスをJSON形式で返します。

**JSONリクエストの構造:**

*   `action`: 実行するAnkiConnectのAPIアクション (例: `addNote`, `findNotes`, `cardsInfo`)
*   `version`: AnkiConnect APIのバージョン (通常は6)
*   `params`: アクションに必要なパラメータ (アクションによって異なる)

**実践的なテクニック**

*   AnkiConnectのAPIドキュメントを参照し、利用可能なアクションを把握する
*   AnkiConnectのサンプルコードを参考に、実装方法を学ぶ
*   エラーレスポンスを解析し、原因を特定する
*   複数のアクションを組み合わせて、複雑な処理を実現する

**応用例とユースケース**

*   テキストファイルからカードを自動的に生成するスクリプトを作成する
*   Webサイトから情報を取得し、Ankiにカードとして追加する
*   スプレッドシートのデータをAnkiにインポートする
*   音声ファイルを自動的にカードに追加する

**トラブルシューティング**

*   AnkiConnectが動作しない場合:
    *   AnkiConnectアドオンが有効になっているか確認する
    *   AnkiConnectの設定を確認し、ポート番号が正しいか確認する
    *   ファイアウォールがAnkiConnectへのアクセスをブロックしていないか確認する
*   エラーレスポンスが返ってくる場合:
    *   リクエストのJSON形式が正しいか確認する
    *   必要なパラメータが全て含まれているか確認する
    *   AnkiConnectのAPIドキュメントを参照し、エラーコードの意味を確認する

### GUI (Qt) を用いたアドオン開発

**概要と重要性**

Ankiのアドオンは、シンプルな機能であればPythonスクリプトだけで実装できますが、より複雑な機能やユーザーインターフェースが必要な場合は、Qtフレームワークを利用することが推奨されます。Qtは、クロスプラットフォームなGUIアプリケーションを開発するための強力なフレームワークであり、Ankiのアドオン開発においても広く利用されています。

**特徴と利点**

*   洗練されたユーザーインターフェースを開発できる
*   クロスプラットフォーム対応 (Windows, macOS, Linux)
*   豊富なウィジェットとレイアウトマネージャーを利用できる
*   AnkiのGUIとシームレスに統合できる

**事前準備と前提条件**

*   Qt Designerのインストール (PyQtまたはPySideに含まれる)
*   PyQtまたはPySideのインストール (`pip install PyQt5` または `pip install PySide2`)
*   Qtの基本的な知識 (ウィジェット、レイアウト、シグナルとスロット)

**基本的な使い方**

Qt Designerを使ってGUIを作成し、PythonコードでそのGUIをAnkiのアドオンに組み込む手順を説明します。

1.  **Qt DesignerでGUIを作成:**

    *   Qt Designerを起動し、新しいウィンドウを作成します。
    *   ウィジェット (ボタン、テキストボックス、ラベルなど) を配置し、レイアウトを調整します。
    *   ウィジェットのプロパティ (テキスト、フォント、色など) を設定します。
    *   作成したGUIを `.ui` ファイルとして保存します (例: `my_dialog.ui`)。

2.  **PythonコードでGUIをロード:**

    ```python
    from aqt import mw
    from aqt.qt import *
    from aqt.utils import showInfo

    class MyDialog(QDialog):
        def __init__(self, parent=None):
            super().__init__(parent)
            # UIファイルをロード
            uifile = os.path.join(os.path.dirname(__file__), "my_dialog.ui")
            loadUi(uifile, self)
            # ボタンがクリックされたときの処理を接続
            self.pushButton.clicked.connect(self.on_button_clicked)

        def on_button_clicked(self):
            showInfo("Button clicked!")

    def show_dialog():
        dialog = MyDialog(mw)
        dialog.exec_()

    # メニューに追加
    action = QAction("Show My Dialog", mw)
    action.triggered.connect(show_dialog)
    mw.form.menuTools.addAction(action)
    ```

    **コードの説明:**

    *   `from aqt.qt import *`:  Qt関連のクラスをインポートします。
    *   `from aqt.utils import showInfo`:  メッセージボックスを表示する関数をインポートします。
    *   `class MyDialog(QDialog)`:  Qtのダイアログクラスを継承したカスタムダイアログクラスを定義します。
    *   `uifile = os.path.join(os.path.dirname(__file__), "my_dialog.ui")`:  UIファイルのパスを生成します。`os.path.dirname(__file__)`は、アドオンのディレクトリを取得します。
    *   `loadUi(uifile, self)`:  UIファイルをロードし、ダイアログに適用します。
    *   `self.pushButton.clicked.connect(self.on_button_clicked)`:  ボタンのクリックシグナルを`on_button_clicked`メソッドに接続します。
    *   `def on_button_clicked(self)`:  ボタンがクリックされたときに実行される処理を定義します。ここではメッセージボックスを表示します。
    *   `def show_dialog()`:  ダイアログを表示する関数を定義します。
    *   `dialog = MyDialog(mw)`:  カスタムダイアログを作成し、親ウィンドウをAnkiのメインウィンドウに設定します。
    *   `dialog.exec_()`:  ダイアログを表示します。`exec_()`は、ダイアログが閉じられるまで処理をブロックします。
    *   `action = QAction("Show My Dialog", mw)`:  メニュー項目を作成します。
    *   `action.triggered.connect(show_dialog)`:  メニュー項目がクリックされたときに`show_dialog`関数を実行するように接続します。
    *   `mw.form.menuTools.addAction(action)`:  メニュー項目をAnkiのツールメニューに追加します。

3.  **アドオンの配置:**

    *   `my_dialog.ui` ファイルと Pythonスクリプト (例: `my_addon.py`) を同じディレクトリに配置します。
    *   アドオンディレクトリ ( `addons21` ) にディレクトリごと配置します (例: `addons21/my_addon/my_addon.py`, `addons21/my_addon/my_dialog.ui`)。
    *   Ankiを再起動します。

ツールメニューに「Show My Dialog」が表示され、クリックすると作成したダイアログが表示されることを確認してください。

**実践的なテクニック**

*   Qtのシグナルとスロットの仕組みを理解し、ウィジェット間の連携を実装する
*   Qtのレイアウトマネージャーを使いこなし、柔軟なGUIを作成する
*   Qtのスタイルシートを使って、GUIの見た目をカスタマイズする
*   AnkiのAPIとQtのGUIを連携させ、高度な機能を実現する

**応用例とユースケース**

*   学習の進捗状況を可視化する

**トラブルシューティング**

*   GUIが表示されない場合:
    *   `.ui` ファイルのパスが正しいか確認する

*   ウィジェットが正しく動作しない場合:
    *   シグナルとスロットの接続が正しいか確認する
    *   ウィジェットのプロパティが正しく設定されているか確認する

### アドオンの配布と共有

**概要と重要性**

せっかく作成したアドオンは、他のAnkiユーザーと共有することで、より多くの人に役立ててもらうことができます。アドオンを配布・共有することで、コミュニティに貢献し、自身の開発スキルを向上させることができます。

**特徴と利点**

*   他のAnkiユーザーにアドオンを利用してもらえる
*   コミュニティからのフィードバックを得られる
*   自身の開発スキルを向上させられる

**事前準備と前提条件**

*   GitHubアカウント (推奨)
*   アドオンのソースコード
*   アドオンの説明文 (日本語と英語)
*   アドオンのアイコン (推奨)

**基本的な使い方**

アドオンを配布する方法はいくつかありますが、ここでは最も一般的な方法である、GitHubを利用した配布方法を説明します。

1.  **GitHubリポジトリを作成:**

    *   GitHubにログインし、新しいリポジトリを作成します。
    *   リポジトリ名は、アドオンの名前を参考に、わかりやすい名前をつけます (例: `anki-my-addon`)。
    *   リポジトリの説明文を入力します。
    *   リポジトリを公開 (Public) に設定します。
    *   `.gitignore` ファイルを作成し、`.DS_Store`, `*.pyc` などの不要なファイルを無視するように設定します。

2.  **アドオンのソースコードをアップロード:**

    *   作成したGitHubリポジトリに、アドオンのソースコードをアップロードします。
    *   アドオンのディレクトリ構成を維持するようにアップロードします (例: `addons21/my_addon/my_addon.py`, `addons21/my_addon/my_dialog.ui`)。

3.  **アドオンの説明文を作成:**

    *   アドオンの使い方、機能、注意点などを説明するドキュメントを作成します。
    *   日本語と英語の両方の説明文を作成することを推奨します。
    *   GitHubリポジトリの `README.md` ファイルに説明文を記述します。

4.  **アドオンのアイコンを作成:**

    *   アドオンのアイコンを作成し、GitHubリポジトリにアップロードします。
    *   アイコンは、アドオンの特徴を表すものが望ましいです。
    *   アイコンのサイズは、128x128ピクセル程度が推奨されます。

5.  **AnkiWebにアドオンを登録:**

    *   AnkiWeb (https://ankiweb.net/) にログインします。
    *   「アドオン」ページにアクセスし、「新しいアドオンを提出」をクリックします。
    *   アドオンの名前、説明文、GitHubリポジトリのURL、アイコンなどを入力します。
    *   アドオンを提出します。
