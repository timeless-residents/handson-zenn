# 1章: はじめに - なぜAnkiConnectとPythonなのか？

## Ankiと反復学習の可能性

### 概要と重要性

Ankiは、間隔反復学習（Spaced Repetition System, SRS）と呼ばれる学習方法を実装した、強力なフラッシュカードアプリケーションです。単純な暗記だけでなく、長期記憶への定着を効率的に支援してくれるため、語学学習、資格試験、医学、法律など、幅広い分野で活用されています。人間の忘却曲線に基づき、忘れる前に復習するタイミングを自動的に調整してくれる点が、Ankiの最大の魅力です。

しかし、Ankiを使い続けるうちに、下記のような課題に直面することがあります。

*   **大量のカード作成:** 試験範囲が広い場合、数百枚、数千枚のカードを手作業で作成するのは非常に手間がかかります。
*   **カードの形式の限界:** テキストだけでなく、音声や画像、数式など、様々な形式でカードを作成したい場合があります。
*   **学習データの分析:** 自分の学習進捗を詳細に分析し、弱点を克服するための戦略を立てたい。
*   **他のツールとの連携:** 他の学習ツールや情報源（辞書、翻訳ツール、Webサイトなど）とAnkiを連携させたい。

Ankiの標準機能だけでは、これらの課題を解決するのは難しい場合があります。そこで登場するのが、AnkiConnectとPythonです。

### 特徴と利点

Ankiの持つポテンシャルを最大限に引き出す鍵となるのが、AnkiConnectです。AnkiConnectは、Ankiを外部プログラムから制御するためのAPI（Application Programming Interface）を提供します。つまり、プログラミングを通じてAnkiの機能を操作し、自動化することができるのです。

AnkiConnectを利用することで、以下のようなことが可能になります。

*   **自動カード生成:** CSVファイルやWebサイトから情報を取得し、自動的にカードを作成する。
*   **高度なカード形式のサポート:** プログラミングによって複雑なカード形式（インタラクティブな要素を含む）を実現する。
*   **学習データの詳細な分析:** Ankiの学習データを取得し、独自の分析ツールを作成する。
*   **他のツールとの連携:** 翻訳ツールや辞書と連携し、効率的な学習環境を構築する。

### 事前準備と前提条件

この書籍を通じてAnkiConnectとPythonを使いこなすためには、いくつかの事前準備と前提条件があります。

1.  **Ankiのインストール:** まだAnkiをインストールしていない場合は、[https://apps.ankiweb.net/](https://apps.ankiweb.net/) からダウンロードしてインストールしてください。
2.  **AnkiConnectアドオンのインストール:** AnkiConnectアドオンをAnkiにインストールします。Ankiを開き、`ツール` > `アドオン` > `アドオンをダウンロード`を選択し、コード `2055492159` を入力してインストールします。
3.  **Pythonのインストール:** Pythonがインストールされていない場合は、[https://www.python.org/](https://www.python.org/) からダウンロードしてインストールしてください。Python 3.7以降を推奨します。
4.  **Pythonの基本的な知識:** 変数、データ型、制御構造（if文、for文など）、関数などの基本的なPythonの知識が必要です。
5.  **JSONの基本的な知識:** AnkiConnectはJSON形式でデータをやり取りするため、JSONの基本的な構造を理解していると役立ちます。
6.  **requestsライブラリのインストール:** PythonからAnkiConnectにアクセスするために、requestsライブラリを使用します。ターミナルまたはコマンドプロンプトで、`pip install requests` を実行してインストールしてください。

### 基本的な使い方

AnkiConnectは、JSON形式のデータをHTTPリクエストとしてAnkiに送信し、その結果をJSON形式で受け取ることで動作します。まずは、Pythonを使ってAnkiConnectにリクエストを送信し、基本的な情報を取得してみましょう。

```python
import requests
import json

def anki_connect_request(action, **params):
    """AnkiConnectにリクエストを送信する関数"""
    requestJson = json.dumps({'action': action, 'version': 6, 'params': params})
    try:
        response = requests.post('http://127.0.0.1:8765', data=requestJson).json()
    except requests.exceptions.ConnectionError:
        print('AnkiConnectに接続できませんでした。Ankiが起動しているか確認してください。')
        return None
    if len(response) != 2:
        raise Exception('response has an unexpected number of fields')
    if 'error' not in response:
        raise Exception('response is missing required error field')
    if 'result' not in response:
        raise Exception('response is missing required result field')
    if response['error'] is not None:
        raise Exception(response['error'])
    return response['result']

# デッキの名前一覧を取得する
deck_names = anki_connect_request('deckNames')
if deck_names:
    print("デッキの一覧:")
    for deck in deck_names:
        print(f"- {deck}")

# バージョン情報を取得する
version = anki_connect_request('version')
print(f"AnkiConnectのバージョン: {version}")
```

このコードを実行する前に、必ずAnkiを起動しておいてください。コードを実行すると、Ankiに登録されているデッキの一覧と、AnkiConnectのバージョン情報が表示されます。

**コードの解説:**

*   `anki_connect_request(action, **params)` 関数は、AnkiConnectにリクエストを送信するための汎用的な関数です。
    *   `action`: 実行するAnkiConnectのAPIアクション名（例: 'deckNames'）。
    *   `params`: アクションに渡すパラメータ（辞書形式）。
*   `requests.post('http://127.0.0.1:8765', data=requestJson)`: AnkiConnectのエンドポイント（通常は `http://127.0.0.1:8765`）に、JSON形式のリクエストをPOSTメソッドで送信します。
*   `response.json()`: レスポンスをJSON形式に変換します。
*   エラー処理: AnkiConnectへの接続エラーや、レスポンスのエラーをチェックします。
*   `deck_names = anki_connect_request('deckNames')`: `deckNames` アクションを使って、デッキの名前一覧を取得します。
*   `version = anki_connect_request('version')`: `version` アクションを使って、AnkiConnectのバージョン情報を取得します。

### 実践的なテクニック

AnkiConnectの真価は、その豊富なAPIアクションにあります。ここでは、いくつかの実践的なテクニックを紹介します。

**1. カードの作成:**

AnkiConnectを使ってカードを作成するには、`addNote` アクションを使用します。

```python
# カードを作成する
note = {
    "deckName": "Default",
    "modelName": "Basic",
    "fields": {
        "Front": "こんにちは",
        "Back": "Hello"
    },
    "options": {
        "allowDuplicate": False,
        "duplicateScope": "deck"
    },
    "tags": ["Japanese", "Greeting"]
}

result = anki_connect_request('addNote', note=note)
if result:
    print(f"カードが作成されました。ノートID: {result}")
```

このコードは、「こんにちは」という日本語の単語と、その英語訳「Hello」を記述したカードを「Default」デッキに作成します。

**パラメータの解説:**

*   `deckName`: カードを作成するデッキの名前。
*   `modelName`: カードのモデル（テンプレート）の名前。Ankiには、Basic、Basic (and reversed card)、Basic (optional reversed card)、Clozeなどの標準モデルが用意されています。カスタムモデルを使用することも可能です。
*   `fields`: カードの各フィールドの内容（辞書形式）。`Front`フィールドと`Back`フィールドは、通常、表と裏に対応します。
*   `options`: カード作成に関するオプション。
    *   `allowDuplicate`: 重複したカードの作成を許可するかどうか（True/False）。
    *   `duplicateScope`: 重複チェックの範囲（"deck"または"global"）。
*   `tags`: カードに付与するタグのリスト。

**2. 大量のカードをCSVファイルからインポート:**

CSVファイルからカードをインポートするには、以下の手順を実行します。

1.  CSVファイルを用意します。CSVファイルの各行が1枚のカードに対応し、各列がカードのフィールドに対応します。例えば、`Front,Back,Tag`というヘッダーを持つCSVファイルは、表、裏、タグの3つのフィールドを持つカードを定義します。
2.  PythonスクリプトでCSVファイルを読み込み、各行を`addNote`アクションを使ってAnkiに送信します。

```python
import csv

def import_cards_from_csv(csv_file_path, deck_name, model_name, tag):
    """CSVファイルからカードをインポートする"""
    with open(csv_file_path, 'r', encoding='utf-8') as csvfile:
        reader = csv.DictReader(csvfile)
        for row in reader:
            note = {
                "deckName": deck_name,
                "modelName": model_name,
                "fields": row,
                "options": {
                    "allowDuplicate": False,
                    "duplicateScope": "deck"
                },
                "tags": [tag]
            }
            result = anki_connect_request('addNote', note=note)
            if result:
                print(f"カードが作成されました。ノートID: {result}")
            else:
                print(f"カードの作成に失敗しました。: {row}")

# CSVファイルを指定してカードをインポートする
csv_file_path = 'cards.csv'  # CSVファイルのパス
deck_name = 'MyDeck'  # カードを作成するデッキの名前
model_name = 'Basic'  # カードのモデルの名前
tag = 'Imported'  # カードに付与するタグ

import_cards_from_csv(csv_file_path, deck_name, model_name, tag)
```

このコードは、`cards.csv`ファイルからカードを読み込み、「MyDeck」デッキに作成します。各カードには「Imported」というタグが付与されます。

**3. カードの検索と更新:**

`findNotes`アクションを使ってカードを検索し、`updateNoteFields`アクションを使ってカードのフィールドを更新することができます。

```python
# カードを検索する
query = 'deck:"Default" Front:"こんにちは"'
note_ids = anki_connect_request('findNotes', query=query)

if note_ids:
    print(f"該当するカードが見つかりました。ノートID: {note_ids}")

    # カードのフィールドを更新する
    note_id = note_ids[0]  # 最初のカードのIDを取得
    fields = {
        "Front": "こんばんは",
        "Back": "Good evening"
    }
    note = {
        "id": note_id,
        "fields": fields
    }
    result = anki_connect_request('updateNoteFields', note=note)

    if result:
        print("カードが更新されました。")
    else:
        print("カードの更新に失敗しました。")
else:
    print("該当するカードが見つかりませんでした。")
```

このコードは、「Default」デッキの中で、「Front」フィールドに「こんにちは」という文字列を含むカードを検索し、見つかったカードの「Front」フィールドを「こんばんは」に、「Back」フィールドを「Good evening」に更新します。

**4. カードの削除:**

`deleteNotes`アクションを使ってカードを削除することができます。

```python
# カードを削除する
query = 'deck:"Default" tag:"ToDelete"'
note_ids = anki_connect_request('findNotes', query=query)

if note_ids:
    print(f"削除するカードが見つかりました。ノートID: {note_ids}")

    result = anki_connect_request('deleteNotes', notes=note_ids)

    if result:
        print(f"{result}枚のカードが削除されました。")
    else:
        print("カードの削除に失敗しました。")
else:
    print("削除するカードが見つかりませんでした。")
```

このコードは、「Default」デッキの中で、「ToDelete」というタグが付与されたカードを検索し、見つかったカードを削除します。

### トラブルシューティング

AnkiConnectの使用中に問題が発生した場合は、以下の点を確認してください。

*   Ankiが起動しているか。
*   AnkiConnectアドオンが正しくインストールされているか。
*   AnkiConnectの設定で、外部からの接続が許可されているか。（`ツール` > `アドオン` > `AnkiConnect` > `設定`）
*   Pythonスクリプトで指定しているAnkiConnectのエンドポイントが正しいか。（通常は `http://127.0.0.1:8765`）
*   AnkiConnectに送信するJSONデータが正しい形式であるか。
*   AnkiConnectのAPIアクション名やパラメータが正しいか。（AnkiConnectのドキュメントを参照: [https://foosoft.net/projects/anki-connect/](https://foosoft.net/projects/anki-connect/)）
*   エラーメッセージをよく読んで、原因を特定する。
*   AnkiConnectのログを確認する。（`ツール` > `アドオン` > `AnkiConnect` > `設定`でログを有効にする）

**よくあるエラー:**

*   **ConnectionError:** AnkiConnectに接続できませんでした。Ankiが起動しているか、AnkiConnectアドオンが正しくインストールされているかを確認してください。
*   **JSONDecodeError:** JSONデータをデコードできませんでした。JSONデータの形式が正しいかを確認してください。
*   **KeyError:** 存在しないキーにアクセスしようとしました。APIアクションのパラメータが正しいかを確認してください。
*   **Anki側からのエラーメッセージ:** AnkiConnectからのレスポンスにエラーメッセージが含まれている場合は、その内容をよく読んでください。APIアクションのパラメータが不正である可能性があります。
* **Permission Denied:** AnkiConnectの設定で、外部からの接続が許可されていない可能性があります。AnkiConnectの設定を確認してください。
