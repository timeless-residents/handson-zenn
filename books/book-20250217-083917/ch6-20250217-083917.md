## 6. データ分析の実践: テクニカル指標の計算と可視化

この章では、金融市場のデータ分析において不可欠なテクニカル分析（TA）の実践的な手法を解説します。移動平均線、RSI、MACDといった基本的なテクニカル指標の計算から、ローソク足パターンやチャートパターンの検出、そしてTA-Libを活用した効率的な分析まで、ステップバイステップで習得を目指します。異常値の検出と処理にも焦点を当て、より信頼性の高い分析結果を得るためのノウハウを伝授します。

### 6.1. 移動平均線、RSI、MACDなどのテクニカル指標の計算

#### 概要と重要性

テクニカル指標は、過去の価格と出来高のデータに基づいて計算され、将来の価格変動を予測するために使用されます。移動平均線、RSI（Relative Strength Index）、MACD（Moving Average Convergence Divergence）などは、その中でも特にポピュラーで、多くのトレーダーやアナリストに利用されています。これらの指標を理解し、適切に活用することで、市場のトレンドや過熱感を把握し、より精度の高い取引判断を下すことができます。

#### 特徴と利点

*   **移動平均線:** 一定期間の価格の平均値を線で結んだもので、トレンドの方向性を把握するのに役立ちます。
*   **RSI:** 相対力指数は、価格変動の勢いを測定し、買われすぎや売られすぎの状況を判断するために使用されます。
*   **MACD:** 移動平均収束拡散は、2つの移動平均線の関係性に基づいてトレンドの変化を捉え、売買シグナルを生成します。

これらの指標は、単独で使用するだけでなく、組み合わせて使用することで、より強力な分析を行うことができます。

```python
import yfinance as yf
import pandas as pd
import numpy as np


def calculate_moving_average(df, window):
    """
    移動平均線を計算する関数
    """
    return df["Close"].rolling(window=window).mean()


def calculate_rsi(df, period=14):
    """
    RSI (Relative Strength Index)を計算する関数
    """
    # 価格変化を計算
    delta = df["Close"].diff()

    # 上昇幅と下落幅を分ける
    gain = (delta.where(delta > 0, 0)).rolling(window=period).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=period).mean()

    # RSIを計算
    rs = gain / loss
    rsi = 100 - (100 / (1 + rs))

    return rsi


def calculate_macd(df, fast_period=12, slow_period=26, signal_period=9):
    """
    MACD (Moving Average Convergence Divergence)を計算する関数
    """
    # 短期と長期の指数移動平均を計算
    exp1 = df["Close"].ewm(span=fast_period, adjust=False).mean()
    exp2 = df["Close"].ewm(span=slow_period, adjust=False).mean()

    # MACDライン
    macd = exp1 - exp2

    # シグナルライン
    signal = macd.ewm(span=signal_period, adjust=False).mean()

    return macd, signal


def analyze_stock(ticker_symbol, start_date, end_date):
    try:
        # 株価データを取得
        stock = yf.Ticker(ticker_symbol)
        df = stock.history(start=start_date, end=end_date)

        if df.empty:
            raise ValueError("データが取得できませんでした")

        # 移動平均線の計算
        df["MA_20"] = calculate_moving_average(df, 20)
        df["MA_50"] = calculate_moving_average(df, 50)

        # RSIの計算
        df["RSI"] = calculate_rsi(df, 14)

        # MACDの計算
        df["MACD"], df["Signal"] = calculate_macd(df, 12, 26, 9)

        # 基本統計情報を表示
        print(f"\n{ticker_symbol}の基本統計情報:")
        print(df["Close"].describe())

        # 最新のテクニカル指標を表示
        last_row = df.iloc[-1]
        print(f"\n最新のテクニカル指標 ({df.index[-1].strftime('%Y-%m-%d')}):")
        print(f"終値: {last_row['Close']:.2f}")
        print(f"20日移動平均: {last_row['MA_20']:.2f}")
        print(f"50日移動平均: {last_row['MA_50']:.2f}")
        print(f"RSI: {last_row['RSI']:.2f}")
        print(f"MACD: {last_row['MACD']:.2f}")
        print(f"MACDシグナル: {last_row['Signal']:.2f}")

        return df

    except Exception as e:
        print(f"エラーが発生しました: {e}")
        return None
```

```python
    """
    Calculate moving average
    """
    return df["Close"].rolling(window=window).mean()


def calculate_rsi(df, period=14):
    """
    Calculate RSI (Relative Strength Index)
    """
    delta = df["Close"].diff()
    gain = (delta.where(delta > 0, 0)).rolling(window=period).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=period).mean()
    rs = gain / loss
    rsi = 100 - (100 / (1 + rs))
    return rsi


def calculate_macd(df, fast_period=12, slow_period=26, signal_period=9):

    Calculate MACD (Moving Average Convergence Divergence)
```

#### 実践的なテクニック

*   **ゴールデンクロス/デッドクロス:** 短期移動平均線が長期移動平均線を上抜ける（ゴールデンクロス）と買いシグナル、下抜ける（デッドクロス）と売りシグナルと見なされます。
*   **RSIのダイバージェンス:** 株価が上昇しているのにRSIが下降している場合、上昇トレンドの弱まりを示唆することがあります。
*   **MACDのヒストグラム:** MACDとシグナルラインの差をヒストグラムで表示することで、トレンドの強さを視覚的に把握できます。

#### 応用例とユースケース

*   **自動売買:** テクニカル指標をトリガーとして、自動的に売買を行うシステムを構築できます。
*   **ポートフォリオのリバランス:** テクニカル指標を用いて、ポートフォリオのリスクを管理し、最適な配分を維持することができます。

#### トラブルシューティング

*   **データの欠損:** 株価データに欠損値が含まれている場合、`fillna()`などの関数で補完する必要があります。
*   **パラメータの最適化:** テクニカル指標のパラメータ（例: 移動平均線の期間）は、銘柄や市場の状況によって最適な値が異なります。過去のデータを用いて検証し、最適なパラメータを見つけることが重要です。
*   **データの取得エラー:** `pandas_datareader`でデータの取得に失敗する場合、APIの制限やネットワークの問題が考えられます。別のデータソースを試すか、時間をおいて再度試行してください。

### 6.2. ローソク足パターンの検出: ハーミ、包み足、カラカサなど

#### 概要と重要性

ローソク足は、一定期間の始値、高値、安値、終値を視覚的に表現したもので、相場の勢いや転換点を示唆するパターンが数多く存在します。ハーミ、包み足、カラカサなどは、その中でも代表的なパターンであり、これらのパターンを理解し、適切に解釈することで、より精度の高い取引判断を下すことができます。

#### 特徴と利点

*   **ハーミ:** 前日のローソク足に比べて実体が小さいローソク足が現れた場合、相場の転換点を示唆することがあります。
*   **包み足:** 前日のローソク足を完全に包み込むローソク足が現れた場合、強いトレンド転換の兆候と見なされます。
*   **カラカサ:** 上ヒゲが長く、実体が小さいローソク足で、上昇トレンドの終焉を示唆することがあります。

これらのパターンは、単独で判断するのではなく、他のテクニカル指標と組み合わせて分析することで、より信頼性の高い結果を得ることができます。

#### 基本的な使い方

ローソク足パターンを検出するためには、まずローソク足の形状を定義する必要があります。ここでは例として、ハーミ、包み足、カラカサを検出する関数を定義します。

```python
from datetime import datetime, timedelta

import matplotlib.pyplot as plt
import mplfinance as mpf
import numpy as np
import pandas as pd
import yfinance as yf


def debug_dataframe(df, label="DataFrame Debug Info"):
    """DataFrameの構造をデバッグ表示する補助関数"""
    print(f"\n=== {label} ===")
    print("Columns:", df.columns)
    print("\nColumn Levels:", df.columns.nlevels)
    if isinstance(df.columns, pd.MultiIndex):
        print("\nMultiIndex Levels:")
        for i in range(df.columns.nlevels):
            print(f"Level {i}:", df.columns.get_level_values(i).unique())
    print("\nShape:", df.shape)
    print("\nFirst few rows:")
    print(df.head(2))
    print("=" * 50)


def get_value(series, column):
    """Seriesから単一の値を取得する補助関数"""
    if isinstance(series.index, pd.MultiIndex):
        return series[
            (
                "Adj Close" if column == "Close" else column,
                series.index.get_level_values(-1)[0],
            )
        ].item()
    return series[column].item()


def is_harami(data, idx):
    """ハラミを検出する関数"""
    if idx <= 0:
        return False

    current = data.iloc[idx]
    previous = data.iloc[idx - 1]

    real_body_prev = abs(get_value(previous, "Close") - get_value(previous, "Open"))
    real_body = abs(get_value(current, "Close") - get_value(current, "Open"))

    size_condition = real_body < 0.2 * real_body_prev

    bullish_harami = get_value(current, "Close") > get_value(
        previous, "Open"
    ) and get_value(current, "Open") < get_value(previous, "Close")

    bearish_harami = get_value(current, "Open") > get_value(
        previous, "Close"
    ) and get_value(current, "Close") < get_value(previous, "Open")

    return size_condition and (bullish_harami or bearish_harami)


def is_engulfing(data, idx):
    """包み足を検出する関数"""
    if idx <= 0:
        return False

    current = data.iloc[idx]
    previous = data.iloc[idx - 1]

    real_body_prev = abs(get_value(previous, "Close") - get_value(previous, "Open"))
    real_body = abs(get_value(current, "Close") - get_value(current, "Open"))

    return (
        get_value(current, "Open") > get_value(previous, "Close")
        and get_value(current, "Close") < get_value(previous, "Open")
        and real_body > 1.1 * real_body_prev
    )


def is_karakasa(data, idx):
    """カラカサ（傘）パターンを検出する関数"""
    if idx <= 0:
        return False

    current = data.iloc[idx]

    c_close = get_value(current, "Close")
    c_open = get_value(current, "Open")
    c_high = get_value(current, "High")
    c_low = get_value(current, "Low")

    body_len = abs(c_close - c_open)
    upper_shadow = c_high - max(c_close, c_open)
    lower_shadow = min(c_close, c_open) - c_low

    return upper_shadow > 2 * body_len and lower_shadow < 0.1 * body_len


def analyze_patterns(symbol, start_date=None, end_date=None):
    """株価データを取得してパターンを分析する関数"""
    if start_date is None:
        start_date = (datetime.now() - timedelta(days=365)).strftime("%Y-%m-%d")
    if end_date is None:
        end_date = datetime.now().strftime("%Y-%m-%d")

    # データ取得
    df = yf.download(symbol, start=start_date, end=end_date)

    # データフレームの構造をデバッグ表示
    debug_dataframe(df, "Original DataFrame")

    # マルチインデックスの場合は解除
    if isinstance(df.columns, pd.MultiIndex):
        # 必要なカラムを選択して新しいDataFrameを作成
        df_new = pd.DataFrame(
            {
                "Open": df[("Open", symbol)],
                "High": df[("High", symbol)],
                "Low": df[("Low", symbol)],
                "Close": df[("Close", symbol)],
                "Volume": df[("Volume", symbol)],
            }
        )
        df = df_new

    debug_dataframe(df, "Processed DataFrame")

    # パターン検出結果を格納する列を追加
    df["Harami"] = False
    df["Engulfing"] = False
    df["Karakasa"] = False

    # 各行でパターンを検出
    for idx in range(1, len(df)):
        df.iloc[idx, df.columns.get_loc("Harami")] = is_harami(df, idx)
        df.iloc[idx, df.columns.get_loc("Engulfing")] = is_engulfing(df, idx)
        df.iloc[idx, df.columns.get_loc("Karakasa")] = is_karakasa(df, idx)

    return df


def plot_candlestick_patterns(df, title="Technical Pattern Analysis"):
    """Visualize candlestick chart and patterns"""
    # Set up style
    mc = mpf.make_marketcolors(
        up="red", down="blue", edge="inherit", wick="inherit", volume="in", inherit=True
    )
    s = mpf.make_mpf_style(marketcolors=mc, gridstyle="--", y_on_right=False)

    # Prepare plots for each pattern
    addplots = []

    # Pattern configurations
    pattern_configs = [
        ("Harami", "^", "blue"),
        ("Engulfing", "v", "red"),
        ("Karakasa", "s", "green"),
    ]

    # Create series for each pattern
    for pattern_name, marker, color in pattern_configs:
        # Create a series with NaN values where pattern is not present
        pattern_series = pd.Series(index=df.index, data=np.nan)
        pattern_indices = df.index[df[pattern_name]]

        if len(pattern_indices) > 0:
            # Place markers slightly below the low price
            offset = (
                0.99
                if pattern_name == "Harami"
                else 0.98 if pattern_name == "Engulfing" else 0.97
            )
            pattern_series[pattern_indices] = df.loc[pattern_indices, "Low"] * offset

            # Add plot
            addplots.append(
                mpf.make_addplot(
                    pattern_series,
                    type="scatter",
                    marker=marker,
                    markersize=100,
                    color=color,
                    label=f"{pattern_name} ({marker})",
                )
            )

    # Draw chart
    _fig, axes = mpf.plot(
        df,
        type="candle",
        style=s,
        title=title,
        volume=True,
        addplot=addplots,
        returnfig=True,
        figsize=(15, 10),
    )

    # Add legend if patterns were found
    if addplots:
        axes[0].legend()

    plt.show()

    print("\nDrawing chart...")
    plot_candlestick_patterns(
        df, f"Pattern Analysis: {symbol} ({start_date} - {end_date})"
    )
```

#### 実践的なテクニック

*   **組み合わせ分析:** ローソク足パターンを移動平均線やRSIなどのテクニカル指標と組み合わせて分析することで、より信頼性の高い売買シグナルを生成できます。
*   **トレンドフォロー:** 上昇トレンド中に現れた強気のローソク足パターンは買いシグナル、下降トレンド中に現れた弱気のローソク足パターンは売りシグナルと見なされます。
*   **逆張り:** 相場の過熱感を示すローソク足パターン（例: カラカサ）は、逆張りのエントリーポイントとして活用できます。

#### 応用例とユースケース

*   **スキャルピング:** 短時間で小さな利益を積み重ねるスキャルピング戦略において、ローソク足パターンは非常に有効なツールとなります。
*   **デイトレード:** 一日のうちに取引を完結させるデイトレード戦略において、ローソク足パターンはエントリーとエグジットのタイミングを判断するのに役立ちます。

#### トラブルシューティング

*   **ノイズの除去:** ローソク足パターンは、ダマシと呼ばれる誤ったシグナルを出すことがあります。他のテクニカル指標と組み合わせて分析することで、ノイズを軽減することができます。
*   **パラメータの調整:** ローソク足パターンの定義は、銘柄や市場の状況によって調整する必要があります。過去のデータを用いて検証し、最適なパラメータを見つけることが重要です。
*    **出来高との組み合わせ:** ローソク足パターンを出来高と組み合わせて分析することで、パターン発生の信頼性を高めることができます。例えば、包み足の出現時に出来高が急増している場合は、より強いシグナルと見なされます。

### 6.3. チャートパターンの検出: ヘッドアンドショルダー、ダブルトップなど

#### 概要と重要性

チャートパターンは、過去の価格変動をグラフ化したチャート上に現れる特定の形状のことで、将来の価格変動を予測するために使用されます。ヘッドアンドショルダー（三尊天井）、ダブルトップ（二点天井）などは、その中でも代表的なパターンであり、これらのパターンを理解し、適切に解釈することで、より精度の高い取引判断を下すことができます。

#### 特徴と利点

*   **ヘッドアンドショルダー:** 上昇トレンドの終焉を示唆するパターンで、左肩、ヘッド（頭）、右肩の3つのピークとネックラインで構成されます。ネックラインを下抜けると、下降トレンドへの転換が示唆されます。
*   **ダブルトップ:** 上昇トレンドの終焉を示唆するパターンで、2つのほぼ同じ高さのピークで構成されます。2つのピークを結んだラインを下抜けると、下降トレンドへの転換が示唆されます。

これらのパターンは、市場の心理状態を反映していると考えられており、テクニカル分析において重要な役割を果たします。

#### 事前準備と前提条件

*   **Python環境:** Python 3.7以上がインストールされていること。
*   **必要なライブラリ:** `pandas`, `numpy`, `matplotlib` (可視化のため)

これらのライブラリは、以下のコマンドでインストールできます。

```bash
pip install pandas numpy matplotlib
```

#### 基本的な使い方

チャートパターンを検出するためには、まず価格データの形状を分析する必要があります。ここでは例として、ヘッドアンドショルダーとダブルトップを検出する関数を定義します。これらの関数は、簡略化された例であり、実際にはより複雑なロジックが必要となる場合があります。

```python

def get_value(series, column):
    """Seriesから単一の値を取得する補助関数"""
    if isinstance(series.index, pd.MultiIndex):
        return series[
            (
                "Adj Close" if column == "Close" else column,
                series.index.get_level_values(-1)[0],
            )
        ].item()
    return series[column].item()


def is_harami(data, idx):
    """ハラミを検出する関数"""
    if idx <= 0:
        return False

    current = data.iloc[idx]
    previous = data.iloc[idx - 1]

    real_body_prev = abs(get_value(previous, "Close") - get_value(previous, "Open"))
    real_body = abs(get_value(current, "Close") - get_value(current, "Open"))

    size_condition = real_body < 0.2 * real_body_prev

    bullish_harami = get_value(current, "Close") > get_value(
        previous, "Open"
    ) and get_value(current, "Open") < get_value(previous, "Close")

    bearish_harami = get_value(current, "Open") > get_value(
        previous, "Close"
    ) and get_value(current, "Close") < get_value(previous, "Open")

    return size_condition and (bullish_harami or bearish_harami)


def is_engulfing(data, idx):
    """包み足を検出する関数"""
    if idx <= 0:
        return False

    current = data.iloc[idx]
    previous = data.iloc[idx - 1]

    real_body_prev = abs(get_value(previous, "Close") - get_value(previous, "Open"))
    real_body = abs(get_value(current, "Close") - get_value(current, "Open"))

    return (
        get_value(current, "Open") > get_value(previous, "Close")
        and get_value(current, "Close") < get_value(previous, "Open")
        and real_body > 1.1 * real_body_prev
    )


def is_karakasa(data, idx):
    """カラカサ（傘）パターンを検出する関数"""
    if idx <= 0:
        return False

    current = data.iloc[idx]

    c_close = get_value(current, "Close")
    c_open = get_value(current, "Open")
    c_high = get_value(current, "High")
    c_low = get_value(current, "Low")

    body_len = abs(c_close - c_open)
    upper_shadow = c_high - max(c_close, c_open)
    lower_shadow = min(c_close, c_open) - c_low

    return upper_shadow > 2 * body_len and lower_shadow < 0.1 * body_len


def detect_head_and_shoulders(data):
    """ヘッドアンドショルダーパターンを検出する関数"""
    high_prices = data["High"].values
    low_prices = data["Low"].values

    # ピークと谷を検出
    peaks = []
    valleys = []

    for i in range(2, len(high_prices) - 2):
        # ピーク検出（前後2日間より高い）
        if (
            high_prices[i] > high_prices[i - 2]
            and high_prices[i] > high_prices[i - 1]
            and high_prices[i] > high_prices[i + 1]
            and high_prices[i] > high_prices[i + 2]
        ):
            peaks.append((i, high_prices[i]))

        # 谷検出（前後2日間より低い）
        if (
            low_prices[i] < low_prices[i - 2]
            and low_prices[i] < low_prices[i - 1]
            and low_prices[i] < low_prices[i + 1]
            and low_prices[i] < low_prices[i + 2]
        ):
            valleys.append((i, low_prices[i]))

    # ヘッドアンドショルダーパターンの検出
    if len(peaks) >= 3 and len(valleys) >= 2:
        for i in range(len(peaks) - 2):
            # 3つのピークを取得
            left_shoulder = peaks[i]
            head = peaks[i + 1]
            right_shoulder = peaks[i + 2]

            # パターンの条件をチェック
            if (
                abs(left_shoulder[1] - right_shoulder[1])
                < 0.02 * head[1]  # 左右の肩がほぼ同じ高さ
                and head[1] > left_shoulder[1]  # 頭が左肩より高い
                and head[1] > right_shoulder[1]
            ):  # 頭が右肩より高い
                return [left_shoulder[0], head[0], right_shoulder[0]]

    return None


def detect_double_top(data):
    """ダブルトップパターンを検出する関数"""
    high_prices = data["High"].values

    # ピークを検出
    peaks = []
    for i in range(2, len(high_prices) - 2):
        if (
            high_prices[i] > high_prices[i - 2]
            and high_prices[i] > high_prices[i - 1]
            and high_prices[i] > high_prices[i + 1]
            and high_prices[i] > high_prices[i + 2]
        ):
            peaks.append((i, high_prices[i]))

    # ダブルトップの検出
    if len(peaks) >= 2:
        for i in range(len(peaks) - 1):
            top1_idx, top1_price = peaks[i]
            top2_idx, top2_price = peaks[i + 1]

            # 条件チェック
            price_diff = abs(top1_price - top2_price)
            idx_diff = abs(top2_idx - top1_idx)

            if (
                price_diff < 0.02 * top1_price  # 価格差が2%以内
                and idx_diff > 10  # 最低10日間の間隔
                and idx_diff < 60
            ):  # 最大60日間の間隔
                return [top1_idx, top2_idx]

    return None


def analyze_patterns(symbol, start_date=None, end_date=None):
    """株価データを取得してパターンを分析する関数"""
    if start_date is None:
        start_date = (datetime.now() - timedelta(days=365)).strftime("%Y-%m-%d")
    if end_date is None:
        end_date = datetime.now().strftime("%Y-%m-%d")

    # データ取得
    df = yf.download(symbol, start=start_date, end=end_date)

    # データフレームの構造をデバッグ表示
    debug_dataframe(df, "Original DataFrame")

    # マルチインデックスの場合は解除
    if isinstance(df.columns, pd.MultiIndex):
        df_new = pd.DataFrame(
            {
                "Open": df[("Open", symbol)],
                "High": df[("High", symbol)],
                "Low": df[("Low", symbol)],
                "Close": df[("Close", symbol)],
                "Volume": df[("Volume", symbol)],
            }
        )
        df = df_new

    debug_dataframe(df, "Processed DataFrame")

    # 基本パターン検出結果を格納する列を追加
    df["Harami"] = False
    df["Engulfing"] = False
    df["Karakasa"] = False
    df["HeadAndShoulders"] = False
    df["DoubleTop"] = False

    # 基本パターンの検出
    for idx in range(1, len(df)):
        df.iloc[idx, df.columns.get_loc("Harami")] = is_harami(df, idx)
        df.iloc[idx, df.columns.get_loc("Engulfing")] = is_engulfing(df, idx)
        df.iloc[idx, df.columns.get_loc("Karakasa")] = is_karakasa(df, idx)

    # 複合パターンの検出
    hs_pattern = detect_head_and_shoulders(df)
    if hs_pattern:
        for idx in hs_pattern:
            df.iloc[idx, df.columns.get_loc("HeadAndShoulders")] = True

    dt_pattern = detect_double_top(df)
    if dt_pattern:
        for idx in dt_pattern:
            df.iloc[idx, df.columns.get_loc("DoubleTop")] = True

    return df


def plot_candlestick_patterns(df, title="Technical Pattern Analysis"):
    """Visualize candlestick chart and patterns"""
    # Set up style
    mc = mpf.make_marketcolors(
        up="red", down="blue", edge="inherit", wick="inherit", volume="in", inherit=True
    )
    s = mpf.make_mpf_style(marketcolors=mc, gridstyle="--", y_on_right=False)

    # Prepare plots for each pattern
    addplots = []

    # Pattern configurations
    pattern_configs = [
        ("Harami", "^", "blue"),
        ("Engulfing", "v", "red"),
        ("Karakasa", "s", "green"),
        ("HeadAndShoulders", "d", "purple"),
        ("DoubleTop", "p", "orange"),
    ]

    # Create series for each pattern
    for pattern_name, marker, color in pattern_configs:
        pattern_series = pd.Series(index=df.index, data=np.nan)
        pattern_indices = df.index[df[pattern_name]]

        if len(pattern_indices) > 0:
            # Place markers at different vertical positions
            offset = {
                "Harami": 0.99,
                "Engulfing": 0.98,
                "Karakasa": 0.97,
                "HeadAndShoulders": 0.96,
                "DoubleTop": 0.95,
            }[pattern_name]

            pattern_series[pattern_indices] = df.loc[pattern_indices, "Low"] * offset

            # Add plot
            addplots.append(
                mpf.make_addplot(
                    pattern_series,
                    type="scatter",
                    marker=marker,
                    markersize=100,
                    color=color,
                    label=f"{pattern_name} ({marker})",
                )
            )

    # Draw chart
    _fig, axes = mpf.plot(
        df,
        type="candle",
        style=s,
        title=title,
        volume=True,
        addplot=addplots,
        returnfig=True,
        figsize=(15, 10),
    )

    # Add legend if patterns were found
    if addplots:
        axes[0].legend()

    plt.show()
```

### 6.4. TA-Libを活用したテクニカル分析の効率化

#### 概要と重要性

TA-Lib（Technical Analysis Library）は、テクニカル分析のための様々な関数を提供するPythonライブラリです。移動平均線、RSI、MACDなどの基本的な指標から、より高度な指標まで、幅広い関数が利用可能です。TA-Libを活用することで、テクニカル分析の効率を大幅に向上させることができます。

#### 特徴と利点

*   **豊富な関数:** 200種類以上のテクニカル指標関数を提供
*   **高速な計算:** C言語で記述されており、高速な計算が可能
*   **一貫性のある結果:** 複数のプラットフォームで一貫した結果を提供

これらの特徴により、TA-Libはプロのトレーダーやアナリストにとって不可欠なツールとなっています。

### 6.5. 複数のテクニカル指標を組み合わせた分析

#### 概要と重要性

テクニカル分析では、単一の指標だけではなく、複数の指標を組み合わせることで、より信頼性の高い売買シグナルを得ることができます。異なる視点から市場を分析することで、誤ったシグナルを排除し、より精度の高い取引判断を下すことが可能になります。

#### 特徴と利点

*   **相互補完:** 異なる指標を組み合わせることで、それぞれの弱点を補完し、より強力な分析を行うことができます。
*   **コンファメーション:** 複数の指標が同じ方向を示している場合、売買シグナルの信頼性が高まります。
*   **リスク分散:** 単一の指標に依存するリスクを軽減することができます。

#### 事前準備と前提条件

*   **Python環境:** Python 3.7以上がインストールされていること。
*   **必要なライブラリ:** `pandas`, `numpy`, `matplotlib`, `TA-Lib`

これらのライブラリは、事前にインストールしておく必要があります。

#### 基本的な使い方

複数のテクニカル指標を組み合わせるためには、まず個々の指標を計算し、それらの関係性を分析します。ここでは例として、移動平均線、RSI、MACDを組み合わせて分析する方法を解説します。

```python
import yfinance as yf

    (df["SMA_20"] < df["Close"]) & (df["RSI"] > 70) & (df["MACD"] < df["Signal"])
)

# 可視化
```

### 6.6. 異常値の検出と処理: 外れ値の影響を軽減

#### 概要と重要性

データ分析において、異常値（外れ値）は分析結果に大きな影響を与える可能性があります。特に金融市場のデータはノイズが多く、異常値が頻繁に発生します。これらの異常値を適切に検出し、処理することで、より信頼性の高い分析結果を得ることができます。

#### 特徴と利点

*   **分析精度の向上:** 異常値を処理することで、分析結果の精度が向上します。
*   **予測精度の向上:** 異常値の影響を軽減することで、将来の価格変動の予測精度が向上します。
*   **リスク管理の強化:** 異常値を早期に検出することで、予期せぬ損失を回避し、リスク管理を強化することができます。

#### 事前準備と前提条件

*   **Python環境:** Python 3.7以上がインストールされていること。
*   **必要なライブラリ:** `pandas`, `numpy`, `matplotlib`, `scipy`

これらのライブラリは、事前にインストールしておく必要があります。

#### 基本的な使い方

異常値を検出するためには、様々な手法があります。ここでは例として、Zスコア法、四分位範囲（IQR）法、移動平均法を解説します。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats
import pandas_datareader.data as web

# 株価データの取得 (例: Apple)
start = '2023-01-01'
end = '2024-01-01'
df = web.DataReader('AAPL', 'yahoo', start, end)

# Zスコア法
def detect_outliers_zscore(data, threshold=3):
    """Zスコア法で異常値を検出する関数"""
    z = np.abs(stats.zscore(data['Close']))
    outlier_indices = np.where(z > threshold)
    return outlier_indices[0]

# IQR法
def detect_outliers_iqr(data):
    """IQR法で異常値を検出する関数"""
    Q1 = data['Close'].quantile(0.25)
    Q3 = data['Close'].quantile(0.75)
    IQR = Q3 - Q1
    outlier_indices = data[(data['Close'] < Q1 - 1.5 * IQR) | (data['Close'] > Q3 + 1.5 * IQR)].index
    return outlier_indices

# 移動平均法
def detect_outliers_moving_average(data, window=20, threshold=2):
    """移動平均法で異常値を検出する関数"""
    moving_average = data['Close'].rolling(window=window).mean()
    moving_std = data['Close'].rolling(window=window).std()
    outlier_indices = data[abs(data['Close'] - moving_average) > threshold * moving_std].index
    return outlier_indices

# 異常値の検出
zscore_outliers = detect_outliers_zscore(df)
iqr_outliers = detect_outliers_iqr(df)
moving_average_outliers = detect_outliers_moving_average(df)

print("Zスコア法で検出された異常値:", zscore_outliers)
print("IQR法で検出された異常値:", iqr_outliers.values)
print("移動平均法で検出された異常値:", moving_average_outliers.values)
```

異常値を検出した後、どのように処理するかを決定する必要があります。一般的な処理方法としては、削除、補完、変換などがあります。

```python
# 異常値の処理 (例: 補完)
def handle_outliers_interpolation(data):
    """線形補完で異常値を処理する関数"""
    data_copy = data.copy()
    data_copy['Close'].iloc[zscore_outliers] = np.nan
    data_copy['Close'].interpolate(inplace=True)
    return data_copy

df_cleaned = handle_outliers_interpolation(df)

# 可視化
plt.figure(figsize=(12, 6))
plt.plot(df['Close'], label='Original Data')
plt.plot(df_cleaned['Close'], label='Cleaned Data (Interpolation)')
plt.plot(df.iloc[zscore_outliers]['Close'], marker='o', color='red', markersize=8, label='Outliers')
plt.legend()
plt.title('Outlier Detection and Handling')
plt.show()
```
