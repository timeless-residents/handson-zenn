## 第 6 章：生成戦略：より自然で多様なキャプションを生成する

AI が生成するキャプションは、時に紋切り型で面白みに欠けることがあります。しかし、生成戦略を工夫することで、より自然で多様なキャプションを生み出すことが可能です。この章では、基本的な生成戦略から、より高度なテクニックまでを解説し、読者の皆さんが AI を活用して魅力的なキャプションを作成できるようになることを目指します。

### Greedy Search、Beam Search：基本的な生成戦略

**概要と重要性**

キャプション生成の最も基本的なアプローチは、Greedy Search と Beam Search です。これらの手法は、AI モデルが生成する単語の確率に基づいて、最も可能性の高い単語を選択していくことでキャプションを構築します。

Greedy Search はシンプルで高速ですが、局所的な最適解に陥りやすく、不自然なキャプションを生成しやすいという欠点があります。一方、Beam Search は、複数の候補を保持しながら探索を進めるため、より良いキャプションを生成する可能性が高まります。

**特徴と利点**

- **Greedy Search:**
  - 特徴：最も確率の高い単語を逐次的に選択
  - 利点：高速で実装が容易
- **Beam Search:**
  - 特徴：ビーム幅（beam size）と呼ばれるパラメータで指定された数の候補を保持しながら探索
  - 利点：Greedy Search よりも高品質なキャプションを生成しやすい

**事前準備と前提条件**

- Python 環境
- PyTorch などの深層学習フレームワーク
- 事前に学習済みのキャプション生成モデル (例: image captioning モデル)

**基本的な使い方**

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

# モデルとトークナイザーのロード
model_name = "gpt2"  # 例: GPT-2
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

def generate_caption_greedy(prompt, max_length=20):
    """Greedy Searchによるキャプション生成"""
    input_ids = tokenizer.encode(prompt, return_tensors="pt")
    generated_ids = model.generate(input_ids, max_length=max_length)
    caption = tokenizer.decode(generated_ids[0], skip_special_tokens=True)
    return caption

def generate_caption_beam_search(prompt, beam_size=5, max_length=20):
    """Beam Searchによるキャプション生成"""
    input_ids = tokenizer.encode(prompt, return_tensors="pt")
    generated_ids = model.generate(
        input_ids,
        max_length=max_length,
        num_beams=beam_size,
        early_stopping=True,
        num_return_sequences=1 # 複数の候補を返すことも可能
    )
    caption = tokenizer.decode(generated_ids[0], skip_special_tokens=True)
    return caption

# 例
prompt = "A photo of a cat"
greedy_caption = generate_caption_greedy(prompt)
beam_search_caption = generate_caption_beam_search(prompt)

print("Greedy Search:", greedy_caption)
print("Beam Search:", beam_search_caption)
```

**実践的なテクニック**

- **ビーム幅の調整:** ビーム幅を大きくすると、より多様な候補を探索できますが、計算コストが増加します。適切なビーム幅は、モデルの性能や計算リソースによって異なります。一般的には、3〜10 程度が用いられます。
- **長さの正規化 (Length Normalization):** Beam Search において、生成されるキャプションの長さが長くなるほどスコアが低くなる傾向があります。これを防ぐために、生成されたキャプションの長さを考慮した正規化を行うことが効果的です。`length_penalty` パラメータを調整することで、長さを考慮したスコアリングが可能です。
- **Early Stopping:** `early_stopping=True` を設定することで、ビームサーチが完了する前に、十分な数の文が生成された時点で処理を停止し、計算時間を短縮することができます。

**応用例とユースケース**

- **EC サイトの商品説明:** 商品の画像から自動で説明文を生成し、商品ページの作成を効率化します。
- **SNS の投稿文作成:** ユーザーがアップロードした画像から、魅力的な投稿文を生成し、SNS のエンゲージメントを高めます。
- **動画の字幕生成:** 動画の内容を解析し、自動で字幕を生成することで、アクセシビリティを向上させます。

**トラブルシューティング**

- **生成されるキャプションが単調:** より多様なキャプションを生成するために、Sampling などの高度な生成戦略を検討してください。
- **生成されるキャプションが長すぎる/短すぎる:** `max_length` パラメータを調整して、適切な長さを設定してください。また、`min_length` パラメータも利用可能です。
- **メモリ不足:** ビーム幅を小さくしたり、バッチサイズを小さくしたりして、メモリ使用量を削減してください。

**まとめと次のステップ**

Greedy Search と Beam Search は、キャプション生成の基本的な手法ですが、より自然で多様なキャプションを生成するためには、Sampling などの高度な生成戦略が必要となります。次のセクションでは、Sampling について詳しく解説します。

### Sampling：多様なキャプションを生成する

**概要と重要性**

Sampling は、確率分布に基づいて単語をランダムに選択する生成戦略です。これにより、Greedy Search や Beam Search では得られない、より多様で創造的なキャプションを生成することができます。

Sampling には、Temperature Sampling、Top-k Sampling、Nucleus Sampling (Top-p Sampling)などの様々なバリエーションがあります。それぞれの特徴を理解し、適切な手法を選択することが重要です。

**特徴と利点**

- **Temperature Sampling:**
  - 特徴：モデルが出力する確率分布の温度（temperature）を調整することで、生成されるキャプションのランダム性を制御します。温度が高いほど、より多様なキャプションが生成されますが、文法的に不自然なキャプションも生成されやすくなります。
  - 利点：ランダム性の制御が容易
- **Top-k Sampling:**
  - 特徴：確率上位 k 個の単語の中からランダムに選択します。
  - 利点：比較的自然なキャプションを生成しやすい
- **Nucleus Sampling (Top-p Sampling):**
  - 特徴：確率の累積値が閾値 p を超えるまで、確率の高い単語を選択し、その中からランダムに選択します。
  - 利点：文脈に応じて適切なランダム性を付与できる

**事前準備と前提条件**

- 前項と同様

**基本的な使い方**

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

# モデルとトークナイザーのロード
model_name = "gpt2"  # 例: GPT-2
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

def generate_caption_temperature_sampling(prompt, temperature=1.0, max_length=20):
    """Temperature Samplingによるキャプション生成"""
    input_ids = tokenizer.encode(prompt, return_tensors="pt")
    generated_ids = model.generate(
        input_ids,
        max_length=max_length,
        do_sample=True,
        temperature=temperature
    )
    caption = tokenizer.decode(generated_ids[0], skip_special_tokens=True)
    return caption

def generate_caption_top_k_sampling(prompt, k=50, max_length=20):
    """Top-k Samplingによるキャプション生成"""
    input_ids = tokenizer.encode(prompt, return_tensors="pt")
    generated_ids = model.generate(
        input_ids,
        max_length=max_length,
        do_sample=True,
        top_k=k
    )
    caption = tokenizer.decode(generated_ids[0], skip_special_tokens=True)
    return caption

def generate_caption_top_p_sampling(prompt, p=0.9, max_length=20):
    """Top-p (Nucleus) Samplingによるキャプション生成"""
    input_ids = tokenizer.encode(prompt, return_tensors="pt")
    generated_ids = model.generate(
        input_ids,
        max_length=max_length,
        do_sample=True,
        top_p=p,
        top_k=0 # top_kと同時に使用しない
    )
    caption = tokenizer.decode(generated_ids[0], skip_special_tokens=True)
    return caption

# 例
prompt = "A photo of a cat"
temperature_caption = generate_caption_temperature_sampling(prompt, temperature=0.7)
top_k_caption = generate_caption_top_k_sampling(prompt, k=30)
top_p_caption = generate_caption_top_p_sampling(prompt, p=0.9)

print("Temperature Sampling:", temperature_caption)
print("Top-k Sampling:", top_k_caption)
print("Top-p Sampling:", top_p_caption)
```

**実践的なテクニック**

- **Temperature の調整:** 温度を高くすると、より多様なキャプションが生成されますが、文法的に不自然になる可能性が高まります。逆に、温度を低くすると、より安定したキャプションが生成されます。適切な温度は、モデルの性能やタスクによって異なります。0.7〜1.2 程度が一般的です。
- **k の調整:** Top-k Sampling において、k を大きくすると、より多様なキャプションが生成されます。しかし、k を大きくしすぎると、関係のない単語が選択される可能性が高まります。
- **p の調整:** Top-p Sampling において、p を大きくすると、より多様なキャプションが生成されます。p を小さくすると、より安定したキャプションが生成されます。

**応用例とユースケース**

- **ブログ記事のタイトル生成:** ブログ記事の内容から、魅力的なタイトルを複数生成し、読者の興味を引きます。
- **広告コピーの作成:** 商品やサービスの情報を基に、様々な表現の広告コピーを生成し、広告効果を高めます。
- **物語のプロット生成:** 物語のテーマや登場人物を設定し、複数のプロットを生成することで、創作活動を支援します。

**トラブルシューティング**

- **生成されるキャプションが意味不明:** Temperature が高すぎる可能性があります。Temperature を下げてみてください。Top-k や Top-p Sampling を試すのも有効です。
- **生成されるキャプションが同じものばかり:** Sampling が機能していない可能性があります。`do_sample=True`が設定されているか確認してください。

**まとめと次のステップ**

Sampling は、多様なキャプションを生成するための強力な手法です。Temperature Sampling、Top-k Sampling、Top-p Sampling などの様々なバリエーションを理解し、タスクに応じて使い分けることが重要です。次のセクションでは、生成されたキャプションの中から最適なものを選択する方法について解説します。

### キャプションの評価と選択：生成されたキャプションの中から最適なものを選択する

**概要と重要性**

Sampling などの手法で複数のキャプションを生成した場合、その中から最も適切で魅力的なキャプションを選択する必要があります。キャプションの評価と選択は、最終的なキャプションの品質を大きく左右する重要なステップです。

評価方法としては、人間の評価、自動評価メトリクス、モデルによる評価などがあります。それぞれの特徴を理解し、状況に応じて適切な評価方法を選択することが重要です。

**特徴と利点**

- **人間の評価:**
  - 特徴：人間がキャプションを読んで、その品質や適切さを評価します。
  - 利点：最も正確な評価が可能
  - 欠点：時間とコストがかかる
- **自動評価メトリクス:**
  - 特徴：BLEU、ROUGE、METEOR などの指標を用いて、キャプションの品質を自動的に評価します。
  - 利点：高速で客観的な評価が可能
  - 欠点：必ずしも人間の評価と一致しない
- **モデルによる評価:**
  - 特徴：別の AI モデルを用いて、キャプションの品質を評価します。
  - 利点：自動評価メトリクスよりも人間の評価に近い結果が得られる可能性がある
  - 欠点：計算コストが高い

**事前準備と前提条件**

- 生成されたキャプションのリスト
- 自動評価メトリクスを使用する場合は、NLTK などのライブラリ
- モデルによる評価を行う場合は、学習済みの評価モデル

**基本的な使い方**

```python
from nltk.translate.bleu_score import sentence_bleu

def evaluate_caption_bleu(candidate, reference):
    """BLEUスコアによるキャプションの評価"""
    reference = [reference.split()]  # referenceはリストのリストでなければならない
    candidate = candidate.split()
    score = sentence_bleu(reference, candidate)
    return score

# 例
candidate_caption = "A cute cat is sleeping on the sofa."
reference_caption = "The adorable cat sleeps soundly on the couch."

bleu_score = evaluate_caption_bleu(candidate_caption, reference_caption)
print("BLEU Score:", bleu_score)
```

**実践的なテクニック**

- **複数の評価指標の組み合わせ:** BLEU、ROUGE、METEOR などの複数の評価指標を組み合わせることで、より総合的な評価を行うことができます。
- **人間の評価と自動評価の組み合わせ:** 自動評価で候補を絞り込み、絞り込まれた候補を人間が評価することで、効率的に最適なキャプションを選択することができます。
- **ランキング学習:** 複数のキャプションを生成し、それぞれのキャプションに対して人間の評価を行い、その結果を基にランキング学習を行うことで、より人間の評価に近いキャプションを選択するモデルを構築することができます。

**応用例とユースケース**

- **キャプション生成システムの品質評価:** 生成されたキャプションを評価することで、システムの改善点を特定し、品質向上に役立てます。
- **最適なキャプションの自動選択:** 生成された複数のキャプションの中から、自動的に最適なキャプションを選択し、ユーザーに提供します。
- **キャプションの自動修正:** 生成されたキャプションを評価し、問題点があれば自動的に修正することで、品質を向上させます。

**トラブルシューティング**

- **自動評価メトリクスと人間の評価が一致しない:** 自動評価メトリクスは、必ずしも人間の評価と一致するとは限りません。人間の評価を参考に、適切な評価指標を選択する必要があります。
- **評価モデルの学習に時間がかかる:** 評価モデルの学習には、大量のデータと計算リソースが必要です。事前に学習済みのモデルを利用したり、分散学習を行うなどの対策が必要です。

**まとめと次のステップ**

キャプションの評価と選択は、生成されたキャプションの品質を大きく左右する重要なステップです。人間の評価、自動評価メトリクス、モデルによる評価などの様々な評価方法を理解し、状況に応じて適切な方法を選択することが重要です。

### 実装例：Python による各種生成戦略の実装と比較

**概要と重要性**

このセクションでは、これまでに解説した Greedy Search、Beam Search、Sampling といった各種生成戦略を Python で実装し、その動作と結果を比較します。実際にコードを動かすことで、それぞれの生成戦略の特徴をより深く理解することができます。

**特徴と利点**

- **実践的なコード例:** 各生成戦略の具体的なコード例を提供します。
- **比較と分析:** 各生成戦略の出力結果を比較し、それぞれの利点と欠点を分析します。
- **カスタマイズのヒント:** 各生成戦略のパラメータを調整し、出力結果を改善するためのヒントを提供します。

**事前準備と前提条件**

- Python 環境
- PyTorch などの深層学習フレームワーク
- Transformers ライブラリ
- 事前に学習済みのキャプション生成モデル (例: GPT-2, Bart, T5)

**実装例**

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

# モデルとトークナイザーのロード
model_name = "gpt2"  # 例: GPT-2
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

def generate_caption(prompt, strategy="greedy", **kwargs):
    """キャプション生成関数（各種戦略に対応）"""
    input_ids = tokenizer.encode(prompt, return_tensors="pt")

    if strategy == "greedy":
        generated_ids = model.generate(input_ids, **kwargs)
    elif strategy == "beam":
        generated_ids = model.generate(input_ids, num_beams=5, early_stopping=True, **kwargs)
    elif strategy == "temperature":
        generated_ids = model.generate(input_ids, do_sample=True, temperature=0.7, **kwargs)
    elif strategy == "top_k":
        generated_ids = model.generate(input_ids, do_sample=True, top_k=50, **kwargs)
    elif strategy == "top_p":
        generated_ids = model.generate(input_ids, do_sample=True, top_p=0.9, top_k=0, **kwargs) # top_k=0 は重要
    else:
        raise ValueError("Invalid strategy.")

    caption = tokenizer.decode(generated_ids[0], skip_special_tokens=True)
    return caption

# プロンプト
prompt = "A photo of a delicious pizza"

# 各生成戦略でキャプションを生成
greedy_caption = generate_caption(prompt, strategy="greedy", max_length=20)
beam_caption = generate_caption(prompt, strategy="beam", max_length=20)
temperature_caption = generate_caption(prompt, strategy="temperature", max_length=20)
top_k_caption = generate_caption(prompt, strategy="top_k", max_length=20)
top_p_caption = generate_caption(prompt, strategy="top_p", max_length=20)

# 結果の表示
print("Greedy Search:", greedy_caption)
print("Beam Search:", beam_caption)
print("Temperature Sampling:", temperature_caption)
print("Top-k Sampling:", top_k_caption)
print("Top-p Sampling:", top_p_caption)
```

**比較と分析**

上記のコードを実行すると、各生成戦略で異なるキャプションが生成されます。

- **Greedy Search:** 高速ですが、単調で面白みのないキャプションになりがちです。
- **Beam Search:** Greedy Search よりも高品質なキャプションを生成できますが、計算コストが高くなります。
- **Temperature Sampling:** ランダム性が高く、創造的なキャプションが生成される可能性がありますが、文法的に不自然なキャプションも生成されやすくなります。
- **Top-k Sampling:** Temperature Sampling よりも安定したキャプションを生成できますが、多様性はやや低くなります。
- **Top-p Sampling:** 文脈に応じて適切なランダム性を付与できるため、バランスの取れたキャプションを生成できます。

**実践的なテクニック**

- **戦略の組み合わせ:** 複数の生成戦略を組み合わせることで、より高度なキャプション生成が可能です。例えば、Beam Search で複数の候補を生成し、その中から Temperature Sampling でランダムに選択する、といった方法があります。
- **Fine-tuning:** 特定のタスクに特化したキャプションを生成するために、モデルを Fine-tuning することも有効です。
- **Prompt Engineering:** プロンプトを工夫することで、生成されるキャプションの品質を向上させることができます。

**応用例とユースケース**

- **データ拡張:** 生成されたキャプションをデータ拡張に利用することで、モデルの汎化性能を向上させることができます。
- **多様なコンテンツ生成:** 様々な生成戦略を組み合わせることで、多様なコンテンツを自動生成することができます。

**トラブルシューティング**

- **CUDA out of memory エラー:** GPU のメモリが不足している可能性があります。バッチサイズを小さくしたり、モデルを CPU に移動したり、不要な変数を削除したりすることで、メモリ使用量を削減できます。
- **生成されるキャプションが期待どおりにならない:** プロンプトを調整したり、生成戦略のパラメータを調整したりすることで、出力結果を改善できる可能性があります。
