## 第 11 章：対話型キャプショニング：質問応答とキャプション生成の融合

### 質問応答システムの基礎：QA モデルの仕組み

**概要と重要性**

画像の内容を理解するために、従来のキャプション生成モデルは単に画像を説明するテキストを生成するだけでした。しかし、現実世界では、画像に関する疑問を持つことがあります。例えば、「これは何をしている場面ですか？」や「この人の服装の特徴は？」といった具体的な質問です。質問応答（QA）システムは、このような質問に対して、画像の内容を理解し、適切な回答を提供する役割を果たします。対話型キャプショニングは、この QA システムとキャプション生成モデルを融合させ、よりインタラクティブで深い画像理解を可能にする技術です。

**特徴と利点**

QA システムは、以下の特徴と利点があります。

- **特定の質問への回答:** 画像全体ではなく、特定の質問に焦点を当てた回答を提供できます。
- **詳細な情報抽出:** 画像の細部やコンテキストに関する情報を引き出すことができます。
- **ユーザーとの対話:** ユーザーの質問に応じて、追加の情報を提供したり、回答を修正したりできます。
- **キャプションの改善:** 質問応答の結果をキャプション生成にフィードバックすることで、より正確で詳細なキャプションを生成できます。

**事前準備と前提条件**

QA モデルを理解し実装するには、以下の知識が必要です。

- **自然言語処理（NLP）の基礎:** 単語の埋め込み、シーケンスモデル、Attention 機構など。
- **深層学習の基礎:** ニューラルネットワーク、畳み込みニューラルネットワーク（CNN）、リカレントニューラルネットワーク（RNN）など。
- **Python の基礎:** PyTorch などの深層学習フレームワークの使用経験。

**基本的な使い方**

QA システムは、通常、以下のステップで構成されます。

1.  **質問のエンコード:** 質問文をベクトル表現に変換します。
2.  **画像のエンコード:** 画像をベクトル表現に変換します。
3.  **Attention メカニズム:** 質問と画像の特徴量を照合し、関連性の高い部分に注意を向けます。
4.  **回答の生成:** 注意機構に基づいて、回答を生成します。

**実践的なテクニック**

QA モデルの性能を向上させるためのテクニックをいくつか紹介します。

- **データ拡張:** 質問と回答のペアを生成し、モデルの学習データを増やします。
- **アンサンブル学習:** 複数の QA モデルを組み合わせることで、より頑健なシステムを構築します。
- **事前学習済みモデルの利用:** BERT や RoBERTa などの事前学習済みモデルを利用することで、学習効率を向上させます。
- **Attention 機構の改良:** より高度な Attention 機構（例えば、Self-Attention や Multi-Head Attention）を導入します。

**応用例とユースケース**

QA システムは、様々な分野で応用されています。

- **画像検索:** ユーザーの質問に基づいて画像を検索できます。
- **医療診断:** 医療画像に関する質問に答えることで、医師の診断を支援します。
- **教育:** 画像教材に関する質問に答えることで、学生の学習をサポートします。
- **カスタマーサポート:** 商品画像に関する質問に答えることで、顧客の問い合わせに対応します。

**トラブルシューティング**

QA システムを構築する際に、よく遭遇する問題とその解決策を紹介します。

- **学習データの不足:** データ拡張や事前学習済みモデルの利用を検討します。
- **過学習:** ドロップアウトや正則化などの手法を適用します。
- **Attention 機構の不具合:** Attention の可視化ツールを利用して、Attention が適切に働いているか確認します。
- **計算資源の不足:** GPU の利用やモデルの軽量化を検討します。

### 対話型キャプショニングモデル：Question-Guided Attention

**概要と重要性**

対話型キャプショニングモデルは、質問応答システムとキャプション生成モデルを組み合わせたものです。従来のキャプション生成モデルは、画像を単に説明するテキストを生成するだけでしたが、対話型キャプショニングモデルは、ユーザーの質問に応じて、より詳細で関連性の高いキャプションを生成できます。Question-Guided Attention（質問誘導型 Attention）は、質問の内容に基づいて画像のどの部分に注意を向けるかを制御するメカニズムであり、対話型キャプショニングモデルの中核となる技術です。

**特徴と利点**

Question-Guided Attention は、以下の特徴と利点があります。

- **質問に基づいた注意:** 質問の内容に応じて、画像の関連部分に注意を向けることができます。
- **詳細なキャプション生成:** 画像全体ではなく、質問に関連する部分に焦点を当てた詳細なキャプションを生成できます。
- **ユーザーとの対話:** ユーザーの質問に応じて、キャプションの内容を調整できます。
- **キャプションの精度向上:** 質問情報を活用することで、キャプションの精度を向上させることができます。

**事前準備と前提条件**

Question-Guided Attention を理解し実装するには、以下の知識が必要です。

- **Attention 機構の基礎:** Self-Attention、Multi-Head Attention など。
- **キャプション生成モデルの基礎:** Encoder-Decoder モデル、Seq2Seq モデルなど。
- **質問応答システムの基礎:** QA モデルの仕組み。

**基本的な使い方**

Question-Guided Attention は、通常、以下のステップで構成されます。

1.  **質問のエンコード:** 質問文をベクトル表現に変換します。
2.  **画像のエンコード:** 画像をベクトル表現に変換します。
3.  **質問誘導型 Attention:** 質問のベクトル表現を用いて、画像の特徴マップに対する Attention 重みを計算します。
4.  **コンテキストベクトルの生成:** Attention 重みを用いて、画像の特徴マップを重み付けし、コンテキストベクトルを生成します。
5.  **キャプションの生成:** コンテキストベクトルと前のステップで生成された単語を用いて、次の単語を予測します。

**実践的なテクニック**

Question-Guided Attention の性能を向上させるためのテクニックをいくつか紹介します。

- **Attention 機構の改良:** より高度な Attention 機構（例えば、Transformer の Multi-Head Attention）を導入します。
- **質問と画像の融合:** 質問と画像の特徴量を効果的に融合させるためのアーキテクチャを設計します。
- **事前学習済みモデルの利用:** BERT や RoBERTa などの事前学習済みモデルを利用して、質問のエンコードを強化します。
- **損失関数の工夫:** キャプションの精度を向上させるための損失関数（例えば、CIDEr や SPICE）を導入します。

**応用例とユースケース**

Question-Guided Attention は、様々な分野で応用されています。

- **画像検索:** ユーザーの質問に基づいて、詳細な説明文を含む画像を検索できます。
- **教育:** 画像教材に関する質問に答えることで、学生の学習を支援します。
- **カスタマーサポート:** 商品画像に関する質問に答えることで、顧客の問い合わせに対応します。
- **アクセシビリティ:** 視覚障碍者向けに、画像の内容を詳細に説明するテキストを生成します。

**トラブルシューティング**

Question-Guided Attention を構築する際に、よく遭遇する問題とその解決策を紹介します。

- **Attention が質問に適切に誘導されない:** Attention の可視化ツールを利用して、Attention が適切に働いているか確認します。
- **キャプションが質問と無関係:** 質問と画像の融合方法を見直します。
- **キャプションの精度が低い:** 損失関数の見直しや、学習データの増強を検討します。

### 強化学習：対話を通じたキャプションの改善

**概要と重要性**

強化学習は、エージェントが環境との相互作用を通じて最適な行動を学習する機械学習の一分野です。対話型キャプショニングにおいて、強化学習は、生成されたキャプションの品質を向上させるために使用されます。特に、人間との対話を通じて報酬を得ることで、モデルはより自然で人間らしいキャプションを生成する能力を向上させることができます。

**特徴と利点**

強化学習を用いたキャプション改善には、以下の特徴と利点があります。

- **人間の評価を反映:** 人間がキャプションを評価し、報酬を与えることで、モデルは人間の好みに合ったキャプションを学習できます。
- **長期的な報酬の最大化:** モデルは、短期的な報酬だけでなく、長期的な報酬を最大化するように学習するため、より包括的で正確なキャプションを生成できます。
- **多様なキャプションの生成:** 強化学習は、exploration と exploitation のバランスを取ることで、多様なキャプションを生成する能力を向上させます。
- **非可微分な評価指標の利用:** CIDEr や SPICE などの、微分不可能な評価指標を報酬関数として使用できます。

**事前準備と前提条件**

強化学習を対話型キャプショニングに適用するには、以下の知識が必要です。

- **強化学習の基礎:** マルコフ決定過程（MDP）、Q 学習、方策勾配法など。
- **キャプション生成モデルの基礎:** Encoder-Decoder モデル、Seq2Seq モデルなど。
- **報酬関数の設計:** 適切な報酬関数を設計する能力。

**基本的な使い方**

強化学習を用いたキャプション改善は、通常、以下のステップで構成されます。

1.  **環境の定義:** 画像、質問、現在のキャプションの状態を環境として定義します。
2.  **行動の定義:** 次の単語を選択する行動を定義します。
3.  **報酬関数の定義:** 生成されたキャプションの品質を評価する報酬関数を定義します。
4.  **エージェントの学習:** 強化学習アルゴリズム（例えば、REINFORCE や Actor-Critic）を用いて、エージェントを学習させます。

**実践的なテクニック**

強化学習を用いたキャプション改善の性能を向上させるためのテクニックをいくつか紹介します。

- **報酬関数の工夫:** 複数の評価指標を組み合わせたり、人間の評価を導入したりすることで、より適切な報酬関数を設計します。
- **探索戦略の改良:** ε-greedy 法や Boltzmann 探索などの、より効果的な探索戦略を導入します。
- **方策勾配法の分散削減:** REINFORCE アルゴリズムの分散を削減するためのテクニック（例えば、Baseline 法）を適用します。
- **Actor-Critic 法の導入:** Actor と Critic の両方を学習することで、学習の安定性を向上させます。

強化学習は、様々な分野で応用されています。

強化学習を対話型キャプショニングに適用する際に、よく遭遇する問題とその解決策を紹介します。

**1. データの前処理**

画像データと質問データを読み込み、モデルが処理できる形式に変換します。ここでは、COCO データセットを想定しています。

```python
import torch
import torchvision.transforms as transforms
from PIL import Image
import nltk

# トークナイザの準備
nltk.download('punkt')

class Vocabulary(object):
    def __init__(self):
        self.word2idx = {}
        self.idx2word = {}
        self.idx = 0

    def add_word(self, word):
        if not word in self.word2idx:
            self.word2idx[word] = self.idx
            self.idx2word[self.idx] = word
            self.idx += 1

    def __call__(self, word):
        if not word in self.word2idx:
            return self.word2idx['<unk>']
        return self.word2idx[word]

def build_vocab(caption_path, threshold):
    """Build a simple vocabulary wrapper."""
    with open(caption_path, 'r', encoding="utf8") as f:
        captions = f.readlines()

    counter = {}
    vocab = Vocabulary()
    vocab.add_word('<pad>')
    vocab.add_word('<start>')
    vocab.add_word('<end>')
    vocab.add_word('<unk>')

    for i, caption in enumerate(captions):
        tokens = nltk.tokenize.word_tokenize(caption.lower())
        for token in tokens:
            if not token in counter:
                counter[token] = 0
            counter[token] += 1

        if (i+1) % 1000 == 0:
            print("[{}/{}]: Tokenized the captions.".format(i+1, len(captions)))

    # If the word frequency is less than 'threshold', then simply discard it.
    words = [word for word, cnt in counter.items() if cnt >= threshold]

    # Create the vocabulary.
    for i, word in enumerate(words):
        vocab.add_word(word)
    return vocab

# 画像の変換
def transform():
    return transforms.Compose([
        transforms.Resize(256),
        transforms.CenterCrop(224),
        transforms.ToTensor(),
        transforms.Normalize((0.485, 0.456, 0.406),
                             (0.229, 0.224, 0.225))])

# 例：
vocab = build_vocab("captions.txt", threshold=4) # キャプションファイルのパスと出現頻度の閾値を設定
transform = transform()
```

**2. Encoder の構築**

CNN を用いて画像をエンコードします。ここでは、ResNet-152 をベースに、最終層を削除したものを使用します。

```python
import torch.nn as nn
import torchvision.models as models

class EncoderCNN(nn.Module):
    def __init__(self, embed_size):
        super(EncoderCNN, self).__init__()
        resnet = models.resnet152(pretrained=True)
        modules = list(resnet.children())[:-1]      # delete the last fc layer.
        self.resnet = nn.Sequential(*modules)
        self.linear = nn.Linear(resnet.fc.in_features, embed_size)
        self.bn = nn.BatchNorm1d(embed_size, momentum=0.01)

    def forward(self, images):
        """Extract feature vectors from pre-trained ResNet."""
        with torch.no_grad():
            features = self.resnet(images)
        features = features.reshape(features.size(0), -1)
        features = self.bn(self.linear(features))
        return features
```

**3. Question Encoder の構築**

LSTM を用いて質問文をエンコードします。

```python
class QuestionEncoder(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size):
        super(QuestionEncoder, self).__init__()
        self.embed = nn.Embedding(vocab_size, embed_size)
        self.lstm = nn.LSTM(embed_size, hidden_size, batch_first=True)

    def forward(self, questions, lengths):
        """Encode question vectors."""
        embeddings = self.embed(questions)
        packed = torch.nn.utils.rnn.pack_padded_sequence(embeddings, lengths, batch_first=True, enforce_sorted=False)
        outputs, (hidden, cell) = self.lstm(packed)
        return hidden[0] # Return only the last hidden state
```

**4. Attention 機構の構築**

質問と画像の特徴量に基づいて Attention 重みを計算します。

```python
class Attention(nn.Module):
    def __init__(self, image_feature_size, question_feature_size, attention_hidden_size):
        super(Attention, self).__init__()
        self.linear_image = nn.Linear(image_feature_size, attention_hidden_size)
        self.linear_question = nn.Linear(question_feature_size, attention_hidden_size)
        self.linear_attention = nn.Linear(attention_hidden_size, 1)

    def forward(self, image_features, question_features):
        """Compute attention weights."""
        # image_features: (batch_size, image_feature_size)
        # question_features: (batch_size, question_feature_size)
        batch_size = image_features.size(0)

        # Calculate attention weights
        image_proj = self.linear_image(image_features)
        question_proj = self.linear_question(question_features).unsqueeze(1) # (batch_size, 1, attention_hidden_size)

        # Repeat image_proj to match question_proj's dimension
        image_proj = image_proj.unsqueeze(1)

        # Calculating attention scores
        attention_scores = torch.tanh(image_proj + question_proj)
        attention_scores = self.linear_attention(attention_scores).squeeze(2) # (batch_size, 1)

        # Applying softmax to get attention weights
        attention_weights = torch.softmax(attention_scores, dim=1) # (batch_size, 1)

        return attention_weights
```

**5. Decoder の構築**

Attention 機構からの情報と前の単語に基づいて、次の単語を予測します。

```python
class DecoderRNN(nn.Module):
    def __init__(self, embed_size, hidden_size, vocab_size, num_layers, image_feature_size, question_feature_size, attention_hidden_size):
        super(DecoderRNN, self).__init__()
        self.embed = nn.Embedding(vocab_size, embed_size)
        self.attention = Attention(image_feature_size, question_feature_size, attention_hidden_size)
        self.lstm = nn.LSTM(embed_size + image_feature_size, hidden_size, num_layers, batch_first=True)
        self.linear = nn.Linear(hidden_size, vocab_size)

    def forward(self, features, captions, lengths, question_features):
        """Decode image feature vectors and generates captions."""
        embeddings = self.embed(captions)

        # Prepare image features
        image_features_expanded = features.unsqueeze(1).expand(-1, embeddings.size(1), -1)

        # Calculate attention weights
        attention_weights = self.attention(features, question_features)

        # Apply attention to the image features
        attended_image_features = features * attention_weights

        # Concatenate image features and embeddings
        inputs = torch.cat((embeddings, image_features_expanded), 2)

        packed = torch.nn.utils.rnn.pack_padded_sequence(inputs, lengths, batch_first=True, enforce_sorted=False)
        hiddens, _ = self.lstm(packed)
        outputs = self.linear(hiddens[0])
        return outputs
```

```python
class InteractiveCaptioningModel(nn.Module):
    def __init__(self, embed_size, hidden_size, vocab_size, num_layers, image_feature_size, question_feature_size, attention_hidden_size):
        super(InteractiveCaptioningModel, self).__init__()
        self.encoder = EncoderCNN(image_feature_size)
        self.question_encoder = QuestionEncoder(vocab_size, embed_size, question_feature_size)
        self.decoder = DecoderRNN(embed_size, hidden_size, vocab_size, num_layers, image_feature_size, question_feature_size, attention_hidden_size)

    def forward(self, images, questions, question_lengths, captions, lengths):
        """Generate captions for images given questions."""
        image_features = self.encoder(images)
        question_features = self.question_encoder(questions, question_lengths)
        outputs = self.decoder(image_features, captions, lengths, question_features)
        return outputs
```
