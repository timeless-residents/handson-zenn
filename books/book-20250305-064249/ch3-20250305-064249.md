## 第3章：センサーデータの取得と処理：温湿度、照度、加速度

この章では、環境モニタリングや制御、モーション検知など、幅広い用途で活躍する温湿度、照度、加速度センサーの活用方法について解説します。DHT11/DHT22、BH1750/TSL2561、MPU6050/ADXL345といった代表的なセンサーを取り上げ、基本的な使い方から実践的なテクニック、応用例まで、段階的に学習できるように構成しました。初心者の方でも安心して読み進められるように、詳細な説明と具体的なコード例を交えながら、センサーデータの取得と処理に関する知識を深めていきましょう。

### 3.1 温湿度センサー：DHT11/DHT22の利用

#### 3.1.1 概要と重要性

温湿度センサーは、周囲の温度と湿度を測定するセンサーです。住宅、オフィス、工場、農業など、様々な環境で利用されており、環境モニタリング、空調制御、データロギングなど、幅広い用途に活用されています。DHT11とDHT22は、比較的安価で扱いやすい温湿度センサーとして、DIYプロジェクトや教育現場でよく使用されています。

#### 3.1.2 特徴と利点

* **DHT11:**
    * 測定範囲：温度 (0℃ - 50℃)、湿度 (20% - 90%RH)
    * 精度：温度 (±2℃)、湿度 (±5%RH)
    * 低価格
    * 比較的低消費電力
* **DHT22:**
    * 測定範囲：温度 (-40℃ - 80℃)、湿度 (0% - 100%RH)
    * 精度：温度 (±0.5℃)、湿度 (±2%RH)
    * DHT11よりも広い測定範囲と高い精度

どちらのセンサーも、デジタル出力であるため、マイコンとの接続が容易です。単一のピンでデータ伝送を行うため、配線も簡単です。

#### 3.1.3 事前準備と前提条件

* **必要なもの:**
    * DHT11またはDHT22センサー
    * マイコンボード (例：Arduino, Raspberry Pi)
    * ジャンパーワイヤー
    * 抵抗 (4.7kΩ - 10kΩ) ※プルアップ抵抗として使用
* **前提条件:**
    * マイコンボードの基本的な知識
    * Arduino IDEまたはPythonなどのプログラミング環境のセットアップ

#### 3.1.4 基本的な使い方 (Arduinoの場合)

1. **配線:**
    * DHT11/DHT22のVCCピンをマイコンの5Vまたは3.3Vに接続します。
    * DHT11/DHT22のGNDピンをマイコンのGNDに接続します。
    * DHT11/DHT22のDATAピンをマイコンのデジタルピンに接続します (例：2番ピン)。
    * DATAピンとVCCピンの間にプルアップ抵抗 (4.7kΩ - 10kΩ) を接続します。

2. **Arduino IDEへのライブラリのインストール:**
    * Arduino IDEを開き、「スケッチ」->「ライブラリをインクルード」->「ライブラリの管理...」を選択します。
    * 検索バーに「DHT sensor library」と入力し、Adafruit社製のライブラリをインストールします。
    * また、「Adafruit Unified Sensor」ライブラリもインストールします。

3. **サンプルコード:**

```arduino
#include <DHT.h>

#define DHTPIN 2     // DHT11/DHT22のDATAピンが接続されているピン番号
#define DHTTYPE DHT22   // DHT22を使用する場合。DHT11の場合はDHT11に変更

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  delay(2000);  // 2秒間隔で測定

  float h = dht.readHumidity();
  float t = dht.readTemperature();

  if (isnan(h) || isnan(t)) {
    Serial.println("Failed to read from DHT sensor!");
    return;
  }

  Serial.print("Humidity: ");
  Serial.print(h);
  Serial.print(" %\t");
  Serial.print("Temperature: ");
  Serial.print(t);
  Serial.println(" *C");
}
```

4. **コードの説明:**
    * `#include <DHT.h>`: DHTライブラリをインクルードします。
    * `#define DHTPIN 2`: DHTのDATAピンが接続されているデジタルピンを定義します。
    * `#define DHTTYPE DHT22`: 使用するDHTセンサーの種類を定義します。
    * `DHT dht(DHTPIN, DHTTYPE);`: DHTオブジェクトを生成します。
    * `dht.begin();`: DHTセンサーを初期化します。
    * `dht.readHumidity();`: 湿度を読み込みます。
    * `dht.readTemperature();`: 温度を読み込みます (摂氏)。
    * `isnan(h) || isnan(t)`: 読み込みに失敗した場合の処理。
    * `Serial.print(...)`: シリアルモニタに結果を出力します。

5. **実行:**
    * Arduino IDEで上記のコードをコンパイルし、マイコンボードに書き込みます。
    * シリアルモニタを開き、温度と湿度の値が表示されることを確認します。

#### 3.1.5 実践的なテクニック

* **校正:** DHT11/DHT22は、個体差や環境によって測定値に誤差が生じることがあります。正確な測定が必要な場合は、既知の温度と湿度と比較して校正を行うことをお勧めします。
* **フィルタリング:**  測定値にノイズが混入する場合、移動平均フィルターなどのデジタルフィルターを適用することで、より安定した値を得ることができます。
* **データロギング:**  測定したデータをSDカードやクラウドストレージに記録することで、長期的な環境モニタリングが可能になります。

#### 3.1.6 応用例とユースケース

* **スマートホーム:** 室内環境をモニタリングし、エアコンや加湿器を自動制御するシステムを構築できます。
* **農業:** 温室内の温度と湿度を監視し、最適な環境を維持することで、作物の生育を促進できます。
* **気象観測:**  簡易的な気象観測システムを構築し、地域の気象データを収集できます。
* **倉庫管理:** 倉庫内の温度と湿度を監視し、商品の品質劣化を防ぎます。

#### 3.1.7 トラブルシューティング

* **読み込みに失敗する場合:**
    * 配線を確認してください。特に、プルアップ抵抗が正しく接続されているか確認してください。
    * DHTセンサーの種類が正しく設定されているか確認してください。
    * DHTセンサーが破損していないか確認してください。
    * 電源電圧が安定しているか確認してください。
* **測定値が異常な場合:**
    * センサーが直射日光や熱源にさらされていないか確認してください。
    * センサーが結露していないか確認してください。
    * センサーの校正を行ってください。

### 3.2 照度センサー：BH1750/TSL2561の利用

#### 3.2.1 概要と重要性

照度センサーは、周囲の明るさを測定するセンサーです。照明制御、ディスプレイの明るさ調整、セキュリティシステムなど、様々な用途に利用されています。BH1750とTSL2561は、それぞれ異なる特徴を持つ照度センサーであり、用途に応じて使い分けることができます。

#### 3.2.2 特徴と利点

* **BH1750:**
    * デジタル出力 (I2C)
    * 広い測定範囲 (1 - 65535 lx)
    * 周囲光スペクトルに近似した特性
    * 簡単な操作
* **TSL2561:**
    * デジタル出力 (I2C)
    * 高感度 (0.1 - 40000+ lx)
    * 赤外線光と可視光を個別に測定可能
    * 暗所での測定に強い

BH1750は、広い範囲の明るさを測定でき、扱いやすさが特徴です。TSL2561は、高感度で暗所での測定に優れており、より詳細な光の情報が必要な場合に適しています。

#### 3.2.3 事前準備と前提条件

* **必要なもの:**
    * BH1750またはTSL2561センサー
    * マイコンボード (例：Arduino, Raspberry Pi)
    * ジャンパーワイヤー
    * (必要に応じて) 抵抗 (プルアップ抵抗として使用)
* **前提条件:**
    * マイコンボードの基本的な知識
    * I2C通信の基本的な知識
    * Arduino IDEまたはPythonなどのプログラミング環境のセットアップ

#### 3.2.4 基本的な使い方 (Arduinoの場合)

1. **配線:**
    * BH1750/TSL2561のVCCピンをマイコンの5Vまたは3.3Vに接続します。
    * BH1750/TSL2561のGNDピンをマイコンのGNDに接続します。
    * BH1750/TSL2561のSDAピンをマイコンのSDAピン (Arduino Unoの場合、A4ピン) に接続します。
    * BH1750/TSL2561のSCLピンをマイコンのSCLピン (Arduino Unoの場合、A5ピン) に接続します。
    * 一部のモジュールでは、プルアップ抵抗が内蔵されていない場合があるため、SDAピンとSCLピンにそれぞれプルアップ抵抗 (4.7kΩ - 10kΩ) を接続する必要がある場合があります。

2. **Arduino IDEへのライブラリのインストール:**
    * Arduino IDEを開き、「スケッチ」->「ライブラリをインクルード」->「ライブラリの管理...」を選択します。
    * 検索バーに「BH1750」または「TSL2561」と入力し、適切なライブラリをインストールします。例：BH1750の場合は"BH1750FVI by CLAW", TSL2561の場合は"TSL2561 by Adafruit"。

3. **サンプルコード (BH1750の場合):**

```arduino
#include <Wire.h>
#include <BH1750FVI.h>

BH1750FVI LightSensor;

void setup() {
  Serial.begin(9600);
  Wire.begin();
  LightSensor.begin(); // デフォルトのアドレス(0x23)を使用
}

void loop() {
  float lux = LightSensor.getLux();

  if (lux != -1) {
    Serial.print("Illuminance: ");
    Serial.print(lux);
    Serial.println(" lx");
  } else {
    Serial.println("Error reading sensor data");
  }

  delay(1000);
}
```

4. **サンプルコード (TSL2561の場合):**

```arduino
#include <Wire.h>
#include <Adafruit_TSL2561.h>

Adafruit_TSL2561 tsl = Adafruit_TSL2561(TSL2561_ADDR_FLOAT, 12345); // I2CアドレスとセンサーID

void setup() {
  Serial.begin(9600);
  Wire.begin();

  if (!tsl.begin()) {
    Serial.println("Ooops, no TSL2561 detected ... Check your wiring!");
    while (1);
  }

  // ゲインを設定 (オプション)
  // tsl.setGain(TSL2561_GAIN_0X);  // 1xゲイン
  // tsl.setGain(TSL2561_GAIN_16X); // 16xゲイン

  // 積分時間を設定 (オプション)
  // tsl.setIntegrationTime(TSL2561_INTEGRATIONTIME_13MS);
  // tsl.setIntegrationTime(TSL2561_INTEGRATIONTIME_101MS);
  // tsl.setIntegrationTime(TSL2561_INTEGRATIONTIME_402MS);
}

void loop() {
  uint16_t visible, infrared, fullSpectrum;

  tsl.getLuminosity(&fullSpectrum, &infrared, &visible);

  Serial.print("Full Spectrum: "); Serial.print(fullSpectrum); Serial.print("  ");
  Serial.print("Infrared: "); Serial.print(infrared); Serial.print("  ");
  Serial.print("Visible: "); Serial.print(visible); Serial.print("  ");
  Serial.print("Lux: "); Serial.println(tsl.calculateLux(fullSpectrum, infrared));

  delay(1000);
}
```

5. **コードの説明 (BH1750の場合):**
    * `#include <Wire.h>`: I2C通信ライブラリをインクルードします。
    * `#include <BH1750FVI.h>`: BH1750ライブラリをインクルードします。
    * `BH1750FVI LightSensor;`: BH1750オブジェクトを生成します。
    * `LightSensor.begin();`: BH1750センサーを初期化します。
    * `LightSensor.getLux();`: 照度 (ルクス) を読み込みます。

6. **コードの説明 (TSL2561の場合):**
    * `#include <Wire.h>`: I2C通信ライブラリをインクルードします。
    * `#include <Adafruit_TSL2561.h>`: TSL2561ライブラリをインクルードします。
    * `Adafruit_TSL2561 tsl = Adafruit_TSL2561(TSL2561_ADDR_FLOAT, 12345);`: TSL2561オブジェクトを生成します。
    * `tsl.begin();`: TSL2561センサーを初期化します。
    * `tsl.getLuminosity(&fullSpectrum, &infrared, &visible);`: フルスペクトル、赤外線、可視光の値を読み込みます。
    * `tsl.calculateLux(fullSpectrum, infrared);`: 照度 (ルクス) を計算します。
    * ゲインと積分時間は、センサーの感度と測定精度を調整するために設定できます。

7. **実行:**
    * Arduino IDEで上記のコードをコンパイルし、マイコンボードに書き込みます。
    * シリアルモニタを開き、照度の値が表示されることを確認します。

#### 3.2.5 実践的なテクニック

* **ゲインと積分時間の調整 (TSL2561の場合):** TSL2561では、ゲインと積分時間を調整することで、測定範囲や感度を最適化できます。暗所ではゲインを高く、積分時間を長く設定することで、より正確な測定が可能になります。
* **遮光:** 周囲の光がセンサーに直接当たらないように、適切な遮光を行うことで、より正確な測定ができます。
* **平均化:** 測定値にノイズが混入する場合、複数回の測定値を平均化することで、より安定した値を得ることができます。

#### 3.2.6 応用例とユースケース

* **スマート照明:** 周囲の明るさに応じて照明の明るさを自動調整するシステムを構築できます。
* **ディスプレイの明るさ調整:** 周囲の明るさに応じてディスプレイの明るさを自動調整するシステムを構築できます。
* **セキュリティシステム:**  明るさの変化を検知して、侵入者を検知するシステムを構築できます。
* **植物育成:** 植物に必要な光量をモニタリングし、適切な光量を供給するシステムを構築できます。

#### 3.2.7 トラブルシューティング

* **読み込みに失敗する場合:**
    * 配線を確認してください。特に、SDAピンとSCLピンが正しく接続されているか確認してください。
    * I2Cアドレスが正しいか確認してください (TSL2561の場合、ADDRピンの設定によりアドレスが変わります)。
    * プルアップ抵抗が必要な場合、正しく接続されているか確認してください。
    * センサーが破損していないか確認してください。
* **測定値が異常な場合:**
    * センサーが汚れていないか確認してください。
    * センサーが遮蔽されていないか確認してください。
    * TSL2561の場合、ゲインと積分時間が適切に設定されているか確認してください。

### 3.3 加速度センサー：MPU6050/ADXL345の利用

#### 3.3.1 概要と重要性

加速度センサーは、物体の加速度を測定するセンサーです。モーション検知、傾斜検知、振動検知、衝撃検知など、様々な用途に利用されています。MPU6050とADXL345は、それぞれ異なる特徴を持つ加速度センサーであり、用途に応じて使い分けることができます。MPU6050は、加速度センサーに加えてジャイロセンサーも内蔵しており、より高度なモーション検知が可能です。

#### 3.3.2 特徴と利点

* **MPU6050:**
    * デジタル出力 (I2C)
    * 3軸加速度 + 3軸ジャイロ
    * 温度センサー内蔵
    * DMP (Digital Motion Processor) による高度なモーション処理
* **ADXL345:**
    * デジタル出力 (I2C/SPI)
    * 3軸加速度
    * 高分解能 (最大13ビット)
    * 低消費電力
    * 衝撃検知機能

MPU6050は、1つのチップで加速度と角速度を測定できるため、姿勢制御や慣性航法などに適しています。ADXL345は、高分解能で低消費電力であり、小型デバイスやウェアラブルデバイスに適しています。

#### 3.3.3 事前準備と前提条件

* **必要なもの:**
    * MPU6050またはADXL345センサー
    * マイコンボード (例：Arduino, Raspberry Pi)
    * ジャンパーワイヤー
    * (必要に応じて) 抵抗 (プルアップ抵抗として使用)
* **前提条件:**
    * マイコンボードの基本的な知識
    * I2C通信またはSPI通信の基本的な知識
    * Arduino IDEまたはPythonなどのプログラミング環境のセットアップ

#### 3.3.4 基本的な使い方 (Arduinoの場合)

1. **配線 (MPU6050の場合):**
    * MPU6050のVCCピンをマイコンの5Vまたは3.3Vに接続します。
    * MPU6050のGNDピンをマイコンのGNDに接続します。
    * MPU6050のSDAピンをマイコンのSDAピン (Arduino Unoの場合、A4ピン) に接続します。
    * MPU6050のSCLピンをマイコンのSCLピン (Arduino Unoの場合、A5ピン) に接続します。
    * MPU6050のINTピン (割り込みピン) は、必要に応じてマイコンのデジタルピンに接続します。
    * SDAピンとSCLピンにそれぞれプルアップ抵抗 (4.7kΩ - 10kΩ) を接続します。

2. **配線 (ADXL345の場合、I2C通信):**
    * ADXL345のVCCピンをマイコンの5Vまたは3.3Vに接続します。
    * ADXL345のGNDピンをマイコンのGNDに接続します。
    * ADXL345のSDAピンをマイコンのSDAピン (Arduino Unoの場合、A4ピン) に接続します。
    * ADXL345のSCLピンをマイコンのSCLピン (Arduino Unoの場合、A5ピン) に接続します。
    * ADXL345のINT1ピン (割り込みピン) および INT2ピン (割り込みピン) は、必要に応じてマイコンのデジタルピンに接続します。
    * SDAピンとSCLピンにそれぞれプルアップ抵抗 (4.7kΩ - 10kΩ) を接続します。

3. **Arduino IDEへのライブラリのインストール:**
    * Arduino IDEを開き、「スケッチ」->「ライブラリをインクルード」->「ライブラリの管理...」を選択します。
    * 検索バーに「MPU6050」または「ADXL345」と入力し、適切なライブラリをインストールします。例：MPU6050の場合は"MPU6050 by Jeff Rowberg", ADXL345の場合は"ADXL345 by SparkFun"。

4. **サンプルコード (MPU6050の場合):**

```arduino
#include <Wire.h>
#include <MPU6050.h>

MPU6050 mpu;
int16_t ax, ay, az, gx, gy, gz;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  mpu.initialize();

  Serial.println(mpu.testConnection() ? "MPU6050 connection successful" : "MPU6050 connection failed");
}

void loop() {
  mpu.getMotion6(&ax, &ay, &az, &gx, &gy, &gz);

  Serial.print("a/x="); Serial.print(ax);
  Serial.print(" a/y="); Serial.print(ay);
  Serial.print(" a/z="); Serial.print(az);
  Serial.print(" g/x="); Serial.print(gx);
  Serial.print(" g/y="); Serial.print(gy);
  Serial.print(" g/z="); Serial.println(gz);

  delay(10);
}
```

5. **サンプルコード (ADXL345の場合、I2C通信):**

```arduino
#include <Wire.h>
#include <ADXL345.h>

ADXL345 adxl;
int x, y, z;

void setup() {
  Serial.begin(9600);
  Wire.begin();

  if (!adxl.begin()) {
    Serial.println("ADXL345 connection failed");
    while (1);
  }

  adxl.setRange(ADXL345_RANGE_2G); // 加速度範囲を設定 (2G, 4G, 8G, 16G)
}

void loop() {
  adxl.readXYZ(&x, &y, &z);

  Serial.print("x = "); Serial.print(x);
  Serial.print(" y = "); Serial.print(y);
  Serial.print(" z = "); Serial.println(z);

  delay(100);
}
```

6. **コードの説明 (MPU6050の場合):**
    * `#include <Wire.h>`: I2C通信ライブラリをインクルードします。
    * `#include <MPU6050.h>`: MPU6050ライブラリをインクルードします。
    * `MPU6050 mpu;`: MPU6050オブジェクトを生成します。
    * `mpu.initialize();`: MPU6050センサーを初期化します。
    * `mpu.getMotion6(&ax, &ay, &az, &gx, &gy, &gz);`: 加速度と角速度を読み込みます。

7. **コードの説明 (ADXL345の場合):**
    * `#include <Wire.h>`: I2C通信ライブラリをインクルードします。
    * `#include <ADXL345.h>`: ADXL345ライブラリをインクルードします。
    * `ADXL345 adxl;`: ADXL345オブジェクトを生成します。
    * `adxl.begin();`: ADXL345センサーを初期化します。
    * `adxl.setRange(ADXL345_RANGE_2G);`: 加速度範囲を設定します。
    * `adxl.readXYZ(&x, &y, &z);`: 加速度を読み込みます。

#### 3.3.5 実践的なテクニック

* **キャリブレーション:**  加速度センサーは、個体差や環境によってオフセットが生じることがあります。キャリブレーションを行うことで、より正確な測定が可能になります。
* **ローパスフィルター:**  測定値にノイズが混入する場合、ローパスフィルターを適用することで、より安定した値を得ることができます。
* **DMP (MPU6050の場合):** MPU6050のDMPを利用することで、複雑なモーション処理をオフロードし、マイコンの負荷を軽減できます。

#### 3.3.6 応用例とユースケース

* **姿勢制御:** ロボットやドローンの姿勢を制御するシステムを構築できます。
* **モーションキャプチャ:** 人間の動きを3Dデータとして取得するシステムを構築できます。
* **歩数計:** 歩数をカウントするウェアラブルデバイスを開発できます。
* **衝突検知:** 車両や機械の衝突を検知するシステムを構築できます。
* **振動解析:** 機械の振動を解析し、異常を検知するシステムを構築できます。
* **ゲームコントローラー:** 傾きや動きを検知するゲームコントローラーを開発できます。

#### 3.3.7 トラブルシューティング

* **読み込みに失敗する場合:**
    * 配線を確認してください。特に、SDAピンとSCLピンが正しく接続されているか確認してください。
    * I2Cアドレスが正しいか確認してください。
    * プルアップ抵抗が必要な場合、正しく接続されているか確認してください。
    * センサーが破損していないか確認してください。
* **測定値が異常な場合:**
    * センサーが強い磁場や振動の影響を受けていないか確認してください。
    * センサーのキャリブレーションを行ってください。
    * ADXL345の場合、加速度範囲が適切に設定されているか確認してください。
