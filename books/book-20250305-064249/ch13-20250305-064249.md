## 第13章：アグリテック：環境モニタリング、自動水やり

### 13.1 環境モニタリング：温湿度、照度、土壌水分

#### 概要と重要性

アグリテック、すなわち農業技術は、従来の農業にテクノロジーを導入することで、効率性、生産性、持続可能性を向上させることを目指します。その中でも環境モニタリングは、作物の生育状況を把握し、適切な管理を行うための基盤となる重要な要素です。温湿度、照度、土壌水分などの環境データをリアルタイムで収集・分析することで、病害虫の発生予測、生育不良の早期発見、最適な水やりタイミングの判断など、様々な意思決定を支援します。

これまでは、熟練した農家が長年の経験と勘に基づいて環境を判断していましたが、高齢化や後継者不足により、そのノウハウを継承することが難しくなっています。環境モニタリングシステムは、属人的な知識に依存せず、客観的なデータに基づいた農業を可能にし、誰でも安定した品質の作物を生産できる可能性を広げます。また、大規模農場だけでなく、家庭菜園や植物工場など、様々な規模の農業において、環境モニタリングは有効な手段となります。

#### 特徴と利点

環境モニタリングシステムの主な特徴と利点は以下の通りです。

*   **リアルタイムなデータ収集:** 温湿度、照度、土壌水分などをリアルタイムで計測し、状況を常に把握できます。
*   **データロギングと可視化:** 収集したデータを記録し、グラフなどで可視化することで、長期的な傾向分析や異常検知が容易になります。
*   **遠隔モニタリング:** スマートフォンやPCなどから、どこからでも環境データを確認できます。
*   **自動化の基盤:** 収集したデータを元に、自動水やりシステムや換気システムなどを制御できます。
*   **省力化:** 人的な巡回や計測作業を削減し、省力化に貢献します。
*   **収量・品質の向上:** 最適な環境管理により、作物の生育を促進し、収量と品質を向上させます。
*   **資源の効率的な利用:** 水や肥料などの資源を必要な時に必要な量だけ使用することで、無駄を削減し、環境負荷を低減します。

#### 事前準備と前提条件

環境モニタリングシステムを構築するにあたり、以下の準備と前提条件が必要となります。

*   **計測機器の選定:** 
    *   **温湿度センサー:** DHT11、DHT22、BME280など、様々な種類があります。精度や価格、動作範囲などを考慮して選びます。
    *   **照度センサー:** BH1750FVI、TSL2561など、周囲の明るさを計測できるセンサーです。
    *   **土壌水分センサー:** 静電容量式、抵抗式などがあります。静電容量式は、耐久性が高く、長期間の使用に適しています。抵抗式は安価ですが、電解質の影響を受けやすく、腐食しやすいというデメリットがあります。
*   **マイクロコントローラー:** Arduino、Raspberry Piなど、センサーからデータを受信し、処理・送信するための制御装置です。Raspberry Piは、処理能力が高く、ネットワーク接続機能も充実しているため、データロギングや遠隔モニタリングに適しています。Arduinoは、低消費電力で小型なため、バッテリー駆動のシステムに適しています。
*   **通信環境:** Wi-Fi、Bluetooth、LoRaWANなど、データをクラウドやローカルサーバーに送信するための通信手段が必要です。
*   **電源:** センサーやマイクロコントローラーを動作させるための電源が必要です。ACアダプター、バッテリー、ソーラーパネルなど、環境や用途に合わせて選択します。
*   **開発環境:** Arduino IDE、Pythonなど、マイクロコントローラーにプログラムを書き込むための開発環境が必要です。
*   **クラウドサービス:** (必要に応じて) AWS IoT Core、Google Cloud IoT Platformなど、データを保存・分析するためのクラウドサービスを利用します。
*   **基本的なプログラミングスキル:** C++、Pythonなど、マイクロコントローラーを制御するためのプログラミングスキルが必要です。
*   **電子工作の知識:** 回路の接続、配線など、基本的な電子工作の知識が必要です。

#### 基本的な使い方

ここでは、ArduinoとDHT11温湿度センサー、BH1750FVI照度センサー、静電容量式土壌水分センサーを使用して、基本的な環境モニタリングシステムを構築する手順を説明します。

**1. 回路の接続:**

*   DHT11:
    *   VCC -> Arduino 5V
    *   GND -> Arduino GND
    *   DATA -> Arduino デジタルピン2
*   BH1750FVI:
    *   VCC -> Arduino 3.3V
    *   GND -> Arduino GND
    *   SDA -> Arduino SDA (A4)
    *   SCL -> Arduino SCL (A5)
*   静電容量式土壌水分センサー:
    *   VCC -> Arduino 3.3V
    *   GND -> Arduino GND
    *   AOUT -> Arduino アナログピン A0

**2. Arduino IDEのインストールと設定:**

Arduino IDEを公式サイトからダウンロードしてインストールします。Arduino IDEを起動し、ボードの種類をArduino Unoに設定します。

**3. ライブラリのインストール:**

*   DHT11:  スケッチ -> ライブラリをインクルード -> ライブラリの管理... で "DHT sensor library" を検索し、インストールします。
*   BH1750FVI: 同様に "BH1750FVI" を検索し、インストールします。

**4. コードの記述:**

以下のサンプルコードをArduino IDEにコピーし、コンパイルしてArduinoに書き込みます。

```cpp
#include <DHT.h>
#include <Wire.h>
#include <BH1750FVI.h>

#define DHTPIN 2     // DHT11のデータピン
#define DHTTYPE DHT11   // DHT11センサー

DHT dht(DHTPIN, DHTTYPE);
BH1750FVI lightSensor;

const int soilMoisturePin = A0;  // 土壌水分センサーのアナログピン

void setup() {
  Serial.begin(9600);
  dht.begin();
  Wire.begin();
  lightSensor.begin();
}

void loop() {
  delay(2000);

  // 温湿度センサーからデータを読み取る
  float temperature = dht.readTemperature();
  float humidity = dht.readHumidity();

  // 照度センサーからデータを読み取る
  float lux = lightSensor.getLux();

  // 土壌水分センサーからデータを読み取る
  int soilMoistureValue = analogRead(soilMoisturePin);
  // 土壌水分値は0-1023の範囲で、値が大きいほど乾燥していることを示す
  // 値を0-100%の範囲に変換する場合、以下の式を使用できます
  // float soilMoisturePercentage = map(soilMoistureValue, 1023, 0, 0, 100);


  // データを出力
  Serial.print("Temperature: ");
  Serial.print(temperature);
  Serial.print(" *C, Humidity: ");
  Serial.print(humidity);
  Serial.print(" %, Light: ");
  Serial.print(lux);
  Serial.print(" lux, Soil Moisture: ");
  Serial.println(soilMoistureValue); // または soilMoisturePercentage

}
```

**5. シリアルモニタの確認:**

Arduino IDEのシリアルモニタを開き、環境データが表示されることを確認します。

#### 実践的なテクニック

*   **センサーのキャリブレーション:** センサーの個体差や環境条件により、計測値に誤差が生じる場合があります。既知の値と比較して、オフセット値を調整することで、精度を向上させることができます。
*   **データフィルタリング:** ノイズを除去するために、移動平均法やカルマンフィルタなどのデータフィルタリング技術を適用します。
*   **閾値の設定:** 環境データに基づいて、アラートを発生させるための閾値を設定します。例えば、土壌水分が一定値を下回った場合に、水やりが必要であることを通知するなどが考えられます。
*   **データロギング:** 収集したデータをSDカードやクラウドストレージに記録し、長期的な傾向分析や異常検知に役立てます。
*   **ネットワーク接続:** Wi-FiやBluetoothなどを利用して、データをスマートフォンやPCに送信し、遠隔モニタリングを可能にします。

#### 応用例とユースケース

*   **スマート農業:** 広大な農地にセンサーを設置し、環境データを収集・分析することで、最適な水やりや施肥のタイミングを判断し、効率的な農業を実現します。
*   **植物工場:** 閉鎖された空間で、環境データを厳密に制御し、高品質な作物を安定的に生産します。
*   **家庭菜園:** センサーで土壌の状態を把握し、水やりのタイミングを逃さず、野菜を元気に育てます。
*   **グリーンインフラ:** 都市部の緑化スペースにセンサーを設置し、環境データを収集・分析することで、ヒートアイランド現象の緩和や生物多様性の保全に役立てます。
*   **研究開発:** 植物の生育環境と生育状況の関係を分析し、新品種の開発や栽培技術の改善に役立てます。

**具体的なユースケース:**

あるトマト農家では、環境モニタリングシステムを導入することで、収量が20%向上しました。以前は、勘に頼って水やりを行っていたため、乾燥気味の日もあれば、過湿になる日もあり、生育にムラが生じていました。しかし、土壌水分センサーの導入により、土壌の水分量を正確に把握し、必要な時に必要な量の水を与えることができるようになりました。また、温度センサーと湿度センサーのデータに基づいて、ハウス内の換気を調整することで、病害虫の発生を抑制し、農薬の使用量を削減することができました。

#### トラブルシューティング

*   **センサーが値を返さない:** 回路の接続、電源、ライブラリのインストールなどを確認します。センサーが故障している可能性も考慮します。
*   **計測値が異常:** センサーのキャリブレーション、データフィルタリングなどを試します。センサーの設置場所が適切でない可能性も考慮します。
*   **通信が不安定:** Wi-Fiルーターの設定、アンテナの位置などを確認します。電波干渉が発生している可能性も考慮します。
*   **データロギングができない:** SDカードの容量、ファイル形式などを確認します。クラウドストレージの認証設定が正しいか確認します。
*   **プログラムがコンパイルできない:** ライブラリのバージョン、コードの記述ミスなどを確認します。

**注意点:**

*   屋外で使用する場合は、センサーを防水ケースに入れるなど、防水対策を施してください。
*   土壌水分センサーは、土壌に直接触れるため、腐食しやすい場合があります。定期的に清掃し、必要に応じて交換してください。
*   バッテリー駆動の場合は、バッテリーの残量に注意し、定期的に充電または交換してください。
*   データはあくまで参考として、最終的な判断は経験に基づいて行ってください。

### 13.2 自動水やり：土壌水分センサーによる制御

#### 概要と重要性

自動水やりシステムは、土壌水分センサーで土壌の乾燥状態を検知し、設定された閾値に基づいて自動的に水やりを行うシステムです。これにより、水やりの手間を省力化できるだけでなく、過剰な水やりによる根腐れや、乾燥による生育不良を防ぎ、作物の健康な生育を促進します。特に、多忙な現代人にとって、自動水やりシステムは、時間と労力を節約しながら、植物を育てるための有効な手段となります。また、留守中の水やりを心配する必要もなくなり、旅行や出張なども安心して楽しむことができます。

#### 特徴と利点

自動水やりシステムの主な特徴と利点は以下の通りです。

*   **省力化:** 水やりの手間を大幅に削減できます。
*   **最適化:** 土壌の状態に合わせて、最適なタイミングで水やりを行います。
*   **節水:** 必要な時に必要な量の水だけを使用するため、無駄な水の使用を抑えます。
*   **生育促進:** 水不足や過剰な水やりによるストレスを軽減し、作物の生育を促進します。
*   **遠隔管理:** スマートフォンやPCから、水やり状況を確認したり、設定を変更したりできます。
*   **カスタマイズ:** 水やりの頻度や時間、水量などを、作物の種類や生育段階に合わせて細かく調整できます。
*   **環境保護:** 節水効果により、水資源の保護に貢献します。

#### 事前準備と前提条件

自動水やりシステムを構築するにあたり、以下の準備と前提条件が必要となります。

*   **土壌水分センサー:** 静電容量式、抵抗式などがあります。上記のセクションを参照してください。
*   **マイクロコントローラー:** Arduino、Raspberry Piなど、センサーからデータを受信し、ポンプを制御するための制御装置です。
*   **ウォーターポンプ:** 小型水中ポンプ、ペリスタルティックポンプなど、水を供給するためのポンプです。
*   **リレーモジュール:** マイクロコントローラーの信号で、ポンプの電源をON/OFFするためのリレーモジュールが必要です。
*   **給水チューブ:** ポンプから植物まで水を運ぶための給水チューブが必要です。
*   **電源:** センサー、マイクロコントローラー、ポンプを動作させるための電源が必要です。
*   **水源:** 水を供給するための水源が必要です。貯水タンク、水道などを用意します。
*   **基本的なプログラミングスキル:** C++、Pythonなど、マイクロコントローラーを制御するためのプログラミングスキルが必要です。
*   **電子工作の知識:** 回路の接続、配線など、基本的な電子工作の知識が必要です。

#### 基本的な使い方

ここでは、Arduino、静電容量式土壌水分センサー、小型水中ポンプ、リレーモジュールを使用して、基本的な自動水やりシステムを構築する手順を説明します。

**1. 回路の接続:**

*   土壌水分センサー:
    *   VCC -> Arduino 3.3V
    *   GND -> Arduino GND
    *   AOUT -> Arduino アナログピン A0
*   リレーモジュール:
    *   VCC -> Arduino 5V
    *   GND -> Arduino GND
    *   IN -> Arduino デジタルピン 8
*   ポンプ:
    *   リレーのNO (Normally Open) 端子にポンプのプラス線を接続します。
    *   ポンプのマイナス線を電源のマイナスに接続します。
    *   ポンプのプラス電源はリレーのCOM (Common) 端子に接続します。

**2. Arduino IDEのインストールと設定:**

上記のセクションを参照してください。

**3. コードの記述:**

以下のサンプルコードをArduino IDEにコピーし、コンパイルしてArduinoに書き込みます。

```cpp
const int soilMoisturePin = A0;  // 土壌水分センサーのアナログピン
const int relayPin = 8;        // リレーモジュールのピン
const int dryThreshold = 600;    // 乾燥状態の閾値 (調整が必要)
const int wetThreshold = 400;    // 湿潤状態の閾値 (調整が必要)

void setup() {
  Serial.begin(9600);
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, HIGH); // 初期状態ではポンプをOFFにする
}

void loop() {
  int soilMoistureValue = analogRead(soilMoisturePin);

  Serial.print("Soil Moisture Value: ");
  Serial.println(soilMoistureValue);

  if (soilMoistureValue > dryThreshold) {
    // 土壌が乾燥している場合、ポンプをONにする
    Serial.println("Soil is dry, turning on the pump.");
    digitalWrite(relayPin, LOW); // リレーをONにしてポンプを起動
    delay(5000); // 5秒間水やり (調整が必要)
    digitalWrite(relayPin, HIGH); // リレーをOFFにしてポンプを停止
    Serial.println("Watering completed.");
    delay(60000); // 1分間待機
  } else if (soilMoistureValue < wetThreshold) {
        // 土壌が湿っている場合、ポンプをOFFにする
        Serial.println("Soil is wet, pump is OFF.");
        digitalWrite(relayPin, HIGH); // リレーをOFFにしてポンプを停止
        delay(60000); // 1分間待機
  } else {
    // 土壌水分が適切な場合、何もしない
    Serial.println("Soil moisture is optimal.");
    delay(60000); // 1分間待機
  }
}
```

**4. 動作確認:**

Arduino IDEのシリアルモニタを開き、土壌水分値を確認します。土壌が乾燥している状態になると、ポンプが作動し、水やりが行われることを確認します。

#### 実践的なテクニック

*   **閾値の調整:** 土壌の種類や作物の種類に合わせて、閾値を調整します。乾燥状態と湿潤状態の閾値を適切に設定することで、最適な水やりを実現します。
*   **水やりの時間調整:** ポンプの種類や給水チューブの長さ、植物の種類に合わせて、水やりの時間を調整します。適切な水量を供給することで、根腐れや乾燥を防ぎます。
*   **複数のセンサーの利用:** 複数の場所にセンサーを設置することで、土壌の水分状態をより正確に把握できます。特に、広い範囲を管理する場合は、複数のセンサーの利用が有効です。
*   **タイマー機能の追加:** 時間帯を指定して水やりを行うように設定できます。夜間に水やりを行うことで、蒸発を防ぎ、節水効果を高めます。
*   **クラウド連携:** データをクラウドに送信し、スマートフォンやPCから、水やり状況を確認したり、設定を変更したりできます。

#### 応用例とユースケース

*   **ベランダ菜園:** ベランダで育てている野菜やハーブに、自動で水やりを行います。
*   **プランター:** プランターに植えた花や観葉植物に、自動で水やりを行います。
*   **温室:** 温室内の植物に、自動で水やりを行います。温度や湿度も同時にモニタリングすることで、より最適な環境管理を実現します。
*   **ゴルフ場:** 広大なゴルフ場の芝生に、自動で水やりを行います。土壌の状態に合わせて、必要な場所にだけ水やりを行うことで、節水効果を高めます。
*   **公園:** 公園の樹木や花壇に、自動で水やりを行います。

**具体的なユースケース:**

あるオフィスでは、観葉植物に自動水やりシステムを導入することで、植物の世話にかかる時間を大幅に削減しました。以前は、従業員が交代で水やりを行っていましたが、忙しい時期には水やりを忘れてしまうこともあり、植物が枯れてしまうこともありました。しかし、自動水やりシステムの導入により、常に最適な水分量を保つことができ、植物は生き生きと成長し、オフィスに潤いを与えています。

#### トラブルシューティング

*   **ポンプが動かない:** 回路の接続、リレーモジュールの動作、ポンプの電源などを確認します。ポンプが詰まっている可能性も考慮します。
*   **水やりが止まらない:** 土壌水分センサーの故障、閾値の設定ミスなどを確認します。
*   **水やりが不均一:** 給水チューブの詰まり、ポンプの能力不足などを確認します。
*   **センサーの値が不安定:** センサーの接続、電源、ノイズなどを確認します。

**注意点:**

*   ポンプの能力は、給水チューブの長さや高さを考慮して選択してください。
*   貯水タンクの水が空にならないように、定期的に補充してください。
*   冬場は、ポンプや給水チューブが凍結しないように、対策を施してください。
*   システムに異常が発生した場合は、速やかに原因を特定し、対処してください。

#### まとめと次のステップ

自動水やりシステムは、水やりの手間を省力化し、作物の生育を促進する便利なツールです。この記事では、基本的な自動水やりシステムの構築方法から、実践的なテクニック、応用例まで幅広く解説しました。

次のステップとしては、以下のことを検討してみてください。

*   **ソーラーパネルの導入:** ソーラーパネルを導入し、バッテリーを充電することで、電源のない場所でも自動水やりシステムを運用できます。
*   **スマートフォンアプリの開発:** スマートフォンアプリを開発し、水やり状況の確認や設定変更を、より簡単に行えるようにします。
*   **AIによる水やり制御:** AIを活用し、気象データや過去の生育データなどを分析し、より最適な水やり制御を実現します。
*   **灌漑システムの構築:** より大規模な自動水やりシステムを構築し、農地や庭全体に効率的に水やりを行います。

アグリテックは、日々進化を続けています。常に最新の技術を学び、積極的に導入することで、より効率的で持続可能な農業を実現しましょう。
