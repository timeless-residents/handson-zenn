## 第2章：ESP32の基本機能：Wi-Fi、Bluetooth、GPIO制御

この章では、ESP32を使いこなす上で最も重要な3つの機能、Wi-Fi、Bluetooth、GPIO制御について解説します。これらの機能を理解し、実際に使えるようになることで、IoTデバイス開発の幅が大きく広がります。初心者の方でも理解しやすいように、基礎から応用まで、具体的なコード例を交えながら丁寧に解説していきます。

### 2.1 Wi-Fi接続：ネットワークへの接続と設定

#### 2.1.1 概要と重要性

ESP32のWi-Fi機能は、IoTデバイスをインターネットに接続するための基盤となる機能です。センサーデータや制御情報をクラウドに送信したり、遠隔からデバイスを操作したりと、IoTデバイスならではの機能を実現するために不可欠です。安定したWi-Fi接続を確立し、セキュリティにも配慮した設定を行うことが重要となります。

#### 2.1.2 特徴と利点

*   **IEEE 802.11 b/g/n対応:** 2.4GHz帯のWi-Fiネットワークに接続できます。
*   **Stationモード/Access Pointモード:** デバイスをWi-Fiルーターに接続するだけでなく、ESP32自体がアクセスポイントとして機能することも可能です。
*   **セキュリティ:** WEP、WPA/WPA2 PSK、Enterpriseに対応しており、安全な通信を実現できます。
*   **省電力:** Wi-Fiモデムを間欠的に動作させることで、消費電力を抑えることができます。

#### 2.1.3 事前準備と前提条件

*   ESP32開発環境 (Arduino IDE、PlatformIOなど) のセットアップが完了していること
*   Wi-Fiルーターが利用可能であること
*   Wi-FiルーターのSSIDとパスワードを把握していること

#### 2.1.4 基本的な使い方

**1. Wi-Fiライブラリのインクルード:**

まず、Wi-Fiライブラリをインクルードします。

```c++
#include <WiFi.h>
```

**2. Wi-Fi接続情報の定義:**

SSIDとパスワードを定義します。実際の環境に合わせて書き換えてください。

```c++
const char* ssid     = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
```

**3. setup()関数での接続処理:**

`setup()`関数内でWi-Fiに接続するコードを記述します。

```c++
void setup() {
  Serial.begin(115200);
  delay(10);

  Serial.println("Connecting to WiFi...");
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("");
  Serial.println("WiFi connected");
  Serial.print("IP address: ");
  Serial.println(WiFi.localIP());
}
```

**4. loop()関数での処理:**

`loop()`関数では、Wi-Fi接続が維持されているか確認したり、ネットワーク経由でデータを受信したりする処理を記述します。ここでは、接続状態を表示する例を示します。

```c++
void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("WiFi connected");
  } else {
    Serial.println("WiFi disconnected");
  }
  delay(5000);
}
```

**5. 全体のコード例:**

```c++
#include <WiFi.h>

const char* ssid     = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";

  Serial.begin(115200);
  delay(10);

  Serial.println("Connecting to WiFi...");
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("");
  Serial.println("WiFi connected");
  Serial.print("IP address: ");
  Serial.println(WiFi.localIP());
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("WiFi connected");
  } else {
    Serial.println("WiFi disconnected");
  }
  delay(5000);
}
```

#### 2.1.5 実践的なテクニック

*   **固定IPアドレスの設定:** DHCPではなく、固定IPアドレスを設定することで、ネットワーク上でのデバイスの識別が容易になります。

    ```c++
    IPAddress ip(192, 168, 1, 100); // 希望するIPアドレス
    IPAddress gateway(192, 168, 1, 1); // ゲートウェイアドレス
    IPAddress subnet(255, 255, 255, 0); // サブネットマスク
    IPAddress dns(8, 8, 8, 8);       // DNSサーバー

    WiFi.config(ip, gateway, subnet, dns);
    ```

*   **Wi-Fi接続状態の監視:** `WiFi.status()`関数で接続状態を監視し、切断された場合に自動的に再接続する処理を実装します。

    ```c++
    if (WiFi.status() != WL_CONNECTED) {
      Serial.println("Reconnecting to WiFi...");
      WiFi.begin(ssid, password);
    }
    ```

*   **Wi-Fi Direct (P2P) の利用:** Wi-Fi Directを利用することで、ルーターを介さずに、ESP32デバイス同士が直接通信できます。

#### 2.1.6 応用例とユースケース

*   **温湿度センサーデータのクラウド送信:** 温湿度センサーから得られたデータを、Wi-Fi経由でクラウドサービス（AWS IoT、Google Cloud IoTなど）に送信し、データの可視化や分析を行います。
*   **スマートホームデバイスの制御:** スマートフォンアプリからESP32に接続し、照明や家電製品を遠隔操作します。
*   **ネットワークカメラ:** カメラモジュールをESP32に接続し、撮影した映像をWi-Fi経由でストリーミング配信します。

#### 2.1.7 トラブルシューティング

*   **Wi-Fiに接続できない:**
    *   SSIDとパスワードが正しいか確認してください。
    *   Wi-Fiルーターが正常に動作しているか確認してください。
    *   ESP32がWi-Fiルーターの電波範囲内にあるか確認してください。
    *   電源供給が安定しているか確認してください。
*   **Wi-Fiが頻繁に切断される:**
    *   Wi-Fiルーターのチャンネルを変更してみてください。
    *   ESP32をWi-Fiルーターに近づけてみてください。
    *   省電力モードが有効になっている場合は、無効にしてみてください。

### 2.2 Bluetooth通信：BLE（Bluetooth Low Energy）の基礎

#### 2.2.1 概要と重要性

ESP32のBluetooth機能、特にBLE（Bluetooth Low Energy）は、低消費電力で近距離無線通信を実現するための重要な機能です。スマートフォンや他のBLE対応デバイスとのデータ交換、ビーコンによる位置情報サービス、ウェアラブルデバイスとの連携など、様々な用途に活用できます。

#### 2.2.2 特徴と利点

*   **Bluetooth Low Energy (BLE):** 低消費電力で動作し、ボタン電池駆動のデバイスでも長期間使用できます。
*   **GATT (Generic Attribute Profile):** データの送受信を行うためのプロトコル。UUID (Universally Unique Identifier) を使用して、サービスとキャラクタリスティックを定義します。
*   **Central/Peripheral:** デバイスの役割を定義します。CentralはPeripheralに接続し、Peripheralは接続を待ち受けます。
*   **Advertising:** Peripheralが自身の存在をCentralに知らせるための仕組みです。
*   **セキュリティ:** ペアリングによる暗号化通信をサポートし、安全なデータ交換が可能です。

#### 2.2.3 事前準備と前提条件

*   ESP32開発環境 (Arduino IDE、PlatformIOなど) のセットアップが完了していること
*   BLE対応のスマートフォンまたはPC
*   BLE通信の基本的な知識 (GATT、UUIDなど)

#### 2.2.4 基本的な使い方

**1. Bluetoothライブラリのインクルード:**

まず、Bluetoothライブラリをインクルードします。

```c++
#include <BLEDevice.h>
#include <BLEUtils.h>
#include <BLEServer.h>
```

**2. サービスとキャラクタリスティックのUUID定義:**

サービスとキャラクタリスティックのUUIDを定義します。UUIDは一意である必要があり、オンラインUUIDジェネレーターなどで生成できます。

```c++
#define SERVICE_UUID        "4fafc201-1fb5-459e-8fcc-c5c9c331914b"
#define CHARACTERISTIC_UUID "beb5483e-36e1-4688-b7f5-ea07361b26a8"
```

**3. setup()関数でのBLEサーバーの初期化と起動:**

`setup()`関数内でBLEサーバーを初期化し、アドバタイズを開始します。

```c++
void setup() {
  Serial.begin(115200);

  BLEDevice::init("MyESP32"); // BLEデバイス名

  BLEServer *pServer = BLEDevice::createServer();
  BLEService *pService = pServer->createService(SERVICE_UUID);
  BLECharacteristic *pCharacteristic = pService->createCharacteristic(
                                         CHARACTERISTIC_UUID,
                                         BLECharacteristic::PROPERTY_READ   |
                                         BLECharacteristic::PROPERTY_WRITE  |
                                         BLECharacteristic::PROPERTY_NOTIFY
                                       );

  pCharacteristic->setValue("Hello World");
  pService->start();

  BLEAdvertising *pAdvertising = BLEDevice::getAdvertising();
  pAdvertising->addServiceUUID(SERVICE_UUID);
  pAdvertising->setScanResponse(true);
  pAdvertising->setMinPreferred(0x06);  // functions that help with iPhone connections issue
  pAdvertising->setMinPreferred(0x12);
  BLEDevice::startAdvertising();
  Serial.println("Characteristic defined! Now you can read it in your phone!");
}
```

**4. loop()関数での処理:**

`loop()`関数では、BLE接続の維持やデータ送受信の処理を行います。ここでは、受信したデータをシリアルモニタに表示する例を示します。

```c++
void loop() {
  //  BLE接続の維持処理 (必要に応じて実装)
  delay(2000);
}
```

**5. 全体のコード例:**

```c++
#include <BLEDevice.h>
#include <BLEUtils.h>
#include <BLEServer.h>

#define SERVICE_UUID        "4fafc201-1fb5-459e-8fcc-c5c9c331914b"
#define CHARACTERISTIC_UUID "beb5483e-36e1-4688-b7f5-ea07361b26a8"

  BLECharacteristic *pCharacteristic = pService->createCharacteristic(
                                         CHARACTERISTIC_UUID,
                                         BLECharacteristic::PROPERTY_READ   |
                                         BLECharacteristic::PROPERTY_WRITE  |
                                         BLECharacteristic::PROPERTY_NOTIFY
                                       );

  pCharacteristic->setValue("Hello World");
  pService->start();

  BLEAdvertising *pAdvertising = BLEDevice::getAdvertising();
  pAdvertising->addServiceUUID(SERVICE_UUID);
  pAdvertising->setScanResponse(true);
  pAdvertising->setMinPreferred(0x06);  // functions that help with iPhone connections issue
  pAdvertising->setMinPreferred(0x12);
  BLEDevice::startAdvertising();
  Serial.println("Characteristic defined! Now you can read it in your phone!");
}

void loop() {
  //  BLE接続の維持処理 (必要に応じて実装)
  delay(2000);
}
```

#### 2.2.5 実践的なテクニック

*   **Notificationによるリアルタイムデータ送信:** CharacteristicのPropertyに`BLECharacteristic::PROPERTY_NOTIFY`を追加することで、PeripheralからCentralにリアルタイムでデータを送信できます。
*   **Indicationsによる確認応答付きデータ送信:** `BLECharacteristic::PROPERTY_INDICATE`を使用すると、Centralからの確認応答が必要となり、より信頼性の高いデータ送信が可能です。
*   **バッテリー残量のモニタリング:** バッテリー残量をBLE経由で送信し、スマートフォンアプリなどで確認できるようにします。
*   **セキュリティ:** ペアリングを設定し、安全なBLE通信を確立します。

#### 2.2.6 応用例とユースケース

*   **ウェアラブルデバイス:** 心拍数、歩数、加速度などのセンサーデータをBLE経由でスマートフォンに送信します。
*   **ビーコン:** 店舗や施設内に設置されたビーコンから発信される信号を受信し、位置情報に基づいたサービスを提供します。
*   **スマートロック:** スマートフォンのBLE機能を利用して、ドアの施錠・解錠を行います。
*   **IoTデバイスの設定:** スマートフォンからBLE経由でWi-FiのSSIDやパスワードを設定します。

#### 2.2.7 トラブルシューティング

*   **BLEデバイスが見つからない:**
    *   ESP32の電源が入っているか確認してください。
    *   スマートフォンまたはPCのBluetoothが有効になっているか確認してください。
    *   ESP32がアドバタイズを開始しているか確認してください。
*   **BLE接続が確立できない:**
    *   PINコード認証が必要な場合は、正しいPINコードを入力してください。
    *   ESP32とスマートフォンまたはPCの距離が近すぎないか確認してください。
    *   他のBLEデバイスとの干渉がないか確認してください。

### 2.3 GPIO制御：デジタル入出力とアナログ入出力

#### 2.3.1 概要と重要性

ESP32のGPIO（General Purpose Input/Output）は、外部のセンサーやアクチュエータと接続するためのインターフェースです。デジタル信号の入出力、アナログ信号の入出力、PWM制御など、様々な機能を提供し、多様な電子工作やIoTデバイス開発の可能性を広げます。

#### 2.3.2 特徴と利点

*   **多彩なピン配置:** 豊富な数のGPIOピンを備えており、様々な周辺機器と接続できます。
*   **デジタル入出力:** デジタル信号の入力と出力が可能で、LEDの点灯、スイッチの読み取りなどに利用できます。
*   **アナログ入出力 (ADC/DAC):** アナログ信号のデジタル変換（ADC）と、デジタル信号のアナログ変換（DAC）が可能で、センサーデータの取得やアナログ制御に利用できます。
*   **PWM (Pulse Width Modulation):** パルスのデューティ比を制御することで、LEDの明るさ調整やモーターの速度制御など、アナログ的な制御を実現できます。
*   **割り込み:** 特定のGPIOピンの状態変化を検知して、割り込み処理を実行できます。

#### 2.3.3 事前準備と前提条件

*   ESP32開発環境 (Arduino IDE、PlatformIOなど) のセットアップが完了していること
*   ブレッドボード、ジャンパーワイヤーなどの電子工作に必要な部品
*   LED、抵抗、スイッチ、センサーなどの周辺機器

#### 2.3.4 基本的な使い方

**1. ピンモードの設定:**

`pinMode()`関数で、GPIOピンを入力モード (INPUT) または出力モード (OUTPUT) に設定します。

```c++
const int ledPin = 2; // LEDを接続するピン
const int buttonPin = 4; // スイッチを接続するピン

void setup() {
  pinMode(ledPin, OUTPUT); // LEDピンを出力モードに設定
  pinMode(buttonPin, INPUT_PULLUP); // スイッチピンを入力モードに設定（プルアップ抵抗内蔵）
  Serial.begin(115200);
}
```

**2. デジタル出力:**

`digitalWrite()`関数で、GPIOピンにHIGHまたはLOWのデジタル信号を出力します。

```c++
void loop() {
  digitalWrite(ledPin, HIGH); // LEDを点灯
  delay(1000);
  digitalWrite(ledPin, LOW);  // LEDを消灯
  delay(1000);
}
```

**3. デジタル入力:**

`digitalRead()`関数で、GPIOピンのデジタル信号を読み取ります。

```c++
void loop() {
  int buttonState = digitalRead(buttonPin); // スイッチの状態を読み取る

  if (buttonState == LOW) { // スイッチが押された場合
    Serial.println("Button Pressed!");
    digitalWrite(ledPin, HIGH); // LEDを点灯
  } else {
    digitalWrite(ledPin, LOW); // LEDを消灯
  }
  delay(100);
}
```

**4. アナログ入力 (ADC):**

`analogRead()`関数で、GPIOピンのアナログ信号を読み取り、0から4095のデジタル値に変換します。

```c++
const int sensorPin = 36; // アナログセンサーを接続するピン

void setup() {
  Serial.begin(115200);
}

void loop() {
  int sensorValue = analogRead(sensorPin); // センサー値を読み取る
  Serial.print("Sensor Value: ");
  Serial.println(sensorValue);
  delay(100);
}
```

**5. アナログ出力 (DAC):**

`dacWrite()`関数で、GPIOピンにアナログ信号を出力します。ESP32にはDAC機能を持つピンが2つ（GPIO25、GPIO26）あります。

```c++
const int dacPin = 25; // DAC出力ピン

void setup() {
  Serial.begin(115200);
}

void loop() {
  for (int i = 0; i < 255; i++) {
    dacWrite(dacPin, i); // DAC出力値を設定
    delay(10);
  }
}
```

**6. PWM出力:**

`ledcSetup()`関数、`ledcAttachPin()`関数、`ledcWrite()`関数を使用して、PWM出力を設定します。

```c++
const int pwmPin = 13; // PWM出力ピン
const int ledChannel = 0; // PWMチャンネル

void setup() {
  Serial.begin(115200);
  ledcSetup(ledChannel, 5000, 8); // チャンネル、周波数、分解能を設定
  ledcAttachPin(pwmPin, ledChannel); // ピンをチャンネルに割り当てる
}

void loop() {
  for (int dutyCycle = 0; dutyCycle <= 255; dutyCycle++) {
    ledcWrite(ledChannel, dutyCycle); // PWMデューティ比を設定
    delay(10);
  }
  for (int dutyCycle = 255; dutyCycle >= 0; dutyCycle--) {
    ledcWrite(ledChannel, dutyCycle); // PWMデューティ比を設定
    delay(10);
  }
}
```

#### 2.3.5 実践的なテクニック

*   **プルアップ/プルダウン抵抗の利用:** スイッチの入力時にノイズが発生する場合は、プルアップ抵抗またはプルダウン抵抗を使用します。ESP32には内蔵プルアップ抵抗があり、`INPUT_PULLUP`モードで有効にできます。
*   **割り込み処理:** 特定のGPIOピンの状態変化を検知して割り込み処理を実行することで、高速なイベント処理が可能になります。
*   **I2C/SPI通信:** I2CやSPIといったシリアル通信プロトコルを利用して、様々なセンサーやデバイスと通信できます。

#### 2.3.6 応用例とユースケース

*   **スマートホームデバイス:** 温度センサー、湿度センサー、照度センサーなどからデータを収集し、エアコンや照明などを制御します。
*   **ロボット制御:** モータードライバーを介してモーターを制御し、ロボットの移動やアームの制御を行います。
*   **環境モニタリング:** 大気圧センサー、CO2センサーなどからデータを収集し、環境の変化を監視します。
*   **インタラクティブアート:** センサーやスイッチを使って、音や光をインタラクティブに制御します。

#### 2.3.7 トラブルシューティング

*   **GPIOピンが正常に動作しない:**
    *   ピンモードの設定が正しいか確認してください。
    *   配線が正しいか確認してください。
    *   電源供給が安定しているか確認してください。
    *   GPIOピンの最大電流を超えていないか確認してください。
*   **アナログ入力値が安定しない:**
    *   配線にノイズが混入していないか確認してください。
    *   キャパシタを追加してノイズを除去してみてください。
    *   サンプリングレートを調整してみてください。
