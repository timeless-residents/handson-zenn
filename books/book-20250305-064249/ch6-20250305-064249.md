## 第6章：省電力設計：バッテリー駆動とDeep Sleepモード

モノのインターネット（IoT）やウェアラブルデバイスの開発において、省電力設計は非常に重要な要素です。バッテリー駆動時間を最大化し、メンテナンス頻度を減らすことは、製品の利便性や競争力を高める上で欠かせません。この章では、バッテリー駆動の基礎知識から、Deep Sleepモードによる消費電力削減、そして電源管理チップの活用まで、実践的な省電力設計のテクニックを解説します。

### 6.1 バッテリー駆動：リチウムイオン電池の利用と充電回路

#### 6.1.1 概要と重要性

組み込み機器の電源として広く利用されているリチウムイオン電池は、高いエネルギー密度と比較的軽量であることが特徴です。しかし、その性能を最大限に引き出すためには、適切な充電回路と放電制御が不可欠です。不適切な取り扱いは、バッテリーの寿命を縮めるだけでなく、発火や爆発といった重大な事故につながる可能性もあります。

#### 6.1.2 特徴と利点

*   **高いエネルギー密度:** 比較的小さいサイズで多くの電力を供給できます。
*   **低い自己放電率:** 長期間未使用でも、比較的電力を維持できます。
*   **豊富な種類:** 用途に合わせて様々なサイズ、形状、容量のバッテリーを選択できます。

#### 6.1.3 事前準備と前提条件

*   **必要な知識:** 電気回路の基礎知識、オームの法則、電圧・電流・抵抗の概念
*   **必要なツール:** マルチメーター、オシロスコープ（任意）、安定化電源、ブレッドボード、テスター
*   **使用する部品:** リチウムイオン電池、バッテリー充電IC（例: TP4056）、保護回路モジュール（任意）、抵抗、コンデンサ、配線材

#### 6.1.4 基本的な使い方

リチウムイオン電池の充電は、通常CC/CV (定電流/定電圧) 方式で行われます。これは、まず定電流で充電し、バッテリー電圧が所定の値（例: 4.2V）に達したら、定電圧で充電を続ける方式です。

以下は、一般的なリチウムイオン電池充電回路の例です（充電ICとしてTP4056を使用）。

```
[VCC (5V)] -- [R1 (充電電流設定抵抗)] -- [TP4056 VIN]
[TP4056 BAT] -- [リチウムイオン電池 +]
[TP4056 GND] -- [リチウムイオン電池 -] -- [GND]
[TP4056 CHRG (LED indicator)] -- [LED] -- [R2 (電流制限抵抗)] -- [GND]
```

*   **R1:** 充電電流を設定します。TP4056のデータシートを参照して、適切な抵抗値を計算してください。
*   **LED:** 充電状態を表示します。TP4056のCHRGピンは、充電中はLOW、充電完了でHIGHになります。
*   **保護回路モジュール:** 過充電、過放電、過電流からバッテリーを保護します。

**重要な注意点:**

*   バッテリーの極性を絶対に間違えないでください。逆接続はバッテリーの損傷や爆発の原因となります。
*   指定された充電電圧を超えないようにしてください。過充電はバッテリーの寿命を縮めるだけでなく、危険です。
*   バッテリーの温度を常に監視し、異常な発熱がないか確認してください。

#### 6.1.5 実践的なテクニック

**バッテリー容量の最適化:**

*   デバイスの消費電流を正確に測定し、必要なバッテリー容量を計算します。
*   バッテリー容量が大きすぎると、デバイスのサイズと重量が増加します。逆に、小さすぎると、バッテリー駆動時間が短くなります。

**充電効率の向上:**

*   高品質のバッテリー充電ICを使用します。
*   充電回路の配線を最適化し、電圧降下を最小限に抑えます。
*   充電温度を適切に管理します。高温や低温での充電は、充電効率を低下させます。

**バッテリー寿命の延長:**

*   バッテリーを過放電させないように、適切な放電制御を行います。
*   バッテリーを高温にさらさないようにしてください。
*   長期間使用しない場合は、バッテリーを約50%充電した状態で保管します。

#### 6.1.6 応用例とユースケース

*   **ウェアラブルデバイス:** スマートウォッチやフィットネストラッカーでは、小型で軽量、かつ長寿命なバッテリーが必要です。低消費電力設計とバッテリー管理技術を組み合わせることで、数日間のバッテリー駆動を実現できます。
*   **IoTセンサー:** 環境センサーやスマートメーターでは、バッテリー駆動による長期間の автономность（自律性）が求められます。Deep Sleepモードを積極的に活用し、必要な時だけセンサーを起動することで、バッテリー寿命を大幅に延ばすことができます。
*   **ポータブル医療機器:** 在宅医療で使用される酸素濃縮器や血糖値測定器では、安全性が非常に重要です。バッテリーの過充電や過放電を防ぐための保護回路は必須です。

#### 6.1.7 トラブルシューティング

*   **バッテリーが充電されない:** 充電回路の配線を確認してください。充電ICが正常に動作しているか確認してください。バッテリーが故障している可能性があります。
*   **バッテリー駆動時間が短い:** デバイスの消費電力を再度測定してください。バッテリーが劣化している可能性があります。Deep Sleepモードの設定が正しくない可能性があります。
*   **バッテリーが異常に発熱する:** 充電を停止し、バッテリーの状態を確認してください。バッテリーが損傷している可能性があります。

#### 6.1.8 まとめと次のステップ

リチウムイオン電池の特性を理解し、適切な充電回路と放電制御を行うことは、バッテリー駆動デバイスの性能と安全性を確保するために不可欠です。次のステップとして、様々なバッテリー充電ICのデータシートを比較検討し、自身のプロジェクトに最適なものを選択してください。また、バッテリー保護回路の設計についても学習することをお勧めします。

### 6.2 Deep Sleepモード：消費電力の削減

#### 6.2.1 概要と重要性

Deep Sleepモードは、組み込みシステムにおいて、消費電力を劇的に削減するための最も重要な手法の一つです。デバイスが動作していない時間、特に待機状態の消費電力を最小限に抑えることで、バッテリー駆動時間を大幅に延長できます。

#### 6.2.2 特徴と利点

*   **大幅な消費電力削減:** マイクロコントローラーやその他のコンポーネントの動作を停止することで、通常動作時の数十分の一から数百分の一まで消費電力を削減できます。
*   **バッテリー駆動時間の延長:** 特にバッテリー駆動のデバイスにおいて、Deep Sleepモードはバッテリー寿命を最大限に引き出すための鍵となります。
*   **環境への配慮:** 消費電力を削減することで、二酸化炭素排出量の削減に貢献できます。

#### 6.2.3 事前準備と前提条件

*   **必要な知識:** マイクロコントローラーのアーキテクチャ、割り込み処理、省電力モードに関する知識
*   **必要なツール:** IDE (Integrated Development Environment)、デバッガー
*   **使用する部品:** マイクロコントローラー (例: ESP32, STM32), RTC (Real-Time Clock) モジュール（任意）

#### 6.2.4 基本的な使い方

Deep Sleepモードへの移行は、通常、マイクロコントローラーの専用命令やAPI関数を呼び出すことで行います。移行時に、ウェイクアップの条件（例: タイマー割り込み、外部割り込み）を設定します。

以下は、ESP32でDeep Sleepモードを使用する例です。

```c++
#include <esp_sleep.h>

// Deep Sleepの時間をマイクロ秒単位で設定
#define SLEEP_TIME_US 5000000 // 5秒

void setup() {
  Serial.begin(115200);
  Serial.println("Going to sleep...");

  // タイマーによるウェイクアップの設定
  esp_sleep_enable_timer_wakeup(SLEEP_TIME_US);

  // Deep Sleepモードへ移行
  esp_deep_sleep_start();

  // このコードはDeep Sleepから復帰後に実行されます
  Serial.println("This will never be printed");
}

void loop() {
  // こちらも実行されません
}
```

このコードは、ESP32を5秒間Deep Sleepモードにし、その後ウェイクアップして再起動します。

**Deep Sleepモードからの復帰:**

*   **タイマー割り込み:** 設定した時間が経過すると、自動的にウェイクアップします。
*   **外部割り込み:** 特定のピンの状態が変化すると、ウェイクアップします (例: ボタンが押された場合)。
*   **RTC (Real-Time Clock):** RTCモジュールを使用すると、より正確な時間でウェイクアップできます。

#### 6.2.5 実践的なテクニック

**消費電流の最小化:**

*   Deep Sleepモードに入る前に、不要な周辺機器（例: UART, SPI, I2C）を無効化します。
*   マイクロコントローラーのデータシートを参照し、Deep Sleepモード時の消費電流が最小になるように設定します。
*   外部回路の消費電流も考慮し、必要に応じて電源を遮断します (例: ローサイドスイッチを使用)。

**ウェイクアップ時間の短縮:**

*   ウェイクアップ後、迅速にタスクを実行できるように、必要な処理を最適化します。
*   頻繁にウェイクアップする必要がある場合は、Deep Sleepモードではなく、より消費電力の低いStandbyモードやIdleモードを検討します。

**データ保持:**

*   Deep Sleepモード中にデータを保持する必要がある場合は、RTCメモリやフラッシュメモリを使用します。
*   保持するデータの量を最小限に抑えることで、消費電力を削減できます。

#### 6.2.6 応用例とユースケース

*   **環境センサー:** 一定時間ごとに温度や湿度を測定し、Deep Sleepモードで待機するセンサーノードは、数年間バッテリー駆動できます。
*   **スマートメーター:** 使用電力量を定期的に送信し、それ以外の時間はDeep Sleepモードで待機することで、バッテリー寿命を大幅に延ばすことができます。
*   **ウェアラブルデバイス:** 歩数計や心拍数モニターは、ユーザーが操作していない時間帯はDeep Sleepモードに移行し、バッテリー消費を抑えます。

#### 6.2.7 トラブルシューティング

*   **Deep Sleepモードから復帰しない:** ウェイクアップ条件の設定が正しいか確認してください。電源供給が安定しているか確認してください。マイクロコントローラーが故障している可能性があります。
*   **Deep Sleepモード時の消費電流が高い:** 周辺機器が無効化されているか確認してください。外部回路の消費電流を確認してください。マイクロコントローラーの設定が最適化されているか確認してください。
*   **データがDeep Sleepモード中に消失する:** データを保持するためのメモリが正しく設定されているか確認してください。

#### 6.2.8 まとめと次のステップ

Deep Sleepモードは、バッテリー駆動デバイスの消費電力を削減するための強力なツールです。マイクロコントローラーの特性を理解し、適切な設定を行うことで、バッテリー寿命を大幅に延ばすことができます。次のステップとして、自身のプロジェクトで使用するマイクロコントローラーの省電力モードに関するドキュメントを熟読し、様々なウェイクアップ条件を試してみてください。

### 6.3 電源管理チップの利用：LDOレギュレーター

#### 6.3.1 概要と重要性

電源管理チップ (PMIC: Power Management Integrated Circuit) は、組み込みシステムの電源回路を効率的に管理するためのICです。特に、LDO (Low Dropout) レギュレーターは、入力電圧と出力電圧の差が小さい場合でも安定した電圧を供給できるため、バッテリー駆動デバイスに最適です。

#### 6.3.2 特徴と利点

*   **安定した電圧供給:** 入力電圧が変動しても、出力電圧を一定に保ちます。
*   **低ノイズ:** スイッチングレギュレーターと比較して、ノイズが少ないため、アナログ回路や高精度センサーに適しています。
*   **小型化:** 必要な部品点数が少なく、実装面積を小さくできます。
*   **低消費電力:** 動作時の自己消費電流が少ないため、バッテリー駆動時間を延ばすことができます。

#### 6.3.3 事前準備と前提条件

*   **必要な知識:** 電圧レギュレーターの基礎知識、LDOレギュレーターの動作原理、電気回路の設計
*   **必要なツール:** マルチメーター、オシロスコープ（任意）、ブレッドボード、テスター、はんだごて
*   **使用する部品:** LDOレギュレーター (例: MCP1700, LP2985), コンデンサ、抵抗、配線材

#### 6.3.4 基本的な使い方

LDOレギュレーターは、通常、入力端子、出力端子、グラウンド端子の3つの端子を持ちます。入力端子に電圧を印加すると、出力端子から安定した電圧が出力されます。

以下は、LDOレギュレーターの基本的な接続例です。

```
[VIN (バッテリー電圧)] -- [LDO VIN]
[LDO VOUT] -- [負荷 (例: マイクロコントローラー)]
[LDO GND] -- [GND]

[LDO VIN] -- [コンデンサ C1 (入力コンデンサ)] -- [GND]
[LDO VOUT] -- [コンデンサ C2 (出力コンデンサ)] -- [GND]
```

*   **C1 (入力コンデンサ):** 入力電圧の安定化に使用します。LDOレギュレーターのデータシートで推奨される容量と種類を選択してください。
*   **C2 (出力コンデンサ):** 出力電圧の安定化に使用します。LDOレギュレーターのデータシートで推奨される容量と種類を選択してください。

**LDOレギュレーター選定のポイント:**

*   **入力電圧範囲:** バッテリーの電圧変動範囲を考慮して、適切な入力電圧範囲を持つLDOレギュレーターを選択してください。
*   **出力電圧:** 必要な出力電圧を持つLDOレギュレーターを選択してください。可変出力電圧を持つLDOレギュレーターもあります。
*   **出力電流:** 負荷に必要な最大電流を供給できるLDOレギュレーターを選択してください。
*   **ドロップアウト電圧:** 入力電圧と出力電圧の差が小さい場合でも、安定した電圧を供給できるLDOレギュレーターを選択してください。ドロップアウト電圧が小さいほど、バッテリーをより効率的に使用できます。
*   **静止電流 (Quiescent Current):** LDOレギュレーター自身の消費電流です。バッテリー駆動時間を延ばすためには、静止電流が小さいLDOレギュレーターを選択してください。

#### 6.3.5 実践的なテクニック

**効率の最適化:**

*   LDOレギュレーターの入力電圧と出力電圧の差をできるだけ小さくします。過剰な電圧降下は熱損失につながり、効率を低下させます。
*   負荷に必要な電流を正確に把握し、過剰な出力電流容量を持つLDOレギュレーターを使用しないようにします。

**ノイズ対策:**

*   LDOレギュレーターの近くに、適切な容量のコンデンサを配置します。
*   グラウンド配線を最適化し、グラウンドループを最小限に抑えます。
*   必要に応じて、LCフィルターを追加します。

**熱対策:**

*   LDOレギュレーターのデータシートを参照し、許容される動作温度範囲を確認します。
*   放熱板を使用したり、基板の銅箔パターンを工夫したりすることで、LDOレギュレーターの温度上昇を抑制します。

#### 6.3.6 応用例とユースケース

*   **マイクロコントローラーの電源:** 安定した電圧を供給し、ノイズを低減することで、マイクロコントローラーの動作を安定させます。
*   **センサーの電源:** 高精度センサーの感度を最大限に引き出すために、低ノイズなLDOレギュレーターを使用します。
*   **無線通信モジュールの電源:** 電圧変動による通信品質の低下を防ぐために、安定した電圧を供給します。

#### 6.3.7 トラブルシューティング

*   **出力電圧が安定しない:** 入力電圧がLDOレギュレーターの動作範囲内にあるか確認してください。コンデンサの容量が不足している可能性があります。LDOレギュレーターが故障している可能性があります。
*   **LDOレギュレーターが異常に発熱する:** 出力電流がLDOレギュレーターの定格を超えている可能性があります。入力電圧と出力電圧の差が大きすぎる可能性があります。
*   **ノイズが多い:** グラウンド配線が適切でない可能性があります。コンデンサの配置が最適化されていない可能性があります。

#### 6.3.8 まとめと次のステップ

LDOレギュレーターは、組み込みシステムの電源回路において、安定した電圧を供給し、ノイズを低減するための重要な部品です。LDOレギュレーターの特性を理解し、適切な選定と回路設計を行うことで、システム全体の性能と信頼性を向上させることができます。次のステップとして、様々なLDOレギュレーターのデータシートを比較検討し、自身のプロジェクトに最適なものを選択してください。また、より高度な電源管理チップの利用も検討することをお勧めします。
