## 第10章：画像処理：カメラモジュール、画像認識

### 10.1 カメラモジュール：画像データの取得

**10.1.1 概要と重要性**

現代の組み込みシステムにおいて、カメラモジュールは「目」の役割を果たし、周囲の状況を認識し、データとして処理するための重要なセンサーです。ロボット、ドローン、監視カメラ、自動運転車など、幅広い分野で活用されています。画像データを取得し、それを適切に処理・解析することで、高度な自律性やインテリジェンスをシステムに付与できます。このセクションでは、カメラモジュールから画像データを取得するための基礎知識と実践的な方法について解説します。

**10.1.2 特徴と利点**

カメラモジュールには、以下のような特徴と利点があります。

*   **汎用性:** さまざまなメーカーから多様な仕様のモジュールが提供されており、用途や予算に合わせて選択できます。
*   **低コスト:** 近年の技術進歩により、高性能なカメラモジュールが比較的安価に手に入るようになりました。
*   **小型化:** 組み込みシステムへの搭載を考慮し、小型で軽量なモジュールが多く存在します。
*   **リアルタイム性:** 高速な画像取得と処理が可能なモジュールもあり、リアルタイムなシステム構築に適しています。

**10.1.3 事前準備と前提条件**

このセクションを理解するためには、以下の知識があると役立ちます。

*   **組み込みシステムの基本的な知識:** マイクロコントローラやシングルボードコンピュータの構成、GPIOの制御など。
*   **プログラミングの基礎:** C/C++、Pythonなどのプログラミング言語の知識。
*   **画像処理の基礎知識:** RGB、YUVなどのカラーフォーマット、画像解像度、フレームレートなど。

また、以下のハードウェアとソフトウェアが必要です。

*   **カメラモジュール:** 今回は例として、一般的なUSBカメラまたは Raspberry Pi Camera Module V2 を使用します。
*   **開発ボード:** Raspberry Pi、Arduino (カメラシールドが必要) など。
*   **開発環境:** Python、OpenCVなど。
*   **OS:** Linux (Raspberry Piの場合)、またはArduino IDE。

**10.1.4 基本的な使い方**

ここでは、Raspberry Pi と OpenCV を用いて USB カメラから画像を取得する例を示します。

1.  **OpenCVのインストール:**

    Raspberry Pi に OpenCV がインストールされていない場合は、ターミナルで以下のコマンドを実行します。

    ```bash
    sudo apt update
    sudo apt install python3-opencv
    ```

2.  **カメラの接続:**

    USB カメラを Raspberry Pi の USB ポートに接続します。

3.  **Pythonスクリプトの作成:**

    `capture_image.py` という名前のPythonスクリプトを作成し、以下のコードを記述します。

    ```python
    import cv2

    # カメラの起動 (0 はデフォルトのカメラデバイス)
    cap = cv2.VideoCapture(0)

    # カメラが正常に起動したか確認
    if not cap.isOpened():
        print("カメラを開けませんでした")
        exit()

    # 画像の取得
    ret, frame = cap.read()

    # 画像が正常に取得できたか確認
    if not ret:
        print("画像を取得できませんでした")
        exit()

    # 画像の表示
    cv2.imshow("Camera Feed", frame)
    cv2.waitKey(0)  # キーが押されるまで待機
    cv2.destroyAllWindows()

    # 画像の保存
    cv2.imwrite("captured_image.jpg", frame)

    # カメラのリソースを解放
    cap.release()
    ```

4.  **スクリプトの実行:**

    ターミナルで以下のコマンドを実行します。

    ```bash
    python3 capture_image.py
    ```

    このスクリプトを実行すると、カメラからの映像がウィンドウに表示され、`captured_image.jpg` という名前で画像が保存されます。

**10.1.5 実践的なテクニック**

*   **解像度の調整:** `cap.set(cv2.CAP_PROP_FRAME_WIDTH, width)` および `cap.set(cv2.CAP_PROP_FRAME_HEIGHT, height)` を使用して、カメラの解像度を調整できます。
*   **フレームレートの調整:** `cap.set(cv2.CAP_PROP_FPS, fps)` を使用して、カメラのフレームレートを調整できます。
*   **グレースケール画像への変換:** `cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)` を使用して、カラー画像をグレースケール画像に変換できます。グレースケール画像は、画像処理の計算量を削減するのに役立ちます。
*   **画像の回転・反転:** `cv2.rotate()` または `cv2.flip()` を使用して、画像を回転または反転できます。

    ```python
    # 例：画像を90度回転
    rotated_image = cv2.rotate(frame, cv2.ROTATE_90_CLOCKWISE)
    ```
*   **画像のトリミング:** 画像の一部分だけを切り出すことも可能です。

    ```python
    # 例：画像の左上から100x100ピクセルを切り出す
    cropped_image = frame[0:100, 0:100]
    ```

**10.1.6 応用例とユースケース**

*   **監視カメラ:** 定期的に画像を撮影し、異常を検知するシステムを構築できます。
*   **ロボットビジョン:** ロボットが周囲の状況を認識し、自律的に行動するための情報源として活用できます。
*   **品質管理:** 製品の画像を撮影し、欠陥を自動的に検出するシステムを構築できます。
*   **顔認識ドアロック:** カメラで顔を認証し、ドアのロックを解除するシステムを構築できます。

**10.1.7 トラブルシューティング**

*   **カメラが認識されない:** USBケーブルが正しく接続されているか確認してください。また、カメラドライバが正しくインストールされているか確認してください。
*   **画像が取得できない:** カメラモジュールの電源が入っているか確認してください。また、カメラの設定が正しいか確認してください。
*   **画像の表示が遅い:** 画像解像度を下げるか、フレームレートを調整してください。

**10.1.8 まとめと次のステップ**

このセクションでは、カメラモジュールから画像データを取得するための基本的な知識と実践的な方法について解説しました。次のステップとして、取得した画像データを処理し、より高度なタスクを実行するための画像認識技術について学習しましょう。

### 10.2 画像認識：物体検出、顔認識

**10.2.1 概要と重要性**

画像認識は、コンピュータが画像内の物体や特徴を識別する技術です。物体検出は、画像内に存在する特定の物体（例：自動車、歩行者）の位置と種類を特定する技術であり、顔認識は、画像に写っている人物の顔を識別する技術です。これらの技術は、セキュリティ、自動運転、医療診断、エンターテインメントなど、様々な分野で応用されています。

**10.2.2 特徴と利点**

*   **自動化:** 人間の手を介さずに、画像内の情報を自動的に抽出できます。
*   **高速処理:** 大量の画像を高速に処理できます。
*   **高精度:** 特定の条件下では、人間以上の精度で物体や顔を認識できます。
*   **拡張性:** 新しい物体や顔を学習させることで、認識対象を拡張できます。

**10.2.3 事前準備と前提条件**

このセクションを理解するためには、以下の知識があると役立ちます。

*   **10.1 カメラモジュール：画像データの取得** の知識
*   **機械学習の基礎知識:** 特に、教師あり学習、ニューラルネットワークの基礎。
*   **OpenCVの知識:** 画像処理に必要な基本的な関数（フィルタリング、特徴抽出など）の利用経験。

また、以下のハードウェアとソフトウェアが必要です。

*   **カメラモジュール:** 10.1で使用したものと同じもの。
*   **開発ボード:** Raspberry Pi、GPU搭載のPCなど。
*   **開発環境:** Python、OpenCV、TensorFlow/Keras、PyTorchなど。
*   **学習済みモデル:** 物体検出や顔認識用に事前に学習されたモデル。

**10.2.4 基本的な使い方**

ここでは、OpenCV と TensorFlow を用いて、画像内の物体を検出する例を示します。事前に TensorFlow と OpenCV がインストールされていることを前提とします。また、TensorFlowのインストールには pip を使用します。

```bash
pip install tensorflow opencv-python
```

1.  **学習済みモデルのダウンロード:**

    TensorFlow の公式ドキュメントや Model Zoo から、COCOデータセットで学習済みのSSD MobileNet v3 モデルをダウンロードします。ダウンロードしたモデルファイル（`.pb`）と設定ファイル（`.pbtxt`）を同じディレクトリに配置します。

    ```bash
    # 例：model_directory/frozen_inference_graph.pb, model_directory/ssd_mobilenet_v3_large_coco_2020_01_14.pbtxt
    ```

2.  **Pythonスクリプトの作成:**

    `object_detection.py` という名前のPythonスクリプトを作成し、以下のコードを記述します。

    ```python
    import cv2
    import tensorflow as tf

    # モデルのロード
    model_path = 'model_directory/frozen_inference_graph.pb'
    config_path = 'model_directory/ssd_mobilenet_v3_large_coco_2020_01_14.pbtxt'

    net = cv2.dnn.readNetFromTensorflow(model_path, config_path)

    # 画像の読み込み
    img = cv2.imread("image.jpg")  # 検出したい画像を指定
    height, width, channels = img.shape

    # 画像の前処理
    blob = cv2.dnn.blobFromImage(img, 0.007843, (300, 300), 127.5)

    # モデルへの入力
    net.setInput(blob)

    # 推論の実行
    detections = net.forward()

    # 検出結果の処理
    for i in range(detections.shape[2]):
        confidence = detections[0, 0, i, 2]
        if confidence > 0.5:  # 信頼度閾値
            class_id = int(detections[0, 0, i, 1])
            x1 = int(detections[0, 0, i, 3] * width)
            y1 = int(detections[0, 0, i, 4] * height)
            x2 = int(detections[0, 0, i, 5] * width)
            y2 = int(detections[0, 0, i, 6] * height)

            # 検出された物体の描画
            cv2.rectangle(img, (x1, y1), (x2, y2), (0, 255, 0), 2)
            cv2.putText(img, str(class_id), (x1, y1 - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.9, (0, 255, 0), 2)

    # 結果の表示
    cv2.imshow("Object Detection", img)
    cv2.waitKey(0)
    cv2.destroyAllWindows()
    ```

    このスクリプトを実行する前に、`image.jpg` を検出したい画像ファイルに置き換えてください。また、`model_directory` をダウンロードしたモデルファイルと設定ファイルが格納されているディレクトリに置き換えてください。

3.  **スクリプトの実行:**

    ターミナルで以下のコマンドを実行します。

    ```bash
    python3 object_detection.py
    ```

    このスクリプトを実行すると、画像内の物体が検出され、検出結果が画像に描画されて表示されます。

**10.2.5 実践的なテクニック**

*   **信頼度閾値の調整:** `confidence > 0.5` の値を調整することで、検出される物体の数を調整できます。閾値を高くすると、信頼度の高い物体のみが検出されますが、検出漏れが増える可能性があります。閾値を低くすると、より多くの物体が検出されますが、誤検出が増える可能性があります。
*   **クラスIDの対応:** `class_id` は、検出された物体の種類を表すIDです。COCOデータセットの場合、IDと物体の対応は、[COCO dataset](https://cocodataset.org/#explore) の公式ドキュメントで確認できます。
*   **GPUの活用:** TensorFlow を GPU で実行するように設定することで、推論速度を大幅に向上させることができます。
*   **OpenCV DNNモジュールの活用:** 上記の例では、OpenCV の DNN (Deep Neural Network) モジュールを使用しました。このモジュールは、さまざまなディープラーニングフレームワークで学習されたモデルを簡単にロードして実行できます。

**10.2.6 応用例とユースケース**

*   **自動運転:** 車両、歩行者、信号機などを検出し、安全な運転を支援します。
*   **セキュリティ:** 監視カメラ映像から不審な人物や行動を検出し、警報を発します。
*   **医療診断:** X線画像やMRI画像から病変を検出し、診断を支援します。
*   **小売:** 店内の顧客の行動を分析し、マーケティング戦略の改善に役立てます。
*   **顔認証システム:** 顔認識技術を応用し、個人認証やアクセス制御を行います。

**10.2.7 トラブルシューティング**

*   **モデルがロードできない:** モデルファイルと設定ファイルのパスが正しいか確認してください。また、TensorFlow のバージョンがモデルと互換性があるか確認してください。
*   **物体が検出されない:** 信頼度閾値を下げてみてください。また、画像の前処理が正しいか確認してください。
*   **推論速度が遅い:** GPU を活用するか、モデルを軽量化してください。

**10.2.8 まとめと次のステップ**

このセクションでは、画像認識の基本的な概念と実践的な方法について解説しました。次のステップとして、独自のデータセットで物体検出モデルを学習させる方法や、より高度な画像認識技術について学習しましょう。また、組み込み環境での推論最適化についても検討すると良いでしょう。例えば、TensorFlow Liteを利用することで、リソースが限られた環境でも効率的な推論が可能になります。

### 10.3 QRコード読み取り

**10.3.1 概要と重要性**

QRコード（Quick Responseコード）は、二次元バーコードの一種で、大量の情報をコンパクトに格納できるため、様々な用途で広く利用されています。商品情報、URL、連絡先情報などをQRコードにエンコードし、スマートフォンや専用のリーダーで読み取ることで、簡単に情報を取得できます。組み込みシステムにおいても、設定情報の設定や、機器の識別、トレーサビリティ管理など、様々な用途で活用されています。

**10.3.2 特徴と利点**

*   **大容量:** 数字、英字、漢字、記号など、様々なデータを格納できます。
*   **高速読み取り:** 多少の汚れや歪みがあっても、高速に読み取ることができます。
*   **汎用性:** スマートフォン、タブレット、専用のリーダーなど、様々なデバイスで読み取ることができます。
*   **無償利用:** QRコードの規格は公開されており、ライセンス料なしで自由に利用できます。

**10.3.3 事前準備と前提条件**

このセクションを理解するためには、以下の知識があると役立ちます。

*   **10.1 カメラモジュール：画像データの取得** の知識
*   **画像処理の基礎知識:** 画像の二値化、エッジ検出など。

また、以下のハードウェアとソフトウェアが必要です。

*   **カメラモジュール:** 10.1で使用したものと同じもの。
*   **開発ボード:** Raspberry Pi、スマートフォンなど。
*   **開発環境:** Python、OpenCV、pyzbarなど。
*   **QRコード生成ツール:** オンラインのQRコード生成サービスや、専用のソフトウェア。

**10.3.4 基本的な使い方**

ここでは、OpenCV と pyzbar を用いて、画像内の QRコードを読み取る例を示します。事前に pyzbar がインストールされていることを前提とします。

```bash
pip install pyzbar opencv-python
```

1.  **Pythonスクリプトの作成:**

    `qr_code_reader.py` という名前のPythonスクリプトを作成し、以下のコードを記述します。

    ```python
    import cv2
    from pyzbar.pyzbar import decode

    # カメラの起動 (0 はデフォルトのカメラデバイス)
    cap = cv2.VideoCapture(0)

    # カメラが正常に起動したか確認
    if not cap.isOpened():
        print("カメラを開けませんでした")
        exit()

    while True:
        # 画像の取得
        ret, frame = cap.read()

        # 画像が正常に取得できたか確認
        if not ret:
            print("画像を取得できませんでした")
            break

        # QRコードの読み取り
        decoded_objects = decode(frame)

        # 読み取ったQRコードの情報を表示
        for obj in decoded_objects:
            print("Data:", obj.data.decode('utf-8'))
            # QRコードの周りに枠を描画
            points = obj.polygon
            if len(points) > 4:
                hull = cv2.convexHull(np.array([point for point in points], dtype=np.float32))
                hull = list(map(tuple, np.squeeze(hull)))
            else:
                hull = points;

            n = len(hull)
            for j in range(0, n):
                cv2.line(frame, hull[j], hull[(j+1) % n], (255,0,0), 2)


        # 画像の表示
        cv2.imshow("QR Code Reader", frame)

        # 'q'キーが押されたら終了
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break

    # カメラのリソースを解放
    cap.release()
    cv2.destroyAllWindows()
    ```

2.  **スクリプトの実行:**

    ターミナルで以下のコマンドを実行します。

    ```bash
    python3 qr_code_reader.py
    ```

    このスクリプトを実行すると、カメラからの映像が表示され、QRコードが検出されると、その内容が表示されます。

**10.3.5 実践的なテクニック**

*   **読み取り速度の向上:** 画像の解像度を調整したり、カメラのフォーカスを調整したりすることで、読み取り速度を向上させることができます。
*   **複数のQRコードの読み取り:** `decode()` 関数は、画像内に複数のQRコードが存在する場合、すべてのQRコードを読み取ります。
*   **QRコードの生成:** QRコードを生成するには、`qrcode` ライブラリを使用します。

    ```python
    import qrcode

    data = "https://www.example.com"
    img = qrcode.make(data)
    img.save("qr_code.png")
    ```

**10.3.6 応用例とユースケース**

*   **在庫管理:** 商品にQRコードを付与し、在庫状況をリアルタイムに管理します。
*   **チケットレス入場:** チケット代わりにQRコードを使用し、スムーズな入場を実現します。
*   **電子決済:** スマートフォンでQRコードを読み取り、簡単に決済を行います。
*   **機器の設定:** QRコードに設定情報をエンコードし、機器に読み込ませることで、簡単に設定を行います。
*   **トレーサビリティ管理:** 製品の製造履歴や流通経路をQRコードで管理します。

**10.3.7 トラブルシューティング**

*   **QRコードが読み取れない:** カメラのフォーカスが合っているか確認してください。また、QRコードが汚れていないか確認してください。
*   **読み取り速度が遅い:** 画像の解像度を下げてみてください。
*   **誤った情報が読み取られる:** QRコードが破損していないか確認してください。
