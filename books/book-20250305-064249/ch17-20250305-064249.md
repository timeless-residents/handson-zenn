## 第17章：ESP32 Mesh Network：分散型ネットワーク構築

### 17.1 ESP-MESHの基本

#### 概要と重要性

ESP-MESHは、Espressif Systemsが提供する、ESP32をベースにしたメッシュネットワークプロトコルです。従来のWi-Fiネットワークは、通常、アクセスポイント（AP）を中心としたスター型トポロジーで構成されます。しかし、ESP-MESHは、ノード同士が互いに通信し、自律的にネットワークを形成する、分散型のネットワーク構造を構築できます。

この技術の重要性は、カバレッジの拡張、耐障害性の向上、柔軟なネットワーク構築にあります。従来のWi-Fiでは電波が届きにくい場所や、障害物が多い環境でも、ESP-MESHを用いることで安定した通信環境を実現できます。また、ノードが故障しても、他のノードが通信経路を自動的に再構築するため、ネットワーク全体の可用性が高まります。

#### 特徴と利点

ESP-MESHの主な特徴と利点は以下の通りです。

*   **自己組織化（Self-Organizing）：** ノードが自動的にネットワークを形成し、最適な経路を選択します。
*   **自己修復（Self-Healing）：** ノードの故障や通信障害が発生した場合、自動的に代替経路を探索し、ネットワークを維持します。
*   **柔軟なスケーラビリティ：** 必要に応じてノードを追加・削除することで、ネットワークの規模を容易に変更できます。
*   **カバレッジの拡張：** 中継ノードを経由することで、電波の届きにくい場所にもネットワークを拡張できます。
*   **耐障害性：** 一つのノードが故障しても、他のノードが通信経路を再構築するため、ネットワーク全体の可用性が高まります。
*   **省電力モード：** バッテリー駆動のデバイスに適した、省電力モードをサポートしています。
*   **セキュアな通信：** WPA2-PSKやAES暗号化などのセキュリティ機能を利用できます。

#### 事前準備と前提条件

ESP-MESHを始める前に、以下の準備が必要です。

1.  **ESP32開発ボード：** 少なくとも2つ以上のESP32開発ボードが必要です。推奨はESP32-DevKitCです。
2.  **Arduino IDEまたはESP-IDF：** ESP32のプログラミング環境として、Arduino IDE（ESP32コアをインストール済み）またはESP-IDFを使用します。ここではArduino IDEを使用した例を紹介します。
3.  **USBケーブル：** ESP32開発ボードをPCに接続するためのUSBケーブルが必要です。
4.  **Wi-Fi環境：** ESP-MESHネットワークを構築する際に、初期設定やインターネット接続が必要となる場合があります。
5.  **ESP-MESHライブラリ：** Arduino IDEを使用する場合は、ESP-MESHライブラリをインストールする必要があります。Arduino IDEのライブラリマネージャから「ESP-MESH」を検索してインストールします。

#### 基本的な使い方

ESP-MESHの基本的な使い方は以下の通りです。

1.  **ルートノードのプログラム：** ネットワークの起点となるルートノードのプログラムを作成します。ルートノードは、外部ネットワーク（インターネット）への接続を確立する役割も担います。
2.  **子ノードのプログラム：** ルートノードに接続する子ノードのプログラムを作成します。子ノードは、ルートノードまたは他の子ノードを経由して通信を行います。
3.  **プログラムの書き込み：** 作成したプログラムをESP32開発ボードに書き込みます。
4.  **動作確認：** ESP32開発ボードを起動し、シリアルモニタなどで動作状況を確認します。

以下に、ルートノードと子ノードの簡単なスケッチ例を示します。

**ルートノードのスケッチ (root.ino):**

```arduino
#include <WiFi.h>
#include <esp_mesh.h>
#include <esp_mesh_internal.h>

#define MESH_SSID       "ESP-MESH-NETWORK"  // MeshネットワークのSSID
#define MESH_PASSWORD   "password123"       // Meshネットワークのパスワード
#define MESH_PORT       5555                // Meshネットワークのポート

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA); // STAモードに設定

  mesh_cfg_t cfg = {
    .channel = 1,
    .router.ssid = MESH_SSID,
    .router.password = MESH_PASSWORD,
    .mesh_id = {0x77, 0x77, 0x77, 0x77, 0x77, 0x77}
  };
  esp_mesh_init();
  esp_mesh_set_self_organized(true);  // 自己組織化を有効にする
  esp_mesh_set_ap_authmode(WIFI_AUTH_WPA2_PSK); // AP認証モードを設定
  esp_mesh_set_max_layer(3);           // 最大ホップ数を設定
  esp_mesh_set_topology(MESH_TOPOLOGY_TREE); // トポロジーをツリー型に設定
  esp_mesh_set_config(&cfg);
  esp_mesh_start();

  Serial.println("Root node initialized");
}

void loop() {
  // ルートノードの処理
  delay(1000);
}
```

**子ノードのスケッチ (child.ino):**

このスケッチでは、`mesh_cfg_t` 構造体を使用して、メッシュネットワークのSSID、パスワード、チャネルなどを設定しています。`esp_mesh_init()` 関数でESP-MESHを初期化し、`esp_mesh_start()` 関数でメッシュネットワークを開始します。 `esp_mesh_set_self_organized(true)` で自己組織化を有効にしています。

#### 実践的なテクニック

ESP-MESHをより効果的に活用するためのテクニックをいくつか紹介します。

*   **データ転送：** `esp_mesh_send()` 関数を使用して、メッシュネットワーク内のノード間でデータを送受信できます。データの形式は自由に定義できますが、JSONなどの構造化された形式を使用すると、データの解析が容易になります。

*   **ノード情報の取得：** `esp_mesh_get_device_list()` 関数を使用して、メッシュネットワーク内のノードの情報を取得できます。この情報には、MACアドレス、IPアドレス、RSSI（受信信号強度）などが含まれます。

*   **省電力化：** ESP-MESHは、省電力モードをサポートしています。`esp_mesh_set_sleep()` 関数を使用すると、ノードをスリープモードに移行させることができます。定期的にデータを送信する必要がある場合は、タイマー割り込みなどを使用して、スリープモードから復帰させることができます。

*   **ルーティング制御：** デフォルトでは、ESP-MESHは最適な経路を自動的に選択しますが、必要に応じてルーティングを制御することもできます。`esp_mesh_set_routing_policy()` 関数を使用すると、特定のノードを経由するように経路を指定できます。

#### 応用例とユースケース

ESP-MESHは、さまざまな分野で応用できます。以下に具体的なユースケースをいくつか紹介します。

*   **スマートホーム：** 家全体をカバーするスマートホームシステムを構築できます。センサーやアクチュエータを搭載したESP32ノードを各部屋に配置し、メッシュネットワークで接続することで、安定した通信環境を実現できます。
*   **農業：** 広大な農地にセンサーを配置し、土壌の状態や気象情報を収集するシステムを構築できます。ESP-MESHを使用することで、電源や通信インフラが整っていない場所でも、データを収集できます。
*   **産業用IoT：** 工場内の機器の状態を監視するシステムを構築できます。ESP-MESHを使用することで、ノイズが多い環境でも、安定した通信環境を実現できます。
*   **災害対策：** 災害発生時に、通信インフラが寸断された場合でも、ESP-MESHを使用することで、臨時の通信ネットワークを構築できます。
*   **環境モニタリング：** 広範囲な環境データを収集するために、センサーノードを分散配置し、ESP-MESHでデータを集約するシステムを構築できます。

#### トラブルシューティング

ESP-MESHを使用する際に、よく発生する問題とその解決策を以下に示します。

*   **ノードが接続できない：** SSID、パスワード、チャネルなどの設定が正しいか確認してください。また、ノード同士の距離が離れすぎていないか、障害物がないか確認してください。シリアルモニタでエラーメッセージを確認すると、原因の特定に役立ちます。
*   **通信が不安定：** 電波干渉がないか確認してください。また、ノードのファームウェアが最新版であるか確認してください。
*   **データが損失する：** ネットワークの負荷が高い可能性があります。データの送信頻度を減らすか、ノードを追加してネットワークを分散化してください。
*   **ルートノードがダウンした場合：** ルートノードがダウンすると、メッシュネットワーク全体が機能停止する可能性があります。冗長化のために、複数のルートノードを配置することを検討してください。

### 17.2 Mesh Networkの実装

#### 概要と重要性

このセクションでは、ESP-MESHネットワークを実際に実装する際の具体的な手順と、より高度な設定について解説します。基本的な設定だけでなく、データの送受信、ルーティング制御、省電力化などのテクニックを習得することで、より実用的なメッシュネットワークを構築できるようになります。

#### 特徴と利点

このセクションで解説する実装テクニックの特徴と利点は以下の通りです。

*   **データ転送：** ネットワーク内のノード間で効率的にデータを送受信できます。
*   **ルーティング制御：** 特定のノードを経由するように経路を指定することで、ネットワークのパフォーマンスを最適化できます。
*   **省電力化：** バッテリー駆動のデバイスの寿命を延ばすことができます。
*   **エラー処理：** 通信エラーが発生した場合に、自動的に再接続を試みることで、ネットワークの信頼性を高めることができます。
*   **動的なネットワーク管理：** ネットワークの状態を監視し、必要に応じて設定を変更することで、常に最適な状態を維持できます。

#### 事前準備と前提条件

17.1と同様の準備に加え、以下を推奨します。

1.  **JSONライブラリ:** ノード間でのデータ交換にJSON形式を使用する場合、Arduino JSONライブラリをインストールしてください。
2.  **シリアル通信ツール:** Tera Term, Puttyなどのシリアル通信ツールがあると、各ノードのログを確認する際に便利です。

#### 基本的な使い方

**1. データ転送の実装:**

ESP-MESHネットワーク内のノード間でデータを送受信するには、`esp_mesh_send()` 関数を使用します。送信するデータは、`mesh_data_t` 構造体に格納します。

```arduino
#include <WiFi.h>
#include <esp_mesh.h>
#include <esp_mesh_internal.h>
#include <ArduinoJson.h>

#define MESH_SSID       "ESP-MESH-NETWORK"
#define MESH_PASSWORD   "password123"
#define MESH_PORT       5555

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);

  mesh_cfg_t cfg = {
    .channel = 1,
    .router.ssid = MESH_SSID,
    .router.password = MESH_PASSWORD,
    .mesh_id = {0x77, 0x77, 0x77, 0x77, 0x77, 0x77}
  };
  esp_mesh_init();
  esp_mesh_set_self_organized(true);
  esp_mesh_set_ap_authmode(WIFI_AUTH_WPA2_PSK);
  esp_mesh_set_max_layer(3);
  esp_mesh_set_topology(MESH_TOPOLOGY_TREE);
  esp_mesh_set_config(&cfg);
  esp_mesh_start();

  esp_mesh_set_recv_cb(&mesh_rx_cb); // 受信コールバック関数を設定

  Serial.println("Node initialized");
}

void loop() {
  // 10秒ごとにデータを送信する
  static unsigned long lastSendTime = 0;
  if (millis() - lastSendTime > 10000) {
    lastSendTime = millis();

    // JSONデータを作成
    StaticJsonDocument<200> doc;
    doc["sensor"] = "Temperature";
    doc["value"] = random(20, 30); // 20～30℃のランダムな温度

    char jsonBuffer[256];
    serializeJson(doc, jsonBuffer);

    // データ送信
    mesh_data_t data;
    data.size = strlen(jsonBuffer) + 1; // ヌル文字を含む
    data.proto = MESH_PROTO_JSON; // カスタムプロトコル
    data.tos = MESH_TOS_P2P;

    esp_err_t err = esp_mesh_send(NULL, &data, (uint8_t*)jsonBuffer, data.size, NULL, 0); // NULLはブロードキャスト
    if (err != ESP_OK) {
      Serial.printf("Error sending data: %d\n", err);
    } else {
      Serial.println("Data sent");
    }
  }

  delay(1000);
}


void mesh_rx_cb(mesh_addr_t from, mesh_data_t* data, uint8_t* payload, size_t size) {
  Serial.printf("Received data from: %02x%02x%02x%02x%02x%02x, size:%d\n",
                from.addr[0], from.addr[1], from.addr[2], from.addr[3], from.addr[4], from.addr[5], size);

  Serial.printf("Data: %s\n", (char*)payload);
}

```

このコードでは、10秒ごとにランダムな温度データをJSON形式で生成し、`esp_mesh_send()` 関数を使用してブロードキャストで送信しています。受信側では、`mesh_rx_cb()` コールバック関数でデータを受信し、シリアルモニタに出力します。

**2. ルーティング制御:**

ESP-MESHは、デフォルトでは最適な経路を自動的に選択しますが、必要に応じてルーティングを制御することもできます。`esp_mesh_set_routing_policy()` 関数を使用すると、特定のノードを経由するように経路を指定できます。

```c
// 特定のノードを経由するように経路を指定する例
mesh_addr_t dest_addr;
// dest_addrに宛先ノードのMACアドレスを設定
esp_mesh_set_routing_policy(&dest_addr, 1); // 1は特定のノードを経由するポリシー
```

**3. 省電力化の実装:**

ESP-MESHは、省電力モードをサポートしています。`esp_mesh_set_sleep()` 関数を使用すると、ノードをスリープモードに移行させることができます。

```c
// ノードをスリープモードに移行する例
esp_mesh_set_sleep(true);
```

スリープモードから復帰するには、タイマー割り込みや外部割り込みを使用します。

#### 実践的なテクニック

*   **JSONデータの活用：** ノード間で送受信するデータは、JSON形式で構造化することをお勧めします。JSONライブラリを使用すると、データの解析や生成が容易になります。
*   **エラー処理：** `esp_mesh_send()` 関数は、エラーコードを返します。エラーが発生した場合は、適切なエラー処理を行うようにしてください。例えば、再送信を試みるなどの対策を講じることができます。
*   **ブロードキャストの制限：** ブロードキャストは、ネットワーク全体の負荷を高める可能性があります。必要に応じて、ユニキャストを使用するようにしてください。
*   **OTAアップデート：** ESP-MESHネットワーク内のノードのファームウェアを、無線経由でアップデートすることができます。OTAアップデートを使用すると、メンテナンスが容易になります。

#### 応用例とユースケース

*   **スマート農業：** 農地の各所に設置されたセンサーノードから、土壌の水分量や温度などのデータを収集し、ESP-MESHネットワークを通じて集約します。収集したデータは、灌漑システムの制御などに利用できます。
*   **スマートシティ：** 街灯やゴミ箱などのインフラにESP32ノードを組み込み、ESP-MESHネットワークを通じて状態を監視します。収集したデータは、効率的なメンテナンスやリソースの最適化に利用できます。
*   **ウェアラブルデバイス：** 複数のウェアラブルデバイスをESP-MESHネットワークで接続し、互いに情報を共有することができます。例えば、心拍数や位置情報などを共有し、グループでの運動をサポートするアプリケーションなどが考えられます。

#### トラブルシューティング

*   **データが届かない：** 宛先ノードのMACアドレスが正しいか確認してください。また、ネットワークのトポロジーが変化し、経路が切断されている可能性があります。`esp_mesh_get_routing_table()` 関数を使用して、ルーティングテーブルを確認してください。
*   **スリープモードから復帰しない：** スリープモードから復帰するための設定が正しいか確認してください。タイマー割り込みや外部割り込みの設定に誤りがある可能性があります。
*   **OTAアップデートに失敗する：** ファームウェアのイメージが正しいか確認してください。また、ネットワークの接続が不安定な可能性があります。

### 17.3 Mesh Networkの応用

#### 概要と重要性

このセクションでは、ESP-MESHネットワークの応用的な使い方について解説します。具体的には、外部ネットワークとの連携、セキュリティの強化、ネットワーク管理の自動化などのテーマを取り上げます。これらの応用テクニックを習得することで、より高度なメッシュネットワークシステムを構築できるようになります。

#### 特徴と利点

このセクションで解説する応用テクニックの特徴と利点は以下の通りです。

*   **外部ネットワーク連携：** メッシュネットワークをインターネットなどの外部ネットワークに接続することで、データの収集や制御を遠隔で行うことができます。
*   **セキュリティ強化：** メッシュネットワークのセキュリティを強化することで、不正アクセスやデータ改ざんなどのリスクを軽減できます。
*   **ネットワーク管理の自動化：** ネットワークの状態を監視し、必要に応じて設定を自動的に変更することで、運用コストを削減できます。
*   **分散処理：** メッシュネットワーク内のノードに処理を分散することで、システムの負荷を分散し、パフォーマンスを向上させることができます。
*   **フォールトトレランス：** ノードの故障時にも、自動的に代替経路を探索することで、システムの可用性を高めることができます。

#### 事前準備と前提条件

1.  **MQTTブローカー:** クラウドとの連携にMQTTを使用する場合、MQTTブローカーが必要です。公開されているブローカーを利用するか、自分で構築してください。
2.  **TLS/SSL証明書:** HTTPSやTLS/SSLを使用する際、適切な証明書が必要です。
3.  **データベース:** 収集したデータを保存するためのデータベース(例: MySQL, PostgreSQL, MongoDB)があると便利です。

#### 基本的な使い方

**1. 外部ネットワークとの連携 (MQTT):**

ESP-MESHネットワークをインターネットなどの外部ネットワークに接続するには、ゲートウェイノードを設置し、外部ネットワークとの通信を中継します。ここでは、MQTTプロトコルを使用して、クラウドにデータを送信する例を示します。

```arduino
#include <WiFi.h>
#include <esp_mesh.h>
#include <esp_mesh_internal.h>
#include <PubSubClient.h>
#include <ArduinoJson.h>

#define MESH_SSID       "ESP-MESH-NETWORK"
#define MESH_PASSWORD   "password123"
#define MESH_PORT       5555

// MQTTサーバーの設定
#define MQTT_SERVER     "your_mqtt_server"
#define MQTT_PORT       1883
#define MQTT_USER       "your_mqtt_user"
#define MQTT_PASSWORD   "your_mqtt_password"
#define MQTT_TOPIC      "esp32/mesh/data"

WiFiClient espClient;
PubSubClient client(espClient);

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);

  mesh_cfg_t cfg = {
    .channel = 1,
    .router.ssid = MESH_SSID,
    .router.password = MESH_PASSWORD,
    .mesh_id = {0x77, 0x77, 0x77, 0x77, 0x77, 0x77}
  };
  esp_mesh_init();
  esp_mesh_set_self_organized(true);
  esp_mesh_set_ap_authmode(WIFI_AUTH_WPA2_PSK);
  esp_mesh_set_max_layer(3);
  esp_mesh_set_topology(MESH_TOPOLOGY_TREE);
  esp_mesh_set_config(&cfg);
  esp_mesh_start();

  esp_mesh_set_recv_cb(&mesh_rx_cb);

  // WiFiに接続
  WiFi.begin("Your WiFi SSID", "Your WiFi Password");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("Connected to WiFi");

  client.setServer(MQTT_SERVER, MQTT_PORT);
  client.setCallback(mqtt_callback); // MQTT受信コールバックを設定
  connectMQTT();

  Serial.println("Gateway node initialized");
}

void loop() {
  client.loop(); // MQTTクライアントの処理

  static unsigned long lastSendTime = 0;
  if (millis() - lastSendTime > 10000) {
    lastSendTime = millis();

    // JSONデータを作成
    StaticJsonDocument<200> doc;
    doc["sensor"] = "Gateway";
    doc["value"] = random(20, 30);

    char jsonBuffer[256];
    serializeJson(doc, jsonBuffer);

    // MQTTでデータを送信
    if (client.connected()) {
      client.publish(MQTT_TOPIC, jsonBuffer);
      Serial.println("Published to MQTT");
    } else {
      Serial.println("Not connected to MQTT, reconnecting...");
      connectMQTT();
    }
  }

  delay(1000);
}


void connectMQTT() {
    while (!client.connected()) {
        Serial.print("Attempting MQTT connection...");
        // 接続を試みる
        if (client.connect("ESP32Client", MQTT_USER, MQTT_PASSWORD)) {
            Serial.println("connected");
            // ... およびトピックをサブスクライブ
            client.subscribe(MQTT_TOPIC);
        } else {
            Serial.print("failed, rc=");
            Serial.print(client.state());
            Serial.println(" try again in 5 seconds");
            // 5秒待って再試行
            delay(5000);
        }
    }
}

void mqtt_callback(char* topic, byte* message, unsigned int length) {
  Serial.print("Message arrived [");
  Serial.print(topic);
  Serial.print("] ");
  for (int i = 0; i < length; i++) {
    Serial.print((char)message[i]);
  }
  Serial.println();
}

void mesh_rx_cb(mesh_addr_t from, mesh_data_t* data, uint8_t* payload, size_t size) {
  Serial.printf("Received data from: %02x%02x%02x%02x%02x%02x, size:%d\n",
                from.addr[0], from.addr[1], from.addr[2], from.addr[3], from.addr[4], from.addr[5], size);

  Serial.printf("Data: %s\n", (char*)payload);

  // 受信したデータをMQTTで送信
  if (client.connected()) {
    client.publish(MQTT_TOPIC, (char*)payload);
    Serial.println("Published to MQTT from Mesh Data");
  } else {
    Serial.println("Not connected to MQTT, reconnecting...");
    connectMQTT();
  }
}
```

このコードでは、ゲートウェイノードがWi-Fiに接続し、MQTTブローカーに接続します。メッシュネットワーク内のノードから受信したデータは、MQTTブローカーに転送されます。

**2. セキュリティの強化 (WPA3):**

ESP-MESHは、WPA2-PSKだけでなく、より強力なWPA3-SAEをサポートしています。WPA3を使用することで、ブルートフォースアタックに対する耐性を高めることができます。

```c
// WPA3-SAEを設定する例
mesh_cfg_t cfg = {
    .channel = 1,
    .router.ssid = MESH_SSID,
    .router.password = MESH_PASSWORD,
    .mesh_id = {0x77, 0x77, 0x77, 0x77, 0x77, 0x77},
    .ap_authmode = WIFI_AUTH_WPA3_SAE // WPA3-SAEを設定
};
```

**3. ネットワーク管理の自動化:**

ESP-MESHネットワークの状態を監視し、必要に応じて設定を自動的に変更することができます。例えば、ノードのRSSI（受信信号強度）を監視し、RSSIが低い場合は、近くのノードを経由するようにルーティングを自動的に変更することができます。

#### 実践的なテクニック

*   **ロードバランシング：** 複数のゲートウェイノードを設置し、負荷を分散することで、ネットワークのパフォーマンスを向上させることができます。
*   **QoS (Quality of Service)：** データの種類に応じて優先度を設定することで、重要なデータの遅延を最小限に抑えることができます。
*   **ネットワーク監視ツール：** Grafanaなどのネットワーク監視ツールを使用すると、メッシュネットワークの状態を可視化し、問題の早期発見に役立ちます。
*   **分散データベース：** 収集したデータを、メッシュネットワーク内の複数のノードに分散して保存することで、データの可用性を高めることができます。

#### 応用例とユースケース

*   **災害対策：** 災害発生時に、通信インフラが寸断された場合でも、ESP-MESHネットワークを使用して、被災地の状況をリアルタイムに把握することができます。収集したデータは、救助活動の効率化に役立ちます。
*   **スマートロジスティクス：** 倉庫内の在庫状況をリアルタイムに把握し、最適なルートで商品を搬送することができます。ESP-MESHネットワークを使用することで、広い倉庫内でも安定した通信環境を実現できます。
*   **環境モニタリング：** 広範囲な環境データを収集するために、センサーノードを分散配置し、ESP-MESHネットワークでデータを集約します。収集したデータは、環境汚染の監視や気候変動の研究に利用できます。

#### トラブルシューティング

*   **MQTT接続が不安定：** MQTTブローカーの設定が正しいか確認してください。また、ネットワークの接続が不安定な可能性があります。
*   **セキュリティの問題：** WPA3-SAEを使用している場合は、すべてのノードがWPA3-SAEに対応しているか確認してください。
*   **ネットワーク管理の問題：** ネットワーク監視ツールを使用しても、データが正常に表示されない場合は、ツールの設定が正しいか確認してください。
