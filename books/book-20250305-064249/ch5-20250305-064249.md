## 第5章：データ可視化：Webサーバー構築とダッシュボード作成

データ可視化は、収集したデータを理解し、そこから洞察を得るための強力な手段です。IoTデバイスから得られるセンサーデータは、時に膨大で複雑になりがちですが、適切な可視化ツールを用いることで、データの傾向や異常を容易に把握できます。本章では、ESP32上で動作するWebサーバーを構築し、GrafanaとInfluxDBを連携させてダッシュボードを作成する方法、そしてNode-REDによるデータフロー構築と可視化について解説します。これらの技術を組み合わせることで、リアルタイムなデータ監視、異常検知、そしてより深いデータ分析が可能になります。

### 5.1 Webサーバー構築：ESP32上で動作するシンプルなWebサーバー

#### 5.1.1 概要と重要性

ESP32は、Wi-FiとBluetooth機能を内蔵した低コストなマイクロコントローラーです。その手軽さと汎用性から、IoTプロジェクトにおいて広く利用されています。ESP32上にWebサーバーを構築することで、センサーデータをリアルタイムにブラウザ上で確認したり、設定を変更したりすることが可能になります。これは、IoTデバイスの状態を遠隔から監視・制御するための基本的な手段となります。

#### 5.1.2 特徴と利点

*   **シンプルさ:** ESP32上で動作するWebサーバーは、複雑な設定を必要とせず、比較的簡単に構築できます。
*   **リアルタイム性:** センサーデータをほぼリアルタイムで表示できるため、迅速な意思決定に貢献します。
*   **カスタマイズ性:** Webサーバーのコードを自由にカスタマイズできるため、特定のニーズに合わせた表示や機能を追加できます。
*   **低コスト:** ESP32自体が安価であり、他のハードウェアやソフトウェアに依存しないため、低コストで実現可能です。

#### 5.1.3 事前準備と前提条件

*   ESP32開発環境の構築 (Arduino IDEなど)
*   ESP32ボード
*   Wi-Fi環境
*   ArduinoJsonライブラリ (JSONデータのパースと生成に使用)

#### 5.1.4 基本的な使い方

以下のコードは、ESP32上でシンプルなWebサーバーを構築し、接続されたクライアントに"Hello from ESP32!"というテキストを返す例です。

```cpp
#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "YourWiFiSSID";
const char* password = "YourWiFiPassword";

WebServer server(80);

void handleRoot() {
  server.send(200, "text/plain", "Hello from ESP32!");
}

void setup() {
  Serial.begin(115200);

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("");
  Serial.println("WiFi connected");

  server.on("/", handleRoot);

  server.begin();
  Serial.println("Web server started");
  Serial.print("Use this URL : http://");
  Serial.println(WiFi.localIP());
}

void loop() {
  server.handleClient();
}
```

**コード解説:**

1.  **ヘッダーファイルのインクルード:** `WiFi.h` (Wi-Fi接続)、`WebServer.h` (Webサーバー機能)をインクルードします。
2.  **Wi-Fi設定:** `ssid`と`password`に、接続するWi-FiネットワークのSSIDとパスワードを設定します。
3.  **WebServerインスタンスの作成:** ポート80でWebServerインスタンスを作成します。
4.  **ルートハンドラ:** `handleRoot()`関数は、ルートパス("/")へのリクエストを処理します。この関数は、HTTPステータスコード200 (OK)と、"Hello from ESP32!"というテキストをクライアントに送信します。
5.  **setup()関数:**
    *   シリアル通信を初期化します。
    *   Wi-Fiネットワークに接続します。接続が完了するまで待機します。
    *   ルートパス("/")に対するハンドラを登録します。
    *   Webサーバーを開始します。
6.  **loop()関数:**
    *   `server.handleClient()`関数は、クライアントからのリクエストを処理し続けます。

このコードをESP32に書き込み、シリアルモニタでESP32のIPアドレスを確認し、WebブラウザでそのIPアドレスにアクセスすると、"Hello from ESP32!"というテキストが表示されるはずです。

#### 5.1.5 実践的なテクニック

*   **センサーデータの表示:** センサーから読み取ったデータをJSON形式でクライアントに送信し、JavaScriptで解析してWebページ上に表示できます。
*   **設定変更:** Webページ上のフォームからデータを送信し、ESP32の設定（例：サンプリングレート、閾値など）を変更できます。
*   **認証:** Basic認証やDigest認証などを実装することで、Webサーバーへのアクセスを制限できます。

#### 5.1.6 応用例とユースケース

*   **環境モニタリング:** 温湿度センサーからデータを収集し、Webページ上でリアルタイムに表示する。
*   **スマートホーム:** 照明や家電製品のオン/オフをWebページから制御する。
*   **遠隔制御ロボット:** ロボットの状態を監視し、Webページから操作する。

#### 5.1.7 トラブルシューティング

*   **Wi-Fi接続の問題:** SSIDやパスワードが正しいか確認してください。Wi-Fiルーターとの距離が遠すぎないか確認してください。
*   **Webページが表示されない:** ESP32のIPアドレスが正しいか確認してください。ポート80がブロックされていないか確認してください。
*   **メモリ不足:** Webページのサイズが大きすぎると、ESP32のメモリが不足する可能性があります。コードを最適化するか、より多くのメモリを搭載したESP32を使用してください。

### 5.2 ダッシュボード作成：GrafanaとInfluxDBの連携

#### 5.2.1 概要と重要性

Grafanaは、オープンソースのデータ可視化ツールであり、様々なデータソースからデータを取得し、美しいダッシュボードを作成することができます。InfluxDBは、時系列データを効率的に保存・管理するためのデータベースです。この二つを連携させることで、ESP32から収集したセンサーデータをリアルタイムに可視化し、長期的なデータ分析を行うことが可能になります。

#### 5.2.2 特徴と利点

*   **柔軟性:** Grafanaは、多様なデータソースに対応しており、様々な種類のデータを可視化できます。
*   **豊富な可視化オプション:** Grafanaは、グラフ、ゲージ、テーブルなど、様々な可視化オプションを提供します。
*   **リアルタイム性:** InfluxDBは、高速なデータ書き込みとクエリ処理をサポートしており、リアルタイムなデータ可視化に適しています。
*   **スケーラビリティ:** InfluxDBは、大量のデータを効率的に処理できるため、大規模なIoTシステムにも対応できます。

#### 5.2.3 事前準備と前提条件

*   InfluxDBのインストールと設定 (公式ドキュメントを参照)
*   Grafanaのインストールと設定 (公式ドキュメントを参照)
*   ESP32がInfluxDBにデータを送信できる環境

#### 5.2.4 基本的な使い方

1.  **InfluxDBの設定:** InfluxDBに、ESP32からのデータを保存するためのデータベースを作成します。

    ```bash
    influx -execute 'CREATE DATABASE esp32_data'
    ```

2.  **ESP32からのデータ送信:** ESP32からInfluxDBにデータを送信するコードを記述します。以下のコードは、DHT11センサーから読み取った温度と湿度をInfluxDBに送信する例です。

    ```cpp
    #include <WiFi.h>
    #include <HTTPClient.h>
    #include <DHT.h>
    #include <ArduinoJson.h>

    const char* ssid = "YourWiFiSSID";
    const char* password = "YourWiFiPassword";

    const char* influxdbHost = "YourInfluxDBHost"; // 例: "192.168.1.100"
    const int influxdbPort = 8086;
    const char* influxdbDatabase = "esp32_data";

    #define DHTPIN 2     // デジタルピン2に接続
    #define DHTTYPE DHT11   // DHT 11

    DHT dht(DHTPIN, DHTTYPE);

    void setup() {
      Serial.begin(115200);
      dht.begin();

      WiFi.begin(ssid, password);
      while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
      }
      Serial.println("");
      Serial.println("WiFi connected");
    }

    void loop() {
      delay(2000);

      float h = dht.readHumidity();
      float t = dht.readTemperature();

      if (isnan(h) || isnan(t)) {
        Serial.println(F("Failed to read from DHT sensor!"));
        return;
      }

      String influxData = "temperature,sensor=dht11 value=" + String(t) + "\n" +
                          "humidity,sensor=dht11 value=" + String(h);

      if (WiFi.status() == WL_CONNECTED) {
        HTTPClient http;

        String influxURL = "http://" + String(influxdbHost) + ":" + String(influxdbPort) + "/write?db=" + String(influxdbDatabase);

        http.begin(influxURL);
        http.addHeader("Content-Type", "application/x-www-form-urlencoded");

        int httpResponseCode = http.POST(influxData);

        if (httpResponseCode > 0) {
          Serial.print("HTTP Response code: ");
          Serial.println(httpResponseCode);
        } else {
          Serial.print("Error code: ");
          Serial.println(httpResponseCode);
        }

        http.end();
      } else {
        Serial.println("WiFi Disconnected");
      }
    }
    ```

    **コード解説:**

    *   DHT11センサーから温度と湿度を読み取ります。
    *   InfluxDBのLine Protocol形式でデータを作成します。
    *   HTTPClientライブラリを使用して、InfluxDBにデータをPOSTします。
    *   `influxdbHost`, `influxdbPort`, `influxdbDatabase` は、InfluxDBの設定に合わせて変更してください。

3.  **Grafanaの設定:** GrafanaにInfluxDBデータソースを追加します。

    *   GrafanaのWebインターフェースにアクセスします。
    *   "Configuration" -> "Data Sources" を選択します。
    *   "Add data source" をクリックします。
    *   InfluxDBを選択し、InfluxDBのURL、データベース名、ユーザー名、パスワードを入力します。
    *   "Save & Test" をクリックして、接続を確認します。

4.  **ダッシュボードの作成:** Grafanaで新しいダッシュボードを作成し、温度と湿度のグラフを追加します。

    *   "Create" -> "Dashboard" を選択します。
    *   "Add new panel" をクリックします。
    *   データソースとしてInfluxDBを選択します。
    *   クエリエディタで、温度と湿度のデータを取得するクエリを入力します。
    *   グラフの種類（例：Time series）を選択し、軸の設定を行います。
    *   パネルの設定を保存します。

#### 5.2.5 実践的なテクニック

*   **アラートの設定:** Grafanaで、温度や湿度が閾値を超えた場合にアラートを発するように設定できます。
*   **データのフィルタリング:** Grafanaのクエリエディタを使用して、特定のセンサーや時間範囲のデータを表示できます。
*   **ダッシュボードの共有:** Grafanaのダッシュボードを他のユーザーと共有したり、埋め込み可能なリンクを生成したりできます。

#### 5.2.6 応用例とユースケース

*   **農業:** 温湿度、土壌水分量、日照時間などのデータを可視化し、作物の生育状況を監視する。
*   **工場:** 設備の温度、振動、電力消費量などのデータを可視化し、設備の異常を検知する。
*   **スマートシティ:** 交通量、大気汚染、エネルギー消費量などのデータを可視化し、都市の状況を監視する。

#### 5.2.7 トラブルシューティング

*   **GrafanaがInfluxDBに接続できない:** InfluxDBのURL、データベース名、ユーザー名、パスワードが正しいか確認してください。InfluxDBサーバーが起動しているか確認してください。
*   **グラフにデータが表示されない:** InfluxDBにデータが正しく書き込まれているか確認してください。Grafanaのクエリが正しいか確認してください。
*   **アラートが発動しない:** アラートの条件が正しく設定されているか確認してください。

#### 5.2.8 まとめと次のステップ

### 5.3 Node-REDによるデータフロー構築と可視化

#### 5.3.1 概要と重要性

Node-REDは、ビジュアルプログラミングツールであり、ノードと呼ばれるブロックを接続することで、様々なデータフローを簡単に構築することができます。IoTデバイスからのデータ処理、APIとの連携、データベースへの書き込み、そしてダッシュボードの作成など、幅広い用途に利用できます。Node-REDを使用することで、複雑な処理をコーディングなしで実現し、開発時間を大幅に短縮することができます。

#### 5.3.2 特徴と利点

*   **直感的な操作:** ドラッグ＆ドロップでノードを接続するだけで、データフローを構築できます。
*   **豊富なノード:** 様々な種類のノードが用意されており、様々なデータソースとの連携やデータ処理が可能です。
*   **容易な拡張性:** 独自のノードを開発して、Node-REDの機能を拡張することができます。
*   **Webベースのインターフェース:** Webブラウザ上で動作するため、どこからでもアクセスできます。

#### 5.3.3 事前準備と前提条件

*   Node-REDのインストールと設定 (公式ドキュメントを参照)
*   ESP32がNode-REDにデータを送信できる環境

#### 5.3.4 基本的な使い方

1.  **Node-REDの起動:** WebブラウザでNode-REDのインターフェースにアクセスします。通常は、`http://localhost:1880` でアクセスできます。

2.  **フローの作成:** 空のフローを作成し、必要なノードを配置します。

3.  **ノードの接続:** ノードをドラッグ＆ドロップで配置し、接続線で繋ぎます。

4.  **ノードの設定:** ノードをダブルクリックして、設定を行います。

5.  **フローのデプロイ:** "Deploy"ボタンをクリックして、フローを実行します。

以下の例は、ESP32から送信されたデータをNode-REDで受信し、デバッグコンソールに出力するシンプルなフローです。

*   **Inputノード:** `http`ノードを使用し、ESP32からのPOSTリクエストを受信します。`URL` に `/data` を設定し、`Method` に `POST` を設定します。

*   **Outputノード:** `debug`ノードを使用し、受信したデータをデバッグコンソールに出力します。

```json
[
  {
    "id": "a1b2c3d4e5f6g7h8",
    "type": "http in",
    "z": "YOUR_FLOW_ID",
    "name": "Receive Data",
```

**ESP32コード (例):**

```cpp
#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>

const char* ssid = "YourWiFiSSID";
const char* password = "YourWiFiPassword";

const char* nodeRedHost = "YourNodeRedHost"; // 例: "192.168.1.100"
const int nodeRedPort = 1880;

void setup() {
  Serial.begin(115200);

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("");
  Serial.println("WiFi connected");
}

void loop() {
  delay(2000);

  // センサーデータ (ダミーデータ)
  float temperature = random(20, 30);
  float humidity = random(50, 70);

  // JSONデータの作成
  StaticJsonDocument<200> doc;
  doc["temperature"] = temperature;
  doc["humidity"] = humidity;

  String jsonData;
  serializeJson(doc, jsonData);

  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;

    String nodeRedURL = "http://" + String(nodeRedHost) + ":" + String(nodeRedPort) + "/data";

    http.begin(nodeRedURL);
    http.addHeader("Content-Type", "application/json");

    int httpResponseCode = http.POST(jsonData);

    if (httpResponseCode > 0) {
      Serial.print("HTTP Response code: ");
      Serial.println(httpResponseCode);
    } else {
      Serial.print("Error code: ");
      Serial.println(httpResponseCode);
    }

    http.end();
  } else {
    Serial.println("WiFi Disconnected");
  }
}
```

**解説:**

*   ESP32は、JSON形式で温度と湿度のデータをNode-REDにPOSTします。
*   Node-REDの`http in`ノードは、`/data` エンドポイントでPOSTリクエストをリッスンします。
*   受信したデータは、`debug`ノードによってデバッグコンソールに出力されます。

#### 5.3.5 実践的なテクニック

*   **データの変換:** `function`ノードを使用して、データの形式を変換したり、計算を実行したりできます。
*   **データベースへの書き込み:** `influxdb`ノードを使用して、InfluxDBにデータを書き込むことができます。
*   **ダッシュボードの作成:** `node-red-dashboard`ノードを使用して、Webベースのダッシュボードを作成できます。

#### 5.3.6 応用例とユースケース

*   **スマート農業:** センサーデータを収集し、自動で灌漑システムを制御する。
*   **スマートホーム:** 照明、エアコン、セキュリティシステムなどを統合的に制御する。
*   **産業IoT:** 設備の稼働状況を監視し、故障を予測する。

#### 5.3.7 トラブルシューティング

*   **フローが動作しない:** ノードの設定が正しいか確認してください。ノード間の接続が正しく行われているか確認してください。
*   **データが正しく処理されない:** `function`ノードのコードにエラーがないか確認してください。
*   **ダッシュボードが表示されない:** `node-red-dashboard`ノードが正しく設定されているか確認してください。

本章で解説したWebサーバー構築、GrafanaとInfluxDBの連携、そしてNode-REDによるデータフロー構築と可視化は、IoTプロジェクトにおけるデータ可視化の基盤となります。これらの技術を習得することで、センサーデータを最大限に活用し、よりスマートなシステムを構築することが可能になります。
