## 第11章 dAppフロントエンド開発の基礎

dApp（分散型アプリケーション）のフロントエンドは、ユーザーがブロックチェーンとインタラクトするための窓口です。洗練されたUI/UXを提供することで、dAppの普及に大きく貢献できます。本章では、dAppフロントエンド開発の基礎となるWeb3.js、Ethers.js、React、Next.jsといった主要な技術について、実践的なコード例を交えながら詳しく解説します。

### 11.1 Web3.jsとEthers.js

#### 11.1.1 Web3.jsとEthers.jsの比較

**概要と重要性**

Web3.jsとEthers.jsは、JavaScriptからEthereumブロックチェーンと通信するための最も一般的なライブラリです。スマートコントラクトの呼び出し、トランザクションの送信、イベントの監視など、dApp開発に必要な機能を網羅しています。どちらのライブラリもdApp開発において中心的な役割を担っており、使いこなせるようになることが不可欠です。

**特徴と利点**

| 特徴          | Web3.js                                    | Ethers.js                                     |
|---------------|---------------------------------------------|----------------------------------------------|
| サイズ        | 大きい                                      | 比較的小さい                                  |
| 依存関係      | 大きく、より多くの外部ライブラリに依存          | 比較的少ない                                  |
| TypeScriptサポート | 比較的弱い（型定義が不完全な場合がある）          | 強力（TypeScriptフレンドリー）                 |
| ウォレット管理 | 抽象度が低い、複雑なウォレット統合が必要な場合がある | シンプルで安全なウォレット管理機能が組み込み済み |
| コミュニティ     | 大きい                                      | 活発で成長中                                  |

**Web3.js** は、歴史が長く、最も広く使われているライブラリです。豊富なドキュメントとコミュニティサポートが強みですが、コードサイズが大きく、TypeScriptのサポートが不十分な点がデメリットとして挙げられます。

**Ethers.js** は、比較的新しいライブラリであり、軽量で使いやすく、TypeScriptとの親和性が高いことが特徴です。セキュリティにも配慮されており、ウォレット管理機能が組み込まれているため、より安全なdApp開発が可能です。

**どちらを選ぶべきか？**

新規プロジェクトであれば、TypeScriptのサポートが充実しており、軽量でモダンなEthers.jsがおすすめです。既存のWeb3.jsプロジェクトを引き継ぐ場合や、Web3.jsの豊富なドキュメントやコミュニティサポートが必要な場合は、Web3.jsを選択すると良いでしょう。

#### 11.1.2 アカウントへの接続

**事前準備と前提条件**

*   MetaMaskなどのEthereumウォレットがインストールされ、設定済みであること
*   Node.jsとnpm (または yarn) がインストールされていること

**基本的な使い方**

まずは、プロジェクトにライブラリをインストールします。

```bash
# Ethers.js の場合
npm install ethers

# Web3.js の場合
npm install web3
```

次に、JavaScriptコードでライブラリをインポートし、MetaMaskなどのウォレットに接続します。

**Ethers.js の場合:**

```javascript
import { ethers } from 'ethers';

async function connectWallet() {
  // MetaMaskが利用可能か確認
  if (typeof window.ethereum !== 'undefined') {
    try {
      // MetaMaskに接続
      await window.ethereum.request({ method: 'eth_requestAccounts' });

      // プロバイダを取得
      const provider = new ethers.providers.Web3Provider(window.ethereum);

      // サインナーを取得 (署名を行うアカウント)
      const signer = provider.getSigner();

      // アカウントのアドレスを取得
      const address = await signer.getAddress();
      console.log("接続されたアカウント:", address);

      return { provider, signer, address };

    } catch (error) {
      console.error("接続エラー:", error);
    }
  } else {
    console.log("MetaMaskがインストールされていません");
  }
}

connectWallet();
```

**Web3.js の場合:**

```javascript
import Web3 from 'web3';

async function connectWallet() {
  // MetaMaskが利用可能か確認
  if (typeof window.ethereum !== 'undefined') {
    try {
      // MetaMaskに接続
      await window.ethereum.request({ method: 'eth_requestAccounts' });

      // Web3インスタンスを作成
      const web3 = new Web3(window.ethereum);

      // アカウントのアドレスを取得
      const accounts = await web3.eth.getAccounts();
      const address = accounts[0];
      console.log("接続されたアカウント:", address);

      return { web3, address };

    } catch (error) {
      console.error("接続エラー:", error);
    }
  } else {
    console.log("MetaMaskがインストールされていません");
  }
}

connectWallet();
```

**実践的なテクニック**

*   **エラーハンドリング:** 接続に失敗した場合の処理を適切に行う。
*   **ネットワークの切り替え:** MetaMaskが接続されているネットワークをチェックし、必要なネットワークに切り替えるように促す。
*   **アカウントの変更:** 接続されているアカウントが変更された場合に、適切に処理を行う。`window.ethereum.on('accountsChanged', (accounts) => { /* アカウント変更時の処理 */ });`

**トラブルシューティング**

*   **MetaMaskが認識されない:** MetaMaskがインストールされているか、ブラウザの設定で有効になっているかを確認する。
*   **接続が拒否される:** MetaMaskでdAppへのアクセス許可を与えているかを確認する。
*   **ネットワークエラー:** MetaMaskが正しいネットワークに接続されているかを確認する。

#### 11.1.3 コントラクトの呼び出し

**概要と重要性**

dAppの中核となる機能は、スマートコントラクトとのインタラクションです。Web3.jsまたはEthers.jsを使用して、コントラクトの関数を呼び出し、データを読み書きすることで、dAppはブロックチェーン上で動作するロジックを実行できます。

**事前準備と前提条件**

*   コントラクトのABI (Application Binary Interface) とアドレスが必要です。
*   接続済みのEthereumアカウントが必要です。

**基本的な使い方**

コントラクトのABIとアドレスを使って、コントラクトのインスタンスを作成します。

**Ethers.js の場合:**

```javascript
import { ethers } from 'ethers';

// コントラクトのアドレスとABI
const contractAddress = "0x..."; // コントラクトのアドレス
const contractABI = [...]; // コントラクトのABI

async function interactWithContract(signer) {
  // コントラクトのインスタンスを作成
  const contract = new ethers.Contract(contractAddress, contractABI, signer);

  try {
    // コントラクトの関数を呼び出す (読み取り専用)
    const value = await contract.myReadOnlyFunction();
    console.log("読み取り専用関数の値:", value);

    // コントラクトの関数を呼び出す (書き込み)
    const transaction = await contract.myWriteFunction("データ");
    await transaction.wait(); // トランザクションが完了するまで待機
    console.log("書き込みトランザクションが完了しました");

  } catch (error) {
    console.error("コントラクトの呼び出しエラー:", error);
  }
}

// (connectWallet() で取得した) signer を渡す
async function main() {
  const { signer } = await connectWallet();
  await interactWithContract(signer);
}

main();
```

**Web3.js の場合:**

```javascript
import Web3 from 'web3';

// コントラクトのアドレスとABI
const contractAddress = "0x..."; // コントラクトのアドレス
const contractABI = [...]; // コントラクトのABI

async function interactWithContract(web3, address) {
  // コントラクトのインスタンスを作成
  const contract = new web3.eth.Contract(contractABI, contractAddress);

  try {
    // コントラクトの関数を呼び出す (読み取り専用)
    const value = await contract.methods.myReadOnlyFunction().call();
    console.log("読み取り専用関数の値:", value);

    // コントラクトの関数を呼び出す (書き込み)
    const transaction = await contract.methods.myWriteFunction("データ").send({ from: address });
    console.log("書き込みトランザクションが完了しました", transaction);

  } catch (error) {
    console.error("コントラクトの呼び出しエラー:", error);
  }
}

// (connectWallet() で取得した) web3 と address を渡す
async function main() {
  const { web3, address } = await connectWallet();
  await interactWithContract(web3, address);
}

main();
```

**実践的なテクニック**

*   **ガス料金の見積もり:** トランザクション送信前にガス料金を見積もり、ユーザーに適切なガス料金を設定するように促す。
*   **トランザクションの確認:** トランザクションがブロックチェーンに正常に取り込まれたことを確認する。
*   **関数のオーバーロード:** 同じ名前で異なる引数を持つ関数を呼び出す場合は、ABIで関数を特定する。

**応用例とユースケース**

*   **トークンの転送:** ERC-20トークンの`transfer`関数を呼び出し、トークンを別のアドレスに転送する。
*   **NFTのミント:** ERC-721トークンの`mint`関数を呼び出し、新しいNFTを生成する。
*   **DeFiプロトコルとの連携:** DeFiプロトコルのスマートコントラクトと連携し、トークンの貸し借りや交換を行う。

**トラブルシューティング**

*   **トランザクションが失敗する:** ガス料金が不足している、コントラクトにエラーがある、アカウントに十分な残高がないなどの原因が考えられます。
*   **コントラクトが見つからない:** コントラクトのアドレスが正しいか、ネットワークが正しいかを確認する。
*   **ABIのエラー:** ABIがコントラクトのコードと一致しているかを確認する。

#### 11.1.4 イベントの監視

**概要と重要性**

スマートコントラクトから発行されるイベントを監視することで、dAppはブロックチェーンの状態変化にリアルタイムで対応できます。イベントは、トランザクションの成功、データの更新、エラーの発生など、様々な情報をdAppに通知するために使用されます。

**事前準備と前提条件**

*   コントラクトのABIが必要です。
*   接続済みのEthereumアカウントが必要です。

**基本的な使い方**

コントラクトのインスタンスを作成し、`on`メソッドを使ってイベントを監視します。

**Ethers.js の場合:**

```javascript
import { ethers } from 'ethers';

// コントラクトのアドレスとABI
const contractAddress = "0x..."; // コントラクトのアドレス
const contractABI = [...]; // コントラクトのABI

async function listenForEvents(signer) {
  // コントラクトのインスタンスを作成
  const contract = new ethers.Contract(contractAddress, contractABI, signer);

  // イベントを監視
  contract.on("MyEvent", (arg1, arg2, event) => {
    console.log("MyEventが発生しました:", arg1, arg2, event);
  });
}

// (connectWallet() で取得した) signer を渡す
async function main() {
  const { signer } = await connectWallet();
  await listenForEvents(signer);
}

main();
```

**Web3.js の場合:**

```javascript
import Web3 from 'web3';

// コントラクトのアドレスとABI
const contractAddress = "0x..."; // コントラクトのアドレス
const contractABI = [...]; // コントラクトのABI

async function listenForEvents(web3) {
  // コントラクトのインスタンスを作成
  const contract = new web3.eth.Contract(contractABI, contractAddress);

  // イベントを監視
  contract.events.MyEvent({
    fromBlock: 'latest' // 最新のブロックから監視
  })
  .on('data', (event) => {
    console.log("MyEventが発生しました:", event);
  })
  .on('error', console.error);
}

// (connectWallet() で取得した) web3 を渡す
async function main() {
  const { web3 } = await connectWallet();
  await listenForEvents(web3);
}

main();
```

**実践的なテクニック**

*   **イベントフィルタリング:** 特定の条件を満たすイベントのみを監視する。
*   **過去のイベント:** ブロックチェーン上に記録された過去のイベントを取得する。
*   **イベントハンドリング:** イベントが発生した際に、dAppの状態を更新する。

**応用例とユースケース**

*   **リアルタイム通知:** トランザクションの成功をユーザーに通知する。
*   **データ同期:** ブロックチェーン上のデータが更新された際に、dAppのデータを同期する。
*   **ゲーム開発:** ゲームの状態変化をイベントとして監視し、ゲームロジックを実行する。

**トラブルシューティング**

*   **イベントが発生しない:** コントラクトがイベントを発行しているか、イベント名が正しいかを確認する。
*   **イベントデータが不正:** イベントのABIが正しいかを確認する。
*   **ネットワークエラー:** ネットワーク接続が安定しているかを確認する。

**まとめと次のステップ**

Web3.jsとEthers.jsは、dAppフロントエンド開発において必要不可欠なライブラリです。アカウントへの接続、コントラクトの呼び出し、イベントの監視といった基本的な操作をマスターすることで、dApp開発の幅が大きく広がります。次のステップでは、ReactやNext.jsといったフレームワークとこれらのライブラリを組み合わせ、より高度なdAppフロントエンドを構築する方法について学びます。

### 11.2 ReactとNext.js

#### 11.2.1 ReactとNext.jsの概要

**概要と重要性**

Reactは、ユーザーインターフェースを構築するためのJavaScriptライブラリであり、Next.jsは、Reactをベースにしたフレームワークです。どちらもコンポーネントベースのアーキテクチャを採用しており、UIの再利用性と保守性を高めることができます。dAppフロントエンド開発では、ReactまたはNext.jsを使用することで、効率的かつ高品質なUIを構築できます。

**特徴と利点**

| 特徴          | React                                       | Next.js                                        |
|---------------|---------------------------------------------|----------------------------------------------|
| タイプ        | JavaScriptライブラリ                            | Reactフレームワーク                               |
| 主な用途      | UIの構築                                     | フルスタックWebアプリケーションの開発                       |
| レンダリング    | クライアントサイドレンダリング (CSR) が基本      | サーバーサイドレンダリング (SSR) と静的サイト生成 (SSG) をサポート |
| ルーティング     | 独自のルーティング設定が必要                       | ファイルシステムベースのルーティング                     |
| SEO対策        | CSRのため、対策が必要                           | SSRによりSEOに強い                                 |
| パフォーマンス | 初期表示速度が遅い場合がある                       | 最適化されたパフォーマンス                               |

**React** は、柔軟性が高く、自由度の高いUIを構築できます。豊富なライブラリやツールが利用可能であり、大規模なアプリケーション開発にも適しています。

**Next.js** は、Reactの機能を拡張し、サーバーサイドレンダリング (SSR) や静的サイト生成 (SSG) をサポートしています。SEO対策やパフォーマンスの最適化が容易であり、より優れたユーザーエクスペリエンスを提供できます。

**どちらを選ぶべきか？**

SEO対策が重要となるWebサイトや、初期表示速度を重視する場合は、Next.jsがおすすめです。UIの自由度を高く保ちたい場合や、既存のReactプロジェクトにdApp機能を組み込む場合は、Reactを選択すると良いでしょう。

#### 11.2.2 dAppフロントエンドの構築

**事前準備と前提条件**

*   Node.jsとnpm (または yarn) がインストールされていること
*   ReactまたはNext.jsの基本的な知識があること

**基本的な使い方**

まずは、プロジェクトを作成します。

**Reactの場合:**

```bash
npx create-react-app my-dapp
cd my-dapp
npm install ethers
```

**Next.jsの場合:**

```bash
npx create-next-app my-dapp
cd my-dapp
npm install ethers
```

次に、コンポーネントを作成し、Web3.jsまたはEthers.jsを使ってスマートコントラクトと連携します。

**Reactの例:**

```jsx
import React, { useState, useEffect } from 'react';
import { ethers } from 'ethers';

const contractAddress = "0x..."; // コントラクトのアドレス
const contractABI = [...]; // コントラクトのABI

function App() {
  const [account, setAccount] = useState(null);
  const [contract, setContract] = useState(null);
  const [data, setData] = useState(null);

  useEffect(() => {
    async function connectWallet() {
      if (typeof window.ethereum !== 'undefined') {
        const provider = new ethers.providers.Web3Provider(window.ethereum);
        const signer = provider.getSigner();
        const address = await signer.getAddress();
        setAccount(address);

        const contractInstance = new ethers.Contract(contractAddress, contractABI, signer);
        setContract(contractInstance);
      }
    }

    connectWallet();
  }, []);

  useEffect(() => {
    async function fetchData() {
      if (contract) {
        const value = await contract.myReadOnlyFunction();
        setData(value);
      }
    }

    fetchData();
  }, [contract]);

  return (
    <div>
      <h1>dApp Example</h1>
      {account ? (
        <p>Connected Account: {account}</p>
      ) : (
        <button onClick={async () => {
          await window.ethereum.request({ method: 'eth_requestAccounts' });
        }}>Connect Wallet</button>
      )}
      {data && <p>Data from Contract: {data.toString()}</p>}
    </div>
  );
}

export default App;
```

**実践的なテクニック**

*   **コンポーネントの分割:** UIを再利用可能なコンポーネントに分割し、コードの可読性と保守性を高める。
*   **状態管理:** React Context APIやReduxなどの状態管理ライブラリを使用し、アプリケーション全体の状態を効率的に管理する。
*   **UIライブラリ:** Material UIやAnt DesignなどのUIライブラリを使用し、洗練されたUIを迅速に構築する。

**応用例とユースケース**

*   **ソーシャルメディア:** ブロックチェーン上に投稿を記録するソーシャルメディアプラットフォームを構築する。

*   **レンダリングエラー:** コンポーネントのpropsやstateが正しく設定されているかを確認する。

*   **Web3.js/Ethers.jsのエラー:** ライブラリのバージョンが最新であるか、コントラクトとの接続が確立されているかを確認する。

#### 11.2.3 Metamaskとの連携

**概要と重要性**

MetaMaskは、ブラウザ上で動作するEthereumウォレットであり、dAppとユーザーを繋ぐ重要な役割を担っています。ReactやNext.jsで構築されたdAppフロントエンドは、MetaMaskと連携することで、ユーザーは安全にトランザクションを署名し、ブロックチェーンとインタラクトすることができます。

**事前準備と前提条件**

*   MetaMaskがインストールされ、設定済みであること

**基本的な使い方**

MetaMaskに接続し、アカウント情報を取得します。

```javascript
import { ethers } from 'ethers';

async function connectWallet() {
  if (typeof window.ethereum !== 'undefined') {
    try {
      // MetaMaskに接続
      await window.ethereum.request({ method: 'eth_requestAccounts' });

      // プロバイダを取得
      const provider = new ethers.providers.Web3Provider(window.ethereum);

      // サインナーを取得 (署名を行うアカウント)
      const signer = provider.getSigner();

      // アカウントのアドレスを取得
      const address = await signer.getAddress();
      console.log("接続されたアカウント:", address);

      return { provider, signer, address };

    } catch (error) {
      console.error("接続エラー:", error);
    }
  } else {
    console.log("MetaMaskがインストールされていません");
  }
}
```

**実践的なテクニック**

*   **ネットワークの切り替え:** MetaMaskが接続されているネットワークをチェックし、必要なネットワークに切り替えるように促す。
*   **アカウントの変更:** 接続されているアカウントが変更された場合に、適切に処理を行う。
*   **トランザクションの署名:** MetaMaskを使用して、トランザクションに署名し、ブロックチェーンに送信する。

**応用例とユースケース**

*   **トークンの転送:** MetaMaskを使用して、ERC-20トークンを別のアドレスに転送する。
*   **NFTの購入:** MetaMaskを使用して、NFTを購入する。
*   **DeFiプロトコルとの連携:** MetaMaskを使用して、DeFiプロトコルと連携し、トークンの貸し借りや交換を行う。

**トラブルシューティング**

*   **MetaMaskが認識されない:** MetaMaskがインストールされているか、ブラウザの設定で有効になっているかを確認する。
*   **接続が拒否される:** MetaMaskでdAppへのアクセス許可を与えているかを確認する。
*   **トランザクションが拒否される:** ガス料金が不足している、アカウントに十分な残高がないなどの原因が考えられます。
