## 10. Stream Deckプラグイン開発 - 独自の機能を拡張する

### 10.1 Stream Deckプラグイン開発の基礎

**概要と重要性**

Stream Deckは、ゲーム実況者やコンテンツクリエイターを中心に、様々なタスクを効率化するための強力なツールとして普及しています。その魅力の一つは、プラグインによる機能拡張性です。プラグインを開発することで、Stream Deckを自分のワークフローに完全に統合し、日々の作業を劇的に改善することができます。このセクションでは、Stream Deckプラグイン開発の基礎となる概念と、なぜプラグイン開発が重要なのかを解説します。

**特徴と利点**

Stream Deckプラグイン開発には、以下のような特徴と利点があります。

*   **自由な機能拡張:** 標準機能では実現できない独自の機能をStream Deckに追加できます。
*   **ワークフローの効率化:** 繰り返し行うタスクをワンタッチで実行できるようになり、作業時間を大幅に短縮できます。
*   **コミュニティへの貢献:** 作成したプラグインを公開することで、他のStream Deckユーザーのワークフロー改善に貢献できます。
*   **プログラミングスキルの向上:** プラグイン開発を通じて、Web技術（HTML, CSS, JavaScript）やJSONなどの知識を実践的に学ぶことができます。

**事前準備と前提条件**

Stream Deckプラグイン開発を始める前に、以下の準備が必要です。

*   **Stream Deck本体:** 当然ながら、Stream Deck本体が必要です。
*   **Stream Deckソフトウェア:** 最新版のStream Deckソフトウェアをインストールしておきましょう。
*   **開発環境:** テキストエディタ（VS Code, Sublime Textなど）とWebブラウザ（Chrome, Firefoxなど）を用意します。
*   **プログラミングの基礎知識:** HTML, CSS, JavaScriptの基本的な知識があると、よりスムーズに開発を進められます。JSONの知識もあると便利です。

**基本的な使い方**

Stream Deckプラグインは、基本的にはHTML, CSS, JavaScriptで構成されるWebアプリケーションです。Stream Deckソフトウェアは、プラグインを起動すると、内蔵のブラウザエンジンでWebアプリケーションを表示し、Stream Deckのボタン操作に応じてJavaScriptの関数を実行します。

プラグインは以下のファイルで構成されます。

*   **manifest.json:** プラグインの設定ファイル。プラグインの名前、説明、アイコン、使用するアクションなどの情報を記述します。
*   **アクションのHTMLファイル:** 各アクション（ボタンに割り当てる機能）のUIを定義するHTMLファイル。
*   **JavaScriptファイル:** アクションのロジックを記述するJavaScriptファイル。

**実践的なテクニック**

*   **Stream Deck SDK:** Stream Deck SDKは、プラグイン開発を支援するJavaScriptライブラリです。これを利用することで、Stream Deckソフトウェアとの通信や、設定UIの作成などを簡単に行うことができます。SDKはElgatoのデベロッパーサイトからダウンロードできます。
*   **Debugging:** Chrome DevToolsなどのブラウザの開発ツールを使って、JavaScriptのデバッグを行うことができます。Stream Deckソフトウェアの設定で「Developer」オプションを有効にすると、プラグインのWebページをDevToolsで検査できます。
*   **JSON Schema:** `manifest.json`の形式を定義するために、JSON Schemaを利用することができます。これによって、設定ファイルの記述ミスを防ぎ、より堅牢なプラグインを開発できます。

**応用例とユースケース**

*   **OBS Studio制御プラグイン:** OBS Studioのシーン切り替え、ソースの表示/非表示、録画開始/停止などをStream Deckから制御できます。
*   **Twitter投稿プラグイン:** Stream Deckから直接Twitterに投稿できます。
*   **スマートホーム制御プラグイン:** Philips HueなどのスマートホームデバイスをStream Deckから制御できます。
*   **カスタムタイマープラグイン:** ストリーミングやポッドキャストで役立つ、カスタマイズ可能なタイマーを表示できます。

**トラブルシューティング**

*   **プラグインが認識されない:** `manifest.json`の形式に誤りがないか確認してください。
*   **プラグインが起動しない:** JavaScriptのエラーがないか、ブラウザの開発ツールで確認してください。
*   **Stream Deck SDKのメソッドが動作しない:** SDKのバージョンが最新であるか確認し、ドキュメントをよく読んでください。

**まとめと次のステップ**

このセクションでは、Stream Deckプラグイン開発の基礎を学びました。次のセクションでは、実際にプラグイン開発環境を構築し、簡単なプラグインを作成してみましょう。

### 10.2 プラグイン開発環境の構築

**概要と重要性**

プラグイン開発をスムーズに進めるためには、適切な開発環境の構築が不可欠です。このセクションでは、Stream Deckプラグイン開発に必要なツールをインストールし、開発環境をセットアップする手順を解説します。

**特徴と利点**

*   **効率的な開発:** 適切なツールを使うことで、コードの記述、デバッグ、テストを効率的に行うことができます。
*   **品質の向上:** コーディング規約やリンターを導入することで、コードの品質を向上させることができます。
*   **再現性の確保:** 開発環境を構築することで、チームメンバー間で同じ環境を共有し、再現性を確保できます。

**事前準備と前提条件**

*   **Visual Studio Code (VS Code)などのテキストエディタ:** コードの記述、編集、デバッグに使用します。
*   **Node.jsとnpm (Node Package Manager):** JavaScriptの実行環境とパッケージ管理ツールです。Stream Deck SDKのインストールや、ビルドツールなどの利用に必要です。
*   **Git:** バージョン管理システムです。プラグインのソースコードを管理し、変更履歴を追跡するために使用します。

**基本的な使い方**

1.  **Node.jsとnpmのインストール:** Node.jsの公式サイトから、最新版のNode.jsをダウンロードしてインストールします。npmはNode.jsと一緒にインストールされます。

    ```bash
    node -v
    npm -v
    ```

    上記のコマンドでバージョンが表示されれば、正しくインストールされています。

2.  **Visual Studio Code (VS Code)のインストール:** VS Codeの公式サイトから、VS Codeをダウンロードしてインストールします。

3.  **Stream Deck SDKのインストール:** npmを使ってStream Deck SDKをインストールします。ターミナルを開き、以下のコマンドを実行します。

    ```bash
    npm install --save-dev @elgato/streamdeck
    ```

    このコマンドを実行すると、`node_modules`ディレクトリにStream Deck SDKがインストールされます。

4.  **VS Codeの拡張機能のインストール:** VS Codeには、プラグイン開発を支援する様々な拡張機能があります。以下のような拡張機能をインストールすると便利です。

    *   **ESLint:** JavaScriptのコードの品質をチェックするリンターです。
    *   **Prettier:** コードを自動的に整形するフォーマッターです。
    *   **JSON Tools:** JSONファイルの編集を支援するツールです。

5.  **プロジェクトの作成:** プラグインのプロジェクトディレクトリを作成し、必要なファイルを配置します。

    ```
    my-streamdeck-plugin/
    ├── manifest.json
    ├── index.html
    ├── index.js
    └── styles.css
    ```

**実践的なテクニック**

*   **package.jsonの作成:** `package.json`ファイルを作成することで、プロジェクトの依存関係を管理し、ビルドスクリプトなどを定義することができます。

    ```bash
    npm init -y
    ```

    このコマンドを実行すると、`package.json`ファイルが作成されます。

*   **ビルドスクリプトの定義:** `package.json`ファイルにビルドスクリプトを定義することで、JavaScriptのコードをminifyしたり、CSSファイルを結合したりすることができます。

    ```json
    {
      "scripts": {
        "build": "webpack"
      },
      "devDependencies": {
        "webpack": "^5.0.0",
        "webpack-cli": "^4.0.0"
      }
    }
    ```

    上記の例では、webpackを使ってJavaScriptのコードをビルドするスクリプトを定義しています。

*   **デバッグ環境の構築:** VS Codeのデバッグ機能を使って、Stream Deckプラグインをデバッグすることができます。`launch.json`ファイルを作成し、デバッグ設定を記述します。

**応用例とユースケース**

*   **CI/CDパイプラインの構築:** GitHub ActionsなどのCI/CDツールを使って、プラグインのビルド、テスト、デプロイを自動化することができます。
*   **Dockerコンテナの利用:** Dockerコンテナを使って、開発環境をコンテナ化することで、環境依存の問題を解決し、再現性を高めることができます。

**トラブルシューティング**

*   **npmコマンドが動作しない:** Node.jsとnpmが正しくインストールされているか確認してください。環境変数が正しく設定されているか確認してください。
*   **VS Codeの拡張機能が動作しない:** VS Codeを再起動してみてください。拡張機能が最新版であるか確認してください。
*   **Stream Deck SDKのインストールに失敗する:** インターネット接続を確認してください。npmのキャッシュをクリアしてみてください。

**まとめと次のステップ**

このセクションでは、Stream Deckプラグイン開発に必要な環境構築の手順を学びました。次のセクションでは、実際に簡単なプラグインを作成し、Stream Deckで動作させてみましょう。

### 10.3 簡単なプラグインを作成してみよう

**概要と重要性**

このセクションでは、実際に簡単なStream Deckプラグインを作成し、動作させることで、プラグイン開発の基本的な流れを理解します。具体的なコード例を参考にしながら、プラグインの構造や、Stream Deckとの連携方法を学びましょう。

**特徴と利点**

*   **実践的な学習:** 実際に手を動かすことで、プラグイン開発の理解を深めることができます。
*   **問題解決能力の向上:** エラーが発生した場合、原因を特定し、解決する能力を養うことができます。
*   **自信の獲得:** 自分で作成したプラグインがStream Deckで動作するのを見ることで、達成感を得ることができます。

**事前準備と前提条件**

*   **10.2で構築した開発環境:** 開発環境が正しく構築されている必要があります。
*   **Stream Deck本体とソフトウェア:** Stream Deck本体がPCに接続され、ソフトウェアがインストールされている必要があります。

**基本的な使い方**

ここでは、ボタンを押すと指定されたテキストをコンソールに出力するだけのシンプルなプラグインを作成します。

1.  **プロジェクトディレクトリの作成:** 新しいディレクトリを作成し、その中に以下のファイルを作成します。

    ```
    simple-plugin/
    ├── manifest.json
    ├── index.html
    └── index.js
    ```

2.  **manifest.jsonの記述:** `manifest.json`ファイルに、プラグインの情報を記述します。

    ```json
    {
      "SDKVersion": 2,
      "Author": "Your Name",
      "Name": "Simple Plugin",
      "Description": "A simple plugin that logs text to the console.",
      "Version": "1.0",
      "Icon": "icon",
      "URL": "https://example.com",
      "CodePath": "index.html",
      "Actions": [
        {
          "Name": "Log Text",
          "UUID": "com.example.simpleplugin.logtext",
          "Icon": "actionIcon",
          "PropertyInspectorPath": null,
          "Controllers": [
            "Keypad"
          ]
        }
      ]
    }
    ```

    *   `SDKVersion`: 使用するStream Deck SDKのバージョンを指定します。
    *   `Author`: プラグインの作者名を指定します。
    *   `Name`: プラグインの名前を指定します。
    *   `Description`: プラグインの説明を指定します。
    *   `Version`: プラグインのバージョンを指定します。
    *   `Icon`: プラグインのアイコンのファイル名を指定します。
    *   `URL`: プラグインの公式サイトのURLを指定します。
    *   `CodePath`: プラグインのエントリーポイントとなるHTMLファイルのパスを指定します。
    *   `Actions`: プラグインが提供するアクションの情報を記述します。
        *   `Name`: アクションの名前を指定します。
        *   `UUID`: アクションの一意な識別子を指定します。
        *   `Icon`: アクションのアイコンのファイル名を指定します。
        *   `PropertyInspectorPath`: アクションの設定UIのHTMLファイルのパスを指定します。`null`の場合は設定UIがないことを意味します。
        *   `Controllers`: アクションが対応するStream Deckデバイスの種類を指定します。

3.  **index.htmlの記述:** `index.html`ファイルに、アクションのUIと、JavaScriptのコードを記述します。

    ```html
    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="UTF-8">
      <title>Simple Plugin</title>
    </head>
    <body>
      <script src="index.js"></script>
    </body>
    </html>
    ```

4.  **index.jsの記述:** `index.js`ファイルに、アクションのロジックを記述します。Stream Deck SDKを使って、ボタンが押されたときにコンソールにテキストを出力する処理を記述します。

    ```javascript
    $sd.on('keyUp', function(evt) {
      if (evt.action === 'com.example.simpleplugin.logtext') {
        console.log('Button pressed!');
      }
    });
    ```

    ここでは `$sd` はStream Deck SDKのインスタンスを表します。 `on('keyUp', ...)`はキーが離されたタイミングで発火するイベントを登録します。

5.  **アイコンの準備:** `manifest.json`で指定したアイコンファイル(`icon.png`と`actionIcon.png`)をプロジェクトディレクトリに配置します。これらのアイコンは、Stream Deckソフトウェアでプラグインやアクションを表示するために使用されます。適当な画像編集ツールで作成してください。

6.  **プラグインのインストール:** 作成したプラグインのディレクトリをzip形式で圧縮し、拡張子を`.sdPlugin`に変更します。このファイルをダブルクリックすると、Stream Deckソフトウェアが起動し、プラグインがインストールされます。

7.  **Stream Deckソフトウェアでの設定:** Stream Deckソフトウェアを起動し、作成したプラグインのアクションをStream Deckのボタンに割り当てます。ボタンを押すと、コンソールにテキストが出力されることを確認します。

**実践的なテクニック**

*   **Stream Deck SDKの活用:** Stream Deck SDKには、プラグイン開発を支援する様々な機能が用意されています。例えば、`showAlert()`メソッドを使うと、Stream Deckのディスプレイにアラートを表示することができます。
*   **Property Inspectorの作成:** `PropertyInspectorPath`にHTMLファイルを指定することで、アクションの設定UIを作成することができます。設定UIで入力された値をJavaScriptのコードで取得し、アクションの動作をカスタマイズすることができます。
*   **設定データの保存と読み込み:** `setSettings()`メソッドと`getSettings()`メソッドを使うことで、アクションの設定データを保存したり、読み込んだりすることができます。

**応用例とユースケース**

*   **カウントアップタイマー:** ボタンを押すとカウントアップを開始し、経過時間をStream Deckのディスプレイに表示するプラグイン。
*   **ミュート切り替え:** ボタンを押すとマイクのミュート/ミュート解除を切り替えるプラグイン。
*   **URL起動:** ボタンを押すと特定のURLをブラウザで開くプラグイン。

**トラブルシューティング**

*   **プラグインがインストールできない:** zipファイルの形式が正しいか確認してください。`manifest.json`の形式に誤りがないか確認してください。Stream Deckソフトウェアを再起動してみてください。
*   **アクションが動作しない:** JavaScriptのコードにエラーがないか、ブラウザの開発ツールで確認してください。`manifest.json`の`UUID`が正しいか確認してください。
*   **Property Inspectorが表示されない:** `PropertyInspectorPath`に指定したHTMLファイルが存在するか確認してください。HTMLファイルにJavaScriptのエラーがないか確認してください。

**まとめと次のステップ**

このセクションでは、簡単なStream Deckプラグインを作成し、動作させることで、プラグイン開発の基本的な流れを理解しました。次のセクションでは、作成したプラグインを配布し、公開する方法を学びましょう。

### 10.4 プラグインの配布と公開

**概要と重要性**

素晴らしいプラグインを作成したら、それを他のStream Deckユーザーと共有したいと思うでしょう。このセクションでは、作成したプラグインを配布し、公開する方法を解説します。プラグインを公開することで、他のユーザーのワークフロー改善に貢献し、コミュニティを活性化することができます。

**特徴と利点**

*   **コミュニティへの貢献:** 作成したプラグインを公開することで、他のStream Deckユーザーの役に立つことができます。
*   **フィードバックの獲得:** 他のユーザーからのフィードバックを受けることで、プラグインの改善点を見つけることができます。
*   **知名度の向上:** プラグインを公開することで、自身のスキルや実績をアピールすることができます。

**事前準備と前提条件**

*   **完成したプラグイン:** 動作確認済みのプラグインが必要です。
*   **GitHubアカウント:** プラグインのソースコードを公開するために使用します。
*   **プラグインの紹介文:** プラグインの説明、使い方、注意点などを記述した文章を用意します。
*   **プラグインのスクリーンショット:** プラグインの動作画面をキャプチャした画像を用意します。

**基本的な使い方**

1.  **プラグインのパッケージング:** プラグインのディレクトリをzip形式で圧縮し、拡張子を`.sdPlugin`に変更します。

2.  **GitHubリポジトリの作成:** GitHubで新しいリポジトリを作成し、プラグインのソースコードをアップロードします。`.gitignore`ファイルを作成し、`node_modules`ディレクトリや、ビルドされたファイルをGitの管理対象から除外することをお勧めします。

3.  **プラグインの紹介文の作成:** プラグインの説明、使い方、注意点などを記述したREADMEファイルを作成します。Markdown形式で記述すると、GitHub上で見やすく表示されます。

4.  **プラグインの公開:** GitHubリポジトリを公開します。

5.  **配布方法の選択:** プラグインの配布方法として、以下のいずれかを選択します。

    *   **GitHub Releases:** GitHubのリリースページに`.sdPlugin`ファイルをアップロードし、ダウンロードリンクを公開します。
    *   **自身のウェブサイト:** 自身のウェブサイトに`.sdPlugin`ファイルをアップロードし、ダウンロードリンクを公開します。
    *   **Stream Deck Plugin Store (開発中):** Elgatoが提供する公式のプラグインストアに登録します。（現在は開発中のため、利用できません。）
6.  **コミュニティへの告知:** Stream Deckのコミュニティフォーラムや、SNSなどでプラグインの公開を告知します。

**実践的なテクニック**

*   **Semantic Versioning:** バージョン管理にSemantic Versioning (SemVer) を採用することで、プラグインの変更内容を明確に伝えることができます。
*   **CHANGELOGの作成:** バージョンごとの変更内容を記述したCHANGELOGファイルを作成することで、ユーザーはプラグインのアップデート内容を把握することができます。
*   **Issue Trackerの活用:** GitHubのIssue Trackerを活用して、ユーザーからのバグ報告や機能要望を受け付けます。

**応用例とユースケース**

*   **プラグインの販売:** Gumroadなどのプラットフォームを利用して、プラグインを有料で販売することができます。
*   **スポンサーシップの募集:** GitHub Sponsorsなどのプラットフォームを利用して、プラグインの開発を支援してくれるスポンサーを募集することができます。

**トラブルシューティング**

*   **プラグインがダウンロードできない:** ダウンロードリンクが正しいか確認してください。`.sdPlugin`ファイルが壊れていないか確認してください。
*   **プラグインがインストールできない:** 10.3のトラブルシューティングを参照してください。
*   **ユーザーからの質問やバグ報告に対応できない:** FAQを作成したり、サポート体制を整えたりすることで、ユーザーからの問い合わせに対応しやすくすることができます。
