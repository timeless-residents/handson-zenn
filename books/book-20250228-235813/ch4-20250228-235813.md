## 第4章: Python API を利用した Whisper 実装

Whisper は、OpenAI が開発した高性能な音声認識モデルです。この章では、Python API を利用して Whisper を実装し、音声データの文字起こしを行う方法を解説します。基本的な使い方から、詳細な設定やパラメータ調整まで、段階的に理解を深められるように構成されています。

### Whisper Python API の概要

#### 概要と重要性

Whisper の Python API は、プログラムから Whisper モデルを簡単に操作するためのインターフェースを提供します。これにより、音声ファイルの文字起こし、リアルタイム音声認識、多言語翻訳など、様々なタスクを自動化できます。API を利用することで、複雑な機械学習の知識がなくても、高度な音声処理機能をアプリケーションに組み込むことが可能です。

#### 特徴と利点

*   **簡単な統合:** Python ライブラリとして提供されており、既存の Python プロジェクトに簡単に組み込むことができます。
*   **柔軟なカスタマイズ:** モデルサイズ、言語、タスクなど、様々なパラメータを調整できます。
*   **高性能:** OpenAI によってトレーニングされた強力なモデルを使用するため、高い精度で文字起こしが可能です。
*   **多言語対応:** 多くの言語に対応しており、多言語環境での利用に適しています。

#### 事前準備と前提条件

*   **Python のインストール:** Python 3.7 以上がインストールされている必要があります。
*   **pip のインストール:** Python のパッケージ管理ツールである pip がインストールされている必要があります。
*   **Whisper ライブラリのインストール:** 以下のコマンドを実行して、Whisper ライブラリをインストールします。

    ```bash
    pip install -U openai-whisper
    ```

*   **FFmpeg のインストール (必要な場合):** 一部の音声ファイル形式を処理するには、FFmpeg が必要です。
    *   **Windows:** [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html) からダウンロードし、環境変数 PATH に FFmpeg の bin ディレクトリを追加します。
    *   **macOS:** `brew install ffmpeg` でインストールできます。
    *   **Linux:** `apt-get install ffmpeg` (Debian/Ubuntu) または `yum install ffmpeg` (CentOS/RHEL) でインストールできます。

### 基本的な文字起こし処理の実装

#### 基本的な使い方

まずは、最もシンプルな文字起こし処理を実装してみましょう。以下のコードは、指定された音声ファイルを文字起こしし、結果をコンソールに出力します。

```python
import whisper

# モデルのロード
model = whisper.load_model("base") # "tiny", "base", "small", "medium", "large" など

# 音声ファイルのパス
audio_path = "audio.mp3"

# 文字起こしの実行
result = model.transcribe(audio_path)

# 結果の表示
print(result["text"])
```

このコードでは、`whisper.load_model()` 関数で Whisper モデルをロードします。モデルサイズは "tiny", "base", "small", "medium", "large" などから選択できます。一般的に、大きいモデルほど精度が高くなりますが、処理時間も長くなります。`model.transcribe()` 関数に音声ファイルのパスを渡すと、文字起こしが実行され、結果が辞書形式で返されます。この辞書には、文字起こしされたテキストだけでなく、タイムスタンプなどの情報も含まれています。`result["text"]` で文字起こしされたテキストを取得できます。

#### 実践的なテクニック

*   **ファイルパスの指定:** `audio_path` には、音声ファイルの絶対パスまたは相対パスを指定できます。
*   **モデルサイズの選択:** 処理速度と精度のバランスを考慮して、適切なモデルサイズを選択します。最初は "base" モデルから試してみるのがおすすめです。
*   **エラーハンドリング:** `try-except` ブロックを使用して、ファイルが見つからないなどのエラーを処理します。

#### 応用例とユースケース

*   **音声メモの文字起こし:** 音声メモを自動的にテキストに変換し、議事録作成を効率化します。
*   **動画の字幕作成:** 動画の音声を文字起こしし、字幕ファイル (SRT, VTT など) を生成します。
*   **音声検索:** 音声ファイルを文字起こしし、テキスト検索エンジンと組み合わせて、音声データの内容を検索可能にします。

#### トラブルシューティング

*   **`FileNotFoundError`:** 指定された音声ファイルが見つからない場合、このエラーが発生します。ファイルパスが正しいか確認してください。
*   **`RuntimeError: Failed to load audio`:** FFmpeg がインストールされていないか、正しく設定されていない場合に発生します。FFmpeg をインストールし、環境変数を設定してください。
*   **文字起こしの精度が低い:** より大きいモデル ("small", "medium", "large") を試してみるか、詳細設定でパラメータを調整してください (後述)。

### 詳細設定とパラメータ調整

#### 概要と重要性

Whisper は、様々なパラメータを調整することで、文字起こしの精度や速度を最適化できます。言語の指定、タスクの選択、温度パラメータの調整など、状況に応じた設定を行うことで、より高品質な文字起こし結果を得ることが可能です。

#### 特徴と利点

*   **言語指定:** 文字起こしする言語を明示的に指定することで、精度を向上させることができます。
*   **タスク指定:** 文字起こし (transcribe) または翻訳 (translate) を選択できます。
*   **温度パラメータ:** 生成されるテキストのランダム性を制御できます。
*   **詳細なパラメータ制御:** 多くのパラメータを調整することで、特定の音声データに合わせた最適化が可能です。

#### 基本的な使い方

`model.transcribe()` 関数には、様々なオプションパラメータを指定できます。以下は、言語を指定して文字起こしを行う例です。

```python
import whisper

model = whisper.load_model("base")
audio_path = "audio.mp3"

result = model.transcribe(audio_path, language="ja") # 日本語を指定

print(result["text"])
```

#### 実践的なテクニック

*   **言語指定:** `language` パラメータに言語コード (例: "en" (英語), "ja" (日本語), "fr" (フランス語)) を指定します。言語コードは、ISO 639-1 規格に従います。
*   **タスク指定:** `task` パラメータに "transcribe" (文字起こし) または "translate" (翻訳) を指定します。
*   **温度パラメータ (temperature):** 生成されるテキストのランダム性を制御します。0 に近いほど決定論的になり、1 に近いほどランダムになります。複数の値を指定することで、最適な値を探すことができます (例: `temperature=[0.0, 0.2, 0.5, 1.0]`)。
*   **`initial_prompt`:** 文字起こしの最初の手がかりとなるテキストを指定します。これにより、特定の単語やフレーズを認識しやすくなります。
*   **`beam_size`:** ビームサーチのビーム幅を指定します。大きいほど精度が向上する可能性がありますが、処理時間も長くなります。
*   **`condition_on_previous_text`:** 前のセグメントのテキストを次のセグメントの条件として使用するかどうかを指定します。
*   **`fp16`:** 半精度浮動小数点数 (float16) を使用するかどうかを指定します。GPU を使用する場合、True に設定すると高速化する可能性があります。

```python
import whisper

model = whisper.load_model("medium")
audio_path = "audio.mp3"

options = {
    "language": "ja",
    "task": "transcribe",
    "temperature": 0.0,
    "initial_prompt": "これは議事録です。",
    "beam_size": 5,
    "condition_on_previous_text": True,
    "fp16": False
}

result = model.transcribe(audio_path, **options)

print(result["text"])
```

#### 応用例とユースケース

*   **会議の議事録作成:** `initial_prompt` に会議のテーマや参加者名などを指定することで、より正確な議事録を作成できます。
*   **外国語学習:** 音声を文字起こしし、翻訳機能と組み合わせて、外国語の学習をサポートします。
*   **アクセントの強い音声の文字起こし:** `temperature` パラメータを調整することで、アクセントの強い音声でも高い精度で文字起こしできます。

#### トラブルシューティング

*   **精度が向上しない:** 様々なパラメータを試して、最適な組み合わせを見つける必要があります。特に、`temperature`、`beam_size`、`initial_prompt` は精度に影響を与えやすいパラメータです。
*   **処理時間が長すぎる:** より小さいモデル ("tiny", "base", "small") を試してみるか、`fp16` を True に設定して、高速化を試みます。
*   **GPU メモリ不足:** より小さいモデルを使用するか、`fp16` を False に設定して、GPU メモリの使用量を減らします。また、GPU を搭載した環境での実行を検討してください。
