## 第10章: Web アプリケーションへの Whisper 統合

### Flask/Django を用いた Web アプリケーションの構築

#### 概要と重要性

Whisper を Web アプリケーションに統合することで、ユーザーはブラウザから直接音声ファイルをアップロードし、その内容をテキストに変換できるようになります。これは、議事録作成、インタビューの書き起こし、講義ノートの作成など、様々な場面で非常に役立ちます。Web アプリケーションとして提供することで、ユーザーは特定のソフトウェアをインストールする必要がなくなり、利便性が向上します。

#### 特徴と利点

*   **アクセシビリティ:** ブラウザさえあれば、どこからでも利用可能。
*   **利便性:** ソフトウェアのインストールや設定が不要。
*   **スケーラビリティ:** Web アプリケーションのフレームワークを利用することで、ユーザー数の増加に対応しやすい。
*   **カスタマイズ性:** ユーザーインターフェースや機能を追加・変更しやすい。
*   **統合性:** 既存の Web アプリケーションに容易に統合可能。

#### 事前準備と前提条件

*   **Python のインストール:** Python 3.7 以上が推奨されます。
*   **仮想環境の構築:** プロジェクトごとに依存関係を管理するために、仮想環境を使用することを強く推奨します。
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # Linux/macOS
    # venv\Scripts\activate  # Windows
    ```
*   **Flask または Django のインストール:** どちらのフレームワークを使用するか選択し、インストールします。
    ```bash
    pip install flask  # Flask の場合
    pip install django  # Django の場合
    ```
*   **Whisper のインストール:** `openai-whisper` パッケージをインストールします。
    ```bash
    pip install openai-whisper
    ```
*   **FFmpeg のインストール:** 音声ファイルの形式によっては、FFmpeg が必要になる場合があります。お使いの OS に合わせてインストールしてください。
    ```bash
    # 例 (Ubuntu):
    sudo apt-get update
    sudo apt-get install ffmpeg
    ```

#### 基本的な使い方 (Flask を使用)

1.  **Flask アプリケーションの作成:** 以下のコードを `app.py` として保存します。

    ```python
    from flask import Flask, render_template, request, redirect, url_for
    import whisper
    import os
    from werkzeug.utils import secure_filename

    app = Flask(__name__)
    app.config['UPLOAD_FOLDER'] = 'uploads'  # アップロードされたファイルを保存するディレクトリ
    os.makedirs(app.config['UPLOAD_FOLDER'], exist_ok=True)  # ディレクトリが存在しない場合に作成
    app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024  # 最大ファイルサイズ (16MB)

    # Whisper モデルのロード (初回のみ)
    model = whisper.load_model("base")  # モデルサイズを指定

    ALLOWED_EXTENSIONS = {'mp3', 'wav', 'mp4', 'm4a'}  # 許可するファイル拡張子

    def allowed_file(filename):
        return '.' in filename and \
               filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

    @app.route('/', methods=['GET', 'POST'])
    def upload_file():
        if request.method == 'POST':
            # ファイルがリクエストに含まれているか確認
            if 'file' not in request.files:
                return 'No file part'

            file = request.files['file']

            # ファイルが選択されていない場合
            if file.filename == '':
                return 'No selected file'

            # ファイルのアップロードと処理
            if file and allowed_file(file.filename):
                filename = secure_filename(file.filename)
                filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)
                file.save(filepath)

                # Whisper による音声認識
                try:
                    result = model.transcribe(filepath)
                    transcription = result["text"]

                    # ファイルの削除 (オプション)
                    os.remove(filepath)

                    return render_template('result.html', transcription=transcription)

                except Exception as e:
                    os.remove(filepath)  # エラー発生時もファイルを削除
                    return f"Transcription failed: {str(e)}"


        return render_template('index.html')

    if __name__ == '__main__':
        app.run(debug=True)
    ```

2.  **HTML テンプレートの作成:** `templates` フォルダを作成し、`index.html` と `result.html` を以下の内容で保存します。

    `templates/index.html`:

    ```html
    <!DOCTYPE html>
    <html>
    <head>
        <title>Whisper 音声認識</title>
    </head>
    <body>
        <h1>音声ファイルをアップロードしてください</h1>
        <form method="post" enctype="multipart/form-data">
            <input type="file" name="file">
            <input type="submit" value="アップロード">
        </form>
    </body>
    </html>
    ```

    `templates/result.html`:

    ```html
    <!DOCTYPE html>
    <html>
    <head>
        <title>Whisper 音声認識結果</title>
    </head>
    <body>
        <h1>音声認識結果</h1>
        <p>{{ transcription }}</p>
    </body>
    </html>
    ```

3.  **アプリケーションの実行:**

    ```bash
    python app.py
    ```

    ブラウザで `http://127.0.0.1:5000/` にアクセスし、音声ファイルをアップロードして試してください。

#### 実践的なテクニック

*   **モデルの選択:** Whisper には複数のモデルサイズ（`tiny`, `base`, `small`, `medium`, `large`）があります。精度と速度のトレードオフを考慮して、適切なモデルを選択してください。`"base"` モデルは、一般的な用途に適しています。より高精度な結果を求める場合は `"medium"` または `"large"` モデルを検討してください。ただし、これらのモデルはより多くの計算リソースを必要とします。
    ```python
    model = whisper.load_model("large")
    ```

*   **ファイルサイズの制限:** 大きなファイルをアップロードすると、サーバーの負荷が高まり、処理時間も長くなります。ファイルサイズを制限することを推奨します。
    ```python
    app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024  # 16MB に制限
    ```

*   **エラーハンドリング:** ファイル形式の誤りや Whisper の処理中にエラーが発生した場合に、適切なエラーメッセージを表示するようにしてください。
    ```python
    try:
        result = model.transcribe(filepath)
        transcription = result["text"]
    except Exception as e:
        return f"Transcription failed: {str(e)}"
    ```

*   **進捗状況の表示:** 大きなファイルを処理する場合、進捗状況を表示することで、ユーザーエクスペリエンスを向上させることができます。Flask-socketio などを使用して、クライアントにリアルタイムで進捗状況を送信することができます。

*   **キャッシュ:** 同じファイルが何度もアップロードされる場合、結果をキャッシュすることで処理時間を短縮できます。

*   **セキュリティ:** アップロードされたファイルを安全に処理するために、ファイル名をサニタイズし、許可された拡張子のみを受け入れるようにしてください。`werkzeug.utils.secure_filename` を使用すると、ファイル名を安全に処理できます。

*   **GPU の利用:** Whisper の処理は計算負荷が高いため、GPU を利用することで大幅に処理時間を短縮できます。GPU を利用するには、PyTorch が CUDA を利用できるように設定する必要があります。

#### 応用例とユースケース

*   **議事録作成:** 会議の録音をアップロードし、自動的に議事録を作成する。
*   **インタビューの書き起こし:** インタビューの音声をテキストに変換し、記事の作成を支援する。
*   **講義ノートの作成:** 講義の録音をアップロードし、学生が講義ノートを作成するのを支援する。
*   **カスタマーサポート:** 音声による問い合わせ内容をテキストに変換し、対応履歴として保存する。
*   **音声翻訳:** 音声をテキストに変換した後、翻訳 API を利用して他の言語に翻訳する。

#### トラブルシューティング

*   **"No module named 'openai_whisper'"**: `openai-whisper` パッケージがインストールされているか確認してください。仮想環境を使用している場合は、仮想環境がアクティブになっていることを確認してください。
*   **"FFmpeg not found"**: FFmpeg がインストールされているか、およびシステムパスに正しく設定されているか確認してください。
*   **音声認識の精度が低い**: モデルのサイズを大きくするか、音声ファイルの品質を向上させることを試してください。また、Whisper は特定の言語やアクセントに対して最適化されていない場合があります。
*   **アップロードエラー**:  `request.files` が空かどうか、ファイル名が安全かどうか、ファイルサイズが制限を超えていないかを確認してください。

### 音声ファイルのアップロードと処理

#### 概要と重要性

Webアプリケーションで音声ファイルをアップロードし、処理する機能は、Whisperを統合する上で不可欠です。ユーザーが手軽に音声データを提供できる環境を構築することは、アプリケーションの使いやすさを大きく向上させます。

#### 特徴と利点

*   **多様なファイル形式のサポート:** 様々な音声ファイル形式（mp3, wav, mp4, m4aなど）に対応することで、ユーザーの利便性を高めます。
*   **非同期処理:** 大容量ファイルの処理をバックグラウンドで行うことで、ユーザー体験を向上させます。
*   **ファイルサイズの制限:** サーバーの負荷を軽減し、セキュリティリスクを減らすために、アップロードするファイルサイズを制限します。
*   **エラー処理:** ファイルのアップロード中に発生する可能性のあるエラー（ファイル形式の誤り、ファイルサイズの超過など）を適切に処理します。
*   **ストレージの最適化:** アップロードされたファイルを効率的に管理し、ストレージの使用量を最適化します。

#### 事前準備と前提条件

*   **Flask/Djangoの設定:** Webアプリケーションフレームワーク（FlaskまたはDjango）が正しく設定されていることを確認します。
*   **アップロードフォルダの作成:** アップロードされたファイルを保存するためのフォルダを作成します。
*   **必要なライブラリのインストール:** ファイルの処理に必要なライブラリ（`werkzeug`など）をインストールします。

#### 基本的な使い方 (Flask を使用)

1.  **アップロードフォームの作成:** ユーザーがファイルをアップロードするためのHTMLフォームを作成します。
    ```html
    <form method="post" enctype="multipart/form-data">

    </form>
    ```

2.  **アップロード処理の実装:** Flaskで、アップロードされたファイルを処理するルートを定義します。
    ```python
    from flask import Flask, request, redirect, url_for
    import os
    from werkzeug.utils import secure_filename

    app = Flask(__name__)
    UPLOAD_FOLDER = 'uploads'  # アップロードフォルダを指定
    app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER
    app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024  # 16MBまで

    ALLOWED_EXTENSIONS = {'mp3', 'wav', 'mp4', 'm4a'} # 許可する拡張子

    def allowed_file(filename):
        return '.' in filename and \
               filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

    @app.route('/upload', methods=['POST'])
    def upload_file():
        if request.method == 'POST':
            # ファイルが存在しない場合のエラー処理
            if 'audio_file' not in request.files:
                return 'ファイルがありません'

            file = request.files['audio_file']

            # ファイル名が空の場合のエラー処理
            if file.filename == '':
                return 'ファイルが選択されていません'

            # ファイルの形式が許可されていない場合のエラー処理
            if file and allowed_file(file.filename):
                filename = secure_filename(file.filename)
                filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)
                file.save(filepath)
                return 'ファイルが正常にアップロードされました'
            else:
                return '許可されていないファイル形式です'

        return '''
        <!doctype html>
        <html>
        <head>
            <title>ファイルアップロード</title>
        </head>
        <body>
            <h1>音声ファイルをアップロードしてください</h1>
            <form method="post" enctype="multipart/form-data" action="/upload">
              <input type="file" name="audio_file">
              <input type="submit" value="アップロード">
            </form>
        </body>
        </html>
        '''
    ```

### 結果の表示とダウンロード機能の実装

*   **編集機能:** 必要に応じて、テキストを編集できる機能を提供することで、ユーザーが結果を修正したり、追加の情報を加えたりすることができます。
*   **検索機能:** 大量のテキストから特定のキーワードを検索できる機能を提供することで、ユーザーが目的の情報を素早く見つけられるようにします。
*   **印刷機能:** テキストを印刷できる機能を提供することで、ユーザーが紙媒体で結果を確認できるようにします。

#### 事前準備と前提条件

*   **Whisperによる音声認識の実装:** 音声ファイルをテキストに変換する機能が実装されていることを確認します。
*   **テキスト表示領域の確保:** Webページにテキストを表示するための領域を確保します。

#### 基本的な使い方 (Flask を使用)

1.  **テキストの表示:** Whisperによる音声認識の結果をWebページに表示します。
    ```python
    from flask import Flask, render_template, request, send_file
    import whisper
    import os
    from werkzeug.utils import secure_filename
    import io

    app = Flask(__name__)
    app.config['UPLOAD_FOLDER'] = 'uploads'
    os.makedirs(app.config['UPLOAD_FOLDER'], exist_ok=True)
    app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024

    model = whisper.load_model("base")
    ALLOWED_EXTENSIONS = {'mp3', 'wav', 'mp4', 'm4a'}

    def allowed_file(filename):
        return '.' in filename and \
               filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

    @app.route('/', methods=['GET', 'POST'])
    def upload_file():
        if request.method == 'POST':
            if 'file' not in request.files:
                return 'No file part'

            file = request.files['file']

            if file.filename == '':
                return 'No selected file'

            if file and allowed_file(file.filename):
                filename = secure_filename(file.filename)
                filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)
                file.save(filepath)

                try:
                    result = model.transcribe(filepath)
                    transcription = result["text"]
                    os.remove(filepath)
                    return render_template('result.html', transcription=transcription)

                except Exception as e:
                    os.remove(filepath)
                    return f"Transcription failed: {str(e)}"

        return render_template('index.html')

    @app.route('/download')
    def download_file():
        transcription = request.args.get('transcription')
        if not transcription:
            return "No transcription to download."

        # テキストデータをバイトストリームとして保存
        output = io.BytesIO(transcription.encode('utf-8'))

        # ファイルを送信
        return send_file(
            output,
            mimetype='text/txt',
            as_attachment=True,
            download_name='transcription.txt'
        )

    if __name__ == '__main__':
        app.run(debug=True)
    ```

    `templates/result.html`:

    ```html
    <!DOCTYPE html>
    <html>
    <head>
        <title>Whisper 音声認識結果</title>
    </head>
    <body>
        <h1>音声認識結果</h1>
        <p>{{ transcription }}</p>
        <a href="{{ url_for('download_file', transcription=transcription) }}">テキストファイルをダウンロード</a>
    </body>
    </html>
    ```

#### 実践的なテクニック

*   **テキストのフォーマット:** テキストを見やすくするために、HTMLタグを使用してフォーマットします（例：段落分け、リスト表示など）。
*   **タイムスタンプの追加:** 音声データとテキストを同期させるために、タイムスタンプをテキストに追加します。 Whisperの出力にはタイムスタンプも含まれているので、それを利用します。
*   **クリップボードへのコピー:** テキストを簡単にコピーできるように、クリップボードにコピーする機能を追加します。
*   **Markdown形式での表示:** テキストをMarkdown形式で表示することで、見出しやリストなどの構造を表現できます。

#### 応用例とユースケース

*   **議事録作成ツール:** 会議の録音をテキストに変換し、参加者、日時、議題などのメタデータを追加して表示するツール。
*   **字幕作成ツール:** 動画の音声をテキストに変換し、字幕ファイル（srt形式など）としてダウンロードできるようにするツール。
*   **ナレーション作成ツール:** テキストを入力すると、自動的にナレーションを作成するツール。

#### トラブルシューティング

*   **文字化け:** テキストのエンコーディングを確認します（UTF-8が推奨）。
*   **ダウンロードできない:** サーバーの設定を確認し、ファイルのダウンロードが許可されていることを確認します。
*   **表示が崩れる:** HTMLタグが正しく記述されているか確認します。

#### まとめと次のステップ

このセクションでは、Whisperによる音声認識の結果を表示し、ダウンロードする機能について学びました。これらの機能は、アプリケーションのユーザビリティを向上させる上で非常に重要です。

次のステップとしては、ユーザーインターフェースを改善し、より高度な機能（編集機能、検索機能など）を追加することを検討してください。また、作成した Web アプリケーションを実際にデプロイし、運用してみることをお勧めします。
