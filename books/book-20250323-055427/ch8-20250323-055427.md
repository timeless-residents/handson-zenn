## 第 8 章: スタイルを極める！ LoRA/Dreambooth による独自モデルの作成

### LoRA/Dreambooth とは？: モデルを自分好みにカスタマイズ

#### 概要と重要性

Stable Diffusion のような画像生成 AI は、その汎用性の高さから様々な場面で利用されていますが、「もうちょっとだけ、自分のイメージに近づけたい…！」と思ったことはありませんか？ LoRA (Low-Rank Adaptation) と Dreambooth は、そんな願いを叶えるための技術です。既存の学習済みモデルを、比較的小さなデータセットで、かつ高速に、特定のスタイルやオブジェクトに特化させることを可能にします。

たとえば、「特定のアーティストの画風でイラストを生成したい」「自分のペットそっくりのキャラクターを生成したい」といった場合に、LoRA や Dreambooth は非常に有効な手段となります。これらの技術を習得することで、あなたの創造性をさらに解放し、よりパーソナライズされた画像生成 AI の世界を体験できるでしょう。

#### 特徴と利点

LoRA と Dreambooth は、既存の Stable Diffusion モデルを微調整するための技術ですが、それぞれに異なる特徴と利点があります。

- **LoRA (Low-Rank Adaptation)**: 学習させるパラメータ数を大幅に削減することで、学習時間を短縮し、生成される LoRA モデルのファイルサイズを小さく抑えることができます。このため、手軽に試したり、複数の LoRA モデルを組み合わせて使用したりするのに適しています。また、学習に必要な GPU リソースも比較的少なくて済むため、ハイエンドな GPU を持っていなくても学習が可能です。

- **Dreambooth**: より忠実に特定のオブジェクトやスタイルを学習させることができます。LoRA に比べて学習データ量が多く必要になる傾向がありますが、その分、生成される画像のクオリティは高くなります。ただし、学習時間が長くなることや、学習に必要な GPU リソースが多くなることには注意が必要です。

**主な利点:**

- **手軽なカスタマイズ**: 大規模なデータセットや計算リソースを必要とせず、既存のモデルを自分好みに調整できます。
- **高速な学習**: LoRA は特に、学習時間が短く、気軽に試せるのが魅力です。
- **汎用性の向上**: 特定のスタイルやオブジェクトに特化させることで、より具体的なイメージを生成できます。
- **創造性の解放**: 既存のモデルの限界を超え、独自の表現を追求できます。

#### 事前準備と前提条件

LoRA/Dreambooth を始める前に、以下の準備が必要です。

1.  **Stable Diffusion 環境の構築**: AUTOMATIC1111 版 Stable Diffusion web UI (以下、web UI) がインストールされていることを前提とします。まだの場合は、以下のリポジトリを参考にインストールしてください: [https://github.com/AUTOMATIC1111/stable-diffusion-webui](https://github.com/AUTOMATIC1111/stable-diffusion-webui)

2.  **Python の知識**: Python の基本的な構文やパッケージのインストール方法を理解していることが望ましいです。

3.  **GPU**: 学習には GPU が必要です。VRAM 8GB 以上を推奨します。VRAM が少ない場合は、LoRA の学習を行うか、学習時の設定を調整する必要があります。

4.  **必要な拡張機能のインストール**:

    - **LoRA**: web UI の Extensions タブから「Available」を選択し、「LoRA」と検索してインストールします。
    - **Dreambooth**: web UI の Extensions タブから「Available」を選択し、「sd-dreambooth-extension」と検索してインストールします。

5.  **学習データの準備**: 後述する「レトロゲーム風キャラクターに特化した学習データの作成」を参照して、学習データを用意してください。

#### 基本的な使い方

ここでは、LoRA の基本的な使い方について説明します。

1.  **LoRA の学習**:

    - web UI の Dreambooth タブを開き、Model Name（モデル名）を入力します。
    - Create をクリックして、新しいモデルを作成します。
    - Pretrained Model Name でベースとなるモデルを選択します。
    - Instance Prompt にトリガーワードを入力します。これがモデルを呼び出すためのキーワードになります。（例: `sks retrogame`)
    - Training Images Dir に学習画像が入ったディレクトリを指定します。
    - Steps に学習ステップ数を指定します。最初は 3000 ステップ程度から始め、様子を見て調整するのがおすすめです。
    - Save checkpoint frequency に、モデルの保存頻度を指定します。頻繁に保存することで、学習の途中で問題が発生した場合でも、途中から再開できます。
    - Train をクリックして、学習を開始します。

    ```python
    # 学習設定の例 (コマンドライン引数)
    --pretrained_model_name_or_path="runwayml/stable-diffusion-v1-5"
    --instance_data_dir="./data/retrogame"
    --instance_prompt="sks retrogame character"
    --resolution=512
    --train_batch_size=1
    --gradient_accumulation_steps=1
    --learning_rate=5e-4
    --max_train_steps=3000
    --save_steps=500
    --output_dir="./output/retrogame_lora"
    --seed=42
    --train_text_encoder
    --create_in_dir
    ```

2.  **LoRA モデルの利用**:

    - 学習が完了すると、web UI の models/Lora ディレクトリに LoRA モデルが保存されます。
    - txt2img タブまたは img2img タブを開き、プロンプトにトリガーワードを含めます。
    - LoRA モデルを選択します。web UI のインターフェース上で`<lora:モデル名:重み>`のように指定します。重みは 0 から 1 の間で調整できます。
    - Generate をクリックして、画像を生成します。

    ```python
    # プロンプトの例
    prompt = "sks retrogame character, pixel art, vibrant colors"
    negative_prompt = "blurry, distorted, low quality"
    ```

#### 実践的なテクニック

- **学習データの質**: 学習データの質は、生成される画像のクオリティに大きく影響します。解像度が高く、ノイズの少ない画像を用意しましょう。
- **トリガーワードの選定**: 他のモデルと競合しない、ユニークなトリガーワードを選びましょう。
- **学習ステップ数の調整**: 学習ステップ数が少なすぎると学習が不十分になり、多すぎると過学習になる可能性があります。学習曲線を確認しながら、適切なステップ数を見つけましょう。Tensorboard などのツールを使うと便利です。
- **プロンプトの工夫**: トリガーワードだけでなく、具体的な指示を与えることで、よりイメージに近い画像を生成できます。
- **LoRA の重みの調整**: LoRA の重みを調整することで、LoRA モデルの影響度を調整できます。0 に近いほど元のモデルに近く、1 に近いほど LoRA モデルの影響が強くなります。
- **複数の LoRA の組み合わせ**: 複数の LoRA モデルを組み合わせることで、より複雑な表現が可能になります。

#### 応用例とユースケース

- **ゲームキャラクターの作成**: 自分がプレイしたいレトロゲーム風のキャラクターを生成できます。
- **イラストのスタイル変換**: 既存のイラストを、特定のアーティストの画風に変換できます。
- **商品画像の生成**: 新しい商品の画像を、様々な背景や構図で生成できます。
- **アバターの作成**: 自分の顔写真から、AI アバターを作成できます。
- **建築デザイン**: 特定の建築様式を学習させ、新しい建築デザインを生成できます。

#### トラブルシューティング

- **学習が進まない**: 学習データが少なすぎるか、学習ステップ数が少なすぎる可能性があります。学習データを増やしたり、学習ステップ数を増やしたりしてみましょう。
- **過学習**: 学習ステップ数が多すぎる可能性があります。学習ステップ数を減らしたり、正則化の手法を試したりしてみましょう。
- **生成される画像が崩れる**: 学習データに問題がある可能性があります。学習データを確認し、ノイズの多い画像や解像度の低い画像を取り除きましょう。
- **VRAM 不足**: 学習時のバッチサイズを小さくしたり、xFormers を有効にしたり、Low VRAM オプションを試したりしてみましょう。LoRA は比較的 VRAM 消費量が少ないので、LoRA を使うのも有効な手段です。
- **CUDA out of memory**: `--medvram`や`--xformers`といった起動オプションを試してみましょう。

LoRA は、Stable Diffusion を自分好みにカスタマイズするための強力なツールです。この章で紹介した内容を参考に、色々な LoRA モデルを試したり、自分で LoRA モデルを作成したりして、画像生成 AI の世界をさらに深く探求してみてください。

次のステップとしては、以下のことを試してみるのがおすすめです。

- **Dreambooth の学習**: LoRA よりも高品質なモデルを作成できます。
- **ControlNet との組み合わせ**: ControlNet と LoRA を組み合わせることで、より細かい制御が可能になります。
- **LoRA Gallery の活用**: 他の人が作成した LoRA モデルを試してみるのも良いでしょう。

### レトロゲーム風キャラクターに特化した学習データの作成

#### 概要と重要性

LoRA/Dreambooth の成否を左右する最も重要な要素の一つが、学習データの質です。特に、特定のスタイルやオブジェクトを学習させる場合、適切なデータセットを用意することが不可欠になります。ここでは、レトロゲーム風キャラクターに特化した学習データを作成する具体的な手順とテクニックについて解説します。

#### 特徴と利点

質の高い学習データを作成することで、以下の効果が期待できます。

- **生成される画像のクオリティ向上**: 鮮明でノイズの少ない画像は、学習効率を高め、より高品質な画像を生成します。
- **学習時間の短縮**: 適切なデータセットは、学習プロセスを効率化し、学習時間を短縮します。
- **意図したスタイルの再現**: 特定のスタイルを忠実に再現するためには、そのスタイルを代表する画像を集める必要があります。

#### 事前準備と前提条件

1.  **画像収集ツール**: 画像を効率的に収集するためのツール (例: Image Downloader, DownThemAll!) があると便利です。
2.  **画像編集ソフト**: 画像のリサイズ、トリミング、ノイズ除去などを行うための画像編集ソフト (例: GIMP, Photoshop) が必要です。
3.  **学習データの保存場所**: 収集した画像を保存するためのディレクトリを用意します。

#### 基本的な使い方

1.  **テーマの決定**: どんなレトロゲーム風キャラクターを生成したいかを具体的に決めます。例えば、「8bit 風ドット絵の RPG キャラクター」「16bit 風アクションゲームの主人公」など、具体的なイメージを持つことが重要です。

2.  **画像収集**:

    - Google 画像検索、Pinterest、DeviantArt などのサイトから、テーマに合致する画像を収集します。
    - 収集する際には、以下の点に注意します。
      - **解像度**: 512x512 以上の解像度がある画像を選びましょう。
      - **アスペクト比**: できるだけ正方形に近い画像を選びましょう。
      - **著作権**: 著作権に配慮し、商用利用可能な画像を選びましょう。
      - **バリエーション**: 様々なポーズ、アングル、表情の画像を集めましょう。
    - Pixabay や Unsplash といったサイトで、CC0 ライセンスの画像を探すのも有効な手段です。

3.  **画像整理**:

    - 収集した画像を、テーマごとにディレクトリに整理します。
    - 重複している画像や、テーマに合わない画像を取り除きます。

4.  **画像加工**:

    - 画像編集ソフトを使って、以下の処理を行います。
      - **リサイズ**: 全ての画像を同じサイズ (例: 512x512) にリサイズします。
      - **トリミング**: 画像の中心にキャラクターが配置されるようにトリミングします。
      - **ノイズ除去**: 画像にノイズがある場合は、ノイズ除去フィルターを適用します。
      - **明るさ/コントラスト調整**: 画像全体の明るさやコントラストを調整します。
    - AI を使った画像アップスケーラー (例: Real-ESRGAN) を利用して、低解像度の画像を高品質化することも有効です。

5.  **キャプション作成**:

    - 各画像に対応するキャプションファイルを作成します。
    - キャプションファイルには、画像の内容を説明するテキストを記述します。
    - 例: `sks retrogame character, pixel art, warrior, sword, shield`
    - BLIP (Bootstrapping Language-Image Pre-training) などのツールを使って、自動的にキャプションを生成することも可能です。

6.  **データセットの確認**:
    - 作成したデータセットを再度確認し、不備がないかチェックします。
    - 必要に応じて、画像の追加や修正を行います。

#### 実践的なテクニック

- **データ拡張**: 画像を左右反転させたり、ランダムにクロップしたりすることで、データセットのバリエーションを増やし、過学習を抑制できます。
- **ネガティブプロンプトの活用**: 生成したくない要素 (例: blurry, distorted, low quality) を記述したテキストファイルを用意し、学習時にネガティブプロンプトとして指定することで、生成される画像の品質を向上させることができます。
- **教師なし学習の活用**: まずは大量の画像を使って教師なし学習を行い、その後、少量の教師ありデータでファインチューニングすることで、学習効率を高めることができます。
- **メタデータの活用**: 画像にメタデータ (例: タイトル, 説明, タグ) を付与することで、より詳細な情報を学習させることができます。

#### 応用例とユースケース

- **ゲーム開発**: レトロゲーム風のキャラクターを自動生成し、ゲーム開発の効率化に役立てることができます。
- **イラスト制作**: 様々なスタイルのレトロゲーム風イラストを生成し、イラスト制作のインスピレーションを得ることができます。
- **NFT アート**: 生成したレトロゲーム風キャラクターを NFT アートとして販売することができます。

#### トラブルシューティング

- **学習データが不足している**: より多くの画像を集めるか、データ拡張の手法を試してみましょう。
- **学習データに偏りがある**: データセット内の各クラス (例: ポーズ, アングル, 表情) の画像の数を均等にしましょう。
- **キャプションが不正確**: キャプションの内容を見直し、より正確な記述を心がけましょう。
- **画像サイズが統一されていない**: 全ての画像を同じサイズにリサイズしましょう。
- **画像の品質が低い**: より高品質な画像を選びましょう。

#### まとめと次のステップ

質の高い学習データを作成することは、LoRA/Dreambooth の成功に不可欠です。この章で紹介した手順とテクニックを参考に、あなたの創造性を最大限に引き出すためのデータセットを作成してください。

次のステップとしては、以下のことを試してみるのがおすすめです。

- **データセットの共有**: 作成したデータセットを公開し、他の人と共有することで、より多くのフィードバックを得ることができます。
- **データセットの改善**: フィードバックを参考に、データセットを改善し、より高品質なモデルを作成しましょう。
- **異なるスタイルの学習データの作成**: レトロゲーム風以外のスタイル (例: アニメ, 実写) の学習データを作成し、様々な表現を試してみましょう。

### 学習の実行と評価: 成果を可視化する

#### 概要と重要性

学習データの準備が完了したら、いよいよ LoRA/Dreambooth の学習を実行します。しかし、学習を実行するだけでなく、その過程を注意深く監視し、結果を評価することが、より良いモデルを作成するために非常に重要です。ここでは、学習の実行方法、学習状況のモニタリング、そして学習結果の評価方法について詳しく解説します。

#### 特徴と利点

学習の実行と評価を適切に行うことで、以下のメリットが得られます。

- **最適な学習設定の発見**: 様々なパラメータを試すことで、あなたのデータセットに最適な学習設定を見つけることができます。
- **過学習の早期発見**: 学習の進行状況を監視することで、過学習の兆候を早期に発見し、対策を講じることができます。
- **生成される画像の品質向上**: 学習結果を評価し、改善点を見つけることで、生成される画像の品質を向上させることができます。
- **学習時間の短縮**: 無駄な学習を避け、効率的に学習を進めることができます。

#### 事前準備と前提条件

1.  **LoRA/Dreambooth 環境**: 前述の通り、AUTOMATIC1111 版 Stable Diffusion web UI に LoRA/Dreambooth の拡張機能がインストールされている必要があります。
2.  **学習済みモデル**: Stable Diffusion の学習済みモデル (例: `runwayml/stable-diffusion-v1-5`) が必要です。
3.  **TensorBoard**: 学習状況を可視化するために、TensorBoard をインストールしておくと便利です。`pip install tensorboard`でインストールできます。

#### 基本的な使い方

1.  **学習の実行**:

    - web UI の Dreambooth タブを開き、前述の手順に従って学習を開始します。
    - 学習中は、コンソールに表示されるログを注意深く監視します。
    - 学習の進行状況は、TensorBoard を使って可視化することもできます。

    ```python
    # TensorBoardの起動
    tensorboard --logdir="./output/retrogame_lora/logs"
    ```

2.  **学習状況のモニタリング**:

    - TensorBoard を使って、loss (損失) などの指標を監視します。
    - loss が徐々に減少していれば、学習は順調に進んでいます。
    - loss が停滞したり、逆に増加したりする場合は、学習設定を見直す必要があります。
    - 学習の途中で、生成される画像のサンプルを確認することも重要です。

3.  **学習結果の評価**:
    - 学習が完了したら、生成される画像を評価します。
    - プロンプトを色々変えてみて、意図した通りの画像が生成されるか確認します。
    - 生成された画像を比較し、最も品質の高いモデルを選びます。
    - 生成された画像に問題がある場合は、学習設定を見直したり、学習データを修正したりして、再度学習を行います。

#### 実践的なテクニック

- **学習率の調整**: 学習率を調整することで、学習の速度や安定性を制御できます。一般的に、学習率が小さすぎると学習が進まず、大きすぎると学習が不安定になります。
- **バッチサイズの調整**: バッチサイズを調整することで、VRAM の使用量を制御できます。VRAM が不足する場合は、バッチサイズを小さくしましょう。
- **正則化の手法**: L1 正則化や L2 正則化などの正則化の手法を適用することで、過学習を抑制できます。
- **アーリーストッピング**: 検証データを使って、学習の早期終了判定を行うことで、過学習を抑制できます。
- **ハイパーパラメータの最適化**: Optuna などのツールを使って、ハイパーパラメータを自動的に最適化することができます。
- **Prompt Engineering**: 生成される画像の品質は、プロンプトの記述方法に大きく左右されます。様々なプロンプトを試して、最適なプロンプトを見つけましょう。例えば、`sks retrogame character, pixel art, warrior, sword, shield, detailed background, vibrant colors, 8bit`のように、具体的な指示を与えることで、よりイメージに近い画像を生成できます。

#### 応用例とユースケース

- **自動パラメータ調整**: 学習状況を監視しながら、学習率やバッチサイズなどのパラメータを自動的に調整するシステムを構築することができます。
- **異常検知**: 学習状況を監視し、異常な挙動 (例: loss の急激な増加) を検知するシステムを構築することができます。
- **A/B テスト**: 複数のモデルを同時に学習させ、生成される画像の品質を比較することで、最適なモデルを選択することができます。

#### トラブルシューティング

- **loss が減少しない**: 学習率が小さすぎるか、学習データに問題がある可能性があります。学習率を大きくしたり、学習データを見直したりしてみましょう。
- **loss が振動する**: 学習率が大きすぎる可能性があります。学習率を小さくしてみましょう。
- **過学習**: 学習ステップ数が多すぎるか、正則化が不足している可能性があります。学習ステップ数を減らしたり、正則化の手法を試したりしてみましょう。
- **生成される画像が崩れる**: 学習データに問題がある可能性があります。学習データを確認し、ノイズの多い画像や解像度の低い画像を取り除きましょう。
- **OOM (Out of Memory) エラー**: バッチサイズを小さくしたり、勾配累積の手法を試したりしてみましょう。

#### まとめと次のステップ

学習の実行と評価は、LoRA/Dreambooth の成功に不可欠なプロセスです。この章で紹介した手順とテクニックを参考に、学習状況を注意深く監視し、最適なモデルを作成してください。

次のステップとしては、以下のことを試してみるのがおすすめです。

- **異なる学習設定の試行**: 学習率やバッチサイズなど、様々な学習設定を試して、最適な設定を見つけましょう。
- **異なる正則化の手法の試行**: L1 正則化や L2 正則化など、様々な正則化の手法を試して、過学習を抑制しましょう。
- **異なるモデルの比較**: 複数のモデルを学習させ、生成される画像の品質を比較することで、最適なモデルを選択しましょう。
- **生成画像の改善**: 生成された画像に問題がある場合は、学習設定を見直したり、学習データを修正したりして、再度学習を行い、画像の品質を向上させましょう。
- **コミュニティへの参加**: LoRA/Dreambooth のコミュニティに参加し、他のユーザーと情報交換を行うことで、より深く理解を深めることができます。

これらのステップを踏むことで、あなたは LoRA/Dreambooth のエキスパートとなり、自分の創造性を最大限に引き出すことができるでしょう。
