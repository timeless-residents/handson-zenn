## 第 19 章: パフォーマンス最適化: スムーズなゲームプレイのために

ゲーム開発において、パフォーマンスはプレイヤーエクスペリエンスを大きく左右する重要な要素です。どんなに素晴らしいアイデアや美しいグラフィックも、カクカクした動きや頻繁なフリーズによって台無しになってしまいます。本章では、スムーズなゲームプレイを実現するためのパフォーマンス最適化について、基本的な考え方から具体的なテクニックまでを解説します。

### フレームレートの維持: 60fps を目指す

#### 概要と重要性

フレームレート (fps: frames per second) は、1 秒間に画面に表示される画像の枚数を表します。数値が高いほど、動きは滑らかに見え、プレイヤーは快適にゲームをプレイできます。一般的に、60fps を維持することが理想とされ、少なくとも 30fps を下回らないように心がけるべきです。

フレームレートが低いと、プレイヤーは操作の遅延を感じたり、画面のちらつきを感じたりして、ストレスを感じやすくなります。特にアクションゲームや VR ゲームなど、高速な反応が求められるゲームでは、フレームレートの維持が不可欠です。

#### 特徴と利点

60fps を維持することの利点は、以下のように多岐にわたります。

- **快適なゲーム体験:** 滑らかな動きは、没入感を高め、プレイヤーをゲームの世界に引き込みます。
- **操作性の向上:** 入力に対する反応が早くなるため、プレイヤーはより正確な操作を行えます。
- **疲労感の軽減:** 画面のちらつきが減ることで、長時間のプレイでも目の疲れを軽減できます。
- **高品質な印象:** スムーズな動きは、ゲームのクオリティを高く見せます。

#### 事前準備と前提条件

フレームレートを最適化するためには、以下のツールや知識が必要になります。

- **プロファイラ:** CPU や GPU の使用状況を可視化し、パフォーマンスボトルネックを特定するツール（Unity Profiler, Unreal Engine Profiler など）。
- **デバッガー:** コードの実行状況を追跡し、パフォーマンスに影響を与える箇所を特定するツール。
- **プラットフォームの知識:** ターゲットプラットフォーム (PC, モバイル, コンソール) のハードウェアスペックや制限を理解する。
- **グラフィックス API の知識:** DirectX, Vulkan, OpenGL などのグラフィックス API の基本的な知識。

#### 基本的な使い方

まずは、現在のフレームレートを計測し、目標値との差を確認します。多くのゲームエンジンには、フレームレートを表示する機能が標準で備わっています。

**Unity の場合:**

```csharp
using UnityEngine;

public class FPSCounter : MonoBehaviour
{
    float deltaTime = 0.0f;

    void Update()
    {
        deltaTime += (Time.deltaTime - deltaTime) * 0.1f;
    }

    void OnGUI()
    {
        int w = Screen.width, h = Screen.height;

        GUIStyle style = new GUIStyle();

        Rect rect = new Rect(0, 0, w, h * 2 / 100);
        style.alignment = TextAnchor.UpperLeft;
        style.fontSize = h * 2 / 100;
        style.normal.textColor = new Color(0.0f, 0.0f, 0.5f, 1.0f);
        float msec = deltaTime * 1000.0f;
        float fps = 1.0f / deltaTime;
        string text = string.Format("{0:0.0} ms ({1:0.} fps)", msec, fps);
        GUI.Label(rect, text, style);
    }
}
```

**Unreal Engine の場合:**

コンソールコマンド `stat fps` を入力することで、画面にフレームレートを表示できます。

フレームレートが低い場合は、プロファイラを使用してパフォーマンスボトルネックを特定します。プロファイラは、CPU 時間や GPU 時間を消費している箇所を特定し、最適化の優先順位をつけるのに役立ちます。

#### 実践的なテクニック

フレームレートを向上させるための実践的なテクニックをいくつか紹介します。

- **オブジェクトの数を減らす:** シーン内のオブジェクト数を減らすことで、CPU の負荷を軽減できます。不要なオブジェクトは削除したり、オブジェクトを結合したりすることで、描画負荷を減らすことができます。

- **描画距離を調整する:** カメラから遠いオブジェクトの描画距離を短くすることで、GPU の負荷を軽減できます。LOD (Level of Detail) 技術を使用することで、オブジェクトの距離に応じて詳細度を自動的に調整できます。

- **シャドウの品質を下げる:** シャドウは GPU に大きな負荷をかけるため、シャドウの品質を下げることでパフォーマンスを向上させることができます。シャドウを完全に無効にするのも有効な手段です。

- **テクスチャのサイズを最適化する:** テクスチャのサイズが大きいほど、GPU メモリを消費し、描画負荷も高くなります。テクスチャのサイズを必要最小限に抑えたり、テクスチャ圧縮を使用したりすることで、パフォーマンスを向上させることができます。

- **シェーダーを最適化する:** シェーダーは GPU 上で実行されるプログラムであり、複雑なシェーダーは GPU に大きな負荷をかけます。シェーダーを簡素化したり、不要な計算を削除したりすることで、パフォーマンスを向上させることができます。Shader Graph などのビジュアルツールを使うと比較的容易に最適化が可能です。

- **スクリプトの最適化:** スクリプトは CPU 上で実行されるプログラムであり、非効率なスクリプトは CPU に大きな負荷をかけます。スクリプトを最適化したり、不要な処理を削除したりすることで、パフォーマンスを向上させることができます。オブジェクトのキャッシュ、文字列処理の最適化、コルーチンの使用などが有効です。

- **バッチ処理:** 複数のオブジェクトをまとめて描画することで、描画回数を減らし、パフォーマンスを向上させることができます。特に、同じマテリアルを使用するオブジェクトは、バッチ処理に適しています。Unity であれば Static Batching, Dynamic Batching, SRP Batcher など様々なバッチ処理の方法があります。

#### 応用例とユースケース

**ケーススタディ:** 大量のオブジェクトが存在するオープンワールドゲーム

オープンワールドゲームでは、大量のオブジェクトを描画する必要があるため、パフォーマンスの最適化が非常に重要です。LOD 技術を使用して、オブジェクトの距離に応じて詳細度を自動的に調整したり、カリング技術を使用して、画面に表示されないオブジェクトを描画しないようにしたりすることで、パフォーマンスを向上させることができます。さらに、オブジェクトを分割して、ストリーミングロードすることで、メモリ使用量を抑えることも重要です。

**ケーススタディ:** モバイルゲーム

モバイルゲームは、PC ゲームに比べてハードウェアスペックが低いため、パフォーマンスの最適化がさらに重要です。テクスチャのサイズを小さくしたり、シャドウを無効にしたり、シェーダーを簡素化したりすることで、パフォーマンスを向上させることができます。また、モバイルデバイスに特化した最適化技術（GPU インスタンシング、テクスチャ圧縮など）を使用することも有効です。

#### トラブルシューティング

フレームレートが安定しない場合、以下の点を確認してください。

- **CPU 使用率:** CPU 使用率が 100%に近い場合、CPU がボトルネックになっている可能性があります。スクリプトの最適化やオブジェクト数の削減を検討してください。
- **GPU 使用率:** GPU 使用率が 100%に近い場合、GPU がボトルネックになっている可能性があります。テクスチャのサイズを小さくしたり、シャドウの品質を下げたり、シェーダーを簡素化したりすることで、GPU 負荷を軽減できます。
- **メモリ使用量:** メモリ使用量が上限に達している場合、メモリ不足が原因でパフォーマンスが低下している可能性があります。不要なオブジェクトを削除したり、テクスチャのサイズを小さくしたり、メモリリークを修正したりすることで、メモリ使用量を削減できます。
- **描画コール数:** 描画コール数が多いほど、CPU に負荷がかかります。バッチ処理を使用したり、オブジェクトを結合したりすることで、描画コール数を削減できます。

#### まとめと次のステップ

フレームレートの維持は、快適なゲームプレイを実現するための重要な要素です。プロファイラを使用してパフォーマンスボトルネックを特定し、オブジェクト数の削減、描画距離の調整、シャドウの品質調整、テクスチャのサイズ最適化、シェーダーの最適化、スクリプトの最適化、バッチ処理などのテクニックを駆使して、60fps を維持できるように努力しましょう。

次のステップとしては、より高度な最適化技術（GPU インスタンシング、テクスチャ圧縮、マルチスレッド処理など）について学習することをおすすめします。

### メモリ管理: 無駄なメモリ消費を抑える

#### 概要と重要性

メモリ管理は、ゲームの安定性とパフォーマンスに直接影響する重要な要素です。ゲームが使用できるメモリ容量には限りがあり、無駄なメモリ消費は、パフォーマンス低下、クラッシュ、最悪の場合、ゲームが起動しなくなる原因となります。

特に、モバイルゲームや VR ゲームなど、メモリ容量が限られているプラットフォームでは、メモリ管理が重要になります。

#### 特徴と利点

適切なメモリ管理を行うことの利点は、以下のように多岐にわたります。

- **安定性の向上:** メモリリークやメモリオーバーフローを防ぎ、クラッシュを減らすことができます。
- **パフォーマンスの向上:** 不要なメモリ割り当てや解放を減らし、ガベージコレクションの頻度を減らすことで、パフォーマンスを向上させることができます。
- **リソースの有効活用:** 限られたメモリ容量を有効活用し、より多くのオブジェクトやテクスチャを使用することができます。
- **プラットフォーム対応:** メモリ容量が限られているプラットフォームでも、快適にゲームをプレイすることができます。

#### 事前準備と前提条件

メモリ管理を行うためには、以下のツールや知識が必要になります。

- **プロファイラ:** メモリの使用状況を可視化し、メモリリークやメモリオーバーフローを特定するツール (Unity Profiler, Unreal Engine Profiler など)。
- **デバッガー:** コードの実行状況を追跡し、メモリ関連の問題を引き起こしている箇所を特定するツール。
- **ガベージコレクションの知識:** ガベージコレクションの仕組みを理解し、ガベージコレクションの頻度を減らすための対策を講じる。
- **メモリ管理の基本的な知識:** メモリの割り当てと解放、メモリリーク、メモリオーバーフローなどの基本的な知識。

#### 基本的な使い方

まずは、プロファイラを使用してメモリの使用状況を監視します。プロファイラは、メモリの使用量、メモリ割り当て回数、ガベージコレクションの頻度などを可視化し、メモリ関連の問題を特定するのに役立ちます。

**Unity の場合:**

Unity Profiler の Memory モジュールを使用することで、メモリの使用状況を詳細に分析できます。

**Unreal Engine の場合:**

Unreal Engine Profiler の Memory Insights を使用することで、メモリの使用状況を詳細に分析できます。

メモリリークが発生している場合は、デバッガーを使用してメモリリークの原因となっているコードを特定します。メモリリークは、オブジェクトが不要になった後もメモリ上に残ってしまう現象であり、メモリ使用量を増加させる原因となります。

#### 実践的なテクニック

メモリ消費を抑えるための実践的なテクニックをいくつか紹介します。

- **オブジェクトプール:** オブジェクトの生成と破棄を繰り返す処理は、メモリ割り当てと解放のオーバーヘッドが大きいため、オブジェクトプールを使用することで、パフォーマンスを向上させることができます。オブジェクトプールは、あらかじめ必要なオブジェクトを生成しておき、必要に応じて再利用する仕組みです。

- **テクスチャ圧縮:** テクスチャはメモリを大量に消費するため、テクスチャ圧縮を使用することで、メモリ使用量を削減することができます。テクスチャ圧縮には、DXT, ETC, ASTC などの様々なフォーマットがあります。

- **アセットバンドル:** アセットバンドルは、複数のアセットをまとめてロードできる仕組みであり、メモリ使用量を効率的に管理することができます。アセットバンドルを使用することで、必要なアセットだけをロードし、不要になったアセットをアンロードすることができます。

- **不要なオブジェクトの削除:** シーン内に不要なオブジェクトが存在する場合は、削除することでメモリ使用量を削減することができます。

- **データのシリアライズとデシリアライズ:** 大量のデータをメモリに保持する必要がある場合は、データをシリアライズしてファイルに保存し、必要な時にデシリアライズすることで、メモリ使用量を削減することができます。

- **文字列の扱い:** 文字列はメモリを消費しやすいデータ型であるため、文字列の生成を極力抑えるようにします。StringBuilder クラスを使用したり、文字列をキャッシュしたりするなどの対策が有効です。

- **構造体 (Struct) の利用:** クラス (Class) に比べて、構造体はメモリの割り当てが効率的です。大量のデータを扱う場合、構造体を使用することでメモリ使用量を削減できる場合があります。

#### 応用例とユースケース

**ケーススタディ:** モバイルゲームにおけるテクスチャ管理

モバイルゲームでは、テクスチャのメモリ使用量が制限されるため、テクスチャ圧縮やアトラス化などのテクニックを駆使して、メモリ使用量を最適化する必要があります。また、使用頻度の低いテクスチャは、メモリからアンロードすることで、メモリ使用量を削減することができます。

**ケーススタディ:** VR ゲームにおけるオブジェクトプール

VR ゲームでは、大量のオブジェクトを高速に生成・破棄する必要があるため、オブジェクトプールが非常に有効です。例えば、弾丸や爆発エフェクトなどのオブジェクトをオブジェクトプールで管理することで、パフォーマンスを向上させることができます。

#### トラブルシューティング

メモリリークが発生している場合、以下の点を確認してください。

- **イベントリスナーの解除漏れ:** イベントリスナーを登録した場合、不要になった時点で解除する必要があります。解除漏れは、メモリリークの原因となります。
- **非管理リソースの解放漏れ:** 非管理リソース (テクスチャ、メッシュ、オーディオなど) は、明示的に解放する必要があります。解放漏れは、メモリリークの原因となります。
- **循環参照:** オブジェクト同士が互いに参照しあっている場合、ガベージコレクションが正常に動作しない場合があります。循環参照を解消することで、メモリリークを防ぐことができます。

#### まとめと次のステップ

メモリ管理は、ゲームの安定性とパフォーマンスに不可欠な要素です。プロファイラを使用してメモリの使用状況を監視し、オブジェクトプール、テクスチャ圧縮、アセットバンドル、不要なオブジェクトの削除などのテクニックを駆使して、メモリ消費を最小限に抑えるように努力しましょう。

次のステップとしては、より高度なメモリ管理技術（メモリプール、カスタムアロケータなど）について学習することをおすすめします。

### モバイル対応: スマートフォンでも快適に動作させる

#### 概要と重要性

近年、モバイルゲーム市場は急速に拡大しており、スマートフォンで快適にゲームをプレイできることは、成功の鍵となります。モバイルデバイスは、PC やコンソールに比べてハードウェアスペックが低いため、パフォーマンスの最適化が非常に重要です。

モバイル対応では、フレームレートの維持、メモリ管理、バッテリー消費の抑制など、様々な課題に取り組む必要があります。

#### 特徴と利点

モバイル対応を行うことの利点は、以下のように多岐にわたります。

- **リーチの拡大:** より多くのユーザーにゲームをプレイしてもらうことができます。
- **収益の向上:** モバイルゲーム市場は巨大であり、収益向上の可能性が高まります。
- **競争力の強化:** 競合他社との差別化を図ることができます。
- **技術力の向上:** モバイルデバイスに特化した最適化技術を習得することができます。

#### 事前準備と前提条件

モバイル対応を行うためには、以下のツールや知識が必要になります。

- **モバイルデバイス:** 実際のモバイルデバイスでテストを行うことで、パフォーマンスや互換性の問題を特定できます。
- **開発環境:** Android Studio, Xcode などのモバイルデバイス向けの開発環境が必要です。
- **プロファイラ:** モバイルデバイスの CPU、GPU、メモリの使用状況を可視化するツールが必要です。
- **モバイルデバイスの知識:** Android, iOS などのモバイル OS の仕組みや制限を理解する必要があります。

#### 基本的な使い方

まずは、ターゲットとなるモバイルデバイスを選定し、開発環境を構築します。次に、ゲームをモバイルデバイスに移植し、動作確認を行います。

動作確認の際には、プロファイラを使用してパフォーマンスを監視し、ボトルネックを特定します。

#### 実践的なテクニック

モバイルデバイスで快適に動作させるための実践的なテクニックをいくつか紹介します。

- **低ポリゴンモデルの使用:** ポリゴン数の多いモデルは、GPU に大きな負荷をかけるため、低ポリゴンモデルを使用することで、パフォーマンスを向上させることができます。

- **ライトマップの使用:** リアルタイムライトは、GPU に大きな負荷をかけるため、ライトマップを使用することで、パフォーマンスを向上させることができます。ライトマップは、あらかじめシーンのライティングを計算してテクスチャに焼き込む技術です。

- **モバイルシェーダーの使用:** モバイルデバイスに最適化されたシェーダーを使用することで、パフォーマンスを向上させることができます。モバイルシェーダーは、より少ない計算量で高品質な描画を実現するように設計されています。

- **UI の最適化:** UI は、CPU に負荷をかける処理であるため、UI の最適化は重要です。UI を簡素化したり、不要な UI 要素を削除したりすることで、パフォーマンスを向上させることができます。

- **タッチ操作の最適化:** タッチ操作は、PC やコンソールの操作に比べて精度が低いため、タッチ操作を最適化する必要があります。タッチ判定領域を大きくしたり、操作説明を表示したりすることで、操作性を向上させることができます。

- **解像度の調整:** モバイルデバイスの解像度に合わせてゲームの解像度を調整することで、パフォーマンスを向上させることができます。

- **省電力モードの利用:** バッテリー消費を抑えるために、省電力モードを利用することを検討しましょう。省電力モードでは、フレームレートを制限したり、GPU のクロック周波数を下げたりすることで、バッテリー消費を抑えることができます。

- **ネットワーク通信の最適化:** ネットワーク通信は、バッテリーを消費する処理であるため、ネットワーク通信を最適化する必要があります。データの送信量を減らしたり、通信頻度を減らしたりすることで、バッテリー消費を抑えることができます。

#### 応用例とユースケース

**ケーススタディ:** バッテリー消費を抑えるための戦略

モバイルゲームでは、バッテリー消費が重要な課題となります。フレームレートを制限したり、GPU のクロック周波数を下げたりするだけでなく、不要な処理を停止したり、ネットワーク通信を最適化したりすることで、バッテリー消費を抑えることができます。例えば、プレイヤーが操作していない時には、ゲームの処理を一時停止したり、広告の表示頻度を減らしたりするなどの対策が有効です。

**ケーススタディ:** 低スペックデバイスへの対応

低スペックデバイスでも快適にゲームをプレイできるように、グラフィック品質を調整したり、解像度を下げたりするなどの対策が必要です。また、不要な機能を削除したり、処理を簡略化したりすることで、パフォーマンスを向上させることができます。

#### トラブルシューティング

モバイルデバイスでゲームが正常に動作しない場合、以下の点を確認してください。

- **デバイスの互換性:** ゲームがターゲットデバイスに対応しているかどうかを確認してください。
- **OS のバージョン:** ゲームがターゲット OS のバージョンに対応しているかどうかを確認してください。
- **メモリ容量:** デバイスのメモリ容量が十分であるかどうかを確認してください。
- **ストレージ容量:** デバイスのストレージ容量が十分であるかどうかを確認してください。
- **ネットワーク接続:** ネットワーク接続が安定しているかどうかを確認してください。

#### まとめと次のステップ

モバイル対応は、ゲームのリーチを拡大し、収益を向上させるための重要な要素です。低ポリゴンモデルの使用、ライトマップの使用、モバイルシェーダーの使用、UI の最適化、タッチ操作の最適化などのテクニックを駆使して、スマートフォンでも快適に動作するように努力しましょう。

次のステップとしては、モバイルデバイスに特化した最適化技術（GPU インスタンシング、テクスチャ圧縮、ASTC など）について学習することをおすすめします。また、モバイルデバイスのハードウェアスペックや制限について深く理解することも重要です。
