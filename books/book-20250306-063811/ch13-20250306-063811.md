## 第13章：ローカル5G：高速・低遅延ネットワーク構築

### 13.1 ローカル5Gの基礎：周波数帯、免許申請

#### 13.1.1 概要と重要性

ローカル5Gは、企業や自治体などが特定のエリア内で自営の5Gネットワークを構築・運用できるシステムです。従来のキャリアが提供する広域ネットワークとは異なり、自社のニーズに合わせて柔軟にネットワークを設計できるため、高速・低遅延といった5Gの特性を最大限に活かしたサービスを提供できます。製造業における工場の自動化、建設業における遠隔操作、医療分野における遠隔診療など、様々な分野で革新的な応用が期待されています。

#### 13.1.2 特徴と利点

*   **柔軟なネットワーク設計:** 企業のニーズに合わせて、カバーエリア、通信速度、遅延時間などを自由に設計できます。
*   **高いセキュリティ:** 自社ネットワーク内でデータ処理を行うため、外部からの攻撃リスクを低減できます。
*   **高速・低遅延:** 5Gの高速通信と低遅延性を最大限に活かしたアプリケーションを実現できます。
*   **コスト削減:** 特定エリアに特化したネットワーク構築により、既存の通信インフラにかかるコストを削減できます。
*   **地域活性化:** 地域独自のサービス提供や防災対策など、地域社会に貢献できます。

#### 13.1.3 事前準備と前提条件

ローカル5Gを導入する前に、以下の点を検討しておく必要があります。

*   **目的の明確化:** ローカル5Gを導入する目的を明確にし、どのようなサービスを提供したいのか、どのような課題を解決したいのかを具体的に定める必要があります。
*   **必要なエリアの選定:** ローカル5Gを構築するエリアを明確にします。エリアの広さ、建物の構造、電波環境などを考慮して最適なエリアを選定します。
*   **必要な帯域幅の検討:** 提供するサービスに必要な帯域幅を検討します。必要な帯域幅によって、使用する周波数帯やネットワーク構成が変わってきます。
*   **免許申請の準備:** ローカル5Gの免許申請には、技術的な知識や書類作成が必要になります。専門家の支援を得ることも検討しましょう。
*   **予算の確保:** ローカル5Gの構築には、基地局設備、ネットワーク構築費用、運用費用など、多額の費用がかかります。事前に予算を確保しておく必要があります。

#### 13.1.4 基本的な使い方

ローカル5Gの構築は、大きく分けて以下のステップで進められます。

1.  **免許申請:** 総務省にローカル5Gの免許を申請します。
2.  **基地局の設置:** 必要な場所に基地局を設置します。
3.  **ネットワーク構築:** 基地局とコアネットワークを接続し、ネットワークを構築します。
4.  **端末の接続:** 5G対応の端末をネットワークに接続します。
5.  **運用・保守:** ネットワークの運用・保守を行います。

#### 13.1.5 実践的なテクニック

**周波数帯の選択:**

ローカル5Gで使用できる周波数帯は、国によって異なります。日本では、主に以下の周波数帯が利用可能です。

*   **28.2 - 29.1 GHz:** 高速通信が可能ですが、伝搬距離が短いという特徴があります。
*   **4.6 - 4.9 GHz:** 伝搬距離が長く、広いエリアをカバーできます。
*   **230 MHz帯:** IoT用途向けの周波数帯です。

どの周波数帯を選択するかは、提供するサービスやエリアの状況によって異なります。一般的には、高速通信が必要な場合は28 GHz帯、広いエリアをカバーしたい場合は4.6 GHz帯を選択します。

**免許申請のポイント:**

ローカル5Gの免許申請は、技術的な知識や書類作成が必要になります。以下のポイントを押さえて申請を進めましょう。

*   **申請書類の準備:** 総務省のウェブサイトから申請書類をダウンロードし、必要事項を記入します。
*   **技術基準適合証明:** 使用する基地局設備が技術基準に適合していることを証明する必要があります。
*   **電波防護指針の遵守:** 電波が人体に与える影響を考慮し、電波防護指針を遵守する必要があります。
*   **申請代行サービスの利用:** 申請手続きに不安がある場合は、申請代行サービスを利用することもできます。

**例：総務省への免許申請に必要な書類（一部抜粋）**

*   免許申請書
*   無線局事項書
*   工事設計書
*   無線局の設置場所を示す図面
*   無線局の系統図
*   無線設備の仕様書
*   その他、総務省が指定する書類

#### 13.1.6 応用例とユースケース

*   **スマートファクトリー:** 工場内の無線化により、生産設備の稼働状況をリアルタイムに監視し、効率的な生産管理を実現します。
*   **建設現場の遠隔操作:** 建設機械を遠隔操作することで、危険な場所での作業を減らし、安全性を向上させます。
*   **医療分野における遠隔診療:** 高精細な映像伝送により、遠隔地にいる医師が患者の状態を正確に把握し、適切な診療を提供します。
*   **スマートシティ:** 街全体のデータを収集・分析し、交通渋滞の緩和、エネルギー効率の向上、防災対策の強化など、様々な課題を解決します。
*   **エンターテインメント:** VR/ARを活用した臨場感あふれるコンテンツを提供し、新しいエンターテインメント体験を創出します。

#### 13.1.7 トラブルシューティング

*   **電波が届かない:** 基地局の設置場所やアンテナの向きを見直す必要があります。また、電波干渉の原因となる機器がないか確認しましょう。
*   **通信速度が遅い:** 基地局の容量が不足している可能性があります。基地局の増設や周波数帯の変更を検討しましょう。
*   **端末がネットワークに接続できない:** 端末の設定が正しいか確認しましょう。また、基地局との距離が遠すぎる可能性もあります。
*   **ネットワークが不安定:** 基地局やコアネットワークに障害が発生している可能性があります。ログを確認し、原因を特定しましょう。

### 13.2 ローカル5Gネットワークの設計と構築

#### 13.2.1 概要と重要性

ローカル5Gネットワークの設計と構築は、その後の運用効率やパフォーマンスに大きく影響する重要なプロセスです。単に機器を設置するだけでなく、綿密な計画に基づき、エリアの特性、必要な帯域幅、セキュリティ要件などを考慮した最適なネットワークを構築する必要があります。

#### 13.2.2 特徴と利点

*   **柔軟なトポロジー:** スター型、メッシュ型、ハイブリッド型など、様々なトポロジーを選択できます。
*   **QoS (Quality of Service) の設定:** アプリケーションごとに優先度を設定し、重要なトラフィックを優先的に処理できます。
*   **セキュリティ対策:** ファイアウォール、VPN、アクセス制御など、様々なセキュリティ対策を講じることができます。
*   **ネットワーク監視:** ネットワークの状態をリアルタイムに監視し、障害発生時に迅速に対応できます。
*   **容易な拡張性:** 将来的な需要の増加に対応できるよう、ネットワークを容易に拡張できます。

#### 13.2.3 事前準備と前提条件

*   **ネットワーク要件の定義:** 必要な通信速度、遅延時間、セキュリティレベルなどを明確に定義します。
*   **エリア調査:** 電波環境、建物の構造、障害物の有無などを調査します。
*   **機器選定:** 基地局、コアネットワーク機器、端末などを選定します。
*   **ネットワーク設計:** ネットワークトポロジー、周波数帯、QoS設定などを設計します。
*   **設置場所の確保:** 基地局やコアネットワーク機器の設置場所を確保します。
*   **電力供給の確保:** 機器に必要な電力を供給できる環境を整備します。

#### 13.2.4 基本的な使い方

ローカル5Gネットワークの構築は、以下のステップで進められます。

1.  **ネットワーク設計:** ネットワーク要件に基づいて、ネットワークトポロジー、周波数帯、QoS設定などを設計します。
2.  **機器設置:** 設計に基づいて、基地局、コアネットワーク機器、端末などを設置します。
3.  **機器設定:** 機器の初期設定を行い、ネットワークに接続します。
4.  **ネットワーク検証:** ネットワークの動作確認を行い、パフォーマンスを測定します。
5.  **セキュリティ設定:** ファイアウォール、VPN、アクセス制御などのセキュリティ設定を行います。
6.  **運用開始:** ネットワークの運用を開始します。

#### 13.2.5 実践的なテクニック

**基地局の設置場所の選定:**

基地局の設置場所は、電波の届きやすさ、設置の容易さ、メンテナンス性などを考慮して選定する必要があります。以下の点に注意しましょう。

*   **見通しの良い場所:** 障害物が少なく、電波が届きやすい場所を選びます。
*   **高さ:** 高い場所に設置することで、広いエリアをカバーできます。
*   **電力供給:** 機器に必要な電力を供給できる場所を選びます。
*   **メンテナンス性:** メンテナンスが容易な場所を選びます。
*   **景観:** 周囲の景観に配慮した設置方法を検討します。

**ネットワークトポロジーの選定:**

ネットワークトポロジーは、ネットワークの信頼性、拡張性、コストなどを考慮して選定する必要があります。

*   **スター型:** シンプルな構成で、コストを抑えることができます。ただし、中央の基地局に障害が発生すると、ネットワーク全体が停止する可能性があります。
*   **メッシュ型:** 複数の経路で接続されているため、信頼性が高いネットワークを構築できます。ただし、コストが高くなる傾向があります。
*   **ハイブリッド型:** スター型とメッシュ型の組み合わせで、それぞれの利点を活かすことができます。

**QoS (Quality of Service) の設定:**

QoSは、アプリケーションごとに優先度を設定し、重要なトラフィックを優先的に処理する技術です。以下のパラメータを設定できます。

*   **帯域幅:** アプリケーションに割り当てる帯域幅を設定します。
*   **遅延:** アプリケーションに許容される遅延時間を設定します。
*   **優先度:** アプリケーションの優先度を設定します。

**例：LinuxサーバでのQoS設定（tcコマンド）**

```bash
# eth0インターフェースにQoSを設定
tc qdisc add dev eth0 root handle 1: htb default 12

# クラスを作成 (1:1 はルートクラス)
tc class add dev eth0 parent 1: classid 1:1 htb rate 1000mbit

# クラスを作成 (1:10, 優先度高)
tc class add dev eth0 parent 1:1 classid 1:10 htb rate 800mbit ceil 1000mbit prio 0

# クラスを作成 (1:11, 優先度中)
tc class add dev eth0 parent 1:1 classid 1:11 htb rate 100mbit ceil 500mbit prio 1

# クラスを作成 (1:12, 優先度低)
tc class add dev eth0 parent 1:1 classid 1:12 htb rate 10mbit ceil 100mbit prio 2

# フィルタを設定 (ポート80宛のトラフィックを優先度高のクラスへ)
tc filter add dev eth0 protocol ip parent 1:0 prio 1 u32 match ip dport 80 0xffff flowid 1:10

# 設定確認
tc qdisc show dev eth0
tc class show dev eth0
tc filter show dev eth0
```

**セキュリティ対策:**

ローカル5Gネットワークのセキュリティ対策は、以下のレイヤーで実施する必要があります。

*   **物理層:** 基地局やコアネットワーク機器への物理的なアクセスを制限します。
*   **ネットワーク層:** ファイアウォール、VPN、アクセス制御など、ネットワーク層でのセキュリティ対策を講じます。
*   **アプリケーション層:** アプリケーションの脆弱性を対策し、安全な通信プロトコルを使用します。

#### 13.2.6 応用例とユースケース

*   **スマートオフィス:** オフィス内の無線化により、従業員の生産性を向上させます。

#### 13.2.7 トラブルシューティング

*   **ネットワークに接続できない:** 端末の設定、基地局の状態、ネットワーク設定などを確認します。
*   **通信速度が遅い:** 基地局の負荷、電波干渉、QoS設定などを確認します。
*   **セキュリティの問題:** ファイアウォールの設定、VPNの接続、アクセス制御などを確認します。
*   **ネットワークが不安定:** 基地局の障害、コアネットワーク機器の障害、ネットワーク設定の誤りなどを確認します。

### 13.3 ローカル5Gを活用したアプリケーション

#### 13.3.1 概要と重要性

ローカル5Gの真価は、その高速・低遅延という特性を活かした様々なアプリケーションによって発揮されます。単なる高速なWi-Fiの代替ではなく、これまで技術的な制約で実現できなかった高度なサービスを可能にするポテンシャルを秘めています。

#### 13.3.2 特徴と利点

*   **リアルタイム性:** 低遅延通信により、遠隔操作や制御、リアルタイム映像伝送などが可能になります。
*   **高信頼性:** 安定した通信品質により、ミッションクリティカルなアプリケーションを実現できます。
*   **大容量:** 高速通信により、高精細な映像や大量のデータを伝送できます。
*   **セキュリティ:** 自社ネットワーク内でデータ処理を行うため、セキュリティリスクを低減できます。
*   **柔軟性:** 様々なデバイスやアプリケーションに対応できます。

#### 13.3.3 事前準備と前提条件

*   **アプリケーションの要件定義:** 必要な通信速度、遅延時間、セキュリティレベルなどを明確に定義します。
*   **デバイスの選定:** アプリケーションに必要な機能を備えたデバイスを選定します。
*   **ネットワーク環境の整備:** アプリケーションに必要なネットワーク環境を整備します。
*   **開発環境の構築:** アプリケーションの開発に必要な環境を構築します。
*   **テスト環境の構築:** アプリケーションのテストに必要な環境を構築します。

#### 13.3.4 基本的な使い方

ローカル5Gを活用したアプリケーションの開発は、以下のステップで進められます。

1.  **要件定義:** アプリケーションの要件を明確に定義します。
2.  **設計:** アプリケーションの設計を行います。
3.  **開発:** アプリケーションを開発します。
4.  **テスト:** アプリケーションのテストを行います。
5.  **導入:** アプリケーションを導入します。
6.  **運用:** アプリケーションの運用を行います。

#### 13.3.5 実践的なテクニック

**エッジコンピューティングの活用:**

ローカル5Gネットワークのエッジ部分にサーバーを配置することで、データ処理を分散し、遅延をさらに低減できます。

**例： Kubernetes を使ったエッジコンピューティング環境の構築**

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: edge-application
spec:
  replicas: 1
  selector:
    matchLabels:
      app: edge-application
  template:
    metadata:
      labels:
        app: edge-application
    spec:
      nodeSelector: # 特定のエッジノードにデプロイ
        node-role.kubernetes.io/edge: "true"
      containers:
      - name: edge-application
        image: your-edge-application-image:latest
        ports:
        - containerPort: 8080

---
apiVersion: v1
kind: Service
metadata:
  name: edge-application-service
spec:
  selector:
    app: edge-application
  ports:
  - protocol: TCP
    port: 80
    targetPort: 8080
  type: LoadBalancer # 必要に応じて NodePort などに変更
```

**ネットワークスライシングの活用:**

ネットワークを複数の論理的なネットワークに分割することで、アプリケーションごとに異なる要件に対応できます。

**例： ネットワークスライシングによるQoS制御**

*   **スライス1:** リアルタイム制御アプリケーション向け (低遅延、高信頼性)
*   **スライス2:** 大容量データ伝送アプリケーション向け (高帯域幅)
*   **スライス3:** IoTデバイス向け (低消費電力)

**セキュリティ対策:**

アプリケーションのセキュリティ対策は、以下の点に注意する必要があります。

*   **認証・認可:** ユーザー認証、デバイス認証、アクセス制御などを実装します。
*   **暗号化:** 通信データを暗号化します。
*   **脆弱性対策:** アプリケーションの脆弱性を対策します。
*   **ログ監視:** アプリケーションのログを監視し、不正なアクセスを検知します。

#### 13.3.6 応用例とユースケース

*   **自動運転:** 車両間のリアルタイムな情報共有により、安全な自動運転を実現します。
*   **遠隔手術:** 高精細な映像と低遅延通信により、遠隔地にいる医師が手術を支援します。
*   **VR/ARエンターテインメント:** 臨場感あふれるVR/ARコンテンツを提供し、新しいエンターテインメント体験を創出します。
*   **スマート農業:** ドローンやセンサーから収集したデータを分析し、効率的な農業を支援します。
*   **建設現場の安全管理:** 作業員のバイタルデータを収集し、熱中症や事故を防止します。

#### 13.3.7 トラブルシューティング

*   **アプリケーションが動作しない:** ネットワーク接続、デバイスの設定、アプリケーションの設定などを確認します。
*   **通信速度が遅い:** ネットワークの負荷、QoS設定、デバイスの性能などを確認します。
*   **セキュリティの問題:** 認証・認可の設定、暗号化の設定、脆弱性対策などを確認します。
*   **アプリケーションが不安定:** ネットワークの障害、デバイスの障害、アプリケーションのバグなどを確認します。

#### 13.3.8 まとめと次のステップ

このセクションでは、ローカル5Gを活用した具体的なアプリケーションについて解説しました。ローカル5Gは、様々な分野で革新的なサービスを実現する可能性を秘めています。ぜひ、ローカル5Gを活用して、新しいビジネスを創出してください。そして、常に最新の技術動向を追いかけ、より高度なアプリケーションの開発に挑戦していきましょう。
