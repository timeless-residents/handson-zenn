## 第6章：リアルタイム制御：フィードバック制御、PID制御、状態空間モデル

### 6.1 自動制御の基礎：開ループ制御、閉ループ制御

#### 概要と重要性

自動制御は、人間が介在せずにシステムを自動的に目標の状態に保つ技術です。現代社会において、工場の生産ラインからエアコン、自動車の自動運転まで、あらゆる分野で不可欠な役割を果たしています。自動制御を理解することは、ロボット工学、組み込みシステム開発、産業オートメーションといった分野で活躍するための基礎となります。

制御方法には大きく分けて、開ループ制御と閉ループ制御（フィードバック制御）の2種類があります。それぞれの特徴を理解し、適切な制御方式を選択することが、安定したシステム構築の鍵となります。

#### 特徴と利点

*   **開ループ制御:**
    *   特徴：制御対象の状態を監視せず、あらかじめ設定されたプログラムに基づいて操作量を決定します。
    *   利点：構造が簡単で低コスト。応答速度が速い。
    *   欠点：外乱や制御対象の変動に弱い。目標値からのずれが生じやすい。

*   **閉ループ制御 (フィードバック制御):**
    *   特徴：制御対象の状態をセンサーで検出し、目標値との差（偏差）に基づいて操作量を決定します。
    *   利点：外乱や制御対象の変動に強く、目標値を正確に維持できる。
    *   欠点：構造が複雑で高コスト。応答速度が遅くなることがある。不安定になる可能性がある。

#### 事前準備と前提条件

*   基本的なプログラミングスキル（Pythonなど）
*   簡単な電気回路の知識
*   制御対象となるシステムの理解 (例: DCモーターの特性)

#### 基本的な使い方

**1. 開ループ制御の例：タイマー制御**

例として、単純なタイマー制御を考えてみましょう。LEDを5秒間点灯させ、その後消灯させるプログラムです。

```python
import time
import RPi.GPIO as GPIO # Raspberry Piの場合

# GPIOピンの設定
led_pin = 17
GPIO.setmode(GPIO.BCM)
GPIO.setup(led_pin, GPIO.OUT)

try:
    GPIO.output(led_pin, GPIO.HIGH) # LED点灯
    time.sleep(5) # 5秒待機
    GPIO.output(led_pin, GPIO.LOW) # LED消灯
    print("LED制御完了")

except KeyboardInterrupt:
    print("プログラム停止")

finally:
    GPIO.cleanup()
```

この例では、LEDの状態を監視していません。もし、LEDが故障して点灯しなかったとしても、プログラムは5秒後に消灯処理を行います。

**2. 閉ループ制御の例：温度制御**

より複雑な例として、フィードバック制御を用いた温度制御を考えてみましょう。ここでは、理想的な温度を目標値として、ヒーターの出力を調整して目標温度を維持します。

```python
# (簡略化された) フィードバック制御の例
target_temperature = 30 # 目標温度 (℃)
current_temperature = 25 # 現在温度 (℃) (センサーから取得)
heater_power = 0 # ヒーター出力 (0-100%)

kp = 0.5 # 比例ゲイン

while True:
    # センサーから現在の温度を取得 (実際にはセンサー読み取りの処理が必要)
    # current_temperature = read_temperature_sensor()  # センサーからの読み取り関数を別途定義

    error = target_temperature - current_temperature # 偏差

    heater_power = kp * error # 比例制御

    # ヒーター出力の制限
    heater_power = max(0, min(heater_power, 100))

    print(f"現在温度: {current_temperature:.2f}℃, ヒーター出力: {heater_power:.2f}%")

    # ヒーターへの出力処理 (PWM制御など)
    # set_heater_power(heater_power)  # ヒーター出力制御関数を別途定義

    time.sleep(1) # 1秒待機
```

この例では、現在の温度をセンサーから読み取り、目標温度との偏差を計算します。その偏差に比例ゲインを掛けた値をヒーターの出力として調整します。

#### 実践的なテクニック

*   **センサーの選定:** 制御対象の状態を正確に検出できるセンサーを選定することが重要です。温度、圧力、流量、位置など、制御対象に適したセンサーを選択する必要があります。
*   **アクチュエータの選定:** 操作量を正確に制御できるアクチュエータを選定することが重要です。モーター、バルブ、ヒーターなど、制御対象に適したアクチュエータを選択する必要があります。
*   **ゲイン調整:** フィードバック制御におけるゲイン調整は、システムの安定性と応答性を決定する重要な要素です。ゲインが高すぎるとシステムが不安定になり、ゲインが低すぎると応答が遅くなります。

#### 応用例とユースケース

*   **産業用ロボット:** ロボットアームの関節の角度を制御し、正確な動作を実現します。
*   **エアコン:** 室温を目標温度に維持するために、コンプレッサーの出力を調整します。
*   **自動車のクルーズコントロール:** 車速を一定に保つために、エンジンのスロットル開度を調整します。
*   **ドローン:** 姿勢を安定させるために、モーターの回転数を制御します。

#### トラブルシューティング

*   **システムが不安定になる:** ゲインが高すぎる可能性があります。ゲインを下げてみてください。
*   **応答が遅い:** ゲインが低すぎる可能性があります。ゲインを上げてみてください。
*   **目標値からのずれが大きい:** センサーの精度が低い可能性があります。より精度の高いセンサーを使用するか、キャリブレーションを行ってください。

### 6.2 状態空間モデルによる高度な制御

#### 概要と重要性

状態空間モデルは、システムの動的な挙動を数学的に表現するための強力なツールです。古典的なPID制御に比べて、多入力多出力システムや複雑な非線形システムを扱うのに適しています。状態空間モデルを用いることで、システムの安定性解析、最適制御、オブザーバ設計などが可能になり、より高度な制御システムを構築できます。

#### 特徴と利点

*   **多変数システム:** 複数の入力と出力を持つシステムを容易に扱えます。
*   **内部状態の表現:** システムの内部状態を明示的に表現できるため、システムの詳細な理解に役立ちます。
*   **線形代数の活用:** 線形代数の理論に基づいているため、数学的な解析が容易です。
*   **最適制御:** 最適な制御入力を設計するための理論的な基盤を提供します。
*   **オブザーバ設計:** センサーから直接計測できない状態を推定するためのオブザーバを設計できます。

#### 事前準備と前提条件

*   線形代数の基礎知識（行列、ベクトル、固有値、固有ベクトルなど）
*   微分方程式の基礎知識
*   制御工学の基礎知識（伝達関数、周波数応答など）
*   プログラミングスキル（MATLAB、Pythonなど）

#### 基本的な使い方

**1. 状態空間モデルの表現**

状態空間モデルは、以下の2つの式で表現されます。

```
x'(t) = Ax(t) + Bu(t)  (状態方程式)
y(t) = Cx(t) + Du(t)  (出力方程式)
```

ここで、

*   `x(t)`: 状態ベクトル（システムの内部状態を表す）
*   `u(t)`: 入力ベクトル（システムへの操作量）
*   `y(t)`: 出力ベクトル（センサーで計測される量）
*   `A`: システム行列（状態の遷移を表す）
*   `B`: 入力行列（入力が状態に与える影響を表す）
*   `C`: 出力行列（状態が出力に与える影響を表す）
*   `D`: 直達行列（入力が直接出力に与える影響を表す）
*   `x'(t)`: 状態ベクトルの時間微分

**2. 状態空間モデルの作成例：DCモーター**

DCモーターの状態空間モデルを作成する例を示します。

*   入力：電圧 `V`
*   出力：回転速度 `ω`
*   状態変数：電流 `i`, 回転速度 `ω`

DCモーターの物理モデルから、以下の微分方程式が得られます。

```
L * di/dt = -R * i - K_e * ω + V
J * dω/dt = K_t * i - b * ω
```

ここで、

*   `L`: インダクタンス
*   `R`: 抵抗
*   `K_e`: 逆起電力定数
*   `J`: 慣性モーメント
*   `K_t`: トルク定数
*   `b`: 粘性摩擦係数

これらの式を状態空間モデルの形式に変換すると、以下のようになります。

```
x(t) = [i(t); ω(t)]  (状態ベクトル)
u(t) = V(t)  (入力)
y(t) = ω(t)  (出力)

A = [[-R/L, -K_e/L]; [K_t/J, -b/J]]  (システム行列)
B = [[1/L]; [0]]  (入力行列)
C = [[0, 1]]  (出力行列)
D = [[0]]  (直達行列)
```

**3. Pythonによる状態空間モデルの表現**

Pythonで状態空間モデルを表現するには、NumPyなどの数値計算ライブラリを使用します。

```python
import numpy as np
from scipy.signal import lti, step

# DCモーターのパラメータ (例)
L = 0.1  # インダクタンス (H)
R = 1    # 抵抗 (Ω)
Ke = 0.01 # 逆起電力定数 (V/(rad/s))
J = 0.01 # 慣性モーメント (kg*m^2)
Kt = 0.01 # トルク定数 (Nm/A)
b = 0.001 # 粘性摩擦係数 (Nms)

# 状態空間モデルの行列を定義
A = np.array([[-R/L, -Ke/L], [Kt/J, -b/J]])
B = np.array([[1/L], [0]])
C = np.array([[0, 1]])
D = np.array([[0]])

# scipy.signal.ltiを使って状態空間モデルを定義
system = lti(A, B, C, D)

# ステップ応答を計算
t, y = step(system)

# 結果をプロット (matplotlibが必要)
import matplotlib.pyplot as plt
plt.plot(t, y)
plt.xlabel("時間 (秒)")
plt.ylabel("回転速度 (rad/s)")
plt.title("DCモーターのステップ応答")
plt.grid(True)
plt.show()
```

このコードは、DCモーターの状態空間モデルを定義し、ステップ応答を計算してプロットします。`scipy.signal.lti`関数を使うことで、簡単に状態空間モデルを扱うことができます。

#### 実践的なテクニック

*   **可制御性と可観測性:** システムが制御可能であるか（全ての状態を制御できるか）、観測可能であるか（全ての状態を観測できるか）を事前に確認することが重要です。可制御性、可観測性の判別には、それぞれ可制御性行列、可観測性行列を用います。
*   **極配置法:** システムの極（固有値）を適切な位置に配置することで、システムの安定性と応答性を調整できます。
*   **最適レギュレータ（LQR):** システムの状態を目標値に維持するための最適な制御入力を計算します。LQRでは、状態の偏差と制御入力に対するペナルティを設定し、コスト関数を最小化する制御入力を求めます。
*   **カルマンフィルタ:** ノイズを含むセンサーデータから、システムの状態を最適に推定します。

#### 応用例とユースケース

*   **航空機の自動操縦:** 航空機の姿勢、速度、高度を制御するために、状態空間モデルとカルマンフィルタが使用されます。
*   **化学プラントのプロセス制御:** 反応器の温度、圧力、流量などを制御するために、状態空間モデルと最適レギュレータが使用されます。
*   **電力系統の安定化制御:** 発電機の出力、電圧、周波数を制御するために、状態空間モデルとモデル予測制御が使用されます。
*   **ロボットの軌道追従制御:** ロボットが目標軌道を正確に追従するように、状態空間モデルと極配置法が使用されます。

#### トラブルシューティング

*   **システムが不安定になる:** 極配置が不適切である可能性があります。極を左半平面に配置するように調整してください。
*   **制御入力が大きすぎる:** LQRのペナルティが不適切である可能性があります。制御入力に対するペナルティを大きくしてください。
*   **状態推定の精度が低い:** カルマンフィルタのノイズ共分散が不適切である可能性があります。ノイズ共分散を調整してください。
*   **モデルと実際のシステムが一致しない:** モデルのパラメータを調整するか、より複雑なモデルを使用してください。

### 6.3 アクチュエータの選定と制御：モーター、バルブ、ヒーター

#### 概要と重要性

アクチュエータは、制御システムからの指令を受けて、物理的な動作を行うためのデバイスです。モーター、バルブ、ヒーターなど、様々な種類のアクチュエータが存在し、制御対象や用途に応じて適切なアクチュエータを選択する必要があります。アクチュエータの選定と制御は、制御システムの性能を大きく左右する重要な要素です。

#### 特徴と利点

*   **モーター:** 回転運動を生成するために使用されます。DCモーター、ACモーター、ステッピングモーターなど、様々な種類があります。
*   **バルブ:** 液体や気体の流量を制御するために使用されます。電磁弁、比例制御弁など、様々な種類があります。
*   **ヒーター:** 熱エネルギーを生成するために使用されます。抵抗ヒーター、熱電素子など、様々な種類があります。

#### 事前準備と前提条件

*   電気回路の基礎知識
*   制御対象となるシステムの理解
*   アクチュエータのデータシートの読解力

#### 基本的な使い方

**1. モーターの選定と制御**

*   **DCモーター:** 比較的安価で制御が容易です。PWM制御によって回転速度を制御できます。
*   **ACモーター:** 高効率で長寿命です。インバーター制御によって回転速度を制御できます。
*   **ステッピングモーター:** 正確な位置決めが可能です。パルス信号によって回転角度を制御できます。

**DCモーターのPWM制御例 (Arduino)**

```arduino
// モーター制御ピン
int motorPin = 9;

// PWMデューティー比 (0-255)
int pwmValue = 128;

void setup() {
  // モーターピンを出力に設定
  pinMode(motorPin, OUTPUT);
}

void loop() {
  // PWM信号を出力
  analogWrite(motorPin, pwmValue);
}
```

**2. バルブの選定と制御**

*   **電磁弁:** ON/OFF制御に用いられます。ソレノイドによって弁を開閉します。
*   **比例制御弁:** 流量を連続的に制御できます。入力信号に応じて弁の開度を調整します。

**比例制御弁の制御例 (Python + Arduino)**

```python
# Python (PC側)
import serial
import time

# シリアルポートの設定
ser = serial.Serial('COM3', 9600)  # シリアルポート名は環境に合わせて変更

# 弁の開度 (0-255)
valve_opening = 128

# Arduinoに弁の開度を送信
ser.write(str(valve_opening).encode())

time.sleep(1)  # 1秒待機

ser.close()

```

```arduino
// Arduino (マイコン側)
int valvePin = 9; // 弁の制御ピン

void setup() {
  Serial.begin(9600);
  pinMode(valvePin, OUTPUT);
}

void loop() {
  if (Serial.available() > 0) {
    int valveValue = Serial.parseInt(); // 弁の開度を受信
    analogWrite(valvePin, valveValue);   // PWM信号を出力
  }
}
```

**3. ヒーターの選定と制御**

*   **抵抗ヒーター:** 安価でシンプルな構造です。ON/OFF制御またはPWM制御によって出力を制御できます。
*   **熱電素子:** 正確な温度制御が可能です。電流の方向によって加熱または冷却を行います。

**抵抗ヒーターのON/OFF制御例 (Raspberry Pi)**

```python
import RPi.GPIO as GPIO
import time

# ヒーター制御ピン
heater_pin = 17

GPIO.setmode(GPIO.BCM)
GPIO.setup(heater_pin, GPIO.OUT)

try:
    GPIO.output(heater_pin, GPIO.HIGH) # ヒーターON
    time.sleep(10) # 10秒間加熱
    GPIO.output(heater_pin, GPIO.LOW) # ヒーターOFF
    print("ヒーター制御完了")

except KeyboardInterrupt:
    print("プログラム停止")

finally:
    GPIO.cleanup()
```

#### 実践的なテクニック

*   **アクチュエータのデータシートの確認:** 定格電圧、電流、トルク、応答速度などの仕様を確認し、制御対象に適したアクチュエータを選択してください。
*   **アクチュエータの駆動回路の設計:** アクチュエータを駆動するための適切な回路を設計してください。モータードライバ、バルブドライバ、ヒータードライバなどを使用します。
*   **フィードバック制御の導入:** センサーからのフィードバック情報を用いて、アクチュエータの動作を制御することで、より高精度な制御を実現できます。
*   **安全対策:** アクチュエータの故障や誤動作による事故を防ぐために、安全回路や保護機能を設けてください。

#### 応用例とユースケース

*   **3Dプリンター:** ステッピングモーターを用いて、ヘッドの位置決めとフィラメントの送り出しを行います。
*   **自動販売機:** 電磁弁を用いて、飲料や食品の払い出しを行います。
*   **恒温槽:** 抵抗ヒーターと熱電素子を用いて、槽内の温度を一定に保ちます。
*   **スマートホーム:** 照明、エアコン、ドアロックなどをモーター、バルブ、ヒーターなどを組み合わせて制御します。

#### トラブルシューティング

*   **アクチュエータが動作しない:** 電源供給、配線、制御信号などを確認してください。
*   **アクチュエータの動作が不安定:** 駆動回路のパラメータ、制御ゲインなどを調整してください。
*   **アクチュエータが過熱する:** 定格電流、負荷などを確認してください。冷却ファンなどを設置してください。
*   **アクチュエータから異音が発生する:** 部品の摩耗、異物の混入などを確認してください。
