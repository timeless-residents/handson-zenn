## 第9章：モデルの読み込み - GLTF, OBJ, FBX

この章では、3Dグラフィックスの世界で広く利用されている3つの主要なモデル形式、GLTF、OBJ、FBXに焦点を当て、それぞれの形式の特性、読み込み方法、およびThree.jsでの実践的な利用方法を解説します。3Dモデルを効果的に活用することで、Webアプリケーションの表現力を飛躍的に向上させることができます。

### GLTF (GL Transmission Format)

#### 概要と重要性

GLTF（GL Transmission Format）は、3Dシーンやモデルを効率的に伝送するために設計されたファイル形式です。その効率性と拡張性から、現代の3DグラフィックスWebアプリケーションにおいてデファクトスタンダードになりつつあります。

#### 特徴と利点

*   **効率的なデータ転送:** バイナリ形式やデータ圧縮をサポートし、ファイルサイズを小さく保つことができます。
*   **ランタイム最適化:** WebGLなどのリアルタイムレンダリングエンジンとの相性が良く、高速な読み込みとレンダリングが可能です。
*   **拡張性:** PBR（物理ベースレンダリング）マテリアル、アニメーション、スキンメッシュ、その他の高度な機能に対応しています。
*   **幅広い互換性:** 多くの3Dモデリングソフトウェアやゲームエンジンでサポートされています。

#### 事前準備と前提条件

Three.jsでGLTFモデルを読み込むには、`GLTFLoader`を使用します。まずはThree.jsのライブラリと`GLTFLoader`をプロジェクトにインポートする必要があります。

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.157.0/build/three.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.157.0/examples/js/loaders/GLTFLoader.js"></script>
```

#### 基本的な使い方

`GLTFLoader`を使用してGLTFモデルを読み込む基本的なコードは以下の通りです。

```javascript
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

// シーン、カメラ、レンダラーの作成 (他の章で説明されていることを前提)
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// GLTFLoaderのインスタンスを作成
const loader = new GLTFLoader();

// GLTFモデルを読み込む
loader.load(
    'path/to/your/model.gltf', // モデルのパス
    (gltf) => {
        // モデルがロードされた時の処理
        scene.add(gltf.scene); // シーンにモデルを追加
        // 必要に応じて、カメラの位置を調整
        camera.position.z = 5;

        // アニメーションループ
        function animate() {
            requestAnimationFrame(animate);
            renderer.render(scene, camera);
        }
        animate();
    },
    (xhr) => {
        // ロード状況を表示 (任意)
        console.log((xhr.loaded / xhr.total * 100) + '% loaded');
    },
    (error) => {
        // エラー処理
        console.error('An error happened', error);
    }
);
```

**コードの説明:**

*   `GLTFLoader`のインスタンスを作成します。
*   `loader.load()`メソッドを使用して、GLTFモデルを非同期で読み込みます。
*   コールバック関数の中で、ロードされたモデル（`gltf.scene`）をシーンに追加します。
*   `xhr`コールバックは、ロードの進行状況を表示するために使用できます。
*   `error`コールバックは、エラーが発生した場合に処理を行います。

#### マテリアルとテクスチャの適用

GLTF形式は、マテリアルとテクスチャの情報をモデルデータ自体に含めることができます。多くの場合、特別な設定なしに、ロードした時点でモデルにマテリアルとテクスチャが自動的に適用されます。

ただし、必要に応じてマテリアルを調整することも可能です。`gltf.scene`の各メッシュに対して、`material`プロパティを操作することで、マテリアルの色、テクスチャ、その他のプロパティを変更できます。

```javascript
gltf.scene.traverse((child) => {
    if (child.isMesh) {
        // マテリアルの色を変更
        child.material.color.setHex(0xff0000); // 赤色に変更

        // テクスチャを読み込んで適用する場合
        const textureLoader = new THREE.TextureLoader();
        textureLoader.load('path/to/your/texture.jpg', (texture) => {
            child.material.map = texture;
            child.material.needsUpdate = true; // マテリアルの更新を通知
        });
    }
});
```

#### 実践的なテクニック

*   **環境光の設定:** GLTFモデルの見た目は、シーンの照明に大きく影響されます。アンビエントライトや指向性ライトを適切に設定することで、モデルの質感をよりリアルに表現できます。
*   **影の有効化:** レンダラーで影を有効にし、ライトとモデルの両方で`castShadow`および`receiveShadow`プロパティを`true`に設定します。
*   **アニメーションの再生:** GLTFモデルにアニメーションが含まれている場合、`gltf.animations`配列からアニメーションクリップを取得し、`AnimationMixer`を使用して再生できます。

    ```javascript
    if (gltf.animations && gltf.animations.length) {
        const mixer = new THREE.AnimationMixer(gltf.scene);
        const clip = gltf.animations[0]; // 最初のアニメーションクリップ
        const action = mixer.clipAction(clip);
        action.play();

        // アニメーションループ内でmixerを更新
        function animate() {
            requestAnimationFrame(animate);
            mixer.update(deltaTime); // deltaTimeはフレーム間の経過時間
            renderer.render(scene, camera);
        }
        animate();
    }
    ```

#### 応用例とユースケース

*   **製品展示:** ECサイトなどで、ユーザーが製品を3Dでインタラクティブに確認できる機能を提供します。
*   **バーチャルリアリティ (VR) / 拡張現実 (AR):** VR/ARアプリケーションで、高品質な3Dモデルをリアルタイムに表示します。
*   **ゲーム開発:** Webゲームのキャラクターや背景オブジェクトとして使用します。
*   **建築ビジュアライゼーション:** 建物の外観や内装を3Dで表現し、顧客に提案します。

#### トラブルシューティング

*   **モデルが表示されない:** モデルのパスが正しいか、モデルファイルが破損していないかを確認してください。また、モデルが非常に大きく、カメラから遠すぎないか確認してください。
*   **テクスチャが表示されない:** テクスチャのパスが正しいか、テクスチャファイルが破損していないかを確認してください。また、マテリアルにテクスチャが正しく割り当てられているか確認してください。
*   **アニメーションが再生されない:** アニメーションクリップが正しくロードされているか、`AnimationMixer`が正しく更新されているか確認してください。

#### まとめと次のステップ

GLTFは、現代のWebベースの3Dグラフィックスにおいて非常に強力なツールです。このセクションで学んだ知識を基に、様々なGLTFモデルを読み込んで、Webアプリケーションに統合してみてください。より複雑なモデルやアニメーションを扱う場合は、Three.jsの公式ドキュメントやオンラインのリソースを参照することをお勧めします。

### OBJ (Wavefront OBJ)

#### 概要と重要性

OBJ（Wavefront OBJ）は、最も古くから存在する3Dモデル形式の一つで、シンプルなテキストベースのフォーマットが特徴です。モデリングソフトウェア間の互換性が高く、広く利用されています。

#### 特徴と利点

*   **シンプルな構造:** テキストベースで可読性が高く、編集が容易です。
*   **高い互換性:** 多くの3Dモデリングソフトウェアでサポートされています。
*   **幅広い用途:** 静的なモデルの表現に適しています。

#### 事前準備と前提条件

Three.jsでOBJモデルを読み込むには、`OBJLoader`を使用します。Three.jsのライブラリと`OBJLoader`をプロジェクトにインポートする必要があります。

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.157.0/build/three.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.157.0/examples/js/loaders/OBJLoader.js"></script>
```

#### MTLファイルとの連携

OBJ形式は、マテリアル情報をMTL（Material Template Library）ファイルに別途保存します。`MTLLoader`を使用してMTLファイルを読み込み、OBJモデルに適用することで、色やテクスチャなどのマテリアル情報を再現できます。

```javascript
import * as THREE from 'three';
import { OBJLoader } from 'three/addons/loaders/OBJLoader.js';
import { MTLLoader } from 'three/addons/loaders/MTLLoader.js';

// MTLLoaderのインスタンスを作成
const mtlLoader = new MTLLoader();

// MTLファイルを読み込む
mtlLoader.load('path/to/your/material.mtl', (materials) => {
    materials.preload(); // マテリアルを事前にロード

    // OBJLoaderのインスタンスを作成
    const objLoader = new OBJLoader();
    objLoader.setMaterials(materials); // マテリアルをOBJLoaderに設定

    // OBJモデルを読み込む
    objLoader.load(
        'path/to/your/model.obj',
        (object) => {
            scene.add(object);
            camera.position.z = 5;

            function animate() {
                requestAnimationFrame(animate);
                renderer.render(scene, camera);
            }
            animate();
        },
        (xhr) => {
            console.log((xhr.loaded / xhr.total * 100) + '% loaded');
        },
        (error) => {
            console.error('An error happened', error);
        }
    );
});
```

**コードの説明:**

*   `MTLLoader`のインスタンスを作成し、MTLファイルを読み込みます。
*   `materials.preload()`を呼び出して、マテリアルを事前にロードします。
*   `OBJLoader`のインスタンスを作成し、`setMaterials()`メソッドを使用して、ロードしたマテリアルをOBJLoaderに設定します。
*   OBJモデルをロードする際に、マテリアル情報が適用されます。

#### 実践的なテクニック

*   **モデルのスケーリングと位置調整:** OBJモデルは、元のサイズや原点からの位置が適切でない場合があります。`object.scale.set()`や`object.position.set()`を使用して、モデルのサイズや位置を調整します。
*   **法線ベクトルの計算:** OBJファイルに法線ベクトルが含まれていない場合、`geometry.computeVertexNormals()`を使用して、法線ベクトルを計算します。
*   **スムーズシェーディングの適用:** `MeshPhongMaterial`などのマテリアルを使用し、`flatShading`プロパティを`false`に設定することで、スムーズシェーディングを適用できます。

#### 応用例とユースケース

*   **静的なオブジェクトの表示:** 製品モデル、建築モデル、インテリアモデルなど、静的なオブジェクトを表示します。
*   **レガシーシステムの移行:** 古いシステムで使用されていたOBJモデルを、最新のWebアプリケーションに移行します。
*   **3Dモデリング学習:** OBJ形式のシンプルな構造を利用して、3Dモデリングの基礎を学習します。

#### トラブルシューティング

*   **モデルが表示されない:** モデルのパス、MTLファイルのパスが正しいか確認してください。また、ファイルへのアクセス権があるか確認してください。
*   **マテリアルが適用されない:** MTLファイルが正しくロードされているか、OBJLoaderにマテリアルが正しく設定されているか確認してください。
*   **モデルが非常に小さい/大きい:** `object.scale.set()`を使用して、モデルのサイズを調整してください。

#### まとめと次のステップ

OBJ形式は、シンプルな構造と高い互換性を持つため、Webアプリケーションで静的な3Dモデルを扱う際に便利な形式です。MTLファイルとの連携を理解し、モデルのサイズや位置を調整することで、より効果的な表現が可能になります。

### FBX (Filmbox)

#### 概要と重要性

FBX（Filmbox）は、Autodesk社が開発した3Dデータ交換フォーマットであり、アニメーションデータや高度なマテリアル情報を扱うのに適しています。ゲーム開発や映像制作などの分野で広く利用されています。

#### 特徴と利点

*   **アニメーション対応:** スキンメッシュアニメーション、ボーンアニメーションなど、様々なアニメーション形式をサポートします。
*   **高度なマテリアル情報:** PBRマテリアル、テクスチャ、シェーダーなど、高度なマテリアル情報を保持できます。
*   **幅広いソフトウェアとの互換性:** Autodesk Maya、3ds Max、Unity、Unreal Engineなど、多くのソフトウェアでサポートされています。

#### 事前準備と前提条件

Three.jsでFBXモデルを読み込むには、`FBXLoader`を使用します。Three.jsのライブラリと`FBXLoader`をプロジェクトにインポートする必要があります。

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.157.0/build/three.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.157.0/examples/js/loaders/FBXLoader.js"></script>
```

#### アニメーションデータの扱い

FBXモデルにアニメーションが含まれている場合、`object.animations`配列にアニメーションクリップが格納されます。`AnimationMixer`を使用して、アニメーションを再生できます。

```javascript
// FBXモデルをロードした後
if (object.animations && object.animations.length) {
    const mixer = new THREE.AnimationMixer(object);
    const clip = object.animations[0]; // 最初のアニメーションクリップ
    const action = mixer.clipAction(clip);
    action.play();

    // アニメーションループ内でmixerを更新
    function animate() {
        requestAnimationFrame(animate);
        mixer.update(deltaTime); // deltaTimeはフレーム間の経過時間
        renderer.render(scene, camera);
    }
    animate();
}
```

**コードの説明:**

*   `AnimationMixer`のインスタンスを作成し、FBXモデルを渡します。
*   `object.animations`配列からアニメーションクリップを取得します。
*   `mixer.clipAction()`メソッドを使用して、アニメーションクリップからアニメーションアクションを作成します。
*   `action.play()`メソッドを使用して、アニメーションを再生します。
*   アニメーションループ内で、`mixer.update()`メソッドを呼び出して、アニメーションを更新します。

#### 実践的なテクニック

*   **スキニングメッシュの最適化:** FBXモデルにスキニングメッシュが含まれている場合、頂点シェーダーでボーン変換を行うため、パフォーマンスが低下する可能性があります。頂点数を減らす、ボーン数を減らすなど、モデルを最適化することで、パフォーマンスを向上させることができます。
*   **テクスチャの最適化:** FBXモデルにテクスチャが含まれている場合、テクスチャの解像度を下げる、テクスチャ形式を最適化するなど、テクスチャを最適化することで、ロード時間を短縮し、パフォーマンスを向上させることができます。
*   **ライティングの調整:** FBXモデルのマテリアルは、異なるライティング環境で見た目が変わる可能性があります。シーンのライティングに合わせて、マテリアルのパラメータを調整することで、よりリアルな表現が可能になります。

#### 応用例とユースケース

*   **ゲームキャラクターのアニメーション:** ゲームキャラクターのアニメーションを再生します。
*   **インタラクティブな3Dコンテンツ:** ユーザーの操作に応じて、3Dモデルのアニメーションを制御します。
*   **バーチャル展示会:** 製品の3Dモデルを展示し、アニメーションで製品の機能を説明します。

#### トラブルシューティング

*   **モデルが表示されない:** モデルのパスが正しいか確認してください。また、ファイルへのアクセス権があるか確認してください。
*   **アニメーションが再生されない:** アニメーションクリップが正しくロードされているか、`AnimationMixer`が正しく設定されているか確認してください。また、アニメーションループ内で`mixer.update()`メソッドが正しく呼び出されているか確認してください。
*   **パフォーマンスが低い:** スキニングメッシュの頂点数が多い、テクスチャの解像度が高いなど、モデルの複雑さが原因である可能性があります。モデルを最適化することで、パフォーマンスを向上させることができます。

#### まとめと次のステップ

FBX形式は、アニメーションデータや高度なマテリアル情報を扱うのに適した形式です。`FBXLoader`を使用してFBXモデルを読み込み、`AnimationMixer`を使用してアニメーションを再生することで、Webアプリケーションに豊かな表現力を加えることができます。パフォーマンスに注意しながら、様々なFBXモデルを試してみてください。

この章では、GLTF, OBJ, FBXという３つの主要なモデル形式について、Three.jsでの読み込み方法と実践的な活用方法を解説しました。これらの知識を活かして、あなたのWebアプリケーションをさらに魅力的なものにしてください。
