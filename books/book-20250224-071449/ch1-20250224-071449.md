# 第1章：Three.jsへようこそ - 3D Webの扉を開く

この章では、Three.jsの世界への第一歩を踏み出します。Three.jsとは何か、なぜWebで3D表現を実現するためにThree.jsが重要なのか、そして実際に手を動かして最初の3Dシーンを作成するまでの道のりを、丁寧に解説していきます。3Dグラフィックスの経験がない方でも、この章を読み終える頃には、Three.jsの基礎を理解し、自信を持って次のステップに進めるようになるでしょう。

## Three.jsとは何か？

### Three.jsの概要と歴史

Three.jsは、Webブラウザ上で3Dグラフィックスを簡単に扱えるように設計されたJavaScriptライブラリです。ブラウザ上でネイティブに3D描画を可能にするWebGLの複雑さを抽象化し、より直感的で扱いやすいAPIを提供します。

Three.jsの歴史は古く、2010年にフランス人プログラマー、Ricardo Cabello（Mr.doob）によって開発が開始されました。当初は個人的なプロジェクトとしてスタートしましたが、そのシンプルさと強力な機能が多くの開発者に支持され、急速に普及しました。現在では、オープンソースプロジェクトとして活発に開発が続けられており、世界中の開発者によって改良と機能追加が行われています。

### WebGLとの関係性

Three.jsを理解する上で、WebGLとの関係性を把握することは非常に重要です。WebGL（Web Graphics Library）は、Webブラウザ上でOpenGL ES 2.0をベースとした3DグラフィックスAPIを利用するためのJavaScript APIです。WebGLを利用することで、プラグインなしでブラウザ上でハードウェアアクセラレーションによる高速な3D描画が可能になります。

しかし、WebGLのAPIは非常に低レベルであり、直接扱うには高度な知識と労力が必要です。そこで登場するのがThree.jsです。Three.jsは、WebGLの複雑さを隠蔽し、より抽象的で使いやすいAPIを提供することで、開発者がより簡単に3Dコンテンツを作成できるようにします。

例えるなら、WebGLが生の素材（OpenGL ES 2.0）であるのに対し、Three.jsはそれらを調理して美味しく食べられる料理にするためのレシピ集のようなものです。Three.jsを使うことで、WebGLの複雑なコードを直接書くことなく、簡単に3Dオブジェクトの作成、アニメーション、ライティング、テクスチャリングなどの処理を行うことができます。

### どのような表現ができるのか？

Three.jsを使えば、アイデア次第で様々な表現が可能です。以下は、Three.jsで実現できる表現の一例です。

*   **インタラクティブな3Dモデルの表示:** 製品の3Dモデルを表示し、ユーザーが自由に回転、拡大縮小、分解などを操作できるWebサイトを作成できます。ECサイトなどで活用されています。
*   **没入感のあるゲーム:** Webブラウザ上で動作する3Dゲームを開発できます。シューティングゲーム、パズルゲーム、アドベンチャーゲームなど、様々なジャンルのゲームをThree.jsで実現可能です。
*   **データビジュアライゼーション:** 大量のデータを3Dグラフやチャートとして視覚化し、データの傾向やパターンを分かりやすく表現できます。科学研究やビジネス分析で活用されています。
*   **バーチャルリアリティ(VR)・拡張現実(AR)コンテンツ:** WebVRやWebARの技術と組み合わせることで、VR/AR体験をWebブラウザ上で提供できます。教育、エンターテイメント、トレーニングなど、幅広い分野で応用されています。
*   **建築ビジュアライゼーション:** 建物の3Dモデルを作成し、様々な角度から見たり、内装をカスタマイズしたりできるWebアプリケーションを開発できます。不動産業界で活用されています。
*   **アニメーション:** 3Dオブジェクトに動きを与え、魅力的なアニメーションを制作できます。WebサイトのUI/UXの向上や、プロモーションビデオなどに活用されています。

これらの表現はほんの一例に過ぎません。Three.jsは、Webにおける3D表現の可能性を大きく広げるツールであり、あなたの創造性を形にするための強力な武器となるでしょう。

## 開発環境の構築

### 必要なソフトウェアとツール

Three.jsの開発に必要なソフトウェアとツールは、非常にシンプルです。

1.  **テキストエディタ:** コードを書くためのツールです。後述するように、様々なエディタがありますが、自分に合ったものを選びましょう。
2.  **Webブラウザ:** 作成した3Dシーンを表示するためのブラウザです。最新版のGoogle Chrome、Firefox、Safariなどを推奨します。
3.  **Live Server (オプション):** Webページを自動的にリロードしてくれるツールです。コードを修正するたびにブラウザを手動でリロードする手間を省き、開発効率を大幅に向上させます。

### エディタの選定 (VSCode, Sublime Textなど)

テキストエディタは、プログラミングにおける必須アイテムです。Three.jsの開発に適したエディタとしては、以下のものが挙げられます。

*   **Visual Studio Code (VSCode):** Microsoftが開発している無料のエディタです。豊富な拡張機能が利用可能で、JavaScript、HTML、CSSの開発を強力にサポートします。特に、Three.jsのコード補完やエラーチェック機能を提供する拡張機能が充実しており、開発効率を大幅に向上させることができます。
*   **Sublime Text:** 軽快な動作が特徴の有料エディタです。シンプルなUIと高度なカスタマイズ性が魅力で、多くのプログラマーに愛用されています。プラグインを導入することで、Three.jsの開発をサポートする機能を追加できます。
*   **Atom:** GitHubが開発している無料のエディタです。カスタマイズ性が高く、様々なパッケージをインストールすることで、自分好みの開発環境を構築できます。

これらのエディタ以外にも、Emacs、Vimなど、様々なエディタが存在します。どれを選ぶかは個人の好みによりますが、初心者の方には、無料で多機能なVSCodeをおすすめします。

**VSCodeのインストールと設定:**

1.  [https://code.visualstudio.com/](https://code.visualstudio.com/) からVSCodeをダウンロードし、インストールします。
2.  VSCodeを起動し、拡張機能マーケットプレイスを開きます（View -> Extensions）。
3.  以下の拡張機能をインストールします。
    *   **JavaScript (ES6) code snippets:** JavaScriptのコードスニペットを提供し、コーディングを効率化します。
    *   **HTML CSS Support:** HTMLとCSSのコード補完、シンタックスハイライトを提供します。
    *   **Live Server:** ローカルサーバーを起動し、ファイルの変更を自動的にブラウザに反映します。
    *   **Three.js Editor:** (Three.jsを深く利用するようになったら) Three.jsのシーンをGUIで編集できるツールです。

### Live Serverの導入と設定

Live Serverは、Webページの開発効率を向上させるための非常に便利なツールです。Live Serverを導入することで、HTML、CSS、JavaScriptファイルを編集するたびに、ブラウザが自動的にリロードされ、変更内容がすぐに確認できます。

**Live Serverのインストールと設定 (VSCodeの場合):**

1.  VSCodeを起動し、拡張機能マーケットプレイスを開きます（View -> Extensions）。
2.  `Live Server` を検索し、インストールします。
3.  HTMLファイルを開き、右クリックして `Open with Live Server` を選択します。
4.  Live Serverが起動し、ブラウザにWebページが表示されます。
5.  HTML、CSS、JavaScriptファイルを編集すると、ブラウザが自動的にリロードされ、変更内容が反映されます。

Live Serverの設定を変更したい場合は、VSCodeの設定（File -> Preferences -> Settings）で、`liveServer` を検索し、設定項目を編集します。例えば、ポート番号を変更したり、自動リロードの間隔を設定したりできます。

## Hello, Three.js! - 最初の3Dシーンを作成

### シーン、カメラ、レンダラーの基本

Three.jsで3Dシーンを作成するには、以下の3つの要素が不可欠です。

*   **シーン (Scene):** 3Dオブジェクト、ライト、カメラなどを配置する舞台となる空間です。
*   **カメラ (Camera):** シーンをどの角度から見るかを決定する視点です。Three.jsには、透視投影カメラ (PerspectiveCamera) や正投影カメラ (OrthographicCamera) など、様々な種類のカメラが用意されています。
*   **レンダラー (Renderer):** シーンとカメラの情報をもとに、3Dオブジェクトを実際に描画する役割を担います。WebGLRendererを使用することで、WebGLを利用した高速な描画が可能になります。

これらの3つの要素を組み合わせることで、3Dシーンを構築し、Webブラウザ上に表示することができます。

### 立方体を表示する最小限のコード

それでは、実際にコードを書いて、最初の3Dシーンを作成してみましょう。以下のコードは、立方体を表示するための最小限のコードです。

```html
<!DOCTYPE html>
<html>
<head>
    <title>Hello, Three.js!</title>
    <style>
        body { margin: 0; }
        canvas { display: block; }
    </style>
</head>
<body>
    <script src="https://cdn.jsdelivr.net/npm/three@0.155.0/build/three.min.js"></script>
    <script>
        // シーンを作成
        const scene = new THREE.Scene();

        // カメラを作成
        const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
        camera.position.z = 5;

        // レンダラーを作成
        const renderer = new THREE.WebGLRenderer();
        renderer.setSize( window.innerWidth, window.innerHeight );
        document.body.appendChild( renderer.domElement );

        // 立方体を作成
        const geometry = new THREE.BoxGeometry();
        const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
        const cube = new THREE.Mesh( geometry, material );
        scene.add( cube );

        // アニメーションループ
        function animate() {
            requestAnimationFrame( animate );

            cube.rotation.x += 0.01;
            cube.rotation.y += 0.01;

            renderer.render( scene, camera );
        }

        animate();
    </script>
</body>
</html>
```

上記のコードを `index.html` という名前で保存し、Live Serverで開いてみてください。緑色の立方体が回転する様子が表示されるはずです。

**コードの解説:**

*   **Three.jsのインポート:** `<script src="https://cdn.jsdelivr.net/npm/three@0.155.0/build/three.min.js"></script>` でThree.jsのライブラリを読み込んでいます。CDNを使用することで、簡単にThree.jsを利用できます。
*   **シーンの作成:** `const scene = new THREE.Scene();` でシーンを作成しています。
*   **カメラの作成:** `const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );` で透視投影カメラを作成しています。`75` は視野角、`window.innerWidth / window.innerHeight` はアスペクト比、`0.1` と `1000` はそれぞれnearとfarのクリッピング面を表します。`camera.position.z = 5;` でカメラの位置をZ軸方向に5移動させています。
*   **レンダラーの作成:** `const renderer = new THREE.WebGLRenderer();` でWebGLレンダラーを作成しています。`renderer.setSize( window.innerWidth, window.innerHeight );` でレンダラーのサイズをウィンドウサイズに合わせています。`document.body.appendChild( renderer.domElement );` でレンダラーの描画領域をHTMLドキュメントに追加しています。
*   **立方体の作成:** `const geometry = new THREE.BoxGeometry();` で立方体のジオメトリを作成しています。`const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );` で緑色のマテリアルを作成しています。`const cube = new THREE.Mesh( geometry, material );` でジオメトリとマテリアルを組み合わせてメッシュを作成しています。`scene.add( cube );` で立方体をシーンに追加しています。
*   **アニメーションループ:** `function animate() { ... }` でアニメーションループを作成しています。`requestAnimationFrame( animate );` でブラウザにアニメーションの実行を依頼しています。`cube.rotation.x += 0.01;` と `cube.rotation.y += 0.01;` で立方体をX軸とY軸方向に回転させています。`renderer.render( scene, camera );` でシーンをレンダリングしています。

### HTML/CSSとの連携

Three.jsは、HTMLとCSSとシームレスに連携することができます。例えば、HTML要素の上に3Dオブジェクトを重ねて表示したり、CSSで3Dシーンのレイアウトを調整したりすることができます。

以下の例は、HTML要素の上に3Dオブジェクトを重ねて表示する例です。

```html
<!DOCTYPE html>
<html>
<head>
    <title>Hello, Three.js!</title>
    <style>
        body { margin: 0; overflow: hidden; } /* overflow: hidden; を追加 */
        canvas { position: absolute; top: 0; left: 0; z-index: 1; } /* position: absolute; と z-index: 1; を追加 */
        .overlay { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); z-index: 2; color: white; font-size: 2em; } /* .overlayを追加 */
    </style>
</head>
<body>
    <div class="overlay">Hello, Three.js!</div>
    <script src="https://cdn.jsdelivr.net/npm/three@0.155.0/build/three.min.js"></script>
    <script>
        // シーンを作成
        const scene = new THREE.Scene();

        // カメラを作成
        const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
        camera.position.z = 5;

        // レンダラーを作成
        const renderer = new THREE.WebGLRenderer({ alpha: true }); // alpha: true を追加
        renderer.setSize( window.innerWidth, window.innerHeight );
        document.body.appendChild( renderer.domElement );
        renderer.setClearColor( 0x000000, 0 ); // 透明な背景色を設定

        // 立方体を作成
        const geometry = new THREE.BoxGeometry();
        const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
        const cube = new THREE.Mesh( geometry, material );
        scene.add( cube );

        // アニメーションループ
        function animate() {
            requestAnimationFrame( animate );

            cube.rotation.x += 0.01;
            cube.rotation.y += 0.01;

            renderer.render( scene, camera );
        }

        animate();
    </script>
</body>
</html>
```

上記のコードでは、`.overlay` というクラスを持つ `div` 要素を作成し、CSSで中央に配置しています。`canvas` 要素には `position: absolute;` と `z-index: 1;` を設定し、`.overlay` 要素には `z-index: 2;` を設定することで、`.overlay` 要素が `canvas` 要素の上に表示されるようにしています。また、`renderer` の作成時に `{ alpha: true }` を指定し、`renderer.setClearColor( 0x000000, 0 );` で背景色を透明に設定することで、`.overlay` 要素が3Dオブジェクトの上に透けて見えるようにしています。`body` に `overflow: hidden;` を追加して、スクロールバーが表示されないようにしています。

このように、Three.jsとHTML/CSSを組み合わせることで、よりリッチでインタラクティブなWebアプリケーションを開発することができます。

## まとめと次のステップ

この章では、Three.jsの概要、開発環境の構築、そして最初の3Dシーンの作成について学びました。Three.jsは、Webブラウザ上で3Dグラフィックスを簡単に扱えるように設計された強力なJavaScriptライブラリであり、アイデア次第で様々な表現が可能です。

次のステップとしては、以下の内容を学ぶことをおすすめします。

*   **様々な種類のジオメトリとマテリアル:** 立方体以外の形状や、様々な質感のマテリアルを試してみましょう。
*   **ライトとシャドウ:** シーンに光源を追加し、影を表現してみましょう。
*   **テクスチャ:** 3Dオブジェクトに画像テクスチャを適用してみましょう。
*   **アニメーション:** より複雑なアニメーションを作成してみましょう。
*   **インタラクション:** マウスやキーボードの操作で3Dオブジェクトを操作できるようにしてみましょう。
*   **モデルのインポート:** Blenderなどの3Dモデリングツールで作成したモデルをThree.jsにインポートしてみましょう。

Three.jsの世界は奥深く、学ぶべきことはたくさんありますが、一つずつ着実にステップアップしていくことで、必ず素晴らしい3D Webコンテンツを作成できるようになります。この章が、あなたの3D Web開発の旅の始まりとなることを願っています。頑張ってください！
