## 第4章：マテリアル (Material) - 表面の質感と表現

この章では、Three.jsにおけるマテリアルについて深く掘り下げていきます。マテリアルは、3Dオブジェクトの表面の見た目を決定する非常に重要な要素です。単純な色から、複雑な光の反射やテクスチャの表現まで、マテリアルを使いこなすことで、あなたの3Dシーンは劇的に変化します。この章では、基本的なマテリアルから、現代的な物理ベースレンダリング(PBR)まで、段階的に解説し、実践的なコード例を交えながら、Three.jsのマテリアルの世界を探求していきます。

### 基本マテリアル (MeshBasicMaterial, MeshNormalMaterialなど)

**1. 概要と重要性**

基本マテリアルは、Three.jsの中でも最もシンプルで、計算負荷の低いマテリアルです。光の影響を受けないため、ライティングの設定に関わらず、常に一定の色で表示されます。主にデバッグ用や、パフォーマンスが重要な場合に利用されます。`MeshBasicMaterial`と`MeshNormalMaterial`は、その代表的なものです。

**2. 特徴と利点**

*   **計算負荷が低い:** 光源計算を行わないため、複雑なシーンでも高速にレンダリングできます。
*   **シンプルな表現:** 色、透明度、ワイヤーフレームなど、基本的なプロパティのみを制御できます。
*   **デバッグ用途に最適:** オブジェクトの形状や位置を確認する際に便利です。

**3. 事前準備と前提条件**

*   Three.jsの基本的な知識 (シーン、カメラ、レンダラーの概念)
*   HTML、JavaScriptの基本的な知識

**4. 基本的な使い方**

まずは、最も基本的な`MeshBasicMaterial`から見ていきましょう。

```javascript
// シーン、カメラ、レンダラーの初期化 (省略)

// マテリアルの作成
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 }); // 緑色

// ジオメトリの作成
const geometry = new THREE.BoxGeometry(1, 1, 1);

// メッシュの作成
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// アニメーションループ (省略)
```

`MeshBasicMaterial`のコンストラクタに、`color`プロパティを設定することで、オブジェクトの色を指定できます。`color`は、16進数(0x00ff00)または、`THREE.Color`オブジェクトで指定できます。

次に、`MeshNormalMaterial`を見てみましょう。

```javascript
const material = new THREE.MeshNormalMaterial();

const geometry = new THREE.BoxGeometry(1, 1, 1);
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
```

`MeshNormalMaterial`は、オブジェクトの法線ベクトルをRGBカラーとして表示します。これにより、オブジェクトの表面の向きを視覚的に確認できます。主にデバッグ用途に使用されます。

**5. 実践的なテクニック**

*   **透明度の設定:** `transparent`を`true`に設定し、`opacity`プロパティで透明度を調整します。

```javascript
const material = new THREE.MeshBasicMaterial({
    color: 0xff0000,
    transparent: true,
    opacity: 0.5
});
```

*   **ワイヤーフレームの表示:** `wireframe`を`true`に設定することで、オブジェクトをワイヤーフレームで表示できます。

```javascript
const material = new THREE.MeshBasicMaterial({
    color: 0x0000ff,
    wireframe: true
});
```

*   **両面表示:** `side` プロパティを `THREE.DoubleSide` に設定することで、オブジェクトの裏面も表示できます。デフォルトでは `THREE.FrontSide` になっており、表面のみ表示されます。

```javascript
const material = new THREE.MeshBasicMaterial({
  color: 0xffffff,
  side: THREE.DoubleSide
});
```

**6. 応用例とユースケース**

*   **UI要素の表示:** 光源の影響を受けないため、UI要素を常に一定の色で表示するのに適しています。
*   **デバッグ情報の可視化:** `MeshNormalMaterial`を使用して、オブジェクトの法線ベクトルを可視化します。
*   **シンプルなプロトタイプ:** 光源設定の手間を省き、オブジェクトの形状や配置に集中したい場合に便利です。

**7. トラブルシューティング**

*   **オブジェクトが真っ黒になる:** 光源がない場合、`MeshLambertMaterial`や`MeshPhongMaterial`は真っ黒になりますが、`MeshBasicMaterial`は設定した色で表示されるはずです。もし真っ黒になる場合は、シーンにオブジェクトが正しく追加されているか、カメラの位置が適切かを確認してください。
*   **透明度がうまく反映されない:** レンダラーの`alpha`オプションが有効になっているか確認してください。`new THREE.WebGLRenderer({ alpha: true })`

**8. まとめと次のステップ**

`MeshBasicMaterial`と`MeshNormalMaterial`は、Three.jsの基本となるマテリアルです。これらのマテリアルを理解することで、より複雑なマテリアルの理解を深めることができます。次のステップでは、光源の影響を受けるマテリアルについて学習しましょう。

### 光源の影響を受けるマテリアル (MeshLambertMaterial, MeshPhongMaterial)

**1. 概要と重要性**

`MeshLambertMaterial`と`MeshPhongMaterial`は、光源の影響を受けるマテリアルです。これらのマテリアルを使用することで、3Dオブジェクトに陰影をつけ、よりリアルな表現が可能になります。`MeshLambertMaterial`は拡散反射光のみを考慮し、`MeshPhongMaterial`は拡散反射光と鏡面反射光を考慮します。

**2. 特徴と利点**

*   **リアルな表現:** 光源の影響を受けるため、オブジェクトに陰影がつき、よりリアルな表現が可能になります。
*   **多様な表現:** 環境光、拡散反射光、鏡面反射光のパラメータを調整することで、様々な質感を表現できます。
*   **幅広い用途:** ゲーム、建築ビジュアライゼーション、製品デザインなど、様々な分野で使用できます。

**3. 事前準備と前提条件**

*   Three.jsの基本的な知識 (シーン、カメラ、レンダラー、ジオメトリの概念)
*   HTML、JavaScriptの基本的な知識
*   光源の基本的な知識 (環境光、指向性ライト、点光源など)

**4. 基本的な使い方**

まずは、`MeshLambertMaterial`から見ていきましょう。

```javascript
// シーン、カメラ、レンダラーの初期化 (省略)

// 環境光の追加
const ambientLight = new THREE.AmbientLight(0x404040);
scene.add(ambientLight);

// 指向性ライトの追加
const directionalLight = new THREE.DirectionalLight(0xffffff, 0.5);
directionalLight.position.set(1, 1, 1);
scene.add(directionalLight);

// マテリアルの作成
const material = new THREE.MeshLambertMaterial({ color: 0xff0000 }); // 赤色

// ジオメトリの作成
const geometry = new THREE.BoxGeometry(1, 1, 1);

// メッシュの作成
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// アニメーションループ (省略)
```

`MeshLambertMaterial`を使用するには、シーンに光源を追加する必要があります。ここでは、環境光(`AmbientLight`)と指向性ライト(`DirectionalLight`)を追加しています。環境光はシーン全体を均等に照らし、指向性ライトは特定の方向から光を照射します。

次に、`MeshPhongMaterial`を見てみましょう。

```javascript
const material = new THREE.MeshPhongMaterial({
    color: 0xff0000,
    shininess: 30 // 光沢度
});
```

`MeshPhongMaterial`には、`shininess`プロパティがあります。このプロパティは、オブジェクトの光沢度を調整します。値が大きいほど、光沢が強くなります。

**5. 実践的なテクニック**

*   **環境光、拡散反射光、鏡面反射光の調整:** `color`、`emissive`、`specular`プロパティを調整することで、オブジェクトの質感を細かく制御できます。

```javascript
const material = new THREE.MeshPhongMaterial({
    color: 0xff0000, // 拡散反射光の色
    emissive: 0x111111, // 自己発光色
    specular: 0xffffff, // 鏡面反射光の色
    shininess: 30
});
```

*   **法線マップの利用:** `normalMap`プロパティに法線マップテクスチャを設定することで、オブジェクトの表面に凹凸を表現できます。これにより、より複雑な質感を表現できます。

```javascript
const textureLoader = new THREE.TextureLoader();
const normalMap = textureLoader.load('textures/normal_map.png');

const material = new THREE.MeshPhongMaterial({
    color: 0xff0000,
    normalMap: normalMap
});
```

*   **スペキュラマップの利用:** `specularMap`プロパティにスペキュラマップテクスチャを設定することで、オブジェクトの表面の光沢を部分的に制御できます。

```javascript
const textureLoader = new THREE.TextureLoader();
const specularMap = textureLoader.load('textures/specular_map.png');

const material = new THREE.MeshPhongMaterial({
    color: 0xff0000,
    specularMap: specularMap,
    shininess: 30
});
```

**6. 応用例とユースケース**

*   **ゲームキャラクターの表現:** `MeshLambertMaterial`や`MeshPhongMaterial`を使用して、ゲームキャラクターに陰影をつけ、リアルな表現を実現します。
*   **建築ビジュアライゼーション:** 建物の外観や内観を、光源を考慮してリアルに表現します。
*   **製品デザイン:** 製品の表面の質感や光沢を表現し、より魅力的な製品画像を作成します。

**7. トラブルシューティング**

*   **オブジェクトが真っ黒になる:** シーンに光源が不足している可能性があります。環境光や指向性ライトを追加してみてください。
*   **光沢が強すぎる/弱すぎる:** `shininess`プロパティの値を調整してみてください。
*   **法線マップがうまく表示されない:** 法線マップの方向が正しいか確認してください。Three.jsでは、Y軸が上向きの法線マップを使用する必要があります。

**8. まとめと次のステップ**

`MeshLambertMaterial`と`MeshPhongMaterial`は、光源の影響を受けるマテリアルであり、3Dオブジェクトに陰影をつけ、よりリアルな表現を実現できます。これらのマテリアルを使いこなすことで、あなたの3Dシーンはさらに魅力的になります。次のステップでは、物理ベースレンダリング(PBR)について学習しましょう。

### 物理ベースレンダリング (PBR) - MeshStandardMaterial, MeshPhysicalMaterial

**1. 概要と重要性**

物理ベースレンダリング (PBR) は、現実世界の物理法則に基づいて光の反射をシミュレートするレンダリング手法です。Three.jsでは、`MeshStandardMaterial`と`MeshPhysicalMaterial`がPBRをサポートしています。PBRを使用することで、よりリアルで自然な質感を表現できます。特に`MeshPhysicalMaterial`はより高度な表現が可能です。

**2. 特徴と利点**

*   **リアルな表現:** 現実世界の物理法則に基づいて光の反射をシミュレートするため、非常にリアルな質感を表現できます。
*   **環境光の影響:** 環境マップを使用することで、周囲の環境光を考慮したライティングが可能です。
*   **直感的なパラメータ:** `roughness` (粗さ) と `metalness` (金属度) など、直感的なパラメータで質感を調整できます。
*   **多様な表現:** 金属、木材、ガラス、布など、様々な質感を表現できます。

**3. 事前準備と前提条件**

*   Three.jsの基本的な知識 (シーン、カメラ、レンダラー、ジオメトリの概念)
*   HTML、JavaScriptの基本的な知識
*   `MeshLambertMaterial`と`MeshPhongMaterial`の知識
*   テクスチャの基本的な知識 (カラーマップ、ラフネスマップ、メタリックマップなど)
*   環境マップ (Equirectangular形式またはCube形式)

**4. 基本的な使い方**

まずは、`MeshStandardMaterial`から見ていきましょう。

```javascript
// シーン、カメラ、レンダラーの初期化 (省略)

// 環境光の追加
const ambientLight = new THREE.AmbientLight(0x404040);
scene.add(ambientLight);

// 指向性ライトの追加
const directionalLight = new THREE.DirectionalLight(0xffffff, 0.5);
directionalLight.position.set(1, 1, 1);
scene.add(directionalLight);

// マテリアルの作成
const material = new THREE.MeshStandardMaterial({
    color: 0xff0000, // 基本色
    roughness: 0.5, // 粗さ (0.0: 滑らか, 1.0: 粗い)
    metalness: 0.5 // 金属度 (0.0: 非金属, 1.0: 金属)
});

// ジオメトリの作成
const geometry = new THREE.BoxGeometry(1, 1, 1);

// メッシュの作成
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// アニメーションループ (省略)
```

`MeshStandardMaterial`では、`color` (基本色)、`roughness` (粗さ)、`metalness` (金属度) の3つのパラメータが重要です。`roughness`は表面の粗さを調整し、`metalness`は金属のような光沢を表現します。

次に、環境マップ(envMap)を設定してみましょう。

```javascript
const textureLoader = new THREE.TextureLoader();
const envMap = textureLoader.load('textures/environment_map.jpg'); // 環境マップのパス

const material = new THREE.MeshStandardMaterial({
    color: 0xff0000,
    roughness: 0.5,
    metalness: 0.5,
    envMap: envMap // 環境マップの設定
});

scene.environment = envMap; // シーン全体に環境光を適用（Three.js r152以降）
```

`envMap`プロパティに環境マップを設定することで、オブジェクトは周囲の環境光を反射するようになります。これにより、よりリアルなライティングが可能になります。 Three.js r152以降では、`scene.environment`にenvMapを設定することで、シーン全体に環境光を適用できます。

**5. 実践的なテクニック**

*   **ラフネスマップとメタリックマップの利用:** `roughnessMap`と`metalnessMap`プロパティにテクスチャを設定することで、オブジェクトの表面の粗さと金属度を部分的に制御できます。

```javascript
const textureLoader = new THREE.TextureLoader();
const roughnessMap = textureLoader.load('textures/roughness_map.png');
const metalnessMap = textureLoader.load('textures/metalness_map.png');

const material = new THREE.MeshStandardMaterial({
    color: 0xff0000,
    roughness: 1.0, // 全体的な粗さの基準値
    metalness: 0.0, // 全体的な金属度の基準値
    roughnessMap: roughnessMap, // 粗さマップ
    metalnessMap: metalnessMap // 金属度マップ
});
```

*   **Ambient Occlusion Map の利用:** `aoMap`プロパティにテクスチャを設定することで、オブジェクトの細かい部分の影を表現できます。

```javascript
const textureLoader = new THREE.TextureLoader();
const aoMap = textureLoader.load('textures/ao_map.png');

const material = new THREE.MeshStandardMaterial({
    color: 0xff0000,
    aoMap: aoMap,
    aoMapIntensity: 1.0 // AOマップの強度
});
```

*   **Image Based Lighting (IBL) の設定:** 球面調和関数 (SH) を使用した環境光の設定を行うことで、より自然なライティングを実現します。Three.jsには、IBLを簡単に設定できるライブラリやツールが用意されています。

```javascript
import { RGBELoader } from 'three/examples/jsm/loaders/RGBELoader.js';
import { EXRLoader } from 'three/examples/jsm/loaders/EXRLoader.js';

let hdrEquirect;

new RGBELoader()
  .setPath( 'textures/' )
  .load( 'filename.hdr', function ( texture ) {

    hdrEquirect = texture;
    hdrEquirect.mapping = THREE.EquirectangularReflectionMapping;

    material.envMap = hdrEquirect;

} );

new EXRLoader()
  .setPath( 'textures/' )
  .load( 'filename.exr', function ( texture ) {

    hdrEquirect = texture;
    hdrEquirect.mapping = THREE.EquirectangularReflectionMapping;

    material.envMap = hdrEquirect;

} );
```

**6. 応用例とユースケース**

*   **製品ビジュアライゼーション:** 金属、ガラス、プラスチックなど、様々な素材の質感をリアルに表現し、製品の魅力を最大限に引き出します。
*   **映画やゲームの制作:** よりリアルな背景やキャラクターを制作し、没入感を高めます。
*   **バーチャルリアリティ (VR) / 拡張現実 (AR) アプリケーション:** 現実世界と区別がつかないほどリアルなオブジェクトを表示し、より自然な体験を提供します。
*   **デジタルツイン:** 現実世界の構造物や設備を3Dモデルで再現し、メンテナンスやシミュレーションに活用します。

**7. トラブルシューティング**

*   **オブジェクトが暗すぎる/明るすぎる:** `roughness`と`metalness`の値を調整してみてください。また、環境マップの明るさも影響します。
*   **環境マップがうまく反映されない:** 環境マップの形式が正しいか確認してください。Three.jsでは、Equirectangular形式またはCube形式の環境マップをサポートしています。また、テクスチャのロードが完了しているかを確認してください。
*   **ラフネスマップとメタリックマップがうまく表示されない:** テクスチャの解像度が十分か確認してください。また、UV座標が正しく設定されているか確認してください。
*   **想定通りの質感にならない**: PBRはパラメータの調整が複雑であるため、パラメータの組み合わせや、テクスチャの組み合わせなどを変更して試行錯誤を繰り返す必要があります。

**8. まとめと次のステップ**

`MeshStandardMaterial`と`MeshPhysicalMaterial`は、物理ベースレンダリング(PBR)をサポートするマテリアルであり、現実世界の物理法則に基づいて光の反射をシミュレートします。これらのマテリアルを使いこなすことで、非常にリアルな質感を表現できます。PBRは、より高度なレンダリング技術ですが、その効果は絶大です。ぜひ、PBRマテリアルを使いこなして、あなたの3Dシーンをさらに進化させてください。次のステップでは、シェーダーについて学習しましょう。
