## 第8章：アニメーション - オブジェクトを動かす

3Dモデルが静止しているだけでは、魅力的な体験は生まれません。アニメーションは、3D空間に命を吹き込み、ユーザーを惹きつけ、インタラクティブな世界を作り出すための重要な要素です。この章では、Three.jsを使ってオブジェクトを動かすための様々なテクニックを、基本的なアニメーションループから、より高度なTween.jsやGLTFアニメーションまで、段階的に解説します。初心者の方でも理解しやすいように、実践的なコードスニペットを交えながら、アニメーションの基礎から応用までを網羅的に学びましょう。

### アニメーションの基本

#### 概要と重要性

アニメーションの基本は、時間経過とともにオブジェクトの状態（位置、回転、スケールなど）を変化させることです。ウェブブラウザにおけるアニメーションは、主にJavaScriptによって制御され、特に`requestAnimationFrame`というAPIが重要な役割を果たします。

`requestAnimationFrame`は、ブラウザが次の再描画を行う前に実行する関数をスケジュールします。これにより、滑らかでパフォーマンスの高いアニメーションを実現できます。アニメーションがない3D空間は、単なる静的な画像と変わりません。アニメーションを駆使することで、生き生きとしたインタラクティブな体験を提供し、ユーザーエンゲージメントを大幅に向上させることができます。

#### 特徴と利点

*   **パフォーマンス**: `requestAnimationFrame`は、ブラウザの描画タイミングに合わせてアニメーションを実行するため、CPU負荷を軽減し、滑らかなアニメーションを実現します。
*   **柔軟性**: JavaScriptを使用することで、複雑なアニメーションロジックを自由に記述できます。
*   **制御性**: アニメーションの開始、停止、速度などを細かく制御できます。

#### 事前準備と前提条件

*   基本的なHTML、CSS、JavaScriptの知識
*   Three.jsの基本的な使い方（シーン、カメラ、レンダラーのセットアップなど）
*   3Dオブジェクトの作成とシーンへの追加

#### 基本的な使い方

1.  **アニメーションループの作成**: `requestAnimationFrame`を使って、アニメーションループを作成します。このループ内で、オブジェクトの状態を更新し、レンダリングを行います。

```javascript
function animate() {
  requestAnimationFrame(animate);

  // オブジェクトの状態を更新する処理

  renderer.render(scene, camera);
}

animate();
```

2.  **オブジェクトの位置、回転、スケールの変更**: アニメーションループ内で、オブジェクトの`position`、`rotation`、`scale`プロパティを更新します。

```javascript
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

function animate() {
  requestAnimationFrame(animate);

  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  renderer.render(scene, camera);
}

animate();
```

この例では、立方体がX軸とY軸を中心に回転します。`rotation.x`と`rotation.y`に微小な値を加算することで、回転アニメーションを実現しています。

#### 実践的なテクニック

*   **時間経過を利用したアニメーション**: `Date.now()`や`performance.now()`を使って、アニメーションの開始からの経過時間を計測し、それに応じてオブジェクトの状態を変化させます。これにより、フレームレートに依存しない、より安定したアニメーションを実現できます。

```javascript
let startTime = performance.now();

function animate() {
  requestAnimationFrame(animate);

  let currentTime = performance.now();
  let elapsedTime = (currentTime - startTime) / 1000; // 経過時間を秒単位で取得

  cube.position.x = Math.sin(elapsedTime) * 2; // X軸方向にサイン波で移動

  renderer.render(scene, camera);
}

animate();
```

*   **複数のオブジェクトのアニメーション**: 複数のオブジェクトに対して、それぞれ異なるアニメーションを適用することができます。

```javascript
const cube1 = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), new THREE.MeshBasicMaterial({ color: 0xff0000 }));
const cube2 = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), new THREE.MeshBasicMaterial({ color: 0x0000ff }));

cube1.position.x = -2;
cube2.position.x = 2;

scene.add(cube1, cube2);

function animate() {
  requestAnimationFrame(animate);

  cube1.rotation.x += 0.01;
  cube2.rotation.y += 0.02;

  renderer.render(scene, camera);
}

animate();
```

#### 応用例とユースケース

*   **UIアニメーション**: ボタンのホバー効果、メニューのスライドイン・アウトなど、ユーザーインターフェースにアニメーションを組み込むことで、視覚的なフィードバックを提供し、操作性を向上させることができます。
*   **インタラクティブな3Dモデル**: マウスオーバーやクリックなどのユーザーインタラクションに応じて、3Dモデルをアニメーションさせることで、より没入感のある体験を提供できます。
*   **ゲーム開発**: キャラクターの移動、ジャンプ、攻撃などのアニメーションを実装することで、ゲームの臨場感を高めることができます。
*   **データビジュアライゼーション**: 時間経過とともに変化するデータをアニメーションで表現することで、データの傾向やパターンをより分かりやすく伝えることができます。

#### トラブルシューティング

*   **アニメーションがカクカクする**: `requestAnimationFrame`を使用しているか確認してください。また、オブジェクトの状態を更新する処理が重すぎると、フレームレートが低下し、アニメーションがカクカクすることがあります。処理を最適化するか、より高性能なハードウェアを使用することを検討してください。
*   **アニメーションが意図した通りに動かない**: オブジェクトの`position`、`rotation`、`scale`プロパティを更新する際に、適切な値を設定しているか確認してください。また、時間経過を利用したアニメーションの場合、経過時間の計算が正しいか確認してください。
*   **メモリリーク**: アニメーションループ内で、不要なオブジェクトを生成したり、イベントリスナーを登録したりすると、メモリリークが発生する可能性があります。不要になったオブジェクトは適切に破棄し、イベントリスナーは削除するようにしてください。

#### まとめと次のステップ

このセクションでは、`requestAnimationFrame`を使った基本的なアニメーションループの作成方法と、オブジェクトの位置、回転、スケールを変化させる方法について学びました。次のステップでは、Tween.jsというライブラリを使って、より高度なアニメーションを簡単に実装する方法について解説します。

### Tween.jsによるアニメーション

#### 概要と重要性

Tween.jsは、JavaScriptでスムーズなアニメーションを簡単に作成するためのライブラリです。位置、回転、スケールなどのプロパティを、指定された時間内に、特定のイージング関数を使って変化させることができます。手動でアニメーションロジックを記述するよりも、はるかに効率的に、洗練されたアニメーションを実装できます。

#### 特徴と利点

*   **簡単**: シンプルなAPIで、複雑なアニメーションを簡単に作成できます。
*   **スムーズ**: イージング関数を使用することで、自然で滑らかなアニメーションを実現できます。
*   **柔軟**: 様々なプロパティをアニメーションさせることができます。
*   **制御性**: アニメーションの開始、停止、一時停止、再開などを制御できます。
*   **チェーン**: 複数のアニメーションをチェーンさせることができます。

#### 事前準備と前提条件

*   基本的なHTML、CSS、JavaScriptの知識
*   Three.jsの基本的な使い方（シーン、カメラ、レンダラーのセットアップなど）
*   Tween.jsライブラリのダウンロードまたはCDNの利用

#### 基本的な使い方

1.  **Tween.jsの導入と設定**: Tween.jsライブラリをダウンロードし、HTMLファイルに読み込むか、CDNを使って読み込みます。

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/tween.js/18.6.4/Tween.min.js"></script>
```

2.  **Tweenの作成**: `new TWEEN.Tween()`コンストラクタを使って、Tweenオブジェクトを作成します。引数には、アニメーションさせるオブジェクトを指定します。

```javascript
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

const target = { x: 5 }; // アニメーション後の値

const tween = new TWEEN.Tween(cube.position) // アニメーション対象のプロパティ
  .to(target, 1000) // アニメーション後の値とアニメーション時間（ミリ秒）
  .easing(TWEEN.Easing.Quadratic.InOut) // イージング関数
  .start(); // アニメーション開始
```

3.  **アニメーションループの更新**: アニメーションループ内で、`TWEEN.update()`を呼び出して、Tween.jsのアニメーションを更新します。

```javascript
function animate() {
  requestAnimationFrame(animate);

  TWEEN.update(); // Tween.jsのアニメーションを更新

  renderer.render(scene, camera);
}

animate();
```

#### 実践的なテクニック

*   **複数のプロパティのアニメーション**: 複数のプロパティを同時にアニメーションさせることができます。

```javascript
const target = { x: 5, y: 3, z: -2 };

const tween = new TWEEN.Tween(cube.position)
  .to(target, 2000)
  .easing(TWEEN.Easing.Elastic.Out)
  .start();
```

*   **イージング関数の利用**: Tween.jsには、様々なイージング関数が用意されています。イージング関数を使うことで、アニメーションの速度変化を滑らかにすることができます。

```javascript
// 例：イージング関数を変更
const tween = new TWEEN.Tween(cube.position)
  .to({ x: 5 }, 1000)
  .easing(TWEEN.Easing.Bounce.Out) // イージング関数をBounce.Outに変更
  .start();
```

*   **アニメーションのチェーン**: 複数のアニメーションをチェーンさせることができます。

```javascript
const tween1 = new TWEEN.Tween(cube.position)
  .to({ x: 5 }, 1000)
  .easing(TWEEN.Easing.Quadratic.InOut);

const tween2 = new TWEEN.Tween(cube.rotation)
  .to({ y: Math.PI * 2 }, 1000) // 1回転
  .easing(TWEEN.Easing.Quadratic.InOut);

tween1.chain(tween2); // tween1の完了後にtween2を開始

tween1.start();
```

*   **コールバック関数の利用**: アニメーションの開始時、終了時、更新時などに、コールバック関数を実行することができます。

```javascript
const tween = new TWEEN.Tween(cube.position)
  .to({ x: 5 }, 1000)
  .easing(TWEEN.Easing.Quadratic.InOut)
  .onStart(() => {
    console.log("アニメーション開始！");
  })
  .onComplete(() => {
    console.log("アニメーション完了！");
  })
  .start();
```

#### 応用例とユースケース

*   **インタラクティブなアニメーション**: マウスの動きに合わせてオブジェクトをアニメーションさせたり、ボタンをクリックしたときに特定のアニメーションを再生したりすることができます。
*   **ローディングアニメーション**: ローディング中に、プログレスバーやスピナーなどのアニメーションを表示することができます。
*   **スクロールアニメーション**: スクロール位置に応じて、オブジェクトをアニメーションさせることができます。パララックス効果などを実現できます。

#### トラブルシューティング

*   **アニメーションが始まらない**: `TWEEN.update()`がアニメーションループ内で呼び出されているか確認してください。また、`tween.start()`を呼び出して、アニメーションを開始しているか確認してください。
*   **アニメーションがカクカクする**: イージング関数を使用しているか確認してください。また、アニメーション時間が短すぎると、アニメーションがカクカクすることがあります。アニメーション時間を長くするか、イージング関数を調整してください。
*   **アニメーションが途中で止まる**: `TWEEN.update()`が呼び出されなくなると、アニメーションが途中で止まります。アニメーションループが正常に動作しているか確認してください。

### GLTFアニメーション

#### 概要と重要性

GLTF（GL Transmission Format）は、3Dモデルを効率的に転送およびロードするためのファイル形式です。GLTFファイルには、3Dモデルのジオメトリ、マテリアル、テクスチャだけでなく、アニメーションデータを含めることができます。Three.jsでは、GLTFLoaderを使ってGLTFファイルを読み込み、AnimationMixerを使ってアニメーションを再生することができます。

GLTFアニメーションは、特にキャラクターアニメーションや複雑なオブジェクトの動きを表現するのに適しています。例えば、ゲームキャラクターの歩行アニメーションや、機械の動作アニメーションなどを、簡単にThree.jsのシーンに組み込むことができます。

#### 特徴と利点

*   **効率的なファイル形式**: GLTFは、ファイルサイズが小さく、ロード時間が短いため、ウェブアプリケーションに最適です。
*   **アニメーション対応**: GLTFファイルには、アニメーションデータを含めることができます。
*   **標準化**: GLTFは、Khronos Groupによって標準化されており、様々な3Dモデリングツールでサポートされています。
*   **容易な統合**: Three.jsのGLTFLoaderとAnimationMixerを使って、簡単にアニメーションを再生できます。

#### 事前準備と前提条件

*   基本的なHTML、CSS、JavaScriptの知識
*   Three.jsの基本的な使い方（シーン、カメラ、レンダラーのセットアップなど）
*   GLTFモデルファイル（.gltfまたは.glb）
*   GLTFLoaderの導入 (Three.jsに含まれています)

#### 基本的な使い方

1.  **GLTFLoaderのインスタンスを作成**: `THREE.GLTFLoader`コンストラクタを使って、GLTFLoaderのインスタンスを作成します。

```javascript
const loader = new THREE.GLTFLoader();
```

2.  **GLTFファイルの読み込み**: `loader.load()`メソッドを使って、GLTFファイルを読み込みます。

```javascript
loader.load(
  'path/to/model.gltf',
  function (gltf) {
    // モデルの読み込みが完了したときの処理
    scene.add(gltf.scene); // モデルをシーンに追加

    mixer = new THREE.AnimationMixer(gltf.scene); // AnimationMixerを作成

    gltf.animations.forEach((clip) => {
      mixer.clipAction(clip).play(); // アニメーションを再生
    });
  },
  function (xhr) {
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  function (error) {
    console.log('An error happened');
  }
);
```

3.  **AnimationMixerの作成**: `THREE.AnimationMixer`コンストラクタを使って、AnimationMixerのインスタンスを作成します。引数には、アニメーションを適用する3Dモデルを指定します。通常は、`gltf.scene`を渡します。

4.  **アニメーションの再生**: `mixer.clipAction()`メソッドを使って、アニメーションクリップを作成し、`play()`メソッドを使って再生します。

5.  **アニメーションループの更新**: アニメーションループ内で、`mixer.update()`を呼び出して、AnimationMixerのアニメーションを更新します。引数には、経過時間（秒単位）を指定します。

```javascript
let mixer;

function animate() {
  requestAnimationFrame(animate);

  if (mixer) {
    mixer.update(0.01); // AnimationMixerのアニメーションを更新（0.01秒ずつ進める）
  }

  renderer.render(scene, camera);
}

animate();
```

#### 実践的なテクニック

*   **複数のアニメーションの制御**: GLTFファイルに複数のアニメーションが含まれている場合、それぞれのアニメーションを個別に制御することができます。

```javascript
loader.load(
  'path/to/model.gltf',
  function (gltf) {
    scene.add(gltf.scene);

    mixer = new THREE.AnimationMixer(gltf.scene);

    const animations = gltf.animations;

    const idleAction = mixer.clipAction(animations[0]); // アイドルアニメーション
    const walkAction = mixer.clipAction(animations[1]); // 歩行アニメーション

    idleAction.play(); // アイドルアニメーションを再生

    // 歩行アニメーションを再生する例
    // walkAction.play();
    // idleAction.stop();
  },
  function (xhr) {
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  function (error) {
    console.log('An error happened');
  }
);
```

*   **アニメーションのループ**: `setLoop()`メソッドを使って、アニメーションのループモードを設定することができます。

```javascript
const clipAction = mixer.clipAction(clip);
clipAction.setLoop(THREE.LoopRepeat, Infinity); // 無限ループ
clipAction.play();
```

*   **アニメーションの速度**: `setSpeed()`メソッドを使って、アニメーションの再生速度を設定することができます。

```javascript
const clipAction = mixer.clipAction(clip);
clipAction.setSpeed(2); // 2倍速で再生
clipAction.play();
```

*   **アニメーションのフェードイン・アウト**: `crossFadeFrom()`メソッドと`crossFadeTo()`メソッドを使って、アニメーションをスムーズに切り替えることができます。

```javascript
// アイドルアニメーションから歩行アニメーションにフェードイン
idleAction.fadeOut(0.5); // 0.5秒かけてフェードアウト
walkAction.reset().fadeIn(0.5).play(); // 0.5秒かけてフェードイン
```

#### 応用例とユースケース

*   **ゲーム開発**: キャラクターのアニメーション（歩行、ジャンプ、攻撃など）、オブジェクトの動作（ドアの開閉、機械の作動など）を実装することができます。
*   **製品デモンストレーション**: 製品の3Dモデルをアニメーションさせて、機能や動作を分かりやすく説明することができます。
*   **バーチャルリアリティ（VR）/拡張現実（AR）**: VR/AR環境で、インタラクティブな3Dモデルをアニメーションさせることができます。
*   **オンラインストア**: 製品の3Dモデルをアニメーションさせて、より魅力的に見せることができます。例えば、服を着たマネキンを歩かせる、家具の配置をアニメーションで変更するなどが考えられます。

#### トラブルシューティング

*   **モデルが表示されない**: GLTFファイルのパスが正しいか確認してください。また、GLTFファイルが破損していないか確認してください。
*   **アニメーションが再生されない**: AnimationMixerが正しく作成されているか確認してください。また、アニメーションクリップが正しく再生されているか確認してください。
*   **アニメーションがカクカクする**: モデルの頂点数が多すぎると、アニメーションがカクカクすることがあります。モデルを最適化するか、より高性能なハードウェアを使用することを検討してください。
*   **テクスチャが表示されない**: テクスチャのパスが正しいか確認してください。また、テクスチャファイルが破損していないか確認してください。
*   **エラーメッセージ**: ブラウザの開発者ツールを開き、エラーメッセージを確認してください。エラーメッセージは、問題の解決に役立つ情報を提供してくれます。

次のステップとしては、シェーダープログラミングに挑戦することで、さらに高度な表現を追求したり、物理エンジンを導入して、よりリアルなインタラクションを実現したりすることができます。
