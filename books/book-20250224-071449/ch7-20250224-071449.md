# 第7章：影 (Shadow) - よりリアルな表現へ

3Dモデルに影をつけることは、シーンのリアリティを飛躍的に向上させるための重要な要素です。影があることで、オブジェクトが空間に存在している感覚が生まれ、奥行きや位置関係をより正確に把握できるようになります。この章では、Three.jsで影を表現するための技術であるシャドウマッピングの基本から応用までを解説します。

## シャドウマッピングの基本

### シャドウマップとは？

シャドウマップとは、光源から見たシーンの深度情報を記録したテクスチャのことです。この深度情報を使って、各ピクセルが影の中にあるかどうかを判断します。簡単に言うと、光源から見てオブジェクトの裏側にあるピクセルは影になる、という考え方です。

**重要性:**

シャドウマップは、リアルタイム3Dグラフィックスにおいて影を生成するための最も一般的な手法の一つです。処理負荷と品質のバランスが良く、多くの環境で使用されています。

### シャドウを落とすオブジェクトと受け取るオブジェクトの設定

Three.jsで影を生成するには、以下の2つの設定が必要です。

1.  **影を落とすオブジェクト:** `object.castShadow = true;`
2.  **影を受け取るオブジェクト:** `object.receiveShadow = true;`

`castShadow`を`true`に設定したオブジェクトは、他のオブジェクトに影を落とします。一方、`receiveShadow`を`true`に設定したオブジェクトは、他のオブジェクトから影を受け取ります。

**例:**

```javascript
// シーンの作成
const scene = new THREE.Scene();

// カメラの作成
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 5, 10);
camera.lookAt(0, 0, 0);

// レンダラーの作成
const renderer = new THREE.WebGLRenderer({antialias: true});
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.shadowMap.enabled = true; // シャドウマップを有効にする
document.body.appendChild(renderer.domElement);

// 光源の作成 (平行光源)
const directionalLight = new THREE.DirectionalLight(0xffffff, 1);
directionalLight.position.set(5, 5, 5);
directionalLight.castShadow = true; // 光源が影を生成するように設定
scene.add(directionalLight);

// 光源のヘルパー (デバッグ用)
const directionalLightHelper = new THREE.DirectionalLightHelper( directionalLight, 5 );
scene.add( directionalLightHelper );

// シャドウマップの解像度を設定 (後述)
directionalLight.shadow.mapSize.width = 2048;
directionalLight.shadow.mapSize.height = 2048;

// 影の範囲を設定
directionalLight.shadow.camera.near = 0.5;
directionalLight.shadow.camera.far = 500;

// 正投影カメラの範囲を調整
directionalLight.shadow.camera.left = -10;
directionalLight.shadow.camera.right = 10;
directionalLight.shadow.camera.top = 10;
directionalLight.shadow.camera.bottom = -10;

// シャドウカメラヘルパー
const shadowCameraHelper = new THREE.CameraHelper( directionalLight.shadow.camera );
scene.add( shadowCameraHelper );

// 地面の作成
const planeGeometry = new THREE.PlaneGeometry(20, 20);
const planeMaterial = new THREE.MeshStandardMaterial({ color: 0x808080 });
const plane = new THREE.Mesh(planeGeometry, planeMaterial);
plane.rotation.x = -Math.PI / 2;
plane.receiveShadow = true; // 地面が影を受け取るように設定
scene.add(plane);

// 立方体の作成
const cubeGeometry = new THREE.BoxGeometry(2, 2, 2);
const cubeMaterial = new THREE.MeshStandardMaterial({ color: 0xff0000 });
const cube = new THREE.Mesh(cubeGeometry, cubeMaterial);
cube.position.set(0, 1, 0);
cube.castShadow = true; // 立方体が影を落とすように設定
scene.add(cube);

// アニメーションループ
function animate() {
  requestAnimationFrame(animate);

  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  renderer.render(scene, camera);
}

animate();
```

**解説:**

*   `renderer.shadowMap.enabled = true;` は、レンダラー全体でシャドウマップを有効にするための重要な設定です。これを忘れると影は表示されません。
*   `directionalLight.castShadow = true;` は、平行光源が影を生成するように指示します。
*   `plane.receiveShadow = true;` は、地面が他のオブジェクトから影を受け取るように設定します。
*   `cube.castShadow = true;` は、立方体が地面に影を落とすように設定します。
*   `directionalLight.shadow.mapSize.width`と`directionalLight.shadow.mapSize.height`は、シャドウマップの解像度を設定します。後述します。
*   `directionalLight.shadow.camera.near`と`directionalLight.shadow.camera.far`は、影を投影するカメラのニアクリップ面とファークリップ面を設定します。これらの値を適切に設定することで、影の精度と範囲を調整できます。
*   `directionalLight.shadow.camera.left`, `directionalLight.shadow.camera.right`, `directionalLight.shadow.camera.top`, `directionalLight.shadow.camera.bottom`は、正投影カメラの範囲を設定します。平行光源のシャドウは正投影カメラで生成されるため、これらの値を調整することで、影の範囲と精度を制御できます。

### シャドウマップの解像度 (shadow.mapSize) の調整

シャドウマップの解像度は、影の品質に直接影響します。解像度が高いほど、影は滑らかになり、ギザギザが目立たなくなります。しかし、解像度を高くすると、処理負荷が増加します。

**設定:**

```javascript
directionalLight.shadow.mapSize.width = 2048;
directionalLight.shadow.mapSize.height = 2048;
```

**解像度の選択:**

*   **低い解像度 (512x512):** モバイルデバイスやローエンドPCなど、パフォーマンスが限られた環境に適しています。
*   **中程度の解像度 (1024x1024):** 一般的なデスクトップPCに適しています。
*   **高い解像度 (2048x2048以上):** ハイエンドPCや、特に高品質な影が必要な場合に適しています。

**パフォーマンスへの影響:**

シャドウマップの解像度を上げると、GPUの負荷が増加します。特に、複数の光源でシャドウを生成する場合、パフォーマンスへの影響は大きくなります。解像度を調整する際は、常にパフォーマンスを考慮してください。

**実践的なテクニック:**

*   **動的な解像度調整:** ユーザーのデバイス性能に応じて、シャドウマップの解像度を動的に変更することができます。例えば、フレームレートが低い場合は解像度を下げ、高い場合は解像度を上げるように調整します。
*   **シャドウカリング:** カメラから見えないオブジェクトの影を生成しないようにすることで、パフォーマンスを向上させることができます。

## シャドウの種類

Three.jsでは、いくつかの種類のシャドウマップが用意されています。それぞれ特徴が異なるため、用途に応じて適切なものを選択する必要があります。

*   `THREE.BasicShadowMap`
*   `THREE.PCFShadowMap` (デフォルト)
*   `THREE.PCFSoftShadowMap`

**設定:**

```javascript
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // シャドウマップの種類を設定
```

### PCFShadowMap (Percentage Closer Filtering)

**概要と重要性:**

PCF (Percentage Closer Filtering) シャドウマップは、シャドウマップの基本的な実装を改善したものです。シャドウの境界を滑らかにするために、複数のシャドウマップサンプルを平均化します。デフォルトで使用されるシャドウマップで、パフォーマンスと品質のバランスが取れています。

**特徴と利点:**

*   基本的なシャドウマッピングよりも滑らかな影を生成します。
*   処理負荷が比較的低いです。
*   多くの環境で良好な結果が得られます。

**基本的な使い方:**

特に設定は不要です。`renderer.shadowMap.enabled = true;` を設定するだけで、自動的にPCFシャドウマップが使用されます。

**応用例とユースケース:**

*   一般的なゲームやアプリケーション
*   リアルタイムレンダリング
*   パフォーマンスが重要な環境

### PCFSoftShadowMap

**概要と重要性:**

PCFSoftShadowMapは、PCFShadowMapをさらに改善したものです。より多くのシャドウマップサンプルを平均化することで、さらに滑らかな影を生成します。

**特徴と利点:**

*   PCFShadowMapよりもさらに滑らかな影を生成します。
*   影の境界が自然に見えます。

**基本的な使い方:**

```javascript
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
```

**注意点:**

*   PCFSoftShadowMapは、PCFShadowMapよりも処理負荷が高くなります。
*   特に高い解像度で使用すると、パフォーマンスに影響を与える可能性があります。

**応用例とユースケース:**

*   高品質なビジュアライゼーション
*   建築物のレンダリング
*   高品質なゲーム

### BasicShadowMap

**概要と重要性:**

BasicShadowMapは、最も基本的なシャドウマッピングの実装です。シャドウマップサンプルを1つだけ使用するため、影の境界がギザギザになりやすいです。

**特徴と利点:**

*   処理負荷が最も低いシャドウマッピング手法です。
*   非常に古いデバイスや、極端にパフォーマンスが限られた環境で使用できます。

**基本的な使い方:**

```javascript
renderer.shadowMap.type = THREE.BasicShadowMap;
```

**注意点:**

*   影の品質は最も低いです。
*   できる限り、PCFShadowMapまたはPCFSoftShadowMapを使用することを推奨します。

**応用例とユースケース:**

*   非常に古いデバイス
*   極端にパフォーマンスが限られた環境
*   影の品質が重要でない場合

## シャドウのトラブルシューティング

### シャドウがギザギザになる

**原因:**

*   シャドウマップの解像度が低い。
*   シャドウマップの種類がBasicShadowMapである。

**解決策:**

*   シャドウマップの解像度を上げる。
*   PCFShadowMapまたはPCFSoftShadowMapを使用する。
*   `shadow.bias` の値を調整する (後述)。

### シャドウが途切れる

**原因:**

*   光源の`shadow.camera.near`と`shadow.camera.far`の値が適切でない。
*   オブジェクトが光源のシャドウカメラの範囲外にある。

**解決策:**

*   `shadow.camera.near`と`shadow.camera.far`の値を調整する。オブジェクト全体がシャドウカメラの範囲内に収まるように調整してください。
*   光源の位置を調整する。

### シャドウが正しく表示されない

**原因:**

*   `renderer.shadowMap.enabled = true;`が設定されていない。
*   `object.castShadow = true;`または`object.receiveShadow = true;`が設定されていない。
*   マテリアルが影を受け取るように設定されていない (MeshStandardMaterialなどを使用)。
*   シャドウマップのバイアス (shadow.bias) が適切でない。

**解決策:**

*   `renderer.shadowMap.enabled = true;`を設定する。
*   `object.castShadow = true;`と`object.receiveShadow = true;`を適切に設定する。
*   MeshStandardMaterialまたはMeshLambertMaterialを使用する。これらのマテリアルは、デフォルトで影を受け取るように設定されています。
*  `shadow.bias` の値を調整する。

**shadow.biasについて:**

`shadow.bias`は、シャドウマップの精度を高めるために使用されるパラメータです。シャドウマップは、光源から見たオブジェクトの深度情報を記録しますが、深度情報の誤差によって、オブジェクト自身に影ができてしまう現象 (シャドウアクネ) が発生することがあります。`shadow.bias`は、この誤差を補正し、シャドウアクネを軽減するために使用されます。

```javascript
directionalLight.shadow.bias = -0.0005; // 一般的には小さな負の値を設定
```

`shadow.bias`の値を小さくすると、シャドウアクネは軽減されますが、影がオブジェクトから離れて見える現象が発生することがあります。逆に、`shadow.bias`の値を大きくすると、影がオブジェクトに近づきますが、シャドウアクネが発生しやすくなります。

**実践的なテクニック:**

*   **シャドウバイアスのアニメーション:** オブジェクトの動きに合わせて、`shadow.bias`の値を動的に調整することで、より自然な影を生成することができます。
*   **シャドウマップのデバッグ:** シャドウマップをテクスチャとして表示することで、シャドウマップの問題を特定することができます。
