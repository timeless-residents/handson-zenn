# 第6章：光 (Light) - シーンを照らす

この章では、Three.jsにおけるライティングの基礎から応用までを徹底的に解説します。光はシーンの雰囲気やオブジェクトの形状を表現する上で非常に重要な要素です。適切なライティングは、モデルのリアリティを高め、没入感のある体験を提供します。この章を通じて、Three.jsのライティングに関する深い知識と実践的なスキルを身につけ、あなたの3Dシーンをより魅力的なものにしましょう。

## 環境光 (AmbientLight)

### 概要と重要性

環境光は、シーン全体を均一に照らす光です。影を作り出すことはなく、シーンの全体的な明るさを調整する役割を果たします。特に、他の種類のライトと組み合わせて使用することで、影の暗さを和らげ、細部を見やすくする効果があります。

### 特徴と利点

*   **均一な照明:** シーン全体を均一に照らすため、オブジェクトの位置に関わらず明るさが一定です。
*   **手軽さ:** 設定が簡単で、すぐにシーンに適用できます。
*   **影の緩和:** 他のライトによって生成された影を弱め、より自然な見え方を実現します。

### 事前準備と前提条件

Three.jsの基本的なセットアップが完了していることを前提とします。具体的には、シーン、カメラ、レンダラーが作成済みであり、基本的なオブジェクトの表示ができる状態である必要があります。

### 基本的な使い方

環境光を作成するには、`THREE.AmbientLight`クラスを使用します。以下のコードは、白い環境光を作成し、シーンに追加する例です。

```javascript
// シーンの作成 (既に存在することを想定)
const scene = new THREE.Scene();

// 環境光の作成
const ambientLight = new THREE.AmbientLight( 0xffffff, 0.5 ); // 色：白、強さ：0.5
scene.add( ambientLight );

// ... レンダリングループ ...
```

*   `0xffffff`は16進数表記で白を表します。色を変更することで、シーン全体の雰囲気を大きく変えることができます。
*   2番目の引数は`intensity`（強さ）を表します。0から1の範囲で指定し、光の強さを調整します。

### 実践的なテクニック

環境光の色と強さを調整することで、シーンの雰囲気を大きく変えることができます。例えば、夕焼けのような暖かみのあるシーンを演出するには、オレンジ色に近い色を使用し、強さを少し弱めるのが効果的です。

```javascript
const ambientLight = new THREE.AmbientLight( 0xffa500, 0.3 ); // 色：オレンジ、強さ：0.3
scene.add( ambientLight );
```

### 応用例とユースケース

*   **ゲーム:** 夜のシーンで、わずかな光を表現するために使用します。
*   **建築ビジュアライゼーション:** 室内の全体的な明るさを調整するために使用します。
*   **製品プレゼンテーション:** モデルの細部を強調し、見やすくするために使用します。

### トラブルシューティング

*   **シーンが明るすぎる場合:** 環境光の強さを弱めるか、色を暗めに調整します。
*   **シーンが暗すぎる場合:** 環境光の強さを強めるか、色を明るめに調整します。
*   **他のライトの効果が薄れる場合:** 環境光の強さを調整し、他のライトとのバランスを取ります。

### まとめと次のステップ

環境光は、シーンの基本的な明るさを調整するために不可欠なライトです。色と強さを調整することで、シーンの雰囲気を大きく変えることができます。次のステップでは、特定の方向から光を当てる平行光源について学びます。

## 平行光源 (DirectionalLight)

### 概要と重要性

平行光源（DirectionalLight）は、太陽光のように、無限遠から特定の方向に平行な光線を照射する光源です。この光は、位置情報を持たず、方向のみを持ちます。そのため、オブジェクトのサイズに関わらず、均一な影を生成することができます。建築ビジュアライゼーションや大規模な屋外シーンでよく使用されます。

### 特徴と利点

*   **均一な影:** オブジェクトのサイズや位置に関わらず、均一な影を生成します。
*   **効率的な計算:** 光源の位置を考慮する必要がないため、比較的計算コストが低いです。
*   **自然な太陽光の表現:** 太陽光を模倣するのに適しています。

### 事前準備と前提条件

Three.jsの基本的なセットアップが完了していること、および環境光の知識があることを前提とします。

### 基本的な使い方

平行光源を作成するには、`THREE.DirectionalLight`クラスを使用します。以下のコードは、白い平行光源を作成し、シーンに追加する例です。

```javascript
// シーンの作成 (既に存在することを想定)
const scene = new THREE.Scene();

// 平行光源の作成
const directionalLight = new THREE.DirectionalLight( 0xffffff, 0.5 ); // 色：白、強さ：0.5
directionalLight.position.set( 1, 1, 1 ); // 光の方向を設定 (原点から(1, 1, 1)への方向)
scene.add( directionalLight );

// ... レンダリングループ ...
```

*   `position`プロパティは、光源の位置ではなく、光の方向を示します。実際には、原点から指定した座標へのベクトルが光の方向となります。
*   シャドウを有効にするには、いくつかの設定が必要です。後述します。

### 実践的なテクニック

平行光源の方向を調整することで、時間帯や季節感を表現することができます。例えば、朝焼けや夕焼けを表現するには、光の色をオレンジ色や赤色に近づけ、方向を水平線近くに設定します。

```javascript
directionalLight.color.set( 0xff8c00 ); // オレンジ色
directionalLight.position.set( 1, -1, -1 ); // 地平線近くからの光
```

### シャドウの設定

平行光源でシャドウを生成するには、以下の手順が必要です。

1.  レンダラーでシャドウを有効にする。
2.  光源でシャドウを有効にする。
3.  シャドウを生成するオブジェクトで`castShadow`プロパティを`true`に設定する。
4.  シャドウを受け取るオブジェクトで`receiveShadow`プロパティを`true`に設定する。

```javascript
// レンダラーの設定
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // シャドウのタイプ (オプション)

// 光源の設定
directionalLight.castShadow = true;

// シャドウの解像度を設定 (オプション)
directionalLight.shadow.mapSize.width = 512;
directionalLight.shadow.mapSize.height = 512;

// シャドウの範囲を設定 (重要)
directionalLight.shadow.camera.near = 0.5;
directionalLight.shadow.camera.far = 500;
directionalLight.shadow.camera.left = -5;
directionalLight.shadow.camera.right = 5;
directionalLight.shadow.camera.top = 5;
directionalLight.shadow.camera.bottom = -5;

// シャドウを生成するオブジェクト
cube.castShadow = true;

// シャドウを受け取るオブジェクト
plane.receiveShadow = true;
```

*   `shadow.camera`の各プロパティは、シャドウを生成するカメラの視錐台を定義します。これらの値を適切に設定しないと、シャドウが正しく表示されないことがあります。特に`near`と`far`の値は重要です。
*   `PCFSoftShadowMap`は、より滑らかなシャドウを生成するためのオプションです。

### 応用例とユースケース

*   **建築ビジュアライゼーション:** 太陽光をシミュレートし、建物や庭の影を表現します。
*   **ゲーム:** 屋外シーンで、時間帯や天候の変化を表現します。
*   **シミュレーション:** 自然環境における光と影の影響を分析します。

### トラブルシューティング

*   **シャドウが表示されない場合:**
    *   レンダラーでシャドウが有効になっているか確認します。
    *   光源でシャドウが有効になっているか確認します。
    *   オブジェクトの`castShadow`および`receiveShadow`プロパティが正しく設定されているか確認します。
    *   `shadow.camera`のパラメータが適切に設定されているか確認します。特に`near`と`far`の値が重要です。
*   **シャドウがギザギザになる場合:**
    *   `shadow.mapSize`の値を大きくします。ただし、計算コストが増加します。
    *   シャドウのタイプを`THREE.PCFSoftShadowMap`に変更します。
*   **パフォーマンスが低下する場合:**
    *   シャドウの解像度を下げます。
    *   シャドウを生成するオブジェクトの数を減らします。

### まとめと次のステップ

平行光源は、均一な影を生成し、自然な太陽光を表現するのに適した光源です。シャドウの設定にはいくつかの手順が必要ですが、適切に設定することで、シーンのリアリティを大幅に向上させることができます。次のステップでは、特定の位置から放射状に光を当てる点光源について学びます。

## 点光源 (PointLight)

### 概要と重要性

点光源（PointLight）は、電球のように、特定の位置から全方向に光を放射する光源です。光は距離が離れるほど減衰し、オブジェクトの形状や質感の表現に大きく貢献します。インテリアの照明や炎などの表現に最適です。

### 特徴と利点

*   **全方向への照射:** 特定の位置から全方向に光を放射するため、周囲のオブジェクトを自然に照らします。
*   **距離による減衰:** 光は距離が離れるほど減衰するため、現実的な照明効果を再現できます。
*   **柔軟性:** 位置、色、強さ、距離を調整することで、様々な照明効果を表現できます。

### 事前準備と前提条件

Three.jsの基本的なセットアップが完了していること、および環境光と平行光源の知識があることを前提とします。

### 基本的な使い方

点光源を作成するには、`THREE.PointLight`クラスを使用します。以下のコードは、白い点光源を作成し、シーンに追加する例です。

```javascript
// シーンの作成 (既に存在することを想定)
const scene = new THREE.Scene();

// 点光源の作成
const pointLight = new THREE.PointLight( 0xffffff, 1, 100 ); // 色：白、強さ：1、距離：100
pointLight.position.set( 0, 10, 0 ); // 光源の位置を設定
scene.add( pointLight );

// ... レンダリングループ ...
```

*   3番目の引数`distance`は、光が減衰し始める距離を表します。この距離を超えると、光の強さが指数関数的に減衰します。0を指定すると、距離による減衰は発生しません。
*   シャドウを有効にするには、平行光源と同様に、いくつかの設定が必要です。

### 実践的なテクニック

点光源の距離を調整することで、照明範囲を制御することができます。また、色温度を調整することで、暖色系の照明や寒色系の照明を表現できます。

```javascript
pointLight.distance = 50; // 照明範囲を狭める
pointLight.color.set( 0xffd700 ); // 暖色系の照明
```

### シャドウの設定

点光源でシャドウを生成するには、平行光源と同様の手順が必要です。ただし、点光源のシャドウは、キューブマップを使用して生成されるため、いくつかの違いがあります。

```javascript
// レンダラーの設定
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // シャドウのタイプ (オプション)

// 光源の設定
pointLight.castShadow = true;

// シャドウの解像度を設定 (オプション)
pointLight.shadow.mapSize.width = 512;
pointLight.shadow.mapSize.height = 512;

// シャドウの範囲を設定 (重要)
pointLight.shadow.camera.near = 0.1;
pointLight.shadow.camera.far = 1000;

// シャドウを生成するオブジェクト
cube.castShadow = true;

// シャドウを受け取るオブジェクト
plane.receiveShadow = true;
```

*   点光源のシャドウは、`shadow.camera`の`fov`（視野角）プロパティを持ちません。代わりに、キューブマップを使用して全方向のシャドウを生成します。
*   点光源のシャドウは、平行光源に比べて計算コストが高いため、パフォーマンスに注意が必要です。

### 応用例とユースケース

*   **インテリアデザイン:** 室内の照明をシミュレートし、雰囲気のある空間を表現します。
*   **ゲーム:** 炎やランプなどの光源を表現し、リアリティを高めます。
*   **VFX:** 特殊効果として、爆発や魔法などの光を表現します。

### トラブルシューティング

*   **シャドウが表示されない場合:**
    *   レンダラーでシャドウが有効になっているか確認します。
    *   光源でシャドウが有効になっているか確認します。
    *   オブジェクトの`castShadow`および`receiveShadow`プロパティが正しく設定されているか確認します。
    *   `shadow.camera`の`near`と`far`の値が適切に設定されているか確認します。
*   **シャドウが不自然な場合:**
    *   `shadow.mapSize`の値を大きくします。ただし、計算コストが増加します。
    *   `distance`の値を調整し、照明範囲を調整します。
*   **パフォーマンスが低下する場合:**
    *   シャドウの解像度を下げます。
    *   シャドウを生成するオブジェクトの数を減らします。
    *   点光源の数を減らします。

### まとめと次のステップ

点光源は、全方向に光を放射し、距離による減衰を伴う光源です。インテリアの照明や炎などの表現に最適です。シャドウの設定にはいくつかの注意点がありますが、適切に設定することで、シーンのリアリティを大幅に向上させることができます。次のステップでは、特定の方向へ円錐状に光を照射するスポットライトについて学びます。

## スポットライト (SpotLight)

### 概要と重要性

スポットライト（SpotLight）は、劇場で使用される照明のように、特定の位置から円錐状に光を照射する光源です。照らす方向、範囲、減衰などを細かく制御できるため、特定のオブジェクトを強調したり、ドラマチックな効果を生み出すのに適しています。

### 特徴と利点

*   **指向性のある照明:** 特定の方向へ光を照射するため、オブジェクトの一部を強調することができます。
*   **柔軟な制御:** 位置、方向、角度、減衰などを細かく調整できます。
*   **ドラマチックな効果:** 特定のオブジェクトに焦点を当てることで、ドラマチックなシーンを演出できます。

### 事前準備と前提条件

Three.jsの基本的なセットアップが完了していること、および環境光、平行光源、点光源の知識があることを前提とします。

### 基本的な使い方

スポットライトを作成するには、`THREE.SpotLight`クラスを使用します。以下のコードは、白いスポットライトを作成し、シーンに追加する例です。

```javascript
// シーンの作成 (既に存在することを想定)
const scene = new THREE.Scene();

// スポットライトの作成
const spotLight = new THREE.SpotLight( 0xffffff, 1 ); // 色：白、強さ：1
spotLight.position.set( 0, 20, 0 ); // 光源の位置を設定
spotLight.target.position.set( 0, 0, 0 ); // 照らすターゲットの位置を設定
scene.add( spotLight );
scene.add( spotLight.target ); // ターゲットをシーンに追加 (重要)

// ... レンダリングループ ...
```

*   `target`プロパティは、スポットライトが照らすターゲットとなるオブジェクト（`THREE.Object3D`）を指定します。このターゲットの位置に向かって光が照射されます。
*   **重要:** ターゲットオブジェクトをシーンに追加することを忘れないでください。
*   スポットライトの角度や減衰などを調整するには、以下のプロパティを使用します。
    *   `angle`: スポットライトの照射角度（ラジアン）。
    *   `penumbra`: スポットライトのエッジのぼかし具合（0〜1）。
    *   `distance`: 光が減衰し始める距離。
    *   `decay`: 距離による減衰率。
*   シャドウを有効にするには、他の光源と同様に、いくつかの設定が必要です。

### 実践的なテクニック

スポットライトの角度を調整することで、照明範囲を制御することができます。また、`penumbra`を調整することで、エッジのぼかし具合を調整し、より自然な照明効果を演出できます。

```javascript
spotLight.angle = Math.PI / 6; // 照射角度を狭める
spotLight.penumbra = 0.5; // エッジをぼかす
```

### シャドウの設定

スポットライトでシャドウを生成するには、平行光源や点光源と同様の手順が必要です。

```javascript
// レンダラーの設定
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // シャドウのタイプ (オプション)

// 光源の設定
spotLight.castShadow = true;

// シャドウの解像度を設定 (オプション)
spotLight.shadow.mapSize.width = 512;
spotLight.shadow.mapSize.height = 512;

// シャドウの範囲を設定 (重要)
spotLight.shadow.camera.near = 0.5;
spotLight.shadow.camera.far = 200;
spotLight.shadow.camera.fov = 30; // 視野角

// シャドウを生成するオブジェクト
cube.castShadow = true;

// シャドウを受け取るオブジェクト
plane.receiveShadow = true;
```

*   スポットライトのシャドウは、`shadow.camera`の`fov`（視野角）プロパティを持ちます。この値を調整することで、シャドウの範囲を制御できます。
*   スポットライトのシャドウは、他の光源に比べて計算コストが高いため、パフォーマンスに注意が必要です。

### 応用例とユースケース

*   **ステージ照明:** 舞台上の人物やオブジェクトを照らし出し、演出効果を高めます。
*   **製品プレゼンテーション:** 製品の一部を強調し、魅力を引き立てます。
*   **ゲーム:** 懐中電灯やサーチライトなどの光源を表現し、ゲームプレイを盛り上げます。

### トラブルシューティング

*   **スポットライトが照らさない場合:**
    *   `target`プロパティが正しく設定されているか確認します。
    *   ターゲットオブジェクトがシーンに追加されているか確認します。
    *   スポットライトの位置とターゲットの位置関係が適切か確認します。
*   **シャドウが表示されない場合:**
    *   レンダラーでシャドウが有効になっているか確認します。
    *   光源でシャドウが有効になっているか確認します。
    *   オブジェクトの`castShadow`および`receiveShadow`プロパティが正しく設定されているか確認します。
    *   `shadow.camera`のパラメータが適切に設定されているか確認します。特に`near`、`far`、`fov`の値が重要です。
*   **シャドウが不自然な場合:**
    *   `shadow.mapSize`の値を大きくします。ただし、計算コストが増加します。
    *   `angle`と`penumbra`の値を調整し、照明範囲とエッジのぼかし具合を調整します。
*   **パフォーマンスが低下する場合:**
    *   シャドウの解像度を下げます。
    *   シャドウを生成するオブジェクトの数を減らします。
    *   スポットライトの数を減らします。

### まとめと次のステップ

スポットライトは、特定の方向へ円錐状に光を照射する光源です。照らす方向、範囲、減衰などを細かく制御できるため、特定のオブジェクトを強調したり、ドラマチックな効果を生み出すのに適しています。シャドウの設定にはいくつかの注意点がありますが、適切に設定することで、シーンのリアリティを大幅に向上させることができます。次のステップでは、これらの光源を可視化し、調整を容易にするヘルパーについて学びます。

## ヘルパー (LightHelper) による可視化

### 概要と重要性

Three.jsの`LightHelper`は、光源の種類に応じて、光源の位置、方向、範囲などを視覚的に表示するためのツールです。これにより、シーン内の光源の位置や設定を直感的に把握し、調整することができます。特に、複雑なシーンや複数の光源を使用する場合に非常に役立ちます。

### 特徴と利点

*   **視覚的な表現:** 光源の位置、方向、範囲などを視覚的に表示します。
*   **直感的な調整:** 光源の設定を直感的に調整することができます。
*   **デバッグの容易化:** 光源に関する問題を特定しやすくなります。

### 事前準備と前提条件

Three.jsの基本的なセットアップが完了していること、および各種光源（環境光、平行光源、点光源、スポットライト）の知識があることを前提とします。

### 基本的な使い方

各光源に対応する`LightHelper`クラスを使用します。

*   **`THREE.AmbientLightHelper`**: 環境光にはヘルパーは不要です。
*   **`THREE.DirectionalLightHelper`**: 平行光源用
*   **`THREE.PointLightHelper`**: 点光源用
*   **`THREE.SpotLightHelper`**: スポットライト用

以下のコードは、平行光源のヘルパーを作成し、シーンに追加する例です。

```javascript
// シーンの作成 (既に存在することを想定)
const scene = new THREE.Scene();

// 平行光源の作成 (既に存在することを想定)
const directionalLight = new THREE.DirectionalLight( 0xffffff, 0.5 );
directionalLight.position.set( 1, 1, 1 );
scene.add( directionalLight );

// 平行光源ヘルパーの作成
const directionalLightHelper = new THREE.DirectionalLightHelper( directionalLight, 5 ); // 光源、サイズ
scene.add( directionalLightHelper );

// ... レンダリングループ ...

// レンダリングループ内でヘルパーを更新する (特にSpotLightHelper)
directionalLightHelper.update();
```

*   `DirectionalLightHelper`のコンストラクタには、光源とサイズ（ヘルパーの大きさ）を渡します。
*   `SpotLightHelper`は、光源の設定が変更された場合に、`update()`メソッドを呼び出して、ヘルパーの表示を更新する必要があります。

```javascript
// スポットライトヘルパーの作成
const spotLightHelper = new THREE.SpotLightHelper( spotLight );
scene.add( spotLightHelper );

// ... レンダリングループ ...

// レンダリングループ内でヘルパーを更新する (重要)
spotLightHelper.update();
```

### 実践的なテクニック

`LightHelper`を使用することで、光源の位置や方向をインタラクティブに調整することができます。例えば、`OrbitControls`などを使用してカメラを操作しながら、`LightHelper`の位置や方向をマウスでドラッグすることで、最適な照明設定を見つけることができます。

### 応用例とユースケース

*   **照明デザイン:** 3Dモデルの照明を調整し、リアリティを高めます。
*   **ゲーム開発:** ゲーム内の光源の位置や方向を調整し、ゲームプレイを盛り上げます。
*   **教育:** 光源の仕組みを視覚的に理解するための教材として活用します。

### トラブルシューティング

*   **ヘルパーが表示されない場合:**
    *   ヘルパーがシーンに追加されているか確認します。
    *   ヘルパーのサイズが小さすぎないか確認します。
    *   `SpotLightHelper`の場合、`update()`メソッドが呼び出されているか確認します。
*   **ヘルパーが邪魔な場合:**
    *   ヘルパーの表示/非表示を切り替える機能を追加します。
    *   ヘルパーのサイズを小さくします。
    *   デバッグが終わったら、ヘルパーを削除します。
