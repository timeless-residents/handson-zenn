## 第3章：形状 (Geometry) - 3Dモデルの基礎

この章では、Three.jsにおける3Dモデルの基礎となる形状（Geometry）について深く掘り下げていきます。Three.jsの表現力豊かな3D世界を構築するために、基本形状の理解から、カスタムジオメトリの作成、そしてそれらを組み合わせたり変形させたりする応用テクニックまで、段階的に解説します。初心者の方から、より高度な表現を追求したい上級者の方まで、幅広い読者層にとって価値のある内容を目指します。

### 基本形状 (BoxGeometry, SphereGeometry, PlaneGeometryなど)

#### 概要と重要性

3Dモデルの基本は、立方体、球、平面といったシンプルな形状から始まります。これらの基本的な形状を理解することは、複雑なモデルを構築するための土台となります。Three.jsでは、これらの形状を簡単に生成するための`BoxGeometry`, `SphereGeometry`, `PlaneGeometry`などのクラスが用意されています。

#### 特徴と利点

これらの基本形状は、パラメータを調整することで、様々な形状やサイズに変化させることができます。また、パフォーマンスが高く、シンプルな形状であれば大量に配置しても負荷が少ないという利点があります。

#### 事前準備と前提条件

*   Three.jsの基本的なセットアップが完了していること（`Scene`, `Camera`, `Renderer`の定義）。
*   JavaScriptの基本的な知識。

#### 基本的な使い方

**1. BoxGeometry (立方体)**

```javascript
// BoxGeometryの作成 (幅, 高さ, 奥行き)
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );
```

*   `BoxGeometry(width, height, depth, widthSegments, heightSegments, depthSegments)`
    *   `width`: 幅
    *   `height`: 高さ
    *   `depth`: 奥行き
    *   `widthSegments`: 幅方向の分割数 (省略可能)
    *   `heightSegments`: 高さ方向の分割数 (省略可能)
    *   `depthSegments`: 奥行き方向の分割数 (省略可能)

`widthSegments`, `heightSegments`, `depthSegments`を増やすほど、立方体はより細かく分割され、複雑な変形を適用しやすくなります。ただし、ポリゴン数が増えるため、パフォーマンスに影響を与える可能性があります。

**2. SphereGeometry (球)**

```javascript
// SphereGeometryの作成 (半径, 幅セグメント, 高さセグメント)
const geometry = new THREE.SphereGeometry( 1, 32, 32 );
const material = new THREE.MeshBasicMaterial( { color: 0xff0000 } );
const sphere = new THREE.Mesh( geometry, material );
scene.add( sphere );
```

*   `SphereGeometry(radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength)`
    *   `radius`: 半径
    *   `widthSegments`: 水平方向の分割数
    *   `heightSegments`: 垂直方向の分割数
    *   `phiStart`: 水平方向の開始角度 (ラジアン)
    *   `phiLength`: 水平方向の角度範囲 (ラジアン)
    *   `thetaStart`: 垂直方向の開始角度 (ラジアン)
    *   `thetaLength`: 垂直方向の角度範囲 (ラジアン)

`widthSegments`, `heightSegments`を増やすほど、球体はより滑らかになります。角度パラメータを使用することで、球体の一部のみを生成できます。

**3. PlaneGeometry (平面)**

```javascript
// PlaneGeometryの作成 (幅, 高さ)
const geometry = new THREE.PlaneGeometry( 5, 5 );
const material = new THREE.MeshBasicMaterial( { color: 0x0000ff, side: THREE.DoubleSide } ); // 裏面も表示
const plane = new THREE.Mesh( geometry, material );
scene.add( plane );
```

*   `PlaneGeometry(width, height, widthSegments, heightSegments)`
    *   `width`: 幅
    *   `height`: 高さ
    *   `widthSegments`: 幅方向の分割数 (省略可能)
    *   `heightSegments`: 高さ方向の分割数 (省略可能)

平面はデフォルトでは片面しか表示されません。`THREE.DoubleSide`マテリアルを使用することで、両面を表示できます。

#### 実践的なテクニック

*   **形状のスケール、回転、移動:**  `mesh.scale.set(x, y, z)`, `mesh.rotation.set(x, y, z)`, `mesh.position.set(x, y, z)`を使って、形状の大きさを変えたり、回転させたり、位置を調整したりできます。これらのプロパティをアニメーションさせることで、動きのある表現も可能です。

```javascript
cube.scale.set(2, 0.5, 1); // 幅2倍、高さ半分
cube.rotation.x = Math.PI / 4; // X軸方向に45度回転
cube.position.y = 1; // Y軸方向に1移動
```

#### 応用例とユースケース

*   **ゲーム:**  地形や建物の基礎として。
*   **建築ビジュアライゼーション:**  部屋の壁や床など。
*   **データビジュアライゼーション:**  グラフの棒として。
*   **教育:**  幾何学的な形状の学習。

#### 頂点、面、法線の概念

*   **頂点 (Vertex):** 形状を構成する点。3次元空間上の座標を持ちます。
*   **面 (Face):** 3つ以上の頂点によって囲まれた領域。通常は三角形です。
*   **法線 (Normal):** 面に対して垂直なベクトル。面の向きを示し、光の当たり方を計算するために使用されます。

これらの概念は、カスタムジオメトリを作成する上で非常に重要になります。

#### トラブルシューティング

*   **形状が表示されない:** マテリアルの色が背景色と同じ、またはライトが当たっていない可能性があります。`side: THREE.DoubleSide` を設定して両面表示を試すのも有効です。
*   **形状がカクカクしている:**  `widthSegments`や`heightSegments`の値を大きくして、分割数を増やすと滑らかになります。ただし、パフォーマンスとのトレードオフがあります。

#### まとめと次のステップ

基本形状は、3Dモデルの基礎となる重要な要素です。パラメータを調整することで様々な形状を作成できること、そして頂点、面、法線という基本的な概念を理解できたと思います。次のステップでは、`BufferGeometry`を使って、より複雑なカスタムジオメトリを作成する方法を学びます。

### カスタムジオメトリの作成

#### 概要と重要性

Three.jsの`BufferGeometry`を使用すると、頂点データを直接操作して、独自の形状を自由に作成できます。基本形状だけでは表現できない、複雑でユニークな3Dモデルを作成する際に不可欠な技術です。

#### 特徴と利点

*   **自由度が高い:** どのような形状でも作成可能。
*   **最適化されたパフォーマンス:** 必要なデータのみをGPUに送信するため、パフォーマンスが良い。
*   **ローレベルな制御:** 頂点データ、UV座標、法線ベクトルなどを直接操作可能。

#### 事前準備と前提条件

*   基本形状の知識
*   JavaScriptの配列操作
*   ベクトルの基本的な知識 (法線ベクトルの計算に使用)

#### 基本的な使い方

```javascript
// 頂点座標の配列
const vertices = new Float32Array( [
    -1.0, -1.0,  1.0, // 頂点1
     1.0, -1.0,  1.0, // 頂点2
     1.0,  1.0,  1.0, // 頂点3
    -1.0,  1.0,  1.0  // 頂点4
] );

// インデックス配列 (三角形を定義)
const indices = new Uint16Array( [
    0, 1, 2, // 面1
    2, 3, 0  // 面2
] );

// BufferGeometryの作成
const geometry = new THREE.BufferGeometry();

// 頂点バッファの設定
geometry.setAttribute( 'position', new THREE.BufferAttribute( vertices, 3 ) );

// インデックスバッファの設定
geometry.setIndex( new THREE.BufferAttribute( indices, 1 ) );

// 法線ベクトルの自動計算
geometry.computeVertexNormals();

// マテリアルとメッシュの作成
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );
```

**コード解説:**

1.  **頂点座標の配列 (vertices):** 各頂点のX, Y, Z座標を順番に格納します。`Float32Array`は、浮動小数点数を効率的に扱うための型付き配列です。この例では、4つの頂点を持つ四角形を定義しています。
2.  **インデックス配列 (indices):** 頂点のインデックスを使用して、三角形を定義します。`Uint16Array`は、符号なし16ビット整数を効率的に扱うための型付き配列です。この例では、2つの三角形で四角形を構成しています。
3.  **BufferGeometryの作成:** `THREE.BufferGeometry`のインスタンスを作成します。
4.  **頂点バッファの設定:** `geometry.setAttribute()`を使って、`position`属性に頂点座標のバッファを設定します。`THREE.BufferAttribute(vertices, 3)`は、頂点座標の配列と、各頂点の要素数 (この場合はX, Y, Zの3つ) を指定します。
5.  **インデックスバッファの設定:** `geometry.setIndex()`を使って、インデックスバッファを設定します。
6.  **法線ベクトルの自動計算:** `geometry.computeVertexNormals()`を使って、各頂点の法線ベクトルを自動的に計算します。法線ベクトルは、光の当たり方を計算するために重要です。
7.  **マテリアルとメッシュの作成:** 通常のメッシュと同様に、マテリアルとメッシュを作成し、シーンに追加します。

#### UV座標の設定

UV座標は、テクスチャをジオメトリにマッピングするために使用されます。0から1の範囲で定義され、各頂点に割り当てられます。

```javascript
// UV座標の配列
const uvs = new Float32Array( [
    0.0, 0.0,
    1.0, 0.0,
    1.0, 1.0,
    0.0, 1.0
] );

// UVバッファの設定
geometry.setAttribute( 'uv', new THREE.BufferAttribute( uvs, 2 ) );

// マテリアルの設定 (テクスチャを使用)
const texture = new THREE.TextureLoader().load( 'texture.jpg' );
const material = new THREE.MeshBasicMaterial( { map: texture } );
```

`uv`属性にUV座標のバッファを設定します。`THREE.TextureLoader()`を使ってテクスチャをロードし、マテリアルの`map`プロパティに設定します。

#### 法線ベクトルの計算

`geometry.computeVertexNormals()`で自動計算することもできますが、複雑な形状の場合や、特定の効果を出すために、手動で計算する必要がある場合があります。

```javascript
// 法線ベクトルの配列 (各頂点に対して)
const normals = new Float32Array( [
    0.0, 0.0, 1.0, // 頂点1
    0.0, 0.0, 1.0, // 頂点2
    0.0, 0.0, 1.0, // 頂点3
    0.0, 0.0, 1.0  // 頂点4
] );

// 法線バッファの設定
geometry.setAttribute( 'normal', new THREE.BufferAttribute( normals, 3 ) );
```

#### 実践的なテクニック

*   **動的なジオメトリ:**  `BufferAttribute`の`needsUpdate`プロパティを`true`に設定することで、頂点データを更新し、アニメーションなどの動的な表現を実現できます。

```javascript
// アニメーションループ内で
vertices[0] += 0.01; // 頂点1のX座標を更新
geometry.attributes.position.needsUpdate = true; // バッファを更新
```

#### 応用例とユースケース

*   **パーティクルシステム:** 大量のパーティクルを効率的に描画。
*   **地形生成:** リアルタイムに地形を生成・変形。
*   **複雑な形状モデリング:**  基本形状では表現できない、独自の形状を作成。
*   **カスタムシェーダー:**  頂点データをシェーダーに渡し、高度なエフェクトを実現。

#### トラブルシューティング

*   **形状が崩れる:**  頂点座標やインデックスが正しく定義されているか確認。特にインデックスの順番が時計回りまたは反時計回りに統一されているか注意。
*   **テクスチャが正しく表示されない:** UV座標が正しく設定されているか確認。テクスチャのラップモードやフィルタリング設定も確認。
*   **パフォーマンスが悪い:**  頂点数を減らす、または`BufferGeometry`の最適化を検討。不要な属性を削除する。

#### まとめと次のステップ

`BufferGeometry`を使うことで、3Dモデル作成の自由度が大幅に向上します。頂点データ、UV座標、法線ベクトルなどを直接操作することで、独自の形状を作成し、高度なエフェクトを実現できます。次のステップでは、複数のジオメトリを結合したり、ジオメトリを変形させる方法を学びます。

### ジオメトリの結合と変形

#### 概要と重要性

複数のジオメトリを結合することで、複雑なモデルを効率的に作成できます。また、ジオメトリを変形させることで、アニメーションや特殊効果を実現できます。

#### 特徴と利点

*   **効率的なモデル作成:** 複数のパーツを組み合わせて、複雑なモデルを構築。
*   **アニメーションの可能性:** 頂点データをアニメーションさせることで、様々な動きを表現。
*   **特殊効果:** ジオメトリの変形を利用して、ユニークな視覚効果を実現。

#### 事前準備と前提条件

*   基本形状の知識
*   カスタムジオメトリの知識
*   JavaScriptの配列操作

#### 複数のジオメトリを結合する (mergeBufferGeometries)

Three.jsの`BufferGeometryUtils.mergeBufferGeometries()`を使用すると、複数の`BufferGeometry`を一つの`BufferGeometry`に結合できます。

```javascript
import { BufferGeometryUtils } from 'three/examples/jsm/utils/BufferGeometryUtils.js';

// 複数のジオメトリを作成
const geometry1 = new THREE.BoxGeometry( 1, 1, 1 );
const geometry2 = new THREE.SphereGeometry( 0.5, 32, 32 );

// 位置を調整
geometry2.translate( 1.5, 0, 0 );

// ジオメトリを結合
const mergedGeometry = BufferGeometryUtils.mergeBufferGeometries( [ geometry1, geometry2 ] );

// マテリアルとメッシュの作成
const material = new THREE.MeshBasicMaterial( { color: 0xff00ff } );
const mesh = new THREE.Mesh( mergedGeometry, material );
scene.add( mesh );
```

**注意点:**

*   結合するジオメトリは、同じ属性 (position, normal, uvなど) を持っている必要があります。
*   結合後のジオメトリの頂点数は、結合前のジオメトリの頂点数の合計になります。
*   マテリアルは、結合後のジオメトリ全体に適用されます。異なるマテリアルを適用したい場合は、`groups`プロパティを使用する必要があります。

#### ジオメトリを変形する (MorphTargets)

MorphTargetsは、ジオメトリの頂点位置を時間経過とともに変化させることで、アニメーションを実現する技術です。

```javascript
// 基本となるジオメトリ
const geometry = new THREE.SphereGeometry( 1, 32, 32 );

// 変形後のジオメトリ (ターゲット)
const targetGeometry = new THREE.SphereGeometry( 1.2, 32, 32 );

// MorphTargetsの設定
geometry.morphTargets.push( { name: 'target1', vertices: targetGeometry.attributes.position.array } );

// マテリアルの設定 (morphTargetsプロパティをtrueにする)
const material = new THREE.MeshBasicMaterial( { color: 0x00ffff, morphTargets: true } );
const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );

// アニメーションループ内で
mesh.morphTargetInfluences[0] = Math.sin( Date.now() * 0.001 ) * 0.5 + 0.5; // 0から1の範囲で変化
```

**コード解説:**

1.  **基本となるジオメトリ (geometry):** アニメーションのベースとなるジオメトリを作成します。
2.  **変形後のジオメトリ (targetGeometry):** 変形後の形状を表すジオメトリを作成します。この例では、少し膨らんだ球体を作成しています。
3.  **MorphTargetsの設定:** `geometry.morphTargets.push()`を使って、MorphTargetを追加します。`name`はMorphTargetの名前、`vertices`は変形後の頂点座標の配列を指定します。
4.  **マテリアルの設定:** `morphTargets: true`を設定し、MorphTargetsを有効にします。
5.  **アニメーションループ内で:** `mesh.morphTargetInfluences[0]`を使って、MorphTargetの影響度を調整します。0から1の範囲で指定し、0は基本形状、1は変形後の形状を表します。

#### 実践的なテクニック

*   **複数のMorphTargets:** 複数のMorphTargetsを設定することで、より複雑なアニメーションを実現できます。
*   **カスタムシェーダー:** MorphTargetsのデータをシェーダーに渡し、高度なエフェクトを実現できます。
*   **ボーンアニメーションとの組み合わせ:**  ボーンアニメーションとMorphTargetsを組み合わせることで、よりリアルなキャラクターアニメーションを実現できます。

#### 応用例とユースケース

*   **キャラクターアニメーション:** 表情の変化や体の動きを表現。
*   **特殊効果:**  爆発、変形、溶解などの視覚効果。
*   **データビジュアライゼーション:**  データの変化を形状の変化として表現。

#### トラブルシューティング

*   **MorphTargetsが動作しない:**  `morphTargets: true`が設定されているか確認。頂点数が基本形状と変形後の形状で一致しているか確認。
*   **パフォーマンスが悪い:**  MorphTargetの数を減らす、または頂点数を減らすことを検討。

#### まとめと次のステップ

ジオメトリの結合と変形は、3Dモデルの表現力を高めるための強力なツールです。複数のジオメトリを組み合わせることで複雑なモデルを効率的に作成し、MorphTargetsを使ってアニメーションや特殊効果を実現できます。
