## 第11章：ポストエフェクト - 画面全体に効果を付与

ゲームやインタラクティブなアプリケーションにおいて、ポストエフェクトは最終的なビジュアルの印象を大きく左右する重要な要素です。まるで映画の撮影後に行う映像編集のように、レンダリングされた画面全体に対して、色味の調整、光の表現、ノイズの付加など、さまざまな効果をリアルタイムに適用できます。この章では、ポストエフェクトの基本から応用までを丁寧に解説し、あなたの作品のクオリティを一段階向上させるための知識と技術を提供します。

### ポストエフェクトの基本

#### 概要と重要性

ポストエフェクトは、3Dオブジェクトの描画が完了した後、最終的な画面イメージに対して追加される視覚効果です。これにより、3Dモデリングやテクスチャだけでは表現しきれない、より深みのある、あるいは独特な雰囲気を作り出すことができます。特に、没入感を高めたり、特定の感情を喚起したりする際に非常に有効です。

#### 特徴と利点

*   **非破壊編集:** 既存の3Dオブジェクトやシーンデータを変更せずに、画面全体に効果を適用できます。
*   **柔軟性:** さまざまな種類の効果を組み合わせることで、複雑なビジュアル表現が可能です。
*   **パフォーマンス調整:** ポストエフェクトのパラメータを調整することで、見た目のクオリティとパフォーマンスのバランスを取ることができます。
*   **容易な実験:** さまざまなポストエフェクトを簡単に試せるため、ビジュアルスタイルの検討が容易になります。

#### 事前準備と前提条件

この章では、WebGLフレームワークとしてThree.jsを使用します。Three.jsの基本的な知識（シーン、カメラ、レンダラーの扱いなど）があることを前提として解説を進めます。もしThree.jsに不慣れな場合は、公式ドキュメントや入門チュートリアルを参照してください。

```javascript
// Three.jsの基本的なセットアップ
import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
```

#### RenderTargetの利用

ポストエフェクトを実現するためには、まずレンダリング結果を一度画面ではなく、`RenderTarget`というメモリ上のテクスチャに描画する必要があります。これは、レンダーパスを2回行うことを意味します。1回目はシーンを`RenderTarget`に描き込み、2回目は`RenderTarget`の内容を画面に描画する際にポストエフェクトを適用します。

```javascript
// RenderTargetの作成
const renderTarget = new THREE.WebGLRenderTarget(window.innerWidth, window.innerHeight);
```

#### EffectComposerによるポストエフェクトの適用

Three.jsでは、`EffectComposer`というクラスを利用することで、複数のポストエフェクトを簡単に管理し、順番に適用することができます。`EffectComposer`は、`RenderTarget`への描画と、ポストエフェクトの適用を自動的に処理してくれます。

```javascript
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/examples/jsm/postprocessing/RenderPass.js';

// EffectComposerの作成
const composer = new EffectComposer(renderer, renderTarget);

// シーンを描画するためのRenderPassを追加
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// アニメーションループ内での描画処理
function animate() {
    requestAnimationFrame(animate);

    // EffectComposerを使って描画
    composer.render();
}

animate();
```

#### 各パスの順番と設定

`EffectComposer`に`addPass()`で追加されたポストエフェクトは、追加された順番に適用されます。パスの順番は、最終的な見た目に大きな影響を与えるため、注意が必要です。例えば、ブルーム（光の滲み）を適用してから色収差を適用するのと、その逆では、全く異なる結果になります。

各パスには、`enabled`プロパティがあり、これを`false`に設定することで、一時的にパスを無効化できます。デバッグやパフォーマンス調整に便利です。また、`renderToScreen`プロパティを`true`に設定すると、そのパスの結果が直接画面に描画されます。通常、最後のパスのみが`renderToScreen`を`true`に設定します。

### よく使われるポストエフェクト

#### Bloom (光の滲み)

**概要と重要性:** Bloomは、明るい部分から光が滲み出るように見せる効果です。これにより、画面に輝きと柔らかさを加え、より幻想的な雰囲気を演出できます。

**特徴と利点:**

*   画面全体の印象を大きく変えることができる。
*   光の表現を豊かにし、リアリティを高めることができる。
*   少ない計算コストで、視覚的なインパクトを与えることができる。

**基本的な使い方:**

```javascript
import { BloomPass } from 'three/examples/jsm/postprocessing/BloomPass.js';

// BloomPassの作成 (parameters: strength, kernelSize, sigma, blurStrength)
const bloomPass = new BloomPass(1, 25, 4, 256);
composer.addPass(bloomPass);
```

*   `strength`: ブルームの強度。
*   `kernelSize`: ブルームのぼかしに使用されるカーネルのサイズ。
*   `sigma`: ブルームのガウスぼかしの標準偏差。
*   `resolution`: ブルームのエフェクトをレンダリングするために使用される解像度。

**実践的なテクニック:**

*   ブルームを適用する前に、明るい部分だけを抽出するレイヤーマスクを作成することで、より繊細なブルーム効果を実現できます。
*   シーン内の光源の色に合わせて、ブルームの色を調整することで、より自然な見た目にすることができます。

**応用例とユースケース:**

*   夜景のシーンで、街灯やネオンサインを強調する。
*   ファンタジーゲームで、魔法のエフェクトや光の表現を強化する。
*   SF映画で、未来的な都市の雰囲気を演出する。

**トラブルシューティング:**

*   ブルームが強すぎると、画面全体が白っぽくなってしまうため、`strength`パラメータを適切に調整してください。
*   パフォーマンスが低下する場合は、`resolution`パラメータを下げることで、計算コストを削減できます。

#### Glitch (ノイズ)

**概要と重要性:** Glitchは、画面に意図的なノイズや歪みを加える効果です。これにより、不安定さや混乱、あるいはサイバーパンク的な雰囲気を演出できます。

**特徴と利点:**

*   画面に独特な視覚的インパクトを与えることができる。
*   デジタル的な世界観やストーリーテリングを表現するのに適している。
*   比較的少ない計算コストで、効果的な演出が可能。

**基本的な使い方:**

```javascript
import { GlitchPass } from 'three/examples/jsm/postprocessing/GlitchPass.js';

// GlitchPassの作成 (parameters: dt_size)
const glitchPass = new GlitchPass();
composer.addPass(glitchPass);
```

*   `goWild`: Glitchの強さをランダムに変化させるかどうか。
*   `dt_size`: Glitchのブロックサイズ。

**実践的なテクニック:**

*   特定のイベントが発生した際に、一時的にGlitchを適用することで、ドラマチックな演出が可能です。
*   Glitchの効果音と組み合わせることで、より没入感のある体験を作り出すことができます。

**応用例とユースケース:**

*   ホラーゲームで、精神的な不安定さや狂気を表現する。
*   サイバーパンクゲームで、ハッキングやシステムエラーを視覚的に表現する。
*   ミュージックビデオで、アーティスティックな映像効果として使用する。

**トラブルシューティング:**

*   Glitchが激しすぎると、画面が見づらくなってしまうため、`goWild`パラメータや、`dt_size`を調整してください。
*   Glitchの発生頻度が高すぎると、視聴者に不快感を与えてしまう可能性があるため、発生タイミングを慎重に検討してください。

#### FilmGrain (フィルムグレイン)

**概要と重要性:** FilmGrainは、古いフィルムのような粒子状のノイズを画面に加える効果です。これにより、ノスタルジックな雰囲気や、映画のような質感を演出できます。

**特徴と利点:**

*   画面に深みと質感を与えることができる。
*   デジタル映像にアナログ的な温かみを加えることができる。
*   比較的少ない計算コストで、効果的な演出が可能。

**基本的な使い方:**

```javascript
import { FilmPass } from 'three/examples/jsm/postprocessing/FilmPass.js';

// FilmPassの作成 (parameters: noiseIntensity, scanlinesIntensity, scanlinesCount, grayscale)
const filmPass = new FilmPass(0.35, 0.35, 2048, false);
composer.addPass(filmPass);
```

*   `noiseIntensity`: ノイズの強度。
*   `scanlinesIntensity`: スキャンラインの強度。
*   `scanlinesCount`: スキャンラインの数。
*   `grayscale`: グレースケールにするかどうか。

**実践的なテクニック:**

*   FilmGrainの強度を控えめに調整することで、画面に微妙な質感を与えることができます。
*   色収差やビネットなどの効果と組み合わせることで、よりリアルなフィルムの質感を再現できます。

**応用例とユースケース:**

*   歴史的な背景を持つゲームや映画で、時代感を演出する。
*   ドキュメンタリー映画で、リアリティを高める。
*   ポートフォリオサイトで、写真や映像作品に独自のスタイルを与える。

**トラブルシューティング:**

*   FilmGrainが強すぎると、画面が見づらくなってしまうため、`noiseIntensity`パラメータを適切に調整してください。
*   スキャンラインが目立ちすぎる場合は、`scanlinesIntensity`パラメータを下げるか、`scanlinesCount`パラメータを増やすことで改善できます。

#### RGBShift (RGBシフト)

**概要と重要性:** RGBShiftは、画面の色チャンネル（赤、緑、青）をわずかにずらす効果です。これにより、サイケデリックな雰囲気や、レンズの歪みのような効果を演出できます。

**特徴と利点:**

*   画面にユニークな視覚効果を与えることができる。
*   幻想的あるいは不安定な雰囲気を表現するのに適している。
*   比較的少ない計算コストで、効果的な演出が可能。

**基本的な使い方:**

```javascript
import { ShaderPass } from 'three/examples/jsm/postprocessing/ShaderPass.js';
import { RGBShiftShader } from 'three/examples/jsm/shaders/RGBShiftShader.js';

// RGBShiftShaderの作成
const rgbShiftShader = RGBShiftShader;
const rgbShiftPass = new ShaderPass( rgbShiftShader );
composer.addPass(rgbShiftPass);
```

RGBShiftShaderにはuniform変数として `amount` (シフト量) と `angle` (シフトの角度) があります。これらは、`rgbShiftPass.uniforms[ 'amount' ].value` のようにアクセスして値を変更できます。

**実践的なテクニック:**

*   RGBShiftのシフト量を、時間やイベントに応じて変化させることで、ダイナミックな演出が可能です。
*   画面の一部だけにRGBShiftを適用することで、特定のオブジェクトや領域を強調できます。

**応用例とユースケース:**

*   音楽ゲームで、リズムに合わせてRGBShiftを変化させる。
*   シューティングゲームで、被弾時にRGBShiftを適用する。
*   アート作品で、抽象的な視覚表現を追求する。

**トラブルシューティング:**

*   RGBShiftのシフト量が大きすぎると、画面が見づらくなってしまうため、`amount`パラメータを適切に調整してください。
*   角度を固定するだけでなく、時間とともに変化させることで、より動きのある効果が得られます。

### カスタムポストエフェクトの作成

#### 概要と重要性

既存のポストエフェクトに満足できない場合や、より独自の視覚表現を追求したい場合は、シェーダーを使ってカスタムポストエフェクトを作成することができます。シェーダーは、GPU上で実行されるプログラムであり、ピクセル単位で色を操作することができます。

#### 事前準備と前提条件

カスタムポストエフェクトを作成するためには、GLSL（OpenGL Shading Language）の基本的な知識が必要です。GLSLは、シェーダーを記述するための言語であり、C言語に似た構文を持っています。

#### シェーダーを使った独自のポストエフェクトの実装

1.  **シェーダーコードの作成:** GLSLで頂点シェーダーとフラグメントシェーダーを記述します。
2.  **ShaderMaterialの作成:** Three.jsの`ShaderMaterial`クラスを使って、シェーダーコードをマテリアルとして定義します。
3.  **ShaderPassの作成:** `ShaderPass`クラスを使って、カスタムマテリアルをポストエフェクトとして適用します。

**例：シンプルな色反転ポストエフェクト**

```javascript
// 頂点シェーダー
const vertexShader = `
  varying vec2 vUv;

  void main() {
    vUv = uv;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

// フラグメントシェーダー
const fragmentShader = `
  uniform sampler2D tDiffuse;
  varying vec2 vUv;

  void main() {
    vec4 texel = texture2D(tDiffuse, vUv);
    gl_FragColor = vec4(1.0 - texel.r, 1.0 - texel.g, 1.0 - texel.b, texel.a);
  }
`;

import { ShaderMaterial } from 'three';
import { ShaderPass } from 'three/examples/jsm/postprocessing/ShaderPass.js';

// ShaderMaterialの作成
const colorInvertMaterial = new ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    tDiffuse: { value: null }
  }
});

// ShaderPassの作成
const colorInvertPass = new ShaderPass(colorInvertMaterial, "tDiffuse");
composer.addPass(colorInvertPass);
```

この例では、`tDiffuse`という名前のuniform変数に、前のパスの結果（シーンのレンダリング結果）が渡されます。フラグメントシェーダーでは、`texture2D()`関数を使ってテクスチャから色を取得し、各色チャンネルの値を反転させています。

#### 実践的なテクニック

*   `gl_FragCoord`変数を使って、ピクセルの座標を取得し、座標に基づいて色を変化させることで、面白い効果を作り出すことができます。
*   `time` uniform変数を使って、時間とともに変化するエフェクトを作成することができます。
*   複数のテクスチャをシェーダーに渡すことで、より複雑なエフェクトを実現できます。

#### 応用例とユースケース

*   水面の波紋や屈折を再現する。
*   炎や煙のようなパーティクルエフェクトを画面全体に適用する。
*   特定のオブジェクトを強調したり、ぼかしたりする。

#### トラブルシューティング

*   シェーダーコードにエラーがある場合、画面が真っ黒になることがあります。ブラウザの開発者ツールを使って、エラーメッセージを確認してください。
*   シェーダーのパフォーマンスが低い場合、画面の描画速度が低下することがあります。シェーダーコードを最適化するか、エフェクトの解像度を下げることを検討してください。

#### まとめと次のステップ

この章では、ポストエフェクトの基本から応用までを学びました。`EffectComposer`を使って複数のエフェクトを組み合わせたり、シェーダーを使って独自のポストエフェクトを作成したりすることで、あなたの作品のビジュアルクオリティを飛躍的に向上させることができます。

次のステップとして、より高度なシェーダー技術を学び、物理ベースレンダリング（PBR）やグローバルイルミネーション（GI）などの最新技術を取り入れることをお勧めします。これらの技術を習得することで、よりリアルで美しいビジュアル表現が可能になります。また、他のThree.jsのサンプルコードやコミュニティの情報を参考に、さまざまなポストエフェクトを試してみることで、あなたの創造性をさらに刺激することができるでしょう。
