## 第16章：インタラクション - ユーザーとの対話

3D空間をただ眺めるだけでなく、ユーザーが積極的に関わり、操作できるインタラクティブな体験を提供することは、Web 3Dコンテンツの魅力を大きく高めます。本章では、マウス、キーボード、タッチといった主要な入力デバイスを通じて、ユーザーが3Dオブジェクトやシーンと対話するための実装方法を詳しく解説します。基本的なイベント処理から、より高度な操作まで、段階的に理解を深め、実践的なスキルを習得できるように構成しました。

### マウスイベント

#### 概要と重要性

マウスイベントは、Web 3D環境における最も基本的なインタラクション手段の一つです。オブジェクトの選択、詳細情報の表示、ドラッグ＆ドロップ操作など、多様な機能を実現できます。ユーザーは直感的に3D空間を操作し、コンテンツをより深く理解することができます。

#### 特徴と利点

*   **直感的な操作性:** マウス操作は多くのユーザーにとって馴染み深く、特別な学習コストを必要としません。
*   **多様なイベント:** `click`, `mouseover`, `mouseout`, `mousedown`, `mouseup`, `mousemove`など、豊富なイベントを活用できます。
*   **柔軟なカスタマイズ:** イベントリスナーを自由に設定し、独自のインタラクションを構築できます。

#### 事前準備と前提条件

*   Three.jsの基本的な知識（シーン、カメラ、レンダラーの作成）
*   HTML, CSS, JavaScriptの基本的な知識

#### 基本的な使い方

1.  **Raycasterの作成:** マウスの位置から3D空間へ光線を飛ばし、交差するオブジェクトを検出するためにRaycasterを使用します。

    ```javascript
    const raycaster = new THREE.Raycaster();
    const mouse = new THREE.Vector2();
    ```

2.  **マウス位置の正規化:** ブラウザのクライアント座標を-1から+1の範囲に正規化します。

    ```javascript
    function onMouseMove(event) {
      // ブラウザ座標を正規化
      mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
      mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
    }

    window.addEventListener('mousemove', onMouseMove, false);
    ```

3.  **Raycasterの更新と交差判定:** アニメーションループ内でRaycasterを更新し、シーン内のオブジェクトとの交差を判定します。

    ```javascript
    function animate() {
      requestAnimationFrame(animate);

      // Raycasterの原点と方向を更新
      raycaster.setFromCamera(mouse, camera);

      // シーン内のオブジェクトとの交差を検出
      const intersects = raycaster.intersectObjects(scene.children);

      if (intersects.length > 0) {
        // 交差したオブジェクトに対する処理
        console.log("Hit object:", intersects[0].object);
      }

      renderer.render(scene, camera);
    }

    animate();
    ```

#### 実践的なテクニック

*   **オブジェクトの選択:** 交差したオブジェクトをハイライト表示したり、選択状態を切り替えたりすることができます。

    ```javascript
    let selectedObject = null;

    function animate() {
      requestAnimationFrame(animate);

      raycaster.setFromCamera(mouse, camera);
      const intersects = raycaster.intersectObjects(scene.children);

      if (intersects.length > 0) {
        const intersectedObject = intersects[0].object;

        if (intersectedObject !== selectedObject) {
          if (selectedObject) {
            selectedObject.material.color.setHex(selectedObject.currentHex);
          }
          selectedObject = intersectedObject;
          selectedObject.currentHex = selectedObject.material.color.getHex();
          selectedObject.material.color.setHex(0xff0000); // ハイライト色
        }
      } else {
        if (selectedObject) {
          selectedObject.material.color.setHex(selectedObject.currentHex);
        }
        selectedObject = null;
      }

      renderer.render(scene, camera);
    }
    ```

*   **マウスオーバー時の情報表示:** マウスがオブジェクト上にある時に、オブジェクトに関する情報をポップアップ表示することができます。

    ```javascript
    const tooltip = document.createElement('div');
    tooltip.style.position = 'absolute';
    tooltip.style.backgroundColor = 'white';
    tooltip.style.padding = '5px';
    tooltip.style.border = '1px solid black';
    tooltip.style.display = 'none';
    document.body.appendChild(tooltip);

    function onMouseMove(event) {
        mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
        mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

        raycaster.setFromCamera(mouse, camera);
        const intersects = raycaster.intersectObjects(scene.children);

        if (intersects.length > 0) {
            const intersectedObject = intersects[0].object;
            tooltip.textContent = intersectedObject.name; // オブジェクトの名前を表示
            tooltip.style.left = event.clientX + 'px';
            tooltip.style.top = event.clientY + 'px';
            tooltip.style.display = 'block';
        } else {
            tooltip.style.display = 'none';
        }
    }

    window.addEventListener('mousemove', onMouseMove, false);
    ```

*   **クリックイベントの処理:** オブジェクトをクリックしたときに、特定の処理を実行することができます。

    ```javascript
    function onMouseClick(event) {
      raycaster.setFromCamera(mouse, camera);
      const intersects = raycaster.intersectObjects(scene.children);

      if (intersects.length > 0) {
        const clickedObject = intersects[0].object;
        alert(`Clicked on ${clickedObject.name}`); // オブジェクト名を表示
        // 他の処理...
      }
    }

    window.addEventListener('click', onMouseClick, false);
    ```

*   **ドラッグ＆ドロップの実装:** マウスでオブジェクトを掴んで移動させる操作を実装することができます。

    ```javascript
    let dragging = false;
    let dragObject = null;
    let offset = new THREE.Vector3();

    function onMouseDown(event) {
        raycaster.setFromCamera(mouse, camera);
        const intersects = raycaster.intersectObjects(scene.children);

        if (intersects.length > 0) {
            dragging = true;
            dragObject = intersects[0].object;

            // ドラッグ開始位置のオフセットを計算
            const plane = new THREE.Plane(new THREE.Vector3(0, 1, 0), 0); // XY平面
            raycaster.ray.intersectPlane(plane, offset);
            offset.sub(dragObject.position);
        }
    }

    function onMouseMove(event) {
        if (dragging && dragObject) {
            raycaster.setFromCamera(mouse, camera);
            const plane = new THREE.Plane(new THREE.Vector3(0, 1, 0), 0); // XY平面
            const intersectionPoint = new THREE.Vector3();

            raycaster.ray.intersectPlane(plane, intersectionPoint);
            intersectionPoint.add(offset);
            dragObject.position.copy(intersectionPoint); // オブジェクトの位置を更新
        }
    }

    function onMouseUp(event) {
        dragging = false;
        dragObject = null;
    }

    window.addEventListener('mousedown', onMouseDown, false);
    window.addEventListener('mousemove', onMouseMove, false);
    window.addEventListener('mouseup', onMouseUp, false);
    ```

#### 応用例とユースケース

*   **製品コンフィギュレーター:** Webサイト上で、ユーザーが製品の色やパーツを自由にカスタマイズできる機能。
*   **3Dモデルの編集ツール:** 3Dモデルをマウス操作で変形させたり、パーツを追加・削除したりできるツール。
*   **インタラクティブな博物館展示:** 3Dモデルを操作しながら、展示物の詳細情報を確認できる機能。
*   **ゲーム開発:** マウス操作によるキャラクターの移動、オブジェクトの操作、UIの操作など。

#### トラブルシューティング

*   **オブジェクトが選択できない:** Raycasterの原点と方向が正しく設定されているか確認してください。また、オブジェクトがRaycasterの範囲内にあるか、マテリアルがRaycastを受け付ける設定になっているか確認してください。
*   **マウス位置がずれる:** ブラウザのクライアント座標を正規化する処理が正しく実装されているか確認してください。
*   **ドラッグ＆ドロップがスムーズに動作しない:** マウスの移動量に基づいてオブジェクトの位置を更新する処理が正しく実装されているか確認してください。

#### まとめと次のステップ

マウスイベントは、Web 3Dコンテンツにインタラクティビティを付与するための強力なツールです。Raycasterを活用することで、オブジェクトの選択、情報の表示、ドラッグ＆ドロップなど、様々な操作を実装できます。次のステップとして、キーボードイベントやタッチイベントを組み合わせることで、さらに豊かなインタラクション体験を構築することができます。

### キーボードイベント

#### 概要と重要性

キーボードイベントは、マウス操作に加えて、より精密な操作や複雑なコマンド入力を可能にします。ゲーム、シミュレーション、3Dモデリングツールなど、幅広いアプリケーションで利用されています。

#### 特徴と利点

*   **精密な操作:** 数値入力やショートカットキーによる操作など、マウス操作だけでは難しい精密な操作を実現できます。
*   **複雑なコマンド入力:** 複数のキーを組み合わせることで、複雑なコマンドを直感的に実行できます。
*   **ゲームコントローラーの代替:** キーボードをゲームコントローラーとして利用することができます。

#### 事前準備と前提条件

*   Three.jsの基本的な知識
*   HTML, CSS, JavaScriptの基本的な知識

#### 基本的な使い方

1.  **キーイベントリスナーの登録:** `keydown`, `keyup`, `keypress`などのイベントリスナーを登録します。

    ```javascript
    document.addEventListener('keydown', onKeyDown, false);
    document.addEventListener('keyup', onKeyUp, false);
    ```

2.  **キーコードの取得:** イベントオブジェクトから、押されたキーのキーコードを取得します。

    ```javascript
    function onKeyDown(event) {
      const keyCode = event.keyCode;
      console.log("Key pressed:", keyCode);
      // キーコードに基づいた処理
    }

    function onKeyUp(event) {
        const keyCode = event.keyCode;
        console.log("Key released:", keyCode);
        // キーコードに基づいた処理
    }
    ```

3.  **キーコードに基づいた処理:** キーコードに応じて、オブジェクトの移動、カメラの制御、アニメーションの開始など、様々な処理を実行します。

    ```javascript
    const keys = {};

    document.addEventListener('keydown', (event) => {
      keys[event.key] = true; // キーが押されたことを記録
    });

    document.addEventListener('keyup', (event) => {
      keys[event.key] = false; // キーが離されたことを記録
    });

    function update() {
      if (keys['w']) {
        camera.position.z -= 0.1; // 前進
      }
      if (keys['s']) {
        camera.position.z += 0.1; // 後退
      }
      if (keys['a']) {
        camera.position.x -= 0.1; // 左移動
      }
      if (keys['d']) {
        camera.position.x += 0.1; // 右移動
      }

      renderer.render(scene, camera);
      requestAnimationFrame(update);
    }

    update();
    ```

#### 実践的なテクニック

*   **キー入力によるオブジェクトの操作:** キー入力に応じて、オブジェクトの位置、回転、スケールを変化させることができます。

    ```javascript
    const cube = scene.children[0]; // 適当なオブジェクト

    document.addEventListener('keydown', (event) => {
      switch (event.key) {
        case 'ArrowUp':
          cube.position.y += 0.1; // 上移動
          break;
        case 'ArrowDown':
          cube.position.y -= 0.1; // 下移動
          break;
        case 'ArrowLeft':
          cube.rotation.y += 0.1; // 左回転
          break;
        case 'ArrowRight':
          cube.rotation.y -= 0.1; // 右回転
          break;
      }
    });
    ```

*   **カメラの制御:** キー入力によって、カメラの位置や向きを制御することができます。

    ```javascript
    const cameraSpeed = 0.1;

    document.addEventListener('keydown', (event) => {
      switch (event.key) {
        case 'w':
          camera.position.z -= cameraSpeed; // 前進
          break;
        case 's':
          camera.position.z += cameraSpeed; // 後退
          break;
        case 'a':
          camera.position.x -= cameraSpeed; // 左移動
          break;
        case 'd':
          camera.position.x += cameraSpeed; // 右移動
          break;
        case 'q':
          camera.rotation.y += 0.05; // 左旋回
          break;
        case 'e':
          camera.rotation.y -= 0.05; // 右旋回
          break;
      }
    });
    ```

*   **ショートカットキーの実装:** CtrlやShiftキーと組み合わせて、特定の機能を実行することができます。

    ```javascript
    document.addEventListener('keydown', (event) => {
      if (event.ctrlKey && event.key === 's') {
        event.preventDefault(); // ブラウザのデフォルト動作をキャンセル
        console.log("Save action triggered!");
        // 保存処理...
      }
    });
    ```

#### 応用例とユースケース

*   **3Dゲーム:** キャラクターの移動、ジャンプ、攻撃などの操作。
*   **3Dモデリングツール:** オブジェクトの変形、視点の変更、コマンドの実行。
*   **VR/ARアプリケーション:** ヘッドセットやコントローラーの操作をキーボードで代替。
*   **シミュレーション:** キー入力によるパラメーターの変更、イベントのトリガー。

#### トラブルシューティング

*   **キーイベントが反応しない:** イベントリスナーが正しく登録されているか、フォーカスが正しい要素に当たっているか確認してください。
*   **キーコードが正しく取得できない:** ブラウザによってキーコードが異なる場合があります。`event.key`または`event.code`プロパティを使用することを検討してください。
*   **意図しない動作が発生する:** キーイベントが連続して発生することがあります。debounceやthrottleなどのテクニックを使用して、イベントの発生頻度を制御することを検討してください。

#### まとめと次のステップ

キーボードイベントは、Web 3Dコンテンツに精密な操作と複雑なコマンド入力を可能にします。オブジェクトの操作、カメラの制御、ショートカットキーの実装など、多様な機能を実装できます。次のステップとして、マウスイベントやタッチイベントと組み合わせることで、より直感的で洗練されたインタラクション体験を構築することができます。

### タッチイベント

#### 概要と重要性

タッチイベントは、スマートフォンやタブレットなどのタッチスクリーンデバイスでWeb 3Dコンテンツを操作するための重要な手段です。ピンチ操作によるズームイン・ズームアウト、スワイプ操作による視点変更など、直感的な操作を提供できます。

#### 特徴と利点

*   **直感的な操作性:** タッチ操作はマウス操作よりも直感的で、没入感の高い体験を提供できます。
*   **マルチタッチ操作:** 複数の指を使った操作（ピンチ、回転など）に対応しています。
*   **モバイルデバイスとの親和性:** スマートフォンやタブレットなど、モバイルデバイスでの利用に最適化されています。

#### 事前準備と前提条件

*   Three.jsの基本的な知識
*   HTML, CSS, JavaScriptの基本的な知識
*   タッチスクリーンデバイス（スマートフォン、タブレットなど）

#### 基本的な使い方

1.  **タッチイベントリスナーの登録:** `touchstart`, `touchmove`, `touchend`, `touchcancel`などのイベントリスナーを登録します。

    ```javascript
    document.addEventListener('touchstart', onTouchStart, false);
    document.addEventListener('touchmove', onTouchMove, false);
    document.addEventListener('touchend', onTouchEnd, false);
    document.addEventListener('touchcancel', onTouchCancel, false);
    ```

2.  **タッチイベント情報の取得:** イベントオブジェクトから、タッチされた指の数、位置、ターゲット要素などの情報を取得します。

    ```javascript
    function onTouchStart(event) {
      event.preventDefault(); // デフォルトのタッチ操作をキャンセル
      const touches = event.touches;
      console.log("Touch started:", touches);
      // タッチ情報に基づいた処理
    }

    function onTouchMove(event) {
      event.preventDefault();
      const touches = event.touches;
      console.log("Touch moved:", touches);
      // タッチ情報に基づいた処理
    }

    function onTouchEnd(event) {
      event.preventDefault();
      const touches = event.changedTouches;
      console.log("Touch ended:", touches);
      // タッチ情報に基づいた処理
    }

    function onTouchCancel(event) {
      event.preventDefault();
      console.log("Touch cancelled");
      // キャンセル処理
    }
    ```

3.  **タッチ情報に基づいた処理:** タッチされた指の数、位置、移動量などに応じて、オブジェクトの操作、カメラの制御、アニメーションの開始など、様々な処理を実行します。

#### 実践的なテクニック

*   **シングルタッチによる視点変更:** 1本の指で画面をドラッグすることで、視点を回転させることができます。

    ```javascript
    let touchStartX = 0;
    let touchStartY = 0;

    function onTouchStart(event) {
        touchStartX = event.touches[0].clientX;
        touchStartY = event.touches[0].clientY;
    }

    function onTouchMove(event) {
        const touchX = event.touches[0].clientX;
        const touchY = event.touches[0].clientY;

        const deltaX = (touchX - touchStartX) * 0.005;
        const deltaY = (touchY - touchStartY) * 0.005;

        camera.rotation.y += deltaX;
        camera.rotation.x += deltaY;

        touchStartX = touchX;
        touchStartY = touchY;
    }
    ```

*   **ピンチ操作によるズームイン・ズームアウト:** 2本の指でピンチ操作を行うことで、カメラをズームイン・ズームアウトさせることができます。

    ```javascript
    let initialDistance = 0;

    function getDistance(event) {
      const dx = event.touches[0].clientX - event.touches[1].clientX;
      const dy = event.touches[0].clientY - event.touches[1].clientY;
      return Math.sqrt(dx * dx + dy * dy);
    }

    function onTouchStart(event) {
      if (event.touches.length === 2) {
        initialDistance = getDistance(event);
      }
    }

    function onTouchMove(event) {
      if (event.touches.length === 2) {
        const currentDistance = getDistance(event);
        const delta = currentDistance - initialDistance;

        camera.position.z += delta * 0.01; // ズームイン・ズームアウト

        initialDistance = currentDistance;
      }
    }
    ```

*   **スワイプ操作によるオブジェクトの操作:** 画面をスワイプすることで、オブジェクトを回転させたり、移動させたりすることができます。

    ```javascript

    ```

#### 応用例とユースケース

*   **モバイルゲーム:** タッチ操作によるキャラクターの移動、ジャンプ、攻撃などの操作。
*   **3Dモデルビューワー:** タッチ操作による視点の変更、ズームイン・ズームアウト。
*   **ARアプリケーション:** タッチ操作によるオブジェクトの配置、操作。

#### トラブルシューティング

*   **タッチイベントが反応しない:** イベントリスナーが正しく登録されているか、viewportの設定が正しいか確認してください。
*   **マルチタッチ操作がうまくいかない:** タッチイベントの処理が複雑になるため、デバッグが難しい場合があります。デバッグツールやconsole.logを活用して、タッチイベントの情報を確認してください。
*   **タッチ操作がぎこちない:** タッチ操作の感度や速度を調整することで、よりスムーズな操作感を実現できます。
