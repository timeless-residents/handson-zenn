## 第13章：物理エンジン - リアルな動きを実現する

この章では、JavaScript製の物理エンジンであるCannon.jsを用いて、Three.jsで作成した3D空間にリアルな動きを付与する方法を解説します。ゲームやインタラクティブなWebアプリケーションにおいて、物理エンジンは没入感を高めるための重要な要素です。静的な3Dモデルに物理的な挙動を与えることで、オブジェクト同士の衝突、重力、摩擦といった現実世界の法則をシミュレートし、より自然で魅力的な体験を提供できます。初心者の方でも理解できるように、基本的な概念から応用的なテクニックまで、段階的に解説していきます。

### Cannon.jsの導入と設定

#### Cannon.jsの概要

Cannon.jsは、軽量かつ高性能なJavaScript製の3D物理エンジンです。Webブラウザ上で動作し、Three.jsなどの3Dグラフィックスライブラリと組み合わせて使用することで、インタラクティブな3D環境に物理シミュレーションを組み込むことができます。剛体の衝突判定、重力、摩擦、反発などの基本的な物理現象を扱うことができ、ゲーム開発やシミュレーションなど、様々な分野で活用されています。

**特徴と利点:**

*   **軽量:** 最小限の依存関係で、高速な物理シミュレーションを実現します。
*   **オープンソース:** MITライセンスで公開されており、商用利用も可能です。
*   **Three.jsとの連携:** Three.jsとの連携が容易で、3Dモデルに物理的な挙動を簡単に付与できます。
*   **豊富な機能:** 剛体の衝突判定、重力、摩擦、反発、バネ、拘束など、様々な物理現象をシミュレートできます。
*   **活発なコミュニティ:** ドキュメントやサンプルコードが豊富で、問題解決のための情報が容易に入手できます。

#### Three.jsとの連携

Cannon.jsをThree.jsと連携させるには、まずCannon.jsとThree.jsのライブラリを読み込む必要があります。CDNやnpmを使って導入できます。

```javascript
import * as THREE from 'three';
import * as CANNON from 'cannon-es';

```

**基本的な使い方:**

1.  **物理ワールドの作成:** `CANNON.World` クラスを使用して、物理ワールドを作成します。
2.  **重力の設定:** 物理ワールドの重力を設定します。通常は、Y軸方向に負の値を設定します。
3.  **剛体の作成:** `CANNON.Body` クラスを使用して、剛体を作成します。
4.  **形状の作成:** `CANNON.Box`, `CANNON.Sphere`, `CANNON.Plane`などのクラスを使用して、剛体の形状を作成します。
5.  **剛体の追加:** 作成した剛体を物理ワールドに追加します。
6.  **Three.jsオブジェクトの作成:** Three.jsの `THREE.Mesh` などを使用して、3Dオブジェクトを作成します。
7.  **物理ワールドと3Dオブジェクトの関連付け:** 剛体の位置と回転を、対応する3Dオブジェクトの位置と回転に同期させます。
8.  **物理ワールドの更新:** アニメーションループの中で、物理ワールドを一定間隔で更新します。

**サンプルコード:**

```javascript
// 1. シーン、カメラ、レンダラーの作成（Three.js）
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// 2. Cannon.jsのワールドを作成
const world = new CANNON.World();
world.gravity.set(0, -9.82, 0); // 重力を設定

// 3. 地面を作成（Cannon.jsとThree.js）
const groundShape = new CANNON.Plane();
const groundBody = new CANNON.Body({ mass: 0, shape: groundShape });
groundBody.quaternion.setFromEuler(-Math.PI / 2, 0, 0); // 地面を水平にする
world.addBody(groundBody);

const groundGeometry = new THREE.PlaneGeometry(10, 10);
const groundMaterial = new THREE.MeshBasicMaterial({ color: 0x888888, side: THREE.DoubleSide });
const groundMesh = new THREE.Mesh(groundGeometry, groundMaterial);
groundMesh.rotation.x = -Math.PI / 2;
scene.add(groundMesh);

// 4. 箱を作成（Cannon.jsとThree.js）
const boxShape = new CANNON.Box(new CANNON.Vec3(0.5, 0.5, 0.5));
const boxBody = new CANNON.Body({ mass: 1, shape: boxShape });
boxBody.position.set(0, 5, 0);
world.addBody(boxBody);

const boxGeometry = new THREE.BoxGeometry(1, 1, 1);
const boxMaterial = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const boxMesh = new THREE.Mesh(boxGeometry, boxMaterial);
scene.add(boxMesh);

camera.position.z = 5;

// アニメーションループ
function animate() {
  requestAnimationFrame(animate);

  // Cannon.jsのワールドを更新
  world.step(1 / 60); // フレームレートに合わせて更新

  // Cannon.jsの情報をThree.jsに反映
  boxMesh.position.copy(boxBody.position);
  boxMesh.quaternion.copy(boxBody.quaternion);

  renderer.render(scene, camera);
}

animate();
```

**注意点:**

*   Cannon.jsとThree.jsでは、座標系の向きが異なる場合があります。必要に応じて、座標系の変換を行う必要があります。
*   物理ワールドの更新間隔は、フレームレートに合わせて調整する必要があります。通常は、1/60秒（60FPSの場合）に設定します。
*   複雑な形状の衝突判定は、パフォーマンスに影響を与える可能性があります。できるだけ単純な形状を使用するように心がけましょう。

#### 実務での具体的なユースケース

*   **ゲーム開発:** オブジェクトの衝突、破壊、爆発などの表現に使用できます。
*   **建築シミュレーション:** 建物の構造解析や、地震時の挙動シミュレーションに使用できます。
*   **製品デザイン:** 製品の落下試験や、耐久性テストに使用できます。
*   **インタラクティブなWebサイト:** ユーザーがオブジェクトを操作できるインタラクティブなコンテンツを作成できます。

#### トラブルシューティング

*   **オブジェクトが落下しない:** 重力が設定されているか確認してください。また、質量が0でないか確認してください。
*   **オブジェクトが衝突しない:** 形状が適切に設定されているか確認してください。また、物理ワールドに剛体が追加されているか確認してください。
*   **パフォーマンスが低い:** 形状を単純化したり、物理ワールドの更新間隔を長くしたりしてみてください。

### 剛体 (Rigidbody) の作成

#### Box、Sphere、Planeなどの形状

剛体は、物理シミュレーションにおける基本的な要素であり、質量と形状を持つオブジェクトです。Cannon.jsでは、`CANNON.Body`クラスを使用して剛体を作成します。剛体の形状は、`CANNON.Box`, `CANNON.Sphere`, `CANNON.Plane`などのクラスを使用して定義します。

**形状の種類:**

*   **Box:** 直方体の形状。`CANNON.Box(new CANNON.Vec3(x, y, z))`のように、各軸方向の半分の長さを指定します。
*   **Sphere:** 球の形状。`CANNON.Sphere(radius)`のように、半径を指定します。
*   **Plane:** 無限に広がる平面の形状。`CANNON.Plane()`のように、引数は不要です。
*   **ConvexPolyhedron:** 凸多面体の形状。頂点と面を指定して定義します。複雑な形状を表現するのに適しています。
*   **Trimesh:** 三角形のメッシュの形状。頂点とインデックスを指定して定義します。Three.jsのモデルをそのまま利用できます。

**基本的な使い方:**

1.  **形状の作成:** 適切な形状クラスを使用して、形状オブジェクトを作成します。
2.  **剛体の作成:** `CANNON.Body`クラスのコンストラクタに、質量と形状オブジェクトを渡して、剛体を作成します。
3.  **剛体の追加:** 作成した剛体を物理ワールドに追加します。

**サンプルコード:**

```javascript
// 箱の作成
const boxShape = new CANNON.Box(new CANNON.Vec3(1, 1, 1));
const boxBody = new CANNON.Body({ mass: 1, shape: boxShape });
boxBody.position.set(0, 5, 0);
world.addBody(boxBody);

// 球の作成
const sphereShape = new CANNON.Sphere(1);
const sphereBody = new CANNON.Body({ mass: 1, shape: sphereShape });
sphereBody.position.set(2, 5, 0);
world.addBody(sphereBody);

// 地面の作成
const groundShape = new CANNON.Plane();
const groundBody = new CANNON.Body({ mass: 0, shape: groundShape });
groundBody.quaternion.setFromEuler(-Math.PI / 2, 0, 0); // 地面を水平にする
world.addBody(groundBody);
```

#### 質量、摩擦、反発係数の設定

剛体の挙動は、質量、摩擦、反発係数などの物理パラメータによって大きく変化します。これらのパラメータを適切に設定することで、よりリアルな物理シミュレーションを実現できます。

*   **質量 (mass):** 剛体の重さを表します。質量が大きいほど、動きにくくなります。質量が0の場合、剛体は静止し、他の剛体の動きに影響を与えません。
*   **摩擦 (friction):** 剛体同士が接触したときの摩擦力を表します。摩擦が大きいほど、滑りにくくなります。値は0から1の間で設定します。
*   **反発係数 (restitution):** 剛体同士が衝突したときの反発力を表します。反発係数が大きいほど、よく跳ね返ります。値は0から1の間で設定します。

**基本的な使い方:**

1.  **剛体の作成:** `CANNON.Body`クラスのコンストラクタで、質量を指定します。
2.  **マテリアルの作成:** `CANNON.Material`クラスを使用して、摩擦と反発係数を設定します。
3.  **接触マテリアルの作成:** `CANNON.ContactMaterial`クラスを使用して、2つのマテリアル間の摩擦と反発係数を設定します。
4.  **接触マテリアルの追加:** `CANNON.World`クラスの `addContactMaterial` メソッドを使用して、接触マテリアルを物理ワールドに追加します。

**サンプルコード:**

```javascript
// マテリアルの作成
const groundMaterial = new CANNON.Material({ friction: 0.4, restitution: 0.3 });
const ballMaterial = new CANNON.Material({ friction: 0.1, restitution: 0.7 });

// 接触マテリアルの作成
const groundBallContactMaterial = new CANNON.ContactMaterial(groundMaterial, ballMaterial, {
  friction: 0.4,
  restitution: 0.3,
});

// 接触マテリアルの追加
world.addContactMaterial(groundBallContactMaterial);

// 地面の作成
const groundShape = new CANNON.Plane();
const groundBody = new CANNON.Body({ mass: 0, shape: groundShape, material: groundMaterial });
groundBody.quaternion.setFromEuler(-Math.PI / 2, 0, 0); // 地面を水平にする
world.addBody(groundBody);

// 球の作成
const sphereShape = new CANNON.Sphere(1);
const sphereBody = new CANNON.Body({ mass: 1, shape: sphereShape, material: ballMaterial });
sphereBody.position.set(2, 5, 0);
world.addBody(sphereBody);
```

**実践的なテクニック:**

*   **質量を調整する:** オブジェクトの大きさに合わせて質量を調整することで、よりリアルな動きを実現できます。
*   **摩擦を調整する:** オブジェクトの材質に合わせて摩擦を調整することで、滑りやすさを表現できます。
*   **反発係数を調整する:** オブジェクトの材質に合わせて反発係数を調整することで、跳ね返り方を表現できます。
*   **接触マテリアルを使用する:** 異なる材質のオブジェクト同士の接触を表現するために、接触マテリアルを使用します。

**注意点:**

*   質量が0の剛体は、他の剛体の動きに影響を与えません。
*   摩擦と反発係数は、0から1の間で設定します。
*   接触マテリアルは、2つのマテリアル間の摩擦と反発係数を設定します。

#### 実務での具体的なユースケース

*   **ボーリングゲーム:** ボールの質量、レーンの摩擦、ピンの反発係数を調整することで、リアルなボーリングの挙動をシミュレートできます。
*   **カーレースゲーム:** 車の質量、タイヤの摩擦、壁の反発係数を調整することで、リアルなカーレースの挙動をシミュレートできます。
*   **破壊シミュレーション:** 建物の材質の摩擦、爆発物の反発係数を調整することで、リアルな破壊の挙動をシミュレートできます。

#### トラブルシューティング

*   **オブジェクトが滑りすぎる:** 摩擦を大きくしてみてください。
*   **オブジェクトが跳ね返らない:** 反発係数を大きくしてみてください。
*   **オブジェクトが動きがおかしい:** 質量、摩擦、反発係数のバランスが崩れている可能性があります。調整してみてください。

### 衝突判定とイベント処理

#### 衝突イベントのリスナー

物理エンジンにおいて、オブジェクト同士の衝突を検知し、そのタイミングで特定の処理を実行することは非常に重要です。Cannon.jsでは、`addEventListener`メソッドを使用して、衝突イベントのリスナーを登録できます。

**衝突イベントの種類:**

*   **collide:** 剛体同士が衝突したときに発生します。
*   **beginContact:** 剛体同士が接触を開始したときに発生します。
*   **endContact:** 剛体同士が接触を終了したときに発生します。

**基本的な使い方:**

1.  **リスナーの登録:** `CANNON.Body`クラスの`addEventListener`メソッドを使用して、衝突イベントのリスナーを登録します。
2.  **イベントハンドラの作成:** イベントが発生したときに実行されるイベントハンドラを作成します。イベントハンドラには、衝突に関する情報が格納された`event`オブジェクトが渡されます。
3.  **衝突情報の取得:** `event`オブジェクトから、衝突した剛体や衝突点などの情報を取得します。

**サンプルコード:**

```javascript
// 箱の作成
const boxShape = new CANNON.Box(new CANNON.Vec3(1, 1, 1));
const boxBody = new CANNON.Body({ mass: 1, shape: boxShape });
boxBody.position.set(0, 5, 0);
world.addBody(boxBody);

// 球の作成
const sphereShape = new CANNON.Sphere(1);
const sphereBody = new CANNON.Body({ mass: 1, shape: sphereShape });
sphereBody.position.set(2, 5, 0);
world.addBody(sphereBody);

// 衝突イベントのリスナーを登録
boxBody.addEventListener("collide", (event) => {
  console.log("箱と何かが衝突しました！");
  console.log("衝突した剛体:", event.body);
  console.log("衝突点:", event.contact.bi);
});
```

#### 衝突時の処理

衝突イベントが発生したときに、様々な処理を実行できます。例えば、衝突音を再生したり、衝突したオブジェクトの色を変更したり、スコアを加算したりすることができます。

**実践的なテクニック:**

*   **衝突音の再生:** `Audio`オブジェクトを使用して、衝突音を再生します。
*   **オブジェクトの色の変更:** `THREE.Mesh`の`material`プロパティを変更して、オブジェクトの色を変更します。
*   **スコアの加算:** スコアを管理する変数に、一定の値を加算します。
*   **パーティクルの生成:** 衝突時にパーティクルを生成することで、視覚的な効果を高めることができます。
*   **オブジェクトの破壊:** 衝突時にオブジェクトを破壊することで、よりリアルな表現を実現できます。

**サンプルコード:**

```javascript
// 衝突音の再生
const audio = new Audio("collision.mp3");

boxBody.addEventListener("collide", (event) => {
  audio.play();

  // オブジェクトの色の変更
  boxMesh.material.color.setHex(0xff0000);
});
```

**注意点:**

*   衝突イベントハンドラの中で重い処理を実行すると、パフォーマンスに影響を与える可能性があります。できるだけ軽量な処理を実行するように心がけましょう。
*   衝突イベントは、物理ワールドが更新されるたびに発生する可能性があります。必要に応じて、イベントの発生回数を制限する必要があります。

#### 実務での具体的なユースケース

*   **アクションゲーム:** 敵キャラクターとの衝突判定、武器とオブジェクトの衝突判定などに使用できます。
*   **パズルゲーム:** ブロック同士の衝突判定、ボールとゴールの衝突判定などに使用できます。
*   **シミュレーションゲーム:** 車同士の衝突判定、建物とオブジェクトの衝突判定などに使用できます。

#### トラブルシューティング

*   **衝突イベントが発生しない:** 剛体が適切に設定されているか確認してください。また、衝突イベントリスナーが登録されているか確認してください。
*   **衝突イベントが連続して発生する:** 剛体が接触したままになっている可能性があります。剛体の形状や物理パラメータを調整してみてください。

### 物理エンジンの応用

#### ドミノ倒し、ボールの落下、布のシミュレーション

物理エンジンは、様々な物理現象をシミュレートできます。ここでは、ドミノ倒し、ボールの落下、布のシミュレーションという３つの応用例を紹介します。

**1. ドミノ倒し:**

ドミノ倒しは、物理エンジンの基本的な応用例です。ドミノを並べて、最初のドミノを倒すことで、連鎖的にドミノが倒れていく様子をシミュレートできます。

**実装のポイント:**

*   **ドミノの作成:** `CANNON.Box`クラスを使用して、ドミノの形状を作成します。
*   **ドミノの配置:** ドミノを等間隔に並べて配置します。
*   **最初のドミノを倒す:** 最初のドミノに力を加えて倒します。
*   **連鎖的な衝突:** ドミノが衝突することで、連鎖的にドミノが倒れていきます。

**サンプルコード (簡略化):**

```javascript
// ドミノの作成
const dominoShape = new CANNON.Box(new CANNON.Vec3(0.1, 0.5, 0.3));
const dominoBody = new CANNON.Body({ mass: 1, shape: dominoShape });

// ドミノの配置
for (let i = 0; i < 10; i++) {
  const domino = dominoBody.clone();
  domino.position.set(i * 0.5, 0.5, 0);
  world.addBody(domino);
}

// 最初のドミノを倒す
dominoBody.applyImpulse(new CANNON.Vec3(1, 0, 0), new CANNON.Vec3(0, 0, 0));
```

**2. ボールの落下:**

ボールの落下は、重力と摩擦の基本的な物理現象をシミュレートする例です。ボールを空中に配置し、重力によって落下する様子をシミュレートできます。

**実装のポイント:**

*   **ボールの作成:** `CANNON.Sphere`クラスを使用して、ボールの形状を作成します。
*   **ボールの配置:** ボールを空中に配置します。
*   **重力の設定:** 物理ワールドに重力を設定します。
*   **摩擦の設定:** 地面との摩擦を設定します。

**サンプルコード (簡略化):**

```javascript
// ボールの作成
const sphereShape = new CANNON.Sphere(1);
const sphereBody = new CANNON.Body({ mass: 1, shape: sphereShape });
sphereBody.position.set(0, 5, 0);
world.addBody(sphereBody);

// 重力の設定
world.gravity.set(0, -9.82, 0);

// 地面との摩擦の設定
const groundMaterial = new CANNON.Material({ friction: 0.4, restitution: 0.3 });
const ballMaterial = new CANNON.Material({ friction: 0.1, restitution: 0.7 });
const groundBallContactMaterial = new CANNON.ContactMaterial(groundMaterial, ballMaterial, {
  friction: 0.4,
  restitution: 0.3,
});
world.addContactMaterial(groundBallContactMaterial);

const groundShape = new CANNON.Plane();
const groundBody = new CANNON.Body({ mass: 0, shape: groundShape, material: groundMaterial });
groundBody.quaternion.setFromEuler(-Math.PI / 2, 0, 0); // 地面を水平にする
world.addBody(groundBody);
```

**3. 布のシミュレーション:**

布のシミュレーションは、より複雑な物理現象をシミュレートする例です。布を質点の集合としてモデル化し、質点同士をバネで繋ぐことで、布の動きを表現します。

**実装のポイント:**

*   **質点の作成:** `CANNON.Body`クラスを使用して、質点を作成します。
*   **質点の配置:** 質点を格子状に配置します。
*   **バネの作成:** `CANNON.Spring`クラスを使用して、質点同士をバネで繋ぎます。
*   **風の影響:** 質点に風の力を加えることで、布が風になびく様子をシミュレートできます。

**サンプルコード (簡略化):**

```javascript
// 質点の数
const numPointsX = 10;
const numPointsY = 10;

// 質点の距離
const distance = 0.5;

// 質点の配列
const points = [];

// 質点の作成と配置
for (let i = 0; i < numPointsX; i++) {
  points[i] = [];
  for (let j = 0; j < numPointsY; j++) {
    const pointShape = new CANNON.Sphere(0.1);
    const pointBody = new CANNON.Body({ mass: 1, shape: pointShape });
    pointBody.position.set(i * distance, j * distance, 0);
    world.addBody(pointBody);
    points[i][j] = pointBody;
  }
}

// バネの作成
for (let i = 0; i < numPointsX; i++) {
  for (let j = 0; j < numPointsY; j++) {
    if (i < numPointsX - 1) {
      const spring = new CANNON.Spring(points[i][j], points[i + 1][j], {
        restLength: distance,
        stiffness: 100,
        damping: 10,
      });
      world.addSpring(spring);
    }
    if (j < numPointsY - 1) {
      const spring = new CANNON.Spring(points[i][j], points[i][j + 1], {
        restLength: distance,
        stiffness: 100,
        damping: 10,
      });
      world.addSpring(spring);
    }
  }
}
```

#### 実務での具体的なユースケース

*   **ゲーム開発:** ドミノ倒しゲーム、ボールを使った物理パズルゲーム、布の動きを表現するゲームなどに使用できます。
*   **建築シミュレーション:** 建物の倒壊シミュレーション、橋の揺れシミュレーションなどに使用できます。
*   **服飾デザイン:** 服のシミュレーション、布のドレープ表現などに使用できます。

#### トラブルシューティング

*   **シミュレーションが不安定になる:** 質量、バネの硬さ、ダンピングなどのパラメータを調整してみてください。
*   **パフォーマンスが低い:** 質点の数を減らしたり、バネの数を減らしたりしてみてください。
