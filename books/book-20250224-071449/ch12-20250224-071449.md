## 第12章：シェーダー - 表現の限界を超える

ゲームやインタラクティブな3Dアプリケーションにおいて、シェーダーは表現力を飛躍的に向上させるための強力なツールです。  従来の固定機能パイプラインでは実現できなかった、高度な視覚効果や物理シミュレーションを手軽に実装できます。 この章では、シェーダーの基礎から応用までを段階的に解説し、読者が自身のプロジェクトでシェーダーを効果的に活用できるようになることを目指します。

### シェーダーの基本

シェーダーは、GPU上で実行される小さなプログラムです。  3Dオブジェクトの頂点やピクセルの色、位置、その他の属性を計算するために使用されます。 これにより、従来のレンダリングパイプラインでは実現できなかった、高度な視覚効果やカスタマイズされた表現が可能になります。

**概要と重要性**

シェーダーは、3Dグラフィックスの品質と表現力を左右する重要な要素です。  現実世界の物理現象をシミュレートしたり、独特なアートスタイルを表現したり、パフォーマンスを最適化したりするなど、その応用範囲は非常に広いです。

**特徴と利点**

*   **柔軟性:**  独自のアルゴリズムを実装することで、既存のレンダリングパイプラインでは実現できない視覚効果を作成できます。
*   **パフォーマンス:**  GPUの並列処理能力を活用することで、CPUで行うよりも高速な処理が可能です。
*   **リアルタイム性:**  リアルタイムで視覚効果を生成し、インタラクティブな体験を提供できます。
*   **カスタマイズ性:**  マテリアルやライティングを細かく制御し、独自のアートスタイルを表現できます。

**事前準備と前提条件**

*   **WebGLの基礎知識:**  Three.jsはWebGLを抽象化したライブラリなので、WebGLの基本的な概念（頂点、フラグメント、シェーダープログラムなど）を理解していると、より深くシェーダーを理解できます。
*   **Three.jsの基本的な使い方:**  基本的なシーンの構築、オブジェクトの配置、カメラの設定など、Three.jsの基本的な操作を理解している必要があります。
*   **GLSLの知識:**  シェーダーの記述にはGLSLという言語を使用します。  C言語に似た構文を持つため、プログラミングの経験があれば比較的容易に習得できます。

**基本的な使い方**

Three.jsでシェーダーを使用するには、`ShaderMaterial`というマテリアルを使用します。 `ShaderMaterial`は、頂点シェーダーとフラグメントシェーダーのソースコードをパラメータとして受け取り、メッシュに適用することでシェーダーを実行します。

```javascript
// 頂点シェーダーのソースコード
const vertexShader = `
  void main() {
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

// フラグメントシェーダーのソースコード
const fragmentShader = `
  void main() {
    gl_FragColor = vec4(1.0, 0.0, 0.0, 1.0); // 赤色
  }
`;

// ShaderMaterialの作成
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
});

// メッシュの作成
const geometry = new THREE.BoxGeometry(1, 1, 1);
const mesh = new THREE.Mesh(geometry, material);

scene.add(mesh);
```

上記のコードは、最もシンプルなシェーダーの例です。  頂点シェーダーは頂点の位置を変換し、フラグメントシェーダーはピクセルの色を赤色に設定します。

**GLSL (OpenGL Shading Language) の基礎**

GLSLは、GPU上でシェーダーを記述するために使用される言語です。  C言語に似た構文を持ち、ベクトルや行列などのグラフィックス処理に特化したデータ型や関数が用意されています。

*   **データ型:**
    *   `float`: 浮動小数点数
    *   `vec2`, `vec3`, `vec4`: 2次元、3次元、4次元ベクトル
    *   `mat2`, `mat3`, `mat4`: 2x2、3x3、4x4行列
    *   `sampler2D`: 2Dテクスチャ
*   **変数修飾子:**
    *   `attribute`: 頂点ごとに異なる値（頂点シェーダーでのみ使用可能）
    *   `uniform`: シェーダー全体で共通の値（JavaScriptから値を渡す）
    *   `varying`: 頂点シェーダーからフラグメントシェーダーへ渡される値
*   **組み込み変数:**
    *   `gl_Position`: 頂点シェーダーの出力。頂点のスクリーン空間座標
    *   `gl_FragColor`: フラグメントシェーダーの出力。ピクセルの色

**頂点シェーダーとフラグメントシェーダー**

シェーダーは、主に頂点シェーダーとフラグメントシェーダーの2つの種類に分けられます。

*   **頂点シェーダー:**  各頂点に対して実行され、頂点の位置、法線、テクスチャ座標などを変換します。  通常、モデル空間からワールド空間、ビュー空間、クリップ空間へと頂点の座標を変換するために使用されます。
*   **フラグメントシェーダー:**  各ピクセル（フラグメント）に対して実行され、ピクセルの色を決定します。  ライティング、テクスチャマッピング、特殊効果などを実装するために使用されます。

**実践的なテクニック**

*   **uniform変数の使用:**  JavaScriptからシェーダーに値を渡すには、`uniform`変数を使用します。 `uniform`変数は、シェーダー全体で共通の値として使用できます。

```javascript
// uniform変数の定義
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    uColor: { value: new THREE.Color(0xff0000) }, // 赤色
    uTime: { value: 0.0 },
  },
});

// アニメーションループ内でuniform変数の値を更新
function animate() {
  requestAnimationFrame(animate);

  material.uniforms.uTime.value += 0.01;

  renderer.render(scene, camera);
}
```

```glsl
// フラグメントシェーダー
uniform vec3 uColor;
uniform float uTime;

void main() {
  // 時間によって色を変化させる
  float r = sin(uTime) * 0.5 + 0.5;
  gl_FragColor = vec4(uColor * r, 1.0);
}
```

*   **varying変数の使用:**  頂点シェーダーからフラグメントシェーダーへ値を渡すには、`varying`変数を使用します。 `varying`変数は、頂点シェーダーで計算された値を、フラグメントシェーダーで補間された値として使用できます。

```glsl
// 頂点シェーダー
varying vec3 vNormal;

void main() {
  vNormal = normal;
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
```

```glsl
// フラグメントシェーダー
varying vec3 vNormal;

void main() {
  // 法線ベクトルを色として使用する
  gl_FragColor = vec4(vNormal * 0.5 + 0.5, 1.0);
}
```

**応用例とユースケース**

*   **リアルタイムエフェクト:** 炎、水、煙などのリアルタイムエフェクトを作成できます。
*   **カスタムマテリアル:**  ユニークなテクスチャやライティングを表現するカスタムマテリアルを作成できます。
*   **データビジュアライゼーション:**  数値データを3D空間に可視化できます。
*   **ゲーム:**  キャラクターの表現、環境の表現、特殊効果など、ゲームのあらゆる面で使用できます。

**トラブルシューティング**

*   **シェーダーがコンパイルできない:**  GLSLの構文エラーや、GPUのドライバの問題が原因である可能性があります。 エラーメッセージをよく確認し、構文エラーを修正するか、GPUのドライバを更新してください。
*   **シェーダーが正しく表示されない:**  uniform変数の値が正しく設定されていない、varying変数が正しく補間されていない、などの原因が考えられます。  デバッグツールを使用して、シェーダーの実行状況を確認してください。
*   **パフォーマンスが低い:**  シェーダーの処理が重すぎる、テクスチャのサイズが大きすぎる、などの原因が考えられます。  シェーダーの処理を最適化したり、テクスチャのサイズを小さくしたりすることで、パフォーマンスを改善できます。

### カスタムマテリアルの作成

Three.jsでカスタムマテリアルを作成するには、`ShaderMaterial`を使用します。 `ShaderMaterial`は、頂点シェーダーとフラグメントシェーダーのソースコードをパラメータとして受け取り、メッシュに適用することでシェーダーを実行します。

**概要と重要性**

カスタムマテリアルを作成することで、Three.jsの標準マテリアルでは表現できない、独自の視覚効果を実現できます。  これにより、プロジェクトの個性を際立たせ、より魅力的なビジュアルを作成できます。

**特徴と利点**

*   **表現力の向上:**  標準マテリアルでは実現できない、高度な視覚効果や物理シミュレーションを実装できます。
*   **カスタマイズ性:**  マテリアルのあらゆる側面を細かく制御し、独自のアートスタイルを表現できます。
*   **パフォーマンス:**  特定のハードウェアに合わせて最適化されたシェーダーを作成することで、パフォーマンスを向上させることができます。

**事前準備と前提条件**

*   **シェーダーの基本知識:**  前のセクションで解説した、シェーダーの基本的な概念とGLSLの知識が必要です。
*   **Three.jsの基本的な使い方:**  シーンの構築、オブジェクトの配置、カメラの設定など、Three.jsの基本的な操作を理解している必要があります。

**ShaderMaterialの利用**

`ShaderMaterial`は、頂点シェーダーとフラグメントシェーダーのソースコードをパラメータとして受け取るマテリアルです。

```javascript
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    // uniform変数の定義
  },
});
```

`vertexShader`と`fragmentShader`には、それぞれ頂点シェーダーとフラグメントシェーダーのソースコードを文字列として渡します。 `uniforms`には、シェーダーで使用するuniform変数をオブジェクトとして定義します。

**uniforms (uniform変数) の定義と使用**

uniform変数は、JavaScriptからシェーダーに値を渡すために使用されます。 `uniforms`オブジェクトに、uniform変数の名前と初期値を定義します。

```javascript
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    uColor: { value: new THREE.Color(0xff0000) }, // 赤色
    uTime: { value: 0.0 },
    uResolution: { value: new THREE.Vector2(window.innerWidth, window.innerHeight) },
  },
});
```

上記の例では、`uColor`、`uTime`、`uResolution`という3つのuniform変数を定義しています。 `uColor`は`THREE.Color`オブジェクト、`uTime`は数値、`uResolution`は`THREE.Vector2`オブジェクトとして定義されています。

シェーダー内では、これらのuniform変数を以下のように使用できます。

```glsl
uniform vec3 uColor;
uniform float uTime;
uniform vec2 uResolution;

void main() {
  // 時間によって色を変化させる
  float r = sin(uTime) * 0.5 + 0.5;
  gl_FragColor = vec4(uColor * r, 1.0);

  // 画面の解像度に基づいて処理を行う
  vec2 uv = gl_FragCoord.xy / uResolution.xy;
}
```

**応用例とユースケース**

*   **パーティクルシステム:**  大量のパーティクルを効率的にレンダリングするために、シェーダーを使用できます。

*   **マウスインタラクションが機能しない:**  マウスイベントリスナーが正しく設定されているか、マウスの位置が正しくシェーダーに渡されているかを確認してください。

### シェーダーによる表現

シェーダーを使用することで、従来のレンダリングパイプラインでは実現できなかった、様々な視覚効果を表現できます。  このセクションでは、波紋、雲、炎などの表現方法について具体的に解説します。

**概要と重要性**

シェーダーによる表現は、3Dグラフィックスのリアリティと魅力を大幅に向上させるための重要な要素です。  現実世界の物理現象をシミュレートしたり、幻想的な世界観を表現したりするなど、その応用範囲は非常に広いです。

**事前準備と前提条件**

**波紋、雲、炎などの表現**

以下に、波紋、雲、炎などの表現方法について、具体的なコード例とともに解説します。

*   **波紋:**

波紋は、正弦波関数を使用して表現できます。  中心からの距離と時間に基づいて正弦波の値を計算し、頂点の位置をずらすことで、波紋のような効果を作り出します。

```glsl
// 頂点シェーダー
uniform float uTime;
uniform float uAmplitude; // 波の振幅
uniform float uFrequency; // 波の頻度

void main() {
  float distance = length(position.xz); // 中心からの距離
  float displacement = sin(distance * uFrequency + uTime) * uAmplitude;

  vec3 newPosition = position + vec3(0.0, displacement, 0.0);

  gl_Position = projectionMatrix * modelViewMatrix * vec4(newPosition, 1.0);
}
```

```javascript
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    uTime: { value: 0.0 },
    uAmplitude: { value: 0.1 },
    uFrequency: { value: 5.0 },
  },
  wireframe: true //分かりやすくワイヤーフレーム表示
});
```

この例では、`uAmplitude`で波の振幅を、`uFrequency`で波の頻度を調整できます。時間`uTime`を更新することで、波紋が広がっていくアニメーションを表現できます。

*   **雲:**

雲は、パーリンノイズなどのノイズ関数を使用して表現できます。  ノイズ関数は、ランダムな値の分布を生成する関数で、自然なテクスチャを生成するのに適しています。

```glsl
// フラグメントシェーダー
uniform float uTime;

// パーリンノイズ関数 (簡略版)
float rand(vec2 n) {
    return fract(sin(dot(n, vec2(12.9898, 4.1414))) * 43758.5453);
}

float noise(vec2 p){
	vec2 fl = floor(p);
  vec2 fr = fract(p);
	vec4 v = vec4(rand(fl), rand(fl + vec2(1.0,0.0)), rand(fl + vec2(0.0,1.0)), rand(fl + vec2(1.0,1.0)));
  vec2 s = fr * fr * (3.0 - 2.0 * fr);
	return mix(mix(v.x, v.y, s.x), mix(v.z, v.w, s.x), s.y);
}

void main() {
  vec2 uv = gl_FragCoord.xy / resolution;
  float cloud = noise(uv * 5.0 + uTime);
  gl_FragColor = vec4(vec3(cloud), 1.0);
}
```

```javascript
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    uTime: { value: 0.0 },
    resolution: { value: new THREE.Vector2(window.innerWidth, window.innerHeight) }
  },
});
```

この例では、`noise`関数を使用してノイズを生成し、それを雲の密度として使用しています。 時間`uTime`を更新することで、雲が変化していくアニメーションを表現できます。 より複雑な雲を表現するには、複数のノイズ関数を重ね合わせたり、テクスチャを使用したりする必要があります。

*   **炎:**

炎は、ノイズ関数と色を組み合わせることで表現できます。  ノイズ関数を使用して炎の形状を生成し、温度に応じて色を変化させることで、炎のような効果を作り出します。

```glsl
// フラグメントシェーダー
uniform float uTime;

// パーリンノイズ関数 (簡略版) - 上記の雲の例と同じ

void main() {
  vec2 uv = gl_FragCoord.xy / resolution;
  float fire = noise(uv * 10.0 + vec2(0.0, uTime * 2.0)); // 時間によるY軸方向への移動

  // 色付け
  vec3 color = mix(vec3(0.0,0.0,0.0), vec3(1.0, 0.0, 0.0), fire); // 黒 -> 赤
  color = mix(color, vec3(1.0, 1.0, 0.0), fire * fire); // 赤 -> 黄色
  color = mix(color, vec3(1.0, 1.0, 1.0), fire * fire * fire); // 黄色 -> 白

  gl_FragColor = vec4(color, 1.0);
}
```

```javascript
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    uTime: { value: 0.0 },
    resolution: { value: new THREE.Vector2(window.innerWidth, window.innerHeight) }
  },
});
```

この例では、`noise`関数を使用して炎の形状を生成し、`mix`関数を使用して温度に応じて色を変化させています。 時間`uTime`を更新することで、炎が燃え上がるアニメーションを表現できます。 よりリアルな炎を表現するには、テクスチャを使用したり、より複雑な色付けを行ったりする必要があります。

**ノーマルマップの生成**

ノーマルマップは、オブジェクトの表面の法線ベクトルを記録したテクスチャです。  ノーマルマップを使用することで、ポリゴン数を増やさずに、オブジェクトに細かい凹凸を与えることができます。

```glsl
// フラグメントシェーダー
uniform sampler2D uHeightMap; // 高さマップ
uniform float uStrength; // 強度

void main() {
  vec2 uv = gl_FragCoord.xy / resolution;

  // 高さマップから高さを取得
  float height = texture2D(uHeightMap, uv).r;

  // 隣接するピクセルの高さを取得
  float heightU = texture2D(uHeightMap, uv + vec2(1.0 / resolution.x, 0.0)).r;
  float heightV = texture2D(uHeightMap, uv + vec2(0.0, 1.0 / resolution.y)).r;

  // 法線ベクトルを計算
  vec3 normal = normalize(vec3(
    (height - heightU) * uStrength,
    (height - heightV) * uStrength,
    1.0
  ));

  // 法線ベクトルを色として出力
  gl_FragColor = vec4(normal * 0.5 + 0.5, 1.0);
}
```


**実践的なテクニック**

*   **複数のシェーダーを組み合わせる:**  複数のシェーダーを組み合わせることで、より複雑な視覚効果を実現できます。 例えば、波紋と雲を組み合わせたり、炎と煙を組み合わせたりすることができます。
*   **ポストエフェクトを使用する:**  ポストエフェクトを使用することで、シーン全体にエフェクトを適用できます。 例えば、ブルーム、ぼかし、色収差などのエフェクトを適用できます。
*   **フレームバッファを使用する:**  フレームバッファを使用することで、シェーダーの出力をテクスチャとして再利用できます。 これにより、より複雑なレンダリングパイプラインを構築できます。

**応用例とユースケース**

*   **リアルな水面表現:**  波紋、反射、屈折などを組み合わせることで、リアルな水面を表現できます。
*   **美しい空の表現:**  雲、太陽、星などを組み合わせることで、美しい空を表現できます。
*   **迫力のある炎の表現:**  炎、煙、熱などを組み合わせることで、迫力のある炎を表現できます。

*   **シェーダーの結果が期待通りにならない:**  シェーダーのコードをデバッグしたり、パラメータを調整したりすることで、問題を解決できます。
