## 第10章：パーティクル - 無数の粒子による表現

パーティクルは、無数の小さな粒子を用いて、煙、炎、星空、魔法エフェクトなど、複雑で動的な視覚効果を生み出すための強力なツールです。 Three.jsにおけるパーティクルシステムは、比較的容易に実装できるにも関わらず、表現力豊かな映像を作り出すことが可能です。この章では、パーティクルの基礎から応用までを段階的に解説し、読者の皆さんが Three.js プロジェクトでパーティクルを効果的に活用できるようになることを目指します。

### パーティクルシステムの基本

#### ParticleSystemとは？

パーティクルシステムは、小さな粒子（パーティクル）を大量に生成、操作、描画することで、雲、炎、煙、水しぶき、爆発、花火など、複雑で動きのあるエフェクトをシミュレートする技術です。 各パーティクルは、位置、速度、色、寿命などの属性を持ち、これらの属性は時間の経過とともに変化します。 パーティクルシステムは、これらのパーティクルをまとめて管理し、一連のルールに従ってそれらを更新およびレンダリングします。

**重要性:** パーティクルシステムは、静的なメッシュやテクスチャでは表現が難しい、自然現象やダイナミックなエフェクトを表現する上で非常に重要な役割を果たします。ゲーム、ビジュアライゼーション、インタラクティブアートなど、幅広い分野で活用されています。

**利点:**

*   **表現力:** 複雑なエフェクトを比較的少ないリソースで表現できます。
*   **柔軟性:** パーティクルの属性を調整することで、様々なエフェクトを作成できます。
*   **動的表現:** 時間とともに変化する自然な動きを表現できます。
*   **パフォーマンス:** GPUによる並列処理に適しており、大量のパーティクルを効率的にレンダリングできます。（GPUパーティクルの場合）

#### パーティクルの生成と初期化

パーティクルシステムの最初のステップは、パーティクルの生成と初期化です。 Three.js では、`THREE.Points`オブジェクトと`THREE.BufferGeometry`、そしてパーティクルを描画するためのマテリアルを組み合わせてパーティクルシステムを構築します。`THREE.BufferGeometry`はパーティクルの位置、色、サイズなどの属性を格納する効率的な方法を提供します。

**事前準備と前提条件:**

*   Three.js の基本的な知識（シーン、カメラ、レンダラーのセットアップ）
*   JavaScript の基本的な知識

**基本的な使い方:**

1.  **ジオメトリの作成:** パーティクルの数分の頂点を持つ `THREE.BufferGeometry` を作成します。

    ```javascript
    const particleCount = 1000;
    const geometry = new THREE.BufferGeometry();

    const positions = new Float32Array(particleCount * 3); // x, y, z
    const colors = new Float32Array(particleCount * 3); // r, g, b
    const sizes = new Float32Array(particleCount); // size

    for (let i = 0; i < particleCount; i++) {
        positions[i * 3] = (Math.random() - 0.5) * 10; // -5 to 5
        positions[i * 3 + 1] = (Math.random() - 0.5) * 10;
        positions[i * 3 + 2] = (Math.random() - 0.5) * 10;

        colors[i * 3] = Math.random();
        colors[i * 3 + 1] = Math.random();
        colors[i * 3 + 2] = Math.random();

        sizes[i] = Math.random() * 5 + 1; // 1 to 6
    }

    geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
    geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));
    geometry.setAttribute('size', new THREE.BufferAttribute(sizes, 1));
    ```

2.  **マテリアルの作成:** パーティクルを描画するためのマテリアルを作成します。`THREE.PointsMaterial`または`THREE.SpriteMaterial`を使用します。（後述）

    ```javascript
    const material = new THREE.PointsMaterial({
        size: 0.1,
        vertexColors: true, // 頂点の色を使用
        opacity: 0.5,
        transparent: true,
        blending: THREE.AdditiveBlending // 加算合成
    });
    ```

3.  **パーティクルシステムの作成:** ジオメトリとマテリアルを使用して、`THREE.Points`オブジェクトを作成します。

    ```javascript
    const particles = new THREE.Points(geometry, material);
    scene.add(particles);
    ```

**実践的なテクニック:**

*   **初期位置のランダム化:** `Math.random()` を使用して、パーティクルの初期位置をランダムに分散させます。
*   **初期色のランダム化:**  `Math.random()` を使用して、パーティクルの初期色をランダムに設定します。
*   **パーティクルの寿命:** 各パーティクルに寿命を設定し、一定時間が経過したら消滅させることで、より自然なエフェクトを表現できます。
*   **パーティクルの生成速度:** 一定時間ごとに新しいパーティクルを生成することで、継続的なエフェクトを作成できます。

**応用例とユースケース:**

*   **花火:** ランダムな方向に爆発するパーティクルと、時間の経過とともに色が変化するパーティクルを組み合わせることで、花火を表現できます。
*   **煙:** 上昇するパーティクルと、時間の経過とともに透明度が変化するパーティクルを組み合わせることで、煙を表現できます。
*   **魔法エフェクト:** 特殊な形状のテクスチャを使用したパーティクルと、特定の方向に移動するパーティクルを組み合わせることで、魔法エフェクトを表現できます。

**トラブルシューティング:**

*   **パーティクルが表示されない:**
    *   ジオメトリに頂点データが正しく設定されているか確認してください。
    *   マテリアルの `size` プロパティが適切な値に設定されているか確認してください。
    *   マテリアルの `visible` プロパティが `true` に設定されているか確認してください。
    *   カメラの位置と向きが適切であるか確認してください。
*   **パーティクルの動きが不自然:**
    *   パーティクルの速度、加速度、寿命などのパラメータを調整してください。
    *   パーティクル間の相互作用（重力、衝突など）を考慮してください。

#### パーティクルの位置、速度、色の設定

パーティクルの位置、速度、色は、パーティクルシステムの見た目と挙動を決定する重要な属性です。 これらの属性を適切に設定することで、様々なエフェクトを作り出すことができます。

**事前準備と前提条件:**

*   前のセクションの知識（パーティクルの生成と初期化）
*   ベクトル演算の基本的な知識

**基本的な使い方:**

1.  **位置の設定:** `THREE.BufferAttribute` を使用して、パーティクルの位置を設定します。

    ```javascript
    const positions = geometry.attributes.position.array;
    for (let i = 0; i < particleCount; i++) {
        positions[i * 3] = (Math.random() - 0.5) * 10; // x
        positions[i * 3 + 1] = (Math.random() - 0.5) * 10; // y
        positions[i * 3 + 2] = (Math.random() - 0.5) * 10; // z
    }
    geometry.attributes.position.needsUpdate = true; // バッファを更新
    ```

2.  **速度の設定:** パーティクルの速度は、通常、毎フレーム更新されます。

    ```javascript
    const velocities = new Float32Array(particleCount * 3); // x, y, z
    for (let i = 0; i < particleCount; i++) {
        velocities[i * 3] = (Math.random() - 0.5) * 0.1;
        velocities[i * 3 + 1] = Math.random() * 0.2; // 上向きに移動
        velocities[i * 3 + 2] = (Math.random() - 0.5) * 0.1;
    }

    function updateParticles() {
        const positions = geometry.attributes.position.array;
        for (let i = 0; i < particleCount; i++) {
            positions[i * 3] += velocities[i * 3];
            positions[i * 3 + 1] += velocities[i * 3 + 1];
            positions[i * 3 + 2] += velocities[i * 3 + 2];
        }
        geometry.attributes.position.needsUpdate = true;
    }
    ```

    `updateParticles()` 関数をアニメーションループ内で呼び出す必要があります。

3.  **色の設定:** `THREE.BufferAttribute` を使用して、パーティクルの色を設定します。

    ```javascript
    const colors = geometry.attributes.color.array;
    for (let i = 0; i < particleCount; i++) {
        colors[i * 3] = Math.random();
        colors[i * 3 + 1] = Math.random();
        colors[i * 3 + 2] = Math.random();
    }
    geometry.attributes.color.needsUpdate = true; // バッファを更新
    ```

**実践的なテクニック:**

*   **時間の経過とともに変化する色:**  アニメーションループ内でパーティクルの色を更新することで、時間の経過とともに色が変化するエフェクトを作成できます。
*   **速度による色の変化:**  パーティクルの速度に応じて色を変化させることで、よりリアルなエフェクトを作成できます。 例えば、高速で移動するパーティクルを明るく、低速で移動するパーティクルを暗くすることができます。
*   **重力、風などの影響:**  パーティクルの速度に重力や風の影響を加えることで、より自然な動きを表現できます。

**応用例とユースケース:**

*   **炎:**  下から上に移動し、時間の経過とともに色がオレンジから赤、そして黒に変化するパーティクルを組み合わせることで、炎を表現できます。
*   **滝:**  上から下に移動し、落下速度が徐々に速くなるパーティクルを組み合わせることで、滝を表現できます。
*   **煙:**  上昇しながら拡散し、時間の経過とともに透明度が変化するパーティクルを組み合わせることで、煙を表現できます。

**トラブルシューティング:**

*   **パーティクルの動きが遅い/速い:**
    *   速度のスケールを調整してください。
    *   フレームレートに応じて速度を調整してください（`deltaTime` を使用）。
*   **パーティクルの色が変化しない:**
    *   `geometry.attributes.color.needsUpdate` が `true` に設定されているか確認してください。
    *   マテリアルの `vertexColors` プロパティが `true` に設定されているか確認してください。

### パーティクルの描画方法

Three.js では、主に `THREE.PointsMaterial` と `THREE.SpriteMaterial` の2つのマテリアルを使用してパーティクルを描画します。 それぞれのマテリアルには特徴があり、表現したいエフェクトに応じて使い分ける必要があります。

#### PointsMaterial

`THREE.PointsMaterial` は、各パーティクルを単なる点として描画するためのマテリアルです。 軽量でパフォーマンスが高いため、大量のパーティクルを扱う場合に適しています。

**特徴と利点:**

*   **シンプル:** シンプルな API で簡単に使用できます。
*   **軽量:** パフォーマンスが高く、大量のパーティクルを効率的に描画できます。
*   **カスタマイズ可能:** サイズ、色、透明度などをカスタマイズできます。

**事前準備と前提条件:**

*   前のセクションまでの知識
*   Three.js のマテリアルに関する基本的な知識

**基本的な使い方:**

1.  **マテリアルの作成:** `THREE.PointsMaterial` を作成します。

    ```javascript
    const material = new THREE.PointsMaterial({
        size: 0.1, // パーティクルのサイズ
        color: 0xffffff, // パーティクルの色 (白)
        opacity: 0.8, // 透明度
        transparent: true // 透明を有効にする
    });
    ```

2.  **`vertexColors`の使用:** 頂点の色情報を使用したい場合は、`vertexColors` プロパティを `true` に設定します。

    ```javascript
    const material = new THREE.PointsMaterial({
        size: 0.1,
        vertexColors: true // 頂点の色を使用
    });
    ```

    この場合、`THREE.BufferGeometry` に色の属性を追加する必要があります（前のセクションを参照）。

**実践的なテクニック:**

*   **サイズの調整:**  `size` プロパティを調整することで、パーティクルのサイズを変更できます。
*   **色の変更:**  `color` プロパティを調整することで、パーティクルの色を変更できます。
*   **透明度の調整:**  `opacity` プロパティと `transparent` プロパティを組み合わせて、パーティクルの透明度を調整できます。
*   **Blending:**  `blending` プロパティを使用すると、パーティクルと背景の色の合成方法を指定できます。`THREE.AdditiveBlending` (加算合成) は、明るいエフェクト（炎、光など）によく使用されます。`THREE.SubtractiveBlending` (減算合成) は、暗いエフェクトに適しています。

    ```javascript
    const material = new THREE.PointsMaterial({
        size: 0.1,
        color: 0xffffff,
        blending: THREE.AdditiveBlending // 加算合成
    });
    ```

**応用例とユースケース:**

*   **星空:**  ランダムな位置に配置された小さな白いパーティクルを大量に描画することで、星空を表現できます。
*   **雪:**  落下する白いパーティクルをランダムな速度で移動させることで、雪を表現できます。
*   **塵:**  舞い上がる灰色のパーティクルを不規則な動きで移動させることで、塵を表現できます。

**トラブルシューティング:**

*   **パーティクルが小さすぎる/大きすぎる:**
    *   `size` プロパティを調整してください。
*   **色が正しく表示されない:**
    *   `color` プロパティが適切な値に設定されているか確認してください。
    *   `vertexColors` プロパティが正しく設定されているか確認してください。
*   **透明度が反映されない:**
    *   `transparent` プロパティが `true` に設定されているか確認してください。
    *   `opacity` プロパティが適切な値に設定されているか確認してください。

#### SpriteMaterial

`THREE.SpriteMaterial` は、各パーティクルをテクスチャ付きの四角形（スプライト）として描画するためのマテリアルです。 より複雑な形状やアニメーションを表現したい場合に適しています。

**特徴と利点:**

*   **テクスチャの利用:** より複雑な形状やアニメーションを表現できます。
*   **柔軟性:** 様々なテクスチャを使用することで、多彩なエフェクトを作成できます。
*   **視覚的な豊かさ:** 単なる点よりも視覚的に豊かな表現が可能です。

**事前準備と前提条件:**

*   前のセクションまでの知識
*   テクスチャに関する基本的な知識
*   Three.js のマテリアルに関する基本的な知識

**基本的な使い方:**

1.  **テクスチャのロード:**  `THREE.TextureLoader` を使用してテクスチャをロードします。

    ```javascript
    const textureLoader = new THREE.TextureLoader();
    const texture = textureLoader.load('particle.png'); // テクスチャのパス
    ```

2.  **マテリアルの作成:**  `THREE.SpriteMaterial` を作成し、ロードしたテクスチャを `map` プロパティに設定します。

    ```javascript
    const material = new THREE.SpriteMaterial({
        map: texture, // テクスチャ
        color: 0xffffff, // パーティクルの色 (白)
        opacity: 0.8, // 透明度
        transparent: true, // 透明を有効にする
        blending: THREE.AdditiveBlending // 加算合成
    });
    ```

3.  **パーティクルシステムの作成:**  ジオメトリとマテリアルを使用して `THREE.Points` オブジェクトを作成します。

    ```javascript
    const particles = new THREE.Points(geometry, material);
    scene.add(particles);
    ```

**実践的なテクニック:**

*   **アニメーションテクスチャ:**  複数のフレームを含むテクスチャを使用し、`map.offset` と `map.repeat` をアニメーションループ内で更新することで、パーティクルをアニメーションさせることができます。これは、爆発エフェクトなどでよく用いられる手法です。
*   **UV マッピング:**  ジオメトリの UV 属性を調整することで、テクスチャのどの部分を各パーティクルに表示するかを制御できます。
*   **サイズの調整:**  `scale` プロパティを使用することで、パーティクルのサイズを調整できます。 スプライトはもともと四角形なので、`size`ではなく、スケールで調整します。

    ```javascript
    for (let i = 0; i < particleCount; i++) {
        const sprite = new THREE.Sprite(material);
        sprite.scale.set(0.1, 0.1, 1); // x, y, z
        // ... 位置の設定 ...
        scene.add(sprite);
    }
    ```

**応用例とユースケース:**

*   **炎:**  炎のテクスチャを使用し、色の変化や透明度の調整を組み合わせることで、炎を表現できます。
*   **煙:**  煙のテクスチャを使用し、拡散するような動きを加えることで、煙を表現できます。
*   **魔法エフェクト:**  特殊な形状のテクスチャを使用し、回転や拡大縮小などのアニメーションを加えることで、魔法エフェクトを表現できます。

**トラブルシューティング:**

*   **テクスチャが表示されない:**
    *   テクスチャのパスが正しいか確認してください。
    *   テクスチャがロードされているか確認してください（`texture.onload` などを使用）。
    *   マテリアルの `map` プロパティが正しく設定されているか確認してください。
*   **テクスチャが歪んで表示される:**
    *   UV マッピングが正しいか確認してください。
    *   テクスチャのサイズが適切か確認してください。
*   **アニメーションが正しく再生されない:**
    *   `map.offset` と `map.repeat` が正しく更新されているか確認してください。
    *   テクスチャのフレーム数が正しいか確認してください。

### パーティクルの応用

このセクションでは、これまで学んだ知識を応用して、より複雑なパーティクルエフェクトを作成する方法について解説します。 具体的には、煙、炎、星空などの表現と、GPUパーティクル（シェーダー）の基本的な概念について説明します。

#### 煙、炎、星空などの表現

**煙:**

煙のエフェクトを作成するには、上昇しながら拡散し、時間の経過とともに透明度が変化するパーティクルを使用します。

1.  **パーティクルの生成と初期化:**
    *   パーティクルの初期位置を煙の発生源に設定します。
    *   パーティクルに上向きの速度を与えます。
    *   パーティクルの寿命をランダムに設定します。

2.  **パーティクルの更新:**
    *   パーティクルの位置を速度に基づいて更新します。
    *   時間の経過とともにパーティクルの透明度を減少させます。
    *   パーティクルをランダムな方向に拡散させます。
    *   寿命が尽きたパーティクルを消滅させます。

3.  **パーティクルの描画:**
    *   `THREE.SpriteMaterial` を使用して、煙のテクスチャをパーティクルに適用します。
    *   `blending` プロパティを `THREE.AdditiveBlending` に設定して、加算合成を行います。

**炎:**

炎のエフェクトを作成するには、下から上に移動し、時間の経過とともに色が変化するパーティクルを使用します。

1.  **パーティクルの生成と初期化:**
    *   パーティクルの初期位置を炎の発生源に設定します。
    *   パーティクルに上向きの速度を与えます。
    *   パーティクルの寿命をランダムに設定します。
    *   パーティクルの初期色をオレンジ色に設定します。

2.  **パーティクルの更新:**
    *   パーティクルの位置を速度に基づいて更新します。
    *   時間の経過とともにパーティクルの色をオレンジ色から赤色、そして黒色に変化させます。
    *   寿命が尽きたパーティクルを消滅させます。

3.  **パーティクルの描画:**
    *   `THREE.SpriteMaterial` を使用して、炎のテクスチャをパーティクルに適用します。
    *   `blending` プロパティを `THREE.AdditiveBlending` に設定して、加算合成を行います。

**星空:**

星空のエフェクトを作成するには、ランダムな位置に配置された小さな白いパーティクルを大量に描画します。

1.  **パーティクルの生成と初期化:**
    *   パーティクルの位置をランダムに設定します。
    *   パーティクルの色を白色に設定します。
    *   パーティクルのサイズを小さく設定します。

2.  **パーティクルの描画:**
    *   `THREE.PointsMaterial` を使用して、パーティクルを単なる点として描画します。

**実践的なテクニック:**

*   **ノイズ関数:**  パーティクルの動きにノイズ関数（例：Perlin noise）を適用することで、より自然な動きを表現できます。
*   **パーティクルの相互作用:**  パーティクル間に重力や衝突などの相互作用を導入することで、より複雑なエフェクトを作成できます。
*   **シェーダー:**  シェーダーを使用することで、パーティクルの描画方法をより細かく制御できます。（次項参照）

**応用例とユースケース:**

*   **ゲーム:** 爆発、炎、煙、魔法エフェクトなど、様々なゲームエフェクトを表現できます。
*   **ビジュアライゼーション:** データ可視化のために、パーティクルを使用して複雑な情報を表現できます。
*   **インタラクティブアート:**  ユーザーの操作に応じて変化するパーティクルエフェクトを作成できます。

#### GPUパーティクル (シェーダー)

GPUパーティクルは、パーティクルの生成、更新、描画を GPU で行うことで、大量のパーティクルを効率的にレンダリングする技術です。 Three.js では、シェーダー（GLSL）を使用して GPU パーティクルを実装します。

**特徴と利点:**

*   **高いパフォーマンス:** GPU の並列処理能力を最大限に活用できます。
*   **大量のパーティクル:** 数十万、数百万のパーティクルをリアルタイムでレンダリングできます。
*   **柔軟な制御:** シェーダーを使用することで、パーティクルの挙動を細かく制御できます。

**事前準備と前提条件:**

*   WebGL とシェーダー（GLSL）に関する基本的な知識
*   前のセクションまでの知識

**基本的な仕組み:**

1.  **頂点シェーダー:**  各パーティクルの位置、サイズ、色などを計算します。
2.  **フラグメントシェーダー:**  各パーティクルの色を決定します。
3.  **テクスチャ:**  パーティクルの状態（位置、速度、寿命など）をテクスチャに保存し、シェーダーで読み書きします。

**簡単な例:**

ここでは、最も基本的なGPUパーティクルの例として、位置情報を頂点シェーダーでランダムに設定する例を示します。

```javascript
const geometry = new THREE.BufferGeometry();
const vertices = new Float32Array(particleCount * 3);

for (let i = 0; i < particleCount * 3; i++) {
  vertices[i] = Math.random() * 20 - 10;
}

geometry.setAttribute('position', new THREE.BufferAttribute(vertices, 3));

const material = new THREE.ShaderMaterial({
  vertexShader: `
    void main() {
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
      gl_PointSize = 5.0;
    }
  `,
  fragmentShader: `
    void main() {
      gl_FragColor = vec4(1.0, 1.0, 1.0, 1.0); // 白
    }
  `
});

const particles = new THREE.Points(geometry, material);
scene.add(particles);
```

この例では、`vertexShader`で各頂点の位置を設定し、`fragmentShader`でパーティクルの色を白に設定しています。より複雑な表現を行うには、`uniform`変数を使用して外部からシェーダーにパラメータを渡したり、テクスチャを使用してパーティクルの状態を管理したりする必要があります。

**実践的なテクニック:**

*   **Ping-Pong バッファ:**  パーティクルの状態を更新するために、2つのテクスチャを交互に使用するテクニックです。 一方のテクスチャから状態を読み込み、新しい状態をもう一方のテクスチャに書き込みます。 次のフレームでは、読み書きするテクスチャを入れ替えます。
*   **計算シェーダー:**  WebGL2 で利用可能な計算シェーダーを使用すると、パーティクルの更新処理をより効率的に行うことができます。
*   **フレームバッファオブジェクト (FBO):**  テクスチャにレンダリングするために使用します。

**トラブルシューティング:**

*   **シェーダーがコンパイルされない:**
    *   シェーダーコードに構文エラーがないか確認してください。
    *   WebGL のバージョンとシェーダーコードのバージョンが一致しているか確認してください。
*   **パーティクルが表示されない/正しく表示されない:**
    *   頂点シェーダーとフラグメントシェーダーの計算が正しいか確認してください。
    *   テクスチャの読み書きが正しいか確認してください。
    *   `uniform` 変数の値が適切に設定されているか確認してください。
