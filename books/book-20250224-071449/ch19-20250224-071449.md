## 第19章：Three.jsライブラリとコミュニティ

Three.jsはそれ自体でも強力な3Dライブラリですが、さらにその可能性を広げる豊富な周辺ライブラリと、活発なコミュニティが存在します。これらのリソースを活用することで、開発効率を向上させ、より複雑で洗練された3D表現を実現できます。本章では、Three.jsの可能性を最大限に引き出すためのライブラリとコミュニティについて、実践的な内容を交えながら解説します。

### 便利なライブラリの紹介

Three.jsの機能を拡張し、開発を効率化するための便利なライブラリを紹介します。

#### GUIライブラリ (lil-gui, dat.GUI)

**1. 概要と重要性**

GUIライブラリは、Three.jsアプリケーションのパラメーターをリアルタイムに調整できるインターフェースを提供します。色、位置、スケール、その他様々な変数をGUI上で操作することで、直感的に最適な設定を見つけられます。特に、プロトタイピング段階や、インタラクティブなデモを作成する際に非常に役立ちます。

**2. 特徴と利点**

*   **リアルタイム調整:** パラメーターの変更が即座にシーンに反映されるため、視覚的なフィードバックを得ながら調整できます。
*   **直感的な操作:** スライダー、カラーピッカー、チェックボックスなど、使いやすいコントロールが用意されています。
*   **コードの簡略化:** GUIを通じてパラメーターを調整するため、コードを何度も書き換える必要がありません。
*   **デバッグの効率化:** 問題の原因となっているパラメーターを特定しやすくなります。

**3. 事前準備と前提条件**

Three.jsの基本的な知識が必要です。また、`lil-gui`または`dat.GUI`をインストールする必要があります。`lil-gui`はよりモダンなGUIライブラリであり、パフォーマンスと使いやすさが向上しています。ここでは`lil-gui`を例に説明します。

```bash
npm install lil-gui
```

または、CDNを使用して直接HTMLに組み込むことも可能です。

```html
<script src="https://cdn.jsdelivr.net/npm/lil-gui@0.18/dist/lil-gui.umd.min.js"></script>
```

**4. 基本的な使い方**

```javascript
import * as THREE from 'three';
import { GUI } from 'lil-gui';

// シーン、カメラ、レンダラーの初期化 (Three.jsの基本的な設定は省略)
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

// 立方体の作成
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );

camera.position.z = 5;

// GUIの作成
const gui = new GUI();

// キューブの回転パラメーター
const cubeParams = {
    rotationX: 0,
    rotationY: 0,
    rotationZ: 0,
    color: 0x00ff00,
};

// GUIにパラメーターを追加
gui.add(cubeParams, 'rotationX', 0, Math.PI * 2).onChange( (value) => {
    cube.rotation.x = value;
});
gui.add(cubeParams, 'rotationY', 0, Math.PI * 2).onChange( (value) => {
    cube.rotation.y = value;
});
gui.add(cubeParams, 'rotationZ', 0, Math.PI * 2).onChange( (value) => {
    cube.rotation.z = value;
});
gui.addColor(cubeParams, 'color').onChange( (value) => {
    cube.material.color.set(value);
});

// アニメーションループ
function animate() {
    requestAnimationFrame( animate );
    renderer.render( scene, camera );
}
animate();
```

このコードでは、立方体の回転と色をGUIで操作できます。`gui.add()`でパラメーターを追加し、`.onChange()`で値が変更されたときの処理を定義します。`gui.addColor()`はカラーピッカーを追加します。

**5. 実践的なテクニック**

*   **フォルダーの使用:** GUIを整理するために、フォルダーを使用できます。

    ```javascript
    const cubeFolder = gui.addFolder('Cube');
    cubeFolder.add(cubeParams, 'rotationX', 0, Math.PI * 2).name('Rotation X').onChange( (value) => {
        cube.rotation.x = value;
    });
    cubeFolder.open(); // 初期状態でフォルダーを開く
    ```

*   **ステップ値の指定:** スライダーの刻み幅を指定できます。

    ```javascript
    gui.add(cubeParams, 'rotationX', 0, Math.PI * 2).step(0.01);
    ```

*   **関数の追加:** ボタンを追加して、特定の関数を実行できます。

    ```javascript
    const actions = {
        resetRotation: () => {
            cube.rotation.set(0, 0, 0);
            cubeParams.rotationX = 0;
            cubeParams.rotationY = 0;
            cubeParams.rotationZ = 0;
        }
    };
    gui.add(actions, 'resetRotation');
    ```

**6. 応用例とユースケース**

*   **パーティクルシステムの調整:** パーティクルの発生数、速度、色などをリアルタイムに調整できます。
*   **シェーダーのパラメーター調整:** カスタムシェーダーのuniform変数をGUIで操作できます。
*   **ゲームのデバッグ:** ゲームのパラメーターを調整し、バグの原因を特定しやすくします。
*   **建築ビジュアライゼーション:** マテリアル、照明、カメラアングルなどを調整して、最適なレンダリング設定を見つけます。

**7. トラブルシューティング**

*   **GUIが表示されない:** `lil-gui`または`dat.GUI`が正しくインストールされているか確認してください。また、CSSが適切に適用されているか確認してください。
*   **パラメーターが反映されない:** `.onChange()`コールバック関数が正しく定義されているか確認してください。

**8. まとめと次のステップ**

GUIライブラリを使用することで、Three.jsアプリケーションの開発効率を大幅に向上させることができます。様々なパラメーターをリアルタイムに調整し、直感的に最適な設定を見つけましょう。次は、物理エンジンについて学びます。

#### 物理エンジン (Cannon.js, Ammo.js)

**1. 概要と重要性**

物理エンジンは、Three.jsのオブジェクトに物理的な挙動（重力、衝突、摩擦など）を付与するためのライブラリです。リアルなインタラクションやシミュレーションを実現するために不可欠です。

**2. 特徴と利点**

*   **リアルな挙動:** オブジェクトが重力に従って落下したり、衝突時に反発したりする様子を再現できます。
*   **インタラクティブ性:** ユーザーがオブジェクトを操作したり、物理的なイベントをトリガーしたりできます。
*   **シミュレーション:** 現実世界の物理現象をシミュレーションできます。
*   **ゲーム開発:** 物理エンジンは、ゲームのリアリティと面白さを向上させるために不可欠です。

**3. 事前準備と前提条件**

Three.jsの基本的な知識が必要です。また、`Cannon.js`または`Ammo.js`をインストールする必要があります。`Ammo.js`はWebAssemblyで動作するため、`Cannon.js`よりも一般的にパフォーマンスが高いですが、導入が少し複雑です。ここでは`Cannon.js`を例に説明します。

```bash
npm install cannon
```

または、CDNを使用して直接HTMLに組み込むことも可能です。

```html
<script src="https://cdn.jsdelivr.net/npm/cannon@0.6.2/cannon.min.js"></script>
```

**4. 基本的な使い方**

```javascript
import * as THREE from 'three';
import * as CANNON from 'cannon';

// Three.jsの初期化 (省略)
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

// Cannon.jsの初期化
const world = new CANNON.World();
world.gravity.set(0, -9.82, 0); // 重力の設定

// 床の作成 (Three.js)
const planeGeometry = new THREE.PlaneGeometry( 10, 10 );
const planeMaterial = new THREE.MeshBasicMaterial( {color: 0xffffff, side: THREE.DoubleSide} );
const plane = new THREE.Mesh( planeGeometry, planeMaterial );
plane.rotation.x = -Math.PI / 2;
scene.add(plane);

// 床の作成 (Cannon.js)
const planeShape = new CANNON.Plane();
const planeBody = new CANNON.Body({ mass: 0 }); // 静止させるためにmassを0に
planeBody.addShape(planeShape);
planeBody.quaternion.setFromAxisAngle(new CANNON.Vec3(1,0,0),-Math.PI/2); // 回転
world.addBody(planeBody);

// ボールの作成 (Three.js)
const sphereGeometry = new THREE.SphereGeometry( 1, 32, 32 );
const sphereMaterial = new THREE.MeshBasicMaterial( { color: 0xff0000 } );
const sphere = new THREE.Mesh( sphereGeometry, sphereMaterial );
sphere.position.y = 5;
scene.add(sphere);

// ボールの作成 (Cannon.js)
const sphereShape = new CANNON.Sphere(1);
const sphereBody = new CANNON.Body({
    mass: 5,
    position: new CANNON.Vec3(0, 5, 0),
    shape: sphereShape
});
world.addBody(sphereBody);

// アニメーションループ
function animate() {
    requestAnimationFrame( animate );

    // Cannon.jsのステップ
    world.step(1/60);

    // Three.jsのオブジェクトの位置をCannon.jsのオブジェクトと同期
    sphere.position.copy(sphereBody.position);
    sphere.quaternion.copy(sphereBody.quaternion);
    plane.position.copy(planeBody.position);
    plane.quaternion.copy(planeBody.quaternion);

    renderer.render( scene, camera );
}
animate();
```

このコードでは、ボールが重力に従って落下し、床に衝突する様子をシミュレーションしています。Three.jsのオブジェクトとCannon.jsのオブジェクトを対応させ、アニメーションループ内で位置と回転を同期させる必要があります。

**5. 実践的なテクニック**

*   **衝突イベントの処理:** オブジェクト間の衝突を検出し、特定の処理を実行できます。

    ```javascript
    sphereBody.addEventListener("collide",function(e){
        console.log("The sphere just collided with something!");
    });
    ```

*   **マテリアルの設定:** オブジェクトの摩擦係数や反発係数を設定できます。

    ```javascript
    const physicsMaterial = new CANNON.Material("slipperyMaterial");
    const physicsContactMaterial = new CANNON.ContactMaterial(physicsMaterial, physicsMaterial, {
        friction: 0.0,
        restitution: 0.3
    });
    world.addContactMaterial(physicsContactMaterial);
    sphereBody.material = physicsMaterial;
    planeBody.material = physicsMaterial;
    ```

*   **複合形状の使用:** 複雑な形状のオブジェクトを表現するために、複数の形状を組み合わせることができます。

**6. 応用例とユースケース**

*   **破壊シミュレーション:** オブジェクトが破壊される様子をシミュレーションできます。
*   **ゲームの物理演算:** ボールを投げる、車を運転するなどのアクションをリアルに表現できます。
*   **ロボットシミュレーション:** ロボットの動作をシミュレーションできます。
*   **建築構造のシミュレーション:** 建物の構造が地震や風などの外力に耐えられるかをシミュレーションできます。

**7. トラブルシューティング**

*   **オブジェクトが正常に衝突しない:** `mass`の値が適切か確認してください。また、形状が正しく定義されているか確認してください。
*   **パフォーマンスが低い:** `world.step()`の引数を調整してください。また、不要な物理演算を減らしてください。

**8. まとめと次のステップ**

物理エンジンを使用することで、Three.jsアプリケーションにリアリティとインタラクティブ性を加えることができます。衝突イベントの処理やマテリアルの設定など、様々なテクニックを駆使して、より高度なシミュレーションを実現しましょう。次は、ローダーについて学びます。

#### ローダー (DRACOLoader, KTX2Loader)

**1. 概要と重要性**

ローダーは、様々な3Dモデル形式（glTF, OBJ, FBXなど）をThree.jsに読み込むためのライブラリです。DRACOLoaderとKTX2Loaderは、それぞれモデルの圧縮とテクスチャの圧縮に特化しており、ロード時間を短縮し、パフォーマンスを向上させるために重要です。

**2. 特徴と利点**

*   **DRACOLoader:** 3Dモデルのジオメトリを圧縮することで、ファイルサイズを大幅に削減し、ロード時間を短縮します。特に、複雑なモデルやモバイル環境で効果を発揮します。
*   **KTX2Loader:** テクスチャを圧縮することで、GPUメモリの使用量を削減し、パフォーマンスを向上させます。特に、高解像度のテクスチャを使用する場合に有効です。
*   **ロード時間の短縮:** ファイルサイズが小さくなるため、ネットワーク経由でのダウンロード時間が短縮されます。
*   **パフォーマンスの向上:** GPUメモリの使用量が削減されるため、レンダリングパフォーマンスが向上します。

**3. 事前準備と前提条件**

Three.jsの基本的な知識が必要です。また、`DRACOLoader`と`KTX2Loader`をインストールする必要があります。これらのローダーは、Three.jsのexamplesフォルダに含まれています。

```bash
npm install three
```

Three.jsをインストール後、examplesフォルダから必要なファイルをコピーするか、CDNを使用します。

**4. 基本的な使い方 (DRACOLoader)**

```javascript
import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/examples/jsm/loaders/DRACOLoader.js';

// シーン、カメラ、レンダラーの初期化 (省略)
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

// DRACOLoaderの初期化
const dracoLoader = new DRACOLoader();
dracoLoader.setDecoderPath( '/examples/jsm/libs/draco/' ); // DRACOデコーダーのパスを設定

// GLTFLoaderの初期化
const gltfLoader = new GLTFLoader();
gltfLoader.setDRACOLoader( dracoLoader );

// モデルのロード
gltfLoader.load( 'path/to/model.gltf', function ( gltf ) {
    scene.add( gltf.scene );
    // モデルのロード完了後の処理
}, undefined, function ( error ) {
    console.error( error );
} );

// アニメーションループ (省略)
function animate() {
    requestAnimationFrame( animate );
    renderer.render( scene, camera );
}
animate();
```

このコードでは、DRACOで圧縮されたglTFモデルをロードしています。`DRACOLoader`の`.setDecoderPath()`でDRACOデコーダーのパスを設定する必要があります。

**5. 基本的な使い方 (KTX2Loader)**

```javascript
import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';
import { KTX2Loader } from 'three/examples/jsm/loaders/KTX2Loader.js';

// シーン、カメラ、レンダラーの初期化 (省略)
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

// KTX2Loaderの初期化
const ktx2Loader = new KTX2Loader()
	.setTranscoderPath( '/examples/jsm/libs/basis/' )
	.detectRenderer( renderer );

// GLTFLoaderの初期化
const gltfLoader = new GLTFLoader();
gltfLoader.setKTX2Loader( ktx2Loader );

// モデルのロード
gltfLoader.load( 'path/to/model.gltf', function ( gltf ) {
    scene.add( gltf.scene );
    // モデルのロード完了後の処理
}, undefined, function ( error ) {
    console.error( error );
} );

// アニメーションループ (省略)
function animate() {
    requestAnimationFrame( animate );
    renderer.render( scene, camera );
}
animate();
```

このコードでは、KTX2で圧縮されたテクスチャを使用するglTFモデルをロードしています。`KTX2Loader`の`.setTranscoderPath()`でトランスコーダーのパスを設定する必要があります。

**6. 実践的なテクニック**

*   **プログレスイベントの処理:** モデルのロード状況をプログレスバーで表示できます。

    ```javascript
    gltfLoader.load( 'path/to/model.gltf', function ( gltf ) {
        // モデルのロード完了後の処理
    }, function ( xhr ) {
        console.log( ( xhr.loaded / xhr.total * 100 ) + '% loaded' );
    }, function ( error ) {
        console.error( error );
    } );
    ```

*   **エラーハンドリング:** モデルのロードに失敗した場合の処理を記述できます。

    ```javascript
    gltfLoader.load( 'path/to/model.gltf', function ( gltf ) {
        // モデルのロード完了後の処理
    }, undefined, function ( error ) {
        console.error( 'An error happened' );
    } );
    ```

**7. 応用例とユースケース**

*   **WebAR/VRアプリケーション:** モバイルデバイスでのパフォーマンスが重要となるため、モデルの圧縮とテクスチャの圧縮が不可欠です。
*   **オンラインゲーム:** 多数のモデルを効率的にロードし、レンダリングする必要があります。
*   **製品ビジュアライゼーション:** 高品質なモデルをスムーズに表示する必要があります。

**8. トラブルシューティング**

*   **モデルがロードされない:** パスが正しいか確認してください。また、必要なローダーが正しく初期化されているか確認してください。
*   **テクスチャが表示されない:** KTX2Loaderを使用している場合、トランスコーダーのパスが正しく設定されているか確認してください。
*   **パフォーマンスが低い:** モデルのポリゴン数を減らすか、テクスチャの解像度を下げることを検討してください。
