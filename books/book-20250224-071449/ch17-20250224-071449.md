## 第17章：VR/AR - 没入感のある体験

現実世界と仮想世界を融合させるVR/AR（Virtual Reality/Augmented Reality）技術は、エンターテイメントからビジネスまで、あらゆる分野で革新的な体験を生み出しています。この章では、Webブラウザ上でVR/AR体験を構築するためのWebXR APIについて、基本的な概念から実践的なテクニックまでを解説します。没入感のある体験をWebで実現するための第一歩を踏み出しましょう。

### WebXRの基本

#### 概要と重要性

WebXR APIは、WebブラウザからVR/ARデバイスにアクセスし、没入感のある体験を構築するための標準規格です。従来のネイティブアプリケーション開発と比較して、WebXRはクロスプラットフォームに対応し、ユーザーは特別なソフトウェアをインストールする必要なく、WebブラウザからVR/AR体験にアクセスできます。この手軽さがWebXRの大きな魅力であり、教育、トレーニング、エンターテイメントなど、様々な分野での応用が期待されています。

#### 特徴と利点

*   **クロスプラットフォーム:** 異なるVR/ARデバイスやプラットフォームに対応し、一度の開発で幅広いユーザーに体験を提供できます。
*   **インストール不要:** Webブラウザ上で動作するため、ユーザーは特別なソフトウェアをインストールする必要がありません。
*   **アクセシビリティ:** Web標準技術に基づいているため、Webアクセシビリティの恩恵を受けることができます。
*   **セキュリティ:** Webブラウザのセキュリティモデルに基づいて動作するため、ネイティブアプリケーションと比較して安全性が高いと言えます。

#### 事前準備と前提条件

WebXR開発には、以下の環境が必要です。

*   **対応ブラウザ:** Chrome (Android, Windows)、Firefox (Android, Windows)、Edge (Windows)など、WebXR APIに対応したブラウザが必要です。
*   **VR/ARデバイス:** VRヘッドセット (Oculus, HTC Vive, etc.) やAR対応スマートフォン/タブレットが必要です。
*   **開発環境:** HTML、JavaScript、CSSの基本的な知識が必要です。3Dグラフィックスの知識 (Three.js, Babylon.jsなど) があると、より高度な表現が可能です。
*   **Webサーバ:** 開発したコンテンツをWebサーバに配置し、ブラウザからアクセスできるようにする必要があります。

#### WebXR APIの概要

WebXR APIは、以下の主要なインターフェースで構成されています。

*   **`XRSystem`:** VR/ARデバイスの検出、セッションの作成など、WebXRシステムの初期化を行います。
*   **`XRSession`:** VR/AR体験の実行に必要な情報を保持します。フレームの描画、入力の処理などを行います。
*   **`XRFrame`:** 特定の瞬間のVR/AR環境の状態を表します。カメラの位置、デバイスの姿勢などが含まれます。
*   **`XRReferenceSpace`:** 3D空間における座標系を定義します。
*   **`XRView`:** ユーザーの視点からのVR/AR環境を表します。
*   **`XRWebGLLayer`:** WebGLコンテキストとVR/AR環境を関連付け、3Dグラフィックスを描画します。
*   **`XRInputSource`:** VRコントローラーなどの入力デバイスを表します。

#### VR/ARデバイスの検出と初期化

WebXR体験を開始するには、まず`XRSystem`インターフェースを通じてVR/ARデバイスを検出し、`XRSession`を作成する必要があります。

```javascript
async function initXR() {
  // XRシステムの取得
  if (navigator.xr) {
    try {
      // AR対応セッションをリクエスト (fallbackとしてVR)
      const session = await navigator.xr.requestSession("immersive-ar", {
        requiredFeatures: ["hit-test", "dom-overlay"], // ARに必要な機能
        optionalFeatures: ["local-floor"],          // 任意機能 (平面検出)
      }).catch(() => navigator.xr.requestSession("immersive-vr")); // AR失敗時にVR

      session.addEventListener("end", () => {
        console.log("XRセッションが終了しました");
      });

      // セッションの初期化処理
      await initSession(session);
    } catch (error) {
      console.error("XRセッションの初期化に失敗しました:", error);
    }
  } else {
    console.log("WebXRはサポートされていません");
  }
}

// XRセッション初期化の処理
async function initSession(session) {
  // WebGLコンテキストの取得
  const canvas = document.createElement("canvas");
  document.body.appendChild(canvas);
  gl = canvas.getContext("webgl", {xrCompatible: true}); // xrCompatibleをtrueに

  if (!gl) {
      console.error("WebGLコンテキストの作成に失敗しました");
      session.end();
      return;
  }

  // XRWebGLLayerの作成
  xrLayer = new XRWebGLLayer(session, gl);
  session.updateRenderState({ baseLayer: xrLayer });

  // リファレンススペースの作成
  xrRefSpace = await session.requestReferenceSpace("local"); //ローカル座標系
  // or 'local-floor' ユーザーの足元を基準とした座標系 (AR向け)
  // or 'viewer'  ユーザーの頭を基準とした座標系

  session.requestAnimationFrame(render);
  session.addEventListener("select", onSelect);
  // セッションをグローバル変数に格納 (必須ではないがデバッグに便利)
  xrSession = session;
}

function render(time, frame) {
  if (!frame) return;
  let session = frame.session;

  session.requestAnimationFrame(render);

  // XRのフレーム情報を取得
  let pose = frame.getViewerPose(xrRefSpace);
  if (pose) {
    let glLayer = xrSession.renderState.baseLayer;
    gl.bindFramebuffer(gl.FRAMEBUFFER, glLayer.framebuffer);
    gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

    for (let view of pose.views) {
      let viewport = xrSession.renderState.baseLayer.getViewport(view);
      gl.viewport(viewport.x, viewport.y, viewport.width, viewport.height);

      // ビューごとの描画処理 (projectionMatrixとviewMatrixを使用)
      const projectionMatrix = view.projectionMatrix;
      const viewMatrix = pose.transform.inverse.matrix;

      drawScene(projectionMatrix, viewMatrix);
    }
  }
}

function drawScene(projectionMatrix, viewMatrix) {
  // ここにThree.jsやBabylon.jsを使った3Dオブジェクトの描画処理を記述します。
  // projectionMatrix: 射影行列
  // viewMatrix: ビュー行列
}

function onSelect(event) {
  // コントローラーのトリガーが押されたときの処理
  console.log("Select Event:", event);
}

// 初期化処理の実行
initXR();
```

**コード解説:**

1.  `navigator.xr.requestSession()`: VR/ARセッションをリクエストします。 `"immersive-vr"` はVR、 `"immersive-ar"` はARセッションをそれぞれリクエストします。 `requiredFeatures` は必須機能、 `optionalFeatures` は任意機能を指定します。
2.  `session.addEventListener('end', ...)`: VR/ARセッションが終了したときに実行される処理を登録します。
3.  `canvas.getContext('webgl', {xrCompatible: true})`: WebGLコンテキストを取得します。 `xrCompatible: true` を指定することで、WebXRとWebGLを連携させることができます。
4.  `new XRWebGLLayer(session, gl)`: WebGLコンテキストとVR/AR環境を関連付ける`XRWebGLLayer`を作成します。
5.  `session.updateRenderState({ baseLayer: xrLayer })`: `XRSession`のレンダリング状態を更新します。
6.  `session.requestReferenceSpace('local')`: 3D空間における座標系(`XRReferenceSpace`)を定義します。
7.  `session.requestAnimationFrame(render)`: フレームごとに`render`関数を実行するようにリクエストします。
8.  `frame.getViewerPose(xrRefSpace)`: 特定の瞬間のVR/AR環境におけるユーザーの視点の情報を取得します。
9. `drawScene(projectionMatrix, viewMatrix)` : Three.jsやBabylon.jsを使って3Dオブジェクトを描画します。
10. `session.addEventListener("select", onSelect)`: コントローラーのトリガーが押されたときに`onSelect`関数が実行されます。

**注意点:**

*   VR/ARデバイスが接続されていない場合や、WebXR APIがサポートされていないブラウザでは、`navigator.xr`が`null`になります。
*   `requestSession()`はPromiseを返すため、`async/await`を使用する必要があります。
*   `XRReferenceSpace`の種類によって、座標系の原点や向きが異なります。適切な種類を選択する必要があります。
*   WebGLコンテキストの`xrCompatible`オプションを`true`に設定する必要があります。

#### 実践的なテクニック

*   **3Dライブラリの活用:** Three.jsやBabylon.jsなどの3Dライブラリを使用することで、3Dオブジェクトの作成や操作、レンダリング処理を効率的に行うことができます。
*   **シェーダーの利用:** WebGLのシェーダーを使用することで、高度な視覚効果を実現できます。

*   **画面がちらつく:** VR/ARデバイスのリフレッシュレートとWebGLのレンダリングレートが一致しているか確認してください。

### VRコンテンツの作成

#### 概要と重要性

VRコンテンツの作成は、ユーザーを完全に仮想世界に没入させる体験を提供します。VRコントローラーを活用することで、ユーザーは仮想世界でオブジェクトを操作したり、移動したり、他のユーザーとインタラクションしたりすることができます。

#### 特徴と利点

*   **高い没入感:** ユーザーは完全に仮想世界に没入し、現実世界を忘れてしまうほどの体験を得ることができます。
*   **自由なインタラクション:** VRコントローラーを使用することで、ユーザーは仮想世界で自由にオブジェクトを操作したり、移動したりすることができます。
*   **新しいコミュニケーション:** VR空間で他のユーザーとコミュニケーションを取ることで、現実世界では体験できない新しいコミュニケーションを生み出すことができます。

#### 事前準備と前提条件

*   **VRヘッドセット:** Oculus Rift、HTC Vive、Windows Mixed RealityなどのVRヘッドセットが必要です。
*   **VRコントローラー:** VRヘッドセットに対応したVRコントローラーが必要です。
*   **3Dライブラリ:** Three.jsやBabylon.jsなどの3Dライブラリが必要です。

#### VRコントローラーの利用

WebXR APIを通じてVRコントローラーにアクセスし、コントローラーの状態 (位置、回転、ボタンの状態など) を取得することができます。

```javascript
function initXR() {
    // (前略)
    session.addEventListener("inputsourceschange", onInputSourcesChange);
}

function onInputSourcesChange(event) {
    // コントローラーが接続された時
    if (event.added) {
        for (const source of event.added) {
            inputSources.push(source); // グローバル配列に格納
            console.log("Input Source Added:", source);

            //コントローラーのモデルをロード (例: Three.js)
            loadControllerModel(source);
        }
    }

    // コントローラーが切断された時
    if (event.removed) {
        for (const source of event.removed) {
            inputSources = inputSources.filter(s => s !== source); // 配列から削除
            console.log("Input Source Removed:", source);

            // コントローラーのモデルをシーンから削除
            removeControllerModel(source);
        }
    }
}


function render(time, frame) {
    // (前略)
    // 各コントローラーの状態を更新
    for (const source of inputSources) {
        updateController(source, frame);
    }
}


function updateController(source, frame) {
    let pose = frame.getPose(source.gripSpace, xrRefSpace); // gripSpaceを使う
    if (pose) {
        // コントローラーの位置と回転を更新 (例: Three.js)
        updateControllerModel(source, pose.transform.matrix); // Three.jsのmatrixを使用

        // ボタンの状態を取得
        if (source.gamepad) {
          // Aボタンが押されているか
          if (source.gamepad.buttons[0].pressed) {
            console.log("Aボタンが押されました");
          }
        }
    }
}


function loadControllerModel(source) {
    // Three.jsでGLTFモデルをロード
    const loader = new THREE.GLTFLoader();
    loader.load('path/to/controller.gltf', (gltf) => {
        const controllerModel = gltf.scene;
        controllerModel.userData.inputSource = source; // inputSourceをuserDataに格納
        scene.add(controllerModel);
    }, undefined, (error) => {
        console.error("コントローラーモデルのロードに失敗:", error);
    });
}

function updateControllerModel(source, matrix) {
    // 対応するコントローラーモデルを取得
    const controllerModel = scene.children.find(child => child.userData.inputSource === source);
    if (controllerModel) {
        // Three.jsのMatrix4に変換
        const mat4 = new THREE.Matrix4();
        mat4.fromArray(matrix);
        controllerModel.matrix.copy(mat4);
        controllerModel.matrixAutoUpdate = false;
    }
}

function removeControllerModel(source) {
  // シーンからコントローラーモデルを削除
  const controllerModel = scene.children.find(child => child.userData.inputSource === source);
  if (controllerModel) {
      scene.remove(controllerModel);
  }
}
```

**コード解説:**

1.  `session.addEventListener('inputsourceschange', ...)`: コントローラーの接続状態が変化したときに実行される処理を登録します。
2.  `frame.getPose(source.gripSpace, xrRefSpace)`: 特定の瞬間のVR/AR環境におけるコントローラーの位置と回転の情報を取得します。`gripSpace`はコントローラーのグリップ部分の座標系を表します。
3.  `source.gamepad.buttons[0].pressed`: コントローラーのボタンの状態を取得します。
4.  `loadControllerModel(source)`: コントローラーの3Dモデルをロードします。
5.  `updateControllerModel(source, matrix)`: コントローラーの3Dモデルの位置と回転を更新します。
6.  `removeControllerModel(source)`: コントローラーの3Dモデルをシーンから削除します。

**ポイント:**

* コントローラーのモデルは、Grip Spaceに追従させると自然な見た目になります。
* 各コントローラーの状態は、フレームごとに更新する必要があります。
*  `gamepad` プロパティを使うことで、ボタン、スティック、トリガーの状態を取得できます。

#### 3D空間でのインタラクション

VRコントローラーの情報を利用して、3D空間でのインタラクションを実装することができます。

```javascript
function onSelect(event) {
  // コントローラーの位置からレイを飛ばす
  const inputSource = event.inputSource;
  let pose = event.frame.getPose(inputSource.targetRaySpace, xrRefSpace); // targetRaySpaceを使う

  if (pose) {
      const origin = new THREE.Vector3(pose.transform.position.x, pose.transform.position.y, pose.transform.position.z);
      const direction = new THREE.Vector3(0, 0, -1).applyQuaternion(new THREE.Quaternion(pose.transform.orientation.x, pose.transform.orientation.y, pose.transform.orientation.z, pose.transform.orientation.w));

      const raycaster = new THREE.Raycaster(origin, direction);
      const intersects = raycaster.intersectObjects(scene.children);

      if (intersects.length > 0) {
          const intersectedObject = intersects[0].object;
          console.log("オブジェクトにヒット:", intersectedObject.name);

          // オブジェクトに対する処理 (例: 色を変える)
          intersectedObject.material.color.set(0xff0000);
      }
  }
}
```

**コード解説:**

1. `event.frame.getPose(inputSource.targetRaySpace, xrRefSpace)`: コントローラーから伸びるレイの原点と方向を取得します。 `targetRaySpace` は、コントローラーから伸びるレイの座標系を表します。
2. `THREE.Raycaster`: レイとオブジェクトの交差判定を行うためのクラスです。
3. `raycaster.intersectObjects(scene.children)`: シーン内のオブジェクトとレイの交差判定を行います。
4. 交差したオブジェクトに対して、何らかの処理を行います。

#### トラブルシューティング

### ARコンテンツの作成

#### 概要と重要性

ARコンテンツの作成は、現実世界に仮想オブジェクトを重ね合わせる体験を提供します。ARは、エンターテイメント、教育、ビジネスなど、様々な分野で応用されており、現実世界を拡張する新しい可能性を秘めています。

#### 特徴と利点

*   **現実世界の拡張:** 現実世界に仮想オブジェクトを重ね合わせることで、現実世界を拡張することができます。
*   **インタラクティブな体験:** ユーザーは仮想オブジェクトとインタラクションすることで、よりインタラクティブな体験を得ることができます。
*   **多様な応用:** ARは、エンターテイメント、教育、ビジネスなど、様々な分野で応用することができます。

#### 事前準備と前提条件

*   **AR対応デバイス:** ARCore (Android) または ARKit (iOS) に対応したスマートフォン/タブレットが必要です。

#### カメラ映像の表示

WebXR APIを使用すると、カメラ映像をWebGLのテクスチャとして利用し、背景として表示することができます。

```javascript
//初期化時にsessionのconfigure処理を追加

    // (前略)
    try {
        await session.configure({
            requiredFeatures: ['dom-overlay', 'camera-access'],
            domOverlay: {root: document.body}
        });
    } catch (e) {
        console.error("Session configure failed", e);
        // Fallback処理を記述
    }

    session.requestAnimationFrame(render);
}


function render(time, frame) {
  if (!frame) return;
  let session = frame.session;

  session.requestAnimationFrame(render);

  // XRのフレーム情報を取得

  if (pose) {
    let glLayer = xrSession.renderState.baseLayer;
    gl.bindFramebuffer(gl.FRAMEBUFFER, glLayer.framebuffer);
    gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);

    // ARの場合、カメラ映像を背景として描画
    if (session.environmentBlendMode === 'opaque') { // 'additive' は透過
      // Three.jsなどでカメラ映像を背景に描画する処理
      // 例: Three.jsでカメラ映像をテクスチャとしてMaterialに設定
      // backgroundTexture.needsUpdate = true;  // テクスチャを更新
      // renderer.render(scene, camera); // レンダリング
    }

    for (let view of pose.views) {
      let viewport = xrSession.renderState.baseLayer.getViewport(view);
      gl.viewport(viewport.x, viewport.y, viewport.width, viewport.height);

      // ビューごとの描画処理 (projectionMatrixとviewMatrixを使用)
      const projectionMatrix = view.projectionMatrix;
      const viewMatrix = pose.transform.inverse.matrix;

      drawScene(projectionMatrix, viewMatrix);
    }
  }
}
```

**コード解説:**

1.  `session.configure()`: `camera-access` 機能を有効化し、セッションを構成します。
2.  `session.environmentBlendMode === 'opaque'`: カメラ映像の描画が必要かどうかを判定します。
3.  Three.jsなどでカメラ映像をテクスチャとして利用し、背景に描画します。

**ポイント:**

*   `environmentBlendMode` が `opaque` の場合は、カメラ映像を背景に描画する必要があります。
*   カメラ映像は、フレームごとに更新する必要があります。

#### マーカー認識、平面認識

WebXR APIには、マーカー認識や平面認識のためのAPIは直接含まれていません。これらの機能を実現するためには、別のライブラリやAPI (AR.js, MindAR, ARCore, ARKitなど) を利用する必要があります。

ここでは、ARCoreの`Hit Test`機能を利用して、平面上に3Dオブジェクトを配置する方法を説明します。

```javascript
async function initXR() {
    // (前略)
    session.addEventListener("select", onSelect);
}

function onSelect(event) {
    // (前略)
    // レイを飛ばして平面を検出
    const inputSource = event.inputSource;
    let pose = event.frame.getPose(inputSource.targetRaySpace, xrRefSpace);

    if (pose) {
        const x = gl.drawingBufferWidth / 2;
        const y = gl.drawingBufferHeight / 2;

        // Hit Testを実行
        session.requestHitTest(x, y, xrRefSpace).then( hitResults => {
            if (hitResults.length > 0) {
                const hitPose = hitResults[0].getPose(xrRefSpace); // 最初の結果を使用

                // 3Dオブジェクトを配置
                placeObject(hitPose.transform.matrix); // 3Dオブジェクトを配置
            }
        });
    }
}


function placeObject(matrix) {
    // Three.jsで3Dオブジェクトを生成
    const geometry = new THREE.BoxGeometry(0.1, 0.1, 0.1);
    const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
    const cube = new THREE.Mesh(geometry, material);

    // 行列を適用して位置と回転を設定
    const mat4 = new THREE.Matrix4();
    mat4.fromArray(matrix);
    cube.matrix.copy(mat4);
    cube.matrixAutoUpdate = false;

    // シーンに追加
    scene.add(cube);
}
```

**コード解説:**

1. `session.requestHitTest(x, y, xrRefSpace)`:  指定された座標からレイを飛ばし、現実世界の平面との交点を検出します。
2. `hitResults[0].getPose(xrRefSpace)`:  検出された交点の位置と回転の情報を取得します。
3. `placeObject(matrix)`:  3Dオブジェクトを生成し、交点の位置と回転に合わせて配置します。

**ポイント:**

*   `requestHitTest` は非同期処理なので、`then` で結果を受け取る必要があります。
*   `getPose` で取得できるのは、`XRReferenceSpace` に相対的な位置と回転です。
*   `Hit Test` は、ARCoreやARKitなどのプラットフォームに依存する機能です。

#### 3Dオブジェクトの配置

3Dオブジェクトを配置するには、Three.jsやBabylon.jsなどの3Dライブラリを使用します。

```javascript
// (前略)
function drawScene(projectionMatrix, viewMatrix) {
  // Three.js の scene, camera を更新
  camera.projectionMatrix.fromArray(projectionMatrix);
  camera.matrix.fromArray(viewMatrix);
  camera.matrixWorldInverse.copy(camera.matrix).invert();
  renderer.render(scene, camera);
}
```

**コード解説:**

1.  `camera.projectionMatrix.fromArray(projectionMatrix)`:  射影行列を Three.js のカメラに適用します。
2.  `camera.matrix.fromArray(viewMatrix)`:  ビュー行列を Three.js のカメラに適用します。
3.  `renderer.render(scene, camera)`:  シーンをレンダリングします。

**ポイント:**

*   射影行列とビュー行列は、フレームごとに更新する必要があります。
*   Three.js のカメラの位置と回転は、ビュー行列から計算する必要があります。

#### 実践的なテクニック

*   **シャドウの追加:**  シャドウを追加することで、3Dオブジェクトのリアリティを高めることができます。
*   **ライティングの調整:**  ライティングを調整することで、3Dオブジェクトの雰囲気を変えることができます。
*   **アニメーションの追加:**  アニメーションを追加することで、3Dオブジェクトをより生き生きと表現することができます。

#### 応用例とユースケース

*   **ARゲーム:**  現実世界を舞台にしたARゲームを開発することができます。
*   **ARショッピング:**  自宅に家具を配置するシミュレーションをARで提供することができます。
*   **ARナビゲーション:**  現実世界の風景に道案内を表示するARナビゲーションを開発することができます。

#### トラブルシューティング

*   **3Dオブジェクトが正しく表示されない:**  射影行列とビュー行列が正しく適用されているか確認してください。
*   **パフォーマンスが低い:**  オブジェクトの簡略化、テクスチャの最適化、描画処理の削減など、パフォーマンス最適化を行ってください。
*   **Hit Test がうまくいかない:**  十分な明るさがあるか、平面がはっきりと認識されているか確認してください。
