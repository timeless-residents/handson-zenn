# 第14章：Blenderとの連携 - 3Dモデルの作成から活用まで

3Dモデルは、ウェブサイトやアプリケーションに没入感とインタラクティブ性をもたらす強力なツールです。特に、Three.jsのようなWebGLライブラリを使用することで、ブラウザ上で高品質な3Dコンテンツを手軽に実現できます。そして、3Dモデルの作成において、Blenderは非常に強力な選択肢となります。

Blenderは、フリーかつオープンソースの3Dモデリングソフトウェアであり、モデリング、テクスチャリング、アニメーションなど、3Dコンテンツ制作に必要な機能を網羅しています。本章では、Blenderで作成した3DモデルをThree.jsで活用するための実践的な方法を解説します。初心者の方にも分かりやすいように、Blenderの基本操作から、Three.jsへのインポート、マテリアルの調整まで、段階的に説明していきます。

## Blenderの基本操作

### 概要と重要性

Blenderは、その多機能性から初心者には敷居が高いと感じられることもありますが、基本的な操作を理解すれば、非常に強力なツールとなります。このセクションでは、Blenderのインターフェース、モデリング、テクスチャリング、アニメーションの基本を解説します。

### 特徴と利点

*   **無償かつオープンソース:** 個人利用だけでなく商用利用も可能です。
*   **多機能:** モデリング、テクスチャリング、アニメーション、レンダリングなど、3Dコンテンツ制作に必要な機能が揃っています。
*   **クロスプラットフォーム:** Windows、macOS、Linuxで動作します。
*   **活発なコミュニティ:** 豊富なドキュメントやチュートリアル、アドオンが利用可能です。

### 事前準備と前提条件

*   Blenderのインストール: Blender公式サイト ([https://www.blender.org/](https://www.blender.org/)) から最新版をダウンロードしてインストールしてください。

### 基本的な使い方

#### インターフェースの理解

Blenderのインターフェースは、いくつかの主要なエリアに分かれています。

*   **3Dビューポート:** 3Dモデルの表示と操作を行うメインのエリアです。
*   **アウトライナー:** シーン内のオブジェクトの階層構造を表示します。オブジェクトの選択、表示/非表示の切り替えなどに使用します。
*   **プロパティエディタ:** 選択したオブジェクトやシーンのプロパティ（位置、回転、スケール、マテリアルなど）を編集します。
*   **タイムライン:** アニメーションの編集に使用します。
*   **ツールバー:** モデリングや編集のためのツールが並んでいます。

**基本的な操作:**

*   **視点操作:**
    *   マウスの中ボタン: 回転
    *   Shift + マウスの中ボタン: 移動
    *   マウスホイール: ズーム
*   **オブジェクトの選択:** 左クリック
*   **オブジェクトの移動:** Gキーを押してマウスを動かす
*   **オブジェクトの回転:** Rキーを押してマウスを動かす
*   **オブジェクトのスケール:** Sキーを押してマウスを動かす

#### モデリング

Blenderでのモデリングは、基本となるプリミティブ（立方体、球、円柱など）を変形していくことで行われます。

**基本的なモデリング操作:**

1.  **オブジェクトの追加:** Shift + Aキーを押して、メニューから追加したいオブジェクトを選択します。
2.  **編集モード:** Tabキーを押して、オブジェクトを編集モードに切り替えます。
3.  **頂点、辺、面の選択:** 画面左上のアイコンから、編集したい要素を選択します。
4.  **押し出し:** Eキーを押して、選択した面を押し出します。
5.  **ベベル:** Ctrl + Bキーを押して、選択した辺をベベル（面取り）します。

#### テクスチャリング

テクスチャリングは、3Dモデルに色や模様を付けることで、リアリティを高める重要な要素です。

**基本的なテクスチャリング操作:**

1.  **マテリアルの追加:** プロパティエディタのマテリアルタブを開き、"新規"ボタンをクリックします。
2.  **シェーダーエディタ:** 上部のワークスペースから"Shading"を選択し、シェーダーエディタを開きます。
3.  **テクスチャの追加:** Shift + Aキーを押して、テクスチャを追加します（例: "Image Texture"）。
4.  **テクスチャの割り当て:** テクスチャノードの出力と、マテリアル出力の入力（例: "Base Color"）を接続します。

#### アニメーション

Blenderでは、キーフレームを使ってオブジェクトの動きをアニメーションさせることができます。

**基本的なアニメーション操作:**

1.  **キーフレームの挿入:** オブジェクトを選択し、Iキーを押して、キーフレームを挿入するプロパティ（位置、回転、スケールなど）を選択します。
2.  **タイムラインの移動:** タイムライン上のカーソルを移動させ、オブジェクトの位置や回転を変更します。
3.  **キーフレームの挿入:** 再度Iキーを押して、キーフレームを挿入します。

### 実践的なテクニック

*   **モディファイアー:** Blenderには、様々なモディファイアーが用意されており、複雑な形状を簡単に作成できます。例えば、Subdivision Surfaceモディファイアーを使うと、滑らかな曲面を作成できます。
*   **スカルプトモード:** スカルプトモードを使うと、粘土をこねるように、直感的に形状を編集できます。

### 応用例とユースケース

*   **ゲームアセットの作成:** Blenderで作成した3Dモデルは、ゲームエンジン（Unity, Unreal Engineなど）で使用できます。
*   **建築ビジュアライゼーション:** 建築物の3Dモデルを作成し、リアルなレンダリングを作成できます。
*   **プロダクトデザイン:** 製品のプロトタイプを3Dモデルで作成し、デザインの検討やプレゼンテーションに活用できます。

### トラブルシューティング

*   **Blenderが重い:** オブジェクトのポリゴン数を減らす、モディファイアーの適用数を減らす、テクスチャの解像度を下げるなどの対策を試してください。
*   **テクスチャが表示されない:** テクスチャのパスが正しいか確認してください。また、UV展開が正しく行われているか確認してください。

### まとめと次のステップ

このセクションでは、Blenderの基本的な操作について解説しました。次のセクションでは、Blenderで作成した3DモデルをThree.jsで利用できる形式でエクスポートする方法について解説します。

## Three.jsで利用できる形式でのエクスポート

### 概要と重要性

Blenderで作成した3DモデルをThree.jsで利用するためには、適切な形式でエクスポートする必要があります。Three.jsでは、GLTF形式とOBJ形式が一般的に使用されます。それぞれの形式には、特徴と利点があります。

### 特徴と利点

*   **GLTF形式:**
    *   **効率的なデータ構造:** 3Dモデル、マテリアル、テクスチャ、アニメーションなどを効率的に格納できます。
    *   **バイナリ形式:** テキスト形式のOBJ形式よりもファイルサイズが小さくなります。
    *   **Three.jsとの親和性:** Three.jsのGLTFLoaderで簡単に読み込むことができます。
*   **OBJ形式:**
    *   **シンプルな形式:** 3Dモデルの頂点、面、法線などの情報をテキスト形式で格納します。
    *   **幅広い互換性:** 多くの3Dソフトウェアでサポートされています。

### 事前準備と前提条件

*   Blenderで3Dモデルを作成済みであること。
*   Three.jsプロジェクトを作成済みであること。

### 基本的な使い方

#### GLTF形式でのエクスポート設定

1.  **Blenderでモデルを開く:** エクスポートしたい3DモデルをBlenderで開きます。
2.  **エクスポート:** ファイル > エクスポート > glTF 2.0 (.glb/.gltf) を選択します。
3.  **エクスポート設定:** エクスポート設定ウィンドウで、以下の項目を設定します。
    *   **形式:** glTF Binary (.glb) または glTF Separate (.gltf + .bin + textures) を選択します。
        *   `.glb` はモデル、テクスチャ、アニメーションを一つのファイルにまとめる形式です。手軽ですが、ファイルサイズが大きくなる傾向があります。
        *   `.gltf` はモデルの構造を記述したファイルで、テクスチャやバイナリデータは別のファイルに保存されます。複数のファイルを管理する必要がありますが、テクスチャの再利用などが容易になります。
    *   **含める:**
        *   **選択オブジェクト:** 選択したオブジェクトのみをエクスポートします。
        *   **カスタムプロパティ:** カスタムプロパティをエクスポートします。
        *   **PBRマテリアル:** PBR（Physically Based Rendering）マテリアルをエクスポートします。Three.jsでPBRマテリアルを使用する場合は、必ずチェックしてください。
    *   **トランスフォーム:**
        *   **Y軸アップ:** Three.jsではY軸が上方向なので、チェックを入れてください。
    *   **ジオメトリ:**
        *   **法線:** 法線をエクスポートします。Three.jsでスムーズなライティングを行うためには、法線が必要です。
        *   **UV:** UV座標をエクスポートします。テクスチャを正しく表示するためには、UV座標が必要です。
        *   **頂点カラー:** 頂点カラーをエクスポートします。
    *   **アニメーション:**
        *   **アニメーション:** アニメーションをエクスポートします。
    *   **シェイプキー:** シェイプキーをエクスポートします。

4.  **エクスポート実行:** "glTF 2.0をエクスポート"ボタンをクリックして、ファイルを保存します。

**推奨設定例:**

*   形式: glTF Binary (.glb)
*   含める > 選択オブジェクト: チェック (必要に応じて)
*   トランスフォーム > Y軸アップ: チェック
*   ジオメトリ > 法線: チェック
*   ジオメトリ > UV: チェック

#### OBJ形式でのエクスポート設定

1.  **Blenderでモデルを開く:** エクスポートしたい3DモデルをBlenderで開きます。
2.  **エクスポート:** ファイル > エクスポート > Wavefront (.obj) を選択します。
3.  **エクスポート設定:** エクスポート設定ウィンドウで、以下の項目を設定します。
    *   **選択オブジェクト:** 選択したオブジェクトのみをエクスポートします。
    *   **マテリアルを適用:** マテリアル情報をエクスポートします。Three.jsでマテリアルを適用する場合は、チェックしてください。
    *   **UVを適用:** UV座標をエクスポートします。テクスチャを正しく表示するためには、UV座標が必要です。
    *   **法線を適用:** 法線をエクスポートします。Three.jsでスムーズなライティングを行うためには、法線が必要です。
    *   **Y軸アップ:** Three.jsではY軸が上方向なので、チェックを入れてください。

4.  **エクスポート実行:** "OBJをエクスポート"ボタンをクリックして、ファイルを保存します。

**推奨設定例:**

*   選択オブジェクト: チェック (必要に応じて)
*   マテリアルを適用: チェック
*   UVを適用: チェック
*   法線を適用: チェック
*   Y軸アップ: チェック

### 実践的なテクニック

*   **エクスポートプリセット:** 複数のモデルをエクスポートする場合、エクスポート設定をプリセットとして保存しておくと便利です。
*   **バッチエクスポート:** 複数のモデルをまとめてエクスポートすることができます。

### 応用例とユースケース

*   **ウェブサイトへの3Dモデルの埋め込み:** GLTF形式でエクスポートした3Dモデルを、Three.jsを使ってウェブサイトに埋め込むことができます。
*   **オンライン3Dビューワーの作成:** Three.jsを使って、オンラインで3Dモデルを閲覧できるビューワーを作成することができます。

### トラブルシューティング

*   **モデルが正しく表示されない:** エクスポート設定が正しいか確認してください。特に、法線、UV座標、Y軸アップの設定を確認してください。
*   **テクスチャが表示されない:** テクスチャのパスが正しいか確認してください。

## エクスポート時の注意点

### 概要と重要性

Blenderで作成した3DモデルをThree.jsで正しく表示するためには、エクスポート時にいくつかの注意点があります。スケール、回転、原点の調整、テクスチャのパス設定などが重要です。

### 特徴と利点

*   **スケールの調整:** BlenderとThree.jsでは、スケールの単位が異なる場合があります。必要に応じて、スケールを調整する必要があります。
*   **回転の調整:** BlenderとThree.jsでは、座標系の向きが異なる場合があります。必要に応じて、回転を調整する必要があります。
*   **原点の調整:** 3Dモデルの原点の位置が、Three.jsでの表示に影響を与える場合があります。必要に応じて、原点の位置を調整する必要があります。
*   **テクスチャのパス設定:** テクスチャのパスが正しく設定されていない場合、Three.jsでテクスチャが表示されません。テクスチャのパスを相対パスまたは絶対パスで設定する必要があります。

### 事前準備と前提条件

*   Blenderで3Dモデルを作成済みであること。
*   Three.jsプロジェクトを作成済みであること。

### 基本的な使い方

#### スケール、回転、原点の調整

**スケールの調整:**

Blenderで作成した3DモデルをThree.jsで表示した際に、サイズが大きすぎたり小さすぎたりする場合は、Blenderでスケールを調整する必要があります。

1.  **オブジェクトを選択:** スケールを調整したいオブジェクトを選択します。
2.  **スケール変更:** Nキーを押して、トランスフォームパネルを開きます。
3.  **スケール値を調整:** スケール値を調整します。例えば、スケール値を0.01にすると、オブジェクトのサイズが1/100になります。
4.  **スケールを適用:** Ctrl + Aキーを押して、"スケール"を選択し、スケールを適用します。

**回転の調整:**

Blenderで作成した3DモデルをThree.jsで表示した際に、向きが異なっている場合は、Blenderで回転を調整する必要があります。

1.  **オブジェクトを選択:** 回転を調整したいオブジェクトを選択します。
2.  **回転変更:** Nキーを押して、トランスフォームパネルを開きます。
3.  **回転値を調整:** 回転値を調整します。
4.  **回転を適用:** Ctrl + Aキーを押して、"回転"を選択し、回転を適用します。

**原点の調整:**

3Dモデルの原点の位置が、Three.jsでの表示に影響を与える場合があります。例えば、オブジェクトが回転する際に、原点を中心に回転させたい場合は、原点の位置をオブジェクトの中心に設定する必要があります。

1.  **オブジェクトを選択:** 原点を調整したいオブジェクトを選択します。
2.  **原点の移動:** オブジェクト > トランスフォーム > 原点 > "ジオメトリを原点に移動" を選択します。

#### テクスチャのパス設定

テクスチャのパスが正しく設定されていない場合、Three.jsでテクスチャが表示されません。テクスチャのパスを相対パスまたは絶対パスで設定する必要があります。

**相対パス:**

テクスチャファイルが、Blenderファイルと同じディレクトリまたはサブディレクトリにある場合は、相対パスを使用できます。

1.  **シェーダーエディタを開く:** 上部のワークスペースから"Shading"を選択し、シェーダーエディタを開きます。
2.  **テクスチャノードを選択:** テクスチャノードを選択します。
3.  **画像ファイルを選択:** テクスチャノードの"開く"ボタンをクリックして、画像ファイルを選択します。
4.  **相対パス:** Blenderは自動的に相対パスを使用します。

**絶対パス:**

テクスチャファイルが、Blenderファイルとは異なる場所に保存されている場合は、絶対パスを使用する必要があります。しかし、絶対パスは環境によって変わるため、できる限り相対パスを使用することを推奨します。

### 実践的なテクニック

*   **Emptyオブジェクトの使用:** 3Dモデルの原点を調整する際に、Emptyオブジェクトを使用すると便利です。Emptyオブジェクトを3Dモデルの親オブジェクトとして設定し、Emptyオブジェクトの位置を調整することで、3Dモデルの原点を調整できます。

### 応用例とユースケース

*   **複数の3Dモデルの配置:** 複数の3DモデルをThree.jsで配置する際に、それぞれの3Dモデルの原点の位置を調整することで、配置を容易にすることができます。

### トラブルシューティング

*   **スケールが正しくない:** BlenderとThree.jsでのスケールの単位が異なるため、スケールを調整する必要があります。
*   **回転が正しくない:** BlenderとThree.jsでの座標系の向きが異なるため、回転を調整する必要があります。
*   **原点の位置が正しくない:** 3Dモデルの原点の位置が、Three.jsでの表示に影響を与えるため、原点の位置を調整する必要があります。
*   **テクスチャが表示されない:** テクスチャのパスが正しく設定されていないため、テクスチャのパスを修正する必要があります。

### まとめと次のステップ

## Three.jsへのインポートと表示

### 概要と重要性

Blenderで作成し、エクスポートした3DモデルをThree.jsで表示するには、適切なローダーを使用してモデルを読み込み、シーンに追加する必要があります。このセクションでは、GLTFLoaderとOBJLoaderを使った読み込み方法、およびマテリアルの調整について解説します。

### 特徴と利点

*   **GLTFLoader:**
    *   GLTF形式のモデルを効率的に読み込むことができます。
    *   マテリアル、テクスチャ、アニメーションなどの情報を自動的に読み込みます。
*   **OBJLoader:**
    *   OBJ形式のモデルを読み込むことができます。
    *   シンプルなモデルを簡単に読み込むことができます。

### 事前準備と前提条件

*   Three.jsプロジェクトを作成済みであること。
*   GLTFLoaderまたはOBJLoaderをインストール済みであること。

    ```bash
    npm install three @types/three  # Three.js本体
    npm install --save-dev three-gltf-loader  # GLTFLoader（公式ではないですが、簡単のため）
    npm install --save-dev three-obj-loader  # OBJLoader （公式ではないですが、簡単のため）
    ```

*   BlenderからエクスポートしたGLTFファイルまたはOBJファイルがあること。

### 基本的な使い方

#### GLTFLoaderを使った読み込み

```javascript
import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader';

// シーン、カメラ、レンダラーの作成（省略）
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

const loader = new GLTFLoader();

loader.load(
    'path/to/your/model.glb', // モデルのパス
    function ( gltf ) {
        scene.add( gltf.scene ); // シーンにモデルを追加
        camera.position.z = 5; // カメラの位置を調整

        function animate() {
            requestAnimationFrame( animate );
            renderer.render( scene, camera );
        }
        animate();
    },
    function ( xhr ) {
        console.log( ( xhr.loaded / xhr.total * 100 ) + '% loaded' ); // ロード状況を表示
    },
    function ( error ) {
        console.log( 'An error happened' ); // エラー発生時の処理
        console.error( error );
    }
);
```

**コード解説:**

#### OBJLoaderを使った読み込み

```javascript
import * as THREE from 'three';
import { OBJLoader } from 'three/examples/jsm/loaders/OBJLoader';
import { MTLLoader } from 'three/examples/jsm/loaders/MTLLoader';

// シーン、カメラ、レンダラーの作成（省略）
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

// MTLローダーのインスタンスを作成
const mtlLoader = new MTLLoader();

// MTLファイルのパスを指定して読み込む
mtlLoader.load('path/to/your/model.mtl', function(materials) {
  materials.preload(); // マテリアルを事前にロード
  const objLoader = new OBJLoader(); // OBJローダーのインスタンスを作成
  objLoader.setMaterials(materials); // OBJローダーにMTLローダーで読み込んだマテリアルをセット

  // OBJファイルのパスを指定して読み込む
  objLoader.load('path/to/your/model.obj', function(object) {
    scene.add(object); // シーンにモデルを追加
    camera.position.z = 5; // カメラの位置を調整

    function animate() {
      requestAnimationFrame( animate );
      renderer.render( scene, camera );
    }
    animate();
  },
  function ( xhr ) {
    console.log( ( xhr.loaded / xhr.total * 100 ) + '% loaded' ); // ロード状況を表示
  },
  function ( error ) {
    console.log( 'An error happened' ); // エラー発生時の処理
    console.error( error );
  });
});
```

**コード解説:**

1.  **OBJLoaderとMTLLoaderのインポート:**  `import { OBJLoader } from 'three/examples/jsm/loaders/OBJLoader';` と `import { MTLLoader } from 'three/examples/jsm/loaders/MTLLoader';`でOBJLoaderとMTLLoaderをインポートします。
2.  **MTLLoaderのインスタンス化:** `const mtlLoader = new MTLLoader();`でMTLLoaderのインスタンスを作成します。OBJ形式の場合、マテリアルは別のMTLファイルに保存されていることが多いため、MTLLoaderを使ってマテリアルを読み込む必要があります。
3.  **マテリアルの読み込み:** `mtlLoader.load()` メソッドを使って、マテリアルを読み込みます。
4.  **OBJLoaderのインスタンス化:** `const objLoader = new OBJLoader();` でOBJLoaderのインスタンスを作成します。
5.  **マテリアルの設定:** `objLoader.setMaterials(materials);`でOBJLoaderにMTLLoaderで読み込んだマテリアルをセットします。
6.  **モデルの読み込み:** `objLoader.load()` メソッドを使って、モデルを読み込みます。
    *   第1引数: モデルのパスを指定します。
    *   第2引数: モデルの読み込みが完了した際に実行されるコールバック関数を指定します。
    *   第3引数: モデルのロード状況を表示するコールバック関数を指定します。
    *   第4引数: エラーが発生した場合に実行されるコールバック関数を指定します。
7.  **シーンにモデルを追加:** コールバック関数内で、`scene.add( object );` を使って、モデルをシーンに追加します。
8.  **アニメーションループ:** シーンとカメラをレンダリングするためのアニメーションループを作成します。

#### マテリアルの調整

GLTFLoaderまたはOBJLoaderで読み込んだモデルのマテリアルは、Three.jsのMaterialクラスのインスタンスとして取得できます。マテリアルのプロパティを調整することで、モデルの色、質感、透明度などを変更することができます。

```javascript
// モデルの読み込み（上記コード参照）

loader.load(
    'path/to/your/model.glb',
    function ( gltf ) {
        const model = gltf.scene;
        scene.add( model );

        // マテリアルの調整
        model.traverse( ( child ) => {
            if ( child.isMesh ) {
                // メッシュのマテリアルを取得
                const material = child.material;

                // マテリアルのプロパティを調整
                material.color.setHex( 0xff0000 ); // 赤色に変更
                material.metalness = 0.5; // 金属感を調整
                material.roughness = 0.5; // 粗さを調整
            }
        } );

        // アニメーションループ（省略）
    }
);
```

**コード解説:**

1.  **モデルの取得:** `const model = gltf.scene;` で読み込んだモデルを取得します。
2.  **モデルのトラバース:** `model.traverse()` メソッドを使って、モデルの全ての子オブジェクトをトラバースします。
3.  **メッシュの判定:** `if ( child.isMesh )` で、子オブジェクトがメッシュであるかどうかを判定します。
4.  **マテリアルの取得:** `const material = child.material;` でメッシュのマテリアルを取得します。
5.  **マテリアルのプロパティを調整:** `material.color.setHex( 0xff0000 );` のように、マテリアルのプロパティを調整します。
