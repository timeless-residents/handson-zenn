## 第2章：Three.jsの基本要素 - シーン、カメラ、レンダラー

Three.js は、Webブラウザ上で3Dグラフィックスを扱うための強力なJavaScriptライブラリです。美しい3D表現を実現するためには、シーン、カメラ、レンダラーという3つの基本要素を深く理解することが不可欠です。本章では、これらの要素を丁寧に解説し、実践的なテクニックや応用例を通して、Three.jsの世界への第一歩を力強くサポートします。

### シーン (Scene) の理解

#### 概要と重要性

Three.jsにおけるシーンは、3Dオブジェクトやライト、カメラなど、あらゆる要素を配置する舞台です。映画や演劇の舞台と同じように、シーンがなければ何も表示されません。シーンは、Three.jsアプリケーションの根幹であり、3D空間の構造を定義します。

#### 特徴と利点

*   **オブジェクトの管理:** シーンは、3Dオブジェクトを階層的に管理するためのコンテナとして機能します。
*   **グローバル設定:**  シーンは、霧(fog)や背景色など、シーン全体の環境設定を保持します。
*   **描画順の制御:**  シーンに追加されたオブジェクトは、自動的に描画されます。

#### 事前準備と前提条件

*   Three.jsの基本的なセットアップが完了していること (CDNまたはnpmでThree.jsが利用可能であること)
*   JavaScriptの基本的な知識があること

#### 基本的な使い方

1.  **シーンの作成:**

```javascript
import * as THREE from 'three';

const scene = new THREE.Scene();
```

2.  **オブジェクトの追加:**

```javascript
const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );
```

3.  **オブジェクトの削除:**

```javascript
scene.remove( cube ); // シーンから cube を削除
cube.geometry.dispose(); // ジオメトリを破棄
cube.material.dispose(); // マテリアルを破棄
```

   **重要:** オブジェクトを削除する際は、メモリリークを防ぐために、ジオメトリとマテリアルの `dispose()` メソッドを呼び出すことを推奨します。

#### 実践的なテクニック

*   **オブジェクトの親子関係:**  `object.add(child)` を使用して、オブジェクトを別のオブジェクトの子として追加できます。これにより、親子関係にあるオブジェクトをまとめて移動・回転させることができます。
    ```javascript
    const parent = new THREE.Object3D();
    const child = new THREE.Mesh(new THREE.SphereGeometry(0.5, 32, 32), new THREE.MeshBasicMaterial({ color: 0xff0000 }));
    parent.add(child);
    scene.add(parent);

    parent.position.set(1,0,0); //親の位置を変更
    child.position.set(1,0,0); //子も位置を変更
    ```

*   **シーングラフの活用:**  複雑な3Dモデルは、複数のオブジェクトを組み合わせて構成されることが一般的です。シーングラフを利用することで、これらのオブジェクトを階層的に管理し、効率的に操作できます。

    ```javascript
    // 例: 車のシーングラフ
    const car = new THREE.Group(); // グループを作成
    const body = new THREE.Mesh(new THREE.BoxGeometry(2, 1, 1), new THREE.MeshPhongMaterial({ color: 0x808080 }));
    const wheel1 = new THREE.Mesh(new THREE.CylinderGeometry(0.3, 0.3, 0.2, 32), new THREE.MeshPhongMaterial({ color: 0x000000 }));
    const wheel2 = wheel1.clone();
    const wheel3 = wheel1.clone();
    const wheel4 = wheel1.clone();

    wheel1.position.set(-0.8, -0.5, 0.5);
    wheel2.position.set(0.8, -0.5, 0.5);
    wheel3.position.set(-0.8, -0.5, -0.5);
    wheel4.position.set(0.8, -0.5, -0.5);

    car.add(body);
    car.add(wheel1);
    car.add(wheel2);
    car.add(wheel3);
    car.add(wheel4);

    scene.add(car);
    ```

#### 応用例とユースケース

*   **ゲーム開発:**  シーンは、ゲームのレベルやステージを表現するために使用されます。
*   **建築ビジュアライゼーション:**  建物やインテリアの3Dモデルをシーンに配置し、リアルな視覚化を実現できます。
*   **データ可視化:**  複雑なデータを3Dオブジェクトとしてシーンに配置し、視覚的に理解しやすい表現を作成できます。
*   **製品プレゼンテーション:** 製品の3Dモデルをシーンに配置し、インタラクティブなプレゼンテーションを制作できます。

#### トラブルシューティング

*   **オブジェクトが表示されない:**
    *   オブジェクトがカメラの視野外にある可能性があります。カメラの位置や向き、視野角を調整してください。
    *   オブジェクトのマテリアルが正しく設定されていない可能性があります。
    *   ライトが不足している可能性があります。

*   **パフォーマンスの問題:**
    *   シーン内のオブジェクト数が多すぎる可能性があります。オブジェクトの数を減らすか、最適化してください。
    *   テクスチャのサイズが大きすぎる可能性があります。テクスチャを圧縮するか、より小さいサイズを使用してください。
    *   WebGLRendererの設定で、`antialias` を `true` に設定すると、パフォーマンスが低下する場合があります。必要に応じて `false` に設定してください。

#### まとめと次のステップ

シーンは、Three.jsアプリケーションにおける3D空間の基盤です。オブジェクトの追加と削除、シーングラフの活用など、シーンの基本的な使い方をマスターすることで、より複雑な3D表現が可能になります。次のステップでは、カメラの種類と設定について学び、3D空間を様々な視点から捉える方法を習得しましょう。

### カメラ (Camera) の種類と設定

#### 概要と重要性

カメラは、3Dシーンをどの視点からレンダリングするかを決定する要素です。現実世界のカメラと同様に、Three.jsのカメラも位置、向き、視野角などのパラメータを持ちます。適切なカメラ設定は、3Dシーンの見栄えを大きく左右します。

#### 特徴と利点

*   **視点の制御:** カメラの位置と向きを調整することで、3Dシーンを様々な視点から観察できます。
*   **投影方法の選択:** PerspectiveCameraとOrthographicCameraという2種類のカメラがあり、用途に応じて投影方法を選択できます。
*   **カメラコントロールの利用:** OrbitControlsやFlyControlsなどのカメラコントロールを使用することで、マウスやキーボードでインタラクティブにカメラを操作できます。

#### 事前準備と前提条件

*   シーンの作成が完了していること
*   PerspectiveCameraとOrthographicCameraの違いを理解していること

#### 基本的な使い方

1.  **PerspectiveCamera (透視投影) の作成:**

```javascript
const fov = 75; // 視野角 (Field of View)
const aspect = window.innerWidth / window.innerHeight; // アスペクト比
const near = 0.1; // ニアクリップ面
const far = 1000; // ファークリップ面
const camera = new THREE.PerspectiveCamera( fov, aspect, near, far );
camera.position.z = 5; // カメラの位置
```

2.  **OrthographicCamera (正投影) の作成:**

```javascript
const aspect = window.innerWidth / window.innerHeight;
const camera = new THREE.OrthographicCamera(
    -5 * aspect,  // left
     5 * aspect,  // right
     5,            // top
    -5,            // bottom
    0.1,           // near
    1000           // far
);
camera.position.z = 5;
```

3.  **カメラの位置、向き、視野角の調整:**

```javascript
camera.position.set( 0, 2, 5 ); // 位置を設定
camera.lookAt( scene.position ); // シーンの中心を見るように設定
camera.fov = 60; // 視野角を変更
camera.updateProjectionMatrix(); // 変更を反映
```

#### 実践的なテクニック

*   **カメラコントロールの導入 (OrbitControls):**

```javascript
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js';

const controls = new OrbitControls( camera, renderer.domElement );
controls.enableDamping = true; // ダンプニングを有効にする
controls.dampingFactor = 0.05; // ダンプニングの強さ
controls.screenSpacePanning = false; // 水平方向のパンを無効にする
controls.minDistance = 1; // カメラの最小距離
controls.maxDistance = 10; // カメラの最大距離

// レンダリングループ内で controls.update() を呼び出す
function animate() {
    requestAnimationFrame( animate );
    controls.update(); // カメラコントロールを更新
    renderer.render( scene, camera );
}
animate();
```

*   **カメラの追従:**  オブジェクトを追従するようにカメラを動かすことで、よりダイナミックな表現が可能です。

```javascript
// 例: キューブを追従するカメラ
function animate() {
    requestAnimationFrame( animate );

    // キューブの位置を取得
    const cubePosition = cube.position.clone();

    // カメラの位置をキューブの位置から少しオフセット
    camera.position.copy(cubePosition).add(new THREE.Vector3(2, 2, 2));

    // カメラがキューブを見るように設定
    camera.lookAt(cubePosition);

    renderer.render( scene, camera );
}
```

*   **複数のカメラの切り替え:**  複数のカメラを作成し、必要に応じて切り替えることで、様々な視点からの表現を実現できます。

#### 応用例とユースケース

*   **製品デモ:**  製品の3Dモデルを様々な角度から見せるために、複数のカメラを切り替えることができます。
*   **ゲーム開発:**  一人称視点 (FPS) や三人称視点 (TPS) など、ゲームの種類に応じて適切なカメラを選択し、操作方法を実装します。
*   **VR/ARアプリケーション:**  VR/ARヘッドセットの動きに合わせてカメラを動かし、没入感のある体験を提供します。
*   **建築ビジュアライゼーション:**  建物の内部をウォークスルーするために、カメラをスムーズに移動させることができます。

#### トラブルシューティング

*   **カメラがオブジェクトを捉えない:**
    *   `near` と `far` の値が適切でない可能性があります。オブジェクトが `near` と `far` の範囲内に収まるように調整してください。
    *   カメラの位置や向きが正しくない可能性があります。
*   **OrbitControls が動作しない:**
    *   `OrbitControls` のインスタンスが正しく作成されているか確認してください。
    *   `renderer.domElement` が正しいDOM要素を参照しているか確認してください。
    *   `animate` 関数内で `controls.update()` が呼び出されているか確認してください。

#### まとめと次のステップ

カメラは、3Dシーンの視点を決定する重要な要素です。PerspectiveCameraとOrthographicCameraの違いを理解し、カメラコントロールを使いこなすことで、より魅力的な3D表現が可能になります。次のステップでは、レンダラーの設定について学び、3DシーンをWebブラウザに表示する方法を習得しましょう。

### レンダラー (Renderer) の設定

#### 概要と重要性

レンダラーは、シーンとカメラの情報に基づいて、3DグラフィックスをWebブラウザ上に描画する役割を担います。Three.jsでは、WebGLRendererが最も一般的であり、GPUを利用して高速なレンダリングを実現します。適切なレンダラーの設定は、パフォーマンスと画質のバランスを保つ上で重要です。

#### 特徴と利点

*   **高速なレンダリング:**  WebGLRendererは、GPUを利用して高速なレンダリングを実現します。
*   **柔軟な設定:**  キャンバスサイズ、アスペクト比、アンチエイリアスなど、様々な設定を調整できます。
*   **多様なエフェクト:**  ポストプロセッシングエフェクトを適用することで、より高度な視覚効果を実現できます。

#### 事前準備と前提条件

*   シーンとカメラの作成が完了していること
*   HTMLに`<canvas>`要素が追加されていること

#### 基本的な使い方

1.  **WebGLRenderer の作成:**

```javascript
const renderer = new THREE.WebGLRenderer({antialias: true});
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement ); // canvas要素をDOMに追加
```

2.  **キャンバスサイズとアスペクト比の設定:**

```javascript
renderer.setSize( window.innerWidth, window.innerHeight ); // サイズを設定
camera.aspect = window.innerWidth / window.innerHeight; // アスペクト比を更新
camera.updateProjectionMatrix(); // 投影行列を更新
```

3.  **レンダリングループの実装 (requestAnimationFrame):**

```javascript
function animate() {
    requestAnimationFrame( animate );
    renderer.render( scene, camera ); // シーンとカメラをレンダリング
}
animate();
```

4. **アンチエイリアスの設定:**

```javascript
const renderer = new THREE.WebGLRenderer({antialias: true}); //アンチエイリアスを有効にする
```

#### 実践的なテクニック

*   **高解像度ディスプレイ対応:**  `window.devicePixelRatio` を利用して、高解像度ディスプレイでより精細な描画を実現できます。

```javascript
renderer.setPixelRatio( window.devicePixelRatio );
renderer.setSize( window.innerWidth, window.innerHeight );
```

*   **シャドウの有効化:**

```javascript
renderer.shadowMap.enabled = true; // シャドウを有効にする
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // シャドウの種類を設定
```

   **注意:**  シャドウを有効にするには、ライトとオブジェクトの両方でシャドウを設定する必要があります。

*   **背景色の設定:**

```javascript
renderer.setClearColor( 0x000000, 1 ); // 背景色を黒に設定 (透明度 1)
```

*   **パフォーマンスの最適化:**

    *   `renderer.autoClear = false;` を設定し、フレームごとにシーン全体を再描画するのを防ぎます。
    *   不要なオブジェクトをシーンから削除します。
    *   テクスチャのサイズを最適化します。
    *   WebGLRenderer の設定で、`antialias` を `true` に設定すると、パフォーマンスが低下する場合があります。必要に応じて `false` に設定してください。

#### 応用例とユースケース

*   **インタラクティブな3Dコンテンツ:**  マウスやキーボードの操作に応じて、3Dオブジェクトを動かしたり、カメラを操作したりできます。
*   **データ可視化:**  データを3Dグラフとして表示し、インタラクティブに探索できます。
*   **VR/ARアプリケーション:**  VR/ARデバイスからの入力に基づいて、3Dシーンをリアルタイムにレンダリングします。
*   **ゲーム開発:**  複雑なゲームロジックと3Dグラフィックスを組み合わせて、没入感のあるゲーム体験を提供します。

#### トラブルシューティング

*   **画面が真っ暗になる:**
    *   ライトが不足している可能性があります。シーンにライトを追加してください。
    *   カメラの位置が正しくない可能性があります。カメラの位置を調整してください。
    *   マテリアルの設定が正しくない可能性があります。
*   **パフォーマンスが低い:**
    *   オブジェクト数が多すぎる可能性があります。オブジェクト数を減らすか、最適化してください。
    *   テクスチャのサイズが大きすぎる可能性があります。テクスチャを圧縮するか、より小さいサイズを使用してください。
    *   `antialias` が有効になっている場合、無効にすることを検討してください。
*   **画面がぼやける:**
    *   `antialias` が有効になっているか確認してください。有効になっている場合は、解像度を上げるか、別のアンチエイリアス手法を試してください。
