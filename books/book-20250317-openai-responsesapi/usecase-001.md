# システムプロンプトによる応答調整

## 概要

AIモデルの真の力を引き出すには、単に質問するだけでなく、「どのように」応答すべきかを指示することが重要です。このユースケースでは、OpenAI Responses APIの`instructions`パラメータ（システムプロンプト）を活用して、同じ質問に対して異なる視点、トーン、スタイルの応答を生成する方法を解説します。

## 技術的解説

### システムプロンプトの役割

システムプロンプト（`instructions`パラメータ）は、AIモデルに対して「どのような役割を担うべきか」「どのようなトーンで応答すべきか」などの指示を与えるための強力なメカニズムです。これにより、ユーザー入力（`input`）はそのままに、応答の特性を大きく変化させることができます。

### 実装のポイント

```python
def create_response_with_instructions(client, prompt_text, instructions):
    """指定されたシステムプロンプト（instructions）を使用してレスポンスを生成します。"""
    response = client.responses.create(
        model="gpt-4o",
        input=prompt_text,
        instructions=instructions
    )
    return response
```

この関数は、基本的なAPIリクエストに`instructions`パラメータを追加しています。このシンプルな追加だけで、モデルの応答特性を根本的に変えることができます。

## 多様な視点の実現

このサンプルでは、「AIの未来について教えてください」という同一の質問に対して、5つの異なる視点からの回答を生成しています：

```python
instructions_list = [

        "instructions": "あなたは楽観的な未来学者です。技術の発展によるポジティブな側面に焦点を当ててください。"
    },
    {
        "description": "バランスの取れた視点",
        "instructions": "あなたは中立的な技術アナリストです。AIの可能性とリスクの両方をバランス良く議論してください。"
    },
    {
        "description": "批判的な視点",
        "instructions": "あなたは慎重な技術批評家です。新技術の潜在的なリスクや課題を強調してください。"
    },
    {
        "description": "教育的な視点",
        "instructions": "あなたは大学教授です。論理的で教育的な解説をしてください。400字以内で簡潔に説明してください。"
    },
    {
        "description": "クリエイティブな視点",
        "instructions": "あなたはSF作家です。想像力豊かな未来シナリオを短い物語形式で描写してください。"
    }

```

各指示は、モデルに異なる「ペルソナ」を与え、それに応じた応答スタイルを引き出します。

## 効果的なシステムプロンプト設計のポイント

システムプロンプトを最大限に活用するためのベストプラクティスを紹介します：

### 1. 明確なペルソナ定義

「あなたは〇〇です」という形式で、モデルに明確な役割やアイデンティティを与えましょう。抽象的な指示よりも、具体的なペルソナを設定する方が効果的です。

**効果的な例**:
```
あなたは20年の経験を持つデータサイエンティストです。複雑な統計概念を初心者にもわかりやすく説明するのが得意です。
```

**あまり効果的でない例**:
```
専門的に説明してください。
```

### 2. 具体的な制約条件

出力の長さ、形式、含めるべき要素などを明示的に指定しましょう。

**効果的な例**:
```
あなたは簡潔なビジネスレポートの専門家です。300字以内で、3つの箇条書きポイントと1つの結論を含めてください。
```

**あまり効果的でない例**:
```
短く書いてください。
```

### 3. トーンと文体の指定

応答の感情的トーンや文体を具体的に指定することで、ブランドボイスや状況に合った表現を引き出せます。

**効果的な例**:
```
あなたは高級ホテルのコンシェルジュです。丁寧でありながらも温かみのある口調で、お客様の質問に答えてください。専門用語は避け、上品な表現を使ってください。
```

**あまり効果的でない例**:
```
フレンドリーに答えてください。
```

### 4. 複数の指示の優先順位

複数の指示を含める場合は、優先順位を明確にしましょう。

**効果的な例**:
```
あなたは技術ブログのライターです。以下の優先順位で応答してください：
1. 正確性を最優先すること
2. 初心者にもわかりやすい説明を心がけること
3. 可能であれば実用的な例を含めること
```

## 応用テクニック

### 1. 条件付き指示

特定の条件に基づいて応答を調整する指示を含めることができます。

```python
instructions = """
あなたは旅行アドバイザーです。ユーザーの質問に以下のルールに従って回答してください：
- 家族旅行について質問された場合は、子供向けアクティビティを必ず含めてください
- 予算について言及があれば、その範囲内のオプションのみを提案してください
- 特定の季節が指定されている場合は、その時期に最適な目的地を優先してください
"""
```

### 2. メタ指示

応答プロセス自体についての指示を含めることで、より洗練された回答を引き出せます。

```python
instructions = """
あなたは製品マネージャーです。質問に答える前に、以下のステップで考えてください：
1. まず、質問の背後にある真のニーズを特定する
2. 次に、複数の解決策の選択肢を考える
3. 最後に、それぞれの選択肢のメリット・デメリットを分析した上で最適な提案をする

これらの思考プロセスは明示せず、最終的な回答のみを提示してください。
"""
```

### 3. 多段階指示

複雑なタスクを段階的に処理するよう指示することで、より構造化された応答を得られます。

```python
instructions = """
あなたは投資アドバイザーです。以下の3段階で回答を構成してください：

第1段階: 提示された投資機会の主要なリスク要因を3つ特定する
第2段階: それぞれのリスクに対する緩和策を提案する
第3段階: リスクとリターンのバランスを考慮した総合的な推奨事項をまとめる
"""
```

## まとめ

システムプロンプト（`instructions`パラメータ）は、OpenAI Responses APIの最も強力な機能の一つです。同じユーザー入力に対して、目的に応じた多様な応答を生成できるこの機能を活用することで、AIアプリケーションの表現力と適応性を大幅に向上させることができます。

ビジネスコンテキストでは、この機能により：
- 多様な視点からの分析を効率的に生成
- 異なる対象者に合わせたコンテンツの最適化
- ブランドボイスや特定のコミュニケーションスタイルの一貫した維持

が可能になります。システムプロンプトの設計は、AIとのコミュニケーションをより効果的にするための「メタスキル」として、今後ますます重要になるでしょう。

次のステップとして、複数の入力テキストによる応答生成（usecase-002）や、ストリーミングによるリアルタイム応答表示（usecase-003）など、さらに高度な機能を探索してみましょう。

## 実行方法

1. プロジェクトのルートディレクトリに`.env`ファイルを作成し、OpenAI APIキーを設定します：

```
OPENAI_API_KEY=your_api_key_here
```

2. 必要なパッケージをインストールします：

```bash
pip install -r requirements.txt
```

3. スクリプトを実行します：

```bash
python main.py
```

実行結果として、同じ「AIの未来について教えてください」という質問に対する5つの異なる視点からの回答が表示されます。それぞれの回答がどのように異なるかを比較し、システムプロンプトの効果を実感してください。
