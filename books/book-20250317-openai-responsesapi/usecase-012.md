# 複数画像の分析と比較

## 概要

AIの視覚理解能力は、単一の画像だけでなく、複数の画像を同時に処理し、それらの関係性を理解することにも及びます。このユースケースでは、OpenAI Responses APIを使用して複数の画像を同時に分析し、それらの間の関係、パターン、相違点を詳細に比較する方法を紹介します。体系的な比較基準に基づく分析、画像間の共通パターンの検出、スタイルとコンテンツの分離分析など、複数画像処理の高度な活用法を示します。

## 技術的解説

### 複数画像の処理

OpenAI Responses APIでは、単一のリクエストで複数の画像を送信し、それらを総合的に分析することができます。これにより、画像間の比較、パターン検出、関連性分析などの高度なタスクが可能になります。

#### 複数画像の送信

複数の画像を含むリクエストは、以下のように構築します：

```python
def analyze_multiple_images(client, image_paths, prompt):
    """複数の画像を分析します。"""
    # 入力形式を構築
    content = [{"type": "text", "text": prompt}]
    
    # 画像を追加
    for path in image_paths:
        base64_image = encode_image_to_base64(path)
        content.append({
            "type": "image_url",
            "image_url": {
                "url": f"data:image/jpeg;base64,{base64_image}"
            }
        })
    
    # APIリクエスト
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": content}]
    )
    
    return {
        "id": response.id,
        "model": response.model,
        "created_at": response.created,
        "output_text": response.choices[0].message.content,
        "usage": response.usage
    }
```

#### 画像メタデータの活用

画像の分析をより効果的に行うために、画像のメタデータを抽出して活用することができます：

```python
def get_image_metadata(image_path):
    """画像のメタデータを取得します。"""
    metadata = {
        "filename": os.path.basename(image_path),
        "size_bytes": os.path.getsize(image_path),
    }
    
    if PIL_AVAILABLE:
        try:
            with Image.open(image_path) as img:
                metadata["format"] = img.format
                metadata["mode"] = img.mode
                metadata["width"] = img.width
                metadata["height"] = img.height
                metadata["aspect_ratio"] = round(img.width / img.height, 2)
        except Exception as e:
            print(f"画像メタデータの取得に失敗しました: {e}")
    
    return metadata
```

### 比較分析の実装

複数画像の比較分析は、明示的な比較基準を定義し、それに基づいて各画像を評価することで実現できます：

```python
def generate_comparative_analysis(client, image_paths, criteria_list):
    """複数の画像を指定された基準で比較分析します。"""
    # 基準をJSON文字列に変換
    criteria_json = json.dumps(criteria_list)
    
    # 比較プロンプトの作成
    prompt = f"""
    以下の画像を詳細に比較分析してください。
    
    比較基準:
    {criteria_json}
    
    各比較基準について、すべての画像を評価し、比較してください。
    
    結果は以下のJSON形式で出力してください:
    ```json
    {{
      "comparison_table": [
        {{
          "criteria": "基準名",
          "image1": "画像1の評価",
          "image2": "画像2の評価",
          ...
        }},
        ...
      ],
      "overall_analysis": "全体的な比較分析の要約",
      "unique_features": [
        "画像固有の特徴1",
        "画像固有の特徴2",
        ...
      ]
    }}
    ```
    
    必ずJSONフォーマットで出力してください。
    """
    
    # 分析の実行
    response = analyze_multiple_images(client, image_paths, prompt)
    
    return response
```

この作品は現代風景写真の伝統に位置づけられますが、19世紀ロマン主義絵画の影響を強く受けています。特にカスパー・ダーヴィト・フリードリヒやアルバート・ビアスタットのような画家が追求した崇高（サブライム）の美学を想起させます。技術的には21世紀のデジタル写真技術を用いながらも、19世紀後半から20世紀初頭にかけての絵画的写真（ピクトリアリズム）の美学的伝統を継承しています。

### 技法と表現方法
高解像度デジタル撮影技術を用い、広角レンズによる遠近感の強調と、おそらく偏光フィルターによる水面の反射コントロールが特徴的です。露出は高ダイナミックレンジ（HDR）技術またはグラデーションフィルターを使用して、空と水面の明暗差を適切に処理しています。後処理では彩度と明瞭度の微調整が行われていますが、過度な操作は避けられ、自然主義的表現が維持されています。

### 構図と視覚要素
古典的な三分割構図を基本としながら、水平線を中心とした完全な左右対称性が特徴的です。この対称性は水面の鏡面反射によって強化され、視覚的な調和と安定感を生み出しています。前景から背景へと視線を誘導する奥行き（レイヤー）の配置は、伝統的な風景画の技法を踏襲しています。中央に主要な山を配置する構図は、東洋の山水画の影響も感じさせます。

### 色彩理論分析
冷色系（青と緑）が支配的なパレットは、静謐さと内省的な雰囲気を醸成しています。補色関係にある暖色（山の茶色や金色の光）がアクセントとして効果的に使用され、視覚的な緊張と調和を同時に生み出しています。色彩の飽和度は自然な範囲内に抑えられており、色調の微妙な変化が空間の奥行きを表現しています。

### 芸術的意義
この作品は単なる風景記録を超え、自然の崇高さと人間の小ささを対比する哲学的テーマを内包しています。アンセル・アダムスやエリオット・ポーターなどの環境保護主義的写真家の伝統を継承しつつ、デジタル時代における自然表現の可能性を示しています。完璧な反射による二重性のモチーフは、現実と理想、物質と精神の二元論を視覚的に表現しており、鑑賞者に哲学的な内省を促します。

## 実装上の注意点

複数画像の分析と比較を実装する際の主な注意点は以下の通りです：

### 1. 画像数と処理効率

- **最適な画像数**: 一度に処理する画像数は2〜5枚程度が最適です。多すぎると処理時間が長くなり、分析の質も低下する可能性があります。
- **画像サイズの最適化**: 大きな画像はリサイズして送信することで、処理時間とトークン使用量を削減できます。
- **バッチ処理**: 多数の画像を処理する場合は、小さなバッチに分けて処理することを検討しましょう。

```python
def prepare_images_from_directory(dir_path, max_images=5):
    """ディレクトリから画像ファイルを準備します。"""
    image_extensions = ['.jpg', '.jpeg', '.png', '.gif', '.webp']
    image_files = []
    
    for file in os.listdir(dir_path):
        file_path = os.path.join(dir_path, file)
        if os.path.isfile(file_path) and any(file.lower().endswith(ext) for ext in image_extensions):
            image_files.append(file_path)
            
    # 最大画像数を制限
    return image_files[:max_images]
```

### 2. プロンプト設計

- **明確な比較基準**: 画像比較の基準を明確に定義することで、より構造化された分析結果が得られます。
- **目的の明確化**: 分析の目的（類似点の発見、相違点の特定、パターン検出など）を明確にすることで、より適切な結果が得られます。
- **出力形式の指定**: 構造化された出力が必要な場合は、JSON形式などの具体的な出力形式を指定しましょう。

```python
# 比較基準の明確な定義

### 3. 結果の処理と表示

- **JSON抽出**: 構造化された出力を要求した場合は、レスポンスからJSONデータを適切に抽出する処理が必要です。
- **表形式表示**: 比較結果を表形式で表示することで、情報の理解と比較が容易になります。
- **視覚化**: 必要に応じて、分析結果をグラフや図表で視覚化することを検討しましょう。

```python
def extract_json_from_response(text):
    """レスポンステキストからJSONを抽出します。"""
    try:
        # コードブロック内のJSONを探す
        if "```json" in text and "```" in text.split("```json", 1)[1]:
            json_text = text.split("```json", 1)[1].split("```", 1)[0].strip()
            return json.loads(json_text)
        
        # コードブロックがない場合は全体をJSONとして解析
        return json.loads(text)
    except Exception as e:
        print(f"JSONの抽出に失敗しました: {e}")
        return None
```
