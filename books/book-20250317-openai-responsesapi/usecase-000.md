# 基本的なテキスト応答生成

## 概要

OpenAI Responses APIを使い始める最初のステップとして、このユースケースでは最もシンプルな形式でのテキスト応答生成を実装します。APIの基本的な使い方を理解し、簡単なプロンプトから高品質な応答を得る方法を学びましょう。

## 技術的解説

### APIの基本構造

OpenAI Responses APIは、テキスト生成のための直感的なインターフェースを提供します。基本的なリクエストは以下の要素で構成されます：

- **model**: 使用するAIモデル（例：`gpt-4o`）
- **input**: モデルへの入力テキスト（プロンプト）
- **instructions**: （オプション）モデルの応答方法を指示するシステムプロンプト

### 実装のポイント

このサンプルコードでは、以下の重要な実装パターンを示しています：

1. **環境設定の分離**: API認証情報を`.env`ファイルに保存し、コードから分離
2. **エラーハンドリング**: 適切な例外処理による堅牢な実装
3. **関数の分割**: 責務を明確に分けた関数設計
4. **レスポンス解析**: APIからの応答を構造化して処理

## コード解説

```python
def create_response(client, prompt_text):
    """OpenAI Responses APIを使用してテキスト応答を生成します。"""
    response = client.responses.create(
        model="gpt-4o",
        input=prompt_text,
    )
    return response
```

このコアとなる関数は、OpenAIクライアントとプロンプトテキストを受け取り、APIリクエストを実行します。シンプルな実装ですが、これだけで強力なAI応答を生成できます。

```python
def display_response(response):
    """APIからの応答を整形して表示します。"""
    print("Response ID:", response.id)
    print("Model:", response.model)
    print("Created at:", response.created_at)
    print("\nOutput Text:")
    print(response.output_text)

    print("\nToken Usage:")
    print(f"Input tokens: {response.usage.input_tokens}")
    print(f"Output tokens: {response.usage.output_tokens}")
    print(f"Total tokens: {response.usage.total_tokens}")
```

応答オブジェクトには、生成されたテキスト（`output_text`）だけでなく、メタデータやトークン使用量などの重要な情報も含まれています。これらを表示することで、APIの使用状況を把握できます。

## ビジネス活用シナリオ

このシンプルなAPIの呼び出しだけでも、様々なビジネスシーンで活用できます：

### 1. カスタマーサポートの自動化

基本的なFAQ応答を自動化し、サポートチームの負担を軽減します。顧客からの一般的な質問に対して、一貫性のある高品質な回答を24時間提供できます。

```python
prompt = "返品ポリシーについて教えてください"
response = create_response(client, prompt)
```

### 2. コンテンツ生成の効率化

マーケティング資料やソーシャルメディア投稿のドラフト作成を支援します。基本的なアイデアから出発して、洗練された文章を生成できます。

```python
prompt = "新製品Xの特徴を5つのポイントでまとめてください"
response = create_response(client, prompt)
```

### 3. 情報の要約と整理

長文レポートや会議議事録を簡潔に要約し、重要なポイントを抽出します。情報過多の環境で、意思決定に必要な情報を素早く把握できます。

```python
prompt = "以下の四半期レポートの主要ポイントを3つにまとめてください：[レポート内容]"
response = create_response(client, prompt)
```

## 実装のベストプラクティス

### 1. プロンプトの最適化

より良い結果を得るためには、明確で具体的なプロンプトを設計しましょう：

- **具体的な指示**: 「挨拶してください」より「日本語、英語、中国語で挨拶してください」
- **コンテキストの提供**: 背景情報や目的を含めると、より適切な応答が得られます
- **出力形式の指定**: 必要な場合は、箇条書きや段落など、希望する形式を明示します

### 2. エラー処理の強化

実運用環境では、より堅牢なエラー処理を実装しましょう：

- **リトライロジック**: 一時的なネットワークエラーに対応するためのリトライ
- **タイムアウト設定**: 長時間のリクエストを適切に処理
- **レート制限の考慮**: APIの使用制限に達した場合の対応

### 3. レスポンスの検証

生成されたコンテンツを使用する前に、適切な検証を行いましょう：

- **長さの確認**: 期待される長さの範囲内か
- **内容の検証**: 機密情報や不適切な内容が含まれていないか
- **フォーマットの確認**: 期待される構造（JSON、マークダウンなど）に従っているか

## 発展的な活用方法

このシンプルな基本実装を出発点として、以下のような拡張が可能です：

1. **システムプロンプトの追加**: `instructions`パラメータを使用して、応答のトーンやスタイルを制御
2. **パラメータの調整**: `temperature`や`max_tokens`などのパラメータを調整して、出力の多様性や長さをコントロール
3. **ストリーミング応答**: リアルタイムでテキストを生成する`stream=True`オプションの活用
