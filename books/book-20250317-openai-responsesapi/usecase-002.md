# 複数の入力テキストによる応答生成

## 概要

AIとの対話は、単一の質問と回答だけでなく、文脈や複数の情報源を考慮することで、より豊かで有用なものになります。このユースケースでは、OpenAI Responses APIの複数入力テキスト機能を活用して、会話の履歴を維持したり、複数のドキュメントを同時に処理したりする方法を解説します。

## 技術的解説

### 複数入力の仕組み

OpenAI Responses APIでは、`input`パラメータに単一のテキスト文字列ではなく、メッセージオブジェクトの配列を渡すことができます。各メッセージは以下の構造を持ちます：

```python
{
    "type": "message",
    "role": "user" or "assistant",
    "content": [
        {
            "type": "input_text" or "output_text",
            "text": "メッセージの内容"
        }
    ]
}
```

この構造により、ユーザーとアシスタントの対話履歴や、複数のドキュメントを順序立てて提供できます。

### 実装のポイント

```python
def create_response_with_multiple_inputs(client, messages):
    """複数の入力テキスト（メッセージ）を使用してレスポンスを生成します。"""
    response = client.responses.create(
        model="gpt-4o",
        input=messages
    )
    return response
```

この関数は、メッセージオブジェクトの配列を`input`パラメータとして受け取り、それらすべてを考慮した応答を生成します。

```python
def create_single_message(role, content):
    """単一のメッセージオブジェクトを作成します。"""
    return {
        "type": "message",
        "role": role,
        "content": [
            {
                "type": "input_text" if role == "user" else "output_text",
                "text": content
            }
        ]
    }
```

この補助関数は、メッセージオブジェクトの作成を簡略化します。`role`パラメータに応じて適切な`type`値を設定しています。

## 効果的な複数入力設計のポイント

複数入力テキスト機能を最大限に活用するためのベストプラクティスを紹介します：

### 1. 適切なメッセージ分割

情報を適切な単位で分割することで、モデルの理解を助けます：

- **論理的なまとまり**: 関連する情報は同じメッセージにまとめる
- **段階的な指示**: 複雑なタスクは段階的に指示する
- **明確な区分け**: 異なる種類の情報（例：データと指示）は分けて提供する

### 2. ロールの効果的な活用

`user`と`assistant`のロールを適切に使い分けることで、より自然な対話を実現できます：

- **会話の流れ**: 実際の対話のように、ユーザーとアシスタントが交互に発言する形式を維持する
- **アシスタントの回答例**: 望ましい回答スタイルの例を`assistant`ロールで示す
- **ユーザーの追加情報**: 補足情報や修正は`user`ロールで提供する

### 3. 文脈の最適化

文脈情報の量と質を最適化することで、より適切な応答を引き出せます：

- **関連性の高い情報**: タスクに直接関係する情報に焦点を当てる
- **最新情報の優先**: 最新の対話や指示を優先的に考慮するよう設計する
- **トークン制限の考慮**: 入力トークン数の制限を考慮し、必要に応じて古い情報を要約または省略する

## 実行方法

1. プロジェクトのルートディレクトリに`.env`ファイルを作成し、OpenAI APIキーを設定します：

```
OPENAI_API_KEY=your_api_key_here
```

2. 必要なパッケージをインストールします：

```bash
pip install -r requirements.txt
```

3. スクリプトを実行します：

```bash
python main.py
```
