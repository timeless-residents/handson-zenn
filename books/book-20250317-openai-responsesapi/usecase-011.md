# テキストと画像の複合入力

## 概要

AIの能力は、単一のモダリティを超えて、複数の情報源を組み合わせた理解へと進化しています。このユースケースでは、OpenAI Responses APIを使用して、テキストと画像を組み合わせた複合入力を処理し、より高度な対話や分析を実現する方法を紹介します。単一の会話で複数の画像を扱う方法、会話の文脈を維持しながら画像に関する対話を続ける方法など、マルチモーダル対話の可能性を探ります。

## 技術的解説

### 複合入力の仕組み

OpenAI Responses APIでは、テキストと画像を組み合わせた複合入力を処理できます。これにより、画像に関する質問、複数画像の比較、画像を基にした創造的なコンテンツ生成など、より豊かな対話体験が可能になります。

#### 複合メッセージの構築

複合入力を含むメッセージは、以下のように構築します：

```python
def create_conversation(messages):
    """会話履歴をフォーマットします。"""
    formatted_messages = []

    for msg in messages:
        role = msg.get("role", "user")
        content = msg.get("content", [])

        if isinstance(content, str):
            # テキストのみのメッセージ
            formatted_messages.append({"role": role, "content": content})
        else:
            # 複合メッセージ（テキスト+画像）
            formatted_content = []

            for item in content:
                if item["type"] == "text":
                    formatted_content.append({"type": "text", "text": item["text"]})
                elif item["type"] == "image":
                    # ローカルファイルパスの場合はBase64エンコード
                    if "path" in item:
                        image_data = encode_image_to_base64(item["path"])
                        formatted_content.append(
                            {
                                "type": "image_url",
                                "image_url": {
                                    "url": f"data:image/jpeg;base64,{image_data}"
                                },
                            }
                        )
                    # URLの場合はそのまま使用
                    elif "url" in item:
                        formatted_content.append(
                            {"type": "image_url", "image_url": {"url": item["url"]}}
                        )

            formatted_messages.append({"role": role, "content": formatted_content})

    return formatted_messages
```

#### 複合入力を使った会話

複合入力を含む会話は、以下のように実装します：

```python
def chat_with_images(client, messages):
    """画像を含む会話を行います。"""
    formatted_messages = create_conversation(messages)

    # APIリクエスト
    response = client.chat.completions.create(
        model="gpt-4o", messages=formatted_messages
    )

    return {
        "id": response.id,
        "model": response.model,
        "created_at": response.created,
        "output_text": response.choices[0].message.content,
        "usage": response.usage,
    }
```

### 会話の文脈維持

複合入力を含む会話でも、通常のテキスト会話と同様に文脈を維持できます。これにより、画像に関する対話を継続し、より深い分析や理解を実現できます：

```python
# 初期質問と画像
messages = [
    {
        "role": "user",
        "content": [
            {"type": "text", "text": "この図表について説明してください"},
            {"type": "image", "path": "chart.jpg"}
        ]
    }
]

# 応答の取得
response = chat_with_images(client, messages)

# 会話履歴に応答を追加
messages.append({"role": "assistant", "content": response["output_text"]})

# フォローアップ質問
messages.append(
    {"role": "user", "content": "この図表から読み取れるビジネスへの影響は？"}
)

# フォローアップ応答の取得
follow_up_response = chat_with_images(client, messages)
```

```python
    """画像を含む顧客サポートを提供します。"""
```

### 2. 不動産物件の仮想ツアーと分析

複数の物件写真を送信し、AIが物件の特徴、メリット、改善点などを分析して提供します：


## 実装上の注意点

テキストと画像の複合入力を実装する際の主な注意点は以下の通りです：

### 1. 会話の文脈管理

- **会話履歴の適切な構造化**: 複合入力を含む会話履歴は、適切に構造化する必要があります。特に、テキストのみのメッセージと複合メッセージを区別して処理することが重要です。
- **文脈の維持**: フォローアップ質問や継続的な対話では、前の応答を会話履歴に適切に追加し、文脈を維持することが重要です。
- **メモリ管理**: 長い会話や多数の画像を含む会話では、メモリ使用量に注意し、必要に応じて古い会話履歴を要約または削除することを検討しましょう。

### 2. 画像処理

- **画像サイズと品質**: 大きな画像はAPIの処理に時間がかかるため、適切なサイズにリサイズすることが推奨されます。
- **複数画像の送信**: 一度に多数の画像を送信する場合は、APIの制限に注意し、必要に応じてバッチ処理を検討しましょう。
- **画像形式**: APIがサポートしている画像形式（JPEG、PNG、GIF、WebP）であることを確認しましょう。

### 3. プロンプト設計

- **明確な指示**: 画像に関する質問や指示は、具体的かつ明確に提供することが重要です。
- **目的の明確化**: 画像分析の目的（比較、説明、創作など）を明確にすることで、より適切な結果が得られます。
- **文脈情報の提供**: 背景情報や目的を提供することで、より文脈に沿った分析や応答が得られます。

### 4. エラーハンドリング

- **画像読み込みエラー**: 画像ファイルの読み込みに失敗した場合の適切なエラーハンドリングが必要です。
- **APIエラー**: APIからのエラーレスポンスを適切に処理し、ユーザーに分かりやすいフィードバックを提供しましょう。
- **タイムアウト対策**: 大きな画像や複雑な分析では処理に時間がかかる場合があるため、適切なタイムアウト設定が必要です。
