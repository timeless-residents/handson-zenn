## 第17章：IoTプラットフォーム構築 - Raspberry Piと連携する

IoT（Internet of Things）は、私たちの生活やビジネスに大きな変革をもたらしています。この章では、Raspberry Piを核としたIoTプラットフォームを構築し、センサーデータの収集、可視化、デバイス制御といった一連のプロセスを実践的に解説します。初心者の方でも理解しやすいように、段階的な説明と具体的なコード例を交えながら進めていきます。

### Raspberry Piのセットアップ：OSインストール、ネットワーク設定

**1. 概要と重要性**

Raspberry Piは、低価格ながらパワフルなシングルボードコンピュータであり、IoTプラットフォームの中核として最適です。OSのインストールとネットワーク設定は、すべての始まりであり、ここがうまくいかないと何も始まりません。

**2. 特徴と利点**

*   小型で低消費電力
*   豊富なGPIOポートによる拡張性
*   Linuxベースの自由度の高い開発環境
*   活発なコミュニティと豊富な情報

**3. 事前準備と前提条件**

*   Raspberry Pi本体 (推奨: Raspberry Pi 4 Model B)
*   microSDカード (16GB以上推奨)
*   microSDカードリーダー/ライター
*   モニター、キーボード、マウス (初期設定時)
*   インターネット接続

**4. 基本的な使い方**

**a. OSのインストール (Raspberry Pi OS)**

1.  Raspberry Pi公式ページからRaspberry Pi Imagerをダウンロードし、インストールします。([https://www.raspberrypi.com/software/](https://www.raspberrypi.com/software/))
2.  Raspberry Pi Imagerを起動し、「OSを選ぶ」をクリックします。
3.  「Raspberry Pi OS (32-bit)」または「Raspberry Pi OS (64-bit)」を選択します。（用途に合わせて選択してください。特に理由がなければ64bit版をおすすめします）
4.  「ストレージを選ぶ」をクリックし、microSDカードを選択します。
5.  「書き込む」をクリックし、OSの書き込みを開始します。
6.  書き込みが完了したら、microSDカードをRaspberry Piに挿入します。

**b. Raspberry Piの起動と初期設定**

1.  モニター、キーボード、マウスをRaspberry Piに接続します。
2.  Raspberry Piに電源を接続し、起動します。
3.  初期設定ウィザードに従い、言語、キーボードレイアウト、パスワードを設定します。

**c. ネットワーク設定 (Wi-Fi)**

1.  デスクトップ右上のネットワークアイコンをクリックします。
2.  利用可能なWi-Fiネットワークの一覧から、接続したいネットワークを選択します。
3.  パスワードを入力し、接続します。

**d. SSHの有効化**

SSHは、Raspberry Piにリモートからアクセスするために必要です。ターミナルを開き、以下のコマンドを実行します。

```bash
sudo raspi-config
```

raspi-configのインターフェースが開くので、「Interface Options」を選択し、「SSH」を選択して有効にします。

**5. 実践的なテクニック**

**a. 静的IPアドレスの設定**

DHCPによるIPアドレスの動的な割り当てではなく、Raspberry Piに固定のIPアドレスを割り当てることで、ネットワーク上の他のデバイスからのアクセスが容易になります。

1.  ターミナルで以下のコマンドを実行し、ネットワーク設定ファイルを編集します。

```bash
sudo nano /etc/dhcpcd.conf
```

2.  ファイル末尾に、以下のような設定を追加します。(例: Wi-Fiの場合)

```
interface wlan0
static ip_address=192.168.1.100/24  # 適切なIPアドレス、サブネットマスクを設定
static routers=192.168.1.1       # ルーターのIPアドレス
static domain_name_servers=8.8.8.8 8.8.4.4  # DNSサーバー (Google Public DNS)
```

3.  ファイルを保存し、Raspberry Piを再起動します。

**b. リモートアクセス (SSH)**

別のPCからRaspberry PiにSSHでアクセスするには、ターミナルまたはコマンドプロンプトで以下のコマンドを実行します。

```bash
ssh pi@192.168.1.100  # piはユーザー名、192.168.1.100はRaspberry PiのIPアドレス
```

**6. 応用例とユースケース**

*   スマートホームゲートウェイ
*   リモート監視システム
*   産業用IoTデバイス

**7. トラブルシューティング**

*   **起動しない:** 電源、microSDカードの挿入状況、OSの書き込みが正常に行われたかを確認してください。
*   **ネットワークに接続できない:** Wi-Fiのパスワード、SSIDが正しいか、DHCPサーバーが有効になっているかを確認してください。
*   **SSH接続できない:** SSHが有効になっているか、ファイアウォールがSSHのポート (22番) をブロックしていないかを確認してください。

### MQTTブローカー構築：Mosquittoの導入

**1. 概要と重要性**

MQTT (Message Queuing Telemetry Transport) は、軽量なメッセージングプロトコルであり、IoTデバイス間のデータ交換に広く利用されています。Mosquittoは、オープンソースのMQTTブローカーであり、Raspberry Piで簡単に構築できます。

**2. 特徴と利点**

*   軽量で低消費電力
*   Publish-Subscribeモデルによる柔軟な通信
*   QoS (Quality of Service) による信頼性の高いデータ転送
*   オープンソースで無償利用可能

**3. 事前準備と前提条件**

*   Raspberry Piがインターネットに接続されていること
*   Raspberry Piのターミナルにアクセスできること

**4. 基本的な使い方**

**a. Mosquittoのインストール**

ターミナルで以下のコマンドを実行し、Mosquittoをインストールします。

```bash
sudo apt update
sudo apt install mosquitto mosquitto-clients
```

**b. Mosquittoの起動と停止**

Mosquittoを起動するには、以下のコマンドを実行します。

```bash
sudo systemctl start mosquitto
```

Mosquittoを停止するには、以下のコマンドを実行します。

```bash
sudo systemctl stop mosquitto
```

Mosquittoの状態を確認するには、以下のコマンドを実行します。

```bash
sudo systemctl status mosquitto
```

**c. Mosquittoの設定**

Mosquittoの設定ファイルは `/etc/mosquitto/mosquitto.conf` にあります。セキュリティのため、初期設定ではローカルホストからの接続のみが許可されています。外部からの接続を許可するには、設定ファイルを編集する必要があります。(セキュリティには十分注意してください)

```bash
sudo nano /etc/mosquitto/mosquitto.conf
```

以下の行をコメントアウトまたは削除します。

```
listener 1883
#bind_address 127.0.0.1
```

変更を保存し、Mosquittoを再起動します。

**d. MQTTクライアントの利用**

Mosquittoには、コマンドラインからMQTTメッセージの送受信を行うためのクライアントが含まれています。

*   **Publish:** メッセージを送信するには、以下のコマンドを実行します。

```bash
mosquitto_pub -h localhost -t "topic/test" -m "Hello, MQTT!"
```

*   **Subscribe:** メッセージを受信するには、以下のコマンドを実行します。

```bash
mosquitto_sub -h localhost -t "topic/test"
```

**5. 実践的なテクニック**

**a. ユーザー認証の設定**

MQTTブローカーへの不正アクセスを防ぐため、ユーザー認証を設定することを強く推奨します。

1.  パスワードファイルを作成します。

```bash
sudo mosquitto_passwd -c /etc/mosquitto/passwd pi  # piはユーザー名
```

パスワードを求められるので、入力します。

2.  Mosquittoの設定ファイルを編集します。

```bash
sudo nano /etc/mosquitto/mosquitto.conf
```

以下の行を追加します。

```
allow_anonymous false
password_file /etc/mosquitto/passwd
```

3.  Mosquittoを再起動します。

```bash
sudo systemctl restart mosquitto
```

**b. TLS/SSLによる暗号化**

通信の暗号化により、MQTTメッセージのセキュリティを向上させることができます。

(詳細な手順は割愛しますが、証明書の作成、設定ファイルの編集が必要です。Mosquittoの公式ドキュメントを参照してください。)

**6. 応用例とユースケース**

*   スマートホームデバイスの制御
*   センサーデータの収集と分析
*   産業用機器の遠隔監視

**7. トラブルシューティング**

*   **Mosquittoが起動しない:** 設定ファイルに誤りがないか、ポートが他のプロセスで使用されていないかを確認してください。
*   **MQTTクライアントが接続できない:** ブローカーのIPアドレス、ポート番号、認証情報が正しいか、ファイアウォールがMQTTのポートをブロックしていないかを確認してください。
*   **メッセージが送受信できない:** トピック名が一致しているか、QoSの設定が適切かを確認してください。

### Node-REDによるビジュアルプログラミング

**1. 概要と重要性**

Node-REDは、ビジュアルプログラミング環境であり、IoTアプリケーションの開発を容易にします。GUIベースのインターフェースで、ノードを繋ぎ合わせるだけで、複雑な処理を記述できます。

**2. 特徴と利点**

*   ドラッグ＆ドロップによる直感的な操作
*   豊富なノードライブラリによる拡張性
*   Webブラウザベースの開発環境
*   JavaScriptによるカスタマイズ

**3. 事前準備と前提条件**

*   Raspberry Piがインターネットに接続されていること
*   Node.jsおよびnpmがインストールされていること (Raspberry Pi OSにはプリインストールされていることが多い)

**4. 基本的な使い方**

**a. Node-REDのインストール**

ターミナルで以下のコマンドを実行し、Node-REDをインストールします。

```bash
sudo apt update
sudo apt install node-red
```

**b. Node-REDの起動と停止**

Node-REDを起動するには、以下のコマンドを実行します。

```bash
node-red-start
```

Node-REDを停止するには、以下のコマンドを実行します。

```bash
node-red-stop
```

**c. Node-REDへのアクセス**

Webブラウザを開き、`http://[Raspberry PiのIPアドレス]:1880` にアクセスします。

**d. フローの作成**

Node-REDのインターフェースで、左側のパレットからノードをドラッグ＆ドロップし、キャンバス上に配置します。ノード同士を線で繋ぎ、処理の流れを定義します。

**e. ノードの設定**

ノードをダブルクリックすると、設定画面が開きます。各ノードに必要なパラメーターを設定します。

**f. フローのデプロイ**

フローの作成が完了したら、右上の「デプロイ」ボタンをクリックし、フローをRaspberry Piにデプロイします。

**5. 実践的なテクニック**

**a. MQTTノードの利用**

MQTTノードを使用すると、MQTTブローカーとの通信を簡単に行うことができます。

1.  MQTT inノードを配置し、MQTTブローカーのIPアドレス、ポート番号、トピックを設定します。
2.  MQTT outノードを配置し、MQTTブローカーのIPアドレス、ポート番号、トピックを設定します。
3.  inノードとoutノードを繋ぎ、メッセージの流れを定義します。

**b. センサーデータの処理**

関数ノードを使用すると、JavaScriptでセンサーデータの処理を行うことができます。

1.  センサーから受信したデータを、JSON形式に変換します。
2.  JSONデータから必要な値を抽出し、グラフ表示に適した形式に変換します。

**c. ダッシュボードの作成**

dashboardノードを使用すると、センサーデータを可視化するためのダッシュボードを作成できます。

1.  UI groupノードを配置し、ダッシュボードのグループを作成します。
2.  UI chartノードを配置し、グラフを表示するための要素を追加します。
3.  UI gaugeノードを配置し、メーターを表示するための要素を追加します。

**6. 応用例とユースケース**

*   スマートホームの自動化
*   工場の稼働状況監視
*   農業における環境制御

**7. トラブルシューティング**

*   **Node-REDが起動しない:** Node.jsが正常にインストールされているか、ポートが他のプロセスで使用されていないかを確認してください。
*   **ノードが正常に動作しない:** ノードの設定が正しいか、必要なノードがインストールされているかを確認してください。
*   **ダッシュボードが表示されない:** UIノードが正常に動作しているか、ダッシュボードのパスが正しいかを確認してください。

### センサーデータの収集と可視化

**1. 概要と重要性**

IoTの核心は、センサーデータを収集し、分析し、活用することです。このセクションでは、Raspberry Piに接続されたセンサーからデータを収集し、Node-REDを使って可視化する方法を解説します。

**2. 特徴と利点**

*   リアルタイムなデータモニタリング
*   データ分析による異常検知
*   データに基づいた意思決定の支援

**3. 事前準備と前提条件**

*   Raspberry Piに接続されたセンサー (例: 温湿度センサー DHT11/DHT22, 光センサー BH1750)
*   必要なライブラリのインストール (例: DHT11/DHT22用ライブラリ)

**4. 基本的な使い方**

**a. センサーデータの読み取り**

センサーからデータを読み取るためのPythonスクリプトを作成します。

```python
# 例: DHT11/DHT22からのデータ読み取り
import Adafruit_DHT
import time

sensor = Adafruit_DHT.DHT22
pin = 4  # GPIOピン番号

while True:
    humidity, temperature = Adafruit_DHT.read_retry(sensor, pin)

    if humidity is not None and temperature is not None:
        print('Temp={0:0.1f}*C  Humidity={1:0.1f}%'.format(temperature, humidity))
    else:
        print('Failed to get reading. Try again!')

    time.sleep(2)
```

**b. Node-REDでのデータの受信と処理**

1.  execノードを配置し、Pythonスクリプトを実行します。

```
command: python /home/pi/dht22.py
```

2.  jsonノードを配置し、Pythonスクリプトの出力をJSON形式に変換します。

3.  functionノードを配置し、JSONデータから必要な値を抽出します。

```javascript
msg.payload = {
    temperature: parseFloat(msg.payload.split("Temp=")[1].split("*C")[0]),
    humidity: parseFloat(msg.payload.split("Humidity=")[1].split("%")[0])
};
return msg;
```

**c. データの可視化**

1.  UI chartノードを配置し、温度と湿度をグラフ表示します。
2.  UI gaugeノードを配置し、温度と湿度をメーター表示します。

**5. 実践的なテクニック**

**a. データロギング**

fileノードを使用すると、センサーデータをファイルに記録することができます。これにより、過去のデータを分析したり、異常検知のモデルを構築したりすることが可能になります。

**b. データの可視化のカスタマイズ**

chartノードの設定を調整することで、グラフの色、ラベル、軸などをカスタマイズできます。

*   スマートホームにおけるエネルギー消費量の監視

**7. トラブルシューティング**

*   **センサーからデータが読み取れない:** センサーの配線、ライブラリのインストール状況、GPIOピン番号が正しいかを確認してください。
*   **Node-REDでデータを受信できない:** execノードの設定、Pythonスクリプトの出力形式が正しいかを確認してください。
*   **グラフが表示されない:** chartノードの設定、データ形式が正しいかを確認してください。

### IoTデバイスの制御

**1. 概要と重要性**

IoTデバイスの制御は、単にデータを受信するだけでなく、アクションを実行することで、IoTの可能性を最大限に引き出す上で重要です。このセクションでは、Raspberry Piを使ってIoTデバイスを制御する方法を解説します。

**2. 特徴と利点**

*   遠隔からのデバイス操作
*   自動化された制御
*   省エネルギーと効率化

**3. 事前準備と前提条件**

*   Raspberry Piに接続された制御対象デバイス (例: LED, リレー, サーボモーター)
*   GPIOピン制御のためのライブラリ (例: RPi.GPIO)

**4. 基本的な使い方**

**a. GPIOピンの制御**

PythonスクリプトでGPIOピンを制御します。

```python
import RPi.GPIO as GPIO
import time

GPIO.setmode(GPIO.BCM)
GPIO.setup(18, GPIO.OUT)  # GPIO 18を出力に設定

try:
    while True:
        GPIO.output(18, GPIO.HIGH)  # GPIO 18をHighに設定 (LED点灯)
        time.sleep(1)
        GPIO.output(18, GPIO.LOW)   # GPIO 18をLowに設定 (LED消灯)
        time.sleep(1)
except KeyboardInterrupt:
    GPIO.cleanup()
```

**b. Node-REDでの制御**

1.  injectノードを配置し、制御信号を生成します。
2.  execノードを配置し、Pythonスクリプトを実行します。

```
command: python /home/pi/led_control.py
```

3.  UI buttonノードを配置し、WebブラウザからGPIOピンを制御します。

**5. 実践的なテクニック**

**a. MQTT経由での制御**

MQTTメッセージを受信し、GPIOピンを制御することができます。これにより、インターネット経由でデバイスを制御することが可能になります。

**b. センサーデータに基づいた制御**

センサーデータに基づいて、自動的にデバイスを制御することができます。例えば、温度が一定の値を超えたら、ファンを自動的に回転させるなど。

**6. 応用例とユースケース**

*   スマートホームにおける照明の制御
*   工場のライン制御
*   農業における灌漑システムの制御

**7. トラブルシューティング**

*   **デバイスが動作しない:** GPIOピンの配線、ライブラリのインストール状況、GPIOピン番号が正しいかを確認してください。
*   **Node-REDから制御できない:** execノードの設定、Pythonスクリプトの実行権限が正しいかを確認してください。

### トラブルシューティング：デバイス接続エラー、データ通信エラー

**1. 概要と重要性**

IoTシステムの構築では、さまざまなエラーが発生する可能性があります。このセクションでは、一般的なトラブルシューティングについて解説します。

**2. デバイス接続エラー**

*   **原因:** センサーやアクチュエータがRaspberry Piに正しく接続されていない、GPIOピンの設定が間違っている、必要なライブラリがインストールされていない。
*   **解決策:**
    *   配線を確認し、GPIOピン番号が正しいか確認してください。
    *   必要なライブラリがインストールされているか確認してください。
    *   センサーやアクチュエータのデータシートを参照し、正しい配線を確認してください。
    *   GPIOピンの保護回路を使用することを検討してください。

**3. データ通信エラー**

*   **原因:** MQTTブローカーが起動していない、ネットワーク接続が不安定、トピック名が間違っている、認証情報が間違っている。
*   **解決策:**
    *   MQTTブローカーが起動しているか確認してください。
    *   Raspberry Piがインターネットに接続されているか確認してください。
    *   トピック名が正しいか確認してください。
    *   認証情報が正しいか確認してください。
    *   ファイアウォールがMQTTのポートをブロックしていないか確認してください。

**4. Node-REDのエラー**

*   **原因:** ノードの設定が間違っている、必要なノードがインストールされていない、フローが正しく接続されていない。
*   **解決策:**
    *   ノードの設定を確認し、必要なパラメーターが正しく設定されているか確認してください。
    *   必要なノードがインストールされているか確認してください。
    *   フローが正しく接続されているか確認してください。
    *   Node-REDのログを確認し、エラーメッセージを参考に問題を解決してください。

**5. その他の一般的なエラー**

*   **権限エラー:** Pythonスクリプトの実行権限がない場合、エラーが発生することがあります。`chmod +x [スクリプト名].py` コマンドで実行権限を与えてください。
*   **メモリ不足:** Raspberry Piのメモリが不足すると、Node-REDがクラッシュしたり、プログラムが正常に動作しないことがあります。不要なプロセスを停止するか、より多くのメモリを搭載したRaspberry Piを使用することを検討してください。

**6. まとめ**

IoTシステムの構築では、様々なトラブルが発生する可能性がありますが、一つ一つ丁寧に原因を特定し、解決していくことで、より安定したシステムを構築することができます。ログの確認、エラーメッセージの解読、コミュニティへの質問などが問題解決の鍵となります。

この章を通して、Raspberry Piを基盤としたIoTプラットフォーム構築の基礎を学ぶことができました。この知識を活かし、あなた自身のアイデアを形にしてください。
