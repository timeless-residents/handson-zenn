## 第 13 章：Salesforce Functions：サーバーレスアーキテクチャ

### 13.1 Salesforce Functions の基本：Node.js、Java、Go

#### 13.1.1 概要と重要性

Salesforce Functions は、Salesforce プラットフォーム上でサーバーレスアプリケーションを構築・実行するための強力なツールです。従来の Apex トリガーや Visualforce ページでは実現が難しかった複雑な処理や、リソースを大量に消費する処理をオフロードすることができます。これにより、Salesforce のコア機能を拡張し、パフォーマンスを向上させ、開発効率を向上させることができます。Node.js, Java, Go といった多様な言語をサポートしており、開発者は自身の得意な言語で Functions を記述できます。サーバーレスアーキテクチャを採用することで、インフラの管理から解放され、ビジネスロジックに集中できます。

#### 13.1.2 特徴と利点

Salesforce Functions の主な特徴と利点は以下の通りです。

- **サーバーレス:** インフラストラクチャの管理が不要で、自動的にスケーリングされます。
- **マルチ言語サポート:** Node.js, Java, Go などの複数のプログラミング言語をサポートします。
- **統合された開発環境:** Salesforce DX (Developer Experience) と統合されており、開発、テスト、デプロイが容易です。
- **セキュリティ:** Salesforce のセキュリティモデルを継承し、安全な環境で実行されます。
- **イベント駆動:** Salesforce のイベント (レコードの作成、更新など) に基づいて Function をトリガーできます。
- **従量課金:** 実際に Function が実行された時間に基づいて課金されるため、コスト効率が良いです。
- **Salesforce データへの容易なアクセス:** Salesforce 組織内のデータに安全かつ容易にアクセスできます。

#### 13.1.3 事前準備と前提条件

Salesforce Functions を使用する前に、以下の準備が必要です。

1.  **Salesforce 開発環境 (Developer Edition または Sandbox):** Functions を使用するには、Salesforce の開発環境が必要です。Developer Edition は無料で利用できます。
2.  **Salesforce CLI (Command Line Interface):** Salesforce CLI は、Salesforce 組織との連携や Functions の開発・デプロイに必要なコマンドラインツールです。 [Salesforce CLI インストールガイド](https://developer.salesforce.com/docs/atlas.en-us.sfdx_setup.meta/sfdx_setup/sfdx_setup_install_cli.htm) に従ってインストールしてください。
3.  **Node.js, Java, Go のいずれかの開発環境:** 使用する言語に応じて、それぞれの開発環境をインストールします。
    - **Node.js:** [Node.js 公式サイト](https://nodejs.org/ja/) から最新の LTS (Long Term Support) バージョンをダウンロードしてインストールします。 npm (Node Package Manager) も同時にインストールされます。
    - **Java:** [Oracle JDK](https://www.oracle.com/java/technologies/javase-jdk17-downloads.html) または OpenJDK をインストールします。 Java 11 以上を推奨します。
    - **Go:** [Go 公式サイト](https://go.dev/dl/) から最新バージョンをダウンロードしてインストールします。
4.  **Functions プラグインのインストール:** Salesforce CLI を使用して、Functions プラグインをインストールします。
    ```bash
    sfdx plugins:install @salesforce/plugin-functions
    ```
5.  **Functions の有効化:** Salesforce 組織で Functions を有効にする必要があります。 Salesforce の管理画面から、Functions の設定を行い、有効化してください。

#### 13.1.4 基本的な使い方

Salesforce Functions の基本的な使い方を、Node.js を例に説明します。

1.  **プロジェクトの作成:** Salesforce CLI を使用して、新しい Functions プロジェクトを作成します。

    ```bash
    sfdx generate:function -n my-first-function -l node
    ```

    これにより、`my-first-function`という名前の Node.js Functions プロジェクトが作成されます。プロジェクトのディレクトリ構成は以下のようになります。

    ```
    my-first-function/
    ├── function.js       # Functionsのロジックを記述するファイル
    ├── package.json      # Node.jsのパッケージ定義ファイル
    └── .sfignore         # デプロイ時に無視するファイルを指定
    ```

2.  **Function の記述:** `function.js` ファイルに Function のロジックを記述します。

    ```javascript
    module.exports = async (payload, context) => {
      const name = payload.name || "World";
      const message = `Hello, ${name}!`;

      context.log(message);

      return { message };
    };
    ```

    この例では、入力された名前 (payload.name) を使って挨拶メッセージを作成し、ログに出力して、結果を返します。

3.  **ローカルでの実行:** Salesforce CLI を使用して、ローカルで Function を実行できます。

    ```bash
    sfdx run:function -f my-first-function
    ```

    プロンプトが表示されたら、ペイロードを入力します。例えば、`{"name": "Salesforce"}` を入力すると、以下のような結果が表示されます。

    ```json
    {
      "message": "Hello, Salesforce!"
    }
    ```

4.  **Salesforce 組織へのデプロイ:** Salesforce CLI を使用して、Function を Salesforce 組織にデプロイします。

    ```bash
    sfdx deploy:function -f my-first-function
    ```

    デプロイが完了すると、Salesforce 組織内で Function を利用できるようになります。

5.  **Apex からの呼び出し:** デプロイされた Function は、Apex から呼び出すことができます。

    ```apex
    String functionName = 'my-first-function';
    Map<String, Object> payload = new Map<String, Object>{'name' => 'Apex'};

    // Function の起動 (非同期)
    Function.invoke(functionName, JSON.serialize(payload), new Function.FunctionInvocationCallback() {
      public void onSuccess(Object result) {
        System.debug('Function execution succeeded: ' + result);
      }
      public void onError(String errorMessage) {
        System.debug('Function execution failed: ' + errorMessage);
      }
    });
    ```

    あるいは、Future メソッドを利用して結果を同期的に取得できます。

    ```apex
    @future(callout=true)
    public static void callMyFirstFunction(String functionName, String payload) {
        String result = Function.invoke(functionName, payload);
        System.debug('Function execution succeeded: ' + result);
    }
    ```

#### 13.1.5 実践的なテクニック

- **環境変数の使用:** Functions の設定で環境変数を定義し、Function 内で使用することができます。データベース接続情報や API キーなどの機密情報を安全に管理するために、環境変数の利用を推奨します。
- **ライブラリの利用:** Node.js の場合、`package.json` ファイルに依存関係を記述することで、npm で公開されているライブラリを Function 内で利用できます。Java の場合、Maven や Gradle を使用して依存関係を管理します。
- **ログの活用:** `context.log()` メソッドを使用して、Function の実行中にログを出力することができます。ログは、デバッグやパフォーマンス分析に役立ちます。

#### 13.1.6 応用例とユースケース

Salesforce Functions は、さまざまなユースケースで活用できます。

- **バッチ処理:** 大量のデータを処理するバッチ処理を Functions で実行することで、Salesforce のガバナ制限を回避できます。
- **外部システムとの連携:** 外部 API を呼び出してデータを取得したり、外部データベースにデータを書き込んだりする処理を Functions で実行できます。
- **画像処理:** 画像のリサイズや変換などの処理を Functions で実行できます。
- **機械学習:** 機械学習モデルを実行して、予測や分析を行う処理を Functions で実行できます。

#### 13.1.7 トラブルシューティング

- **デプロイエラー:** デプロイ時にエラーが発生する場合は、Salesforce CLI のバージョンが最新であるか確認してください。また、`sfdx force:org:open` コマンドで Salesforce 組織にアクセスして、デプロイログを確認すると、エラーの原因を特定できます。
- **実行時エラー:** Function の実行時にエラーが発生する場合は、ログを確認してエラーの原因を特定してください。 `context.log()` メソッドを使用して、デバッグ情報を出力すると、より詳細な情報を得られます。
- **タイムアウト:** Function の実行時間が制限時間を超えた場合は、タイムアウトエラーが発生します。処理時間を短縮するか、Functions の設定でタイムアウト時間を延長してください。

#### 13.1.8 まとめと次のステップ

Salesforce Functions は、Salesforce プラットフォーム上でサーバーレスアプリケーションを構築するための強力なツールです。Node.js, Java, Go などの多様な言語をサポートし、柔軟な開発を可能にします。この章では、Functions の基本的な使い方を学びました。次のステップでは、外部サービスとの連携や、より高度なユースケースについて学びましょう。

### 13.2 外部サービスとの連携：API 呼び出し、データベース接続

#### 13.2.1 概要と重要性

Salesforce Functions の重要な機能の一つは、外部サービスとの連携です。API 呼び出しやデータベース接続を通じて、Salesforce のデータを外部システムと統合したり、外部システムの機能を Salesforce で利用したりすることができます。これにより、Salesforce の可能性を大きく広げ、より複雑なビジネス要件に対応できます。

#### 13.2.2 特徴と利点

- **柔軟な連携:** さまざまな API プロトコル (REST, SOAP, GraphQL など) やデータベース (MySQL, PostgreSQL, MongoDB など) をサポートします。
- **セキュリティ:** Salesforce のセキュリティモデルを継承し、安全な環境で外部サービスと連携できます。OAuth などの認証メカニズムを容易に実装できます。
- **パフォーマンス:** 外部サービスとの連携を Functions で行うことで、Salesforce のパフォーマンスに影響を与えることなく、処理を実行できます。
- **スケーラビリティ:** Functions は自動的にスケーリングされるため、大量のリクエストにも対応できます。

#### 13.2.3 事前準備と前提条件

1.  **API エンドポイントまたはデータベースの準備:** 連携する API のエンドポイントや、データベースの接続情報を準備します。
2.  **認証情報:** API やデータベースへのアクセスに必要な認証情報 (API キー、ユーザー名、パスワードなど) を準備します。
3.  **必要なライブラリのインストール:** 使用する言語に応じて、API クライアントライブラリやデータベースドライバをインストールします。

#### 13.2.4 基本的な使い方

##### 13.2.4.1 API 呼び出し (Node.js)

Node.js で外部 API を呼び出す基本的な例を示します。`axios`という HTTP クライアントライブラリを使用します。

1.  **`axios` のインストール:**

    ```bash
    npm install axios
    ```

2.  **Function の記述:**

    ```javascript
    const axios = require("axios");

    module.exports = async (payload, context) => {
      try {
        const response = await axios.get("https://api.example.com/data"); // 例として仮のAPI URLを使用
        const data = response.data;

        context.log(data);

        return { data };
      } catch (error) {
        context.log(error);
        throw error;
      }
    };
    ```

    この例では、`axios.get()` メソッドを使用して、指定された API エンドポイントからデータを取得します。取得したデータはログに出力され、結果として返されます。

##### 13.2.4.2 データベース接続 (Node.js, MySQL)

Node.js で MySQL データベースに接続する基本的な例を示します。`mysql`という MySQL クライアントライブラリを使用します。

1.  **`mysql` のインストール:**

    ```bash
    npm install mysql
    ```

2.  **Function の記述:**

    ```javascript
    const mysql = require("mysql");

    module.exports = async (payload, context) => {
      const connection = mysql.createConnection({
        host: process.env.DB_HOST, // 環境変数から取得
        user: process.env.DB_USER, // 環境変数から取得
        password: process.env.DB_PASSWORD, // 環境変数から取得
        database: process.env.DB_DATABASE, // 環境変数から取得
      });

      return new Promise((resolve, reject) => {
        connection.connect((err) => {
          if (err) {
            context.log(err);
            reject(err);
            return;
          }

          connection.query(
            "SELECT * FROM mytable",
            (error, results, fields) => {
              if (error) {
                context.log(error);
                reject(error);
                return;
              }

              context.log(results);
              resolve({ results });
            }
          );

          connection.end();
        });
      });
    };
    ```

    この例では、`mysql.createConnection()` メソッドを使用してデータベースに接続し、`connection.query()` メソッドを使用してクエリを実行します。環境変数を使用して、データベースの接続情報を安全に管理しています。必ず、Salesforce Functions の設定画面で環境変数を設定してください。

#### 13.2.5 実践的なテクニック

- **認証情報の管理:** 認証情報は、環境変数または Salesforce の資格情報ストアに安全に保管します。コード内に直接記述しないでください。
- **エラーハンドリング:** API 呼び出しやデータベース接続時にエラーが発生する可能性があるため、try-catch ブロックを使用してエラーを適切に処理します。
- **タイムアウトの設定:** API 呼び出しやデータベースクエリにタイムアウトを設定することで、応答がない場合に処理を中断し、リソースの浪費を防ぎます。
- **コネクションプーリング:** データベース接続を再利用するために、コネクションプーリングを使用します。これにより、パフォーマンスを向上させることができます。Node.js の mysql ライブラリを使用している場合は、`mysql.createPool` を利用できます。

#### 13.2.6 応用例とユースケース

- **顧客データの補完:** 外部 API (例: 企業情報データベース) を呼び出して、顧客データ (例: 企業規模、業界) を補完します。
- **支払い処理:** 外部決済 API (例: Stripe, PayPal) を呼び出して、支払い処理を行います。
- **在庫管理:** 外部在庫管理システムと連携して、在庫情報を Salesforce に同期します。
- **IoT デバイスとの連携:** IoT デバイスから送信されたデータを収集し、Salesforce に保存します。

#### 13.2.7 トラブルシューティング

- **API 呼び出しエラー:** API エンドポイントが正しいか、API キーが有効か、必要なパラメータが送信されているかを確認してください。
- **データベース接続エラー:** データベースのホスト名、ポート番号、ユーザー名、パスワード、データベース名が正しいかを確認してください。
- **ネットワークエラー:** Functions が実行されている環境から、外部サービスへのネットワークアクセスが許可されているかを確認してください。
- **タイムアウトエラー:** API 呼び出しやデータベースクエリのタイムアウト時間を延長するか、処理時間を短縮してください。

#### 13.2.8 まとめと次のステップ

Salesforce Functions を使用すると、API 呼び出しやデータベース接続を通じて、外部サービスと簡単に連携できます。認証情報の管理、エラーハンドリング、タイムアウトの設定など、実践的なテクニックを習得することで、より安全で信頼性の高い連携を実現できます。次のステップでは、Functions を活用した具体的なユースケースについて学びましょう。

### 13.3 Function の活用事例：画像処理、データ変換、API 連携

#### 13.3.1 概要と重要性

Salesforce Functions は、様々な処理をオフロードし、Salesforce の機能を拡張するために活用できます。画像処理、データ変換、API 連携といった多様なタスクを Functions で実行することで、Salesforce のパフォーマンスを向上させ、より複雑なビジネスロジックを実装できます。このセクションでは、具体的な活用事例を紹介し、Functions の可能性を探ります。

#### 13.3.2 特徴と利点

- **パフォーマンス向上:** リソースを大量に消費する処理を Functions で実行することで、Salesforce のコア機能のパフォーマンスを維持できます。
- **柔軟性:** 様々なプログラミング言語やライブラリを利用できるため、高度な処理も容易に実装できます。
- **スケーラビリティ:** Functions は自動的にスケーリングされるため、大量のリクエストにも対応できます。
- **開発効率:** Salesforce のガバナ制限を気にすることなく、自由にコードを記述できます。

#### 13.3.3 事前準備と前提条件

1.  **必要なライブラリのインストール:** 活用事例に応じて、必要なライブラリをインストールします。画像処理には`sharp`、データ変換には`lodash`、API 連携には`axios`などがよく使用されます。
2.  **API エンドポイントまたはデータベースの準備:** API 連携を行う場合は、連携先の API エンドポイントを準備します。
3.  **認証情報:** API やデータベースへのアクセスに必要な認証情報を準備します。

#### 13.3.4 基本的な使い方

##### 13.3.4.1 画像処理 (Node.js, `sharp`)

Node.js で`sharp`ライブラリを使用して、画像のリサイズを行う例を示します。

1.  **`sharp` のインストール:**

    ```bash
    npm install sharp
    ```

2.  **Function の記述:**

    ```javascript
    const sharp = require("sharp");
    const fs = require("fs").promises;

    module.exports = async (payload, context) => {
      try {
        const imageBase64 = payload.image; // Base64エンコードされた画像データ
        const buffer = Buffer.from(imageBase64, "base64");

        // 画像リサイズ
        const resizedImageBuffer = await sharp(buffer)
          .resize(200, 200) // 幅200px、高さ200pxにリサイズ
          .toBuffer();

        const resizedImageBase64 = resizedImageBuffer.toString("base64");

        // 一時ファイルに保存 (デバッグ用)
        // await fs.writeFile('resized.jpg', resizedImageBuffer);

        return { resizedImage: resizedImageBase64 };
      } catch (error) {
        context.log(error);
        throw error;
      }
    };
    ```

    この例では、Base64 エンコードされた画像データを受け取り、`sharp`ライブラリを使用してリサイズします。リサイズされた画像データは Base64 エンコードされ、結果として返されます。`fs.promises.writeFile` の部分は、デバッグのためにローカルにファイルを保存する処理です。コメントアウトされているので、必要に応じて有効にしてください。

3.  **Apex からの呼び出し:**

    ```apex
    String imageBase64 = '...'; // Base64エンコードされた画像データ
    Map<String, Object> payload = new Map<String, Object>{'image' => imageBase64};

    // Function の起動 (同期)
    String result = Function.invoke('resize-image', JSON.serialize(payload));
    Map<String, Object> resultMap = (Map<String, Object>) JSON.deserializeUntyped(result);
    String resizedImageBase64 = (String) resultMap.get('resizedImage');

    // resizedImageBase64 を利用
    System.debug('Resized image (Base64): ' + resizedImageBase64);
    ```

##### 13.3.4.2 データ変換 (Node.js, `lodash`)

Node.js で`lodash`ライブラリを使用して、JSON データの構造を変換する例を示します。

1.  **`lodash` のインストール:**

    ```bash
    npm install lodash
    ```

2.  **Function の記述:**

    ```javascript
    const _ = require("lodash");

    module.exports = async (payload, context) => {
      try {
        const data = payload.data; // 変換対象のJSONデータ

        // lodashを使用してデータ変換
        const transformedData = _.map(data, (item) => {
          return {
            id: item.recordId,
            name: item.recordName,
            value: item.recordValue,
          };
        });

        context.log(transformedData);

        return { transformedData };
      } catch (error) {
        context.log(error);
        throw error;
      }
    };
    ```

    この例では、JSON データを受け取り、`lodash.map()` メソッドを使用してデータの構造を変換します。変換されたデータは、結果として返されます。

##### 13.3.4.3 API 連携 (Node.js, `axios`)

Node.js で`axios`ライブラリを使用して、外部 API からデータを取得し、Salesforce に保存する例を示します。

1.  **`axios` のインストール:**

    ```bash
    npm install axios
    ```

2.  **Function の記述:**

    ```javascript
    const axios = require("axios");
    const jsforce = require("jsforce");

    module.exports = async (payload, context) => {
      try {
        const accessToken = context.accessToken; // Salesforce Access Token
        const instanceUrl = context.org.url; // Salesforce Instance URL

        // jsforce で Salesforce に接続
        const conn = new jsforce.Connection({
          instanceUrl: instanceUrl,
          accessToken: accessToken,
        });

        // 外部APIからデータを取得
        const response = await axios.get("https://api.example.com/accounts"); // 例として仮のAPI URLを使用
        const accounts = response.data;

        // Salesforce に Account レコードを作成
        for (const account of accounts) {
          await conn.sobject("Account").create({
            Name: account.name,
            AccountNumber: account.accountNumber,
          });
        }

        return { message: "Accounts created successfully" };
      } catch (error) {
        context.log(error);
        throw error;
      }
    };
    ```

    この例では、`axios.get()` メソッドを使用して外部 API からデータを取得し、`jsforce`ライブラリを使用して Salesforce に Account レコードを作成します。`context.accessToken` と `context.org.url` を利用して、Salesforce への認証情報を取得しています。

#### 13.3.5 実践的なテクニック

- **大規模データの処理:** 大量のデータを処理する場合は、ストリーミング処理やバッチ処理を検討します。
- **エラーハンドリング:** 予期しないエラーが発生した場合に備えて、エラーハンドリングを実装します。
- **ロギング:** 処理の進行状況やエラー情報をログに出力することで、デバッグや監視を容易にします。
- **環境変数の活用:** API キーやデータベース接続情報などの機密情報は、環境変数に格納し、コード内に直接記述しないようにします。

#### 13.3.6 応用例とユースケース

- **リードのエンリッチメント:** 外部 API を呼び出して、リードの情報を補完します。
- **請求書の PDF 生成:** 請求書データを基に PDF ファイルを生成します。
- **機械翻訳:** テキストデータを別の言語に翻訳します。
- **感情分析:** テキストデータから感情を分析します。

#### 13.3.7 トラブルシューティング

- **ライブラリのインストールエラー:** `npm install` コマンドでライブラリのインストールに失敗する場合は、Node.js と npm のバージョンが正しいか、ネットワーク接続が正常かを確認してください。
- **実行時エラー:** Function の実行時にエラーが発生する場合は、ログを確認してエラーの原因を特定してください。
- **タイムアウトエラー:** 処理時間が長すぎる場合は、コードを最適化するか、タイムアウト時間を延長してください。

#### 13.3.8 まとめと次のステップ

Salesforce Functions は、画像処理、データ変換、API 連携など、様々な処理をオフロードし、Salesforce の機能を拡張するために活用できます。具体的な活用事例を参考に、自社のビジネス要件に合わせた Functions を開発し、Salesforce の可能性を最大限に引き出してください。
