## 伊賀で聞いた話

三重県伊賀市で、忍者の末裔を名乗る店主と話す機会があった。

「忍者はメモを取らなかった。取れなかった、というより、取ってはいけなかった。」

メモは証拠になる。潜入中に書き物が見つかれば、正体がばれる。捕まれば仲間も危険になる。だから忍者は、見たものをすべて「脳に焼き付ける」技術を磨いた。

店主が実演してくれた。部屋の中の20個のオブジェクトを0.5秒だけ見て、すべて列挙する。筆者は同じことを試みたが、5〜6個が限界だった。

その後、店主から先祖の話を聞いた。仇討ちにあい、腕を刀で切られた。血だらけになって忍者を続けられなくなり、その地に残って茶屋を開いた。

その話を聞いたとき、不思議なことが起きた。情報として受け取ったはずの話が、身体に刺さってきた。「これが口伝なのだ」と、その瞬間に体感した。

この体験から、一冊の本が生まれた。

## 本書で実装するもの

忍者の網膜瞬間記憶術をAIトレーニングアプリとして実装する。

```
忍者の網膜瞬間記憶トレーナー
├── フラッシュ表示エンジン（画像を0.1〜2秒だけ表示）
├── 想起インターフェース（見たものをテキストで入力）
├── Claude APIによる採点エンジン（正確性・詳細度を評価）
├── Eloレーティングによる難易度自動調整
└── 間隔反復スケジューラ（エビングハウス忘却曲線対応）
```

技術スタックはPython（FastAPI）+ Claude API + HTML/JS。

## なぜAIで採点するか

ルールベースの採点だとこうなる。

```python
# ルールベース（硬直的）
def simple_score(correct: list, recalled: str) -> int:
    count = sum(1 for item in correct if item in recalled)
    return int(count / len(correct) * 100)
```

「リンゴ」と「apple」は別物になる。「赤くて丸い果物」という説明的な回答はゼロ点になる。フィードバックが生成できない。

Claude APIを使うとこれが解決する。自然言語の柔軟性、部分点の計算、そして忍者の言葉遣いでのフィードバック生成まで一括で処理できる。

```python
# Claude APIによる採点（一部抜粋）
prompt = f"""あなたは忍者の記憶術道場の採点官です。

## 正解
{correct_objects}

## 訓練者の回答
{user_recall}

表記のゆれは正解として扱い、部分的な説明にも加点してください。
忍者の段位（見習い/下忍/中忍/上忍/影）で評価し、
具体的なアドバイスを50文字以内で返してください。

JSON形式で返してください。"""
```

## 生存と記憶が結びつくとき

なぜ忍者はこれほどの記憶力を持てたのか。答えは神経科学にある。

アドレナリンとノルアドレナリンが分泌されると、記憶の固定化を担う海馬と扁桃体が強く活性化する。「命がかかった記憶」は通常の何倍もの強度で固定される。

つまり**生存と記憶が結びついたとき、脳は限界を超える**。

現代人に同じ状況は作れない。しかしAIトレーナーで「適度な緊張感」を設計することで、この神経科学的な仕組みを部分的に再現できる。タイムバー、ライフ制限、即時フィードバック——それらは生存プレッシャーのデジタル的近似だ。

## Legacy DXという試み

日本の伝統技術・文化が失われていく速度は、思っているより速い。職人の平均年齢は70歳を超えている。20年後、多くの技術は「知っている人間がいなくなる」。

網膜瞬間記憶術はその一つだ。

このシリーズ（Legacy DX）では、忍術に限らず、組紐・発酵・棚田農業・茶道・能楽など、さまざまな伝統技術をAIでデジタル化していく予定だ。

コードはすべてMITライセンスで公開している。改善・応用・派生は自由だ。

伝統技術の保存は、一人では到底無理なプロジェクトだ。
